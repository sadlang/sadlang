# مقدمة إلى لغة ص

**لغة ص** (Sad) هي لغة برمجة عربية حديثة، مفتوحة المصدر، مصمّمة ليكتب بها المطور بلغته العربية الأم.

## لماذا لغة ص؟

البرمجة بلغتك الأم أسرع فهماً وأعمق تعبيراً. لغة ص تلغي الحاجز اللغوي بين المبرمج العربي وكوده.

```sad
# مرحباً! هذا كود عربي حقيقي
متغير رسالة = "أهلاً بلغة ص!"
اطبع_سطر(رسالة)
```

## الميزات الرئيسية

### مفسّر وسريع التطوير
```bash
sad برنامجي.ص
```
شغّل فوراً دون تجميع.

### مترجم أصيل (via LLVM)
```bash
sadc برنامجي.ص -o برنامجي
./برنامجي
```
أداء عالٍ بكود أصيل.

### دعم كامل للعربية والإنجليزية
```sad
# يمكنك مزج العربية والإنجليزية
متغير myList = [1، 2، 3]
لكل item في myList
  اطبع(item)
نهاية
```

## مبادئ التصميم

| المبدأ | التفصيل |
|--------|---------|
| **عربية أولاً** | كلمات مفتاحية، رسائل خطأ، توثيق — كلها عربية |
| **البساطة** | بنية نحوية واضحة، لا غموض |
| **الأداء** | مفسّر للتطوير، مترجم للإنتاج |
| **الأدوات** | مدير حزم، منسّق، LSP — مدمجة في الحزمة |
