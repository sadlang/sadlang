# المولدات

المولد دالة تُنتج قيماً بشكل تدريجي باستخدام `أنتج`.

```sad
مولد دالة أرقام_لا_نهائية(من = 0)
  متغير ن = من
  بينما (صحيح)
    أنتج ن
    ن += 1
  نهاية
نهاية

# الاستخدام
لكل رقم في أخذ(أرقام_لا_نهائية()، 5)
  اطبع_سطر(رقم)  # 0 1 2 3 4
نهاية
```

## مولد الأولياء

```sad
مولد دالة الأعداد_الأولية()
  متغير المرشحون = {}

  أنتج 2
  المرشحون[2] = 4

  متغير ن = 3
  بينما (صحيح)
    متغير أولي = صحيح
    لكل (م، حد) في المرشحون
      إذا (ن >= حد)
        المرشحون[م] += م
      نهاية
      إذا (ن % م == 0)
        أولي = خطأ
        توقف
      نهاية
    نهاية
    إذا (أولي)
      أنتج ن
      المرشحون[ن] = ن * ن
    نهاية
    ن += 2
  نهاية
نهاية

# أول 10 أعداد أولية
لكل عدد في أخذ(الأعداد_الأولية()، 10)
  اطبع_سطر(عدد)
نهاية
```
