# مكتبة io

```sad
استورد io من "stdlib/io"

# قراءة من المستخدم
متغير اسم = io.اقرأ_سطر("أدخل اسمك: ")
اطبع_سطر("مرحباً " + اسم)

# العمل مع الملفات
متغير ملف = io.افتح("بيانات.txt"، "كتابة")
ملف.اكتب("أول سطر\n")
ملف.اكتب("ثاني سطر\n")
ملف.أغلق()

# قراءة ملف
لكل سطر في io.اقرأ_سطور("بيانات.txt")
  اطبع_سطر(سطر)
نهاية
```

## الدوال الرئيسية

| الدالة | الوصف |
|--------|-------|
| `اطبع(...)` | طباعة بدون سطر جديد |
| `اطبع_سطر(...)` | طباعة مع سطر جديد |
| `io.اقرأ_سطر(رسالة)` | قراءة سطر من المستخدم |
| `io.افتح(مسار، وضع)` | فتح ملف |
| `io.اقرأ_ملف(مسار)` | قراءة ملف كاملاً نصاً |
| `io.اقرأ_سطور(مسار)` | قراءة الملف سطراً سطراً |
| `io.اكتب_ملف(مسار، محتوى)` | كتابة ملف |
| `io.موجود(مسار)` | هل الملف/المجلد موجود؟ |
