# مكتبة math

```sad
استورد رياضيات من "stdlib/math"

اطبع(رياضيات.جذر(16))       # 4
اطبع(رياضيات.أس(2، 10))     # 1024
اطبع(رياضيات.مطلق(-5))      # 5
اطبع(رياضيات.جيب(90))       # 1.0
اطبع(رياضيات.عشوائي(1، 6))  # رقم عشوائي 1..6
اطبع(رياضيات.pi)             # 3.14159...
```

| الدالة | الوصف |
|--------|-------|
| `جذر(ن)` | الجذر التربيعي |
| `أس(أساس، قوة)` | الأس |
| `مطلق(ن)` | القيمة المطلقة |
| `جيب(ز)`/`جتا(ز)`/`ظا(ز)` | الدوال المثلثية (بالدرجات) |
| `لوغاريتم(ن)` | اللوغاريتم الطبيعي |
| `أكبر(أ، ب)` / `أصغر(أ، ب)` | الأكبر/الأصغر |
| `عشوائي(أ، ب)` | رقم عشوائي في نطاق |
| `تقريب(ن، خانات)` | تقريب لمنازل عشرية |
