# أول برنامج بلغة ص

## مرحباً يا عالم!

أنشئ ملفاً باسم `مرحبا.ص` واكتب:

```sad
اطبع_سطر("مرحباً يا عالم! 🌍")
```

شغّله:

```bash
sad مرحبا.ص
```

الخرج:

```
مرحباً يا عالم! 🌍
```

## برنامج بمتغيرات

```sad
# تعريف متغيرات
متغير اسم = "محمد"
متغير عمر = 22
متغير طالب = صحيح

# طباعة
اطبع_سطر("الاسم: " + اسم)
اطبع_سطر("العمر: " + عمر)
اطبع_سطر("هو طالب؟ " + طالب)
```

## برنامج بدالة

```sad
## استقبال المستخدم وتحديد تصنيفه

دالة صنّف_عمر(عمر)
  إذا (عمر < 13)
    ارجع "طفل"
  وإلا إذا (عمر < 18)
    ارجع "مراهق"
  وإلا إذا (عمر < 60)
    ارجع "بالغ"
  وإلا
    ارجع "كبير السن"
  نهاية
نهاية

متغير العمر = 25
اطبع_سطر("التصنيف: " + صنّف_عمر(العمر))
```

## البرنامج الأول بالأصناف

```sad
صنف طالب
  باني(الاسم، المعدل)
    هذا.الاسم = الاسم
    هذا.المعدل = المعدل
  نهاية

  دالة أقرأ_التقدير()
    إذا (هذا.المعدل >= 90)
      ارجع "ممتاز"
    وإلا إذا (هذا.المعدل >= 75)
      ارجع "جيد جداً"
    وإلا إذا (هذا.المعدل >= 60)
      ارجع "جيد"
    وإلا
      ارجع "راسب"
    نهاية
  نهاية

  دالة اطبع_معلوماتي()
    اطبع_سطر("الطالب: " + هذا.الاسم)
    اطبع_سطر("المعدل: " + هذا.المعدل + "%")
    اطبع_سطر("التقدير: " + هذا.أقرأ_التقدير())
  نهاية
نهاية

متغير أحمد = جديد طالب("أحمد علي"، 87)
أحمد.اطبع_معلوماتي()
```

الخرج:
```
الطالب: أحمد علي
المعدل: 87%
التقدير: جيد جداً
```
