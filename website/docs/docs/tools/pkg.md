# sad-pkg — مدير الحزم

```bash
# تثبيت حزمة
sad-pkg تثبيت اسم-الحزمة

# إزالة حزمة
sad-pkg إزالة اسم-الحزمة

# البحث
sad-pkg بحث "كلمة"

# إنشاء مشروع جديد
sad-pkg جديد مشروع-جديد
cd مشروع-جديد
sad-pkg تثبيت

# نشر حزمة
sad-pkg نشر
```

## ملف project.json

```json
{
  "الاسم":    "مشروعي",
  "الإصدار": "1.0.0",
  "الوصف":   "وصف مشروعي",
  "الاعتماديات": {
    "sad-http":  "^2.1.0",
    "sad-json":  "^1.3.0"
  }
}
```
