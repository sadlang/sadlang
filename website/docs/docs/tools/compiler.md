# sadc — المترجم الأصيل (LLVM)

يحوّل كود لغة ص إلى ملف تنفيذي أصيل عبر LLVM 18.

```bash
# ترجمة بسيطة
sadc برنامجي.ص -o برنامجي
./برنامجي

# مستوى التحسين
sadc -O0 برنامجي.ص   # بدون تحسين (للتطوير)
sadc -O2 برنامجي.ص   # تحسين معتدل
sadc -O3 برنامجي.ص   # أقصى تحسين

# عرض LLVM IR
sadc --أظهر-llvm برنامجي.ص

# هدف محدد
sadc --هدف x86_64-linux-gnu برنامجي.ص
sadc --هدف aarch64-apple-macosx12 برنامجي.ص

# الربط بمكتبات خارجية
sadc برنامجي.ص -L/usr/lib -lm
```

## المتطلبات

يتطلب LLVM 18 — مدمج بالكامل في `sadc.exe` (لا تثبيت منفصل).
