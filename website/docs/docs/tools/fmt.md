# sad-fmt — منسّق الكود

```bash
# تنسيق ملف واحد (يُعدّل في المكان)
sad-fmt ملفي.ص

# معاينة فقط (بدون تعديل)
sad-fmt --استعراض ملفي.ص

# تنسيق كل الملفات في مجلد
sad-fmt ./src/

# التحقق (يفشل إذا كان الكود يحتاج تنسيقاً)
sad-fmt --تحقق ملفي.ص
```

## قواعد التنسيق

- المسافة البادئة: 2 مسافات
- سطر فارغ بين الدوال والأصناف
- مسافة حول العوامل الثنائية
- الفاصلة `،` بعدها مسافة
