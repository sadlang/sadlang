# الأنماط والمطابقة

يوفر `طابق` / `عندما` مطابقة أنماط قوية:

```sad
طابق (قيمة)
  عندما 0                    اطبع("صفر")        نهاية
  عندما 1..10                اطبع("1 إلى 10")   نهاية
  عندما رقم س إذا (س > 100)  اطبع("كبير: " + س) نهاية
  عندما نص ن                 اطبع("نص: " + ن)   نهاية
  عندما [أول، ...باقي]       اطبع("قائمة")      نهاية
  افتراضي                    اطبع("شيء آخر")    نهاية
نهاية
```

## مطابقة الأصناف

```sad
صنف شكل  نهاية
صنف دائرة يرث شكل   باني(نصف_القطر)  هذا.نصف_القطر = نصف_القطر نهاية نهاية
صنف مستطيل يرث شكل  باني(ع، ط)      هذا.ع = ع ؛ هذا.ط = ط نهاية نهاية

دالة مساحة(شكل)
  طابق (شكل)
    عندما دائرة د    ارجع 3.14159 * د.نصف_القطر ** 2   نهاية
    عندما مستطيل م   ارجع م.ع * م.ط                    نهاية
    افتراضي          ارجع 0                              نهاية
  نهاية
نهاية
```
