# تطوير تطبيقات أندرويد بلغة ص

دليل شامل لبناء تطبيقات أندرويد باستخدام لغة ص العربية فقط.

## المقدمة

يتيح لك هذا النظام بناء تطبيقات أندرويد كاملة باستخدام لغة ص دون الحاجة إلى كتابة أي كود بـ Java أو Kotlin أو XML. يتم تنفيذ كود ص مباشرة على الجهاز عبر runtime مدمج في التطبيق.

## البنية المعمارية

```
┌─────────────────────────────────────────────────────┐
│                    تطبيق APK                         │
├─────────────────────────────────────────────────────┤
│  ┌─────────────┐  ┌────────────────────────────┐   │
│  │ ملفات .ص   │  │  مكتبة sad_android.so     │   │
│  │ (assets)    │  │  (Runtime + Interpreter)   │   │
│  └─────────────┘  └────────────────────────────┘   │
│         ↓                      ↓                    │
│  ┌─────────────────────────────────────────────┐   │
│  │            JNI Bridge                        │   │
│  └─────────────────────────────────────────────┘   │
│         ↓                      ↓                    │
│  ┌─────────────┐  ┌────────────────────────────┐   │
│  │ Kotlin      │  │   Jetpack Compose UI       │   │
│  │ SadActivity │  │   (مولد من JSON)           │   │
│  └─────────────┘  └────────────────────────────┘   │
└─────────────────────────────────────────────────────┘
```

## البدء السريع

### 1. إنشاء مشروع جديد

أنشئ مجلداً جديداً وأضف الملفات التالية:

```
my_app/
├── main.ص           # الملف الرئيسي
└── تطبيق.json       # إعدادات التطبيق
```

### 2. ملف الإعدادات (تطبيق.json)

```json
{
    "app_name": "تطبيقي",
    "app_name_en": "My App",
    "package_name": "com.example.myapp",
    "version_code": 1,
    "version_name": "1.0.0",
    "min_sdk": 21,
    "target_sdk": 34,
    "main_file": "main.ص",
    "permissions": ["الإنترنت"],
    "icon": null
}
```

### 3. الكود الرئيسي (main.ص)

```س
استورد "اندرويد"

صنف تطبيقي يرث تطبيق
    
    دالة ابنِ_الواجهة()
        متغير ui = واجهة_المستخدم
        
        متغير عمود = ui.عمود("وسط"، 16)
        ui.هامش(عمود، 24)
        
        ui.أضف(عمود، ui.عنوان("مرحباً بالعالم!"))
        ui.أضف(عمود، ui.نص("هذا تطبيقي الأول بلغة ص"))
        ui.أضف(عمود، ui.زر("اضغطني"، "زر_ترحيب"))
        
        ارجع عمود
    نهاية
    
    دالة عند_ضغط_زر(المعرف)
        إذا (المعرف == "زر_ترحيب")
            رسالة("مرحباً من لغة ص! 🎉")
        نهاية
    نهاية

نهاية

شغّل(جديد تطبيقي())
```

### 4. بناء التطبيق

```bash
python tools/android/build_apk.py --project ./my_app
```

## المكتبة القياسية للأندرويد

### واجهة المستخدم

```س
استورد "اندرويد"

# الحاويات
واجهة_المستخدم.عمود(المحاذاة، التباعد)
واجهة_المستخدم.صف(المحاذاة، التباعد)
واجهة_المستخدم.صندوق(المحاذاة)
واجهة_المستخدم.بطاقة(الارتفاع)
واجهة_المستخدم.تمرير(أفقي)

# النصوص والعرض
واجهة_المستخدم.نص(المحتوى، الحجم، اللون، الوزن)
واجهة_المستخدم.عنوان(المحتوى، الحجم)
واجهة_المستخدم.صورة(المصدر)
واجهة_المستخدم.أيقونة(الاسم، الحجم)
واجهة_المستخدم.فاصل(المسافة)

# التفاعل
واجهة_المستخدم.زر(النص، المعرف)
واجهة_المستخدم.حقل_إدخال(التلميح، العنوان، المعرف)
واجهة_المستخدم.مربع_اختيار(النص، المعرف، محدد)
واجهة_المستخدم.مفتاح(النص، المعرف، مفعل)
واجهة_المستخدم.منزلق(المعرف، الحد_الأدنى، الحد_الأقصى، القيمة)

# التقدم
واجهة_المستخدم.شريط_تقدم(التقدم، غير_محدد)
واجهة_المستخدم.تقدم_دائري(التقدم، غير_محدد)

# الألوان
لون.أبيض()
لون.أسود()
لون.أحمر()
لون.أخضر()
لون.أزرق()
لون.مخصص(أحمر، أخضر، أزرق)
```

```س
# معلومات الجهاز

# الملفات

# الموقع الجغرافي

# المشاركة

مشاركة.شارك_صورة(المسار)

# الحافظة
حافظة.انسخ(النص)
حافظة.الصق()

# الاهتزاز
اهتزاز.اهتز(المدة)
اهتزاز.قصير()

# الروابط
روابط.افتح(الرابط)

روابط.هاتف(الرقم)

# الحوارات
حوار.رسالة(النص)
```

### طلبات HTTP

```س
# طلبات بسيطة

إذا (نتيجة.نجح)
    اطبع(نتيجة.محتوى)
وإلا
    اطبع("خطأ: " + نتيجة.خطأ)

# JSON

api.رمز_التوثيق("your-token")
```

## البناء والنشر

### بناء نسخة تطوير
```bash

```

```bash
adb install build/android_build/app/build/outputs/apk/debug/app-debug.apk
```
