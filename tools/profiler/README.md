# مصحح الأداء — لغة ص (sad-profiler v1.2.0)

مصحح أداء مدمج مع مفسر لغة ص لتحليل زمن التنفيذ وتحديد الاختناقات.

## الاستخدام السريع

```bash
# استخدام الأداة المستقلة
sad-profiler ملف.ص
sad-profiler ملف.ص --صيغة=html --ملف=تقرير.html
sad-profiler ملف.ص --صيغة=json --ملف=تقرير.json

# استخدام مع المفسر
sad --تنميط ملف.ص
sad --profile --profile-format=json ملف.ص
```

### أمثلة متقدمة

```bash
# ملخص مختصر
sad-profiler ملف.ص --ملخص

# تقرير التوزيع الزمني
sad-profiler ملف.ص --توزيع

# دوال ساخنة/باردة
sad-profiler ملف.ص --ساخن-بارد

# تفاصيل دالة محددة
sad-profiler ملف.ص --تفاصيل=جمع

# مقارنة دالتين
sad-profiler ملف.ص --مقارنة=جمع,ضرب

# أخذ عينات (كل 10 استدعاءات)

# تصدير HTML مع استبعاد المدمجة
sad-profiler ملف.ص --صيغة=html --بدون-مدمجة --ملف=تقرير.html
```

## ما يقيسه المصحح

- **عدد استدعاءات كل دالة** — كم مرة استُدعيت (مستخدم + مدمجة)
- **الزمن الشامل** (inclusive) — زمن الدالة + الدوال الفرعية
- **الزمن الحصري** (exclusive) — زمن الدالة بدون الفرعية (محمي من القيم السالبة)
- **معدل الاستدعاء** (callRate) — استدعاءات/ثانية
- **الاستدعاءات التكرارية** — عدد مرات استدعاء الدالة لنفسها ونسبتها المئوية
- **التباين والانحراف المعياري** — variance و stdDev لزمن الاستدعاءات
- **الكفاءة** — نسبة الزمن الحصري إلى الشامل
- **ساخن/بارد** — تصنيف تلقائي: ساخنة (>10% من الزمن أو >100 استدعاء) وباردة (<1% و<5 استدعاءات)
- **شجرة الاستدعاءات** — بنية الاستدعاء الكاملة مع الأزمنة
- **نقاط الاختناق** — الدوال التي تستهلك أكثر من 25% من الزمن
- **تتبع المتغيرات** — عدد المتغيرات المُنشأة أثناء التنفيذ
- **تتبع النطاقات** — عدد انتقالات النطاق وأقصى عمق
- **تتبع الكائنات** — عدد الكائنات المُنشأة (حسب الصنف)

## صيغ التقرير

### TEXT (نصي)
تقرير نصي ملون مع جدول وشجرة استدعاءات وأشرطة نسبة.

### JSON
بيانات كاملة بصيغة JSON للتحليل البرمجي، تشمل كل الإحصائيات.

### HTML
تقرير تفاعلي RTL مع:
- ثيم داكن/فاتح قابل للتبديل
- 3 تبويبات: جدول الدوال، رسوم بيانية، شجرة استدعاء
- جدول قابل للفرز (بالنقر على رؤوس الأعمدة)
- بحث وتصفية
- تصدير CSV مباشر من المتصفح
- أشرطة بيانية CSS بدون مكتبات خارجية
- أقسام قابلة للطي/التوسيع

### FLAMEGRAPH (لهب)
صيغة FlameGraph المتوافقة مع أدوات مثل `flamegraph.pl`.

### CSV
بيانات مفصولة بفاصلة للاستيراد في Excel.

## الأداء والتحسينات

- **عدادات ذرية**: جميع العدادات العامة (`totalFunctionCalls`, `totalBuiltinCalls`, إلخ) تستخدم `std::atomic<uint64_t>` مع `memory_order_relaxed` — بدون أقفال
- **أخذ العينات**: خيار `--عينات=N` لتسجيل استدعاء واحد من كل N — يقلل الحمل بشكل كبير في البرامج الثقيلة
- **قفل مزدوج التحقق**: `maxScopeDepth_` يستخدم double-checked locking لتقليل التنافس
- **حد التتبع**: `maxTrackedFunctions=10000` يمنع استهلاك الذاكرة المفرط

## الأمان والمتانة

- حماية من الأسماء الفارغة في `onFunctionEnter`
- حماية من الزمن الحصري السالب (`std::max(0, elapsed - children)`)
- حد أقصى للدوال المتتبعة (10,000) لمنع تسرب الذاكرة
- حماية من المسارات الفارغة في `saveReport`
- RAII عبر `ProfileGuard` مع دعم النقل والإلغاء

## ربط المفسر

المصحح مربوط بالمفسر في 3 نقاط:
1. **استدعاء الدوال** — `expression_evaluator_calls.cpp`: `ProfileGuard` يغلف تنفيذ الدوال
2. **المتغيرات والنطاقات** — `statement_executor.cpp`: تتبع إنشاء المتغيرات ودخول/خروج النطاقات
3. **الكائنات** — `expression_evaluator_oop.cpp`: تتبع إنشاء الكائنات حسب الصنف
