# سجل التغييرات / Changelog

## [2.0.0] - 2025-01-01

### جديد / New
- دعم جميع الكلمات المفتاحية الـ 40 المحجوزة + 20 كلمة سياقية + 9 أنواع مدمجة
- تمييز التعليقات بالترتيب الصحيح: توثيق كتلة `#** **#` → كتلة `#* *#` → توثيق سطر `##` → سطر `#`
- 30 قالب كود (snippets) محدّثة بالصيغة الصحيحة
- أمر تشغيل الملف مباشرة (F5) مع زر ▶ في شريط المحرر
- أمر إنشاء ملف .ص جديد
- اختصار Ctrl+Shift+R لإعادة تشغيل خادم اللغة
- إعدادات محرر مخصصة لملفات .ص (Unicode highlights off, tab size 4)
- دعم الاستيفاء في النصوص `\{تعبير}`
- تمييز العوامل: `**` (أس), `&&`, `||`, `!`, `->`, `? :`
- تمييز العوامل المنطقية العربية: `و`, `أو`, `ليس`
- دعم طي الكتل: جميع كلمات البداية → `نهاية`
- قواعد مسافة بادئة تلقائية لجميع الكتل

### إصلاحات / Fixes
- إصلاح التعليقات الكتلية `#* *#` التي لم تكن تعمل (خطأ ترتيب regex)
- إزالة 5 كلمات مفتاحية قديمة لم تعد موجودة (`لـ`, `إلى`, `أعمل`, `إرجاع`, `استمرار`)
- إصلاح أسماء الأنواع: `فارغ` → `فراغ`, `قاموس` → `خريطة`, إضافة `عدم` و`أي`
- إصلاح مراقب الملفات: `*.ص` بدلاً من `*.{s,sad}`
- إصلاح إعادة تشغيل الخادم (getExtensionContext المعطلة)
- استبدال `onReady()` المهملة بـ `onDidChangeState()`
- إصلاح ترتيب أنماط الأرقام (hex/binary/octal قبل integer)
- إزالة أنماط الكلمات الإنجليزية الميتة

### تحسينات / Improvements
- خادم LSP محسّن مع 20+ مزوّد (provider)
- دعم Type Hierarchy, تحليل الأداء, تحليل الأمان
- مرجع مراجع متقدم (تجاهل النصوص المقتبسة)
- تنسيق كود محسّن يدعم جميع كلمات الكتل
