## ✨ الميزات الرئيسية

### تمييز بناء الجملة العربية
- **40 كلمة محجوزة** + **20+ كلمة سياقية** + **9 أنواع مدمجة**
- تعليقات: سطرية `#`، كتلية `#* *#`، توثيقية `## ...` و `#** **#`
- نصوص مع استيفاء `"\{تعبير}"`
- أرقام: عشري، ست عشري `0x`، ثنائي `0b`، ثماني `0o`، عشري حقيقي

### خادم اللغة (LSP) عالي الأداء
مدمج مع خادم LSP يوفر:
- **إكمال تلقائي** — دوال، متغيرات، كلمات مفتاحية، أنواع
- **Go to Definition** — الانتقال لتعريف أي رمز
- **Find References** — إيجاد جميع الاستخدامات
- **Hover** — معلومات النوع والتوثيق
- **التنسيق** — تنسيق تلقائي يدعم جميع كتل اللغة
- **التشخيصات** — أخطاء وتحذيرات بالوقت الفعلي
- **إعادة التسمية** — تغيير اسم الرمز في جميع الملفات
- **Type Hierarchy** — شجرة الوراثة بين الأصناف
- **طي الكتل** — طي `دالة`/`صنف`/`إذا`/`بينما` حتى `نهاية`
- **Semantic Tokens** — تلوين دلالي متقدم

### ← دعم RTL (من اليمين لليسار)
- **لوحة RTL جانبية** — عرض الكود بتنسيق عربي حقيقي (من اليمين لليسار) مع تلوين نحوي كامل
- **نقر للانتقال** — انقر أي سطر في لوحة RTL للقفز إليه في المحرر
- **تزامن آني** — أي تعديل في المحرر يظهر فوراً في لوحة RTL
- **تبديل سريع** — `Ctrl+Shift+;` لتبديل بين RTL و LTR
- **شريط حالة** — يعرض اتجاه النص الحالي مع إمكانية النقر للتبديل

اطبع_سطر("النتيجة: " + نتيجة)

## 📦 التثبيت

### من VS Code Marketplace
1. افتح VS Code ← Extensions (`Ctrl+Shift+X`)
2. ابحث عن **"Sad Language"**
3. اضغط **Install**

### من ملف VSIX
```bash
code --install-extension sad-language-2.0.0.vsix
```

### وضع التطوير
```bash
cd tools/vscode-extension
npm install
npm run compile
# اضغط F5 لفتح Extension Development Host
```

## ⚙️ الإعدادات

```jsonc
{
  // مسار خادم اللغة (يكتشف تلقائياً)

  // مسار مفسر لغة ص (يكتشف تلقائياً)

  // تفعيل/تعطيل خادم اللغة
  "sad.server.enabled": true,

  // تفعيل RTL (من اليمين لليسار)

  // تتبع الاتصالات (off / messages / verbose)

  // التنسيق التلقائي
  "sad.formatting.enabled": true,
  "sad.formatting.tabSize": 4,
  "sad.formatting.insertSpaces": true
}
```

## 📋 المتطلبات

- **VS Code** 1.70.0 أو أحدث
- **خادم اللغة** (`sad-lsp`) — يُبنى مع المشروع أو حدد المسار يدوياً
- **المفسر** (`sad`) — لتشغيل الملفات مباشرة

### بناء من المصدر
```bash
cmake -S . -B build
cmake --build build --config Debug --target sad
cmake --build build --config Debug --target sad-lsp-server
```
