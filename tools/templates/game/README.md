# {{PROJECT_NAME}}

A 2D game built with Sad Language and Raylib.

## Features

- ✅ Player movement
- ✅ Score tracking
- ✅ 60 FPS gameplay

## Installation

```bash
# Clone the repository
git clone https://github.com/{{AUTHOR_NAME}}/{{PROJECT_NAME}}.git
cd {{PROJECT_NAME}}

# Install dependencies
sad-pkg install

# Build
sad build
```

## Usage

```bash
# Run game
sad run dev
```

## Controls

- **Arrow Keys** - Move player
- **ESC** - Exit game

## Development

```bash
# Build release version
sad build --release

# Run tests
sad test
```
