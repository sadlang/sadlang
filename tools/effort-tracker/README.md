# 📊 نظام تقدير الجهد (Effort Estimation System)

## مقدمة للمبتدئين

### ما هو "تقدير الجهد"؟

**تقدير الجهد** هو توقع كم من الوقت والعمل تحتاجه مهمة معينة.

```
┌─────────────────────────────────────────────────────────────────┐
│                    لماذا نُقدّر الجهد؟                                    │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   🎯 التخطيط                                                       │
│      └─ كم يوم نحتاج لإنهاء المشروع؟                                         │
│                                                                 │
│   👥 توزيع العمل                                               │
│      └─ من يستطيع إنجاز هذه المهمة؟                            │
│                                                                 │
│   💰 الميزانية                                                 │
│      └─ كم ستكلف هذه الميزة؟                                   │
│                                                                 │
│   ⚠️ إدارة المخاطر                                             │
│      └─ هل لدينا وقت كافٍ؟                                     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### مثال من الحياة

تخيل أنك تريد طبخ وجبة:
- **S (صغير)**: إعداد شاي ☕ = 5 دقائق
- **M (متوسط)**: إعداد فطور 🍳 = 30 دقيقة
- **L (كبير)**: إعداد غداء كامل 🍽️ = 2 ساعة
- **XL (ضخم)**: حفلة عشاء لـ 50 شخص 🎉 = يوم كامل

## كيف نُقدّر؟

### الخطوة 1: فهم المهمة

قبل التقدير، اسأل:

```
┌─────────────────────────────────────────────────────────────────┐
│                    أسئلة الفهم                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   1. ماذا نبني بالضبط؟                                         │
│      └─ هل الهدف واضح؟                                         │
│                                                                 │
│   2. ما الملفات المتأثرة؟                                       │
│      └─ ملف واحد؟ عدة ملفات؟ نظام كامل؟                        │
│                                                                 │
│   3. هل هناك تبعيات؟                                           │
│      └─ هل نحتاج إنهاء شيء آخر أولاً؟                          │
│                                                                 │
│   4. ما مستوى المخاطرة؟                                        │
│      └─ كود جديد؟ تعديل كود قائم؟                              │
│                                                                 │
│   5. هل هناك مجهولات؟                                          │
│      └─ تقنية جديدة؟ مكتبة غير مألوفة؟                         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### الخطوة 2: المقارنة بمهام سابقة

```
💡 أفضل طريقة للتقدير: قارن بشيء أنجزته من قبل!

سؤال: "مهمة إضافة التحقق من الأذونات - ما مقاسها؟"

فكّر: "آخر مرة أضفت نظام تحقق استغرقت يومين...
       هذه المهمة أبسط قليلاً... إذاً M"
```

### الخطوة 3: إضافة هامش الأمان

```
┌─────────────────────────────────────────────────────────────────┐
│                    قاعدة هامش الأمان                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   المجهولات × المخاطرة = الهامش                                │
│                                                                 │
│   • كل شيء واضح + مألوف = +0%                                  │
│   • بعض الأشياء غير واضحة = +25%                               │
│   • تقنية جديدة = +50%                                         │
│   • مجهولات كثيرة = +100% (ضاعف التقدير!)                      │
│                                                                 │
│   مثال:                                                        │
│   ─────                                                        │
│   تقدير أولي: M (2 يوم)                                        │
│   مجهول: مكتبة جديدة (+50%)                                    │
│   التقدير النهائي: M→L (3 أيام)                                │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## نصائح للتقدير الأفضل

### 1. تتبّع التقديرات السابقة

```
المهمة     | التقدير | الفعلي | الفرق
───────────┼─────────┼────────┼───────
T1020      | M (2d)  | 3d     | +50%
T1021      | S (4h)  | 4h     | 0%
T1022      | L (5d)  | 8d     | +60%
```

### 2. احذر من هذه الفخاخ

```
┌─────────────────────────────────────────────────────────────────┐
│                    فخاخ التقدير الشائعة                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│ 🕳️ فخ "هذا سهل"                                                │
│    ❌ "أعرف كيف أفعلها - ساعة واحدة"                           │
│    ✅ فكّر في: الاختبارات؟ التوثيق؟ المراجعة؟                  │
│                                                                 │
│ 🕳️ فخ "90% جاهز"                                               │
│    ❌ "خلصت 90%، باقي القليل"                                  │
│    ✅ الـ 10% الأخيرة غالباً تأخذ 50% من الوقت!                │
│                                                                 │
│ 🕳️ فخ "لو كنت وحدي"                                            │
│    ❌ "لو عملت بدون مقاطعات، يوم واحد"                         │
│    ✅ الواقع: اجتماعات + أسئلة + مراجعات = 3 أيام              │
│                                                                 │
│ 🕳️ فخ "نسخ ولصق"                                               │
│    ❌ "سأنسخ من المشروع الآخر - سريع"                          │
│    ✅ النسخ دائماً يحتاج تعديل + اختبار + تكامل                │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
