# خادم لغة ص — Sad Language Server (LSP)

> **القلب المجّانيّ المفتوح** لذكاء لغة ص داخل المحرّرات (VS Code وغيرها) عبر
> بروتوكول خادم اللغة (Language Server Protocol). يوفّر إكمالًا وتلميحًا وتنقّلًا
> وتشخيصًا وتلوينًا دلاليًّا — كلّه عربيّ أصيل، ومشتقّ من **مصدر الحقيقة**
> (`language-truth/*.yaml`) لا من قوائم مهرَّدة.

<div dir="rtl">

| الحقل | القيمة |
|------|--------|
| الاسم التنفيذيّ | `sad-lsp` |
| المكتبة | `sad_lsp_engine` (ساكنة) |
| اللغة | C++17 |
| الاعتماد | `sad_shared` + `sad_type_system` + `sad_formatter` |
| البروتوكول | LSP عبر JSON-RPC (stdin/stdout) |
| الترميز | UTF-8 عربيّ/إنجليزيّ؛ مواضع UTF-16 |

</div>

## ٣. الارتباط بمصدر الحقيقة (لا تهريد)

ذكاء الخادم مشتقّ من `language-truth/*.yaml` عبر توليد كود وقت البناء — فأيّ
تعديل في المصدر ينساب تلقائيًّا دون لمس C++:

```
language-truth/keywords.yaml ─┐
language-truth/builtins/*.yaml├─► gen_*.py (وقت البناء) ─► *_generated.h
language-truth/types.yaml ────┘        (cmake/codegen.cmake)        │
                                                                    ▼
              sad_shared يُترجم المُولَّد ─────────────► sad_lsp_engine
                                                                    │
                  يستهلكه الخادم وقت التشغيل:                        ▼
   • register_builtins()      ← Sad::Builtins::ALL_BUILTINS   (1073 مدمجة)
   • isKnownBuiltin()         ← السجلّ نفسه                    (كاشف «غير معرّف»)
   • block_openers            ← Sad::Lexer::Generated::allEntries() (دور block_opener)
   • تلوين الكلمات المفتاحية   ← KeywordTable (المعجم المُولَّد)
```

| تُضيف في YAML | يظهر في الخادم بلا تعديل كود |
|---|---|
| مدمجة جديدة | إكمال + تلميح + لا تُحذَّر «غير معرّفة» |
| كلمة بدور `block_opener` | كشف الكتل + الإغلاق بـ«نهاية» |
| كلمة محجوزة جديدة | تمييزها معجميًّا + تلوينها دلاليًّا |

## ٤. الميزات المدعومة

<div dir="rtl">

### التشخيص والتحليل
| الميزة | الوصف |
|--------|-------|
| 🩺 التشخيصات | أخطاء/تحذيرات نحويّة ودلاليّة مع نشر تدريجيّ (debounce) |
| 🔎 كاشف المشاكل المعروفة | أنماط موثَّقة (مثل `SAD-P2`: حلقة قد تكون لانهائية) |
| ⚠️ كشف «غير معرّف» | يستشير سجلّ المدمجات (مصدر الحقيقة) فلا إنذار كاذب |

### ذكاء اللغة والتنقّل
| الميزة | الدالة |
|--------|--------|
| ✦ الإكمال التلقائيّ (مدمجات + رموز + قصاصات) | `completion` |
| ✦ التلميح (hover) للكلمات والدوال | `hover` |
| ✦ الذهاب إلى التعريف | `definition` |
| ✦ كلّ المراجع | `references` |
| ✦ إبراز الرمز في المستند | `document_highlights` |
| ✦ مساعدة التوقيع | `signature_help` |
| ✦ شجرة الاستدعاءات | `call_hierarchy_*` |
| ✦ شجرة الأنواع | `type_hierarchy_*` |
| ✦ روابط المستند | `document_links` |

### العرض والرموز
| الميزة | الدالة |
|--------|--------|
| 🎨 التلوين الدلاليّ (كامل/نطاق) | `semantic_tokens_full` · `semantic_tokens_range` |
| 🧩 رموز المستند ومساحة العمل | `document_symbols` · `workspace_symbols` |
| 📐 نطاق التحديد الذكيّ | `selection_range` |
| 🪟 الطيّ (folding) | `folding_ranges` |
| 🏷️ تلميحات مضمّنة (inlay hints) | `inlay_hints` |
| 🔭 عدسات الكود (code lens) | `code_lens` |

### التحرير
| الميزة | الدالة |
|--------|--------|
| ✏️ إعادة التسمية | `prepare_rename` · `rename` |
| 🛠️ إجراءات الكود | `code_actions` |
| 📏 تنسيق المستند/النطاق/أثناء الكتابة | `format_document` · `format_range` · `on_type_formatting` |

</div>

> **عربيّ أصيل:** الإكمال والبحث يتجاهلان التشكيل وأشكال الألف/الهمزة (تطبيع في
> `arabic_utils`)، والفاصلة العربية «،» محفّز إكمال.

## ٦. البناء والتشغيل

```powershell
# بناء التنفيذيّ
cmake --build build --target sad-lsp

# الناتج
build/bin/Debug/sad-lsp.exe        # يتكلّم LSP عبر stdin/stdout

# الاختبارات (تحت BUILD_TESTS=ON)
ctest --test-dir build -C Debug -R Lsp
```

أربع سويتات اختبار: `LspCodeActionsTests`، `LspEngineComprehensiveTests`،
`LspNavigationComprehensiveTests`، `LspBehaviorTests` (اختبارات C++ + سلوك).

## ٧. ملاحظات معماريّة

- **القلب المجّانيّ:** أُزيلت المزوّدات المتقدّمة (نسخ احتياطيّ، أمان، أداء، جودة،
  مساعد ذكيّ) لتبقى هذه الطبقة منتجًا مجّانيًّا مفتوحًا؛ الميزات المدفوعة منتجات
  منفصلة (نموذج Open Core).
- **محرّك واحد لكلّ عمليّة:** يُبنى الفهرس مرّة لكلّ محرّك؛ لا حالة ساكنة مشتركة
  بين الخيوط (تفاديًا لسباقات التزامن).
- **المعالِجات لا ترمي أبدًا:** كلّ معالِج طلب LSP يتدهور بأمان عند الحالات
  الحدّيّة (مثل مسارات عربيّة) بدل إسقاط طبقة JSON-RPC.
