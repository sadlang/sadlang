# أداة iOS لغة ص — sad-ios

أداة سطر أوامر لبناء تطبيقات iOS من كود لغة ص.

## الأوامر

```bash
# إنشاء مشروع جديد
sad-ios أنشئ تطبيقي
sad-ios create MyApp

# بناء المشروع
sad-ios ابنِ ./تطبيقي
sad-ios build ./MyApp

# بناء + تشغيل في المحاكي
sad-ios شغّل ./تطبيقي
sad-ios run ./MyApp
```

## الخيارات

| الخيار | الوصف |
|--------|-------|
| `--معرّف <id>` | معرّف الحزمة (Bundle ID) |
| `--إصدار <v>` | إصدار التطبيق |
| `--فريق <id>` | معرّف فريق التطوير (Apple Team ID) |
| `--بدون-عربي` | تعطيل دعم الاتجاه من اليمين لليسار (RTL) |

## بنية المشروع المُولَّد

```
تطبيقي/
├── CMakeLists.txt          # ملف بناء CMake
├── Info.plist              # إعدادات التطبيق
├── تطبيقيApp.swift         # نقطة الدخول SwiftUI
├── ContentView.swift       # الواجهة الرئيسية
├── Assets.xcassets/        # أيقونات وصور
├── generated/              # ملفات Swift المُولَّدة من كود ص
└── sad_sources/            # ملفات لغة ص المصدرية
    └── الرئيسية.ص
```

## كيف يعمل

1. تكتب كود بلغة ص في مجلد `sad_sources/`
2. الأداة تستخدم المترجم `sadc` لتحويل الكود إلى Swift
3. يتم بناء المشروع عبر `xcodebuild`

## المتطلبات

- macOS مع Xcode مُثبت
- `sadc` (مترجم لغة ص)
