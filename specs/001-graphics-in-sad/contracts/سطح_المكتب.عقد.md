# عقد واجهة طبقة سطح المكتب بلغة ص

يحدّد هذا العقد الواجهة التصريحيّة التي تعرضها طبقة سطح المكتب الجديدة (`stdlib/سطح_المكتب/`) لبرامج ص، والعقد بينها وبين جسور العتاد. **الأسماء مبدئيّة** — تُثبَّت عند التنفيذ عبر مصدر حقيقة الأدوات/المدمجات، لا تُخترَع عشوائيًّا.

---

## ١. الودجات الجاهزة (مُستهلَكة — لا تُعرَّف هنا)

من `features/graphics/stdlib/رسومات.ص` (موجودة): `نص_عنصر`، `زر`، `صورة`، `أيقونة`، `عمود`، `صف`، `رصة`، `شبكة`، `حاوية`، `بطاقة`، `شريط_تطبيق`، `حوار`، … + طرق التعديل: `.لون`، `.لون_خلفية`، `.حجم_خط`، `.حشوة`، `.تباعد`، `.عند_النقر`. طبقة سطح المكتب **تركِّب** منها.

---

## ٢. صدَفة سطح المكتب (جديد — تركيب)

```
دالة أنشئ_سطح_المكتب(خلفيّة، شريط، أيقونات) → عنصر
    # يركّب: خلفيّة + شريط علويّ (اسم نظام + ساعة) + شبكة أيقونات
```

**العقد**: يُرجع شجرة عناصر جاهزة للتخطيط/الرسم عبر المسار القائم. كلّ نصّ عربيّ يُشكَّل عبر جسر العرض (RTL صحيح). الألوان/القياسات/النصوص ثوابت مسمّاة (لا سلاسل مباشرة).

**شبكة الأيقونات**:
```
دالة شبكة_أيقونات(قائمة_أيقونات) → عنصر    # توزيع منتظم، تسمية تحت كلّ أيقونة
```
كلّ أيقونة: `أيقونة_سطح(رمز، تسمية، إجراء)` حيث `إجراء` ردّ نداء يُفتَح عند النقر.

---

## ٣. مدير النوافذ (جديد جوهريّ)

```
دالة أنشئ_مدير_نوافذ() → مدير
دالة (مدير).افتح_نافذة(عنوان، محتوى، موضع، حجم) → مقبض_نافذة
دالة (مدير).أغلق_نافذة(مقبض)
دالة (مدير).ارفع_للمقدّمة(مقبض)          # إعادة ترتيب z
دالة (مدير).حرّك_نافذة(مقبض، موضع_جديد)
```

**العقد السلوكيّ**:
- الرسم: خلف→أمام (النوافذ بترتيب z).
- الإدخال: hit-test أمام→خلف ⇒ أعلى نافذة تحت المؤشّر تتلقّى الحدث؛ نقرها يرفعها للمقدّمة ويركّزها.
- سحب شريط العنوان ⇒ تحديث موضع النافذة المركَّزة.
- زرّ الإغلاق ⇒ إزالة من القائمة + تحرير (صفر تسريب: حالة النافذة الدائمة تُحرَّر، وأشجار الإطار في الأرينا العابرة).
- حالة النوافذ (القائمة/المواضع/z/التركيز) في المخزن الدائم بمقبض؛ لا مؤشّرات خام.

---

## ٤. مدير الملفّات (جديد — تركيب فوق FS)

```
دالة أنشئ_مدير_ملفّات(مسار_بدء) → عنصر
```

**العقد**: يستدعي `اسرد_مجلد(مسار)`، يبني شبكة أيقونات من النتائج (تمييز ملفّ/مجلّد بصريًّا عبر `هل_مجلد`)، نقر مجلّد ⇒ `اسرد_مجلد` للمسار الفرعيّ (تحديث العرض)، «للأعلى» ⇒ المجلّد الأب. مكدّس المسار في المخزن الدائم. أسماء الملفّات (وقد تكون عربيّة) تُشكَّل عبر جسر العرض.

**⚠️ تصحيح ونستون — حالة المدمجات في مسار المترجم (الوضع المستقلّ)**:
- **جاهز في المترجم**: `اسرد_مجلد` (يُرجع أسماءً نصّيّة **بلا نوع**)، `اقرأ_ملف`، `اكتب_ملف`، (أنشئ/احذف/انسخ/انقل)_ملف.
- **مفسِّر فقط — غائب عن المترجم**: `هل_مجلد`، `حجم_ملف`، `امتداد_ملف`، `المجلد_الحالي`.
- **⇒ يلزم مدمَج جسر جديد `هل_مجلد(مسار)` في المترجم + وقت تشغيل الوضع المستقلّ (RFC)** لتحقيق FR-007 (تمييز ملفّ/مجلّد). بند «آليّة» يسبق US2. لا يُفترَض التركيب الصرف.

---

## ٥. جسر التشغيل (تمديد C++ — يبقى جسرًا)

```
تشغيل_سطح_المكتب(سطح، مدير_نوافذ)    # يعمّم تشغيل_تطبيق لعدّة جذور z
```

**العقد مع الجسر** (السياسة في ص، الآليّة في المكتبة/الجسر):
- `buildRoot(عرض، ارتفاع)` ⇒ يستدعي منطق ص لتركيب: سطح المكتب أسفلَ + نوافذ مرتّبةً z أعلى عبر `رصة` + **تموضع مطلق (آليّة ①)**. لا تعميم فعليّ لازم للترتيب z — ترتيب أبناء `رصة` يكفي.
- `onEvent(نوع، عقدة، **EventData**)` ⇒ يمرّر **الموضع/الدلتا (آليّة ②)** للـhit-test في منطق ص (نافذة ثمّ عنصر). **بلا هذا التمرير يتسرّب السحب إلى C++.**
- محتوى كلّ نافذة يُقصّ عبر **آليّة ③** (حاوية قاصّة/مكدّس قصّ).
- `onIterate(سياق)` ⇒ منطق ص يقرّر إعادة البناء (تنقّل/تحديث ساعة/حالة نافذة). النموذج **محتجَز (retained)**: الشجرة تُحتجَز بـ`shared_ptr` والأحداث تُطابَق بهويّة العقدة — لا إعادة بناء كلّ إطار.
- متغيّرات البيئة عقدٌ مع مُشغِّل sad-os: `SAD_UI_FB_FONT`، `SAD_UI_FB_DEVICE` (قائمة).

| الجسر | المسؤوليّة | ملفّ |
