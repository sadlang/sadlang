## المشكلة 1 — الوصول المزدوج `array[i]["key"]` داخل الدوال

**الحالة:** خطأ تشغيل (crash)
**الخطورة:** عالية

**الوصف العربي:**
عند محاولة الوصول إلى عنصر مصفوفة ثم فور ذلك الوصول إلى مفتاح في الخريطة
الناتجة — داخل دالة — ينهار المفسر بدون رسالة خطأ واضحة.

**مثال للمشكلة:**
```sad
نوافذ = [{"عنوان": "نافذة1", "عرض": 20}]

دالة احصل_على_عنوان(فهرس)
    ارجع نوافذ[فهرس]["عنوان"]   # CRASH هنا
نهاية
```

**المتوقع:** إرجاع "نافذة1"
**الفعلي:** انهيار المفسر / توقف البرنامج

**الحل المؤقت المُتّبع:**
استخدام مصفوفات موازية بدلاً من مصفوفة خرائط:
```sad
نوافذ_عناوين = []
نوافذ_أعراض = []

دالة احصل_على_عنوان(فهرس)
    ارجع نوافذ_عناوين[فهرس]   # يعمل
نهاية
```

## المشكلة 2 — `متغير x = x + 1` داخل `بينما` في دالة لا يُحدَّث

**الحالة:** متغير لا يُحدَّث / حلقة لا نهائية
**الخطورة:** عالية جداً

**الوصف العربي:**
عند استخدام `متغير x = x + 1` داخل حلقة `بينما` または `لكل` بداخل دالة،
يُنشئ المفسر متغيراً محلياً جديداً اسمه `x` بدلاً من تحديث المتغير الموجود.
النتيجة: المتغير الخارجي لا يتغير، والحلقة تصبح لا نهائية.

**مثال للمشكلة:**
```sad
دالة عدّ_العناصر()
    متغير عداد = 0
    بينما (عداد < 5)
        اطبع(عداد)
        متغير عداد = عداد + 1   # لا يُحدَّث عداد الخارجي!!
    نهاية
    ارجع عداد
نهاية
# ← حلقة لا نهائية
```

**المتوقع:** طباعة 0,1,2,3,4 ثم الإرجاع
**الفعلي:** حلقة لا نهائية — عداد دائماً 0

**الحل المؤقت المُتّبع:**
استخدام مصفوفة كعداد مُعدَّل:
```sad
عداد_مصفوفة = [0]

دالة عدّ()
    عداد_مصفوفة[0] = عداد_مصفوفة[0] + 1   # يعمل!
نهاية
```
أو استخدام `لكل` مع مصفوفة فهارس مبنية مسبقاً بدلاً من `بينما`.

## المشكلة 3 — `.الطول()` على مصفوفة عامة في دالة عمقها >= 2

**الحالة:** انهيار / crash
**الخطورة:** عالية

**الوصف العربي:**
دالة `الطول()` تعمل على المصفوفات العامة إذا استُدعيت من المستوى الأول.
لكن إذا استُدعيت الدالة من دالة أخرى (عمق الاستدعاء >= 2)، ينهار المفسر.

**مثال للمشكلة:**
```sad
عناصر = [1, 2, 3, 4, 5]

دالة احصل_على_طول()
    ارجع عناصر.الطول()   # عمق 1: يعمل ✓
نهاية

دالة دالة_أخرى()
    متغير ط = عناصر.الطول()   # عمق 2: CRASH ✗
    ارجع ط
نهاية
```

**الحل المؤقت:**
тحسب الطول في الدالة الأعلى وتمرره كمعامل، أو استخدم `لكل` بدلاً من الطول.

## المشكلة 4 — أسماء المتغيرات التي تبدأ بـ `إ` (همزة تحت الألف)

**الحالة:** SEM001 — متغير غير معرّف
**الخطورة:** متوسطة

**الوصف العربي:**
أسماء المتغيرات التي تبدأ بـ `إ` (الف مع همزة وكسرة تحتها) تُسبب خطأ SEM001
حتى لو كانت معرّفة.

**مثال للمشكلة:**
```sad
إندكسات = []     # SEM001 عند الاستخدام
```

**الحل المؤقت:**
استخدم `أ` (ألف مع فتحة همزة فوقها) بدلاً من `إ`:
```sad
أندكسات = []   # يعمل ✓
```

## المشكلة 9 — `نوع` و`حجم` كلمتان محجوزتان لا تصلحان كأسماء معاملات

**الحالة:** SYN001 — خطأ نحوي
**الخطورة:** عالية

**الوصف العربي:**
الكلمتان `نوع` (type) و`حجم` (size) كلمتان محجوزتان في لغة ص.
استخدامهما كأسماء معاملات في الدوال يُسبب SYN001 فورياً.
هذه الكلمات لا تظهر في قائمة الكلمات المحجوزة الرسمية مما يُسبب إرباكاً.

**مثال للمشكلة:**
```sad
دالة احصل_على_نوع(نوع)      # SYN001 — نوع محجوز
    ارجع نوع
نهاية

دالة احصل_على_حجم(حجم)      # SYN001 — حجم محجوز
    ارجع حجم
نهاية
```

**الحل المؤقت:**
تغيير اسم المعامل:
```sad
دالة احصل_على_نمط(نمط)      # يعمل ✓
    ارجع نمط
نهاية

دالة احصل_على_مقاس(مقاس)    # يعمل ✓
    ارجع مقاس
نهاية
```

**الكلمات المشتبه بها (غير موثقة كمحجوزة):**
- `نوع` → استخدم `نمط`
- `حجم` → استخدم `مقاس`

**التوصية:**
نقل جميع الكلمات المحجوزة إلى توثيق رسمي ووضوح من رسائل الخطأ.

## المشكلة 5 — خلط حرف لاتيني في اسم دالة عربية يُسبب SEM004

**الحالة:** SEM004 — خطأ دلالي
**الخطورة:** منخفضة (خطأ مطوّر)

**الوصف العربي:**
إذا كُتب حرف لاتيني عن طريق الخطأ في بداية اسم دالة عربية
مثل `aطبع_سطر` بدلاً من `اطبع_سطر`، يقبل المحلل اللفظي الاسم
كـ identifier مختلط، ثم يُصدر SEM004 عند الاستخدام.

**مثال:**
```sad
aطبع_سطر("مرحبا")   # SEM004 — 'a' اللاتينية تخلط الاسم
```

**المقترح:**
يُفضَّل أن ينتج المحلل اللفظي تحذيراً أو خطأ فورياً عند اكتشاف اسم مختلط.

## المشكلة 6 — الأعداد الكبيرة تُعرض بالتدوين العلمي

**الحالة:** عرض خاطئ (display issue)
**الخطورة:** منخفضة

**الوصف العربي:**
العدد `0x80000000` (قيمة عنوان PCI = 2147483648) يُخزَّن كعدد عشري
وعند طباعته يظهر كـ `2.14748e+09` بدلاً من `2147483648`.
هذا يُصعّب التشخيص ومقارنة العناوين الثنائية.

**مثال:**
```sad
متغير عنوان = 0x80000000
اطبع(عنوان)   # يطبع: 2.14748e+09  (غير مقروء)
```

**المقترح:**
- دعم `طباعة_سداسي(عدد)` أو تنسيق `"{:x}".شكّل(عدد)`
- أو: طباعة الأعداد الصحيحة الكبيرة بدون تدوين علمي

## المشكلة 7 — لا يوجد operator `+=` للمصفوفات

**الحالة:** ميزة مفقودة
**الخطورة:** منخفضة

**الوصف العربي:**
لا يوجد عامل `+=` للإضافة إلى مصفوفة. يجب استخدام `أضف(مصفوفة، قيمة)`.
هذا مقبول لكن يُفرز بعض الإرباك للمبرمجين القادمين من Python/JS.

## المشكلة 8 — لا يوجد `break` / `تكسّر` في الحلقات

**الحالة:** ميزة مفقودة
**الخطورة:** متوسطة

**الوصف العربي:**
لا توجد طريقة للخروج المبكر من حلقة `لكل` أو `بينما` دون شرط خاص.
هذا يُجبر المطوّر على استخدام متغير راية (flag) زائد.

**المقترح:** إضافة كلمة `اخرج` بمعنى `break` داخل الحلقات.
(ملاحظة: `اخرج` موجودة لكن تبدو للخروج من الدالة لا الحلقة)

## المشكلة 10 — `ارجع` بدون قيمة يُسبب خطأ نحوي

**الحالة:** خطأ نحوي
**الخطورة:** عالية

**الوصف العربي:**
الكلمة `ارجع` بدون تعبير بعدها (void return) تُسبب خطأ:
`"expected expression before 'end' keyword"` — الخطأ يظهر عند `نهاية` وليس عند `ارجع`.

```sad
# ❌ لا يعمل:
دالة أغلق(رقم رقم_واصف)
    اذا (شرط)
        ارجع              # خطأ هنا
    نهاية                  # الخطأ يظهر هنا
نهاية

# ✅ الحل:
دالة أغلق(رقم رقم_واصف)
    اذا (شرط)
        ارجع 0
    نهاية
نهاية
```

## المشكلة 11 — لا يمكن استخدام أصناف مخصصة كأنواع حقول

**الحالة:** قيد في تصميم اللغة
**الخطورة:** عالية

**الوصف العربي:**
لا يقبل المحلل النحوي أسماء أصناف مخصصة كأنواع لحقول الصنف.
يقبل فقط: `رقم`، `نص`، `منطقي`، `مصفوفة`.

```sad
# ❌ لا يعمل:
صنف مدير
    خريطة_بت الخريطة          # خطأ
    كاشف_التسرب الكاشف       # خطأ
نهاية

# ✅ الحل: متغيرات عامة
متغير ع_الخريطة = جديد خريطة_بت()
متغير ع_الكاشف = جديد كاشف_التسرب()
```

**التأثير:** يمنع تركيب الأصناف (composition) الطبيعي. الحل بالمتغيرات العامة ينتهك مبادئ OOP.

## المشكلة 12 — القسمة تُنتج أعداداً عشرية دائماً

**الحالة:** سلوك غير متوقع
**الخطورة:** عالية

**الوصف العربي:**
جميع الأرقام في لغة ص هي `double`. عملية القسمة `/` تُرجع عدداً عشرياً حتى لو كانت النتيجة صحيحة (مثل `8 / 4 = 2.0`). هذا يُسبب خطأ عند استخدام الناتج كفهرس مصفوفة.

```sad
متغير فهرس = 8 / 4      # النتيجة: 2.0 (وليس 2)
مصفوفة[فهرس] = 1         # ❌ خطأ: فهرس غير صحيح
```

**المقترح:** إضافة عامل قسمة صحيحة `//`، أو دالة `صحيح()` للتحويل.

## المشكلة 14 — أخطاء متسلسلة (Cascading Errors)

**الحالة:** جودة رسائل الخطأ
**الخطورة:** متوسطة

**الوصف العربي:**
خطأ واحد (مثل `ارجع` بدون قيمة) يُسبب انهيار التحليل وظهور 8+ أخطاء وهمية في أجزاء أخرى من الكود.

**مثال:** خطأ في سطر 342 → أخطاء وهمية في 398، 781، 1286.

**المقترح:** إضافة خوارزمية تعافي من الأخطاء (error recovery) في المحلل.

## المشكلة 16 — `+=` على حقل كائن داخل مصفوفة لا يعمل

**الحالة:** خطأ في المحلل النحوي
**الخطورة:** عالية

**الوصف العربي:**
عند محاولة استخدام `+=` على حقل كائن يتم الوصول إليه عبر فهرس مصفوفة،
يُصدر المحلل خطأ "هدف الإسناد المركب غير صالح". 
الإسناد البسيط `=` يعمل، فقط `+=` (و `-=` و `*=` إلخ) لا يقبل هذا الهدف.

```sad
# ❌ لا يعمل:
العمليات[فهرس].أبناء += [قيمة_جديدة]

# ✅ الحل البديل:
متغير مؤقت = العمليات[فهرس].أبناء
مؤقت += [قيمة_جديدة]
العمليات[فهرس].أبناء = مؤقت
```

**رسالة الخطأ:**
```
خطأ: هدف الإسناد المركب غير صالح - يجب أن يكون متغيراً أو حقل كائن أو عنصر مصفوفة
```

## المشكلة 17 — `جديد` و`سجل` كلمات محجوزة غير موثّقة

**الحالة:** خطأ في المحلل
**الخطورة:** عالية

**الوصف العربي:**
الكلمتان `جديد` و`سجل` محجوزتان ولا يمكن استخدامها كأسماء متغيرات أو معاملات دوال. 
لا يوجد توثيق واضح لهما في قائمة الكلمات المحجوزة.

```sad
# ❌ لا يعمل:
دالة أضف_عنصر(جديد)
    ارجع جديد
نهاية

متغير سجل = "بيانات"   # خطأ!
```

**الحل المؤقت:** استخدام أسماء بديلة: `عنصر_مُضاف` بدل `جديد`، `سجلّ_بيانات` بدل `سجل`.

## المشكلة 18 — `هذا.method()` داخل methods أخرى لا يحفظ التغييرات

**الحالة:** خطأ في وقت التشغيل
**الخطورة:** عالية

**الوصف العربي:**
عند استدعاء `هذا.method()` من داخل method آخر (بما فيه الباني)، التغييرات
التي يجريها الـ method المُستدعى على حقول `هذا` **لا تُحفظ**.

```sad
صنف مخزن
    باني()
        هذا.بيانات = []
        هذا.أضف("عنصر1")   # يُنفَّذ لكن التغيير يضيع!
    نهاية

    دالة أضف(قيمة)
        هذا.بيانات += [قيمة]   # يُنفَّذ لكن لا يُحفظ في الكائن الأصلي
    نهاية
نهاية

متغير م = جديد مخزن()
اطبع(طول(م.بيانات))   # يطبع 0 بدلاً من 1!
```

**الحل المؤقت:** تنفيذ كل المنطق مباشرة في الباني بدون استدعاء methods أخرى.

## المشكلة 19 — القيم الست عشرية (hex literals) غير مدعومة

**الحالة:** خطأ في المحلل المعجمي
**الخطورة:** عالية (نظام التشغيل يحتاجها كثيراً)

**الوصف العربي:**
كتابة أرقام بصيغة `0xFF` أو `0xAA` تُسبب خطأ تحليل. هذه الصيغة ضرورية
لبرمجة الأنظمة (مثال: عناوين المنافذ، قيم المقاطعات، ألوان ARGB).

```sad
# ❌ لا يعمل:
متغير قناع = 0xFF
متغير لون = 0x00FF00

# ✅ الحل البديل:
متغير قناع = 255
متغير لون = 65280
```

**المقترح:** إضافة دعم `0x` و `0b` في المحلل المعجمي.

## المشكلة 22 — `صحيح` ليس معرّفاً (LITERAL_TRUE)

**الحالة:** مقيّد
**الخطورة:** منخفضة

**الوصف العربي:**
`صحيح` هي القيمة المنطقية `true` ولا يمكن استخدامها كاسم متغير.
