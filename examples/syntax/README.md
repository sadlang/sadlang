# ==========================================
# أمثلة تراكيب لغة ص (Syntax Examples)
# Sad Language Syntax Examples
# ==========================================

يحتوي هذا المجلد على أمثلة شاملة لتراكيب لغة ص.

## الملفات (Files)

### 1. `01_syntax_expressions.s`
اختبار التعابير في لغة ص.
- التعابير الحسابية (Arithmetic expressions)
- التعابير المنطقية (Logical expressions)
- تعابير المقارنة (Comparison expressions)
- التعابير الثلاثية (Ternary expressions)
- الأولوية والأقواس (Precedence and parentheses)

### 2. `02_syntax_statements.s`
اختبار العبارات الأساسية.
- عبارات التصريح (Declaration statements)
- عبارات الإسناد (Assignment statements)
- عبارات الإرجاع (Return statements)
- عبارات الطباعة (Print statements)

### 3. `03_syntax_control_flow.s`
اختبار هياكل التحكم بالتدفق.
- عبارات إذا (if statements)
- عبارات بينما (while loops)
- عبارات لكل (for-each loops)
- التداخل (Nesting)

### 4. `04_syntax_operators.s`
اختبار جميع المشغلات.
- مشغلات حسابية (Arithmetic operators)
- مشغلات مقارنة (Comparison operators)
- مشغلات منطقية (Logical operators)
- مشغلات خاصة (Special operators)

### 5. `05_syntax_comprehensive.s`
اختبار شامل يجمع كل التراكيب.
- برنامج كامل يستخدم معظم الميزات (Complete program using most features)

## الاستخدام (Usage)

قم بتشغيل أي ملف مثال:
```bash
c:\s\s_language\build\bin\Debug\sad.exe examples/syntax/01_syntax_expressions.s
```
