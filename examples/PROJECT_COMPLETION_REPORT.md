## 📚 القواعد النحوية المغطاة / Covered EBNF Rules

### أنواع البيانات / Data Types:
```ebnf
✅ integer_literal ::= decimal | binary | octal | hex
✅ float_literal ::= decimal_part ['.' fractional] [exponent]
✅ boolean_literal ::= 'صحيح' | 'خطأ'
✅ string_literal ::= '"' string_char* '"'
✅ array_literal ::= '[' [expression_list] ']'
✅ map_literal ::= '{' [pair_list] '}'
```

### العبارات / Statements:
```ebnf
✅ function_decl ::= 'دالة' [type] ID '(' [params] ')' block
✅ class_decl ::= 'صنف' ID ['يرث' ID] block
✅ if_stmt ::= 'إذا' expr 'أعمل' block ['وإلا' block]
✅ while_stmt ::= 'بينما' expr 'أعمل' block
✅ for_stmt ::= 'لكل' ID 'في' expr 'أعمل' block
✅ try_stmt ::= 'محاولة' ':' block 'خطأ' [ID] ':' block
✅ import_stmt ::= 'استخدم' string_literal
```

### التعبيرات / Expressions:
```ebnf
✅ call_expr ::= ID '(' [arg_list] ')'
✅ member_access ::= expr '.' ID
✅ array_access ::= expr '[' expr ']'
✅ logical_expr ::= expr ('و' | 'أو' | 'ليس') expr
✅ comparison_expr ::= expr ('==' | '!=' | '<' | '>') expr
✅ arithmetic_expr ::= expr ('+' | '-' | '*' | '/' | '%') expr
```

## 💡 أبرز الأمثلة العملية / Highlight Practical Examples

### 🏦 نظام حساب بنكي (OOP):
```sad
صنف حساب_بنكي:
    بناء(الرصيد_الأولي):
        هذا.رصيد = الرصيد_الأولي
    
    دالة إيداع(المبلغ):
        هذا.رصيد = هذا.رصيد + المبلغ
    
    دالة سحب(المبلغ):
        إذا المبلغ <= هذا.رصيد:
            هذا.رصيد = هذا.رصيد - المبلغ
            إرجاع صحيح
        إرجاع خطأ
```

### 🔒 نظام التحقق من كلمات المرور:
```sad
دالة تجزئة_كلمة_المرور(كلمة_المرور):
    إرجاع crypto.sha256(كلمة_المرور)

دالة تحقق_من_كلمة_المرور(كلمة_المرور، التجزئة):
    إرجاع تجزئة_كلمة_المرور(كلمة_المرور) == التجزئة
```

### 🌐 فحص حالة المواقع:
```sad
دالة فحص_موقع(رابط):
    محاولة:
        استجابة = http.احصل(رابط)
        إذا استجابة.حالة == 200:
            إرجاع "نشط ✅"
        إرجاع "مشكلة ⚠️"
    خطأ:
        إرجاع "غير متصل ❌"
```

### 📊 نظام إدارة الطلاب (Database):
```sad
صنف نظام_الطلاب:
    دالة احسب_الإحصائيات():
        إرجاع قاعدة.استعلام("""
            SELECT COUNT(*) as العدد،
                   AVG(المعدل) as المعدل_العام
            FROM الطلاب
        """)
```
