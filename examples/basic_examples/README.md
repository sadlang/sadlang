# فهرس الأمثلة الأساسية - لغة ص
# Basic Examples Index - Sad Programming Language

نقر هنا لمشاهدة جميع الأمثلة الأساسية في لغة ص التي تغطي المفاهيم الأساسية للبرمجة.

## 📚 قائمة الأمثلة

### 1️⃣ [مرحباً بالعالم](01_hello_world.s)
**Hello World والطباعة الأساسية**
- أول برنامج في لغة ص
- طباعة النصوص العربية والإنجليزية
- طباعة الأرقام والقيم المنطقية
- **المفاهيم**: `اطبع()`, النصوص الأساسية

---

### 2️⃣ [المتغيرات وأنواع البيانات](02_variables_data_types.s)
**Variables and Data Types**
- أنواع البيانات: `رقم`, `نص`, `منطق`
- إنشاء وتعديل المتغيرات
- المصفوفات `مصفوفة`
- أمثلة عملية للاستخدام
- **المفاهيم**: المتغيرات, أنواع البيانات, العمليات الأساسية

---

### 3️⃣ [العمليات الحسابية والمقارنات](03_arithmetic_comparisons.s)
**Arithmetic Operations and Comparisons**
- العمليات الحسابية: `+`, `-`, `*`, `/`, `%`
- عمليات المقارنة: `==`, `!=`, `<`, `>`, `<=`, `>=`
- العمليات المنطقية: `&&`, `||`, `!`
- أمثلة رياضية متنوعة (مساحة، فوائد، خصومات)
- **المفاهيم**: الحساب, المقارنات, المنطق

---

### 4️⃣ [الشروط والقرارات](04_conditions_decisions.s)
**Conditions and Decisions (if-else)**
- الشروط الأساسية: `إذا`, `وإلا`, `وإلا إذا`
- الشروط المتعددة والمتداخلة
- أمثلة عملية: تقييم الدرجات, شروط القبول, الطقس
- **المفاهيم**: `إذا`, `وإلا`, المنطق الشرطي

---

### 5️⃣ [الحلقات والتكرار](05_loops_iteration.s)
**Loops and Iteration**
- حلقة `بينما` (while loop)
- العد التصاعدي والتنازلي
- حساب المجموع والمضروب
- جداول الضرب والبحث
- محاكاة عمليات متكررة
- **المفاهيم**: `بينما`, التكرار, العدادات

---

### 6️⃣ [المصفوفات والعمليات](06_arrays_operations.s)
**Arrays and Array Operations**
- إنشاء المصفوفات والوصول للعناصر
- تعديل وإضافة عناصر
- البحث في المصفوفات
- العمليات الحسابية على المصفوفات
- إيجاد القيم الأكبر والأصغر
- ترتيب المصفوفات (Bubble Sort)
- **المفاهيم**: `مصفوفة`, الفهارس, `طول()`

---

### 7️⃣ [الدوال الأساسية](07_basic_functions.s)
**Basic Functions**
- تعريف الدوال: `دالة`, `نهاية`
- الدوال بدون معاملات والدوال مع معاملات
- إرجاع القيم: `أرجع`
- دوال للنصوص والأرقام والمصفوفات
- دوال التحقق والشروط
- حاسبة شاملة
- **المفاهيم**: `دالة`, `أرجع`, المعاملات

---

### 8️⃣ [الدوال المدمجة](08_builtin_functions.s)
**Built-in Functions**
- دوال النصوص: `طول()`, `أكبر()`, `أصغر()`, `جزء()`
- دوال الرياضيات: `مطلق()`, `جذر()`, `قوة()`
- دوال المصفوفات: `أضف_عنصر()`, `احذف_عنصر()`
- دوال التحويل والتاريخ
- مثال تطبيقي شامل
- **المفاهيم**: الدوال المدمجة, معالجة البيانات

---

### 9️⃣ [أساسيات البرمجة الكائنية](09_oop_basics.s)
**Object-Oriented Programming Basics**
- تعريف الأصناف: `صنف`, خصائص عامة وخاصة
- البانى (Constructor) والدوال
- إنشاء الكائنات: `جديد`
- الوراثة: `يرث`, `عام()`
- أمثلة عملية: طالب، حساب بنكي، مكتبة
- **المفاهيم**: `صنف`, `جديد`, `يرث`, `خاص`

---

### 🔟 [مفاهيم البرمجة المتقدمة](10_advanced_programming.s)
**Advanced Programming Concepts**
- الدوال المتداخلة والنطاقات
- الدوال العودية (Recursion): فيبوناتشي، المضروب
- خوارزميات الترتيب والبحث
- هياكل البيانات: Stack المكدس
- خوارزميات متقدمة: الأرقام الأولية
- **المفاهيم**: العودية, خوارزميات, هياكل البيانات

---

## 🎯 كيفية الاستخدام

### تشغيل الأمثلة
```bash
# انتقل إلى مجلد المشروع
cd C:\s\s_language

# تشغيل مثال محدد
.\build\bin\Debug\sad.exe examples\basic_examples\01_hello_world.s
```

### التسلسل المقترح للتعلم
1. **البداية**: ابدأ بـ Hello World (01) والمتغيرات (02)
2. **الأساسيات**: العمليات الحسابية (03) والشروط (04)
3. **التكرار**: الحلقات (05) والمصفوفات (06)
4. **التنظيم**: الدوال الأساسية (07) والمدمجة (08)
5. **المتقدم**: البرمجة الكائنية (09) والمفاهيم المتقدمة (10)

### نصائح للتعلم
- **اقرأ التعليقات**: كل مثال مشروح بالعربية والإنجليزية
- **جرب التعديل**: قم بتعديل القيم والتجربة
- **اكتب أمثلتك**: استخدم المفاهيم لحل مشاكل جديدة
- **تابع تدريجياً**: لا تتخط الأساسيات

## ⚡ أمثلة سريعة

### طباعة بسيطة
```sad
اطبع("مرحباً بك في لغة ص!") ;
```

### متغير ورقم
```sad
رقم العمر = 25 ;
اطبع("العمر:", العمر) ;
```

### شرط بسيط
```sad
إذا ( العمر >= 18 )
    اطبع("بالغ") ;
وإلا
    اطبع("قاصر") ;
نهاية
```

### حلقة بسيطة
```sad
رقم عداد = 1 ;
بينما ( عداد <= 5 )
    اطبع(عداد) ;
    عداد = عداد + 1 ;
نهاية
```

### دالة بسيطة
```sad
دالة مرحبا( نص الاسم )
    اطبع("مرحباً", الاسم) ;
نهاية

مرحبا("أحمد") ;
```
