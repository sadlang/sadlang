## 🚀 كيفية تشغيل المشاريع
**How to Run the Projects**

### متطلبات التشغيل
1. **مترجم لغة Sad** مثبت ومكون بشكل صحيح
2. **نظام التشغيل:** Windows/Linux/macOS
3. **الذاكرة:** 512MB RAM كحد أدنى
4. **المساحة:** 100MB مساحة فارغة

### خطوات التشغيل
```bash
# انتقل إلى مجلد المشروع المطلوب
cd examples/advanced_projects

# شغل أي مشروع باستخدام مترجم Sad
sad 01_advanced_calculator.s
sad 02_student_management_system.s
sad 03_library_management_system.s
sad 04_file_management_system.s
sad 05_number_guessing_game.s
```
