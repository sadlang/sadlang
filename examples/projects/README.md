# 📁 مشاريع الأمثلة / Example Projects

هذا المجلد يحتوي على مشاريع أمثلة كاملة بلغة ص.

This folder contains complete example projects in Sad language.

## 📋 قائمة المشاريع / Project List

### 🟢 مستوى مبتدئ / Beginner Level

1. **مرحبا_عالم / hello_world**
   - أول برنامج تقليدي
   - First traditional program

2. **آلة_حاسبة / calculator**
   - حاسبة بسيطة مع العمليات الأربع
   - Simple calculator with four operations

3. **لعبة_التخمين / guessing_game**
   - لعبة تخمين الرقم
   - Number guessing game

### 🟡 مستوى متوسط / Intermediate Level

4. **قائمة_المهام / todo_app**
   - تطبيق إدارة المهام
   - Task management application

5. **دفتر_العناوين / address_book**
   - إدارة جهات الاتصال
   - Contact management

6. **محلل_النصوص / text_analyzer**
   - تحليل وإحصائيات النصوص
   - Text analysis and statistics

### 🔴 مستوى متقدم / Advanced Level

7. **خادم_ويب / web_server**
   - خادم HTTP بسيط
   - Simple HTTP server

8. **عميل_واجهة_برمجية / api_client**
   - عميل REST API
   - REST API client

9. **نظام_موزع / distributed_system**
   - نظام بسيط موزع
   - Simple distributed system

## 🚀 كيف تبدأ / How to Start

```bash
# اختر مشروعاً وانتقل إليه
cd examples/projects/مرحبا_عالم

# اقرأ ملف README
cat README.md

# شغّل البرنامج
../../build/bin/sad main.s
```

## 📚 هيكل كل مشروع / Project Structure

```
اسم_المشروع/
├── README.md        # شرح المشروع
├── main.s           # نقطة البداية
├── src/             # ملفات الكود
│   └── *.s
├── tests/           # الاختبارات
│   └── test_*.s
└── docs/            # التوثيق (اختياري)
```
