# قائمة المهام 📝

تطبيق متكامل لإدارة المهام اليومية مكتوب بلغة ص.

## 🎯 الميزات

- ✅ إضافة وحذف المهام
- 🔴 تصنيف الأولويات (عالية، متوسطة، منخفضة)
- 📅 تواريخ الاستحقاق
- 📊 إحصائيات الإنجاز
- 🔍 تصفية وبحث

## 🚀 التشغيل

```bash
sad قائمة_المهام/main.s
```

## 📚 المفاهيم المستخدمة

### 1. البرمجة الكائنية (OOP)

```
فئة مهمة
    رقم المعرف
    نص العنوان
    منطقي مكتملة = خطأ
    
    دالة أكمل()
        هذا.مكتملة = صحيح
    نهاية
نهاية
```

### 2. المصفوفات والقواميس

```
مصفوفة مهام = []
مهام.أضف(مهمة_جديدة)

قاموس إحصاء = {
    "إجمالي": 10،
    "مكتملة": 3
}
```

### 3. الدوال مع الإرجاع

```
دالة المهام_النشطة() -> مصفوفة
    مصفوفة نتيجة = []
    لكل م في المهام
        إذا (! م.مكتملة)
            نتيجة.أضف(م)
        نهاية
    نهاية
    ارجع نتيجة
نهاية
```

### 4. القيم الاختيارية

```
دالة ابحث(رقم معرف) -> مهمة؟
    لكل م في المهام
        إذا (م.المعرف == معرف)
            ارجع م
        نهاية
    نهاية
    ارجع فارغ
نهاية
```

## 💡 الأوامر

| الأمر | الوصف |
|-------|-------|
| `أضف "عنوان"` | إضافة مهمة جديدة |
| `أكمل <معرف>` | تحديد مهمة كمكتملة |
| `احذف <معرف>` | حذف مهمة |
| `قائمة` | عرض جميع المهام |
| `نشطة` | عرض المهام النشطة فقط |
| `مكتملة` | عرض المهام المكتملة فقط |
| `إحصائيات` | عرض الإحصائيات |
