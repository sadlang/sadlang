# دفتر العناوين 📇

تطبيق متكامل لإدارة جهات الاتصال مكتوب بلغة ص.

## 🎯 الميزات

- ✅ إضافة وحذف جهات الاتصال
- 🔍 البحث بالاسم أو الهاتف
- ⭐ تحديد المفضلين
- 🏷️ نظام الوسوم
- 📤 تصدير واستيراد JSON

## 🚀 التشغيل

```bash
sad دفتر_العناوين/main.s
```

## 📚 المفاهيم المستخدمة

### 1. الفئات مع الخصائص والدوال

```
فئة جهة_اتصال
    رقم المعرف
    نص الاسم
    نص الهاتف
    منطقي مفضل = خطأ
    
    دالة بناء(رقم معرف، نص اسم)
        هذا.المعرف = معرف
        هذا.الاسم = اسم
    نهاية
    
    دالة الاسم_الكامل() -> نص
        ارجع هذا.الاسم + " " + هذا.اللقب
    نهاية
نهاية
```

### 2. البحث والتصفية

```
دالة ابحث_بالاسم(نص بحث) -> مصفوفة
    مصفوفة نتائج = []
    لكل جهة في الجهات
        إذا (يحتوي(جهة.الاسم، بحث))
            نتائج.أضف(جهة)
        نهاية
    نهاية
    ارجع نتائج
نهاية
```

### 3. خوارزمية الترتيب

```
دالة رتّب_أبجدياً() -> مصفوفة
    # ترتيب فقاعي
    لكل ي في مدى(0، طول(مرتب) - 1)
        لكل ج في مدى(0، طول(مرتب) - ي - 1)
            إذا (مرتب[ج].الاسم > مرتب[ج + 1].الاسم)
                # تبديل
                متغير مؤقت = مرتب[ج]
                مرتب[ج] = مرتب[ج + 1]
                مرتب[ج + 1] = مؤقت
            نهاية
        نهاية
    نهاية
    ارجع مرتب
نهاية
```

### 4. تصدير JSON

```
دالة إلى_json() -> نص
    ارجع """{
    "معرف": """ + لنص(هذا.المعرف) + """,
    "اسم": """" + هذا.الاسم + """"
}"""
نهاية
```

## 💡 الأوامر

| الأمر | الوصف |
|-------|-------|
| `أضف <اسم> <لقب>` | إضافة جهة جديدة |
| `عرض <معرف>` | عرض تفاصيل جهة |
| `حذف <معرف>` | حذف جهة |
| `بحث <نص>` | البحث في الأسماء |
| `قائمة` | عرض جميع الجهات |
| `مفضلون` | عرض المفضلين |
| `تصدير` | تصدير إلى JSON |
