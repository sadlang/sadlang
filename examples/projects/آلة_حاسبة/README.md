# 🧮 آلة حاسبة / Calculator

## الوصف / Description

آلة حاسبة متكاملة تدعم العمليات الأساسية والمتقدمة.

A complete calculator supporting basic and advanced operations.

## ملفات المشروع / Project Files

```
آلة_حاسبة/
├── README.md           # هذا الملف
├── main.s              # الآلة الحاسبة التفاعلية
├── src/
│   ├── basic.s         # العمليات الأساسية
│   ├── advanced.s      # العمليات المتقدمة
│   └── memory.s        # ذاكرة الآلة الحاسبة
└── tests/
    └── test_calc.s     # اختبارات
```

## الميزات / Features

### العمليات الأساسية
- ➕ الجمع
- ➖ الطرح
- ✖️ الضرب
- ➗ القسمة
- 📐 باقي القسمة

### العمليات المتقدمة
- 🔢 القوة (الأس)
- √ الجذر التربيعي
- 📊 النسبة المئوية
- 🔄 العاملي (Factorial)

### الذاكرة
- 💾 حفظ في الذاكرة (M+)
- 📤 استدعاء من الذاكرة (MR)
- 🗑️ مسح الذاكرة (MC)

## التشغيل / Running

```bash
sad main.s
```
