# لعبة التخمين 🎯

مشروع تعليمي ممتع لتعلم البرمجة من خلال لعبة!

## 🎮 عن اللعبة

لعبة التخمين هي لعبة بسيطة حيث:
1. يختار الكمبيوتر رقماً عشوائياً بين 1 و 100
2. تحاول تخمين هذا الرقم
3. يخبرك الكمبيوتر إذا كان تخمينك أعلى أو أقل
4. لديك 10 محاولات فقط!

## 🚀 التشغيل

```bash
sad لعبة_التخمين/main.s
```

## 📚 المفاهيم المستخدمة

### 1. المتغيرات والثوابت
```
رقم الحد_الأدنى = 1
رقم الحد_الأقصى = 100
```

### 2. الشروط (if/else)
```
إذا (تخمين == الهدف)
    اطبع("🎉 صحيح!")
وإلا_إذا (تخمين < الهدف)
    اطبع("⬆️ أعلى!")
وإلا
    اطبع("⬇️ أقل!")
نهاية
```

### 3. الحلقات (while)
```
بينما (المحاولات < أقصى_محاولات)
    # كود اللعبة
نهاية
```

### 4. الدوال
```
دالة احصل_على_تلميح(رقم تخمين، رقم الهدف) -> نص
    # حساب التلميح
    ارجع تلميح
نهاية
```

### 5. الفئات والكائنات
```
فئة إحصائيات
    رقم الفوز = 0
    
    دالة سجّل_فوز()
        هذا.الفوز = هذا.الفوز + 1
    نهاية
نهاية
```

## 🎓 تمارين للتوسع

1. **غيّر نطاق الأرقام**: اجعلها من 1 إلى 1000
2. **أضف مستويات صعوبة**: سهل، متوسط، صعب
3. **أضف نظام نقاط**: نقاط إضافية للتخمين السريع
4. **أضف وضع اللاعبين**: لاعبان يتنافسان
5. **احفظ الإحصائيات**: في ملف للحفظ بين الجلسات
