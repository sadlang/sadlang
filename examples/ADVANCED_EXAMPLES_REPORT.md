### 1️⃣ `02_functions_advanced.s` - الدوال المتقدمة
**الحجم:** ~500 سطر  
**عدد الأمثلة:** 12 موضوع متقدم

**المحتوى الكامل:**

#### 1. دوال Lambda (الدوال المجهولة)
```sad
الجمع = دالة(أ، ب) => أ + ب
التربيع = دالة(س) => س * س
القيمة_المطلقة = دالة(ع) => إذا ع < 0 إرجاع -ع وإلا إرجاع ع
```
- Lambda بسيط
- Lambda مع شرط
- استخدام Lambda مع المصفوفات

#### 2. الإغلاقات (Closures)
```sad
دالة صانع_عداد(القيمة_الأولية):
    رقم العداد = القيمة_الأولية
    دالة زد():
        العداد = العداد + 1
        إرجاع العداد
    إرجاع زد
```
- عدادات مستقلة
- حفظ الحالة
- Closure للضرب

#### 3. الدوال عالية المستوى
```sad
دالة طبق_مرتين(الدالة، القيمة):
    إرجاع الدالة(الدالة(القيمة))
```
- دوال تقبل دوال
- دوال ترجع دوال
- منقحات مخصصة

#### 4. الدوال العودية (Recursion)
- المضروب
- متتالية فيبوناتشي
- القوة العودية

#### 5. المُولدات (Generators)
- مولد الأرقام
- مولد فيبوناتشي
- استخدام `ينتج`

#### 6. المُزينات (Decorators)
- مزين المؤقت
- مزين السجل
- Wrapper functions

#### 7. الدوال الجزئية (Partial Functions)
- تطبيق جزئي للحجج
- إنشاء دوال متخصصة

#### 8. الدوال النقية vs غير النقية
- Pure functions
- Side effects
- Immutability

#### 9. Currying
```sad
دالة جمع_ثلاثة(أ):
    إرجاع دالة(ب):
        إرجاع دالة(ج):
            إرجاع أ + ب + ج
```

#### 10. تركيب الدوال (Composition)
```sad
دالة ركب(د1، د2):
    إرجاع دالة(س) => د1(د2(س))
```

#### 11. Memoization
- تخزين مؤقت للنتائج
- تحسين الأداء
- فيبوناتشي محفوظ

#### 12. Pipeline للمعالجة
- خط معالجة النصوص
- خط معالجة الأرقام
- سلسلة من التحويلات

### 2️⃣ `03_oop_advanced.s` - البرمجة الكائنية المتقدمة
**الحجم:** ~550 سطر  
**عدد الأمثلة:** 8 مواضيع متقدمة

**المحتوى الكامل:**

#### 1. الوراثة (Inheritance)
```sad
صنف كائن_حي:
    دالة تنفس()

صنف إنسان يرث كائن_حي:
    دالة اعمل()

صنف حيوان يرث كائن_حي:
    دالة أصدر_صوت()
```
- صنف أساسي
- أصناف مشتقة
- تجاوز الدوال

#### 2. تعدد الأشكال (Polymorphism)
```sad
صنف شكل:
    دالة احسب_المساحة()
    دالة احسب_المحيط()

صنف دائرة يرث شكل
صنف مستطيل يرث شكل
صنف مثلث يرث شكل
```
- واجهة موحدة
- تنفيذ مختلف
- قائمة أشكال متعددة

#### 3. الأصناف المجردة (Abstract Classes)
```sad
صنف مجرد مركبة:
    دالة مجردة تحرك()
    دالة مجردة توقف()

صنف سيارة يرث مركبة
صنف طائرة يرث مركبة
```

#### 4. الواجهات (Interfaces)
```sad
واجهة قابل_للطباعة:
    دالة إلى_نص()
    دالة اطبع_منسق()

واجهة قابل_للمقارنة:
    دالة يساوي(آخر)
    دالة أكبر_من(آخر)
```

#### 5. الأعضاء الثابتة (Static Members)
```sad
صنف حساب_بنكي:
    ثابت عدد_الحسابات = 0
    ثابت معدل_الفائدة = 2.5
    
    دالة ثابتة احصل_على_معلومات_البنك()
```

#### 6. الخصائص المحسوبة
```sad
@خاصية
دالة مساحة():
    إرجاع هذا._طول * هذا._عرض
```

#### 7. الوراثة المتعددة (Multiple Inheritance)
```sad
صنف بطة يرث حيوان، يطير، يسبح:
    دالة طر()
    دالة اسبح()
```

#### 8. تطبيق عملي: نظام إدارة موظفين
- صنف موظف مجرد
- مهندس مع مشاريع
- مدير مع فريق
- نظام متكامل

### 3️⃣ `05_error_handling_advanced.s` - معالجة الأخطاء المتقدمة
**الحجم:** ~600 سطر  
**عدد الأمثلة:** 10 مواضيع متقدمة

**المحتوى الكامل:**

#### 1. أنواع الأخطاء الأساسية
- خطأ_قسمة_على_صفر
- خطأ_الفهرس
- خطأ_المفتاح
- خطأ_النوع

#### 2. معالجة أخطاء متعددة
```sad
محاولة:
    # عمليات
خطأ خطأ_قسمة_على_صفر:
    # معالجة محددة
خطأ خطأ_القيمة:
    # معالجة محددة
```

#### 3. الأخطاء المخصصة
```sad
صنف خطأ_الرصيد_غير_كاف يرث خطأ:
    بناء(الرصيد_الحالي، المبلغ_المطلوب):
        # رسالة مخصصة

صنف خطأ_الحساب_مغلق يرث خطأ:
    # خطأ خاص بالتطبيق
```

#### 4. كتلة finally
```sad
محاولة:
    # عمليات
خطأ:
    # معالجة
أخيراً:
    # تنظيف مضمون
```

#### 5. التأكيدات (Assertions)
```sad
تأكد العدد >= 0، "العدد يجب أن يكون موجباً"
تأكد ب != 0، "المقام لا يمكن أن يكون صفراً"
```

#### 6. سلسلة الأخطاء (Exception Chaining)
```sad
ارفع خطأ_معالجة_البيانات("فشل") من خ_الأصلي
```

#### 7. معالج السياق (Context Manager)
```sad
صنف مؤقت_الأداء:
    دالة __ادخل__()
    دالة __اخرج__()

مع مؤقت_الأداء("عملية") كـ م:
    # عمليات
```

#### 8. نظام التحقق من صحة البيانات
```sad
صنف مُحقق:
    @ثابت
    دالة حقق_البريد(البريد)
    
    @ثابت
    دالة حقق_العمر(العمر)
```

#### 9. معالجة أخطاء Async
```sad
دالة غير_متزامنة جلب_بيانات():
    محاولة:
        انتظر نم(0.1)
    خطأ:
        # معالجة
```

#### 10. أفضل الممارسات
- أخطاء محددة
- رسائل واضحة
- تنظيف الموارد
- عدم تجاهل الأخطاء

## 🔥 أبرز الأمثلة / Highlighted Examples

```sad
دالة صانع_عداد(القيمة_الأولية):

        العداد = العداد + 1

```

### 🌟 مثال Polymorphism:
```sad
الأشكال = [
    جديد دائرة(5)،
    جديد مستطيل(4، 6)،
    جديد مثلث(8، 3)
]

لكل شكل في الأشكال:
    شكل.عرض_المعلومات()  # نفس الواجهة، تنفيذ مختلف
```

### 🌟 مثال خطأ مخصص:
```sad
صنف خطأ_الرصيد_غير_كاف يرث خطأ:

        هذا.مطلوب = المطلوب

محاولة:
    الحساب.سحب(10000)
خطأ خطأ_الرصيد_غير_كاف كـ خ:
    اطبع("الرصيد: " + خ.رصيد)
```
