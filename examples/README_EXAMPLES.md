## 1️⃣ أمثلة أنواع البيانات / Data Types Examples

### 📊 الأنواع الأساسية / Primitive Types

#### `01_types_integer.s` - الأرقام الصحيحة
**القواعد المستخدمة:**
```ebnf
integer_literal ::= decimal_literal | binary_literal | octal_literal | hex_literal
decimal_literal ::= ['+' | '-'] digit+
binary_literal  ::= '0b' ('0' | '1')+
octal_literal   ::= '0o' [0-7]+
hex_literal     ::= '0x' [0-9a-fA-F]+
```

**المحتوى:**
- أرقام عشرية (Decimal numbers)
- أرقام ثنائية (Binary: 0b1010)
- أرقام ثمانية (Octal: 0o17)
- أرقام ست عشرية (Hexadecimal: 0xFF)
- العمليات الحسابية (+, -, *, /, %, **)
- عمليات المقارنة (<, >, ==, !=, <=, >=)
- أمثلة من الحياة الواقعية

**عدد الأسطر:** 130+

---

#### `01_types_float.s` - الأرقام العشرية
**القواعد المستخدمة:**
```ebnf
float_literal ::= decimal_part ['.' fractional_part] [exponent_part]
exponent_part ::= ('e' | 'E') ['+' | '-'] digit+
```

**المحتوى:**
- أرقام عشرية بسيطة (5.5, 72.3)
- الكسور العشرية (0.25, 0.5)
- الصيغة العلمية (1.5e10, 3.2e-5)
- العمليات الحسابية
- الثوابت الرياضية (π, e, φ)
- حسابات المساحات والسرعة
- تحويل العملات
- حساب المعدلات

**عدد الأسطر:** 140+

---

#### `01_types_boolean.s` - القيم المنطقية
**القواعد المستخدمة:**
```ebnf
boolean_literal ::= 'صحيح' | 'خطأ'
logical_expr ::= expr ('و' | 'أو' | 'ليس') expr
comparison_expr ::= expr ('==' | '!=' | '<' | '>' | '<=' | '>=') expr
```

**المحتوى:**
- القيم المنطقية الأساسية (صحيح، خطأ)
- العمليات المنطقية (و، أو، ليس)
- عمليات المقارنة
- الشروط المركبة
- جداول الحقيقة (Truth tables)
- أمثلة واقعية (صلاحية الدخول، أهلية المنحة)
- التقييم القصير (Short-circuit evaluation)

**عدد الأسطر:** 150+

---

#### `01_types_string.s` - النصوص
**القواعد المستخدمة:**
```ebnf
string_literal ::= '"' string_char* '"' | "'" string_char* "'"
string_char ::= escape_sequence | unicode_char | [^"\\\n]
escape_sequence ::= '\' ('n' | 't' | 'r' | '\' | '"' | "'")
```

**المحتوى:**
- نصوص بسيطة ("مرحباً")
- دمج النصوص (Concatenation)
- حروف الهروب (\n, \t, \")
- النصوص متعددة الأسطر
- النصوص العربية الكاملة (UTF-8)
- بطاقة تعريف الموظف
- العنوان البريدي
- رسائل ترحيبية
- جمل مفيدة

**عدد الأسطر:** 130+

### 📦 الأنواع المركبة / Composite Types

#### `01_types_array.s` - المصفوفات
**القواعد المستخدمة:**
```ebnf
array_literal ::= '[' [expression_list] ']'
expression_list ::= expression (',' expression)*
array_access ::= expression '[' expression ']'
array_method ::= expression '.' method_name '(' [arg_list] ')'
```

**المحتوى:**
- مصفوفة بسيطة [1، 2، 3]
- مصفوفة نصوص ["أحمد"، "محمد"]
- مصفوفة متنوعة [1، "نص"، 3.14]
- الوصول للعناصر array[0]
- تعديل العناصر array[0] = 10
- إضافة عناصر .أضف()
- حذف عناصر .احذف()
- طول المصفوفة .طول()
- التكرار على المصفوفة
- البحث في المصفوفة
- جمع العناصر
- إيجاد أكبر عنصر
- عكس المصفوفة
- تصفية المصفوفة

**عدد الأسطر:** 180+

---

#### `01_types_map.s` - القواميس/الخرائط
**القواعد المستخدمة:**
```ebnf
map_literal ::= '{' [pair_list] '}'
pair_list ::= pair (',' pair)*
pair ::= expression ':' expression
map_access ::= expression '[' expression ']'
```

**المحتوى:**
- قاموس بسيط {"الاسم": "أحمد"}
- الوصول للقيم map["الاسم"]
- تعديل القيم map["السعر"] = 100
- إضافة عناصر جديدة
- قاموس الدرجات
- قاموس جهات الاتصال
- قاموس الأسعار
- البيانات الشخصية
- الإحصائيات
- الإعدادات
- قواميس متداخلة
- حساب المعدل من قاموس

**عدد الأسطر:** 170+

## 2️⃣ أمثلة الدوال / Functions Examples

#### `02_functions_basic.s` - الدوال الأساسية
**القواعد المستخدمة:**
```ebnf
function_decl ::= 'دالة' [type] IDENTIFIER '(' [param_list] ')' block
param_list ::= param (',' param)*
param ::= IDENTIFIER [':' type] ['=' expression]
return_stmt ::= 'إرجاع' [expression]
call_expr ::= IDENTIFIER '(' [arg_list] ')'
```

**المحتوى:**
- دالة بدون معاملات قل_السلام()
- دالة مع معامل واحد مربع(ع)
- دالة مع عدة معاملات جمع_ثلاثة(أ، ب، ج)
- دالة مع نوع إرجاع حساب_المعدل()
- دالة تطبع ولا ترجع
- دالة مع شروط تقييم_الدرجة()
- دالة حسابية معقدة
- دالة تستدعي دالة أخرى
- دالة تحقق من شرط هل_بالغ()
- دالة حساب الفاتورة
- دالة تحويل وحدات

**عدد الأسطر:** 170+

## 3️⃣ أمثلة البرمجة الكائنية / OOP Examples

#### `03_oop_basic.s` - البرمجة الكائنية الأساسية
**القواعد المستخدمة:**
```ebnf
class_decl ::= 'صنف' IDENTIFIER ['يرث' IDENTIFIER] block 'نهاية'
property_decl ::= 'خاصية' [type] IDENTIFIER ['=' expression]
method_decl ::= 'دالة' [type] IDENTIFIER '(' [param_list] ')' block
constructor ::= 'بناء' '(' [param_list] ')' block
object_creation ::= 'جديد' IDENTIFIER '(' [arg_list] ')'
member_access ::= expression '.' IDENTIFIER
```

**المحتوى:**
- صنف شخص بسيط
- صنف حساب_بنكي (إيداع، سحب)
- صنف طالب (تعيين_المعدل، احصل_على_التقدير)
- صنف مستطيل (احسب_المساحة، احسب_المحيط)
- صنف دائرة (مع ثابت باي)
- المنشئات (Constructors)
- الخصائص (Properties)
- الدوال (Methods)
- الوصول للأعضاء (هذا.)

**عدد الأسطر:** 200+

## 4️⃣ أمثلة التحكم في التدفق / Control Flow Examples

#### `04_control_flow.s` - الشروط والحلقات
**القواعد المستخدمة:**
```ebnf
if_stmt ::= 'إذا' expression 'أعمل' block ['وإلا' block] 'نهاية'
while_stmt ::= 'بينما' expression 'أعمل' block 'نهاية'
for_stmt ::= 'لكل' IDENTIFIER 'في' expression 'أعمل' block 'نهاية'
```

**المحتوى:**
- شرط بسيط (إذا)
- شرط مع وإلا (If-Else)
- شروط متداخلة
- شروط متعددة مع و
- شروط متعددة مع أو
- حلقة بينما
- حلقة مع شرط معقد
- حلقة تنازلية (Countdown)
- جدول الضرب
- حساب المتوسط
- البحث عن رقم
- حساب المضروب (Factorial)

**عدد الأسطر:** 160+
