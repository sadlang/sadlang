# برامج WASM للمتصفح — لغة ص
# 10 برامج تجريبية تعمل في المتصفح مباشرة

هذا المجلد يحتوي على 10 برامج بلغة ص مصممة للتحويل إلى WASM والتشغيل في المتصفح.

## البرامج:
1. **مرحبا_wasm** — أول برنامج WASM، طباعة في المتصفح
2. **آلة_حاسبة** — حاسبة تفاعلية مع DOM
3. **رسم_لوحة** — رسم أشكال على Canvas
4. **قائمة_مهام** — تطبيق TODO كامل
5. **مؤقت** — عداد تنازلي + ساعة إيقاف
6. **جلب_بيانات** — جلب بيانات من API
7. **تخزين_محلي** — حفظ/تحميل بيانات محلياً
8. **لعبة_ثعبان** — لعبة Snake بالـ Canvas
9. **محرر_نصوص** — محرر نصوص بسيط
10. **لوحة_معلومات** — Dashboard تفاعلي

## التشغيل:
```bash
# تحويل إلى WASM
sadc --target wasm برنامج.ص -o برنامج.wasm

# فتح في المتصفح
# استخدم ملف HTML المُولّد تلقائياً
```
