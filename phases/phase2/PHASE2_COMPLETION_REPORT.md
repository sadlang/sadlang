## 🧪 أمثلة الاستخدام

### مثال 1: تحليل معجمي بسيط
```cpp
#include "lexer/lexer_core.h"

using namespace Sad::Lexer;

int main() {
    LexerCore lexer("رقم س = 42");
    auto tokens = lexer.tokenize();
    
    for (const auto& token : tokens) {
        std::cout << token.toString() << std::endl;
    }
}
```

**النتيجة:**
```
Token(KEYWORD_INTEGER, 'رقم', 1:1)
Token(IDENTIFIER, 'س', 1:5)
Token(OPERATOR_ASSIGN, '=', 1:7)
Token(LITERAL_INTEGER, '42', 1:9)
Token(END_OF_FILE, '', 1:11)
```

### مثال 2: برنامج كامل
```sad
# برنامج بسيط بلغة ص
رقم س = 10
رقم ص = 20
رقم المجموع = س + ص

اطبع("المجموع هو: " + المجموع)
```

**الرموز المستخرجة:**
```
KEYWORD_INTEGER, IDENTIFIER, OPERATOR_ASSIGN, LITERAL_INTEGER, ...
```

### مثال 3: دالة عربية
```sad
دالة احسب_المساحة(رقم العرض، رقم الارتفاع) {
    رقم المساحة = العرض * الارتفاع
    إرجاع المساحة
}
```
