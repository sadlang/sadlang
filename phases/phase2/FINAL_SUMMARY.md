### 3. المحلل المعجمي (LexerCore)

#### دوال الملاحة والحالة
- ✅ `peek()` - النظر دون تحريك المؤشر
- ✅ `peekNext(offset)` - النظر للأمام بمقدار
- ✅ `advance()` - التقدم حرف واحد (يحدث line/column)
- ✅ `isAtEnd()` - فحص نهاية الملف
- ✅ `getCurrentPosition()` - الموقع الحالي (line:column)

#### دوال التخطي
- ✅ `skipWhitespace()` - تخطي المسافات والتابات والأسطر
- ✅ `skipComment()` - تخطي التعليقات (# و #* *#)

#### دوال المسح (Scanning)
- ✅ `scanNumber()` - أرقام صحيحة وعشرية وسالبة
  - أمثلة: 42، -17، 3.14، 0.5، -2.71
  - كشف الأخطاء: نقطة مكررة، عدم وجود أرقام بعد النقطة
  
- ✅ `scanString()` - نصوص بعلامات تنصيص مزدوجة
  - دعم حروف خاصة: \n (سطر جديد)، \t (تاب)، \\ (شرطة مائلة)، \" (علامة تنصيص)، \r (رجوع)
  - دعم نصوص متعددة الأسطر
  - كشف نصوص غير مغلقة

- ✅ `scanIdentifier()` - معرفات عربية ولاتينية
  - يبدأ بـ: حرف (عربي/لاتيني) أو _
  - يتبعه: أحرف، أرقام، _
  - ربط تلقائي بجدول الكلمات المفتاحية
  - أمثلة: س، count، اسم_المتغير

- ✅ `scanOperator()` - جميع العوامل
  - عوامل ثنائية (13): ==، !=، <=، >=، +=، -=، *=، /=، ++، --، &&، ||، ->
  - عوامل أحادية (10): +، -، *، /، %، =، <، >، !، .

#### الدوال الرئيسية
- ✅ `nextToken()` - استخراج رمز واحد
  - تخطي تلقائي للمسافات والتعليقات
  - معالجة جميع أنواع الرموز
  - إرجاع EOF عند النهاية
  - معالجة الأخطاء

- ✅ `tokenize()` - تحويل النص الكامل
  - حلقة على nextToken()
  - جمع جميع الرموز في vector
  - رمي استثناء عند الخطأ الأول
  - إضافة EOF في النهاية

#### الدوال المساعدة الخاصة
- ✅ `isDigit(c)` - فحص رقم (0-9)
- ✅ `isAlpha(c)` - فحص حرف (عربي/لاتيني/_)
- ✅ `isAlphaNumeric(c)` - فحص حرف أو رقم
- ✅ `isWhitespace(c)` - فحص مسافة بيضاء
- ✅ `makeError(msg)` - إنشاء رمز خطأ

## 📖 أمثلة الاستخدام

### مثال 1: برنامج بسيط
```cpp
#include "lexer/lexer_core.h"
using namespace Sad::Lexer;

int main() {
    LexerCore lexer("رقم س = 42");
    auto tokens = lexer.tokenize();
    
    for (const auto& token : tokens) {
        std::cout << token.toString() << std::endl;
    }
}
```

**النتيجة:**
```
Token(TYPE_INTEGER, 'رقم', 1:1)
Token(IDENTIFIER, 'س', 1:5)
Token(OP_ASSIGN, '=', 1:7)
Token(NUMBER_INTEGER, '42', 1:9)
Token(END_OF_FILE, '', 1:11)
```

### مثال 2: برنامج أكثر تعقيداً
```sad
# برنامج حساب المساحة
دالة احسب_المساحة(رقم العرض، رقم الارتفاع) {
    رقم المساحة = العرض * الارتفاع
    إرجاع المساحة
}

# الاستدعاء
رقم المساحة = احسب_المساحة(10، 20)
اطبع("المساحة = " + المساحة)
```

**الرموز:**
```
COMMENT → "# برنامج حساب المساحة"
KEYWORD_FUNCTION → "دالة"
IDENTIFIER → "احسب_المساحة"
PAREN_LEFT → "("
TYPE_INTEGER → "رقم"
IDENTIFIER → "العرض"
COMMA → ","
...
```

### مثال 3: معالجة الأخطاء
```cpp
try {
    LexerCore lexer("رقم س = 3.14.15");  // نقطة مكررة
    auto tokens = lexer.tokenize();
} catch (const std::runtime_error& e) {
    std::cerr << "خطأ: " << e.what() << std::endl;
    // خطأ معجمي / Lexical error at 1:9: 
    // رقم بصيغة خاطئة - نقطة عشرية متكررة
}
```
