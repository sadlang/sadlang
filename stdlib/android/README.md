# مكتبة أندرويد بلغة ص
## Android SDK for Sad Language

هذه المكتبة تتيح إنشاء تطبيقات أندرويد كاملة بلغة ص فقط، بدون الحاجة لـ Java أو Kotlin.

## البنية

```
android/
├── نواة/                 # النواة الأساسية للتطبيق
│   ├── تطبيق.ص           # Activity, Application
│   ├── خدمة.ص            # Service
│   └── بث.ص              # BroadcastReceiver
├── واجهة/                # مكونات الواجهة (Jetpack Compose)
│   ├── عناصر.ص           # عناصر أساسية (نص، زر، صورة)
│   ├── تخطيط.ص           # تخطيطات (عمود، صف، شبكة)
│   ├── إدخال.ص           # عناصر إدخال
│   ├── قوائم.ص           # قوائم وعناصر متكررة
│   └── تنقل.ص            # التنقل بين الشاشات
├── أدوات/                # أدوات Android
│   ├── كاميرا.ص          # Camera API
│   ├── موقع.ص            # Location API  
│   ├── مستشعرات.ص        # Sensors API
│   ├── إشعارات.ص         # Notifications
│   └── تخزين.ص           # Storage & SharedPreferences
├── شبكة/                 # الاتصال بالشبكة
│   ├── طلبات.ص           # HTTP requests
│   └── ويب_سوكت.ص        # WebSocket
└── قاعدة_بيانات/         # قواعد البيانات
    ├── غرفة.ص            # Room database
    └── تفضيلات.ص         # SharedPreferences
```

## مثال استخدام

```sad
استورد أندرويد::تطبيق
استورد أندرويد::واجهة::*

تطبيق تطبيقي {
    اسم = "تطبيقي الأول"
    معرف = "com.example.myapp"
    إصدار = "1.0.0"
    
    شاشة_رئيسية = الرئيسية
}

شاشة الرئيسية {
    عمود(توسيط) {
        نص("🌟 مرحباً من لغة ص!")
            .حجم(28)
            .لون(أزرق)
        
        فاصل(20)
        
        متغير عداد = 0
        
        نص("العداد: {عداد}")
            .حجم(22)
        
        فاصل(16)
        
        زر("+1") {
            عداد += 1
        }
        
        زر_مخطط("إعادة تعيين") {
            عداد = 0
        }
    }
}
```

## المتطلبات

- Android SDK (API 21+)
- JDK 17+
- Gradle 8.0+
