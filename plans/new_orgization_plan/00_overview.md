# خطة إعادة تنظيم ملفات المشروع - نظرة عامة

## 📅 التاريخ: 9 يناير 2026

---

## 🎯 الهدف

إعادة تنظيم ملفات المشروع بحيث يتم الفصل الواضح بين:
1. **shared/** - الملفات المشتركة بين المفسر والمترجم
2. **interpreter/** - ملفات المفسر (Interpreter)
3. **compiler/** - ملفات المترجم (Compiler)
4. **tools/** - ملفات الأدوات المساعدة

---

## 📊 تحليل الوضع الحالي

### المجلدات المطلوب تنظيمها:

| المجلد | المحتوى | الحجم |
|--------|---------|-------|
| include/ | ملفات الرأس (headers) | ~80 ملف |
| src/ | ملفات المصدر | ~70 ملف |
| compiler/ | المترجم (LLVM, JIT, optimizer) | ~120 ملف |
| vm/ | الآلة الافتراضية | ~10 ملفات |
| runtime/ | إدارة الذاكرة والخيوط | ~15 ملف |
| bytecode/ | صيغة Bytecode | ~5 ملفات |
| graphics/ | نظام الرسومات | ~50 ملف |

---

## 🏗️ الهيكل الجديد المقترح

```
s_language/
├── shared/                      # المكونات المشتركة
│   ├── lexer/                   # المحلل المعجمي
│   ├── parser/                  # المحلل النحوي
│   ├── ast/                     # شجرة البناء المجردة
│   ├── types/                   # أنواع البيانات
│   ├── errors/                  # نظام الأخطاء
│   ├── modules/                 # نظام الوحدات
│   └── utils/                   # أدوات مساعدة
│
├── interpreter/                 # المفسر
│   ├── core/                    # نواة المفسر
│   ├── visitors/                # زوار AST
│   ├── data/                    # إدارة البيانات
│   └── builtins/                # الدوال المدمجة
│
├── compiler/                    # المترجم
│   ├── frontend/                # الواجهة الأمامية (SIR)
│   ├── middle/                  # التحسين ونظام الأنواع
│   ├── backend/                 # الواجهة الخلفية (LLVM)
│   ├── jit/                     # التجميع الفوري
│   └── bytecode/                # توليد Bytecode
│
├── runtime/                     # بيئة التشغيل
│   ├── vm/                      # الآلة الافتراضية
│   ├── memory/                  # إدارة الذاكرة
│   ├── thread/                  # الخيوط
│   └── ffi/                     # واجهة الدوال الخارجية
│
├── tools/                       # الأدوات
│   ├── lsp/                     # خادم LSP
│   ├── repl/                    # واجهة تفاعلية
│   ├── pkg/                     # مدير الحزم
│   └── docgen/                  # مولد التوثيق
│
├── stdlib/                      # المكتبة القياسية (بدون تغيير)
├── graphics/                    # نظام الرسومات (بدون تغيير)
└── tests/                       # الاختبارات (بدون تغيير)
```

## 🔍 تصنيف الملفات

### الملفات المشتركة (shared):
- **lexer/** - يستخدمه المفسر والمترجم
- **parser/** - يستخدمه المفسر والمترجم
- **ast/** - يستخدمه المفسر والمترجم
- **errors/** - يستخدمه الجميع
- **modules/** - يستخدمه المفسر والمترجم
- **types/** - أنواع البيانات الأساسية

### ملفات المفسر فقط (interpreter):
- **interpreter_core** - نواة التنفيذ
- **expression_evaluator** - تقييم التعبيرات
- **statement_executor** - تنفيذ الجمل
- **data managers** - إدارة المتغيرات والدوال

### ملفات المترجم فقط (compiler):
- **SIR** - التمثيل الوسيط
- **LLVM codegen** - توليد كود LLVM
- **JIT** - التجميع الفوري
- **Optimizer** - تمريرات التحسين
- **Type System** - نظام الأنواع المتقدم

## ⚠️ نقاط مهمة

1. **الحفاظ على التوافق**: يجب أن يبني المشروع بنجاح بعد كل مرحلة
2. **النسخ ثم الحذف**: نسخ الملفات أولاً، ثم حذف القديمة بعد التأكد
3. **تحديث المسارات**: تحديث جميع `#include` في الملفات
4. **اختبار شامل**: تشغيل الاختبارات بعد كل مرحلة
