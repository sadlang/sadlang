## ✅ ما يعمل حالياً

### 1. الواجهة الأمامية (Frontend)
- **المحلل المعجمي (Lexer):** يعمل بالكامل
  - دعم الكلمات المفتاحية العربية والإنجليزية
  - دعم الأرقام (عشرية، ثنائية، ثمانية، ست عشرية)
  - دعم النصوص بأنواعها
  - دعم التعليقات
  
- **المحلل النحوي (Parser):** يعمل جزئياً
  - تحليل الدوال
  - تحليل تصريحات المتغيرات
  - تحليل جملة return

- **بناء SIR:** يعمل جزئياً
  - ALLOC للمتغيرات المحلية
  - STORE للقيم الأولية
  - LOAD لقراءة المتغيرات
  - RET للإرجاع

### 2. الواجهة الخلفية (Backend - LLVM)
- **توليد LLVM IR:** يعمل للأساسيات
- **إنشاء Object Files:** يعمل
- **الربط (Linking):** يعمل على Windows

### 3. اختبار ناجح

```s
    ارجع س

```

**الملف:** `sir_builder.cpp` - `buildFunctionCall()`
- الدالة موجودة لكنها لا تولد أي تعليمات SIR
- `اطبع_سطر("مرحبا")` لا يعمل

### 2. العمليات الحسابية
**الملف:** `sir_builder.cpp` - `buildBinaryOp()`
- لا يتم توليد تعليمات الجمع/الطرح/الضرب/القسمة
- `س + ص` لا يولد ADD instruction

### 3. العمليات الأحادية
**الملف:** `sir_builder.cpp` - `buildUnaryOp()`
- السالب (-) والنفي (!) غير مدعومة

### 4. تدفق التحكم

- `buildWhileLoop()` - موجود لكن غير مكتمل
- `buildForLoop()` - موجود لكن غير مكتمل

### 5. النصوص
- لا يوجد دعم للثوابت النصية في LLVM
- عملية الدمج (+) للنصوص غير مدعومة

### 6. المصفوفات والخرائط
