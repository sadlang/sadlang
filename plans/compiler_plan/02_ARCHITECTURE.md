## 📁 هيكل الملفات

### 1. الواجهة الأمامية (Frontend)

```
src/
├── lexer/
│   ├── lexer_core.cpp      # التحليل المعجمي الأساسي
│   ├── lexer_keywords.cpp  # جدول الكلمات المفتاحية
│   └── token.cpp           # تعريف الرموز
│
├── parser/
│   ├── parser_core.cpp     # المحلل النحوي الأساسي
│   ├── parser_core_impl.cpp # تنفيذ التحليل
│   └── parser_modules.cpp  # تحليل الوحدات
│
└── ast/                    # شجرة الصيغة المجردة
    ├── expressions.h       # التعابير
    ├── statements.h        # الجمل
    └── declarations.h      # التصريحات
```

### 2. التمثيل الوسيط (SIR)

```
compiler/frontend/
├── include/
│   ├── sir_types.h         # أنواع SIR و Opcodes
│   ├── sir_instruction.h   # تعليمات SIR
│   ├── sir_module.h        # وحدة SIR
│   └── sir_builder.h       # واجهة البناء
│
└── src/
    ├── sir_builder.cpp     # بناء SIR من AST
    ├── sir_module.cpp      # تنفيذ الوحدة
    └── sir_types.cpp       # تنفيذ الأنواع
```

### 3. الواجهة الخلفية (LLVM Backend)

```
compiler/backends/llvm/
├── llvm_codegen.cpp        # توليد LLVM IR
├── llvm_codegen.h
├── llvm_runtime.cpp        # دوال Runtime
├── llvm_runtime.h
├── llvm_linker.cpp         # الربط
├── llvm_linker.h
├── llvm_optimizer.cpp      # التحسين
└── toolchain_detection.cpp # اكتشاف أدوات البناء
```

## 🔄 تدفق البيانات

### المرحلة 1: التحليل المعجمي (Lexer)
**المدخل:** كود مصدري (نص)
**المخرج:** قائمة رموز (Tokens)

**المسؤوليات:**
- تحويل النص لرموز
- التعرف على الكلمات المفتاحية
- معالجة الأرقام والنصوص
- تجاهل التعليقات

### المرحلة 2: التحليل النحوي (Parser)
**المدخل:** قائمة رموز
**المخرج:** شجرة AST

**المسؤوليات:**
- بناء الشجرة النحوية
- التحقق من صحة البناء
- إنشاء عقد AST للتعابير والجمل

### المرحلة 3: بناء SIR
**المدخل:** شجرة AST
**المخرج:** وحدة SIR

**المسؤوليات:**
- تحويل AST لتعليمات SIR
- إدارة النطاقات والمتغيرات
- إنشاء السجلات الافتراضية

### المرحلة 4: توليد LLVM IR
**المدخل:** وحدة SIR
**المخرج:** LLVM Module

**المسؤوليات:**
- تحويل SIR لـ LLVM IR
- تعيين الأنواع
- ربط دوال Runtime

### المرحلة 5: الربط
**المدخل:** LLVM Module
**المخرج:** ملف تنفيذي (.exe)

**المسؤوليات:**
- توليد Object File
- الربط مع المكتبات
- إنشاء الملف التنفيذي

## 📝 ملاحظات التصميم

### لماذا SIR؟
- **الاستقلالية:** فصل الواجهة الأمامية عن الخلفية
- **التحسين:** يمكن تحسين SIR قبل توليد LLVM IR
- **المرونة:** يمكن إضافة backends أخرى (مثل JIT)

### لماذا LLVM؟
- **الأداء:** تحسينات عالية المستوى
- **التوافقية:** يعمل على جميع الأنظمة
- **النضج:** مكتبة مستقرة ومجربة
