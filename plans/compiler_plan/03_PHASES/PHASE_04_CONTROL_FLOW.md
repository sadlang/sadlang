## 📋 المهام

### 4.1 جملة if/else

**الوصف:** التنفيذ الشرطي

**الصياغة:**
```
إذا (شرط)
    // كود
وإلا
    // كود بديل
نهاية
```

**الملفات المتأثرة:**
- `sir_builder.cpp` - دالة `buildIfStatement()`
- `llvm_codegen.cpp` - توليد فروع شرطية

**خطوات التنفيذ:**
1. توليد الشرط
2. إنشاء BasicBlocks (then, else, merge)
3. توليد BR_COND
4. توليد كود كل فرع
5. دمج الفروع

### 4.2 جملة elif

**الوصف:** الشروط المتعددة المتسلسلة

**الصياغة:**
```
إذا (شرط1)
    // كود
وإلا_إذا (شرط2)
    // كود
وإلا
    // كود افتراضي
نهاية
```

### 4.3 حلقة while

**الوصف:** التكرار بشرط

**الصياغة:**
```
بينما (شرط)
    // كود متكرر
نهاية
```

**الملفات المتأثرة:**
- `sir_builder.cpp` - دالة `buildWhileLoop()`

**خطوات التنفيذ:**
1. إنشاء BasicBlocks (condition, body, exit)
2. القفز للشرط
3. توليد الشرط و BR_COND
4. توليد جسم الحلقة
5. القفز للشرط مرة أخرى

### 4.4 حلقة for التقليدية

**الوصف:** التكرار بعداد

**الصياغة:**
```
لكل (رقم ع = 0؛ ع < 10؛ ع = ع + 1)
    // كود
نهاية
```

**الملفات المتأثرة:**
- `sir_builder.cpp` - دالة `buildForLoop()`

### 4.5 حلقة foreach

**الوصف:** التكرار على مجموعة

**الصياغة:**
```
لكل عنصر في مصفوفة
    // كود
نهاية
```

**ملاحظة:** يحتاج دعم المصفوفات أولاً

### 4.6 break و continue

**الوصف:** التحكم في الحلقات

**الصياغة:**
```
بينما (صحيح)
    إذا (شرط_الخروج)
        اخرج
    نهاية
    إذا (شرط_التخطي)
        استمر
    نهاية
نهاية
```

**الملفات المتأثرة:**
- `sir_builder.cpp` - إدارة سياق الحلقات
- تتبع labels للقفز

### 4.7 switch/case

**الوصف:** التبديل بين حالات متعددة

**الصياغة:**
```
حالة (قيمة)
    عندما 1:
        // كود
    عندما 2:
        // كود
    افتراضي:
        // كود افتراضي
نهاية
```

**الملفات المتأثرة:**
- `sir_builder.cpp` - دالة جديدة `buildSwitchStatement()`
- `llvm_codegen.cpp` - استخدام `CreateSwitch`

## 🧪 اختبارات المرحلة

### اختبار 4.1: if بسيط
```s
دالة رئيسية()
    رقم س = 10
    إذا س > 5
        ارجع 1
    نهاية
    ارجع 0
نهاية
```
**المتوقع:** Exit code = 1

### اختبار 4.2: if/else
```s
دالة رئيسية()
    رقم س = 3
    إذا س > 5
        ارجع 1
    وإلا
        ارجع 2
    نهاية
نهاية
```
**المتوقع:** Exit code = 2

### اختبار 4.3: while
```s
دالة رئيسية()
    رقم مجموع = 0
    رقم ع = 1
    بينما ع <= 10
        مجموع = مجموع + ع
        ع = ع + 1
    نهاية
    ارجع مجموع
نهاية
```
**المتوقع:** Exit code = 55

### اختبار 4.4: for
```s
دالة رئيسية()
    رقم مجموع = 0
    لكل (رقم ع = 1؛ ع <= 5؛ ع = ع + 1)
        مجموع = مجموع + ع
    نهاية
    ارجع مجموع
نهاية
```
**المتوقع:** Exit code = 15

### اختبار 4.5: break
```s
دالة رئيسية()
    رقم ع = 0
    بينما صحيح
        ع = ع + 1
        إذا ع >= 5
            اخرج
        نهاية
    نهاية
    ارجع ع
نهاية
```
**المتوقع:** Exit code = 5

### اختبار 4.6: حلقات متداخلة
```s
دالة رئيسية()
    رقم مجموع = 0
    لكل (رقم ص = 1؛ ص <= 3؛ ص = ص + 1)
        لكل (رقم ع = 1؛ ع <= 3؛ ع = ع + 1)
            مجموع = مجموع + 1
        نهاية
    نهاية
    ارجع مجموع
نهاية
```
**المتوقع:** Exit code = 9

## 📊 BasicBlocks المطلوبة

### لـ if/else
```
entry:
    %cond = ...
    br i1 %cond, label %then, label %else

then:
    ...
    br label %merge

else:
    ...
    br label %merge

merge:
    ...
```

### لـ while
```
entry:
    br label %cond

cond:
    %test = ...
    br i1 %test, label %body, label %exit

body:
    ...
    br label %cond

exit:
    ...
```
