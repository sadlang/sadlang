# 📊 المرحلة 5: نظام الأنواع الكامل

## 📅 التاريخ: 12 يناير 2026

---

## 🎯 الهدف

دعم جميع أنواع البيانات في اللغة:
- الأنواع البسيطة (رقم، عشري، منطقي، نص)
- الأنواع المركبة (مصفوفة، قاموس، مجموعة)
- الأنواع المتقدمة (صف، اختياري، أي)
- تحويل الأنواع

---

## 📋 أنواع البيانات (من rules/01_types.md)

### 5.1 الأنواع البسيطة

| النوع | الكلمة المفتاحية | المقابل LLVM |
|-------|-----------------|--------------|
| Integer | `رقم` | i64 |
| Float | `عشري` | double |
| Boolean | `منطقي` | i1 |
| String | `نص` | i8* / struct |
| Character | `حرف` | i8 |
| Byte | `بايت` | i8 |

### 5.2 الأنواع المركبة

| النوع | الكلمة المفتاحية | الوصف |
|-------|-----------------|-------|
| Array | `مصفوفة` | مصفوفة ديناميكية |
| Map | `قاموس` | جدول تجزئة (key-value) |
| Set | `مجموعة` | مجموعة بدون تكرار |
| Tuple | `صف` | صف ثابت الطول |

### 5.3 الأنواع الخاصة

| النوع | الكلمة المفتاحية | الوصف |
|-------|-----------------|-------|
| None | `عدم` | لا قيمة |
| Any | `أي` | أي نوع |
| Optional | `اختياري<T>` | قيمة أو عدم |
| Union | `اتحاد<T1,T2>` | أحد الأنواع |

## 📋 المهام

### 5.1 نوع النص (String)

**الحالة الحالية:** جزئي

**المطلوب:**
1. تخصيص ديناميكي للذاكرة
2. عمليات النص:
   - الدمج (concatenation)
   - الطول
   - الفهرسة
   - التقطيع (slicing)
3. دوال مدمجة:
   - `طول()` - عدد الأحرف
   - `فهرس()` - البحث عن حرف
   - `استبدل()` - استبدال نص
   - `قسم()` - تقسيم النص
   - `اتحد()` - دمج مصفوفة نصوص

**الملفات المتأثرة:**
- `sir_builder.cpp` - عمليات النص
- `llvm_runtime.cpp` - دوال Runtime للنصوص

### 5.2 نوع المصفوفة (Array)

**الصياغة:**
```
مصفوفة<رقم> أرقام = [1, 2, 3, 4, 5]
أرقام[0] = 10
رقم الطول = طول(أرقام)
```

**العمليات المطلوبة:**
- الإنشاء والتهيئة
- الفهرسة (قراءة/كتابة)
- الإضافة والحذف
- البحث
- الترتيب

**التمثيل الداخلي:**
```
struct Array {
    void* data;      // البيانات
    i64 length;      // الطول الحالي
    i64 capacity;    // السعة المخصصة
    i32 element_size; // حجم العنصر
}
```

### 5.3 نوع القاموس (Map)

**الصياغة:**
```
قاموس<نص، رقم> أعمار = {"أحمد": 25، "علي": 30}
أعمار["سارة"] = 28
```

**العمليات المطلوبة:**
- الإضافة والحذف
- البحث بالمفتاح
- التكرار على المفاتيح/القيم
- التحقق من وجود مفتاح

### 5.4 نوع المجموعة (Set)

**الصياغة:**
```
مجموعة<رقم> أرقام = {1, 2, 3}
أضف(أرقام، 4)
منطقي موجود = يحتوي(أرقام، 2)
```

**العمليات المطلوبة:**
- الإضافة والحذف
- التحقق من العضوية
- عمليات المجموعات:
  - الاتحاد
  - التقاطع
  - الفرق

### 5.5 نوع الصف (Tuple)

**الصياغة:**
```
صف<رقم، نص، منطقي> معلومات = (25، "أحمد"، صحيح)
رقم العمر = معلومات.0
نص الاسم = معلومات.1
```

### 5.6 تحويل الأنواع

**التحويلات الضمنية:**
- `رقم` → `عشري` ✅
- `حرف` → `رقم` ✅

**التحويلات الصريحة:**
```
رقم س = إلى_رقم("123")
نص ن = إلى_نص(456)
عشري ع = إلى_عشري(100)
```

**دوال التحويل المطلوبة:**
- `إلى_رقم()` - من نص أو عشري
- `إلى_نص()` - من أي نوع
- `إلى_عشري()` - من رقم أو نص
- `إلى_منطقي()` - من أي نوع

### 5.7 الاستدلال على الأنواع

**الصياغة:**
```
متغير س = 42        // يُستدل أنه رقم
متغير ن = "مرحبا"   // يُستدل أنه نص
```

**المطلوب:**
- تحليل نوع التعبير في الطرف الأيمن
- تعيين النوع للمتغير


### اختبار 5.3: القاموس
```s

    ق["أ"] = 1
    ق["ب"] = 2

نهاية
```
**المتوقع:** Exit code = 3

### اختبار 5.4: تحويل الأنواع
```s

    ارجع س

```
**المتوقع:** Exit code = 42

```s

    متغير س = 100
    متغير ع = س * 2
    ارجع ع
نهاية
```
**المتوقع:** Exit code = 200
