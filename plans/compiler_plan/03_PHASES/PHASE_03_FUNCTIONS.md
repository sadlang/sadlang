## 📋 المهام

### 3.1 استدعاء الدوال المعرفة من المستخدم

**الوصف:** القدرة على استدعاء دالة معرفة في الكود

**الملفات المتأثرة:**
- `sir_builder.cpp` - دالة `buildFunctionCall()`
- `llvm_codegen.cpp` - دالة `emitCall()`

**الخطوات:**
1. استخراج اسم الدالة من CallExpr
2. بناء قائمة المعاملات
3. توليد تعليمة CALL
4. معالجة القيمة المرجعة

### 3.2 المعاملات (Parameters)

**الوصف:** دعم تمرير القيم للدوال

**أنواع المعاملات:**
| النوع | الوصف | الأولوية |
|-------|-------|----------|
| عادي | `دالة ف(رقم س)` | 🔴 حرجة |
| افتراضي | `دالة ف(رقم س = 10)` | 🟡 مهمة |
| متغير | `دالة ف(*args)` | 🟢 لاحقة |
| مسمى | `دالة ف(**kwargs)` | 🟢 لاحقة |

### 3.3 الدوال المضمنة (Builtin Functions)

**الوصف:** دوال اللغة الأساسية

**قائمة الدوال:**
| الدالة | الوصف | الأولوية |
|--------|-------|----------|
| `اطبع()` | طباعة بدون سطر جديد | 🔴 |
| `اطبع_سطر()` | طباعة مع سطر جديد | 🔴 |
| `اقرأ()` | قراءة من المستخدم | 🟡 |
| `طول()` | طول نص/مصفوفة | 🟡 |
| `نوع()` | نوع القيمة | 🟢 |
| `جذر()` | الجذر التربيعي | 🟢 |
| `قوة()` | الأس | 🟢 |

### 3.4 ربط Runtime

**الوصف:** ربط الدوال المضمنة بـ LLVM Runtime

**الملفات المتأثرة:**
- `llvm_runtime.cpp` - تنفيذ الدوال
- `llvm_runtime.h` - التصريحات
- `llvm_codegen.cpp` - تصريح الدوال في LLVM

**دوال Runtime المطلوبة:**
| الدالة | التوقيع |
|--------|---------|
| `sad_llvm_println` | `void(char*)` |
| `sad_llvm_print` | `void(char*)` |
| `sad_llvm_println_int` | `void(i64)` |
| `sad_llvm_read_line` | `char*()` |

### 3.5 الدوال المجهولة (Lambda)

**الوصف:** دعم `دالة(س) => س * 2`

**الملفات المتأثرة:**
- `sir_builder.cpp` - معالجة LambdaExpr
- `llvm_codegen.cpp` - توليد دالة مجهولة

**الأولوية:** 🟢 متقدمة

### 3.6 الإغلاقات (Closures)

**الوصف:** الدوال التي تلتقط متغيرات من نطاقها

**الملفات المتأثرة:**
- `sir_builder.cpp` - تتبع المتغيرات الملتقطة
- `llvm_codegen.cpp` - إنشاء closure struct

**الأولوية:** 🟢 متقدمة

## 🧪 اختبارات المرحلة

### اختبار 3.1: استدعاء دالة بسيطة
```s
دالة رقم مربع(رقم س)
    ارجع س * س
نهاية

دالة رئيسية()
    رقم نتيجة = مربع(7)
    ارجع نتيجة
نهاية
```
**المتوقع:** Exit code = 49

### اختبار 3.2: دالة بمعاملات متعددة
```s
دالة رقم جمع(رقم أ، رقم ب)
    ارجع أ + ب
نهاية

دالة رئيسية()
    ارجع جمع(20، 22)
نهاية
```
**المتوقع:** Exit code = 42

### اختبار 3.3: دوال متداخلة
```s
دالة رقم ضعف(رقم س)
    ارجع س * 2
نهاية

دالة رقم أربعة_أضعاف(رقم س)
    ارجع ضعف(ضعف(س))
نهاية

دالة رئيسية()
    ارجع أربعة_أضعاف(10)
نهاية
```
**المتوقع:** Exit code = 40

### اختبار 3.4: الطباعة
```s
دالة رئيسية()
    اطبع_سطر("مرحبا بالعالم!")
    ارجع 0
نهاية
```
**المتوقع:** طباعة "مرحبا بالعالم!" و Exit code = 0

### اختبار 3.5: دالة تكرارية (Recursion)
```s
دالة رقم عاملي(رقم ن)
    اذا ن <= 1
        ارجع 1
    نهاية
    ارجع ن * عاملي(ن - 1)
نهاية

دالة رئيسية()
    ارجع عاملي(5)
نهاية
```
**المتوقع:** Exit code = 120
