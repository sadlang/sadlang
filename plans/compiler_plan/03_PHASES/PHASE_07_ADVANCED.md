## 📋 الجزء أ: ميزات Python

### 7A.1 List Comprehension

**الصياغة:**
```
مصفوفة<رقم> مربعات = [س * س لكل س في نطاق(10)]
مصفوفة<رقم> زوجية = [س لكل س في نطاق(20) إذا س % 2 == 0]
```

**المطلوب:**
- تحليل صياغة الفهم
- توليد حلقة ضمنية
- دعم الشرط الاختياري

### 7A.2 Dictionary Comprehension

**الصياغة:**
```
قاموس<رقم، رقم> مربعات = {س: س*س لكل س في نطاق(5)}
```

### 7A.3 Set Comprehension

**الصياغة:**
```
مجموعة<رقم> م = {س % 10 لكل س في نطاق(100)}
```

### 7A.4 Generator Expressions

**الصياغة:**
```
مولد أرقام = (س * 2 لكل س في نطاق(1000000))
```

**المطلوب:**
- الكسل في التقييم (lazy evaluation)
- حفظ الحالة بين الاستدعاءات
- دالة `التالي()` للحصول على القيمة التالية

### 7A.5 المولدات (Generators)

**الصياغة:**
```
دالة مولد أرقام_زوجية(رقم حد)
    رقم ع = 0
    بينما ع < حد
        أنتج ع
        ع = ع + 2
    نهاية
نهاية
```

**المطلوب:**
- كلمة `مولد` بدل `دالة`
- كلمة `أنتج` (yield)
- حفظ واستعادة حالة الدالة

### 7A.6 المزخرفات (Decorators)

**الصياغة:**
```
@توقيت
دالة عملية_بطيئة()
    // كود
نهاية

دالة توقيت(دالة_أصلية)
    دالة مغلفة()
        رقم بداية = الوقت_الحالي()
        دالة_أصلية()
        رقم نهاية = الوقت_الحالي()
        اطبع_سطر("الوقت: " + (نهاية - بداية))
    نهاية
    ارجع مغلفة
نهاية
```

**المطلوب:**
- تحليل صياغة `@`
- تحويل الدالة المزخرفة
- دعم معاملات المزخرف

### 7A.7 مديرو السياق (Context Managers)

**الصياغة:**
```
باستخدام ملف = افتح("data.txt") كـ م
    محتوى = م.اقرأ()
نهاية_استخدام
```

**المطلوب:**
- كلمة `باستخدام` و `كـ`
- استدعاء `__دخول__()` و `__خروج__()`
- ضمان الإغلاق حتى عند الأخطاء

### 7A.8 معامل الفظ (:=)

**الصياغة:**
```
إذا (رقم ن := طول(نص)) > 10
    اطبع_سطر("النص طويل: " + ن)
نهاية
```

**المطلوب:**
- التعيين داخل التعبيرات
- إنشاء متغير في نطاق محلي

### 7A.9 Pattern Matching

**الصياغة:**
```
طابق قيمة
    حالة 1 | 2 | 3:
        اطبع_سطر("رقم صغير")
    حالة نقطة(س، ص):
        اطبع_سطر("نقطة في " + س + "،" + ص)
    حالة _:
        اطبع_سطر("شيء آخر")
نهاية_مطابقة
```

## 📋 الجزء ب: ميزات C++

### 7B.1 القوالب (Templates)

**الصياغة:**
```
قالب<نوع ت>
صنف صندوق
    ت القيمة
    
    دالة بناء(ت قيمة)
        القيمة = قيمة
    نهاية
    
    دالة احصل() ت
        ارجع القيمة
    نهاية
نهاية

صندوق<رقم> ص = جديد صندوق<رقم>(42)
```

**المطلوب:**
- تحليل كلمة `قالب`
- استبدال النوع عند الاستخدام
- توليد نسخ متخصصة

### 7B.2 RAII (إدارة الموارد)

**الصياغة:**
```
صنف قفل_ذكي
    دالة بناء(مؤشر م)
        // الحصول على القفل
    نهاية
    
    دالة هدم()
        // تحرير القفل
    نهاية
نهاية
```

**المطلوب:**
- استدعاء تلقائي لـ `هدم()` عند خروج النطاق
- ضمان تحرير الموارد

### 7B.3 المؤشرات الذكية

**الأنواع:**
- `مؤشر_فريد<ت>` - unique_ptr
- `مؤشر_مشترك<ت>` - shared_ptr
- `مؤشر_ضعيف<ت>` - weak_ptr

**الصياغة:**
```
مؤشر_فريد<شخص> ش = جديد_فريد شخص("أحمد")
مؤشر_مشترك<ملف> م = جديد_مشترك ملف("data.txt")
```

### 7B.4 إعادة تحميل العوامل

**الصياغة:**
```
صنف كسر
    رقم البسط
    رقم المقام
    
    عامل +(كسر آخر) كسر
        ارجع جديد كسر(
            البسط * آخر.المقام + آخر.البسط * المقام،
            المقام * آخر.المقام
        )
    نهاية
نهاية
```

**العوامل القابلة للتحميل:**
- الحسابية: `+`, `-`, `*`, `/`, `%`
- المقارنة: `==`, `!=`, `<`, `>`, `<=`, `>=`
- الفهرسة: `[]`
- الاستدعاء: `()`

### 7B.5 مساحات الأسماء (Namespaces)

**الصياغة:**
```
فضاء رياضيات
    ثابت رقم باي = 3.14159
    
    دالة مساحة_دائرة(رقم نصف_قطر)
        ارجع باي * نصف_قطر * نصف_قطر
    نهاية
نهاية_فضاء

رقم م = رياضيات::مساحة_دائرة(5)
```

### 7B.6 التعبيرات الثابتة (constexpr)

**الصياغة:**
```
ثابت_تعبير رقم مضاعف(رقم س)
    ارجع س * 2
نهاية

ثابت رقم نتيجة = مضاعف(21)  // يُحسب وقت الترجمة
```

### 7B.7 معاملات الإشارة

**الصياغة:**
```
دالة مبادلة(إشارة رقم أ، إشارة رقم ب)
    رقم مؤقت = أ
    أ = ب
    ب = مؤقت
نهاية
```

### 7B.8 دوال Lambda المتقدمة

**الصياغة:**
```
// مع التقاط
دالة_مختصرة مضاعف = [المعامل](رقم س) => س * المعامل

// بدون تقاط
دالة_مختصرة مربع = (رقم س) => س * س
```

## 🧪 اختبارات المرحلة

### اختبار 7.1: List Comprehension
```s
دالة رئيسية()
    مصفوفة<رقم> م = [س * س لكل س في نطاق(5)]
    ارجع م[4]
نهاية
```
**المتوقع:** Exit code = 16

### اختبار 7.2: المولد
```s
دالة مولد عد_تنازلي(رقم من)
    بينما من > 0
        أنتج من
        من = من - 1
    نهاية
نهاية

دالة رئيسية()
    مولد م = عد_تنازلي(5)
    رقم مجموع = 0
    لكل رقم في م
        مجموع = مجموع + رقم
    نهاية
    ارجع مجموع
نهاية
```
**المتوقع:** Exit code = 15

### اختبار 7.3: القوالب
```s
قالب<نوع ت>
دالة اختر_الأكبر(ت أ، ت ب) ت
    إذا أ > ب
        ارجع أ
    نهاية
    ارجع ب
نهاية

دالة رئيسية()
    ارجع اختر_الأكبر<رقم>(10، 20)
نهاية
```
**المتوقع:** Exit code = 20

### اختبار 7.4: إعادة تحميل العوامل
```s
صنف متجه
    رقم س
    رقم ص
    
    عامل +(متجه آخر) متجه
        ارجع جديد متجه(س + آخر.س، ص + آخر.ص)
    نهاية
نهاية

دالة رئيسية()
    متجه م1 = جديد متجه(1، 2)
    متجه م2 = جديد متجه(3، 4)
    متجه م3 = م1 + م2
    ارجع م3.س + م3.ص
نهاية
```
**المتوقع:** Exit code = 10
