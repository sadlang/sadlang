## 📋 المهام

### 6.1 تعريف الأصناف

**الصياغة:**
```
صنف شخص
    نص الاسم
    رقم العمر
    
    دالة تحية()
        اطبع_سطر("مرحبا، أنا " + الاسم)
    نهاية
نهاية
```

**المطلوب:**
- تحليل تعريف الصنف في Parser
- إنشاء جدول الأعضاء (fields)
- إنشاء جدول الدوال (methods)
- توليد SIR لبنية الصنف

**الملفات المتأثرة:**
- `parser_core_impl.cpp` - تحليل تعريف الصنف
- `sir_builder.cpp` - دالة جديدة `buildClassDeclaration()`
- `llvm_codegen.cpp` - توليد struct type

### 6.2 البناء والتدمير

**الصياغة:**
```
صنف شخص
    دالة بناء(نص اسم، رقم عمر)
        الاسم = اسم
        العمر = عمر
    نهاية
    
    دالة هدم()
        // تنظيف الموارد
    نهاية
نهاية
```

**المطلوب:**
- دالة `بناء()` - Constructor
- دالة `هدم()` - Destructor
- تخصيص الذاكرة للكائن
- تحرير الذاكرة عند الهدم

### 6.3 إنشاء الكائنات

**الصياغة:**
```
شخص أحمد = جديد شخص("أحمد"، 25)
أحمد.تحية()
```

**المطلوب:**
- كلمة مفتاحية `جديد`
- تخصيص ذاكرة للكائن
- استدعاء دالة البناء
- الوصول للأعضاء بالنقطة

### 6.4 الوراثة

**الصياغة:**
```
صنف موظف يرث_من شخص
    نص الوظيفة
    رقم الراتب
    
    دالة بناء(نص اسم، رقم عمر، نص وظيفة)
        أساس.بناء(اسم، عمر)
        الوظيفة = وظيفة
    نهاية
نهاية
```

**المطلوب:**
- كلمة مفتاحية `يرث_من`
- نسخ أعضاء الصنف الأب
- كلمة `أساس` للوصول للصنف الأب
- ترتيب استدعاء البناة

### 6.5 تعدد الأشكال (Polymorphism)

**الصياغة:**
```
صنف حيوان
    دالة افتراضية صوت()
        اطبع_سطر("...")
    نهاية
نهاية

صنف قط يرث_من حيوان
    دالة تجاوز صوت()
        اطبع_سطر("مياو")
    نهاية
نهاية

صنف كلب يرث_من حيوان
    دالة تجاوز صوت()
        اطبع_سطر("هاو")
    نهاية
نهاية
```

**المطلوب:**
- كلمة `افتراضية` للدوال القابلة للتجاوز
- كلمة `تجاوز` للدوال المُعاد تعريفها
- جدول الدوال الافتراضية (vtable)
- الربط المتأخر (late binding)

### 6.6 الواجهات (Interfaces)

**الصياغة:**
```
واجهة قابل_للطباعة
    دالة اطبع()
واجهة_نهاية

صنف تقرير يطبق قابل_للطباعة
    دالة اطبع()
        // تنفيذ
    نهاية
نهاية
```

**المطلوب:**
- كلمة `واجهة` لتعريف الواجهة
- كلمة `يطبق` لتطبيق الواجهة
- التحقق من تطبيق جميع الدوال

### 6.7 التغليف ومستويات الوصول

**مستويات الوصول:**
- `عام` - متاح للجميع
- `خاص` - متاح داخل الصنف فقط
- `محمي` - متاح للصنف والأصناف الوارثة

**الصياغة:**
```
صنف حساب_بنكي
    خاص رقم الرصيد
    
    عام دالة إيداع(رقم مبلغ)
        الرصيد = الرصيد + مبلغ
    نهاية
    
    عام دالة الرصيد_الحالي()
        ارجع الرصيد
    نهاية
نهاية
```

### 6.8 الأصناف الثابتة والأعضاء الثابتة

**الصياغة:**
```
صنف رياضيات
    ثابت رقم باي = 3.14159
    
    ثابت دالة مربع(رقم س)
        ارجع س * س
    نهاية
نهاية

رقم نتيجة = رياضيات.مربع(5)
```

### 6.9 الخصائص (Properties)

**الصياغة:**
```
صنف مستطيل
    خاص رقم _عرض
    خاص رقم _ارتفاع
    
    خاصية عرض
        قراءة: ارجع _عرض
        كتابة: _عرض = القيمة
    نهاية_خاصية
    
    خاصية مساحة
        قراءة: ارجع _عرض * _ارتفاع
    نهاية_خاصية
نهاية
```

```s
        س = قيمة_س
        ص = قيمة_ص
    نهاية
نهاية

دالة رئيسية()
    نقطة ن = جديد نقطة(5، 7)
    ارجع ن.س * ن.ص
نهاية
```
**المتوقع:** Exit code = 35

### اختبار 6.3: الوراثة
```s
صنف شكل
    رقم س
    رقم ص
نهاية

صنف دائرة يرث_من شكل
    رقم نصف_قطر
نهاية

دالة رئيسية()
    دائرة د = جديد دائرة()
    د.س = 0
    د.ص = 0
    د.نصف_قطر = 5
    ارجع د.نصف_قطر
نهاية
```
**المتوقع:** Exit code = 5

```s
    نهاية
نهاية

دالة رئيسية()
    حيوان ح = جديد قط()
```

## 📊 التمثيل الداخلي للأصناف

### بنية الكائن في الذاكرة
```
+----------+--------+--------+-----+--------+
| vtable*  | field1 | field2 | ... | fieldN |
+----------+--------+--------+-----+--------+
```

### جدول الدوال الافتراضية (vtable)
```
+------------+------------+-----+------------+
| method1*   | method2*   | ... | methodN*   |
+------------+------------+-----+------------+
```
