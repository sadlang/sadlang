## 🎯 الهدف

تنفيذ مكتبة قياسية شاملة للغة ص تشمل:

## 📋 المهام

### 8.1 دوال الإدخال/الإخراج

**الدوال المطلوبة:**
| الدالة | الوصف |
|--------|-------|
| `اطبع(قيم...)` | طباعة بدون سطر جديد |
| `اطبع_سطر(قيم...)` | طباعة مع سطر جديد |
| `اقرأ()` | قراءة سطر من المستخدم |
| `اقرأ_رقم()` | قراءة رقم |
| `اقرأ_عشري()` | قراءة عدد عشري |

**الملفات المتأثرة:**
- `llvm_runtime.cpp` - تنفيذ الدوال
- `sir_builder.cpp` - ربط الأسماء العربية

### 8.2 دوال الرياضيات

**الدوال المطلوبة:**
| الدالة | الوصف |
|--------|-------|
| `قوة(أساس، أس)` | الأس |
| `جذر(س)` | الجذر التربيعي |
| `مطلق(س)` | القيمة المطلقة |
| `سقف(س)` | التقريب لأعلى |
| `أرضية(س)` | التقريب لأسفل |
| `تقريب(س)` | أقرب عدد صحيح |
| `أقصى(أ، ب)` | الأكبر |
| `أدنى(أ، ب)` | الأصغر |
| `جيب(س)` | sin |
| `جيب_تمام(س)` | cos |
| `ظل(س)` | tan |
| `لوغاريتم(س)` | ln |
| `لوغاريتم_10(س)` | log10 |
| `عشوائي()` | رقم عشوائي 0-1 |
| `عشوائي_نطاق(من، إلى)` | رقم عشوائي في نطاق |

**الثوابت:**
- `باي` = 3.14159265358979
- `هاء` = 2.71828182845904

### 8.3 دوال النصوص

**الدوال المطلوبة:**
| الدالة | الوصف |
|--------|-------|
| `طول(نص)` | عدد الأحرف |
| `حرف_في(نص، فهرس)` | الحرف في موقع |
| `قطع(نص، من، إلى)` | قطع جزء |
| `استبدل(نص، قديم، جديد)` | استبدال |
| `قسم(نص، فاصل)` | تقسيم لمصفوفة |
| `اتحد(مصفوفة، فاصل)` | دمج مصفوفة |
| `أحرف_كبيرة(نص)` | تحويل لحروف كبيرة |
| `أحرف_صغيرة(نص)` | تحويل لحروف صغيرة |
| `قص_فراغات(نص)` | إزالة الفراغات |
| `يبدأ_بـ(نص، بادئة)` | التحقق من البداية |
| `ينتهي_بـ(نص، لاحقة)` | التحقق من النهاية |
| `يحتوي(نص، جزء)` | البحث عن جزء |
| `فهرس(نص، جزء)` | موقع أول ظهور |
| `عكس(نص)` | عكس النص |

### 8.4 دوال المصفوفات

**الدوال المطلوبة:**
| الدالة | الوصف |
|--------|-------|
| `طول(مصفوفة)` | عدد العناصر |
| `أضف(مصفوفة، عنصر)` | إضافة في النهاية |
| `أدرج(مصفوفة، فهرس، عنصر)` | إدراج في موقع |
| `احذف(مصفوفة، فهرس)` | حذف من موقع |
| `بحث(مصفوفة، عنصر)` | البحث عن عنصر |
| `رتب(مصفوفة)` | الترتيب |
| `اعكس(مصفوفة)` | عكس الترتيب |
| `نطاق(من، إلى، خطوة)` | إنشاء مصفوفة أرقام |
| `خريطة(مصفوفة، دالة)` | تطبيق دالة |
| `رشح(مصفوفة، دالة)` | تصفية |
| `اختزل(مصفوفة، دالة، قيمة_أولية)` | reduce |

### 8.5 نظام الملفات

**الدوال المطلوبة:**
| الدالة | الوصف |
|--------|-------|
| `افتح(مسار، وضع)` | فتح ملف |
| `اغلق(ملف)` | إغلاق ملف |
| `اقرأ_ملف(مسار)` | قراءة محتوى كامل |
| `اكتب_ملف(مسار، محتوى)` | كتابة ملف |
| `موجود(مسار)` | التحقق من الوجود |
| `احذف_ملف(مسار)` | حذف ملف |
| `انسخ_ملف(من، إلى)` | نسخ ملف |
| `انقل_ملف(من، إلى)` | نقل/إعادة تسمية |
| `أنشئ_مجلد(مسار)` | إنشاء مجلد |
| `محتويات_مجلد(مسار)` | قائمة الملفات |
| `حجم_ملف(مسار)` | حجم الملف |

**أوضاع فتح الملف:**
- `"ق"` - قراءة
- `"ك"` - كتابة
- `"إ"` - إضافة
- `"قك"` - قراءة وكتابة
