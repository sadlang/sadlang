## 📂 القسم 1: أنواع البيانات (types/)

**المصدر الأساسي:** `01_types.md` (صفحات 1-50)

### 1.1 الأنواع الأساسية (01_primitive_types.md)

**المحتوى:**

#### 1. الأعداد الصحيحة (Integer)
```s
# تعريف
عدد = 42
عدد_سالب = -15
عدد_كبير = 1000000

# العمليات
جمع = 10 + 5      # 15
طرح = 10 - 5      # 5
ضرب = 10 * 5      # 50
قسمة = 10 / 5     # 2
باقي = 10 % 3     # 1
أس = 2 ** 8       # 256
```

#### 2. الأعداد العشرية (Float)
```s
# تعريف
عشري = 3.14
علمي = 2.5e10
سالب = -0.001

# دقة الحسابات
نتيجة = 0.1 + 0.2  # قد لا تساوي 0.3 تماماً
```

#### 3. النصوص (String)
```s
# تعريف
نص = "مرحباً"
نص_مفرد = 'عالم'
نص_متعدد = """
  هذا نص
  متعدد الأسطر
"""

# العمليات
دمج = "مرحباً " + "عالم"     # "مرحباً عالم"
تكرار = "ص" * 3              # "صصص"
طول = طول("نص")               # 2
وصول = نص[0]                 # 'م'
تشريح = نص[1:3]              # 'رح'
```

#### 4. المنطق (Boolean)
```s
# القيم
صح = صح
خطأ = خطأ

# العمليات المنطقية
و = صح و خطأ       # خطأ
أو = صح أو خطأ     # صح
ليس = ليس صح       # خطأ

# المقارنات
يساوي = 5 == 5      # صح
لا_يساوي = 5 != 3   # صح
أكبر = 10 > 5       # صح
أصغر = 3 < 7        # صح
```

#### 5. اللاشيء (None)
```s
# القيمة الفارغة
قيمة = لاشيء

# الاستخدام
دالة نتيجة():
    إذا شرط:
        أرجع 42
    أرجع لاشيء
```

### 1.2 المجموعات (02_collections.md)

**المحتوى:**

#### 1. القائمة (Array/List)
```s
# تعريف
قائمة = [1, 2, 3, 4, 5]
مختلطة = [1, "نص", 3.14, صح]

# العمليات
إضافة = قائمة.أضف(6)
حذف = قائمة.احذف(2)
طول = طول(قائمة)
وصول = قائمة[0]
تشريح = قائمة[1:3]

# الحلقات
لكل عنصر في قائمة:
    اطبع(عنصر)
```

#### 2. القاموس (Map/Dict)
```s
# تعريف
قاموس = {"اسم": "أحمد", "عمر": 25}

# العمليات
وصول = قاموس["اسم"]
تعيين = قاموس["مدينة"] = "القاهرة"
حذف = احذف قاموس["عمر"]
مفاتيح = قاموس.مفاتيح()
قيم = قاموس.قيم()

# الحلقات
لكل مفتاح، قيمة في قاموس:
    اطبع(مفتاح، "=>", قيمة)
```

#### 3. المجموعة (Set)
```s
# تعريف
مجموعة = {1, 2, 3, 4}
فارغة = مجموعة()

# العمليات
إضافة = مجموعة.أضف(5)
حذف = مجموعة.احذف(2)
موجود = 3 في مجموعة

# عمليات المجموعات
اتحاد = مجموعة1 | مجموعة2
تقاطع = مجموعة1 & مجموعة2
فرق = مجموعة1 - مجموعة2
```

#### 4. الصف (Tuple)
```s
# تعريف
صف = (1, 2, 3)
فردي = (42,)

# الخصائص
# غير قابل للتعديل
وصول = صف[0]
تشريح = صف[1:3]

# التفكيك
أ، ب، ج = صف
```

```s
    اطبع("نجح")

    اطبع("رسب")

# إذا-إذا_آخر-وإلا
إذا درجة >= 90:
    اطبع("ممتاز")
إذا_آخر درجة >= 75:
    اطبع("جيد جداً")
إذا_آخر درجة >= 50:
    اطبع("جيد")
وإلا:
    اطبع("ضعيف")
```

### 3.2 الحلقات (02_loops.md)

**المصدر:** `04_syntax.md` (صفحات 15-20)

**المحتوى:**
```s
# حلقة بينما
عداد = 0
بينما عداد < 5:
    اطبع(عداد)
    عداد += 1

# حلقة لكل
قائمة = [1, 2, 3, 4, 5]
لكل عنصر في قائمة:
    اطبع(عنصر)

# حلقة لكل مع نطاق
لكل عدد في نطاق(10):
    اطبع(عدد)

# كسر واستمر
لكل عدد في نطاق(10):
    إذا عدد == 5:
        كسر
    إذا عدد % 2 == 0:
        استمر
    اطبع(عدد)
```
