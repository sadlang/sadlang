### 1.1 الأصناف والكائنات (01_classes_objects.md)

**المحتوى:**

#### 1. تعريف الصنف
```s
# صنف بسيط
صنف شخص:
    # المنشئ
    دالة __بناء__(الذات، اسم، عمر):
        الذات.اسم = اسم
        الذات.عمر = عمر
    
    # طريقة
    دالة عرف(الذات):
        اطبع("أنا", الذات.اسم, "عمري", الذات.عمر)

# إنشاء كائن
أحمد = شخص("أحمد", 25)
أحمد.عرف()
```

#### 2. الخصائص والطرق
```s
صنف دائرة:
    دالة __بناء__(الذات، نصف_قطر):
        الذات.نصف_قطر = نصف_قطر
    
    # خاصية محسوبة
    @خاصية
    دالة مساحة(الذات):
        أرجع 3.14 * الذات.نصف_قطر ** 2
    
    # طريقة
    دالة محيط(الذات):
        أرجع 2 * 3.14 * الذات.نصف_قطر
```

#### 3. طرق الصنف والطرق الثابتة
```s
صنف رياضيات:
    # طريقة ثابتة
    @ثابت
    دالة جمع(أ، ب):
        أرجع أ + ب
    
    # طريقة الصنف
    @صنف
    دالة من_نص(صنف، نص):
        أرجع صنف(رقم(نص))
```

### 2.1 التكوينات (01_comprehensions.md)

**المحتوى:**

#### 1. تكوين القائمة (List Comprehension)
```s
# الطريقة التقليدية
مربعات = []
لكل س في نطاق(10):
    مربعات.أضف(س * س)

# تكوين القائمة
مربعات = [س * س لكل س في نطاق(10)]

# مع شرط
زوجية = [س لكل س في نطاق(10) إذا س % 2 == 0]

# متداخل
مصفوفة = [[س * ص لكل ص في نطاق(3)] لكل س في نطاق(3)]
```

#### 2. تكوين القاموس (Dict Comprehension)
```s
# قاموس من قائمة
مربعات = {س: س * س لكل س في نطاق(5)}
# {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

# مع شرط
زوجية = {س: س * 2 لكل س في نطاق(10) إذا س % 2 == 0}
```

#### 3. تكوين المجموعة (Set Comprehension)
```s
# مجموعة من قائمة
أرقام = {س % 5 لكل س في نطاق(20)}
# {0, 1, 2, 3, 4}
```

### 2.3 مديرو السياق (03_context_managers.md)

**المحتوى:**
```s
# استخدام with
```

### 3.4 تحميل المعاملات (04_operator_overloading.md)

**المحتوى:**
```s
صنف متجه:
    دالة __بناء__(الذات، س، ص):
        الذات.س = س
        الذات.ص = ص
    
    # تحميل +
    دالة __جمع__(الذات، آخر):
        أرجع متجه(الذات.س + آخر.س, الذات.ص + آخر.ص)
    
    # تحميل *
    دالة __ضرب__(الذات، قيمة):
        أرجع متجه(الذات.س * قيمة, الذات.ص * قيمة)
    
    # تحميل ==
    دالة __يساوي__(الذات، آخر):
        أرجع الذات.س == آخر.س و الذات.ص == آخر.ص

# الاستخدام
ع1 = متجه(1, 2)
ع2 = متجه(3, 4)
ع3 = ع1 + ع2       # متجه(4, 6)
ع4 = ع1 * 2        # متجه(2, 4)
```
