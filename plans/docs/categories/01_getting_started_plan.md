### 3. أول برنامج لك (03_first_program.md)

**المصدر:** `10_examples.md` + `04_syntax.md`

**المحتوى:**
1. **مثال "مرحباً بالعالم"**
```s
# ملف: مرحبا.s
اطبع("مرحباً بالعالم!")
```

2. **كتابة الكود**
   - إنشاء ملف جديد
   - كتابة الكود
   - حفظ الملف بامتداد .s

3. **تشغيل البرنامج**
```powershell
sad.exe مرحبا.s
```

4. **فهم النتيجة**
   - شرح ماذا حدث
   - النص المطبوع
   - كيف عمل المفسر

5. **أمثلة إضافية**
   - طباعة أرقام

### 4. المفاهيم الأساسية (04_basic_concepts.md)

**المصدر:** `01_types.md` (صفحات 1-10) + `04_syntax.md`

**المحتوى:**

#### 1. المتغيرات
```s
# تعريف متغير
اسم = "أحمد"
عمر = 25
طول = 1.75
نشط = صح
```

#### 2. أنواع البيانات الأساسية
- **رقم:** أعداد صحيحة وعشرية
- **نص:** سلاسل نصية
- **منطق:** صح/خطأ
- **لاشيء:** قيمة فارغة

#### 3. الدوال الأساسية
```s
# دالة الطباعة
اطبع("نص")

# دالة النوع
نوع(متغير)

# دالة الطول
طول(قائمة)
```

#### 4. التعليقات
```s
# هذا تعليق سطر واحد

/*
  هذا تعليق
  متعدد الأسطر
*/
```

#### 5. العمليات الحسابية البسيطة
```s
# الجمع
نتيجة = 5 + 3

# الطرح
فرق = 10 - 4

# الضرب
ضرب = 6 * 7

# القسمة
قسمة = 20 / 4
```

### 5. الوضع التفاعلي (05_interactive_mode.md)

**المصدر:** معلومات عامة عن REPL

**المحتوى:**

#### 1. ما هو الوضع التفاعلي؟
- شرح مفهوم REPL (Read-Eval-Print Loop)
- الفوائد والاستخدامات

#### 2. بدء الوضع التفاعلي
```powershell
# تشغيل المفسر بدون ملف
sad.exe
```

#### 3. الأوامر الأساسية
```s
>>> اطبع("مرحبا")
مرحبا

>>> 5 + 3
8

>>> متغير = 10
>>> متغير * 2
20
```

#### 4. نصائح الاستخدام
- تجربة الأكواد بسرعة
- اختبار الوظائف
- التعلم التفاعلي

#### 5. الخروج من الوضع التفاعلي
```s
>>> اخرج()
# أو Ctrl+C
```
