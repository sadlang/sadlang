## 🔷 الدالة الرئيسية / Main Function

### الوصف / Description

الدالة الرئيسية هي نقطة الدخول لتنفيذ البرنامج. عند وجود دالة رئيسية في البرنامج، 
يبدأ التنفيذ منها بدلاً من تنفيذ الأوامر مباشرة.

The main function is the entry point for program execution. When a main function 
exists in the program, execution starts from it instead of executing statements directly.

### القاعدة النحوية / Syntax

```ebnf
main_function ::= 'دالة' [return_type] 'رئيسية' '(' [parameters] ')' block

return_type ::= 'صحيح' | 'عدم' | 'فراغ'
parameters ::= 'نص' '[' ']' IDENTIFIER
block ::= statement* 'نهاية'
```

### الأشكال المقبولة / Accepted Forms

#### 1. دالة رئيسية بسيطة / Simple Main Function
```sad
دالة رئيسية()
    اطبع("مرحباً")
نهاية
```

#### 2. دالة رئيسية مع نوع إرجاع / Main with Return Type
```sad
دالة صحيح رئيسية()
    اطبع("مرحباً")
    إرجاع 0
نهاية
```

#### 3. دالة رئيسية مع وسائط / Main with Arguments
```sad
دالة صحيح رئيسية(نص[] الوسائط)
    لكل وسيط في الوسائط
        اطبع(وسيط)
    نهاية
    إرجاع 0
نهاية
```

### القيود / Constraints

1. **دالة واحدة فقط:** لا يمكن تعريف أكثر من دالة رئيسية في البرنامج
   Only one main function per program

2. **نوع الإرجاع:** يجب أن يكون `صحيح` أو `عدم` أو `فراغ` أو غير محدد
   Return type must be `int`, `void`, or unspecified

3. **المعاملات:** إما بدون معاملات أو معامل واحد من نوع `نص[]`
   Parameters: either no parameters or one parameter of type `string[]`

4. **المستوى الأعلى:** يجب تعريف الدالة الرئيسية في المستوى الأعلى للبرنامج
   Must be defined at top-level

### كود الخروج / Exit Code

قيمة الإرجاع من الدالة الرئيسية تُستخدم ككود خروج للبرنامج:
- `0`: تنفيذ ناجح / Successful execution
- غير صفر: حدث خطأ / Error occurred

```sad
دالة صحيح رئيسية()
    إذا فشل_شيء()
        إرجاع 1  // كود خروج خطأ
    نهاية
    
    إرجاع 0  // نجاح
نهاية
```

### الاستخدام من سطر الأوامر / Command-Line Usage

```bash
# تنفيذ برنامج
sad program.s

# تنفيذ مع وسائط
sad program.s arg1 arg2 arg3

# الحصول على كود الخروج
sad program.s
echo $?  # في Linux/Mac
echo %ERRORLEVEL%  # في Windows
```

### التوافق / Compatibility

#### الوضع الجديد (Default)
البرنامج يجب أن يحتوي على دالة رئيسية.

#### الوضع القديم (Legacy)
```bash
sad program.s --legacy-mode
```
يسمح بتنفيذ كود بدون دالة رئيسية (للتوافق مع البرامج القديمة).
```

## 🔢 كود الخروج

### ما هو كود الخروج؟

كود الخروج (Exit Code) هو رقم يُرجعه البرنامج للنظام للإشارة إلى حالة التنفيذ:
- `0`: نجح التنفيذ
- غير صفر: حدث خطأ

### استخدام كود الخروج

```sad
دالة صحيح رئيسية(نص[] الوسائط)
    إذا طول(الوسائط) < 2
        اطبع("خطأ: يجب تمرير وسيطين")
        إرجاع 1  // كود خطأ
    نهاية
    
    // معالجة طبيعية
    إرجاع 0  // نجاح
نهاية
```

### قراءة كود الخروج

#### في Linux/macOS:
```bash
sad program.s
echo $?
```

#### في Windows:
```cmd
sad program.s
echo %ERRORLEVEL%
```

#### في سكريبتات:
```bash
#!/bin/bash
sad program.s arg1 arg2
if [ $? -eq 0 ]; then
    echo "نجح"
else
    echo "فشل"
fi
```

## 📚 أمثلة عملية

### مثال 1: حاسبة بسيطة

```sad
دالة رقم جمع(رقم أ، رقم ب)
    إرجاع أ + ب
نهاية

دالة رقم طرح(رقم أ، رقم ب)
    إرجاع أ - ب
نهاية

دالة صحيح رئيسية(نص[] الوسائط)
    إذا طول(الوسائط) != 3
        اطبع("الاستخدام: calc <رقم1> <عملية> <رقم2>")
        إرجاع 1
    نهاية
    
    رقم رقم1 = إلى_رقم(الوسائط[0])
    نص عملية = الوسائط[1]
    رقم رقم2 = إلى_رقم(الوسائط[2])
    
    إذا عملية == "+"
        اطبع(جمع(رقم1، رقم2))
    وإلا_إذا عملية == "-"
        اطبع(طرح(رقم1، رقم2))
    غير_ذلك
        اطبع("عملية غير مدعومة")
        إرجاع 2
    نهاية
    
    إرجاع 0
نهاية
```

**الاستخدام:**
```bash
sad calc.s 10 + 5    # النتيجة: 15
sad calc.s 20 - 8    # النتيجة: 12
```

### مثال 2: معالج نصوص

```sad
دالة نص إلى_أحرف_كبيرة(نص النص)
    // تنفيذ...
    إرجاع النص
نهاية

دالة نص إلى_أحرف_صغيرة(نص النص)
    // تنفيذ...
    إرجاع النص
نهاية

دالة صحيح رئيسية(نص[] الوسائط)
    إذا طول(الوسائط) < 2
        اطبع("الاستخدام: text_processor <أمر> <نص>")
        اطبع("الأوامر: upper, lower")
        إرجاع 1
    نهاية
    
    نص الأمر = الوسائط[0]
    نص النص = الوسائط[1]
    
    إذا الأمر == "upper"
        اطبع(إلى_أحرف_كبيرة(النص))
    وإلا_إذا الأمر == "lower"
        اطبع(إلى_أحرف_صغيرة(النص))
    غير_ذلك
        اطبع("أمر غير معروف")
        إرجاع 2
    نهاية
    
    إرجاع 0
نهاية
```
