## 🔧 كود الاختبار الآلي

### اختبار C++ للمحلل المعجمي

**الملف:** `tests/lexer_tests/test_main_keyword.cpp`

```cpp
#include "../../include/lexer/lexer_core.h"
#include <cassert>
#include <iostream>

using namespace Sad::Lexer;

void testMainKeyword() {
    std::cout << "Testing main keyword recognition..." << std::endl;
    
    // Test 1: Basic main function
    {
        std::string code = "دالة رئيسية()";
        LexerCore lexer(code);
        
        auto tokens = lexer.tokenize();
        
        assert(tokens.size() == 5); // دالة رئيسية ( ) EOF
        assert(tokens[0].getType() == TokenType::KEYWORD_FUNCTION);
        assert(tokens[1].getType() == TokenType::KEYWORD_MAIN);
        assert(tokens[2].getType() == TokenType::PAREN_LEFT);
        assert(tokens[3].getType() == TokenType::PAREN_RIGHT);
        assert(tokens[4].getType() == TokenType::END_OF_FILE);
        
        std::cout << "  ✓ Basic main function recognized" << std::endl;
    }
    
    // Test 2: Main with return type
    {
        std::string code = "دالة صحيح رئيسية()";
        LexerCore lexer(code);
        
        auto tokens = lexer.tokenize();
        
        assert(tokens.size() == 6); // دالة صحيح رئيسية ( ) EOF
        assert(tokens[0].getType() == TokenType::KEYWORD_FUNCTION);
        assert(tokens[1].getType() == TokenType::TYPE_INTEGER);
        assert(tokens[2].getType() == TokenType::KEYWORD_MAIN);
        
        std::cout << "  ✓ Main with return type recognized" << std::endl;
    }
    
    // Test 3: Complete main function
    {
        std::string code = 
            "دالة صحيح رئيسية()\n"
            "    إرجاع 0\n"
            "نهاية";
        
        LexerCore lexer(code);
        auto tokens = lexer.tokenize();
        
        // Verify KEYWORD_MAIN exists
        bool foundMain = false;
        for (const auto& token : tokens) {
            if (token.getType() == TokenType::KEYWORD_MAIN) {
                foundMain = true;
                break;
            }
        }
        
        assert(foundMain);
        std::cout << "  ✓ Complete main function tokenized" << std::endl;
    }
    
    std::cout << "✅ All main keyword tests passed!" << std::endl;
}

int main() {
    try {
        testMainKeyword();
        return 0;
    } catch (const std::exception& e) {
        std::cerr << "❌ Test failed: " << e.what() << std::endl;
        return 1;
    }
}
```

## ⚠️ نقاط الانتباه

### 1. الكلمة المحجوزة
بعد إضافة `رئيسية` ككلمة مفتاحية، لن يمكن استخدامها كاسم متغير:

```sad
// ❌ خطأ - رئيسية كلمة محجوزة
رقم رئيسية = 10

// ✅ صحيح - استخدام رئيسية كدالة
دالة صحيح رئيسية()
    إرجاع 0
نهاية
```

### 2. حساسية الحالة
تأكد من أن المقارنة تراعي الحالة:

```sad
رئيسية  ← صحيح
رئيسيه   ← خطأ (بالهاء بدلاً من التاء المربوطة)
الرئيسية ← خطأ (مع ال التعريف)
```

### 3. التوافق مع الكلمات المفتاحية الأخرى
تأكد من عدم تعارض `رئيسية` مع كلمات أخرى في الخريطة.

## 🎓 المعلومات الإضافية

### لماذا في المحلل المعجمي؟
المحلل المعجمي (Lexer) هو أول مرحلة في معالجة الكود:
1. **قراءة النص** → تحويله إلى رموز (tokens)
2. **التعرف على الكلمات المفتاحية** → تمييزها عن المعرّفات
3. **تمرير الرموز للمحلل النحوي** → لتحليل البنية

### البنية الحالية
```
النص (Text) 
    ↓
المحلل المعجمي (Lexer) → رموز (Tokens)
    ↓
المحلل النحوي (Parser) → شجرة AST
    ↓
المفسر (Interpreter) → تنفيذ
```
