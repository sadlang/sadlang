## 🎯 الهدف الرئيسي

دعم تعريف دالة رئيسية (main function) في لغة ص كنقطة دخول إلزامية لتنفيذ البرامج، بدلاً من تنفيذ الأوامر مباشرة على مستوى البرنامج (top-level).

---

## 📋 القاعدة النحوية المطلوبة

```
دالة نوع_الإرجاع رئيسية (معاملات)
    أوامر
نهاية
```

### أمثلة الاستخدام

#### مثال 1: دالة رئيسية بسيطة
```sad
دالة صحيح رئيسية()
    اطبع("مرحباً بك في لغة ص!")
    إرجاع 0
نهاية
```

#### مثال 2: دالة رئيسية مع معاملات
```sad
دالة صحيح رئيسية(نص[] الوسائط)
    اطبع("عدد الوسائط: " + طول(الوسائط))
    لكل وسيط في الوسائط
        اطبع("  - " + وسيط)
    نهاية
    إرجاع 0
نهاية
```

#### مثال 3: دالة رئيسية مع مساعدات
```sad
دالة رقم حساب_المجموع(رقم أ، رقم ب)
    إرجاع أ + ب
نهاية

دالة صحيح رئيسية()
    رقم النتيجة = حساب_المجموع(10، 20)
    اطبع("المجموع: " + النتيجة)
    إرجاع 0
نهاية
```

## 🔄 التغييرات المطلوبة

### 1. التحليل المعجمي (Lexer)
- ✅ إضافة كلمة مفتاحية جديدة: `رئيسية` (KEYWORD_MAIN)


### 2. المحلل النحوي (Parser)
- ✅ التعرف على الدالة الرئيسية وتمييزها عن الدوال العادية
- ✅ التحقق من وجود دالة رئيسية واحدة فقط
- ✅ التحقق من أن الدالة الرئيسية تُعرّف في المستوى الأعلى
- ✅ التحقق من توقيع الدالة الرئيسية (signature validation)
- ✅ منع تنفيذ أوامر خارج الدوال (إلا التصريحات)

### 3. شجرة AST
- ✅ إضافة علامة (flag) لتمييز الدالة الرئيسية: `isMainFunction`
- ✅ إضافة عقدة جديدة (اختياري): `MainFunctionDecl`

### 4. المفسر (Interpreter)
- ✅ البحث عن الدالة الرئيسية قبل بدء التنفيذ
- ✅ تنفيذ الدالة الرئيسية كنقطة دخول
- ✅ تمرير وسائط سطر الأوامر (command-line arguments)
- ✅ إرجاع كود الخروج (exit code)
- ✅ معالجة حالة عدم وجود دالة رئيسية (خطأ)

### 5. main.cpp
- ✅ تعديل executeProgram() لتوقع دالة رئيسية
- ✅ تمرير argc/argv للدالة الرئيسية
- ✅ استخدام كود الخروج من الدالة الرئيسية

## 📊 الحالة الحالية للغة

### كيف يعمل التنفيذ حالياً؟
```cpp
// في main.cpp -> executeProgram()
auto result = interpreter.execute(ast);

// في interpreter_core.cpp
ExecutionResult Interpreter::execute(
    const std::vector<std::unique_ptr<AST::Statement>>& program) {
    
    // تنفيذ كل جملة مباشرة
    for (const auto& stmt : program) {
        auto result = executeStatement(*stmt);
        // ...
    }
}
```

**المشكلة:** يتم تنفيذ جميع الجمل مباشرة بدون الحاجة لدالة رئيسية.

### كيف سيعمل بعد التعديل؟
```cpp
// في main.cpp -> executeProgram()
auto result = interpreter.executeMainFunction(ast, argc, argv);

// في interpreter_core.cpp
ExecutionResult Interpreter::executeMainFunction(
    const std::vector<std::unique_ptr<AST::Statement>>& program,
    int argc, char* argv[]) {
    
    // 1. البحث عن الدالة الرئيسية
    FunctionDecl* mainFunc = findMainFunction(program);
    if (!mainFunc) {
        return ExecutionResult(false, Value(), "لم يتم العثور على دالة رئيسية");
    }
    
    // 2. تسجيل جميع الدوال والأصناف
    registerAllDeclarations(program);
    
    // 3. تحضير وسائط الدالة الرئيسية
    std::vector<Value> args = prepareMainArguments(argc, argv);
    
    // 4. استدعاء الدالة الرئيسية
    return callFunction(mainFunc->getName(), args);
}
```

## ⚠️ التحديات المتوقعة

### 1. التوافق مع الكود القديم
**المشكلة:** البرامج الموجودة تنفذ الكود مباشرة بدون دالة رئيسية.

**الحل المقترح:**
- **الخيار 1:** إجبار وجود دالة رئيسية (breaking change)
- **الخيار 2:** دعم كلا النمطين (legacy mode)
- **الخيار 3:** أداة تحويل تلقائية (migration tool)

**القرار الموصى به:** الخيار 2 مع تحذير deprecation

### 2. تمرير وسائط سطر الأوامر
**المشكلة:** كيفية تمرير argc/argv للدالة الرئيسية؟

**الحل المقترح:**
```cpp
// تحويل argc/argv إلى مصفوفة نصوص
std::vector<Value> prepareMainArguments(int argc, char* argv[]) {
    auto argsArray = std::make_shared<ArrayValue>();
    for (int i = 1; i < argc; i++) {  // تجاوز اسم البرنامج
        argsArray->push_back(Value::makeString(argv[i]));
    }
    return {Value::makeArray(argsArray)};
}
```

### 3. كود الخروج
**المشكلة:** كيف نحصل على كود الخروج من الدالة الرئيسية؟

**الحل المقترح:**
```cpp
// في الدالة الرئيسية
إرجاع 0  // نجاح
إرجاع 1  // فشل

// في المفسر
auto result = callFunction("رئيسية", args);
if (result.result.isInteger()) {
    return result.result.toInt();  // كود الخروج
}
return 0;  // افتراضي
```
