# Quick Summary: Main Function Support Plan

---

## 📌 الفكرة الأساسية

إضافة دعم الدالة الرئيسية `رئيسية` كنقطة دخول إلزامية للبرامج في لغة ص.

### القاعدة الجديدة:
```sad
دالة نوع_الإرجاع رئيسية (معاملات)
    أوامر
نهاية
```

### مثال:
```sad
دالة صحيح رئيسية(نص[] الوسائط)
    اطبع("مرحباً من لغة ص!")
    إرجاع 0
نهاية
```

## ⚠️ تحذيرات مهمة

### تغييرات غير متوافقة
- البرامج الجديدة **يجب** أن تحتوي على دالة رئيسية
- `رئيسية` أصبحت كلمة محجوزة
- لا يمكن تنفيذ كود خارج الدوال (في الوضع الجديد)

### الحل للكود القديم
```bash
# استخدام الوضع القديم
sad old_program.s --legacy-mode

# أو التحويل
sad-migrate old_program.s -o new_program.s
```
