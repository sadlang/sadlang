## 🚀 كيف تستخدم الميزات الجديدة

### مثال 1: if/else بسيط
```s
دالة رئيسية()
رقم س = 42

إذا (س > 0)
    اطبع("موجب\n")
وإلا
    اطبع("سالب\n")
نهاية

إرجاع 0
نهاية
```

### مثال 2: else-if متعدد
```s
رقم درجة = 85

إذا (درجة >= 90)
    اطبع("ممتاز\n")
وإلا_إذا (درجة >= 80)
    اطبع("جيد جداً\n")
وإلا_إذا (درجة >= 70)
    اطبع("جيد\n")
وإلا
    اطبع("مقبول\n")
نهاية
```

### مثال 3: Type Narrowing مع null
```s
دالة معالجة_نص(قيمة)
    إذا (قيمة != لاشيء)
        اطبع("النص: ")
        اطبع(قيمة)
        إرجاع قيمة
    وإلا
        اطبع("القيمة فارغة\n")
        إرجاع "افتراضي"
    نهاية
نهاية

دالة رئيسية()
    نص نتيجة1 = معالجة_نص("مرحبا")
    نص نتيجة2 = معالجة_نص(لاشيء)
    إرجاع 0
نهاية
```
