## 7.1: Package Manager (صاد)
### المدة: 3-4 أسابيع | 🔴 أولوية عالية

### الميزات الأساسية
```
المكونات:
├─ Package registry (مستودع مركزي):
│  ├─ Web interface (مثل crates.io, npmjs.com)
│  ├─ API للنشر والبحث
│  ├─ Authentication و Authorization
│  ├─ Package versioning (SemVer)
│  └─ Download statistics
│
├─ CLI tool (صاد):
│  ├─ صاد تهيئة - إنشاء مشروع جديد
│  ├─ صاد تثبيت - تثبيت حزمة
│  ├─ صاد إزالة - إزالة حزمة
│  ├─ صاد تحديث - تحديث الحزم
│  ├─ صاد نشر - نشر حزمة
│  ├─ صاد بحث - البحث عن حزم
│  ├─ صاد توثيق - عرض التوثيق
│  └─ صاد اختبار - تشغيل الاختبارات
│
├─ Manifest file (صاد.تومل):
│  ├─ اسم الحزمة
│  ├─ الإصدار (SemVer)
│  ├─ الاعتماديات (dependencies)
│  ├─ الاعتماديات التطويرية (dev-dependencies)
│  ├─ المؤلفون
│  ├─ الترخيص
│  └─ الوصف
│
├─ Dependency resolution:
│  ├─ Version constraints
│  ├─ Conflict resolution
│  ├─ Lockfile (صاد.قفل)
│  └─ Minimal version selection
│
├─ Build integration:
│  ├─ Custom build scripts
│  ├─ Pre/post install hooks
│  └─ Native dependencies
│
└─ Security:
   ├─ Package signing
   ├─ Checksum verification
   ├─ Vulnerability scanning
   └─ Audit command
```

### مثال صاد.تومل
```
الوصف:
[الحزمة]
اسم = "تطبيق-الويب"
إصدار = "1.0.0"
مؤلفون = ["أحمد محمد <ahmad@example.com>"]
ترخيص = "MIT"
وصف = "تطبيق ويب بسيط"

[اعتماديات]
ويب-سريع = "2.1.0"
قواعد-بيانات = "^3.0.0"

[اعتماديات-تطويرية]
اختبار-سريع = "1.5.0"
```
