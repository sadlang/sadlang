### 3. ORM (Object-Relational Mapping)
#### 3.1 Models Definition
```
المفاهيم:
├─ تعريف النماذج (Classes)
├─ الحقول (Fields) والأنواع
├─ العلاقات (Relationships)

│  ├─ One-to-Many
│  └─ Many-to-Many
├─ الفهارس (Indexes)
├─ القيود (Constraints)
└─ الدوال المخصصة (Methods)
```

#### 3.2 Query Builder
```
الوظائف:
├─ SELECT queries
│  ├─ Where conditions
│  ├─ Joins (inner, left, right, full)
│  ├─ Ordering
│  ├─ Grouping
│  ├─ Having
│  ├─ Limit و Offset
│  └─ Subqueries
├─ INSERT operations
├─ UPDATE operations
├─ DELETE operations
├─ Aggregations (COUNT, SUM, AVG, etc.)
└─ Raw SQL support
```

#### 3.3 Migrations System
```
الميزات:
├─ إنشاء Migration files

```

#### 3.4 Advanced Features

الميزات المتقدمة:

├─ Timestamps (created_at, updated_at)

│  ├─ نموذج (model)
│  ├─ باني_استعلام (query_builder)
│  ├─ علاقات (relationships)
│  ├─ ترحيل (migration)
│  └─ إنشاء (factory)
│
├─ تجميع_الاتصالات (pool)
│  └─ مدير_التجميع (pool_manager)
│
└─ استعلامات (query)

   ├─ تنفيذ (executor)
   └─ تحسين (optimizer)
```

```

   ↓

   ↓

## 📚 أمثلة الاستخدام (بدون كود)

### مثال 1: اتصال بسيط بـ PostgreSQL
```
الوصف:
- إنشاء اتصال بقاعدة بيانات PostgreSQL
- تنفيذ استعلام SELECT بسيط
- طباعة النتائج
- إغلاق الاتصال
```

### مثال 2: ORM Model Definition
```
الوصف:
- تعريف نموذج "مستخدم" (User)
- الحقول: الاسم، البريد الإلكتروني، كلمة المرور
- العلاقات: المستخدم له عدة منشورات (One-to-Many)
- حفظ مستخدم جديد
```

### مثال 3: Query Builder
```
الوصف:
- بناء استعلام معقد باستخدام Query Builder
- WHERE conditions متعددة
- JOIN مع جدول آخر
- ORDER BY و LIMIT
- تنفيذ الاستعلام وطباعة النتائج
```

### مثال 4: Migrations
```
الوصف:
- إنشاء Migration لإضافة جدول "منتجات"
- إضافة الحقول (الاسم، السعر، الوصف)
- تطبيق Migration
- التراجع عن Migration
```

### مثال 5: Transactions
```
الوصف:
- بدء Transaction
- تنفيذ عدة عمليات (INSERT, UPDATE)
- إذا نجحت: Commit
- إذا فشلت: Rollback
```

### مثال 6: Connection Pooling
```
الوصف:
- إنشاء Connection pool بحجم 10
- استخدام الاتصالات من Pool
- إعادة الاتصالات للـ Pool
- مراقبة استخدام Pool
```

### مثال 7: MongoDB Operations
```
الوصف:
- الاتصال بـ MongoDB
- إدراج مستند
- البحث عن مستندات
- تحديث مستند
- حذف مستند
```

### مثال 8: Redis Caching
```
الوصف:
- الاتصال بـ Redis
- تخزين قيمة في Cache
- قراءة القيمة من Cache
- تعيين انتهاء صلاحية (TTL)
- حذف من Cache
```
