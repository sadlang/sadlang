## 🎯 نظرة عامة

### الأهداف

```
1. تنظيم منطقي
   - فصل الاهتمامات (separation of concerns)
   - سهولة التصفح والصيانة
   - قابلية التوسع

2. واجهة واضحة
   - APIs مفهومة
   - أسماء عربية واضحة
   - documentation مدمج

3. اعتمادات محكومة
   - dependency management واضح
   - لا اعتماديات دائرية
   - تحميل كسول (lazy loading)

4. قابلية الاختبار
   - وحدات قابلة للاختبار منفصلة
   - mocking ممكن
   - integration testing سهل
```

## 📝 تفاصيل الوحدات الرئيسية

### 1. وحدة النافذة (رسومات.نافذة)

```
الملفات:
- نافذة.ص          : صنف النافذة الرئيسي
- مدير_نوافذ.ص     : إدارة نوافذ متعددة
- حدث.ص           : أنواع الأحداث
- معلومات_شاشة.ص  : معلومات الشاشات المتصلة

الصادرات:
- نافذة
  * منشئ(العنوان، العرض، الارتفاع)
  * اضبط_العنوان()
  * اضبط_الحجم()
  * أظهر() / أخفي()
  * أغلق()
  * العرض() / الارتفاع()
  * عند_الإغلاق()
  * عند_تغيير_الحجم()
  
- مدير_نوافذ
  * أنشئ_نافذة()
  * أغلق_نافذة()
  * احصل_على_نافذة()
  * عدد_النوافذ()
  
- حدث
  * نوع_الحدث
  * بيانات_الحدث
  
الاعتماديات:
- أدوات.مسجل (للتسجيل)
- أدوات.تكوين (للإعدادات)

مثال الاستخدام:
```
استورد رسومات.نافذة.*

نافذة = نافذة.جديدة("تطبيقي"، 800، 600)

نافذة.عند_الإغلاق(دالة() {
    اطبع("النافذة تُغلق")
})

نافذة.أظهر()
```
```

### 2. وحدة الرسم (رسومات.رسم)

```
الملفات:
- راسم.ص          : واجهة الرسم الرئيسية
- راسم_2د.ص       : رسم ثنائي الأبعاد
- راسم_3د.ص       : رسم ثلاثي الأبعاد
- لوحة.ص         : لوحة رسم مرنة
- تحويل.ص        : تحويلات هندسية
- أشكال/*.ص      : الأشكال الهندسية

الصادرات:
- راسم
  * جديد(نافذة)
  * نظف(لون)
  * اعرض()
  
- راسم_2د (يرث من راسم)
  * اضبط_لون()
  * ارسم_خط()
  * ارسم_مربع()
  * ارسم_دائرة()
  * ارسم_مضلع()
  * ارسم_صورة()
  * ارسم_نص()
  * احفظ() / استرجع()  # transformation stack
  * حرك() / دور() / قِس()
  
- راسم_3د (يرث من راسم)
  * اضبط_الكاميرا()
  * أضف_ضوء()
  * ارسم_نموذج()
  * ارسم_مكعب() / كرة() / ...
  
- تحويل
  * حرك(س، ص)
  * دور(زاوية)
  * قِس(س، ص)
  * مصفوفة()  # الحصول على مصفوفة التحويل
  
الاعتماديات:
- نافذة (للرسم على نافذة)
- لون (للألوان)
- صورة (لرسم الصور)
- خط (لرسم النصوص)
- رياضيات (للتحويلات)

مثال:
```
استورد رسومات.رسم.*
استورد رسومات.لون.*

راسم = راسم_2د.جديد(نافذة)

راسم.نظف(لون.أبيض)
راسم.اضبط_لون(لون.أحمر)
راسم.ارسم_دائرة(400، 300، 50، ممتلئة: صحيح)
راسم.اعرض()
```
```

### 3. وحدة اللون (رسومات.لون)

```
الملفات:
- لون.ص           : صنف اللون
- فضاء_لوني.ص     : تحويلات بين فضاءات الألوان
- لوحة_ألوان.ص    : لوحات ألوان جاهزة

الصادرات:
- لون
  * من_أحمر_أخضر_أزرق(r, g, b, a=255)
  * من_هكس(كود)  # "#FF0000"
  * من_hsv(h, s, v)
  * من_hsl(h, s, l)
  
  # ألوان معرفة مسبقاً
  * أحمر، أخضر، أزرق، أصفر، ...
  * أسود، أبيض، رمادي، شفاف
  
  # عمليات
  * فاتح(نسبة)
  * غامق(نسبة)
  * امزج_مع(لون_آخر، نسبة)
  * عكس()
  * مع_شفافية(قيمة)
  
  # خصائص
  * أحمر() / أخضر() / أزرق() / شفافية()
  * إلى_هكس()
  * إلى_hsv()
  * إلى_hsl()
  
- فضاء_لوني
  * rgb_إلى_hsv()
  * hsv_إلى_rgb()
  * rgb_إلى_hsl()
  * hsl_إلى_rgb()
  
- لوحة_ألوان
  * مواد (Material Design colors)
  * مسطح (Flat UI colors)
  * باستيل
  * داكن
  
الاعتماديات:
- رياضيات.حسابات (للتحويلات)

مثال:
```
استورد رسومات.لون.*

# إنشاء لون
لون1 = لون.من_أحمر_أخضر_أزرق(255، 0، 0)
لون2 = لون.من_هكس("#00FF00")
لون3 = لون.أزرق

# عمليات
لون_فاتح = لون1.فاتح(0.2)  # 20% أفتح
لون_ممزوج = لون1.امزج_مع(لون2، 0.5)  # 50/50

# تحويلات
(h، s، v) = لون1.إلى_hsv()
```
```

### 4. وحدة الصورة (رسومات.صورة)

```
الملفات:
- صورة.ص          : صنف الصورة
- قماش.ص          : textures للرسم
- أطلس.ص         : texture atlas
- رسم_متحرك_مجزأ.ص : sprite و sprite sheet
- معالج_صور.ص     : معالجة وتأثيرات

الصادرات:
- صورة
  * حمل(مسار)
  * من_بيانات(بيانات، عرض، ارتفاع)
  * جديدة(عرض، ارتفاع، لون_خلفية)
  
  * العرض() / الارتفاع()
  * احفظ(مسار)
  
  # تحويلات بسيطة
  * اقلب_أفقيا()
  * اقلب_عموديا()
  * دور(زاوية)
  * غير_الحجم(عرض، ارتفاع)
  * اقص(س، ص، عرض، ارتفاع)
  
- قماش (Texture)
  * من_صورة(صورة)
  * اربط()  # للاستخدام في الرسم
  
- أطلس
  * جديد(عرض، ارتفاع)
  * أضف_صورة(صورة، اسم)
  * احصل_على_منطقة(اسم)
  
- رسم_متحرك_مجزأ (Sprite)
  * جديد(صورة، عرض_إطار، ارتفاع_إطار)
  * اضبط_الإطار(رقم)
  * شغل() / أوقف()
  
- معالج_صور
  * طبق_ضبابية(صورة، نصف_قطر)
  * طبق_حدة(صورة، مقدار)
  * إلى_رمادي(صورة)
  * اضبط_السطوع(صورة، مقدار)
  * اضبط_التباين(صورة، مقدار)
  
الاعتماديات:
- لون
- رياضيات

مثال:
```
استورد رسومات.صورة.*

صورة = صورة.حمل("شخصية.png")
صورة_معدلة = صورة.غير_الحجم(64، 64)
صورة_معدلة.احفظ("شخصية_صغيرة.png")

راسم.ارسم_صورة(صورة_معدلة، 100، 100)
```
```

```
الملفات:

- تخطيط_نص.ص    : تخطيط نص متعدد الأسطر

الصادرات:

  * حمل(مسار، حجم)

  * مسطر()
  
- مدير_خطوط
  * حمل_خط(مسار، حجم، اسم)
  * احصل_على_خط(اسم)
  * الخطوط_المتاحة()
  
- تخطيط_نص
  * جديد(نص، خط، عرض_أقصى)
  * اضبط_المحاذاة(محاذاة)  # يسار، وسط، يمين
  * اضبط_تباعد_الأسطر(مقدار)
  * احسب()
  * الأسطر()
  
- راسم_نص
  * ارسم_نص(راسم، نص، س، ص، خط، لون)
  * ارسم_نص_متعدد(راسم، تخطيط، س، ص، لون)
  
الاعتماديات:
- لون
- رياضيات

مثال:
```

خط = خط.حمل("خط_عربي.ttf"، 24)
(عرض، ارتفاع) = خط.قس_نص("مرحباً بالعالم")

راسم.ارسم_نص("مرحباً بالعالم"، 100، 100، خط، لون.أسود)

### 6. وحدة الإدخال (رسومات.إدخال)

```
الملفات:
- مدير_إدخال.ص    : تنسيق الإدخال
- لوحة_مفاتيح.ص   : إدخال لوحة المفاتيح
- ماوس.ص          : إدخال الماوس
- لمس.ص           : إدخال اللمس
- ذراع_ألعاب.ص    : gamepad/joystick

الصادرات:
- مدير_إدخال (singleton)
  * حدّث()  # يُستدعى كل إطار
  
- لوحة_مفاتيح
  * مفتاح_مضغوط(مفتاح) -> منطقي
  * مفتاح_تم_ضغطه(مفتاح) -> منطقي  # في هذا الإطار
  * مفتاح_تم_تحريره(مفتاح) -> منطقي
  
  * عند_ضغط_مفتاح(دالة)
  * عند_تحرير_مفتاح(دالة)
  * عند_إدخال_نص(دالة)
  
  # مفاتيح معرّفة
  * مفتاح.سهم_أعلى، سهم_أسفل، ...
  * مفتاح.مسافة، إدخال، ...
  * مفتاح.تحكم، تبديل، تحويل، ...
  
- ماوس
  * الموقع() -> (س، ص)
  * زر_مضغوط(زر) -> منطقي
  * زر_تم_ضغطه(زر) -> منطقي
  * زر_تم_تحريره(زر) -> منطقي
  * حركة_العجلة() -> رقم
  
  * عند_نقر(دالة)
  * عند_حركة(دالة)
  * عند_العجلة(دالة)
  
  * زر.يسار، يمين، وسط
  
- لمس (للمستقبل)
  * اللمسات() -> قائمة
  * لمسة_في_موقع(س، ص) -> منطقي
  
- ذراع_ألعاب (للمستقبل)
  * متصل(رقم) -> منطقي
  * المحاور(رقم) -> قائمة
  * الأزرار(رقم) -> قائمة
  
الاعتماديات:
- حدث (من وحدة النافذة)

مثال:
```
استورد رسومات.إدخال.*

إذا لوحة_مفاتيح.مفتاح_مضغوط(مفتاح.سهم_يمين) {
    لاعب.حرك(1، 0)
}

إذا ماوس.زر_تم_ضغطه(زر.يسار) {
    (س، ص) = ماوس.الموقع()
    اطبع("نقر على: "، س، "،"، ص)
}
```
```

### 7. وحدة الصوت (رسومات.صوت)

```
الملفات:
- صوت.ص          : مؤثرات صوتية قصيرة
- موسيقى.ص       : موسيقى طويلة (streaming)
- مصدر_صوتي.ص    : مصدر صوت في الفضاء 3D
- مستمع_صوتي.ص   : المستمع (اللاعب عادة)
- خلاط_صوت.ص     : مزج القنوات الصوتية
- تأثير_صوتي.ص   : تأثيرات (reverb، echo، ...)

الصادرات:
- صوت
  * حمل(مسار)
  * شغل()
  * أوقف()
  * وقف_مؤقت()
  * يعمل() -> منطقي
  
  * اضبط_الصوت(مستوى)  # 0.0 - 1.0
  * اضبط_النغمة(مقدار)  # 0.5 - 2.0
  * اضبط_التكرار(تكرار: منطقي)
  
- موسيقى
  * حمل(مسار)
  * شغل(تكرار: منطقي = صحيح)
  * أوقف()
  * وقف_مؤقت() / استأنف()
  
  * اختفاء_تدريجي(مدة)  # fade out
  * ظهور_تدريجي(مدة)    # fade in
  
  * اضبط_الصوت(مستوى)
  * الموقع_الحالي() -> ثانية
  * اذهب_إلى(ثانية)
  
- مصدر_صوتي (3D)
  * جديد(صوت)
  * اضبط_الموقع(س، ص، ع)
  * اضبط_السرعة(س، ص، ع)  # للـ doppler effect
  * شغل()
  
- مستمع_صوتي (3D)
  * اضبط_الموقع(س، ص، ع)
  * اضبط_الاتجاه(أمام، أعلى)
  * اضبط_السرعة(س، ص، ع)
  
- خلاط_صوت
  * اضبط_صوت_رئيسي(مستوى)
  * اضبط_صوت_موسيقى(مستوى)
  * اضبط_صوت_مؤثرات(مستوى)
  * اكتم(قناة)
  * ألغ_الكتم(قناة)
  
الاعتماديات:
- رياضيات (للصوت 3D)
- أدوات.مسجل

مثال:
```
استورد رسومات.صوت.*

# مؤثر صوتي
انفجار = صوت.حمل("انفجار.wav")
انفجار.اضبط_الصوت(0.7)
انفجار.شغل()

# موسيقى خلفية
موسيقى_خلفية = موسيقى.حمل("موسيقى.mp3")
موسيقى_خلفية.شغل(تكرار: صحيح)
موسيقى_خلفية.اضبط_الصوت(0.3)

# خلاط
خلاط = خلاط_صوت.الوحيد()
خلاط.اضبط_صوت_رئيسي(0.8)
```
```

### 8. وحدة الحركة (رسومات.حركة)

```
الملفات:
- حركة.ص          : صنف الحركة الأساسي
- مجموعة_حركات.ص  : تجميع حركات
- تسهيل.ص         : دوال التسهيل (easing)
- رسم_متحرك_إطارات.ص : frame-by-frame animation
- محرك_حركة.ص     : إدارة تشغيل الحركات

الصادرات:
- حركة
  * جديدة(عنصر، خاصية، من، إلى، مدة، تسهيل)
  * شغل()
  * أوقف()
  * وقف_مؤقت() / استأنف()
  * عكس()
  
  * اضبط_التكرار(عدد)  # -1 = لا نهائي
  * اضبط_التأخير(ثوان)
  
  * عند_الانتهاء(دالة)
  * عند_التحديث(دالة)
  * عند_التكرار(دالة)
  
- مجموعة_حركات
  * متوازية(قائمة_حركات)  # جميعها معاً
  * متتالية(قائمة_حركات)  # واحدة بعد الأخرى
  * مختلطة(...)           # mix & match
  
- تسهيل
  * خطي
  * سلس_دخول، سلس_خروج، سلس_دخول_خروج
```

## 🔗 خريطة الاعتماديات

### رسم بياني للاعتماديات

```
نافذة
  ├─→ أدوات.مسجل
  └─→ أدوات.تكوين

رسم
  ├─→ نافذة
  ├─→ لون
  ├─→ صورة
  ├─→ خط
  └─→ رياضيات

لون
  └─→ رياضيات.حسابات

صورة
  ├─→ لون
  └─→ رياضيات

خط
  ├─→ لون
  └─→ رياضيات

إدخال
  └─→ نافذة (للأحداث)

صوت
  ├─→ رياضيات (للـ 3D)
  └─→ أدوات.مسجل

حركة
  ├─→ رياضيات
  └─→ أدوات.وقت

ألعاب
  ├─→ رسم
  ├─→ إدخال
  ├─→ صوت
  ├─→ حركة
  └─→ فيزياء (اختياري)
```

### قواعد الاعتماديات

```
1. لا اعتماديات دائرية
   ❌ A → B → C → A
   ✅ A → B → C

2. الاعتماد على واجهات (interfaces)
   ✅ interface IRenderer
   ❌ class ConcreteRenderer مباشرة

3. اعتماديات واضحة
   - في أول الملف
   - معلقة

4. الاعتماديات الكسولة (lazy)
   - تحميل عند الحاجة
   - لا تحميل مُبكّر لكل شيء
```

## 📜 نمط الكود الموحد

### مثال: هيكل ملف نموذجي

```
# ملف: صورة.ص
# الغرض: تمثيل وإدارة الصور
# الكاتب: فريق لغة ص
# التاريخ: 2024

# ═══════════════════════════════════════
# الاستيرادات
# ═══════════════════════════════════════

استورد رياضيات.حسابات
استورد رسومات.لون.*
استورد __داخلي.صورة  # C++ backend

# ═══════════════════════════════════════
# الثوابت
# ═══════════════════════════════════════

تنسيق_PNG = "png"
تنسيق_JPEG = "jpeg"
تنسيق_BMP = "bmp"

# ═══════════════════════════════════════
# الأصناف
# ═══════════════════════════════════════

صنف صورة {
    # ───────────────────────────────────
    # الخصائص الخاصة
    # ───────────────────────────────────
    
    _handle: مؤشر        # مقبض C++
    _عرض: رقم
    _ارتفاع: رقم
    _تنسيق: نص
    
    # ───────────────────────────────────
    # المنشئ
    # ───────────────────────────────────
    
    دالة منشئ(عرض: رقم، ارتفاع: رقم، لون_خلفية: لون = لون.شفاف) {
        هذا._عرض = عرض
        هذا._ارتفاع = ارتفاع
        هذا._تنسيق = تنسيق_PNG
        هذا._handle = __داخلي.صورة.أنشئ(عرض، ارتفاع، لون_خلفية)
    }
    
    # ───────────────────────────────────
    # دوال ثابتة (static)
    # ───────────────────────────────────
    
    دالة ثابتة حمل(مسار: نص) -> صورة {
        """
        يحمل صورة من ملف
        
        المعاملات:
            مسار: مسار الملف
            
        الإرجاع:
            كائن صورة
            
        الأخطاء:
            يرمي خطأ إذا فشل التحميل
        """
        
        # التحقق من وجود الملف
        إذا !نظام_ملفات.موجود(مسار) {
            ارم خطأ("الملف غير موجود: " + مسار)
        }
        
        # تحميل
        handle = __داخلي.صورة.حمل(مسار)
        
        إذا handle == لا_شيء {
            ارم خطأ("فشل تحميل الصورة: " + مسار)
        }
        
        # إنشاء كائن
        صورة_جديدة = صورة.__من_مقبض(handle)
        
        مسجل.معلومات("تم تحميل صورة: " + مسار)
        
        أرجع صورة_جديدة
    }
    
    # ───────────────────────────────────
    # Getters & Setters
    # ───────────────────────────────────
    
    دالة العرض() -> رقم {
        أرجع هذا._عرض
    }
    
    دالة الارتفاع() -> رقم {
        أرجع هذا._ارتفاع
    }
    
    # ───────────────────────────────────
    # دوال عامة
    # ───────────────────────────────────
    
    دالة احفظ(مسار: نص، تنسيق: نص = تنسيق_PNG) -> منطقي {
        """
        يحفظ الصورة في ملف
        
        المعاملات:
            مسار: مسار الملف للحفظ
            تنسيق: تنسيق الصورة (png، jpeg، bmp)
            
        الإرجاع:
            صحيح إذا نجح، خطأ otherwise
        """
        
        نتيجة = __داخلي.صورة.احفظ(هذا._handle، مسار، تنسيق)
        
        إذا نتيجة {
            مسجل.معلومات("تم حفظ الصورة: " + مسار)
        } وإلا {
            مسجل.خطأ("فشل حفظ الصورة: " + مسار)
        }
        
        أرجع نتيجة
    }
    
    دالة غير_الحجم(عرض_جديد: رقم، ارتفاع_جديد: رقم) -> صورة {
        """
        يُنشئ نسخة من الصورة بحجم مختلف
        
        المعاملات:
            عرض_جديد: العرض الجديد
            ارتفاع_جديد: الارتفاع الجديد
            
        الإرجاع:
            صورة جديدة بالحجم الجديد
        """
        
        handle_جديد = __داخلي.صورة.غير_الحجم(
            هذا._handle، 
            عرض_جديد، 
            ارتفاع_جديد
        )
        
        أرجع صورة.__من_مقبض(handle_جديد)
    }
    
    # ───────────────────────────────────
    # دوال داخلية
    # ───────────────────────────────────
    
    دالة خاصة __من_مقبض(handle: مؤشر) -> صورة {
        # إنشاء صورة من مقبض موجود
        صورة_جديدة = صورة.__جديد()
        صورة_جديدة._handle = handle
        صورة_جديدة._عرض = __داخلي.صورة.العرض(handle)
        صورة_جديدة._ارتفاع = __داخلي.صورة.الارتفاع(handle)
        أرجع صورة_جديدة
    }
    
    # ───────────────────────────────────
    # المدمر
    # ───────────────────────────────────
    
    دالة تدمير() {
        إذا هذا._handle != لا_شيء {
            __داخلي.صورة.دمر(هذا._handle)
            هذا._handle = لا_شيء
        }
    }
}

# ═══════════════════════════════════════
# الصادرات
# ═══════════════════════════════════════

صدّر صورة
صدّر تنسيق_PNG، تنسيق_JPEG، تنسيق_BMP
```
