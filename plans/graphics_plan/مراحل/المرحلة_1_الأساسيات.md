## 🏗️ المكونات الرئيسية

### 1. نظام النوافذ (Window System)

#### المواصفات
```
الهدف: توفير واجهة موحدة لإنشاء وإدارة النوافذ عبر المنصات

الميزات الأساسية:
- إنشاء نافذة بحجم وموقع محدد
- تغيير حجم النافذة
- ملء الشاشة (fullscreen)
- العنوان والأيقونة
- إظهار/إخفاء النافذة
- التقليل/التكبير
- معالجة أحداث إغلاق النافذة

الميزات المتقدمة:
- نوافذ متعددة
- dialog boxes
- مستويات الشفافية
- نوافذ بدون إطار
- drag & drop
- شاشات متعددة
```

#### API المقترح (عربي)
```
وحدة: رسومات.نافذة

# إنشاء نافذة
نافذة_جديدة(العنوان: نص، العرض: رقم، الارتفاع: رقم) -> نافذة

# خصائص النافذة
نافذة.اضبط_العنوان(العنوان: نص)
نافذة.اضبط_الحجم(العرض: رقم، الارتفاع: رقم)
نافذة.اضبط_الموقع(س: رقم، ص: رقم)
نافذة.اضبط_ملء_شاشة(فعل: منطقي)
نافذة.أظهر()
نافذة.أخفي()
نافذة.أغلق()

# الحصول على الخصائص
نافذة.العرض() -> رقم
نافذة.الارتفاع() -> رقم
نافذة.الموقع() -> (رقم، رقم)
نافذة.مرئية() -> منطقي
نافذة.مركزة() -> منطقي

# أحداث
نافذة.عند_الإغلاق(دالة)
نافذة.عند_تغيير_الحجم(دالة)
نافذة.عند_التحريك(دالة)
نافذة.عند_التركيز(دالة)
نافذة.عند_فقدان_التركيز(دالة)
```

#### التطبيق التقني
```
المنصات المدعومة:
- Windows (Win32 API)
- Linux (X11 / Wayland)
- macOS (Cocoa)

مكتبة الأساس:
- SDL2 (مفضل للنسخة الأولى)
- أو GLFW كبديل

البنية الداخلية:
class Window {
    - native handle
    - properties (size, position, title)
    - event callbacks
    - rendering context
    - input state
}

class WindowManager {
    - منشئ النوافذ
    - مدير الأحداث
    - event loop
}
```

### 2. محرك الرسم 2D (2D Rendering)

#### المواصفات
```
الهدف: رسم الأشكال الأساسية والنصوص والصور بكفاءة

الأشكال الأساسية:
- خطوط (lines)
- مربعات ومستطيلات (rectangles)
- دوائر (circles)
- مضلعات (polygons)
- منحنيات بيزيه (Bezier curves)

عمليات الرسم:
- تحديد اللون (fill)
- تحديد الحد (stroke)
- سمك الخط
- أنماط الخطوط (solid, dashed, dotted)
- الشفافية (alpha blending)

التحويلات (Transformations):
- ترجمة (translation)
- تدوير (rotation)
- قياس (scaling)
- قص (shearing)
- مصفوفة التحويل (transformation matrix)
```

#### API المقترح
```
وحدة: رسومات.رسم

# إعداد
راسم_جديد(نافذة: نافذة) -> راسم

# اللون والنمط
راسم.اضبط_لون(أحمر: رقم، أخضر: رقم، أزرق: رقم، شفافية: رقم = 255)
راسم.اضبط_لون_الحد(...)
راسم.اضبط_سمك_الخط(سمك: رقم)

# الأشكال الأساسية
راسم.ارسم_خط(س1: رقم، ص1: رقم، س2: رقم، ص2: رقم)
راسم.ارسم_مربع(س: رقم، ص: رقم، عرض: رقم، ارتفاع: رقم، ممتلئ: منطقي = صحيح)
راسم.ارسم_دائرة(س: رقم، ص: رقم، نصف_قطر: رقم، ممتلئة: منطقي = صحيح)
راسم.ارسم_مضلع(نقاط: قائمة، ممتلئ: منطقي = صحيح)
راسم.ارسم_قوس(س: رقم، ص: رقم، نصف_قطر: رقم، زاوية_بداية: رقم، زاوية_نهاية: رقم)

# التحويلات
راسم.احفظ()  # حفظ حالة التحويل
راسم.استرجع()  # استرجاع الحالة
راسم.حرك(س: رقم، ص: رقم)
راسم.دور(زاوية: رقم)
راسم.قِس(س: رقم، ص: رقم)

# عمليات الإطار
راسم.نظف(لون: اختياري)  # مسح الشاشة
راسم.اعرض()  # عرض ما تم رسمه
```

#### التطبيق التقني
```
محرك الرسم الأساسي:
- OpenGL 3.3+ (للأداء العالي)
- SDL_Renderer كبديل بسيط

تقنيات الأداء:
- Batch rendering (رسم مجموعات)
- Vertex Buffer Objects (VBO)
- Instanced rendering
- Texture atlases

Shaders:
- Vertex shader بسيط
- Fragment shader للألوان
- shader للشفافية

البنية الداخلية:
class Renderer2D {
    - RenderContext
    - ShaderProgram
    - VertexBuffer
    - BatchQueue
    - TransformStack
    
    methods:
    - drawPrimitive()
    - flushBatch()
    - applyTransform()
}
```

### 3. نظام الألوان

#### المواصفات
```
أنواع الألوان:
- RGB (red, green, blue)
- RGBA (مع الشفافية)
- HSV/HSL (hue, saturation, value/lightness)
- Hex colors (#RRGGBB)

الألوان المعرفة مسبقاً:
- أحمر، أخضر، أزرق، أصفر...
- أسود، أبيض، رمادي...
- ألوان Material Design
- ألوان CSS
```

#### API المقترح
```
وحدة: رسومات.لون

# إنشاء الألوان
لون.من_أحمر_أخضر_أزرق(أحمر: رقم، أخضر: رقم، أزرق: رقم، شفافية: رقم = 255) -> لون
لون.من_هكس(كود: نص) -> لون  # "#FF0000"
لون.من_hsv(هيو: رقم، تشبع: رقم، قيمة: رقم) -> لون

# ألوان معرفة مسبقاً
لون.أحمر
لون.أخضر
لون.أزرق
لون.أصفر
لون.أسود
لون.أبيض
لون.شفاف

# عمليات على الألوان
لون.فاتح(نسبة: رقم) -> لون  # تفتيح
لون.غامق(نسبة: رقم) -> لون  # تغميق
لون.امزج_مع(لون_آخر: لون، نسبة: رقم) -> لون
لون.عكس() -> لون  # اللون المعاكس
لون.مع_شفافية(شفافية: رقم) -> لون

# الحصول على المكونات
لون.أحمر() -> رقم
لون.أخضر() -> رقم
لون.أزرق() -> رقم
لون.شفافية() -> رقم
لون.إلى_هكس() -> نص
```

### 4. نظام الإدخال (Input System)

#### المواصفات
```
أنواع الإدخال:
- لوحة المفاتيح (keyboard)
- الماوس (mouse)
- اللمس (touch) - للمستقبل
- gamepad - للمستقبل

لوحة المفاتيح:
- مفاتيح مضغوطة
- أحداث الضغط والتحرير
- تكرار المفتاح
- modifiers (Ctrl, Alt, Shift)
- إدخال نصي (text input)

الماوس:
- موقع المؤشر
- أزرار الماوس
- النقر المزدوج
- العجلة (scroll wheel)
- الحركة (motion)
- السحب (drag)
```

#### API المقترح
```
وحدة: رسومات.إدخال

# لوحة المفاتيح
إدخال.مفتاح_مضغوط(مفتاح: نص) -> منطقي
إدخال.عند_ضغط_مفتاح(دالة)
إدخال.عند_تحرير_مفتاح(دالة)
إدخال.عند_إدخال_نص(دالة)

# الماوس
إدخال.موقع_الماوس() -> (رقم، رقم)
إدخال.زر_ماوس_مضغوط(زر: نص) -> منطقي  # "يسار"، "يمين"، "وسط"
إدخال.عند_نقر_ماوس(دالة)
إدخال.عند_حركة_ماوس(دالة)
إدخال.عند_عجلة_ماوس(دالة)

# مفاتيح خاصة
مفتاح.سهم_أعلى
مفتاح.سهم_أسفل
مفتاح.سهم_يمين
مفتاح.سهم_يسار
مفتاح.مسافة
مفتاح.إدخال
مفتاح.إزالة
مفتاح.هروب
مفتاح.تحكم
مفتاح.تبديل
مفتاح.تحويل
```

```

إدارة الموارد:
- تحميل (loading)
- تفريغ (unloading)
- تخزين مؤقت (caching)
- memory management
- error handling
```

#### API المقترح
```
وحدة: رسومات.صورة

# تحميل الصور
صورة.حمل(مسار: نص) -> صورة
صورة.من_بيانات(بيانات: قائمة) -> صورة

# معلومات الصورة
صورة.العرض() -> رقم
صورة.الارتفاع() -> رقم
صورة.الحجم() -> (رقم، رقم)

# رسم الصورة
راسم.ارسم_صورة(صورة: صورة، س: رقم، ص: رقم)
راسم.ارسم_صورة_ممددة(صورة: صورة، س: رقم، ص: رقم، عرض: رقم، ارتفاع: رقم)
راسم.ارسم_جزء_صورة(صورة: صورة، مصدر_س: رقم، مصدر_ص: رقم، ...)

# معالجة الصورة (بسيطة)
صورة.اقلب_أفقيا() -> صورة
صورة.اقلب_عموديا() -> صورة

صورة.غير_الحجم(عرض: رقم، ارتفاع: رقم) -> صورة
```

```
وحدة: رسومات.خط

# تحميل الخطوط
خط.حمل(مسار: نص، حجم: رقم) -> خط
خط.من_النظام(اسم: نص، حجم: رقم) -> خط

# رسم النصوص
راسم.ارسم_نص(نص: نص، س: رقم، ص: رقم، خط: خط، لون: لون)

# قياس النص
خط.قس_نص(نص: نص) -> (رقم، رقم)  # العرض والارتفاع
خط.ارتفاع_السطر() -> رقم

# خصائص الخط
خط.عريض() -> خط
خط.مائل() -> خط
خط.مسطر() -> خط
```

## 🎨 أمثلة الاستخدام

### مثال 1: نافذة بسيطة
```
استورد رسومات.نافذة
استورد رسومات.رسم
استورد رسومات.لون

# إنشاء نافذة
نافذة = نافذة_جديدة("مثال بسيط"، 800، 600)

# إنشاء راسم
راسم = راسم_جديد(نافذة)

# الحلقة الرئيسية
بينما نافذة.مفتوحة() {
    # مسح الشاشة
    راسم.نظف(لون.أسود)
    
    # رسم شيء
    راسم.اضبط_لون(لون.أحمر)
    راسم.ارسم_دائرة(400، 300، 50، ممتلئة: صحيح)
    
    # عرض
    راسم.اعرض()
}
```

### مثال 2: رسم متحرك
```
استورد رسومات.*
استورد رياضيات.جيب، جيب_تمام

نافذة = نافذة_جديدة("رسم متحرك"، 800، 600)
راسم = راسم_جديد(نافذة)

زمن = 0

بينما نافذة.مفتوحة() {
    راسم.نظف(لون.أسود)
    
    # دائرة متحركة
    س = 400 + جيب_تمام(زمن) * 200
    ص = 300 + جيب(زمن) * 200
    
    راسم.اضبط_لون(لون.أزرق)
    راسم.ارسم_دائرة(س، ص، 30، ممتلئة: صحيح)
    
    راسم.اعرض()
    زمن = زمن + 0.05
}
```

### مثال 3: إدخال المستخدم
```
استورد رسومات.*

نافذة = نافذة_جديدة("تفاعلي"، 800، 600)
راسم = راسم_جديد(نافذة)

بينما نافذة.مفتوحة() {
    راسم.نظف(لون.أبيض)
    
    # رسم على موقع الماوس
    (ماوس_س، ماوس_ص) = إدخال.موقع_الماوس()
    
    إذا إدخال.زر_ماوس_مضغوط("يسار") {
        راسم.اضبط_لون(لون.أحمر)
        راسم.ارسم_دائرة(ماوس_س، ماوس_ص، 10، ممتلئة: صحيح)
    }
    
    راسم.اعرض()
}
```
