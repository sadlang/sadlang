# نظام واجهات لغة ص (SadUI)

نظام واجهات مستخدم متعدد المنصات للغة ص، مبني على هندسة **الهجين الذكي**.

## الفكرة الأساسية

بدلاً من اختيار نهج واحد (كل شيء أصلي أو كل شيء Canvas)، نستخدم نهجاً ذكياً:

| المنصة | العناصر القياسية | العناصر المخصصة |
|--------|------------------|-----------------|
| سطح المكتب | SDL2 + OpenGL | SDL2 Canvas |
| أندرويد | Jetpack Compose | Compose Canvas |
| iOS | SwiftUI | SwiftUI Canvas/Path |
| ويب | HTML5 + CSS3 | Canvas API |

## البنية

```
sad_ui/
├── core/               النواة المشتركة
│   ├── types.h/cpp     الأنواع الأساسية (50+ تعداد)
│   ├── node.h/cpp      شجرة عناصر الواجهة
│   ├── ir.h/cpp        التمثيل الوسيط
│   ├── ir_builder.h/cpp بنّاء IR مع التوجيه الذكي
│   ├── style.h/cpp     نظام الأنماط والسمات
│   ├── layout.h/cpp    محرك تخطيط Flexbox
│   └── state.h/cpp     إدارة الحالة التفاعلية
│
├── backends/           مولّدات الكود
│   ├── desktop/        SDL2 + OpenGL
│   ├── android/        Jetpack Compose
│   ├── ios/            SwiftUI
│   └── web/            HTML5/CSS3/JS
│
├── widgets/            عناصر واجهة جاهزة
│   ├── text            عنصر النص
│   ├── button          عنصر الزر
│   ├── image           عنصر الصورة
│   ├── column          حاوية عمودية
│   └── row             حاوية أفقية
│
├── pipeline/           خط الأنابيب الرئيسي
├── CMakeLists.txt      ملف البناء
└── README.md           هذا الملف
```

## مسار البيانات

```
كود ص (.ص)
    ↓
UIParser → UINode Tree
    ↓
IRBuilder (توجيه ذكي)
    ↓
IR Module
    ↓
┌──────────────┬───────────────┬──────────────┬──────────────┐
│ Desktop      │ Android       │ iOS          │ Web          │
│ SDL2 render  │ Compose code  │ SwiftUI code │ HTML/CSS/JS  │
└──────────────┴───────────────┴──────────────┴──────────────┘
```

## مثال بلغة ص

```sad
صنف واجهة_رئيسية يرث عرض
    باني()
        متغير العداد = 0
    نهاية

    دالة بناء()
        ارجع عمود
            .حشوة(16)
            .تباعد(12)

            نص("مرحباً بالعالم!")
                .حجم_خط(32)
                .لون(.أزرق)

            نص("العداد: " + العداد)
                .حجم_خط(24)

            زر("زيادة")
                .لون_خلفية(.أخضر)
                .عند_النقر { العداد += 1 }
        نهاية
    نهاية
نهاية
```

## البناء

```bash
# تضمين sad_ui في مشروعك
add_subdirectory(sad_ui)
target_link_libraries(your_target PRIVATE sad_ui)
```
