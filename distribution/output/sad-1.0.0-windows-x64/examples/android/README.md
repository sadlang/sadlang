# تطبيقات Android التجريبية بلغة ص

هذا المجلد يحتوي على 3 تطبيقات Android تجريبية مكتوبة بلغة ص.

## التطبيقات

### 1. تطبيق الآلة الحاسبة (calculator/)
آلة حاسبة بسيطة مع واجهة عربية.

**الميزات:**
- العمليات الأساسية (+، -، ×، ÷)
- الأقواس والنسبة المئوية
- سجل العمليات
- وضع ليلي

**الملفات:**
```
calculator/
├── AndroidManifest.xml
├── src/
│   └── رئيسية.ص
├── res/
│   ├── layout/main.xml
│   └── values/strings-ar.xml
└── build.gradle
```

### 2. تطبيق قائمة المهام (todo/)
تطبيق إدارة المهام مع تخزين محلي.

**الميزات:**
- إضافة/حذف/تعديل المهام
- تصنيف المهام
- تواريخ الاستحقاق
- إشعارات تذكير
- تخزين SQLite محلي

**الملفات:**
```
todo/
├── AndroidManifest.xml
├── src/
│   ├── رئيسية.ص
│   ├── مهمة.ص
│   └── قاعدة_بيانات.ص
├── res/
│   ├── layout/
│   └── values/
└── build.gradle
```

### 3. تطبيق الطقس (weather/)
تطبيق عرض حالة الطقس من API.

**الميزات:**
- الطقس الحالي
- توقعات 5 أيام
- البحث عن مدن
- موقع GPS
- رسوم بيانية

**الملفات:**
```
weather/
├── AndroidManifest.xml
├── src/
│   ├── رئيسية.ص
│   ├── طقس.ص
│   └── api.ص
├── res/
│   ├── layout/
│   ├── drawable/
│   └── values/
└── build.gradle
```

## البناء والتشغيل

### المتطلبات
- Android SDK 26+
- Sad Android Bridge (مضمن)
- Gradle 8.0+

### البناء
```bash
# بناء تطبيق واحد
cd calculator
../gradlew assembleDebug

# بناء جميع التطبيقات
./build_all.sh
```

### التثبيت على الهاتف
```bash
adb install calculator/build/outputs/apk/debug/calculator-debug.apk
```

```sad
        عيّن_المحتوى(R.layout.main)
        
        متغير زر_ترحيب = ابحث_عن_عرض(R.id.btn_hello)
        زر_ترحيب.عند_النقر(لامدا ()
            اظهر_رسالة("مرحباً من لغة ص!")
        نهاية)
    نهاية
    
نهاية
```
