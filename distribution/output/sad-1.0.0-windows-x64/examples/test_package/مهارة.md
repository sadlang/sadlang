# مكتبة الرياضيات للغة ص — ملف المهارة

## الوصف
مكتبة sad-math توفر دوال رياضية شاملة للغة ص. تدعم العمليات الحسابية والإحصائية والهندسية.

## الدوال المتاحة

### الحساب الأساسي
- `جذر(عدد)` — الجذر التربيعي
- `قوة(أساس، أس)` — رفع لقوة
- `مطلق(عدد)` — القيمة المطلقة
- `باقي(أ، ب)` — باقي القسمة
- `تقريب(عدد، خانات)` — تقريب عشري

### الإحصاء
- `متوسط(مصفوفة)` — المتوسط الحسابي
- `وسيط(مصفوفة)` — الوسيط
- `منوال(مصفوفة)` — المنوال
- `انحراف_معياري(مصفوفة)` — الانحراف المعياري
- `تباين(مصفوفة)` — التباين

### الهندسة
- `مساحة_دائرة(نصف_القطر)` — مساحة دائرة
- `محيط_دائرة(نصف_القطر)` — محيط دائرة
- `مساحة_مثلث(قاعدة، ارتفاع)` — مساحة مثلث
- `فيثاغورس(أ، ب)` — الوتر

### المثلثات
- `جا(زاوية)` — جيب الزاوية (sin)
- `جتا(زاوية)` — جيب التمام (cos)
- `ظا(زاوية)` — الظل (tan)

### الثوابت
- `ط` — π (باي) = 3.14159...
- `هـ` — e (أويلر) = 2.71828...

## أنماط الاستخدام الشائعة

### حساب متوسط درجات
```sad
استورد "sad-math" كـ ر

متغير درجات = [95، 87، 92، 78، 88]
متغير المتوسط = ر.متوسط(درجات)
متغير الانحراف = ر.انحراف_معياري(درجات)

اطبع("المتوسط: " + المتوسط)
اطبع("الانحراف المعياري: " + الانحراف)
```

### حساب مساحة دائرة
```sad
استورد "sad-math" كـ ر

متغير نق = 5.0
اطبع("المساحة: " + ر.مساحة_دائرة(نق))
اطبع("المحيط: " + ر.محيط_دائرة(نق))
```
