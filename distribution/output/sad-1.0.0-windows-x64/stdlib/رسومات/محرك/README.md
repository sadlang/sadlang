# محرك الرسومات — Sad Graphics Engine

محرك رسومات متعدد الخلفيات (Backend-switchable) للغة ص، مصمم للعمل في بيئات متعددة:
- **أنظمة التشغيل** (freestanding/bare-metal) عبر framebuffer مباشر
- **سطح المكتب** (hosted) عبر SDL2/OpenGL

## البنية المعمارية

```
┌─────────────────────────────────────────────────────────────┐
│                    تطبيقات المستخدم                         │

└────────────────────────┬────────────────────────────────────┘
                         │
┌────────────────────────▼────────────────────────────────────┐
│               واجهة_محرك.ص (محرك_رسم)                       │
│  ┌─────────────────┬──────────────────┬──────────────────┐  │
│  │ Software Raster │   Canvas API     │   Font Renderer  │  │
│  │  (خطوط/دوائر)   │  (نفّذ_لوحة)     │   (8×8 Bitmap)   │  │
│  └─────────────────┴──────────────────┴──────────────────┘  │
└────────────────────────┬────────────────────────────────────┘
                         │ يرث
          ┌──────────────┴──────────────┐
          ▼                             ▼
┌──────────────────────┐     ┌──────────────────────┐
│   محرك_نواة.ص        │     │   محرك_مدمج.ص        │
│  (Freestanding)      │     │  (SDL2/OpenGL)       │

│  - sad_lowlevel_rt   │     │  - Hardware Accel    │
└──────────────────────┘     └──────────────────────┘
```

## الملفات

| الملف | الوصف |
|-------|-------|
| `واجهة_محرك.ص` | الصنف الأساسي `محرك_رسم` — software rasterizer + Canvas |
| `محرك_نواة.ص` | تنفيذ freestanding باستخدام FFI → `sad_lowlevel_rt.c` |
| `محرك_مدمج.ص` | تنفيذ سطح المكتب باستخدام SDL2 |
| `أحداث.ص` | نظام الأحداث المجرد (لوحة مفاتيح، فأرة) |
| `مدخلات_نواة.ص` | ربط أحداث الأجهزة (IRQ) بطابور الأحداث |
| `مدير_نوافذ.ص` | مدير نوافذ بسيط للأنظمة |
| `خطوط.ص` | خط نقطي مضمن 8×8 (ASCII) |
| `واجهات.ص` | أصناف مساعدة |

## الاستخدام السريع

### ١. إنشاء محرك وتهيئته

```sad
استورد * من رسومات.محرك.محرك_نواة

متغير شاشة = محرك_نواة()
شاشة.تهيئة(1024, 768)
```

### ٢. رسم أشكال بسيطة

```sad
# مسح الشاشة بلون أسود
شاشة.مسح(0)

# رسم مستطيل أحمر
شاشة.ارسم_مستطيل_ممتلئ(100, 100, 200, 150, 0xFF0000)

# رسم دائرة زرقاء
شاشة.ارسم_دائرة_ممتلئة(400, 300, 50, 0x0000FF)

# رسم نص
شاشة.ارسم_نص(10, 10, "مرحباً بالعالم", 0xFFFFFF, 2)

# تحديث الشاشة
شاشة.تبديل()
```

### ٣. معالجة الأحداث

```sad
استورد * من رسومات.محرك.أحداث
استورد * من رسومات.محرك.مدخلات_نواة

متغير طابور = طابور_أحداث()

بينما (شاشة.يعمل())
    جلب_أحداث_نواة(طابور)
    
    بينما (ليس طابور.فارغ())
        متغير ح = طابور.التالي()
        
        إذا (ح.نوع == حدث_ضغط_مفتاح)
            إذا (ح.كود == مفتاح_هروب)
                شاشة.أوقف()
            نهاية
        نهاية
    نهاية
    
    شاشة.ارسم()
    شاشة.تبديل()
نهاية
```

### ٤. استخدام مدير النوافذ

```sad
استورد * من رسومات.محرك.مدير_نوافذ

متغير مدير = مدير_نوافذ(شاشة)

متغير نافذة1 = مدير.أنشئ_نافذة("متصفح", 50, 50, 400, 300)
متغير نافذة2 = مدير.أنشئ_نافذة("محرر", 200, 100, 500, 400)

مدير.ارسم()
```

## دوال محرك_رسم

### الدوال الأساسية
| الدالة | الوصف |
|--------|-------|
| `تهيئة(عرض, ارتفاع)` | تهيئة المحرك |
| `مسح(لون)` | مسح الشاشة |
| `تبديل()` | تبديل المخزن المؤقت |
| `عرض_الشاشة()` / `ارتفاع_الشاشة()` | أبعاد الشاشة |

### الرسم
| الدالة | الوصف |
|--------|-------|
| `ارسم_بكسل(س, ص, لون)` | رسم نقطة |
| `ارسم_خط(س1, ص1, س2, ص2, لون)` | خط (Bresenham) |
| `ارسم_مستطيل(س, ص, ع, ا, لون)` | مستطيل حدود |
| `ارسم_مستطيل_ممتلئ(...)` | مستطيل ملون |
| `ارسم_دائرة(مس, مص, نق, لون)` | دائرة حدود |
| `ارسم_دائرة_ممتلئة(...)` | دائرة ممتلئة |
| `ارسم_مثلث(...)` | مثلث حدود |
| `ارسم_نص(س, ص, نص, لون, مقياس)` | نص |

### الألوان
| الدالة | الوصف |
|--------|-------|
| `لون_من_مكونات(ر, خ, ز, ش)` | RGBA → عدد |
| `لون_أحمر(لون)` | استخراج الأحمر |
| `لون_أخضر(لون)` | استخراج الأخضر |
| `لون_أزرق(لون)` | استخراج الأزرق |

## أنواع الأحداث

| الثابت | القيمة | الوصف |
|--------|--------|-------|
| `حدث_لا_شيء` | 0 | لا حدث |
| `حدث_ضغط_مفتاح` | 1 | ضغط مفتاح |
| `حدث_رفع_مفتاح` | 2 | رفع مفتاح |
| `حدث_حركة_فأرة` | 3 | حركة الفأرة |
| `حدث_ضغط_فأرة` | 4 | ضغط زر فأرة |
| `حدث_رفع_فأرة` | 5 | رفع زر فأرة |
| `حدث_إغلاق` | 7 | طلب إغلاق |

## ثوابت المفاتيح الشائعة

```sad
مفتاح_هروب = 27      مفتاح_إدخال = 13     مفتاح_مسافة = 32
مفتاح_أعلى = 256     مفتاح_أسفل = 257     مفتاح_يمين = 258
مفتاح_يسار = 259     مفتاح_ف1..ف12 = 282..293
```

## إنشاء محرك مخصص

لإنشاء محرك رسم جديد (مثلاً لجهاز خاص)، ارث من `محرك_رسم` ونفّذ:

```sad
صنف محرك_مخصص يرث محرك_رسم
    باني()
        # تهيئة الجهاز
    نهاية
    
    # الدالة الوحيدة المطلوبة:
    دالة ارسم_بكسل(س, ص, لون)
        # كتابة البكسل للجهاز
    نهاية
    
    # اختياري: تجاوز لتحسين الأداء
    دالة مسح(لون)
        # استخدام DMA أو memset سريع
    نهاية
نهاية
```

## الأداء

- **محرك_نواة**: يستخدم دوال C++ محسّنة لـ memset/memcpy
- **طابور_أحداث**: O(1) لـ `التالي()` و `أضف()` باستخدام فهرس
- **Software Rasterizer**: خوارزميات Bresenham و Midpoint Circle

## المتطلبات

### لوضع Freestanding
- مترجم `sadc` مع LLVM
- ملف `sad_lowlevel_rt.c` يوفر دوال FFI

### لوضع Desktop
- SDL2 development libraries
- OpenGL 3.3+
