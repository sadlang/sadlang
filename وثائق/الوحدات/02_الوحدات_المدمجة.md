# الوحدات المدمجة في لغة ص

> توثيق شامل لنظام الوحدات المدمجة (Built-in Modules) والدوال المتاحة فيها

---

## نظرة عامة

لغة ص تستخدم نظام **استيراد حصري** — فقط الدوال الأساسية (اطبع، طول، نوع...) متاحة تلقائياً. باقي الدوال تحتاج استيراد الوحدة المناسبة باستخدام `استورد`.

```sad
استورد محرك    # JSON، XML، خرائط، تواريخ، regex
استورد نصوص     # مصفوفات، نصوص، رياضيات أساسية، أنواع
استورد أساسيات  # ملفات، خروج، زمن، مدى
استورد رياضيات   # مثلثات، لوغاريتمات، عشوائي
استورد تأكيدات  # دوال التأكيد للاختبار
```

---

## الدوال الأساسية (بدون استيراد)

هذه الدوال متاحة دائماً:

| الدالة | الوصف | مثال |
|--------|-------|------|
| `اطبع(قيمة)` | طباعة بدون سطر جديد | `اطبع("مرحبا")` |
| `اطبع_سطر(قيمة)` | طباعة مع سطر جديد | `اطبع_سطر("مرحبا")` |
| `طول(قيمة)` | طول النص أو المصفوفة | `طول("مرحبا")` → `5` |
| `نوع(قيمة)` | نوع القيمة كنص | `نوع(42)` → `"رقم"` |
| `ادخل(رسالة)` | قراءة سطر من المستخدم | `متغير اسم = ادخل("اسمك: ")` |
| `نص(قيمة)` | تحويل إلى نص | `نص(42)` → `"42"` |
| `رقم(قيمة)` | تحويل إلى رقم | `رقم("42")` → `42` |
| `عشري(قيمة)` | تحويل إلى عشري | `عشري("3.14")` → `3.14` |
| `قائمة(...)` | إنشاء مصفوفة | `قائمة(1, 2, 3)` |
| `خريطة(...)` | إنشاء خريطة | `خريطة("أ", 1, "ب", 2)` |

## وحدة محرك / خرائط (`استورد محرك`)

خرائط، JSON، XML، تواريخ، تعبيرات نمطية.

> **أسماء بديلة:** `استورد خرائط`، `استورد json`، `استورد xml`، `استورد maps`، `استورد functional`، `استورد engine`

### JSON

#### `حلل_json(نص)` / `json_parse(نص)` / `تحليل_جيسون(نص)`
تحليل نص JSON إلى قيمة (خريطة، مصفوفة، رقم، نص، منطقي، أو لاشيء).

**يدعم:**
- كائنات `{"مفتاح": قيمة}` → خريطة
- مصفوفات `[1, 2, 3]` → مصفوفة
- نصوص (مع تهريب `\"`, `\\`, `\n`, `\t`, `\r`, `\b`, `\f`)
- **Unicode escapes** `\uXXXX` و surrogate pairs `\uD83D\uDE00`
- أرقام (صحيحة وعشرية، بما فيها `1e10`)
- `true`/`false`/`null`

```sad
استورد محرك

متغير كائن = حلل_json("{\"x\":1,\"arr\":[2,3]}")
اطبع(كائن["x"])        # 1
اطبع(كائن["arr"][0])   # 2

# Unicode
متغير عربي = حلل_json("{\"اسم\":\"\\u0645\\u0631\\u062d\\u0628\\u0627\"}")
اطبع(عربي["اسم"])      # مرحبا
```

#### `حول_لـjson(قيمة)` / `json_stringify(قيمة)` / `نص_جيسون(قيمة)`
تحويل قيمة إلى نص JSON. أحرف non-ASCII تُصدَّر كـ `\uXXXX`.

```sad
استورد محرك

متغير كائن = حلل_json("{\"اسم\":\"مرحبا\"}")
متغير نتيجة = حول_لـjson(كائن)
# نتيجة = {"اسم":"\u0645\u0631\u062D\u0628\u0627"}

# Round-trip مضمون
متغير نسخة = حلل_json(نتيجة)
# نسخة["اسم"] == "مرحبا"
```

#### `json_منسق(قيمة, مسافات)` / `json_pretty(قيمة, مسافات)` / `تنسيق_جيسون(قيمة, مسافات)`
تنسيق JSON بمسافات بادئة (القيمة الافتراضية: 2).

```sad
استورد محرك

متغير كائن = حلل_json("{\"x\":1,\"y\":[2,3]}")
اطبع(json_منسق(كائن, 4))
# {
#     "x": 1,
#     "y": [
#         2,
#         3
#     ]
# }
```

#### `json_مصغر(قيمة)` / `json_minify(قيمة)`
نفس `حول_لـjson` — JSON مدمج بدون مسافات.

#### `json_parse_value(نص)`
اسم بديل لـ `حلل_json`.

### XML

#### `حلل_xml(نص)` / `xml_parse(نص)` / `تحليل_xml(نص)`
تحليل نص XML إلى خريطة بالبنية:
```
{
    "name": "اسم_العنصر",
    "text": "النص الداخلي",
    "children": [عنصر1, عنصر2, ...]
}
```

```sad
استورد محرك

متغير عنصر = حلل_xml("<root><child>مرحبا</child></root>")
اطبع(عنصر["name"])                    # root
اطبع(عنصر["children"][0]["name"])     # child
اطبع(عنصر["children"][0]["text"])     # مرحبا
```

#### `حول_لـxml(خريطة)` / `xml_stringify(خريطة)` / `نص_xml(خريطة)`
تحويل خريطة XML إلى نص XML مدمج.

```sad
استورد محرك

متغير عنصر = حلل_xml("<root><n>5</n></root>")
متغير نص = حول_لـxml(عنصر)
# نص = "<root><n>5</n></root>"
```

#### `xml_منسق(خريطة, مسافات)` / `xml_pretty(خريطة, مسافات)`
تنسيق XML بمسافات بادئة.

```sad
استورد محرك

متغير عنصر = حلل_xml("<root><a>1</a><b>2</b></root>")
اطبع(xml_منسق(عنصر, 2))
# <root>
#   <a>1</a>
#   <b>2</b>
# </root>
```

#### `xml_مصغر(خريطة)` / `xml_minify(خريطة)`
نفس `حول_لـxml` — XML مدمج بدون مسافات.

### الخرائط

| الدالة | الوصف |
|--------|-------|
| `خريطة_جديدة()` | إنشاء خريطة فارغة |
| `مفاتيح(خريطة)` | مصفوفة المفاتيح |
| `قيم(خريطة)` | مصفوفة القيم |
| `دمج(خ1, خ2)` | دمج خريطتين |

### دوال وظيفية

| الدالة | الوصف | مثال |
|--------|-------|------|
| `تصفية(مصفوفة, دالة)` | تصفية عناصر | `تصفية([1,2,3], لامدا(س) س > 1 نهاية)` |
| `تحويل(مصفوفة, دالة)` | تحويل عناصر (map) | `تحويل([1,2,3], لامدا(س) س * 2 نهاية)` |
| `تجميع(مصفوفة, دالة, بداية)` | تجميع (reduce) | `تجميع([1,2,3], لامدا(أ,ب) أ+ب نهاية, 0)` |

## وحدة نصوص (`استورد نصوص`)

مصفوفات، نصوص، رياضيات أساسية، فحص أنواع.

### المصفوفات

| الدالة | الوصف |
|--------|-------|
| `أضف(مصفوفة, عنصر)` | إضافة عنصر |
| `أزل(مصفوفة, فهرس)` | حذف بالفهرس |
| `فرز(مصفوفة)` | ترتيب تصاعدي |
| `عكس(مصفوفة)` | عكس |
| `تسطيح(مصفوفة)` | تسطيح مصفوفة متداخلة |

### النصوص

| الدالة | الوصف |
|--------|-------|
| `قسم(نص, فاصل)` | تقسيم نص |
| `صل(مصفوفة, فاصل)` | دمج مصفوفة كنص |
| `استبدل(نص, قديم, جديد)` | استبدال |
| `بحث(نص, هدف)` | موقع أول تطابق |
| `أحرف_كبيرة(نص)` | تحويل لأحرف كبيرة |
| `أحرف_صغيرة(نص)` | تحويل لأحرف صغيرة |
| `قطعة(نص, بداية, نهاية)` | قص جزء |

### الرياضيات الأساسية

| الدالة | الوصف |
|--------|-------|
| `القيمة_المطلقة(رقم)` / `abs` | القيمة المطلقة |
| `أكبر(قائمة)` / `max` | أكبر قيمة |
| `أصغر(قائمة)` / `min` | أصغر قيمة |
| `جمع(قائمة)` / `sum` | مجموع |
| `الجذر(رقم)` / `sqrt` | الجذر التربيعي |

### فحص الأنواع

| الدالة | الوصف |
|--------|-------|
| `هو_رقم_صحيح(قيمة)` | هل هو رقم صحيح؟ |
| `هو_رقم_عشري(قيمة)` | هل هو عشري؟ |
| `هو_نص(قيمة)` | هل هو نص؟ |
| `هو_مصفوفة(قيمة)` | هل هو مصفوفة؟ |

## وحدة تأكيدات (`استورد تأكيدات`)

دوال التأكيد للاختبارات.

| الدالة | الوصف |
|--------|-------|
| `تأكد_يساوي(أ, ب)` | تأكيد التساوي |
| `تأكد_لا_يساوي(أ, ب)` | تأكيد عدم التساوي |
| `تأكد_صحيح(شرط)` | تأكيد أن الشرط صحيح |
| `تأكد_خطأ(شرط)` | تأكيد أن الشرط خاطئ |
| `تأكد_أكبر(أ, ب)` | تأكيد أ > ب |
| `تأكد_أصغر(أ, ب)` | تأكيد أ < ب |
| `تأكد_لاشيء(قيمة)` | تأكيد أن القيمة لاشيء |
| `تأكد_ليس_لاشيء(قيمة)` | تأكيد أن القيمة ليست لاشيء |
| `هاش(قيمة)` / `hash` | حساب هاش القيمة |

## رسائل الخطأ الذكية

```
❌ خطأ: دالة غير معرّفة: أضف
💡 جرّب: استورد نصوص

❌ خطأ: دالة غير معرّفة: خروج
💡 جرّب: استورد أساسيات

❌ خطأ: دالة غير معرّفة: حلل_json
💡 جرّب: استورد خرائط
```
