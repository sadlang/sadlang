# الاستيراد والتصدير (نظام الوحدات) في لغة ص

## نظرة عامة

لغة ص تدعم نظام وحدات قوي للتنظيم وإعادة استخدام الكود، مع دعم الاستيراد الكامل والانتقائي والتصدير.

---

## الاستيراد الكامل

```sad
# استيراد وحدة كاملة
استورد رياضيات

# استخدام مع اسم الوحدة
متغير نتيجة = رياضيات.جذر(16)
```

### مع مسار منقط

```sad
# وحدات متداخلة
استورد شبكة.http
استورد قاعدة_بيانات.محلي

متغير استجابة = شبكة.http.اطلب("https://example.com")
```

### مع اسم مستعار

```sad
# تسمية مختصرة
استورد رياضيات كـ ر
استورد شبكة.http كـ خ

متغير نتيجة = ر.جذر(25)
متغير ص = خ.اطلب("...")
```

### استيراد من مسار نصي

```sad
# مسار ملف
استورد "مكتبة/أدوات"
استورد "../مشترك/أنواع"
```

## الاستيراد الانتقائي

### استيراد عناصر محددة

```sad
# استيراد دوال محددة
من رياضيات استورد جذر، قوة، باي

# استخدام مباشر بدون اسم الوحدة
متغير نتيجة = جذر(25)
اطبع(باي)
```

### استيراد مع اسم مستعار

```sad
من رياضيات استورد جذر كـ ج، قوة كـ ق

متغير نتيجة = ج(16)    # بدل جذر(16)
```

### استيراد الكل (Wildcard)

```sad
# استيراد جميع العناصر المصدّرة
من رياضيات استورد *

# يمكن استخدام كل شيء من الوحدة مباشرة
متغير نتيجة = جذر(25) + باي
```

> **تحذير:** استيراد الكل `*` قد يتسبب في تعارض الأسماء. يُفضل الاستيراد الانتقائي.

## التصدير

### تصدير دالة

```sad
صدّر دالة جمع(أ: رقم، ب: رقم) رقم
   ارجع أ + ب
نهاية

صدّر دالة طرح(أ: رقم، ب: رقم) رقم
   ارجع أ - ب
نهاية
```

### تصدير صنف

```sad
صدّر صنف متجه
   عشري س
   عشري ص

   باني(س: عشري، ص: عشري)
      هذا.س = س
      هذا.ص = ص
   نهاية

   دالة طول() عشري
      ارجع (هذا.س ** 2 + هذا.ص ** 2) ** 0.5
   نهاية
نهاية
```

### تصدير ثابت ومتغير

```sad
صدّر ثابت PI = 3.14159265
صدّر ثابت E = 2.71828
صدّر متغير عداد_عالمي = 0
```

## مثال عملي: مشروع متعدد الملفات

### ملف `رياضيات.ص`

```sad
# وحدة الرياضيات
صدّر ثابت باي = 3.14159265

صدّر دالة مساحة_الدائرة(نصف_القطر: عشري) عشري
   ارجع باي * نصف_القطر ** 2
نهاية

صدّر دالة محيط_الدائرة(نصف_القطر: عشري) عشري
   ارجع 2 * باي * نصف_القطر
نهاية

# دالة خاصة (لا تُصدّر)
دالة _تحقق_موجب(قيمة: عشري) منطقي
   ارجع قيمة > 0
نهاية
```

### ملف `أشكال.ص`

```sad
# استيراد من وحدة الرياضيات
من رياضيات استورد باي، مساحة_الدائرة

صدّر صنف مستطيل
   عشري الطول
   عشري العرض

   باني(طول: عشري، عرض: عشري)
      هذا.الطول = طول
      هذا.العرض = عرض
   نهاية

   دالة مساحة() عشري
      ارجع هذا.الطول * هذا.العرض
   نهاية
نهاية

صدّر صنف دائرة
   عشري نصف_القطر

   باني(نق: عشري)
      هذا.نصف_القطر = نق
   نهاية

   دالة مساحة() عشري
      ارجع مساحة_الدائرة(هذا.نصف_القطر)
   نهاية
نهاية
```

### ملف `رئيسي.ص`

```sad
من أشكال استورد مستطيل، دائرة
استورد رياضيات كـ ر

متغير م = جديد مستطيل(10.0، 5.0)
متغير د = جديد دائرة(7.0)

اطبع_سطر(f"مساحة المستطيل: {م.مساحة()}")
اطبع_سطر(f"مساحة الدائرة: {د.مساحة()}")
اطبع_سطر(f"قيمة باي: {ر.باي}")
```
