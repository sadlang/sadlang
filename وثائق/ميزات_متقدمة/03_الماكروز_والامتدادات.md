# الماكروز وطرق الامتداد

## الماكروز (Macros)

الماكروز أدوات قوية لإعادة الاستخدام تشبه الدوال لكنها تتميز بـ:
- **أمان النطاق (Hygiene)**: المتغيرات المُعرّفة داخل الماكرو لا تُلوّث النطاق الخارجي
- **النسخ للخلف (Copy-back)**: إذا مُرِّر متغير كوسيط، تُنسخ التعديلات تلقائياً
- **معاملات متغيرة**: مع `...اسم` لجمع عدد غير محدد من الوسائط
- **قيمة إرجاع**: الماكرو يمكن أن يُرجع قيمة بـ `ارجع` (ماكرو تعبيري)

### التعريف والاستدعاء

```sad
# تعريف: ماكرو + اسم + (معاملات) + جسم + نهاية
ماكرو اسم_الماكرو(معامل1، معامل2)
    # جسم الماكرو
نهاية

# الاستدعاء: دائماً بعلامة !
اسم_الماكرو!(قيمة1، قيمة2)
```

### أنواع الماكروز

#### 1. ماكرو بسيط (أمري)
```sad
ماكرو سجّل(رسالة)
    اطبع_سطر("[سجل] " + رسالة)
نهاية

سجّل!("بدء البرنامج")
# الناتج: [سجل] بدء البرنامج
```

#### 2. ماكرو بدون معاملات
```sad
ماكرو مرحبا()
    اطبع_سطر("مرحباً بالعالم!")
نهاية

مرحبا!()
```

#### 3. ماكرو تعبيري (يُرجع قيمة)
```sad
ماكرو أكبر(أ، ب)
    إذا (أ > ب)
        ارجع أ
    وإلا
        ارجع ب
    نهاية
نهاية

متغير الناتج = أكبر!(10، 25)
اطبع_سطر("الأكبر: " + الناتج)  # الأكبر: 25

# يمكن استخدامه في تعبيرات:
متغير مجموع = أكبر!(5، 3) + أكبر!(7، 2)  # 5 + 7 = 12
```

#### 4. ماكرو بمعاملات متغيرة
```sad
# المعامل المتغير (...اسم) يجمع كل الوسائط الإضافية في مصفوفة
ماكرو اطبع_الكل(...عناصر)
    لكل عنصر في عناصر
        اطبع_سطر("→ " + عنصر)
    نهاية
نهاية

اطبع_الكل!("أحمد"، "سارة"، "محمد")
# → أحمد
# → سارة
# → محمد
```

#### 5. ماكرو بمعاملات مطلوبة + متغيرة
```sad
# المعامل المتغير يجب أن يكون الأخير
ماكرو سجّل_بمستوى(مستوى، ...رسائل)
    لكل ر في رسائل
        اطبع_سطر("[" + مستوى + "] " + ر)
    نهاية
نهاية

سجّل_بمستوى!("خطأ"، "فشل الاتصال"، "مهلة انتهت")
# [خطأ] فشل الاتصال
# [خطأ] مهلة انتهت
```

### أمان النطاق (Hygiene)

المتغيرات المُعرّفة داخل الماكرو تعيش في نطاق معزول:

```sad
متغير س = 100

ماكرو اختبار()
    متغير س = 999        # هذا س مختلف!
    اطبع_سطر("داخل: " + س)  # 999
نهاية

اختبار!()
اطبع_سطر("خارج: " + س)     # 100 — لم يتأثر!
```

### النسخ للخلف (Copy-back)

إذا مررت متغيراً كوسيط، التعديلات تُنسخ تلقائياً:

```sad
ماكرو زد(المتغير)
    المتغير = المتغير + 1
نهاية

متغير عداد = 0
زد!(عداد)   # عداد = 1
زد!(عداد)   # عداد = 2
زد!(عداد)   # عداد = 3
اطبع_سطر("العداد: " + عداد)  # العداد: 3
```

### ماكروز متداخلة

يمكن استدعاء ماكرو من داخل ماكرو آخر:

```sad
ماكرو تنسيق(نص)
    ارجع "[" + نص + "]"
نهاية

ماكرو سجّل(رسالة)
    متغير منسّق = تنسيق!(رسالة)
    اطبع_سطر("📝 " + منسّق)
نهاية

سجّل!("مرحبا")  # 📝 [مرحبا]
```

## طرق الامتداد (Extension Methods)

طرق الامتداد تسمح بإضافة دوال جديدة لأصناف موجودة بدون تعديل تعريفها الأصلي:

```sad
# 1. تعريف الصنف الأصلي
صنف نقطة
    متغير عام س
    متغير عام ص
    باني(س، ص)
        هذا.س = س
        هذا.ص = ص
    نهاية
نهاية

# 2. إضافة طرق جديدة عبر امتداد
امتداد نقطة
    دالة وصف()
        ارجع "(" + هذا.س + "، " + هذا.ص + ")"
    نهاية

    دالة مسافة()
        ارجع (هذا.س ** 2 + هذا.ص ** 2) ** 0.5
    نهاية
نهاية

# 3. استخدام الدوال المضافة
متغير ن = نقطة(3، 4)
اطبع_سطر(ن.وصف())    # (3، 4)
اطبع_سطر(ن.مسافة())  # 5
```

### ملاحظات:
- الامتداد لا يستطيع تجاوز دوال موجودة في الصنف (حماية من التعارض)
- يمكن إضافة عدة كتل `امتداد` لنفس الصنف
- داخل الامتداد، `هذا` يشير للكائن الحالي
- الامتداد يعمل على جميع الأصناف بما فيها الأصناف المستوردة
