# القوالب والبرمجة العامة (Generics/Templates) في لغة ص

## نظرة عامة

القوالب في لغة ص تسمح بكتابة دوال وأصناف تعمل مع أنواع مختلفة بدون تكرار الكود. تدعم قيود الأنواع وجمل `حيث` (where clause).

---

## قوالب الدوال

### تعريف قالب دالة

```sad
قالب<نوع ت>
دالة أكبر(أ: ت، ب: ت) ت
   إذا (أ > ب)
      ارجع أ
   وإلا
      ارجع ب
   نهاية
نهاية

# استخدام مع أنواع مختلفة
اطبع(أكبر<رقم>(10، 20))        # 20
اطبع(أكبر<نص>("أحمد"، "زيد"))  # زيد
```

### معاملات نوع متعددة

```sad
قالب<نوع ت، نوع م>
دالة م تحويل(قيمة: ت، محوّل: دالة(ت) -> م)
   ارجع محوّل(قيمة)
نهاية
```

## قوالب الأصناف

```sad
قالب<نوع ت>
صنف صندوق
   خاص ت المحتوى

   باني(قيمة: ت)
      هذا.المحتوى = قيمة
   نهاية

   دالة احصل() ت
      ارجع هذا.المحتوى
   نهاية

   دالة عيّن(قيمة: ت)
      هذا.المحتوى = قيمة
   نهاية
نهاية

# استخدام
متغير صندوق_أرقام = صندوق<رقم>(42)
اطبع(صندوق_أرقام.احصل())   # 42

متغير صندوق_نصوص = صندوق<نص>("مرحباً")
اطبع(صندوق_نصوص.احصل())   # مرحباً
```

## قيود الأنواع (Type Constraints)

### قيد واحد

```sad
قالب<نوع ت : قابل_للمقارنة>
دالة رتب(مصفوفة: مصفوفة<ت>) مصفوفة<ت>
   # خوارزمية الترتيب تحتاج المقارنة
   # ...
نهاية
```

### قيود متعددة

```sad
قالب<نوع ت : قابل_للنسخ + قابل_للمقارنة>
دالة ابحث_وانسخ(مجموعة: مصفوفة<ت>، هدف: ت) ت
   لكل عنصر في مجموعة
      إذا (عنصر.قارن(هدف) == 0)
         ارجع عنصر.نسخ()
      نهاية
   نهاية
   ارمي "غير موجود"
نهاية
```

---

## جملة `حيث` (Where Clause)

```sad
قالب<نوع ت> حيث ت: قابل_للمقارنة
دالة أصغر(مصفوفة: مصفوفة<ت>) ت
   متغير حد = مصفوفة[0]
   لكل عنصر في مصفوفة
      إذا (عنصر.قارن(حد) < 0)
         حد = عنصر
      نهاية
   نهاية
   ارجع حد
نهاية
```

### حيث مع عدة قيود

```sad
قالب<نوع ت، نوع م> حيث ت: قابل_للتسلسل، م: قابل_للتسلسل
دالة دمج(أ: ت، ب: م) نص
   ارجع أ.إلى_نص() + " + " + ب.إلى_نص()
نهاية
```

## تنفيذ القالب (Template Instantiation)

```sad
# تنفيذ صريح للنوع
متغير نتيجة = أكبر<رقم>(10، 20)
متغير قائمة = صندوق<نص>("مرحباً")

# تنفيذ مع new
متغير ق = قائمة<رقم>()
```

## مثال عملي: قائمة مرتبطة عامة

```sad
قالب<نوع ت>
صنف عقدة
   ت القيمة
   عقدة<ت> التالي

   باني(قيمة: ت)
      هذا.القيمة = قيمة
      هذا.التالي = لاشيء
   نهاية
نهاية

قالب<نوع ت>
صنف قائمة_مرتبطة
   متغير خاص الرأس
   متغير خاص الحجم

   باني()
      هذا.الرأس = لاشيء
      هذا.الحجم = 0
   نهاية

   دالة أضف(قيمة: ت)
      متغير عقدة_جديدة = عقدة<ت>(قيمة)
      عقدة_جديدة.التالي = هذا.الرأس
      هذا.الرأس = عقدة_جديدة
      هذا.الحجم += 1
   نهاية

   دالة طول() رقم
      ارجع هذا.الحجم
   نهاية

   دالة تحتوي(قيمة: ت) منطقي
      متغير حالي = هذا.الرأس
      بينما (حالي != لاشيء)
         إذا (حالي.القيمة == قيمة)
            ارجع صحيح
         نهاية
         حالي = حالي.التالي
      نهاية
      ارجع خطأ
   نهاية
نهاية

# استخدام
متغير أرقام = قائمة_مرتبطة<رقم>()
أرقام.أضف(10)
أرقام.أضف(20)
أرقام.أضف(30)
اطبع(أرقام.طول())        # 3
اطبع(أرقام.تحتوي(20))   # صحيح

متغير نصوص = قائمة_مرتبطة<نص>()
نصوص.أضف("مرحباً")
نصوص.أضف("عالم")
```
