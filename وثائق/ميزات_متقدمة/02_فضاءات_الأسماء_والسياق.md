# فضاءات الأسماء ومدير السياق في لغة ص

## نظرة عامة

فضاءات الأسماء تنظم الكود في مساحات منفصلة لتجنب تعارض الأسماء. مدير السياق يضمن تنظيف الموارد تلقائياً.

---

## فضاءات الأسماء (Namespaces)

### التعريف

```sad
# الصيغة 1: مع نهاية_فضاء
فضاء رياضيات
   ثابت باي = 3.14159265

   دالة جمع(أ: عشري، ب: عشري) عشري
      ارجع أ + ب
   نهاية

   دالة ضرب(أ: عشري، ب: عشري) عشري
      ارجع أ * ب
   نهاية
نهاية_فضاء

# الصيغة 2: مع نهاية
فضاء نصوص
   دالة كبّر(نص: نص) نص
      # تحويل إلى أحرف كبيرة
   نهاية
نهاية

# الصيغة 3: مع أقواس
فضاء أدوات {
   دالة سجّل(رسالة: نص)
      اطبع_سطر(f"[سجل] {رسالة}")
   نهاية
}
```

### استخدام فضاء الأسماء

```sad
# وصول مباشر
متغير نتيجة = رياضيات.جمع(3.0، 5.0)
اطبع(رياضيات.باي)

# مع استيراد
استورد رياضيات
من رياضيات استورد جمع، باي
```

### فضاءات متداخلة

```sad
فضاء شركة
   فضاء موظفون
      صنف موظف
         نص الاسم
      نهاية
   نهاية_فضاء

   فضاء مشاريع
      صنف مشروع
         نص العنوان
      نهاية
   نهاية_فضاء
نهاية_فضاء

# الوصول
متغير م = جديد شركة.موظفون.موظف()
```

## مدير السياق (Context Manager / باستخدام)

### الصيغة الأساسية

```sad
باستخدام مورد كـ اسم
   # استخدام المورد
   # يُنظّف تلقائياً عند الخروج
نهاية
```

### مثال: التعامل مع الملفات

```sad
باستخدام افتح("بيانات.txt"، "قراءة") كـ ملف
   متغير محتوى = ملف.اقرأ()
   اطبع_سطر(محتوى)
نهاية
# الملف يُغلق تلقائياً هنا
```

### مثال: اتصال قاعدة بيانات

```sad
باستخدام اتصل_بقاعدة_بيانات("خادم_محلي") كـ قب
   متغير نتائج = قب.نفّذ("اختر * من مستخدمين")
   لكل صف في نتائج
      اطبع_سطر(صف)
   نهاية
نهاية
# الاتصال يُغلق تلقائياً
```

### كيف يعمل مدير السياق

عند الدخول يُستدعى `__دخول__()` وعند الخروج يُستدعى `__خروج__()`:

```sad
صنف مدير_مورد
   دالة __دخول__()
      اطبع("بدء استخدام المورد")
      ارجع هذا
   نهاية

   دالة __خروج__()
      اطبع("تنظيف المورد")
   نهاية
نهاية

باستخدام جديد مدير_مورد() كـ مورد
   اطبع("استخدام المورد")
نهاية

# الخرج:
# بدء استخدام المورد
# استخدام المورد
# تنظيف المورد
```

## تعليقات التوثيق

### الصيغة

دالة عملية()
نهاية

#**
   تعليق توثيق متعدد الأسطر
   يُستخدم لتوثيق الدوال والأصناف
**#
```

### العلامات المدعومة

```sad
/// # دالة الجمع
///
/// تجمع عددين وترجع الناتج.
///
/// @معطى أ - العدد الأول
/// @معطى ب - العدد الثاني
/// @أرجع مجموع العددين
/// @مثال
/// ```ص
/// متغير نتيجة = جمع(3, 5)
/// ```
/// @منذ 1.0
/// @انظر طرح
دالة جمع(أ: رقم، ب: رقم) رقم
   ارجع أ + ب
نهاية
```

### جميع العلامات المدعومة

| العلامة | المعنى |
|---------|--------|
| `@معطى` | وصف معطى/معامل |
| `@أرجع` | وصف القيمة المرجعة |
| `@مثال` | مثال استخدام |
| `@انظر` | مرجع لعنصر آخر |
| `@نسخة` | رقم النسخة |
| `@منذ` | متى أُضيف العنصر |
| `@مهمل` | علامة إهمال (deprecated) |
| `@تحذير` | تحذير مهم |

## الاختبارات

### تعريف اختبار

```sad
اختبر("وصف الاختبار")
   # كود الاختبار
   تأكد(جمع(2، 3) == 5)
   تأكد(طرح(10، 3) == 7)
نهاية
```

### أمثلة

```sad
اختبر("اختبار دالة الجمع")
   تأكد(جمع(0، 0) == 0)
   تأكد(جمع(1، 1) == 2)
   تأكد(جمع(-1، 1) == 0)
   تأكد(جمع(100، 200) == 300)
نهاية

اختبر("اختبار صنف شخص")
   متغير ش = جديد شخص("أحمد"، 25)
   تأكد(ش.الاسم == "أحمد")
   تأكد(ش.العمر == 25)
نهاية
```

### اختبار الخصائص (Property Testing)

```sad
#[اختبار_خاصية(تكرارات = 100)]
دالة خاصية_الجمع_تبادلي(أ: رقم، ب: رقم) منطقي
   ارجع جمع(أ، ب) == جمع(ب، أ)
نهاية

#[اختبار_خاصية(بذرة = 42، حد_أقصى = 1000)]
دالة خاصية_عكس_عكس(قائمة: مصفوفة<رقم>) منطقي
   ارجع اعكس(اعكس(قائمة)) == قائمة
نهاية
```

| السمة | المعنى |
|-------|--------|
| `تكرارات = N` | عدد مرات تشغيل الاختبار بقيم عشوائية |
| `بذرة = N` | بذرة مولد الأرقام العشوائية (للتكرارية) |
| `حد_أقصى = N` | الحد الأقصى لحجم القيم المولدة |
