# معالجة الأخطاء في لغة ص

## نظرة عامة

لغة ص توفر نظام معالجة أخطاء شامل باستخدام `حاول` / `امسك` / `أخيراً` مع دعم أنواع الاستثناءات ورمي الأخطاء المخصصة.

---

## كتلة حاول / امسك / أخيراً

### الصيغة الأساسية

```sad
حاول
   # كود قد يُسبب خطأ
امسك خطأ
   # معالجة الخطأ
نهاية
```

### مع `أخيراً`

```sad
حاول
   # كود قد يُسبب خطأ
   متغير نتيجة = عملية_خطرة()
امسك خ
   # معالجة الخطأ
   اطبع_سطر(f"حدث خطأ: {خ}")
أخيراً
   # يُنفذ دائماً — سواء حدث خطأ أم لا
   أغلق_الموارد()
نهاية
```

### التقاط أنواع محددة من الأخطاء

```sad
حاول
   متغير بيانات = اقرأ_ملف("بيانات.txt")
   متغير نتيجة = حلل(بيانات)
امسك (خطأ_ملف) خ
   اطبع_سطر(f"خطأ في الملف: {خ}")
امسك (خطأ_تحليل) خ
   اطبع_سطر(f"خطأ في التحليل: {خ}")
امسك خ
   # التقاط أي خطأ آخر
   اطبع_سطر(f"خطأ غير متوقع: {خ}")
أخيراً
   اطبع_سطر("تم تنظيف الموارد")
نهاية
```

### ملاحظات
- الأقواس حول نوع الخطأ في `امسك` **اختيارية**
- يمكن وجود عدة كتل `امسك` لأنواع مختلفة
- كتلة `أخيراً` **اختيارية** — تُنفذ دائماً

## رمي الأخطاء

### رمي نص

```sad
دالة قسمة(أ: عشري، ب: عشري) عشري
   إذا (ب == 0)
      ارمي "لا يمكن القسمة على صفر!"
   نهاية
   ارجع أ / ب
نهاية
```

### رمي كائن خطأ

```sad
صنف خطأ_تحقق
   نص الرسالة
   نص الحقل

   باني(رسالة: نص، حقل: نص)
      هذا.الرسالة = رسالة
      هذا.الحقل = حقل
   نهاية
نهاية

دالة تحقق_العمر(عمر: رقم)
   إذا (عمر < 0)
      ارمي جديد خطأ_تحقق("العمر لا يمكن أن يكون سالباً"، "عمر")
   نهاية
   إذا (عمر > 150)
      ارمي جديد خطأ_تحقق("العمر غير واقعي"، "عمر")
   نهاية
نهاية
```

## العقود البرمجية (Design by Contract)

### شروط مسبقة ولاحقة

```sad
دالة قسمة(أ: عشري، ب: عشري) -> عشري
   يتطلب ب != 0                    # شرط مسبق
   يضمن النتيجة * ب == أ           # شرط لاحق
   ارجع أ / ب
نهاية
```

### أنواع العقود

| الكلمة | المعنى | المكان |
|--------|--------|--------|
| `يتطلب` | شرط مسبق (precondition) | بداية الدالة |
| `يضمن` | شرط لاحق (postcondition) | نهاية الدالة |
| `ثابت` | ثابت (invariant) | داخل الصنف |
| `يفترض` | افتراض (assumes) | أي مكان |
| `يؤكد` | تأكيد (asserts) | أي مكان |

### محددات كمية

```sad
دالة كل_موجبة(مصفوفة: مصفوفة<رقم>) منطقي
   يتطلب لكل عنصر في مصفوفة: عنصر > 0
   # ...
نهاية

دالة يوجد_صفر(مصفوفة: مصفوفة<رقم>) منطقي
   يتطلب يوجد عنصر في مصفوفة: عنصر == 0
   # ...
نهاية
```

### كلمة `النتيجة`

في الشروط اللاحقة، `النتيجة` تشير للقيمة المرجعة:

```sad
دالة القيمة_المطلقة(س: عشري) -> عشري
   يضمن النتيجة >= 0
   إذا (س >= 0) ارجع س
   وإلا ارجع -س
   نهاية
نهاية
```

## أمثلة عملية

### نظام تحقق شامل

```sad
صنف خطأ_إدخال
   نص الرسالة
   مصفوفة<نص> الحقول

   باني(رسالة: نص، حقول: مصفوفة<نص> = [])
      هذا.الرسالة = رسالة
      هذا.الحقول = حقول
   نهاية
نهاية

دالة سجّل_مستخدم(اسم: نص، عمر: رقم، بريد: نص)
   متغير أخطاء = []

   إذا (اسم.طول() < 2)
      أخطاء.أضف("الاسم قصير جداً")
   نهاية

   إذا (عمر < 0 أو عمر > 150)
      أخطاء.أضف("العمر غير صالح")
   نهاية

   إذا (ليس "@" في بريد)
      أخطاء.أضف("البريد الإلكتروني غير صالح")
   نهاية

   إذا (أخطاء.طول() > 0)
      ارمي جديد خطأ_إدخال("فشل التحقق"، أخطاء)
   نهاية

   اطبع_سطر(f"تم تسجيل {اسم} بنجاح!")
نهاية

# استخدام
حاول
   سجّل_مستخدم("أ"، -5، "بريد_خاطئ")
امسك (خطأ_إدخال) خ
   اطبع_سطر(f"خطأ: {خ.الرسالة}")
   لكل حقل في خ.الحقول
      اطبع_سطر(f"  - {حقل}")
   نهاية
نهاية
```

### تكرار عملية مع معالجة أخطاء

```sad
دالة اتصل_مع_إعادة(رابط: نص، محاولات: رقم = 3)
   لكل ي في 1..محاولات + 1
      حاول
         متغير نتيجة = اتصل(رابط)
         اطبع_سطر(f"نجح الاتصال في المحاولة {ي}")
         ارجع نتيجة
      امسك خ
         اطبع_سطر(f"فشلت المحاولة {ي}: {خ}")
         إذا (ي == محاولات)
            ارمي f"فشل الاتصال بعد {محاولات} محاولات"
         نهاية
      نهاية
   نهاية
نهاية
```
