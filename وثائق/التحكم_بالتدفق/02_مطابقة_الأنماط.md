# مطابقة الأنماط المتقدمة في لغة ص

## نظرة عامة

مطابقة الأنماط (Pattern Matching) في لغة ص هي ميزة قوية تتجاوز بيان switch/case التقليدي. تدعم أنماطاً متعددة مع شروط حراسة وتفكيك البيانات.

---

## الفرق بين `حالة` و `طابق`

| الميزة | `حالة` (Switch) | `طابق` (Match) |
|--------|----------------|----------------|
| المقارنة | قيم حرفية فقط | أنماط معقدة |
| التفكيك | لا | نعم (قوائم، كائنات) |
| شروط الحراسة | لا | نعم (`إذا`) |
| أنماط بديلة | لا | نعم (`\|`) |
| ربط المتغيرات | لا | نعم |

---

## أنماط القوائم بالتفصيل

### القائمة الفارغة

```sad
طابق بيانات
   عندما []:
      اطبع("لا توجد بيانات")
نهاية
```

### عدد محدد من العناصر

```sad
طابق إحداثيات
   عندما [س]:
      اطبع(f"نقطة أحادية: {س}")
   عندما [س، ص]:
      اطبع(f"نقطة ثنائية: ({س}، {ص})")
   عندما [س، ص، ع]:
      اطبع(f"نقطة ثلاثية: ({س}، {ص}، {ع})")
نهاية
```

### نمط الباقي (`*rest`)

```sad
# التقاط العنصر الأول والباقي
طابق قائمة
   عندما [رأس، *ذيل]:
      اطبع(f"الرأس: {رأس}")
      اطبع(f"الذيل: {ذيل}")
نهاية

# التقاط الأول والأخير والوسط
طابق قائمة
   عندما [أول، *وسط، آخر]:
      اطبع(f"الأول: {أول}، الأخير: {آخر}")
      اطبع(f"الوسط: {وسط}")
نهاية
```

## الأنماط البديلة (OR Patterns)

يمكن دمج عدة أنماط بعامل `|`:

```sad
طابق رمز_العملة
   عندما "SAR" | "AED" | "BHD" | "KWD" | "OMR" | "QAR":
      اطبع("عملة خليجية")
   عندما "EGP" | "MAD" | "TND" | "DZD":
      اطبع("عملة عربية أخرى")
   عندما "USD" | "EUR" | "GBP":
      اطبع("عملة عالمية")
   افتراضي:
      اطبع("عملة غير معروفة")
نهاية
```

## شروط الحراسة المتقدمة

### حراسة بسيطة

```sad
طابق درجة
   عندما د إذا د >= 90: اطبع("ممتاز")
   عندما د إذا د >= 80: اطبع("جيد جداً")
   عندما د إذا د >= 70: اطبع("جيد")
   عندما د إذا د >= 60: اطبع("مقبول")
   عندما _: اطبع("راسب")
نهاية
```

### حراسة مع شروط معقدة

```sad
طابق طلب
   عندما ط إذا ط.نوع == "شراء" و ط.مبلغ > 0:
      اطبع("طلب شراء صالح")
   عندما ط إذا ط.نوع == "شراء" و ط.مبلغ <= 0:
      اطبع("مبلغ غير صالح")
   عندما ط إذا ط.نوع == "إرجاع":
      اطبع("طلب إرجاع")
   عندما _:
      اطبع("نوع طلب غير معروف")
نهاية
```

## أمثلة عملية

### معالج أوامر

```sad
دالة نفّذ_أمر(أمر: نص، معاملات: مصفوفة<نص>)
   طابق أمر
      عندما "مساعدة" | "help":
         اطبع_سطر("الأوامر المتاحة: ...")
      عندما "نسخ" | "copy":
         طابق معاملات
            عندما [مصدر، هدف]:
               اطبع_سطر(f"نسخ من {مصدر} إلى {هدف}")
            عندما [مصدر]:
               اطبع_سطر(f"نسخ {مصدر} إلى الافتراضي")
            عندما _:
               اطبع_سطر("الاستخدام: نسخ <مصدر> [هدف]")
         نهاية
      عندما "خروج" | "exit":
         اطبع_سطر("وداعاً!")
      افتراضي:
         اطبع_سطر(f"أمر غير معروف: {أمر}")
   نهاية
نهاية
```

### تصنيف الأشكال الهندسية

```sad
دالة مساحة(شكل)
   طابق شكل
      عندما {"نوع": "دائرة"، "نصف_قطر": نق}:
         ارجع 3.14159 * نق ** 2
      عندما {"نوع": "مستطيل"، "طول": ط، "عرض": ع}:
         ارجع ط * ع
      عندما {"نوع": "مثلث"، "قاعدة": ق، "ارتفاع": ر}:
         ارجع 0.5 * ق * ر
      عندما _:
         ارمي "شكل غير معروف"
   نهاية
نهاية
```
