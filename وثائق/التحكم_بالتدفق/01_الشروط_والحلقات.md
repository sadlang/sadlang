# الشروط والحلقات في لغة ص

## نظرة عامة

لغة ص تدعم جميع بنى التحكم الأساسية: الشروط، الحلقات، المطابقة، والتوقف والاستمرار. جميع الكتل تنتهي بكلمة `نهاية`.

---

## جملة الشرط: `إذا` / `وإلا`

### الصيغة الأساسية

```sad
إذا (شرط)
   # كود يُنفذ إذا تحقق الشرط
نهاية
```

### مع `وإلا`

```sad
إذا (شرط)
   # كود إذا تحقق الشرط
وإلا
   # كود إذا لم يتحقق
نهاية
```

### مع `وإلا إذا`

```sad
إذا (شرط1)
   # كود إذا تحقق الشرط الأول
وإلا إذا (شرط2)
   # كود إذا تحقق الشرط الثاني
وإلا إذا (شرط3)
   # كود إذا تحقق الشرط الثالث
وإلا
   # كود إذا لم يتحقق أي شرط
نهاية
```

### أمثلة عملية

```sad
متغير درجة = 85

إذا (درجة >= 90)
   اطبع_سطر("ممتاز")
وإلا إذا (درجة >= 80)
   اطبع_سطر("جيد جداً")
وإلا إذا (درجة >= 70)
   اطبع_سطر("جيد")
وإلا إذا (درجة >= 60)
   اطبع_سطر("مقبول")
وإلا
   اطبع_سطر("راسب")
نهاية
```

### ملاحظات
- الأقواس حول الشرط **مطلوبة**: `إذا (شرط)`
- يمكن كتابة `اذا` بدلاً من `إذا` (بدون همزة)
- يمكن كتابة `والا` بدلاً من `وإلا` (بدون همزة)

## حلقة `بينما` (While)

### الصيغة الأساسية

```sad
بينما (شرط)
   # كود يتكرر طالما الشرط متحقق
نهاية
```

### أمثلة

```sad
# عداد تصاعدي
متغير ع = 0
بينما (ع < 10)
   اطبع(ع)
   ع += 1
نهاية

# حلقة لا نهائية (مع نقطة خروج)
بينما (صحيح)
   متغير إدخال = اقرأ_سطر()
   إذا (إدخال == "خروج")
      توقف
   نهاية
   اطبع_سطر(f"كتبت: {إدخال}")
نهاية
```

> **ملاحظة:** `طالما` مرادف لـ `بينما`:
> ```sad
> طالما (شرط)
>    # نفس وظيفة بينما
> نهاية
> ```

## حلقة `لكل` (For Each)

### الصيغة الأساسية

```sad
لكل عنصر في مجموعة
   # كود يتكرر لكل عنصر
نهاية
```

### التكرار على مصفوفة

```sad
متغير فواكه = ["تفاح"، "موز"، "برتقال"]

لكل فاكهة في فواكه
   اطبع_سطر(f"فاكهة: {فاكهة}")
نهاية
```

### التكرار على نطاق

```sad
# من 0 إلى 9
لكل ي في 0..10
   اطبع(ي)
نهاية

# جدول ضرب
لكل ي في 1..10
   اطبع_سطر(f"7 × {ي} = {7 * ي}")
نهاية
```

### التكرار على خريطة

```sad
متغير بيانات = {"اسم": "أحمد"، "عمر": 25}

لكل مفتاح، قيمة في بيانات
   اطبع_سطر(f"{مفتاح}: {قيمة}")
نهاية
```

### الأقواس اختيارية

```sad
# بدون أقواس (الصيغة الوحيدة المدعومة)
لكل عنصر في مجموعة
   # ...
نهاية
```

> ❌ `لكل (عنصر في مجموعة)` بأقواس — أُزيلت

### ملاحظة خاصة بأسماء المتغيرات

يُسمح باستخدام كلمات محجوزة وأسماء أنواع كاسم متغير الحلقة:

```sad
# "رقم" كاسم متغير — مسموح!
لكل رقم في [1، 2، 3]
   اطبع(رقم)
نهاية
```

## `توقف` و `استمر`

### `توقف` (Break)

يخرج من الحلقة الحالية فوراً:

```sad
لكل ي في 0..100
   إذا (ي == 10)
      توقف    # يخرج من الحلقة عند ي = 10
   نهاية
   اطبع(ي)
نهاية
# يطبع: 0, 1, 2, ..., 9
```

### `استمر` (Continue)

يتخطى بقية التكرار الحالي وينتقل للتالي:

```sad
لكل ي في 0..10
   إذا (ي % 2 == 0)
      استمر    # يتخطى الأرقام الزوجية
   نهاية
   اطبع(ي)
نهاية
# يطبع: 1, 3, 5, 7, 9
```

## جملة `حالة` / `طابق` (Switch/Case)

### الصيغة باستخدام `حالة` (Switch)

```sad
حالة (تعبير)
   عندما قيمة1:
      # كود للحالة الأولى
   عندما قيمة2:
      # كود للحالة الثانية
   افتراضي:
      # كود إذا لم تتطابق أي حالة
نهاية
```

### مثال

```sad
متغير يوم = 3

حالة (يوم)
   عندما 1:
      اطبع_سطر("الأحد")
   عندما 2:
      اطبع_سطر("الإثنين")
   عندما 3:
      اطبع_سطر("الثلاثاء")
   عندما 4:
      اطبع_سطر("الأربعاء")
   عندما 5:
      اطبع_سطر("الخميس")
   عندما 6:
      اطبع_سطر("الجمعة")
   عندما 7:
      اطبع_سطر("السبت")
   افتراضي:
      اطبع_سطر("رقم يوم غير صالح")
نهاية
```

### ملاحظات مهمة
- **لا يوجد fall-through** — يُنفذ فقط أول حالة مطابقة
- الشرط يجب أن يكون بين أقواس: `حالة (تعبير)`
- `عندما` تبدأ كل حالة
- `افتراضي` للحالة الافتراضية (اختياري)

## مطابقة الأنماط: `طابق` (Pattern Matching)

### الصيغة الأساسية

```sad
طابق تعبير
   عندما نمط1:
      جسم1
   عندما نمط2:
      جسم2
   افتراضي:
      جسم_افتراضي
نهاية
```

### أنواع الأنماط

#### النمط الحرفي (Literal Pattern)

```sad
طابق قيمة
   عندما 42:
      اطبع("الرقم السحري")
   عندما "أحمد":
      اطبع("اسم معروف")
   عندما صحيح:
      اطبع("قيمة صحيحة")
نهاية
```

#### نمط المتغير (Variable Pattern)

يربط القيمة بمتغير جديد:

```sad
طابق قيمة
   عندما س:
      اطبع(f"القيمة هي: {س}")
نهاية
```

#### النمط العام (Wildcard Pattern)

`_` يطابق أي قيمة دون ربطها:

```sad
طابق قيمة
   عندما 0:
      اطبع("صفر")
   عندما _:
      اطبع("شيء آخر")
نهاية
```

#### نمط القائمة (List Pattern)

```sad
طابق قائمة
   عندما []:
      اطبع("فارغة")
   عندما [أ]:
      اطبع(f"عنصر واحد: {أ}")
   عندما [أ، ب]:
      اطبع(f"عنصران: {أ} و {ب}")
   عندما [أول، *باقي]:
      اطبع(f"أول عنصر: {أول}، والباقي: {باقي}")
نهاية
```

#### نمط القائمة المتقدم مع Rest (`*`)

```sad
طابق أرقام
   عندما [أول، *وسط، آخر]:
      اطبع(f"الأول: {أول}")
      اطبع(f"الوسط: {وسط}")
      اطبع(f"الأخير: {آخر}")
نهاية
```

#### النمط البديل (OR Pattern)

`|` يطابق أي من الأنماط:

```sad
طابق شهر
   عندما 12 | 1 | 2:
      اطبع("شتاء")
   عندما 3 | 4 | 5:
      اطبع("ربيع")
   عندما 6 | 7 | 8:
      اطبع("صيف")
   عندما 9 | 10 | 11:
      اطبع("خريف")
نهاية
```

### شروط الحراسة (Guard Clauses)

يمكن إضافة شرط إضافي بعد النمط باستخدام `إذا`:

```sad
طابق عدد
   عندما س إذا س > 0:
      اطبع("موجب")
   عندما س إذا س < 0:
      اطبع("سالب")
   عندما _:
      اطبع("صفر")
نهاية
```

```sad
# مثال أكثر تعقيداً
طابق شخص
   عندما ش إذا ش.عمر >= 18 و ش.مسجل:
      اطبع("مؤهل للتصويت")
   عندما ش إذا ش.عمر >= 18:
      اطبع("بالغ لكن غير مسجل")
   عندما _:
      اطبع("قاصر")
نهاية
```

## جملة `ارجع` (Return)

```sad
# إرجاع قيمة
دالة مربع(س: رقم) رقم
   ارجع س * س
نهاية

# إرجاع بدون قيمة (فراغ)
دالة طباعة_ترحيب()
   اطبع("مرحباً")
   ارجع
نهاية
```

## أمثلة عملية شاملة

### مثال 1: البحث في مصفوفة

```sad
دالة ابحث(مصفوفة: مصفوفة<رقم>، هدف: رقم) رقم
   لكل ي في 0..مصفوفة.طول()
      إذا (مصفوفة[ي] == هدف)
         ارجع ي    # وجدنا العنصر
      نهاية
   نهاية
   ارجع -1          # لم نجده
نهاية

متغير أرقام = [5، 12، 8، 3، 17، 9]
متغير موضع = ابحث(أرقام، 17)

إذا (موضع != -1)
   اطبع_سطر(f"وُجد في الموضع {موضع}")
وإلا
   اطبع_سطر("غير موجود")
نهاية
```

### مثال 2: تصنيف بمطابقة الأنماط

```sad
دالة صنّف(قيمة)
   طابق قيمة
      عندما رقم إذا رقم < 0:
         ارجع "سالب"
      عندما 0:
         ارجع "صفر"
      عندما رقم إذا رقم > 0 و رقم <= 100:
         ارجع "موجب صغير"
      عندما _:
         ارجع "موجب كبير"
   نهاية
نهاية
```

### مثال 3: حلقات متداخلة مع التحكم

```sad
# طباعة مثلث نجوم
لكل ي في 1..6
   متغير سطر = ""
   لكل ج في 0..ي
      سطر += "* "
   نهاية
   اطبع_سطر(سطر)
نهاية

# النتيجة:
# * 
# * * 
# * * * 
# * * * * 
# * * * * * 
```
