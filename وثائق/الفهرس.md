## نتائج اختبار الميزات

الجدول التالي يلخّص نتائج اختبار ميزات اللغة فعلياً مع المفسر:

| الميزة | الحالة | ملاحظات |
|--------|--------|--------|
| المتغيرات والثوابت | ✅ يعمل | |
| الأنواع (رقم، عشري، نص، منطقي) | ✅ يعمل | المنطقي يظهر true/false |
| العمليات الحسابية (+, -, *, /, %, **) | ✅ يعمل | |
| العمليات المركبة (+=, -=, *=, /=) | ✅ يعمل | `%=` غير مدعوم |
| المقارنة (==, !=, >, <, >=, <=) | ✅ يعمل | |
| المنطق (و، أو، ليس، &&, \|\|) | ✅ يعمل | |
| النصوص والدمج | ✅ يعمل | |
| المصفوفات والفهرسة | ✅ يعمل | .طول() و .أضف() يعملان |
| الخرائط | ✅ يعمل | |
| العامل الثلاثي (? :) | ✅ يعمل | |
| إذا/وإلا/وإلا إذا | ✅ يعمل | |
| بينما | ✅ يعمل | |
| لكل (مصفوفة ونص) | ✅ يعمل | |
| توقف/استمر | ✅ يعمل | |
| الدوال والقيم الافتراضية | ✅ يعمل | |
| الدوال العودية | ✅ يعمل | 5! = 120 |
| لامدا | ✅ يعمل | الصيغة: `لامدا(س) => س * 2` |
| دوال عليا | ✅ يعمل | |
| الأصناف والباني | ✅ يعمل | اختصار هذا.خاصية غير مدعوم |
| الوراثة والأساس | ✅ يعمل | |
| طابق/عندما | ✅ يعمل | يتطلب `:` بعد النمط |
| حاول/امسك/أخيراً | ✅ يعمل | |
| ارمي (throw) | ✅ يعمل | |
| عامل `في` (membership) | ✅ يعمل | |
| ساكن (static) | ❌ محلل فقط | غير مدعوم في المفسر |
