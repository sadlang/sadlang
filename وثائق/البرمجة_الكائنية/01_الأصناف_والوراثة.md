# البرمجة الكائنية (OOP) في لغة ص

## نظرة عامة

لغة ص تدعم البرمجة الكائنية بشكل شامل: أصناف، وراثة (بما في ذلك المتعددة)، بناة وهدام، خصائص، محددات وصول، تحميل عوامل، سمات/واجهات، وأكثر.

---

## الأصناف

### تعريف صنف بسيط

```sad
صنف شخص
   نص الاسم
   رقم العمر

   باني(اسم: نص، عمر: رقم)
      هذا.الاسم = اسم
      هذا.العمر = عمر
   نهاية

   # ⚠️ ملاحظة: الصيغة المختصرة "باني(هذا.الاسم، هذا.العمر)" غير مدعومة في المفسر.
   # استخدم دائماً الإسناد الصريح داخل جسم الباني كما في المثال أعلاه.

   دالة قدم_نفسك()
      اطبع_سطر(f"أنا {هذا.الاسم}، عمري {هذا.العمر} سنة")
   نهاية
نهاية

# إنشاء كائن
متغير ش = شخص("أحمد"، 25)
ش.قدم_نفسك()   # أنا أحمد، عمري 25 سنة
```

## الحقول (Fields)

### تعريف الحقول

```sad
صنف سيارة
   # حقول بأنواع مختلفة
   نص الماركة
   نص الموديل
   رقم السنة
   عشري السعر
   منطقي متاحة

   # حقل مع قيمة افتراضية
   رقم المسافة = 0
نهاية
```

### الوصول للحقول

```sad
متغير س = سيارة()
س.الماركة = "تويوتا"
س.الموديل = "كامري"
اطبع(س.الماركة)       # تويوتا
```

## الباني (Constructor)

### باني بسيط

```sad
صنف نقطة
   عشري س
   عشري ص

   باني(س: عشري، ص: عشري)
      هذا.س = س
      هذا.ص = ص
   نهاية
نهاية
```

### باني مع قيم افتراضية

```sad
صنف مستطيل
   عشري الطول
   عشري العرض

   باني(طول: عشري = 1.0، عرض: عشري = 1.0)
      هذا.الطول = طول
      هذا.العرض = عرض
   نهاية
نهاية

# استخدام القيم الافتراضية
متغير م1 = مستطيل()            # 1.0 × 1.0
متغير م2 = مستطيل(5.0)         # 5.0 × 1.0
متغير م3 = مستطيل(5.0, 3.0)   # 5.0 × 3.0
```

### باني مع استدعاء الأساس

```sad
صنف حيوان
   نص الاسم
   
   باني(اسم: نص)
      هذا.الاسم = اسم
   نهاية
نهاية

صنف قطة يرث حيوان
   نص اللون
   
   # استدعاء الأساس في قائمة التهيئة
   باني(اسم: نص، لون: نص) : الأساس(اسم)
      هذا.اللون = لون
   نهاية
نهاية
```

## الهدام (Destructor)

يُنفذ عند حذف الكائن لتنظيف الموارد:

```sad
صنف ملف
   نص المسار
   رقم المقبض

   باني(مسار: نص)
      هذا.المسار = مسار
      هذا.المقبض = افتح_ملف(مسار)
   نهاية

   هدم()
      أغلق_ملف(هذا.المقبض)
      اطبع_سطر(f"تم إغلاق الملف: {هذا.المسار}")
   نهاية
نهاية
```

## محددات الوصول

### الأنواع المدعومة

| المحدد | المعنى | الوصول |
|--------|--------|--------|
| `عام` | public | من أي مكان |
| `خاص` | private | من داخل الصنف فقط |
| `محمي` | protected | من الصنف والأصناف الوارثة |

### استخدام المحددات

```sad
صنف حساب_بنكي
   # حقول بمحددات وصول
   متغير عام صاحب_الحساب
   متغير خاص الرصيد
   متغير محمي رقم_الحساب

   باني(صاحب: نص، رصيد_ابتدائي: عشري)
      هذا.صاحب_الحساب = صاحب
      هذا.الرصيد = رصيد_ابتدائي
      هذا.رقم_الحساب = "SA" + نص(عشوائي())
   نهاية

   # طريقة عامة
   دالة عام إيداع(مبلغ: عشري)
      إذا (مبلغ > 0)
         هذا.الرصيد += مبلغ
         اطبع_سطر(f"تم إيداع {مبلغ}، الرصيد الجديد: {هذا.الرصيد}")
      نهاية
   نهاية

   # طريقة عامة
   دالة عام سحب(مبلغ: عشري) منطقي
      إذا (مبلغ > 0 و مبلغ <= هذا.الرصيد)
         هذا.الرصيد -= مبلغ
         ارجع صحيح
      نهاية
      ارجع خطأ
   نهاية

   # طريقة خاصة
   دالة خاص احسب_الفائدة() عشري
      ارجع هذا.الرصيد * 0.05
   نهاية

   # طريقة عامة لقراءة الرصيد
   دالة عام الرصيد_الحالي() عشري
      ارجع هذا.الرصيد
   نهاية
نهاية
```

## المعدلات الإضافية

### ساكن (Static)

أعضاء تنتمي للصنف نفسه وليس للكائنات:

> **⚠️ ملاحظة:** الكلمة المفتاحية `ساكن` يتم تحليلها نحوياً بنجاح، لكنها **غير مدعومة بالكامل في المفسر** حالياً. الأمثلة التالية توضّح الصيغة النحوية المقبولة فقط.

```sad
صنف عداد
   متغير ساكن العدد = 0

   باني()
      عداد.العدد += 1
   نهاية

   دالة ساكن كم_عدد() رقم
      ارجع عداد.العدد
   نهاية
نهاية

متغير أ = عداد()
متغير ب = عداد()
اطبع(عداد.كم_عدد())   # 2
```

### مجرد (Abstract)

دوال بدون تنفيذ يجب تنفيذها في الأصناف الوارثة:

```sad
صنف شكل
   دالة مجرد مساحة() عشري
   دالة مجرد محيط() عشري

   دالة وصف()
      اطبع_سطر(f"المساحة: {هذا.مساحة()}، المحيط: {هذا.محيط()}")
   نهاية
نهاية
```

```sad
صنف حيوان
   نص الاسم
   
   باني(اسم: نص)
      هذا.الاسم = اسم
   نهاية

   دالة صوت()
      اطبع_سطر("...")
   نهاية
نهاية

صنف قطة يرث حيوان
   باني(اسم: نص) : الأساس(اسم)
   نهاية

   # تجاوز (override)
   دالة صوت()
      اطبع_سطر("مياو!")
   نهاية
نهاية

صنف كلب يرث حيوان
   باني(اسم: نص) : الأساس(اسم)
   نهاية

   دالة صوت()
      اطبع_سطر("هاو!")
   نهاية
نهاية

# تعدد الأشكال (Polymorphism)
متغير حيوانات = [قطة("مشمش")، كلب("ريكس")]
لكل ح في حيوانات
   ح.صوت()
نهاية
```

### وراثة متعددة

```sad
صنف طائر
   دالة طر()
      اطبع("أطير!")
   نهاية
نهاية

صنف سبّاح
   دالة اسبح()
      اطبع("أسبح!")
   نهاية
نهاية

# وراثة من صنفين
صنف بطة يرث طائر، سبّاح
   باني()
   نهاية
```

### استدعاء الأساس

## الخصائص (Properties)

خصائص مع getter/setter للتحكم في القراءة والكتابة:

```sad
صنف دائرة
   متغير خاص _نصف_القطر

   باني(نق: عشري)
      هذا._نصف_القطر = نق
   نهاية

   # خاصية مع getter و setter
   خاصية عشري نصف_القطر
      احصل
         ارجع هذا._نصف_القطر
      نهاية
      عيّن(قيمة)
         إذا (قيمة > 0)
            هذا._نصف_القطر = قيمة
         وإلا
            ارمي "نصف القطر يجب أن يكون موجباً"
         نهاية
      نهاية
   نهاية

   # خاصية قراءة فقط (بدون setter)
   خاصية عشري المساحة
      احصل
         ارجع 3.14159 * هذا._نصف_القطر ** 2
      نهاية
   نهاية

   # خاصية قراءة فقط
   خاصية عشري المحيط
      احصل
         ارجع 2 * 3.14159 * هذا._نصف_القطر
      نهاية
   نهاية
نهاية

# استخدام الخصائص
متغير د = دائرة(5.0)
اطبع(د.نصف_القطر)   # 5.0  (getter)
د.نصف_القطر = 10.0   # setter
اطبع(د.المساحة)      # 314.159...
اطبع(د.المحيط)       # 62.831...
```

## تحميل العوامل الزائد (Operator Overloading)

### العوامل المدعومة

`+`, `-`, `*`, `/`, `%`, `==`, `!=`, `<`, `>`, `<=`, `>=`, `[]`, `()`

### أمثلة

```sad
صنف متجه
   عشري س
   عشري ص

   باني(س: عشري، ص: عشري)
      هذا.س = س
      هذا.ص = ص
   نهاية

   # جمع متجهين
   عامل +(آخر: متجه) متجه
      ارجع متجه(هذا.س + آخر.س، هذا.ص + آخر.ص)
   نهاية

   # طرح
   عامل -(آخر: متجه) متجه
      ارجع متجه(هذا.س - آخر.س، هذا.ص - آخر.ص)
   نهاية

   # ضرب بعدد
   عامل *(عامل: عشري) متجه
      ارجع متجه(هذا.س * عامل، هذا.ص * عامل)
   نهاية

   # المساواة
   عامل ==(آخر: متجه) منطقي
      ارجع هذا.س == آخر.س و هذا.ص == آخر.ص
   نهاية

   # الفهرسة
   عامل [](فهرس: رقم)
      إذا (فهرس == 0) ارجع هذا.س
      وإلا إذا (فهرس == 1) ارجع هذا.ص
      وإلا ارمي "فهرس خارج النطاق"
      نهاية
   نهاية

   # استدعاء كدالة
   عامل ()()
      ارجع (هذا.س ** 2 + هذا.ص ** 2) ** 0.5
   نهاية
نهاية

# استخدام العوامل المحملة
متغير م1 = متجه(3.0، 4.0)
متغير م2 = متجه(1.0، 2.0)
متغير م3 = م1 + م2          # متجه(4.0، 6.0)
متغير م4 = م1 * 2.0         # متجه(6.0، 8.0)
اطبع(م1 == م2)              # خطأ
اطبع(م1[0])                 # 3.0
اطبع(م1())                  # 5.0 (الطول)
```

## الكلمة المفتاحية `هذا` (this)

تشير إلى الكائن الحالي:

```sad
صنف عقدة
   رقم القيمة
   عقدة التالي

   باني(قيمة: رقم)
      هذا.القيمة = قيمة
      هذا.التالي = لاشيء
   نهاية

   # إرجاع هذا للتسلسل (method chaining)
   دالة عيّن_التالي(عقدة: عقدة) عقدة
      هذا.التالي = عقدة
      ارجع هذا
   نهاية
نهاية

# تسلسل الاستدعاءات
متغير قائمة = عقدة(1)
   .عيّن_التالي(عقدة(2))
   .عيّن_التالي(عقدة(3))
```

## مثال عملي شامل: نظام مكتبة

```sad
# صنف أساسي للكتب
صنف كتاب
   متغير عام العنوان
   متغير عام المؤلف
   متغير خاص مستعار

   باني(عنوان: نص، مؤلف: نص)
      هذا.العنوان = عنوان
      هذا.المؤلف = مؤلف
      هذا.مستعار = خطأ
   نهاية

   دالة عام استعر() منطقي
      إذا (ليس هذا.مستعار)
         هذا.مستعار = صحيح
         ارجع صحيح
      نهاية
      ارجع خطأ
   نهاية

   دالة عام أرجع()
      هذا.مستعار = خطأ
   نهاية

   خاصية منطقي متاح
      احصل
         ارجع ليس هذا.مستعار
      نهاية
   نهاية
نهاية

# صنف المكتبة
صنف مكتبة
   متغير خاص الكتب

   باني()
      هذا.الكتب = []
   نهاية

   دالة عام أضف_كتاب(كتاب: كتاب)
      هذا.الكتب.أضف(كتاب)
   نهاية

   دالة عام ابحث(عنوان: نص) كتاب
      لكل كتاب في هذا.الكتب
         إذا (كتاب.العنوان == عنوان)
            ارجع كتاب
         نهاية
      نهاية
      ارجع لاشيء
   نهاية

   دالة عام المتاحة() مصفوفة<كتاب>
      ارجع [ك لكل ك في هذا.الكتب إذا ك.متاح]
   نهاية
نهاية

# استخدام النظام
متغير مكتبتي = مكتبة()
مكتبتي.أضف_كتاب(كتاب("البؤساء"، "فيكتور هوغو"))
مكتبتي.أضف_كتاب(كتاب("مئة عام من العزلة"، "غارسيا ماركيز"))

متغير كتاب = مكتبتي.ابحث("البؤساء")
إذا (كتاب != لاشيء)
   كتاب.استعر()
   اطبع_سطر(f"تم استعارة: {كتاب.العنوان}")
نهاية
```
