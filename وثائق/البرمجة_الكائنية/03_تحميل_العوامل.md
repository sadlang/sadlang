# تحميل العوامل الزائد (Operator Overloading)

تحميل العوامل الزائد يسمح لك بتعريف سلوك مخصص للعوامل (`+`, `-`, `*`, `[]`, `()`, ...) عند استخدامها مع كائنات أصنافك.

## الصياغة الأساسية

```sad
صنف اسم_الصنف
    عام عامل رمز_العامل(المعاملات) نوع_الإرجاع
        # جسم العامل
    نهاية
نهاية
```

## العوامل المدعومة (18 عامل)

### العوامل الثنائية (Binary Operators)

| العامل | الاستخدام | الوصف |
|--------|----------|-------|
| `+` | `أ + ب` | جمع |
| `-` | `أ - ب` | طرح |
| `*` | `أ * ب` | ضرب |
| `/` | `أ / ب` | قسمة |
| `//` | `أ // ب` | قسمة صحيحة |
| `%` | `أ % ب` | باقي القسمة |
| `**` | `أ ** ب` | أُس (رفع لقوة) |

### عوامل المقارنة (Comparison Operators)

| العامل | الاستخدام | الوصف |
|--------|----------|-------|
| `==` | `أ == ب` | مساواة |
| `!=` | `أ != ب` | عدم مساواة |
| `<` | `أ < ب` | أصغر من |
| `>` | `أ > ب` | أكبر من |
| `<=` | `أ <= ب` | أصغر أو يساوي |
| `>=` | `أ >= ب` | أكبر أو يساوي |

### عوامل خاصة (Special Operators)

| العامل | الاستخدام | المعاملات | الوصف |
|--------|----------|----------|-------|
| `[]` | `أ[فهرس]` | 1 (فهرس) | فهرسة / قراءة |
| `[]=` | `أ[فهرس] = قيمة` | 2 (فهرس، قيمة) | إسناد بالفهرس |
| `()` | `أ(معاملات)` | N (أي عدد) | استدعاء الكائن كدالة |

### العوامل الأحادية (Unary Operators)

| العامل | الاستخدام | المعاملات | الوصف |
|--------|----------|----------|-------|
| `-` | `-أ` | 0 (بدون) | سالب أحادي |
| `!` | `!أ` | 0 (بدون) | نفي منطقي |

> **ملاحظة:** العوامل الأحادية تُعرَّف **بدون معاملات** (أقواس فارغة). المفسر يميز تلقائياً بين `-` الثنائي (معامل واحد) و `-` الأحادي (بدون معاملات).

## أمثلة تفصيلية

### 1. صنف متجه (Vector) — عوامل حسابية ومقارنة

```sad
صنف متجه
    متغير س = 0
    متغير ص = 0

    باني(س_ق، ص_ق)
        هذا.س = س_ق
        هذا.ص = ص_ق
    نهاية

    # جمع متجهين
    عام عامل +(آخر) متجه
        ارجع متجه(هذا.س + آخر.س، هذا.ص + آخر.ص)
    نهاية

    # طرح
    عام عامل -(آخر) متجه
        ارجع متجه(هذا.س - آخر.س، هذا.ص - آخر.ص)
    نهاية

    # ضرب عنصري
    عام عامل *(آخر) متجه
        ارجع متجه(هذا.س * آخر.س، هذا.ص * آخر.ص)
    نهاية

    # مساواة
    عام عامل ==(آخر) منطقي
        ارجع هذا.س == آخر.س و هذا.ص == آخر.ص
    نهاية

    # أصغر من (مقارنة بالمقدار)
    عام عامل <(آخر) منطقي
        ارجع (هذا.س ** 2 + هذا.ص ** 2) < (آخر.س ** 2 + آخر.ص ** 2)
    نهاية

    # سالب أحادي (بدون معاملات!)
    عام عامل -() متجه
        ارجع متجه(-س، -ص)
    نهاية
نهاية

متغير أ = متجه(1، 2)
متغير ب = متجه(3، 4)

متغير ج = أ + ب         # (4، 6)
متغير سالب = -أ         # (-1، -2)
اطبع_سطر(أ == أ)       # صحيح
اطبع_سطر(أ < ب)        # صحيح
```

### 2. عامل `+=` — يعمل تلقائياً!

عامل `+=` **لا يحتاج تعريفاً منفصلاً** — المفسر يحوّله تلقائياً إلى `x = x + y`:

```sad
# إذا عرّفت عامل +، فإن += يعمل تلقائياً:
متغير م = متجه(10، 20)
م += متجه(5، 5)       # يتحول إلى: م = م + متجه(5، 5)
# م الآن = (15، 25)
```

> نفس الشيء ينطبق على `-=`, `*=`, `/=`, `%=`, `**=`.

### 3. عامل الفهرسة `[]` و `[]=`

```sad
صنف قائمة_آمنة
    متغير بيانات = []

    باني(ب)
        هذا.بيانات = ب
    نهاية

    # قراءة بالفهرس
    عام عامل [](فهرس)
        إذا (فهرس < 0 أو فهرس >= طول(هذا.بيانات))
            ارمي "فهرس خارج النطاق: " + فهرس
        نهاية
        ارجع هذا.بيانات[فهرس]
    نهاية

    # إسناد بالفهرس (يأخذ معاملين!)
    عام عامل []=(فهرس، قيمة)
        إذا (فهرس < 0 أو فهرس >= طول(هذا.بيانات))
            ارمي "فهرس خارج النطاق: " + فهرس
        نهاية
        هذا.بيانات[فهرس] = قيمة
    نهاية
نهاية

متغير ق = قائمة_آمنة([10، 20، 30])
اطبع_سطر(ق[0])        # 10
ق[1] = 99              # يستدعي عامل []=
اطبع_سطر(ق[1])        # 99
```

### 4. عامل الاستدعاء `()` — كائنات قابلة للاستدعاء (Functors)

```sad
صنف دالة_خطية
    متغير ميل = 0
    متغير تقاطع = 0

    باني(م، ت)
        هذا.ميل = م
        هذا.تقاطع = ت
    نهاية

    # عامل الاستدعاء: يجعل الكائن يتصرف كدالة
    عام عامل ()(س)
        ارجع هذا.ميل * س + هذا.تقاطع
    نهاية
نهاية

متغير د = دالة_خطية(2، 3)   # y = 2x + 3
اطبع_سطر(د(5))                   # 13
اطبع_سطر(د(0))                   # 3
اطبع_سطر(د(-1))                  # 1
```

### 5. عامل الأُس `**`

```sad
صنف مصفوفة_عددية
    متغير قيم = []

    باني(ق)
        هذا.قيم = ق
    نهاية

    # رفع كل عنصر لأس معين
    عام عامل **(أس)
        متغير نتيجة = []
        لكل ع في هذا.قيم
            نتيجة += [ع ** أس]
        نهاية
        ارجع مصفوفة_عددية(نتيجة)
    نهاية
نهاية

متغير م = مصفوفة_عددية([2، 3، 4])
متغير م2 = م ** 3    # [8, 27, 64]
```

## قواعد مهمة

### 1. نوع الإرجاع يأتي مباشرة بعد القوس (بدون سهم)

```sad
# ✅ صحيح:
عام عامل +(آخر) متجه
    # ...
نهاية

# ❌ خطأ — لا تستخدم سهم:
عام عامل +(آخر) -> متجه    # ممنوع!
```

### 2. العوامل الأحادية: أقواس فارغة

```sad
# عامل أحادي (بدون معاملات):
عام عامل -() متجه           # سالب
    ارجع متجه(-س، -ص)
نهاية

# عامل ثنائي (معامل واحد):
عام عامل -(آخر) متجه        # طرح
    ارجع متجه(هذا.س - آخر.س، هذا.ص - آخر.ص)
نهاية
```

### 3. عامل `[]=` يأخذ معاملين دائماً

```sad
عام عامل []=(فهرس، قيمة)
    # الأول: الفهرس
    # الثاني: القيمة المُسندة
نهاية
```

### 4. عامل `()` يأخذ أي عدد من المعاملات

```sad
عام عامل ()(أ، ب، ج)   # ثلاثة معاملات
    ارجع أ + ب + ج
نهاية
```

### 5. الوراثة

العوامل المحملة **تُورث** تلقائياً من الصنف الأساسي:

```sad
صنف نقطة
    متغير س = 0
    متغير ص = 0
    عام عامل ==(آخر) منطقي
        ارجع هذا.س == آخر.س و هذا.ص == آخر.ص
    نهاية
نهاية

صنف نقطة_ملونة يرث نقطة
    متغير لون = "أحمر"
    # عامل == موروث من نقطة!
نهاية
```

### 6. `هذا` متاح داخل العامل

داخل جسم العامل، يمكنك استخدام `هذا` للوصول لحقول الكائن الحالي:

```sad
عام عامل +(آخر)
    ارجع هذا.س + آخر.س    # ✅
نهاية
```

## ملاحظات تقنية

- العوامل المركبة (`+=`, `-=`, `*=`, `/=`, `%=`, `**=`) تُحوَّل تلقائياً إلى `x = x عامل y` — لا تعرّفها يدوياً.
- يمكن للعامل أن يُرجع أي نوع (كائن جديد، رقم، نص، منطقي...).
- التعديلات على حقول `هذا` داخل العامل تُكتب مباشرة إلى الكائن الأصلي (write-back).
- عامل `()` بديل لـ `__call__` — كلاهما يعمل بنفس الطريقة.

## عوامل التحويل الضمني (Implicit Conversion Operators)

عوامل التحويل الضمني تسمح للكائن بتحويل نفسه تلقائياً إلى نوع آخر عندما يكون ذلك مطلوباً من السياق.

### العوامل المتاحة

| العامل | المعاملات | يُستدعى عندما | المتوقع إرجاعه |
|--------|----------|---------------|---------------|
| `نص` | 0 (بدون) | دمج نصي: `"..." + كائن` | نص (`نص`) |
| `منطقي` | 0 (بدون) | شرط: `إذا (كائن)`، `بينما (كائن)`، `و`، `أو`، `ليس` | منطقي (`صحيح`/`خطأ`) |
| `رقم` | 0 (بدون) | عند الحاجة لتحويل كائن لرقم | رقم أو عشري |

### 1. عامل نص() — التحويل الضمني إلى نص

يُعرَّف الشكل العام:

```sad
صنف نقطة
    متغير س = 0
    متغير ص = 0
    
    باني(س، ص)
        هذا.س = س
        هذا.ص = ص
    نهاية
    
    عام عامل نص()
        ارجع "(" + هذا.س + "، " + هذا.ص + ")"
    نهاية
نهاية

متغير ن = نقطة(3، 4)
# عامل نص() يُستدعى تلقائياً عند الدمج النصي
متغير نتيجة = "النقطة: " + ن    # → "النقطة: (3، 4)"
```

**متى يُستدعى:**
- عند استخدام `+` مع نص: `"نص" + كائن` أو `كائن + "نص"`
- **لا يُستدعى** مع `اطبع(كائن)` — `اطبع` تستخدم التمثيل الافتراضي `صنف{حقل: قيمة}`
- لاستدعائه مع الطباعة: `اطبع("" + كائن)`

### 2. عامل منطقي() — التحويل الضمني في الشروط

```sad
صنف مجموعة
    متغير عناصر = []
    
    باني(ع)
        هذا.عناصر = ع
    نهاية
    
    عام عامل منطقي()
        ارجع طول(هذا.عناصر) > 0
    نهاية
نهاية

متغير م1 = مجموعة([1، 2، 3])
متغير م2 = مجموعة([])

# عامل منطقي() يُستدعى في إذا
إذا (م1)
    اطبع_سطر("غير فارغة")     # ✅ يطبع
نهاية

إذا (م2)
    # لن يدخل هنا
نهاية

# يعمل مع و، أو، ليس
إذا (م1 و ليس م2)
    اطبع_سطر("صحيح!")
نهاية
```

**متى يُستدعى:**
- `إذا (كائن)` — شرط if
- `بينما (كائن)` — شرط while
- `كائن و ...` / `كائن أو ...` — عمليات منطقية
- `ليس كائن` — نفي النتيجة
- `!كائن` — نفي

### 3. عامل منطقي() مع بينما (While)

```sad
صنف عداد
    متغير قيمة = 0
    
    باني(ق)
        هذا.قيمة = ق
    نهاية
    
    عام عامل منطقي()
        ارجع هذا.قيمة > 0
    نهاية
نهاية

متغير ع = عداد(3)
متغير مجموع = 0
بينما (ع)
    مجموع = مجموع + ع.قيمة
    ع.قيمة = ع.قيمة - 1
نهاية
# مجموع = 6 (3 + 2 + 1)
```

### 4. الوراثة مع عوامل التحويل

عوامل التحويل **تُورَث** تلقائياً من الصنف الأب:

```sad
صنف شكل
    متغير اسم = ""
    
    باني(اسم)
        هذا.اسم = اسم
    نهاية
    
    عام عامل نص()
        ارجع "شكل: " + هذا.اسم
    نهاية
    
    عام عامل منطقي()
        ارجع هذا.اسم != ""
    نهاية
نهاية

صنف دائرة يرث شكل
    متغير نصف_قطر = 0
    
    باني(نصف_قطر)
        الأساس("دائرة")
        هذا.نصف_قطر = نصف_قطر
    نهاية
    # عامل نص() و عامل منطقي() موروثان من شكل تلقائياً!
نهاية

صنف مربع يرث شكل
    متغير ضلع = 0
    
    باني(ضلع)
        الأساس("مربع")
        هذا.ضلع = ضلع
    نهاية
    
    # إعادة تعريف عامل نص() (override)
    عام عامل نص()
        ارجع "مربع[" + هذا.ضلع + "]"
    نهاية
نهاية

متغير د = دائرة(5)
اطبع_سطر("" + د)    # → "شكل: دائرة" (موروث)

متغير م = مربع(4)
اطبع_سطر("" + م)    # → "مربع[4]" (مُعاد تعريفه)
```

### كائن بدون عامل تحويل

إذا لم يُعرَّف `عامل نص()` أو `عامل منطقي()`:
- **الدمج النصي** يستخدم التمثيل الافتراضي: `<اسم_الصنف#رقم: حقل=قيمة, ...>`
- **الشروط** تعتبر الكائن `صحيح` إذا كان موجوداً (غير `لاشيء`)

### ملاحظات مهمة

1. عوامل التحويل **لا تأخذ معاملات** — الأقواس فارغة دائماً: `عامل نص()`
2. يجب أن يُرجع `عامل نص()` قيمة **نصية** و `عامل منطقي()` قيمة **منطقية**
3. عوامل التحويل **تُورَث** من الصنف الأب ويمكن **إعادة تعريفها** (override)
4. لا تنس كلمة `عام` قبل `عامل` إذا أردت استخدامه من خارج الصنف

## اطبع() و عامل نص() — التكامل التلقائي

عند تمرير كائن إلى `اطبع()` أو `اطبع_سطر()`، يتم البحث تلقائياً عن `عامل نص()` في الصنف واستدعاؤه. هذا يعني أنك **لا تحتاج** لتحويل الكائن يدوياً إلى نص.

### مثال أساسي

```sad
صنف شخص
    باني(الاسم، العمر)
        هذا.الاسم = الاسم
        هذا.العمر = العمر
    نهاية
    
    عامل نص()
        ارجع هذا.الاسم + " (عمره " + هذا.العمر + ")"
    نهاية
نهاية

متغير ش = شخص("أحمد"، 25)

# كل هذه الطرق تعمل:
اطبع_سطر(ش)                    # → أحمد (عمره 25)
اطبع_سطر("المستخدم: " + ش)    # → المستخدم: أحمد (عمره 25)
```

### ترتيب الأولوية في الطباعة

عند طباعة كائن، يتم البحث بالترتيب التالي:

1. **`عامل نص()`** — إذا كان معرفاً (في الصنف أو الأب)
2. **`__نص_عرض__`** — حقل نصي خاص (إذا موجود)
3. **التمثيل الافتراضي** — `اسم_الصنف{حقل: قيمة, ...}`

### مع الوراثة

```sad
صنف كائن_حي
    باني(الاسم)
        هذا.الاسم = الاسم
    نهاية
    
    عامل نص()
        ارجع "كائن حي: " + هذا.الاسم
    نهاية
نهاية

صنف حيوان يرث كائن_حي
    باني(الاسم، النوع)
        الأساس(الاسم)
        هذا.النوع = النوع
    نهاية
    # عامل نص() موروث — اطبع_سطر تستخدمه تلقائياً
نهاية

صنف قطة يرث حيوان
    باني(الاسم)
        الأساس(الاسم، "قطة")
    نهاية
    
    # إعادة تعريف عامل نص()
    عامل نص()
        ارجع "🐱 " + هذا.الاسم
    نهاية
نهاية

متغير ح = حيوان("أرنب"، "ثديي")
اطبع_سطر(ح)    # → كائن حي: أرنب (موروث من كائن_حي)

متغير ق = قطة("ميمي")
اطبع_سطر(ق)    # → 🐱 ميمي (مُعاد تعريفه في قطة)
```

### كائن بدون عامل نص()

```sad
صنف بسيط
    باني(قيمة)
        هذا.قيمة = قيمة
    نهاية
نهاية

متغير ب = بسيط(42)
اطبع_سطر(ب)    # → بسيط{قيمة: 42}   (التمثيل الافتراضي)
```

### نصيحة

عرّف دائماً `عامل نص()` في أصنافك لتحصل على خرج مقروء عند الطباعة والتصحيح:
