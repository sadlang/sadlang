# السمات والتنفيذات وطرق الامتداد في لغة ص

## نظرة عامة

السمات (Traits) والواجهات (Interfaces) في لغة ص تُعرّف عقوداً يجب على الأصناف تنفيذها. طرق الامتداد تسمح بإضافة دوال لأصناف موجودة.

---

## السمات (Traits / Interfaces)

### تعريف سمة

```sad
سمة قابل_للطباعة
   دالة اطبع()
نهاية

سمة قابل_للمقارنة
   دالة قارن(آخر: أي) رقم
نهاية
```

> **ملاحظة:** كلمة `واجهة` كانت مرادفة لـ `سمة` لكن أُزيلت. استخدم `سمة` فقط.

### سمة مع وراثة سمات (Super Traits)

```sad
سمة قابل_للترتيب يرث قابل_للمقارنة
   دالة رتب()
نهاية
```

### سمة مع تنفيذ افتراضي

```sad
سمة قابل_للوصف
   # دالة مجردة (يجب تنفيذها)
   دالة وصف() نص
   
   # دالة مع تنفيذ افتراضي
   دالة اطبع_الوصف()
      اطبع_سطر(هذا.وصف())
   نهاية
نهاية
```

## تنفيذ السمات (`نفّذ` / `نفذ`)

### الصيغة الأساسية

```sad
# تنفيذ سمة لصنف
نفّذ قابل_للطباعة لـ شخص
   دالة اطبع()
      اطبع_سطر(f"شخص: {هذا.الاسم}، العمر: {هذا.العمر}")
   نهاية
نهاية
```

### تنفيذ عدة سمات

```sad
صنف منتج
   نص الاسم
   عشري السعر

   باني(اسم: نص، سعر: عشري)
      هذا.الاسم = اسم
      هذا.السعر = سعر
   نهاية
نهاية

نفّذ قابل_للطباعة لـ منتج
   دالة اطبع()
      اطبع_سطر(f"{هذا.الاسم}: {هذا.السعر} ريال")
   نهاية
نهاية

نفّذ قابل_للمقارنة لـ منتج
   دالة قارن(آخر: أي) رقم
      إذا (هذا.السعر > آخر.السعر) ارجع 1
      وإلا إذا (هذا.السعر < آخر.السعر) ارجع -1
      وإلا ارجع 0
      نهاية
   نهاية
نهاية
```

### تنفيذ مباشر لصنف (بدون سمة)

يمكن إضافة طرق لصنف خارج تعريفه:

```sad
نفّذ شخص
   دالة عمر_بالأشهر() رقم
      ارجع هذا.العمر * 12
   نهاية

   دالة هل_بالغ() منطقي
      ارجع هذا.العمر >= 18
   نهاية
نهاية
```

## طرق الامتداد (Extension Methods)

### الصيغة الأساسية

```sad
امتداد نص
   دالة رقم عدّ_الكلمات(&هذا)
      ارجع هذا.قسّم(" ").طول()
   نهاية

   دالة نص معكوس(&هذا)
      # إرجاع النص معكوساً
      متغير نتيجة = ""
      لكل ي في (هذا.طول() - 1)..0
         نتيجة += هذا[ي]
      نهاية
      ارجع نتيجة
   نهاية
نهاية

# استخدام
متغير جملة = "مرحباً بالعالم من لغة ص"
اطبع(جملة.عدّ_الكلمات())   # 5
```

### امتداد مع معاملات قالب

```sad
امتداد قائمة[ت]
   دالة ت أول(&هذا)
      ارجع هذا[0]
   نهاية

   دالة ت آخر(&هذا)
      ارجع هذا[هذا.طول() - 1]
   نهاية
نهاية
```

### امتداد مع قيود

```sad
امتداد قائمة[ت] حيث ت: قابل_للمقارنة
   دالة ت أصغر(&هذا)
      متغير حد = هذا[0]
      لكل عنصر في هذا
         إذا (عنصر.قارن(حد) < 0)
            حد = عنصر
         نهاية
      نهاية
      ارجع حد
   نهاية
نهاية
```

### قيود طرق الامتداد
- لا يمكن الوصول للحقول **الخاصة** من طرق الامتداد
- لا يمكن **تجاوز** دوال موجودة في الصنف
- يجب **استيراد** ملف الامتداد لاستخدامه

## مثال عملي شامل

```sad
# تعريف سمة
سمة قابل_للتسلسل
   دالة إلى_نص() نص
   دالة من_نص(بيانات: نص)
نهاية

سمة قابل_للنسخ
   دالة نسخ() أي
نهاية

# صنف يُنفّذ سمتين
صنف عنوان
   نص الشارع
   نص المدينة
   نص الدولة

   باني(شارع: نص، مدينة: نص، دولة: نص)
      هذا.الشارع = شارع
      هذا.المدينة = مدينة
      هذا.الدولة = دولة
   نهاية
نهاية

نفّذ قابل_للتسلسل لـ عنوان
   دالة إلى_نص() نص
      ارجع f"{هذا.الشارع}، {هذا.المدينة}، {هذا.الدولة}"
   نهاية
   
   دالة من_نص(بيانات: نص)
      متغير أجزاء = بيانات.قسّم("، ")
      هذا.الشارع = أجزاء[0]
      هذا.المدينة = أجزاء[1]
      هذا.الدولة = أجزاء[2]
   نهاية
نهاية

نفّذ قابل_للنسخ لـ عنوان
   دالة نسخ() أي
      ارجع جديد عنوان(هذا.الشارع، هذا.المدينة، هذا.الدولة)
   نهاية
نهاية

# استخدام
متغير عن = جديد عنوان("شارع النور"، "الرياض"، "السعودية")
اطبع_سطر(عن.إلى_نص())    # شارع النور، الرياض، السعودية

متغير عن2 = عن.نسخ()       # نسخة مستقلة
```
