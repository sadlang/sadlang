# الدوال في لغة ص

## نظرة عامة

لغة ص تدعم عدة أنواع من الدوال: عادية، غير متزامنة، مولد، لامدا، دوال سهم، والدالة الرئيسية. تدعم أيضاً المعاملات المكتوبة والقيم الافتراضية والمزخرفات.

---

## الدوال العادية

### التعريف الأساسي

```sad
دالة اسم_الدالة(معاملات)
   # جسم الدالة
نهاية
```

### أمثلة

```sad
# دالة بدون معاملات
دالة تحية()
   اطبع_سطر("مرحباً!")
نهاية

# دالة بمعاملات
دالة جمع(أ، ب)
   ارجع أ + ب
نهاية

# استدعاء الدوال
تحية()
متغير نتيجة = جمع(3، 5)
اطبع_سطر(f"النتيجة: {نتيجة}")   # 8
```

---

## المعاملات المكتوبة (Typed Parameters)

### تحديد أنواع المعاملات

```sad
دالة جمع(أ: رقم، ب: رقم)
   ارجع أ + ب
نهاية

دالة تحية(اسم: نص)
   اطبع_سطر(f"مرحباً {اسم}")
نهاية
```

### نوع الإرجاع

يُحدَّد نوع الإرجاع **قبل اسم الدالة** (بين `دالة` والاسم):

```sad
دالة رقم جمع(أ: رقم، ب: رقم)
   ارجع أ + ب
نهاية

دالة نص تحية(اسم: نص)
   ارجع f"مرحباً {اسم}"
نهاية

# بدون نوع إرجاع (استنتاج تلقائي)
دالة مربع(س)
   ارجع س * س
نهاية
```

> **ملاحظة:** الصيغ القديمة (`: رقم`، `-> رقم`، `ترجع رقم` بعد المعاملات) أُزيلت.

### القيم الافتراضية للمعاملات

```sad
دالة تحية(اسم: نص = "عالم"، تكرار: رقم = 1)
   لكل ي في 0..تكرار
      اطبع_سطر(f"مرحباً {اسم}!")
   نهاية
نهاية

# استدعاء مع القيم الافتراضية
تحية()                    # مرحباً عالم! (مرة واحدة)
تحية("أحمد")             # مرحباً أحمد! (مرة واحدة)
تحية("سارة"، 3)          # مرحباً سارة! (3 مرات)
```

### معاملات مختلطة

```sad
# خلط معاملات بأنواع وبدون أنواع وبقيم افتراضية
دالة إنشاء_مستخدم(اسم، بريد: نص، عمر: رقم = 0)
   اطبع_سطر(f"المستخدم: {اسم}، البريد: {بريد}، العمر: {عمر}")
نهاية
```

## دوال لامدا (Lambda)

### الصيغة الأساسية

```sad
# لامدا مع سهم — الأقواس إلزامية دائماً
متغير مضاعفة = لامدا(س) => س * 2
اطبع(مضاعفة(5))   # 10

# لامدا متعددة المعاملات
متغير جمع = لامدا(أ، ب) => أ + ب
اطبع(جمع(3، 7))   # 10

# لامدا بدون معاملات
متغير ثابتة = لامدا() => 42
اطبع(ثابتة())     # 42
```

> **ملاحظة:** الأقواس حول المعاملات إلزامية دائماً.

### لامدا متعددة الأسطر

```sad
# لامدا مع كتلة (بدون فاصل)
متغير عملية = لامدا(أ، ب)
   ارجع أ + ب
نهاية

اطبع(عملية(5، 3))  # 8
```

### لامدا سهم مع كتلة

```sad
متغير معالج = لامدا(س) => إذا (س > 0)
    ارجع س * 2
وإلا
    ارجع 0
نهاية
نهاية
```

## الدوال غير المتزامنة (Async)

### التعريف

```sad
# الصفة بعد الموصوف (قاعدة العربية)
دالة غير_متزامن جلب_بيانات(رابط: نص)
   متغير استجابة = انتظر http.اطلب(رابط)
   ارجع استجابة
نهاية
```

### الانتظار (Await)

```sad
# انتظار بسيط
متغير نتيجة = انتظر جلب_بيانات("https://api.example.com")

# انتظار متوازي (join)
متغير (أ، ب) = انتظر انضم!(جلب_أ()، جلب_ب())

# انتظار سباق (race)
متغير أول = انتظر سباق!(مصدر1()، مصدر2())

# انتظار مع مهلة (timeout)
متغير نتيجة = انتظر مهلة(عملية_طويلة()، 5.ثانية)

# انتظار انتقائي (select)
انتظر اختر! {
   مهمة1 => اطبع("المهمة الأولى انتهت")
   مهمة2 => اطبع("المهمة الثانية انتهت")
}
```

### إغلاق غير متزامن

```sad
متغير معالج = غير_متزامن لامدا(بيانات)
   متغير نتيجة = انتظر حلل(بيانات)
   ارجع نتيجة
نهاية
```

## دوال المولد (Generator)

### التعريف

```sad
مولد دالة عداد(حد: رقم)
   لكل ي في 0..حد
      أنتج ي
   نهاية
نهاية

# استخدام
لكل قيمة في عداد(5)
   اطبع(قيمة)  # 0, 1, 2, 3, 4
نهاية
```

### أنواع `أنتج` (Yield)

```sad
# إنتاج قيمة
أنتج قيمة

# إنتاج بدون قيمة
أنتج

# تفويض لمولد آخر (yield from)
أنتج من مولد_آخر
```

### مثال: فيبوناتشي

```sad
مولد دالة فيبوناتشي()
   متغير أ = 0
   متغير ب = 1
   بينما (صحيح)
      أنتج أ
      متغير مؤقت = أ + ب
      أ = ب
      ب = مؤقت
   نهاية
نهاية

# أول 10 أرقام فيبوناتشي
متغير عداد = 0
لكل ر في فيبوناتشي()
   اطبع_سطر(ر)
   عداد += 1
   إذا (عداد >= 10) توقف
نهاية
```

### مولد غير متزامن

```sad
غير_متزامن مولد دالة أحداث_مباشرة()
   بينما (صحيح)
      متغير حدث = انتظر مستمع.انتظر_حدث()
      أنتج حدث
   نهاية
نهاية
```

## الدالة الرئيسية

نقطة دخول البرنامج الرسمية:

```sad
رئيسية دالة رئيسية()
   اطبع_سطر("مرحباً من البرنامج الرئيسي")
   ارجع 0
نهاية
```

### قيود الدالة الرئيسية
- يُسمح بدالة `رئيسية` **واحدة فقط** في البرنامج
- يجب أن ترجع `رقم` (كود الخروج)
- تقبل **معاملاً واحداً كحد أقصى**

## المزخرفات (Decorators)

### الصيغة

```sad
# مزخرف بدون معاملات
@مزخرف
دالة عملية()
   # ...
نهاية

# مزخرف مع معاملات
@مخبأ(حد = 100)
دالة حساب_مكلف(س: رقم) رقم
   # عملية حسابية مكلفة
   ارجع س ** س
نهاية
```

### أمثلة عملية

```sad
# مزخرف التوقيت
@توقيت
دالة عملية_بطيئة()
   # ...
نهاية

# مزخرف إعادة المحاولة
@إعادة_محاولة(محاولات = 3، تأخير = 1.5)
دالة اتصل_بالخادم()
   # ...
نهاية

# عدة مزخرفات
@تسجيل
@تخزين_مؤقت
دالة جلب_بيانات(معرف: رقم)
   # ...
نهاية
```

## الدوال الخارجية (FFI / Extern)

### دالة خارجية بسيطة

```sad
خارجي("printf") دالة اطبع_س(نسق: نص) رقم
```

### كتلة دوال خارجية

```sad
خارجي_س {
   دالة *فراغ malloc(حجم: حجم)
   دالة free(مؤشر: *فراغ)
   دالة صحيح printf(نسق: *حرف، ...)
}
```

## عامل الأنبوب مع الدوال

```sad
دالة مضاعفة(س: رقم) رقم
   ارجع س * 2
نهاية

دالة زيادة(س: رقم) رقم
   ارجع س + 1
نهاية

# سلسلة أنابيب
متغير نتيجة = 5 |> مضاعفة |> زيادة |> مضاعفة
# ≡ مضاعفة(زيادة(مضاعفة(5))) = مضاعفة(زيادة(10)) = مضاعفة(11) = 22

# مع عنصر نائب
متغير نتيجة2 = 5 |> جمع(_, 3)   # ≡ جمع(5, 3) = 8
```

## أمثلة عملية شاملة

### حاسبة متقدمة

```sad
# دوال حسابية أساسية
دالة جمع(أ: عشري، ب: عشري) عشري
   ارجع أ + ب
نهاية

دالة طرح(أ: عشري، ب: عشري) عشري
   ارجع أ - ب
نهاية

# دالة مع قيمة افتراضية
دالة قوة(قاعدة: عشري، أس: رقم = 2) عشري
   متغير نتيجة = 1.0
   لكل ي في 0..أس
      نتيجة *= قاعدة
   نهاية
   ارجع نتيجة
نهاية

# دالة تستخدم لامدا
متغير عمليات = {
   "+": لامدا أ، ب: أ + ب،
   "-": لامدا أ، ب: أ - ب،
   "*": لامدا أ، ب: أ * ب،
   "/": لامدا أ، ب: أ / ب
}

دالة حاسبة(أ: عشري، عملية: نص، ب: عشري) عشري
   إذا (عملية في عمليات)
      ارجع عمليات[عملية](أ، ب)
   نهاية
   ارمي f"عملية غير معروفة: {عملية}"
نهاية
```

### نظام أحداث بسيط

```sad
# استخدام لامدا كمعالجات أحداث
متغير معالجات = {
   "نقر": لامدا(حدث) => اطبع_سطر(f"تم النقر في ({حدث.س}، {حدث.ص})"),
   "تحريك": لامدا(حدث) => اطبع_سطر(f"تحريك إلى ({حدث.س}، {حدث.ص})"),
   "ضغط_مفتاح": لامدا(حدث) => اطبع_سطر(f"مفتاح: {حدث.مفتاح}")
}
```
