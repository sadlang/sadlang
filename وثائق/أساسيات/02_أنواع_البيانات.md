# أنواع البيانات في لغة ص

## نظرة عامة

لغة ص تدعم مجموعة غنية من أنواع البيانات، مقسمة إلى أنواع أساسية وأنواع مركبة.

---

## الأنواع الأساسية (البدائية)

### رقم (عدد صحيح)

يمثّل الأعداد الصحيحة (موجبة وسالبة):

```sad
متغير أ = 42
متغير ب = -17
متغير ج = 0
رقم عداد = 100
```

**المرادف الإنجليزي:** `int`

### عشري (عدد عشري)

يمثّل الأعداد ذات الفاصلة العشرية:

```sad
متغير نسبة = 3.14
متغير حرارة = -5.7
عشري معدل = 98.5
```

**المرادف الإنجليزي:** `float`

### نص (سلسلة نصية)

يمثّل سلاسل النصوص:

```sad
متغير اسم = "أحمد"
متغير رسالة = "مرحباً بالعالم"
نص عنوان = "شارع النور، المنامة"
```

#### أنواع النصوص الخاصة

```sad
# نص عادي
"نص عادي"

# نص خام (لا تُعالج محارف الهروب)
r"مسار\ملف\جديد"

# نص منسق (f-string) — يدعم تعبيرات داخل الأقواس
f"مرحباً {اسم}، عمرك {عمر} سنة"
```

**المرادف الإنجليزي:** `string`

### منطقي (قيمة صح/خطأ)

يمثّل القيم المنطقية:

```sad
متغير نشط = صحيح
متغير مغلق = خطأ
منطقي جاهز = صحيح
```

| القيمة | المعنى |
|--------|--------|
| `صحيح` | true |
| `خطأ` | false |

**المرادف الإنجليزي:** `bool`

### لاشيء (القيمة الفارغة)

يمثّل غياب القيمة:

```sad
متغير نتيجة = لاشيء
```

**المرادف الإنجليزي:** `null` / `nil`

### فراغ (عدم الإرجاع)

يُستخدم لتحديد أن الدالة لا ترجع قيمة:

```sad
دالة اطبع_ترحيب(اسم: نص) فراغ
   اطبع("مرحباً " + اسم)
نهاية
```

**المرادف الإنجليزي:** `void`

## الأنواع المركبة

### مصفوفة (Array)

قائمة مرتبة من العناصر:

```sad
# مصفوفة أرقام
متغير أرقام = [1، 2، 3، 4، 5]

# مصفوفة نصوص
متغير أسماء = ["أحمد"، "سارة"، "محمد"]

# مصفوفة فارغة
متغير قائمة = []

# الوصول للعناصر
اطبع(أرقام[0])    # يطبع: 1
اطبع(أسماء[1])    # يطبع: سارة

# تعديل العناصر  
أرقام[0] = 10

# مصفوفة مع تحديد النوع
مصفوفة<رقم> درجات = [95، 87، 92]
```

### خريطة (Map / Dictionary)

مجموعة من أزواج مفتاح-قيمة:

```sad
# خريطة بسيطة
متغير شخص = {"اسم": "أحمد"، "عمر": 25، "مدينة": "الرياض"}

# الوصول للقيم
اطبع(شخص["اسم"])      # يطبع: أحمد

# تعديل القيم
شخص["عمر"] = 26

# خريطة فارغة
متغير بيانات = {}

# خريطة مع تحديد الأنواع
خريطة<نص، رقم> درجات = {"رياضيات": 95، "علوم": 87}
```

### أي (Any)

نوع عام يقبل أي قيمة:

```sad
متغير قيمة: أي = 42
قيمة = "نص الآن"      # مسموح
قيمة = [1، 2، 3]      # مسموح أيضاً
```

---

## أنواع القوالب (Generic Types)

يمكن تحديد نوع العناصر داخل المجموعات:

```sad
# مصفوفة من نوع محدد
مصفوفة<رقم> أعداد = [1، 2، 3]
مصفوفة<نص> كلمات = ["أ"، "ب"، "ج"]

# خريطة بأنواع محددة
خريطة<نص، رقم> عمار = {"أحمد": 25، "سارة": 30}
خريطة<رقم، نص> ترجمة = {1: "واحد"، 2: "اثنان"}
```

---

## جدول ملخص الأنواع

| النوع العربي | المرادف الإنجليزي | الوصف | أمثلة |
|-------------|-------------------|-------|-------|
| `رقم` | `int` | عدد صحيح | `42`، `-5`، `0` |
| `عشري` | `float` | عدد عشري | `3.14`، `-2.7` |
| `نص` | `string` | سلسلة نصية | `"مرحباً"` |
| `منطقي` | `bool` | منطقي | `صحيح`، `خطأ` |
| `فراغ` | `void` | لا قيمة مرجعة | — |
| `عدم` | `null` | نوع القيمة الفارغة | `لاشيء` |
| `مصفوفة` | `array` | مصفوفة | `[1، 2، 3]` |
| `خريطة` | `map` | خريطة/قاموس | `{"أ": 1}` |
| `أي` | `any` | نوع عام | أي قيمة |

## التحويل بين الأنواع

يمكن تحويل القيم بين الأنواع باستخدام دوال التحويل:

```sad
# تحويل رقم إلى نص
متغير رقم_نص = نص(42)         # "42"

# تحويل نص إلى رقم
متغير قيمة = رقم("123")       # 123

# تحويل إلى عشري
متغير ع = عشري("3.14")        # 3.14

# تحويل إلى منطقي
متغير م = منطقي(1)             # صحيح
متغير م2 = منطقي(0)            # خطأ
```

## أمثلة عملية

```sad
# برنامج يوضح جميع أنواع البيانات
رقم عمر = 25
عشري طول = 1.75
نص اسم = "خالد"
منطقي طالب = صحيح
مصفوفة<نص> هوايات = ["قراءة"، "برمجة"، "رياضة"]
خريطة<نص، أي> بطاقة = {
   "اسم": اسم،
   "عمر": عمر،
   "طول": طول،
   "طالب": طالب،
   "هوايات": هوايات
}

اطبع_سطر(f"الاسم: {بطاقة["اسم"]}")
اطبع_سطر(f"العمر: {بطاقة["عمر"]}")
اطبع_سطر(f"الهوايات: {بطاقة["هوايات"]}")
```
