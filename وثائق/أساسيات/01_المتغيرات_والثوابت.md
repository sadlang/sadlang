# المتغيرات والثوابت في لغة ص

## نظرة عامة

لغة ص تدعم عدة طرق لتعريف المتغيرات والثوابت، مع دعم كامل لاستنتاج الأنواع وتحديدها صراحةً.

---

## تعريف المتغيرات

### الصيغة الأساسية: `متغير`

الكلمة المفتاحية `متغير` تُعرّف متغيراً قابلاً للتعديل.

```sad
متغير اسم = "أحمد"
متغير عمر = 25
متغير نسبة = 3.14
متغير نشط = صحيح
```

### مع تحديد النوع صراحةً

يمكن تحديد نوع المتغير بعد النقطتين `:` بعد الاسم:

```sad
متغير اسم: نص = "أحمد"
متغير عمر: رقم = 25
متغير نسبة: عشري = 3.14
متغير نشط: منطقي = صحيح
```

### الصيغة المختصرة: النوع أولاً

يمكن كتابة النوع قبل اسم المتغير مباشرة (بدون `متغير`):

```sad
رقم عداد = 0
نص رسالة = "مرحباً بالعالم"
عشري معدل = 98.5
منطقي جاهز = خطأ
```

> **ملاحظة مهمة:** أسماء الأنواع مثل `رقم`، `نص`، `عشري`، `منطقي` **ليست كلمات محجوزة** — يمكن استخدامها كأسماء متغيرات أيضاً! المحلل يميّز بينها حسب السياق (هل يتبعها مُعرّف آخر أم لا).

```sad
# هنا "رقم" هو نوع بيانات و"عداد" هو اسم المتغير
رقم عداد = 10

# هنا "رقم" هو اسم متغير!
متغير رقم = 42
```

## تعريف الثوابت

### الصيغة الأساسية: `ثابت`

الكلمة المفتاحية `ثابت` تُعرّف قيمة لا يمكن تغييرها بعد التعيين:

```sad
ثابت باي = 3.14159265
ثابت الحد_الأقصى = 100
ثابت اسم_التطبيق = "تطبيقي"
ثابت نسخة: نص = "2.0.0"
```

### ثابت ساكن (Static)

القيم الساكنة تُخزن مرة واحدة وتُشارك بين جميع النسخ:

```sad
ثابت ساكن عدد_المستخدمين = 0
```

## استنتاج النوع

عندما لا يُحدد النوع صراحةً، يُستنتج تلقائياً من القيمة الأولية:

```sad
متغير س = 42          # نوعه: رقم
متغير ص = 3.14        # نوعه: عشري
متغير ن = "نص"        # نوعه: نص
متغير م = صحيح        # نوعه: منطقي
متغير ق = [1، 2، 3]   # نوعه: مصفوفة
متغير خ = {"أ": 1}    # نوعه: خريطة
```

> **ملاحظة عن العرض:**
> - قيم `منطقي` تُعرض كـ `true` / `false` (وليس "صحيح" / "خطأ") عند الطباعة.
> - قيمة `لاشيء` تُعرض كـ `void` عند الطباعة.

```sad
متغير م = صحيح
اطبع(م)        # يطبع: true
متغير ف = لاشيء
اطبع(ف)        # يطبع: void
```

---

## القيمة الافتراضية `لاشيء`

إذا لم تُعطَ قيمة أولية، يكون المتغير `لاشيء`:

```sad
متغير نتيجة
اطبع(نتيجة)  # يطبع: لاشيء
```

## تعيين المتغيرات الكائنية

يمكن إنشاء كائنات من الأصناف:

```sad
متغير شخص1 = جديد شخص("أحمد"، 25)

# أو باستخدام النوع أولاً
شخص شخص2 = جديد شخص("سارة"، 30)
```

## عوامل الإسناد

| العامل | الوصف | مثال |
|--------|-------|------|
| `=` | إسناد بسيط | `س = 5` |
| `+=` | جمع وإسناد | `س += 3` → `س = س + 3` |
| `-=` | طرح وإسناد | `س -= 2` → `س = س - 2` |
| `*=` | ضرب وإسناد | `س *= 4` → `س = س * 4` |
| `/=` | قسمة وإسناد | `س /= 2` → `س = س / 2` |
| `:=` | عامل ولروس | `س := تعبير` (إسناد وإرجاع القيمة) |

> **⚠️ ملاحظة:** العامل `%=` (باقي القسمة وإسناد) **غير مدعوم** حالياً في المحلل النحوي ويسبب خطأ تحليل. استخدم بدلاً منه: `س = س % ن`.

### أمثلة على الإسناد المركب

```sad
متغير مجموع = 0
مجموع += 10      # مجموع = 10
مجموع -= 3       # مجموع = 7
مجموع *= 2       # مجموع = 14
مجموع /= 7       # مجموع = 2
```

### إسناد الأعضاء والفهارس

```sad
# إسناد عضو في كائن
كائن.حقل = قيمة_جديدة

# إسناد عنصر في مصفوفة
مصفوفة[0] = قيمة_جديدة

# إسناد مركب عميق
مصفوفة[ي].حقل += 10
```

### عامل ولروس (Walrus Operator)

عامل `:=` يُسند قيمة ويُرجعها في نفس الوقت، مفيد في الشروط:

```sad
إذا (متغير ن := احسب() > 0)
   اطبع("النتيجة موجبة: " + ن)
نهاية
```

---

## الفاصلة المنقوطة

الفاصلة المنقوطة **اختيارية** في لغة ص. يمكن استخدام `;` أو `؛` (العربية):

```sad
# كلاهما صحيح
متغير أ = 5
متغير ب = 10;
متغير ج = 15؛
```

---

## ملخص أنواع التعريف

| الصيغة | المعنى | قابل للتعديل |
|--------|--------|-------------|
| `متغير س = 5` | متغير مع استنتاج نوع | نعم |
| `متغير س: رقم = 5` | متغير مع نوع صريح | نعم |
| `رقم س = 5` | متغير بالنوع أولاً | نعم |
| `ثابت س = 5` | ثابت مع استنتاج نوع | لا |
| `ثابت س: رقم = 5` | ثابت مع نوع صريح | لا |

## أمثلة عملية كاملة

```sad
# برنامج حساب مساحة الدائرة
ثابت باي = 3.14159265

دالة مساحة_الدائرة(نصف_القطر: عشري) عشري
   ارجع باي * نصف_القطر ** 2
نهاية

متغير نق = 5.0
متغير المساحة = مساحة_الدائرة(نق)
اطبع_سطر("مساحة الدائرة: " + المساحة)
```

```sad
# برنامج مع أنواع متعددة
رقم عدد_الطلاب = 30
نص اسم_المدرسة = "مدرسة النور"
عشري معدل_النجاح = 92.5
منطقي مفتوحة = صحيح

إذا (مفتوحة)
   اطبع_سطر(اسم_المدرسة + " - عدد الطلاب: " + عدد_الطلاب)
   اطبع_سطر("معدل النجاح: " + معدل_النجاح + "%")
نهاية
```
