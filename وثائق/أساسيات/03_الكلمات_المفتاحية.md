# الكلمات المفتاحية والمُعرّفات في لغة ص

## نظرة عامة

لغة ص تستخدم **40 كلمة محجوزة** فقط، بالإضافة إلى **3 عوامل منطقية** و**كلمات سياقية** تعمل كمعرّفات عادية خارج سياقها.

## العوامل المنطقية (3 كلمات)

| الكلمة | المعنى | المرادف الرمزي |
|--------|--------|---------------|
| `و` | AND المنطقي | `&&` |
| `أو` | OR المنطقي | `\|\|` |
| `ليس` | NOT المنطقي | `!` |

```sad
إذا (س > 0 و ص > 0)
   اطبع("كلاهما موجب")
نهاية

إذا (أ أو ب)
   اطبع("أحدهما صحيح")
نهاية

إذا (ليس فارغ)
   اطبع("ليس فارغاً")
نهاية
```

## الكلمات السياقية

هذه الكلمات تعمل ككلمات مفتاحية **فقط في سياقها الخاص**، وخارج ذلك تُعامل كمعرّفات عادية:

| الكلمة | المعنى | السياق |
|--------|--------|--------|
| `غير_متزامن` | async | قبل `دالة` |
| `انتظر` | await | قبل تعبير |
| `لامدا` | lambda | بداية تعبير مجهول |
| `أنتج` | yield | داخل دالة مولد |
| `مولد` | generator | قبل `دالة` |
| `باستخدام` | with/using | بداية مدير سياق |
| `نهاية_استخدام` | end using | نهاية مدير سياق |
| `سمة` / `واجهة` | trait/interface | تعريف سمة |
| `نفّذ` / `نفذ` | impl | تنفيذ سمة |
| `قالب` | template | تعريف قالب |
| `فضاء` | namespace | تعريف فضاء أسماء |
| `نهاية_فضاء` | end namespace | نهاية فضاء |
| `اختبر` | test | تعريف اختبار |
| `خاصية` | property | داخل صنف |
| `احصل` | get | داخل خاصية |
| `عيّن` | set | داخل خاصية |
| `هدم` | destructor | داخل صنف |
| `عامل` | operator | تحميل عامل |
| `رئيسية` | main | نقطة الدخول |
| `حالة` | case/switch | بيان حالة |

```sad
# "سمة" ككلمة مفتاحية
سمة قابل_للمقارنة
   دالة قارن(آخر: أي) رقم
نهاية

# "سمة" كاسم متغير (خارج سياقها)
متغير سمة = "صفة معينة"
```

## أسماء الأنواع المدمجة

هذه **ليست محجوزة** — يمكن استخدامها كأسماء:

| الاسم | النوع |
|-------|-------|
| `رقم` | عدد صحيح (integer) |
| `عشري` | عدد عشري (float) |
| `نص` | سلسلة نصية (string) |
| `منطقي` | منطقي (boolean) |
| `فراغ` | لا قيمة (void) |
| `عدم` | نوع القيمة الفارغة (null type) |
| `مصفوفة` | مصفوفة (array) |
| `خريطة` | خريطة/قاموس (map) |
| `أي` | نوع عام (any) |

```sad
# استخدامات صالحة
رقم عداد = 0          # "رقم" كنوع بيانات
متغير رقم = 42        # "رقم" كاسم متغير!
```

## قواعد تسمية المُعرّفات

- يمكن أن تكون الأسماء **عربية** أو **إنجليزية** أو مزيجاً
- تدعم UTF-8 بالكامل
- تبدأ بحرف أو شرطة سفلية `_`
- يمكن أن تحتوي أرقاماً (لكن لا تبدأ بها)

```sad
# أسماء عربية
متغير عداد_الطلاب = 0
متغير مجموع_الدرجات = 0

# أسماء إنجليزية
متغير counter = 0
متغير total = 0

# مزيج
متغير student_عداد = 0
```
