# العمليات على النصوص في لغة ص

## نظرة عامة

لغة ص توفر دعماً غنياً للتعامل مع النصوص، بما في ذلك أنواع مختلفة من النصوص الحرفية والنصوص المنسقة.

---

## أنواع النصوص الحرفية

### النص العادي

```sad
متغير نص1 = "مرحباً بالعالم"
متغير نص2 = "سطر أول\nسطر ثاني"    # مع محارف هروب
```

### محارف الهروب المدعومة

| المحرف | المعنى |
|--------|--------|
| `\n` | سطر جديد |
| `\t` | مسافة جدولة |
| `\\` | شرطة مائلة |
| `\"` | علامة اقتباس مزدوجة |
| `\r` | عودة إلى بداية السطر |

```sad
اطبع("السطر الأول\nالسطر الثاني")
اطبع("عمود1\tعمود2\tعمود3")
اطبع("قال: \"مرحباً\"")
```

### النص الخام (Raw String)

النص الخام لا يُعالج محارف الهروب فيه:

```sad
متغير مسار = r"C:\مستخدمين\أحمد\مستندات"
متغير نمط = r"\d+\.\d+"
```

### النصوص المنسقة (F-Strings)

تسمح بتضمين تعبيرات داخل النص:

```sad
متغير اسم = "أحمد"
متغير عمر = 25

# تضمين متغيرات
اطبع(f"مرحباً {اسم}")

# تضمين تعبيرات
اطبع(f"العمر بعد 5 سنوات: {عمر + 5}")

# تعبيرات معقدة
اطبع(f"النتيجة: {أ > ب ? 'أكبر' : 'أصغر'}")

# متعدد المتغيرات
اطبع(f"الاسم: {اسم}، العمر: {عمر}، الحالة: {عمر >= 18 ? 'بالغ' : 'قاصر'}")
```

#### آلية عمل F-Strings

المحلل يحوّل f-string إلى سلسلة عمليات ربط نصي:

```sad
# هذا:
f"مرحباً {اسم}!"

# يتحول داخلياً إلى:
"مرحباً " + نص(اسم) + "!"
```

## عمليات الربط النصي

### الربط بعامل `+`

```sad
متغير أول = "مرحباً"
متغير ثاني = " بالعالم"
متغير كامل = أول + ثاني    # "مرحباً بالعالم"
```

### الربط مع أنواع أخرى

```sad
متغير رسالة = "العدد: " + 42        # "العدد: 42"
متغير نتيجة = "النسبة: " + 3.14    # "النسبة: 3.14"
```

## عمليات المصفوفات والخرائط

### تعريف المصفوفات

```sad
# مصفوفة حرفية
متغير أرقام = [1، 2، 3، 4، 5]
متغير أسماء = ["أحمد"، "سارة"، "محمد"]
متغير مختلطة = [1، "نص"، صحيح، 3.14]
متغير فارغة = []
```

### الوصول والتعديل

```sad
متغير قائمة = [10، 20، 30، 40، 50]

# قراءة عنصر
اطبع(قائمة[0])      # 10
اطبع(قائمة[2])      # 30

# تعديل عنصر
قائمة[1] = 25
اطبع(قائمة[1])      # 25
```

### تعريف الخرائط

```sad
# خريطة حرفية
متغير شخص = {
   "اسم": "أحمد"،
   "عمر": 25،
   "مدينة": "الرياض"
}

# خريطة فارغة
متغير بيانات = {}
```

### الوصول للخرائط

```sad
اطبع(شخص["اسم"])       # أحمد
شخص["عمر"] = 26        # تعديل
شخص["هاتف"] = "0555"   # إضافة مفتاح جديد
```

### خرائط متقدمة

```sad
# مفاتيح محسوبة
متغير مفتاح = "اسم"
متغير خ = {[مفتاح]: "أحمد"}

# نشر القواميس
متغير أساس = {"أ": 1، "ب": 2}
متغير موسع = {**أساس، "ج": 3}  # {"أ": 1، "ب": 2، "ج": 3}
```

## تعبيرات الفهم (Comprehensions)

### فهم القوائم (List Comprehension)

```sad
# الصيغة: [تعبير لكل متغير في مجموعة]
متغير مربعات = [س * س لكل س في [1، 2، 3، 4، 5]]
# النتيجة: [1، 4، 9، 16، 25]

# مع شرط تصفية
متغير أزواج = [س لكل س في [1، 2، 3، 4، 5، 6] إذا س % 2 == 0]
# النتيجة: [2، 4، 6]

# متداخل
متغير أزواج = [س + ص لكل س في [1، 2] لكل ص في [10، 20]]
# النتيجة: [11، 21، 12، 22]
```

### فهم القواميس (Dict Comprehension)

```sad
# الصيغة: {مفتاح: قيمة لكل متغير في مجموعة}
متغير مربعات = {س: س * س لكل س في [1، 2، 3، 4، 5]}
# النتيجة: {1: 1، 2: 4، 3: 9، 4: 16، 5: 25}

# مع شرط
متغير كبيرة = {س: س * س لكل س في [1، 2، 3، 4، 5] إذا س > 2}
# النتيجة: {3: 9، 4: 16، 5: 25}

# مع قيمة شرطية
متغير تصنيف = {س: "زوجي" إذا س % 2 == 0 وإلا "فردي" لكل س في [1، 2، 3، 4]}
```

### فهم المجموعات (Set Comprehension)

```sad
متغير فريدة = {|س % 10 لكل س في [11، 22، 33، 41، 52]|}
# النتيجة: مجموعة {1، 2، 3}
```

### تعبيرات المولد (Generator Expression)

```sad
# تُقيَّم بشكل كسول (lazy)
متغير مولد = (س * س لكل س في مدى(1000000))
```

## أمثلة عملية شاملة

```sad
# معالجة نصوص
متغير جملة = "مرحباً بالعالم من لغة ص"
اطبع_سطر(f"الجملة: {جملة}")

# بناء جدول
متغير طلاب = [
   {"اسم": "أحمد"، "درجة": 95}،
   {"اسم": "سارة"، "درجة": 88}،
   {"اسم": "محمد"، "درجة": 92}
]

لكل طالب في طلاب
   اطبع_سطر(f"{طالب["اسم"]}: {طالب["درجة"]}")
نهاية

# فهم قوائم عملي
متغير متفوقون = [ط["اسم"] لكل ط في طلاب إذا ط["درجة"] >= 90]
اطبع_سطر(f"المتفوقون: {متفوقون}")

# خريطة الأسماء → الدرجات
متغير سجل = {ط["اسم"]: ط["درجة"] لكل ط في طلاب}
اطبع_سطر(f"السجل: {سجل}")
```
