# العمليات الحسابية والمقارنة في لغة ص

## نظرة عامة

لغة ص تدعم مجموعة كاملة من العوامل الحسابية والمقارنة والمنطقية، مرتبة حسب الأولوية.

---

## العوامل الحسابية

| العامل | الوصف | مثال | النتيجة |
|--------|-------|------|---------|
| `+` | جمع | `5 + 3` | `8` |
| `-` | طرح | `10 - 4` | `6` |
| `*` | ضرب | `3 * 7` | `21` |
| `/` | قسمة | `15 / 4` | `3.75` |
| `%` | باقي القسمة | `17 % 5` | `2` |
| `**` | أس (قوة) | `2 ** 10` | `1024` |

### أمثلة

```sad
متغير أ = 10
متغير ب = 3

اطبع_سطر(أ + ب)     # 13
اطبع_سطر(أ - ب)     # 7
اطبع_سطر(أ * ب)     # 30
اطبع_سطر(أ / ب)     # 3.333...
اطبع_سطر(أ % ب)     # 1
اطبع_سطر(أ ** ب)    # 1000
```

### عامل الأس `**`

عامل الأس **يمين الارتباط** (right-associative):

```sad
# 2 ** 3 ** 2 يُحسب كـ 2 ** (3 ** 2) = 2 ** 9 = 512
اطبع(2 ** 3 ** 2)    # 512 وليس 64
```

## العوامل الأحادية

| العامل | الوصف | مثال | النتيجة |
|--------|-------|------|---------|
| `-` | سالب | `-5` | `-5` |
| `!` | نفي منطقي | `!صحيح` | `خطأ` |
| `ليس` | نفي منطقي (عربي) | `ليس صحيح` | `خطأ` |
| `++` | زيادة بواحد (أمامي) | `++س` | `س + 1` |
| `--` | إنقاص بواحد (أمامي) | `--س` | `س - 1` |
| `~` | نفي بتّي | `~5` | `-6` |

```sad
متغير س = 5
اطبع(-س)        # -5
اطبع(!صحيح)     # خطأ
اطبع(ليس خطأ)   # صحيح

++س              # س = 6
--س              # س = 5
```

### الزيادة والإنقاص اللاحقة (Postfix)

```sad
متغير ع = 10
اطبع(ع++)    # يطبع 10 ثم ع = 11
اطبع(ع--)    # يطبع 11 ثم ع = 10
```

## عوامل المقارنة

| العامل | الوصف | مثال | النتيجة |
|--------|-------|------|---------|
| `==` | يساوي | `5 == 5` | `صحيح` |
| `!=` | لا يساوي | `5 != 3` | `صحيح` |
| `<` | أصغر من | `3 < 5` | `صحيح` |
| `>` | أكبر من | `5 > 3` | `صحيح` |
| `<=` | أصغر أو يساوي | `5 <= 5` | `صحيح` |
| `>=` | أكبر أو يساوي | `6 >= 5` | `صحيح` |

```sad
متغير عمر = 20

إذا (عمر >= 18)
   اطبع("بالغ")
نهاية

إذا (عمر != 0)
   اطبع("العمر ليس صفراً")
نهاية
```

## العوامل المنطقية

### الصيغة الرمزية والعربية

| رمزي | عربي | الوصف | مثال |
|------|------|-------|------|
| `&&` | `و` | AND المنطقي | `صحيح و خطأ` → `خطأ` |
| `\|\|` | `أو` | OR المنطقي | `صحيح أو خطأ` → `صحيح` |
| `!` | `ليس` | NOT المنطقي | `ليس صحيح` → `خطأ` |

```sad
متغير عمر = 25
متغير مسجل = صحيح

# باستخدام الكلمات العربية
إذا (عمر >= 18 و مسجل)
   اطبع("مؤهل")
نهاية

# باستخدام الرموز
إذا (عمر >= 18 && مسجل)
   اطبع("مؤهل")
نهاية

# OR
إذا (عمر < 12 أو عمر > 65)
   اطبع("خصم خاص")
نهاية

# NOT
إذا (ليس مسجل)
   اطبع("سجّل أولاً")
نهاية
```

## عامل العضوية `في`

يتحقق من وجود عنصر في مجموعة:

```sad
متغير أرقام = [1، 2، 3، 4، 5]

إذا (3 في أرقام)
   اطبع("الرقم 3 موجود")
نهاية

إذا (ليس 10 في أرقام)
   اطبع("الرقم 10 غير موجود")
نهاية
```

## العامل الثلاثي (Ternary)

```sad
# الصيغة: شرط ? قيمة_صحيح : قيمة_خطأ
متغير حالة = عمر >= 18 ? "بالغ" : "قاصر"
اطبع(حالة)

# يمكن استخدامه في أي تعبير
متغير أكبر = أ > ب ? أ : ب
```

### العامل الثلاثي المتداخل

```sad
# يمين الارتباط
متغير وصف = عمر < 12 ? "طفل" : عمر < 18 ? "مراهق" : "بالغ"
# يُحسب كـ: عمر < 12 ? "طفل" : (عمر < 18 ? "مراهق" : "بالغ")
```

## العوامل البتّية (Bitwise)

| العامل | الوصف | مثال |
|--------|-------|------|
| `&` | AND بتّي | `5 & 3` → `1` |
| `\|` | OR بتّي | `5 \| 3` → `7` |
| `^` | XOR بتّي | `5 ^ 3` → `6` |
| `~` | NOT بتّي | `~5` → `-6` |
| `<<` | إزاحة يسار | `1 << 3` → `8` |
| `>>` | إزاحة يمين | `8 >> 2` → `2` |

```sad
متغير أ = 0b1010    # 10 في الثنائي
متغير ب = 0b1100    # 12 في الثنائي

اطبع(أ & ب)         # 0b1000 = 8
اطبع(أ | ب)         # 0b1110 = 14
اطبع(أ ^ ب)         # 0b0110 = 6
اطبع(~أ)            # نفي بتي
اطبع(1 << 4)        # 16
اطبع(16 >> 2)       # 4
```

## عامل المدى `..`

ينشئ نطاقاً من القيم:

```sad
# نطاق من 1 إلى 10 (شامل أم لا حسب السياق)
متغير نطاق = 1..10

# استخدام في حلقة
لكل ي في 0..5
   اطبع(ي)    # 0, 1, 2, 3, 4
نهاية
```

## عامل الأنبوب `|>`

يمرر نتيجة تعبير كمعامل أول لدالة أخرى:

```sad
# بدون أنبوب
متغير نتيجة = تصفية(تحويل(جمع(أرقام)))

# مع أنبوب — أوضح وأسهل للقراءة
متغير نتيجة = أرقام |> جمع |> تحويل |> تصفية

# أمثلة عملية
5 |> مضاعفة           # ≡ مضاعفة(5)
5 |> جمع(_, 3)        # ≡ جمع(5, 3) — العنصر النائب _
```

## عامل ولروس `:=`

يُسند قيمة ويُرجعها في نفس الوقت:

```sad
# مفيد داخل الشروط
إذا (متغير طول := احسب_الطول() > 0)
   اطبع(f"الطول: {طول}")
نهاية

# داخل الحلقات
بينما (متغير سطر := اقرأ_سطر() != لاشيء)
   اطبع(سطر)
نهاية
```

## عامل الاقتراض `&`

يُنشئ مرجعاً للقيمة (مستوحى من Rust):

```sad
# مرجع غير قابل للتعديل
متغير مرجع = &قيمة

# مرجع قابل للتعديل
متغير مرجع_متغير = &mut قيمة
```

## جدول أولويات العوامل

من **الأدنى** أولوية إلى **الأعلى**:

| الأولوية | العوامل | الوصف |
|----------|---------|-------|
| 1 | `\|>` | أنبوب |
| 2 | `=`، `+=`، `-=`، `*=`، `/=`، `:=` | إسناد |
| 3 | `? :` | ثلاثي شرطي |
| 4 | `\|\|`، `أو` | OR منطقي |
| 5 | `&&`، `و` | AND منطقي |
| 6 | `\|` | OR بتّي |
| 7 | `^` | XOR بتّي |
| 8 | `&` | AND بتّي |
| 9 | `==`، `!=` | مساواة |
| 10 | `<`، `>`، `<=`، `>=`، `في` | مقارنة |
| 11 | `..` | مدى |
| 12 | `+`، `-`، `<<`، `>>` | جمع/طرح/إزاحة |
| 13 | `*`، `/`، `%` | ضرب/قسمة/باقي |
| 14 | `-`، `!`، `ليس`، `++`، `--`، `~`، `&` | أحادي |
| 15 | `**` | أس |
| 16 | `()`، `.`، `[]`، `++`، `--` | لاحق (postfix) |

## عمليات الوصول للأعضاء والفهرسة

### النقطة `.` — وصول للأعضاء

```sad
كائن.حقل           # الوصول لحقل
كائن.دالة()        # استدعاء طريقة
كائن.حقل.حقل_فرعي  # وصول متسلسل
```

### الأقواس المربعة `[]` — فهرسة

```sad
مصفوفة[0]          # الوصول للعنصر الأول
خريطة["مفتاح"]     # الوصول بالمفتاح
مصفوفة[أ + ب]      # تعبير كفهرس
```

### الأقواس `()` — استدعاء

```sad
دالة()              # استدعاء بدون معاملات
دالة(5، "نص")      # استدعاء مع معاملات
كائن.طريقة(أ)      # استدعاء طريقة
```

## أمثلة عملية شاملة

```sad
# حاسبة بسيطة
دالة حاسبة(أ: عشري، ب: عشري، عملية: نص) عشري
   طابق عملية
      عندما "+": ارجع أ + ب
      عندما "-": ارجع أ - ب
      عندما "*": ارجع أ * ب
      عندما "/":
         إذا (ب != 0)
            ارجع أ / ب
         وإلا
            ارمي "لا يمكن القسمة على صفر"
         نهاية
      عندما "**": ارجع أ ** ب
      عندما "%": ارجع أ % ب
      افتراضي: ارمي "عملية غير معروفة"
   نهاية
نهاية

# استخدام العوامل المنطقية
دالة تحقق_الأهلية(عمر: رقم، دخل: عشري) منطقي
   ارجع عمر >= 18 و عمر <= 65 و دخل > 1000.0
نهاية

# استخدام العامل الثلاثي
دالة قيمة_مطلقة(س: عشري) عشري
   ارجع س >= 0 ? س : -س
نهاية
```
