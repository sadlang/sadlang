# برمجة النظام المتقدمة في لغة ص

## نظرة عامة

لغة ص تدعم ميزات متقدمة لبرمجة النظام تشمل: الواجهة الخارجية (FFI)، الأعمار (Lifetimes)، كود التجميع المدمج، والماكرو.

---

## الواجهة الخارجية (FFI / Extern)

### دالة خارجية بسيطة

```sad
خارجي("printf") دالة اطبع_س(نسق: نص) رقم
```

### كتلة دوال خارجية

```sad
خارجي_س {
   دالة *فراغ malloc(حجم: حجم)
   دالة free(مؤشر: *فراغ)
   دالة صحيح printf(نسق: *حرف، ...)
   دالة حجم strlen(نص: *حرف)
   دالة *فراغ memcpy(هدف: *فراغ، مصدر: *فراغ، حجم: حجم)
}
```

### أنواع الربط

| كلمة عربية | المعنى | اللغة المستهدفة |
|-------------|--------|----------------|
| `خارجي_س` | C linkage | C |
| `خارجي_سي++` | C++ linkage | C++ |
| `خارجي_نظام` | System linkage | نظام التشغيل |
| `خارجي` | الافتراضي | C |

### أنواع C المدعومة بالعربية

| النوع العربي | نوع C | الوصف |
|-------------|-------|-------|
| `فراغ` | `void` | لا قيمة |
| `حرف` | `char` | محرف |
| `صحيح` | `int` | عدد صحيح |
| `طويل` | `long` | عدد طويل |
| `عشري` | `float` | عشري |
| `مزدوج` | `double` | عشري مزدوج |
| `حجم` | `size_t` | حجم ذاكرة |
| `ص8` | `int8_t` | 8 بت |
| `ص16` | `int16_t` | 16 بت |
| `ص32` | `int32_t` | 32 بت |
| `ص64` | `int64_t` | 64 بت |
| `ص_غ8` | `uint8_t` | 8 بت غير مؤشر |
| `ص_غ16` | `uint16_t` | 16 بت غير مؤشر |
| `ص_غ32` | `uint32_t` | 32 بت غير مؤشر |
| `ص_غ64` | `uint64_t` | 64 بت غير مؤشر |

### تعليقات الملكية

```sad
#[ملك_النتيجة]    # المتصل يملك الذاكرة المُرجعة
#[لا_يُحرر]       # لا تحرر هذا المؤشر
#[مستعار]         # مرجع مستعار
#[يُحرر_بـ: free]  # يُحرر بدالة محددة
```

### اتفاقيات الاستدعاء

```sad
#[استدعاء_س]      # cdecl
#[استدعاء_قياسي]  # stdcall
#[استدعاء_سريع]   # fastcall
```

## الأعمار (Lifetimes)

نظام الأعمار مستوحى من لغة Rust لضمان سلامة المراجع.

### دالة مع أعمار

```sad
دالة &'أ نص أطول<'أ>(س: &'أ نص، ص: &'أ نص)
   إذا (س.طول() > ص.طول())
      ارجع س
   وإلا
      ارجع ص
   نهاية
نهاية
```

### بنية مع عمر

```sad
بنية مقتبس<'أ>
   نص_: &'أ نص
نهاية
```

### أنواع الأعمار

| النوع | الرمز | المعنى |
|-------|-------|--------|
| مُسمى | `'أ` | عمر صريح مسمى |
| ثابت | `'ثابت` | يعيش طوال البرنامج |
| مجهول | `'_` | عمر مجهول (يُستنتج) |

### الاقتراض

```sad
# مرجع غير قابل للتعديل
متغير مرجع = &قيمة

# مرجع قابل للتعديل
متغير مرجع_متغير = &mut قيمة
```

## كود التجميع المدمج (Inline Assembly)

### الصيغة الأساسية

```sad
تجميع!("تعليمات"
   : مخرجات
   : مدخلات
   : متلفات
   : خيارات
)
```

### أمثلة

```sad
# قراءة مؤشر المكدس
متغير مكدس: ص_غ64
تجميع!("mov %rsp, $0" : "=r"(مكدس))

# عملية ذرية
تجميع!("lock xchg $0, $1"
   : "+m"(هدف)، "=r"(قديم)
   : "r"(جديد)
   : "memory"
)

# إضافة بسيطة
متغير نتيجة: ص32
تجميع!("add $1, $0"
   : "=r"(نتيجة)
   : "r"(5)، "0"(3)
)
```

### لهجات التجميع

| اللهجة | الكلمة |
|--------|--------|
| Intel | `انتل` |
| AT&T | `att` |

### خيارات التجميع

| الخيار | المعنى |
|--------|--------|
| `متطاير` | لا يُحذف حتى لو بدا غير مستخدم |
| `محاذاة_المكدس` | محاذاة المكدس |
| `صافي` | بدون تأثيرات جانبية |
| `قد_يفشل` | قد يرمي استثناء |

## الماكرو (Macros)

### أنواع أجزاء النمط

| رمز إنجليزي | عربي | المعنى |
|-------------|------|--------|
| `$x:expr` | `$x:عبر` | تعبير |
| `$x:ident` | `$x:معرّف` | مُعرّف |
| `$x:ty` | `$x:نوع` | نوع |
| `$x:block` | `$x:كتلة` | كتلة كود |
| `$x:tt` | `$x:رمز` | شجرة رموز |
| `$x:path` | `$x:مسار` | مسار |
| `$x:pat` | `$x:نمط` | نمط مطابقة |
| `$x:stmt` | `$x:جملة` | جملة |
| `$x:item` | `$x:عنصر` | تعريف |

### أنماط التكرار

```
$($عنصر:عبر),*   # صفر أو أكثر (مع فاصلة)
$($عنصر:عبر),+   # واحد أو أكثر
$($عنصر:عبر)?    # صفر أو واحد
```

## العقود الذكية (Smart Contracts)

### الصيغة

```sad
#[عقد_ذكي]
صنف محفظة
   رصيد: رقم

   #[قابل_للدفع]
   دالة أودع()
      رصيد += msg.قيمة
   نهاية

   دالة اسحب(مبلغ: رقم)
      إذا (رصيد >= مبلغ)
         رصيد -= مبلغ
         أرسل(msg.المرسل، مبلغ)
      نهاية
   نهاية
نهاية
```

### السمات المدعومة

| السمة | المعنى |
|-------|--------|
| `#[عقد_ذكي]` | تعريف عقد ذكي |
| `#[قابل_للدفع]` | الدالة تقبل الدفع |
| `#[عرض_فقط]` | قراءة فقط |
| `#[نقي]` | بدون تأثيرات جانبية |
| `#[حدث]` | تعريف حدث |
| `#[مُنشئ]` | باني العقد |
| `#[تلقائي]` | يُنفذ تلقائياً |

### البلوكشينات المستهدفة

Ethereum، Solana، Polygon، BSC، Avalanche، محلي (للاختبار)

## واجهة المستخدم التصريحية (UI DSL)

### مكونات العرض الأساسية

| المكون | المعنى |
|--------|--------|
| `نص` | عرض نص |
| `صورة` | عرض صورة |
| `أيقونة` | عرض أيقونة |
| `زر` | زر تفاعلي |
| `حقل_نص` | حقل إدخال |
| `منطقة_نص` | منطقة نص كبيرة |
| `تبديل` | مفتاح تبديل |
| `منزلق` | شريط منزلق |

### مكونات التخطيط

| المكون | المعنى |
|--------|--------|
| `عمود` | ترتيب عمودي |
| `صف` | ترتيب أفقي |
| `رصة` | تراكب |
| `شبكة` | شبكة |
| `حاوية` | حاوية عامة |
| `بطاقة` | بطاقة |

### مثال واجهة بسيطة

```sad
منشئ_واجهة تطبيق_حاسبة
   عمود
      نص("الحاسبة") لون("أزرق")
      حقل_نص(متغير: مدخل) تلميح("أدخل رقماً")
      صف
         زر("جمع") عند_نقر(جمع)
         زر("طرح") عند_نقر(طرح)
      نهاية
      نص(النتيجة) لون("أخضر")
   نهاية
نهاية
```
