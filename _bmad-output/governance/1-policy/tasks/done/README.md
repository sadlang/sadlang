# المهام المنجزة (Done Tasks)

> **أرشيف دائم** — لا يُحذف منه أي ملف.

## القواعد

1. PM فقط ينقل المهام من `../active/` إلى هنا بعد استيفاء DoD.
2. كل مهمة منجزة تحوي:
   - `TASK-<id>.md` (نسخة نهائية من التعريف)
   - `TASK-<id>.state.md` (آخر state قبل الإغلاق + قسم "خلاصة ما تعلّمناه")

3. عند إغلاق مهمة، PM يضيف:
   ```markdown
   ## خلاصة ما تعلّمناه (Lessons Learned)
   - <ما نجح>
   - <ما فشل أو احتاج تعديل>
   - <اقتراحات لمهام مشابهة>
   ```

4. إذا الخلاصة تحوي درساً يستحق ذاكرة دائمة → PM يكتبه في `/memories/repo/`.

## التنظيم

المهام مرتّبة زمنياً بالاسم (`TASK-001`, `TASK-002`, ...). لا مجلدات فرعية.
