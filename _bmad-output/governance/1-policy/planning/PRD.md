# PRD — متطلَّبات منتج لغة ص

> **stub أوّلي** — يُكمَّل في ستوريات لاحقة. الهدف الآن: إعطاء الوكلاء سياقاً كافياً لقرارات تقنية بسيطة.

---

## 1. الرؤية

لغة برمجة عربية حديثة (Sad / لغة ص) — تُتيح للناطقين بالعربية كتابة كود واضح بكلمات مفتاحية عربية، مع أداء C++ (عبر LLVM) ومرونة Python (مفسِّر).

## 2. الجمهور المستهدف

- مطوِّرون عرب يتعلَّمون البرمجة لأول مرة (المفسِّر).
- مطوِّرون محترفون يريدون أداءً أصلياً (المترجم `sadc`).
- مدرِّسون يحتاجون لغة تعليمية بنحو عربي طبيعي.

## 3. الأهداف الرئيسية (Goals)

| # | الهدف | حالة |
|---|---|---|
| G1 | مفسِّر مستقر يدعم كل نحو اللغة | ✅ مكتمل |
| G2 | مترجم `sadc` ينتج ملف تنفيذي أصلي | ✅ مكتمل |
| G3 | مكتبة قياسية كاملة (IO، رياضيات، نصوص، شبكة، رسوميات) | 🔄 جزئي |

## 4. الميزات النشطة (مدعومة)

- جميع أنواع البيانات الأساسية: رقم، عشري، نص، منطقي، مصفوفة، خريطة، أي.
- البرمجة الكائنية: صنف، وراثة، سمة، خاصية، باني، هدم.
- المعالجة المتقدمة: طابق/عندما (مطابقة الأنماط)، حاول/امسك، أجّل.
- التزامن: خيوط خفيفة (`أطلق`)، قنوات، WaitGroup، Mutex، Future.
- ماكروز، طرق امتداد، عقود (يتطلب/يضمن).

## 5. الميزات المستقبلية (Backlog)

- اختبار الخصائص (property testing) — `اختبر` مع `تكرارات`.
- توليد ثنائيات لمنصات إضافية (macOS, Linux ARM).
- WebAssembly target.
- REPL تفاعلي محسَّن.

## 6. القيود (Constraints)

- C++17 فقط (لا C++20 إلا بموافقة).
- LLVM 18 (إصدار محدَّد).
- الكود المُولَّد يجب أن يبقى متوافقاً مع Windows و Linux و macOS.

## 7. معايير النجاح (Success Metrics)

- اختبارات شاملة: ≥ 900 (حالياً ≥900 ✅).
- زمن البناء: ≤ 5 دقائق على hardware حديث.
- زمن تشغيل ملف `.ص` بسيط: ≤ 200ms للمفسِّر، ≤ 50ms للمترجم.
