# التنسيق اليومي (Daily Coordination)

> **ملف واحد لكل يوم** — مركز التواصل بين PM والوكلاء الثلاثة.

## الاسم والمكان

`YYYY-MM-DD.md` — تاريخ ISO من `Get-Date -Format "yyyy-MM-dd"` (تاريخ الجهاز الحقيقي، لا تخمين).

## من يكتب فيه؟

| الكاتب | القسم |
|---|---|
| **PM** | "الأولويات اليوم"، "تكاليف جديدة"، "ملاحظات للوكلاء" |
| **Alpha** | "Alpha — تحديث" (سطر واحد عن مهمته النشطة) |
| **Beta** | "Beta — تحديث" |
| **Gamma** | "Gamma — تحديث" |

## القالب

[../templates/DAILY_TEMPLATE.md](../templates/DAILY_TEMPLATE.md)

## القواعد

1. كل وكيل يضيف سطره في بداية يوم عمله (مرة واحدة على الأقل/يوم).
2. PM يراجع كل يوم ويُحدّث الأولويات في بداية اليوم التالي.
3. **هذا الملف هو المصدر الوحيد للتواصل العام** — لا chat، لا message bus، لا قنوات أخرى. أي شيء غير موثّق هنا غير موجود.
4. ملف اليوم لا يُحرَّر بعد منتصف الليل (يُعتبر مُغلقاً، وأي تحديث في اليوم التالي).
5. لا حذف من ملفات الأيام الماضية — أرشيف دائم.

## تنبيه: السياسة 48h Lost Agent

إذا وكيل لم يكتب في daily لـ يومين متتاليين + state.md لم يتحدّث → PM يعتبره مفقوداً ويعيد تكليف مهمته.
