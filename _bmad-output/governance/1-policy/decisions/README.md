# decisions/ — مجلد قرارات المعمارية (1-policy)

يحوي ADRs (Architecture Decision Records) لمنطقة الحوكمة.

## القاعدة

- كل ADR ملف مستقل: `ADR-XXX-<short-name>.md`
- صيغة محتواه: Context → Decision → Consequences → Alternatives Considered
- لا تُحذف ADRs أبداً — تُعلَّم `SUPERSEDED-BY: ADR-YYY` عند الإلغاء.

> _حالياً فارغ — أول ADR متوقع للنقطة R0 (تعليم الوثائق المضلِّلة)._
