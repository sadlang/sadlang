# مواصفات تصميم تجربة المستخدم — محراب (mihrab-ide)

**التاريخ:** 2026-07-25

## ١. سياق المشروع (مُكتشَف)

**محراب** بيئة تطوير مستقلّة للغة ص، مبنيّة على VSCodium-مرقَّع، بدعم RTL من الدرجة الأولى.

**الهويّة البصريّة القائمة:**
- الشعار: «القوس المِحرابيّ الخالص» — قوس مدبَّب أحاديّ الخطّ + مؤشّر ذهبيّ.
- اللون المميِّز: فيروزيّ `#31A796` + ذهب `#E3BE68`.
- السمة الداكنة «محراب الداكنة»: خلفيّة ليليّة `#0F1C24`، نصّ حجريّ `#EDE6D6`.
- السمة الفاتحة: أرضيّة حجريّة `#F5F0E4`، أخضر `#0F7C6E`.

## ٢. المستخدم والتجربة الجوهريّة

- **المستخدم:** المطوّر العربيّ الذي يكتب بلغة ص؛ يقضي ساعات في المحرّر، يقرأ ويكتب RTL.
- **المهمّة الأساسيّة للقشرة:** فتح مشروع ص، تصفّح الملفّات، الكتابة بتلوين نحويّ عربيّ، التشغيل في الطرفيّة، وقراءة الحالة — كلّه باتّجاه يمين ← يسار طبيعيّ لا مقلوب.
- **معيار النجاح:** ألّا يشعر المطوّر أنّ العربيّة «مُلصقة» على محرّر غربيّ، بل أنّ المحرّر وُلد عربيًّا.

## ٣. الأثر الشعوريّ المستهدَف (قرار المالك)

سكينة وتركيز · فخر وأصالة · حداثة واحتراف · دفء وألفة — مجتمعةً. تُترجَم إلى:
- **سكينة/تركيز:** أرضيّة ليليّة هادئة، لكنات خافتة، مساحات تنفّس، زخرفة محيطيّة بشفافيّة ٥٪ فقط.
- **فخر/أصالة:** شعار القوس المحرابيّ حاضر، زخرفة نجميّة ثمانيّة إسلاميّة، مفردات معرّبة كاملة.
- **حداثة/احتراف:** تخطيط يضاهي VS Code، حوافّ مستديرة، ظلال ناعمة، تبديل سمة سلس.
- **دفء/ألفة:** السمة الفاتحة بدفء الورق الحجريّ، الذهب كلمسة أليفة لا صارخة.

## ٤. الإلهام والاتّجاه البصريّ

**مزيج متوازن:** هندسة نجميّة إسلاميّة خفيفة (نجمة ثمانيّة كنمط محيطيّ) + معمار الأقواس المحرابيّة (الشعار + الحوافّ) + دفء الورق (السمة الفاتحة). لا صخب زخرفيّ — الزخرفة أثر لا موضوع.

## ٦ + ٨. الأساس البصريّ والقشرة (مُنفَّذ كنموذج حيّ)

نُفِّذت **قشرة المحرّر الكاملة** كنموذج Artifact تفاعليّ RTL بسمتين:
- شريط عنوان بشعار القوس + قائمة معرّبة (ملفّ/تحرير/تحديد/عرض…) + عنوان مركزيّ.
- **شريط النشاط يمينًا** (RTL) بمؤشّر قوس ذهبيّ للنشِط + شارة إدارة المصدر.
- مستكشف بشجرة مشروع ص (أيقونة القوس لملفّات `.ص`) + مؤشّرات git عربيّة (م/ج).
- تبويبات + مسار تنقّل (breadcrumb) معرّب + محرّر بكود ص حقيقيّ مُبرَز + مؤشّر ذهبيّ نابض + خريطة مصغّرة + زخرفة نجميّة محيطيّة.
- طرفيّة معرّبة (`سد-تشغيل`، موجِّه عربيّ، مخرَجات + سطر نجاح).
- **شريط حالة فيروزيّ** بشارة «اتّجاه: يمين ← يسار»، السطر/العمود، الترميز، «لغة ص».
