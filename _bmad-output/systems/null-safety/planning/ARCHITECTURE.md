# معمارية نظام أمان null — لغة ص

> أُنشئ: 2026-06-13. يبني على نظام الأنواع + سياسة الذاكرة. ينفّذ [ADR-TYPESYSTEM-001](../../type-system/decisions/ADR-TYPESYSTEM-001-NULL-SAFETY.md) §4-5.

## 1. الموقع المعماري

```
مصدر .ص → Lexer → Parser → AST → ┬→ [shared تحليلات] ──→ ┬→ InterpreterCore (sad-run)
                                  │   • Ownership/Borrow    │
                                  │   • NullSafetyAnalyzer ←─┘ (جديد — هذا النظام)
                                  └────────────────────────→ SIRBuilder → LLVM (sadc)
```

`NullSafetyAnalyzer` يُستدعى من **كلا المحرّكين** (نمط `shared/ownership/borrow_checker` المُستدعى من
`interpreter_core.cpp` و`compiler_driver_analysis.cpp`) — فالتحليل **مصدر حقيقة واحد**، لا يُكرَّر ولا يُتخطّى.

> **مشكلة الوضع الحالي (تُحَل هنا):** الفرض موزَّع — مدقّق دلالي (`type_checker`، لا يُفعَّل في sad-run) +
> فحوص متفرّقة في `statement_executor` (فرض P9 الابتدائي). هذا النظام يوحّدها في مكوّن مشترك واحد.

## 2. التكامل مع سياسة الذاكرة (الأعلام الثلاثة)

كل تشخيص أمان null يمرّ عبر `shared/errors/builders/dispatch.h::dispatch(kind, MemoryModeSettings)`:

| العلم | DispatchAction | سلوك أمان null |
|------|----------------|-----------------|
| `--gc` | Ignore | تجاهل (الأمان الصارم معطّل في وضع GC) |
| `--learn` | Warn | تحذير + ملاحظة تعليمية (السلوك الافتراضي الحالي لـP9) |
| `--prod` | Fatal | خطأ قاتل يوقف البناء (أمان null صارم كـRust/Dart sound) |

> هذا يجعل صرامة أمان null **متّسقة مع نموذج الذاكرة المختار** ومع فاحص الملكية — تجربة موحّدة.

## 3. تحليل التدفّق (Smart Narrowing)

بيئة أنواع حسّاسة للتدفّق فوق الـAST:
- **تضييق:** داخل `إذا (س != لاشيء)` (أو خروج فرع `== لاشيء`)، `س: T؟` يُعامَل `T`.
- **تراجع:** عند الخروج من الكتلة، يعود `س` إلى `T؟`.
- **نقاط التضييق:** `!= لاشيء`، `== لاشيء` (عكسي)، `؟؟`، التأكيد `!!`.
- **عائلة:** Kotlin smart casts، TypeScript narrowing، Dart promotion.

## 4. المكوّنات

| المكوّن | الدور |
|--------|------|
| `NullFlowEnvironment` | بيئة تتبّع قابلية null بالنطاق (تضييق/تراجع) |
| `NullSafetyVisitor` | زائر AST: يقرأ أنماط الشروط، يطبّق التضييق، يرصد الوصول غير الآمن |
| تكامل `dispatch()` | توجيه التشخيصات بالشدّة حسب السياسة |
| عامل `!!` (مؤكَّد) | `T؟ → T` صراحةً، خطأ كتالوج عند `عدم` |

## 5. الحدود (ما لا يملكه هذا النظام)

- **تمثيل** `Null`/`T؟`/`Result` + `isAssignableTo` → يملكها **نظام الأنواع** (مُنجَز).
- **عوامل** `?.`/`??`/`؟` (المعجم/المحلّل/التنفيذ الأساسي) → مُنجَزة في نظام الأنواع (P8)؛ هذا النظام يضيف **دلالتها الآمنة** (التضييق + التأكيد).
