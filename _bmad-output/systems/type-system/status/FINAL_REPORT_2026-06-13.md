## 3. المتبقّي

### داخل نظام الأنواع
- **P4 (بقيّة):** ربط `Future`/`Generator` بالـruntime؛ تمثيل `Optional<T>` الداخلي الغنيّ (الآن kind-level)؛ `؟` العربي مدعوم لكن codegen المترجم لا يميّز null.
- **codegen المترجم لـnull/Optional:** `نوع(لاشيء)` المُجمَّع→«مجهول»؛ اختبارات null عليها `@skip_compiler`. (يتقاطع مع NS-06.)

### هاجر إلى نظام null-safety المستقلّ (الجديد)
- **P10 (تضييق التدفّق)** → `NS-03`. السبب: تحليل تدفّق + سياسة، نظام مستقلّ لا تمثيل أنواع.
- **`!!` (P8-AC2)** → `NS-05`.
- **إعادة إرساء فرض P9** في مكوّن مشترك عبر `dispatch()` → `NS-01/NS-02`.

## 4. اكتشافات حوكمية (GR-01)

1. العدد الفعلي للأنواع تطوّر 49→50 (Null)→52 (Point/Rect)؛ مُولَّد من YAML فلا انحراف.
2. **`sadc.exe` كان بائتًا** (9 مايو) فأخفى حالة المترجم الحقيقية طوال جلسات سابقة؛ صُحِّح + سُجِّل في الذاكرة.
3. تقدير P2.5a «23 ملفًّا» كان فعليًّا **400+ نقطة لمس** (XL لا L).
4. **المدقّق الدلالي (`type_checker`) لا يُفعَّل في sad-run** — الفرض الفعلي في `statement_executor`؛ لذا أمان null المتقدّم نظام مشترك مستقلّ (null-safety).
