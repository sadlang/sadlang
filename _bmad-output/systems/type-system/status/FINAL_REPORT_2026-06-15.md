## 2. ما أُنجِز منذ تقرير 06-13 (الفجوات المُغلقة)

| البند | الدليل |
|------|--------|
| **ربط Future (P4)** | `future_func` يَسِم بـ`makeFuture()`؛ `نوع(مستقبل())`=«مستقبل»؛ الطرق سليمة (`type_=OBJECT`) |
| **codegen-null في المترجم** | `لاشيء`→`SadTypeKind::Null` مع حارس i64؛ `mapSIRType(Null)`→i64؛ `نوع(لاشيء)`=«عدم» **مزدوج**؛ حارس segfault في `لاشيء==نص` |
| **توحيد `نوع()` عبر SoT** | `type_of`=`sadTypeKindArabicName(getKind())`؛ الاسم من حقل `typeof_ar` في `types.yaml` ⇒ **تطابق المفسّر=المترجم** (رفع 052) |
| **رفع `@skip_compiler`** | 049/050/051/052/053 صارت **تكافؤًا مزدوجًا** |
| **إصلاح انحدار مطابقة-null** | نمط `عندما لاشيء:` كان يُبنى `Void`؛ صار `makeNull()` (مفسّر) + `Null‖Void` (مترجم) ⇒ X04/P09 مزدوج |
| **حارس تحذير معامل كاذب** | معامل غير مُصرَّح كان يُطلق تحذير نوع؛ حُصِر بالمعاملات المُصرَّحة |

## 4. دروس حوكميّة مُستخلَصة (فخاخ موثّقة)

1. **`sadc` بائت:** هدف `sadc` يُنتج `sad-build.exe`؛ انسخه إلى `sadc.exe` قبل الrunner وإلا فنتائج المترجم بائتة.
2. **مفسّر Debug في الrunner:** الrunner يقرأ مفسّر **Debug** ومترجم **Release**؛ أعد بناء **التهيئتين** أو فنتائج المفسّر بائتة (سبب «اختفاء» إصلاح نمط-null حتى أُعيد بناء Debug).
3. **مراجعة أميليا:** ادّعاء commit سابق أن X04/P09 «متطابقان» كان غير دقيق؛ صُحِّح بالجذر وبرسالة الالتزام.
