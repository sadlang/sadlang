# EPIC-UI-W15 — دعم العناصر الأولية الـ15 في المفسر والمترجم

## 1. الهدف

جعل العناصر الأولية الـ15 (ADR-UI-02) تعمل **وظيفياً** من طرفي التنفيذ:
- **المفسر `sad`:** تعبير العنصر يُنتج كائناً صحيحاً (`نوع() == "object"`)، ومكوّنات
  `واجهة_تصريحية` قابلة للإنشاء بـ `جديد`، والحالة `@حالة` تُفعّل إعادة البناء.
- **المترجم `sadc`:** ترجمة شجرة UI عبر SIR→LLVM إلى ملف تنفيذي أصلي.

## 2. الواقع الحالي (من فحص الكود 2026-06-08)

| الجانب | الحالة | الدليل |
|--------|--------|--------|
| تسجيل العناصر الـ15 كدوال مدمجة | ✅ موجود | `widget_builtins.cpp` (`Bw::COLUMN`... إلخ) |
| تقييم تعبير العنصر → `WidgetBuilder` | ✅ موجود | `expression_evaluator_ui.cpp` (`visitUIWidgetExpr`) |
| `نوع(زر(...))` يرجع كائناً | ❌ يرجع `"مجهول"` | تحقق وظيفي `test_event_system.ص` |
| `جديد <واجهة_تصريحية>()` | ❌ خطأ SEM001 | المكوّن غير مسجّل كصنف |
| تفعيل `@حالة` → إعادة بناء | ❌ غير مفعّل | `ui_state_manager` غير موصول بالتقييم |
| دعم المترجم `sadc` للـ UI | ❌ معدوم | لا `visitUIWidgetExpr` في `compiler/` |

> **الخلاصة:** الطبقة النحوية مكتملة، الجسر في المفسر **شبه مكتمل** (ينقصه التصنيف
> والتسجيل والتفعيل)، والمترجم **خالٍ تماماً** من دعم UI.

## 3. النطاق (Scope)

### داخل النطاق
- إصلاح تصنيف `WidgetBuilder` في `نوع()` ليُرجع `"object"`.
- تسجيل `UIDeclarationNode` كصنف قابل للإنشاء بـ `جديد` في المفسر.
- وصل `UIStateManager` بتقييم `@حالة` (observer → rebuild).
- تغطية العناصر الـ15 كاملةً في المفسر (وسائط + معدّلات + أبناء).
- دعم المترجم: زيارة عقد UI في SIRBuilder وتوليد LLVM (حد أدنى: بناء الشجرة + استدعاء وقت تشغيل).

### خارج النطاق (خطط فرعية أخرى)
- باطن المنصات (Desktop/Web/iOS/Android) — خطة منفصلة.
- العناصر المُهملة الـ55+ — خطة هجرة منفصلة (ADR-UI-02 مرحلة 2/3).
- الأنيميشن/الإيماءات المتقدمة — خطة منفصلة.

## 6. معايير القبول للملحمة (Epic-level AC)

- AC-E1: `نوع(زر("x")) == "object"` يعود صحيحاً (STORY-01).
- AC-E2: `متغير م = جديد مكوّن()` لمكوّن `واجهة_تصريحية` ينجح دون SEM001 (STORY-02).
- AC-E3: تغيير حقل `@حالة` يُطلق إعادة بناء قابلة للرصد (STORY-03).
- AC-E4: `sadc` يترجم ملف `.ص` فيه `واجهة_تصريحية` دون خطأ «عقدة غير مدعومة» (STORY-04).
- AC-E5: `tests/integration/test_event_system.ص` يمر بنسبة 100% (تحقق شامل).
