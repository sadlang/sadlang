    SRC["📜 .ص<br/>عمود(زر('ز'))"] --> LEX["🔤 Lexer"]

## 4. تمثيل العنصر زمن التشغيل (L3)

```mermaid
flowchart TD
    CALL["زر('ز') / عمود(...)"] --> WB["WidgetBuilder<br/>(يرث ObjectInstance)"]
    WB --> NT["نوع العنصر = sad::ui::UINodeType<br/>(تعداد منفصل ~90 قيمة)"]
    WB --> VAL["مُغلَّف في Value<br/>(type_=OBJECT)"]
    VAL --> KIND["getKind()"]
    KIND -.->|"المترجم"| OK["Class ⇒ نوع()=«كائن» ✅"]
    KIND -.->|"المفسّر"| BAD["Any ⇒ نوع()=«أي» 🔴 فجوة"]

    style WB fill:#fef9c3,stroke:#a16207,color:#000
    style OK fill:#dcfce7,stroke:#15803d,color:#000
    style BAD fill:#fecaca,stroke:#b91c1c,color:#000
```

> التصنيف الغنيّ للعناصر يعيش في `UINodeType` (منفصل عن `SadTypeKind`). فجوة P0 مؤكَّدة:
> المفسّر يَسِم قيمة الكائن `Any` (نوع=«أي») بينما المترجم `Class` (نوع=«كائن» — المرجع الصحيح).

## 6. الحالة التفاعلية وإعادة البناء (@حالة)

```mermaid
sequenceDiagram
    participant U as مستخدم
    participant W as عنصر (حدث)
    participant H as معالج الحدث (لامدا)
    participant S as @حالة (UIStateManager)
    participant R as Reconciler
    participant V as الشاشة

    U->>W: نقر/إدخال
    W->>H: تشغيل المعالج
    H->>S: تعديل حقل @حالة
    S->>R: إشعار بالتغيّر
    R->>R: إعادة بناء الشجرة (diff)
    R->>V: تحديث المنطقة المتغيّرة فقط
    Note over S,R: النمط التفاعليّ (مثل React/SwiftUI)
```
