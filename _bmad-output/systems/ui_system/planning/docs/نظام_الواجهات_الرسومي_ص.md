# نظام الواجهات والرسومات التصريحي في لغة ص (SadUI)

> **تاريخ التوثيق:** 2026-06-07
> **المصدر الموثوق:** المحلل النحوي الفعلي `shared/parser/src/ui/parser_ui.cpp` + نواة `sad_ui/` + جسر Android `platform/android/`
> **مبدأ التوثيق:** كل ما يلي مستخرَج من الكود الفعلي (لا من أمثلة قديمة). أمثلة `examples/*.ص` و`distribution/.../android/*.ص` التي تستخدم `صنف ... يرث حالة_عنصر` أو الأقواس `{}` **قديمة ولا تطابق المحلل الحالي**.

---

## 1. ما هو النظام؟

نظام **واجهات تصريحي (Declarative UI) عربي** مدمج في قلب لغة ص، مستوحى من **Flutter + SwiftUI**، لكن بصيغة عربية أصيلة:
- كتل تنتهي بـ `نهاية` (لا أقواس `{}`).
- اتجاه RTL أصلي (يمين→يسار).
- سلسلة معدّلات (Modifier Chain) بنقطة `.` على نمط SwiftUI.
- يُكتب مرة واحدة ويُعرَض على عدة منصات أصلية.

```
┌──────────────────────────────────────────────────────────────────┐
│                     فلسفة SadUI: «الهجين الذكي»                    │
│                                                                    │
│   كل عنصر يُوجَّه تلقائياً لأنسب آلية عرض في كل منصة:               │
│                                                                    │
│     عنصر قياسي  ──►  مكوّن أصلي (Native Widget)                    │
│     عنصر مخصّص  ──►  لوحة رسم (Canvas)                             │
└──────────────────────────────────────────────────────────────────┘
```

| المنصة | العناصر القياسية | العناصر المخصّصة | حالة الكود |
|--------|------------------|------------------|-----------|
| سطح المكتب | SDL2 + OpenGL | SDL2 Canvas | منفّذ (`sad_ui/backends/desktop`) |
| الويب | HTML5 + CSS3 | Canvas API | منفّذ (`sad_ui/backends/web`) |
| أندرويد | Views أصلية عبر JNI | Compose Canvas | جزئي (`platform/android` — `native_ui_builder.cpp` + `SadViewFactory.java`، 903 سطر) |
| iOS | SwiftUI | SwiftUI Path / Metal | منفّذ (`sad_ui/backends/ios` — `swiftui_codegen.cpp` 1645 + `ios_renderer.mm` 664) |

## 3. ماذا يدعم النظام؟

### 3.1 العناصر الأولية الـ 15 (ADR-UI-02)

المحلل يعترف بـ **15 عنصراً أولياً فقط** (`knownWidgets` في `parser_ui.cpp`). كل ما عداها يُبنى تركيبياً كـ `واجهة_تصريحية` مخصّصة:

```
┌─ تخطيط (4 حاويات) ──────────────────────────────────────────┐
│  عمود        صف         رصة         شبكة                      │
│  (Column)   (Row)     (Stack)     (Grid)                     │
├─ عرض (3) ───────────────────────────────────────────────────┤
│  نص          صورة        أيقونة                               │
│  (Text)     (Image)     (Icon)                              │
├─ تفاعل/إدخال (4) ───────────────────────────────────────────┤
│  زر          حقل_نص       مفتاح       منزلق                   │
│  (Button)   (TextField) (Toggle)   (Slider)                 │
├─ هيكل (3 حاويات متقدمة) ─────────────────────────────────────┤
│  حاوية       عرض_تمرير    قائمة_كسولة                         │
│ (Container) (ScrollView) (LazyList)                          │
├─ فراغ (1) ──────────────────────────────────────────────────┤
│  فاصل  (Spacer)                                              │
└─────────────────────────────────────────────────────────────┘

   الحاويات (تقبل أبناء وتُغلَق بـ نهاية):
   عمود، صف، رصة، شبكة، حاوية، عرض_تمرير، قائمة_كسولة
   العناصر الورقية (بلا أبناء): نص، صورة، أيقونة، زر، حقل_نص، مفتاح، منزلق، فاصل
```

### 3.2 العناصر المُهملة (55+) — خطة الهجرة

`deprecatedWidgets` في `parser_ui.cpp` يربط كل عنصر قديم ببديله الأولي، مع تحذير عند الاستخدام:

| عنصر مُهمل | البديل | عنصر مُهمل | البديل |
|-----------|--------|-----------|--------|
| `شريط_تطبيق`، `درج` | `حاوية` | `بطاقة`، `سطح`، `صندوق`، `هيكل` | `حاوية` |
| `حوار`، `ملاح` | `رصة` | `تنقل_سفلي`، `تبويبات`، `شريط_تقييم` | `صف` |
| `خانة_اختيار`، `زر_راديو` | `مفتاح` | `زر_نصي`، `زر_أيقونة`، `زر_عائم` | `زر` |
| `قائمة_عرض`، `عمود_كسول` | `قائمة_كسولة` | `شريط_بحث`، `منتقي`، `منطقة_نص` | `حقل_نص` |
| `وسط`، `حشوة`، `محاذاة`، `موسع`، `مرن` | `حاوية` | `جدول_بيانات` | `شبكة` |

**مراحل الهجرة:** v1.2 (تحذير + يعمل) → v1.3 (ترجمة داخلية تلقائية) → v2.0 (إزالة بخطأ).

### 3.3 المعدّلات (Modifier Chain)

تُطبَّق بالنقطة `.` بعد العنصر، وتتسلسل:

```
نص("مرحباً")
    .حجم(32)            ← معدّل بقيمة
    .لون(.أزرق)          ← معدّل بقيمة رمزية
    .هامش(10)
    .عند_النقر => ...    ← معدّل-حدث
```

أنواع المعدّلات الثلاثة (من `parseModifierChain`):
1. **معدّل بوسائط:** `.حجم(32)` ، `.لون("أحمر")`.
2. **معدّل-حدث:** اسم من `knownEvents` يتبعه معالج.
3. **معدّل بلا وسائط:** `.موسع` ، `.اختياري`.

### 3.4 الأحداث (Events)

المحلل يميّز الأحداث المعروفة (`knownEvents`): `عند_النقر`، `عند_الضغط_المطول`، `عند_السحب`، `عند_التحويم`، `عند_التغيير`، `عند_الظهور`، `عند_الإرسال`. أما نواة IR (`IREventType` في `types.h`) فتدعم **33+ نوع حدث** (نقر، نقر مزدوج، سحب يسار/يمين/أعلى/أسفل، دوران، قائمة سياقية...).

ثلاث صيغ لكتابة معالج الحدث (من `parseUIEventHandler`):

```
# 1) صيغة السهم (تعبير واحد)
زر("زيادة").عند_النقر => عداد += 1

# 2) صيغة الكتلة (عدة جُمَل)
زر("حفظ").عند_النقر
    احفظ()
    اطبع_سطر("تم")
نهاية

# 3) صيغة اللامدا (تمرّر وسيطاً)
حقل_نص("اسم").عند_التغيير(لامدا(ق) الاسم = ق نهاية)
```

### 3.5 إدارة الحالة (State)

داخل `واجهة_تصريحية` تُعلَن الحالة بـ `@` (من `parseUIStateDecl`):

```
┌──────────┬──────────────────────────────┬──────────────────────────┐
│ التصريح  │ المعنى                        │ الصيغة                    │
├──────────┼──────────────────────────────┼──────────────────────────┤
│ @حالة    │ حالة محلية قابلة للتغيير       │ @حالة عداد: عدد = 0       │
│ @ربط     │ مرجع/ربط من الأب              │ @ربط القيمة: نص           │
│ @بيئة    │ حالة عالمية مشتركة             │ @بيئة السمة: نص           │
│ @محسوب   │ قيمة مشتقة (تتطلب تعبيراً)     │ @محسوب الضعف = عداد * 2   │
└──────────┴──────────────────────────────┴──────────────────────────┘
```

أي تغيير على `@حالة` يُعيد بناء الواجهة تلقائياً عبر المُوفّق (Reconciler — `sad_ui/core/reconciler.h`).

### 3.6 الرسم الشرطي والحلقات (ADR-UI-01)

داخل أبناء أي حاوية يُسمح بـ `إذا/وإلا` و`لكل/بينما` لتوليد عناصر ديناميكياً:

```
عمود
    إذا (مسجّل)
        نص("مرحباً!")
    وإلا
        نص("سجّل أولاً")
    نهاية

    لكل مهمة في المهام
        نص(مهمة.العنوان)
    نهاية
نهاية
```

### 3.7 قدرات النواة الأخرى (أدلة من `sad_ui/core/include/sad_ui/`)

- تخطيط Flexbox: `layout.h` — ثيمات/سمات: `theme.h`, `style.h`.
- إيماءات + معالجات إدخال: `gesture.h`, `mouse_processor.h`, `keyboard_processor.h`, `touch_processor.h`.
- تفاعلية: `signal.h`, `state.h`, `property_binding.h`, `reconciler.h`.
- حركة وتمرير: `animation.h`, `scroll_physics.h`.
- وصول وتركيز: `accessibility.h`, `focus.h` — تحقق نماذج: `form_validation.h`.
- تخزين صور مؤقت: `image_cache.h` — إشعارات: `notification.h`.

## 4. كيف نكتب الواجهات بلغة ص؟ (الصيغة الفعلية المعتمدة)

### 4.1 البنية العامة لمكوّن

```
واجهة_تصريحية اسم_المكوّن [يرث أب]
    @حالة ...            # تصريحات الحالة
    @محسوب ...

    دالة بناء()          # الدالة التي تصف الشجرة
        ارجع <عنصر جذر>
    نهاية
نهاية
```

> القاعدة النحوية (BNF) من `parser_ui.cpp`:
> `واجهة_decl → 'واجهة_تصريحية' IDENTIFIER ['يرث' IDENTIFIER] body 'نهاية'`
> `body → (@state_decl | دالة method)*`

### 4.2 مثال كامل — عدّاد تفاعلي (بالصيغة المعتمدة)

```
استورد رسومات

واجهة_تصريحية تطبيق_عداد
    @حالة عداد: عدد = 0

    دالة بناء()
        ارجع عمود
            .حشوة(16)
            .تباعد(12)

            نص("عدد الضغطات:")
                .حجم(18)
                .لون(.رمادي)

            نص("" + عداد)
                .حجم(48)
                .سمك(.غامق)

            صف
                .تباعد(16)

                زر("➖ إنقاص")
                    .لون_خلفية(.أحمر)
                    .عند_النقر => عداد -= 1

                زر("➕ زيادة")
                    .لون_خلفية(.أخضر)
                    .عند_النقر => عداد += 1
            نهاية
        نهاية
    نهاية
نهاية
```

### 4.3 عرض عنصر مباشرة (بدون مكوّن) — كلمة `اعرض`

على المستوى الأعلى للبرنامج تُستخدم الكلمة السياقية `اعرض` لعرض تعبير عنصر:

```
استورد رسومات

اعرض زر("انقرني")
    .لون("أزرق")
    .عند_النقر => اطبع_سطر("تم النقر!")
```

كما يمكن إنشاء عنصر كقيمة عادية واستعماله (من `tests/integration/test_event_system.ص`):

```
متغير زر1 = زر("انقر").عند_النقر(معالج_نقر)
متغير حقل1 = حقل_نص("اسمك").عند_التغيير(معالج_تغيير)
متغير مزخرف = زر("ملوّن").لون("أحمر").حجم(18).هامش(10).عند_النقر(معالج_نقر)
```

### 4.4 القواعد الذهبية

```
✅ استورد رسومات                       في أول الملف
✅ واجهة_تصريحية اسم ... نهاية          لتعريف مكوّن (لا «صنف ... يرث حالة_عنصر»)
✅ @حالة / @ربط / @بيئة / @محسوب         لإدارة الحالة (لا «متغير» للحالة التفاعلية)
✅ الكتل تُغلَق بـ نهاية                  (لا أقواس {})
✅ سلسلة معدّلات بالنقطة .حجم(32).لون()  على نمط SwiftUI
✅ الأحداث: => أو كتلة...نهاية أو لامدا   
✅ استخدم العناصر الأولية الـ15           (العناصر القديمة تعمل لكن تُصدر تحذيراً)
✅ إذا/وإلا و لكل/بينما داخل الأبناء      للرسم الديناميكي
✅ اعرض <عنصر>                          لعرض عنصر على المستوى الأعلى
```

## 5. كيف يعمل باطن العرض لكل منصة؟

### سطح المكتب (SDL2 + OpenGL)
`sad_ui/backends/desktop/src/`: `renderer.cpp` (رسم العناصر)، `renderer_canvas.cpp`/`renderer_draw.cpp` (لوحة الرسم)، `window.cpp` (النافذة)، `text_editing.cpp` (تحرير النص). يُفعّل بـ `SAD_UI_USE_SDL2` (انظر `cmake/sdl2_platforms.cmake`).

### الويب (HTML/CSS/JS)
`sad_ui/backends/web/src/`: مولّدات `html_codegen.cpp`, `html_css_codegen.cpp`, `html_script_codegen.cpp`, `html_element_codegen.cpp` تُنتج صفحة كاملة من شجرة IR.

### أندرويد (Views أصلية عبر JNI)
```
شجرة IR (C++)
   │  native_ui_builder.cpp يمشي على الشجرة
   ▼  JNI مباشر (بلا JSON، بلا WebView)
SadViewFactory.java  ──►  ينشئ View أصلية لكل عقدة
   │  يدعم خصائص: text, fontSize, color, padding,
   │  backgroundColor, alignment, spacing, elevation,
   │  bold/italic, checked, value, opacity, visible...
   ▼
MainActivity (Android)  ──►  واجهة أصلية على الجهاز
```
الملفات: `platform/android/src/native_ui_builder.cpp`، `platform/android/app/java/com/sad/app/{SadViewFactory,SadEngine,MainActivity}.java`. البناء: `build_apk.ps1`.

## 6. الحالة الحالية (التزاماً بـ GR-01 — أدلة لا ادعاءات)

| المكوّن | الحالة | الدليل |
|---------|--------|--------|
| تحليل `واجهة_تصريحية` + المعدّلات + الأحداث | ✅ منفّذ | `parser_ui.cpp` (1029 سطر) |
| العناصر الأولية الـ15 + خريطة الإهمال | ✅ منفّذ | `knownWidgets`, `deprecatedWidgets` |
| الحالة `@حالة/@ربط/@بيئة/@محسوب` | ✅ منفّذ | `parseUIStateDecl` |
| الرسم الشرطي والحلقات | ✅ منفّذ | `parseUIConditional`, `parseUILoop` |

### ⚠️ ملاحظة على الأمثلة القديمة
- `examples/تطبيق_عداد.ص` و`تطبيق_مهام.ص` تستخدم `صنف ... يرث حالة_عنصر` + `جديد هيكل(...)` — **صيغة قديمة لا يقبلها المحلل الحالي**.
- `distribution/.../android/عداد_ui.ص` يستخدم الأقواس `{}` و`عرض()` — **نموذج تصميمي قديم**.
- المثال الموثوق العامل: `tests/integration/test_event_system.ص`.
- **يُوصى** بتحديث/حذف الأمثلة القديمة لتطابق الصيغة المعتمدة (`واجهة_تصريحية` + `نهاية`).
