# دليل العناصر الأولية الـ15 (Primitive Widgets Reference)

> **تاريخ التوثيق:** 2026-06-08
> **المصدر:** `shared/parser/src/ui/parser_ui.cpp` (`knownWidgets`, `containerWidgets`) + `sad_ui/core/types.h`
> **القاعدة (ADR-UI-02):** هذه هي العناصر الأولية الوحيدة المدمجة. كل عنصر آخر يُبنى تركيبياً أو مُهمَل.

---

## 0. نظرة عامة

```
┌─ تخطيط (4) ──┬─ عرض (3) ──┬─ إدخال (4) ──┬─ هيكل (3) ─────┬─ فراغ (1) ─┐
│ عمود          │ نص          │ زر            │ حاوية           │ فاصل        │
│ صف            │ صورة        │ حقل_نص        │ عرض_تمرير       │             │
│ رصة           │ أيقونة      │ مفتاح         │ قائمة_كسولة     │             │
│ شبكة          │             │ منزلق         │                 │             │
└───────────────┴─────────────┴───────────────┴─────────────────┴─────────────┘

   🔲 حاويات (تقبل أبناء، تُغلَق بـ نهاية):
       عمود · صف · رصة · شبكة · حاوية · عرض_تمرير · قائمة_كسولة
   🍃 عناصر ورقية (بلا أبناء):
       نص · صورة · أيقونة · زر · حقل_نص · مفتاح · منزلق · فاصل
```

| المعدّلات الشائعة (تنطبق على معظم العناصر) | |
|---|---|
| `.حشوة(ن)` · `.هامش(ن)` | المسافات الداخلية/الخارجية |
| `.لون(.أزرق)` · `.لون_خلفية(.أخضر)` | الألوان (رمزية أو hex) |
| `.حجم(ن)` · `.عرض(ن)` · `.ارتفاع(ن)` | الأبعاد |
| `.حد(...)` · `.انحناء_حد(ن)` · `.ظل(...)` | الحدود والتأثيرات |
| `.عتامة(٠.٥)` · `.دوران(ن)` · `.مقياس(ن)` | الشفافية والتحويلات |
| `.عند_النقر => ...` | الأحداث (انظر §الأحداث) |
| `.معطّل` · `.تسمية_وصول("...")` | الحالة وإمكانية الوصول |

## القسم الأول: عناصر العرض (🍃 ورقية)

### 1. `نص` (Text)
عنصر نصي بسيط يعرض سلسلة حروف.
```
نص("مرحباً بالعالم")
    .حجم(24)
    .لون(.أزرق)
    .سمك(.غامق)
```
| الوسيط | المحتوى النصي (موضعي أول) |
|--------|---------------------------|
| معدّلات مميزة | `.حجم` · `.سمك` · `.لون` · `.أقصى_أسطر` · `.محاذاة` |

### 2. `صورة` (Image)
يعرض صورة من ملف أو رابط أو ذاكرة (مع تخزين مؤقت — `image_cache.h`).
```
صورة("logo.png")
    .عرض(120)
    .ارتفاع(80)
    .وضع_المحتوى(.احتواء)
```
| الوسيط | المصدر (مسار/رابط) |
|--------|---------------------|
| معدّلات مميزة | `.وضع_المحتوى` (احتواء/تمدد/ملء) · `.عرض` · `.ارتفاع` |

### 3. `أيقونة` (Icon)
أيقونة متجهة (Material Icons أو مخصصة).
```
أيقونة("home")
    .حجم(32)
    .لون(.رمادي)
```

## القسم الثاني: عناصر الإدخال (🍃 ورقية)

### 4. `زر` (Button)
زر قابل للنقر مع نص أو محتوى مخصص.
```
زر("حفظ")
    .لون_خلفية(.أخضر)
    .عند_النقر => احفظ()
```
| الوسيط | عنوان الزر |
|--------|------------|
| الأحداث | `.عند_النقر` · `.عند_الضغط_المطول` |

### 5. `حقل_نص` (TextField)
حقل إدخال نص.
```
حقل_نص("أدخل اسمك")
    .قيمة(الاسم)
    .عند_التغيير(لامدا(ق) الاسم = ق نهاية)
```
| الوسيط | نص التلميح (placeholder) |
|--------|--------------------------|
| الأحداث | `.عند_التغيير` · `.عند_الإرسال` |

### 6. `مفتاح` (Toggle/Switch)
مفتاح تشغيل/إيقاف. (بديل العناصر المُهملة `خانة_اختيار` و`زر_راديو`.)
```
مفتاح(مفعّل)
    .عند_التغيير(لامدا(ق) مفعّل = ق نهاية)
```

### 7. `منزلق` (Slider)
شريط قيمة رقمية قابل للسحب.
```
منزلق(الصوت)
    .أدنى(0)
    .أقصى(100)
    .عند_التغيير(لامدا(ق) الصوت = ق نهاية)
```

## القسم الثالث: عناصر التخطيط (🔲 حاويات)

### 8. `عمود` (Column)
يرتب الأبناء عمودياً (أعلى → أسفل).
```
عمود
    .تباعد(12)
    .محاذاة_رئيسية(.وسط)

    نص("سطر 1")
    نص("سطر 2")
نهاية
```
| معدّلات مميزة | `.تباعد` · `.محاذاة_رئيسية` (المحور العمودي) · `.محاذاة_ثانوية` (الأفقي) |

### 9. `صف` (Row)
يرتب الأبناء أفقياً (يمين → شمال في RTL).
```
صف
    .تباعد(8)

    أيقونة("user")
    نص("المستخدم")
نهاية
```

### 10. `رصة` (Stack / ZStack)
يكدّس الأبناء فوق بعضهم.
```
رصة
    صورة("bg.png")
    نص("نص فوق الصورة")
نهاية
```

### 11. `شبكة` (Grid)
تخطيط شبكي بصفوف وأعمدة.
```
شبكة
    .أعمدة(3)
    .تباعد(8)

    لكل عنصر في العناصر
        نص(عنصر)
    نهاية
نهاية
```

## القسم الرابع: عناصر الهيكل (🔲 حاويات متقدمة)

### 12. `حاوية` (Container)
حاوية عامة بخلفية وحدود وحشوة. (البديل الأولي لـ `بطاقة`/`هيكل`/`صندوق`/`وسط`/`حشوة` المُهملة.)
```
حاوية
    .لون_خلفية(.أبيض)
    .حشوة(16)
    .انحناء_حد(8)
    .ظل(.خفيف)

    نص("محتوى البطاقة")
نهاية
```

### 13. `عرض_تمرير` (ScrollView)
حاوية بمحتوى قابل للتمرير (مع فيزياء تمرير — `scroll_physics.h`).
```
عرض_تمرير
    عمود
        لكل عنصر في القائمة_الطويلة
            نص(عنصر)
        نهاية
    نهاية
نهاية
```

### 14. `قائمة_كسولة` (LazyList)
قائمة تُحمّل عناصرها عند الحاجة فقط (للقوائم الطويلة جداً). (البديل لـ `قائمة_عرض`/`عمود_كسول`.)
```
قائمة_كسولة
    لكل مهمة في المهام
        نص(مهمة.العنوان)
    نهاية
نهاية
```

## القسم الخامس: الفراغ (🍃 ورقي)

### 15. `فاصل` (Spacer/Divider)
مساحة فارغة مرنة لتوزيع المسافات، أو خط فاصل. (البديل لـ `فاصل_خط` المُهمل.)
```
صف
    نص("يسار")
    فاصل(مرونة: 1)    # يدفع العنصرين للطرفين
    نص("يمين")
نهاية
```

## ملحق أ: الأحداث الشائعة

```
.عند_النقر => تعبير               # صيغة السهم
.عند_النقر  ...جُمَل... نهاية       # صيغة الكتلة
.عند_التغيير(لامدا(ق) ... نهاية)  # صيغة اللامدا
```
الأحداث المعروفة للمحلل: `عند_النقر` · `عند_الضغط_المطول` · `عند_السحب` ·
`عند_التحويم` · `عند_التغيير` · `عند_الظهور` · `عند_الإرسال`.
(النواة `IREventType` تدعم 33+ نوعاً، منها السحب الاتجاهي والدوران والقائمة السياقية.)

## ملحق ب: الرسم الديناميكي داخل الحاويات (ADR-UI-01)
```
عمود
    إذا (مسجّل)
        نص("مرحباً")
    وإلا
        نص("سجّل أولاً")
    نهاية

    لكل عنصر في القائمة
        نص(عنصر)
    نهاية
نهاية
```

## ملحق ج: العناصر المُهملة وبدائلها الأولية (ADR-UI-02)
| مُهمل | البديل | مُهمل | البديل |
|------|--------|------|--------|
| بطاقة، هيكل، صندوق، شريط_تطبيق، وسط، حشوة | حاوية | خانة_اختيار، زر_راديو | مفتاح |
| زر_نصي، زر_أيقونة، زر_عائم | زر | حوار، ملاح | رصة |
| قائمة_عرض، عمود_كسول | قائمة_كسولة | تنقل_سفلي، تبويبات | صف |
| شريط_بحث، منتقي، منطقة_نص | حقل_نص | جدول_بيانات | شبكة |
| فاصل_خط | فاصل | | |

> استخدام عنصر مُهمل يعمل حالياً لكن يُصدر تحذير إهمال (المرحلة 1). انظر [ADR-UI-02](../../decisions/ADR-UI-02-fifteen-primitive-widgets.md).
