# الطبقة 3 — اختبارات النظام والأدوات (System)

> اختبارات الأدوات المساندة والبنية وغير الوظيفي: LSP، المنسّق، مدير الحزم، sadinfo،
> اتساق توليد الكود، التوثيق، الأداء (مع عتبات NFR رقمية)، والـ fuzzing.

## البنية

| المجلد | المحتوى | يدمج |
|---|---|---|
| `lsp/` | خادم اللغة | lsp |
| `formatter/` | المنسّق | — |
| `pkg/` | مدير الحزم | pkg |
| `sadinfo/` | أداة استعلام بيانات اللغة | sadinfo |
| `codegen/` | اتساق `language-truth/ → generated/` | — |
| `docs/` | تكافؤ أمثلة التوثيق | docs_extraction, doc_gen_dual_execution, توثيق |
| `benchmark/` | الأداء + عتبات تراجع رقمية | benchmark, benchmarks, performance, stress |
| `fuzzing/` | مدخلات عشوائية | fuzzing |

## ملاحظات

- **عتبات NFR (ADR-004):** كل benchmark حرج له عتبة تراجع رقمية تُفشِل البوّابة عند تجاوزها.
- **الشبكة:** اختبارات الشبكة تُعزل خلف علم تفعيل لتفادي نداءات خارجية في CI.

*جزء من نظام testing-system (الطبقة 3).*
