# الميزة 19: رسائل الخطأ بالعربية الفصحى

**بسم الله الرحمن الرحيم**

**الأولوية**: 🔴 حرجة — المرحلة 1
**المرجع**: م-و-023 من مواصفات BeeOS
**التبعيات**: لا تبعيات

---

## ١. الوصف

**كل** رسائل المترجم — أخطاء وتحذيرات ومعلومات — يجب أن تكون بالعربية الفصحى الواضحة. هذا ليس ترفاً — بل متطلب إلزامي (م-و-023). المبرمج العربي يجب أن يفهم الخطأ **فوراً** بدون ترجمة ذهنية.

---

## ٢. المتطلبات

### ٢.١ أمثلة على رسائل الأخطاء المطلوبة

```
خطأ[م001]: استخدام متغير بعد نقل ملكيته
  --> نواة/الملكة/ذاكرة.ص:42:15
   |
40 |     دع بيانات = اقرأ_ملف("إعدادات.عسل")
41 |     أرسل(بيانات)        // الملكية انتقلت هنا
42 |     اطبع(بيانات)        // ❌ لم يعد صالحاً
   |               ^^^^^^ المتغير `بيانات` استُخدم بعد نقل ملكيته في السطر 41
   |
   = مساعدة: استخدم `.انسخ()` قبل الإرسال إذا كنت تحتاج نسخة

خطأ[م002]: لا يمكن الإعارة كـ `&متغير` — يوجد إعارة مشتركة نشطة
  --> شبكة/بروتوكول.ص:87:10
   |
85 |     دع قارئ = &الحزمة       // إعارة مشتركة
86 |     // ...
87 |     دع كاتب = &متغير الحزمة  // ❌ لا يمكن
   |              ^^^^^^^^^^^^^^^ إعارة حصرية مستحيلة — يوجد قارئ نشط في السطر 85
   |
   = مساعدة: تأكد من انتهاء كل الإعارات المشتركة قبل الإعارة الحصرية

تحذير[ت001]: متغير غير مُستخدم
  --> أدوات/شِل.ص:23:9
   |
23 |     دع عدّاد = 0
   |         ^^^^^^ المتغير `عدّاد` عُرِّف ولم يُستخدم
   |
   = مساعدة: أزل المتغير أو ابدأ اسمه بـ `_` لإسكات التحذير
```

### ٢.٢ فئات الرسائل

| الرمز | الفئة | الوصف |
|-------|-------|-------|
| م0xx | ملكية | أخطاء نظام الملكية والإعارة |
| م1xx | أنواع | أخطاء عدم تطابق الأنواع |
| م2xx | بناء | أخطاء بنية اللغة (syntax) |
| م3xx | نطاق | أخطاء النطاق (متغير غير معرّف) |
| م4xx | تزامن | أخطاء التزامن (مشاركة غير آمنة) |
| ت0xx | تحذيرات | تحذيرات عامة |
| ت1xx | أداء | تحذيرات أداء |

### ٢.٣ متطلبات الجودة

- كل رسالة تحتوي **سهم يُشير للموقع الدقيق** في الكود
- كل رسالة تحتوي **اقتراح إصلاح** (`مساعدة:`)
- الأرقام تُعرض بأرقام عربية أو هندية (حسب إعداد المستخدم)
- دعم الألوان في الطرفية (أحمر للأخطاء، أصفر للتحذيرات)
- دعم RTL في عرض الرسائل

## ٣. معايير القبول

- [ ] كل رسائل المترجم بالعربية الفصحى — لا رسالة إنجليزية واحدة
- [ ] كل خطأ يحتوي رمز فريد (مXXX)
- [ ] كل خطأ يُشير للسطر والعمود الدقيق
- [ ] كل خطأ يحتوي اقتراح إصلاح (`مساعدة:`)
- [ ] دعم الألوان في الطرفية
- [ ] رسائل أخطاء الملكية واضحة ومفيدة (أهم فئة)
- [ ] لا رسالة تقنية غير مفهومة — كلها بلغة بسيطة
