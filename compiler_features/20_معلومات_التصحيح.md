# الميزة 20: معلومات التصحيح (DWARF / GDB)

**بسم الله الرحمن الرحيم**

**الأولوية**: 🟠 عالية — المرحلة 2
**المرجع**: س177 من مواصفات BeeOS، المهمة T044
**التبعيات**: خلفية x86_64 (الميزة 04)

---

## ١. الوصف

المترجم يجب أن يُنتج معلومات تصحيح بصيغة DWARF حتى يمكن استخدام GDB لتصحيح النواة والتطبيقات. هذا مهم خصوصاً لأن BeeOS يعمل على QEMU في المراحل الأولى، وGDB يتصل بـ QEMU لتصحيح النواة عن بُعد.

---

## ٢. المتطلبات

### ٢.١ معلومات DWARF المطلوبة

| المعلومة | الوصف | DWARF Tag |
|---------|-------|-----------|
| الملفات والأسطر | ربط التعليمات بأسطر الكود | DW_TAG_compile_unit |
| المتغيرات | أسماء وأنواع ومواقع المتغيرات | DW_TAG_variable |
| الدوال | أسماء ومعاملات وأنواع الدوال | DW_TAG_subprogram |
| البنيات | حقول وأحجام البنيات | DW_TAG_structure_type |
| التعدادات | قيم وأسماء التعدادات | DW_TAG_enumeration_type |

### ٢.٢ أسماء عربية في المصحح

```
// في GDB يجب أن تظهر الأسماء العربية:
(gdb) break خلية_العسل::أنشئ
(gdb) print عملية.حالة
(gdb) backtrace
#0  معالج_المقاطعة () at نواة/مقاطعات.ص:42
#1  الملكة_المؤسسة () at نواة/عمليات.ص:100
```

### ٢.٣ مستويات التصحيح

```
ص ترجم --تصحيح=0      // بدون معلومات تصحيح
ص ترجم --تصحيح=1      // أسطر فقط (سريع)
ص ترجم --تصحيح=2      // كامل (افتراضي مع --تحسين=0)
ص ترجم --تصحيح=3      // كامل + ماكرو
```
