# الميزة 12: نوع النتيجة والاختياري (Result / Option)

**بسم الله الرحمن الرحيم**

**الأولوية**: 🔴 حرجة — المرحلة 1
**المرجع**: عقود BeeOS API، نموذج البيانات
**التبعيات**: الأنواع المعممة (الميزة 11)، التعدادات (الميزة 13)

---

## ١. الوصف

BeeOS يستخدم نمط **"لا استثناءات" (no exceptions)** — كل خطأ يُعالَج عبر أنواع `نتيجة<ن، خ>` و `اختياري<ن>`. هذا يجعل معالجة الأخطاء **صريحة ومرئية** — لا يمكن تجاهل خطأ بالصدفة.

### لماذا لا استثناءات؟

- الاستثناءات تحتاج runtime support (stack unwinding) — غير متاح في النواة
- الاستثناءات تُخفي مسارات الفشل — خطير في نظام تشغيل
- النتيجة/الاختياري قابلة للتحسين بالكامل في وقت الترجمة

---

## ٢. المتطلبات التفصيلية

### ٢.١ نوع النتيجة (`نتيجة<ن، خ>`)

```
تعداد نتيجة<ن، خ> {
    نجاح(ن),        // العملية نجحت — تحمل القيمة
    فشل(خ),         // العملية فشلت — تحمل الخطأ
}
```

### ٢.٢ نوع الاختياري (`اختياري<ن>`)

```
تعداد اختياري<ن> {
    بعض(ن),         // القيمة موجودة
    لا_شيء,         // القيمة غير موجودة
}
```

### ٢.٣ عامل الانتشار `?`

```
// بدلاً من:
دع واصف = طابق افتح("ملف.نص"، قراءة) {
    نجاح(و) => و,
    فشل(خ) => أعد فشل(خ),
}

// يمكن كتابة:
دع واصف = افتح("ملف.نص"، قراءة)?    // `?` ينشر الخطأ تلقائياً
```

### ٢.٤ دوال مساعدة

```
// فك قيمة مع قيمة افتراضية
دع القيمة = اختياري.أو(قيمة_افتراضية)

// فك قيمة أو panic
دع القيمة = اختياري.فك()   // ينهار إذا كانت لا_شيء

// تحويل
دع نتيجة = اختياري.حوّل(|ق| ق * 2)

// سلسلة
دع القيمة = نتيجة1?.عملية2()?.عملية3()?
```

## ٣. أمثلة من BeeOS

```
// كل عمليات نظام الملفات تُرجع نتيجة
دالة افتح(مسار: نص, وضع: وضع_ملف) → نتيجة<واصف_ملف, خطأ>
دالة اقرأ(واصف: واصف_ملف, حجم: عدد_طبيعي) → نتيجة<[بايت], خطأ>

// الاستخدام مع ? 
دالة اقرأ_إعدادات() → نتيجة<إعدادات, خطأ> {
    دع واصف = افتح("/إعدادات/النظام.عسل", قراءة)?
    دع بيانات = اقرأ(واصف, 4096)?
    دع إعدادات = حلّل_عسل(بيانات)?
    أعد نجاح(إعدادات)
}
```

---

## ٤. معايير القبول

- [ ] دعم `نتيجة<ن، خ>` كنوع مدمج أو في المكتبة القياسية
- [ ] دعم `اختياري<ن>` كنوع مدمج
- [ ] دعم عامل `?` لانتشار الأخطاء
- [ ] المترجم يُحذّر إذا لم يُعالَج نوع `نتيجة` (لا يُمكن تجاهله)
- [ ] تحسين: `اختياري<&ن>` يُمثَّل بمؤشر واحد (null = لا_شيء)
- [ ] تحسين: `نتيجة` لا يحتاج تخصيص heap — على المكدس فقط
- [ ] دعم دوال `حوّل`، `و_إلا`، `أو`، `فك`

---

## ٥. ملاحظات تقنية

- `اختياري<&ن>` يجب أن يكون بنفس حجم المؤشر (null pointer optimization)
- `نتيجة` يجب أن يكون بحجم `max(حجم(ن), حجم(خ)) + 1 بايت` كحد أقصى
- عامل `?` يجب أن يُنتج كود فعّال (مقارنة واحدة + قفزة شرطية)
