---

## ١. الوصف

نظام الوحدات والحزم يُنظّم كود BeeOS في مكتبات قابلة لإعادة الاستخدام. المشروع الكبير مثل BeeOS يحتاج:
- **وحدات (modules)**: تنظيم الكود داخل المشروع الواحد
- **حزم (packages)**: مكتبات مستقلة يمكن مشاركتها
- **تبعيات (dependencies)**: إدارة الحزم التي يعتمد عليها المشروع

---

## ٢. المتطلبات

### ٢.١ نظام الوحدات (Modules)

```
# ملف: نواة/الرئيسية.ص
وحدة ذاكرة          # ← تبحث عن: نواة/ذاكرة.ص أو نواة/ذاكرة/وحدة.ص
وحدة مقاطعات        # ← تبحث عن: نواة/مقاطعات.ص أو نواة/مقاطعات/وحدة.ص
وحدة مُجدول          # ← تبحث عن: نواة/مُجدول.ص أو نواة/مُجدول/وحدة.ص

# استيراد من وحدة
استخدم ذاكرة::مخصّص_الصفحات
استخدم مقاطعات::IDT, معالج_مقاطعةنهاية
استخدم مُجدول::*     # استيراد كل شيء (غير مُحبّذ)
```

### ٢.٢ الرؤية (Visibility)

```
# افتراضياً: خاص (لا يُرى خارج الوحدة)
بنية تفاصيل_داخلية  ... نهاية        # خاص

# عام: يُرى من أي مكان
عام بنية واجهة_عامة  ... نهاية

# عام للحزمة فقط: يُرى داخل الحزمة لكن ليس خارجها
عام(حزمة) بنية مشترك_داخلي  ... نهاية

# عام للوحدة الأب فقط
عام(أب) بنية مشترك_مع_الأب  ... نهاية
```

### ٢.٣ إعادة التصدير (Re-export)

```
# ملف: نواة/وحدة.ص
وحدة ذاكرة
وحدة ملفات

# إعادة تصدير — المستخدم يستورد من نواة مباشرة
عام استخدم ذاكرة::مخصّص_الصفحات
عام استخدم ملفات::BeeFS
```

### ٢.٤ تعريف الحزمة

```
# ملف: مشروع.عش
[حزمة]
الاسم = "نواة_نحلة"
الإصدار = "0.1.0"
المؤلفون = ["فريق BeeOS <team@beeos.org>"]
الوصف = "نواة نظام تشغيل نحلة"
الرخصة = "وقف-1.0"    # رخصة BeeOS

[تبعيات]
مخصّص =  إصدار = "0.1", مسار = "../مخصّص" نهاية
بروتوكول =  إصدار = "0.1", مسار = "../بروتوكول" نهاية
تشفير =  إصدار = "0.1", مسار = "../تشفير" نهاية

[تبعيات_تطوير]
اختبار_نواة =  مسار = "../اختبار_نواة" نهاية

[تبعيات_بناء]
مولّد_جداول =  مسار = "../أدوات/مولّد_جداول" نهاية
```

### ٢.٥ الإصدار الدلالي (Semantic Versioning)

```
# في ملف .عش
[تبعيات]
مكتبة_أ = "1.2.3"       # بالضبط 1.2.3
مكتبة_ب = "^1.2"        # ≥1.2.0, <2.0.0 (متوافق)
مكتبة_ج = "~1.2"        # ≥1.2.0, <1.3.0 (بسيط)
مكتبة_د = "≥1.0, <2.0"  # نطاق مخصص
```

### ٢.٦ ملف القفل (Lock File)

```
# يُولّد تلقائياً: قفل.عش
# يحفظ الإصدارات الدقيقة لضمان بناء متطابق
[[حزمة]]
الاسم = "مخصّص"
الإصدار = "0.1.5"
المصدر = "مسار:../مخصّص"
هاش = "sha256:abc123..."
```

### ٢.٧ ميزات اختيارية (Features)

```
# في مشروع.عش
[ميزات]
افتراضية = ["sse2"]
sse2 = []
avx2 = ["sse2"]
تصحيح_ذاكرة = []
qemu = []

# في الكود:
#[إذا(ميزة = "avx2")]
دالة نسخ_سريعة_avx2(هدف: *متغير بايت, مصدر: *ثابت بايت, حجم: عدد_طبيعي) 
    # نسخة باستخدام AVX2
نهاية

#[إذا(ليس(ميزة = "avx2"))]
دالة نسخ_سريعة_sse2(هدف: *متغير بايت, مصدر: *ثابت بايت, حجم: عدد_طبيعي) 
    # نسخة باستخدام SSE2
نهاية
```
