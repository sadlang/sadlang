## ١. الوصف

الدوال المجهولة (Closures) هي دوال بدون اسم يمكنها التقاط متغيرات من بيئتها المحيطة. BeeOS يستخدمها بكثرة في واجهات الأحداث والاستدعاءات (callbacks).

---

## ٢. المتطلبات

### ٢.١ البنية اللغوية

```
// دالة مجهولة بسيطة
دع ضاعف = |س| س * 2

// مع أنواع صريحة
دع أضف = |أ: عدد_صحيح, ب: عدد_صحيح| → عدد_صحيح { أعد أ + ب }

// التقاط من البيئة
دع عامل = 10
دع اضرب = |س| س * عامل    // `عامل` مُلتقط

// استخدام كمعامل
دع أعداد = [1, 2, 3, 4, 5]
دع مُضاعفة = أعداد.حوّل(|س| س * 2)    // [2, 4, 6, 8, 10]
```

### ٢.٢ أنواع الالتقاط

| النوع | البنية | الوصف |
|-------|-------|-------|
| استعارة مشتركة | `|س| ...` (افتراضي) | يقرأ المتغيرات المحيطة |
| استعارة حصرية | `|س| ...` (تلقائي) | يقرأ ويعدل المتغيرات المحيطة |
| نقل ملكية | `انقل |س| ...` | ينقل ملكية المتغيرات للدالة المجهولة |

### ٢.٣ استخدام في واجهات BeeOS

```
// عند_الأذان — من عقود API (س137)
عند_الأذان(بعض(الفجر), || {
    شغّل_صوت("أذان_الفجر.opus")
})

// مؤقت
بعد(ثانية(5), || {
    اطبع("مرت 5 ثوانٍ")
})

// عند الحدث
عند_حدث("شبكة.اتصال", |حدث| {
    اطبع("اتصال جديد من: {}", حدث.المصدر)
})
```
