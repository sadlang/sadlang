## ١. الوصف

BeeHiveMind هو نظام الذكاء الاصطناعي في BeeOS. يحتاج **محرك استدلال** يعمل محلياً على الجهاز (بدون إنترنت) بأقل من 3000 سطر كود. المترجم يحتاج دعم عمليات int8/int4 المحسّنة لتشغيل نماذج الشبكات العصبية بكفاءة.

### لماذا int8 بدل float32؟

| النوع | الحجم | السرعة | الدقة | الاستخدام |
|-------|-------|--------|-------|-----------|
| float32 | 4 بايت | بطيء | 100% | التدريب |
| float16 | 2 بايت | متوسط | ~99% | استدلال GPU |
| **int8** | **1 بايت** | **سريع جداً** | **~97%** | **استدلال CPU** |
| int4 | ½ بايت | أسرع | ~94% | نماذج صغيرة |

int8 يُعطي 4x تسريع مع فقدان دقة ضئيل — مثالي لـ CPU بدون GPU.

## ٢. المتطلبات

### ٢.١ أنواع بيانات الاستدلال

```
# أنواع مدمجة للاستدلال
نوع ص8 = عدد_صحيح_8;          # int8: -128 إلى 127
نوع ص8_بدون = عدد_طبيعي_8;    # uint8: 0 إلى 255
نوع ص4 = عدد_صحيح_4_مضغوط;   # int4: مضغوط (2 قيم في بايت واحد)

# أنواع SIMD مدمجة
نوع متجه_ص8 = ص8x32;          # 32 قيمة int8 في سجل AVX2 (256-bit)
نوع متجه_ص16 = ص16x16;        # 16 قيمة int16 في سجل AVX2
```

### ٢.٢ عمليات SIMD للاستدلال

```
# ضرب مصفوفات int8 مع تجميع int32 (VNNI / PMADDUBSW)
@ضمّن_دائماً
دالة اضرب_وجمّع_ص8(
    أ: متجه_ص8,      # 32 × int8
    ب: متجه_ص8,      # 32 × int8
) → متجه_ص32         # 8 × int32 (نتيجة التجميع)
    تراب 
        # VPMADDUBSW + VPMADDWD
        "vpmaddubsw {نتيجة_مؤقتة}, {أ}, {ب}"
        "vpmaddwd {نتيجة}, {نتيجة_مؤقتة}, {واحدات}"
    نهاية
نهاية

# ReLU بـ SIMD — max(0, x)
@ضمّن_دائماً
دالة relu_ص8(مُدخل: متجه_ص8) → متجه_ص8 
    أقصى_ص8(مُدخل, صفر_ص8())
نهاية

# Quantize: تحويل float32 إلى int8
دالة كمّم(
    مُدخل: &[ع32],           # float32 array
    معامل_تكميم: ع32,        # scale factor
    نقطة_صفر: ص8              # zero point
) → متجه<ص8> 
    مُدخل.تكرار()
        .خريطة(|ق| قرّب((ق / معامل_تكميم) + نقطة_صفر كـ ع32) كـ ص8)
        .اجمع()
نهاية
```

### ٢.٣ أنواع بيانات المصفوفات

```
# مصفوفة مكمّمة (quantized tensor)
بنية مصفوفة_مكمّمة 
    بيانات: متجه<ص8>,           # القيم المكمّمة
    الشكل: متجه<عدد_طبيعي>,    # الأبعاد [batch, channels, height, width]
    معامل_تكميم: ع32,           # scale
    نقطة_صفر: ص8,               # zero point
نهاية

نفّذ مصفوفة_مكمّمة 
    # ضرب مصفوفات مكمّمة باستخدام SIMD
    دالة اضرب(&ذات, أخرى: &مصفوفة_مكمّمة) → مصفوفة_مكمّمة 
        # تنفيذ باستخدام VNNI/PMADDUBSW
        ...
   نهاية
    
    # Convolution 2D مكمّمة
    دالة التفاف_2د(&ذات, نواة: &مصفوفة_مكمّمة, خطوة: عدد_طبيعي) → مصفوفة_مكمّمة 
        ...
   نهاية
نهاية
```

### ٢.٤ عمليات مدمجة (Intrinsics)

```
# عمليات مدمجة يُوفّرها المترجم مباشرة:

# ضرب نقطي int8 → int32 (أساس كل شيء في الاستدلال)
@مدمج("x86.avx2.pmaddubs.w")
دالة ضرب_نقطي_ص8(أ: ص8x32, ب: ص8x32) → ص16x16;

# أقصى / أدنى int8 (لـ ReLU وغيرها)
@مدمج("x86.avx2.pmaxs.b")
دالة أقصى_ص8(أ: ص8x32, ب: ص8x32) → ص8x32;

@مدمج("x86.avx2.pmins.b")
دالة أدنى_ص8(أ: ص8x32, ب: ص8x32) → ص8x32;

# تحويل int8 ↔ int16 ↔ int32
@مدمج("x86.avx2.pmovsxbw")
دالة وسّع_ص8_ص16(أ: ص8x16) → ص16x16;

# Shuffle int8 (لإعادة ترتيب البيانات)
@مدمج("x86.avx2.pshuf.b")
دالة رتّب_ص8(أ: ص8x32, قناع: ص8x32) → ص8x32;
```

## ٣. أمثلة: BeeHiveMind

### ٣.١ طبقة خطية (Linear Layer)

```
بنية طبقة_خطية {
    أوزان: مصفوفة_مكمّمة,    # [out, in] int8
    انحياز: متجه<ع32>,       # [out] int32
}

نفّذ طبقة_خطية {
    دالة تقدّم(&ذات, مُدخل: &مصفوفة_مكمّمة) → مصفوفة_مكمّمة {
        دع متغير خرج = ذات.أوزان.اضرب(مُدخل)
        خرج.أضف_انحياز(&ذات.انحياز)
        أرجع خرج.كمّم_خرج()     # إعادة التكميم للطبقة التالية
    }
}
```

### ٣.٢ محرك استدلال < 3000 سطر

```
بنية محرك_استدلال {
    طبقات: متجه<طبقة>,
    ذاكرة_مخصصة: مخصّص_ثابت,  # ذاكرة ثابتة، بدون تخصيص ديناميكي
}

نفّذ محرك_استدلال {
    دالة حمّل(مسار_نموذج: &مسار) → نتيجة<محرك_استدلال, خطأ> {
        # تحميل النموذج المكمّم من ملف .نحلة_نموذج
        ...
    }
    
    دالة استدل(&ذات, مُدخل: &[ع32]) → متجه<ع32> {
        دع متغير حالي = مصفوفة_مكمّمة::من_ع32(مُدخل)
        لكل طبقة في &ذات.طبقات {
            حالي = طبقة.تقدّم(&حالي)
        }
        أرجع حالي.إلى_ع32()    # فك التكميم للخرج النهائي
    }
}
```
