# الميزة 23: عمليات ثابتة الزمن (Constant-Time Operations)

**بسم الله الرحمن الرحيم**

**الأولوية**: 🟠 عالية — المرحلة 2
**المرجع**: س145 من مواصفات BeeOS (BeeVault — التشفير)
**التبعيات**: خلفية x86_64 (الميزة 04)، المحسّن (الميزة 25)

---

## ١. الوصف

العمليات ثابتة الزمن ضرورية لأمان BeeVault (نظام التشفير في BeeOS). الخوارزميات المستخدمة (ChaCha20-Poly1305، Ed25519، Argon2id) يجب أن تعمل بنفس الوقت **بغض النظر عن البيانات المُدخلة** — وإلا يمكن للمهاجم استنتاج مفاتيح التشفير من توقيت التنفيذ (timing side-channel attacks).

### المشكلة

محسّنات المترجم (optimizers) تفعل أشياء تُدمّر ثبات الزمن:
- **إزالة الفروع الميتة**: تحوّل `if` إلى `cmov` أو تزيله — تغيير التوقيت
- **استبدال الحلقات**: تطوي حلقات ثابتة — تغيير التوقيت حسب عدد التكرار
- **التحميل المسبق**: ترتيب الذاكرة يتغير — تغيير بسبب cache
- **Short-circuit evaluation**: `و` / `أو` المنطقية لا تُقيّم الطرفين دائماً

### الحل

سمة `@ثابت_الزمن` تمنع المحسّن من تغيير نمط التنفيذ.

---

## ٢. المتطلبات

### ٢.١ سمة `@ثابت_الزمن`

```
// على مستوى الدالة — كل العمليات داخلها ثابتة الزمن
@ثابت_الزمن
دالة قارن_هاش(أ: &[بايت], ب: &[بايت]) → منطقي {
    دع متغير نتيجة: بايت = 0
    لكل ط في 0..أ.الطول() {
        نتيجة |= أ[ط] ^ ب[ط]    // XOR كل بايت — لا short-circuit
    }
    أرجع نتيجة == 0
}
```

### ٢.٢ ما يُمنع على المحسّن

داخل `@ثابت_الزمن`:

| المحسّن | ممنوع؟ | السبب |
|---------|--------|-------|
| إزالة فروع ميتة | ✅ ممنوع | يغير التوقيت حسب البيانات |
| Short-circuit `و`/`أو` | ✅ ممنوع | يقيّم طرف واحد فقط أحياناً |
| تطوير الحلقات (unrolling) | ⚠️ مسموح بحذر | فقط إذا لم يُغيّر عدد التعليمات |
| استبدال `إذا` بـ `cmov` | ✅ مطلوب | `cmov` ثابت الزمن |
| ترتيب التعليمات | ⚠️ مسموح بحذر | لا يُغيّر نمط الوصول للذاكرة |
| إزالة كود "غير مستخدم" | ✅ ممنوع | قد يزيل عمليات تمويه |

### ٢.٣ عمليات مدمجة ثابتة الزمن

```
// مقارنة ثابتة الزمن — لا تتوقف عند أول اختلاف
قارن_ثابت(أ: &[بايت], ب: &[بايت]) → منطقي

// اختيار ثابت الزمن — بدون فرع
اختر_ثابت<ن>(شرط: منطقي, أ: ن, ب: ن) → ن

// مبادلة شرطية ثابتة الزمن
بادل_ثابت<ن>(شرط: منطقي, أ: &متغير ن, ب: &متغير ن)

// صفّر ذاكرة مضمون (لا يُزيله المحسّن أبداً)
صفّر_سري(هدف: &متغير [بايت])
```

### ٢.٤ تحذير المترجم

```
// إذا استُخدمت عملية غير ثابتة الزمن داخل @ثابت_الزمن:
تحذير[ت201]: عملية غير ثابتة الزمن داخل دالة مُعلّمة بـ @ثابت_الزمن
    ← السطر 15: إذا أ > ب { ... }
    ← اقتراح: استخدم اختر_ثابت() بدلاً من إذا
```

## ٣. أمثلة من BeeOS

### ٣.١ مقارنة كلمات المرور في BeeVault

```
@ثابت_الزمن
دالة تحقق_كلمة_مرور(مُدخل: &[بايت], مُخزّن: &[بايت]) → منطقي {
    إذا مُدخل.الطول() != مُخزّن.الطول() {
        // ملاحظة: حتى هذا الفرع يُنفّذ بنفس الوقت (padding)
        أرجع خطأ
    }
    أرجع قارن_ثابت(مُدخل, مُخزّن)
}
```

### ٣.٢ عمليات Ed25519

```
@ثابت_الزمن
دالة ضرب_نقطة_منحنى(نقطة: &نقطة_إدواردز, عدد: &عدد256) → نقطة_إدواردز {
    دع متغير نتيجة = نقطة_إدواردز::المحايد()
    لكل ط في (0..256).عكس() {
        نتيجة = نتيجة.مضاعفة()
        // اختيار ثابت الزمن بدلاً من if
        دع إضافة = اختر_ثابت(عدد.البت(ط), نقطة, &نقطة_إدواردز::المحايد())
        نتيجة = نتيجة.جمع(إضافة)
    }
    أرجع نتيجة
}
```

### ٣.٣ تصفير مفاتيح بعد الاستخدام

```
دالة شفّر_رسالة(مفتاح: &[بايت; 32], رسالة: &[بايت]) → نتيجة<متجه<بايت>, خطأ_تشفير> {
    دع متغير مفتاح_مؤقت = [0بايت; 32]
    انسخ_ذاكرة(&متغير مفتاح_مؤقت, مفتاح, 32)
    
    دع النتيجة = chacha20_poly1305(&مفتاح_مؤقت, رسالة)
    
    // صفّر المفتاح فوراً — المحسّن لا يحذف هذا أبداً
    صفّر_سري(&متغير مفتاح_مؤقت)
    
    أرجع النتيجة
}
```
