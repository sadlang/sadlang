## ١. الوصف

التعدادات مع بيانات مُضمَّنة (tagged unions / algebraic data types) ومطابقة الأنماط (pattern matching) هي أساس نمذجة البيانات في BeeOS. كل حالة من حالات النظام تُمثَّل كتعداد.

---

## ٢. المتطلبات التفصيلية

### ٢.١ تعدادات بسيطة

```
تعداد حالة_عملية {
    بيضة,
    يرقة,
    عاملة,
    نائمة,
    ميتة,
}
```

### ٢.٢ تعدادات مع بيانات (Sum Types)

```
تعداد خطأ_نظام {
    لم_يُوجد(نص),                      // ملف غير موجود — مع اسم الملف
    مرفوض(نص, معرّف_هوية),              // مرفوض — مع السبب والهوية
    ذاكرة_ممتلئة(عدد_طبيعي),            // مع الحجم المطلوب
    مهلة(مدة),                          // مع المدة المنتظرة
    غير_متوقع,                          // بدون بيانات
}

تعداد نوع_ملف {
    ملف,
    مجلد,
    رابط(نص),          // رابط مع المسار المُشار إليه
    جهاز(عدد_رئيسي: عدد_طبيعي, عدد_فرعي: عدد_طبيعي),
    أنبوب,
}
```

### ٢.٣ مطابقة الأنماط الشاملة

```
// المترجم يفرض تغطية كل الحالات
طابق عملية.حالة {
    بيضة => جهّز_العملية(عملية),
    يرقة => حمّل_البرنامج(عملية),
    عاملة => جدوِل(عملية),
    نائمة => تحقق_مؤقت(عملية),
    ميتة => نظّف(عملية),
    // لا يمكن نسيان حالة — خطأ ترجمة
}

// مطابقة مع فك البيانات
طابق الخطأ {
    لم_يُوجد(اسم) => اطبع("الملف {اسم} غير موجود"),
    مرفوض(سبب, _) => اطبع("مرفوض: {سبب}"),
    ذاكرة_ممتلئة(حجم) => اطبع("لا ذاكرة كافية لـ {حجم} بايت"),
    مهلة(مدة) إذا مدة > ثانية(30) => أعد طويلة_جداً,
    مهلة(_) => أعد قصيرة,
    غير_متوقع => انهار("خطأ غير متوقع"),
}

// المطابقة مع حراسة (guard)
طابق قيمة {
    ن إذا ن > 0 => "موجب",
    ن إذا ن < 0 => "سالب",
    _ => "صفر",
}
```

### ٢.٤ إذا-دع (if-let)

```
// فحص حالة واحدة فقط
إذا دع بعض(قيمة) = الاختياري {
    استخدم(قيمة)
}

// أو مع while
طالما دع بعض(عنصر) = القائمة.التالي() {
    عالج(عنصر)
}
```

## ٣. أمثلة من BeeOS

```
// من نموذج البيانات: دورة حياة العملية
طابق العملية.حالة {
    بيضة => {
        // فحص صلاحيات (نِحَل/capabilities)
        إذا !تحقق_نِحَل(العملية) {
            العملية.حالة = ميتة
            أعد فشل(خطأ::مرفوض("نِحَل غير كافية"))
        }
        العملية.حالة = يرقة
    },
    يرقة => {
        حمّل_البرنامج(العملية)?
        العملية.حالة = عاملة
    },
    عاملة => جدوِل(العملية),
    نائمة => { /* تحقق من المؤقت */ },
    ميتة => حرّر_موارد(العملية),
}
```
