# تقرير الميزة 07: المؤشرات والأنواع الثابتة الحجم

## الحالة: ✅ جزئي

## الملفات الموجودة

### الأنواع الثابتة الحجم (موجودة بالكامل)
- `TYPE_U8` / `ط8` / `بايت` — 8 بت بدون إشارة
- `TYPE_U16` / `ط16` / `كلمة` — 16 بت بدون إشارة
- `TYPE_U32` / `ط32` — 32 بت بدون إشارة
- `TYPE_U64` / `ط64` — 64 بت بدون إشارة
- `TYPE_I8` / `ص8` — 8 بت مع إشارة
- `TYPE_I16` / `ص16` — 16 بت مع إشارة
- `TYPE_I32` / `ص32` — 32 بت مع إشارة

### المؤشرات
- `TYPE_PTR` / `مؤشر` — نوع مؤشر أساسي

## ما يحتاج إضافة
1. `*ثابت` و `*متغير` كتمييز بين المؤشرات الثابتة والمتغيرة
2. `اقرأ_متطاير` و `اكتب_متطاير` — عمليات volatile
3. `@محاذاة(N)` — محاذاة الذاكرة
4. أنواع `ع8` إلى `ع128` المطلوبة في المواصفات (بعضها موجود كـ `ط`)
