# تقرير الميزة 06: نظام البنى (Structs)

## الحالة: ✅ جزئي — يحتاج كلمة مفتاحية `بنية`

## الملفات الموجودة
- `compiler_new/include/types/struct_types.h` — نظام البنى في الأنواع
- `compiler_new/src/types/struct_types.cpp` — تنفيذ البنى
- `KEYWORD_PACKED` — الكلمة `محزوم` / `packed` (بنية محزومة)

## ما يحتاج إضافة
1. كلمة مفتاحية `بنية` في الـ Lexer → `KEYWORD_STRUCT`
2. تحليل `بنية اسم { حقول }` في المحلل

## ملاحظة
نظام الأنواع يدعم البنى بالفعل عبر `struct_types.h`، لكن الـ Lexer لا يحتوي على كلمة `بنية`. حالياً يُستخدم `صنف` (`class`) بدلاً منها.
