# تقرير الميزة 02: التجميع المضمّن (Inline Assembly)

## الحالة: ✅ موجود بالكامل

## الملفات الموجودة

### الـ Lexer
- `KEYWORD_ASM` — الكلمة `تجميع` / `asm`
- `KEYWORD_VOLATILE` — الكلمة `متطاير` / `volatile`
- `KEYWORD_EXTERN` — الكلمة `خارجي` / `extern`
- `KEYWORD_REGISTER` — الكلمة `سجل` / `register`
- `KEYWORD_SECTION` — الكلمة `قسم` / `section`

### المحلل
- `shared/parser/src/asm_parser.cpp` — محلل التجميع المضمّن
- `shared/parser/src/extern_parser.cpp` — محلل الدوال الخارجية

### المترجم
- `compiler_new/src/backend/inline_asm.cpp` — توليد كود التجميع المضمّن
- `compiler_new/src/backend/interrupt_handlers.cpp` — معالجات المقاطعات

### الأهداف
- `compiler_new/src/targets/x86_64.cpp` — دعم مسجلات x86_64 الكاملة (RAX-R15, XMM, YMM, ZMM)
