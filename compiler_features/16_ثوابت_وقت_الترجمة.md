# الميزة 16: ثوابت وقت الترجمة (const / comptime)

**بسم الله الرحمن الرحيم**

**الأولوية**: 🟠 عالية — المرحلة 2
**المرجع**: س145 (عمليات ثابتة الزمن للتشفير)، نظام BeeOS
**التبعيات**: لا تبعيات

---

## ١. الوصف

ثوابت وقت الترجمة تسمح بحساب قيم وتنفيذ كود في **وقت الترجمة** بدلاً من وقت التشغيل. هذا مهم لـ BeeOS في عدة سياقات: جداول ثابتة في النواة، أحجام مخازن مؤقتة، حسابات تشفيرية، إلخ.

---

## ٢. المتطلبات

### ٢.١ ثوابت بسيطة

```
ثابت حجم_الصفحة: عدد_طبيعي = 4096
ثابت حجم_القطاع: عدد_طبيعي = 512
ثابت أقصى_عمليات: عدد_طبيعي = 65536
ثابت اسم_النظام: &نص = "BeeOS"
```

### ٢.٢ دوال وقت الترجمة

```
// دالة تُنفَّذ في وقت الترجمة
وقت_ترجمة دالة عدد_الصفحات(حجم: عدد_طبيعي) → عدد_طبيعي {
    أعد (حجم + حجم_الصفحة - 1) / حجم_الصفحة
}

// الاستخدام — الحساب يتم أثناء الترجمة
ثابت صفحات_النواة: عدد_طبيعي = عدد_الصفحات(2 * 1024 * 1024)  // 512 صفحة
```

### ٢.٣ تأكيدات وقت الترجمة

```
// تأكيد شرط في وقت الترجمة — يفشل البناء إذا لم يتحقق
تأكيد_ترجمة(حجم_النوع<خلية_عسل>() == 512, "حجم inode يجب أن يكون 512 بايت")
تأكيد_ترجمة(حجم_النوع<*ثابت ()>() == 8, "يجب أن يكون 64-bit")
```

### ٢.٤ مصفوفات بحجم وقت الترجمة

```
// حجم المصفوفة يجب أن يكون ثابتاً في وقت الترجمة
بنية جدول_IDT {
    مدخلات: [مدخلة_IDT; 256],     // 256 مدخلة — حجم ثابت
}

// جداول جاهزة في وقت الترجمة
ثابت جدول_CRC32: [ع32; 256] = وقت_ترجمة {
    دع جدول: [ع32; 256] = [0; 256]
    لكل ي في 0..256 {
        دع قيمة = ي كـ ع32
        لكل _ في 0..8 {
            قيمة = إذا قيمة & 1 != 0 {
                (قيمة >> 1) ^ 0xEDB88320
            } وإلا {
                قيمة >> 1
            }
        }
        جدول[ي] = قيمة
    }
    جدول
}
```

## ٣. معايير القبول

- [ ] دعم `ثابت` لتعريف ثوابت بسيطة
- [ ] دعم `وقت_ترجمة دالة` لدوال تُنفَّذ أثناء الترجمة
- [ ] دعم `وقت_ترجمة {}` لكتل تُنفَّذ أثناء الترجمة
- [ ] دعم `تأكيد_ترجمة()` لتأكيدات وقت الترجمة
- [ ] دعم `حجم_النوع<ن>()` و `محاذاة_النوع<ن>()` كدوال وقت ترجمة مدمجة
- [ ] المصفوفات بحجم ثابت فقط — لا VLA (Variable Length Arrays) في المكدس
- [ ] حساب ثوابت معقدة (حلقات، شروط) في وقت الترجمة
