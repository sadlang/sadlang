# الميزة 22: وضع النواة (Bare Metal / Freestanding)

**بسم الله الرحمن الرحيم**

**الأولوية**: 🔴 حرجة — المرحلة 1
**المرجع**: س85 من مواصفات BeeOS، م-و-001
**التبعيات**: خلفية x86_64 (الميزة 04)

---

## ١. الوصف

وضع النواة (freestanding) يعني أن المترجم يُنتج كوداً يعمل **بدون نظام تشغيل تحته** — مباشرة على المعالج (bare metal). هذا إلزامي لأن BeeOS **هو** نظام التشغيل.

### ماذا يعني عملياً؟

- **لا مكتبة قياسية**: لا `اطبع()`، لا `افتح()`، لا شيء — النواة تبني كل شيء من الصفر
- **لا runtime**: لا GC، لا panic handler تلقائي، لا stack unwinding
- **لا libc**: لا `malloc`، لا `printf`، لا `memcpy` — كلها تُكتب بلغة ص
- **لا نقطة دخول قياسية**: لا `main()` — نقطة الدخول يُحددها linker script

---

## ٢. المتطلبات

### ٢.١ خيار `--لا-مكتبة-قياسية`

```
ص ترجم --لا-مكتبة-قياسية --هدف=x86_64-نحلة-bare نواة/الرئيسية.ص
```

### ٢.٢ سمة على مستوى الملف

```
// أول سطر في ملفات النواة
#![لا_مكتبة_قياسية]
#![لا_نقطة_دخول]

// تعريف نقطة الدخول يدوياً
#[نقطة_دخول]
خطر دالة _بداية() → ! {
    // هنا يبدأ كل شيء
    // ...
    حلقة {}    // لا يمكن العودة — لا يوجد مكان نعود إليه
}
```

### ٢.٣ معالج الانهيار

```
// في وضع النواة يجب تعريف معالج الانهيار يدوياً
#[معالج_انهيار]
دالة انهيار(معلومات: &معلومات_انهيار) → ! {
    // عرض شاشة "إنّا لله" (BeeInnaa — س181)
    اعرض_شاشة_خضراء(معلومات)
    حلقة {}
}
```

### ٢.٤ دوال مدمجة أساسية (Intrinsics)

حتى بدون مكتبة قياسية، المترجم يجب أن يوفر:

```
// نسخ ذاكرة (مطلوب للمترجم نفسه)
انسخ_ذاكرة(هدف: *متغير بايت, مصدر: *ثابت بايت, حجم: عدد_طبيعي)

// ملء ذاكرة بقيمة
املأ_ذاكرة(هدف: *متغير بايت, قيمة: بايت, حجم: عدد_طبيعي)

// مقارنة ذاكرة
قارن_ذاكرة(أ: *ثابت بايت, ب: *ثابت بايت, حجم: عدد_طبيعي) → عدد_صحيح

// صفّر ذاكرة
صفّر_ذاكرة(هدف: *متغير بايت, حجم: عدد_طبيعي)
```

### ٢.٥ نوع `!` (never type)

```
// الدالة لا تعود أبداً — مطلوب لنقطة دخول النواة ومعالج الانهيار
دالة _بداية() → ! {
    // ...
    حلقة {}     // ← لا عودة
}
```

### ٢.٦ أهداف الترجمة (Targets)

```
ص ترجم --هدف=x86_64-نحلة-bare        // نواة BeeOS على x86_64
ص ترجم --هدف=x86_64-نحلة-نظام        // تطبيق BeeOS على x86_64
ص ترجم --هدف=x86_64-linux-gnu        // تطبيق Linux (للتطوير المبدئي)
```
