# الميزة 26: نظام البناء (BeeNest — عُش النحل)

**بسم الله الرحمن الرحيم**

**الأولوية**: 🟠 عالية — المرحلة 2
**المرجع**: س119 من مواصفات BeeOS، م-و-020
**التبعيات**: خلفية x86_64 (الميزة 04)، صيغة .نحلة (الميزة 21)

---

## ١. الوصف

نظام البناء **عُش** (BeeNest) هو أداة البناء الرسمية لمشاريع لغة ص. يُعادل `cargo` في Rust أو `make` في C. ملفات البناء تُكتب بالعربية بامتداد `.عش`.

### مراحل التطوير

| المرحلة | الأداة | الملاحظات |
|---------|--------|-----------|
| المرحلة 0 (شهر 1-2) | Makefile | bootstrap — لبناء المترجم الأول |
| المرحلة 1 (شهر 3-4) | مترجم ص يبني عُش | الاستضافة الذاتية |
| المرحلة 2 (شهر 5+) | عُش يبني كل شيء | عُش يبني المترجم + النواة + التطبيقات |

## ٢. المتطلبات

### ٢.١ ملف البناء `.عش`

```
// ملف: مشروع.عش
[مشروع]
الاسم = "نواة_نحلة"
الإصدار = "0.1.0"
المؤلفون = ["فريق BeeOS"]
اللغة = "ص"

[تبعيات]
المخصّص = { مسار = "../مخصّص" }
المحمّل = { مسار = "../محمّل" }

[بناء]
الهدف = "x86_64-نحلة-bare"
خيارات_ترجمة = ["--تحسين=2", "--لا-مكتبة-قياسية"]
خيارات_ربط = ["-T", "ربط.ld"]

[بناء.تصحيح]
خيارات_ترجمة = ["--تحسين=0", "--لا-مكتبة-قياسية", "-g"]

[بناء.إنتاج]
خيارات_ترجمة = ["--تحسين=3", "--لا-مكتبة-قياسية", "--lto"]
```

### ٢.٢ أوامر عُش

```
عش بناء                  // بناء المشروع
عش بناء --إنتاج          // بناء للإنتاج
عش بناء --تصحيح          // بناء للتصحيح
عش اختبار                 // تشغيل الاختبارات
عش اختبار --تغطية         // مع تقرير التغطية
عش تشغيل                  // بناء وتشغيل
عش نظّف                   // حذف ملفات البناء
عش وثّق                   // إنشاء التوثيق
عش صيغ                   // تنسيق الكود
عش فحص                   // فحص بدون ترجمة كامل (lint)
عش جديد اسم_المشروع      // إنشاء مشروع جديد
```

### ٢.٣ مساحة العمل (Workspace)

```
// ملف: مساحة.عش (في جذر BeeOS)
[مساحة_عمل]
الأعضاء = [
    "نواة",
    "محمّل",
    "مخصّص_ذاكرة",
    "نظام_ملفات",
    "شبكة",
    "واجهة",
    "أدوات/*",
]

[مساحة_عمل.تبعيات]
// تبعيات مشتركة بين كل المشاريع الفرعية
```

### ٢.٤ بناء صورة ISO

```
// ملف: صورة.عش
[صورة]
النوع = "iso"
المحمّل = "محمّل/خرج/محمّل.نحلة"
النواة = "نواة/خرج/نواة.نحلة"
الملفات = [
    { مصدر = "خطوط/", هدف = "/نظام/خطوط/" },
    { مصدر = "إعدادات/", هدف = "/نظام/إعدادات/" },
]

[صورة.إقلاع]
النوع = "UEFI"
firmware = "OVMF.fd"    // للاختبار على QEMU
```

```
// بناء الصورة
عش صورة                   // ينشئ: beeos.iso
عش صورة --qemu            // ينشئ ويُشغّل على QEMU
```

### ٢.٥ نظام الأهداف (Targets)

```
// ملف هدف مخصص: x86_64-نحلة-bare.هدف.json
{
    "المعمارية": "x86_64",
    "النظام": "bare",
    "نموذج_البيانات": "64bit",
    "المكدّس": "مخصص",
    "panic": "إيقاف",
    "مميزات": [
        "sse2",
        "aes-ni"
    ],
    "ربط": {
        "النوع": "ثابت",
        "السكربت": "ربط.ld"
    }
}
```

### ٢.٦ البناء التزايدي (Incremental)

```
عش بناء    // أول مرة: يبني كل شيء
// تعديل ملف واحد...
عش بناء    // يعيد ترجمة الملفات المتأثرة فقط
```

- المترجم يحفظ dependency graph
- عند تغيير ملف: يُعاد ترجمة الملف + كل الملفات التي تستورده
- عند تغيير ملف `.عش`: يُعاد تحليل البناء

---

## ٣. أمثلة: بناء BeeOS كاملاً

```
// من جذر المشروع:
عش بناء --مساحة --إنتاج    // يبني كل المشاريع الفرعية
عش اختبار --مساحة           // يختبر كل شيء
عش صورة                      // ينشئ ISO
عش صورة --qemu              // يُشغّل على QEMU

// بناء مشروع فرعي فقط:
عش بناء -م نواة             // يبني النواة فقط
عش اختبار -م نظام_ملفات    // يختبر نظام الملفات فقط
```
