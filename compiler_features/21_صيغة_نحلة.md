# الميزة 21: صيغة الملف التنفيذي `.نحلة`

**بسم الله الرحمن الرحيم**

**الأولوية**: 🟠 عالية — المرحلة 2
**المرجع**: س120 من مواصفات BeeOS، المهمة T075
**التبعيات**: خلفية x86_64 (الميزة 04)

---

## ١. الوصف

BeeOS يستخدم صيغة ملف تنفيذي مخصصة `.نحلة` بدل ELF. الصيغة تحمل metadata عربية، معلومات القدرات (capabilities)، توقيع رقمي، ومعلومات ABI.

---

## ٢. المتطلبات

### ٢.١ هيكل ملف `.نحلة`

```
┌─────────────────────┐
│ رأس النحلة (64 بايت)│  ← Magic number + إصدار + metadata
├─────────────────────┤
│ جدول القدرات        │  ← capabilities مطلوبة
├─────────────────────┤
│ قسم الكود (.نص)     │  ← تعليمات الآلة
├─────────────────────┤
│ قسم البيانات (.بيانات)│  ← بيانات مُهيَّأة
├─────────────────────┤
│ قسم القراءة (.ثابت) │  ← ثوابت ونصوص
├─────────────────────┤
│ قسم التصحيح (اختياري)│  ← DWARF debug info
├─────────────────────┤
│ التوقيع الرقمي      │  ← Ed25519 signature
└─────────────────────┘
```

### ٢.٢ رأس النحلة

```
بنية رأس_نحلة 
    سحر: [بايت; 4],              # "نحل" بالعربية (UTF-8)
    إصدار_صيغة: ع16,
    المعمارية: ع16,               # x86_64 = 1, ARM64 = 2
    نقطة_الدخول: ع64,
    عدد_الأقسام: ع16,
    إصدار_ABI: ع32,              # عهد النحل (BeeABI)
    بصمة: [بايت; 32],            # BLAKE3 hash
    اسم: [بايت; 64],             # اسم البرنامج بالعربية
    مُطوِّر: [بايت; 64],          # معرّف BeeID
نهاية
```

### ٢.٣ جدول القدرات

```
# كل برنامج يُعلن ما يحتاجه
قدرات 
    شبكة: قراءة,               # يحتاج قراءة الشبكة
    ملفات: "مستنداتي/",         # يحتاج الوصول لمجلد واحد
    كاميرا: لا,                # لا يحتاج الكاميرا
نهاية
```
