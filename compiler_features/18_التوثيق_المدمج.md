# الميزة 18: توليد التوثيق من الشيفرة

**بسم الله الرحمن الرحيم**

**الأولوية**: 🟠 عالية — المرحلة 2
**المرجع**: س134، س204 من مواصفات BeeOS
**التبعيات**: لا تبعيات

---

## ١. الوصف

BeeOS يفرض توثيقاً إلزامياً — **المترجم يرفض ترجمة دالة عامة بدون `/// شرح`** (س204). أداة `وثّق` تُولّد HTML عربي تلقائياً من تعليقات التوثيق.

---

## ٢. المتطلبات

### ٢.١ تعليقات التوثيق

```
/// فتح ملف في نظام BeeFS
///
/// يفتح الملف المُحدد بالمسار ويُرجع واصف ملف.
/// يدعم المسارات العربية بالكامل (يونيكود NFC).
///
/// # المعاملات
/// - `مسار`: مسار الملف (مثال: "مستنداتي/رسالة.نص")
/// - `وضع`: وضع الفتح (قراءة، كتابة، إنشاء، إلحاق)
///
/// # القيمة المُرجعة
/// `نتيجة<واصف_ملف، خطأ>` — واصف الملف عند النجاح أو خطأ
///
/// # أمثلة
/// ```
/// دع واصف = افتح("سلام.نص"، قراءة)?
/// دع بيانات = اقرأ(واصف، 1024)?
/// أغلق(واصف)?
/// ```
///
/// # الأخطاء
/// - `لم_يُوجد`: الملف غير موجود
/// - `مرفوض`: صلاحيات غير كافية
دالة افتح(مسار: نص, وضع: وضع_ملف) → نتيجة<واصف_ملف, خطأ> {
    // ...
}
```

### ٢.٢ إنفاذ التوثيق

```
// ❌ خطأ ترجمة — دالة عامة بدون توثيق
عام دالة أنشئ_ملف(اسم: نص) → نتيجة<(), خطأ> { /* ... */ }
// خطأ: الدالة العامة `أنشئ_ملف` تفتقر لتعليق توثيق `///`

// ✅ مقبول — دالة خاصة بدون توثيق (تحذير فقط)
دالة دالة_داخلية() { /* ... */ }
```

### ٢.٣ أمر توليد التوثيق

```
ص وثّق                    // يولّد HTML في مجلد وثائق/
ص وثّق --افتح              // يولّد ويفتح في المتصفح
ص وثّق --فحص              // يتحقق فقط (لا يولّد) — مفيد للـ CI
```

## ٣. معايير القبول

- [ ] دعم `/// شرح` لتعليقات التوثيق
- [ ] المترجم يرفض دوال/بنيات عامة بدون توثيق (خطأ أو تحذير قابل للتهيئة)
- [ ] أداة `ص وثّق` تولّد HTML عربي (RTL)
- [ ] دعم أقسام: المعاملات، القيمة المُرجعة، أمثلة، أخطاء
- [ ] أمثلة الكود في التوثيق يُمكن اختبارها (`ص وثّق --اختبر`)
- [ ] دعم روابط بين عناصر التوثيق
