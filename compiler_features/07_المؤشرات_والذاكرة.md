# الميزة 07: المؤشرات وإدارة الذاكرة اليدوية

**بسم الله الرحمن الرحيم**

**المرجع**: س82 من مواصفات BeeOS، م-و-022، المهمة T014
**التبعيات**: نظام الملكية (الميزة 01)

## ١. الوصف

نظام التشغيل يحتاج **سيطرة مباشرة على الذاكرة** بمستوى لا تُوفره اللغات عالية المستوى عادةً. المترجم يجب أن يدعم المؤشرات الخام (raw pointers) وإدارة الذاكرة يدوياً لأن النواة هي التي **تُدير** الذاكرة — لا يوجد runtime تحتها يفعل ذلك.

### لماذا نحتاجها؟

- **جدول الصفحات**: يتطلب كتابة عناوين فيزيائية مباشرة في هياكل بيانات المعالج
- **تعريفات الأجهزة (MMIO)**: القراءة/الكتابة في عناوين ثابتة تتحكم بالأجهزة
- **DMA**: نقل بيانات مباشرة بين الذاكرة والأجهزة بعناوين فيزيائية
- **مُخصص الذاكرة**: النواة تبني مُخصص الذاكرة من الصفر — يحتاج مؤشرات خام
- **الإقلاع**: في أول مراحل الإقلاع لا يوجد حتى مُخصص ذاكرة

## ٢. المتطلبات التفصيلية

### ٢.١ أنواع المؤشرات

| النوع | الوصف | الاستخدام |
|-------|-------|----------|
| `*ثابت ن` | مؤشر خام للقراءة فقط | قراءة MMIO، جداول ثابتة |
| `*متغير ن` | مؤشر خام للقراءة والكتابة | كتابة MMIO، جدول الصفحات |
| `&ن` | مرجع مشترك (آمن) | الاستخدام العادي |
| `&متغير ن` | مرجع حصري (آمن) | الاستخدام العادي |

### ٢.٢ عمليات المؤشرات

```
// تحويل عدد إلى مؤشر (مطلوب لـ MMIO)
دع منفذ = 0x3F8 كـ *متغير بايت

// قراءة من مؤشر خام
خطر {
    دع قيمة = *منفذ
}

// كتابة في مؤشر خام
خطر {
    *منفذ = 0x41    // كتابة حرف 'A' في منفذ السلسلة
}

// حساب المؤشرات (pointer arithmetic)
خطر {
    دع العنصر_الثاني = مؤشر.أزح(1)     // المؤشر + حجم العنصر
    دع العنصر_العاشر = مؤشر.أزح(9)     // المؤشر + 9 × حجم العنصر
}

// تحويل بين أنواع المؤشرات (cast)
خطر {
    دع مؤشر_بايت = مؤشر_عدد كـ *ثابت بايت
}

// مؤشر فارغ (null)
دع فارغ: *ثابت عدد_طبيعي = مؤشر::فارغ()
```

### ٢.٣ التخصيص والتحرير اليدوي

```
// تخصيص ذاكرة خام (في النواة — المُخصص يُبنى من الصفر)
خطر {
    دع كتلة = خصّص_صفحة()             // صفحة 4096 بايت
    
    // استخدام الكتلة...
    
    حرّر_صفحة(كتلة)                    // تحرير يدوي
}
```

### ٢.٤ الوصول المتطاير (Volatile)

لـ MMIO والأجهزة، القراءة/الكتابة **لا يجوز** للمترجم تحسينها أو إزالتها:

```
// قراءة متطايرة — المترجم لا يحذفها حتى لو "لم تُستخدم"
خطر {
    دع حالة = اقرأ_متطاير(0xFEE00030 كـ *ثابت عدد_طبيعي_32)
}

// كتابة متطايرة — المترجم لا يؤجلها أو يُعيد ترتيبها
خطر {
    اكتب_متطاير(0xFEE00030 كـ *متغير عدد_طبيعي_32, 0x000000FF)
}
```

### ٢.٥ أنواع الأحجام الثابتة

لبرمجة الأنظمة يجب دعم أنواع بأحجام دقيقة:

| النوع | الحجم | الوصف |
|-------|-------|-------|
| `بايت` / `ع8` | 1 بايت | عدد طبيعي 8-bit |
| `ع16` | 2 بايت | عدد طبيعي 16-bit |
| `ع32` | 4 بايت | عدد طبيعي 32-bit |
| `ع64` | 8 بايت | عدد طبيعي 64-bit |
| `ع128` | 16 بايت | عدد طبيعي 128-bit |
| `ص8` / `ص16` / `ص32` / `ص64` | متغير | أعداد صحيحة بعلامة |
| `حم32` / `حم64` | 4/8 بايت | أعداد حقيقية IEEE 754 |
| `عنوان` | 8 بايت (64-bit) | حجم المؤشر |
| `منطقي` | 1 بايت | صح/خطأ |

### ٢.٦ التحكم في تخطيط الذاكرة

```
// تحديد محاذاة البنية
@محاذاة(16)
بنية سياق_المعالج {
    rax: ع64,
    rbx: ع64,
    // ...
}

// بنية مضغوطة (packed) — بلا حشو
@مضغوطة
بنية رأس_GDT {
    حد: ع16,
    قاعدة: ع64,
}

// تحديد حجم البنية يدوياً
@حجم(512)
بنية خلية_عسل {    // inode — يجب أن يكون 512 بايت بالضبط
    // ...
}
```

## ٣. أمثلة عملية من BeeOS

### ٣.١ جدول الصفحات (BeeCellMap)

```
// جدول صفحات x86_64 — يحتاج كتابة عناوين فيزيائية مباشرة
@محاذاة(4096)
بنية جدول_صفحات {
    مدخلات: [ع64; 512]     // 512 مدخلة × 8 بايت = 4096 بايت (صفحة كاملة)
}

خطر دالة خريطة(
    جدول: &متغير جدول_صفحات,
    عنوان_افتراضي: ع64,
    عنوان_فيزيائي: ع64,
    صلاحيات: ع64
) {
    دع فهرس = (عنوان_افتراضي >> 12) & 0x1FF
    جدول.مدخلات[فهرس] = عنوان_فيزيائي | صلاحيات | 1  // 1 = موجود
}
```

### ٣.٢ قراءة سجل جهاز (MMIO)

```
// سجلات متحكم المقاطعات APIC
ثابت عنوان_APIC: ع64 = 0xFEE00000

خطر دالة أرسل_EOI() {
    // كتابة 0 في سجل EOI تُنهي المقاطعة
    اكتب_متطاير((عنوان_APIC + 0xB0) كـ *متغير ع32, 0)
}
```

## ٤. معايير القبول

- [ ] دعم المؤشرات الخام `*ثابت ن` و `*متغير ن`
- [ ] تحويل أعداد إلى مؤشرات والعكس
- [ ] حساب المؤشرات (إزاحة)
- [ ] دعم القراءة/الكتابة المتطايرة (volatile)
- [ ] دعم أنواع بأحجام ثابتة (ع8..ع128, ص8..ص64)
- [ ] دعم `@محاذاة` و `@مضغوطة` و `@حجم` للبنيات
- [ ] فرض `خطر {}` لكل عمليات المؤشرات الخام
- [ ] دعم مؤشر فارغ (null) مع إمكانية فحصه
- [ ] دعم تحويل الأنواع بين المؤشرات (`كـ`)
- [ ] كل أنواع البيانات لها حجم معروف في وقت الترجمة

---

## ٥. ملاحظات تقنية

- المؤشرات الخام تعمل **خارج** نظام الملكية — لهذا تتطلب `خطر {}`
- المترجم يجب أن يُحذّر عند الاستخدام المفرط للمؤشرات الخام
- `اقرأ_متطاير` و `اكتب_متطاير` يجب أن تكون دوال مدمجة (intrinsics)
- يجب دعم `حجم_النوع<ن>()` و `محاذاة_النوع<ن>()` كدوال مدمجة
