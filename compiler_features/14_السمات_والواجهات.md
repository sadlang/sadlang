## ١. الوصف

السمات (Traits) هي آلية لتعريف سلوك مشترك بين أنواع مختلفة. BeeOS يحتاجها لتعريف واجهات موحدة لتعريفات الأجهزة، أنظمة الملفات، بروتوكولات الشبكة، وغيرها.

---

## ٢. المتطلبات التفصيلية

### ٢.١ تعريف سمة

```
سمة جهاز {
    دالة اسم(&ذات) → &نص
    دالة هيّئ(&متغير ذات) → نتيجة<(), خطأ>
    دالة اقرأ(&ذات, مخزن: &متغير [بايت]) → نتيجة<عدد_طبيعي, خطأ>
    دالة اكتب(&متغير ذات, بيانات: &[بايت]) → نتيجة<عدد_طبيعي, خطأ>
    
    // دالة افتراضية (اختيارية — يمكن إعادة تعريفها)
    دالة أعد_ضبط(&متغير ذات) → نتيجة<(), خطأ> {
        // تنفيذ افتراضي
        أعد نجاح(())
    }
}
```

### ٢.٢ تنفيذ سمة

```
بنية تخزين_NVMe { /* ... */ }

نفّذ جهاز لـ تخزين_NVMe {
    دالة اسم(&ذات) → &نص { أعد "NVMe" }
    دالة هيّئ(&متغير ذات) → نتيجة<(), خطأ> { /* ... */ }
    دالة اقرأ(&ذات, مخزن: &متغير [بايت]) → نتيجة<عدد_طبيعي, خطأ> { /* ... */ }
    دالة اكتب(&متغير ذات, بيانات: &[بايت]) → نتيجة<عدد_طبيعي, خطأ> { /* ... */ }
}
```

### ٢.٣ سمات كقيود للأنواع المعممة

```
دالة شغّل_جهاز<ج: جهاز>(جهاز: &متغير ج) → نتيجة<(), خطأ> {
    جهاز.هيّئ()?
    // الآن يمكن استخدام كل دوال سمة `جهاز`
}
```

### ٢.٤ كائنات السمة (Trait Objects) — إرسال ديناميكي

```
// عندما لا نعرف النوع في وقت الترجمة
دالة سجّل_جهاز(جهاز: &ديناميكي جهاز) {
    اطبع("تم تسجيل: {}", جهاز.اسم())
}
```

### ٢.٥ سمات مدمجة مطلوبة

| السمة | الوصف | الاستخدام |
|-------|-------|----------|
| `نسخ` (Copy) | قابل للنسخ الثنائي | أنواع بسيطة (أعداد) |
| `استنساخ` (Clone) | قابل للنسخ العميق | بنيات معقدة |
| `إسقاط` (Drop) | دالة تنظيف عند التحرير | موارد النظام |
| `عرض` (Display) | قابل للطباعة | كل شيء |
| `تصحيح` (Debug) | عرض تصحيحي | تطوير |
| `مُرسَل` (Send) | آمن للإرسال بين خيوط | تزامن |
| `مُشارَك` (Sync) | آمن للمشاركة بين خيوط | تزامن |
| `حجم_ثابت` (Sized) | حجم معروف في وقت الترجمة | النواة |
