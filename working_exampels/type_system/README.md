# نظام الأنواع المتقدم في لغة ص - شرح موسّع
# Advanced Type System in Sad Language (لغة ص)

## مقدمة

نظام الأنواع المتقدم هو أحد أهم مكونات لغة ص. يوفر هذا النظام:

### 1. الأنواع الأساسية (Primitive Types)
| النوع العربي | المعنى | الأنواع الداخلية |
|---|---|---|
| `رقم` | عدد صحيح | ح8, ح16, ح32, ح64 (صحيح) |
| `عشري` | عدد عشري | عش32, عش64 |
| `نص` | سلسلة نصية | String (UTF-8) |
| `منطقي` | قيمة منطقية | صح / خطأ |
| `متغير` | نوع مستنتج تلقائياً | يُحدد عند التهيئة |

### 2. استنتاج الأنواع (Type Inference - Hindley-Milner)
النظام يستنتج أنواع المتغيرات تلقائياً عند التهيئة:
```
متغير س = 10        # مستنتج: رقم
متغير ع = 3.14      # مستنتج: عشري
متغير اسم = "أحمد"  # مستنتج: نص
متغير علم = صح      # مستنتج: منطقي
```

### 3. فحص التوافق (Type Compatibility)
- الأنواع المتطابقة: `رقم` مع `رقم`
- التوافق الرقمي: `رقم` مع `عشري` (تحويل ضمني)
- نوع `Any`: يتوافق مع كل الأنواع
- نوع `Never`: نوع فرعي من كل الأنواع

### 4. فحص الأنواع في التعابير
#### العمليات الحسابية
- `+`, `-`, `*`, `/` تتطلب معاملات رقمية
- `+` على النصوص = دمج نصوص
- `/` دائماً ينتج `عشري`

#### عمليات المقارنة
- `>`, `<`, `>=`, `<=`, `==`, `!=` تنتج `منطقي`

#### العمليات المنطقية
- `و`, `أو`, `ليس` تتطلب `منطقي` وتنتج `منطقي`

### 5. فحص أنواع الدوال
- التحقق من أنواع المعاملات عند الاستدعاء
- التحقق من نوع القيمة المرجعة
- تسجيل أنواع المعاملات في نطاق الدالة
- دعم الدوال المتداخلة والتداخل

### 6. إدارة النطاقات (Scope Management)
- نطاق عام (Global Scope) - يحتوي الدوال المدمجة
- نطاق الدالة (Function Scope) - يرث النطاق العام
- نطاقات متداخلة - كل `إذا`, `بينما`, `كتلة` تنشئ نطاقاً فرعياً
- البحث التسلسلي: يبحث في النطاق الحالي ثم الأب حتى النطاق العام

### 7. الأنواع المتقدمة (مخطط مستقبلي)
#### المعممات (Generics)
```
دالة هوية<ن>(س: ن) -> ن
    ارجع س
نهاية
```

#### السمات (Traits)
```
سمة قابل_للعرض
    دالة نص عرض()
نهاية
```

#### البنى (Structs)
```
بنية نقطة
    رقم س
    رقم ص
نهاية
```

#### الاتحادات (Union Types)
```
نوع نتيجة = رقم | نص | خطأ
```

### 8. أوضاع الفحص
- **الوضع العادي** (`--type-check`): يكشف أخطاء الأنواع الأساسية
- **الوضع الصارم** (`--strict-types`): يفرض أن الشروط منطقية + يكشف المتغيرات غير المعرفة
- **وضع التنقيح** (`--debug-types`): يعرض تفاصيل كل نوع مستنتج

### 9. رسائل الأخطاء
جميع الأخطاء تُعرض بالعربية والإنجليزية:
```
❌ خطأ نوع في 'س': عدم تطابق الأنواع: متوقع 'رقم' لكن وُجد 'نص'
❌ Type error in 'x': Type mismatch: expected 'Integer' but got 'String'
```

### 10. الاستخدام
```bash
# المفسر مع فحص الأنواع
sad.exe --type-check ملف.sad
sad.exe --فحص-أنواع ملف.sad

# المترجم مع فحص الأنواع
sadc.exe --type-check ملف.sad
sadc.exe --فحص-الأنواع ملف.sad

# الوضع الصارم
sad.exe --strict-types ملف.sad
sad.exe --أنواع-صارمة ملف.sad

# وضع التنقيح
sad.exe --debug-types ملف.sad
sad.exe --تنقيح-أنواع ملف.sad
```
