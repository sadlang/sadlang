# الدوال المدعومة في المترجم Sad Compiler

## ✅ الدوال المضمّنة المدعومة (13 دالة)

### 1. دوال الإدخال والإخراج (I/O)
- **اطبع / print** - طباعة بدون سطر جديد
- **اطبع_سطر / println** - طباعة مع سطر جديد
- **اقرأ / input** - قراءة من المستخدم

### 2. دوال تحويل الأنواع (Type Conversion)
- **لرقم / to_int** - تحويل إلى رقم صحيح
- **لعشري / to_float** - تحويل إلى رقم عشري
- **لنص / to_string** - تحويل إلى نص

### 3. دوال رياضية أساسية (Basic Math)
- **جذر / sqrt** - الجذر التربيعي
- **أس / power / pow** - رفع للأس (x^y)
- **مطلق / abs** - القيمة المطلقة
- **تقريب / round** - تقريب لأقرب عدد صحيح
- **أرضية / floor** - التقريب للأسفل
- **سقف / ceil** - التقريب للأعلى

### 4. دوال رياضية متقدمة (Advanced Math)
- **مربع / square** - تربيع العدد (x²)
- **جيب / sin** - جيب الزاوية (sine)
- **جيب_تمام / cos** - جيب تمام الزاوية (cosine)
- **ظل / tan** - ظل الزاوية (tangent)

### 5. دوال أخرى
- **طول / length** - طول المصفوفة أو النص

## 📊 ملخص الإحصائيات

- **إجمالي الدوال المدعومة**: 17 دالة
- **دوال I/O**: 3
- **دوال تحويل الأنواع**: 3
- **دوال رياضية**: 10
- **دوال أخرى**: 1

## 🎯 أمثلة الاستخدام

### مثال 1: الدوال الرياضية الأساسية
```sad
دالة رئيسية()
    اطبع_سطر("جذر(16.0) = ")
    اطبع(جذر(16.0))  // النتيجة: 4.0
    
    اطبع("أس(2.0, 3.0) = ")
    اطبع(أس(2.0, 3.0))  // النتيجة: 8.0
    
    اطبع("تقريب(3.7) = ")
    اطبع(تقريب(3.7))  // النتيجة: 4
نهاية
```

### مثال 2: الدوال المثلثية
```sad
دالة رئيسية()
    متغير زاوية = 0.785398  // 45 درجة بالراديان
    
    اطبع("جيب(45°) = ")
    اطبع(جيب(زاوية))  // النتيجة: ~0.707
    
    اطبع("جيب_تمام(45°) = ")
    اطبع(جيب_تمام(زاوية))  // النتيجة: ~0.707
    
    اطبع("ظل(45°) = ")
    اطبع(ظل(زاوية))  // النتيجة: ~1.0
نهاية
```
