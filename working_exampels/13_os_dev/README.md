# 📦 أمثلة برمجة أنظمة التشغيل بلغة ص

## 🔧 نظرة عامة

هذا المجلد يحتوي على أمثلة لبرمجة أنظمة التشغيل باستخدام لغة ص (Sad Language).
تدعم لغة ص عمليات منخفضة المستوى تتيح كتابة أنوية أنظمة تشغيل وبرامج مضمنة.

## 📁 الملفات

| الملف | الوصف |
|-------|-------|
| `01_منافذ_IO.sad` | عمليات قراءة/كتابة المنافذ (outb/inb) |
| `02_شاشة_VGA.sad` | الكتابة المباشرة على شاشة VGA النصية |
| `03_مقاطعات.sad` | المقاطعات والتحكم بالمعالج (cli/sti/hlt/int) |
| `04_ذاكرة_مباشرة.sad` | إدارة الذاكرة المباشرة (peek/poke/memcpy/memset) |
| `05_نواة_بسيطة.sad` | نواة نظام تشغيل بسيطة تجمع كل المفاهيم |

## 🚀 التشغيل

### وضع المفسر (محاكاة)
```bash
# تشغيل في المفسر — يحاكي العمليات ويطبع رسائل تشخيصية
sad.exe 05_نواة_بسيطة.sad
```

### وضع المترجم (كود حقيقي)
```bash
# ترجمة إلى LLVM IR
sadc.exe --emit-llvm 05_نواة_بسيطة.sad -o kernel.ll

# ترجمة إلى ملف كائن
sadc.exe --emit-obj 05_نواة_بسيطة.sad -o kernel.o

# ترجمة إلى ملف تجميع
sadc.exe --emit-asm 05_نواة_بسيطة.sad -o kernel.asm
```

## 📚 الدوال المتاحة

### عمليات المنافذ
| الدالة بالعربية | الدالة بالإنجليزية | الوصف |
|----------------|-------------------|-------|
| `منفذ_اكتب(منفذ, قيمة)` | `outb(port, value)` | كتابة بايت إلى منفذ |
| `منفذ_اقرأ(منفذ)` | `inb(port)` | قراءة بايت من منفذ |

### عمليات الذاكرة
| الدالة بالعربية | الدالة بالإنجليزية | الوصف |
|----------------|-------------------|-------|
| `ذاكرة_اكتب(عنوان, قيمة)` | `poke(addr, value)` | كتابة بايت في عنوان |
| `ذاكرة_اقرأ(عنوان)` | `peek(addr)` | قراءة بايت من عنوان |
| `انسخ_ذاكرة(وجهة, مصدر, حجم)` | `memcpy(dest, src, n)` | نسخ كتلة ذاكرة |
| `املأ_ذاكرة(وجهة, قيمة, حجم)` | `memset(dest, val, n)` | ملء كتلة ذاكرة |

### المقاطعات والمعالج
| الدالة بالعربية | الدالة بالإنجليزية | الوصف |
|----------------|-------------------|-------|
| `مقاطعة(رقم)` | `interrupt(n)` | استدعاء مقاطعة برمجية |
| `توقف()` | `halt()` / `hlt()` | إيقاف المعالج |
| `تعطيل_مقاطعات()` | `cli()` | تعطيل المقاطعات |
| `تفعيل_مقاطعات()` | `sti()` | تفعيل المقاطعات |

### شاشة VGA
| الدالة بالعربية | الدالة بالإنجليزية | الوصف |
|----------------|-------------------|-------|
| `شاشة_اكتب(صف, عمود, حرف, لون)` | `vga_write(row, col, ch, color)` | كتابة حرف على الشاشة |
| `شاشة_امسح(لون)` | `vga_clear(color)` | مسح الشاشة |

## 🎨 ألوان VGA
```
0x00 = أسود       0x08 = رمادي غامق
0x01 = أزرق       0x09 = أزرق فاتح
0x02 = أخضر       0x0A = أخضر فاتح
0x03 = سماوي      0x0B = سماوي فاتح
0x04 = أحمر       0x0C = أحمر فاتح
0x05 = بنفسجي     0x0D = وردي
0x06 = بني        0x0E = أصفر
0x07 = رمادي فاتح 0x0F = أبيض

اللون = (خلفية × 16) + أمامية
مثال: 0x1E = أصفر على أزرق
```
