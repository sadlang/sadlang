## 🏗️ البنية المعمارية

### مسار التجميع (Pipeline):
```
ملف .sad → LexerCore → ParserCore → SIRBuilder → SIRModule → LLVMCodeGen → LLVM IR → Clang → .exe
```

### الملفات المعدّلة:

| الملف | الغرض |
|-------|-------|
| `compiler_new/include/frontend/sir_types.h` | إضافة 14 رمز عملية (opcode) للأمان |

| `tools/compiler/compiler_driver.cpp` | إضافة دوال الأمان للمكتبة المضمنة |

## 📋 قائمة الدوال المدعومة (14 دالة)

### 1. تأكد / assert
- **الاسم العربي:** `تأكد(شرط)`
- **الاسم الإنجليزي:** `assert(condition)`
- **الوصف:** يُوقف البرنامج إذا كان الشرط خاطئاً (false)
- **نوع الإرجاع:** فارغ (void)
- **دالة وقت التشغيل:** `sad_security_assert(i1, ptr)`
- **الحالة:** ✅ يعمل

### 2. تحقق / verify
- **الاسم العربي:** `تحقق(شرط)`
- **الاسم الإنجليزي:** `verify(condition)`
- **الوصف:** يُرجع صحيح أو خطأ بدون إيقاف البرنامج
- **نوع الإرجاع:** منطقي (bool)
- **التنفيذ:** مضمّن في LLVM IR (بدون استدعاء خارجي)
- **الحالة:** ✅ يعمل

### 3. آمن / is_safe
- **الاسم العربي:** `آمن(قيمة)`
- **الاسم الإنجليزي:** `is_safe(value)`
- **الوصف:** يتحقق أن القيمة غير فارغة وآمنة
- **نوع الإرجاع:** منطقي (bool)
- **التنفيذ:** مضمّن في LLVM IR
- **الحالة:** ✅ يعمل

### 4. ذعر / panic
- **الاسم العربي:** `ذعر(رسالة)`
- **الاسم الإنجليزي:** `panic(message)`
- **الوصف:** إيقاف طارئ مع رسالة خطأ
- **نوع الإرجاع:** فارغ (void)
- **دالة وقت التشغيل:** `sad_security_panic(ptr)`
- **الحالة:** ✅ يعمل

### 5. هاش / hash
- **الاسم العربي:** `هاش(نص)`
- **الاسم الإنجليزي:** `hash(text)`
- **الوصف:** حساب بصمة FNV-1a للنص
- **نوع الإرجاع:** عدد صحيح (i64)
- **دالة وقت التشغيل:** `sad_security_hash(ptr)`
- **الحالة:** ✅ يعمل

### 6. شفّر / encrypt
- **الاسم العربي:** `شفّر(نص، مفتاح)`
- **الاسم الإنجليزي:** `encrypt(text, key)`
- **الوصف:** تشفير XOR — يُرجع نص مشفر بصيغة hex
- **نوع الإرجاع:** نص (string)
- **دالة وقت التشغيل:** `sad_security_encrypt(ptr, ptr)`
- **الحالة:** ✅ يعمل

### 7. فك_تشفير / decrypt
- **الاسم العربي:** `فك_تشفير(نص_مشفر، مفتاح)`
- **الاسم الإنجليزي:** `decrypt(encrypted, key)`
- **الوصف:** فك تشفير XOR — يُعيد النص الأصلي
- **نوع الإرجاع:** نص (string)
- **دالة وقت التشغيل:** `sad_security_decrypt(ptr, ptr)`
- **الحالة:** ✅ يعمل

### 8. تأكد_نوع / assert_type
- **الاسم العربي:** `تأكد_نوع(متوقع، فعلي)`
- **الاسم الإنجليزي:** `assert_type(expected, actual)`
- **الوصف:** يتحقق أن النوع المتوقع يطابق الفعلي
- **نوع الإرجاع:** فارغ (void)
- **دالة وقت التشغيل:** `sad_security_assert_type(ptr, ptr)`
- **الحالة:** ✅ يعمل

### 9. تأكد_مساواة / assert_equal
- **الاسم العربي:** `تأكد_مساواة(قيمة1، قيمة2)`
- **الاسم الإنجليزي:** `assert_equal(a, b)`
- **الوصف:** يتحقق من تساوي قيمتين
- **نوع الإرجاع:** فارغ (void)
- **دالة وقت التشغيل:** `sad_security_assert_equal_str(ptr, ptr)`
- **الحالة:** ✅ يعمل

### 10. تأكد_أكبر / assert_greater
- **الاسم العربي:** `تأكد_أكبر(قيمة1، قيمة2)`
- **الاسم الإنجليزي:** `assert_greater(a, b)`
- **الوصف:** يتحقق أن القيمة الأولى أكبر من الثانية
- **نوع الإرجاع:** فارغ (void)
- **التنفيذ:** مقارنة LLVM IR مع assert
- **الحالة:** ✅ يعمل

### 11. نظّف / sanitize
- **الاسم العربي:** `نظّف(نص)`
- **الاسم الإنجليزي:** `sanitize(text)`
- **الوصف:** ترميز HTML entities لمنع هجمات XSS
- **نوع الإرجاع:** نص (string)
- **دالة وقت التشغيل:** `sad_security_sanitize(ptr)`
- **التحويلات:** `<` → `&lt;`, `>` → `&gt;`, `&` → `&amp;`, `"` → `&quot;`, `'` → `&#39;`
- **الحالة:** ✅ يعمل

### 12. وقت_الآن / timestamp
- **الاسم العربي:** `وقت_الآن()`
- **الاسم الإنجليزي:** `timestamp()`
- **الوصف:** يُرجع الطابع الزمني الحالي (Unix timestamp)
- **نوع الإرجاع:** عدد صحيح (i64)
- **دالة وقت التشغيل:** `sad_security_timestamp()`
- **الحالة:** ✅ يعمل

### 13. عشوائي_آمن / secure_random
- **الاسم العربي:** `عشوائي_آمن(حد_أدنى، حد_أقصى)`
- **الاسم الإنجليزي:** `secure_random(min, max)`
- **الوصف:** يُولّد عدد عشوائي في نطاق محدد
- **نوع الإرجاع:** عدد صحيح (i64)
- **دالة وقت التشغيل:** `sad_security_secure_random(i64, i64)`
- **الحالة:** ✅ يعمل

### 14. ترميز_64 / base64_encode
- **الاسم العربي:** `ترميز_64(نص)`
- **الاسم الإنجليزي:** `base64_encode(text)`
- **الوصف:** ترميز النص بصيغة Base64
- **نوع الإرجاع:** نص (string)
- **دالة وقت التشغيل:** `sad_security_base64_encode(ptr)`
- **الحالة:** ✅ يعمل
