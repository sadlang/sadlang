## 🚀 كيفية الاستخدام / How to Use

### تشغيل مثال / Run an Example

```bash
# في المفسر / In Interpreter
sad.exe example.sad

# في المترجم / In Compiler
sadc.exe example.sad --emit-llvm
```

```sad
// جميع الدوال متاحة مباشرة
```

### مثال 1: معالج نصوص / Text Processor

```sad
دالة رئيسية()
    متغير نص = "  Hello WORLD  "

    اطبع(نص)
    اطبع_سطر("]")

    اطبع_سطر("]")
    
    اطبع("صغير: ")
    اطبع_سطر(تحويل_صغير(قص_أطراف(نص)))

```

```sad
    اطبع("مربع 12 = ")
    اطبع_سطر(مربع(12))
```
