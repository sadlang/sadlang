   - البناء في Release mode أسرع وأكثر تحسيناً

2. **المكتبة القياسية:**
   - استخدام `Value` type من Sad::Data namespace
   - دعم الأسماء المتعددة (عربي/إنجليزي) مهم
   - التعامل مع الأخطاء بـ std::invalid_argument و std::domain_error

3. **الاختبار:**
   - ملفات الاختبار البسيطة أفضل من المعقدة
