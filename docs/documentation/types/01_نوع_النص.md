# 📝 نوع النص (String Type)

## 📖 شرح عن النوع

**النص (String)** هو نوع بيانات يُستخدم لتخزين سلاسل من الأحرف، الكلمات، والجمل. النصوص في لغة ص هي **غير قابلة للتعديل (Immutable)**، أي أن أي عملية تعديل تُنشئ نصاً جديداً.

### الخصائص الرئيسية:
- ✅ تدعم اللغة العربية والإنجليزية
- ✅ يمكن استخدام علامات التنصيص المفردة `'` أو المزدوجة `"`
- ✅ تدعم الأحرف الخاصة والرموز
- ✅ قابلة للفهرسة والتقطيع (Indexing & Slicing)
- ✅ غير قابلة للتعديل المباشر

---

## 🔧 كيفية تعريف النوع

### التعريف الأساسي
```s
نص الاسم = "أحمد"
نص الرسالة = 'مرحباً بك'
متغير النص = "يمكن استخدام متغير أيضاً"
```

### النصوص متعددة الأسطر
```s
نص الرسالة = "هذا نص
متعدد
الأسطر"
```

### النصوص الفارغة
```s
نص فارغ = ""
نص فارغ2 = ''
```

### دمج النصوص
```s
نص الاسم_الأول = "محمد"
نص الاسم_الثاني = "أحمد"
نص الاسم_الكامل = الاسم_الأول + " " + الاسم_الثاني  # "محمد أحمد"
```

---

## 📐 قاعدة BNF

```bnf
<string-declaration> ::= "نص" <identifier> "=" <string-literal>
                       | "متغير" <identifier> "=" <string-literal>

<string-literal>     ::= '"' <string-chars> '"'
                       | "'" <string-chars> "'"

<string-chars>       ::= <char>*

<char>               ::= <arabic-char>
                       | <english-char>
                       | <digit>
                       | <special-char>
                       | <escape-sequence>

<escape-sequence>    ::= "\n" | "\t" | "\r" | "\\" | "\"" | "\'"

<arabic-char>        ::= [أ-ي] | [ا-ى] | [٠-٩]
<english-char>       ::= [a-z] | [A-Z]
<digit>              ::= [0-9]
<special-char>       ::= " " | "!" | "@" | "#" | "." | "," | ...
```

## 💡 كيفية استعمال النوع

### الوصول للأحرف بالفهرس
```s
نص الكلمة = "مرحبا"
متغير الحرف_الأول = الكلمة[0]      # "م"
متغير الحرف_الأخير = الكلمة[-1]    # "ا"
```

### التقطيع (Slicing)
```s
نص النص = "لغة البرمجة ص"
متغير الجزء = النص[0:3]             # "لغة"
متغير من_البداية = النص[:5]        # "لغة ا"
متغير للنهاية = النص[5:]            # "لبرمجة ص"
```

### التكرار
```s
نص الرمز = "-"
نص الخط = الرمز * 20                # "--------------------"
```

### التحقق من وجود نص فرعي
```s
نص الجملة = "لغة البرمجة ص سهلة"
إذا "البرمجة" في الجملة إذن
    اطبع_سطر("النص موجود")
نهاية
```

## 📚 المكتبات المضمنة

### 1️⃣ دوال التحويل والأساسيات

| الدالة | الوصف | المدخلات | المخرجات |
|-------|-------|----------|----------|
| `طول(نص)` | حساب طول النص | نص | عدد صحيح |
| `حول_لنص(قيمة)` | تحويل أي قيمة إلى نص | أي نوع | نص |
| `نوع(متغير)` | معرفة نوع المتغير | أي نوع | نص |

### 2️⃣ دوال البحث والاستبدال

| الدالة | الوصف | المدخلات | المخرجات |
|-------|-------|----------|----------|
| `نص.ابحث(نص_فرعي)` | البحث عن نص فرعي | نص | عدد صحيح (الموقع) |
| `نص.استبدل(قديم، جديد)` | استبدال نص | نصين | نص |
| `نص.يبدأ_بـ(بادئة)` | التحقق من البادئة | نص | منطقي |
| `نص.ينتهي_بـ(لاحقة)` | التحقق من اللاحقة | نص | منطقي |
| `نص.احسب(نص_فرعي)` | عدد مرات التكرار | نص | عدد صحيح |

### 3️⃣ دوال التحويل لحالة الأحرف

| الدالة | الوصف | المدخلات | المخرجات |
|-------|-------|----------|----------|
| `نص.كبير()` | تحويل لأحرف كبيرة | لا شيء | نص |
| `نص.صغير()` | تحويل لأحرف صغيرة | لا شيء | نص |
| `نص.عنوان()` | أول حرف كبير | لا شيء | نص |

### 4️⃣ دوال التقطيع والتجزئة

| الدالة | الوصف | المدخلات | المخرجات |
|-------|-------|----------|----------|
| `نص.قسّم(فاصل)` | تقسيم النص | نص | قائمة |
| `نص.قسّم_أسطر()` | تقسيم حسب الأسطر | لا شيء | قائمة |
| `فاصل.ادمج(قائمة)` | دمج قائمة بفاصل | قائمة | نص |

### 5️⃣ دوال التنظيف والتنسيق

| الدالة | الوصف | المدخلات | المخرجات |
|-------|-------|----------|----------|
| `نص.احذف_مسافات()` | حذف المسافات من الطرفين | لا شيء | نص |
| `نص.احذف_مسافات_يسار()` | حذف المسافات من اليسار | لا شيء | نص |
| `نص.احذف_مسافات_يمين()` | حذف المسافات من اليمين | لا شيء | نص |
| `نص.املأ_يسار(عرض، حرف)` | إضافة حشو لليسار | عددين | نص |
| `نص.املأ_يمين(عرض، حرف)` | إضافة حشو لليمين | عددين | نص |
| `نص.وسّط(عرض)` | توسيط النص | عدد | نص |

### 6️⃣ دوال التحقق والفحص

| الدالة | الوصف | المدخلات | المخرجات |
|-------|-------|----------|----------|
| `نص.أرقام()` | التحقق من كون النص أرقام | لا شيء | منطقي |
| `نص.أحرف()` | التحقق من كون النص أحرف | لا شيء | منطقي |
| `نص.أحرف_أرقام()` | التحقق من أحرف وأرقام | لا شيء | منطقي |
| `نص.مسافات()` | التحقق من المسافات فقط | لا شيء | منطقي |

### المثال 2: نظام تنسيق الأسماء

```s
# برنامج لتنسيق وتحليل الأسماء

دالة نسّق_اسم(اسم)
    # إزالة المسافات الزائدة
    نص اسم_نظيف = اسم.احذف_مسافات()
    
    # تقسيم الاسم
    متغير أجزاء = اسم_نظيف.قسّم(" ")
    متغير أجزاء_منسقة = []
    
    # تنسيق كل جزء
    لكل جزء في أجزاء افعل
        إذا طول(جزء) > 0 إذن
            # أول حرف كبير والبقية صغيرة (للإنجليزية)
            متغير جزء_منسق = جزء.عنوان()
            أجزاء_منسقة.أضف(جزء_منسق)
        نهاية
    نهاية
    
    # دمج الأجزاء
    ارجع " ".ادمج(أجزاء_منسقة)
نهاية

دالة حلل_اسم(اسم)
    نص اسم_منسق = نسّق_اسم(اسم)
    متغير أجزاء = اسم_منسق.قسّم(" ")
    متغير عدد_الأجزاء = طول(أجزاء)
    
    متغير معلومات = {
        "الاسم_الكامل": اسم_منسق،
        "عدد_الأجزاء": عدد_الأجزاء،
        "الاسم_الأول": لاشيء،
        "اسم_الأب": لاشيء،
        "اسم_العائلة": لاشيء،
        "عدد_الأحرف": طول(اسم_منسق.استبدل(" "، ""))
    }
    
    إذا عدد_الأجزاء >= 1 إذن
        معلومات["الاسم_الأول"] = أجزاء[0]
    نهاية
    
    إذا عدد_الأجزاء >= 2 إذن
        معلومات["اسم_الأب"] = أجزاء[1]
    نهاية
    
    إذا عدد_الأجزاء >= 3 إذن
        معلومات["اسم_العائلة"] = أجزاء[عدد_الأجزاء - 1]
    نهاية
    
    ارجع معلومات
نهاية

دالة اطبع_معلومات_اسم(معلومات)
    اطبع_سطر("┌─────────────────────────────────┐")
    اطبع_سطر("│      معلومات الاسم             │")
    اطبع_سطر("└─────────────────────────────────┘")
    اطبع_سطر("")
    اطبع_سطر("👤 الاسم الكامل: " + معلومات["الاسم_الكامل"])
    اطبع_سطر("📊 عدد الأجزاء: " + حول_لنص(معلومات["عدد_الأجزاء"]))
    اطبع_سطر("🔤 عدد الأحرف: " + حول_لنص(معلومات["عدد_الأحرف"]))
    اطبع_سطر("")
    
    إذا معلومات["الاسم_الأول"] != لاشيء إذن
        اطبع_سطر("   الاسم الأول: " + معلومات["الاسم_الأول"])
    نهاية
    
    إذا معلومات["اسم_الأب"] != لاشيء إذن
        اطبع_سطر("   اسم الأب: " + معلومات["اسم_الأب"])
    نهاية
    
    إذا معلومات["اسم_العائلة"] != لاشيء إذن
        اطبع_سطر("   اسم العائلة: " + معلومات["اسم_العائلة"])
    نهاية
    
    اطبع_سطر("")
```

### المثال 3: مولد رموز QR نصية (ASCII Art)

```s
# برنامج لإنشاء رموز ASCII من النصوص

دالة أنشئ_صندوق_نص(نص، عرض)
    # حساب المسافات المطلوبة
    متغير طول_النص = طول(نص)
    متغير مسافة_يسار = (عرض - طول_النص) / 2
    متغير مسافة_يمين = عرض - طول_النص - مسافة_يسار
    
    # بناء الصندوق
    نص خط_أفقي = "─" * عرض
    نص نص_ممركز = (" " * مسافة_يسار) + نص + (" " * مسافة_يمين)
    
    متغير صندوق = "┌" + خط_أفقي + "┐\n"
    صندوق = صندوق + "│" + نص_ممركز + "│\n"
    صندوق = صندوق + "└" + خط_أفقي + "┘"
    
    ارجع صندوق
نهاية

دالة نص_لباركود(نص)
    نص باركود = "║"
    
    لكل حرف في نص افعل
        # تحويل الحرف لرمز
        متغير كود = رمز_حرف(حرف) % 4
        
        إذا كود == 0 إذن
            باركود = باركود + "█"
        وإلا_إذا كود == 1 إذن
            باركود = باركود + "▓"
        وإلا_إذا كود == 2 إذن
            باركود = باركود + "▒"
        وإلا
            باركود = باركود + "░"
        نهاية
    نهاية
    
    باركود = باركود + "║"
    ارجع باركود
نهاية

دالة رمز_حرف(حرف)
    # محاكاة دالة ord() - تحويل حرف لكود ASCII
    # في التطبيق الفعلي، ستكون دالة مضمنة
    ارجع طول(حرف) * 42  # قيمة تقريبية للمثال
نهاية

# البرنامج الرئيسي
نص العنوان = "مولد الباركود"
متغير عرض = 40

اطبع_سطر("")
اطبع_سطر(أنشئ_صندوق_نص(العنوان، عرض))
اطبع_سطر("")

متغير نصوص = [
    "لغة ص"،
    "Programming"،
    "2025"
]

لكل نص_مدخل في نصوص افعل
    اطبع_سطر("📝 النص: " + نص_مدخل)
    اطبع_سطر("")
    
    # عنوان الباركود
    متغير خط_فاصل = "═" * (طول(نص_مدخل) + 2)
    اطبع_سطر("╔" + خط_فاصل + "╗")
    
    # الباركود
    نص باركود = نص_لباركود(نص_مدخل)
    اطبع_سطر(باركود)
    
    # قاعدة الباركود
    اطبع_سطر("╚" + خط_فاصل + "╝")
    
    # النص أسفل الباركود
    متغير نص_ممركز = نص_مدخل.وسّط(طول(نص_مدخل) + 4)
    اطبع_سطر(نص_ممركز)
    اطبع_سطر("")
    اطبع_سطر("─" * 45)
    اطبع_سطر("")
نهاية

# إحصائيات
اطبع_سطر("📊 الإحصائيات:")
متغير مجموع_أحرف = 0
لكل نص في نصوص افعل
    مجموع_أحرف = مجموع_أحرف + طول(نص)
نهاية
اطبع_سطر("   عدد النصوص: " + حول_لنص(طول(نصوص)))
اطبع_سطر("   مجموع الأحرف: " + حول_لنص(مجموع_أحرف))
```

## 🎓 ملاحظات مهمة

### 1. النصوص غير قابلة للتعديل
```s
نص الكلمة = "مرحبا"
# الكلمة[0] = "أ"  # ❌ خطأ - لا يمكن التعديل المباشر

# ✅ الطريقة الصحيحة
نص جديد = "أ" + الكلمة[1:]
```

### 2. دعم Unicode
```s
نص نص_عربي = "مرحباً 🌟"
نص نص_صيني = "你好"
نص نص_إيموجي = "😊🎉✨"
# جميعها مدعومة
```

### 3. الأداء
- دمج النصوص باستخدام `+` بطيء للنصوص الكبيرة
- استخدم `قائمة.ادمج()` للأداء الأفضل

```s
# ❌ بطيء
نص نتيجة = ""
لكل عنصر في قائمة افعل
    نتيجة = نتيجة + عنصر
نهاية

# ✅ سريع
نص نتيجة = "".ادمج(قائمة)
```
