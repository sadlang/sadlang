# ✅ نوع المنطقي (Boolean Type)

## 📖 شرح عن النوع

**المنطقي (Boolean)** هو نوع بيانات يحمل إحدى قيمتين فقط: **صح (True)** أو **خطأ (False)**. يُستخدم في الشروط، الحلقات، والمقارنات المنطقية.

### الخصائص الرئيسية:
- ✅ قيمتان فقط: صح أو خطأ
- ✅ ناتج عمليات المقارنة
- ✅ يُستخدم في الشروط والحلقات
- ✅ يمكن التحويل من/إلى أنواع أخرى
- ✅ يدعم العمليات المنطقية (و، أو، ليس)

---

## 🔧 كيفية تعريف النوع

### التعريف المباشر
```s
منطقي صحيح = صح
منطقي خاطئ = خطأ
متغير نشط = صح
```

### من عمليات المقارنة
```s
عدد العمر = 20
منطقي بالغ = العمر >= 18        # صح
منطقي قاصر = العمر < 18         # خطأ
```

### من التحويل
```s
# من الأعداد
منطقي من_صفر = حول_لمنطقي(0)          # خطأ
منطقي من_واحد = حول_لمنطقي(1)          # صح
منطقي من_أي_عدد = حول_لمنطقي(42)      # صح

# من النصوص
منطقي من_نص_فارغ = حول_لمنطقي("")     # خطأ
منطقي من_نص = حول_لمنطقي("مرحبا")      # صح

# من القوائم
منطقي من_قائمة_فارغة = حول_لمنطقي([]) # خطأ
منطقي من_قائمة = حول_لمنطقي([1، 2])    # صح
```

## 📐 قاعدة BNF

```bnf
<boolean-declaration> ::= "منطقي" <identifier> "=" <boolean-literal>
                        | "متغير" <identifier> "=" <boolean-literal>
                        | "متغير" <identifier> "=" <boolean-expression>

<boolean-literal>     ::= "صح" | "خطأ"
                        | "True" | "False"

<boolean-expression>  ::= <comparison-expression>
                        | <logical-expression>
                        | <function-call>

<comparison-expression> ::= <value> <comparison-op> <value>

<comparison-op>       ::= "==" | "!=" | "<" | ">" | "<=" | ">="

<logical-expression>  ::= <boolean> "و" <boolean>
                        | <boolean> "أو" <boolean>
                        | "ليس" <boolean>
```

## 💡 كيفية استعمال النوع

### في الشروط
```s
منطقي مسجل_دخول = صح

إذا مسجل_دخول إذن
    اطبع_سطر("مرحباً بعودتك!")
وإلا
    اطبع_سطر("الرجاء تسجيل الدخول")
نهاية
```

### في الحلقات
```s
منطقي مستمر = صح
عدد عداد = 0

بينما مستمر افعل
    عداد = عداد + 1
    اطبع_سطر(عداد)
    
    إذا عداد >= 5 إذن
        مستمر = خطأ
    نهاية
نهاية
```

### العمليات المنطقية
```s
منطقي أ = صح
منطقي ب = خطأ

# و (AND)
منطقي نتيجة_و = أ و ب          # خطأ

# أو (OR)
منطقي نتيجة_أو = أ أو ب        # صح

# ليس (NOT)
منطقي نتيجة_ليس = ليس أ       # خطأ
```

## 📚 المكتبات المضمنة

### 1️⃣ دوال التحويل

| الدالة | الوصف | المدخلات | المخرجات |
|-------|-------|----------|----------|
| `حول_لمنطقي(قيمة)` | تحويل لمنطقي | أي نوع | منطقي |
| `حول_لنص(منطقي)` | تحويل لنص | منطقي | نص |
| `حول_لعدد(منطقي)` | تحويل لعدد | منطقي | عدد (0 أو 1) |

### 2️⃣ عمليات المقارنة

| العملية | الرمز | الوصف | المثال | النتيجة |
|---------|------|-------|---------|----------|
| يساوي | `==` | المساواة | `5 == 5` | صح |
| لا يساوي | `!=` | عدم المساواة | `5 != 3` | صح |
| أصغر من | `<` | المقارنة | `3 < 5` | صح |
| أكبر من | `>` | المقارنة | `5 > 3` | صح |
| أصغر أو يساوي | `<=` | المقارنة | `5 <= 5` | صح |
| أكبر أو يساوي | `>=` | المقارنة | `5 >= 3` | صح |

### 3️⃣ عمليات منطقية

| العملية | الرمز | الوصف | جدول الصدق |
|---------|------|-------|------------|
| و | `و` | AND | صح و صح = صح<br>صح و خطأ = خطأ<br>خطأ و صح = خطأ<br>خطأ و خطأ = خطأ |
| أو | `أو` | OR | صح أو صح = صح<br>صح أو خطأ = صح<br>خطأ أو صح = صح<br>خطأ أو خطأ = خطأ |
| ليس | `ليس` | NOT | ليس صح = خطأ<br>ليس خطأ = صح |

### 4️⃣ دوال التحقق

| الدالة | الوصف | المدخلات | المخرجات |
|-------|-------|----------|----------|
| `نوع(متغير) == "منطقي"` | التحقق من النوع | أي نوع | منطقي |
| `الكل(قائمة)` | كل العناصر صح؟ | قائمة | منطقي |
| `أي(قائمة)` | أي عنصر صح؟ | قائمة | منطقي |

## 🎓 ملاحظات مهمة

### 1. القيم الصادقة والكاذبة (Truthy & Falsy)
```s
# قيم تُعتبر خطأ عند التحويل
متغير كاذبة = [خطأ، 0، 0.0، ""، []، {}، لاشيء]

# قيم تُعتبر صح عند التحويل
متغير صادقة = [صح، 1، -1، "نص"، [1]، {"مفتاح": "قيمة"}]
```

### 2. الأسبقية في العمليات المنطقية
```s
# ليس > و > أو
منطقي نتيجة = صح أو خطأ و خطأ
# يُنفذ كـ: صح أو (خطأ و خطأ) = صح

# استخدم الأقواس للوضوح
منطقي نتيجة_واضحة = (صح أو خطأ) و خطأ  # خطأ
```

### 3. التقييم الكسول (Short-circuit)
```s
# و: إذا كان الأول خطأ، لا يُقيّم الثاني
منطقي نتيجة = خطأ و دالة_معقدة()  # دالة_معقدة() لن تُنفذ

# أو: إذا كان الأول صح، لا يُقيّم الثاني
منطقي نتيجة = صح أو دالة_معقدة()   # دالة_معقدة() لن تُنفذ
```
