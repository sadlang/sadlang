# ⚪ نوع لاشيء (Null/None Type)

## 📖 شرح عن النوع

**لاشيء (Null/None)** هو نوع بيانات خاص يُمثّل **غياب القيمة** أو **القيمة الفارغة**. يُستخدم للإشارة إلى أن متغيراً لم يُعيّن له قيمة بعد، أو أن دالة لم ترجع أي قيمة.

### الخصائص الرئيسية:
- ✅ يمثل غياب القيمة
- ✅ قيمة واحدة فقط: `لاشيء`
- ✅ يُستخدم كقيمة افتراضية
- ✅ يُعتبر `خطأ` في السياق المنطقي
- ✅ يُستخدم للتحقق من وجود القيم

---

## 🔧 كيفية تعريف النوع

### التعريف المباشر
```s
متغير قيمة = لاشيء
متغير نتيجة = لاشيء
```

### من دالة بدون `ارجع`
```s
دالة دالة_بدون_قيمة()
    اطبع_سطر("مرحباً")
    # لا يوجد ارجع
نهاية

متغير نتيجة = دالة_بدون_قيمة()  # نتيجة = لاشيء
```

### من قاموس بدون مفتاح
```s
متغير قاموس = {"أ": 1، "ب": 2}
متغير قيمة = قاموس.احصل("ج")  # قيمة = لاشيء
```

## 📐 قاعدة BNF

```bnf
<none-declaration>  ::= "متغير" <identifier> "=" "لاشيء"

<none-literal>      ::= "لاشيء"
                      | "None"
                      | "null"
                      | "Null"
```

## 💡 كيفية استعمال النوع

### التحقق من `لاشيء`
```s
متغير قيمة = لاشيء

# الطريقة الصحيحة
إذا قيمة == لاشيء إذن
    اطبع_سطر("القيمة فارغة")
نهاية

# أو باستخدام is
إذا قيمة هو لاشيء إذن
    اطبع_سطر("القيمة فارغة")
نهاية
```

### استخدام كقيمة افتراضية
```s
دالة احسب(أ، ب، عملية)
    إذا عملية == لاشيء إذن
        عملية = "جمع"  # القيمة الافتراضية
    نهاية
    
    إذا عملية == "جمع" إذن
        ارجع أ + ب
    وإلا_إذا عملية == "طرح" إذن
        ارجع أ - ب
    نهاية
نهاية

متغير نتيجة1 = احسب(5، 3، لاشيء)  # يستخدم "جمع"
متغير نتيجة2 = احسب(5، 3، "طرح")    # يستخدم "طرح"
```

### التعامل مع القيم الاختيارية
```s
دالة معلومات_مستخدم(اسم، عمر، بريد)
    اطبع_سطر("الاسم: " + اسم)
    اطبع_سطر("العمر: " + حول_لنص(عمر))
    
    إذا بريد != لاشيء إذن
        اطبع_سطر("البريد: " + بريد)
    وإلا
        اطبع_سطر("البريد: غير متوفر")
    نهاية
نهاية

معلومات_مستخدم("أحمد"، 25، "ahmed@email.com")
معلومات_مستخدم("فاطمة"، 22، لاشيء)
```

## 📚 المكتبات المضمنة

### 1️⃣ دوال التحقق

| الدالة | الوصف | المثال | النتيجة |
|-------|-------|---------|----------|
| `== لاشيء` | التحقق من المساواة | `س == لاشيء` | `صح/خطأ` |
| `!= لاشيء` | التحقق من عدم المساواة | `س != لاشيء` | `صح/خطأ` |
| `هو لاشيء` | التحقق بالهوية | `س هو لاشيء` | `صح/خطأ` |
| `ليس لاشيء` | عكس التحقق | `س ليس لاشيء` | `صح/خطأ` |

### 2️⃣ دوال التحويل

| الدالة | الوصف | المثال | النتيجة |
|-------|-------|---------|----------|
| `حول_لنص(لاشيء)` | تحويل لنص | `حول_لنص(لاشيء)` | `"لاشيء"` |
| `حول_لمنطقي(لاشيء)` | تحويل لمنطقي | `حول_لمنطقي(لاشيء)` | `خطأ` |
| `نوع(لاشيء)` | معرفة النوع | `نوع(لاشيء)` | `"لاشيء"` |

## 🎓 ملاحظات مهمة

### 1. `لاشيء` ليس نفسه الصفر أو النص الفارغ
```s
متغير أ = لاشيء
متغير ب = 0
متغير ج = ""

اطبع_سطر(أ == ب)  # خطأ
اطبع_سطر(أ == ج)  # خطأ
اطبع_سطر(ب == ج)  # خطأ
```

### 2. `لاشيء` في السياق المنطقي
```s
إذا لاشيء إذن
    # لن ينفذ - لاشيء = خطأ منطقياً
نهاية

إذا ليس لاشيء إذن
    # سينفذ - ليس لاشيء = صح
نهاية
```

### 3. استخدم `==` أو `هو` للتحقق
```s
متغير قيمة = لاشيء

# كلاهما صحيح
إذا قيمة == لاشيء إذن
    # ...
نهاية

إذا قيمة هو لاشيء إذن
    # ...
نهاية
```

### 4. تجنب العمليات على `لاشيء`
```s
متغير س = لاشيء

# ❌ يسبب خطأ
# متغير نتيجة = س + 5
# متغير نص = س.كبير()

# ✅ تحقق أولاً
إذا س != لاشيء إذن
    متغير نتيجة = س + 5
نهاية
```
