# 📊 نوع العدد العشري (Float Type)

## 📖 شرح عن النوع

**العدد العشري (Float)** هو نوع بيانات يُستخدم لتخزين الأعداد ذات الفاصلة العشرية (الأعداد الحقيقية). يستخدم هذا النوع لتمثيل القيم التي تتطلب دقة عشرية مثل الأسعار، القياسات، والحسابات العلمية.

### الخصائص الرئيسية:
- ✅ يدعم الأعداد الموجبة والسالبة
- ✅ دقة عالية (64-bit double precision)
- ✅ يدعم الترميز العلمي (Scientific Notation)
- ✅ يدعم القيم الخاصة: Infinity، -Infinity، NaN
- ✅ عمليات رياضية متقدمة

---

## 🔧 كيفية تعريف النوع

### التعريف الأساسي
```s
عشري السعر = 49.99
متغير الطول = 1.75
عشري الحرارة = -15.5
```

### الترميز العلمي
```s
عشري كبير_جداً = 1.5e10        # 15000000000
عشري صغير_جداً = 3.2e-5        # 0.000032
عشري سرعة_الضوء = 3.0e8       # 300000000 م/ث
```

### من الأعداد الصحيحة
```s
عدد صحيح = 42
عشري عشري = حول_لعدد_عشري(صحيح)  # 42.0
```

### من النصوص
```s
نص نص_عدد = "3.14159"
عشري باي = حول_لعدد_عشري(نص_عدد)
```

## 📐 قاعدة BNF

```bnf
<float-declaration> ::= "عشري" <identifier> "=" <float-literal>
                      | "متغير" <identifier> "=" <float-literal>

<float-literal>     ::= <decimal-float>
                      | <scientific-float>

<decimal-float>     ::= ["-"] <digit>+ "." <digit>*
                      | ["-"] <digit>* "." <digit>+

<scientific-float>  ::= <decimal-float> <exponent>
                      | ["-"] <digit>+ <exponent>

<exponent>          ::= ("e" | "E") ["+"|"-"] <digit>+

<digit>             ::= "0" | "1" | ... | "9"
```

## 💡 كيفية استعمال النوع

### العمليات الحسابية
```s
عشري أ = 10.5
عشري ب = 3.2

متغير الجمع = أ + ب       # 13.7
متغير الطرح = أ - ب       # 7.3
متغير الضرب = أ * ب       # 33.6

```

```s

عشري ص = 0.3

# ❌ غير دقيق
إذا س == ص إذن
    # قد لا ينفذ بسبب دقة الفاصلة العائمة
نهاية

# ✅ الطريقة الصحيحة
عشري فرق = مطلق(س - ص)
```

## 📚 المكتبات المضمنة

### 1️⃣ دوال التحويل

| الدالة | الوصف | المدخلات | المخرجات |
|-------|-------|----------|----------|
| `حول_لعدد_عشري(قيمة)` | تحويل لعدد عشري | أي نوع | عدد عشري |
| `حول_لعدد(عدد_عشري)` | تحويل لعدد صحيح | عدد عشري | عدد صحيح |
| `حول_لنص(عدد_عشري)` | تحويل لنص | عدد عشري | نص |

### 2️⃣ دوال التقريب

| الدالة | الوصف | المدخلات | المخرجات |
|-------|-------|----------|----------|
| `قرّب(عدد، منازل)` | تقريب لعدد منازل | عدد، عدد صحيح | عدد عشري |
| `أرضية(عدد)` | التقريب للأسفل | عدد عشري | عدد صحيح |
| `سقف(عدد)` | التقريب للأعلى | عدد عشري | عدد صحيح |
| `قطع(عدد)` | إزالة الجزء العشري | عدد عشري | عدد صحيح |

### 3️⃣ دوال رياضية

| الدالة | الوصف | المدخلات | المخرجات |
|-------|-------|----------|----------|
| `مطلق(عدد)` | القيمة المطلقة | عدد عشري | عدد عشري |
| `جذر_تربيعي(عدد)` | الجذر التربيعي | عدد عشري | عدد عشري |
| `قوة(أساس، أس)` | رفع لأس | عددان | عدد عشري |
| `أس(عدد)` | e^x | عدد عشري | عدد عشري |
| `لوغاريتم(عدد)` | ln(x) | عدد عشري | عدد عشري |
| `لوغاريتم_10(عدد)` | log10(x) | عدد عشري | عدد عشري |

### 4️⃣ دوال مثلثية

| الدالة | الوصف | المدخلات | المخرجات |
|-------|-------|----------|----------|
| `جا(زاوية)` | sin(x) | راديان | عدد عشري |
| `جتا(زاوية)` | cos(x) | راديان | عدد عشري |
| `ظا(زاوية)` | tan(x) | راديان | عدد عشري |
| `قوس_جا(قيمة)` | arcsin(x) | عدد عشري | راديان |
| `قوس_جتا(قيمة)` | arccos(x) | عدد عشري | راديان |
| `قوس_ظا(قيمة)` | arctan(x) | عدد عشري | راديان |

### 5️⃣ دوال التحقق

| الدالة | الوصف | المدخلات | المخرجات |
|-------|-------|----------|----------|
| `محدود(عدد)` | هل العدد محدود؟ | عدد عشري | منطقي |
| `لا_نهائي(عدد)` | هل العدد لا نهائي؟ | عدد عشري | منطقي |
| `ليس_عدد(قيمة)` | هل القيمة NaN؟ | عدد عشري | منطقي |

### 6️⃣ ثوابت رياضية

| الثابت | القيمة | الوصف |
|-------|--------|-------|
| `باي` | 3.14159265359... | π (pi) |
| `ثابت_أويلر` | 2.71828182846... | e (euler) |
| `النسبة_الذهبية` | 1.61803398875... | φ (phi) |

### المثال 3: محلل البيانات الإحصائية

```s
# محلل بيانات إحصائي

دالة المتوسط_الحسابي(قائمة)
    عشري مجموع = 0.0
    لكل عدد في قائمة افعل
        مجموع = مجموع + حول_لعدد_عشري(عدد)
    نهاية
    ارجع مجموع / حول_لعدد_عشري(طول(قائمة))
نهاية

دالة الانحراف_المعياري(قائمة)
    عشري متوسط = المتوسط_الحسابي(قائمة)
    عشري مجموع_مربعات = 0.0
    
    لكل عدد في قائمة افعل
        عشري فرق = حول_لعدد_عشري(عدد) - متوسط
        مجموع_مربعات = مجموع_مربعات + (فرق ** 2)
    نهاية
    
    عشري تباين = مجموع_مربعات / حول_لعدد_عشري(طول(قائمة))
    ارجع جذر_تربيعي(تباين)
نهاية

دالة الوسيط(قائمة)
    # ترتيب القائمة
    متغير مرتبة = رتّب(قائمة)
    عدد الطول = طول(مرتبة)
    
    إذا الطول % 2 == 1 إذن
        # عدد فردي من العناصر
        ارجع حول_لعدد_عشري(مرتبة[الطول / 2])
    وإلا
        # عدد زوجي من العناصر
        عدد وسط1 = مرتبة[الطول / 2 - 1]
        عدد وسط2 = مرتبة[الطول / 2]
        ارجع (حول_لعدد_عشري(وسط1) + حول_لعدد_عشري(وسط2)) / 2.0
    نهاية
نهاية

دالة رتّب(قائمة)
    # فرز بسيط (Bubble Sort)
    متغير نسخة = []
    لكل عنصر في قائمة افعل
        نسخة.أضف(عنصر)
    نهاية
    
    عدد ن = طول(نسخة)
    متغير ع = 0
    بينما ع < ن - 1 افعل
        متغير س = 0
        بينما س < ن - ع - 1 افعل
            إذا نسخة[س] > نسخة[س + 1] إذن
                # تبديل
                متغير مؤقت = نسخة[س]
                نسخة[س] = نسخة[س + 1]
                نسخة[س + 1] = مؤقت
            نهاية
            س = س + 1
        نهاية
        ع = ع + 1
    نهاية
    
    ارجع نسخة
نهاية

اطبع_سطر("─" * 60)

عشري المتوسط = المتوسط_الحسابي(درجات)
عشري الوسيط_قيمة = الوسيط(درجات)
عشري الانحراف = الانحراف_المعياري(درجات)

متغير مرتبة = رتّب(درجات)
عشري أصغر = حول_لعدد_عشري(مرتبة[0])
عشري أكبر = حول_لعدد_عشري(مرتبة[طول(مرتبة) - 1])
عشري المدى = أكبر - أصغر

اطبع_سطر("   المتوسط الحسابي: " + نسّق_عدد_عشري(المتوسط، 2))
اطبع_سطر("   الوسيط: " + نسّق_عدد_عشري(الوسيط_قيمة، 2))
اطبع_سطر("   الانحراف المعياري: " + نسّق_عدد_عشري(الانحراف، 2))
اطبع_سطر("   أصغر قيمة: " + نسّق_عدد_عشري(أصغر، 2))
اطبع_سطر("   أكبر قيمة: " + نسّق_عدد_عشري(أكبر، 2))
اطبع_سطر("   المدى: " + نسّق_عدد_عشري(المدى، 2))

اطبع_سطر("")
اطبع_سطر("═" * 60)
```

## 🎓 ملاحظات مهمة

### 1. دقة الفاصلة العائمة
```s
# ⚠️ مشكلة الدقة
عشري نتيجة = 0.1 + 0.2
اطبع_سطر(نتيجة)  # 0.30000000000000004 وليس 0.3

# ✅ الحل: استخدام التقريب
عشري نتيجة_مقربة = قرّب(نتيجة، 10)
```

### 2. المقارنة الآمنة
```s
# ❌ غير موثوق
إذا 0.1 + 0.2 == 0.3 إذن

# ✅ موثوق
عشري فرق = مطلق((0.1 + 0.2) - 0.3)
إذا فرق < 1e-10 إذن
```

### 3. القيم الخاصة
```s
عشري موجب_لا_نهائي = 1.0 / 0.0
عشري سالب_لا_نهائي = -1.0 / 0.0
عشري ليس_عدد = 0.0 / 0.0

اطبع_سطر(لا_نهائي(موجب_لا_نهائي))  # صح
اطبع_سطر(ليس_عدد(ليس_عدد))           # صح
```
