# 📖 نوع القاموس (Dictionary Type)

## 📖 شرح عن النوع

**القاموس (Dictionary)** هو نوع بيانات مُركّب يُخزّن البيانات على شكل أزواج **مفتاح-قيمة (Key-Value Pairs)**. القواميس في لغة ص **قابلة للتعديل** و**غير مرتبة** (في الإصدارات الحديثة تحفظ ترتيب الإدخال).

### الخصائص الرئيسية:
- ✅ أزواج مفتاح-قيمة
- ✅ المفاتيح فريدة (لا تتكرر)
- ✅ الوصول السريع بالمفتاح O(1)
- ✅ قابل للتعديل
- ✅ يدعم أنواع بيانات مختلفة للقيم

---

## 🔧 كيفية تعريف النوع

### قاموس فارغ
```s
متغير قاموس_فارغ = {}
```

### قاموس بعناصر
```s
متغير طالب = {
    "الاسم": "أحمد"،
    "العمر": 20،
    "التخصص": "علوم حاسب"
}
```

### قواميس متداخلة
```s
متغير بيانات = {
    "الشخصية": {
        "الاسم": "محمد"،
        "العمر": 25
    }،
    "الاتصال": {
        "البريد": "m@example.com"،
        "الهاتف": "0501234567"
    }
}
```

---

## 📐 قاعدة BNF

```bnf
<dict-declaration>   ::= "متغير" <identifier> "=" <dict-literal>

<dict-literal>       ::= "{" <key-value-list>? "}"

<key-value-list>     ::= <key-value-pair>
                       | <key-value-pair> "،" <key-value-list>

<key-value-pair>     ::= <string-literal> ":" <expression>
                       | <identifier> ":" <expression>

<expression>         ::= <value> | <list-literal> | <dict-literal>
```

## 💡 كيفية استعمال النوع

### الوصول للقيم
```s
متغير طالب = {
    "الاسم": "أحمد"،
    "العمر": 20،
    "التخصص": "هندسة"
}

نص الاسم = طالب["الاسم"]          # "أحمد"
عدد العمر = طالب["العمر"]          # 20
```

### الإضافة والتعديل
```s
متغير بيانات = {"المدينة": "الرياض"}

# إضافة عنصر جديد
بيانات["الدولة"] = "السعودية"

# تعديل عنصر موجود
بيانات["المدينة"] = "جدة"
```

### الحذف
```s
متغير قاموس = {"أ": 1، "ب": 2، "ج": 3}

احذف قاموس["ب"]                  # حذف المفتاح "ب"
```

## 📚 المكتبات المضمنة

### 1️⃣ دوال الوصول والتعديل

| الدالة | الوصف | المثال | النتيجة |
|-------|-------|---------|----------|
| `قاموس[مفتاح]` | الوصول للقيمة | `{"أ": 1}["أ"]` | `1` |
| `قاموس[مفتاح] = قيمة` | تعيين قيمة | `د["أ"] = 2` | يحدث القيمة |
| `قاموس.احصل(مفتاح)` | الوصول الآمن | `د.احصل("س")` | `لاشيء` |
| `قاموس.احصل(مفتاح، افتراضي)` | مع قيمة افتراضية | `د.احصل("س"، 0)` | `0` |

### 2️⃣ دوال الإضافة والحذف

| الدالة | الوصف | المثال |
|-------|-------|---------|
| `قاموس.أضف(مفتاح، قيمة)` | إضافة عنصر | `د.أضف("س"، 5)` |
| `قاموس.احذف(مفتاح)` | حذف عنصر | `د.احذف("س")` |
| `قاموس.امسح()` | حذف كل العناصر | `د.امسح()` |
| `قاموس.انزع(مفتاح)` | حذف وإرجاع القيمة | `د.انزع("س")` |

### 3️⃣ دوال الحصول على المحتوى

| الدالة | الوصف | النتيجة |
|-------|-------|----------|
| `قاموس.المفاتيح()` | قائمة المفاتيح | `["أ"، "ب"، "ج"]` |
| `قاموس.القيم()` | قائمة القيم | `[1، 2، 3]` |
| `قاموس.العناصر()` | أزواج مفتاح-قيمة | `[("أ"، 1)، ("ب"، 2)]` |

### 4️⃣ دوال التحقق والمعلومات

| الدالة | الوصف | المثال | النتيجة |
|-------|-------|---------|----------|
| `مفتاح في قاموس` | هل المفتاح موجود؟ | `"أ" في {"أ": 1}` | `صح` |
| `طول(قاموس)` | عدد العناصر | `طول({"أ": 1})` | `1` |

### 5️⃣ دوال الدمج والنسخ

| الدالة | الوصف | المثال |
|-------|-------|---------|
| `قاموس.نسخ()` | نسخ سطحية | `د2 = د1.نسخ()` |
| `قاموس.حدّث(قاموس_آخر)` | دمج قاموسين | `د1.حدّث(د2)` |

### المثال 2: نظام المخزون

```s
# نظام إدارة المخزون

            حول_لنص(منتج["السعر"]).املأ_يسار(8، " ") + " │ " +
            حول_لنص(قيمة).املأ_يسار(9، " ") + " │ " +
            منتج["الفئة"].املأ_يمين(10، " ")
        )
    نهاية
    
    اطبع_سطر("───────┴────────────────────┴─────────┴──────────┴───────────┴──────────")

    اطبع_سطر("")
نهاية

    نهاية
    
    اطبع_سطر("")
نهاية
```

```s
متغير قاموس = {"أ": 1، "أ": 2}
```

```s
متغير قاموس = {"أ": 1}

# متغير قيمة = قاموس["ب"]

متغير قيمة = قاموس.احصل("ب"، 0)  # يعيد 0
```

```s
متغير بيانات = {
```
