## 💡 Design Decisions

### 1. **Stack-Based vs Register-Based**
**Decision**: Stack-based with register hints  
**Rationale**:
- Simpler to implement
- More compact bytecode
- Easier to optimize later
- Register hints allow future optimization

### 2. **Variable-Length Instructions**
**Decision**: Variable-length (1-25 bytes)  
**Rationale**:
- More compact than fixed-length
- Flexible for different operand sizes
- Common operations are shortest

### 3. **Opcode Organization**
**Decision**: Grouped by function (0x00-0xFF)  
**Rationale**:
- Easy to remember
- Clear categories
- Room for expansion
- Logical grouping
