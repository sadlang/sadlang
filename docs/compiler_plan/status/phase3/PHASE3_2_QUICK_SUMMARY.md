## Translation Examples | أمثلة الترجمة

### Arithmetic
```sir
%3 = ADD %1, %2
```
↓
```bytecode
GET_LOCAL 1    ; 5 bytes
GET_LOCAL 2    ; 5 bytes
ADD            ; 1 byte
SET_LOCAL 3    ; 5 bytes
```
Total: 16 bytes

### Conditional Jump
```sir
BR %cond, .label
```
↓
```bytecode
GET_LOCAL cond ; 5 bytes
JMP_IF +offset ; 5 bytes (1 + 4)
```
Total: 10 bytes (offset patched later)

### Function Call
```sir
%ret = CALL func, %arg1, %arg2
```
↓
```bytecode
GET_LOCAL arg1    ; 5 bytes
GET_LOCAL arg2    ; 5 bytes
CALL func_idx 2   ; 6 bytes (1 + 4 + 1)
SET_LOCAL ret     ; 5 bytes
```
Total: 21 bytes

## Architecture | البنية

```
SIR Module → BytecodeEmitter → BytecodeModule
                  ↓
         [Translation Pipeline]
                  ↓
    ┌─────────────────────────┐
    │ 1. Register Globals     │
    │ 2. Translate Functions  │
    │    ├─ Register Params   │
    │    ├─ Emit Blocks       │
    │    │   ├─ Define Label  │
    │    │   └─ Emit Insts    │
    │    └─ Save Metadata     │
    │ 3. Resolve Labels       │
    │ 4. Optimize (optional)  │
    └─────────────────────────┘
                  ↓
    Executable Bytecode (.sbc)
```
