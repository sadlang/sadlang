## 📚 كتب أساسية / Essential Books

### Compiler Design

**1. Dragon Book**
- **Title:** Compilers: Principles, Techniques, and Tools (2nd Edition)
- **Authors:** Alfred V. Aho, Monica S. Lam, Ravi Sethi, Jeffrey D. Ullman
- **Year:** 2006
- **Topics:** Lexical analysis, Parsing, Semantic analysis, Code generation
- **Link:** https://www.amazon.com/Compilers-Principles-Techniques-Tools-2nd/dp/0321486811

**2. Engineering a Compiler**
- **Authors:** Keith D. Cooper, Linda Torczon
- **Year:** 2011
- **Topics:** Modern optimization techniques, Register allocation
- **Link:** https://www.elsevier.com/books/engineering-a-compiler/cooper/978-0-12-088478-0

**3. Modern Compiler Implementation in C**
- **Author:** Andrew W. Appel
- **Year:** 1998
- **Topics:** Tiger language compiler, Functional programming concepts
- **Link:** https://www.cs.princeton.edu/~appel/modern/

**4. Advanced Compiler Design and Implementation**
- **Author:** Steven Muchnick
- **Year:** 1997
- **Topics:** Advanced optimizations, SSA form
- **Link:** https://www.amazon.com/Advanced-Compiler-Design-Implementation-Muchnick/dp/1558603204

## 📌 Quick Reference Card

```
Compiler Pipeline:
Source → Lexer → Parser → AST → Type Check → SIR → Optimize → Backend

LLVM Pipeline:
SIR → LLVM IR → Optimization Passes → Machine Code → Object File

Bytecode Pipeline:
SIR → Bytecode → VM Execution

Testing:
Unit Tests → Integration Tests → E2E Tests → Benchmarks
```
