الميزة الأكثر تأثيراً لتجاوز C++ فعلياً
ثلاث ميزات إذا اجتمعت تجعل sad أسرع من C++ نمطي:

Monomorphization كاملة + Const-generics → كود متخصص بدون vtable indirection
Noalias افتراضي للمراجع المملوكة (مثل Rust) → optimizer يفترض عدم تعرّج → vectorization أكثر
SIMD types مدمجة → كتابة كود متجه بدون intrinsics يدوية
C++ يدفع ضريبة pointer aliasing و templates ضخمة و intrinsics غير محمولة. sad يستطيع تجاوزها بحكم النظام الملكي.
