## 🚀 بداية سريعة

```sad
# أول برنامج بلغة ص
اطبع_سطر("مرحباً بالعالم!")
```

### تشغيل بالمفسر:
```powershell
sad.exe برنامجي.ص
```

### ترجمة وتشغيل:
```powershell
sadc.exe برنامجي.ص -o برنامجي.exe
.\برنامجي.exe
```
