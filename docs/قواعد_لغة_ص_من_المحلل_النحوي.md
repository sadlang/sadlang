## 1. بنية البرنامج

```bnf
program         → declaration* EOF

declaration     → directive_stmt              # @ توجيهات
                 | decorator_decl             # @مزخرف (قبل دوال/أصناف فقط)
                 | import_stmt
                 | from_import_stmt
                 | export_decl
                 | extern_func_decl
                 | function_decl              # يشمل: دالة غير_متزامن
                 | generator_func_decl        # مولد دالة
                 | template_decl
                 | namespace_decl
                 | abstract_class_decl        # صنف مجرد / صنف مجرد محكم
                 | sealed_class_decl          # صنف محكم / صنف محكم مجرد
                 | class_decl
                 | trait_decl
                 | impl_decl
                 | extension_decl
                 | macro_decl
                 | type_alias_decl
                 | contract_decl
                 | struct_decl
                 | enum_decl
                 | test_decl
                 | switch_stmt                # حالة (كلمة سياقية)
                 | var_decl
                 | statement
```

**المصدر:** `parser_core_main.cpp` — دالة `parseDeclaration()`

### ملاحظات:
- البرنامج يُحلل حتى نهاية الملف (EOF)
- يوجد حماية ضد الحلقات اللانهائية (3 محاولات كحد أقصى في نفس الموضع)
- يُسمح بوجود دالة رئيسية واحدة فقط (`رئيسية`)
- المُزخرِفات (`@`) تُطبّق فقط قبل الدوال والأصناف

## 2. التصريحات

### 2.1 تصريح الدوال

```bnf
function_decl   → decorator* 'دالة' [return_type] IDENTIFIER
                  [lifetime_params] '(' [param_list] ')'
                  [contract_clause*]
                  [where_clause]
                  block

decorator       → '@' expression

return_type     → type_token                          # يوضع قبل اسم الدالة فقط

param_list      → parameter (',' | '،' parameter)*
parameter       → [type] IDENTIFIER ['=' expression]  # النوع اختياري
                 | '...' IDENTIFIER                    # معاملات متغيرة (variadic)

lifetime_params → '<' LIFETIME (',' LIFETIME)* '>'    # مثال: <'أ, 'ب>

contract_clause → 'يتطلب' expression [';' | '؛']     # شرط مسبق
                 | 'يضمن' expression [';' | '؛']      # شرط لاحق

where_clause    → 'حيث' constraint (',' constraint)*
constraint      → IDENTIFIER ':' trait_name ('+' trait_name)*
```

**المصدر:** `parser_declarations.cpp` — دالة `parseFunctionDecl()`

#### صيغ خاصة:

```bnf
# الدالة الرئيسية
main_func       → 'دالة' ['رقم'] 'رئيسية' '(' [main_params] ')' block
main_params     → 'نص' '[]' IDENTIFIER              # معامل واحد فقط: نص[]

# الدالة غير المتزامنة (الصفة بعد الموصوف)
async_func      → 'دالة' 'غير_متزامن' IDENTIFIER '(' params ')' block

# دالة المولد (المضاف قبل المضاف إليه)
generator_func  → 'مولد' 'دالة' IDENTIFIER '(' params ')' block

# الدالة الخارجية (FFI)
extern_func     → 'خارجي' ['(' STRING ')'] 'دالة' [type] IDENTIFIER '(' params ')'
```

**ملاحظات مهمة:**
- نوع الإرجاع يوضع **قبل** اسم الدالة فقط: `دالة رقم جمع()`
- استخدام `:` أو `->` أو `ترجع` بعد المعاملات يُنتج خطأ
- `غير_متزامن دالة` (الصفة قبل الموصوف) أُزيلت — يجب استخدام `دالة غير_متزامن`
- `دالة مولد` أُزيلت — يجب استخدام `مولد دالة`
- أسماء المتغيرات يمكن أن تكون كلمات أنواع (`رقم`، `نص`) أو كلمات مفتاحية ناعمة
- المنقوطة اختيارية (`؛` أو `;`)

---

### 2.2 تصريح المتغيرات والثوابت

```bnf
var_decl        → 'متغير' IDENTIFIER ['=' expression] [';']
                 | 'ثابت' IDENTIFIER '=' expression [';']
                 | type IDENTIFIER ['=' expression] [';']            # تصريح بنوع صريح
                 | IDENTIFIER IDENTIFIER ['=' expression] [';']       # تصريح بنوع صنف
```

**المصدر:** `parser_core_main.cpp` — أنماط `KEYWORD_VAR`, `KEYWORD_CONST`, `isTypeToken()`

#### أنماط التصريح المدعومة:
- `متغير س = 10` — تصريح بكلمة `متغير`
- `ثابت ط = 3.14` — ثابت لا يتغير
- `رقم عدد = 42` — تصريح بنوع صريح
- `شخص موظف = جديد شخص()` — تصريح بنوع صنف مخصص
- `متغير` اختياري: يمكن كتابة `رقم س = 5` مباشرة

### 2.3 تصريح الأصناف

> **⚠️ قاعدة الصفة بعد الموصوف:** في لغة ص، المعدّلات (`عام`/`خاص`/`محمي`/`ساكن`/`مجرد`) تأتي **بعد** الكلمة المفتاحية التي تعدّلها (دالة، متغير، باني، إلخ). هذا يتوافق مع القاعدة العربية: "الصفة تتبع الموصوف".

```bnf
class_decl      → 'صنف' ['مجرد'] ['محكم'] IDENTIFIER
                  ['يرث' IDENTIFIER (',' IDENTIFIER)*]
                  [('نفّذ' | 'نفذ') IDENTIFIER (',' IDENTIFIER)*]   # تنفيذ سمات
                  class_body

class_body      → class_member* 'نهاية'

class_member    → field_decl | method_decl | constructor_decl
                 | destructor_decl | property_decl | operator_decl
                 | nested_class_decl

# ⚠️ المعدلات تأتي بعد الكلمة المفتاحية (الصفة بعد الموصوف)
field_decl      → 'متغير' [access_mod] ['ساكن'] IDENTIFIER ['=' expression] [';']

method_decl     → 'دالة' [access_mod] ['ساكن'] ['مجرد']
                  ['غير_متزامن'] [return_type] IDENTIFIER
                  '(' [param_list] ')' block

constructor_decl → 'باني' [access_mod] '(' [ctor_params] ')'
                   [':' 'الأساس' '(' [args] ')']
                   block

ctor_params     → ctor_param (',' ctor_param)*
ctor_param      → 'هذا' '.' IDENTIFIER ['=' expression]   # تعيين تلقائي
                 | [type] IDENTIFIER ['=' expression]       # معامل عادي

destructor_decl → 'هدم' [access_mod] '(' ')' block

property_decl   → 'خاصية' [access_mod] [type] IDENTIFIER
                  'احصل' block 'نهاية'              # getter (مطلوب)
                  ['عيّن' ['(' param ')'] block 'نهاية']  # setter (اختياري)
                  'نهاية'                             # نهاية الخاصية
# ملاحظة: الخاصية تحتاج 3 كلمات 'نهاية': getter + setter + property

operator_decl   → 'عامل' [access_mod] operator_symbol '(' param_list ')' block

const_decl      → 'ثابت' [access_mod] IDENTIFIER '=' expression [';']

access_mod      → 'عام' | 'خاص' | 'محمي'
```

**أمثلة على الصيغة الجديدة (الصفة بعد الموصوف):**
```sad
صنف مجرد شكل
    دالة مجرد مساحة()       # دالة مجردة (بدون جسم)
    نهاية

    دالة عام وصف()           # دالة عامة
        ارجع "شكل"
    نهاية
nهاية

صنف مربع يرث شكل
    متغير عام الضلع         # حقل عام

    باني عام(ض)
        هذا.الضلع = ض
    نهاية

    دالة عام مساحة()
        ارجع هذا.الضلع ** 2
    نهاية

    عامل عام +(آخر)
        ارجع جديد مربع(هذا.الضلع + آخر.الضلع)
    نهاية

    دالة عام ساكن من_مساحة(م)
        ارجع جديد مربع(م ** 0.5)
    نهاية
نهاية
**المصدر:** `parser_core_oop.cpp` — دوال OOP الكاملة

#### الوراثة:
```bnf
# وراثة بسيطة
صنف حيوان يرث كائن_حي ... نهاية

# وراثة متعددة (عبر فواصل)
صنف طالب يرث شخص, متعلم ... نهاية

# باني مع استدعاء الأساس
باني(اسم)
    الأساس(اسم)    # أو: الأساس.باني(اسم)
    هذا.نوع = "طالب"
نهاية

# باني مختصر مع هذا.خاصية
باني(هذا.اسم, هذا.عمر)     # → تلقائياً: هذا.اسم = اسم; هذا.عمر = عمر
نهاية
```

#### الأصناف المجردة والمحكمة:
```bnf
# الصفة بعد الموصوف — المعدلات تأتي بعد 'صنف'
abstract_class  → 'صنف' 'مجرد' IDENTIFIER ...
sealed_class    → 'صنف' 'محكم' IDENTIFIER ...
                 | 'صنف' 'محكم' 'مجرد' IDENTIFIER ...
                 | 'صنف' 'مجرد' 'محكم' IDENTIFIER ...

# ❌ الصيغة القديمة (محذوفة — تُنتج خطأ نحوي مع رسالة إرشادية):
# 'مجرد' 'صنف' ...  ← خطأ: استخدم 'صنف مجرد'
# 'محكم' 'صنف' ...  ← خطأ: استخدم 'صنف محكم'
```

**ملاحظات:**
- لا يُسمح باستخدام `{ }` — يجب استخدام `نهاية`
- `واجهة` أُزيلت — يجب استخدام `سمة` بدلاً منها
- الأصناف المحكمة تسمح بالوراثة فقط من نفس الملف المصدري

## 3. الجمل

### 3.1 جملة الشرط (إذا)

```bnf
if_stmt         → 'إذا' '(' expression ')' block
                  ['وإلا' (if_stmt | block)]

else_if         → 'وإلا' 'إذا' '(' expression ')' block   # على نفس السطر
                 | 'وإلا_إذا' '(' expression ')' block      # ككلمة واحدة
```

**المصدر:** `parser_statements.cpp` — `parseIfStmt()`

**قاعدة مهمة:** إذا أُغلقت كتلة `إذا` بـ `نهاية`، لا يُبحث عن `وإلا` بعدها. `وإلا إذا` على نفس السطر فقط تُعامل كسلسلة — إذا كانت `إذا` على سطر مختلف تُعامل كـ `إذا` متداخلة.

---

### 3.2 الحلقات

```bnf
while_stmt      → 'بينما' '(' expression ')' block

for_stmt        → 'لكل' loop_var [',' loop_var]
                  ('في' expression | 'من' expression ('الى' | 'إلى') expression)
                  block

loop_var        → IDENTIFIER | type_token | keyword_as_name
```

**المصدر:** `parser_statements.cpp` — `parseForStmt()`

#### الصيغ المدعومة:
- `لكل عنصر في مجموعة ... نهاية` — التكرار على مجموعة
- `لكل فهرس, عنصر في مجموعة ... نهاية` — تفكيك الفهرس والقيمة
- `لكل ع من 1 الى 10 ... نهاية` — صيغة النطاق (تدعم `الى` و `إلى`)
- **بدون أقواس** — صيغة الأقواس أُزيلت
- متغير الحلقة يمكن أن يكون كلمة نوع أو كلمة مفتاحية ناعمة: `لكل رقم في [...]`

---

### 3.3 جملة الإرجاع

```bnf
return_stmt     → 'ارجع' [expression] [';']
```

- الإرجاع بدون قيمة مسموح قبل `نهاية`, `وإلا`, `وإلا_إذا`, `امسك`, `أخيراً`

---

### 3.4 جملة yield (للمولدات)

```bnf
yield_stmt      → 'أنتج' [expression] [';']
                 | 'أنتج' 'من' expression [';']       # تفويض لمولد آخر (yield from)
```

**المصدر:** `parser_statements.cpp` — `parseYieldStmt()`

**ملاحظة:** كلمة `من` هنا ليست KEYWORD_FROM بل مُعرّف عادي بقيمة `"من"` — يُتحقق منها كمُعرّف.

---

### 3.5 معالجة الأخطاء (حاول/امسك/أخيراً)

```bnf
try_stmt        → 'حاول' block
                  ('امسك' IDENTIFIER block)*          # بدون أقواس حول اسم الخطأ
                  ['أخيراً' block]

throw_stmt      → 'ارمي' expression [';']
```

**قواعد مهمة:**
- `امسك (خطأ)` بأقواس → **ممنوعة** — يجب استخدام `امسك خطأ` بدون أقواس
- إذا أُغلقت كتلة `امسك` بـ `نهاية` → لا يُبحث عن بنود `امسك` إضافية (يمنع سرقة catch في try متداخل)
- `أخيراً` تُحلل فقط إذا لم تُغلق آخر كتلة catch بـ `نهاية`

---

### 3.6 جملة المطابقة (طابق)

```bnf
match_stmt      → 'طابق' '(' expression ')'
                  match_case*
                  ['افتراضي' ':' block]
                  'نهاية'

match_case      → 'عندما' pattern [guard] ':' block

pattern         → literal_pattern
                 | variable_pattern           # IDENTIFIER (ربط قيمة)
                 | wildcard_pattern           # '_'
                 | range_pattern              # start..end أو start..=end
                 | list_pattern               # [a, b, *rest]
                 | struct_pattern             # {x: value}
                 | or_pattern                 # pattern1 || pattern2
                 | bind_pattern               # name @ pattern
                 | enum_pattern               # Enum.Variant أو Enum.Variant(pat...)

list_pattern    → '[' ']'                     # قائمة فارغة
                 | '[' pattern (',' pattern)* [',' '*' IDENTIFIER] ']'  # مع بقية

enum_pattern    → IDENTIFIER '.' IDENTIFIER ['(' pattern (',' pattern)* ')']

guard           → 'إذا' expression             # شرط حراسة
```

**ملاحظات:**
- `حالة` داخل `طابق` تُنتج خطأ مع اقتراح استخدام `عندما`
- `افتراضي` يُعامل كـ WildcardPattern ويجب أن يكون آخر بند
- النقطتان `:` مطلوبة بعد `عندما`

---

### 3.7 التأجيل المضمون (أجّل)

```bnf
defer_stmt      → 'أجّل' statement              # جملة واحدة على نفس السطر
                 | 'أجّل'                        # كتلة
                   statement*
                   'نهاية'
```

**المصدر:** `parser_statements.cpp` — `parseDeferStmt()`

**قاعدة:** إذا كان الرمز بعد `أجّل` على سطر مختلف → كتلة حتى `نهاية`. إذا على نفس السطر → جملة واحدة.

---

### 3.8 إطلاق goroutine (أطلق)

```bnf
go_stmt         → 'أطلق' expression             # جملة واحدة (استدعاء أو لامدا)
                 | 'أطلق'                        # كتلة (تدعم تصريحات متغير/ثابت/دالة)
                   statement*
                   'نهاية'
```

**المصدر:** `parser_statements.cpp` — `parseGoStmt()`

**نفس قاعدة أجّل:** اختلاف السطر يحدد كتلة أم جملة واحدة.

---

### 3.9 مدير السياق (باستخدام)

```bnf
with_stmt       → 'باستخدام' expression ['كـ' IDENTIFIER]
                  block
                  'نهاية'
```

---

### 3.10 التحكم بالتدفق

```bnf
break_stmt      → 'توقف' [';']

```

---

### 3.11 حالة (Switch)

```bnf
switch_stmt     → 'حالة' expression
                  case_branch*
                  ['افتراضي' ':' block]
                  'نهاية'
```

**ملاحظات:**
- `حالة` كلمة سياقية بدون أقواس — صيغة الأقواس تُنتج خطأ
- النقطتان بعد `عندما` اختيارية (على عكس `طابق` حيث هي مطلوبة)
- `افتراضي` يجب أن يكون آخر بند

## 4. التعبيرات

### 4.1 سلسلة التحليل (من الأدنى للأعلى أولوية)

```bnf
expression      → pipeline

pipeline        → assignment ('|>' assignment)*

assignment      → ternary
                 | ternary ':=' assignment           # Walrus operator
                 | ternary '=' assignment             # إسناد عادي
                 | ternary compound_op assignment      # إسناد مركب

compound_op     → '+=' | '-=' | '*=' | '/=' | '//=' | '%='

ternary         → null_coalesce ('?' expression ':' ternary)?

null_coalesce   → logical_or ('??' logical_or)*

logical_or      → logical_and ('||' | 'أو' logical_and)*

logical_and     → bitwise_or ('&&' | 'و' bitwise_or)*

bitwise_or      → bitwise_xor ('|' bitwise_xor)*

bitwise_xor     → bitwise_and ('^' bitwise_and)*

bitwise_and     → equality ('&' equality)*

equality        → comparison (('==' | '!=') comparison)*

comparison      → range (('<' | '<=' | '>' | '>=' | 'في') range)*

range           → term ('..' term?)?               # term.. بدون نهاية = نطاق مفتوح

term            → factor (('+' | '-') factor)*
                 | factor (('<<' | '>>') factor)*    # إزاحة البت

factor          → unary (('*' | '/' | '//' | '%') unary)*

unary           → ('-' | '!' | 'ليس' | '++' | '--' | '~') unary
                 | '&' ['متغير'] IDENTIFIER           # استعارة
                 | '&' LIFETIME IDENTIFIER             # استعارة مع عمر
                 | power

power           → postfix ('**' power)?               # ربط أيمن

postfix         → primary postfix_op*

postfix_op      → '(' arg_list ')'                    # استدعاء دالة
                 | '!' '(' arg_list ')'               # استدعاء ماكرو (VariableExpr فقط)
                 | '.' IDENTIFIER                      # وصول عضو (يدعم كلمات مفتاحية ناعمة كأسماء)
                 | '.' IDENTIFIER '(' arg_list ')'     # استدعاء طريقة
                 | '.' NUMBER                          # وصول صف رقمي (tuple.0)
                 | '?.' IDENTIFIER                     # وصول آمن (optional chaining)
                 | '[' expression ']'                   # وصول بالفهرس
                 | '[' slice ']'                        # شريحة
                 | '?[' expression ']'                  # وصول آمن بالفهرس
                 | '++' | '--'                         # عامل بعدي

slice           → [expression] ':' [expression] [':' expression]  # [start:end:step]
                 | [expression] '..' [expression]                   # [start..end] — يُحوّل RangeExpr→SliceExpr تلقائياً
```

**المصدر:** `parser_expressions.cpp` — الدوال المتسلسلة بالكامل

### 4.2 التعبيرات الأساسية (Primary)

```bnf
primary         → NUMBER_INTEGER | NUMBER_DOUBLE       # أرقام
                 | STRING_LITERAL                       # نص عادي
                 | STRING_RAW                           # نص خام r"..."
                 | STRING_FSTRING                       # نص منسق f"...{expr}..."
                 | 'صحيح' | 'خطأ'                      # قيم منطقية
                 | 'لاشيء'                              # null
                 | IDENTIFIER                           # مرجع متغير
                 | IDENTIFIER '<' type_args '>'         # تنفيذ قالب
                 | 'جديد' IDENTIFIER ['<' type_args '>'] '(' [args] ')'   # إنشاء كائن
                 | 'هذا'                                # الكائن الحالي
                 | 'الأساس'                             # الصنف الأب (فقط إذا تلاه '.')
                 | 'إذا' '(' expr ')' expr 'وإلا' expr  # تعبير إذا (inline)
                 | 'انتظر' expression                   # تعبير الانتظار
                 | 'انشر' expression                    # نشر الخطأ
                 | 'لامدا' lambda_expr                  # تعبير لامدا
                 | '@' directive_expr                   # توجيهات
                 | '(' expression ')'                   # تجميع
                 | '(' expression ')' '=>' expression    # دالة سهمية: (x) => x+1
                 | '(' ')'                              # صف فارغ
                 | '(' expr ',' [expr (',' expr)*] ')'  # صف (tuple)
                 | '[' array_literal ']'                # مصفوفة
                 | '{' map_literal '}'                  # خريطة
                 | type_keyword '(' [args] ')'           # نوع كدالة: نص(42)
                 | '|' expression '|'                   # قيمة مطلقة |x| → abs(x)
```

**المصدر:** `parser_expressions.cpp` — `parsePrimary()`

**ملاحظات دقيقة:**
- تعبير `إذا` **يعمل بلا أقواس أيضاً**: `إذا شرط ثم تعبير وإلا تعبير` — يُحلل الشرط بـ `parseLogicalOr()`
- كلمة `ثم` **اختيارية** ومُتجاهلة (تُمرر بدون تأثير)
- `'الأساس'` يُنشئ `SuperExpr` فقط إذا تلاه `.` — وإلا يُعامل كمُعرّف عادي اسمه `"الأساس"`
- `'جديد'` يُنشئ `NewExpr` فقط إذا تلاه `IDENTIFIER` — وإلا يُعامل كمتغير عادي
- `'انتظر'` كلمة سياقية — تُستخدم كبداية تعبير await فقط في سياق `parsePrimary`
- `|تعبير|` تُحلل داخلياً بـ `parseBitwiseXor()` (مستوى واحد تحت `bitwiseOr`) لتجنب تفسير `|` الإغلاق كعامل OR بتّي
- أسماء الأنواع (`رقم`، `نص`...) والكلمات المفتاحية الناعمة (`احصل`، `عيّن`...) في موضع `primary` تُحوّل إلى `VariableExpr` — مما يسمح بـ `نص(42)` كاستدعاء دالة
- الدالة السهمية `(x) => expr` تُكتشف بعد إغلاق القوس `)`: إذا تلاه `=>` ويحتوي القوس على `VariableExpr` واحد
- f-string: كل تعبير `{expr}` يُحلل بإنشاء `LexerCore` + `ParserCore` فرعيين — إذا فشل التحليل يُعامل كاسم متغير
- f-string: `{{` و `}}` حروف تجاوز تُنتج `{` و `}` حرفياً

### 4.3 تعبير اللامدا

```bnf
lambda_expr     → 'لامدا' '(' [param_list] ')' '=>' expression        # سهم + تعبير واحد
                 | 'لامدا' '(' [param_list] ')' '=>' block 'نهاية'     # سهم + كتلة
                 | 'لامدا' '(' [param_list] ')' block 'نهاية'          # بدون سهم + كتلة
```

**ملاحظات:**
- الدالة المجهولة والسهمية أُزيلتا — يجب استخدام `لامدا` فقط
- الأقواس حول المعاملات مطلوبة دائماً
- استهلاك `نهاية` ذكي: تُستهلك فقط إذا تلاها محدد إغلاق (`)`, `]`, `,`, `،`, `؛`, `;`)
- صيغة `(x) => تعبير` لا تزال تعمل ضمن التعبيرات بين الأقواس في `parsePrimary()`
- في صيغة السهم `=>`: إذا بدأ الجسم بكلمة مفتاحية جملة (`إذا`، `بينما`، `لكل`، `ارجع`، `متغير`، `ثابت`، `حاول`، `ارمي`، `طابق`، `توقف`، `استمر`) → يُحلل ككتلة حتى `نهاية`

## 6. البرمجة الكائنية

### 6.1 تحليل أعضاء الصنف

> **⚠️ قاعدة الصفة بعد الموصوف:** المعدّلات تأتي **بعد** الكلمة المفتاحية وليس قبلها.

ترتيب تحليل أعضاء الصنف في `parser_declarations.cpp` و `parser_core_oop.cpp`:

1. **الكلمة المفتاحية أولاً:**
   - `باني` → `parseConstructorDeclaration()`
   - `هدم` → `parseDestructorDeclaration()`
   - `دالة` → `parseMethodDeclaration()`
   - `خاصية` → `parsePropertyDeclaration()`
   - `عامل` → `parseOperatorDecl()`
   - `متغير` → `parseFieldDeclaration()`
   - `ثابت` → `parseFieldDeclaration()`
2. **ثم المعدّلات (اختيارية):**
   - **معدلات الرؤية:** `عام` | `خاص` | `محمي` (افتراضي: `عام`)
   - **معدلات إضافية:** `ساكن` | `مجرد`
3. **ثم الاسم والمعاملات**

```bnf
# أمثلة على الصيغة الصحيحة:
دالة عام وصف()            # ✅ دالة + معدّل + اسم
دالة عام ساكن إنشاء()     # ✅ دالة + معدّل + ساكن + اسم
دالة مجرد مساحة()          # ✅ دالة + مجرد + اسم
متغير عام الاسم            # ✅ متغير + معدّل + اسم
ثابت عام الحد = 100       # ✅ ثابت + معدّل + اسم
باني عام(اسم)              # ✅ باني + معدّل + معاملات
هدم عام()                  # ✅ هدم + معدّل
عامل عام +(آخر)           # ✅ عامل + معدّل + رمز + معاملات
خاصية عام الطول            # ✅ خاصية + معدّل + اسم

# ❌ الصيغة القديمة (تُنتج خطأ نحوي مع رسالة إرشادية):
# عام دالة وصف()  ← خطأ: استخدم 'دالة عام'
# خاص متغير س     ← خطأ: استخدم 'متغير خاص'
```

### 6.2 تعبير جديد (new)

```bnf
new_expr        → 'جديد' IDENTIFIER ['<' type_args '>'] '(' [arg_list] ')'
```

- `جديد` يُعامل كمنشئ كائن فقط إذا تلاه مُعرّف (اسم صنف)
- إذا لم يتبعه مُعرّف، يُعامل `جديد` كمتغير عادي: `متغير جديد = 5`

### 6.3 تعبيرات this و super

- `هذا` → `ThisExpr` — الكائن الحالي
- `الأساس` → `SuperExpr` — فقط إذا تلاه `.` (وصول عضو من الصنف الأب)
  - إذا لم يتبعه `.`، يُعامل كمُعرّف عادي

## 13. قواعد إنهاء الجمل والكتل

### 13.1 الكتل

```bnf
block           → statement* 'نهاية'
```

- **جميع الكتل** تنتهي بكلمة `نهاية` (لا `{ }` ولا `:`)
- الاستثناء الوحيد: كتلة `وإلا` تنتهي عندما يُصادف `نهاية` أو `وإلا` أو `وإلا_إذا`

### 13.2 المنقوطة

- المنقوطة **اختيارية** تماماً (`؛` العربية أو `;` الإنجليزية)
- كلاهما متكافئتان تماماً

### 13.3 الفاصلة

- الفاصلة العربية `،` والإنجليزية `,` متكافئتان تماماً
- الفاصلة اللاحقة (trailing comma) مسموحة في:
  - المصفوفات: `[1, 2, 3,]`
  - الخرائط: `{أ: 1, ب: 2,}`
  - المعاملات: `دالة ف(أ, ب,)`

### 13.4 التعليقات

```bnf
line_comment    → '#' text NEWLINE
block_comment   → '#*' text '*#'
doc_comment     → '##' text NEWLINE
                 | '#**' text '**#'
```

- التعليقات التوثيقية تُرفق بأول تصريح يليها
- المحلل يتخطى `WHITESPACE`, `COMMENT`, `DOC_COMMENT`, `NEWLINE`

## 14. نظام أنماط الماكرو المتقدم

**المصدر:** `macro_pattern_parser.cpp`

### 14.1 عناصر أنماط الماكرو

```bnf
macro_pattern       → pattern_element+

pattern_element     → literal_element               # نص ثابت
                     | meta_variable                 # متغير ماكرو $x:نوع
                     | repetition_element            # تكرار $(...)

meta_variable       → '$' IDENTIFIER ':' fragment_kind
                     | '$' IDENTIFIER                # افتراضي: عبر (Expr)

fragment_kind       → 'عبر'    | 'expr'             # تعبير
                     | 'قيمة'   | 'lit'              # قيمة حرفية
                     | 'نوع'    | 'ty'               # نوع
                     | 'كتلة'   | 'block'            # كتلة كود
                     | 'معرّف'  | 'ident'            # مُعرّف
                     | 'رمز'    | 'tt'               # رمز أو شجرة رموز
                     | 'مسار'   | 'path'             # مسار (أ::ب::ج)
                     | 'نمط'    | 'pat'              # نمط مطابقة
                     | 'جملة'   | 'stmt'             # جملة
                     | 'عنصر'   | 'item'             # تعريف (دالة, هيكل)

repetition_element  → '$' '(' pattern ')' repetition_op [separator]

repetition_op       → '*'                            # صفر أو أكثر
                     | '+'                            # واحد أو أكثر
                     | '?' | '؟'                      # اختياري

separator           → ',' | '،' | ';' | '؛'          # الفاصل بين العناصر
```

#### بنية عقدة النمط:
- **Literal:** نص حرفي يجب مطابقته تماماً
- **MetaVar:** متغير يلتقط قيمة من المدخلات (`$اسم:معرّف`)
- **Repetition:** نمط يتكرر مع فاصل اختياري (`$($عنصر:عبر),*`)
- **Sequence:** تسلسل عناصر متتالية
- **Group:** مجموعة عناصر `(...)`

## 15. العقود البرمجية المتقدمة (Design by Contract)

**المصدر:** `contract_parser.cpp`

### 15.1 أنواع العقود الخمسة

```bnf
contract_clause     → 'يتطلب' contract_expr          # شرط مسبق (Precondition)
                     | 'يضمن' contract_expr           # شرط لاحق (Postcondition)
                     | 'ثابت' contract_expr           # ثابت الصنف (Invariant)
                     | 'يفترض' contract_expr          # افتراض (Assumption)
                     | 'يؤكد' contract_expr           # تأكيد (Assertion)

contract_expr       → comparison_expr

                     | field_access

                     | 'النتيجة'                      # مرجع للقيمة المُرجعة (فقط في يضمن)

```

```sad

    يتطلب ب != 0
    يضمن النتيجة * ب == أ

نهاية
```

## 24. تفاصيل دقيقة مُكتشفة من المراجعة العميقة

> هذا القسم يوثّق القواعد الدقيقة التي اكتُشفت من خلال قراءة معمّقة لكل سطر في ملفات المحلل النحوي،
> ولم تكن واضحة في الأقسام السابقة.

### 24.1 صيغ اللامدا الثلاث

**المصدر:** `parser_expressions.cpp` — `parseLambda()`

```bnf
lambda_expr     → 'لامدا' '(' [param_list] ')' '=>' expression        # سهم + تعبير واحد
                 | 'لامدا' '(' [param_list] ')' '=>' block 'نهاية'     # سهم + كتلة
                 | 'لامدا' '(' [param_list] ')' block 'نهاية'          # بدون سهم + كتلة
```

**ملاحظات:**
- الأقواس حول المعاملات **مطلوبة دائماً** (لا يُسمح بـ `لامدا س => ...`)
- استهلاك `نهاية` ذكي: تُستهلك فقط إذا تلاها محدد إغلاق (`)`، `]`، `,`، `،`، `؛`، `;`) لتجنب سرقة `نهاية` الكتلة الأم
- الصيغة السهمية `(x) => تعبير` لا تزال تعمل ضمن التعبيرات بين الأقواس في `parsePrimary()`
- في صيغة السهم `=>`: إذا بدأ الجسم بكلمة مفتاحية جملة (`إذا`، `بينما`، `لكل`، `ارجع`، `متغير`، `ثابت`، `حاول`، `ارمي`، `طابق`، `توقف`، `استمر`) → يُحلل ككتلة حتى `نهاية`

### 24.2 الإسناد المركب المتداخل

**المصدر:** `parser_expressions.cpp` — `parseAssignment()`

```bnf
# الإسناد المركب يدعم أهدافاً متداخلة بعمق:
compound_target → IDENTIFIER                                  # x += y
                | expression '.' IDENTIFIER                    # obj.field += y
                | expression '[' expression ']'                # arr[i] += y
                | 'هذا' '.' IDENTIFIER                         # هذا.field += y
                | expression '[' expression ']' '.' IDENTIFIER # arr[idx].field += y
                | 'هذا' '.' IDENTIFIER '[' expression ']'      # هذا.field[idx] += y
```

كل إسناد مركب `x op= y` يُحوّل نحوياً إلى `x = x op y` مع الحفاظ على بنية الهدف.

### 24.3 خرائط مكتوبة النوع

**المصدر:** `parser_expressions.cpp` — `parsePostfix()`

```bnf

# Dict Comprehension (من parseDictComprehension أو parseMapLiteral):
dict_comp       → '{' key_expr ':' val_expr 'لكل' IDENTIFIER 'في' expression ['إذا' expression] '}'

# Set Comprehension (من parseMapLiteral — لا يوجد ':' بعد أول تعبير):
set_comp        → '{' expression 'لكل' IDENTIFIER 'في' expression ['إذا' expression] '}'
```

**اكتشافات:**
1. التمييز بين خريطة و set يتم بالتحقق من وجود `:` أو `=` بعد المفتاح الأول
2. `parseTernary()` يُستخدم بدل `parseExpression()` لتجنب استهلاك `لكل` كتعبير
3. Trailing comma مسموح في المصفوفات والخرائط

### 24.57 صيغ المعاملات المكتوبة الكاملة

# الكلمات المفتاحية الناعمة مسموحة كأسماء معاملات بعد النوع:

### 24.60 التمييز بين النوع والمتغير — `isTypeToken()` مع lookahead

**المصدر:** `parser_core_helpers.cpp` — `isTypeToken()`

```
# لتمييز "رقم" كنوع من "رقم" كاسم متغير:
#   isTypeToken() يتحقق من:
#   1. رموز TYPE_* (TYPE_INTEGER, TYPE_DOUBLE, ...) → true دائماً
#   2. IDENTIFIER بقيمة ("رقم"|"عشري"|"نص"|"منطقي"|"فراغ"|"عدم"|"مصفوفة"|"خريطة"|"أي")
#      → true فقط إذا peekNext().getType() == TT::IDENTIFIER
#      (أي: الكلمة التالية هي اسم متغير/حقل)
# 
# مثال: متغير رقم = 42 → "رقم" هنا isTypeToken=false (التالي = OP_ASSIGN)
# مثال: رقم س = 42     → "رقم" هنا isTypeToken=true (التالي = IDENTIFIER "س")
```

### 24.62 نظام الاستيراد والتصدير — الصيغ الكاملة

**المصدر:** `parser_modules.cpp`

```bnf
# === الاستيراد ===
import_stmt     → 'استورد' '*' 'من' module_path                         # شامل
                 | 'استورد' import_items 'من' module_path               # انتقائي عربي
                 | 'استورد' module_path ['كـ' IDENTIFIER]                # بسيط مع/بدون اسم مستعار
                 | 'استورد' STRING_LITERAL ['من' module_path] ['كـ' IDENTIFIER]  # مسار نصي

from_import     → 'من' module_path 'استورد' '*'                         # شامل
                 | 'من' module_path 'استورد' import_items                # انتقائي

import_items    → import_item (',' | '،') import_items
import_item     → IDENTIFIER ['كـ' IDENTIFIER]

module_path     → STRING_LITERAL                                         # "وحدة/فرعية"
                 | ('.' | '..') IDENTIFIER ('.' IDENTIFIER)*             # نسبي
                 | IDENTIFIER ('.' IDENTIFIER)*                           # مطلق

# === التصدير ===
export_decl     → 'صدّر' '*' 'من' module_path                          # إعادة تصدير شاملة
                 | 'صدّر' import_items 'من' module_path                 # إعادة تصدير انتقائية
                 | 'صدّر' declaration                                    # تصدير مباشر
                 | 'صدّر' IDENTIFIER ['=' expression]                    # تصدير إسناد/اسم مستعار
                 | 'صدّر' 'خارجي' ['(' STRING ')'] 'دالة' ...           # دالة خارجية مُصدّرة

declaration     → 'دالة' func_decl | 'صنف' class_decl | 'تعداد' enum_decl
                 | 'بنية' struct_decl | 'ثابت' var_decl | 'متغير' var_decl
                 | type var_decl
```

### 24.64 أنماط Pattern Matching المتقدمة — القواعد الكاملة

**المصدر:** `parser_advanced.cpp` — `parsePattern()`, `parsePrimaryPattern()`, `parseListPattern()`, `parseStructPattern()`

```bnf
pattern         → '_'                                                     # شامل (wildcard)
                 | '{' struct_fields '}'                                   # بنية/صنف
                 | '[' list_elements ']'                                   # قائمة
                 | primary_pattern '@' pattern                             # ربط (binding)
                 | primary_pattern ('||' primary_pattern)+                 # OR
                 | primary_pattern                                         # أساسي

primary_pattern → NUMBER ['..' ['='] NUMBER]                              # رقم أو نطاق (مع/بدون شمول)
                 | STRING_LITERAL                                          # نصي
                 | 'صحيح' | 'خطأ'                                         # منطقي
                 | 'لاشيء'                                                 # null
                 | IDENTIFIER '.' IDENTIFIER ['(' pattern_list ')']       # تعداد جبري (ADT)
                 | IDENTIFIER                                              # متغير

list_pattern    → '[' [list_elements] ']'
list_elements   → pattern (',' pattern)* ['*' IDENTIFIER]                 # *rest في النهاية

struct_pattern  → '{' [struct_fields] '}'
struct_fields   → field_pat (',' field_pat)*
field_pat       → IDENTIFIER [':' pattern]                                # بدون : → shorthand (اسم=متغير)

match_stmt      → 'طابق' expression case_clause* ['افتراضي' ':' body] 'نهاية'
case_clause     → 'عندما' pattern ['إذا' expression] ':' body*

# ❌ 'حالة' داخل 'طابق' → خطأ مع تعافي (يُعامل كـ عندما)
# ❌ {} حول طابق → خطأ (أُزيلت — استخدم نهاية)
```

### 24.65 القوالب (Templates) — معاملات الأنواع والقيود

**المصدر:** `parser_advanced.cpp` — `parseTemplateParameters()`, `parseWhereClause()`, `parseTemplateDecl()`

```bnf
template_decl   → 'قالب' '<' type_params '>' ('دالة' func_decl | 'صنف' class_decl)

type_params     → type_param (',' type_param)*
type_param      → ('نوع' | KEYWORD_TYPENAME) IDENTIFIER [':' constraints]

constraints     → IDENTIFIER ('+' IDENTIFIER)*                           # قيود متعددة بـ +

where_clause    → 'حيث' where_item (',' where_item)*
where_item      → IDENTIFIER ['.' IDENTIFIER] ':' constraints
                                  # ↑ associated type path (مسار نوع مرتبط)

# مثال: قالب<نوع ت: قابل_للمقارنة + قابل_للتجزئة> دالة ترتيب(مصفوفة ت عناصر) ...
# مثال: حيث ت.عنصر: قابل_للطباعة
```
