# 10. الخرائط (القواميس)

## إنشاء خريطة

```sad
متغير خ = {"اسم": "أحمد"، "عمر": 25، "مدينة": "الرياض"}
```

## الوصول للقيم

```sad
متغير الاسم = خ["اسم"]
خ["هاتف"] = "0500000000"    # إضافة مفتاح جديد
```

## طرق الخريطة (dot syntax)

| الطريقة | الوصف |
|---------|-------|
| `خ.الحجم()` | عدد العناصر |
| `خ.مفاتيح()` | مصفوفة المفاتيح |
| `خ.القيم()` | مصفوفة القيم |
| `خ.يحتوي("مفتاح")` | هل يوجد المفتاح |
| `خ.فارغة()` | هل الخريطة فارغة |
| `خ.نسخ()` | نسخة مستقلة |
| `خ.دمج(خريطة_أخرى)` | دمج خريطتين |
| `خ.احذف("مفتاح")` | حذف مفتاح |
| `خ.عناصر()` | مصفوفة أزواج [مفتاح، قيمة] |
| `خ.امسح()` | حذف الكل |

---

## 🔸 الأمثلة (8 أمثلة متدرجة)

### مثال 1 — مبتدئ: إنشاء خريطة والوصول لعناصرها
```sad
متغير شخص = {"اسم": "أحمد"، "عمر": 25، "مدينة": "الرياض"}

اطبع_سطر("الاسم: " + شخص["اسم"])
اطبع_سطر("العمر: " + شخص["عمر"])
اطبع_سطر("المدينة: " + شخص["مدينة"])
```
**المخرجات:**
```
الاسم: أحمد
العمر: 25
المدينة: الرياض
```

### مثال 2 — مبتدئ: إضافة وتعديل عناصر
```sad
متغير خ = {"أ": 1، "ب": 2}
اطبع_سطر("قبل: " + خ)

# إضافة عنصر جديد
خ["ج"] = 3
خ["د"] = 4
اطبع_سطر("بعد الإضافة: " + خ)

# تعديل عنصر
خ["أ"] = 100
اطبع_سطر("بعد التعديل: " + خ)
```

### مثال 3 — مبتدئ: حجم الخريطة ومفاتيحها
```sad
متغير خ = {"اسم": "أحمد"، "عمر": 25، "مدينة": "الرياض"}

اطبع_سطر("الحجم: " + خ.الحجم())

متغير م = خ.مفاتيح()
اطبع_سطر("عدد المفاتيح: " + م.الطول())

متغير ق = خ.القيم()
اطبع_سطر("عدد القيم: " + ق.الطول())
```
**المخرجات:**
```
الحجم: 3
عدد المفاتيح: 3
عدد القيم: 3
```

### مثال 4 — متوسط: فحص ومعالجة المفاتيح
```sad
متغير خ = {"اسم": "أحمد"، "عمر": 25، "مدينة": "الرياض"}

# فحص وجود مفتاح
اطبع_سطر("يحتوي 'اسم': " + خ.يحتوي("اسم"))
اطبع_سطر("يحتوي 'هاتف': " + خ.يحتوي("هاتف"))

# هل فارغة
اطبع_سطر("فارغة: " + خ.فارغة())

# نسخ
متغير خ2 = خ.نسخ()
اطبع_سطر("حجم النسخة: " + خ2.الحجم())
```
**المخرجات:**
```
يحتوي 'اسم': صحيح
يحتوي 'هاتف': خطأ
فارغة: خطأ
حجم النسخة: 3
```

### مثال 5 — متوسط: دمج وحذف
```sad
متغير خ = {"اسم": "أحمد"، "عمر": 25}
متغير إضافي = {"هاتف": "0500000000"، "بريد": "a@b.com"}

# دمج
خ.دمج(إضافي)
اطبع_سطر("بعد الدمج - الحجم: " + خ.الحجم())

# حذف
خ.احذف("بريد")
اطبع_سطر("بعد الحذف - الحجم: " + خ.الحجم())

# عناصر
متغير بيانات = {"أ": 1، "ب": 2}
متغير عناصر = بيانات.عناصر()
اطبع_سطر("عدد العناصر: " + عناصر.الطول())

# مسح
بيانات.امسح()
اطبع_سطر("بعد المسح - فارغة: " + بيانات.فارغة())
```
**المخرجات:**
```
بعد الدمج - الحجم: 4
بعد الحذف - الحجم: 3
عدد العناصر: 2
بعد المسح - فارغة: صحيح
```

### مثال 6 — متوسط: التكرار على خريطة
```sad
متغير درجات = {"رياضيات": 95، "علوم": 88، "لغة": 92، "تاريخ": 75}

اطبع_سطر("الدرجات:")
متغير المفاتيح = درجات.مفاتيح()
لكل مفتاح في المفاتيح
    اطبع_سطر("  " + مفتاح + ": " + درجات[مفتاح])
نهاية

# حساب المجموع
متغير القيم = درجات.القيم()
متغير مجموع = 0
لكل قيمة في القيم
    مجموع = مجموع + قيمة
نهاية
اطبع_سطر("المجموع: " + مجموع)
اطبع_سطر("المتوسط: " + (مجموع / درجات.الحجم()))
```
**المخرجات:**
```
الدرجات:
  رياضيات: 95
  علوم: 88
  لغة: 92
  تاريخ: 75
المجموع: 350
المتوسط: 87.5
```

### مثال 7 — متقدم: خريطة متداخلة
```sad
متغير طالب1 = {"اسم": "أحمد"، "درجات": {"رياضيات": 95، "علوم": 88}}
متغير طالب2 = {"اسم": "فاطمة"، "درجات": {"رياضيات": 90، "علوم": 92}}

متغير طلاب = [طالب1، طالب2]

لكل ط في طلاب
    اطبع_سطر("الطالب: " + ط["اسم"])
    متغير د = ط["درجات"]
    اطبع_سطر("  رياضيات: " + د["رياضيات"])
    اطبع_سطر("  علوم: " + د["علوم"])
نهاية
```
**المخرجات:**
```
الطالب: أحمد
  رياضيات: 95
  علوم: 88
الطالب: فاطمة
  رياضيات: 90
  علوم: 92
```

### مثال 8 — متقدم جداً: جدول بيانات بالخرائط
```sad
# نظام سجل الموظفين

دالة أنشئ_موظف(اسم، قسم، راتب)
    ارجع {"اسم": اسم، "قسم": قسم، "راتب": راتب، "تقييم": 0}
نهاية

دالة قيّم(موظف، تقييم)
    موظف["تقييم"] = تقييم
نهاية

دالة علاوة(موظف، نسبة)
    متغير مبلغ = موظف["راتب"] * نسبة / 100
    موظف["راتب"] = موظف["راتب"] + مبلغ
    ارجع مبلغ
نهاية

دالة اعرض(موظف)
    اطبع("  " + موظف["اسم"])
    اطبع(" | " + موظف["قسم"])
    اطبع(" | راتب: " + موظف["راتب"])
    اطبع_سطر(" | تقييم: " + موظف["تقييم"])
نهاية

# إنشاء الموظفين
متغير م1 = أنشئ_موظف("أحمد"، "تقنية"، 15000)
متغير م2 = أنشئ_موظف("فاطمة"، "تسويق"، 12000)
متغير م3 = أنشئ_موظف("خالد"، "تقنية"، 18000)
متغير م4 = أنشئ_موظف("نورة"، "إدارة"، 20000)

# تقييم
قيّم(م1، 9)
قيّم(م2، 8)
قيّم(م3، 7)
قيّم(م4، 10)

# علاوات للمتميزين
متغير موظفين = [م1، م2، م3، م4]
اطبع_سطر("═══════════════════════════════════════════")
اطبع_سطر("         سجل الموظفين")
اطبع_سطر("═══════════════════════════════════════════")

متغير إجمالي_رواتب = 0
لكل م في موظفين
    إذا (م["تقييم"] >= 9)
        متغير ع = علاوة(م، 10)
        اطبع_سطر("  ⭐ علاوة " + ع + " لـ " + م["اسم"])
    نهاية
    اعرض(م)
    إجمالي_رواتب = إجمالي_رواتب + م["راتب"]
نهاية

اطبع_سطر("═══════════════════════════════════════════")
اطبع_سطر("  إجمالي الرواتب: " + إجمالي_رواتب)
اطبع_سطر("  متوسط الرواتب: " + (إجمالي_رواتب / 4))
اطبع_سطر("═══════════════════════════════════════════")
```
