# 16. المترجم sadc — ترجمة لغة ص إلى كود تنفيذي

## 📖 مقدمة

المترجم `sadc` هو مترجم لغة ص الأصلي الذي يحوّل الكود المصدري إلى ملفات تنفيذية أصلية عبر LLVM. يدعم المترجم تحسينات متعددة المستويات (O0–O3)، توليد LLVM IR، ربط المكتبات، واستهداف منصات مختلفة.

---

## 🗂️ البنية الداخلية

```
كود .ص  →  المحلل المعجمي (Lexer)
        →  المحلل النحوي (Parser)  →  شجرة AST
        ↓                              ↓
   SIR Builder (الواجهة الأمامية)
        ↓
   SIR Optimizer (التحسينات الوسطى)
        ↓
   LLVM CodeGen (الواجهة الخلفية)  →  ملف تنفيذي أصلي
```

### المراحل الرئيسية:

| المرحلة | الدور | الملفات |
|---------|-------|---------|
| SIR Builder | تحويل AST إلى تمثيل وسيط SIR | `sir_builder.cpp` |
| SIR Optimizer | تحسينات على مستوى SIR | `optimizer.cpp` |
| LLVM CodeGen | توليد LLVM IR وربطه | `llvm_codegen_*.cpp` |

---

## 📁 الاستخدام

### الترجمة الأساسية

```bash
# ترجمة ملف .ص إلى ملف تنفيذي
sadc program.ص -o program

# ترجمة مع تحسينات كاملة
sadc program.ص -O3 -o program

# ترجمة إلى LLVM IR فقط
sadc program.ص --emit-llvm -o program.ll

# ترجمة بدون ربط (ملف كائن فقط)
sadc program.ص -c -o program.o

# ربط ملفات كائن
sadc file1.o file2.o -o program
```

### مستويات التحسين

| المستوى | التحسينات المطبقة |
|---------|------------------|
| `-O0` | بدون تحسينات (الافتراضي) |
| `-O1` | طي الثوابت + حذف الكود الميت |
| `-O2` | O1 + إزالة التعبيرات المتكررة + نشر النسخ + تخفيض القوة |
| `-O3` | O2 + حركة الكود الثابت خارج الحلقات + دمج المسجلات |

---

## 🔸 التحسينات الجديدة (2026)

### 1. حركة الكود الثابت خارج الحلقات (LICM)

ينقل العمليات التي لا تتغير داخل الحلقة إلى ما قبلها:

```sad
# قبل التحسين:
متغير مجموع = 0
لكل ي في [1، 2، 3، 4، 5]
    متغير عامل = 10 * 20    # ← ثابت داخل الحلقة
    مجموع = مجموع + ي * عامل
نهاية

# بعد التحسين (تلقائياً مع -O3):
# العملية 10 * 20 تُحسب مرة واحدة قبل الحلقة
```

### 2. تخفيض قوة العمليات (Strength Reduction)

يستبدل العمليات المكلفة بأخرى أرخص:

| العملية الأصلية | البديل الأرخص |
|----------------|--------------|
| `س * 8` | `س << 3` (إزاحة بتات) |
| `س / 4` | `س >> 2` |
| `س % 16` | `س & 15` |
| `س * 1` | `س` |
| `س + 0` | `س` |
| `س - س` | `0` |

### 3. تخزين الوحدات المستوردة (Module Caching)

عند استيراد وحدة أكثر من مرة، يتم تخزينها وإعادة استخدامها:

```sad
# لا يُترجم الملف مرتين
استورد رياضيات
استورد رياضيات    # ← يستخدم النسخة المخزنة

# الاستيراد الانتقائي مع أسماء بديلة
من رياضيات استورد جا كـ sin، جتا كـ cos
```

### 4. دعم المصفوفات الأصلية في وقت التشغيل

```sad
متغير أعداد = [10، 20، 30، 40، 50]

# عمليات المصفوفة المدعومة:
اطبع_سطر("الطول: " + أعداد.طول())
أعداد.أضف(60)
أعداد.أزل(0)
```

### 5. دعم القواميس (الخرائط) الأصلية

```sad
متغير بيانات = {"الاسم": "أحمد"، "العمر": 25}

# عمليات القاموس:
بيانات["المدينة"] = "الرياض"
اطبع_سطر("الاسم: " + بيانات["الاسم"])
```

### 6. نظام RTTI حقيقي للأصناف (instanceof)

```sad
صنف حيوان
    باني(الاسم)
        هذا.الاسم = الاسم
    نهاية
نهاية

صنف قط يرث حيوان
    باني()
        هذا.الاسم = "قط"
    نهاية
نهاية

متغير ق = جديد قط()
# فحص النوع الحقيقي - يدعم الوراثة
اطبع_سطر(ق هو حيوان)    # صحيح
```

## 📌 بناء المترجم من المصدر

```bash
# تهيئة البناء مع LLVM
cmake -S . -B build -DENABLE_LLVM_BACKEND=ON -DLLVM_DIR="مسار/LLVM/lib/cmake/llvm"

# بناء sadc (يجب أن يكون Release لتوافق مع LLVM)
cmake --build build --config Release --target sadc

# التحقق
.\build\bin\Release\sadc.exe --help
```

**ملاحظة:** يجب بناء `sadc` في وضع Release ليتوافق مع مكتبات LLVM المبنية بوضع Release.

### مثال 6 — المستوى: متقدم — خوارزمية الترتيب

```sad
دالة ترتيب_فقاعي(مصفوفة)
    متغير ن = مصفوفة.طول()
    متغير ي = 0
    بينما (ي < ن - 1)
        متغير ج = 0
        بينما (ج < ن - ي - 1)
            إذا (مصفوفة[ج] > مصفوفة[ج + 1])
                # تبديل العنصرين
                متغير مؤقت = مصفوفة[ج]
                مصفوفة[ج] = مصفوفة[ج + 1]
                مصفوفة[ج + 1] = مؤقت
            نهاية
            ج = ج + 1
        نهاية
        ي = ي + 1
    نهاية
    ارجع مصفوفة
نهاية

متغير أرقام = [64، 34، 25، 12، 22، 11، 90]
اطبع_سطر("قبل الترتيب: " + أرقام)
ترتيب_فقاعي(أرقام)
اطبع_سطر("بعد الترتيب: " + أرقام)
```

**المخرجات:**
```

بعد الترتيب: [11, 12, 22, 25, 34, 64, 90]
```

## 📊 مقارنة: المفسر مقابل المترجم

| الميزة | المفسر (`sad`) | المترجم (`sadc`) |
|--------|-------------|---------------|
| السرعة | أبطأ (تفسير مباشر) | أسرع (كود أصلي) |
| البدء | فوري | يحتاج ترجمة |
| التوزيع | يحتاج المفسر | ملف تنفيذي مستقل |
| التحسينات | لا | O0–O3 |
| التصحيح | أسهل | يحتاج `-g` |
| LLVM | لا يحتاج | مطلوب |

---

## 📌 مرجع سريع

```bash
# ترجمة وتشغيل
sadc app.ص -o app && ./app

# ترجمة مع تحسينات ومعلومات تصحيح
sadc app.ص -O2 -g -o app

# عرض LLVM IR
sadc app.ص --emit-llvm -o app.ll

# ترجمة فقط بدون ربط
sadc app.ص -c -o app.o
```
