# أدوات التطوير — الدليل الشامل

## نظرة عامة

لغة ص توفر مجموعة أدوات تطوير متكاملة:

```
╔══════════════════════════════════════════════════════╗
║                 أدوات لغة ص                         ║
╠══════════════════════════════════════════════════════╣
║  sad         المفسر الرئيسي — تنفيذ مباشر          ║
║  sadc        المترجم — ملفات تنفيذية أصلية          ║
║  sad-ios     أداة iOS — مشاريع Xcode               ║
║  sad-android أداة Android — مشاريع Gradle          ║
║  sad-pkg     مدير الحزم                            ║
║  sad-fmt     أداة التنسيق                          ║
║  sad-lsp     خادم LSP — دعم المحرر                 ║
╚══════════════════════════════════════════════════════╝
```

## 1. المفسر (sad)

```bash
# تشغيل ملف
sad ملف.ص

# تشغيل تفاعلي (REPL)
sad
```

### الملفات
- `tools/compiler/main_simple.cpp` — نقطة الدخول
- `interpreter_new/` — المفسر الشجري

## 2. المترجم (sadc)

```bash
# ترجمة إلى ملف تنفيذي
sadc ملف.ص -o ملف.exe

# أهداف متعددة
sadc --target android ملف.ص
sadc --target ios-swiftui ملف.ص
sadc --target wasm ملف.ص
```

### الملفات
- `tools/compiler/main.cpp` — نقطة الدخول
- `compiler_new/` — المترجم بالكامل

## 3. أداة iOS (sad-ios)

```bash
# إنشاء مشروع جديد
sad-ios أنشئ تطبيقي
sad-ios create MyApp

# بناء
sad-ios ابنِ ./تطبيقي

# تشغيل في المحاكي
sad-ios شغّل ./تطبيقي
```

### الملفات
- `tools/ios/sad_ios_cli.cpp` — نقطة الدخول
- `tools/ios/CMakeLists.txt` — البناء

### البنية المُولَّدة
```
تطبيقي/
├── CMakeLists.txt
├── Info.plist
├── تطبيقيApp.swift
├── ContentView.swift
├── Assets.xcassets/
├── generated/        ← Swift مُولَّد من كود ص
└── sad_sources/
    └── الرئيسية.ص
```

## 4. أداة Android (sad-android)

```bash
# إنشاء مشروع

# بناء APK

# تشغيل في المحاكي
```

### الملفات

## 5. خادم LSP (sad-lsp)

### الميزات
| الميزة | الوصف |
|--------|-------|
| إكمال تلقائي | دوال، متغيرات، أصناف |
| تشخيصات | أخطاء نحوية ومعنوية فورية |
| الانتقال للتعريف | Go to Definition |
| تلميحات عائمة | معلومات النوع والتوثيق |
| رموز دلالية | تلوين ذكي للنحو العربي |
| بحث الرموز | بحث عبر مساحة العمل |
| إجراءات الكود | إصلاحات سريعة وإعادة هيكلة |
| تلميحات مضمنة | أنواع البيانات المستنتجة |

### الملفات الرئيسية
- `tools/lsp/include/lsp_engine.h` — المحرك
- `tools/lsp/src/completion.cpp` — الإكمال
- `tools/lsp/src/diagnostics.cpp` — التشخيصات
- `tools/lsp/src/goto_definition.cpp` — الانتقال
- `tools/lsp/src/hover.cpp` — التلميحات
- `tools/lsp/src/providers/` — مزودات إضافية

## 6. إضافة VS Code

### الميزات
- تلوين نحوي لملفات `.ص`
- تكامل LSP كامل
- أيقونات وقوالب عربية
- دعم التشغيل والتصحيح

### الملفات
- `tools/vscode-extension/` — الإضافة الكاملة
- `.github/workflows/publish-extension.yml` — نشر تلقائي

### التثبيت
```bash
# من VSIX مُسبق البناء
code --install-extension tools/vscode-extension/*.vsix
```

## البناء الكامل

```powershell
# بناء كل شيء
cmake --build build --config Debug

# بناء أداة محددة
cmake --build build --config Debug --target sad
cmake --build build --config Debug --target sadc
cmake --build build --config Debug --target sad-ios
cmake --build build --config Debug --target sad-android
```
