# الخطة الإستراتيجية الشاملة — لغة ص البرمجية
# Strategic Master Plan — Sad Programming Language

> **الرؤية:** لغة ص هي اللغة العربية الإسلامية الأولى التي تكسر هيمنة الإنجليزية على عالم البرمجة — لغة واحدة، كود واحد، كل المنصات.
>
> **الشعار:** "أكتب بالعربية. شغّل في كل مكان."
>
> **تاريخ الإعداد:** مارس 2026

## القسم 1: الهوية والرسالة

### 1.1 لماذا لغة ص؟

| السؤال | الإجابة |
|--------|--------|
| **لماذا نحتاج لغة برمجة عربية؟** | 400+ مليون عربي يتعلمون البرمجة بلغة أجنبية. إزالة حاجز اللغة يُمكّن ملايين المبرمجين الجدد. |
| **لماذا ليست مجرد ترجمة؟** | لغة ص مصممة من الصفر — ليست wrapper على Python. لها مترجم LLVM أصلي ينتج ملفات تنفيذية حقيقية. |
| **ما الذي يميزها عن محاولات سابقة؟** | أول لغة عربية تجمع: مفسر + مترجم أصلي + متعدد المنصات + UI declarative + مكتبة قياسية + أدوات كاملة. |
| **الهوية الإسلامية؟** | مكتبات مدمجة: حساب أوقات الصلاة، تقويم هجري، اتجاه القبلة، أذكار — كجزء من المنظومة (وليس كميزة رئيسية). |

### 1.2 الموقع التنافسي

```
                          أنظمة (Systems)
                              ↑
                         Rust │ Go
                              │
                    ──────────┼──────────→ سهولة الاستخدام
                         C++  │  Python
                              │     JavaScript
                              │        ← لغة ص ●
                              │      (هوية عربية + قدرات كاملة
                              │       + واجهات متعددة المنصات)
                              ↓
                         تطبيقات (Apps)
                         Dart/Flutter
```

**لغة ص = Python السهولة + Dart/Flutter التعدد + العربية الهوية + LLVM الأداء**

### 1.3 الجمهور المستهدف (بالترتيب)

| الشريحة | الحجم | الأولوية |
|---------|-------|---------|
| **مطورون عرب يريدون البرمجة بالعربية** | ملايين | الأولى |
| **معلمون ومدارس وجامعات عربية** | آلاف | الثانية |
| **مطورو تطبيقات عربية (Android/iOS/Web)** | مئات الآلاف | الثالثة |
| **باحثون في لغات البرمجة** | مئات | الرابعة |
| **مطورو أنظمة (OS/Embedded)** | عشرات | الخامسة |

### 2.2 كيف يعمل "كود واحد → كل المنصات"

```sad
# ═══ هذا الكود يعمل على جميع المنصات بدون تعديل ═══

استورد واجهات

دالة رئيسية()
    متغير التطبيق = عمود(
        خلفية: "أبيض"،
        حشوة: 16،

        نص_واجهة("أهلًا بك في تطبيق ص!"،
            حجم_خط: 24،
            عريض: صحيح
        )،

        صف(
            تباعد: 8،
            زر("سجّل"، لون_زر: "أزرق"، عند_الضغط: لامدا()
                اطبع_سطر("تم التسجيل!")
            نهاية)،
            زر("خروج"، لون_زر: "أحمر"، عند_الضغط: لامدا()
                اطبع_سطر("وداعًا!")
            نهاية)
        )
    )

    اعرض(التطبيق)
نهاية
```

ثم:
```bash
# سطح المكتب (Windows/Linux/macOS)
sad شغّل تطبيق.ص

# ملف تنفيذي أصلي
sadc تطبيق.ص --هدف سطح_مكتب --اخرج تطبيق.exe

# Android APK
sadc تطبيق.ص --هدف أندرويد --اخرج تطبيق.apk

# iOS
sadc تطبيق.ص --هدف ios --اخرج تطبيق.ipa

# Web (WASM)
sadc تطبيق.ص --هدف ويب --اخرج تطبيق/

# Embedded
sadc تطبيق.ص --هدف esp32 --اخرج firmware.bin
```

### 3.2 جدول المقارنة: الحالي → المقترح

| الحالي | المقترح | السبب |
|--------|---------|------|
| `shared/` | `src/core/` | أوضح كمركز |
| `interpreter_new/` | `src/interpreter/` | حذف `_new` |
| `compiler_new/` | `src/compiler/` | حذف `_new` |
| `vm/` | `src/vm/` | داخل `src/` |
| `stdlib/` | `lib/` | أقصر، عرف صناعي |
| `tools/` (60+ مجلد) | `tools/` (8 مجلدات أساسية) | حذف الفارغة |
| `distribution/` | `dist/` | أقصر |
| `runtime_new/` | **حذف** | معطّل |
| `graphics/` | `lib/graphics/` | جزء من المكتبة |
| `network/` | `lib/net/` | جزء من المكتبة |
| `200+ ملف في الجذر` | **نقل** إلى `temp/` أو `.artifacts/` | تنظيف |

## القسم 4: بنية اللغة — التصميم القابل للتوسع

### 4.1 نظام الأنواع الموسّع (v1.0)

```
نظام الأنواع في لغة ص v1.0:
═══════════════════════════

أنواع أولية (Primitive Types):
├── رقم        (int64)      — عدد صحيح 64-بت
├── عشري       (float64)    — عدد عشري 64-بت
├── نص         (string)     — سلسلة UTF-8
├── منطقي      (bool)       — صحيح/خطأ
├── بايت       (u8)         — بايت واحد
├── حرف        (char)       — حرف يونيكود
├── فراغ       (void)       — لا قيمة
└── عدم/لاشيء  (null)       — قيمة فارغة

أنواع مركّبة (Compound Types):
├── مصفوفة<ن>  (Array<T>)   — مصفوفة متجانسة
├── خريطة<م,ن> (Map<K,V>)   — قاموس
├── مجموعة<ن>  (Set<T>)     — مجموعة فريدة
├── ثنائي<أ,ب> (Tuple<A,B>) — مجموعة ثابتة الحجم
└── اختياري<ن> (Option<T>)  — قيمة أو لاشيء (نوع?)

أنواع كائنية (Object Types):
├── صنف        (class)      — نوع مرجعي مع وراثة
├── بنية       (struct)     — نوع قيمة بدون وراثة
├── تعداد      (enum)       — مجموعة حالات
├── سمة        (trait)      — واجهة مجردة
└── لامدا      (lambda)     — دالة مجهولة

أنواع منخفضة المستوى (Low-Level — للمترجم فقط):
├── u8, u16, u32, u64       — أعداد بدون إشارة
├── i8, i16, i32, i64       — أعداد بإشارة
├── ptr<ن>                  — مؤشر
├── usize, isize            — حجم المنصة
└── مصفوفة_ثابتة[ن; حجم]   — مصفوفة ثابتة الحجم
```

### 4.2 نظام الوحدات (Module System)

```sad
# ═══ استيراد مكتبة قياسية ═══
استورد رياضيات                    # كل الوحدة
استورد رياضيات.جيب_تمام           # دالة محددة
استورد شبكات.http كـ خادم         # باسم مستعار

# ═══ استيراد حزمة خارجية ═══
استورد "sad-db" كـ قاعدة_بيانات   # من مستودع الحزم

# ═══ استيراد محلي ═══
استورد "./مساعدات.ص"              # ملف في نفس المشروع
من "./نماذج.ص" استورد مستخدم، مقال

# ═══ تصدير ═══
صدّر دالة حساب_المجموع(أ، ب)
    ارجع أ + ب
نهاية

صدّر صنف قاعدة_بيانات
    # ...
نهاية
```

### 6.1 طبقة التجريد الموحدة (Platform Abstraction Layer)

```
┌─────────────────────────────────────────────────┐
│           sad_platform_api.h                    │
│                                                 │
│  struct SadPlatform {                           │
│    // ═══ واجهة ═══                             │
│    void (*create_window)(...)                   │
│    void (*render_widget)(...)                   │
│    void (*handle_input)(...)                    │
│    void (*play_audio)(...)                      │
│    void (*access_camera)(...)                   │
│    void (*get_location)(...)                    │
│    void (*send_notification)(...)               │
│    void (*read_file)(...)                       │
│    void (*http_request)(...)                    │
│  }                                              │
│                                                 │
│  // التحديد التلقائي:                           │
│  #if __ANDROID__                                │
│    → SadPlatformAndroid                         │
│  #elif __APPLE__                                │
│    → SadPlatformIOS / SadPlatformMacOS          │
│  #elif __EMSCRIPTEN__                           │
│    → SadPlatformWeb                             │
│  #else                                          │
│    → SadPlatformDesktop (SDL2)                  │
│  #endif                                         │
└─────────────────────────────────────────────────┘
```

### 6.2 خط أنابيب الترجمة لكل منصة

| المنصة | الخط | النتيجة |
|--------|------|--------|
| **Desktop** | `.ص → AST → SIR → LLVM IR → x86_64/ARM64 native` | `.exe` / ELF / Mach-O |
| **Android** | `.ص → AST → Kotlin Compose → Gradle → APK` | `.apk` مع UI أصلي |
| **iOS** | `.ص → AST → Swift/SwiftUI → Xcode → IPA` | `.ipa` مع UI أصلي |
| **Web** | `.ص → AST → SIR → LLVM IR → WASM32` + HTML/JS | SPA مع Canvas |
| **Embedded** | `.ص → AST → SIR → LLVM IR → ARM (bare metal)` | Firmware |
| **المفسر** | `.ص → AST → تنفيذ مباشر` | تشغيل فوري (للتطوير) |

## القسم 8: الخلاصة

> هدفنا ليس فقط بناء لغة تعمل، بل بناء **منظومة كاملة** تُثبت أن العربية قادرة على قيادة عالم البرمجة.
