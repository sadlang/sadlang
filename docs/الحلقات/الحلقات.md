# الحلقات في لغة ص

## نظرة عامة

لغة ص توفر نوعين رئيسيين من الحلقات: `بينما` (while) و`لكل` (for-each)، مع دعم عبارات التحكم `اخرج` (break) و`تابع` (continue).

---

## حلقة `بينما` (While)

### الصيغة الأساسية

```sad
بينما (شرط)
    # كود يتكرر طالما الشرط صحيح
نهاية
```

### الكتابة البديلة

يمكن أيضاً استخدام `طالما` بدلاً من `بينما`:

```sad
طالما (شرط)
    # نفس السلوك
نهاية
```

---

## حلقة `لكل` (For-Each)

### التكرار على مصفوفة

```sad
لكل عنصر في مصفوفة
    # كود يُنفّذ لكل عنصر
نهاية
```

### التكرار على نطاق (Range)

```sad
لكل ي في 1..10
    # يتكرر من 1 إلى 10
نهاية
```

### التكرار على نص (الأحرف)

```sad
لكل حرف في "مرحبا"
    اطبع(حرف)
نهاية
```

### التكرار على مصفوفة مُضمّنة

```sad
لكل عنصر في [10، 20، 30]
    اطبع_سطر(عنصر)
نهاية
```

---

## عبارات التحكم في الحلقات

### `اخرج` / `توقف` (Break)

إنهاء الحلقة فوراً:

```sad
بينما (صحيح)
    # ...
    إذا (شرط)
        اخرج
    نهاية
نهاية
```

**البدائل:** `اخرج`، `توقف`، `break`

### `تابع` / `استمر` (Continue)

تخطي باقي التكرار الحالي والانتقال للتالي:

```sad
لكل ي في 1..10
    إذا (ي % 2 == 0)
        تابع    # تخطي الأرقام الزوجية
    نهاية
    اطبع_سطر(ي)
نهاية
```

**البدائل:** `تابع`، `استمر`، `continue`

## عامل النطاق `..`

```sad
متغير نطاق1 = 1..5      # [1, 2, 3, 4, 5] تصاعدي
متغير نطاق2 = 5..1      # [5, 4, 3, 2, 1] تنازلي
```

يمكن أيضاً استخدام دالة `مدى()`:

```sad
متغير أرقام = مدى(1، 10)    # [1, 2, ..., 10]
```
