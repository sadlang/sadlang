# 3. العمليات والتعبيرات

## العمليات الحسابية

| العملية | الرمز | مثال | النتيجة |
|---------|-------|------|---------|
| جمع | `+` | `10 + 3` | `13` |
| طرح | `-` | `10 - 3` | `7` |
| ضرب | `*` | `10 * 3` | `30` |
| قسمة | `/` | `10 / 3` | `3.33..` |
| باقي القسمة | `%` | `10 % 3` | `1` |
| الأس | `**` | `2 ** 8` | `256` |

## عمليات المقارنة

| العملية | الرمز | مثال |
|---------|-------|------|
| يساوي | `==` | `س == 10` |
| لا يساوي | `!=` | `س != 10` |
| أكبر من | `>` | `س > 10` |
| أصغر من | `<` | `س < 10` |
| أكبر أو يساوي | `>=` | `س >= 10` |
| أصغر أو يساوي | `<=` | `س <= 10` |

## العمليات المنطقية

| العملية | الرمز | البديل العربي |
|---------|-------|--------------|
| و (AND) | `&&` | `و` |
| أو (OR) | `\|\|` | `أو` |
| ليس (NOT) | `!` | `ليس` |

## عمليات الإسناد

| العملية | الرمز | المعنى |
|---------|-------|--------|
| إسناد | `=` | `س = 10` |
| إسناد مع جمع | `+=` | `س += 5` يعني `س = س + 5` |
| إسناد مع طرح | `-=` | `س -= 5` يعني `س = س - 5` |
| إسناد مع ضرب | `*=` | `س *= 5` يعني `س = س * 5` |
| إسناد مع قسمة | `/=` | `س /= 5` يعني `س = س / 5` |

## العامل الثلاثي

```sad
متغير نتيجة = شرط ? قيمة_إذا_صحيح : قيمة_إذا_خطأ
```

## عملية دمج النصوص

```sad
متغير جملة = "مرحباً" + " " + "بالعالم"    # "مرحباً بالعالم"
```

## عملية العضوية

```sad
# الكلمة المفتاحية "في" للتحقق من وجود عنصر
متغير موجود = 3 في [1، 2، 3، 4]    # صحيح
```

## 🔸 الأمثلة (8 أمثلة متدرجة)

### مثال 1 — مبتدئ: العمليات الحسابية الأساسية
```sad
رقم أ = 10
رقم ب = 3

اطبع_سطر("الجمع: " + (أ + ب))
اطبع_سطر("الطرح: " + (أ - ب))
اطبع_سطر("الضرب: " + (أ * ب))
اطبع_سطر("القسمة: " + (أ / ب))
اطبع_سطر("الباقي: " + (أ % ب))
```
**المخرجات:**
```
الجمع: 13
الطرح: 7
الضرب: 30
القسمة: 3.33333
الباقي: 1
```

### مثال 2 — مبتدئ: المقارنات
```sad
رقم س = 15
رقم ص = 20

اطبع_سطر("س == ص: " + (س == ص))
اطبع_سطر("س != ص: " + (س != ص))
اطبع_سطر("س > ص: " + (س > ص))
اطبع_سطر("س < ص: " + (س < ص))
اطبع_سطر("س >= 15: " + (س >= 15))
اطبع_سطر("ص <= 20: " + (ص <= 20))
```
**المخرجات:**
```
س == ص: خطأ
س != ص: صحيح
س > ص: خطأ
س < ص: صحيح
س >= 15: صحيح
ص <= 20: صحيح
```

### مثال 3 — مبتدئ: العمليات المنطقية
```sad
متغير أ = صحيح
متغير ب = خطأ

اطبع_سطر("أ && ب: " + (أ && ب))
اطبع_سطر("أ || ب: " + (أ || ب))
اطبع_سطر("!أ: " + (!أ))
اطبع_سطر("!ب: " + (!ب))
```
**المخرجات:**
```
أ && ب: خطأ
أ || ب: صحيح
!أ: خطأ
!ب: صحيح
```

### مثال 4 — مبتدئ: الإسناد المركب
```sad
متغير س = 10
اطبع_سطر("القيمة الأولية: " + س)

س += 5
اطبع_سطر("بعد += 5: " + س)

س -= 3
اطبع_سطر("بعد -= 3: " + س)

س *= 2
اطبع_سطر("بعد *= 2: " + س)

س /= 4
اطبع_سطر("بعد /= 4: " + س)
```
**المخرجات:**
```
القيمة الأولية: 10
بعد += 5: 15
بعد -= 3: 12
بعد *= 2: 24
بعد /= 4: 6
```

### مثال 5 — متوسط: العامل الثلاثي
```sad
رقم درجة = 85

متغير التقدير = درجة >= 90 ? "ممتاز" : درجة >= 80 ? "جيد جداً" : "جيد"
اطبع_سطر("الدرجة: " + درجة + " = " + التقدير)

رقم عمر = 20
متغير الحالة = عمر >= 18 ? "بالغ" : "قاصر"
اطبع_سطر("العمر: " + عمر + " = " + الحالة)

رقم رقم1 = 7
متغير نوع = رقم1 % 2 == 0 ? "زوجي" : "فردي"
اطبع_سطر("الرقم " + رقم1 + " = " + نوع)
```
**المخرجات:**
```
الدرجة: 85 = جيد جداً
العمر: 20 = بالغ
الرقم 7 = فردي
```

### مثال 6 — متوسط: عملية الأس ودمج النصوص
```sad
# الأس
اطبع_سطر("2 ** 10 = " + (2 ** 10))
اطبع_سطر("3 ** 4 = " + (3 ** 4))
اطبع_سطر("5 ** 3 = " + (5 ** 3))

# دمج النصوص مع أرقام
متغير الاسم = "أحمد"
رقم العمر = 25
متغير الجملة = "اسمي " + الاسم + " وعمري " + العمر + " سنة"
اطبع_سطر(الجملة)

# += مع النصوص
متغير نص1 = "مرحبا"
نص1 += " يا"
نص1 += " عالم"
اطبع_سطر(نص1)
```
**المخرجات:**
```
2 ** 10 = 1024
3 ** 4 = 81
5 ** 3 = 125
اسمي أحمد وعمري 25 سنة
مرحبا يا عالم
```

### مثال 7 — متقدم: تعبيرات مركبة
```sad
دالة مساحة_دائرة(نصف_قطر)
    ارجع 3.14159 * نصف_قطر * نصف_قطر
نهاية

دالة مساحة_مستطيل(طول، عرض)
    ارجع طول * عرض
نهاية

دالة مساحة_مثلث(قاعدة، ارتفاع)
    ارجع قاعدة * ارتفاع / 2
نهاية

# حساب مساحات متعددة
رقم ق = 5
رقم ط = 10
رقم ع = 6

اطبع_سطر("مساحة دائرة نصف قطرها " + ق + " = " + مساحة_دائرة(ق))
اطبع_سطر("مساحة مستطيل " + ط + "×" + ع + " = " + مساحة_مستطيل(ط، ع))
اطبع_سطر("مساحة مثلث قاعدته " + ط + " وارتفاعه " + ع + " = " + مساحة_مثلث(ط، ع))

# أيها الأكبر؟
متغير م_دائرة = مساحة_دائرة(ق)
متغير م_مستطيل = مساحة_مستطيل(ط، ع)
متغير م_مثلث = مساحة_مثلث(ط، ع)

متغير الأكبر = م_دائرة > م_مستطيل ? (م_دائرة > م_مثلث ? "الدائرة" : "المثلث") : (م_مستطيل > م_مثلث ? "المستطيل" : "المثلث")
اطبع_سطر("الشكل الأكبر مساحة: " + الأكبر)
```
**المخرجات:**
```
مساحة دائرة نصف قطرها 5 = 78.5398
مساحة مستطيل 10×6 = 60
مساحة مثلث قاعدته 10 وارتفاعه 6 = 30
الشكل الأكبر مساحة: الدائرة
```

### مثال 8 — متقدم جداً: محرك حسابات كامل
```sad
# آلة حاسبة مع سجل العمليات

متغير عدد_العمليات = 0
متغير مجموع_النتائج = 0

دالة سجّل(عملية، نتيجة)
    عدد_العمليات = عدد_العمليات + 1
    مجموع_النتائج = مجموع_النتائج + نتيجة
    اطبع_سطر("  [" + عدد_العمليات + "] " + عملية + " = " + نتيجة)
نهاية

دالة رئيسية()
    اطبع_سطر("═══════════════════════════════")
    اطبع_سطر("   محرك الحسابات المتقدم")
    اطبع_سطر("═══════════════════════════════")
    
    # عمليات حسابية أساسية
    اطبع_سطر("")
    اطبع_سطر("▶ العمليات الأساسية:")
    سجّل("15 + 27", 15 + 27)
    سجّل("100 - 37", 100 - 37)
    سجّل("12 * 8", 12 * 8)
    سجّل("144 / 12", 144 / 12)
    سجّل("17 % 5", 17 % 5)
    
    # عمليات الأس
    اطبع_سطر("")
    اطبع_سطر("▶ الأسس:")
    سجّل("2 ** 16", 2 ** 16)
    سجّل("10 ** 3", 10 ** 3)
    
    # عمليات مركبة
    اطبع_سطر("")
    اطبع_سطر("▶ تعبيرات مركبة:")
    سجّل("(5 + 3) * 2 - 1", (5 + 3) * 2 - 1)
    سجّل("100 / (2 + 3)", 100 / (2 + 3))
    
    # إسناد مركب
    اطبع_سطر("")
    اطبع_سطر("▶ الإسناد المركب:")
    متغير ر = 100
    ر += 50
    سجّل("100 += 50", ر)
    ر -= 30
    سجّل("-= 30", ر)
    ر *= 2
    سجّل("*= 2", ر)
    
    # الملخص
    اطبع_سطر("")
    اطبع_سطر("═══════════════════════════════")
    اطبع_سطر("  عدد العمليات: " + عدد_العمليات)
    اطبع_سطر("  مجموع النتائج: " + مجموع_النتائج)
    اطبع_سطر("  المتوسط: " + (مجموع_النتائج / عدد_العمليات))
    اطبع_سطر("═══════════════════════════════")
نهاية
```
