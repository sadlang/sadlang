# الآلة الافتراضية ومحرك JIT — دليل المطور

## نظرة عامة

الآلة الافتراضية (VM) هي المكون المسؤول عن تنفيذ بايت كود لغة ص. تعمل بنموذج المكدس (stack-based) وتدعم 43+ تعليمة بأسماء عربية.

## البنية المعمارية

```
كود ص (.ص)
    ↓
المحلل المعجمي (Lexer)
    ↓
المحلل النحوي (Parser)
    ↓
شجرة AST
    ↓
    ├── المفسر الشجري (interpreter_new/)
    │   يمشي على AST مباشرة
    │
    └── مولّد البايت كود (vm/)
        ↓
    بايت كود VM
        ↓
        ├── تنفيذ بالآلة الافتراضية (بطيء، متوافق)
        └── JIT (سريع، يحتاج LLVM)
```

## محرك JIT (خالد — أبريل 2026)

### ما هو JIT؟
JIT (Just-In-Time) يحوّل البايت كود إلى كود أصلي (native) أثناء التشغيل، مما يوفر أداء أعلى بكثير من التفسير.

### كيف يعمل؟

1. **المرحلة الأولى — التنميط**: VM يُنفذ البايت كود عادياً ويحسب عدد استدعاءات كل دالة
2. **العتبة**: عند وصول دالة إلى 100 استدعاء، يتم تجميعها JIT بمستوى O1
3. **إعادة التجميع**: عند 1100 استدعاء، يُعاد التجميع بمستوى O3
4. **ذاكرة التخبئة**: الدوال المُجمّعة تُخزن في ذاكرة تخبئة (64MB، LRU)

### الاستخدام في C++

```cpp
#include "sad_jit.h"
using namespace Sad;

// إنشاء محرك JIT بإعدادات افتراضية
إعدادات_JIT إعدادات;
محرك_JIT jit(إعدادات);

// تهيئة (تحتاج LLVM)
if (jit.هيّئ()) {
    // تسجيل دالة
    jit.سجّل_دالة("جمع", بايت_كود_الدالة);
    
    // الترجمة الفورية
    jit.ترجم_فوراً("جمع", مستوى_التحسين::O2);
    
    // طباعة تقرير الأداء
    jit.اطبع_التقرير();
}
```

### الإعدادات

```cpp
إعدادات_JIT إعدادات;
إعدادات.عتبة_الترجمة = 100;           // متى يبدأ التجميع
إعدادات.عتبة_إعادة_الترجمة = 1100;    // متى يُعاد التجميع بـ O3
إعدادات.أقصى_حجم_ذاكرة = 64 * 1024 * 1024;  // 64MB
إعدادات.تحسين_تكيفي = true;           // تحسين تكيفي
إعدادات.مستوى_التسجيل = 1;            // مستوى الطباعة
```

### البناء

```powershell
# بناء مع دعم JIT (يحتاج LLVM)
cmake -S . -B build -DENABLE_LLVM_BACKEND=ON
cmake --build build --target sad_vm

# بناء بدون LLVM (وضع التنميط فقط)
cmake --build build --target sad_vm
```
