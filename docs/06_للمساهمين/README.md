# للمساهمين في التوثيق

> 🟢 مكتمل

مرحباً بك في مجتمع لغة ص!

## ابدأ هنا

1. اقرأ [دستور التوثيق](../CONTRIBUTING_DOCS.md) — القواعد الإلزامية
2. اقرأ [دليل الأسلوب](../STYLE_GUIDE.md) — كيف تكتب
3. استخدم [مرجع القوالب](../TEMPLATE_REFERENCE.md) — قوالب جاهزة

## كيف تساهم

1. انظر قائمة الملفات بعلامة 🔴 (فارغ) في أي قسم
2. اختر ملفاً تريد كتابته
3. انسخ القالب المناسب من [مرجع القوالب](../TEMPLATE_REFERENCE.md)
4. اكتب المحتوى
5. شغّل أدوات التحقق:
   `
   python scripts/validate_docs.py docs/
   python scripts/test_doc_examples.py docs/
   `
6. افتح Pull Request

## أهم القواعد

- كل مثال كود يجب أن يشمل # الناتج: ...
- YAML frontmatter إلزامي في كل ملف
- راجع [دستور التوثيق](../CONTRIBUTING_DOCS.md) للتفاصيل الكاملة
