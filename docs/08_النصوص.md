# 8. النصوص

## إنشاء النصوص

```sad
نص اسم = "أحمد"
متغير رسالة = "مرحباً بالعالم"
```

## دمج النصوص
```sad
متغير جملة = "مرحباً" + " " + "يا" + " " + "عالم"
```

## النصوص المنسقة (F-Strings)

استخدم `م"..."` لتضمين تعبيرات داخل النص:
```sad
متغير اسم = "أحمد"
اطبع_سطر(م"مرحباً {اسم}!")
اطبع_سطر(م"2 + 3 = {2 + 3}")
```

## دوال النصوص المدمجة

| الدالة | الوصف |
|--------|-------|
| `طول_نص(نص)` | طول النص |
| `تحويل_كبير(نص)` | تحويل للأحرف الكبيرة |
| `تحويل_صغير(نص)` | تحويل للأحرف الصغيرة |
| `استبدل(نص، قديم، جديد)` | استبدال نص فرعي |
| `استخراج(نص، بداية، نهاية)` | استخراج جزء |
| `قص_أطراف(نص)` | إزالة المسافات |
| `يبدأ_ب(نص، بادئة)` | هل يبدأ بـ |
| `ينتهي_ب(نص، لاحقة)` | هل ينتهي بـ |
| `يحتوي_على(نص، فرعي)` | هل يحتوي على |
| `بحث(نص، فرعي)` | موقع النص الفرعي |

## طرق النصوص (dot syntax)

```sad
متغير نص1 = "HELLO"
اطبع_سطر(نص1.تحويل_صغير())
اطبع_سطر(نص1.toLower())

متغير نص2 = "hello"
اطبع_سطر(نص2.تحويل_كبير())

متغير نص3 = "مرحبا بالعالم"
اطبع_سطر(نص3.بحث("بال"))
```

## 🔸 الأمثلة (8 أمثلة متدرجة)

### مثال 1 — مبتدئ: إنشاء ودمج النصوص
```sad
نص الاسم = "أحمد"
نص التحية = "مرحباً يا "
متغير الجملة = التحية + الاسم + "!"
اطبع_سطر(الجملة)

# دمج نص مع رقم
رقم العمر = 25
اطبع_سطر("العمر: " + العمر + " سنة")
```
**المخرجات:**
```
مرحباً يا أحمد!
العمر: 25 سنة
```

### مثال 2 — مبتدئ: طول النص
```sad
متغير نص1 = "Hello"
متغير نص2 = "مرحباً"

اطبع_سطر("طول 'Hello' = " + طول_نص(نص1))
اطبع_سطر("طول 'مرحباً' = " + طول_نص(نص2))
اطبع_سطر("طول 'سلام' = " + طول("سلام"))
```
**المخرجات:**
```
طول 'Hello' = 5
طول 'مرحباً' = 6
طول 'سلام' = 4
```

### مثال 3 — مبتدئ: تحويل الحالة
```sad
متغير نص1 = "HELLO WORLD"
اطبع_سطر("تحويل للصغير: " + تحويل_صغير(نص1))

متغير نص2 = "hello world"
اطبع_سطر("تحويل للكبير: " + تحويل_كبير(نص2))

# باستخدام طريقة النقطة
متغير نص3 = "Hello"
اطبع_سطر("toLower: " + نص3.toLower())
```
**المخرجات:**
```
تحويل للصغير: hello world
تحويل للكبير: HELLO WORLD
toLower: hello
```

### مثال 4 — متوسط: النصوص المنسقة (F-Strings)
```sad
# متغير بسيط
متغير الاسم = "أحمد"
اطبع_سطر(م"مرحباً {الاسم}!")

# تعبير حسابي
متغير س = 10
متغير ع = 5
اطبع_سطر(م"المجموع: {س + ع}")

# استدعاء دالة
دالة مربع(ق)
    ارجع ق * ق
نهاية
اطبع_سطر(م"مربع 7: {مربع(7)}")

# عدة تعبيرات
متغير أ = 3
متغير ب = 4
اطبع_سطر(م"{أ} + {ب} = {أ + ب}")

# تعبير مقارنة
اطبع_سطر(م"10 > 5: {10 > 5}")
```
**المخرجات:**
```
مرحباً أحمد!
المجموع: 15
مربع 7: 49
3 + 4 = 7
10 > 5: صحيح
```

### مثال 5 — متوسط: البحث والاستبدال
```sad
متغير نص_أصلي = "مرحبا بالعالم العربي"

# بحث
اطبع_سطر("موقع 'بال': " + بحث(نص_أصلي، "بال"))

# يحتوي على
اطبع_سطر("يحتوي على 'العربي': " + يحتوي_على(نص_أصلي، "العربي"))
اطبع_سطر("يحتوي على 'xyz': " + يحتوي_على(نص_أصلي، "xyz"))

# استبدال
متغير نص_جديد = استبدل("Hello World"، "World"، "Sad")
اطبع_سطر("استبدال: " + نص_جديد)

# يبدأ / ينتهي
اطبع_سطر("يبدأ بـ 'Hello': " + يبدأ_ب("Hello World"، "Hello"))
اطبع_سطر("ينتهي بـ 'ld': " + ينتهي_ب("World"، "ld"))
```
**المخرجات:**
```
موقع 'بال': 7
يحتوي على 'العربي': صحيح
يحتوي على 'xyz': خطأ
استبدال: Hello Sad
يبدأ بـ 'Hello': صحيح
ينتهي بـ 'ld': صحيح
```

### مثال 6 — متوسط: استخراج وقص
```sad
# استخراج جزء من نص
متغير نص1 = "Hello World"
اطبع_سطر("استخراج(1,5): " + استخراج(نص1، 1، 5))

# قص المسافات
متغير نص2 = "  test  "
اطبع_سطر("[" + قص_أطراف(نص2) + "]")

# طرق النقطة على النصوص
متغير نص3 = "مرحبا بالعالم"
اطبع_سطر("بحث عن 'بال': " + نص3.بحث("بال"))
```
**المخرجات:**
```
استخراج(1,5): ello
[test]
بحث عن 'بال': 7
```

### مثال 7 — متقدم: معالج نصوص
```sad
دالة عدد_الكلمات(نص_م)
    متغير عدد = 1
    متغير ط = طول_نص(نص_م)
    متغير ع = 0
    بينما (ع < ط)
        متغير حرف = استخراج(نص_م، ع، ع + 1)
        إذا (حرف == " ")
            عدد = عدد + 1
        نهاية
        ع = ع + 1
    نهاية
    ارجع عدد
نهاية

دالة كرر_نص(نص_م، مرات)
    متغير نتيجة = ""
    متغير ع = 0
    بينما (ع < مرات)
        نتيجة = نتيجة + نص_م
        ع = ع + 1
    نهاية
    ارجع نتيجة
نهاية

متغير جملة = "لغة ص البرمجية رائعة"
اطبع_سطر("النص: " + جملة)
اطبع_سطر("الطول: " + طول_نص(جملة))
اطبع_سطر("عدد الكلمات: " + عدد_الكلمات(جملة))
اطبع_سطر("تكرار '=-': " + كرر_نص("=-"، 15))
```
**المخرجات:**
```
النص: لغة ص البرمجية رائعة
الطول: 21
عدد الكلمات: 4
تكرار '=-': =-=-=-=-=-=-=-=-=-=-=-=-=-=-=-
```

### مثال 8 — متقدم جداً: نظام قوالب نصية
```sad
# نظام قوالب بسيط باستخدام النصوص المنسقة

صنف قالب_رسالة
    نص النوع
    
    باني(نص نوع)
        النوع = نوع
    نهاية
    
    دالة ترحيب(اسم)
        حالة (النوع)
            عندما "رسمي":
                ارجع م"السيد/السيدة {اسم} المحترم/ة، تحية طيبة وبعد..."
            عندما "ودي":
                ارجع م"أهلاً {اسم}! كيف حالك؟"
            افتراضي:
                ارجع م"مرحباً {اسم}"
        نهاية
    نهاية
    
    دالة فاتورة(عميل، مبلغ، عدد)
        متغير إجمالي = مبلغ * عدد
        ارجع م"═══════════════════════
فاتورة - {النوع}
العميل: {عميل}
سعر الوحدة: {مبلغ}
الكمية: {عدد}
الإجمالي: {إجمالي}
═══════════════════════"
    نهاية
نهاية

# استخدام القوالب
متغير رسمي = جديد قالب_رسالة("رسمي")
متغير ودي = جديد قالب_رسالة("ودي")

اطبع_سطر(رسمي.ترحيب("محمد"))

اطبع_سطر(رسمي.فاتورة("شركة النور"، 150، 20))
```
**المخرجات:**

```
السيد/السيدة محمد المحترم/ة، تحية طيبة وبعد...
أهلاً فاطمة! كيف حالك؟

═══════════════════════

```
