# مكتبة شبكات — وثائق واجهة برمجة التطبيقات (API)

> **الاستيراد:** `استورد شبكات`
>
> توفر هذه المكتبة واجهة كائنية كاملة لعمليات الشبكة.
> تُغلّف الوحدتين المضمّنتين `مقابس` (TCP/UDP) و`شبكة` (HTTP + عناوين IP).

| الصنف | الوظيفة |

## صنف مقبس_اتصال

مقبس TCP كائني. يدعم نمطَي **العميل** (للاتصال بخادم) و**الخادم** (لقبول الاتصالات).

### الباني

```sad
متغير م = مقبس_اتصال()           # مقبس جديد
متغير م = مقبس_اتصال(معرّف)      # تغليف معرّف موجود (ناتج عن اقبل)
```

### الطرق

| الميثود | المعاملات | القيمة المُرجعة | الوصف |
|---------|-----------|----------------|-------|
| `ربط(منفذ)` | `منفذ: رقم` | `منطقي` | ربط بمنفذ محلي (0 = تلقائي) |
| `استمع(طاقة?)` | `طاقة: رقم?` | `منطقي` | الاستماع للاتصالات الواردة |
| `اقبل()` | — | `مقبس_اتصال \| لاشيء` | قبول اتصال وارد → مقبس جديد |
| `اتصل(مضيف، منفذ)` | `مضيف: نص`، `منفذ: رقم` | `منطقي` | الاتصال بخادم بعيد |
| `أرسل(بيانات)` | `بيانات: نص` | `رقم` | إرسال بيانات |
| `استقبل(حجم?)` | `حجم: رقم?` | `نص` | استقبال بيانات |
| `أغلق()` | — | `منطقي` | إغلاق المقبس |
| `متصلة()` | — | `منطقي` | هل المقبس متصل؟ |
| `عنوان_الطرف()` | — | `نص` | عنوان الطرف الآخر بصيغة "IP:منفذ" |
| `حدد_مهلة_الاستقبال(مللي)` | `مللي: رقم` | `منطقي` | مهلة استقبال البيانات |
| `حدد_مهلة_الإرسال(مللي)` | `مللي: رقم` | `منطقي` | مهلة إرسال البيانات |
| `أرسل_فوراً(تفعيل)` | `تفعيل: منطقي` | `منطقي` | تعطيل/تفعيل خوارزمية Nagle |
| `المنفذ()` | — | `رقم` | رقم المنفذ المحلي |
| `هل_صالح()` | — | `منطقي` | هل المقبس مفتوح؟ |

### مثال: عميل TCP

```sad
استورد شبكات

متغير عميل = مقبس_اتصال()
عميل.حدد_مهلة_الاستقبال(3000)
إذا (عميل.اتصل("127.0.0.1"، 8080))
    عميل.أرسل("مرحبا بالخادم!")
    اطبع_سطر(عميل.استقبل())
نهاية
عميل.أغلق()
```

### مثال: خادم TCP

```sad
استورد شبكات

متغير خادم = مقبس_اتصال()
خادم.ربط(8080)
خادم.استمع()
متغير وصلة = خادم.اقبل()
إذا (وصلة != لاشيء)
    اطبع_سطر(وصلة.استقبل())
    وصلة.أرسل("وصلني رسالتك!")
    وصلة.أغلق()
نهاية
خادم.أغلق()
```

## صنف مقبس_رسائل

مقبس UDP كائني. لا يضمن الترتيب أو الوصول، لكنه أسرع من TCP.

### الباني

```sad
متغير م = مقبس_رسائل()
```

### الميثودات

| الميثود | المعاملات | القيمة المُرجعة | الوصف |
|---------|-----------|----------------|-------|
| `ربط(منفذ)` | `منفذ: رقم` | `منطقي` | ربط بمنفذ (0 = تلقائي) |
| `أرسل_لـ(بيانات، مضيف، منفذ)` | `بيانات: نص`، `مضيف: نص`، `منفذ: رقم` | `رقم` | إرسال رسالة UDP |
| `استقبل(حجم?)` | `حجم: رقم?` | `نص` | استقبال رسالة UDP |
| `أغلق()` | — | `منطقي` | إغلاق المقبس |
| `حدد_مهلة_الاستقبال(مللي)` | `مللي: رقم` | `منطقي` | مهلة الاستقبال |
| `حدد_مهلة_الإرسال(مللي)` | `مللي: رقم` | `منطقي` | مهلة الإرسال |
| `المنفذ()` | — | `رقم` | رقم المنفذ المحلي |
| `هل_صالح()` | — | `منطقي` | هل المقبس مفتوح؟ |

### مثال

```sad
استورد شبكات

متغير مرسل = مقبس_رسائل()
متغير مستقبل = مقبس_رسائل()
مستقبل.ربط(9000)
مستقبل.حدد_مهلة_الاستقبال(500)
مرسل.أرسل_لـ("رسالة UDP!"، "127.0.0.1"، 9000)
اطبع_سطر(مستقبل.استقبل())
مرسل.أغلق()
مستقبل.أغلق()
```

## صنف عنوان_شبكة

عنوان IP كائني. يدعم IPv4 و IPv6.

### الباني

```sad
متغير ع = عنوان_شبكة(رقم_جهاز، منفذ)        # IPv4 (افتراضي)
متغير ع = عنوان_شبكة(رقم_جهاز، منفذ، 6)     # IPv6
```

| المعامل | النوع | الوصف |
|---------|-------|-------|
| `رقم_جهاز` | `نص` | عنوان IP كنص: `"127.0.0.1"` أو `"::1"` |
| `منفذ` | `رقم` | رقم المنفذ (0 = تلقائي) |
| `نوع` | `رقم?` | 4 أو بدون = IPv4 ، 6 = IPv6 |

### الميثودات

| الميثود | القيمة المُرجعة | الوصف |
|---------|----------------|-------|
| `عنوان_جهاز()` | `نص` | عنوان IP ("127.0.0.1" أو "::1") |
| `عدد_منفذ()` | `رقم` | رقم المنفذ |
| `هل_قديم()` | `منطقي` | هل IPv4؟ |
| `هل_حديث()` | `منطقي` | هل IPv6؟ |
| `كنص()` | `نص` | العنوان الكامل "IP:منفذ" |
| `أغلق()` | — | تحرير الذاكرة |
| `هل_صالح()` | `منطقي` | هل العنوان أُنشئ بنجاح؟ |

### مثال

```sad
استورد شبكات

جهز_الشبكة()

# IPv4
متغير ع4 = عنوان_شبكة("192.168.1.1"، 80)
اطبع_سطر(ع4.عنوان_جهاز())   # "192.168.1.1"
اطبع_سطر(ع4.هل_قديم())      # صحيح
ع4.أغلق()

# IPv6
متغير ع6 = عنوان_شبكة("::1"، 443، 6)
اطبع_سطر(ع6.هل_حديث())      # صحيح
اطبع_سطر(ع6.كنص())          # "::1:443"
ع6.أغلق()

نظف_الشبكة()
```

## صنف متصفح_ويب

عميل HTTP/HTTPS كائني. يدعم جميع أفعال HTTP: GET، POST، PUT، DELETE، PATCH.

### الباني

```sad
متغير م = متصفح_ويب()
```

### الميثودات

#### إعداد العميل

| الميثود | المعاملات | الوصف |
|---------|-----------|-------|
| `اضبط_الرابط(رابط)` | `رابط: نص` | الرابط الأساسي لجميع الطلبات |
| `أضف_رأس(مفتاح، قيمة)` | `مفتاح: نص`، `قيمة: نص` | إضافة ترويسة HTTP مخصصة |
| `اضبط_المهلة(مللي)` | `مللي: رقم` | المهلة القصوى بالمللي ثانية |
| `مصادقة(رمز)` | `رمز: نص` | رمز Bearer للتفويض |

#### إرسال الطلبات

| الميثود | المعاملات | الفعل | الوصف |
|---------|-----------|-------|-------|
| `استرجع(مسار)` | `مسار: نص` | GET | جلب بيانات |
| `أرسل_طلب(مسار، بيانات)` | `مسار: نص`، `بيانات: نص` | POST | إرسال بيانات جديدة |
| `أرسل_تحديث(مسار، بيانات)` | `مسار: نص`، `بيانات: نص` | PUT | استبدال بيانات |
| `أحذف(مسار)` | `مسار: نص` | DELETE | حذف مورد |
| `رقّع(مسار، بيانات)` | `مسار: نص`، `بيانات: نص` | PATCH | تعديل جزئي |

#### قراءة الاستجابة

| الميثود | القيمة المُرجعة | الوصف |
|---------|----------------|-------|
| `ناجح()` | `منطقي` | هل اكتمل الطلب؟ (حتى لو 404) |
| `الرد_ناجح()` | `منطقي` | هل رمز الحالة 2xx؟ |
| `رمز_الرد()` | `رقم` | رمز HTTP (200، 404، 500...) |
| `جسم_الرد()` | `نص` | محتوى جسم الاستجابة |
| `رأس_الرد(اسم)` | `نص` | قيمة ترويسة محددة |
| `وصف_الخطأ()` | `نص` | وصف آخر خطأ شبكي |
| `أفرغ_الرد()` | — | تحرير ذاكرة الاستجابة |

#### إغلاق

| الميثود | الوصف |
|---------|-------|
| `أغلق()` | إغلاق العميل |
| `هل_صالح()` | هل العميل نشط؟ |

### مثال

```sad
استورد شبكات

متغير م = متصفح_ويب()
م.اضبط_الرابط("https://api.example.com")
م.أضف_رأس("Content-Type"، "application/json")
م.اضبط_المهلة(5000)

م.استرجع("/users")
إذا (م.الرد_ناجح())
    اطبع_سطر("المستخدمون: " + م.جسم_الرد())
وإلا
    اطبع_سطر("خطأ " + نص(م.رمز_الرد()) + ": " + م.وصف_الخطأ())
نهاية

م.أرسل_طلب("/users"، '{"اسم": "أحمد"}')
م.أغلق()
```

## صنف خادم_ويب

خادم HTTP كائني. يدعم تسجيل معالجات المسارات وإعدادات CORS.

### الباني

```sad
متغير خ = خادم_ويب()          # بدون منفذ (يُحدد عند ابدأ)
متغير خ = خادم_ويب(منفذ)      # مع تحديد منفذ مبدئي
```

### الميثودات

#### تسجيل المسارات

| الميثود | المعاملات | الوصف |
|---------|-----------|-------|
| `عند_جلب(مسار، معالج)` | `مسار: نص`، `معالج: دالة` | معالج GET |
| `عند_إرسال(مسار، معالج)` | `مسار: نص`، `معالج: دالة` | معالج POST |
| `عند_استبدال(مسار، معالج)` | `مسار: نص`، `معالج: دالة` | معالج PUT |
| `عند_حذف(مسار، معالج)` | `مسار: نص`، `معالج: دالة` | معالج DELETE |

#### التحكم بالخادم

| الميثود | المعاملات | الوصف |
|---------|-----------|-------|
| `ابدأ(منفذ)` | `منفذ: رقم` | بدء الاستماع على المنفذ |
| `أوقف()` | — | إيقاف الخادم |
| `اسمح_بالوصول(نطاق)` | `نطاق: نص` | تفعيل CORS ("*" = الجميع) |
| `أزل()` | — | إزالة الخادم وتحرير الذاكرة |
| `هل_صالح()` | `منطقي` | هل الخادم نشط؟ |

### مثال

```sad
استورد شبكات

متغير خ = خادم_ويب()
خ.اسمح_بالوصول("*")

خ.عند_جلب("/مرحبا"، لامدا(طلب، رد)
    عين_نص_الرد(رد، "أهلاً بالعالم!")
نهاية)

خ.عند_إرسال("/بيانات"، لامدا(طلب، رد)
    متغير جسم = جسم_الطلب(طلب)
    عين_رمز_الرد(رد، 201)
    عين_نص_الرد(رد، "استلمت: " + جسم)
نهاية)

خ.ابدأ(8080)
# ... تشغيل الخادم ...
خ.أوقف()
خ.أزل()
```

## صنف وصلة_آمنة

اتصال HTTPS/TLS كائني. يُغلّف `متصفح_ويب` داخلياً ويُجبر على بروتوكول `https://`.

### الباني

```sad
متغير و = وصلة_آمنة(مضيف)           # منفذ 443 (افتراضي)
متغير و = وصلة_آمنة(مضيف، منفذ)     # منفذ مخصص
```

| المعامل | النوع | الوصف |
|---------|-------|-------|
| `مضيف` | `نص` | اسم المضيف أو IP بدون `https://` |
| `منفذ` | `رقم?` | اختياري — إذا حُذف يُستخدم 443 |

**ملاحظة:** يُضاف `https://` تلقائياً. لا تكتب البروتوكول في `مضيف`.

### الميثودات

#### الإعداد

| الميثود | المعاملات | الوصف |
|---------|-----------|-------|
| `اضبط_المهلة(مللي)` | `مللي: رقم` | مهلة الانتظار |
| `مصادقة(رمز)` | `رمز: نص` | رمز Bearer |
| `أضف_رأس(مفتاح، قيمة)` | `مفتاح: نص`، `قيمة: نص` | ترويسة مخصصة |

#### الطلبات

| الميثود | المعاملات | الفعل | الوصف |
|---------|-----------|-------|-------|
| `استرجع(مسار)` | `مسار: نص` | GET | جلب آمن |
| `أرسل_طلب(مسار، بيانات)` | `مسار: نص`، `بيانات: نص` | POST | إرسال آمن |
| `أرسل_تحديث(مسار، بيانات)` | `مسار: نص`، `بيانات: نص` | PUT | استبدال آمن |
| `أحذف(مسار)` | `مسار: نص` | DELETE | حذف آمن |
| `رقّع(مسار، بيانات)` | `مسار: نص`، `بيانات: نص` | PATCH | تعديل آمن |

#### الاستجابة والإغلاق

| الميثود | القيمة المُرجعة | الوصف |
|---------|----------------|-------|
| `ناجح()` | `منطقي` | هل اكتمل الطلب؟ |
| `الرد_ناجح()` | `منطقي` | هل رمز الحالة 2xx؟ |
| `رمز_الرد()` | `رقم` | رمز HTTP |
| `جسم_الرد()` | `نص` | محتوى الاستجابة |
| `رأس_الرد(اسم)` | `نص` | ترويسة من الاستجابة |
| `وصف_الخطأ()` | `نص` | رسالة آخر خطأ |
| `أفرغ_الرد()` | — | تحرير ذاكرة الاستجابة |
| `مضيف()` | `نص` | اسم المضيف |
| `أغلق()` | — | إغلاق الوصلة |
| `هل_صالح()` | `منطقي` | هل الوصلة مفتوحة؟ |

### مثال

```sad
استورد شبكات

متغير وصلة = وصلة_آمنة("api.github.com")
وصلة.أضف_رأس("User-Agent"، "sad-lang/1.0")
وصلة.اضبط_المهلة(10000)

وصلة.استرجع("/repos/sad-lang/sad/releases/latest")
إذا (وصلة.الرد_ناجح())
    اطبع_سطر(وصلة.جسم_الرد())
وإلا
    اطبع_سطر("فشل: " + وصلة.وصف_الخطأ())
نهاية

وصلة.أغلق()
```

## ملاحظات تقنية مهمة

### ١. تعارض أسماء الميثودات مع الدوال المضمّنة

أسماء ميثودات الأصناف **مختلفة عمداً** عن أسماء الدوال المضمّنة التي تستدعيها، لأن المفسر يُعطي الأولوية لميثودات الصنف داخل جسم الأصناف. جدول الفروق:

| الميثود الكائني | الدالة المضمّنة |
|----------------|----------------|
| `متصلة()` | `هل_متصلة(م)` |
| `المنفذ()` | `منفذ_محلي(م)` |
| `عنوان_جهاز()` | `رقم_الجهاز(م)` |
| `عدد_منفذ()` | `رقم_المنفذ(م)` |
| `اضبط_الرابط(ر)` | `حدد_الموقع(م، ر)` |
| `أضف_رأس(م، ق)` | `أضف_ترويسة(م، مف، ق)` |
| `اضبط_المهلة(مللي)` | `حدد_الانتظار(م، مللي)` |
| `مصادقة(رمز)` | `سجل_دخول_برمز(م، رمز)` |
| `استرجع(مسار)` | `اجلب(م، مسار)` |
| `أرسل_تحديث(م، ب)` | `استبدل(م، مسار، ب)` |
| `أحذف(مسار)` | `احذف_مورد(م، مسار)` |
| `رقّع(م، ب)` | `عدل_مورد(م، مسار، ب)` |
| `ناجح()` | `هل_نجح(م)` |
| `وصف_الخطأ()` | `سبب_الفشل(م)` |
| `رمز_الرد()` | `رمز_الحالة(م)` |
| `جسم_الرد()` | `نص_الرد(م)` |
| `رأس_الرد(اسم)` | `معلومة_الرد(م، اسم)` |
| `الرد_ناجح()` | `هل_الرد_ناجح(م)` |
| `أفرغ_الرد()` | `تجاهل_الرد(م)` |

### ٢. تجنب الكلمات المفتاحية كأسماء متغيرات

احذر من استخدام الحروف المفردة أو الكلمات المفتاحية كأسماء متغيرات:
```sad
# خطأ — "و" هي كلمة مفتاحية (AND)
متغير و = وصلة_آمنة("example.com")  # ← خطأ نحوي!

# صحيح
متغير وصلة = وصلة_آمنة("example.com")  # ← صحيح ✅
```

### ٣. دورة حياة الكائنات

جميع الأصناف تدعم **الهدّام التلقائي** (`هدم()`). الإغلاق صريح مُستحسن:
```sad
متغير م = مقبس_اتصال()
# ... استخدام ...
م.أغلق()    # إغلاق صريح (مُستحسن)
# أو: الهدّام يُغلق تلقائياً عند انتهاء النطاق
```

بعد `أغلق()`، يُرجع `هل_صالح()` قيمة `خطأ`.

### ٤. إعداد الشبكة لعنوان_شبكة

يتطلب `عنوان_شبكة` تهيئة الشبكة:
```sad
جهز_الشبكة()   # يجب استدعاؤها قبل إنشاء عنوان_شبكة
# ... استخدام عنوان_شبكة ...
نظف_الشبكة()   # تنظيف عند الانتهاء
```

### ٥. وصلة_آمنة و HTTPS

`وصلة_آمنة` تستخدم `https://` تلقائياً ولا تقبل `http://` في الاسم:

## أمثلة متقدمة

### خادم HTTP + عميل في نفس البرنامج

```sad
استورد شبكات

# الخادم
متغير خ = خادم_ويب()
خ.عند_جلب("/ping"، لامدا(طلب، رد)
    عين_نص_الرد(رد، "pong")
نهاية)
خ.ابدأ(9999)

# العميل
متغير م = متصفح_ويب()
م.اضبط_الرابط("http://127.0.0.1:9999")
م.اضبط_المهلة(1000)
م.استرجع("/ping")
اطبع_سطر(م.جسم_الرد())   # "pong"
م.أغلق()

خ.أوقف()
خ.أزل()
```

### اتصال TCP مع goroutines

```sad
استورد شبكات

متغير ق = قناة(1)

# خيط الخادم
أطلق
    متغير خ = مقبس_اتصال()
    خ.ربط(0)
    خ.استمع()
    متغير منفذ = خ.المنفذ()
    ق.أرسل(منفذ)
    متغير وصلة = خ.اقبل()
    اطبع_سطر(وصلة.استقبل())
    وصلة.أغلق()
    خ.أغلق()
نهاية

# انتظار المنفذ
متغير م_الخادم = ق.استقبل()

# خيط العميل
أطلق
    متغير عميل = مقبس_اتصال()
    عميل.اتصل("127.0.0.1"، م_الخادم)
    عميل.أرسل("مرحبا من goroutine!")
    عميل.أغلق()
نهاية

انتظر_الكل()
```
