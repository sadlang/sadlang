# بروتوكول شبكة صNet اللامركزية

## نظرة عامة

صNet هي شبكة لامركزية من نظير لنظير (P2P) مبنية كجزء من منظومة لغة صد البرمجية. تهدف إلى توفير بنية تحتية شبكية آمنة ومقاومة للرقابة مع دعم أصيل للغة العربية.

## المكونات الأساسية

### 1. جدول التجزئة الموزع (DHT)

- **الخوارزمية:** Kademlia مع معرّفات 160 بت
- **مسافة التوجيه:** XOR بين المعرّفات
- **حجم الدلو (k):** 20 عُقدة لكل دلو
- **العمليات الأساسية:**
  - `PING` - التحقق من نشاط العُقدة
  - `STORE` - تخزين قيمة مرتبطة بمفتاح
  - `FIND_NODE` - إيجاد أقرب k عُقدة لمعرّف
  - `FIND_VALUE` - البحث عن قيمة مُخزّنة

### 2. اكتشاف الأقران

| الطريقة | الوصف | الاستخدام |
|---------|-------|----------|
| البث المتعدد LAN | اكتشاف محلي عبر UDP multicast | الشبكة المحلية |
| عُقد بذرية DHT | الانضمام عبر عُقد معروفة | أول اتصال |
| تبادل الأقران PEX | مشاركة قوائم الأقران | توسيع الشبكة |
| mDNS | اكتشاف محلي عبر DNS | الشبكة المحلية |

### 3. اجتياز NAT

```
المستخدم  ←→  STUN Server  ←→  الطرف الآخر
    ↓ (إذا فشل STUN)
المستخدم  ←→  TURN Relay  ←→  الطرف الآخر
```

- **STUN:** اكتشاف العنوان العام ونوع NAT
- **TURN:** ترحيل البيانات عبر خادم وسيط
- **ICE:** اختيار أفضل مسار اتصال تلقائياً

### 4. التوجيه البصلي

```
المرسل → [تشفير₁[تشفير₂[تشفير₃[الرسالة]]]]
    ↓
العُقدة₁ → [تشفير₂[تشفير₃[الرسالة]]]  (فك طبقة)
    ↓
العُقدة₂ → [تشفير₃[الرسالة]]  (فك طبقة)
    ↓
العُقدة₃ → [الرسالة]  (فك آخر طبقة)
    ↓
المستقبل
```

- أقصى عدد قفزات: 5
- مفاتيح الجلسة: X25519 + AES-256-CTR
- حماية من تحليل حركة المرور عبر الحشو

## الأمان

### التشفير من طرف لطرف (E2EE)

- **تبادل المفاتيح:** بروتوكول X3DH (Extended Triple Diffie-Hellman)
- **تشفير الرسائل:** AES-256-GCM مع مصادقة
- **السرية الأمامية:** بروتوكول السقّالة المزدوجة (Double Ratchet)
- **المنحنى البيضاوي:** Curve25519

### الهوية اللامركزية (DID)

```
did:sad:<base58(hash(المفتاح_العام))>
```

- متوافقة مع معيار W3C DID v1
- مفاتيح Ed25519 للتوقيع
- X25519 لتبادل المفاتيح
- نقاط خدمة مرتبطة بالهوية

### شبكة الثقة

- نموذج PGP للثقة اللامركزية
- مستويات الثقة: مجهول ← هامشي ← كامل ← مطلق
- **قواعد الثقة الانتقالية:**
  - مصادقة واحدة بثقة كاملة = ثقة كاملة
  - 3 مصادقات بثقة هامشية = ثقة كاملة

### الحماية من هجمات Sybil

1. **إثبات العمل (PoW):** تحدّي حسابي للانضمام
2. **تحليل IP:** كشف التجمّعات المشبوهة
3. **تحليل السلوك:** مراقبة أنماط الاستخدام
4. **السمعة:** نظام نقاط تراكمي

## التخزين الموزع (صتخزين)

### تجزئة الملفات

- حجم القطعة الافتراضي: 256 KB
- ترميز التكافؤ: Reed-Solomon (10+4)
- عامل التكرار: 3 نسخ في الشبكة
- التحقق: بصمات SHA-256 + شجرة Merkle

### عنونة المحتوى

```
صتخزين://<CID_v1>/<المسار>
```

- المحتوى مُعنون ببصمته التشفيرية
- لا يمكن التلاعب بالمحتوى (التحقق ذاتي)
- تثبيت المحتوى لمنع الحذف التلقائي

## نظام أسماء النطاقات (صDNS)

### النطاقات المدعومة

| النطاق | الوصف |
|--------|-------|
| `.صد` | النطاق الرئيسي لشبكة صد |
| `.شبكة` | نطاق الخدمات الشبكية |
| `.sad` | النطاق اللاتيني البديل |

### أنواع السجلات

- `A` / `AAAA` - عناوين IP
- `DID` - معرّف لامركزي (خاص بصNet)
- `ONION` - عنوان خدمة بصلية
- `IPFS` - معرّف محتوى موزع

## البث المباشر

- البرامج الترميزية: H.264, H.265, VP9, AV1 (فيديو) | Opus, AAC (صوت)
- شبكة توزيع: Mesh بين المشاهدين
- المخزن المؤقت: 30 قطعة للتخفيف من التقطّع

## شبكة توزيع المحتوى (صCDN)

- تخزين مؤقت ذكي: LRU / LFU / شعبية
- توزيع جغرافي تلقائي
- إحصائيات: نسبة الإصابة، عرض النطاق، الاتصالات

## أدوات سطر الأوامر

```bash
# تهيئة عُقدة جديدة
sadnet init --port 8000

# الانضمام للشبكة
sadnet join seed.sadnet.org:8000

# عرض الأقران
sadnet peers --verbose

# تخزين ملف
sadnet store ./ملف.txt

# جلب محتوى
sadnet fetch CID_abc123

# حالة العُقدة
sadnet status
```
