# 2. المتغيرات والأنواع

## تعريف المتغيرات

في لغة ص يمكن تعريف المتغيرات بطريقتين:

### 1. بكلمة `متغير` (استنتاج النوع تلقائياً)
```sad
متغير اسم = "أحمد"
متغير عمر = 25
متغير نشط = صحيح
```

### 2. بتحديد النوع صراحةً
```sad
رقم عمر = 25
عشري درجة = 98.5
نص اسم = "أحمد"
منطقي نشط = صحيح
```

## الأنواع الأساسية

| النوع | الوصف | أمثلة |
|-------|-------|-------|
| `رقم` | عدد صحيح | `42`، `-7`، `0` |
| `عشري` | عدد عشري | `3.14`، `-0.5` |
| `نص` | سلسلة نصية | `"مرحباً"` |
| `منطقي` | قيمة منطقية | `صحيح`، `خطأ` |
| `مصفوفة` | قائمة عناصر | `[1، 2، 3]` |
| `خريطة` | قاموس مفتاح-قيمة | `{"اسم": "أحمد"}` |

## القيم المنطقية

```sad
# صحيح = true
# صح = true (اختصار)
# خطأ = false
# خاطئ = false (بديل)

منطقي أ = صحيح
منطقي ب = خطأ
```

## القيم الخاصة

```sad
متغير بلا_قيمة = عدم    # null/void
```

## الثوابت

```sad
ثابت باي = 3.14159
ثابت الاسم = "لغة ص"
# محاولة تعديل الثابت تُلقي خطأ
```

## 🔸 الأمثلة (8 أمثلة متدرجة)

### مثال 1 — مبتدئ: تعريف متغيرات بسيطة
```sad
متغير اسم = "سارة"
متغير عمر = 20
اطبع_سطر("الاسم: " + اسم)
اطبع_سطر("العمر: " + عمر)
```
**المخرجات:**
```
الاسم: سارة
العمر: 20
```

### مثال 2 — مبتدئ: الأنواع المختلفة
```sad
رقم س = 10
رقم ص = 20
رقم المجموع = س + ص

اطبع("س = ")
اطبع_سطر(س)
اطبع("ص = ")
اطبع_سطر(ص)
اطبع("المجموع = ")
اطبع_سطر(المجموع)

نص اسم = "أحمد"
اطبع("الاسم: ")
اطبع_سطر(اسم)

منطقي نتيجة = صحيح
اطبع("النتيجة: ")
اطبع_سطر(نتيجة)
```
**المخرجات:**
```
س = 10
ص = 20
المجموع = 30
الاسم: أحمد
النتيجة: صحيح
```

### مثال 3 — مبتدئ: إعادة إسناد المتغيرات
```sad
متغير قيمة = 100
اطبع_سطر("القيمة الأولى: " + قيمة)

قيمة = 200
اطبع_سطر("القيمة الثانية: " + قيمة)

قيمة = قيمة + 50
اطبع_سطر("بعد الإضافة: " + قيمة)
```
**المخرجات:**
```
القيمة الأولى: 100
القيمة الثانية: 200
بعد الإضافة: 250
```

### مثال 4 — مبتدئ: الثوابت
```sad
ثابت باي = 3.14
ثابت الاسم = "لغة ص"
ثابت نشط = صحيح

اطبع_سطر("باي = " + باي)
اطبع_سطر("الاسم = " + الاسم)
اطبع_سطر("نشط = " + نشط)

# محاولة تعديل ثابت
حاول
    باي = 3.15
    اطبع_سطر("خطأ! تم تعديل الثابت")
امسك (خ)
    اطبع_سطر("صحيح: الثابت محمي من التعديل")
نهاية
```
**المخرجات:**
```
باي = 3.14
الاسم = لغة ص
نشط = صحيح
صحيح: الثابت محمي من التعديل
```

### مثال 5 — متوسط: تحويل الأنواع
```sad
# تحويل نص إلى رقم
متغير نص_رقم = "42"
متغير رقم_فعلي = لرقم(نص_رقم)
اطبع_سطر("الرقم: " + رقم_فعلي)
اطبع_سطر("الرقم + 8 = " + (رقم_فعلي + 8))

# تحويل رقم إلى نص
متغير عدد = 100
متغير نص_عدد = لنص(عدد)
اطبع_سطر("كنص: " + نص_عدد)

# فحص النوع
اطبع_سطر("نوع 42: " + نوع(42))
اطبع_سطر("نوع 'سلام': " + نوع("سلام"))
اطبع_سطر("نوع صحيح: " + نوع(صحيح))
```
**المخرجات:**
```
الرقم: 42
الرقم + 8 = 50
كنص: 100
نوع 42: رقم
نوع 'سلام': نص
نوع صحيح: منطقي
```

### مثال 6 — متوسط: التعامل مع النصوص والأرقام
```sad
دالة رئيسية()
    نص الاسم_الأول = "محمد"
    نص الاسم_الأخير = "علي"
    رقم سنة_الميلاد = 1995
    رقم السنة_الحالية = 2026
    
    نص الاسم_الكامل = الاسم_الأول + " " + الاسم_الأخير
    رقم العمر = السنة_الحالية - سنة_الميلاد
    
    اطبع_سطر("الاسم: " + الاسم_الكامل)
    اطبع_سطر("العمر: " + العمر)
    
    إذا (العمر >= 18)
        اطبع_سطر("بالغ")
    وإلا
        اطبع_سطر("قاصر")
    نهاية
نهاية
```
**المخرجات:**
```
الاسم: محمد علي
العمر: 31
بالغ
```

### مثال 7 — متقدم: نطاقات المتغيرات
```sad
متغير عداد_عالمي = 0

دالة زِد()
    عداد_عالمي = عداد_عالمي + 1
    متغير محلي = "داخل الدالة"
    اطبع_سطر(محلي + " - العداد: " + عداد_عالمي)
نهاية

زِد()
زِد()
زِد()
اطبع_سطر("العداد النهائي: " + عداد_عالمي)
```
**المخرجات:**
```
داخل الدالة - العداد: 1
داخل الدالة - العداد: 2
داخل الدالة - العداد: 3
العداد النهائي: 3
```

### مثال 8 — متقدم جداً: متغيرات مع أصناف وبنى
```sad
# استخدام البنى لتجميع البيانات
بنية إحداثيات
    رقم س = 0
    رقم ص = 0
نهاية

# صنف يستخدم أنواع مختلفة
صنف لاعب
    نص الاسم
    رقم الصحة
    رقم النقاط
    
    باني(نص اسم)
        الاسم = اسم
        الصحة = 100
        النقاط = 0
    نهاية
    
    دالة سجّل_نقاط(رقم نقاط)
        النقاط = النقاط + نقاط
        اطبع_سطر(الاسم + " سجل " + نقاط + " نقطة (الإجمالي: " + النقاط + ")")
    نهاية
    
    دالة تلقّى_ضرر(رقم ضرر)
        الصحة = الصحة - ضرر
        إذا (الصحة < 0)
            الصحة = 0
        نهاية
        اطبع_سطر(الاسم + " تلقى " + ضرر + " ضرر (الصحة: " + الصحة + ")")
    نهاية
    
    دالة حالة()
        اطبع_سطر("═══════════════════")
        اطبع_سطر("اللاعب: " + الاسم)
        اطبع_سطر("الصحة: " + الصحة)
        اطبع_سطر("النقاط: " + النقاط)
        اطبع_سطر("═══════════════════")
    نهاية
نهاية

# الموقع كبنية
متغير موقع = إحداثيات(5، 10)
اطبع_سطر("الموقع: (" + موقع.س + "، " + موقع.ص + ")")

# اللاعب ككائن
متغير بطل = جديد لاعب("فارس")
بطل.سجّل_نقاط(50)
بطل.تلقّى_ضرر(30)
بطل.سجّل_نقاط(25)
بطل.حالة()
```
**المخرجات:**
```
الموقع: (5، 10)
فارس سجل 50 نقطة (الإجمالي: 50)
فارس تلقى 30 ضرر (الصحة: 70)
فارس سجل 25 نقطة (الإجمالي: 75)
═══════════════════
اللاعب: فارس
الصحة: 70
النقاط: 75
═══════════════════
```
