# 📜 دليل أسلوب كتابة كود لغة ص الشامل

## مقدمة للمبتدئين

### ما هو دليل الأسلوب؟

دليل الأسلوب (Style Guide) هو مجموعة من القواعد والاتفاقيات التي تحدد كيفية كتابة الكود بطريقة **موحدة** و**مقروءة** و**احترافية**.

#### لماذا نحتاج دليل أسلوب؟

تخيل أنك تقرأ كتاباً كل فصل فيه مكتوب بخط مختلف وتنسيق مختلف - سيكون صعب القراءة! نفس الشيء ينطبق على الكود:

```
┌─────────────────────────────────────────────────────────────────┐
│  بدون دليل أسلوب           │    مع دليل أسلوب                 │
├─────────────────────────────┼───────────────────────────────────┤
│  دالةمربع(س){               │    دالة مربع(س: عدد) ← عدد      │
│  أرجعس*س                   │        أرجع س * س                 │
│  }                         │    نهاية                          │
├─────────────────────────────┼───────────────────────────────────┤
│  ❌ صعب القراءة            │    ✅ سهل القراءة                 │
│  ❌ غير موحد               │    ✅ موحد                        │
│  ❌ عرضة للأخطاء           │    ✅ آمن                         │
└─────────────────────────────┴───────────────────────────────────┘
```

## الفصل الأول: أساسيات لغة ص

### 1.1 ما هي لغة ص؟

**لغة ص** هي لغة برمجة عربية حديثة صُممت لتكون:
- **آمنة**: تمنع أخطاء الذاكرة في وقت الترجمة
- **سريعة**: تُترجم إلى كود آلة أصلي
- **عربية**: كل الكلمات المفتاحية بالعربية

### 1.2 البنية الأساسية للكود

#### الكتل البرمجية (Blocks)

في لغة ص، **الكتل البرمجية تنتهي بكلمة `نهاية`** بدلاً من الأقواس المعقوصة `{}`:

```ص
// ❌ خطأ - هذه ليست طريقة لغة ص
دالة مرحبا() {
    اطبع("مرحبا")
}

// ✅ صحيح - الطريقة الصحيحة في لغة ص
دالة مرحبا()
    اطبع("مرحبا")
نهاية
```

#### مقارنة مع لغات أخرى

```
┌──────────────────────────────────────────────────────────────────┐
│        لغة C                    │           لغة ص               │
├─────────────────────────────────┼────────────────────────────────┤
│  int square(int x) {            │  دالة مربع( عدد س) ← عدد     │
│      return x * x;              │      أرجع س * س               │
│  }                              │  نهاية                        │
├─────────────────────────────────┼────────────────────────────────┤
│  if (x > 0) {                   │  إذا (س > 0 )                  │
│      printf("positive");        │      اطبع("موجب")             │
│  } else {                       │  وإلا                        │
│      printf("negative");        │      اطبع("سالب")             │
│  }                              │  نهاية                        │
├─────────────────────────────────┼────────────────────────────────┤
│  for (int i=0; i<10; i++) {     │  لكل ن في 0..10              │
│      printf("%d", i);           │      اطبع(ن)                  │
│  }                              │  نهاية                        │
├─────────────────────────────────┼────────────────────────────────┤
│  while (running) {              │  بينما (يعمل )                 │
│      process();                 │      عالج()                   │
│  }                              │  نهاية                        │
└─────────────────────────────────┴────────────────────────────────┘
```

## الفصل الثاني: قواعد التسمية

### 2.1 لماذا التسمية مهمة؟

الاسم الجيد يشرح نفسه! انظر الفرق:

```ص
// ❌ أسماء سيئة - لا تعني شيئاً
متغير س = 100
متغير ص = 5
متغير ع = س / ص

// ✅ أسماء جيدة - تشرح نفسها
متغير السعر_الإجمالي = 100
متغير عدد_العناصر = 5
متغير سعر_العنصر_الواحد = السعر_الإجمالي / عدد_العناصر
```

### 2.2 قواعد تسمية المتغيرات

#### القاعدة: استخدم snake_case بالعربية

```ص
// ✅ صحيح - snake_case عربي
متغير عدد_الطلاب = 30
متغير اسم_المستخدم = "أحمد"
متغير هل_نشط = صحيح

// ❌ خطأ - لا تستخدم هذه الأساليب
متغير عددالطلاب = 30        // بدون فاصل
متغير عددُالطلاب = 30        // تشكيل بدل فاصل
متغير STUDENTS_COUNT = 30   // إنجليزي
متغير numberOfStudents = 30 // camelCase إنجليزي
```

### 2.3 قواعد تسمية الدوال

#### القاعدة: فعل + مفعول بـ snake_case

```ص
// ✅ صحيح - الدالة تفعل شيئاً
دالة احسب_المجموع(أ قائمة<عدد> أرقام) ← عدد
    ...
نهاية

دالة أرسل_بريد(نص إلى،  نص رسالة)
    ...
نهاية

دالة هل_موجود( نص عنصر، قائمة<نص> قائمة) ← منطقي
    ...
نهاية

// ❌ خطأ - أسماء غامضة
دالة معالجة()        // ماذا تعالج؟
دالة بيانات()        // ماذا تفعل بالبيانات؟
دالة تنفيذ()         // تنفيذ ماذا؟
```

### 2.4 قواعد تسمية الأنواع (الهياكل والتعدادات)

#### القاعدة: PascalCase عربي (بدون فواصل)

```ص
// ✅ صحيح
هيكل مستخدم
   نص اسم 
 نص عمر 
نهاية

هيكل طالبجامعي:
    رقم_الطالب: نص
    المعدل: عشري
نهاية

تعداد حالةالطلب:
    جديد
    قيد_المعالجة
    مكتمل
    ملغي
نهاية

// ❌ خطأ
هيكل مستخدم_جديد:     // لا تستخدم snake_case للأنواع
    ...
نهاية
```

### 2.5 قواعد تسمية الثوابت

#### القاعدة: SCREAMING_SNAKE_CASE

```ص
// ✅ صحيح
ثابت الحد_الأقصى_للمحاولات = 3
ثابت حجم_الصفحة_الافتراضي = 20

// يمكن أيضاً بالأحرف الكبيرة للأرقام الرياضية
```

### 3.1 المسافة البادئة (Indentation)

#### القاعدة: 4 مسافات لكل مستوى

```ص
    نهاية
    
    متغير مستخدم = احصل_على_مستخدم(طلب.معرف_المستخدم)
    
    طابق مستخدم:
        حالة بعض(م):
            أرجع نجاح(م.بيانات())
        حالة لاشيء:
            أرجع خطأ("المستخدم غير موجود")
    نهاية
نهاية

// ❌ خطأ - مسافات غير متسقة
دالة سيئة():
  إذا صحيح:          // 2 مسافات

```

### 3.2 الأسطر الفارغة

#### القاعدة: سطر فارغ واحد بين الكتل المنطقية

```ص
// ✅ صحيح

    افعل_أ()
    افعل_ب()
    افعل_ج()
    افعل_د()

نهاية
```

## الفصل السادس: الأنماط الشائعة

### 6.1 معالجة الأخطاء

#### استخدام نوع نتيجة

```ص
// ✅ الطريقة المفضلة - استخدام نتيجة<T, خطأ>
دالة اقرأ_ملف(مسار: نص) ← نتيجة<نص، خطأ_ملف>:

        متغير محتوى = _اقرأ_ملف_خام(مسار)
        أرجع نجاح(محتوى)

        أرجع خطأ(خطأ_ملف::فشل_قراءة(خ.رسالة))

طابق نتيجة:
```

## الفصل السابع: أمثلة عملية

### 7.1 مثال: برنامج إدارة مهام

```ص
/**
 * @ملف: مدير_مهام.ص
 * @وصف: تطبيق بسيط لإدارة قائمة المهام
 */

// ═══════════════════════════════════════════════════════════════
// الأنواع
// ═══════════════════════════════════════════════════════════════

تعداد حالة_مهمة:
    جديدة
    قيد_التنفيذ
    مكتملة
نهاية

هيكل مهمة:
    معرف: عدد
    عنوان: نص
    وصف: نص
    حالة: حالة_مهمة
    تاريخ_الإنشاء: تاريخ_وقت
نهاية

هيكل مدير_مهام:
    مهام: قائمة<مهمة>
    العداد: عدد
نهاية

// ═══════════════════════════════════════════════════════════════
// التنفيذ
// ═══════════════════════════════════════════════════════════════

تنفيذ مدير_مهام:
    /**
     * إنشاء مدير مهام جديد
     */
    دالة جديد() ← ذاتي:
        أرجع مدير_مهام {
            مهام: قائمة_جديدة()،
            العداد: 0
        }
    نهاية
    
    /**
     * إضافة مهمة جديدة
     */
    دالة أضف(&ذاتي متغير، عنوان: نص، وصف: نص) ← عدد:
        ذاتي.العداد += 1
        
        متغير مهمة = مهمة {
            معرف: ذاتي.العداد،
            عنوان: عنوان،
            وصف: وصف،
            حالة: حالة_مهمة::جديدة،
            تاريخ_الإنشاء: الآن()
        }
        
        ذاتي.مهام.أضف(مهمة)
        أرجع ذاتي.العداد
    نهاية
    
    /**
     * تحديث حالة مهمة
     */
    دالة حدث_حالة(&ذاتي متغير، معرف: عدد، حالة: حالة_مهمة) ← نتيجة<()، نص>:
        لكل مهمة في &ذاتي.مهام متغير:

    دالة اعرض_الكل(&ذاتي):

    نهاية
```
