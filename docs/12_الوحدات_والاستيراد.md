# 12. الوحدات والاستيراد

## تصدير

لجعل دالة أو متغير أو صنف متاحاً للاستخدام من ملفات أخرى:

```sad
# ملف: رياضيات.ص

صدّر دالة جمع(أ، ب)
    ارجع أ + ب
نهاية

صدّر رقم باي = 3

صدّر دالة مربع(ن)
    ارجع ن * ن
نهاية
```

## أنماط الاستيراد

### 1. استيراد محدد
```sad
من رياضيات استورد جمع، مربع
```

### 2. استيراد الكل بعلامة *
```sad
من رياضيات استورد *
```

### 3. استيراد بأسماء بديلة
```sad
من رياضيات استورد جمع كـ أضف
```

### 4. استيراد وحدة كاملة
```sad
استورد رياضيات
# الاستخدام: رياضيات.جمع(1، 2)
```

## 🔸 الأمثلة (8 أمثلة متدرجة)

### مثال 1 — مبتدئ: تصدير دالة بسيطة

**ملف `أدوات.ص`:**
```sad
صدّر دالة تحية(اسم)
    اطبع_سطر("مرحباً " + اسم + "!")
نهاية

صدّر دالة وداع(اسم)
    اطبع_سطر("مع السلامة " + اسم + "!")
نهاية
```

**ملف `البرنامج.ص`:**
```sad
من أدوات استورد تحية، وداع

تحية("أحمد")
وداع("أحمد")
```
**المخرجات:**
```
مرحباً أحمد!
مع السلامة أحمد!
```

### مثال 2 — مبتدئ: تصدير متغيرات وثوابت

**ملف `ثوابت.ص`:**
```sad
صدّر رقم النسبة_الذهبية = 1
صدّر رقم سرعة_الضوء = 299792

صدّر دالة اطبع_ثوابت()
    اطبع_سطر("النسبة الذهبية = 1.618")
    اطبع_سطر("سرعة الضوء = 299792 كم/ث")
نهاية
```

**ملف `البرنامج.ص`:**
```sad
من ثوابت استورد سرعة_الضوء، اطبع_ثوابت

اطبع_سطر("سرعة الضوء = " + سرعة_الضوء)
اطبع_ثوابت()
```

### مثال 3 — مبتدئ: استيراد كل شيء

**ملف `أدوات_طباعة.ص`:**
```sad
صدّر دالة اطبع_خط()
    اطبع_سطر("─────────────────────")
نهاية

صدّر دالة اطبع_عنوان(نص)
    اطبع_خط()
    اطبع_سطر("  " + نص)
    اطبع_خط()
نهاية
```

**ملف `البرنامج.ص`:**
```sad
من أدوات_طباعة استورد *

اطبع_عنوان("مرحباً بالعالم")
اطبع_خط()
```

### مثال 4 — متوسط: استيراد بأسماء بديلة

```sad
من رياضيات استورد جمع كـ أضف
من رياضيات استورد مربع كـ تربيع

اطبع_سطر("أضف(3, 5) = " + أضف(3، 5))
اطبع_سطر("تربيع(7) = " + تربيع(7))
```

    إذا (أ > ب)
        ارجع أ
    نهاية
    ارجع ب
نهاية

صدّر دالة الأصغر(أ، ب)
    إذا (أ < ب)
        ارجع أ
    نهاية
    ارجع ب

**ملف `البرنامج.ص`:**

من مكتبة_رياضيات استورد القيمة_المطلقة، الأكبر، الأصغر

### مثال 7 — متقدم: استيراد أصناف

**ملف `نماذج.ص`:**
```sad
صدّر صنف منتج
    نص الاسم
    رقم السعر
    
    باني(نص اسم، رقم سعر)
        الاسم = اسم
        السعر = سعر
    نهاية
    
    دالة اعرض()
        اطبع_سطر("  " + الاسم + " - " + السعر + " ر.س")
    نهاية
نهاية
```

**ملف `المتجر.ص`:**
```sad
من نماذج استورد منتج

متغير م1 = جديد منتج("حاسوب"، 5000)
متغير م2 = جديد منتج("هاتف"، 3000)
م1.اعرض()
م2.اعرض()
```

صدّر دالة اطبع_عنوان(عنوان)

**ملف `البرنامج_الرئيسي.ص`:**
```sad
من مكتبة_رياضيات استورد القيمة_المطلقة، الأكبر، الأصغر
من أدوات_عامة استورد اطبع_خط، اطبع_عنوان، اطبع_نجاح، اطبع_خطأ

صنف حساب
    رقم رقم_ح
    رقم رصيد
    ساكن رقم عداد

    باني(رقم رقم_حساب، رقم رصيد_مبدئي)
        رقم_ح = رقم_حساب
        رصيد = رصيد_مبدئي
        عداد = عداد + 1
    نهاية

    دالة رقم ايداع(رقم مبلغ)
        إذا (مبلغ <= 0)
            اطبع_خطأ("المبلغ يجب أن يكون موجباً")
            ارجع 0
        نهاية
        رصيد = رصيد + مبلغ
        اطبع_نجاح("إيداع " + مبلغ + " → رصيد: " + رصيد)
        ارجع 1
    نهاية

    دالة رقم سحب(رقم مبلغ)
        إذا (مبلغ > رصيد)
            اطبع_خطأ("رصيد غير كافٍ!")
            ارجع 0
        نهاية
        رصيد = رصيد - مبلغ
        اطبع_نجاح("سحب " + مبلغ + " → رصيد: " + رصيد)
        ارجع 1
    نهاية
نهاية

دالة رئيسية()
    اطبع_عنوان("النظام البنكي المتقدم")
    
    متغير ح1 = جديد حساب(1001، 5000)
    متغير ح2 = جديد حساب(1002، 10000)
    
    ح1.ايداع(2000)
    ح1.سحب(1000)
    ح2.سحب(50000)
    
    اطبع_خط()
    اطبع_سطر("  القيمة المطلقة لـ -500: " + القيمة_المطلقة(-500))
    اطبع_سطر("  الأكبر(5000, 10000): " + الأكبر(5000، 10000))
    اطبع_خط()
نهاية
```
