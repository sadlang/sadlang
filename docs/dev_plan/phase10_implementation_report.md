## 🚧 ما يجب إنجازه

### 🔴 المرحلة التالية: التنفيذ الفعلي

#### 1. تنفيذ طي الثوابت (Constant Folding)
**الأولوية:** عالية جداً 🔥

**المطلوب:**
```cpp
// مثال: 2 + 3 → 5
// مثال: "hello" + " world" → "hello world"
// مثال: true && false → false
```

**الخطوات:**
1. التجول في شجرة AST
2. التعرف على التعبيرات الثابتة
3. حساب القيم في وقت الترجمة
4. استبدال التعبير بالقيمة المحسوبة

**الوقت المتوقع:** 2-3 أيام

#### 2. تنفيذ تبسيط التعبيرات (Expression Simplification)
**الأولوية:** عالية 🔥

**المطلوب:**
```cpp
// x * 1 → x
// x + 0 → x
// x * 0 → 0
// x - x → 0
// x / 1 → x
```

**الخطوات:**
1. التعرف على أنماط التبسيط
2. تطبيق قواعد الجبر الأساسية
3. استبدال التعبيرات المعقدة بالمبسطة

**الوقت المتوقع:** 2-3 أيام

#### 3. تنفيذ حذف الكود الميت (Dead Code Elimination)
**الأولوية:** متوسطة-عالية ⚡

**المطلوب:**
```cpp
// حذف المتغيرات غير المستخدمة
// حذف الكود بعد return
// حذف الدوال غير المستدعاة
```

**الخطوات:**
1. تحليل استخدام المتغيرات
2. تحليل تدفق التحكم
3. تحديد الكود غير القابل للوصول
4. حذف العقد الميتة من AST

**الوقت المتوقع:** 3-4 أيام

#### 4. تنفيذ تحسين الحلقات (Loop Optimization)
**الأولوية:** متوسطة ⚡

**التحسينات المطلوبة:**
- **Loop Unrolling**: فك الحلقات الصغيرة
- **Loop Invariant Code Motion**: نقل الكود الثابت خارج الحلقة
- **Strength Reduction**: تبسيط العمليات داخل الحلقة

**الوقت المتوقع:** 4-5 أيام

#### 5. تنفيذ دمج الدوال (Function Inlining)
**الأولوية:** منخفضة-متوسطة 📋

**معايير الدمج:**
- الدوال الصغيرة (< 10 أسطر)
- الدوال المستدعاة مرة واحدة
- تحليل التكلفة/الفائدة

**الوقت المتوقع:** 3-4 أيام

#### 6. تنفيذ إزالة الإسناد الزائد
**الأولوية:** منخفضة 📋

**المطلوب:**
```cpp
// x = 5
// x = 10  // الإسناد الأول غير مستخدم
// → x = 10
```

**الوقت المتوقع:** 2-3 أيام
