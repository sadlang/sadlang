#### اليوم 3-5: تنفيذ Constant Folding
**الهدف:** تطبيق طي الثوابت الكامل

**المهام:**
1. تطبيق `ConstantFoldingPass::apply()`
2. التعامل مع:
   - العمليات الحسابية: `2 + 3 → 5`
   - العمليات المنطقية: `true && false → false`
   - دمج النصوص: `"hello" + " world" → "hello world"`
3. اختبار شامل مع أمثلة متنوعة

#### اليوم 6-7: تنفيذ Expression Simplification
**الهدف:** تبسيط التعبيرات الحسابية

**المهام:**
1. تطبيق `ExpressionSimplificationPass::apply()`
2. التعامل مع:
   - `x + 0 → x`
   - `x * 1 → x`
   - `x * 0 → 0`
   - `x - x → 0`
3. اختبارات regression
