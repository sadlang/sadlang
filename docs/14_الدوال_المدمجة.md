# 14. الدوال المدمجة

## دوال الإدخال والإخراج

| الدالة | الوصف | مثال |
|--------|-------|------|
| `اطبع(قيمة)` | طباعة بدون سطر جديد | `اطبع("مرحباً ")` |
| `اطبع_سطر(قيمة)` | طباعة مع سطر جديد | `اطبع_سطر("مرحباً")` |
| `اقرأ()` | قراءة نص من المستخدم | `متغير اسم = اقرأ()` |
| `اقرأ_رقم()` | قراءة رقم | `متغير ع = اقرأ_رقم()` |

## دوال الرياضيات

| الدالة | الوصف | مثال |
|--------|-------|------|
| `جذر(ن)` / `جذر_تربيعي(ن)` | الجذر التربيعي | `جذر(16)` → `4` |
| `أس(قاعدة، أس)` | الأس | `أس(2، 10)` → `1024` |
| `مربع(ن)` | التربيع | `مربع(7)` → `49` |
| `مطلق(ن)` | القيمة المطلقة | `مطلق(-5)` → `5` |
| `تقريب(ن)` | التقريب لأقرب صحيح | `تقريب(3.7)` → `4` |
| `أرضية(ن)` | التقريب للأسفل | `أرضية(3.9)` → `3` |
| `سقف(ن)` | التقريب للأعلى | `سقف(3.1)` → `4` |
| `جيب(ن)` | sin | `جيب(0.5)` |
| `جيب_تمام(ن)` | cos | `جيب_تمام(0)` → `1` |
| `ظل(ن)` | tan | `ظل(0.785)` |
| `باي()` | π | `باي()` → `3.14159` |
| `عشوائي()` | رقم عشوائي 0-1 | `عشوائي()` |

## دوال النصوص

| الدالة | الوصف |
|--------|-------|
| `طول(نص)` / `طول_نص(نص)` | طول النص |
| `تحويل_كبير(نص)` | أحرف كبيرة |
| `تحويل_صغير(نص)` | أحرف صغيرة |
| `استبدل(نص، قديم، جديد)` | استبدال |
| `استخراج(نص، بداية، نهاية)` | استخراج جزء |
| `قص_أطراف(نص)` | إزالة المسافات |
| `يبدأ_ب(نص، بادئة)` | هل يبدأ بـ |
| `ينتهي_ب(نص، لاحقة)` | هل ينتهي بـ |
| `يحتوي_على(نص، فرعي)` | هل يحتوي |
| `بحث(نص، فرعي)` | موقع أول ظهور |

## دوال المصفوفات

| الدالة | الوصف |
|--------|-------|
| `طول(مصفوفة)` / `حجم_مصفوفة(م)` | عدد العناصر |
| `أضف(مصفوفة، عنصر)` | إضافة عنصر |
| `أزل(مصفوفة، فهرس)` | إزالة بالفهرس |
| `أول(مصفوفة)` | أول عنصر |
| `آخر(مصفوفة)` | آخر عنصر |
| `فرز(مصفوفة)` | ترتيب |
| `قلب(مصفوفة)` | عكس |
| `شريحة(مصفوفة، بداية، نهاية)` | استخراج جزء |
| `فهرس(مصفوفة، عنصر)` | موقع العنصر |
| `يحتوي_عنصر(مصفوفة، عنصر)` | هل يوجد |

## دوال التحويل والفحص

| الدالة | الوصف |
|--------|-------|
| `لرقم(قيمة)` | تحويل لرقم |
| `لنص(قيمة)` | تحويل لنص |
| `نوع(قيمة)` | نوع القيمة |

## الدوال العليا

| الدالة | الوصف |
|--------|-------|
| `تخطيط(مصفوفة، دالة)` | map - تطبيق دالة على كل عنصر |
| `تصفية(مصفوفة، دالة)` | filter - تصفية العناصر |
| `اختزال(مصفوفة، دالة، قيمة_أولية)` | reduce - اختزال لقيمة واحدة |

## دوال الملفات

| الدالة | الوصف |
|--------|-------|
| `اقرأ_ملف(مسار)` | قراءة محتوى ملف |
| `اكتب_ملف(مسار، محتوى)` | كتابة في ملف |
| `احذف_ملف(مسار)` | حذف ملف |

## 🔸 الأمثلة (8 أمثلة متدرجة)

### مثال 1 — مبتدئ: دوال الطباعة
```sad
اطبع("مرحباً ")
اطبع("من ")
اطبع_سطر("لغة ص!")
اطبع_سطر("سطر جديد")
```
**المخرجات:**
```
مرحباً من لغة ص!
سطر جديد
```

### مثال 2 — مبتدئ: دوال الرياضيات الأساسية
```sad
اطبع_سطر("جذر(16) = " + جذر(16))
اطبع_سطر("جذر(25) = " + جذر(25))
اطبع_سطر("أس(2, 8) = " + أس(2، 8))
اطبع_سطر("أس(2, 10) = " + أس(2، 10))
اطبع_سطر("مربع(7) = " + مربع(7))
اطبع_سطر("باي = " + باي())
```
**المخرجات:**
```
جذر(16) = 4
جذر(25) = 5
أس(2, 8) = 256
أس(2, 10) = 1024
مربع(7) = 49
باي = 3.14159
```

### مثال 3 — مبتدئ: دوال التقريب والقيمة المطلقة
```sad
اطبع_سطر("مطلق(-5) = " + مطلق(-5))
اطبع_سطر("مطلق(3) = " + مطلق(3))
اطبع_سطر("تقريب(3.7) = " + تقريب(3.7))
اطبع_سطر("تقريب(3.2) = " + تقريب(3.2))
اطبع_سطر("أرضية(3.9) = " + أرضية(3.9))
اطبع_سطر("سقف(3.1) = " + سقف(3.1))
```
**المخرجات:**
```
مطلق(-5) = 5
مطلق(3) = 3
تقريب(3.7) = 4
تقريب(3.2) = 3
أرضية(3.9) = 3
سقف(3.1) = 4
```

### مثال 4 — متوسط: دوال النصوص
```sad
متغير نص1 = "Hello World"
اطبع_سطر("الطول: " + طول_نص(نص1))
اطبع_سطر("كبير: " + تحويل_كبير(نص1))
اطبع_سطر("صغير: " + تحويل_صغير(نص1))
اطبع_سطر("استبدال: " + استبدل(نص1، "World"، "Sad"))
اطبع_سطر("استخراج(0,5): " + استخراج(نص1، 0، 5))
اطبع_سطر("يبدأ بـ Hello: " + يبدأ_ب(نص1، "Hello"))
اطبع_سطر("موقع 'World': " + بحث(نص1، "World"))
```
**المخرجات:**
```
الطول: 11
كبير: HELLO WORLD
صغير: hello world
استبدال: Hello Sad
استخراج(0,5): Hello
يبدأ بـ Hello: صحيح
موقع 'World': 6
```

### مثال 5 — متوسط: دوال المصفوفات
```sad
متغير م = [5، 2، 8، 1، 9]

اطبع_سطر("الطول: " + طول(م))
اطبع_سطر("الأول: " + أول(م))
اطبع_سطر("الآخر: " + آخر(م))
اطبع_سطر("مرتبة: " + فرز([5، 2، 8، 1، 9]))
اطبع_سطر("معكوسة: " + قلب([1، 2، 3]))
اطبع_سطر("شريحة(1,3): " + شريحة(م، 1، 3))
اطبع_سطر("فهرس 8: " + فهرس(م، 8))
اطبع_سطر("يحتوي 9: " + يحتوي_عنصر(م، 9))

أضف(م، 100)
اطبع_سطر("بعد إضافة 100: " + م)

أزل(م، 0)
اطبع_سطر("بعد إزالة الأول: " + م)
```
**المخرجات:**
```

الآخر: 9

معكوسة: [3، 2، 1]
شريحة(1,3): [2، 8]
فهرس 8: 2
يحتوي 9: صحيح
بعد إضافة 100: [5، 2، 8، 1، 9، 100]
بعد إزالة الأول: [2، 8، 1، 9، 100]
```

### مثال 6 — متوسط: تحويل الأنواع
```sad
# تحويل نص إلى رقم
متغير نص_رقم = "42"
متغير رقم_فعلي = لرقم(نص_رقم)
اطبع_سطر("لرقم('42') = " + رقم_فعلي)
اطبع_سطر("42 + 8 = " + (رقم_فعلي + 8))

# تحويل رقم إلى نص
اطبع_سطر("لنص(3.14) = " + لنص(3.14))

# فحص الأنواع
اطبع_سطر("نوع(42) = " + نوع(42))
اطبع_سطر("نوع('نص') = " + نوع("نص"))
اطبع_سطر("نوع(صحيح) = " + نوع(صحيح))
اطبع_سطر("نوع([1,2]) = " + نوع([1، 2]))
```
**المخرجات:**
```
لرقم('42') = 42
42 + 8 = 50
لنص(3.14) = 3.14
نوع(42) = رقم
نوع('نص') = نص
نوع(صحيح) = منطقي
نوع([1,2]) = مصفوفة
```

### مثال 7 — متقدم: الدوال العليا
```sad
# تخطيط
دالة مضاعفة(ن)
    ارجع ن * 2
نهاية
متغير نتيجة1 = تخطيط([1، 2، 3، 4، 5]، "مضاعفة")
اطبع_سطر("تخطيط مضاعفة: " + نتيجة1)

# تخطيط مع لامدا
متغير ل = لامدا ن: ن * ن
متغير نتيجة2 = تخطيط([1، 2، 3، 4، 5]، ل)
اطبع_سطر("تخطيط تربيع: " + نتيجة2)

# تصفية
دالة أكبر_من_3(ن)
    ارجع ن > 3
نهاية
متغير نتيجة3 = تصفية([1، 2، 3، 4، 5، 6]، "أكبر_من_3")
اطبع_سطر("تصفية > 3: " + نتيجة3)

# اختزال
دالة جمع(أ، ب)
    ارجع أ + ب
نهاية
متغير مجموع = اختزال([1، 2، 3، 4، 5]، "جمع"، 0)
اطبع_سطر("اختزال جمع: " + مجموع)
```
**المخرجات:**
```
تخطيط مضاعفة: [2، 4، 6، 8، 10]
تخطيط تربيع: [1، 4، 9، 16، 25]
تصفية > 3: [4، 5، 6]
اختزال جمع: 15
```
