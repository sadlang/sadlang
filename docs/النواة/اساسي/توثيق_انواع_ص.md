# توثيق أنواع البيانات في لغة ص

## أنواع البيانات الأساسية

| الكلمة المفتاحية | النوع بالعربية | مثال |
|------------------|----------------|-------|
| رقم              | عدد صحيح       | رقم س = 10 |
| عشري             | عدد عشري       | عشري د = 3.14 |
| منطقي            | منطقية         | منطقي صح = صحيح |
| نص               | سلسلة نصية     | نص اسم = "أحمد" |
| مصفوفة           | مصفوفة         | مصفوفة أرقام = [1، 2، 3] |
| خريطة            | خريطة/قاموس    | خريطة بيانات = {"اسم": "سارة"، "عمر": 22} |


## أمثلة إعلان المتغيرات

```sad
# عدد صحيح
رقم العمر = 25

# عدد عشري
عشري النسبة = 0.75

# متغير منطقي
منطقي نشط = صحيح

# سلسلة نصية
نص رسالة = "مرحبا بك في لغة ص"

# مصفوفة أعداد
مصفوفة درجات = [90، 85، 78]

# خريطة بيانات
خريطة طالب = {"اسم": "ليلى"، "معدل": 95}


```

## ملاحظات
- جميع المتغيرات يمكن تسميتها بالعربية أو الإنجليزية.
- يمكن استخدام الفاصلة العربية `،` أو الإنجليزية `,` في المصفوفات والخريطة.
- القيم المنطقية: `صحيح` و`خطأ`.
- القيمة الفارغة: `لاشيء`.
