# وحدة UEFI — بروتوكول الإقلاع الموحد
# UEFI Module — Unified Extensible Firmware Interface

## المقدمة

وحدة UEFI في لغة ص توفر واجهة عربية كاملة للتعامل مع بروتوكول الإقلاع الموحد (UEFI).
تُمكّنك هذه الوحدة من كتابة **محمّلات إقلاع** (Bootloaders) و**أنوية أنظمة تشغيل**
بالكامل بلغة ص العربية.

### ما هو UEFI؟

UEFI (Unified Extensible Firmware Interface) هو المعيار الحديث الذي حلّ محل BIOS القديم.
يوفر UEFI واجهة موحدة بين البرنامج الثابت (Firmware) ونظام التشغيل، ويدعم:

- **إقلاع آمن** (Secure Boot)
- **رسوميات عالية الدقة** عبر GOP (Graphics Output Protocol)
- **نظام ملفات FAT32** على قسم EFI System Partition
- **خدمات ذاكرة متقدمة** (تخصيص صفحات، خريطة ذاكرة)
- **متغيرات NVRAM** لحفظ إعدادات الإقلاع

## البنية العامة

```
مصدر .ص → المفسر (محاكاة UEFI)
         → المترجم sadc → SIR → LLVM IR → ملف PE/COFF (تطبيق UEFI حقيقي)
                                            ↓
                                   sad_lowlevel_rt (تنفيذ freestanding)
```

## الأقسام

### 1. التهيئة والتحكم

| الدالة (عربي) | الدالة (إنجليزي) | الوصف |
|---|---|---|
| `uefi_تهيئة()` | `uefi_initialize()` | تهيئة بيئة UEFI |
| `uefi_هل_مهيأ()` | `uefi_is_initialized()` | هل تم التهيئة؟ |
| `uefi_إنهاء_خدمات_إقلاع(مفتاح)` | `uefi_exit_boot_services(key)` | إنهاء خدمات الإقلاع |
| `uefi_خدمات_إقلاع_منتهية()` | `uefi_boot_services_exited()` | هل انتهت خدمات الإقلاع؟ |
| `uefi_إعادة_تشغيل(نوع)` | `uefi_reset_system(type)` | إعادة تشغيل/إيقاف (0=بارد، 1=دافئ، 2=إيقاف) |

#### مثال:
```sad
# تهيئة UEFI
متغير حالة = uefi_تهيئة()
إذا (حالة == 0)
    اطبع_سطر("تم تهيئة UEFI بنجاح!")
نهاية
```

### 2. إدارة الذاكرة

| الدالة (عربي) | الدالة (إنجليزي) | الوصف |
|---|---|---|
| `uefi_تخصيص_صفحات(نوع، ذاكرة، عدد)` | `uefi_allocate_pages(type, mem, count)` | تخصيص صفحات (4KB لكل صفحة) |
| `uefi_تحرير_صفحات(عنوان، عدد)` | `uefi_free_pages(addr, count)` | تحرير صفحات |
| `uefi_تخصيص_كتلة(نوع، حجم)` | `uefi_allocate_pool(type, size)` | تخصيص كتلة ذاكرة |
| `uefi_تحرير_كتلة(عنوان)` | `uefi_free_pool(addr)` | تحرير كتلة ذاكرة |
| `uefi_خريطة_ذاكرة()` | `uefi_get_memory_map()` | خريطة الذاكرة الكاملة |
| `uefi_مفتاح_خريطة()` | `uefi_get_memory_map_key()` | مفتاح خريطة الذاكرة |
| `uefi_ذاكرة_متاحة()` | `uefi_total_memory()` | إجمالي الذاكرة المتاحة |

#### أنواع الذاكرة:
| القيمة | النوع | الوصف |
|---|---|---|
| 0 | محجوزة | لا يمكن استخدامها |
| 1 | كود المحمّل | كود محمّل الإقلاع |
| 2 | بيانات المحمّل | بيانات محمّل الإقلاع |
| 3 | كود خدمات الإقلاع | كود Boot Services |
| 4 | بيانات خدمات الإقلاع | بيانات Boot Services |
| 5 | كود خدمات وقت التشغيل | كود Runtime Services |
| 6 | بيانات وقت التشغيل | بيانات Runtime Services |
| 7 | تقليدية | ذاكرة حرة قابلة للاستخدام |
| 9 | ACPI قابلة للاسترداد | جداول ACPI |
| 10 | ACPI NVS | ذاكرة ACPI غير متطايرة |
| 11 | MMIO | إدخال/إخراج معيّن بالذاكرة |

#### مثال:
```sad
uefi_تهيئة()

# تخصيص 10 صفحات للنواة
متغير عنوان = uefi_تخصيص_صفحات(0, 7, 10)
اطبع_سطر("عنوان النواة: " + عنوان)

# خريطة الذاكرة
متغير خريطة = uefi_خريطة_ذاكرة()
اطبع_سطر(خريطة)
```

### 3. بروتوكول الرسوميات (GOP)

| الدالة (عربي) | الدالة (إنجليزي) | الوصف |
|---|---|---|
| `uefi_تهيئة_رسوميات()` | `uefi_init_gop()` | تهيئة GOP |
| `uefi_تعيين_وضع_رسوميات(رقم)` | `uefi_set_gop_mode(num)` | تعيين وضع العرض |
| `uefi_استعلام_وضع(رقم)` | `uefi_query_gop_mode(num)` | استعلام معلومات وضع |
| `uefi_عدد_أوضاع_رسوميات()` | `uefi_gop_mode_count()` | عدد الأوضاع المتاحة |
| `uefi_وضع_رسوميات_حالي()` | `uefi_current_gop_mode()` | رقم الوضع الحالي |
| `uefi_عنوان_إطار()` | `uefi_framebuffer_base()` | عنوان إطار الشاشة |
| `uefi_حجم_إطار()` | `uefi_framebuffer_size()` | حجم إطار الشاشة |
| `uefi_ملء_شاشة(أحمر، أخضر، أزرق)` | `uefi_fill_screen(r, g, b)` | ملء الشاشة بلون |
| `uefi_رسم_مستطيل(س، ص، ع، ا، أ، خ، ز)` | `uefi_draw_rect(x, y, w, h, r, g, b)` | رسم مستطيل |

#### الأوضاع المدعومة:
| رقم الوضع | الدقة | نسبة العرض |
|---|---|---|
| 0 | 640×480 | 4:3 |
| 1 | 800×600 | 4:3 |
| 2 | 1024×768 | 4:3 |
| 3 | 1280×720 | 16:9 (HD) |
| 4 | 1920×1080 | 16:9 (Full HD) |

#### مثال — شاشة إقلاع:
```sad
uefi_تهيئة()
uefi_تهيئة_رسوميات()

# تعيين دقة Full HD
uefi_تعيين_وضع_رسوميات(4)

# خلفية زرقاء داكنة
uefi_ملء_شاشة(0, 0, 128)

# شعار أبيض في الوسط
uefi_رسم_مستطيل(810, 440, 300, 200, 255, 255, 255)

اطبع_سطر("شاشة الإقلاع جاهزة!")
```

### 4. خدمات وقت التشغيل

| الدالة (عربي) | الدالة (إنجليزي) | الوصف |
|---|---|---|
| `uefi_الوقت()` | `uefi_get_time()` | الوقت الحالي (نص YYYY-MM-DD HH:MM:SS) |
| `uefi_قراءة_متغير(اسم)` | `uefi_get_variable(name)` | قراءة متغير NVRAM |
| `uefi_كتابة_متغير(اسم، قيمة)` | `uefi_set_variable(name, value)` | كتابة متغير NVRAM |

#### مثال — متغيرات NVRAM:
```sad
uefi_تهيئة()

# حفظ اسم النواة في NVRAM
uefi_كتابة_متغير("اسم_النواة", "صOS v1.0")

# قراءة الاسم لاحقاً
متغير اسم = uefi_قراءة_متغير("اسم_النواة")
اطبع_سطر("اسم النواة: " + اسم)  # صOS v1.0
```

### 5. نظام الملفات

| الدالة (عربي) | الدالة (إنجليزي) | الوصف |
|---|---|---|
| `uefi_فتح_وحدة_تخزين()` | `uefi_open_volume()` | فتح قسم EFI |
| `uefi_فتح_ملف(أب، اسم، وضع)` | `uefi_open_file(parent, name, mode)` | فتح ملف |
| `uefi_قراءة_ملف(واصف، حجم)` | `uefi_read_file(fd, size)` | قراءة ملف |
| `uefi_كتابة_ملف(واصف، بيانات)` | `uefi_write_file(fd, data)` | كتابة ملف |
| `uefi_إغلاق_ملف(واصف)` | `uefi_close_file(fd)` | إغلاق ملف |
| `uefi_معلومات_ملف(واصف)` | `uefi_file_info(fd)` | معلومات الملف |

#### أوضاع فتح الملف:
| القيمة | الوضع |
|---|---|
| 1 | قراءة فقط |
| 2 | كتابة |
| 3 | قراءة + كتابة |

#### مثال — قراءة ملف إعدادات:
```sad
uefi_تهيئة()

# فتح قسم EFI System Partition
متغير جذر = uefi_فتح_وحدة_تخزين()

# فتح ملف إعدادات النواة
متغير ملف = uefi_فتح_ملف(جذر, "\\EFI\\BOOT\\kernel.cfg", 1)

# قراءة المحتوى
متغير محتوى = uefi_قراءة_ملف(ملف, 4096)
اطبع_سطر("الإعدادات: " + محتوى)

# إغلاق الملف
uefi_إغلاق_ملف(ملف)
```

## سيناريو كامل — محمّل إقلاع UEFI

```sad
# ===================================================
# محمّل إقلاع صOS — Sad OS UEFI Bootloader
# ===================================================

# الخطوة 1: تهيئة UEFI
uefi_تهيئة()
اطبع_سطر("✓ تم تهيئة UEFI")

# الخطوة 2: تهيئة الرسوميات
uefi_تهيئة_رسوميات()
uefi_تعيين_وضع_رسوميات(4)  # 1920x1080
اطبع_سطر("✓ دقة 1920x1080")

# الخطوة 3: شاشة إقلاع
uefi_ملء_شاشة(0, 0, 64)  # خلفية زرقاء داكنة
uefi_رسم_مستطيل(760, 390, 400, 300, 255, 255, 255)  # شعار

# الخطوة 4: فتح قسم EFI وقراءة النواة
متغير جذر = uefi_فتح_وحدة_تخزين()
متغير نواة = uefi_فتح_ملف(جذر, "\\EFI\\BOOT\\kernel.bin", 1)
اطبع_سطر("✓ تم فتح ملف النواة")

# الخطوة 5: تخصيص ذاكرة للنواة
متغير عنوان_نواة = uefi_تخصيص_صفحات(0, 7, 256)  # 1MB
اطبع_سطر("✓ تم تخصيص ذاكرة للنواة عند: " + عنوان_نواة)

# الخطوة 6: حفظ معلومات الإقلاع
uefi_كتابة_متغير("آخر_إقلاع", "ناجح")
uefi_كتابة_متغير("نسخة_النواة", "1.0.0")

# الخطوة 7: الحصول على خريطة الذاكرة والمفتاح
متغير مفتاح = uefi_مفتاح_خريطة()
متغير ذاكرة = uefi_ذاكرة_متاحة()
اطبع_سطر("✓ الذاكرة المتاحة: " + ذاكرة + " بايت")

# الخطوة 8: إنهاء خدمات الإقلاع
# ⚠ نقطة اللاعودة — بعد هذا لا يمكن استخدام خدمات UEFI
uefi_إنهاء_خدمات_إقلاع(مفتاح)
اطبع_سطر("✓ تم إنهاء خدمات الإقلاع")

# الخطوة 9: النواة تتحكم الآن!
اطبع_سطر("🚀 صOS v1.0 — نظام التشغيل العربي!")
```

## وضع المحاكاة مقابل الأجهزة الحقيقية

| الخاصية | المحاكاة (المفسر) | الأجهزة الحقيقية (المترجم) |
|---|---|---|
| **الذاكرة** | مُحاكاة بخريطة ثابتة | خريطة UEFI الحقيقية |
| **GOP** | 5 أوضاع محاكاة | أوضاع الشاشة الفعلية |
| **نظام الملفات** | ملفات في الذاكرة | قسم EFI System Partition |
| **NVRAM** | متغيرات في الذاكرة | ذاكرة NVRAM الحقيقية |
| **الوقت** | وقت النظام المضيف | ساعة CMOS/RTC |
| **إعادة التشغيل** | محاكاة فقط | إعادة تشغيل حقيقية |

### خطوط الأنابيب:

**المفسر:**
```
uefi_تهيئة() → builtin_registry_part20 → UefiManager::initialize()
```

**المترجم:**
```
uefi_تهيئة() → SIRBuilder → LOWLEVEL_UEFI_INIT
             → LLVMCodeGen → call sad_ll_uefi_init()
             → Linker → sad_lowlevel_rt.c::sad_ll_uefi_init()
```

## ملاحظات فنية

1. **ExitBootServices**: بعد استدعاء هذه الدالة، تصبح خدمات الإقلاع غير متاحة.
   يجب الحصول على خريطة الذاكرة والمفتاح أولاً.

2. **GOP Framebuffer**: العنوان الفيزيائي لإطار الشاشة يبقى صالحاً بعد
   ExitBootServices. يمكن الكتابة مباشرة إلى الذاكرة.

3. **NVRAM**: متغيرات NVRAM تبقى عبر إعادة التشغيل على بيئة حقيقية.
   في المحاكاة تُفقد عند إنهاء البرنامج.

4. **أنواع التخصيص**: `AllocateAnyPages (0)` هو الأكثر شيوعاً.
   `AllocateAddress (2)` يخصص عند عنوان محدد.
