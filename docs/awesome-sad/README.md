## المكتبات / Libraries

### الشبكة / Network

- [sad-http](https://github.com/sad-lang/sad-http) - مكتبة HTTP شاملة / Comprehensive HTTP library
- [sad-websocket](https://github.com/sad-lang/sad-websocket) - دعم WebSocket / WebSocket support

- [sad-mongodb](https://github.com/sad-lang/sad-mongodb) - MongoDB driver

- [sad-ui](https://github.com/sad-lang/sad-ui) - مكتبة واجهات أصلية / Native UI library
- [sad-gtk](https://github.com/sad-lang/sad-gtk) - GTK binding
- [sad-qt](https://github.com/sad-lang/sad-qt) - Qt binding
- [sad-imgui](https://github.com/sad-lang/sad-imgui) - Dear ImGui binding

- [sad-graphics](https://github.com/sad-lang/sad-graphics) - 2D/3D graphics
- [sad-sdl2](https://github.com/sad-lang/sad-sdl2) - SDL2 binding
- [sad-opengl](https://github.com/sad-lang/sad-opengl) - OpenGL wrapper
- [sad-vulkan](https://github.com/sad-lang/sad-vulkan) - Vulkan wrapper

### الألعاب / Games

- [sad-game](https://github.com/sad-lang/sad-game) - Game development framework

- [sad-xml](https://github.com/sad-lang/sad-xml) - XML parsing
