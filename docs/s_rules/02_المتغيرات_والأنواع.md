# المتغيرات وأنواع البيانات

## القاعدة
المتغيرات هي حاويات لتخزين القيم في الذاكرة. تدعم لغة ص أنواع بيانات متعددة: الأعداد الصحيحة، الأعداد العشرية، السلاسل النصية، القيم المنطقية، القوائم، والقواميس.

---

## الشرح التفصيلي

### تعريف المتغيرات

#### الصياغة الأساسية
```s
متغير اسم_المتغير = القيمة
```

- **متغير**: كلمة مفتاحية لتعريف متغير جديد
- **اسم_المتغير**: اسم يختاره المبرمج
- **=**: عامل الإسناد (Assignment)
- **القيمة**: البيانات المُخزّنة

#### المتغيرات الديناميكية
لغة ص لغة ديناميكية النوع (Dynamically Typed)، أي أن نوع المتغير يُحدد تلقائياً:

```s
متغير العدد = 10        # عدد صحيح تلقائياً
متغير الاسم = "أحمد"     # نص تلقائياً
متغير القيمة = 3.14      # عدد عشري تلقائياً
```

### أنواع البيانات الأساسية

#### ١. الأعداد الصحيحة (Integer)
```s
متغير العمر = 25
متغير السنة = 2025
متغير عدد_الطلاب = 150
```

#### ٢. الأعداد العشرية (Float)
```s
متغير الطول = 1.75
متغير السعر = 49.99
متغير النسبة = 0.85
```

#### ٣. السلاسل النصية (String)
```s
نص الاسم = "محمد"
نص  المدينة = "الرياض"
متغير الرسالة = 'مرحباً بكم'    # يمكن استخدام ' أو "
```

#### ٤. القيم المنطقية (Boolean)
```s
متغير صحيح = صح    # true
متغير خاطئ = خطأ   # false
```

#### ٥. لا شيء (Null/None)
```s
متغير فارغ = لاشيء   # null/none
```

#### ٦. القوائم (Lists)
```s
متغير الأرقام = [1، 2، 3، 4، 5]
متغير الأسماء = ["أحمد"، "فاطمة"، "علي"]
متغير مختلط = [1، "نص"، 3.14، صح]
```

#### ٧. القواميس (Dictionaries)
```s
متغير الطالب = {
    "الاسم": "أحمد"،
    "العمر": 20،
    "التخصص": "علوم الحاسب"
}
```

### عمليات على المتغيرات

#### الإسناد
```s
متغير س = 10
س = 20           # تغيير القيمة
س = س + 5        # استخدام القيمة الحالية
```

#### الإسناد المتعدد
```s
متغير أ، ب، ج = 1، 2، 3
```

#### تبديل القيم
```s
متغير أ = 5
متغير ب = 10
أ، ب = ب، أ     # الآن أ = 10 و ب = 5
```

### التحويل بين الأنواع

#### إلى عدد صحيح
```s
متغير نص = "123"
متغير رقم = حول_لعدد_صحيح(نص)    # 123
```

#### إلى عدد عشري
```s
متغير نص = "3.14"
متغير رقم = حول_لعدد_عشري(نص)    # 3.14
```

#### إلى نص
```s
متغير رقم = 100
متغير نص = حول_لنص(رقم)           # "100"
```

#### إلى منطقي
```s
متغير رقم = 0
متغير منطقي = حول_لمنطقي(رقم)    # خطأ (0 = false)
```

### التحقق من النوع

```s
متغير قيمة = 123

إذا نوع(قيمة) == "عدد" إذن
    اطبع_سطر("هذا رقم")
نهاية
```

## المثال الأول: حاسبة معدل الدرجات

```s
# برنامج لحساب معدل الدرجات مع معلومات الطالب

# بيانات الطالب
متغير اسم_الطالب = "أحمد محمد"
متغير رقم_الطالب = 2025001
متغير الفصل = "الأول"

# الدرجات
متغير درجة_الرياضيات = 95
متغير درجة_الفيزياء = 88
متغير درجة_الكيمياء = 92
متغير درجة_العربية = 90
متغير درجة_الإنجليزية = 87

# حساب المجموع والمعدل
متغير المجموع = درجة_الرياضيات + درجة_الفيزياء + درجة_الكيمياء + درجة_العربية + درجة_الإنجليزية
متغير المعدل = المجموع / 5.0

# حساب النسبة المئوية (من 100)
متغير النسبة_المئوية = (المعدل / 100) * 100

# تحديد حالة النجاح
متغير ناجح = المعدل >= 60

# عرض النتائج
اطبع_سطر("===== تقرير درجات الطالب =====")
اطبع_سطر("الاسم: " + اسم_الطالب)
اطبع_سطر("رقم الطالب: " + حول_لنص(رقم_الطالب))
اطبع_سطر("الفصل الدراسي: " + الفصل)
اطبع_سطر("--------------------------------")
اطبع_سطر("الرياضيات: " + حول_لنص(درجة_الرياضيات))
اطبع_سطر("الفيزياء: " + حول_لنص(درجة_الفيزياء))
اطبع_سطر("الكيمياء: " + حول_لنص(درجة_الكيمياء))
اطبع_سطر("العربية: " + حول_لنص(درجة_العربية))
اطبع_سطر("الإنجليزية: " + حول_لنص(درجة_الإنجليزية))
اطبع_سطر("--------------------------------")
اطبع_سطر("المجموع: " + حول_لنص(المجموع) + " من 500")
اطبع_سطر("المعدل: " + حول_لنص(المعدل))
اطبع_سطر("النسبة المئوية: " + حول_لنص(النسبة_المئوية) + "%")

إذا ناجح إذن
    اطبع_سطر("الحالة: ناجح ✓")
وإلا
    اطبع_سطر("الحالة: راسب ✗")
نهاية
```

**الخرج:**
```
===== تقرير درجات الطالب =====
الاسم: أحمد محمد
رقم الطالب: 2025001
الفصل الدراسي: الأول
--------------------------------
الرياضيات: 95
الفيزياء: 88
الكيمياء: 92
العربية: 90
الإنجليزية: 87
--------------------------------
المجموع: 452 من 500
المعدل: 90.4
النسبة المئوية: 90.4%
الحالة: ناجح ✓
```

**الشرح:**
- استخدام أنواع متعددة: نص، أعداد صحيحة، أعداد عشرية، منطقية
- العمليات الحسابية على المتغيرات
- تحويل الأنواع عند الطباعة
- استخدام المتغيرات المنطقية في الشروط

## المثال الثاني: إدارة بيانات منتج

```s
# برنامج لإدارة معلومات منتج في متجر

# معلومات المنتج الأساسية
متغير اسم_المنتج = "حاسوب محمول"
متغير كود_المنتج = "LAP-2025-001"
متغير الفئة = "إلكترونيات"

# الأسعار
متغير السعر_الأصلي = 3500.00
متغير نسبة_الخصم = 15.0              # 15%
متغير السعر_بعد_الخصم = السعر_الأصلي - (السعر_الأصلي * نسبة_الخصم / 100)

# المخزون
متغير الكمية_المتوفرة = 25
متغير الحد_الأدنى = 5
متغير يحتاج_طلب = الكمية_المتوفرة <= الحد_الأدنى

# المواصفات (قاموس)
متغير المواصفات = {
    "المعالج": "Intel Core i7"،
    "الذاكرة": "16 جيجابايت"،
    "التخزين": "512 SSD"،
    "الشاشة": "15.6 بوصة"
}

# التقييمات
متغير التقييمات = [5، 4، 5، 4، 5]  # من 5
متغير مجموع_التقييمات = 0
متغير عدد_التقييمات = طول(التقييمات)

# حساب متوسط التقييم
لكل تقييم في التقييمات افعل
    مجموع_التقييمات = مجموع_التقييمات + تقييم
نهاية
متغير متوسط_التقييم = مجموع_التقييمات / عدد_التقييمات

# عرض معلومات المنتج
اطبع_سطر("╔════════════════════════════════════╗")
اطبع_سطر("║       معلومات المنتج              ║")
اطبع_سطر("╚════════════════════════════════════╝")
اطبع_سطر("")
اطبع_سطر("📦 المنتج: " + اسم_المنتج)
اطبع_سطر("🔖 الكود: " + كود_المنتج)
اطبع_سطر("📂 الفئة: " + الفئة)
اطبع_سطر("")
اطبع_سطر("💰 السعر الأصلي: " + حول_لنص(السعر_الأصلي) + " ريال")
اطبع_سطر("🎁 الخصم: " + حول_لنص(نسبة_الخصم) + "%")
اطبع_سطر("💵 السعر بعد الخصم: " + حول_لنص(السعر_بعد_الخصم) + " ريال")
اطبع_سطر("")
اطبع_سطر("📊 الكمية المتوفرة: " + حول_لنص(الكمية_المتوفرة))
إذا يحتاج_طلب إذن
    اطبع_سطر("⚠️  تنبيه: الكمية منخفضة - يُنصح بالطلب!")
وإلا
    اطبع_سطر("✅ المخزون جيد")
نهاية
اطبع_سطر("")
اطبع_سطر("⭐ التقييم: " + حول_لنص(متوسط_التقييم) + " من 5")
اطبع_سطر("📝 عدد التقييمات: " + حول_لنص(عدد_التقييمات))
اطبع_سطر("")
اطبع_سطر("🔧 المواصفات:")
اطبع_سطر("   • المعالج: " + المواصفات["المعالج"])
اطبع_سطر("   • الذاكرة: " + المواصفات["الذاكرة"])
اطبع_سطر("   • التخزين: " + المواصفات["التخزين"])
اطبع_سطر("   • الشاشة: " + المواصفات["الشاشة"])
```

**الخرج:**
```
╔════════════════════════════════════╗
║       معلومات المنتج              ║
╚════════════════════════════════════╝

📦 المنتج: حاسوب محمول
🔖 الكود: LAP-2025-001
📂 الفئة: إلكترونيات

💰 السعر الأصلي: 3500.0 ريال
🎁 الخصم: 15.0%
💵 السعر بعد الخصم: 2975.0 ريال

📊 الكمية المتوفرة: 25
✅ المخزون جيد

⭐ التقييم: 4.6 من 5
📝 عدد التقييمات: 5

🔧 المواصفات:
   • المعالج: Intel Core i7
```

**الشرح:**
- استخدام القواميس لتخزين بيانات منظمة
- استخدام القوائم للتقييمات

- الشروط المنطقية للتحقق من المخزون
- حلقات لحساب المتوسط

## المثال الثالث: محول وحدات متعدد

```s
# برنامج لتحويل بين وحدات القياس المختلفة

# ====== تحويلات الطول ======
دالة حول_متر_لكيلومتر(متر)
    ارجع متر / 1000.0
نهاية

دالة حول_كيلومتر_لميل(كيلومتر)
    ارجع كيلومتر * 0.621371
نهاية

# ====== تحويلات الوزن ======
دالة حول_جرام_لكيلوجرام(جرام)
    ارجع جرام / 1000.0
نهاية

دالة حول_كيلوجرام_لرطل(كيلوجرام)
    ارجع كيلوجرام * 2.20462
نهاية

# ====== تحويلات الحرارة ======
دالة حول_مئوية_لفهرنهايت(مئوية)
    ارجع (مئوية * 9.0 / 5.0) + 32.0
نهاية

دالة حول_فهرنهايت_لمئوية(فهرنهايت)
    ارجع (فهرنهايت - 32.0) * 5.0 / 9.0
نهاية

# ====== البرنامج الرئيسي ======
اطبع_سطر("═══════════════════════════════")
اطبع_سطر("    محول الوحدات المتعدد     ")
اطبع_سطر("═══════════════════════════════")
اطبع_سطر("")

# تحويلات الطول
متغير المسافة_بالمتر = 5000.0
متغير المسافة_بالكيلومتر = حول_متر_لكيلومتر(المسافة_بالمتر)
متغير المسافة_بالميل = حول_كيلومتر_لميل(المسافة_بالكيلومتر)

اطبع_سطر("📏 تحويلات الطول:")
اطبع_سطر("   " + حول_لنص(المسافة_بالمتر) + " متر")
اطبع_سطر("   = " + حول_لنص(المسافة_بالكيلومتر) + " كيلومتر")
اطبع_سطر("   = " + حول_لنص(المسافة_بالميل) + " ميل")
اطبع_سطر("")

# تحويلات الوزن
متغير الوزن_بالجرام = 2500.0
متغير الوزن_بالكيلوجرام = حول_جرام_لكيلوجرام(الوزن_بالجرام)
متغير الوزن_بالرطل = حول_كيلوجرام_لرطل(الوزن_بالكيلوجرام)

اطبع_سطر("⚖️  تحويلات الوزن:")
اطبع_سطر("   " + حول_لنص(الوزن_بالجرام) + " جرام")
اطبع_سطر("   = " + حول_لنص(الوزن_بالكيلوجرام) + " كيلوجرام")
اطبع_سطر("   = " + حول_لنص(الوزن_بالرطل) + " رطل")
اطبع_سطر("")

# تحويلات الحرارة
متغير درجة_الحرارة_مئوية = 25.0
متغير درجة_الحرارة_فهرنهايت = حول_مئوية_لفهرنهايت(درجة_الحرارة_مئوية)

اطبع_سطر("🌡️  تحويلات الحرارة:")
اطبع_سطر("   " + حول_لنص(درجة_الحرارة_مئوية) + "°C")
اطبع_سطر("   = " + حول_لنص(درجة_الحرارة_فهرنهايت) + "°F")
اطبع_سطر("")

# جدول قيم متعددة
متغير درجات_مئوية = [0، 10، 20، 30، 40]
اطبع_سطر("📊 جدول تحويل درجات الحرارة:")
اطبع_سطر("   مئوية | فهرنهايت")
اطبع_سطر("   -------|---------")

لكل درجة في درجات_مئوية افعل
    متغير فهرنهايت = حول_مئوية_لفهرنهايت(درجة)
    اطبع_سطر("   " + حول_لنص(درجة) + "°C    | " + حول_لنص(فهرنهايت) + "°F")
نهاية
```

**الخرج:**

- دوال متخصصة للتحويل بين الوحدات

- حلقات لإنشاء جداول

## ملاحظات مهمة

### ١. النطاق (Scope)
```s
متغير عام = 100

دالة مثال()
    متغير محلي = 50     # متغير محلي داخل الدالة فقط
    اطبع_سطر(عام)       # يمكن الوصول للمتغير العام
نهاية

اطبع_سطر(عام)           # صحيح
# اطبع_سطر(محلي)       # خطأ - خارج النطاق
```

### ٢. الثوابت
```s
# لغة ص تدعم الثوابت باستخدام الحروف الكبيرة
متغير PI = 3.14159265359
متغير MAX_SIZE = 1000

# العرف: لا تغير قيمة الثوابت في الكود
```

### ٣. المتغيرات الفارغة
```s
متغير قيمة = لاشيء

إذا قيمة == لاشيء إذن
    اطبع_سطر("المتغير فارغ")
نهاية
```

### ٤. حذف المتغيرات
```s
متغير مؤقت = "قيمة"
احذف مؤقت              # حذف المتغير من الذاكرة
```

## أفضل الممارسات

1. **أسماء واضحة**: استخدم أسماء توضح الغرض
   ```s
   متغير عمر_الطالب = 20        # جيد
   متغير ع = 20                  # سيء
   ```

2. **الثوابت بحروف كبيرة**: للتمييز عن المتغيرات
   ```s
   متغير MAX_USERS = 100
   متغير DEFAULT_TIMEOUT = 30
   ```

3. **تهيئة المتغيرات**: أعط قيمة ابتدائية
   ```s
   متغير العداد = 0             # جيد
   متغير المجموع = 0.0          # جيد
   ```

4. **تجنب التسميات المربكة**: لا تستخدم أسماء مشابهة
   ```s
   متغير اسم = "أحمد"
   متغير اسم١ = "محمد"          # مربك
   متغير الاسم_الأول = "محمد"   # أفضل
   ```
