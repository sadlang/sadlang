# التعامل مع نظام التشغيل

## القاعدة
مكتبة نظام التشغيل توفر واجهة برمجية للتفاعل مع نظام التشغيل وإدارة الموارد والعمليات.

---

## الشرح التفصيلي

### استيراد المكتبة

```s
استورد نظام_التشغيل من "نظام"
# أو
استورد نت من "نظام"
```

### معلومات النظام

#### `نت.اسم_النظام()` - System Name
الحصول على اسم نظام التشغيل

**القيم الممكنة:**
- `"ويندوز"` / `"Windows"`
- `"لينكس"` / `"Linux"`
- `"ماك"` / `"macOS"`

```s
متغير النظام = نت.اسم_النظام()
اطبع_سطر("نظام التشغيل: " + النظام)
```

#### `نت.معمارية_النظام()` - Architecture
معرفة معمارية المعالج

**القيم الممكنة:**
- `"64بت"` / `"x64"`
- `"32بت"` / `"x86"`
- `"ARM64"`

```s
متغير المعمارية = نت.معمارية_النظام()
اطبع_سطر("المعمارية: " + المعمارية)
```

#### `نت.إصدار_النظام()` - OS Version
الحصول على إصدار نظام التشغيل

```s
متغير الإصدار = نت.إصدار_النظام()
اطبع_سطر("الإصدار: " + الإصدار)
```

#### `نت.اسم_المضيف()` - Hostname
اسم الجهاز على الشبكة

```s
متغير اسم_الجهاز = نت.اسم_المضيف()
اطبع_سطر("اسم الجهاز: " + اسم_الجهاز)
```

### متغيرات البيئة

#### `نت.احصل_على_متغير(اسم)` - Get Environment Variable
قراءة متغير بيئة

```s
متغير المسار = نت.احصل_على_متغير("PATH")
متغير المستخدم = نت.احصل_على_متغير("USERNAME")
```

#### `نت.ضع_متغير(اسم، قيمة)` - Set Environment Variable
تعيين متغير بيئة

```s
نت.ضع_متغير("MY_APP"، "1.0.0")
```

#### `نت.جميع_المتغيرات()` - All Environment Variables
الحصول على جميع متغيرات البيئة كقاموس

```s
متغير المتغيرات = نت.جميع_المتغيرات()
لكل اسم، قيمة في المتغيرات افعل
    اطبع_سطر(اسم + " = " + قيمة)
نهاية
```

### تنفيذ الأوامر

#### `نت.نفذ_أمر(أمر)` - Execute Command
تنفيذ أمر في سطر الأوامر

```s
متغير النتيجة = نت.نفذ_أمر("dir")        # Windows
متغير النتيجة = نت.نفذ_أمر("ls")         # Linux/Mac
```

**القيمة المرجعة**: قاموس يحتوي على:
- `"الخرج"` / `"output"`: النص المطبوع
- `"كود_الخروج"` / `"exit_code"`: رقم الخروج (0 = نجح)
- `"أخطاء"` / `"errors"`: رسائل الأخطاء

```s
متغير النتيجة = نت.نفذ_أمر("python --version")
إذا النتيجة["كود_الخروج"] == 0 إذن
    اطبع_سطر("Python موجود: " + النتيجة["الخرج"])
وإلا
    اطبع_سطر("خطأ: " + النتيجة["أخطاء"])
نهاية
```

#### `نت.نفذ_في_الخلفية(أمر)` - Execute in Background
تنفيذ أمر في الخلفية دون انتظار

```s
متغير معرف_العملية = نت.نفذ_في_الخلفية("notepad.exe")
اطبع_سطر("تم تشغيل العملية: " + حول_لنص(معرف_العملية))
```

### إدارة المسارات

#### `نت.المسار_الحالي()` - Current Directory
الحصول على المسار الحالي

```s
متغير المسار = نت.المسار_الحالي()
اطبع_سطر("المسار الحالي: " + المسار)
```

#### `نت.غير_المسار(مسار)` - Change Directory
تغيير المسار الحالي

```s
نت.غير_المسار("C:\\المشاريع")
```

#### `نت.مسار_المنزل()` - Home Directory
مجلد المستخدم الرئيسي

```s
متغير المنزل = نت.مسار_المنزل()
# Windows: C:\Users\username
# Linux: /home/username
```

#### `نت.مسار_مؤقت()` - Temp Directory
مجلد الملفات المؤقتة

```s
متغير المؤقت = نت.مسار_مؤقت()
```

### معلومات الموارد

#### `نت.عدد_المعالجات()` - CPU Count
عدد أنوية المعالج

```s
متغير الأنوية = نت.عدد_المعالجات()
اطبع_سطر("عدد الأنوية: " + حول_لنص(الأنوية))
```

#### `نت.استخدام_المعالج()` - CPU Usage
نسبة استخدام المعالج (0-100)

```s
متغير الاستخدام = نت.استخدام_المعالج()
اطبع_سطر("استخدام المعالج: " + حول_لنص(الاستخدام) + "%")
```

#### `نت.معلومات_الذاكرة()` - Memory Info
معلومات الذاكرة العشوائية (RAM)

**القيمة المرجعة**: قاموس يحتوي على:
- `"الكلية"` / `"total"`: الذاكرة الكلية بالبايت
- `"المتاحة"` / `"available"`: الذاكرة المتاحة
- `"المستخدمة"` / `"used"`: الذاكرة المستخدمة
- `"النسبة"` / `"percent"`: نسبة الاستخدام

```s
متغير الذاكرة = نت.معلومات_الذاكرة()
متغير جيجا = الذاكرة["الكلية"] / (1024 * 1024 * 1024)
اطبع_سطر("الذاكرة الكلية: " + حول_لنص(جيجا) + " جيجا")
اطبع_سطر("نسبة الاستخدام: " + حول_لنص(الذاكرة["النسبة"]) + "%")
```

#### `نت.معلومات_القرص(مسار)` - Disk Info
معلومات مساحة القرص

```s
متغير القرص = نت.معلومات_القرص("C:\\")
اطبع_سطر("المساحة الكلية: " + حول_لنص(القرص["الكلية"] / (1024**3)) + " جيجا")
اطبع_سطر("المساحة الحرة: " + حول_لنص(القرص["الحرة"] / (1024**3)) + " جيجا")
```

### وقت التشغيل

#### `نت.وقت_التشغيل()` - Uptime
وقت تشغيل النظام بالثواني

```s
متغير الثواني = نت.وقت_التشغيل()
متغير الساعات = الثواني / 3600
اطبع_سطر("النظام يعمل منذ: " + حول_لنص(الساعات) + " ساعة")
```

```s
# برنامج لمراقبة موارد نظام التشغيل

استورد نت من "نظام"
استورد وقت من "وقت"

# دالة لتحويل البايت لوحدات مناسبة
دالة حجم_قابل_للقراءة(بايت)
    متغير وحدات = ["بايت"، "كيلو"، "ميجا"، "جيجا"، "تيرا"]
    متغير مؤشر = 0
    متغير الحجم = بايت
    
    بينما الحجم >= 1024 و مؤشر < طول(وحدات) - 1 افعل
        الحجم = الحجم / 1024.0
        مؤشر = مؤشر + 1
    نهاية
    
    ارجع نسق("{0:.2f} {1}"، الحجم، وحدات[مؤشر])
نهاية

# دالة لعرض معلومات النظام
دالة معلومات_النظام()
    امسح_الشاشة()
    بلون("سماوي"، "╔════════════════════════════════════════════╗")
    بلون("سماوي"، "║      🖥️  مراقب موارد النظام              ║")
    بلون("سماوي"، "╚════════════════════════════════════════════╝")
    اطبع_سطر("")
    
    # معلومات أساسية
    بلون("أصفر"، "📋 معلومات النظام:")
    اطبع_سطر("   • نظام التشغيل: " + نت.اسم_النظام())
    اطبع_سطر("   • الإصدار: " + نت.إصدار_النظام())
    اطبع_سطر("   • المعمارية: " + نت.معمارية_النظام())
    اطبع_سطر("   • اسم الجهاز: " + نت.اسم_المضيف())
    اطبع_سطر("   • اسم المستخدم: " + نت.احصل_على_متغير("USERNAME"))
    
    # وقت التشغيل
    متغير الثواني = نت.وقت_التشغيل()
    متغير أيام = الثواني / 86400
    متغير ساعات = (الثواني % 86400) / 3600
    متغير دقائق = (الثواني % 3600) / 60
    
    اطبع_سطر("   • وقت التشغيل: " + حول_لنص(أيام) + " يوم، " + 
                حول_لنص(ساعات) + " ساعة، " + حول_لنص(دقائق) + " دقيقة")
    اطبع_سطر("")
نهاية

# دالة لعرض معلومات المعالج
دالة معلومات_المعالج()
    بلون("أصفر"، "⚙️  المعالج (CPU):")
    متغير عدد_الأنوية = نت.عدد_المعالجات()
    متغير الاستخدام = نت.استخدام_المعالج()
    
    اطبع_سطر("   • عدد الأنوية: " + حول_لنص(عدد_الأنوية))
    اطبع_سطر("   • الاستخدام: " + حول_لنص(الاستخدام) + "%")
    
    # شريط تقدم للاستخدام
    متغير الأعمدة = الاستخدام / 2  # كل عمود = 2%
    متغير الشريط = "["
    لكل ع في مدى(50) افعل
        إذا ع < الأعمدة إذن
            الشريط = الشريط + "█"
        وإلا
            الشريط = الشريط + "░"
        نهاية
    نهاية
    الشريط = الشريط + "]"
    
    إذا الاستخدام > 80 إذن
        بلون("أحمر"، "   " + الشريط)
    وإلا_إذا الاستخدام > 60 إذن
        بلون("أصفر"، "   " + الشريط)
    وإلا
        بلون("أخضر"، "   " + الشريط)
    نهاية
    
    اطبع_سطر("")
نهاية

# دالة لعرض معلومات الذاكرة
دالة معلومات_الذاكرة()
    بلون("أصفر"، "💾 الذاكرة (RAM):")
    متغير الذاكرة = نت.معلومات_الذاكرة()
    
    متغير الكلية_جيجا = الذاكرة["الكلية"] / (1024 * 1024 * 1024)
    متغير المستخدمة_جيجا = الذاكرة["المستخدمة"] / (1024 * 1024 * 1024)
    متغير المتاحة_جيجا = الذاكرة["المتاحة"] / (1024 * 1024 * 1024)
    
    اطبع_سطر("   • المجموع: " + نسق("{0:.2f} جيجا"، الكلية_جيجا))
    اطبع_سطر("   • المستخدم: " + نسق("{0:.2f} جيجا"، المستخدمة_جيجا))
    اطبع_سطر("   • المتاح: " + نسق("{0:.2f} جيجا"، المتاحة_جيجا))
    اطبع_سطر("   • نسبة الاستخدام: " + حول_لنص(الذاكرة["النسبة"]) + "%")
    
    # شريط تقدم
    متغير النسبة = الذاكرة["النسبة"]
    متغير الأعمدة = النسبة / 2
    متغير الشريط = "["
    
    لكل ع في مدى(50) افعل
        إذا ع < الأعمدة إذن
            الشريط = الشريط + "█"
        وإلا
            الشريط = الشريط + "░"
        نهاية
    نهاية
    الشريط = الشريط + "]"
    
    إذا النسبة > 80 إذن
        بلون("أحمر"، "   " + الشريط)
    وإلا_إذا النسبة > 60 إذن
        بلون("أصفر"، "   " + الشريط)
    وإلا
        بلون("أخضر"، "   " + الشريط)
    نهاية
    
    اطبع_سطر("")
نهاية

# دالة لعرض معلومات الأقراص
دالة معلومات_الأقراص()
    بلون("أصفر"، "💿 الأقراص:")
    
    # قائمة الأقراص (حسب نظام التشغيل)
    متغير الأقراص = []
    
    إذا نت.اسم_النظام() == "ويندوز" إذن
        الأقراص = ["C:\\"، "D:\\"، "E:\\"]
    وإلا
        الأقراص = ["/"، "/home"، "/tmp"]
    نهاية
    
    لكل قرص في الأقراص افعل
        إذا نت.يوجد_مسار(قرص) إذن
            متغير معلومات = نت.معلومات_القرص(قرص)
            
            متغير الكلية = معلومات["الكلية"] / (1024**3)
            متغير المستخدمة = معلومات["المستخدمة"] / (1024**3)
            متغير الحرة = معلومات["الحرة"] / (1024**3)
            متغير النسبة = (معلومات["المستخدمة"] / معلومات["الكلية"]) * 100
            
            اطبع_سطر("")
            اطبع_سطر("   📂 القرص: " + قرص)
            اطبع_سطر("      • المجموع: " + نسق("{0:.2f} جيجا"، الكلية))
            اطبع_سطر("      • المستخدم: " + نسق("{0:.2f} جيجا"، المستخدمة))
            اطبع_سطر("      • الحر: " + نسق("{0:.2f} جيجا"، الحرة))
            اطبع_سطر("      • نسبة الاستخدام: " + نسق("{0:.1f}%"، النسبة))
        نهاية
    نهاية
    
    اطبع_سطر("")
نهاية

# البرنامج الرئيسي - مراقبة مستمرة
متغير مستمر = صح
متغير العداد = 0

بينما مستمر افعل
    معلومات_النظام()
    معلومات_المعالج()
    معلومات_الذاكرة()
    معلومات_الأقراص()
    
    العداد = العداد + 1
    اطبع_سطر("🔄 التحديث رقم: " + حول_لنص(العداد))
    اطبع_سطر("")
    بلون("سماوي"، "⏱️  سيتم التحديث التلقائي بعد 5 ثوانٍ...")
    بلون("سماوي"، "   اضغط Ctrl+C للخروج")
    
    # انتظار 5 ثوانٍ
    وقت.نم(5)
نهاية
```

- مراقبة شاملة لموارد النظام

- معلومات مفصلة عن جميع الموارد

## المثال الثاني: مدير العمليات البسيط

```s
# مدير العمليات - إدارة البرامج قيد التشغيل

استورد نت من "نظام"
استورد عمليات من "نظام.عمليات"

# دالة لعرض قائمة العمليات
دالة اعرض_العمليات()
    امسح_الشاشة()
    بلون("سماوي"، "╔════════════════════════════════════════════════════╗")
    بلون("سماوي"، "║          📊 مدير العمليات (Task Manager)         ║")
    بلون("سماوي"، "╚════════════════════════════════════════════════════╝")
    اطبع_سطر("")
    
    # الحصول على قائمة العمليات
    متغير العمليات = عمليات.قائمة_العمليات()
    متغير المجموع = طول(العمليات)
    
    بلون("أخضر"، "عدد العمليات النشطة: " + حول_لنص(المجموع))
    اطبع_سطر("")
    
    # ترتيب حسب استخدام الذاكرة
    متغير العمليات_مرتبة = رتب(العمليات، مفتاح=دالة(ع) ارجع ع["الذاكرة"] نهاية، عكسي=صح)
    
    # عرض أعلى 10 عمليات
    اطبع_سطر("┌────────┬────────────────────────────┬────────────┬──────────┐")
    اطبع_سطر("│  PID   │    اسم العملية            │   الذاكرة  │   CPU%   │")
    اطبع_سطر("├────────┼────────────────────────────┼────────────┼──────────┤")
    
    متغير عداد = 0
    لكل عملية في العمليات_مرتبة افعل
        إذا عداد >= 10 إذن
            اخرج
        نهاية
        
        متغير المعرف = عملية["المعرف"]
        متغير الاسم = عملية["الاسم"]
        متغير الذاكرة = عملية["الذاكرة"] / (1024 * 1024)  # ميجابايت
        متغير المعالج = عملية["استخدام_المعالج"]
        
        # قص الاسم إذا كان طويلاً
        إذا طول(الاسم) > 26 إذن
            الاسم = اقتطع(الاسم، 0، 23) + "..."
        نهاية
        
        اطبع_سطر(نسق("│ {0:6} │ {1:26} │ {2:8.1f} MB│ {3:7.1f}% │"، 
                        المعرف، الاسم، الذاكرة، المعالج))
        
        عداد = عداد + 1
    نهاية
    
    اطبع_سطر("└────────┴────────────────────────────┴────────────┴──────────┘")
    اطبع_سطر("")
نهاية

# دالة لإيقاف عملية
دالة اوقف_عملية()
    اطبع("")
    اطبع("أدخل PID للعملية المراد إيقافها: ")
    متغير المعرف = حول_لعدد_صحيح(اقرأ_سطر())
    
    حاول
        إذا عمليات.اوقف_عملية(المعرف) إذن
            بلون("أخضر"، "✓ تم إيقاف العملية بنجاح")
        وإلا
            بلون("أحمر"، "✗ فشل في إيقاف العملية - قد تحتاج صلاحيات")
        نهاية
    اقبض خطأ
        بلون("أحمر"، "✗ خطأ: " + خطأ.رسالة())
    نهاية
    
    اطبع("")
    اطبع("اضغط Enter للمتابعة...")
    اقرأ_سطر()
نهاية

# دالة لتشغيل برنامج جديد
دالة شغل_برنامج()
    اطبع("")
    اطبع("أدخل مسار البرنامج أو اسم الأمر: ")
    متغير الأمر = اقرأ_سطر()
    
    حاول
        متغير المعرف = نت.نفذ_في_الخلفية(الأمر)
        بلون("أخضر"، "✓ تم تشغيل البرنامج - PID: " + حول_لنص(المعرف))
    اقبض خطأ
        بلون("أحمر"، "✗ فشل في تشغيل البرنامج: " + خطأ.رسالة())
    نهاية
    
    اطبع("")
    اطبع("اضغط Enter للمتابعة...")
    اقرأ_سطر()
نهاية

# دالة للبحث عن عملية
دالة ابحث_عن_عملية()
    اطبع("")
    اطبع("أدخل اسم العملية للبحث: ")
    متغير البحث = اقرأ_سطر()
    
    متغير العمليات = عمليات.قائمة_العمليات()
    متغير النتائج = []
    
    لكل عملية في العمليات افعل
        إذا يحتوي(اصغر_حالة(عملية["الاسم"])، اصغر_حالة(البحث)) إذن
            اضف(النتائج، عملية)
        نهاية
    نهاية
    
    اطبع("")
    إذا طول(النتائج) > 0 إذن
        بلون("أخضر"، "✓ تم العثور على " + حول_لنص(طول(النتائج)) + " عملية:")
        اطبع_سطر("")
```

## ملخص الدوال

### معلومات النظام
- `نت.اسم_النظام()` - اسم نظام التشغيل
- `نت.إصدار_النظام()` - إصدار النظام
- `نت.معمارية_النظام()` - معمارية المعالج
- `نت.اسم_المضيف()` - اسم الجهاز
- `نت.وقت_التشغيل()` - مدة تشغيل النظام

### متغيرات البيئة
- `نت.احصل_على_متغير(اسم)` - قراءة متغير
- `نت.ضع_متغير(اسم، قيمة)` - تعيين متغير
- `نت.جميع_المتغيرات()` - كل المتغيرات

### تنفيذ الأوامر
- `نت.نفذ_أمر(أمر)` - تنفيذ مع انتظار
- `نت.نفذ_في_الخلفية(أمر)` - تنفيذ في الخلفية

### المسارات
- `نت.المسار_الحالي()` - المسار الحالي
- `نت.غير_المسار(مسار)` - تغيير المسار
- `نت.مسار_المنزل()` - مجلد المستخدم
- `نت.مسار_مؤقت()` - المجلد المؤقت

### الموارد
- `نت.عدد_المعالجات()` - عدد الأنوية
- `نت.استخدام_المعالج()` - نسبة استخدام CPU
- `نت.معلومات_الذاكرة()` - معلومات RAM
- `نت.معلومات_القرص(مسار)` - معلومات القرص
