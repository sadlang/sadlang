## 🎯 كيفية استخدام هذا الدليل

### للمبتدئين
ابدأ بالمرحلة الأولى واقرأ الملفات بالترتيب. كل ملف يحتوي على:
- **القاعدة**: شرح موجز للمفهوم
- **الشرح التفصيلي**: توضيح كامل مع الأمثلة
- **ثلاثة أمثلة عملية**: تطبيقات حقيقية

### للمحترفين
يمكنك الانتقال مباشرة إلى المرحلة التي تحتاجها. كل مرحلة مستقلة نسبياً.

### للمطورين
راجع المرحلة السادسة والسابعة لفهم المكتبات المضمنة ودعم نظم التشغيل.

## 📖 اصطلاحات مستخدمة

- **متغير (var)**: تخزين القيم
- **دالة (function)**: كتلة كود قابلة لإعادة الاستخدام
- **صنف (class)**: قالب لإنشاء الكائنات
- **وحدة (module)**: ملف يحتوي على كود قابل للاستيراد
- **حزمة (package)**: مجموعة من الوحدات

## 🚀 البدء السريع

```s
# برنامجك الأول
اطبع_سطر("مرحباً بك في لغة ص!")

# متغير بسيط
متغير اسم = "أحمد"
اطبع_سطر("مرحباً " + اسم)

# دالة بسيطة
دالة احسب_المجموع(أ، ب)
    متغير النتيجة = أ + ب
    ارجع النتيجة
نهاية

اطبع_سطر(احسب_المجموع(5، 3))
```

## 💡 نصائح للتعلم

1. **اقرأ الشرح أولاً**: افهم المفهوم قبل تجربة الأمثلة
2. **جرّب الأمثلة**: شغّل الكود على جهازك
3. **عدّل الأمثلة**: غيّر القيم والتعليمات لترى النتائج
4. **اكتب كودك الخاص**: طبّق ما تعلمته في مشاريع صغيرة
5. **راجع بانتظام**: عُد للأساسيات كلما احتجت
