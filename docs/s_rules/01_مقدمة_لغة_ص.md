# مقدمة عن لغة ص

## القاعدة
لغة ص هي لغة برمجة عربية حديثة تدعم البرمجة الإجرائية والكائنية، مصممة لتكون سهلة التعلم وقوية في الأداء.

---

## الشرح التفصيلي

### ما هي لغة ص؟
لغة ص (Sad Language) هي لغة برمجة مفتوحة المصدر تم تصميمها لتمكين المبرمجين العرب من الكتابة بلغتهم الأم. تجمع اللغة بين:

- **السهولة**: صياغة واضحة وبسيطة
- **القوة**: دعم كامل للبرمجة الكائنية والوظيفية
- **الأداء**: سرعة تنفيذ عالية
- **العربية**: كلمات مفتاحية وتوثيق باللغة العربية

### لماذا لغة ص؟

#### ١. اللغة العربية أولاً
- الكلمات المفتاحية بالعربية (`متغير`، `دالة`، `إذا`)
- أسماء المتغيرات والدوال بالعربية
- رسائل الأخطاء بالعربية

#### ٢. سهولة التعلم
- صياغة مشابهة للعربية الفصحى
- لا حاجة لفواصل منقوطة `;` في نهاية الأسطر
- استخدام الكلمات العربية بدلاً من الرموز

#### ٣. قوة الأداء
- مترجم سريع
- دعم للبرمجة غير المتزامنة
- مكتبات غنية ومتنوعة

#### ٤. المجتمع والدعم
- مفتوحة المصدر
- توثيق شامل بالعربية
- مجتمع نشط من المطورين

### البنية الأساسية

#### هيكل البرنامج
```s
# التعليقات تبدأ بعلامة #

# تعريف المتغيرات
متغير اسم_المتغير = القيمة

# تعريف الدوال
دالة اسم_الدالة(المعاملات)
    # كود الدالة
    ارجع النتيجة
نهاية

# الجملة الرئيسية
اطبع_سطر("مرحباً بالعالم")
```

### الملفات
- امتداد ملفات لغة ص: `.s`
- مثال: `برنامجي.s`

---

## المثال الأول: برنامج بسيط

```s
# برنامج يطبع رسالة ترحيب

# طباعة رسالة
اطبع_سطر("مرحباً بك في لغة ص!")
اطبع_سطر("هذه أول تجربة لك")

# متغير بسيط
متغير اسم = "أحمد"
اطبع_سطر("أهلاً " + اسم)
```

**الخرج:**
```
مرحباً بك في لغة ص!
هذه أول تجربة لك
أهلاً أحمد
```

**الشرح:**
- `اطبع_سطر()`: دالة مضمنة لطباعة نص مع سطر جديد
- `متغير`: كلمة مفتاحية لتعريف متغير
- `+`: عامل لدمج السلاسل النصية

---

## المثال الثاني: حساب بسيط

```s
# برنامج لحساب مساحة مستطيل

# إدخال البيانات
اطبع("أدخل الطول: ")
متغير الطول = حول_لعدد(اقرأ_سطر())

اطبع("أدخل العرض: ")
متغير العرض = حول_لعدد(اقرأ_سطر())

# الحساب
متغير المساحة = الطول * العرض

# عرض النتيجة
اطبع_سطر("مساحة المستطيل = " + حول_لنص(المساحة))
```

**مثال تشغيل:**
```
أدخل الطول: 5
أدخل العرض: 3
مساحة المستطيل = 15
```

**الشرح:**
- `اطبع()`: طباعة بدون سطر جديد
- `اقرأ_سطر()`: قراءة مدخلات من المستخدم
- `حول_لعدد()`: تحويل نص إلى رقم
- `حول_لنص()`: تحويل رقم إلى نص

---

## المثال الثالث: دالة مخصصة

```s
# برنامج لحساب متوسط درجات طالب

# تعريف دالة لحساب المتوسط
دالة احسب_المتوسط(درجة١، درجة٢، درجة٣)
    متغير المجموع = درجة١ + درجة٢ + درجة٣
    متغير المتوسط = المجموع / 3
    ارجع المتوسط
نهاية

# تعريف دالة لتحديد التقدير
دالة احصل_على_التقدير(المتوسط)
    إذا المتوسط >= 90 إذن
        ارجع "ممتاز"
    وإلا_إذا المتوسط >= 80 إذن
        ارجع "جيد جداً"
    وإلا_إذا المتوسط >= 70 إذن
        ارجع "جيد"
    وإلا_إذا المتوسط >= 60 إذن
        ارجع "مقبول"
    وإلا
        ارجع "راسب"
    نهاية
نهاية

# البرنامج الرئيسي
اطبع_سطر("=== حساب متوسط الدرجات ===")

متغير درجة_الرياضيات = 85
متغير درجة_العلوم = 90
متغير درجة_العربية = 78

متغير المتوسط = احسب_المتوسط(درجة_الرياضيات، درجة_العلوم، درجة_العربية)
متغير التقدير = احصل_على_التقدير(المتوسط)

اطبع_سطر("درجة الرياضيات: " + حول_لنص(درجة_الرياضيات))
اطبع_سطر("درجة العلوم: " + حول_لنص(درجة_العلوم))
اطبع_سطر("درجة العربية: " + حول_لنص(درجة_العربية))
اطبع_سطر("المتوسط: " + حول_لنص(المتوسط))
اطبع_سطر("التقدير: " + التقدير)
```

**الخرج:**
```
=== حساب متوسط الدرجات ===
درجة الرياضيات: 85
درجة العلوم: 90
درجة العربية: 78
المتوسط: 84.33333333333333
التقدير: جيد جداً
```

**الشرح:**
- `دالة ... نهاية`: تعريف دالة مخصصة
- `ارجع`: إرجاع قيمة من الدالة
- `إذا ... وإلا_إذا ... وإلا ... نهاية`: جملة شرطية متعددة الحالات
- يمكن استخدام الدوال في دوال أخرى

## ملاحظات مهمة

### ١. التعليقات
```s
# هذا تعليق من سطر واحد

# يمكنك كتابة عدة تعليقات
# واحدة تلو الأخرى
```

### ٢. الحساسية للحالة
- لغة ص حساسة للحالة (Case-Sensitive)
- `متغير` مختلفة عن `متغيِر`
- الأسماء العربية يجب أن تكون دقيقة

### ٣. المسافات والمحاذاة
- المسافات مهمة داخل الكتل (Indentation)
- استخدم 4 مسافات أو Tab واحد
- كل كتلة داخل دالة أو شرط يجب أن تكون محاذية

```s
دالة مثال()
    # هذا صحيح - محاذاة صحيحة
    اطبع_سطر("مرحباً")
نهاية
```

### ٤. أسماء المتغيرات والدوال
**يُسمح:**
- الأحرف العربية: `اسم`، `العمر`
- الأحرف الإنجليزية: `name`، `age`
- الأرقام (ليس في البداية): `متغير1`
- الشرطة السفلية: `اسم_المستخدم`

**لا يُسمح:**
- البدء برقم: `1متغير` ❌
- الرموز الخاصة: `اسم@`، `قيمة$` ❌
- الكلمات المحجوزة: `متغير`، `دالة` ❌

## تثبيت وتشغيل لغة ص

### التثبيت على Windows
```bash
# تحميل المثبت من الموقع الرسمي
# sad-lang.org/download

# أو استخدام الأمر
winget install SadLang.Sad
```

### التثبيت على Linux/Mac
```bash
# استخدام مدير الحزم
curl -sSL https://sad-lang.org/install.sh | bash

# أو التحميل المباشر
git clone https://github.com/sad-lang/sad
cd sad
./install.sh
```

### تشغيل برنامج
```bash
# تشغيل ملف
sad برنامجي.s

# الوضع التفاعلي (REPL)
sad

# التحقق من الإصدار
sad --version
```
