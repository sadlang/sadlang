### 3. دوال معالجة القوالب

#### 3.1 تخزين دوال القوالب
```cpp
void buildTemplateFunction(const std::shared_ptr<AST::FunctionDecl>& funcDecl);
```
- تخزين AST الأصلي للدالة
- حفظ معاملات النوع (مثل `ت`, `U`, `T`)
- لا يتم توليد SIR فوراً

#### 3.2 إنشاء نسخة متخصصة (Instantiation)
```cpp
std::string instantiateTemplate(
    const std::string& templateName,
    const std::vector<SIRType>& typeArgs
);
```
- استبدال معاملات النوع بأنواع محددة
- توليد اسم فريد للنسخة (مثل `أكبر_رقم`)
- بناء SIR للنسخة المتخصصة
- إضافة الدالة المُنشأة إلى جدول الدوال

#### 3.3 استدعاء القوالب
تم تعديل `buildFunctionCall()` لاكتشاف استدعاء دوال القوالب:
```cpp
// (AR) إذا كانت دالة قالب، قم بإنشاء نسخة متخصصة
if (templateFunctions_.find(funcName) != templateFunctions_.end()) {
    // (AR) استنتاج الأنواع من المعاملات
    std::vector<SIRType> inferredTypes = inferTemplateTypes(
        templateFunctions_[funcName].typeParameters,
        argTypes
    );
    
    // (AR) إنشاء نسخة متخصصة
    std::string instantiatedName = instantiateTemplate(funcName, inferredTypes);
    funcName = instantiatedName;
}
```

### 4. استنتاج الأنواع (Type Inference)
```cpp
std::vector<SIRType> inferTemplateTypes(
    const std::vector<std::string>& typeParams,
    const std::vector<SIRType>& argTypes
);
```
- استنتاج تلقائي للأنواع من المعاملات
- دعم الأنواع البسيطة والمركبة
- معالجة الأخطاء عند عدم القدرة على الاستنتاج

