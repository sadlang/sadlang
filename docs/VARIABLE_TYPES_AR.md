# أنواع المتغيرات في لغة ص

## مقدمة
لغة ص توفر نظام أنواع غني ومرن يدعم أنواعاً بدائية ومركبة. هذا المقال يشرح جميع أنواع المتغيرات المتاحة وطرق تعريفها المختلفة مع أمثلة عملية.

---

## أنواع المتغيرات في لغة ص

أنواع المتغيرات الأساسية المدعومة في لغة ص هي:

- **رقم** : عدد صحيح (يُمثّل بـ ستة وستون بت)
- **عشري** : عدد عشري (يُمثّل بـ ستة وستون بت)
- **نص** : سلسلة نصية
- **منطقي** : قيمة صحيح أو خطأ
- **مصفوفة** : قائمة ديناميكية من القيم
- **قاموس** : جدول ارتباطي (مفتاح وقيمة)
- **عدم** : قيمة فارغة / لاشيء

---

## ملاحظة مهمة عن الفاصلة المنقوطة

لغة ص تدعم الفاصلة المنقوطة العربية والإنجليزية، ويمكن أن تكتب الأوامر بدون فاصلة منقوطة أيضاً. الأمثلة التالية صحيحة:

```
رقم العمر = 25؛
رقم العمر = 25;
رقم العمر = 25
```

كل الصيغ الثلاث صحيحة وتعطي نفس النتيجة.

---

## طرق تعريف المتغيرات

في لغة ص يمكنك تعريف المتغيرات بعدة طرق مختلفة:

### الطريقة الأولى: النوع ثم الاسم ثم القيمة (بدون فاصلة)

```
نوع_المتغير اسم_المتغير = القيمة
```

**أمثلة:**
```
رقم العمر = 30
عشري السعر = 99.99
نص الاسم = "محمد"
منطقي يفعل = صحيح
```

### الطريقة الثانية: النوع ثم الاسم ثم القيمة (بفاصلة منقوطة عربية)

```
نوع_المتغير اسم_المتغير = القيمة؛
```

**أمثلة:**
```
رقم الدرجة = 85؛
نص ترحيب = "السلام عليكم"؛
مصفوفة الأرقام = [1، 2، 3]؛
```

### الطريقة الثالثة: النوع ثم الاسم ثم القيمة (بفاصلة منقوطة إنجليزية)

```
نوع_المتغير اسم_المتغير = القيمة;
```

**أمثلة:**
```
رقم السنة = 2025;
عشري الوزن = 75.5;
نص الرسالة = "السلام عليكم";
```

### الطريقة الرابعة: تعريف المتغير مع تحديد النوع والاسم (بدون تهيئة فورية)

```
نوع_المتغير : اسم_المتغير
```

**أمثلة:**
```
رقم : العدد
نص : الاسم
مصفوفة : البيانات
```

## أمثلة تفصيلية لكل نوع متغير

### مثال ١: متغير نصي

```
نص رسالة_الترحيب = "السلام عليكم ورحمة الله وبركاته"
اطبع(رسالة_الترحيب)
```

**النتيجة:**
```
السلام عليكم ورحمة الله وبركاته
```

### مثال ٢: متغير رقمي

```
رقم العمر = 25
اطبع("العمر هو: " + العمر)
```

**النتيجة:**
```
العمر هو: 25
```

### مثال ٣: متغير عشري

```
عشري درجة_الحرارة = 36.5
اطبع("درجة الحرارة: " + درجة_الحرارة)
```

**النتيجة:**
```
درجة الحرارة: 36.5
```

### مثال ٤: متغير منطقي

```
منطقي هل_الطالب_ناجح = صحيح
اذا(هل_الطالب_ناجح) {
    اطبع("مبروك، أنت ناجح")
}
```

**النتيجة:**
```
مبروك، أنت ناجح
```

### مثال ٥: متغير مصفوفة

```
مصفوفة الأرقام = [1، 2، 3، 4، 5]
اطبع("الأرقام: " + الأرقام)
```

**النتيجة:**
```
الأرقام: [1, 2, 3, 4, 5]
```

### مثال ٦: متغير قاموس

```
قاموس المعلومات = {"الاسم": "أحمد"، "السن": 30، "المدينة": "الرياض"}
اطبع("الاسم: " + المعلومات["الاسم"])
```

**النتيجة:**
```
الاسم: أحمد
```

### مثال ٧: استخدام متغيرات متعددة معاً

```
نص الاسم = "فاطمة"
رقم العمر = 28
عشري الراتب = 5000.50
منطقي يعمل = صحيح

اطبع("الاسم: " + الاسم)
اطبع("العمر: " + العمر)
اطبع("الراتب: " + الراتب)
اطبع("يعمل: " + يعمل)
```

**النتيجة:**
```
الاسم: فاطمة
العمر: 28
الراتب: 5000.5
يعمل: صحيح
```

### مثال ٨: تعديل قيمة المتغير

```
رقم العداد = 0
اطبع("القيمة الأولية: " + العداد)

العداد = العداد + 1
اطبع("بعد الزيادة: " + العداد)

العداد = العداد * 2
اطبع("بعد المضاعفة: " + العداد)
```

**النتيجة:**
```
القيمة الأولية: 0
بعد الزيادة: 1
بعد المضاعفة: 2
```

### مثال ٩: متغير يحتوي على نتيجة عملية حسابية

```
رقم العدد_الأول = 10
رقم العدد_الثاني = 20
رقم المجموع = العدد_الأول + العدد_الثاني

اطبع("مجموع العددين هو: " + المجموع)
```

**النتيجة:**
```
مجموع العددين هو: 30
```

### مثال ١٠: استخدام الفاصلة المنقوطة

```
نص البلد = "السعودية"؛
رقم عدد_السكان = 35000000;
عشري مساحة = 2149690.0

اطبع("البلد: " + البلد)
اطبع("السكان: " + عدد_السكان)
اطبع("المساحة: " + مساحة)
```

**النتيجة:**
```
البلد: السعودية
السكان: 35000000
المساحة: 2149690
```

## نصائح مهمة

١. **اختيار اسم واضح للمتغير:** استخدم أسماء معبّرة تدل على محتوى المتغير

٢. **تتبع نوع المتغير:** تأكد من أن القيمة المُسندة تطابق نوع المتغير

٣. **استخدام الفاصلة المنقوطة بثبات:** قد تحتاج في بعض الحالات المتقدمة

٤. **استخدام أسماء عربية واضحة:** اللغة تدعم الأسماء العربية كاملة

٥. **الاختبار والتحقق:** دائماً اختبر البرنامج للتأكد من صحة المتغيرات
