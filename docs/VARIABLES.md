**تعريف المتغيرات في لغة ص — دليل للمبرمجين**

مقدمة
- هذا المستند يشرح قواعد تعريف المتغيرات في لغة ص: المفاهيم الأساسية، صيغ التصريح، سلوك المتغيرات (قابلية التغيير، النطاق)، وربطها بالأنواع. لكل نوع تصريح أقدم القاعدة، شرحًا موجزًا، ثم 15 مثالًا مع تعليقات سريعة حول النتيجة المتوقعة.

ملاحظة عامة عن النحو
- صيغ التصريح المدعومة (مبسط):
  1. `var|let|const name : Type = initializer;`  — تصريح مع وسم قابلية التغيير/ثبات.
  2. `Type name = initializer;` — صيغة النوع أولاً (type-first).
  3. `name = expr;` — تعيين/استنتاج نوع (عند سياق مناسب).
  4. `صدّر` أمام التصريح لجعله صادرًا (global/exported).

**1. `const` — القاعدة**
- القاعدة: `const` يُعرِّف متغيرًا ثابتًا لا يمكن إعادة تعيينه بعد التهيئة. يجب تهيئته عند التصريح.

الشرح:
- `const` مناسب للقيم التي لا تتغير (ثوابت أو مراجع لكائنات لا يُراد إعادة ربطها). لمّا كانت بعض القيم مرجعية (مصفوفة/كائن)، فـ`const` يمنع إعادة ربط المتغير لكنه لا يمنع تعديل المحتوى الداخلي للكائن المرجعي ما لم تُوفر لغة قيودًا إضافية.

أمثلة (15):
1) const عدد صحيح بسيط
```s
const PI: عشري = 3.14159;
```
2) const نص
```s
const GREETING: نص = "مرحبا";
```
3) const مصفوفة (لا تعيد ربط)
```s
const A: مصفوفة<رقم> = [1,2,3];
A[0] = 9; // مسموح بتغيير العنصر
// A = [4,5,6]; // خطأ: إعادة ربط const غير مسموح
```
4) const خريطة
```s
const M: قاموس<نص, رقم> = {"a":1};
M["b"] = 2; // تعديل محتوى الخريطة مسموح
```
5) const دالة (مرجع)
```s
const f: function = (x: رقم) => x*2;
// f = other; // خطأ: لا يمكن إعادة ربط
```
6) const دون نوع صريح (استنتاج)
```s
const x = 5; // x: رقم
```
7) const مع export
```s
صدّر const VERSION: نص = "1.0";
```
8) const مؤشر/مؤشر خام
```s
const p: مؤشر = null; // pointer type: ثبات الربط
```
9) const صفوف/كائنات متداخلة
```s
const config = { host: "localhost", ports: [80,443] };
config.ports[0] = 8080; // مسموح
```
10) const مع تحويل صريح
```s
const s: نص = toString(123);
```
11) const داخل دالة (local const)
```s
func f() {
  const threshold: رقم = 10;
  return threshold;
}
```
12) const حقول صنف (ثابت صفيفي)
```s
class C { const MAX: رقم = 100; }
```
13) تعليق وأفضل الممارسات
```s
// استخدام const للقيم التي لا تتغير لتسهيل القراءة والأمان
```
14) const مع إغلاق (closure)
```s
func make() {
  const n = 3;
  return () => n*2; // الإغلاق يلتقط n الثابت
}
```
15) const وقراءة من ملف/موارد
```s
const CONFIG_JSON: نص = readFile("config.json");
```

**2. `let` — القاعدة**
- القاعدة: `let` يعرّف متغيرًا قابل التغيير ضمن نطاقه (عادة محليّ داخل الكتلة أو الدالة). يمكن تهيئته فورًا أو لاحقًا حسب النحو.

الشرح:
- `let` مناسب للمتغيرات المؤقتة والحسابية. يتيح إعادة التعيين `=` دون تقييد. يتم تحديد نطاقه اعتمادًا على قواعد اللغة (عادة نطاق كتلة `{}` أو جسم الدالة).

أمثلة (15):
1) تعريف وإعادة تعيين
```s
let x: رقم = 1;
x = x + 1; // 2
```
2) استنتاج النوع
```s
let s = "abc"; // s: نص
s = "def";
```
3) استخدام في حلقة
```s
for (let i = 0; i < 5; i = i + 1) {
  // ...
}
```
4) مصفوفة قابلة للتعديل
```s
let arr = [1,2,3];
arr.push(4);
```
5) إعادة ربط مرجع
```s
let obj = {a:1};
obj = {a:2};
```
6) let داخل شرط
```s
if (cond) { let v = 1; } // v غير مرئي خارج الكتلة
```
7) let مع تعبير معقّد
```s
let sum = numbers.reduce((a,b) => a + b, 0);
```
8) let و closure
```s
let n = 0;
func inc() { n = n + 1; }
```
9) let كمتغير وسيط
```s
let temp = computeExpensive();
use(temp);
```
10) let متزامن/متعدد الأسطر
```s
let x = 1,
    y = 2;
```
11) let مع النوع الصريح
```s
let name: نص = "S";
```
12) let مع استدعاء دالة
```s
let res = parse(someStr);
```
13) let حقل صنف (غير ثابت)
```s
class Point { let x: رقم = 0; }
```
14) let ضمن نطاق اللامدا
```s
let f = () => { let a = 1; return a; };
```
15) let و destructuring (إن دعمت اللغة)
```s
let [a,b] = [1,2];
```

**3. `var` — القاعدة**
- القاعدة: `var` يعرّف متغيرًا قابل التغيير؛ قد يختلف نطاقه عن `let` (مثلاً نطاق دالة بدلاً من نطاق كتلة) اعتمادًا على تفاصيل اللغة.

الشرح:
- بعض اللغات تميّز `var` عن `let` في نطاقه وسلوكه (مثل hoisting). في وثيقة الشيفرة الحالية تُذْكَر `var/let/const` كصيغ ممكنة؛ اعتبر `var` مخصصًا للسلوك التقليدي القابل للتغيير مع نطاق أوسع (تحقّق من المواصفات عند الحاجة).

أمثلة (15):
1) var أساسي
```s
var i: رقم = 0;
i = 5;
```
2) var مع استنتاج
```s
var msg = "hello";
```
3) var عبر الكتلة (إذا كانت اللغة تدعم hoisting)
```s
if (cond) { var v = 1; }
// v قد يكون مرئيًا هنا تبعاً للقواعد
```
4) var للـ globals (داخل ملف)
```s
var counter = 0;
```
5) var مع تهيئة لاحقة
```s
var x; x = compute();
```
6) var و loop
```s
for (var k = 0; k < 3; k = k + 1) { }
```
7) var و الإغلاق
```s
var n = 1;
func g() { n = n + 1; }
```
8) var و إعادة ربط مرجع
```s
var a = [1]; a = [2];
```
9) var مع export
```s
صدّر var MODE = "dev";
```
10) var بدون نوع صريح
```s
var flag = true;
```
11) var و التهيئة المركبة
```s
var config = loadConfig();
```
12) var وحساب العدادات
```s
var sum = 0;
for (var i = 0; i < n; i = i + 1) sum = sum + arr[i];
```
13) var داخل دالة
```s
func f() { var tmp = 5; return tmp; }
```
14) var مع دوال مرتجعة
```s
var make = () => { var x = 0; return () => x++; };
```
15) var ومشاركة الحالة
```s
var state = { open: true };
```

**4. Type-first (قواعد `Type name = value;`) — القاعدة**
- القاعدة: يمكنك الإعلان عن متغير بصيغة النوع أولاً مثل `رقم x = 5;` أو `نص s = "a";`. هذه الصيغة تُستخدم أيضاً عند تعريف متغيرات مصنّفة (class-typed) بدون كلمة محجوزة `let/var/const`.

الشرح:
- هذه الصيغة مفيدة لكتابة سريعة متوافقة مع نمط لغات إعلانية حيث يبدأ التصريح بنوع المتغير. في المحلل تُقرَأ كنوع ثم اسم ثم مُهيِّئ اختياري. تعتمد قابلية التغيير على السياق (قد تكون افتراضات الـ default متغيرة ما لم تستخدم `const`).

أمثلة (15):
1) رقم أولي
```s
رقم a = 10;
```
2) نص أولي
```s
نص name = "Ali";
```
3) مصفوفة مع نوع
```s
مصفوفة<رقم> nums = [1,2,3];
```
4) قاموس مع نوعين
```s
قاموس<نص, رقم> m = {"x":1};
```
5) class-typed (انظر القسم التالي)
```s
Point p = new Point();
```
6) عدم/void
```s
فراغ nothing = عدم;
```
7) نوع دالة
```s
function f = (x: رقم) => x*2;
```
8) استنتاج مقابل تصريح صريح
```s
رقم x = 5; // صريح
var y = 6; // استنتاج
```
9) نوع خام/مؤشر
```s
مؤشر p = null;
```
10) بايت/نوع منخفض المستوى (إن وُجد)
```s
int8 b = 127;
```
11) نوع مع مديونية (nullable)
```s
نص? maybe = null;
```
12) return variable style
```s
رقم z = compute();
```
13) استخدام في API/Exports
```s
صدّر نص NAME = "S";
```
14) نوع مع conversion صريح
```s
نص s = toString(10);
```
15) نوع ضمن ملف مصدر
```s
مصفوفة<نص> lines = readLines("file.txt");
```

**5. Class-typed variables (متغيرات من نوع صنف) — القاعدة**
- القاعدة: عند وجود اسم صنف معرف، يمكن استخدامه كسطر بداية للتصريح: `ClassName varName = new ClassName();` أو ضمن صيغة `let varName: ClassName = new ClassName();`.

الشرح:
- المحلل يقوم بتسجيل الأصناف مؤقتًا أثناء التحليل ويسمح بتصريح متغيرات من هذا النوع. المتغير يكون مرجعًا إلى كائن (object instance) وتخضع lifetime و semantics إلى ObjectManager/GC.

أمثلة (15):
1) إنشاء كائن بسيط
```s
Point p = new Point();
```
2) مع let
```s
let q: Point = new Point();
```
3) تعيين خصائص
```s
p.x = 1; p.y = 2;
```
4) تمرير كمرجع
```s
let r = p; r.x = 5; // يؤثر على p
```
5) nullable reference
```s
Point? maybe = null;
```
6) استدعاء باني مع معطيات
```s
Point p2 = new Point(1,2);
```
7) مصفوفة من كائنات
```s
مصفوفة<Point> arr = [new Point(), new Point()];
```
8) حقل صنف داخل صنف
```s
class Node { let next: Node? = null; }
```
9) مقارنة مرجع
```s
let same = (p == q);
```
10) استخدام في دوال
```s
func translate(pt: Point) { pt.x += 1; }
```
11) export صنفي
```s
صدّر Point origin = new Point();
```
12) التحقق من النوع قبل الوصول
```s
if (v.isObject()) { let o = v.asObject(); }
```
13) استخدام IDisposable-like (موارد)
```s
let f: File = open("a.txt");
f.close();
```
14) إغلاق يلتقط مرجع صنف
```s
let maker = () => { let p = new Point(); return () => p; };
```
15) وراثة: إعلان لمتحول من فئة مشتقة
```s
Base b = new Derived();
```

**6. Exported / Global variables (`صدّر`) — القاعدة**
- القاعدة: وضع الكلمة المفتاحية `صدّر` قبل التصريح يجعل المتغير مرئيًا كوحدة تصدير (module export) أو global حسب سياق التحزيم.

الشرح:
- يتم استخدام `صدّر` لتصدير قيم/ثوابت ودوال من ملف كوحدة. على مستوى التنفيذ يُخزن المتغير ضمن جدول الـ globals في الـ VM ويمكن الوصول إليه عبر import في ملفات أخرى.

أمثلة (15):
1) تصدير ثابت
```s
صدّر const NAME: نص = "MyLib";
```
2) تصدير متغير قابل للتغيير
```s
صدّر var mode = "dev";
```
3) تصدير دالة
```s
صدّر func greet() { print("hi"); }
```
4) تصدير صنف
```s
صدّر class Point { x: رقم; y: رقم; }
```
5) تصدير مصفوفة
```s
صدّر مصفوفة<نص> defaults = ["a","b"];
```
6) تصدير خريطة
```s
صدّر قاموس<نص, رقم> versionInfo = {"major":1};
```
7) تصدير مرجع مورد
```s
صدّر let db = connectDB();
```
8) استيراد/استهلاك من ملف آخر (مثال استخدام)
```s
استورد mylib
print(mylib.NAME);
```
9) تصدير مع نوع صريح
```s
صدّر رقم MAX_CONN = 10;
```
10) تصدير Closure
```s
صدّر const make = () => () => 1;
```
11) تصدير مؤشر/مؤشر خام
```s
صدّر مؤشر nativePtr = getNativePtr();
```
12) تصدير كائن مُهيأ
```s
صدّر let config = { debug: true };
```
13) تصدير متعدد
```s
صدّر const A = 1; صدّر const B = 2;
```
14) best-practice: استخدم أسماء واضحة عند التصدير
```s
صدّر const DEFAULT_TIMEOUT = 30;
```
15) تصدير وتهيئة عبر قراءة ملف
```s
صدّر const SETTINGS = readJSON("settings.json");
```
