# 1. مقدمة وبداية سريعة

## ما هي لغة ص؟

**لغة ص** (Sad) هي لغة برمجة عربية حديثة مبنية على C++17، مصممة لتكون:
- **عربية بالكامل**: كلمات مفتاحية ومُعرّفات عربية مع دعم UTF-8
- **سهلة التعلم**: بنية واضحة وبسيطة
- **قوية**: تدعم البرمجة الكائنية والدوال العليا والوراثة
- **مزدوجة التشغيل**: مفسر مباشر (`sad`) ومترجم إلى ملفات تنفيذية (`sadc`)

## تشغيل البرامج

### المفسر (sad)
```powershell
# تشغيل ملف .ص مباشرة
sad.exe ملفي.ص
```

### المترجم (sadc)
```powershell
# ترجمة إلى ملف تنفيذي
sadc.exe ملفي.ص -o ملفي.exe
.\ملفي.exe
```

## البنية العامة للبرنامج

### أبسط برنامج
```sad
اطبع_سطر("مرحباً بالعالم!")
```

### برنامج مع دالة رئيسية
```sad
دالة رئيسية()
    اطبع_سطر("مرحباً بالعالم!")
نهاية
```

> **ملاحظة**: الدالة الرئيسية `دالة رئيسية()` اختيارية. يمكنك كتابة التعليمات مباشرة في المستوى الأعلى.

## التعليقات

```sad
# هذا تعليق سطري

#* هذا تعليق
   متعدد الأسطر *#

## هذا تعليق توثيقي
```

## قواعد أساسية

- جميع الكتل تنتهي بكلمة `نهاية`
- الفاصلة العربية `،` والإنجليزية `,` كلاهما مدعوم
- المنقوطة `؛` أو `;` اختيارية في نهاية السطر
- سطر جديد = نهاية الجملة
- المسافات البادئة (Indentation) اختيارية لكن مُستحسنة للوضوح

## 🔸 الأمثلة (8 أمثلة متدرجة)

### مثال 1 — مبتدئ: أول برنامج
```sad
# أول برنامج بلغة ص
اطبع_سطر("مرحباً بالعالم!")
```
**المخرجات:**
```
مرحباً بالعالم!
```

### مثال 2 — مبتدئ: طباعة عدة أسطر
```sad
اطبع_سطر("=============================")
اطبع_سطر("  مرحباً بلغة ص البرمجية")
اطبع_سطر("=============================")
اطبع_سطر("لغة برمجة عربية حديثة")
اطبع_سطر("تدعم المفسر والمترجم معاً")
```
**المخرجات:**
```
=============================
  مرحباً بلغة ص البرمجية
=============================
لغة برمجة عربية حديثة
تدعم المفسر والمترجم معاً
```

### مثال 3 — مبتدئ: الفرق بين اطبع واطبع_سطر
```sad
اطبع("أهلاً ")
اطبع("يا ")
اطبع_سطر("عالم!")
اطبع_سطر("سطر جديد هنا")
```
**المخرجات:**
```
أهلاً يا عالم!
سطر جديد هنا
```

### مثال 4 — مبتدئ: استخدام التعليقات
```sad
# هذا البرنامج يوضح التعليقات
اطبع_سطر("قبل التعليق")

#* هذا الجزء
   لن يُنفَّذ
   لأنه تعليق كتلة *#

اطبع_سطر("بعد التعليق")
```
**المخرجات:**
```
قبل التعليق
بعد التعليق
```

### مثال 5 — متوسط: الدالة الرئيسية مع متغيرات
```sad
دالة رئيسية()
    متغير الاسم = "لغة ص"
    متغير الإصدار = 1
    اطبع("مرحباً من ")
    اطبع(الاسم)
    اطبع(" الإصدار ")
    اطبع_سطر(الإصدار)
نهاية
```
**المخرجات:**
```
مرحباً من لغة ص الإصدار 1
```

### مثال 6 — متوسط: برنامج متعدد الدوال
```sad
دالة تحية(اسم)
    اطبع_سطر("مرحباً يا " + اسم + "!")
نهاية

دالة وداع(اسم)
    اطبع_سطر("مع السلامة يا " + اسم + "!")
نهاية

تحية("أحمد")
تحية("فاطمة")
وداع("أحمد")
```
**المخرجات:**
```
مرحباً يا أحمد!
مرحباً يا فاطمة!
مع السلامة يا أحمد!
```

### مثال 7 — متقدم: برنامج مع أصناف
```sad
صنف تطبيق
    نص الاسم
    رقم الإصدار
    
    باني(نص اسم، رقم إصدار)
        الاسم = اسم
        الإصدار = إصدار
    نهاية
    
    دالة شغّل()
        اطبع_سطر("تشغيل " + الاسم + " v" + الإصدار)
    نهاية
نهاية

متغير برنامجي = جديد تطبيق("تطبيقي"، 1)
برنامجي.شغّل()
```
**المخرجات:**
```
تشغيل تطبيقي v1
```

### مثال 8 — متقدم جداً: برنامج متكامل
```sad
# برنامج متكامل يجمع عدة ميزات

دالة خط()
    اطبع_سطر("══════════════════════════════")
نهاية

صنف مشروع
    نص الاسم
    رقم عدد_الملفات
    ساكن رقم عدد_المشاريع
    
    باني(نص اسم، رقم ملفات)
        الاسم = اسم
        عدد_الملفات = ملفات
        عدد_المشاريع = عدد_المشاريع + 1
    نهاية
    
    دالة اعرض()
        اطبع("  📁 ")
        اطبع(الاسم)
        اطبع(" (")
        اطبع(عدد_الملفات)
        اطبع_سطر(" ملف)")
    نهاية
    
    ساكن دالة رقم الإجمالي()
        ارجع عدد_المشاريع
    نهاية
نهاية

دالة رئيسية()
    خط()
    اطبع_سطر("  لوحة تحكم المطور")
    خط()
    
    متغير م1 = جديد مشروع("موقعي"، 15)
    متغير م2 = جديد مشروع("تطبيق_الجوال"، 42)
    متغير م3 = جديد مشروع("خدمة_API"، 8)
    
    م1.اعرض()
    م2.اعرض()
    م3.اعرض()
    
    خط()
    اطبع_سطر("  إجمالي المشاريع: " + مشروع.الإجمالي())
    خط()
نهاية
```
**المخرجات:**
```
══════════════════════════════
  لوحة تحكم المطور
══════════════════════════════
  📁 موقعي (15 ملف)
  📁 تطبيق_الجوال (42 ملف)
  📁 خدمة_API (8 ملف)
══════════════════════════════
  إجمالي المشاريع: 3
══════════════════════════════
```
