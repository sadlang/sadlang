# نظام البناء — `cmake/` + `CMakeLists.txt`

> **الأداة:** CMake 3.16+  
> **المولد:** MSBuild (Windows), Make/Ninja (Linux/macOS)  
> **الخيارات الرئيسية:** `ENABLE_LLVM_BACKEND`, `BUILD_TESTS`, `HAS_RUNTIME_NEW`

---

```
CMakeLists.txt (الجذر)

cmake/*.cmake (وحدات)
    ↓
كل مجلد فرعي CMakeLists.txt
```

## أوامر البناء

```powershell
# تهيئة
cmake -S . -B build

# بناء المفسر فقط (أسرع)
cmake --build build --config Debug --target sad-run

# بناء المترجم (Release ضروري!)
cmake --build build --config Release --target sad-build

# بناء كل شيء
cmake --build build --config Debug

# مع تفعيل الاختبارات
cmake -S . -B build -DBUILD_TESTS=ON
cmake --build build --config Debug
ctest --test-dir build -R Comprehensive

# مع تفعيل LLVM
cmake -S . -B build -DENABLE_LLVM_BACKEND=ON
```

## ⚠️ ملاحظات

1. **`sadc` يجب بناؤه بـ `--config Release`** — مكتبات LLVM 18 مبنية Release فقط
2. **الاختبارات معطّلة افتراضياً** — فعّلها بـ `-DBUILD_TESTS=ON`
3. **LLVM اختياري** — `ENABLE_LLVM_BACKEND=ON` لبناء المترجم
4. **`executables.cmake`** هو الملف الأهم — يحدد ما يدخل في كل ملف تنفيذي
