### `VariableManager` — إدارة المتغيرات
```cpp
class VariableManager {
    // تخزين مُتداخل (stack of scopes)
    std::vector<std::unordered_map<std::string, Value>> scopes_;
    
public:
    void declareVariable(const std::string& name, const Value& value);
    void setVariable(const std::string& name, const Value& value);
    Value getVariable(const std::string& name) const;
    bool hasVariable(const std::string& name) const;
    
    // نطاقات
    void pushScope();            // فتح نطاق جديد
    void popScope();             // إغلاق النطاق الحالي
    
    // التقاط (للـ goroutines)
    std::unordered_map<std::string, Value> captureVisibleVariables() const;
};
```

class ScopeManager {

## ⚠️ ملاحظات مهمة

1. **`FunctionManager` يُشارَك بين الـ goroutines** (read-only) — الباقي كل goroutine له نسخة خاصة
2. **النطاقات مُتداخلة** — `VariableManager` يبحث من الداخل للخارج
3. **`OwnershipManager` اختياري** — غير مُفعَّل افتراضياً
