# مسار الكود — من المصدر إلى البرنامج النهائي على كل المنصات

> **الغرض:** فهم كيف يتحول كود ص (.ص) إلى برنامج قابل للتشغيل عبر كل المسارات والمنصات  
> **التاريخ:** يوليو 2025

---

## المسارات الثلاثة

لغة ص تدعم **ثلاث طرق** لتنفيذ الكود:

| # | المسار | الأداة | المخرج | السرعة |
|---|--------|--------|--------|--------|
| 1 | **المفسر** | `sad.exe` | تنفيذ فوري | عادية |
| 2 | **الآلة الافتراضية** | `sad.exe` (VM mode) | بايت كود ثم تنفيذ | متوسطة |
| 3 | **المترجم** | `sadc.exe` | ملف تنفيذي أصلي | أعلى |

## المسار 1: المفسر (التشغيل الفوري)

```
مبرمج يكتب:  مرحبا.ص
     │
     ▼
sad.exe مرحبا.ص
     │
     ▼  ┌──────────────────────────────────────────────────────┐
     ├──┤ 1. LexerCore::tokenize()                            │
     │  │    ← يقرأ الملف UTF-8                                │
     │  │    → ينتج vector<Token>                              │
     │  │    الملف: shared/lexer/src/lexer_core.cpp            │
     │  └──────────────────────────────────────────────────────┘
     │
     ▼  ┌──────────────────────────────────────────────────────┐
     ├──┤ 2. ParserCore::parseProgram()                        │
     │  │    ← يأخذ vector<Token>                              │
     │  │    → ينتج StmtList (شجرة AST)                        │
     │  │    الملف: shared/parser/src/core/parser_core.cpp     │
     │  └──────────────────────────────────────────────────────┘
     │
     ▼  ┌──────────────────────────────────────────────────────┐
     ├──┤ 3. InterpreterCore::execute(ast)                     │
     │  │    ← يأخذ AST                                        │
     │  │    → يمشي على الشجرة عقدة بعقدة                       │
     │  │    الملف: interpreter_new/src/core/interpreter_core.cpp │
     │  │                                                      │
     │  │    لكل عقدة:                                          │
     │  │    ├── تعبير → ExpressionEvaluator::evaluate()        │
     │  │    │   يحسب القيمة (رقم, نص, كائن)                    │
     │  │    │                                                  │
     │  │    └── جملة → StatementExecutor::execute()            │
     │  │        ينفذ (متغير, شرط, حلقة, استدعاء)               │
     │  │                                                      │
     │  │    الموارد المساعدة:                                   │
     │  │    ├── VariableManager  ← تخزين المتغيرات             │
     │  │    ├── FunctionManager  ← تسجيل الدوال                │
     │  │    ├── ScopeManager     ← إدارة النطاقات              │
     │  │    ├── BuiltinRegistry  ← 21 دالة مدمجة              │
     │  │    └── ModuleLoader     ← استورد (تحميل كسول)         │
     │  └──────────────────────────────────────────────────────┘
     │
     ▼
  نتيجة فورية (stdout)
```

**أمر التشغيل:**
```powershell
# Windows
.\build\bin\Debug\sad.exe examples\مرحبا.ص

# Linux/macOS
./build/bin/sad examples/مرحبا.ص
```

## المسار 2: الآلة الافتراضية (بايت كود)

```
مبرمج يكتب:  مرحبا.ص
     │
     ▼
sad.exe --vm مرحبا.ص
     │
     ├── 1. LexerCore::tokenize()     → vector<Token>
     ├── 2. ParserCore::parseProgram() → AST
     │
     ▼  ┌──────────────────────────────────────────────────────┐
     ├──┤ 3. VmCompiler::compile(ast)                          │
     │  │    ← يأخذ AST                                        │
     │  │    → ينتج Chunk (بايت كود)                            │
     │  │    الملف: vm/src/sad_vm_compiler.cpp                 │
     │  │                                                      │
     │  │    لكل عقدة AST:                                      │
     │  │    ├── رقم حرفي → OP_PUSH_CONST(index)               │
     │  │    ├── جمع → OP_ADD                                   │
     │  │    ├── إذا → OP_JUMP_IF_FALSE + OP_JUMP              │
     │  │    ├── دالة → OP_CALL                                 │
     │  │    └── اطبع → OP_BUILTIN_PRINT                       │
     │  └──────────────────────────────────────────────────────┘
     │
     ▼  ┌──────────────────────────────────────────────────────┐
     ├──┤ 4. VmExecutor::execute(chunk)                        │
     │  │    ← يأخذ Chunk                                      │
     │  │    → ينفذ على مكدس                                    │
     │  │    الملف: vm/src/sad_vm_executor.cpp                 │
     │  │                                                      │
     │  │    الحلقة الرئيسية:                                    │
     │  │    بينما (IP < نهاية_البايتكود):                       │
     │  │        opcode = chunk[IP++]                           │
     │  │        switch(opcode):                                │
     │  │            OP_PUSH    → push(constants[arg])          │
     │  │            OP_ADD     → push(pop() + pop())           │
     │  │            OP_CALL    → إطار جديد + قفز               │
     │  │            OP_RETURN  → حذف إطار + إرجاع              │
     │  │            OP_HALT    → توقف                          │
     │  └──────────────────────────────────────────────────────┘
     │
     ▼
  نتيجة (stdout)
```

## المسار 3: المترجم (ملف تنفيذي أصلي)

```
مبرمج يكتب:  مرحبا.ص
     │
     ▼
sadc.exe مرحبا.ص -o مرحبا.exe
     │
     ├── 1. LexerCore::tokenize()     → vector<Token>
     ├── 2. ParserCore::parseProgram() → AST
     │
     ▼  ┌──────────────────────────────────────────────────────┐
     ├──┤ 3. التحليل الدلالي (اختياري)                          │
     │  │    compiler_new/src/semantic/                        │
     │  │    ├── TypeChecker      ← فحص الأنواع                │
     │  │    ├── BorrowChecker    ← فحص الاستعارة               │
     │  │    ├── OwnershipTracker ← تتبع الملكية                │
     │  │    └── Exhaustiveness   ← شمولية المطابقة             │
     │  └──────────────────────────────────────────────────────┘
     │
     ▼  ┌──────────────────────────────────────────────────────┐
     ├──┤ 4. SIRBuilder::build(ast)                            │
     │  │    ← يأخذ AST                                        │
     │  │    → ينتج SIRModule                                   │
     │  │    الملف: compiler_new/src/frontend/sir_builder_module.cpp │
     │  │                                                      │
     │  │    لكل عقدة AST:                                      │
     │  │    ├── متغير → SIR::ALLOC + SIR::STORE               │
     │  │    ├── قراءة → SIR::LOAD                              │
     │  │    ├── عملية → SIR::BINOP                             │
     │  │    ├── إذا → SIR::BRANCH + SIR::JUMP                 │
     │  │    ├── دالة → SIR::CALL + SIR::RETURN                │
     │  │    └── اطبع → SIR::BUILTIN_PRINT                     │
     │  │                                                      │
     │  │    12 تعليمة SIR: ALLOC, STORE, LOAD, CALL,          │
     │  │    RETURN, BRANCH, JUMP, BINOP, UNOP, PHI, CAST,     │
     │  │    BUILTIN_PRINT                                     │
     │  └──────────────────────────────────────────────────────┘
     │
     ▼  ┌──────────────────────────────────────────────────────┐
     ├──┤ 5. تحسين SIR (اختياري: -O1, -O2, -O3)               │
     │  │    compiler_new/src/optimizer/ + middle/             │
     │  │    ├── O1: ConstantFolding, DCE, CopyPropagation     │
     │  │    ├── O2: + CSE, Inlining, LICM, StrengthReduction │
     │  │    └── O3: + TailCall, Peephole, SROA                │
     │  └──────────────────────────────────────────────────────┘
     │
     ▼  ┌──────────────────────────────────────────────────────┐
     ├──┤ 6. LLVMCodeGen::generate(sirModule)                  │
     │  │    ← يأخذ SIRModule                                   │
     │  │    → ينتج llvm::Module                                │
     │  │    الملف: compiler_new/src/backend/llvm/             │
     │  │                                                      │
     │  │    لكل تعليمة SIR:                                    │
     │  │    ├── ALLOC → CreateAlloca()                         │
     │  │    ├── STORE → CreateStore()                          │
     │  │    ├── LOAD → CreateLoad()                            │
     │  │    ├── CALL → CreateCall()                            │
     │  │    ├── BINOP → CreateAdd/Sub/Mul/...                  │
     │  │    ├── BRANCH → CreateCondBr()                        │
     │  │    ├── JUMP → CreateBr()                              │
     │  │    ├── PHI → CreatePHI()                              │
     │  │    └── RETURN → CreateRet()                           │
     │  └──────────────────────────────────────────────────────┘
     │
     ▼  ┌──────────────────────────────────────────────────────┐
     ├──┤ 7. تحسين LLVM IR                                     │
     │  │    llvm_optimizer.cpp                                │
     │  │    LLVM Pass Pipeline (O0-O3)                        │
     │  └──────────────────────────────────────────────────────┘
     │
     ▼  ┌──────────────────────────────────────────────────────┐
     ├──┤ 8. إنتاج ملف كائن (.o)                               │
     │  │    llvm_codegen_output.cpp → emitObjectFile()        │
     │  │    LLVM TargetMachine → .o                           │
     │  └──────────────────────────────────────────────────────┘
     │
     ▼  ┌──────────────────────────────────────────────────────┐
     ├──┤ 9. الربط (Linking)                                    │
     │  │    llvm_linker.cpp                                   │
     │  │    toolchain_detection.cpp → كشف GCC/Clang/MSVC     │
     │  │    .o + runtime_new + libc → ملف تنفيذي              │
     │  └──────────────────────────────────────────────────────┘
     │
     ▼
  مرحبا.exe (ملف تنفيذي أصلي)
```

**أوامر التشغيل:**
```powershell
# ترجمة عادية
sadc.exe مرحبا.ص -o مرحبا.exe

# مع تحسينات
sadc.exe مرحبا.ص -o مرحبا.exe -O2

# إنتاج LLVM IR فقط
sadc.exe مرحبا.ص --emit-llvm -o مرحبا.ll

# ترجمة لمنصة محددة
sadc.exe مرحبا.ص --target=x86_64-linux-gnu -o مرحبا
```

## المنصات المدعومة

### Windows (المنصة الرئيسية)

| المكون | التفاصيل |
|--------|---------|
| **المترجم C++** | MSVC (Visual Studio 2019+) |
| **LLVM** | 18.x (Release فقط!) |
| **البناء** | CMake + MSBuild |
| **الناتج** | `.exe` (PE format) |
| **الربط** | link.exe (MSVC linker) |
| **وقت التشغيل** | MSVCRT + runtime_new |

```powershell
# بناء المفسر
cmake -S . -B build -G "Visual Studio 17 2022"
cmake --build build --config Debug --target sad

# بناء المترجم (Release ضروري!)
cmake --build build --config Release --target sadc

# تشغيل
.\build\bin\Debug\sad.exe ملف.ص          # مفسر
.\build\bin\Release\sadc.exe ملف.ص -o ملف.exe  # مترجم
```

### Linux

| المكون | التفاصيل |
|--------|---------|
| **المترجم C++** | GCC 9+ أو Clang 10+ |
| **LLVM** | 18.x |
| **البناء** | CMake + Make/Ninja |
| **الناتج** | ELF executable |
| **الربط** | ld أو lld |
| **وقت التشغيل** | glibc + runtime_new |

```bash
# بناء
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)

# تشغيل
./build/bin/sad ملف.ص                    # مفسر
./build/bin/sadc ملف.ص -o ملف             # مترجم
./ملف                                    # تشغيل الناتج
```

### macOS

| المكون | التفاصيل |
|--------|---------|
| **المترجم C++** | Apple Clang (Xcode) |
| **LLVM** | 18.x (عبر Homebrew) |
| **البناء** | CMake + Ninja/Make |
| **الناتج** | Mach-O executable |
| **الربط** | ld64 |

```bash
brew install llvm@18
cmake -S . -B build -DLLVM_DIR=$(brew --prefix llvm@18)/lib/cmake/llvm
cmake --build build
```

### Android (تجريبي)

| المكون | التفاصيل |
|--------|---------|
| **Toolchain** | NDK + Clang |
| **الناتج** | `.so` (shared library) أو APK |
| **الملفات** | `tools/compiler/compiler_driver_android.cpp` |

```powershell
sadc.exe ملف.ص --target=aarch64-linux-android -o ملف.so
```

### WebAssembly (تجريبي)

| المكون | التفاصيل |
|--------|---------|
| **Toolchain** | Emscripten أو LLVM WASM backend |
| **الناتج** | `.wasm` |
| **الملفات** | `tools/wasm/` |

### Bare Metal / نظام تشغيل أفق

| المكون | التفاصيل |
|--------|---------|
| **وضع** | Freestanding (بلا libc) |
| **الناتج** | `.elf` (Multiboot) |
| **وقت التشغيل** | `runtime_new/freestanding/` |
| **الملفات** | `llvm_codegen_freestanding.cpp`, `llvm_bare_metal_linker.cpp`, `llvm_multiboot.cpp` |

```powershell
sadc.exe kernel.ص --freestanding --target=x86_64-none-elf -o kernel.elf
```

## ملخص المسار الكامل (من حرف واحد إلى تنفيذ)

```
المبرمج يكتب: اطبع("مرحبا")
        │
        ▼ (UTF-8 bytes)
    ┌─ Lexer ─────────────────────────────────────────┐
    │ "اطبع" → IDENTIFIER("اطبع")                     │
    │ "("     → LEFT_PAREN                             │
    │ "مرحبا"  → STRING_LITERAL("مرحبا")               │
    │ ")"     → RIGHT_PAREN                            │
    └─────────────────────────────────────────────────┘
        │ 4 tokens
        ▼
    ┌─ Parser ────────────────────────────────────────┐
    │ FunctionCallExpr                                 │
    │ ├── callee: IdentifierExpr("اطبع")              │
    │ └── args: [StringLiteralExpr("مرحبا")]          │
    └─────────────────────────────────────────────────┘
        │ 1 AST node
        ▼
    ┌─ مسار المفسر ───────────────────────────────────┐
    │ ExpressionEvaluator::visitFunctionCall()         │
    │ → BuiltinRegistry::call("اطبع", ["مرحبا"])     │
    │ → stdout: مرحبا                                  │
    └─────────────────────────────────────────────────┘
        أو
    ┌─ مسار المترجم ──────────────────────────────────┐
    │ SIR: BUILTIN_PRINT("مرحبا")                     │
    │             ▼                                    │
    │ LLVM IR: call @sad_print(i8* "مرحبا")           │
    │             ▼                                    │
    │ x86_64:  mov rdi, .str_مرحبا                     │
    │          call printf                             │
    └─────────────────────────────────────────────────┘
```
