# التحليل الدلالي — `compiler_new/src/semantic/`

> **الدور:** فحص صحة البرنامج دلالياً **قبل** توليد SIR  
> **الفضاء:** `Sad::Compiler::Semantic`  
> **المدخل:** AST (شجرة البنية المجردة)  
> **المخرج:** AST مُعلَّمة (annotated) + تقارير أخطاء  
> **عدد الملفات:** 10

---

## نظرة عامة

التحليل الدلالي هو مرحلة **بين** المحلل النحوي والمترجم. يتحقق من أن البرنامج صحيح
**معنوياً** وليس فقط نحوياً. يشمل: فحص الأنواع, فحص الملكية, تحليل الأعمار, فحص الشمولية.

```
AST → [Semantic Analysis] → AST مُعلَّمة + أخطاء → [SIR Builder]
```

---

## جدول الملفات (10 ملفات)

| الملف | الدور | الدوال الرئيسية |
|-------|------|-----------------|
| `type_checker.cpp` | ⚡ **فحص الأنواع** — تطابق المعاملات والقيم المُرجعة | `checkTypes()`, `checkAssignment()`, `checkFunctionCall()` |
| `borrow_checker.cpp` | فحص الاستعارة (Borrow Checking) — نموذج ملكية مشابه لـ Rust | `checkBorrows()`, `checkMutableBorrow()` |
| `ownership_tracker.cpp` | تتبع الملكية — من يملك كل قيمة ومتى تُحرَّر | `trackOwnership()`, `transferOwnership()` |
| `move_analyzer.cpp` | تحليل النقل (Move) — اكتشاف use-after-move | `analyzeMove()`, `checkUseAfterMove()` |
| `lifetime_analyzer.cpp` | تحليل الأعمار (Lifetimes) — تعليقات `<'أ>` | `analyzeLifetimes()`, `checkLifetimeConstraints()` |
| `exhaustiveness.cpp` | فحص شمولية المطابقة (Pattern Exhaustiveness) | `checkExhaustiveness()`, `checkMatchCoverage()` |
| `unsafe_checker.cpp` | فحص كتل `@غير_آمن` — تأكد من وجود العلامة | `checkUnsafeBlocks()`, `reportUnsafeOperation()` |
| `cascade_prevention.cpp` | منع أخطاء متسلسلة (Cascade Prevention) | `shouldSuppress()`, `trackRecoveryPoint()` |
| `pattern_ownership.cpp` | ملكية الأنماط في `طابق` | `checkPatternOwnership()` |
| `this_binding.cpp` | ربط `هذا` (this) — تأكد من صحة الوصول | `resolveThisBinding()`, `checkThisContext()` |

## مسار التنفيذ

```
SemanticPass::analyze(ast)
    │
    ├── TypeChecker::check(ast)           ← فحص الأنواع
    │   ├── checkFunctionSignatures()
    │   ├── checkExpressionTypes()
    │   └── checkReturnTypes()
    │
    ├── OwnershipTracker::track(ast)      ← تتبع الملكية
    │   ├── BorrowChecker::check()        ← فحص الاستعارة
    │   ├── MoveAnalyzer::analyze()       ← تحليل النقل
    │   └── LifetimeAnalyzer::analyze()   ← تحليل الأعمار
    │
    ├── ExhaustivenessChecker::check()    ← شمولية المطابقة
    ├── UnsafeChecker::check()            ← كتل غير آمنة
    └── ThisBinding::resolve()            ← ربط هذا
```
