# شجرة البنية المجردة — `shared/ast/`

> **الدور:** تعريف جميع عقد AST التي تمثل بنية البرنامج  
> **الفضاء:** `Sad::AST`  
> **الأنماط:** Visitor Pattern — كل عقدة تملك `accept(ASTVisitor&)`

---

## نظرة عامة

شجرة البنية المجردة (AST) هي **التمثيل الداخلي** للبرنامج بعد التحليل النحوي.  
كل عقدة تمثل وحدة بنائية: تعبير (ما يُقيَّم إلى قيمة) أو جملة (ما يُنفَّذ).

التسلسل الهرمي الأساسي:
```
ASTNode (الجذر)
├── Expression (تعابير — تُقيَّم إلى قيمة)
│   ├── LiteralExpr, BinaryExpr, UnaryExpr, ...
│   ├── CallExpr, MemberAccessExpr, IndexExpr, ...
│   └── LambdaExpr, ComprehensionExpr, ...
└── Statement (جمل — تُنفَّذ)
    ├── VarDeclStmt, FuncDeclStmt, ClassDeclStmt, ...
    ├── IfStmt, WhileStmt, ForStmt, MatchStmt, ...
    └── TryStmt, ReturnStmt, BlockStmt, ...
```

## الأصناف الأساسية

### `ASTNode` — الجذر
```cpp
class ASTNode {
public:
    virtual ~ASTNode() = default;
    virtual void accept(ASTVisitor& visitor) = 0;  // نمط الزائر
    
    Lexer::Position position;      // موقع العقدة في المصدر
    std::string filename;          // اسم الملف المصدري
};
```

### `Expression` — قاعدة التعابير
```cpp
class Expression : public ASTNode {
public:
    Data::DataType resultType = Data::DataType::UNKNOWN;  // نوع النتيجة
};
using ExprPtr = std::unique_ptr<Expression>;
using ExprList = std::vector<ExprPtr>;
```

### `Statement` — قاعدة الجمل
```cpp
class Statement : public ASTNode {};
using StmtPtr = std::unique_ptr<Statement>;
using StmtList = std::vector<StmtPtr>;
```

### `ASTVisitor` — واجهة الزائر
```cpp
class ASTVisitor {
public:
    // تعابير
    virtual void visit(LiteralExpr& node) = 0;
    virtual void visit(BinaryExpr& node) = 0;
    virtual void visit(UnaryExpr& node) = 0;
    virtual void visit(CallExpr& node) = 0;
    virtual void visit(MemberAccessExpr& node) = 0;
    // ... 50+ دالة visit أخرى
    
    // جمل
    virtual void visit(VarDeclStmt& node) = 0;
    virtual void visit(IfStmt& node) = 0;
    virtual void visit(WhileStmt& node) = 0;
    // ... 30+ دالة visit أخرى
};
```

## أمثلة عقد AST شائعة

### `BinaryExpr` — عملية ثنائية (أ + ب)
```cpp
class BinaryExpr : public Expression {
    ExprPtr left;                      // الطرف الأيسر
    Lexer::TokenType operatorType;     // العامل (+, -, *, /, ...)
    ExprPtr right;                     // الطرف الأيمن
};
```

### `IfStmt` — جملة شرطية
```cpp
class IfStmt : public Statement {
    ExprPtr condition;                 // الشرط
    StmtList thenBranch;              // كتلة "إذا"
    StmtList elseBranch;              // كتلة "وإلا" (اختيارية)
};
```

### `FuncDeclStmt` — تصريح دالة
```cpp
class FuncDeclStmt : public Statement {
    std::string name;                  // اسم الدالة
    std::vector<Parameter> params;     // المعاملات
    StmtList body;                    // جسم الدالة
    TypeAnnotation returnType;         // نوع الإرجاع (اختياري)
    bool isAsync;                      // غير_متزامن؟
    bool isAbstract;                   // مجرد؟
    AccessModifier access;             // عام/خاص/محمي
};
```

### `ClassDeclStmt` — تصريح صنف
```cpp
class ClassDeclStmt : public Statement {
    std::string name;                  // اسم الصنف
    std::string parentName;            // الصنف الأب (وراثة)
    StmtList members;                 // الأعضاء (حقول + دوال)
    ConstructorDeclStmt* constructor;   // الباني
    DestructorDeclStmt* destructor;     // الهدم
    std::vector<std::string> traits;   // السمات المنفّذة
    bool isAbstract;                   // مجرد؟
    bool isSealed;                     // محكم؟
};
```

## ⚠️ ملاحظات مهمة

1. **كل عقدة `unique_ptr`** — الملكية واضحة: الأب يملك أبناءه
2. **`accept()` ضرورية** — بدونها لن يعمل نمط الزائر
3. **عند إضافة عقدة جديدة يجب تحديث 4+ أماكن:** header + cpp + visitor interface + كل visitor تنفيذي
4. **`statements.h.bak` و `.tmp`** — ملفات مؤقتة يمكن تجاهلها
