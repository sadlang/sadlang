# نظام الأنواع — `shared/types/`

> **الدور:** تعريف القيم في وقت التشغيل + نظام الأنواع الموحد  
> **الفضاء:** `Sad::Data` (القيم والكائنات)، `Sad::Types` (نظام الأنواع)  
> **المفهوم الأساسي:** `Value` = نوع موحد يحمل أي قيمة (variant-based)

---

## نظرة عامة

نظام الأنواع هو **العمود الفقري** لوقت التشغيل. كل قيمة في لغة ص تُمثَّل بكائن `Value`  
الذي يعتمد داخلياً على `std::variant`. النظام يضم:
- `Value` — النوع الموحد (رقم، عشري، نص، منطقي، مصفوفة، خريطة، كائن، دالة)
- `ObjectInstance` — تمثيل كائنات الأصناف (يُمرَّر بالمرجع عبر `shared_ptr`)
- `ClassType` — وصف الصنف (الحقول، الدوال، الأب، السمات)
- `FunctionRef` — مرجع لدالة (عادية أو لامدا أو مدمجة)
- `SadTypeSystem` / `SadTypeKind` — نظام الأنواع الثابت

## الأصناف الرئيسية

### `Value` — النوع الموحد ⚡
```cpp
class Value {
    SadTypeKind type_;    // نوع القيمة الحالية
    
    // التخزين الداخلي (variant)
    std::variant<
        std::monostate,                                    // VOID
        int64_t,                                           // INTEGER
        double,                                            // DOUBLE
        std::string,                                       // STRING
        bool,                                              // BOOLEAN
        std::vector<Value>,                                // ARRAY
        std::unordered_map<std::string, Value>,           // MAP
        std::shared_ptr<ObjectInstance>,                    // OBJECT
        FunctionRef,                                       // FUNCTION
        std::vector<Value>                                 // TUPLE
    > data_;
    
public:
    // إنشاء قيم
    Value();                              // VOID
    explicit Value(int64_t v);            // INTEGER
    explicit Value(double v);             // DOUBLE  
    explicit Value(const std::string& v); // STRING
    explicit Value(bool v);               // BOOLEAN
    
    // استخراج القيم
    int64_t getInteger() const;
    double getDouble() const;
    const std::string& getString() const;
    bool getBoolean() const;
    std::vector<Value>& getArray();
    std::unordered_map<std::string, Value>& getMap();
    std::shared_ptr<ObjectInstance> getObject() const;
    
    // استعلام النوع
    SadTypeKind getType() const;
    bool isInteger() const;
    bool isString() const;
    bool isObject() const;
    bool isNull() const;
    bool isTruthy() const;              // هل القيمة "صحيحة"؟
    
    // تحويل
    std::string toString() const;       // تحويل لنص
    double toDouble() const;            // تحويل لعشري
    
    // عمليات
    bool equals(const Value& other) const;
    int compare(const Value& other) const;  // <0, 0, >0
};
```

### `ObjectInstance` — كائن صنف
```cpp
class ObjectInstance {
    std::shared_ptr<ClassType> classType_;                    // وصف الصنف
    std::unordered_map<std::string, Value> fields_;          // الحقول
    std::unordered_map<std::string, FunctionRef> methods_;   // الدوال (override)
    
public:
    void setField(const std::string& name, const Value& value);
    Value getField(const std::string& name) const;
    bool hasField(const std::string& name) const;
    
    void setMethod(const std::string& name, const FunctionRef& method);
    FunctionRef getMethod(const std::string& name) const;
    bool hasMethod(const std::string& name) const;
    
    std::shared_ptr<ClassType> getClassType() const;
    std::string getClassName() const;
};
```

### `ClassType` — وصف الصنف
```cpp
class ClassType {
    std::string name_;                     // اسم الصنف
    std::shared_ptr<ClassType> parent_;    // الصنف الأب
    
    // أعضاء الصنف
    std::unordered_map<std::string, DataType> fieldTypes_;
    std::unordered_map<std::string, FunctionRef> methods_;

public:
    bool isSubclassOf(const std::string& name) const;     // فحص الوراثة
    FunctionRef findMethod(const std::string& name) const; // بحث (يشمل الأب)
};
```

## العلاقات

```
Value ─────────→ ObjectInstance ─────→ ClassType
  │   (shared_ptr)    │  (fields/methods)  │ (parent chain)
  │                   │                     │
  ├── FunctionRef     │                     └── OperatorOverload
  ├── int64_t         │
  ├── double          └── Value (recursion via fields)
  ├── std::string
  ├── std::vector<Value>
  └── std::unordered_map<std::string, Value>
```

- **🔗 يُستخدم في كل مكان:** المفسر، المترجم، الدوال المدمجة، VM
- **🔗 يعتمد على:** `function_ref.h`، `sad_type_system.h`

## ⚠️ ملاحظات مهمة

1. **الكائنات تُمرَّر بالمرجع** — `OBJECT` يحمل `shared_ptr<ObjectInstance>` وليس نسخة
2. **`MAP` لا يزال مدعوماً** — للتوافق الخلفي، لكن الأصناف تُنشأ كـ `OBJECT`
3. **Windows: `VOID` macro** — `value.h` يلغي `#undef VOID` لتجنب تعارض مع Windows.h
4. **`DataType` لا يحتوي على `ANY`** — استخدم `DataType::OBJECT` بدلاً منه
5. **`ValueType` ثوابت توافقية فقط** — النوع الفعلي أصبح `SadTypeKind` مباشرة
