# المحلل المعجمي — `shared/lexer/`

> **الدور:** تحويل النص المصدري (UTF-8) إلى تدفق رموز (Tokens)  
> **الفضاء:** `Sad::Lexer`  
> **المدخل:** `std::string` (كود مصدري)  
> **المخرج:** `std::vector<Token>`

---

## نظرة عامة

المحلل المعجمي هو **أول مرحلة** في مسار المعالجة. يستقبل نصاً مصدرياً ويُخرج قائمة رموز.
يتعرف على:
- 40 كلمة محجوزة عربية + 3 عوامل منطقية (`و`، `أو`، `ليس`)
- كلمات سياقية (لا تُسجَّل في جدول الكلمات — يتعرف عليها المحلل النحوي)
- أنواع مدمجة (`رقم`، `نص`، `عشري`...) كمعرّفات عادية
- الأرقام (صحيحة وعشرية)، النصوص (عادية و f-strings و raw)، المعرّفات
- العوامل (حسابية، مقارنة، منطقية، إسناد)
- التعليقات (`#` سطرية، `#* *#` كتلية، `#** **#` توثيقية)

## الهياكل والأصناف الرئيسية

### `Position` — موقع الرمز في المصدر
```cpp
struct Position {
    size_t line;    // رقم السطر (يبدأ من 1)
    size_t column;  // رقم العمود (يبدأ من 1)
    size_t offset;  // الإزاحة من بداية الملف (يبدأ من 0)
    size_t length;  // طول الرمز بالأحرف
    
    std::string toString() const;  // "سطر:عمود"
};
```

### `TokenType` — تعداد أنواع الرموز
منظم في فئات:
- **[محجوزة]** بنيات: `KEYWORD_FUNCTION`, `KEYWORD_CLASS`, `KEYWORD_END`, ...
- **[محجوزة]** تحكم: `KEYWORD_IF`, `KEYWORD_WHILE`, `KEYWORD_FOR`, ...
- **[محجوزة]** أخطاء: `KEYWORD_TRY`, `KEYWORD_CATCH`, `KEYWORD_THROW`, ...
- **[محجوزة]** وصول: `KEYWORD_PUBLIC`, `KEYWORD_PRIVATE`, `KEYWORD_PROTECTED`
- **[محجوزة]** وحدات: `KEYWORD_IMPORT`, `KEYWORD_FROM`, `KEYWORD_AS`, `KEYWORD_EXPORT`
- **[محجوزة]** متغيرات: `KEYWORD_VAR`, `KEYWORD_CONST`, `KEYWORD_STATIC`
- **[سياقية]** (في enum لكن لا تُنتَج من اللكسر): `KEYWORD_ASYNC`, `KEYWORD_PROPERTY`, `KEYWORD_LAMBDA`, ...
- **[مدمجة]** أنواع: `TYPE_INTEGER`, `TYPE_STRING`, `TYPE_BOOLEAN`, ... (لا تُنتَج من اللكسر)
- **عوامل**: `OP_PLUS`, `OP_MINUS`, `OP_MULTIPLY`, `OP_DIVIDE`, ...
- **قيم حرفية**: `NUMBER_INTEGER`, `NUMBER_DOUBLE`, `STRING_LITERAL`, ...
- **أنواع منخفضة**: `TYPE_U8`, `TYPE_I32`, `TYPE_PTR`, ... (لبرمجة الأنظمة)

### `Token` — الرمز المفرد
```cpp
class Token {
    TokenType type_;        // نوع الرمز
    std::string value_;     // القيمة النصية
    Position position_;     // الموقع في المصدر
    
    TokenType getType() const;
    std::string getValue() const;
    Position getPosition() const;
};
```

### `LexerCore` — المحلل المعجمي
```cpp
class LexerCore {
public:
    explicit LexerCore(const std::string& source);
    
    // ⚡ نقطة الدخول الرئيسية
    std::vector<Token> tokenize();    // تحويل النص بالكامل إلى رموز
    Token nextToken();                 // الحصول على الرمز التالي فقط
    
    // التنقل في النص
    char peek() const;                // النظر بدون تقدم
    char peekNext(size_t offset = 1) const;
    char advance();                    // التقدم حرف
    bool isAtEnd() const;
    Position getCurrentPosition() const;
    
    // تخطي
    void skipWhitespace();
    void skipComment();
    
    // مسح أنواع الرموز
    Token scanNumber();                // أرقام صحيحة وعشرية
    Token scanString();                // نصوص عادية
    Token scanRawString();             // نصوص خام r"..."
    Token scanFString();               // f-strings
    Token scanIdentifierOrKeyword();   // معرّفات وكلمات مفتاحية
};
```

### `KeywordTable` — جدول الكلمات المحجوزة
```cpp
class KeywordTable {
public:
    static void initialize();                                    // تهيئة لمرة واحدة
    static TokenType lookup(const std::string& word);           // بحث O(1)
    static bool isKeyword(const std::string& word);             // هل كلمة محجوزة؟
    static const std::vector<std::string>& getAllKeywords();    // قائمة الكل
};
```

## مسار التنفيذ

```
LexerCore(source)
    │
    ▼ tokenize()
    ┌────────────────────┐
    │  حلقة: حتى EOF    │
    │  ├─ skipWhitespace │
    │  ├─ skipComment    │
    │  ├─ isDigit?       │──→ scanNumber()
    │  ├─ isQuote?       │──→ scanString() / scanFString() / scanRawString()
    │  ├─ isAlpha/UTF8?  │──→ scanIdentifierOrKeyword()
    │  │                 │      └─→ KeywordTable::lookup()
    │  └─ operator?      │──→ العامل المناسب
    └────────────────────┘
    │
    ▼
    std::vector<Token> + Token(EOF) في النهاية
```

## ⚠️ ملاحظات مهمة

1. **الكلمات السياقية لا تُسجَّل في `lexer_keywords.cpp`** — Lexer ينتجها كـ `IDENTIFIER` والـ Parser يتعرف عليها سياقياً
2. **أسماء الأنواع المدمجة (`رقم`، `نص`...) أصبحت معرّفات عادية** — Lexer لا ينتج `TYPE_INTEGER` بل `IDENTIFIER` بقيمة `"رقم"`
3. **`Position.line` يبدأ من 1** — وليس 0
4. **Windows: `VOID` macro** — token.h يلغي تعريف `#undef VOID` لتجنب تعارض مع Windows.h
