# الآلة الافتراضية — `vm/`

> **الدور:** آلة بايت كود مبنية على المكدس (Stack-based VM)  
> **الفضاء:** `sad::vm`  
> **المدخل:** AST (عبر المترجم الداخلي) → بايت كود  
> **المخرج:** تنفيذ البرنامج  
> **عدد الملفات:** 11 (7 headers + 4 sources)

---

## نظرة عامة

آلة افتراضية مربوطة مباشرة بالمفسر. تحوّل AST إلى بايت كود ثم تنفذه على مكدس.

```
AST → [VmCompiler] → Chunk (بايت كود) → [VmExecutor] → تنفيذ
```

**المعمارية:**

```
┌─────────────────────────────────────┐
│           المكدس (Stack)            │
│  [قيمة] [قيمة] [قيمة] ... ← قمة    │  حجم أقصى: 65536
├─────────────────────────────────────┤
│      إطارات الاستدعاء (Call Frames)  │
│  [إطار 0: رئيسي] [إطار 1: دالة_أ]  │  عمق أقصى: 1024
├─────────────────────────────────────┤
│       المتغيرات العامة (Globals)     │
│  {"س" → 42, "اسم" → "أحمد"}       │
├─────────────────────────────────────┤
│      الدوال الأصلية (Native Fns)    │
│  {"اطبع" → ..., "ادخل" → ...}     │
└─────────────────────────────────────┘
```

| النطاق | المجموعة | أمثلة |
|--------|---------|-------|
| `0x00-0x0F` | المكدس الأساسية | `عملية_لا_شيء`, `ادفع_ثابت`, `اسحب`, `انسخ_القمة` |
| `0x10-0x1F` | الحسابية | `اجمع`, `اطرح`, `اضرب`, `اقسم`, `باقي` |
| `0x20-0x2F` | المنطقية والبتية | `و`, `أو`, `ليس`, `بت_و`, `بت_أو` |
| `0x30-0x3F` | المقارنة | `يساوي`, `لا_يساوي`, `أقل`, `أكبر` |
| `0x40-0x4F` | التحكم | `اقفز`, `اقفز_إذا_خطأ`, `استدعِ`, `عُد`, `توقف` |
| `0x50-0x5F` | المتغيرات | `حمّل_محلي`, `خزّن_محلي`, `حمّل_عام`, `خزّن_عام` |
| `0x60-0x6F` | النصوص والتحويل | `إلى_نص`, `إلى_رقم`, `اربط_نصوص` |
| `0x70-0x7F` | المصفوفات والقواميس | `أنشئ_مصفوفة`, `احصل_عنصر`, `عيّن_عنصر` |

| `0x90-0x9F` | الدوال المدمجة | `اطبع`, `ادخل`, `طول` |
| `0xA0-0xAF` | معالجة الأخطاء | `حاول_ابدأ`, `ارمِ`, `امسك` |
| `0xB0-0xBF` | الوحدات | `استورد`, `صدّر` |
| `0xC0-0xCF` | الإغلاقات | `أنشئ_إغلاق`, `حمّل_مرفوع`, `خزّن_مرفوع` |
| `0xF0-0xFF` | خاصة | `تصحيح_نقطة_توقف`, `أوقف` |

## دورة التنفيذ

```
VmExecutor::execute(chunk)
    │
    ├── إعادة المكدس والإطارات
    │
    └── loop:
        ├── 1. اقرأ رمز_العملية ← chunk[IP++]
        ├── 2. فكّ المعاملات (إن وُجدت)
        ├── 3. switch(رمز_العملية):
        │       ├── ادفع_ثابت → push(constants[arg])
        │       ├── اجمع → push(pop() + pop())
        │       ├── استدعِ → إطار جديد + قفز
        │       ├── عُد → حذف إطار + إرجاع قمة
        │       └── أوقف → break
        └── 4. كرّر
```

## العلاقات

- **🔗 يستهلك:** AST من `shared/ast/` (عبر `VmCompiler`)
- **🔗 مربوط بـ:** `InterpreterCore` (المفسر يمكنه تفويض التنفيذ للـ VM)
- **🔗 مستقل عن:** LLVM (لا يحتاج المترجم)

## ⚠️ ملاحظات

1. **البايت كود كلّه بالعربية** — أسماء العمليات والبنيات عربية: `رمز_عملية`, `إطار_استدعاء`, `كائن_دالة`

4. **تعليمات بطول متغير** — `[opcode: 1B] [arg1: 0-4B] [arg2: 0-4B]`
5. **JIT مبدئي** — `sad_jit.cpp/h` موجود لكنه في مرحلة مبكرة
