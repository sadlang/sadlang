# المحسّنات — `compiler_new/src/optimizer/` + `src/middle/`

> **الدور:** تحسين SIR قبل توليد LLVM IR (مرور وسيط)  
> **الفضاء:** `Sad::Compiler::Optimizer`  
> **المدخل:** `SIRModule` (خام)  
> **المخرج:** `SIRModule` (محسّن)  
> **عدد الملفات:** 25 (7 في optimizer/ + 18 في middle/)

---

## نظرة عامة

طبقتان من التحسينات:
1. **`optimizer/`** — تمريرات بسيطة على مستوى SIR (طي الثوابت, تبسيط التعابير, تضمين)
2. **`middle/`** — تمريرات متقدمة بنمط LLVM Pass Manager (15 تمريرة مسجلة)

```
SIRModule (خام) → [optimizer/] → [middle/] → SIRModule (محسّن) → LLVM CodeGen
```

---

## `optimizer/` — التحسينات الأساسية (7 ملفات)

| الملف | الدور |
|-------|------|
| `optimization_pass.cpp` | **القاعدة الأساسية** — واجهة التمريرة الواحدة |
| `optimization_pass_constant_folding.cpp` | طي الثوابت (`3 + 5` → `8`) |
| `optimization_pass_expr_loop.cpp` | تبسيط التعابير داخل الحلقات |
| `optimization_pass_inline_assign.cpp` | تضمين الإسناد (`متغير x = 5; اطبع(x)` → `اطبع(5)`) |
| `advanced_optimizer.cpp` | تحسينات متقدمة (inlining, DCE) |
| `arabic_passes.cpp` | تحسينات خاصة بالنصوص العربية |
| `optimizer_o2.h` | إعدادات مستوى O2 |

## `middle/` — تمريرات Pass Manager (18 ملف)

### البنية التحتية

| الملف | الدور |
|-------|------|
| `pass.cpp` | ⚡ **الصنف الأساسي** لكل تمريرة |
| `pass_manager.cpp` | ⚡ **مدير التمريرات** — يسجل ويرتب وينفذ |
| `optimizer.cpp` | المحسّن الرئيسي — نقطة الدخول |

### تمريرات التحسين (15 تمريرة)

| الملف | الاسم | الدور |
|-------|------|------|
| `constant_folding_pass.cpp` | طي الثوابت | `3+5` → `8`, `"أ"+"ب"` → `"أب"` |
| `dead_code_elimination_pass.cpp` | حذف الكود الميت | إزالة متغيرات/دوال غير مستخدمة |
| `copy_propagation_pass.cpp` | نشر النسخ | `y=x; z=y` → `z=x` |
| `cse_pass.cpp` | إزالة التعابير المشتركة (CSE) | حساب مرة واحدة وإعادة استخدام |
| `inlining_pass.cpp` | تضمين الدوال | استبدال الاستدعاء بجسم الدالة |
| `tail_call_pass.cpp` | تحسين الاستدعاء الذيلي | تحويل التكرار إلى حلقة |
| `strength_reduction_pass.cpp` | تخفيض القوة | `x*2` → `x<<1` |
| `licm_pass.cpp` | نقل الثوابت خارج الحلقة (LICM) | رفع حسابات ثابتة خارج الحلقة |
| `peephole_pass.cpp` | تحسين نافذة صغيرة | أنماط محلية (2-3 تعليمات) |
| `branch_folding_pass.cpp` | طي التفريعات | إزالة تفريعات غير ضرورية |
| `sroa_pass.cpp` | تفكيك المجاميع (SROA) | تحويل struct → متغيرات مستقلة |
| `register_coalescing_pass.cpp` | دمج السجلات | تقليل عدد المتغيرات المؤقتة |
| `async_transform.cpp` | تحويل async | تحويل `غير_متزامن`/`انتظر` |
| `async_comprehension.cpp` | فهم async | تبسيط أنماط async |
| `class_desugar.cpp` | تبسيط الأصناف | تحويل OOP لنمط أدنى |

## مسار التنفيذ

```
Optimizer::optimize(sirModule, level)
    │
    ├── level >= O1:
    │   ├── ConstantFoldingPass
    │   ├── DeadCodeEliminationPass
    │   └── CopyPropagationPass
    │
    ├── level >= O2:
    │   ├── CSEPass
    │   ├── InliningPass
    │   ├── LICMPass
    │   ├── StrengthReductionPass
    │   └── BranchFoldingPass
    │
    └── level >= O3:
        ├── TailCallPass
        ├── PeepholePass
        ├── SROAPass
        └── RegisterCoalescingPass
```

## ⚠️ ملاحظات

1. **طبقتان مستقلتان** — `optimizer/` (أساسي) و `middle/` (متقدم) يمكن تشغيل أحدهما بدون الآخر
2. **Pass Manager** في `middle/` يتبع نمط LLVM — كل تمريرة صنف مستقل يُسجَّل ويُنفَّذ بالترتيب
3. **`class_desugar.cpp`** يحوّل الأصناف لهياكل + دوال قبل الوصول للـ codegen
