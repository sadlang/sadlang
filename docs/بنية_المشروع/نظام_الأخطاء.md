# نظام الأخطاء — `shared/errors/`

> **الدور:** إدارة مركزية للأخطاء والتحذيرات مع تشخيصات ذكية  
> **الفضاء:** `Sad::Errors`  
> **النمط:** Singleton (`ErrorManager`) + أنظمة فرعية ذكية

---

## نظرة عامة

نظام الأخطاء يوفر:
- **تجميع مركزي** — كل الأخطاء تمر عبر `DiagnosticSink`
- **تشخيصات ذكية** — اقتراحات إصلاح تلقائية
- **وضع المعلم** — شرح تعليمي للأخطاء (للمبتدئين)
- **منع التتابع** — الخطأ الأول لا يُسبب فيض أخطاء وهمية
- **تعدد اللغات** — عربية وإنجليزية
- **تكامل LSP** — إخراج JSON للـ IDE

## الأصناف الرئيسية

### `Diagnostic` — تشخيص مفرد
```cpp
struct Diagnostic {
    DiagnosticLevel level;       // ERROR, WARNING, NOTE, HINT
    ErrorCode code;              // كود رقمي (E001, W002, ...)
    std::string message;         // الرسالة الأساسية
    SourceLocation location;     // موقع الخطأ
    std::string explanation;     // شرح مفصل (وضع المعلم)
    std::vector<FixSuggestion> fixes;  // اقتراحات الإصلاح
};
```

### `DiagnosticSink` — مجمع التشخيصات
```cpp
class DiagnosticSink {
    void add(const Diagnostic& diag);           // إضافة تشخيص
    void clear();                                // مسح الكل
    const std::vector<Diagnostic>& getAll() const;
    size_t getErrorCount() const;
    size_t getWarningCount() const;
};
```

### `ErrorManager` — المدير المركزي (Singleton)
```cpp
class ErrorManager {
    static ErrorManager& getInstance();
    
    void reportError(ErrorCode code, const SourceLocation& loc, 
                    const std::string& msg);
    void reportWarning(ErrorCode code, const SourceLocation& loc,
                      const std::string& msg);
    
    bool hasErrors() const;
    void printAll(std::ostream& out) const;
    std::string toJSON() const;              // للـ LSP/IDE
};
```
