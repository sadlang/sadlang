# المحلل النحوي — `shared/parser/`

> **الدور:** تحويل تدفق الرموز (Tokens) إلى شجرة البنية المجردة (AST)  
> **الفضاء:** `Sad::Parser`  
> **المدخل:** `Lexer::LexerCore&`  
> **المخرج:** `AST::StmtList` (قائمة جمل AST)  
> **التقنية:** Recursive Descent Parsing مع lookahead

---

## نظرة عامة

المحلل النحوي هو **المرحلة الثانية** في مسار المعالجة. يقرأ الرموز من المحلل المعجمي  
ويبني شجرة AST تمثل بنية البرنامج. يدعم:
- التصريحات (دوال، أصناف، متغيرات، ثوابت، تعدادات، بنيات، سمات)
- الجمل (إذا/وإلا، بينما، لكل، طابق/عندما، حاول/امسك)
- التعابير (حسابية، منطقية، استدعاء دوال، فهرسة، عضوية، لامدا)
- OOP (وراثة، خصائص get/set، تحميل عوامل زائد، هدم)
- ميزات متقدمة (generators, list comprehensions, async/await, macros, defer)
- واجهات المستخدم التصريحية (UI DSL)
- العقود البرمجية (يتطلب/يضمن)
- الكلمات السياقية بنمط التحقق المزدوج

## الصنف الرئيسي: `ParserCore`

```cpp
class ParserCore {
public:
    explicit ParserCore(Lexer::LexerCore& lexer);
    
    // ⚡ نقطة الدخول الرئيسية
    AST::StmtList parseProgram();      // يحلل البرنامج الكامل
    
    // استعلام الأخطاء
    bool hasErrors() const;
    void printErrors() const;
    std::vector<std::string> getErrors() const;
    std::string getRecoveryStats(bool useArabic = true) const;
    
private:
    Lexer::LexerCore& lexer_;          // مرجع للمحلل المعجمي
    Lexer::Token current_;             // الرمز الحالي
    Lexer::Token previous_;            // الرمز السابق
    
    // التنقل في الرموز
    void advance();                    // التقدم للرمز التالي
    bool check(TokenType type);        // تحقق بدون تقدم
    bool match(TokenType type);        // تحقق مع تقدم
    Token consume(TokenType type, const std::string& msg);  // توقع رمز محدد
    
    // تحليل التعابير (حسب الأولوية)
    ExprPtr parseExpression();         // المستوى الأعلى
    ExprPtr parseAssignment();         // =, +=, -=, ...
    ExprPtr parseTernary();            // ? :
    ExprPtr parseOr();                 // أو, ||
    ExprPtr parseAnd();                // و, &&
    ExprPtr parseEquality();           // ==, !=
    ExprPtr parseComparison();         // <, >, <=, >=
    ExprPtr parseTerm();               // +, -
    ExprPtr parseFactor();             // *, /, %
    ExprPtr parseUnary();              // !, -, ليس
    ExprPtr parsePrimary();            // حرفيات، معرّفات، أقواس
    
    // تحليل التصريحات
    StmtPtr parseDeclaration();        // موزّع للتصريحات
    StmtPtr parseFunctionDecl();       // دالة
    StmtPtr parseClassDecl();          // صنف
    StmtPtr parseVarDecl();            // متغير/ثابت
    StmtPtr parseEnumDecl();           // تعداد
    StmtPtr parseStructDecl();         // بنية
    StmtPtr parseTraitDecl();          // سمة
    StmtPtr parseImplDecl();           // نفّذ
    
    // تحليل الجمل
    StmtPtr parseStatement();          // موزّع للجمل
    StmtPtr parseIfStmt();             // إذا/وإلا
    StmtPtr parseWhileStmt();          // بينما
    StmtPtr parseForStmt();            // لكل
    StmtPtr parseReturnStmt();         // ارجع
    StmtPtr parseMatchStmt();          // طابق/عندما
    StmtPtr parseTryStmt();            // حاول/امسك/أخيراً
};
```

## نمط التحقق المزدوج للكلمات السياقية

```cpp
// الكلمة السياقية "سمة" لا تُسجَّل في KeywordTable
// لذلك يجب التحقق منها كمُعرّف أيضاً:
if (check(TokenType::KEYWORD_TRAIT) || 
    (check(TokenType::IDENTIFIER) && current_.getValue() == "سمة"))
{
    return parseTraitDecl();
}
```

هذا النمط يتكرر لكل كلمة سياقية: `خاصية`، `هدم`، `عامل`، `غير_متزامن`، `لامدا`، `سمة`، `نفّذ`، `أجّل`، `أطلق`، `اختر`، الخ.

## مسار التنفيذ

```
ParserCore(lexer)
    │
    ▼ parseProgram()
    ┌────────────────────────────────────┐
    │  حلقة: حتى EOF                    │
    │  ├─ parseDeclaration()             │
    │  │   ├─ دالة? → parseFunctionDecl │
    │  │   ├─ صنف?  → parseClassDecl    │
    │  │   ├─ متغير/ثابت? → parseVarDecl│
    │  │   ├─ استورد? → parseImport     │
    │  │   ├─ سمة?  → parseTraitDecl    │
    │  │   └─ ... → parseStatement()     │
    │  │        ├─ إذا?   → parseIfStmt  │
    │  │        ├─ بينما? → parseWhile   │
    │  │        ├─ لكل?   → parseForStmt │
    │  │        ├─ طابق?  → parseMatch   │
    │  │        ├─ حاول?  → parseTry     │
    │  │        └─ ...   → parseExprStmt │
    │  │             └─ parseExpression() │
    │  └─ [تعافي من الأخطاء إن وُجدت]    │
    └────────────────────────────────────┘
```

## ⚠️ ملاحظات مهمة

1. **أسماء الأنواع تُتعرف سياقياً** — `isTypeToken()` مع lookahead: `IDENTIFIER("رقم")` يُعامل كنوع **فقط** إذا تلاه `IDENTIFIER` آخر
2. **`نهاية` تنهي جميع الكتل** — بدلاً من `}` 
3. **الفاصلة العربية `،` والعادية `,` متكافئتان** — المحلل يقبل كلاهما
4. **المنقوطة اختيارية** — `؛` أو `;` كلاهما يُقبل ويُتجاهل
