# المكتبة القياسية — `stdlib/`

> **الدور:** مكتبات قياسية مكتوبة بـ C++ تُستدعى من كود ص عبر `استورد`  
> **عدد المجلدات:** 30+  
> **طريقة الوصول:** `استورد رياضيات` أو `من رياضيات استورد جذر`

---

## نظرة عامة

المكتبة القياسية تُحمَّل كسولاً (lazy loading) — لا تُحمَّل إلا عند الاستيراد.  
كل مكتبة مجلد مستقل يحوي ملفات `.cpp` و/أو `.h`.

## نظام الاستيراد

```sad
# استيراد كامل
استورد رياضيات

# استيراد بإسم مستعار
استورد رياضيات كـ ر

# استيراد دالة محددة
من رياضيات استورد جذر

# استيراد كل الصادرات
من رياضيات استورد *
```

**البدائل المعروفة:**
| الوحدة | البدائل |
|--------|--------|
| `رياضيات` | `math`, `حساب` |
| `نصوص` | `strings`, `str`, `سلاسل` |
| `أساسيات` | `basics`, `base`, `ملفات` |
| `خرائط` | `maps`, `json`, `xml` |
| `تزامن_متقدم` | `async`, `توازي` |

## ⚠️ ملاحظات

1. **تحميل كسول** — لا تُحمَّل المكتبة إلا عند `استورد`
2. **ازدواجية عربي/إنجليزي** — بعض المكتبات لها مجلدين (مثل `string/` و `نص/`)
3. **الدوال المدمجة لا تحتاج استيراد** — `اطبع`, `طول`, `نوع`, تحويل الأنواع
4. **الإمتدادات في `إضافات/`** — مكتبات المجتمع
