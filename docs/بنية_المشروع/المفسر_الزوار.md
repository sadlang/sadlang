# زوار المفسر — `interpreter_new/src/visitors/`

> **الدور:** تنفيذ نمط الزائر (Visitor) لاجتياز AST وتنفيذ البرنامج  
> **المكونان الرئيسيان:** `StatementExecutor` (الجمل) + `ExpressionEvaluator` (التعابير)  
> **النمط:** كل ملف .cpp يُنفذ مجموعة من دوال `visit()` لصنف واحد

---

## نظرة عامة

الزوار هم **قلب المفسر**. ملفان رئيسيان يتقاسمان المسؤوليات:
- `StatementExecutor` — ينفذ الجمل (إذا، بينما، لكل، تصريحات، ...)
- `ExpressionEvaluator` — يُقيّم التعابير (حسابية، منطقية، استدعاء، ...)

كل منهما مُقسَّم إلى **عدة ملفات .cpp** حسب الفئة لتقليل حجم الملف.

## `ExpressionEvaluator` — مقيّم التعابير

```cpp
class ExpressionEvaluator : public AST::ASTVisitor {
    Data::VariableManager& varManager_;
    Data::FunctionManager& funcManager_;
    Data::OwnershipManager* ownershipManager_;
    
    Data::Value lastResult_;               // آخر نتيجة محسوبة
    StatementExecutor* stmtExecutor_;      // مرجع لمنفذ الجمل (للاستدعاءات)
    
public:
    // استخراج النتيجة
    Data::Value getResult() const;
    
    // تقييم تعبير مباشرة
    Data::Value evaluate(AST::Expression& expr);
    
    // ---- دوال visit ---- (50+ دالة)
    void visit(AST::LiteralExpr& node) override;
    void visit(AST::BinaryExpr& node) override;
    void visit(AST::CallExpr& node) override;
    void visit(AST::NewExpr& node) override;
    // ...
    
private:
    // عمليات ثنائية
    Data::Value performBinaryOp(const Data::Value& left, 
                                TokenType op, 
                                const Data::Value& right);
    
    // استدعاء دوال
    Data::Value callFunction(const std::string& name, 
                            const std::vector<Data::Value>& args);
    Data::Value callBuiltin(const std::string& name,
                           const std::vector<Data::Value>& args);
    
    // طرق مدمجة على الأنواع
    Data::Value evaluateStringMethod(const std::string& str,
                                    const std::string& method,
                                    const std::vector<Data::Value>& args);
    Data::Value evaluateArrayMethod(std::vector<Data::Value>& arr,
                                   const std::string& method,
                                   const std::vector<Data::Value>& args);
};
```

## `StatementExecutor` — منفذ الجمل

```cpp
class StatementExecutor : public AST::ASTVisitor {
    Data::VariableManager& varManager_;
    Data::FunctionManager& funcManager_;
    Data::ScopeManager& scopeManager_;
    Data::OwnershipManager* ownershipManager_;
    
    ExpressionEvaluator& evaluator_;       // مرجع لمقيّم التعابير
    
    FlowControl flowControl_ = FlowControl::NONE;  // حالة التدفق
    Data::Value returnValue_;              // قيمة الإرجاع
    
public:
    // ---- دوال visit ---- (40+ دالة)
    void visit(AST::VarDeclStmt& node) override;
    void visit(AST::IfStmt& node) override;
    void visit(AST::WhileStmt& node) override;
    void visit(AST::ForStmt& node) override;
    void visit(AST::FuncDeclStmt& node) override;
    void visit(AST::ClassDeclStmt& node) override;
    void visit(AST::TryStmt& node) override;
    // ...
    
    // إدارة التدفق
    FlowControl getFlowControl() const;
    void resetFlowControl();
    Data::Value getReturnValue() const;
    
    // تنفيذ كتلة
    void executeBlock(const AST::StmtList& stmts);
    
    // تنفيذ دالة
    Data::Value executeFunction(const AST::FuncDeclStmt& func,
                               const std::vector<Data::Value>& args);
};
```

### `FlowControl` — التحكم بالتدفق
```cpp
enum class FlowControl {
    NONE,      // تدفق عادي
    RETURN,    // ارجع — خروج من دالة
    BREAK,     // توقف — خروج من حلقة
    CONTINUE,  // استمر — التكرار التالي
    YIELD      // أنتج — مولّد
};
```

## مسار التنفيذ (مثال: `إذا (س > 5) اطبع("كبير") نهاية`)

```
StatementExecutor::visit(IfStmt)
    │
    ├── evaluator_.evaluate(condition)  ← "س > 5"
    │       │
    │       ├── visit(BinaryExpr)
    │       │   ├── evaluate(IdentifierExpr "س")  → Value(10)
    │       │   ├── evaluate(LiteralExpr "5")     → Value(5)
    │       │   └── performBinaryOp(10, >, 5)     → Value(true)
    │       └── return Value(true)
    │
    ├── isTruthy(result)?  → true
    │
    └── executeBlock(thenBranch)
            │
            └── visit(ExprStmt)
                    └── evaluator_.visit(CallExpr "اطبع")
                            └── callBuiltin("اطبع", ["كبير"])
```
