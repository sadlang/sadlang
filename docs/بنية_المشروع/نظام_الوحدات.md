# نظام الوحدات — `shared/modules/`

> **الدور:** تحميل الوحدات (استيراد/تصدير)، حل الاعتماديات، التخزين المؤقت  
> **الفضاء:** `Sad::Modules`  
> **النمط:** Singleton (`ModuleLoader`) مع مكونات متخصصة

---

## نظرة عامة

نظام الوحدات يدير **استيراد وتصدير** الكود بين ملفات `.ص`. يدعم:
- `استورد رياضيات` — استيراد وحدة كاملة
- `استورد رياضيات كـ ر` — استيراد بإسم مستعار
- `من رياضيات استورد جذر` — استيراد رمز محدد
- `من رياضيات استورد *` — استيراد كل الصادرات
- حل الاعتماديات الدائرية
- كشف الدورات
- تخزين مؤقت للتحليل

## مسار التحميل

```
استورد رياضيات
    │
    ▼ ModuleLoader::load("رياضيات")
    ┌─────────────────────────────────────┐
    │ 1. SearchPathManager::findModule()  │ ← بحث في: ./، stdlib/، packages/
    │ 2. ModuleCache::get()               │ ← محمّل سابقاً؟ ارجع من الكاش
    │ 3. LexerCore + ParserCore           │ ← حلل الملف إلى AST
    │ 4. DependencyGraph::add()           │ ← سجّل الاعتماديات
    │ 5. DependencyGraph::detectCycles()  │ ← كشف دورات
    │ 6. ModuleValidator::validate()      │ ← تحقق من الصادرات
    │ 7. SymbolResolver::resolve()        │ ← حل الرموز
    │ 8. ModuleCache::store()             │ ← خزّن في الكاش
    └─────────────────────────────────────┘
```

## العلاقات

- **🔗 يُستخدم من:** `StatementExecutor` (المفسر — عند تنفيذ `استورد`)، `SIRBuilder` (المترجم)
- **🔗 يعتمد على:** `LexerCore`, `ParserCore` (لتحليل ملفات الوحدات)

---

## ⚠️ ملاحظات مهمة

1. **الوحدات المدمجة** (رياضيات، نصوص، أساسيات...) لا تُحمَّل من ملفات — تُسجَّل في `BuiltinModuleRegistry`
2. **مسارات البحث:** المجلد الحالي → `stdlib/` → `packages/`
3. **الاعتماديات الدائرية** تُكشف وتُرفض مع رسالة خطأ واضحة
