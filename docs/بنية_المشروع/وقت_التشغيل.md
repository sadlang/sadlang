# وقت التشغيل — `runtime_new/`

> **الدور:** وقت تشغيل مستقل (freestanding) + ABI/FFI + ربط VM  
> **التفعيل:** `HAS_RUNTIME_NEW` (CMake)  
> **المخرج:** مكتبة يُربط بها الملف التنفيذي

---

## نظرة عامة

وقت التشغيل يوفر الخدمات الأساسية التي يحتاجها البرنامج المُترجَم:
- إدارة الذاكرة (allocators)
- معالجة الاستثناءات (exceptions)
- FFI (واجهة الدوال الخارجية)
- ABI (واجهة التطبيق الثنائية)
- ربط VM (bytecode compatibility)

```
.exe مُترجَم → [ربط] ← runtime_new / freestanding runtime
```

| `sad_lowlevel_rt.c/h` | وقت تشغيل منخفض المستوى (C) |
| `sad_types.h` | أنواع أساسية |

| `sad_control_flow.h` | تحكم بالتدفق |

| `sad_mmio.h` | MMIO (وصول للعتاد) |
| `linker/` | سكريبتات الربط |

## `src/` — وقت التشغيل القياسي (8 مجلدات فرعية)

| المجلد | الدور |
|-------|------|
| `abi/` | ABI — واجهة التطبيق الثنائية (استدعاء الدوال, تمرير المعاملات) |
| `ffi/` | FFI — استدعاء دوال C/C++ من ص والعكس |
| `memory/` | إدارة الذاكرة (GC, allocators) |
| `exception/` | معالجة الاستثناءات (حاول/امسك) |
| `thread/` | إدارة الخيوط |
| `vm/` | ربط مع الآلة الافتراضية |
| `panic/` | معالجة الذعر |
| `sandbox/` | بيئة محمية (sandboxing) |

## ⚠️ ملاحظات

1. **`freestanding/`** — بلا libc, بلا OS, يُستخدم لبناء نواة أفق
2. **`HAS_RUNTIME_NEW`** — يجب تفعيله في CMake لبناء وقت التشغيل الجديد
3. **`sad_lowlevel_rt.c`** — ملف C وليس C++ (للتوافق مع الربط المنخفض المستوى)
