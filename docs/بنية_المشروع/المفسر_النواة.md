# نواة المفسر — `interpreter_new/`

> **الدور:** نقطة الدخول الرئيسية لتنفيذ برامج لغة ص  
> **الفضاء:** `Sad::Interpreter`  
> **المدخل:** `AST::StmtList` (شجرة AST)  
> **المخرج:** `ExecutionResult` (نجاح/فشل + نتيجة)

---

## نظرة عامة

المفسر هو **مفسر شجري** (tree-walking interpreter) ينفذ AST مباشرة.  
البنية الداخلية تتبع **فصل الاهتمامات**:

```
InterpreterCore (المنسق)
    │
    ├── StatementExecutor (منفذ الجمل)
    │       └── يستخدم ExpressionEvaluator داخلياً
    │
    ├── ExpressionEvaluator (مقيّم التعابير)
    │
    ├── VariableManager (إدارة المتغيرات)
    ├── FunctionManager (إدارة الدوال)  
    ├── ScopeManager (إدارة النطاقات)
    ├── ClassManager (إدارة الأصناف)
    ├── ObjectManager (إدارة الكائنات)
    └── OwnershipManager (إدارة الملكية — اختياري)
```

## الصنف الرئيسي: `InterpreterCore`

```cpp
class InterpreterCore {
public:
    InterpreterCore();
    explicit InterpreterCore(const InterpreterOptions& options);
    
    // ⚡ نقطة الدخول الرئيسية
    ExecutionResult execute(const AST::StmtList& program);
    
    // تنفيذ ملف
    ExecutionResult executeFile(const std::string& filePath);
    
    // تنفيذ نص مباشر
    ExecutionResult executeSource(const std::string& source);
    
    // الوصول للمكونات الداخلية
    Data::VariableManager& getVariableManager();
    Data::FunctionManager& getFunctionManager();
    
private:
    InterpreterOptions options_;
    
    // المكونات
    std::unique_ptr<Data::VariableManager> varManager_;
    std::unique_ptr<Data::FunctionManager> funcManager_;
    std::unique_ptr<Data::ScopeManager> scopeManager_;
    std::unique_ptr<Data::OwnershipManager> ownershipManager_;
    std::unique_ptr<StatementExecutor> executor_;
    std::unique_ptr<ExpressionEvaluator> evaluator_;
    
    void initializeBuiltins();    // تسجيل الدوال المدمجة
};
```

### `InterpreterOptions` — خيارات المفسر
```cpp
struct InterpreterOptions {
    bool enableDebugMode = false;         // وضع التصحيح
    bool enableStrictMode = false;        // الوضع الصارم
    size_t maxCallDepth = 1000;           // أقصى عمق استدعاء
    bool enableOwnership = false;         // نظام الملكية
    bool enableTypeCheck = false;         // فحص الأنواع
    bool enableSecurity = false;          // نظام الأمان
    std::string currentFilePath;          // مسار الملف (للاستيراد)
    bool enableHotReload = false;         // إعادة التحميل الساخن
};
```

### `ExecutionResult` — نتيجة التنفيذ
```cpp
struct ExecutionResult {
    bool success;                         // نجح التنفيذ؟
    Data::Value result;                   // النتيجة
    std::string errorMessage;             // رسالة الخطأ (إن وجدت)
};
```

## مسار التنفيذ

```
InterpreterCore::execute(program)
    │
    ├── initializeBuiltins()          ← تسجيل اطبع، اطبع_سطر، طول، نوع، ...
    │
    ▼ لكل statement في program:
    ┌──────────────────────────────┐
    │  statement->accept(*executor) │ ← نمط الزائر
    │                              │
    │  StatementExecutor::visit()  │
    │  ├─ VarDeclStmt → إنشاء متغير│
    │  ├─ FuncDeclStmt → تسجيل دالة│
    │  ├─ IfStmt → تقييم شرط + تنفيذ│
    │  ├─ WhileStmt → حلقة         │
    │  ├─ CallExpr → استدعاء دالة   │
    │  │     └─ ExprEvaluator      │
    │  └─ ...                      │
    └──────────────────────────────┘
```

## أمان الخيوط (Goroutines)

كل goroutine يعمل بمكونات مستقلة:
- `StatementExecutor` خاص
- `ScopeManager` خاص
- `VariableManager` خاص
- `OwnershipManager` خاص

يُشارك فقط:
- `FunctionManager` (قراءة فقط)
- `SadChannel` (آمن للتزامن عبر mutex داخلي)

المتغيرات تُلتقط كـ **snapshot** عبر `captureVisibleVariables()`.

## ⚠️ ملاحظات مهمة

1. **`maxCallDepth = 1000`** — حماية من التكرار اللانهائي
2. **`initializeBuiltins()`** يُستدعى مرة واحدة عند الإنشاء — يسجل ~21 دالة مدمجة
3. **`expression_evaluator_core.cpp.fixed` و `.new`** — ملفات مؤقتة يمكن تجاهلها
