# الأصناف والبرمجة الكائنية في لغة ص

## نظرة عامة

لغة ص تدعم البرمجة الكائنية (OOP) بشكل كامل، تشمل: الأصناف (Classes)، الباني (Constructor)، الوراثة (Inheritance)، التغليف (Encapsulation)، الأعضاء الساكنة، والتعدد الشكلي (Polymorphism).

---

## تعريف صنف بسيط

```sad
صنف اسم_الصنف
    # الحقول (الخصائص)
    نص الاسم
    رقم العمر
    
    # الباني
    باني(اسم، عمر)
        هذا.الاسم = اسم
        هذا.العمر = عمر
    نهاية
    
    # الدوال (الطرق)
    دالة عرض()
        اطبع_سطر(هذا.الاسم + " - " + هذا.العمر)
    نهاية
نهاية
```

## البدائل المدعومة لكلمة `باني`

| الكلمة | القبول |
|--------|-------|
| `باني` | ✓ الأكثر شيوعاً |
| `بناء` | ✓ |
| `منشئ` | ✓ |
| `constructor` | ✓ |

## إنشاء كائنات

```sad
متغير شخص = جديد اسم_الصنف("أحمد"، 25)
شخص.عرض()
```

---

## الوراثة

```sad
صنف صنف_فرعي يرث صنف_أب
    باني(...)
        أساس(...)    # استدعاء باني الأب
    نهاية
نهاية
```

**بدائل `أساس`:** `الأساس`، `الاساس`، `أصل`، `super`

---

## محددات الوصول

| المحدد | الوصف |
|--------|-------|
| `عام` | متاح من أي مكان (public) |
| `خاص` | متاح فقط داخل الصنف (private) |
| `محمي` | متاح في الصنف والأصناف الوارثة (protected) |

---

## الأعضاء الساكنة

```sad
صنف مثال
    ساكن رقم العدد = 0
    
    ساكن دالة رقم كم()
        ارجع العدد
    نهاية
نهاية
```

---

## المدمّر (Destructor)

```sad
صنف مورد
    مدمر
        اطبع_سطر("تم تنظيف المورد")
    نهاية
نهاية
```

**البدائل:** `مدمر`، `هادم`

---

## المرجع `هذا`

الكلمة `هذا` تشير إلى الكائن الحالي، وتُستخدم للوصول إلى الحقول والطرق:

```sad
هذا.الاسم = اسم
هذا.عرض()
```
