### الأسبوع 1: مدخل إلى لغة ص

#### 📖 المحتوى النظري
- تاريخ البرمجة العربية
- مقدمة إلى لغة ص
- تثبيت وإعداد بيئة التطوير
- أول برنامج: "مرحباً بالعالم"
- تركيب اللغة: الكتل، نهاية، التعليقات

#### 💻 التطبيق العملي
```sad
# أول برنامج
اطبع_سطر("مرحباً بالعالم! 🌍")

# التعليقات
# هذا تعليق سطر واحد

#*
هذا تعليق
متعدد الأسطر
*#
```

#### 📝 التقييم
- **واجب 1:** كتابة 5 برامج تطبع رسائل مختلفة

### الأسبوع 2: المتغيرات وأنواع البيانات

#### 📖 المحتوى النظري
- المتغيرات: `متغير`
- الثوابت: `ثابت`
- أنواع البيانات:
  - `رقم` — أعداد صحيحة
  - `عشري` — أعداد عشرية
  - `نص` — سلاسل نصية
  - `منطقي` — صحيح/خطأ
- العمليات الحسابية: `+` `-` `*` `/` `%` `**`

#### 💻 التطبيق العملي
```sad
متغير عمر = 25
ثابت اسم = "أحمد"
متغير راتب = 5000.50
متغير متزوج = صحيح

اطبع_سطر("الاسم: " + اسم)
اطبع_سطر("العمر: " + عمر)
اطبع_سطر("الراتب بعد الزيادة: " + (راتب * 1.1))
```

#### 📝 التقييم
- **واجب 2:** حاسبة بسيطة (جمع، طرح، ضرب، قسمة)

### الأسبوع 3: التحكم في التدفق

#### 📖 المحتوى النظري
- الشروط: `إذا`، `وإلا`
- الشروط المتداخلة
- العوامل المنطقية: `و`، `أو`، `ليس` (أو `&&`، `||`، `!`)
- عوامل المقارنة: `==`، `!=`، `<`، `>`، `<=`، `>=`

#### 💻 التطبيق العملي
```sad
متغير درجة = 85

إذا (درجة >= 90)
    اطبع_سطر("ممتاز! 🌟")
وإلا إذا (درجة >= 80)
    اطبع_سطر("جيد جداً 👍")
وإلا إذا (درجة >= 70)
    اطبع_سطر("جيد")
وإلا
    اطبع_سطر("يحتاج تحسين")
نهاية

# التحقق المتعدد
متغير عمر = 25
متغير لديه_رخصة = صحيح

إذا (عمر >= 18 و لديه_رخصة)
    اطبع_سطر("يمكنك القيادة 🚗")
نهاية
```

#### 📝 التقييم
- **واجب 3:** برنامج تصنيف الأعمار + برنامج حساب الضرائب

### الأسبوع 6: المصفوفات والقوائم

#### 📖 المحتوى النظري
- إنشاء المصفوفات
- الوصول للعناصر بالفهرس
- دوال المصفوفات: `طول`، `أضف`، `احذف`

#### 💻 التطبيق العملي
```sad

# المرور على العناصر
لكل فاكهة في فواكه
    اطبع_سطر("🍎 " + فاكهة)
نهاية

# إيجاد أكبر رقم
دالة أكبر(أرقام)
    متغير الأكبر = أرقام[0]
    لكل رقم في أرقام
        إذا (رقم > الأكبر)
            الأكبر = رقم
        نهاية
    نهاية
    ارجع الأكبر
نهاية
```

### الأسبوع 9: الأصناف والكائنات

#### 📖 المحتوى النظري
- تعريف الصنف: `صنف`
- الخصائص والدوال
- إنشاء الكائنات: `جديد`
- المرجع `هذا`
- الباني: `باني`

#### 💻 التطبيق العملي
```sad
# صنف سيارة
صنف سيارة
    # الخصائص
    متغير ماركة
    متغير موديل
    متغير سرعة = 0
    
    # الباني
    باني(الماركة، الموديل)
        هذا.ماركة = الماركة
        هذا.موديل = الموديل
    نهاية
    
    # الدوال
    دالة تسريع(مقدار)
        هذا.سرعة = هذا.سرعة + مقدار
        اطبع_سطر("السرعة الحالية: " + هذا.سرعة)
    نهاية
    
    دالة فرملة()
        هذا.سرعة = 0
        اطبع_سطر("توقفت السيارة")
    نهاية
    
    دالة معلومات()
        اطبع_سطر(هذا.ماركة + " " + هذا.موديل)
    نهاية
نهاية

# إنشاء كائن
متغير سيارتي = جديد سيارة("تويوتا"، "كامري")
سيارتي.معلومات()
سيارتي.تسريع(50)
سيارتي.تسريع(30)
سيارتي.فرملة()
```
