# 🎯 مدخل إلى لغة ص

## الأسابيع 1-2: الأساسيات

### لغة ص — البرمجة بالعربية

---

# 🌟 ما هي لغة ص؟

- لغة برمجة **عربية** حديثة
- سهلة التعلم للمبتدئين
- قوية للمحترفين
- مفتوحة المصدر

```sad
اطبع_سطر("مرحباً بالعالم! 🌍")
```

---

# 📦 تثبيت لغة ص

### Windows
```powershell
# تحميل من GitHub
git clone https://github.com/sad-lang/sad
cd sad
cmake -B build
cmake --build build
```

### تشغيل برنامج
```powershell
sad.exe برنامجي.ص
```

# 📊 المتغيرات

### الإعلان عن متغير
```sad
متغير اسم = "أحمد"
متغير عمر = 25
متغير راتب = 5000.50
متغير متزوج = صحيح
```

### الثوابت (لا يمكن تغييرها)
```sad
ثابت باي = 3.14159
ثابت اسم_التطبيق = "تطبيقي"
```

---

# 🔢 أنواع البيانات

| النوع | الوصف | مثال |
|-------|-------|------|
| `رقم` | عدد صحيح | `42` |
| `عشري` | عدد عشري | `3.14` |
| `نص` | سلسلة نصية | `"مرحباً"` |
| `منطقي` | صحيح/خطأ | `صحيح`، `خطأ` |

```sad
متغير س = 10         # رقم
متغير ص = 3.14      # عشري
متغير اسم = "علي"   # نص
متغير فعال = صحيح   # منطقي
```

---

# ➕ العمليات الحسابية

| العامل | العملية | مثال |
|--------|---------|------|
| `+` | جمع | `5 + 3` → `8` |
| `-` | طرح | `5 - 3` → `2` |
| `*` | ضرب | `5 * 3` → `15` |
| `/` | قسمة | `6 / 2` → `3` |
| `%` | باقي القسمة | `7 % 3` → `1` |
| `**` | أس | `2 ** 3` → `8` |

# 🔄 تحويل الأنواع

```sad
متغير رقم_نص = "42"
متغير رقم = إلى_رقم(رقم_نص)

متغير عدد = 100
متغير نص = إلى_نص(عدد)

اطبع_سطر("العدد: " + نص)
```

---

# 🎯 النصوص والعمليات عليها

```sad
متغير اسم = "أحمد"
متغير تحية = "مرحباً"

# دمج النصوص
متغير رسالة = تحية + " يا " + اسم + "!"
اطبع_سطر(رسالة)  # مرحباً يا أحمد!

# طول النص
اطبع_سطر(طول(اسم))  # 4
```

# 📝 ملخص

✅ لغة ص لغة برمجة عربية سهلة ومرنة

✅ المتغيرات: `متغير` للمتغيرات، `ثابت` للثوابت

✅ أنواع البيانات: `رقم`، `عشري`، `نص`، `منطقي`

✅ التعليقات: `#` للسطر، `#* *#` للكتلة

✅ العمليات: `+` `-` `*` `/` `%` `**`
