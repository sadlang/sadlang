# 🔧 ما هي الدالة؟

> **الدالة** هي كتلة من الكود يمكن إعادة استخدامها

### لماذا نستخدم الدوال؟
- 🔄 إعادة الاستخدام
- 📚 التنظيم
- 🐛 سهولة الصيانة
- 🧪 سهولة الاختبار

```sad
دالة مرحباً()
    اطبع_سطر("مرحباً بالعالم! 🌍")
```

# 📥 دالة مع معاملات

```sad
دالة تحية(اسم)
    اطبع_سطر("مرحباً يا " + اسم + "!")
نهاية

تحية("أحمد")   # مرحباً يا أحمد!
تحية("سارة")   # مرحباً يا سارة!
```

### معاملات متعددة
```sad
دالة اطبع_معلومات(اسم، عمر)
    اطبع_سطر(اسم + " عمره " + عمر + " سنة")
نهاية

اطبع_معلومات("محمد"، 25)
```

# 📤 القيمة المرجعة: `ارجع`

```sad
دالة جمع(أ، ب)
    ارجع أ + ب
نهاية

متغير النتيجة = جمع(10، 20)
اطبع_سطر("المجموع: " + النتيجة)  # 30
```

### دالة مساحة الدائرة
```sad
دالة مساحة_دائرة(نصف_القطر)
    ثابت باي = 3.14159
    ارجع باي * نصف_القطر ** 2
نهاية

اطبع_سطر(مساحة_دائرة(5))  # 78.53975
```

# 🔁 الدوال التكرارية (Recursion)

```sad
دالة مضروب(ن)
    إذا (ن <= 1)
        ارجع 1
    نهاية
    ارجع ن * مضروب(ن - 1)
نهاية

اطبع_سطر(مضروب(5))  # 120 = 5×4×3×2×1
```

### فيبوناتشي
```sad
دالة فيبوناتشي(ن)
    إذا (ن <= 1)
        ارجع ن
    نهاية
    ارجع فيبوناتشي(ن - 1) + فيبوناتشي(ن - 2)
نهاية
```

# 📋 المصفوفات (Arrays)

### إنشاء مصفوفة
```sad
متغير أرقام = [1، 2، 3، 4، 5]
متغير أسماء = ["أحمد"، "سارة"، "محمد"]
متغير فارغة = []
```

### الوصول للعناصر (الفهرس يبدأ من 0)
```sad
اطبع_سطر(أرقام[0])   # 1
اطبع_سطر(أرقام[2])   # 3
اطبع_سطر(أسماء[1])   # سارة
```

---

# 🔧 عمليات المصفوفات

```sad
متغير قائمة = [1، 2، 3]

# الطول
اطبع_سطر(طول(قائمة))  # 3

# إضافة عنصر
أضف(قائمة، 4)  # [1, 2, 3, 4]

# حذف عنصر
احذف(قائمة، 0)  # [2, 3, 4]

# تعديل عنصر
قائمة[0] = 10  # [10, 3, 4]
```

# 🔄 المرور على المصفوفة

### باستخدام `لكل`
```sad
متغير فواكه = ["تفاح"، "برتقال"، "موز"]

لكل فاكهة في فواكه
    اطبع_سطر("🍎 " + فاكهة)
نهاية
```

### باستخدام الفهرس
```sad
متغير عداد = 0
بينما (عداد < طول(فواكه))
    اطبع_سطر(عداد + ": " + فواكه[عداد])
    عداد = عداد + 1
نهاية
```

# 🎯 دوال مع مصفوفات

```sad
# إيجاد أكبر عنصر
دالة أكبر(قائمة)
    متغير الأكبر = قائمة[0]
    لكل عنصر في قائمة
        إذا (عنصر > الأكبر)
            الأكبر = عنصر
        نهاية
    نهاية
    ارجع الأكبر
نهاية

# حساب المجموع
دالة مجموع(قائمة)
    متغير الناتج = 0
    لكل عنصر في قائمة
        الناتج = الناتج + عنصر
    نهاية
    ارجع الناتج
نهاية

اطبع_سطر(أكبر([5، 2، 9، 1، 7]))  # 9
اطبع_سطر(مجموع([1، 2، 3، 4، 5]))  # 15
```

# 🔍 البحث في المصفوفة

```sad
دالة بحث(قائمة، قيمة)
    متغير فهرس = 0
    لكل عنصر في قائمة
        إذا (عنصر == قيمة)
            ارجع فهرس
        نهاية
        فهرس = فهرس + 1
    نهاية
    ارجع -1  # غير موجود
نهاية

متغير أرقام = [10، 20، 30، 40، 50]
اطبع_سطر(بحث(أرقام، 30))  # 2
اطبع_سطر(بحث(أرقام، 100)) # -1
```
