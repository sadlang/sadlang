# ❓ الشروط: `إذا`

### البنية الأساسية
```sad
إذا (شرط)
    # الكود هنا
نهاية
```

### مثال
```sad
متغير عمر = 20

إذا (عمر >= 18)
    اطبع_سطر("أنت بالغ ✓")
نهاية
```

---

# 🔄 الشرط مع `وإلا`

```sad
متغير درجة = 75

إذا (درجة >= 60)

وإلا
    اطبع_سطر("راسب 😢")
نهاية
```

### الخرج:
```
ناجح! 🎉
```

# 📊 شروط متعددة

```sad
متغير درجة = 85

إذا (درجة >= 90)
    اطبع_سطر("ممتاز! 🌟")
وإلا إذا (درجة >= 80)
    اطبع_سطر("جيد جداً 👍")
وإلا إذا (درجة >= 70)
    اطبع_سطر("جيد")
وإلا إذا (درجة >= 60)
    اطبع_سطر("مقبول")
وإلا
    اطبع_سطر("راسب")
نهاية
```

# ⚖️ عوامل المقارنة

| العامل | المعنى | مثال |
|--------|--------|------|
| `==` | يساوي | `س == 5` |
| `!=` | لا يساوي | `س != 5` |
| `>` | أكبر من | `س > 5` |
| `<` | أصغر من | `س < 5` |
| `>=` | أكبر أو يساوي | `س >= 5` |
| `<=` | أصغر أو يساوي | `س <= 5` |

---

# 🔗 العوامل المنطقية

| العامل | المعنى | مثال |
|--------|--------|------|
| `و` أو `&&` | AND | `س > 0 و س < 10` |
| `أو` أو `\|\|` | OR | `س < 0 أو س > 100` |
| `ليس` أو `!` | NOT | `ليس (س == 0)` |

```sad
متغير عمر = 25
متغير لديه_رخصة = صحيح

إذا (عمر >= 18 و لديه_رخصة)
    اطبع_سطر("يمكنك القيادة 🚗")
نهاية
```

# 🔄 حلقة `بينما`

```sad
متغير عداد = 1
```

# 🛑 `توقف` و `استمر`

### `توقف` — إنهاء الحلقة
```sad
متغير ع = 0
بينما (صحيح)
    ع = ع + 1
    إذا (ع > 5)
        توقف
    نهاية
    اطبع_سطر(ع)
نهاية
```

### `استمر` — تخطي التكرار الحالي
```sad
لكل رقم في [1, 2, 3, 4, 5]
    إذا (رقم == 3)
        استمر
    نهاية
    اطبع_سطر(رقم)  # يطبع: 1, 2, 4, 5
نهاية
```

---

# 🔄 حلقات متداخلة

```sad
# جدول الضرب
لكل س في [1، 2، 3، 4، 5]
    لكل ص في [1، 2، 3، 4، 5]
        متغير نتيجة = س * ص
        اطبع(س + "×" + ص + "=" + نتيجة + " ")
    نهاية
    اطبع_سطر("")
نهاية
```

# 🎲 مثال عملي: لعبة تخمين

```sad
متغير الرقم_السري = 7
متغير محاولات = 0

بينما (صحيح)
    متغير تخمين = اقرأ_رقم("خمّن الرقم (1-10): ")
    محاولات = محاولات + 1
    
    إذا (تخمين == الرقم_السري)
        اطبع_سطر("🎉 أحسنت! في " + محاولات + " محاولات")
        توقف
    وإلا إذا (تخمين < الرقم_السري)
        اطبع_سطر("⬆️ أكبر")
    وإلا
        اطبع_سطر("⬇️ أصغر")
    نهاية
نهاية
```
