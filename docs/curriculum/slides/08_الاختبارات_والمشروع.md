# ✅ التأكيدات الأساسية

| الدالة | الوصف |
|--------|-------|
| `تأكد(شرط)` | تأكد أن الشرط صحيح |
| `تأكد_مساواة(فعلي، متوقع)` | تأكد من التساوي |
| `تأكد_عدم_مساواة(أ، ب)` | تأكد من عدم التساوي |
| `تأكد_صحيح(قيمة)` | تأكد أنها `صحيح` |
| `تأكد_خطأ(قيمة)` | تأكد أنها `خطأ` |
| `تأكد_لاشيء(قيمة)` | تأكد أنها `لاشيء` |
| `تأكد_استثناء(كود)` | تأكد أنه يرمي استثناء |

---

# 📋 مثال: اختبار دالة جمع

```sad
استورد "test"

دالة جمع(أ، ب)
    ارجع أ + ب
نهاية

اختبر("جمع أرقام موجبة")
    تأكد_مساواة(جمع(2، 3)، 5)
    تأكد_مساواة(جمع(10، 20)، 30)
    تأكد_مساواة(جمع(0، 0)، 0)
نهاية

اختبر("جمع أرقام سالبة")
    تأكد_مساواة(جمع(-1، -1)، -2)
    تأكد_مساواة(جمع(-5، 5)، 0)
نهاية

شغّل_الاختبارات()
```

# 📦 اختبار الأصناف

```sad
صنف حساب
    خاص متغير رصيد = 0
    
    دالة إيداع(مبلغ)
        هذا.رصيد = هذا.رصيد + مبلغ
    نهاية
    
    دالة الرصيد()
        ارجع هذا.رصيد
    نهاية
نهاية

اختبر("إيداع في الحساب")
    متغير ح = جديد حساب()
    ح.إيداع(100)
    تأكد_مساواة(ح.الرصيد()، 100)
    ح.إيداع(50)
    تأكد_مساواة(ح.الرصيد()، 150)
نهاية
```

# 📝 جودة الكود

### ما نبحث عنه:
- ✅ أسماء واضحة للمتغيرات والدوال
- ✅ دوال قصيرة ومركزة
- ✅ تعليقات مفيدة
- ✅ معالجة الأخطاء
- ✅ تنظيم في أصناف منطقية

### مثال جيد:
