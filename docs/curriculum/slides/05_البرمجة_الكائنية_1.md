# ❓ ما هي البرمجة الكائنية؟

### الكائن = بيانات + سلوكيات

مثال: **سيارة** 🚗
- **البيانات:** اللون، الماركة، السرعة
- **السلوكيات:** تسريع، فرملة، تشغيل

### لماذا نستخدمها؟
- 📦 تنظيم الكود
- 🔄 إعادة الاستخدام
- 🧩 نمذجة العالم الحقيقي

# 📦 تعريف صنف بسيط

```sad
صنف شخص
    # الخصائص
    متغير اسم
    متغير عمر
    
    # دالة
    دالة تحية()
        اطبع_سطر("مرحباً، أنا " + هذا.اسم)
    نهاية
نهاية
```

---

# 🆕 إنشاء كائن

```sad
# إنشاء كائن
متغير شخص1 = جديد شخص()

# تعيين الخصائص
شخص1.اسم = "أحمد"
شخص1.عمر = 25

# استدعاء الدالة
شخص1.تحية()  # مرحباً، أنا أحمد
```

# 🔧 الباني (`باني`)

> الباني دالة خاصة تُنفذ عند إنشاء الكائن

```sad
صنف شخص
    متغير اسم
    متغير عمر
    
    # الباني
    باني(الاسم، العمر)
        هذا.اسم = الاسم
        هذا.عمر = العمر
    نهاية
    
    دالة تحية()
        اطبع_سطر("أنا " + هذا.اسم + "، عمري " + هذا.عمر)
    نهاية
نهاية

# إنشاء مع قيم
متغير شخص1 = جديد شخص("أحمد"، 25)
شخص1.تحية()  # أنا أحمد، عمري 25
```

# 👆 المرجع `هذا`

> `هذا` يشير للكائن الحالي

```sad
صنف دائرة
    متغير نصف_القطر
    
    باني(نصف_القطر)
        # نميز بين المعامل والخاصية
        هذا.نصف_القطر = نصف_القطر
    نهاية
    
    دالة مساحة()
        ارجع 3.14159 * هذا.نصف_القطر ** 2
    نهاية
    
    دالة محيط()
        ارجع 2 * 3.14159 * هذا.نصف_القطر
    نهاية
نهاية
```

# 🚗 مثال عملي: سيارة

```sad
صنف سيارة
    متغير ماركة
    متغير موديل
    متغير سرعة = 0
    
    باني(الماركة، الموديل)
        هذا.ماركة = الماركة
        هذا.موديل = الموديل
    نهاية
    
    دالة تسريع(مقدار)
        هذا.سرعة = هذا.سرعة + مقدار
        اطبع_سطر("السرعة: " + هذا.سرعة + " كم/س")
    نهاية
    
    دالة فرملة()
        هذا.سرعة = 0
        اطبع_سطر("توقفت السيارة 🛑")
    نهاية
نهاية

متغير سيارتي = جديد سيارة("تويوتا"، "كامري")
سيارتي.تسريع(60)   # السرعة: 60 كم/س
سيارتي.تسريع(40)   # السرعة: 100 كم/س
سيارتي.فرملة()      # توقفت السيارة 🛑
```

# 🔄 الوراثة: `يرث`

```sad
    نهاية
    
    دالة صوت()
        اطبع_سطر("...")
    نهاية
نهاية

صنف قطة يرث حيوان

    نهاية
نهاية

صنف كلب يرث حيوان
    دالة صوت()
        اطبع_سطر("هاو هاو! 🐕")
    نهاية
نهاية
```

# 📞 استدعاء الأساس: `الأساس`

```sad
صنف شكل
    متغير اسم
    
    باني(الاسم)
        هذا.اسم = الاسم
    نهاية
    
    دالة وصف()
        اطبع_سطر("شكل: " + هذا.اسم)
    نهاية
نهاية

صنف مستطيل يرث شكل
    متغير عرض
    متغير ارتفاع
    
    باني(العرض، الارتفاع)
        الأساس("مستطيل")  # استدعاء باني الصنف الأب
        هذا.عرض = العرض
        هذا.ارتفاع = الارتفاع
    نهاية
    
    دالة مساحة()
        ارجع هذا.عرض * هذا.ارتفاع
    نهاية
نهاية
```

# 🔒 مستويات الوصول

| المستوى | الوصف |
|---------|-------|
| `عام` | يمكن الوصول من أي مكان (افتراضي) |
| `خاص` | فقط داخل الصنف |
| `محمي` | داخل الصنف والأصناف المشتقة |

```sad
صنف حساب
    خاص متغير رصيد = 0
    
    دالة إيداع(مبلغ)
        هذا.رصيد = هذا.رصيد + مبلغ
    نهاية
    
    دالة الرصيد()
        ارجع هذا.رصيد
    نهاية
نهاية
```

# 💳 مثال: حساب بنكي

```sad
صنف حساب_بنكي
    خاص متغير رصيد = 0
    متغير رقم_الحساب
    متغير صاحب_الحساب
    
    باني(الرقم، الصاحب)
        هذا.رقم_الحساب = الرقم
        هذا.صاحب_الحساب = الصاحب
    نهاية
    
    دالة إيداع(مبلغ)
        إذا (مبلغ > 0)
            هذا.رصيد = هذا.رصيد + مبلغ
            اطبع_سطر("تم إيداع: " + مبلغ + " ر.س")
        نهاية
    نهاية
    
    دالة سحب(مبلغ)
        إذا (مبلغ <= هذا.رصيد)
            هذا.رصيد = هذا.رصيد - مبلغ
            اطبع_سطر("تم سحب: " + مبلغ + " ر.س")
            ارجع صحيح
        نهاية
        اطبع_سطر("رصيد غير كافٍ!")
        ارجع خطأ
    نهاية
    
    دالة عرض_الرصيد()
        اطبع_سطر("الرصيد: " + هذا.رصيد + " ر.س")
    نهاية
نهاية
```

# 💡 تمارين

### تمرين 1: صنف طالب
أنشئ صنف `طالب` مع: اسم، رقم، درجات، ودالة لحساب المعدل.

### تمرين 2: صنف كتاب
أنشئ صنف `كتاب` مع: عنوان، مؤلف، عدد_الصفحات.

### تمرين 3: وراثة الأشكال
أنشئ: `مثلث`، `شبه_منحرف` يرثان من `شكل`.
