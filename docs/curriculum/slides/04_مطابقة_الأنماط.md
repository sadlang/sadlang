# ❓ ما هي مطابقة الأنماط؟

> طريقة أنيقة للتحقق من قيمة متغير ومعالجة كل حالة

### بدون مطابقة (طريقة تقليدية)
```sad
إذا (يوم == 1)
    اطبع_سطر("الأحد")
وإلا إذا (يوم == 2)
    اطبع_سطر("الاثنين")
وإلا
    ...
نهاية
```

### مع مطابقة الأنماط ✨
```sad
طابق (يوم)
    عندما 1: اطبع_سطر("الأحد")
    عندما 2: اطبع_سطر("الاثنين")
    ...
نهاية
```

# 📋 البنية الأساسية

```sad
طابق (قيمة)
    عندما نمط1:
        # كود
    عندما نمط2:
        # كود
    افتراضي:
        # إذا لم يتطابق أي نمط
نهاية
```

# 🔢 مثال: أيام الأسبوع

```sad
متغير يوم = 3

    عندما 1:
        اطبع_سطر("الأحد ☀️")
    عندما 2:
        اطبع_سطر("الاثنين 📅")
    عندما 3:

    عندما 4:
        اطبع_سطر("الأربعاء 📅")
    عندما 5:
        اطبع_سطر("الخميس 📅")
    عندما 6:
        اطبع_سطر("الجمعة 🕌")
    عندما 7:
        اطبع_سطر("السبت 🏖️")
    افتراضي:
        اطبع_سطر("يوم غير صالح")
نهاية
```

# 🌍 النمط الشامل

### `افتراضي` — يطابق أي شيء
```sad
طابق (لون)
    عندما "أحمر":
        اطبع_سطر("🔴")
    عندما "أخضر":
        اطبع_سطر("🟢")
    افتراضي:
        اطبع_سطر("لون غير معروف")
نهاية
```

### `_` — تجاهل القيمة
```sad
طابق (نتيجة)
    عندما 100:
        اطبع_سطر("كامل!")
    عندما _:
        اطبع_سطر("ليس كاملاً")
نهاية
```

# 📋 مطابقة القوائم

```sad
متغير نقاط = [100، 200]

طابق (نقاط)
    عندما []:
        اطبع_سطر("قائمة فارغة")
    عندما [س]:
        اطبع_سطر("عنصر واحد: " + س)
    عندما [أ، ب]:
        اطبع_سطر("عنصران: " + أ + " و " + ب)
    عندما [أ، ب، ج]:
        اطبع_سطر("ثلاثة عناصر")
    افتراضي:
        اطبع_سطر("أكثر من ثلاثة")
نهاية
```

# 🛡️ معالجة الأخطاء: `حاول`/`امسك`

```sad
حاول
    # كود قد يُسبب خطأ
    متغير نتيجة = 10 / 0
امسك (خطأ)
    # معالجة الخطأ
    اطبع_سطر("خطأ: " + خطأ)
نهاية
```

# 💣 رمي الاستثناءات: `ارمي`

```sad
دالة قسمة(أ، ب)
    إذا (ب == 0)
        ارمي "خطأ: القسمة على صفر!"
    نهاية
    ارجع أ / ب
نهاية

حاول
    اطبع_سطر(قسمة(10، 0))
امسك (خطأ)
    اطبع_سطر("حدث خطأ: " + خطأ)
نهاية
```

### الخرج:
```
حدث خطأ: خطأ: القسمة على صفر!
```

# 🔄 `أخيراً` — ينفذ دائماً

```sad
حاول
    متغير ملف = افتح("بيانات.txt")
    # قراءة الملف...
امسك (خطأ)
    اطبع_سطر("خطأ في قراءة الملف")
أخيراً
    اغلق(ملف)
    اطبع_سطر("تم إغلاق الملف")
نهاية
```

> `أخيراً` يُنفذ سواء حدث خطأ أم لا

# 🎯 مثال عملي: حاسبة

```sad
دالة حاسبة(أ، عملية، ب)
    طابق (عملية)
        عندما "+":
            ارجع أ + ب
        عندما "-":
            ارجع أ - ب
        عندما "*":
            ارجع أ * ب
        عندما "/":
            إذا (ب == 0)
                ارمي "لا يمكن القسمة على صفر"
            نهاية
            ارجع أ / ب
        افتراضي:
            ارمي "عملية غير معروفة: " + عملية
    نهاية
نهاية

حاول
    اطبع_سطر(حاسبة(10، "+"، 5))  # 15
    اطبع_سطر(حاسبة(10، "/"، 0))  # خطأ!
امسك (خطأ)
    اطبع_سطر(خطأ)
نهاية
```
