# 📝 الواجب 1: أساسيات لغة ص

## المستوى: مبتدئ
## الأسبوع: 1-2

---

## 🎯 الأهداف

- التعرف على بنية البرنامج في لغة ص
- استخدام دالة الطباعة
- فهم المتغيرات والثوابت
- تطبيق العمليات الحسابية

---

## التمارين

### تمرين 1: مرحباً بالعالم (5 نقاط)

اكتب برنامجاً يطبع الرسائل التالية:
```
مرحباً بالعالم!
هذا أول برنامج لي بلغة ص
🎉
```

---

### تمرين 2: بطاقة تعريف (10 نقاط)

اكتب برنامجاً يُنشئ متغيرات لتخزين معلوماتك الشخصية ثم يطبعها:
- الاسم
- العمر
- المدينة
- التخصص

الخرج المتوقع:
```
═══════════════════════
   بطاقة تعريف
═══════════════════════
الاسم: محمد أحمد
العمر: 20 سنة
المدينة: الرياض
التخصص: علوم الحاسب
═══════════════════════
```

---

### تمرين 3: حاسبة بسيطة (15 نقاط)

اكتب برنامجاً يُعرّف رقمين ويحسب ويطبع:
- مجموعهما
- فرقهما
- حاصل ضربهما
- ناتج قسمتهما
- باقي قسمتهما

---

### تمرين 4: مساحة المستطيل (10 نقاط)

اكتب برنامجاً يحسب مساحة ومحيط مستطيل أبعاده 8 × 5.

---

### تمرين 5: تحويل درجات الحرارة (10 نقاط)

اكتب برنامجاً يحوّل درجة حرارة من فهرنهايت إلى مئوية.

الصيغة: `C = (F - 32) × 5/9`

---

## حل تمرين 2

```sad
# بطاقة تعريف
متغير الاسم = "محمد أحمد"
متغير العمر = 20
متغير المدينة = "الرياض"
متغير التخصص = "علوم الحاسب"

اطبع_سطر("═══════════════════════")
اطبع_سطر("   بطاقة تعريف")
اطبع_سطر("═══════════════════════")
اطبع_سطر("الاسم: " + الاسم)
اطبع_سطر("العمر: " + العمر + " سنة")
اطبع_سطر("المدينة: " + المدينة)
اطبع_سطر("التخصص: " + التخصص)
اطبع_سطر("═══════════════════════")
```

## حل تمرين 3

```sad
# حاسبة بسيطة
متغير أ = 15
متغير ب = 4

اطبع_سطر("العدد الأول: " + أ)
اطبع_سطر("العدد الثاني: " + ب)
اطبع_سطر("─────────────────")
اطبع_سطر("المجموع: " + (أ + ب))
اطبع_سطر("الفرق: " + (أ - ب))
اطبع_سطر("الضرب: " + (أ * ب))
اطبع_سطر("القسمة: " + (أ / ب))
اطبع_سطر("الباقي: " + (أ % ب))
```

---

## حل تمرين 4

```sad
# مساحة ومحيط المستطيل
ثابت العرض = 8
ثابت الارتفاع = 5

متغير المساحة = العرض * الارتفاع
متغير المحيط = 2 * (العرض + الارتفاع)

اطبع_سطر("أبعاد المستطيل: " + العرض + " × " + الارتفاع)
اطبع_سطر("المساحة: " + المساحة + " وحدة مربعة")
اطبع_سطر("المحيط: " + المحيط + " وحدة")
```

---

## حل تمرين 5

```sad
# تحويل درجات الحرارة
متغير فهرنهايت = 98.6

# الصيغة: C = (F - 32) × 5/9
متغير مئوية = (فهرنهايت - 32) * 5 / 9

اطبع_سطر("درجة الحرارة بالفهرنهايت: " + فهرنهايت + "°F")
اطبع_سطر("درجة الحرارة بالمئوية: " + مئوية + "°C")
```
