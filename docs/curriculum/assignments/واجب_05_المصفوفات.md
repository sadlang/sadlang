# 📝 الواجب 5: المصفوفات

## المستوى: متوسط
## الأسبوع: 6

---

## 🎯 الأهداف

- إنشاء المصفوفات والتعامل معها
- كتابة دوال تعمل على المصفوفات
- الخوارزميات الأساسية

---

## التمارين

### تمرين 1: عمليات المصفوفات (20 نقاط)

أنشئ الدوال التالية:
- `مجموع(قائمة)` — مجموع العناصر
- `متوسط(قائمة)` — المتوسط الحسابي
- `أكبر(قائمة)` — أكبر عنصر
- `أصغر(قائمة)` — أصغر عنصر

---

### تمرين 2: البحث (15 نقاط)

أنشئ دالة `بحث(قائمة، قيمة)` تُرجع فهرس العنصر أو -1 إذا لم يُوجد.

---

### تمرين 3: العكس (15 نقاط)

أنشئ دالة `عكس(قائمة)` تُرجع القائمة معكوسة.

---

### تمرين 4: إزالة التكرارات (20 نقاط)

أنشئ دالة `فريدة(قائمة)` تُرجع القائمة بدون عناصر مكررة.

---

### تمرين 5: الترتيب (30 نقاط)

أنشئ دالة `رتّب(قائمة)` ترتب القائمة تصاعدياً.

# البحث

دالة بحث(قائمة، قيمة)
    متغير فهرس = 0
    لكل عنصر في قائمة
        إذا (عنصر == قيمة)
            ارجع فهرس
        نهاية
        فهرس = فهرس + 1
    نهاية
    ارجع -1  # غير موجود
نهاية

# البحث مع إرجاع كل الفهارس
دالة بحث_الكل(قائمة، قيمة)
    متغير نتائج = []
    متغير فهرس = 0
    
    لكل عنصر في قائمة
        إذا (عنصر == قيمة)
            أضف(نتائج، فهرس)
        نهاية
        فهرس = فهرس + 1
    نهاية
    
    ارجع نتائج
نهاية

# اختبار
متغير أرقام = [1، 5، 3، 5، 2، 5]
اطبع_سطر("بحث عن 5: " + بحث(أرقام، 5))     # 1
اطبع_سطر("بحث عن 10: " + بحث(أرقام، 10))   # -1

دالة عكس(قائمة)
    متغير نتيجة = []
    متغير ف = طول(قائمة) - 1

# الترتيب (Bubble Sort)

دالة رتّب(قائمة)
    متغير ن = طول(قائمة)
    متغير ف1 = 0
    
    بينما (ف1 < ن)
        متغير ف2 = 0
        بينما (ف2 < ن - ف1 - 1)
            إذا (قائمة[ف2] > قائمة[ف2 + 1])
                # تبديل
                متغير مؤقت = قائمة[ف2]
                قائمة[ف2] = قائمة[ف2 + 1]
                قائمة[ف2 + 1] = مؤقت
            نهاية
            ف2 = ف2 + 1
        نهاية
        ف1 = ف1 + 1
    نهاية
    
    ارجع قائمة
نهاية

# اختبار

اطبع("قبل الترتيب: ")
لكل ر في أرقام
    اطبع(ر + " ")
نهاية
