## 📖 مقدمة

عناوين IP هي "عناوين منازل" الإنترنت. بدونها، لا يمكن لأي جهازين التواصل. في هذا الدليل، سنفهم IPv4 و IPv6 بعمق، متى نستخدم كل منهما، وكيف نتعامل معهما في لغة ص.

---

## 🔢 IPv4 (Internet Protocol version 4)

### ما هو IPv4؟

IPv4 هو النظام الأقدم والأكثر انتشاراً. تم إطلاقه في 1981 ولا يزال يسيطر على معظم الإنترنت.

**مثال عنوان IPv4:**
```
192.168.1.100
```

### بنية العنوان

عنوان IPv4 مكون من **4 أرقام** مفصولة بنقاط، كل رقم بين `0` و `255`:

```
192  .  168  .  1  .  100
└─┬─┘   └─┬─┘  └┬┘  └─┬─┘
  أوكتت   أوكتت  أوكتت  أوكتت
 (8 بت)  (8 بت) (8 بت) (8 بت)

الإجمالي: 32 بت = 4 بايت
```

### عدد العناوين المتاحة

$2^{32} = 4,294,967,296$ عنوان (حوالي 4.3 مليار)

**المشكلة:** هذا العدد نفذ! في 2011، نفذت عناوين IPv4 المتاحة. لهذا نحتاج IPv6.

### أنواع عناوين IPv4

**1. عناوين خاصة (Private) - للشبكات المحلية**
```
10.0.0.0 - 10.255.255.255        (16 مليون عنوان)
172.16.0.0 - 172.31.255.255      (1 مليون عنوان)
192.168.0.0 - 192.168.255.255    (65,536 عنوان)
```
- لا تعمل على الإنترنت العام
- تستخدم داخل الشبكات المنزلية والشركات
- تُترجم لعنوان عام عبر NAT

**2. عناوين عامة (Public)**
أي عنوان آخر غير المحجوزات. هذه تعمل على الإنترنت.

**3. عناوين خاصة مشهورة**
```
127.0.0.1        - localhost (جهازك نفسه)
127.0.0.0/8      - كل شبكة loopback
0.0.0.0          - عنوان "أي" (للاستماع على كل الواجهات)
255.255.255.255  - broadcast (للإرسال للجميع)
```

### أمثلة في لغة ص

```sad
استخدم شبكة

دالة رئيسية() {
    // الاتصال بـ localhost
    عميل1 = شبكة.اتصل_tcp("127.0.0.1", 8080)
    
    // الاتصال بجهاز آخر على الشبكة المحلية
    عميل2 = شبكة.اتصل_tcp("192.168.1.100", 8080)
    
    // الاتصال بخادم على الإنترنت
    عميل3 = شبكة.اتصل_tcp("93.184.216.34", 80)  // example.com
    
    // خادم يستمع على كل الواجهات
    خادم = شبكة.انشئ_خادم_tcp(8080)
    // يستمع على 0.0.0.0:8080 تلقائياً
}
```

### التحقق من صحة عنوان IPv4

```sad
دالة هو_ipv4_صالح(عنوان: نص) -> منطقي {
    أجزاء = عنوان.قسم(".")
    
    // يجب أن يكون 4 أجزاء
    إذا أجزاء.طول() != 4 {
        ارجع خطأ
    }
    
    // كل جزء يجب أن يكون رقماً بين 0 و 255
    لكل جزء في أجزاء {
        محاولة {
            رقم = نص.الى_رقم_صحيح(جزء)
            
            إذا رقم < 0 أو رقم > 255 {
                ارجع خطأ
            }
        } اصطياد {
            ارجع خطأ  // ليس رقماً
        }
    }
    
    ارجع صحيح
}

// أمثلة
اطبع(هو_ipv4_صالح("192.168.1.1"))      // صحيح
اطبع(هو_ipv4_صالح("256.1.1.1"))       // خطأ (256 أكبر من 255)
اطبع(هو_ipv4_صالح("192.168.1"))       // خطأ (3 أجزاء فقط)
اطبع(هو_ipv4_صالح("192.168.1.abc"))   // خطأ (ليس رقماً)
```

## 🌍 IPv6 (Internet Protocol version 6)

### ما هو IPv6؟

IPv6 هو الجيل الجديد من عناوين IP، صُمم لحل مشكلة نفاد IPv4. تم إطلاقه في 1998 لكن انتشاره لا يزال بطيئاً.

**مثال عنوان IPv6:**
```
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

### بنية العنوان

عنوان IPv6 مكون من **8 مجموعات** من 4 أرقام سداسية عشرية:

```
2001:0db8:85a3:0000:0000:8a2e:0370:7334
└──┬──┘└──┬──┘└──┬──┘└──┬──┘└──┬──┘└──┬──┘└──┬──┘└──┬──┘
  16 بت  16 بت  16 بت  16 بت  16 بت  16 بت  16 بت  16 بت

الإجمالي: 128 بت = 16 بايت
```

### عدد العناوين المتاحة

$2^{128} = 340,282,366,920,938,463,463,374,607,431,768,211,456$

أي حوالي **340 أُندَسِيلْيُون** عنوان! كافٍ لإعطاء كل ذرة على الأرض عنوان IP!

### اختصارات الكتابة

IPv6 يسمح باختصارات لتسهيل الكتابة:

**1. حذف الأصفار البادئة**
```
// كامل
2001:0db8:0000:0042:0000:8a2e:0370:7334

// مختصر
2001:db8:0:42:0:8a2e:370:7334
```

**2. استبدال مجموعات أصفار متتالية بـ `::`**
```
// كامل
2001:0db8:0000:0000:0000:0000:0000:0001

// مختصر
2001:db8::1

// ملاحظة: يمكن استخدام :: مرة واحدة فقط!
```

**3. أمثلة شائعة**
```
::1                  - localhost (مثل 127.0.0.1 في IPv4)
::                   - عنوان "أي" (مثل 0.0.0.0 في IPv4)
2001:db8::1          - عنوان مثالي (للتوثيق)
fe80::1              - link-local (للشبكة المحلية)
```

### كتابة IPv6 مع منافذ

في IPv4، نكتب: `192.168.1.1:8080`

في IPv6، نحتاج أقواس مربعة لتمييز العنوان عن المنفذ:
```
[2001:db8::1]:8080
```

**أمثلة في لغة ص:**
```sad
استخدم شبكة

دالة رئيسية() {
    // الاتصال بـ IPv6 localhost
    عميل1 = شبكة.اتصل_tcp("[::1]", 8080)
    // أو
    عميل2 = شبكة.اتصل_tcp("::1", 8080)
    
    // عنوان IPv6 كامل
    عميل3 = شبكة.اتصل_tcp("[2001:db8::1]", 8080)
    
    // خادم IPv6
    خادم = شبكة.انشئ_خادم_tcp_ipv6(8080)
}
```

### أنواع عناوين IPv6

**1. Global Unicast (2000::/3)**
عناوين عامة على الإنترنت، مثل IPv4 العامة.

**2. Link-Local (fe80::/10)**
للاتصال داخل نفس الشبكة المحلية فقط.

**3. Unique Local (fc00::/7)**
مثل عناوين IPv4 الخاصة (192.168.x.x)، للشبكات الخاصة.

**4. Multicast (ff00::/8)**
للبث الجماعي.

**5. خاصة مشهورة**
```
::1            - localhost
::             - عنوان غير محدد
::ffff:0:0/96  - IPv4-mapped (لاستخدام IPv4 فوق IPv6)
```

## 🔀 Dual Stack: استخدام IPv4 و IPv6 معاً

### ما هو Dual Stack؟

تطبيق يدعم IPv4 و IPv6 في نفس الوقت. هذا هو الأمثل حالياً حيث IPv6 لم ينتشر بالكامل.

### كيف نبني خادم Dual Stack؟

```sad
استخدم شبكة
استخدم خيط

دالة رئيسية() {
    اطبع("🌐 خادم Dual Stack")
    اطبع("═══════════════════════════")
    
    // خادم IPv4
    خادم_ipv4 = شبكة.انشئ_خادم_tcp(8080)
    اطبع("✅ IPv4 يستمع على 0.0.0.0:8080")
    
    // خادم IPv6
    خادم_ipv6 = شبكة.انشئ_خادم_tcp_ipv6(8080)
    اطبع("✅ IPv6 يستمع على [::]:8080")
    
    // بدء خيط لكل خادم
    خيط.ابدأ(عالج_خادم_ipv4، [خادم_ipv4])
    خيط.ابدأ(عالج_خادم_ipv6، [خادم_ipv6])
    
    اطبع("⏳ في انتظار اتصالات...")
    
    // الانتظار للأبد
    بينما صحيح {
        نم(1000)
    }
}

دالة عالج_خادم_ipv4(خادم) {
    بينما صحيح {
        عميل = خادم.اقبل()
        اطبع("🔗 IPv4: " + عميل.عنوان_البعيد())
        // معالجة العميل...
        عميل.اغلق()
    }
}

دالة عالج_خادم_ipv6(خادم) {
    بينما صحيح {
        عميل = خادم.اقبل()
        اطبع("🔗 IPv6: " + عميل.عنوان_البعيد())
        // معالجة العميل...
        عميل.اغلق()
    }
}
```

### عميل ذكي يحاول كلا النوعين

```sad
دالة اتصل_ذكي(مضيف: نص، منفذ: رقم) {
    // محاولة IPv6 أولاً (المستقبل)
    محاولة {
        اطبع("🔄 أحاول IPv6...")
        عميل = شبكة.اتصل_tcp_ipv6(مضيف، منفذ)
        اطبع("✅ اتصال IPv6 نجح!")
        ارجع عميل
    } اصطياد (خطأ) {
        اطبع("⚠️ IPv6 فشل، أحاول IPv4...")
    }
    
    // التراجع لـ IPv4
    محاولة {
        عميل = شبكة.اتصل_tcp(مضيف، منفذ)
        اطبع("✅ اتصال IPv4 نجح!")
        ارجع عميل
    } اصطياد (خطأ) {
        اطبع("❌ فشل الاتصال بكلا البروتوكولين!")
        ارجع باطل
    }
}

// الاستخدام
عميل = اتصل_ذكي("example.com", 80)
```

## 🔍 اكتشاف نوع العنوان

```sad
دالة نوع_العنوان(عنوان: نص) -> نص {
    // التحقق من IPv4
    إذا عنوان.يحتوي_على(".") {
        أجزاء = عنوان.قسم(".")
        إذا أجزاء.طول() == 4 {
            ارجع "IPv4"
        }
    }
    
    // التحقق من IPv6
    إذا عنوان.يحتوي_على(":") {
        ارجع "IPv6"
    }
    
    // ربما اسم نطاق
    ارجع "اسم_نطاق"
}

// أمثلة
اطبع(نوع_العنوان("192.168.1.1"))       // IPv4
اطبع(نوع_العنوان("2001:db8::1"))      // IPv6
اطبع(نوع_العنوان("example.com"))      // اسم_نطاق
```

## 📊 مقارنة IPv4 vs IPv6

| الخاصية | IPv4 | IPv6 |
|---------|------|------|
| **طول العنوان** | 32 بت (4 بايت) | 128 بت (16 بايت) |
| **الصيغة** | عشري منقّط | سداسي عشري مع نقطتين |
| **مثال** | 192.168.1.1 | 2001:db8::1 |
| **عدد العناوين** | ~4.3 مليار | ~340 أُندَسِيلْيُون |
| **الحالة** | نفذت العناوين | متوفر بكثرة |
| **NAT** | ضروري عملياً | اختياري |
| **Broadcast** | مدعوم | لا (يُستخدم multicast) |
| **الأمان** | IPsec اختياري | IPsec مدمج |
| **الانتشار** | ~95% من الإنترنت | ~35% من الإنترنت |

## 💡 أفضل الممارسات

### 1. ادعم كلا البروتوكولين

```sad
// ✅ جيد - يعمل مع IPv4 و IPv6
عميل = شبكة.اتصل_tcp(عنوان، منفذ)
// المكتبة تكتشف النوع تلقائياً
```

### 2. استخدم أسماء النطاقات عندما ممكن

```sad
// ✅ أفضل
عميل = شبكة.اتصل_tcp("example.com", 80)
// DNS سيعيد IPv4 أو IPv6 حسب ما هو متاح

// ❌ أقل مرونة
عميل = شبكة.اتصل_tcp("93.184.216.34", 80)
```

### 3. لا تفترض صيغة العنوان

```sad
// ❌ سيء - يفترض IPv4
أجزاء = عنوان.قسم(".")
ip_أول = أجزاء[0]

// ✅ جيد - يعمل مع كلاهما
عنوان_مقبس = شبكة.حلل_عنوان(عنوان)
نوع = عنوان_مقبس.هو_ipv4() ? "IPv4" : "IPv6"
```

### 4. استخدم أقواس في IPv6 مع المنافذ

```sad
// ✅ صحيح
"[2001:db8::1]:8080"

// ❌ خطأ (غامض)
"2001:db8::1:8080"
```

## 🎓 خلاصة

- **IPv4**: النظام القديم، 32 بت، نفذت عناوينه، لكن لا يزال الأكثر انتشاراً
- **IPv6**: النظام الجديد، 128 بت، عناوين غير محدودة عملياً، المستقبل
- **Dual Stack**: ادعم كلاهما للتوافق الأقصى
- **لغة ص**: تدعم كلا البروتوكولين تلقائياً ✅
