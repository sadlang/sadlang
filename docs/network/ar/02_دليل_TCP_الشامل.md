## 📖 مقدمة

بروتوكول TCP (Transmission Control Protocol) هو العمود الفقري للإنترنت الحديث. كل مرة تفتح فيها موقعاً إلكترونياً، ترسل بريداً إلكترونياً، تحمل ملفاً، أو تشاهد فيديو على YouTube، أنت تستخدم TCP. في هذا الدليل الشامل، سنتعلم كل شيء عن TCP من الأساسيات إلى التقنيات المتقدمة، مع أمثلة عملية كثيرة في لغة ص.

TCP هو بروتوكول موثوق يضمن وصول بياناتك كاملة وبالترتيب الصحيح. هذا يجعله الخيار المثالي لأي تطبيق يحتاج لنقل بيانات دقيقة. لكن TCP ليس مجرد "أرسل واستقبل" - إنه نظام معقد مليء بالتفاصيل التي تجعله قوياً وفعالاً. سنستكشف هذه التفاصيل معاً خطوة بخطوة.

## 🏗️ كيف يعمل TCP: الأساسيات التقنية

### عملية المصافحة الثلاثية (Three-Way Handshake)

قبل أن يرسل TCP أي بيانات حقيقية، يقوم بعملية ذكية اسمها "المصافحة الثلاثية". فكر فيها كتحية مهذبة قبل بدء المحادثة:

**الخطوة 1 - SYN:** العميل يرسل رسالة SYN (Synchronize) للخادم يقول فيها: "مرحباً، أريد الاتصال بك. هذا هو رقم التسلسل الخاص بي."

**الخطوة 2 - SYN-ACK:** الخادم يرد برسالة SYN-ACK (Synchronize-Acknowledge) يقول فيها: "مرحباً بك! استلمت رسالتك. هذا هو رقم التسلسل الخاص بي."

**الخطوة 3 - ACK:** العميل يرد برسالة ACK (Acknowledge) يقول فيها: "ممتاز! استلمت ردك. لنبدأ الآن!"

بعد هذه المصافحة، يصبح الاتصال "مُنشأً" (Established) ويمكن إرسال البيانات الحقيقية. هذه العملية تحدث تلقائياً عند استدعاء `اتصل()` في العميل و `اقبل()` في الخادم - لغة ص تتولى كل التفاصيل!

### أرقام التسلسل والتأكيد

TCP يرقّم كل بايت يرسله. تخيل أنك ترسل كتاباً صفحة بصفحة، وكل صفحة عليها رقم. المستقبل يستخدم هذه الأرقام للتأكد من:
1. وصول كل الصفحات
2. ترتيب الصفحات بشكل صحيح
3. عدم تكرار أي صفحة

عندما يستقبل طرف البيانات، يرسل رسالة ACK (Acknowledgment) يقول فيها: "استلمت حتى الصفحة رقم X". إذا لم يصل ACK في وقت معقول، المُرسل يعيد إرسال البيانات تلقائياً.

### التحكم في التدفق (Flow Control)

TCP ذكي جداً في إدارة سرعة الإرسال. المستقبل يخبر المُرسل بحجم "نافذته" (Window Size) - كم بايت يمكنه استقبالها دون انتظار. إذا كانت النافذة صغيرة (المستقبل مشغول)، المُرسل يبطئ. إذا كانت كبيرة، يسرّع.

### التحكم في الازدحام (Congestion Control)

TCP أيضاً يراقب حالة الشبكة نفسها. إذا اكتشف ازدحاماً (حزم تُفقد بسبب امتلاء الموجهات)، يقلل سرعة الإرسال تدريجياً. عندما تتحسن الأمور، يزيد السرعة مرة أخرى. هذا السلوك يجعل الإنترنت يعمل بسلاسة حتى مع ملايين الاتصالات المتزامنة!

## 💻 بناء خادم TCP في لغة ص

### الخادم البسيط: الأساسيات

لنبدأ ببناء خادم TCP بسيط خطوة بخطوة. سنشرح كل سطر بالتفصيل:

```sad
استخدم شبكة

دالة رئيسية() {
    // 1. إنشاء خادم TCP
    // نحدد المنفذ 8080 - يمكنك استخدام أي منفذ من 1024 إلى 65535
    خادم = شبكة.انشئ_خادم_tcp(8080)
    
    // 2. التحقق من نجاح الإنشاء
    إذا خادم == باطل {
        اطبع("❌ خطأ: لم أستطع إنشاء الخادم!")
        اطبع("الأسباب المحتملة:")
        اطبع("  - المنفذ 8080 مستخدم من برنامج آخر")
        اطبع("  - ليس لديك صلاحيات (استخدم منفذ أكبر من 1024)")
        ارجع 1
    }
    
    اطبع("✅ الخادم يعمل على المنفذ 8080")
    اطبع("في انتظار اتصالات...")
    
    // 3. قبول اتصال عميل واحد
    عميل = خادم.اقبل()
    // خادم.اقبل() يتوقف هنا حتى يتصل عميل!
    // هذا يسمى "Blocking Call" - ننتظر حتى يحدث شيء
    
    اطبع("✅ عميل اتصل من: " + عميل.عنوان_البعيد())
    
    // 4. استقبال بيانات من العميل
    // نطلب استقبال حتى 1024 بايت
    بيانات = عميل.استقبل(1024)
    اطبع("📨 استقبلت " + بيانات.طول() + " بايت")
    
    // 5. إرسال رد للعميل
    رد = "شكراً! استلمت رسالتك"
    عميل.ارسل_الكل(رد)
    
    // 6. إغلاق الاتصال بشكل لطيف
    عميل.اغلق()
    خادم.اغلق()
    
    اطبع("✅ تم إغلاق الخادم")
}
```

هذا خادم بسيط لكنه يوضح المفاهيم الأساسية. لكن خادم حقيقي يحتاج لخدمة عملاء متعددين في نفس الوقت!

### خادم متعدد العملاء (Multi-Client Server)

الخادم الحقيقي يجب أن يخدم عدة عملاء في نفس الوقت. هناك طريقتان رئيسيتان لتحقيق هذا:

**الطريقة 1: خادم متسلسل (Sequential Server)**
يخدم عميلاً واحداً في كل مرة، ينتهي منه، ثم ينتقل للتالي:

```sad
استخدم شبكة
استخدم نص

دالة رئيسية() {
    خادم = شبكة.انشئ_خادم_tcp(8080)
    اطبع("🚀 خادم متعدد العملاء يعمل...")
    
    عدد_العملاء = 0
    
    // حلقة لا نهائية لقبول عملاء متعددين
    بينما صحيح {
        اطبع("\n⏳ في انتظار عميل جديد...")
        
        عميل = خادم.اقبل()
        عدد_العملاء = عدد_العملاء + 1
        
        اطبع("✅ عميل #" + عدد_العملاء + " اتصل!")
        اطبع("   العنوان: " + عميل.عنوان_البعيد())
        
        // معالجة طلبات هذا العميل
        عالج_عميل(عميل، عدد_العملاء)
        
        اطبع("👋 عميل #" + عدد_العملاء + " غادر")
    }
}

دالة عالج_عميل(عميل، رقم_العميل) {
    بينما صحيح {
        // استقبال بيانات
        بيانات = عميل.استقبل(4096)
        
        // إذا كانت فارغة، العميل قطع الاتصال
        إذا بيانات.طول() == 0 {
            اكسر
        }
        
        // تحويل من بايتات إلى نص
        رسالة = نص.من_بايتات(بيانات)
        اطبع("📨 عميل #" + رقم_العميل + ": " + رسالة)
        
        // إرسال رد
        رد = "خادم → عميل #" + رقم_العميل + ": استلمت '" + رسالة + "'"
        عميل.ارسل_الكل(نص.الى_بايتات(رد))
    }
    
    عميل.اغلق()
}
```

هذا الخادم يخدم عملاء متعددين، لكن واحداً تلو الآخر. إذا كان عميل واحد بطيئاً، العملاء الآخرون ينتظرون. للتطبيقات البسيطة، هذا كافٍ تماماً!

**الطريقة 2: خادم متوازي (Concurrent Server)**
في التطبيقات المتقدمة، تريد خدمة جميع العملاء في نفس الوقت. هذا يتطلب استخدام خيوط (Threads) أو عمليات غير متزامنة (Async/Await). سنغطي هذا في دليل متقدم لاحقاً.

## 📱 بناء عميل TCP في لغة ص

### العميل البسيط

بناء عميل TCP أبسط من بناء خادم:

```sad
استخدم شبكة
استخدم نص

دالة رئيسية() {
    اطبع("🔌 جاري الاتصال بالخادم...")
    
    // الاتصال بخادم على نفس الجهاز (127.0.0.1) منفذ 8080
    عميل = شبكة.اتصل_tcp("127.0.0.1", 8080)
    
    إذا عميل == باطل {
        اطبع("❌ فشل الاتصال!")
        اطبع("تأكد من:")
        اطبع("  - الخادم يعمل")
        اطبع("  - العنوان والمنفذ صحيحان")
        اطبع("  - لا يوجد جدار ناري يمنع الاتصال")
        ارجع 1
    }
    
    اطبع("✅ تم الاتصال بنجاح!")
    اطبع("   عنوان الخادم: " + عميل.عنوان_البعيد())
    اطبع("   عنوانك المحلي: " + عميل.عنوان_المحلي())
    
    // إرسال رسالة
    رسالة = "مرحباً من العميل!"
    عميل.ارسل_الكل(نص.الى_بايتات(رسالة))
    اطبع("📤 أرسلت: " + رسالة)
    
    // استقبال رد
    رد_بايتات = عميل.استقبل(1024)
    رد = نص.من_بايتات(رد_بايتات)
    اطبع("📨 الخادم رد: " + رد)
    
    // إغلاق الاتصال
    عميل.اغلق()
    اطبع("✅ تم قطع الاتصال")
}
```

### عميل تفاعلي (Interactive Client)

لنبني عميلاً تفاعلياً يسمح للمستخدم بإرسال رسائل متعددة:

```sad
استخدم شبكة
استخدم نص
استخدم إدخال_إخراج

دالة رئيسية() {
    // الاتصال بالخادم
    عميل = شبكة.اتصل_tcp("127.0.0.1", 8080)
    
    إذا عميل == باطل {
        اطبع("❌ فشل الاتصال بالخادم")
        ارجع 1
    }
    
    اطبع("✅ متصل بالخادم!")
    اطبع("\nأوامر متاحة:")
    اطبع("  - اكتب رسالة واضغط Enter لإرسالها")
    اطبع("  - اكتب 'خروج' للإنهاء")
    اطبع("  - اكتب 'معلومات' لعرض معلومات الاتصال")
    اطبع("")
    
    بينما صحيح {
        // قراءة أمر من المستخدم
        اطبع("> ", نهاية="")
        أمر = إدخال_إخراج.اقرأ_سطر()
        
        // معالجة الأوامر الخاصة
        إذا أمر == "خروج" {
            اطبع("👋 إنهاء الاتصال...")
            اكسر
        }
        
        إذا أمر == "معلومات" {
            اطبع("ℹ️  معلومات الاتصال:")
            اطبع("  - عنوان الخادم: " + عميل.عنوان_البعيد())
            اطبع("  - عنوانك: " + عميل.عنوان_المحلي())
            استمر
        }
        
        إذا أمر.طول() == 0 {
            استمر  // تجاهل الأسطر الفارغة
        }
        
        // إرسال الرسالة
        عميل.ارسل_الكل(نص.الى_بايتات(أمر))
        
        // استقبال الرد
        رد_بايتات = عميل.استقبل(4096)
        
        إذا رد_بايتات.طول() == 0 {
            اطبع("❌ الخادم قطع الاتصال")
            اكسر
        }
        
        رد = نص.من_بايتات(رد_بايتات)
        اطبع("← " + رد)
        اطبع("")
    }
    
    عميل.اغلق()
    اطبع("✅ تم قطع الاتصال بنجاح")
}
```

## ⚙️ خيارات TCP المتقدمة

### TCP_NODELAY: تعطيل خوارزمية Nagle

خوارزمية Nagle هي تحسين في TCP يجمع الحزم الصغيرة معاً قبل الإرسال. هذا يقلل عدد الحزم لكنه يضيف تأخيراً صغيراً (حتى 200ms). للتطبيقات الحساسة للوقت (ألعاب، أنظمة تداول)، تريد تعطيل هذا:

```sad
استخدم شبكة

دالة رئيسية() {
    عميل = شبكة.اتصل_tcp("localhost", 8080)
    
    // تعطيل Nagle's Algorithm للحصول على أقل تأخير
    عميل.عين_بدون_تأخير(صحيح)
    
    // الآن الرسائل ترسل فوراً دون انتظار!
    عميل.ارسل("بيانات حساسة للوقت")
}
```

**متى تستخدم TCP_NODELAY:**
- ✅ ألعاب أونلاين (كل ميلي ثانية مهمة)
- ✅ أنظمة التداول المالي
- ✅ تطبيقات التحكم عن بعد
- ✅ بروتوكولات الدردشة الفورية

**متى لا تستخدمه:**
- ❌ نقل ملفات كبيرة (الإنتاجية أهم من التأخير)
- ❌ البث المباشر (يُفضل UDP)
- ❌ عمليات Batch (التجميع مفيد)

### SO_KEEPALIVE: الحفاظ على الاتصال حياً

في بعض الأحيان، تريد معرفة إذا كان الطرف الآخر لا يزال متصلاً حتى لو لم ترسل بيانات. SO_KEEPALIVE يرسل "رسائل قلب" (heartbeat) تلقائياً:

```sad
استخدم شبكة

دالة رئيسية() {
    خادم = شبكة.انشئ_خادم_tcp(8080)
    عميل = خادم.اقبل()
    
    // تفعيل Keep-Alive
    عميل.عين_حافظ_على_الحياة(صحيح)
    
    // الآن TCP سيرسل رسائل keep-alive تلقائياً
    // إذا لم يرد الطرف الآخر بعد عدة محاولات، الاتصال يُعتبر مقطوعاً
    
    // يمكنك الانتظار لوقت طويل دون قلق
    بينما صحيح {
        بيانات = عميل.استقبل(1024)
        إذا بيانات.طول() == 0 {
            اطبع("العميل انقطع")
            اكسر
        }
        // معالجة البيانات...
    }
}
```

### SO_REUSEADDR: إعادة استخدام العنوان فوراً

عند إغلاق خادم TCP وإعادة تشغيله مباشرة، قد تواجه خطأ "العنوان قيد الاستخدام". SO_REUSEADDR يحل هذه المشكلة:

```sad
استخدم شبكة

دالة رئيسية() {
    خادم = شبكة.انشئ_خادم_tcp(8080)
    
    // السماح بإعادة استخدام المنفذ فوراً بعد الإغلاق
    خادم.عين_اعادة_استخدام_العنوان(صحيح)
    
    // الآن يمكنك إيقاف الخادم وإعادة تشغيله فوراً دون انتظار!
}
```

### مهلات الإرسال والاستقبال (Timeouts)

بدون مهلات، برنامجك قد "يتجمد" إلى الأبد في انتظار بيانات قد لا تصل أبداً:

```sad
استخدم شبكة

دالة رئيسية() {
    عميل = شبكة.اتصل_tcp("خادم_بطيء.com", 8080)
    
    // تعيين مهلة استقبال: 5 ثوانٍ
    عميل.عين_مهلة_الاستقبال(5000)  // بالميلي ثانية
    
    // تعيين مهلة إرسال: 3 ثوانٍ
    عميل.عين_مهلة_الإرسال(3000)
    
    محاولة {
        بيانات = عميل.استقبل(1024)
        // إذا لم تصل بيانات خلال 5 ثوانٍ، سيحدث استثناء
    } اصطياد (خطأ) {
        اطبع("❌ انتهت المهلة! الخادم بطيء جداً")
    }
}
```

### أحجام المخازن المؤقتة (Buffer Sizes)

TCP يستخدم مخازن مؤقتة (buffers) للإرسال والاستقبال. يمكنك ضبط أحجامها:

```sad
استخدم شبكة

دالة رئيسية() {
    خادم = شبكة.انشئ_خادم_tcp(8080)
    
    // زيادة حجم مخزن الاستقبال إلى 256KB
    خادم.عين_حجم_مخزن_الاستقبال(256 * 1024)
    
    // زيادة حجم مخزن الإرسال إلى 256KB
    خادم.عين_حجم_مخزن_الإرسال(256 * 1024)
    
    // مفيد عند نقل ملفات كبيرة أو عبر شبكات عالية السرعة
}
```

## 🎯 أمثلة عملية متقدمة

### مثال 1: خادم نقل ملفات

خادم بسيط يستقبل ملفات من العملاء:

```sad
استخدم شبكة
استخدم ملف
استخدم نص

دالة رئيسية() {
    خادم = شبكة.انشئ_خادم_tcp(9000)
    خادم.عين_اعادة_استخدام_العنوان(صحيح)
    
    اطبع("📁 خادم نقل الملفات يعمل على المنفذ 9000")
    
    بينما صحيح {
        عميل = خادم.اقبل()
        اطبع("\n✅ عميل جديد من: " + عميل.عنوان_البعيد())
        
        محاولة {
            // 1. استقبال اسم الملف (أول 256 بايت)
            اسم_ملف_بايتات = عميل.استقبل_الكل(256)
            اسم_الملف = نص.من_بايتات(اسم_ملف_بايتات).قص()
            
            اطبع("📝 اسم الملف: " + اسم_الملف)
            
            // 2. استقبال حجم الملف (8 بايتات، رقم صحيح كبير)
            حجم_بايتات = عميل.استقبل_الكل(8)
            حجم_الملف = نص.الى_رقم_صحيح(نص.من_بايتات(حجم_بايتات))
            
            اطبع("📊 حجم الملف: " + حجم_الملف + " بايت")
            
            // 3. استقبال محتوى الملف
            ملف_خرج = ملف.افتح("uploads/" + اسم_الملف، "wb")
            
            مستقبل = 0
            بينما مستقبل < حجم_الملف {
                // استقبال على دفعات 64KB
                حجم_الدفعة = اصغر(65536، حجم_الملف - مستقبل)
                دفعة = عميل.استقبل_الكل(حجم_الدفعة)
                
                ملف_خرج.اكتب(دفعة)
                مستقبل = مستقبل + دفعة.طول()
                
                // عرض التقدم
                نسبة = (مستقبل * 100) / حجم_الملف
                اطبع("📥 " + نسبة + "% (" + مستقبل + "/" + حجم_الملف + " بايت)", نهاية="\r")
            }
            
            ملف_خرج.اغلق()
            اطبع("\n✅ تم استقبال الملف بنجاح!")
            
            // إرسال تأكيد للعميل
            عميل.ارسل_الكل("نجح")
            
        } اصطياد (خطأ) {
            اطبع("❌ خطأ أثناء استقبال الملف: " + خطأ.رسالة())
            عميل.ارسل_الكل("فشل")
        }
        
        عميل.اغلق()
    }
}

دالة اصغر(أ، ب) {
    إذا أ < ب {
        ارجع أ
    } وإلا {
        ارجع ب
    }
}
```

### مثال 2: عميل HTTP بسيط

بناء عميل HTTP من الصفر لفهم كيف تعمل طلبات الويب:

```sad
استخدم شبكة
استخدم نص

دالة اجلب_صفحة_ويب(مضيف، مسار) {
    اطبع("🌐 جاري الاتصال بـ " + مضيف + "...")
    
    // الاتصال بالخادم على المنفذ 80 (HTTP)
    عميل = شبكة.اتصل_tcp(مضيف، 80)
    
    إذا عميل == باطل {
        اطبع("❌ فشل الاتصال")
        ارجع باطل
    }
    
    // بناء طلب HTTP GET
    طلب = "GET " + مسار + " HTTP/1.1\r\n"
    طلب = طلب + "Host: " + مضيف + "\r\n"
    طلب = طلب + "User-Agent: Sad-Language/1.0\r\n"
    طلب = طلب + "Connection: close\r\n"
    طلب = طلب + "\r\n"
    
    اطبع("📤 إرسال طلب HTTP...")
    اطبع(طلب)
    
    // إرسال الطلب
    عميل.ارسل_الكل(نص.الى_بايتات(طلب))
    
    // استقبال الرد
    اطبع("\n📥 استقبال الرد...")
    رد_كامل = ""
    
    بينما صحيح {
        دفعة = عميل.استقبل(4096)
        
        إذا دفعة.طول() == 0 {
            اكسر  // الخادم أغلق الاتصال
        }
        
        رد_كامل = رد_كامل + نص.من_بايتات(دفعة)
    }
    
    عميل.اغلق()
    
    اطبع("✅ تم استقبال " + رد_كامل.طول() + " حرف")
    ارجع رد_كامل
}

دالة رئيسية() {
    رد = اجلب_صفحة_ويب("example.com", "/")
    
    إذا رد != باطل {
        اطبع("\n📄 محتوى الصفحة:")
        اطبع("═══════════════════════════════════")
        اطبع(رد)
    }
}
```

هذا المثال يوضح كيف تعمل طلبات HTTP على مستوى TCP الخام. في التطبيقات الحقيقية، ستستخدم مكتبة HTTP الجاهزة في لغة ص، لكن فهم الأساسيات مهم جداً!

## 🔧 أفضل الممارسات في TCP

### 1. دائماً استخدم مهلات (Timeouts)

```sad
// ❌ سيء: قد يتجمد إلى الأبد
بيانات = عميل.استقبل(1024)

// ✅ جيد: مهلة معقولة
عميل.عين_مهلة_الاستقبال(30000)  // 30 ثانية
محاولة {
    بيانات = عميل.استقبل(1024)
} اصطياد (مهلة_انتهت) {
    اطبع("الخادم بطيء جداً")
}
```

### 2. استخدم `ارسل_الكل()` لضمان إرسال كل البيانات

```sad
// ❌ سيء: قد لا ترسل كل البيانات
عميل.ارسل(بيانات_كبيرة)

// ✅ جيد: يضمن إرسال كل البيانات
عميل.ارسل_الكل(بيانات_كبيرة)
```

### 3. أغلق الاتصالات دائماً

```sad
// استخدم محاولة/نهائياً للتأكد من الإغلاق حتى عند الأخطاء
عميل = شبكة.اتصل_tcp("example.com", 80)

محاولة {
    // عمليات الشبكة...
    عميل.ارسل("بيانات")
} نهائياً {
    // سيُنفذ حتى لو حدث خطأ
    عميل.اغلق()
}
```

### 4. تعامل مع الأخطاء بشكل صحيح

```sad
محاولة {
    عميل = شبكة.اتصل_tcp("example.com", 80)
    // العمليات...
} اصطياد (خطأ_اتصال_رُفض) {
    اطبع("الخادم رفض الاتصال")
} اصطياد (خطأ_مهلة) {
    اطبع("انتهت مهلة الاتصال")
} اصطياد (خطأ_شبكة عام) {
    اطبع("خطأ عام: " + عام.رسالة())
}
```

### 5. استخدم مخازن مؤقتة مناسبة

```sad
// ❌ سيء: مخزن صغير جداً = استدعاءات كثيرة
بيانات = عميل.استقبل(16)  // 16 بايت فقط!

// ✅ جيد: حجم معقول
بيانات = عميل.استقبل(8192)  // 8KB - حجم جيد لمعظم التطبيقات

// 🎯 أفضل: حجم كبير لنقل ملفات
بيانات = عميل.استقبل(65536)  // 64KB - ممتاز للملفات الكبيرة
```

## 📊 قياس الأداء والتحسين

### قياس سرعة النقل

```sad
استخدم شبكة
استخدم وقت

دالة قياس_سرعة_نقل() {
    // إنشاء بيانات اختبار 10MB
    حجم_البيانات = 10 * 1024 * 1024  // 10 ميجابايت
    بيانات_اختبار = انشئ_بيانات_عشوائية(حجم_البيانات)
    
    عميل = شبكة.اتصل_tcp("localhost", 8080)
    
    // قياس الوقت
    وقت_البداية = وقت.الآن()
    
    عميل.ارسل_الكل(بيانات_اختبار)
    
    وقت_النهاية = وقت.الآن()
    
    // حساب السرعة
    مدة_ثوانٍ = (وقت_النهاية - وقت_البداية) / 1000.0
    سرعة_mb_ثانية = (حجم_البيانات / 1024.0 / 1024.0) / مدة_ثوانٍ
    
    اطبع("📊 إحصائيات النقل:")
    اطبع("   البيانات: " + حجم_البيانات + " بايت")
    اطبع("   المدة: " + مدة_ثوانٍ + " ثانية")
    اطبع("   السرعة: " + سرعة_mb_ثانية + " MB/s")
    
    عميل.اغلق()
}
```

## 🎓 خلاصة

في هذا الدليل الشامل، تعلمنا:

✅ كيف يعمل TCP داخلياً (المصافحة الثلاثية، أرقام التسلسل)

✅ خيارات TCP المتقدمة (TCP_NODELAY، Keep-Alive، إلخ)  
✅ أمثلة عملية (نقل ملفات، HTTP)  
✅ أفضل الممارسات والتحسين  

TCP هو بروتوكول قوي جداً، والآن أنت تمتلك الأدوات اللازمة لبناء تطبيقات شبكية موثوقة في لغة ص!
