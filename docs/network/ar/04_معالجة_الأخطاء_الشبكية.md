## 📖 مقدمة

في عالم الشبكات، الأخطاء ليست استثناءً - إنها القاعدة! الشبكات معقدة ومليئة بالمشاكل المحتملة: الاتصال قد ينقطع فجأة، الخوادم قد تكون مشغولة، الحزم قد تضيع، والمهلات قد تنتهي. التطبيق الشبكي الجيد ليس الذي لا يواجه أخطاء، بل الذي يتعامل معها بأناقة ويتعافى منها بذكاء.

في هذا الدليل الشامل، سنتعلم كل شيء عن معالجة الأخطاء الشبكية في لغة ص. سنستكشف أنواع الأخطاء المختلفة، كيفية اكتشافها، وأفضل الطرق للتعامل معها. سنبني تطبيقات مرنة تستمر في العمل حتى في أسوأ الظروف!

## 🎯 لماذا معالجة الأخطاء مهمة جداً؟

### الواقع القاسي للشبكات

تخيل أنك بنيت تطبيق دردشة رائعاً. المستخدم يكتب رسالة طويلة، يضغط "إرسال"، ثم... لا شيء يحدث. التطبيق "تجمد" ولا يستجيب. السبب؟ الشبكة انقطعت للحظة، وتطبيقك لم يكن مستعداً لهذا. المستخدم محبط، يغلق التطبيق، ويكتب مراجعة سلبية. كل هذا كان يمكن تجنبه بمعالجة أخطاء صحيحة!

الأخطاء الشبكية تحدث طوال الوقت:
- **في المنزل:** المستخدم يبتعد عن جهاز الواي فاي، الإشارة تضعف، الاتصال ينقطع
- **في القطار:** النفق يقطع إشارة الموبايل
- **في المقهى:** شبكة الواي فاي العامة مزدحمة وبطيئة
- **في المكتب:** قسم IT يعيد تشغيل الموجه (Router)
- **في السيرفر:** خادم قاعدة البيانات ممتلئ بالطلبات

كل هذه سيناريوهات حقيقية وشائعة جداً. تطبيقك يجب أن يكون جاهزاً لها جميعاً!

### عواقب معالجة الأخطاء السيئة

**فقدان البيانات:** مستخدم يملأ استمارة طويلة، يضغط "إرسال"، تحدث مشكلة شبكية، كل البيانات تختفي. المستخدم غاضب ولن يعيد المحاولة.

**تجربة مستخدم سيئة:** التطبيق "يتجمد" لدقائق في انتظار شبكة لن تستجيب. المستخدم يضطر لإغلاقه بالقوة.

**مشاكل أمنية:** أخطاء غير معالجة قد تكشف معلومات حساسة في رسائل الخطأ، أو تترك اتصالات مفتوحة، أو تسمح بهجمات.

**صعوبة الصيانة:** بدون معالجة أخطاء منظمة، من المستحيل معرفة ما الذي يحدث خطأ في الإنتاج. السجلات فوضوية، والمشاكل تتكرر بدون حل.

### فوائد معالجة الأخطاء الجيدة

**موثوقية:** التطبيق يستمر في العمل حتى في ظروف صعبة.

**تجربة مستخدم ممتازة:** رسائل خطأ واضحة ومفيدة، محاولات إعادة تلقائية، واستعادة تلقائية.

**سهولة الصيانة:** سجلات منظمة تسهل تتبع المشاكل وحلها.

**ثقة المستخدم:** عندما يثق المستخدم أن تطبيقك لن "يخذله"، سيستمر في استخدامه.

## 📋 أنواع الأخطاء الشبكية

لغة ص توفر نظام أخطاء شامل يغطي كل المشاكل الشبكية المحتملة. دعنا نستكشفها:

### 1. أخطاء الاتصال (Connection Errors)

#### ConnectionRefused (الاتصال مرفوض)

**السبب:** لا يوجد خادم يستمع على المنفذ المحدد.

**السيناريو الشائع:** حاولت الاتصال بخادم لم يُشغَّل بعد، أو أعطيت رقم منفذ خاطئ.

```sad
استخدم شبكة

دالة رئيسية() {
    محاولة {
        // محاولة الاتصال بمنفذ عشوائي (لا أحد يستمع هناك!)
        عميل = شبكة.اتصل_tcp("localhost", 12345)
    } اصطياد (خطأ_شبكة.اتصال_مرفوض خطأ) {
        اطبع("❌ الخادم لا يعمل على المنفذ 12345")
        اطبع("💡 نصيحة: تأكد من تشغيل الخادم أولاً")
        اطبع("   أو تحقق من رقم المنفذ الصحيح")
    }
}
```

**كيف نتعامل معه:**
```sad
دالة اتصل_مع_إعادة_محاولة(عنوان، منفذ، محاولات=3) {
    لـ ع من 1 إلى محاولات {
        محاولة {
            ارجع شبكة.اتصل_tcp(عنوان، منفذ)
        } اصطياد (خطأ_شبكة.اتصال_مرفوض) {
            إذا ع == محاولات {
                اطبع("❌ فشل الاتصال بعد " + محاولات + " محاولات")
                ارجع باطل
            }
            
            اطبع("⏳ المحاولة " + ع + " فشلت، أعيد بعد 2 ثانية...")
            نم(2000)
        }
    }
}
```

#### ConnectionReset (الاتصال قُطع)

**السبب:** الطرف الآخر أغلق الاتصال فجأة (crash أو قطع شبكة).

**السيناريو الشائع:** كنت تتواصل مع خادم، ثم انقطعت كهرباء الخادم أو حدث crash.

```sad
استخدم شبكة

دالة رئيسية() {
    عميل = شبكة.اتصل_tcp("server.com", 8080)
    
    محاولة {
        // أرسل بيانات
        عميل.ارسل_الكل("بيانات مهمة")
        
        // حاول استقبال رد
        رد = عميل.استقبل(1024)
        
    } اصطياد (خطأ_شبكة.اتصال_قُطع) {
        اطبع("⚠️ الخادم قطع الاتصال فجأة!")
        اطبع("💡 الأسباب المحتملة:")
        اطبع("   - الخادم crash")
        اطبع("   - الشبكة انقطعت")
        اطبع("   - الخادم أعيد تشغيله")
        
        // محاولة إعادة الاتصال
        محاولة_اعادة_الاتصال()
    }
}

دالة محاولة_اعادة_الاتصال() {
    اطبع("🔄 جاري إعادة الاتصال...")
    نم(3000)  // انتظار 3 ثوانٍ
    
    محاولة {
        عميل_جديد = شبكة.اتصل_tcp("server.com", 8080)
        اطبع("✅ تم إعادة الاتصال بنجاح!")
        ارجع عميل_جديد
    } اصطياد (خطأ) {
        اطبع("❌ فشلت إعادة الاتصال")
        ارجع باطل
    }
}
```

#### ConnectionTimedOut (انتهت مهلة الاتصال)

**السبب:** محاولة الاتصال استغرقت وقتاً طويلاً جداً.

**السيناريو الشائع:** الخادم بطيء جداً، أو جدار ناري يحجب الاتصال.

```sad
استخدم شبكة

دالة رئيسية() {
    محاولة {
        // محاولة الاتصال بخادم بطيء أو غير موجود
        عميل = شبكة.اتصل_tcp("very-slow-server.com", 80)
        
    } اصطياد (خطأ_شبكة.مهلة_انتهت) {
        اطبع("⏰ انتهت مهلة الاتصال!")
        اطبع("💡 الأسباب المحتملة:")
        اطبع("   - الخادم بطيء جداً")
        اطبع("   - الشبكة بطيئة")
        اطبع("   - جدار ناري يحجب الاتصال")
        اطبع("   - العنوان خاطئ")
    }
}
```

### 2. أخطاء الإرسال والاستقبال

#### SendFailed (فشل الإرسال)

**السبب:** لم يتمكن من إرسال البيانات.

```sad
استخدم شبكة

دالة ارسل_مع_معالجة_اخطاء(مقبس، بيانات) {
    محاولة {
        مقبس.ارسل_الكل(بيانات)
        ارجع صحيح
        
    } اصطياد (خطأ_شبكة.إرسال_فشل خطأ) {
        اطبع("❌ فشل إرسال البيانات")
        
        // محاولة إعادة الإرسال
        اطبع("🔄 أعيد المحاولة...")
        نم(1000)
        
        محاولة {
            مقبس.ارسل_الكل(بيانات)
            اطبع("✅ نجح الإرسال في المحاولة الثانية")
            ارجع صحيح
        } اصطياد (خطأ_ثاني) {
            اطبع("❌ فشل الإرسال نهائياً")
            اطبع("📝 تم حفظ البيانات محلياً للإرسال لاحقاً")
            حفظ_في_طابور_الإرسال(بيانات)
            ارجع خطأ
        }
    }
}
```

#### ReceiveFailed (فشل الاستقبال)

**السبب:** لم يتمكن من استقبال البيانات.

```sad
دالة استقبل_مع_معالجة_اخطاء(مقبس، حجم) {
    محاولة {
        ارجع مقبس.استقبل(حجم)
        
    } اصطياد (خطأ_شبكة.استقبال_فشل خطأ) {
        اطبع("❌ فشل استقبال البيانات: " + خطأ.رسالة())
        
        // التحقق من حالة الاتصال
        إذا !مقبس.متصل() {
            اطبع("⚠️ الاتصال مقطوع!")
            // محاولة إعادة الاتصال
        }
        
        ارجع باطل
    }
}
```

### 3. أخطاء المهلات (Timeout Errors)

المهلات ليست دائماً "أخطاء" بالمعنى التقليدي - أحياناً هي حماية ضرورية:

```sad
استخدم شبكة

دالة استقبل_مع_مهلة_ذكية(مقبس، مهلة_ms) {
    مقبس.عين_مهلة_الاستقبال(مهلة_ms)
    
    محاولة {
        بيانات = مقبس.استقبل(4096)
        ارجع (صحيح، بيانات)
        
    } اصطياد (خطأ_شبكة.مهلة_انتهت) {
        // ليست بالضرورة مشكلة - ربما لا توجد بيانات الآن
        ارجع (خطأ، باطل)
    }
}

// الاستخدام:
(نجح، بيانات) = استقبل_مع_مهلة_ذكية(مقبس، 5000)

إذا نجح {
    اطبع("✅ استقبلت بيانات: " + بيانات)
} وإلا {
    اطبع("ℹ️ لا توجد بيانات جديدة (هذا طبيعي)")
}
```

## 🛡️ استراتيجيات معالجة الأخطاء المتقدمة

### 1. إعادة المحاولة التلقائية مع Exponential Backoff

لا تعيد المحاولة فوراً - انتظر مدة متزايدة بين كل محاولة:

```sad
استخدم شبكة
استخدم رياضيات

صنف اعادة_محاولة_ذكية {
    محاولة_حالية: رقم
    محاولات_قصوى: رقم
    انتظار_اساسي: رقم  // بالميلي ثانية
    انتظار_اقصى: رقم
    
    دالة __init__(محاولات_قصوى=5، انتظار_اساسي=1000، انتظار_اقصى=60000) {
        هذا.محاولة_حالية = 0
        هذا.محاولات_قصوى = محاولات_قصوى
        هذا.انتظار_اساسي = انتظار_اساسي
        هذا.انتظار_اقصى = انتظار_اقصى
    }
    
    دالة احسب_انتظار() {
        // Exponential backoff: 1s, 2s, 4s, 8s, 16s, ...
        انتظار = هذا.انتظار_اساسي * رياضيات.قوة(2، هذا.محاولة_حالية)
        
        // لا نتجاوز الحد الأقصى
        إذا انتظار > هذا.انتظار_اقصى {
            انتظار = هذا.انتظار_اقصى
        }
        
        // إضافة عشوائية بسيطة (jitter) لتجنب thundering herd
        عشوائي = رياضيات.عشوائي() * 1000
        ارجع انتظار + عشوائي
    }
    
    دالة نفذ(دالة، معاملات=[]) {
        بينما هذا.محاولة_حالية < هذا.محاولات_قصوى {
            محاولة {
                // محاولة تنفيذ الدالة
                نتيجة = دالة(*معاملات)
                اطبع("✅ نجحت العملية في المحاولة " + (هذا.محاولة_حالية + 1))
                ارجع نتيجة
                
            } اصطياد (خطأ) {
                هذا.محاولة_حالية = هذا.محاولة_حالية + 1
                
                إذا هذا.محاولة_حالية >= هذا.محاولات_قصوى {
                    اطبع("❌ فشلت كل المحاولات!")
                    ارمِ خطأ  // إعادة رمي الخطأ
                }
                
                انتظار = هذا.احسب_انتظار()
                اطبع("⏳ المحاولة " + هذا.محاولة_حالية + " فشلت")
                اطبع("   أعيد بعد " + (انتظار / 1000.0) + " ثانية...")
                
                نم(انتظار)
            }
        }
    }
}

// مثال استخدام:
دالة رئيسية() {
    معيد = اعادة_محاولة_ذكية(محاولات_قصوى=5)
    
    محاولة {
        عميل = معيد.نفذ(شبكة.اتصل_tcp، ["server.com", 8080])
        اطبع("✅ تم الاتصال!")
    } اصطياد (خطأ) {
        اطبع("❌ فشل الاتصال نهائياً بعد 5 محاولات")
    }
}
```

### 2. Circuit Breaker Pattern

عندما يفشل خادم باستمرار، توقف عن محاولة الاتصال به لفترة:

```sad
صنف قاطع_دائرة {
    حالة: نص  // "مغلق" أو "مفتوح" أو "نصف_مفتوح"
    فشل_متتالي: رقم
    عتبة_الفشل: رقم
    وقت_الفتح: رقم
    مدة_الانتظار: رقم  // بالميلي ثانية
    
    دالة __init__(عتبة_الفشل=5، مدة_الانتظار=60000) {
        هذا.حالة = "مغلق"
        هذا.فشل_متتالي = 0
        هذا.عتبة_الفشل = عتبة_الفشل
        هذا.مدة_الانتظار = مدة_الانتظار
    }
    
    دالة نفذ(دالة، معاملات=[]) {
        إذا هذا.حالة == "مفتوح" {
            // تحقق إذا حان وقت المحاولة مرة أخرى
            إذا (وقت.الآن() - هذا.وقت_الفتح) > هذا.مدة_الانتظار {
                اطبع("🔄 القاطع نصف مفتوح - أحاول مرة أخرى...")
                هذا.حالة = "نصف_مفتوح"
            } وإلا {
                اطبع("⛔ القاطع مفتوح - الخدمة معطلة مؤقتاً")
                ارمِ خطأ_جديد("الخدمة غير متاحة مؤقتاً")
            }
        }
        
        محاولة {
            نتيجة = دالة(*معاملات)
            
            // نجح! أعد تعيين القاطع
            هذا.عند_النجاح()
            ارجع نتيجة
            
        } اصطياد (خطأ) {
            هذا.عند_الفشل()
            ارمِ خطأ
        }
    }
    
    دالة عند_النجاح() {
        هذا.فشل_متتالي = 0
        هذا.حالة = "مغلق"
        اطبع("✅ القاطع مغلق - الخدمة تعمل بشكل طبيعي")
    }
    
    دالة عند_الفشل() {
        هذا.فشل_متتالي = هذا.فشل_متتالي + 1
        
        إذا هذا.فشل_متتالي >= هذا.عتبة_الفشل {
            هذا.حالة = "مفتوح"
            هذا.وقت_الفتح = وقت.الآن()
            اطبع("⚠️ القاطع فُتح - الخدمة معطلة!")
            اطبع("   سأحاول مرة أخرى بعد " + (هذا.مدة_الانتظار / 1000) + " ثانية")
        }
    }
}

// مثال استخدام:
قاطع = قاطع_دائرة(عتبة_الفشل=3، مدة_الانتظار=30000)

دالة اتصل_بخادم() {
    محاولة {
        عميل = قاطع.نفذ(شبكة.اتصل_tcp، ["unstable-server.com", 8080])
        // استخدم العميل...
    } اصطياد (خطأ) {
        اطبع("الخدمة غير متاحة حالياً")
    }
}
```

### 3. Fallback Strategies (استراتيجيات البديل)

عندما تفشل الخدمة الأساسية، استخدم بديلاً:

```sad
صنف مدير_خدمات_مرن {
    خوادم: قائمة<عنوان>
    خادم_حالي: رقم
    
    دالة __init__(قائمة_خوادم) {
        هذا.خوادم = قائمة_خوادم
        هذا.خادم_حالي = 0
    }
    
    دالة اتصل() {
        // محاولة الاتصال بكل الخوادم بالترتيب
        لـ ع من 0 إلى هذا.خوادم.طول() {
            خادم = هذا.خوادم[(هذا.خادم_حالي + ع) % هذا.خوادم.طول()]
            
            اطبع("🔄 أحاول الاتصال بـ " + خادم.عنوان + ":" + خادم.منفذ)
            
            محاولة {
                عميل = شبكة.اتصل_tcp(خادم.عنوان، خادم.منفذ)
                
                // نجح! حدّث الخادم الحالي
                هذا.خادم_حالي = (هذا.خادم_حالي + ع) % هذا.خوادم.طول()
                
                اطبع("✅ تم الاتصال بنجاح!")
                ارجع عميل
                
            } اصطياد (خطأ) {
                اطبع("❌ فشل الاتصال بـ " + خادم.عنوان)
            }
        }
        
        // كل الخوادم فشلت!
        اطبع("❌ كل الخوادم معطلة!")
        ارجع باطل
    }
}

// مثال استخدام:
مدير = مدير_خدمات_مرن([

    {عنوان: "emergency-server.com", منفذ: 8080}
])

عميل = مدير.اتصل()
إذا عميل != باطل {
```

## 📊 التسجيل والمراقبة

### نظام تسجيل شامل

```sad
صنف مسجل_شبكة {
    ملف_السجل: نص
    مستوى: نص  // "debug", "info", "warning", "error"
    
    دالة سجل(مستوى، رسالة، تفاصيل={}) {
        إذا !هذا.يجب_تسجيل(مستوى) {
            ارجع
        }
        
        طابع_زمني = وقت.الآن_بتنسيق("%Y-%m-%d %H:%M:%S")
        سطر_سجل = "[" + طابع_زمني + "] [" + مستوى + "] " + رسالة
        
        // إضافة تفاصيل إضافية إذا وُجدت
        إذا تفاصيل.طول() > 0 {
            سطر_سجل = سطر_سجل + " | " + نص.من_كائن(تفاصيل)
        }
        
        // الكتابة للملف
        ملف.اضف(هذا.ملف_السجل، سطر_سجل + "\n")
        
        // العرض على الشاشة (حسب المستوى)
        إذا مستوى == "error" {
            اطبع("❌ " + سطر_سجل)
        } وإلا إذا مستوى == "warning" {
            اطبع("⚠️ " + سطر_سجل)
        } وإلا إذا مستوى == "info" {
            اطبع("ℹ️ " + سطر_سجل)
        }
    }
    
    دالة خطأ(رسالة، استثناء=باطل) {
        تفاصيل = {}
        
        إذا استثناء != باطل {
            تفاصيل["نوع_الخطأ"] = استثناء.نوع()
            تفاصيل["رسالة_الخطأ"] = استثناء.رسالة()
            تفاصيل["كود_الخطأ"] = استثناء.كود()
        }
        
        هذا.سجل("error"، رسالة، تفاصيل)
    }
}

// الاستخدام:
مسجل = مسجل_شبكة("network.log"، "info")

محاولة {
    عميل = شبكة.اتصل_tcp("server.com", 8080)
    مسجل.سجل("info"، "تم الاتصال بنجاح"، {
        خادم: "server.com:8080"،
        وقت_الاتصال: وقت.الآن()
    })
    
} اصطياد (خطأ_شبكة.اتصال_مرفوض خطأ) {
    مسجل.خطأ("فشل الاتصال بالخادم"، خطأ)
}
```
