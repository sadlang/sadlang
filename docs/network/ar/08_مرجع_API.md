## 📦 الأصناف (Classes)

### `مقبس_tcp` (TcpSocket)

مقبس TCP لاتصالات موثوقة ومرتبة.

#### المنشئات (Constructors)

**`شبكة.انشئ_مقبس_tcp()`**
```sad
مقبس = شبكة.انشئ_مقبس_tcp()
```
- **الوصف:** ينشئ مقبس TCP جديد
- **الإرجاع:** `مقبس_tcp` أو `باطل` عند الفشل
- **الاستثناءات:** `خطأ_شبكة.فشل_إنشاء_مقبس`

**`شبكة.انشئ_خادم_tcp(منفذ: رقم)`**
```sad
خادم = شبكة.انشئ_خادم_tcp(8080)
```
- **الوصف:** ينشئ خادم TCP يستمع على منفذ محدد
- **المعاملات:**
  - `منفذ`: رقم المنفذ (1-65535)
- **الإرجاع:** `مقبس_tcp` (خادم)
- **الاستثناءات:** 
  - `خطأ_شبكة.عنوان_مستخدم` - المنفذ مستخدم
  - `خطأ_شبكة.فشل_إنشاء_مقبس`

**`شبكة.اتصل_tcp(عنوان: نص, منفذ: رقم)`**
```sad
عميل = شبكة.اتصل_tcp("127.0.0.1", 8080)
```
- **الوصف:** يتصل بخادم TCP
- **المعاملات:**
  - `عنوان`: عنوان IP أو اسم النطاق
  - `منفذ`: رقم المنفذ
- **الإرجاع:** `مقبس_tcp` (متصل)
- **الاستثناءات:**
  - `خطأ_شبكة.اتصال_مرفوض` - الخادم رفض
  - `خطأ_شبكة.مهلة_انتهت` - انتهت مهلة الاتصال
  - `خطأ_شبكة.عنوان_غير_صالح` - عنوان خاطئ

#### دوال الخادم

**`اقبل() -> مقبس_tcp`**
```sad
عميل = خادم.اقبل()
```
- **الوصف:** ينتظر ويقبل اتصال عميل جديد
- **الإرجاع:** `مقبس_tcp` (اتصال العميل)
- **ملاحظات:** 
  - دالة blocking - تنتظر حتى يتصل عميل
  - يجب استدعاؤها على خادم فقط
- **الاستثناءات:** `خطأ_شبكة.فشل_القبول`

#### دوال الإرسال

**`ارسل(بيانات: قائمة<بايت>) -> رقم`**
```sad
عدد = عميل.ارسل([0x48, 0x65, 0x6C, 0x6C, 0x6F])
```
- **الوصف:** يرسل بيانات (قد لا يرسل الكل)
- **المعاملات:**
  - `بيانات`: مصفوفة بايتات للإرسال
- **الإرجاع:** عدد البايتات المرسلة فعلياً
- **الاستثناءات:** `خطأ_شبكة.إرسال_فشل`

**`ارسل_الكل(بيانات: قائمة<بايت>)`**
```sad
عميل.ارسل_الكل(نص.الى_بايتات("مرحباً"))
```
- **الوصف:** يرسل كل البيانات (يضمن إرسال الكل)
- **المعاملات:**
  - `بيانات`: مصفوفة بايتات للإرسال
- **الإرجاع:** لا شيء
- **ملاحظات:** يُفضل على `ارسل()` في معظم الحالات
- **الاستثناءات:** `خطأ_شبكة.إرسال_فشل`

#### دوال الاستقبال

**`استقبل(حجم: رقم) -> قائمة<بايت>`**
```sad
بيانات = عميل.استقبل(1024)
```
- **الوصف:** يستقبل حتى `حجم` بايت
- **المعاملات:**
  - `حجم`: الحد الأقصى من البايتات
- **الإرجاع:** مصفوفة بايتات (قد تكون أقل من `حجم`)
- **ملاحظات:** 
  - إذا أرجع مصفوفة فارغة، الاتصال مقطوع
  - قد يستقبل أقل من `حجم`
- **الاستثناءات:** 
  - `خطأ_شبكة.استقبال_فشل`
  - `خطأ_شبكة.مهلة_انتهت`

**`استقبل_الكل(حجم: رقم) -> قائمة<بايت>`**
```sad
بيانات = عميل.استقبل_الكل(1024)
```
- **الوصف:** يستقبل `حجم` بايت بالضبط
- **المعاملات:**
  - `حجم`: عدد البايتات المطلوب
- **الإرجاع:** مصفوفة بايتات بطول `حجم` بالضبط
- **ملاحظات:** يستمر بالاستقبال حتى يكمل `حجم`
- **الاستثناءات:** `خطأ_شبكة.استقبال_فشل`

**`استقبل_نص(حجم: رقم) -> نص`**
```sad
رسالة = عميل.استقبل_نص(1024)
```
- **الوصف:** يستقبل ويحول لنص مباشرة
- **المعاملات:**
  - `حجم`: الحد الأقصى من البايتات
- **الإرجاع:** نص (UTF-8)
- **ملاحظات:** مختصر لـ `نص.من_بايتات(عميل.استقبل(حجم))`

#### دوال الإغلاق

**`اغلق()`**
```sad
عميل.اغلق()
```
- **الوصف:** يغلق المقبس تماماً
- **ملاحظات:** يجب استدعاؤه دائماً عند الانتهاء

**`اوقف_الإرسال()`**
```sad
عميل.اوقف_الإرسال()
```
- **الوصف:** يوقف الإرسال فقط (يمكن الاستقبال)
- **الاستخدام:** للإغلاق اللطيف

**`اوقف_الاستقبال()`**
```sad
عميل.اوقف_الاستقبال()
```
- **الوصف:** يوقف الاستقبال فقط (يمكن الإرسال)

**`اوقف_كلاهما()`**
```sad
عميل.اوقف_كلاهما()
```
- **الوصف:** يوقف الإرسال والاستقبال

#### دوال الخيارات

**`عين_بدون_تأخير(قيمة: منطقي)`**
```sad
عميل.عين_بدون_تأخير(صحيح)
```
- **الوصف:** تفعيل/تعطيل TCP_NODELAY (Nagle's algorithm)
- **المعاملات:**
  - `قيمة`: `صحيح` لتعطيل Nagle (أقل تأخير)
- **الاستخدام:** للتطبيقات الحساسة للوقت

**`عين_حافظ_على_الحياة(قيمة: منطقي)`**
```sad
عميل.عين_حافظ_على_الحياة(صحيح)
```
- **الوصف:** تفعيل SO_KEEPALIVE
- **الوصف:** يرسل رسائل قلب تلقائية

**`عين_اعادة_استخدام_العنوان(قيمة: منطقي)`**
```sad
خادم.عين_اعادة_استخدام_العنوان(صحيح)
```
- **الوصف:** تفعيل SO_REUSEADDR
- **الاستخدام:** لإعادة تشغيل الخادم فوراً

**`عين_مهلة_الإرسال(ميلي_ثانية: رقم)`**
```sad
عميل.عين_مهلة_الإرسال(5000)  // 5 ثوانٍ
```
- **الوصف:** تحديد مهلة عمليات الإرسال
- **المعاملات:**
  - `ميلي_ثانية`: المهلة بالميلي ثانية (0 = لا مهلة)

**`عين_مهلة_الاستقبال(ميلي_ثانية: رقم)`**
```sad
عميل.عين_مهلة_الاستقبال(10000)  // 10 ثوانٍ
```
- **الوصف:** تحديد مهلة عمليات الاستقبال
- **ملاحظات:** مهم جداً لتجنب التجميد

**`عين_حجم_مخزن_الإرسال(حجم: رقم)`**
```sad
عميل.عين_حجم_مخزن_الإرسال(256 * 1024)  // 256KB
```
- **الوصف:** تحديد حجم مخزن الإرسال
- **الاستخدام:** لتحسين الأداء

**`عين_حجم_مخزن_الاستقبال(حجم: رقم)`**
```sad
عميل.عين_حجم_مخزن_الاستقبال(256 * 1024)
```
- **الوصف:** تحديد حجم مخزن الاستقبال

**`عين_منع(قيمة: منطقي)`**
```sad
عميل.عين_منع(خطأ)  // وضع non-blocking
```
- **الوصف:** تحديد وضع الانتظار
- **المعاملات:**
  - `صحيح`: blocking (ينتظر)
  - `خطأ`: non-blocking (يعود فوراً)

#### دوال المعلومات

**`عنوان_المحلي() -> نص`**
```sad
عنوان = عميل.عنوان_المحلي()
// مثال: "192.168.1.100:54321"
```
- **الوصف:** يعيد العنوان المحلي للمقبس
- **الإرجاع:** نص بصيغة "IP:منفذ"

**`عنوان_البعيد() -> نص`**
```sad
عنوان = عميل.عنوان_البعيد()
// مثال: "192.168.1.200:8080"
```
- **الوصف:** يعيد العنوان البعيد (الطرف الآخر)
- **الإرجاع:** نص بصيغة "IP:منفذ"

**`متصل() -> منطقي`**
```sad
إذا عميل.متصل() {
    اطبع("لا يزال متصلاً")
}
```
- **الوصف:** يتحقق إذا كان الاتصال لا يزال قائماً
- **الإرجاع:** `صحيح` إذا متصل، `خطأ` إذا مقطوع

### `مقبس_udp` (UdpSocket)

مقبس UDP لاتصالات سريعة بدون ضمان.

#### المنشئات

**`شبكة.انشئ_مقبس_udp()`**
```sad
مقبس = شبكة.انشئ_مقبس_udp()
```
- **الوصف:** ينشئ مقبس UDP جديد
- **الإرجاع:** `مقبس_udp`
- **الاستثناءات:** `خطأ_شبكة.فشل_إنشاء_مقبس`

#### دوال الربط والاتصال

**`اربط(منفذ: رقم)`**
```sad
مقبس.اربط(9090)
```
- **الوصف:** يربط المقبس بمنفذ محدد
- **المعاملات:**
  - `منفذ`: رقم المنفذ
- **ملاحظات:** ضروري قبل الاستقبال
- **الاستثناءات:** `خطأ_شبكة.عنوان_مستخدم`

**`اتصل(عنوان: نص, منفذ: رقم)`**
```sad
مقبس.اتصل("192.168.1.100", 8080)
```
- **الوصف:** "يربط" المقبس بعنوان محدد (UDP المتصل)
- **ملاحظات:** 
  - لا ينشئ اتصال حقيقي
  - يسمح باستخدام `ارسل()` بدلاً من `ارسل_الى()`

**`افصل()`**
```sad
مقبس.افصل()
```
- **الوصف:** يفصل UDP المتصل

#### دوال الإرسال والاستقبال (غير متصل)

**`ارسل_الى(بيانات: قائمة<بايت>, عنوان: عنوان_مقبس)`**
```sad
عنوان = شبكة.انشئ_عنوان("192.168.1.100", 8080)
مقبس.ارسل_الى([0x48, 0x69], عنوان)
```
- **الوصف:** يرسل حزمة لعنوان محدد
- **المعاملات:**
  - `بيانات`: البيانات للإرسال
  - `عنوان`: عنوان الوجهة
- **الإرجاع:** عدد البايتات المرسلة
- **ملاحظات:** UDP قد يفقد الحزم!

**`استقبل_من(حجم: رقم) -> (قائمة<بايت>, عنوان_مقبس)`**
```sad
(بيانات، مرسل) = مقبس.استقبل_من(1024)
اطبع("من: " + مرسل.عنوان())
```
- **الوصف:** يستقبل حزمة ويعيد المرسل
- **المعاملات:**
  - `حجم`: الحد الأقصى من البايتات
- **الإرجاع:** (بيانات، عنوان_المرسل)

#### دوال الإرسال والاستقبال (متصل)

**`ارسل(بيانات: قائمة<بايت>)`**
```sad
مقبس.اتصل("server.com", 8080)
مقبس.ارسل([0x48, 0x69])
```
- **الوصف:** يرسل لعنوان المتصل به
- **ملاحظات:** يعمل فقط بعد `اتصل()`

**`استقبل(حجم: رقم) -> قائمة<بايت>`**
```sad
بيانات = مقبس.استقبل(1024)
```
- **الوصف:** يستقبل من العنوان المتصل به

#### دوال البث (Broadcast)

**`فعل_البث()`**
```sad
مقبس.فعل_البث()
```
- **الوصف:** يفعّل البث العام
- **ملاحظات:** ضروري قبل الإرسال لـ 255.255.255.255

**`عطل_البث()`**
```sad
مقبس.عطل_البث()
```
- **الوصف:** يعطّل البث العام

#### دوال Multicast

**`انضم_لمجموعة_multicast(عنوان: نص)`**
```sad
مقبس.انضم_لمجموعة_multicast("239.0.0.1")
```
- **الوصف:** ينضم لمجموعة multicast
- **المعاملات:**
  - `عنوان`: عنوان المجموعة (224.0.0.0 - 239.255.255.255)

**`غادر_مجموعة_multicast(عنوان: نص)`**
```sad
مقبس.غادر_مجموعة_multicast("239.0.0.1")
```
- **الوصف:** يغادر مجموعة multicast

**`عين_multicast_ttl(ttl: رقم)`**
```sad
مقبس.عين_multicast_ttl(32)
```
- **الوصف:** يحدد TTL لحزم multicast
- **المعاملات:**
  - `ttl`: عدد القفزات (1-255)
  - 1 = شبكة محلية فقط
  - 32 = عدة شبكات
  - 255 = الإنترنت كله

**`عين_multicast_loopback(قيمة: منطقي)`**
```sad
مقبس.عين_multicast_loopback(خطأ)
```
- **الوصف:** تفعيل/تعطيل استقبال رسائلك الخاصة
- **المعاملات:**
  - `صحيح`: ستستقبل رسائلك
  - `خطأ`: لن تستقبل رسائلك

### `عنوان_مقبس` (SocketAddress)

يمثل عنوان شبكي (IP + منفذ).

#### المنشئات

**`شبكة.انشئ_عنوان(ip: نص, منفذ: رقم)`**
```sad
عنوان = شبكة.انشئ_عنوان("192.168.1.100", 8080)
```
- **الوصف:** ينشئ عنوان من IP ومنفذ
- **المعاملات:**
  - `ip`: عنوان IPv4 أو IPv6
  - `منفذ`: رقم المنفذ
- **الإرجاع:** `عنوان_مقبس`

**`شبكة.حلل_عنوان(نص: نص)`**
```sad
عنوان = شبكة.حلل_عنوان("192.168.1.100:8080")
```
- **الوصف:** يحلل عنوان من نص
- **الصيغ المدعومة:**
  - `"192.168.1.100:8080"`
  - `"localhost:8080"`
  - `"[::1]:8080"` (IPv6)
- **الاستثناءات:** `خطأ_شبكة.عنوان_غير_صالح`

#### دوال المعلومات

**`عنوان() -> نص`**
```sad
ip = عنوان.عنوان()  // "192.168.1.100"
```
- **الوصف:** يعيد عنوان IP فقط

**`منفذ() -> رقم`**
```sad
رقم = عنوان.منفذ()  // 8080
```
- **الوصف:** يعيد رقم المنفذ

**`نصي() -> نص`**
```sad
كامل = عنوان.نصي()  // "192.168.1.100:8080"
```
- **الوصف:** يعيد العنوان الكامل

**`هو_ipv4() -> منطقي`**
```sad
إذا عنوان.هو_ipv4() {
    اطبع("هذا IPv4")
}
```

**`هو_ipv6() -> منطقي`**
```sad
إذا عنوان.هو_ipv6() {
    اطبع("هذا IPv6")
}
```

## ⚠️ الاستثناءات (Exceptions)

جميع استثناءات الشبكة تنتمي لـ `خطأ_شبكة`:

```sad
محاولة {
    // كود شبكي
} اصطياد (خطأ_شبكة خطأ) {
    اطبع("خطأ شبكي: " + خطأ.رسالة())
}
```

### أنواع الأخطاء

- `خطأ_شبكة.اتصال_مرفوض` - Connection refused
- `خطأ_شبكة.اتصال_قُطع` - Connection reset
- `خطأ_شبكة.مهلة_انتهت` - Timeout
- `خطأ_شبكة.إرسال_فشل` - Send failed
- `خطأ_شبكة.استقبال_فشل` - Receive failed
- `خطأ_شبكة.عنوان_مستخدم` - Address in use
- `خطأ_شبكة.عنوان_غير_صالح` - Invalid address
- `خطأ_شبكة.فشل_إنشاء_مقبس` - Socket creation failed
