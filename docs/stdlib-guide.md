# دليل المكتبة القياسية — لغة ص

> **تاريخ التوليد**: 17 أبريل 2026  
> **الإصدار**: 1.0.0

---

## نظرة عامة

المكتبة القياسية للغة ص توفر مجموعة شاملة من الوحدات والدوال المضمنة. تنقسم إلى:

1. **دوال مضمنة تلقائياً** — لا تحتاج استيراد
2. **وحدات قياسية** — تحتاج استيراد بـ `استورد`
3. **وحدات متخصصة** — للمهام المتقدمة

---

## 1. الدوال المضمنة تلقائياً

### 1.1 دوال الإخراج

```sad
اطبع("نص")           # طباعة بدون سطر اطبع_سطر("نص")       # طباعة مع سطر جديد
```

### 1.2 دوال الإدخال

```sad
متغير مدخل = اقرأ()              # قراءة نص
متغير مدخل = اقرأ("أدخل اسمك: ")  # قراءة مع رسالة
```

### 1.3 دوال الطول والنوع

```sad
طول("مرحبا")        # 5
طول([1، 2، 3])      # 3

نوع(42)             # "رقم"
نوع("نص")           # "نص"
نوع([])             # "مصفوفة"
```

### 1.4 دوال تحويل الأنواع

```sad
رقم("42")           # 42
عشري("3.14")        # 3.14
نص(100)             # "100"
منطقي(1)            # صحيح
```

### 1.5 دوال التزامن

```sad
# إنشاء قناة مخزّنة
متغير ق = قناة(10)

# انتظار جميع الخيوط
انتظر_الكل()

# عدد المهام النشطة
عدد_المهام()

# مجموعة انتظار
متغير مج = مجموعة_انتظار()

# قفل
متغير ق = قفل()

# مستقبل
متغير م = مستقبل()
```

## 2. طرق الأنواع المضمنة

### 2.1 طرق المصفوفات

```sad
متغير م = [1، 2، 3]

م.اضف(4)                    # إضافة عنصر
م.احذف_اخير()               # حذف آخر عنصر
م.رتب()                     # ترتيب تصاعدي
م.عكس()                     # عكس الترتيب
م.يحتوي(2)                  # هل يحتوي على 2؟
م.فهرس(2)                   # فهرس العنصر 2
م.شريحة(0، 2)               # [1، 2]
م.خريطة(لامدا (س) س * 2)   # [2، 4، 6]
م.رشح(لامدا (س) س > 1)     # [2، 3]
م.اختزل(لامدا (ت، س) ت + س، 0)  # 6
م.لكل(لامدا (س) اطبع(س))
م.اول()                     # 1
م.آخر()                     # 3
م.فارغة()                   # خطأ
م.الطول()                   # 3
م.مسطح()                    # تسطيح متداخل
```

### 2.2 طرق النصوص

```sad
متغير ن = "مرحبا بالعالم"

ن.طول()                     # 12
ن.يحتوي("مرحبا")            # صحيح
ن.يبدأ_بـ("مرحبا")          # صحيح
ن.ينتهي_بـ("العالم")        # صحيح
ن.تقسيم(" ")               # ["مرحبا"، "بالعالم"]
ن.استبدل("مرحبا"، "أهلا")   # "أهلا بالعالم"
ن.استخراج(0، 5)             # "مرحبا"
ن.قص_أطراف()                # إزالة المسافات
ن.تحويل_كبير()              # حروف كبيرة
ن.تحويل_صغير()              # حروف صغيرة
```

### 2.3 طرق الخرائط

```sad
متغير خ = {}

خ.عيّن("مفتاح"، 42)         # إضافة/تعديل
خ.احصل("مفتاح")             # 42
خ.احذف("مفتاح")             # حذف
خ.يحتوي("مفتاح")            # هل موجود؟
خ.مفاتيح()                  # مصفوفة المفاتيح
خ.قيم()                     # مصفوفة القيم
خ.حجم()                     # عدد العناصر
خ.فارغة()                   # هل فارغة؟
```

### 2.4 طرق القنوات

```sad
متغير ق = قناة(10)

ق.أرسل(42)                  # إرسال (حجب)
ق.استقبل()                  # استقبال (حجب)
ق.حاول_ارسل(42)             # إرسال بدون حجب
ق.حاول_استقبل()             # استقبال بدون حجب
ق.أرسل_بمهلة(42، 1000)      # إرسال بمهلة (مللي ثانية)
ق.استقبل_بمهلة(500)         # استقبال بمهلة
ق.الحجم()                   # عدد العناصر
ق.السعة()                   # السعة القصوى
ق.فارغة()                   # هل فارغة؟
ق.أغلق()                    # إغلاق القناة
ق.مغلقة()                   # هل مغلقة؟
```

## 3. الوحدات القياسية

### 3.1 وحدة الرياضيات (`رياضيات`)

```sad
استورد رياضيات
# أو: من رياضيات استورد *

رياضيات.جذر(16)             # 4
رياضيات.أس(2، 10)           # 1024
رياضيات.لوغاريتم(100)       # 2
رياضيات.جيب(0)              # 0
رياضيات.تجيب(0)             # 1
رياضيات.مطلق(-5)            # 5
رياضيات.بتر(3.7)            # 3
رياضيات.سقف(3.2)            # 4
رياضيات.أرضية(3.7)          # 3
رياضيات.عشوائي()            # رقم عشوائي [0، 1)
رياضيات.عشوائي_صحيح(1، 10)  # رقم عشوائي صحيح
رياضيات.باي                 # π
رياضيات.هـ                   # e
```

### 3.2 وحدة النصوص (`نصوص`)

```sad
استورد نصوص

نصوص.حروف("abc")            # ['a'، 'b'، 'c']
نصوص.كلمات("a b c")         # ["a"، "b"، "c"]
نصوص.أسطر("a\nb")           # ["a"، "b"]
نصوص.تكرار("ص"، 3)          # "صصص"
نصوص.عكس("مرحبا")           # "ابحرم"
نصوص.هل_رقم("123")          # صحيح
نصوص.هل_حروف("abc")         # صحيح
نصوص.هل_فارغ("")            # صحيح
```

### 3.3 وحدة الأساسيات (`أساسيات`)

```sad
استورد أساسيات

أساسيات.خروج(0)              # إنهاء البرنامج
أساسيات.مدى(10)              # [0..9]
أساسيات.مدى(1، 10)           # [1..9]
أساسيات.مدى(1، 10، 2)        # [1، 3، 5، 7، 9]
أساسيات.تأكد(شرط، "رسالة")   # تأكيد
```

### 3.4 وحدة الملفات (`ملفات`)

```sad
استورد ملفات

# قراءة ملف
متغير محتوى = ملفات.اقرأ("ملف.txt")

# كتابة ملف
ملفات.اكتب("ملف.txt"، "محتوى")

# إلحاق
ملفات.الحق("ملف.txt"، "محتوى إضافي")

# فحص الوجود
ملفات.موجود("ملف.txt")        # صحيح/خطأ

# حذف
ملفات.احذف("ملف.txt")

# نسخ
ملفات.انسخ("مصدر.txt"، "وجهة.txt")

# قائمة الملفات
ملفات.قائمة("مجلد/")
```

### 3.5 وحدة JSON (`json`)

```sad
استورد json

# تحويل إلى JSON
متغير نص = json.نص({"اسم": "أحمد"، "عمر": 25})

# تحليل JSON
متغير كائن = json.حلل('{"اسم": "أحمد"}')

# تنسيق جميل
json.تنسيق(كائن، مسافات: 2)
```

### 3.6 وحدة HTTP (`http`)

```sad
استورد http

# طلب GET
متغير استجابة = http.احصل("https://api.example.com/data")

# طلب POST
متغير استجابة = http.أرسل("https://api.example.com/data"، {
    جسم: {"اسم": "أحمد"}،
    ترويسات: {"Content-Type": "application/json"}
})

# فحص الحالة
إذا (استجابة.حالة == 200)
    اطبع_سطر(استجابة.جسم)
نهاية
```

### 3.7 وحدة التشفير (`تشفير`)

```sad
استورد تشفير

# هاش SHA-256
متغير هاش = تشفير.sha256("نص")

# هاش MD5
متغير هاش = تشفير.md5("نص")

# Base64
متغير مشفر = تشفير.base64_ترميز("نص")
متغير أصلي = تشفير.base64_فك(مشفر)

# تشفير AES
متغير مشفر = تشفير.aes_تشفير("نص"، مفتاح)
متغير أصلي = تشفير.aes_فك(مشفر، مفتاح)
```

### 3.8 وحدة الوقت (`وقت`)

```sad
استورد وقت

# الوقت الحالي
متغير الآن = وقت.الآن()

# تنسيق التاريخ
وقت.تنسيق(الآن، "YYYY-MM-DD HH:mm:ss")

# تحليل التاريخ
وقت.حلل("2024-01-15"، "YYYY-MM-DD")

# الفرق بين تاريخين
وقت.فرق(تاريخ1، تاريخ2)

# انتظار
وقت.انتظر(1000)  # مللي ثانية
```

### 3.9 وحدة المقابس (`مقابس`)

```sad
استورد مقابس

# خادم TCP
متغير خادم = مقابس.tcp_خادم("0.0.0.0"، 8080)
خادم.استمع(لامدا (اتصال)
    متغير بيانات = اتصال.اقرأ()
    اتصال.اكتب("مرحبا")
    اتصال.أغلق()
نهاية)

# عميل TCP
متغير عميل = مقابس.tcp_عميل("localhost"، 8080)
عميل.اكتب("مرحبا")
متغير استجابة = عميل.اقرأ()
عميل.أغلق()
```

### 3.10 وحدة الرسوميات (`رسومات`)

```sad
استورد رسومات

# إنشاء نافذة
متغير نافذة = رسومات.نافذة("عنوان"، 800، 600)

# رسم الأشكال
نافذة.مستطيل(10، 10، 100، 50، لون: "أحمر")
نافذة.دائرة(200، 200، 50، لون: "أزرق")
نافذة.خط(0، 0، 100، 100، لون: "أخضر")
نافذة.نص("مرحبا"، 50، 50، حجم: 24)

# تحديث الشاشة
نافذة.تحديث()

# حلقة الأحداث
بينما (نافذة.مفتوحة())
    متغير حدث = نافذة.انتظر_حدث()
    طابق (حدث.نوع)
        عندما "إغلاق":
            نافذة.أغلق()
        عندما "مفتاح":
            اطبع_سطر("مفتاح: " + حدث.مفتاح)
    نهاية
نهاية
```

## 5. صيغ الاستيراد

```sad
# استيراد كامل (فضاء أسماء)
استورد رياضيات
رياضيات.جذر(16)

# استيراد مع اسم مستعار
استورد رياضيات كـ ر
ر.جذر(16)

# استيراد دالة محددة
من رياضيات استورد جذر
جذر(16)

# استيراد كل الصادرات
من رياضيات استورد *
جذر(16)

# استيراد متعدد
من رياضيات استورد جذر، أس، باي
```

## 6. ملاحظات مهمة

### 6.1 القسمة

```sad
# القسمة / تعطي عشري دائماً
10 / 3          # 3.333...

# للقسمة الصحيحة
رقم(10 / 3)    # 3
```

### 6.2 معالجة الأخطاء

```sad
# امسك بدون أقواس
حاول
    # كود قد يفشل
امسك خطأ
    اطبع_سطر("خطأ: " + خطأ)
أخيراً
    # تنظيف
نهاية
```

### 6.3 كلمات محجوزة

الكلمات التالية **سياقية** — لا تُستخدم كأسماء متغيرات أو دوال في سياقها:
- `حالة` — في المطابقة
- `مولّد` — في المولدات
- `انتظر` — في البرمجة غير المتزامنة
