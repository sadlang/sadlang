# 🚀 تطوير تطبيقات Android بلغة ص

لغة ص تقدم تجربة تطوير Android **أسرع وأبسط من Flutter** مع دعم كامل للعربية.

## ⚡ البداية السريعة

```powershell
# إنشاء مشروع جديد
sad-android new تطبيقي

# الدخول للمجلد
cd تطبيقي

# بناء APK
sad-android build

# تشغيل على الجهاز
sad-android run

# تشغيل مع Hot Reload
sad-android hot
```

## 📱 مثال: تطبيق Hello World

```sad
استورد "اندرويد/تطبيق"
استورد "اندرويد/واجهة"

دالة رئيسية()
    شغّل_تطبيق(
        الشاشة_الرئيسية = سقالة(
            شريط_علوي = شريط_تطبيق(العنوان = "تطبيقي")،
            الجسم = وسط(
                نص("مرحباً بالعالم! 🌍")
            )
        )
    )
نهاية
```


## 🔄 إدارة الحالة (State Management)

لغة ص تستخدم نظام **إشارات (Signals)** أفضل من setState و Provider:

```sad
استورد "اندرويد/حالة"

# إنشاء إشارة
متغير العداد = إشارة(0)

# قيمة محسوبة تلقائياً
متغير العداد_مضاعف = محسوب(دالة()
    ارجع العداد.القيمة() * 2
نهاية)

# في الواجهة
عمود([
    نص("العداد: " + العداد.القيمة())،
    نص("المضاعف: " + العداد_مضاعف.القيمة())،
    زر(
        النص = "زيادة"،
        عند_الضغط = دالة()
            العداد.عيّن(العداد.القيمة() + 1)
            # الواجهة تتحدث تلقائياً! ✨
        نهاية
    )
])
```

## 🔥 Hot Reload

التحديث الساخن مدمج ويحافظ على حالة التطبيق:


## 📊 مقارنة مع Flutter

| الميزة | Flutter | لغة ص |

## 🎮 مكتبة الرسوميات ثلاثية الأبعاد

```sad
استورد "اندرويد/رسوميات_ثلاثية"

# إنشاء مشهد 3D
متغير المشهد = مشهد_ثلاثي()
متغير الكاميرا = كاميرا_منظور({"زاوية_الرؤية" = 75})
متغير المكعب = مكعب({"الحجم" = 2})

المشهد.أضف(المكعب)

# تحميل نموذج GLTF
متغير النموذج = نموذج_ثلاثي()
انتظر النموذج.حمّل("assets/robot.gltf")

```
