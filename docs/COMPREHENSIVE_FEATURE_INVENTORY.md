## 4. التحكم بالتدفق

### 4.1 الشروط — `إذا` / `وإلا` / `وإلا_إذا`

**AST Node:** `IfStmt`
**الحالة:** ✅ مكتمل في المفسر والمترجم

```sad
إذا (شرط)
    # جسم
وإلا
    # جسم بديل
نهاية
```

```sad
إذا (س > 0)
    اطبع("موجب")
وإلا إذا (س == 0)
    اطبع("صفر")
وإلا
    اطبع("سالب")
نهاية
```

**ملاحظات:**
- الأقواس حول الشرط اختيارية (لكن شائعة)
- عبارة if كتعبير (inline): `متغير ن = إذا (شرط) قيمة1 وإلا قيمة2 نهاية`
- يدعم `وإلا_إذا` أو `وإلا إذا` (كلمتان)

### 4.2 حلقة `بينما`

**AST Node:** `WhileStmt`
**الحالة:** ✅ مكتمل

```sad
بينما (شرط)
    # جسم
نهاية
```

**بدائل:** `طالما` مرادف لـ `بينما`

### 4.3 حلقة `لكل`

**AST Node:** `ForStmt` / `ForRangeStmt`
**الحالة:** ✅ مكتمل

```sad
# حلقة بسيطة
لكل عنصر في مصفوفة
    اطبع(عنصر)
نهاية

# مع فهرس (تفكيك)
لكل فهرس، قيمة في مصفوفة
    اطبع(فهرس + ": " + قيمة)
نهاية

# مع أقواس (اختيارية)
لكل (عنصر في [1، 2، 3])
    اطبع(عنصر)
نهاية
```

**ملاحظات:**
- يدعم التفكيك (destructuring) للفهرس والقيمة

```sad
متغير أسماء = {م: طول(م) لكل م، ق في عناصر إذا ق > 0}
```

### 11.3 عامل Walrus (`:=`)

**AST Node:** `WalrusExpr`
**الحالة:** ✅ مكتمل

```sad

    اطبع("النتيجة: " + ن)
نهاية
```

### 11.4 نطاقات (Ranges)

```sad
    اطبع(ع)
نهاية
```

### 11.5 الاقتراض (Borrowing)

## 12. التوجيهات (Directives)

التوجيهات تبدأ بـ `@` وتوفر تحكماً منخفض المستوى.

### 12.1 `@حجم` — حجم النوع

**AST Node:** `SizeofExpr`

```sad
متغير حجم_رقم = @حجم(رقم)    # → 8 (بايت)
متغير حجم_نص = @حجم(نص)
```

### 12.2 `@ذري` — عمليات ذرية

**AST Node:** `AtomicExpr`

```sad
@ذري(تحميل، عداد)           # قراءة ذرية
@ذري(تخزين، عداد، 42)       # كتابة ذرية
@ذري(مقارنة_وتبديل، عداد، 0، 1)  # CAS
```

### 12.3 `@غير_آمن` — كتلة غير آمنة

**AST Node:** `UnsafeBlockStmt`

```sad
@غير_آمن
    # كود بدون فحوصات أمان
    متغير مؤشر = &قيمة
نهاية
```

### 12.4 `@وقت_الترجمة` — تنفيذ وقت الترجمة

**AST Node:** `ComptimeBlockStmt`

```sad
@وقت_الترجمة
    ثابت حجم_المصفوفة = 1024
نهاية
```

### 12.5 `@متطاير` — متغير متطاير

**AST Node:** `VolatileVarDeclStmt`

```sad
@متطاير متغير سجل_حالة = 0
```

### 12.6 `@تجميع` — تجميع مضمن

```sad
@تجميع("nop")                        # بدون مدخلات/مخرجات
@تجميع("mov %1, %0", "=r"(نتيجة), "r"(مدخل), "memory")
```
