# نظام الرسوميات — دليل المطور

## نظرة عامة

نظام الرسوميات في لغة ص يوفر واجهة برمجة عربية كاملة للرسوميات ثنائية الأبعاد،
مبنية على SDL2 + OpenGL 3.3. يتكون من ثلاث طبقات رئيسية:

```
╔═══════════════════════════════════════════════════╗
║        واجهات المستخدم (sad::graphics::ui)       ║
║  Widget, Button, Label, Panel, Slider, etc.       ║
╠═══════════════════════════════════════════════════╣
║        محرك الرسم (SadGraphics)                   ║
║  Renderer2D, Renderer2DAdvanced                   ║
║  Transform2D, مخزن_البكسل                        ║
╠═══════════════════════════════════════════════════╣
║        طبقة النظام                                ║
║  SDL2 2.28.5 + OpenGL 3.3 (GLAD)                 ║
╚═══════════════════════════════════════════════════╝
```

## الملفات الرئيسية

### محرك الرسم
| الملف | الوصف |
|-------|-------|
| `graphics/include/rendering/renderer2d.h` | Renderer2D + Advanced |
| `graphics/src/rendering/renderer2d.cpp` | التنفيذ الأساسي |
| `graphics/src/rendering/renderer2d_advanced.cpp` | الميزات المتقدمة |
| `graphics/include/rendering/render_context.h` | سياق OpenGL |

### واجهات المستخدم
| الملف | الوصف |
|-------|-------|
| `graphics/include/ui/widget.h` | الصنف الأساسي للعناصر |
| `graphics/include/ui/button.h` | زر |
| `graphics/include/ui/label.h` | نص |
| `graphics/include/ui/panel.h` | لوحة |
| `graphics/include/ui/slider.h` | منزلق |
| `graphics/include/ui/checkbox.h` | مربع اختيار |
| `graphics/include/ui/textinput.h` | حقل إدخال |

## Renderer2D — الرسم الأساسي

### الأشكال الأساسية

```cpp
Renderer2D renderer;

// مستطيل ممتلئ
renderer.FillRect(x, y, width, height, color);

// مستطيل فارغ (إطار)
renderer.DrawRect(x, y, width, height, color, lineWidth);

// دائرة
renderer.FillCircle(cx, cy, radius, color);

// خط
renderer.DrawLine(x1, y1, x2, y2, color, lineWidth);

// مثلث
renderer.FillTriangle(x1,y1, x2,y2, x3,y3, color);

// نص
renderer.DrawText("مرحباً", x, y, fontSize, color);
```

## Renderer2DAdvanced — الميزات المتقدمة (كامل — أبريل 2026)

### منحنيات بيزيه

```cpp
Renderer2DAdvanced advanced;

// منحنى بيزيه تربيعي
advanced.رسم_بيزيه_تربيعي(
    بداية_x, بداية_y,    // نقطة البداية
    تحكم_x, تحكم_y,      // نقطة التحكم
    نهاية_x, نهاية_y,    // نقطة النهاية
    لون, سمك
);

// منحنى بيزيه تكعيبي
advanced.رسم_بيزيه_تكعيبي(
    بداية_x, بداية_y,
    تحكم1_x, تحكم1_y,    // نقطة التحكم الأولى
    تحكم2_x, تحكم2_y,    // نقطة التحكم الثانية
    نهاية_x, نهاية_y,
    لون, سمك
);

// مسار بيزيه متعدد النقاط
std::vector<float> نقاط = { x1,y1, x2,y2, x3,y3, x4,y4, ... };
advanced.رسم_مسار_بيزيه(نقاط, لون, سمك);
```

### التحويلات (Transform2D)

```cpp
Transform2D تحويل = Transform2D::هوية();
تحويل = تحويل.ترجمة(100, 200);  // إزاحة
تحويل = تحويل.دوران(3.14f / 4);  // دوران 45°
تحويل = تحويل.تكبير(2.0f, 2.0f); // تكبير مرتين

// تطبيق التحويل على نقطة
auto [px, py] = تحويل.طبّق(10, 20);

// دمج تحويلين
Transform2D نتيجة = تحويل1.اضرب(تحويل2);

// عكس التحويل
Transform2D معكوس = تحويل.عكس();
```

### الظلال

```cpp
إعدادات_الظل ظل;
ظل.إزاحة_أفقية = 4.0f;
ظل.إزاحة_رأسية = 4.0f;
ظل.نصف_قطر_الضبابية = 8.0f;
ظل.لون = {0, 0, 0, 128};
ظل.مفعّل = true;

advanced.رسم_ظل_مستطيل(x, y, w, h, ظل);
```

### التدرجات اللونية

```cpp
إعدادات_التدرج تدرج;
تدرج.نوع = نوع_التدرج::خطي;
تدرج.لون_بداية = {255, 0, 0, 255};   // أحمر
تدرج.لون_نهاية = {0, 0, 255, 255};   // أزرق

advanced.رسم_مستطيل_متدرج(x, y, w, h, تدرج);

// تدرج دائري
تدرج.نوع = نوع_التدرج::شعاعي;
advanced.رسم_دائرة_متدرجة(cx, cy, radius, تدرج);
```

### مرشحات الصور

```cpp
مخزن_البكسل بكسل(عرض, ارتفاع);

// ضبابية غاوسية
Renderer2DAdvanced::ضبابية_غاوسية(بكسل, نصف_القطر);

// وهج
Renderer2DAdvanced::توهج(بكسل, نصف_القطر, شدة);

// تدرج رمادي
Renderer2DAdvanced::تدرج_رمادي(بكسل);

// عكس الألوان
Renderer2DAdvanced::عكس_الألوان(بكسل);

// تباين
Renderer2DAdvanced::تباين(بكسل, عامل);

// سطوع
Renderer2DAdvanced::سطوع(بكسل, عامل);

// مرشح لون
Renderer2DAdvanced::مرشح_لون(بكسل, أحمر, أخضر, أزرق);
```

### مخزن البكسل (Pixel Buffer)

```cpp
مخزن_البكسل بكسل(عرض, ارتفاع);

// كتابة بكسل
بكسل.ضع_بكسل(x, y, {255, 0, 0, 255});

// قراءة بكسل
auto لون = بكسل.احصل_بكسل(x, y);

// ملء بلون
بكسل.املأ({0, 0, 0, 255});

// مسح (شفاف)
بكسل.امسح();

// دمج مخزنين
بكسل.ادمج(مخزن_آخر, x, y);

// نسخ منطقة
بكسل.انسخ_منطقة(مصدر, src_x, src_y, dst_x, dst_y, w, h);

// رسم على الشاشة
بكسل.ارسم_على_الشاشة(renderer, x, y);
```

## الاعتمادات

- **SDL2 2.28.5** — مدمج في `graphics/third_party/SDL2/`
- **GLAD** — OpenGL loader، مدمج في `graphics/third_party/glad/`
- **stb_image** — قراءة الصور

## ملاحظات مهمة

- SDL2.dll يُنسخ تلقائياً إلى مجلد الإخراج عند البناء
- فضاء الأسماء `sad::graphics::ui` لواجهات المستخدم
- فضاء الأسماء `SadGraphics` لمحرك الرسم
- LNK4006 warnings موجودة مسبقاً (تعارض بين ui_layout.obj وملفات widgets الفردية) — لا تؤثر على الوظائف
