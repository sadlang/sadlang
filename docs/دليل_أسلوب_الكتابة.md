## 1. مبادئ عامة

### 1.1 نظام الطبقات

كل بنية نحوية لها **ثلاث طبقات** من الصيغ:

| الطبقة | الرمز | الوصف | الاستخدام |
|--------|-------|-------|-----------|
| **أساسية** | 🟢 | الصيغة المفضّلة — الأقرب للعربية | دائماً |
| **بديلة** | 🟡 | مقبولة في حالات خاصة | عند الحاجة |
| **توافقية** | 🔴 | تعمل لكن لا يُنصح بها | للقراءة فقط |

### 1.2 القواعد الذهبية

1. **الكلمات العربية أولاً** — استخدم `نهاية` بدلاً من `{}`
2. **الوضوح قبل الاختصار** — `متغير اسم: نوع = قيمة` أوضح من `نوع اسم = قيمة`
3. **الفاصلة العربية** — استخدم `،` بدلاً من `,` (كلاهما مدعوم ومتكافئ تماماً)
4. **المنقوطة** — استخدم `؛` أو `;` (كلاهما مدعوم ومتكافئ تماماً)
5. **اسم عربي** — سمِّ المتغيرات والدوال بالعربية ما أمكن

## 2. المتغيرات والثوابت

### 🟢 أساسية — كلمة مفتاحية + اسم + نوع اختياري

```sad
متغير العمر: رقم = 25
متغير الاسم: نص = "أحمد"
ثابت الباي: عشري = 3.14159
متغير القائمة = [1، 2، 3]        # استنتاج النوع عند الوضوح
```

### 🟡 بديلة — النوع أولاً (عند الوضوح التام)

```sad
رقم العداد = 0                    # واضح: النوع ثم الاسم
نص الرسالة = "مرحبا"
```

> **متى تُستخدم؟** في الحقول داخل الأصناف والبنى حيث النوع ضروري.

### 🟡 بديلة — متغيرات متعددة

```sad
متغير عرض = 800، ارتفاع = 600     # حالة خاصة: متغيرات مترابطة
ثابت حد_أدنى = 0، حد_أقصى = 100
```

### 🔴 توافقية — بدون كلمة مفتاحية أو نوع

```sad
# ❌ لا يُنصح — غموض بين أسماء الأنواع والمتغيرات
متغير نص = "هذا نص"              # هل نص نوع أم اسم؟
```

## 3. الدوال

### 🟢 أساسية — النوع قبل اسم الدالة

```sad
دالة رقم جمع(أ: رقم، ب: رقم)
    ارجع أ + ب
نهاية
```

> **لماذا؟** صيغة واحدة واضحة — النوع يأتي بين `دالة` واسمها، مثل `int sum()` في C.

### 🟢 أساسية — بدون نوع إرجاع (استنتاج تلقائي)

```sad
دالة مربع(س: رقم)
    ارجع س * س
نهاية
```

### ❌ صيغ مُزالة (لم تعد مدعومة)

```
# تمت إزالة جميع صيغ نوع الإرجاع بعد المعاملات:
دالة جمع(أ، ب) ترجع رقم    # ❌ كلمة ترجع
دالة جمع(أ، ب) -> رقم      # ❌ سهم
دالة جمع(أ، ب): رقم        # ❌ نقطتان
# ✅ الصحيح: دالة رقم جمع(أ، ب)
```

### معاملات الدالة

```sad
# 🟢 أساسية — مع نوع ووسيط افتراضي
دالة تحية(اسم: نص، لغة: نص = "عربية")
    # ...
نهاية

# 🟢 أساسية — بدون نوع (استنتاج تلقائي)
دالة اطبع_مرتين(قيمة)
    اطبع(قيمة)
    اطبع(قيمة)
نهاية
```

### الدالة الرئيسية

```sad
# 🟢 أساسية
دالة رئيسية()
    اطبع("مرحبا بالعالم!")
نهاية
```

### الدالة غير المتزامنة

```sad
# 🟢 الصيغة الوحيدة — الصفة بعد الموصوف (قاعدة عربية)
دالة غير_متزامن نص جلب_بيانات(رابط: نص)
    متغير نتيجة = انتظر طلب_شبكة(رابط)
    ارجع نتيجة
نهاية
```

> ❌ `غير_متزامن دالة` — أُزيلت (الصفة قبل الاسم مخالفة لقواعد العربية)

### الدالة الخارجية (FFI)

```sad
# 🟢 أساسية — مع اسم الربط
خارجي "C" دالة رقم printf(نص التنسيق)

# 🟡 بديلة — بدون اسم الربط
خارجي دالة رقم clear_screen()
```

## 4. الشروط والحلقات

### جملة الشرط

```sad
# 🟢 أساسية
إذا (س > 10)
    اطبع("كبير")
وإلا إذا (س > 5)
    اطبع("متوسط")
وإلا
    اطبع("صغير")
نهاية
```

### حلقة بينما

```sad
# 🟢 أساسية
بينما (العداد < 10)
    اطبع(العداد)
    العداد += 1
نهاية
```

### حلقة لكل

```sad
# 🟢 بدون أقواس (العربية لا تستخدم أقواس)
لكل عنصر في [1، 2، 3]
    اطبع(عنصر)
نهاية

# 🟢 مع فهرس
لكل فهرس، قيمة في القائمة
    اطبع(فهرس، قيمة)
نهاية

# 🟢 نطاق
لكل ع من 1 الى 10
    اطبع(ع)
نهاية
```

> ❌ `لكل (عنصر في قائمة)` بأقواس — أُزيلت

### جملة باستخدام

```sad
# 🟢 الصيغة الوحيدة — بـ "نهاية"
باستخدام افتح("بيانات.txt") كـ ملف
    اطبع(ملف.اقرأ())
نهاية
```

> ❌ `نهاية_استخدام` — أُزيلت، استخدم `نهاية` فقط

### التحكم في الحلقات

```sad
# 🟢 أساسية
توقف                              # break
استمر                             # continue
```

## 5. اللامدا

### 🟢 أساسية — سهم مع أقواس

```sad
متغير مضاعف = لامدا(س) => س * 2
متغير جامع = لامدا(أ، ب) => أ + ب
```

> **لماذا؟** الأقواس توضح المعاملات، والسهم يوضح الجسم.

### 🟡 بديلة — لامدا متعددة الأسطر (بدون فاصل)

```sad
متغير معالج = لامدا(قيمة)
    إذا (قيمة > 0)
        ارجع قيمة * 2
    نهاية
    ارجع 0
نهاية
```

### 🟡 بديلة — لامدا سهم مع كتلة

```sad
متغير معالج = لامدا(قيمة) => إذا (قيمة > 0)
    ارجع قيمة * 2
نهاية
```

> **ملاحظة:** الأقواس حول المعاملات إلزامية دائماً.

### ❌ صيغ مُزالة (لم تعد مدعومة)

```
# تمت إزالة هذه الصيغ من اللغة:
لامدا س: س + 1              # بدون أقواس + نقطتين
لامدا(س): اطبع(س) نهاية     # نقطتان بدلاً من سهم
لامدا(س) { ارجع س + 1 }     # أقواس معقوفة
(ن: ن * 2)                   # لامدا مختصرة
س => س * س                   # دالة سهم بدون لامدا
دالة(أ، ب) ارجع أ + ب نهاية  # دالة مجهولة
```

## 6. البرمجة الكائنية

### تعريف الصنف

```sad
# 🟢 أساسية — بكلمة "يرث" (عربية طبيعية)
صنف طالب يرث شخص نفّذ قابل_للطباعة
    متغير عام الاسم
    متغير خاص العمر

    باني(هذا.الاسم، هذا.عمر)
        الأساس("طالب")
    نهاية

    دالة عام وصف()
        ارجع "الطالب: " + هذا.الاسم
    نهاية
نهاية
```

### الوراثة

```sad
# 🟢 الطريقة الوحيدة — كلمة "يرث"
صنف قطة يرث حيوان
    # ...
نهاية
```

> **ملاحظة:** الوراثة بالنقطتين `:` (مثل C++) تمت إزالتها.

### الباني

```sad
# 🟢 أساسية — كلمة "باني"
باني(هذا.الاسم، هذا.العمر)
    اطبع("تم الإنشاء")
نهاية

# 🟡 بديلة — مع استدعاء الأساس
باني(اسم: نص) : الأساس(اسم)
    هذا.الاسم = اسم
نهاية
```

> **ملاحظة:** استخدام اسم الصنف كباني (مثل C++) تم إزاته. استخدم `باني` فقط.

### الخصائص

```sad
# 🟢 أساسية — النوع ثم الاسم
خاصية رقم العمر
    احصل
        ارجع هذا._عمر
    نهاية
    عيّن(قيمة)
        هذا._عمر = قيمة
    نهاية
نهاية
```

### تحميل العوامل

```sad
# 🟢 أساسية
عام عامل +(آخر: متجه) متجه
    ارجع متجه(هذا.س + آخر.س، هذا.ص + آخر.ص)
نهاية
```

### المعدّلات

```sad
# 🟢 أساسية — بالعربية دائماً
دالة عام طريقة()       # ✅
متغير خاص حقل            # ✅
دالة محمي مساعد()       # ✅
دالة ساكن مشتركة()      # ✅
دالة مجرد يجب_التنفيذ()  # ✅
```

## 7. مطابقة الأنماط

### 🟢 أساسية — طابق مع عندما

```sad
طابق (العمر)
    عندما 0..13:
        اطبع("طفل")
    عندما 13..20:
        اطبع("مراهق")
    عندما ن إذا ن > 60:
        اطبع("كبير في السن")
    افتراضي:
        اطبع("بالغ")
نهاية
```

### أنماط متقدمة

```sad
# 🟢 أساسية
طابق (بيانات)
    عندما [أول، *باقي]:                      # تفكيك قائمة
        اطبع("الأول: " + أول)
    عندما {اسم: ن، عمر: ع} إذا ع > 18:     # تفكيك بنية + حارس
        اطبع(ن + " بالغ")
    عندما 1 || 2 || 3:                       # بدائل
        اطبع("رقم صغير")
    عندما لون.أحمر:                          # عضو تعداد مؤهل
        اطبع("أحمر!")
    افتراضي:
        اطبع("غير معروف")
نهاية
```

### 🔴 توافقية — حالة (switch)

```sad
# حالة بدون أقواس (الصيغة الوحيدة المدعومة)
حالة النوع
    عندما "أ":
        # ...
    افتراضي:
        # ...
نهاية
```

> ❌ `حالة (تعبير)` بأقواس — أُزيلت.
> **لماذا؟** `طابق` أقوى ويدعم الأنماط، `حالة` محدود بالقيم الحرفية.

## 8. الوحدات والتصدير

### الاستيراد

```sad
# 🟢 أساسية — من ... استورد
من رياضيات استورد جذر، قوة             # الأكثر عربية: "من X استورد Y"

# 🟡 بديلة — استورد مباشر
استورد رياضيات
استورد رياضيات كـ م                    # مع إعادة تسمية

# 🟡 بديلة — استيراد كل شيء
من رياضيات استورد *
```

### التصدير

```sad
# 🟢 أساسية — قبل التصريح
صدّر دالة جمع(أ، ب)
    ارجع أ + ب
نهاية

# 🟡 بديلة — تصدير مجمّع
صدّر {جمع، طرح، ضرب}
```

## 9. البنى والتعدادات

### البنية

```sad
# 🟢 أساسية — بنهاية
بنية نقطة
    عشري س = 0.0
    عشري ص = 0.0

    دالة عشري مسافة(أخرى: نقطة)
        ارجع ((هذا.س - أخرى.س)**2 + (هذا.ص - أخرى.ص)**2)**0.5
    نهاية
نهاية
```

> **ملاحظة:** صيغة الأقواس المعقوصة `{ }` تمت إزالتها. استخدم `نهاية` فقط.

### التعداد

```sad
# 🟢 أساسية — بنهاية
تعداد اتجاه
    شمال = 0
    جنوب = 1
    شرق = 2
    غرب = 3
نهاية
```

> **ملاحظة:** صيغة الأقواس المعقوصة `{ }` تمت إزالتها. استخدم `نهاية` فقط.

### السمة والتنفيذ

```sad
# 🟢 أساسية
سمة قابل_للطباعة
    دالة نص إلى_نص()
نهاية

نفّذ قابل_للطباعة لـ شخص
    دالة نص إلى_نص()
        ارجع هذا.الاسم
    نهاية
نهاية
```

## 10. الفواصل والمحددات

### 🟢 أساسية — فاصلة عربية

```sad
دالة ج(أ، ب، ج)                      # ✅ فاصلة عربية ،
متغير قائمة = [1، 2، 3]
```

### 🟡 بديلة — فاصلة لاتينية

```sad
دالة ج(أ, ب, ج)                      # مقبول عند الكتابة بلوحة إنجليزية
```

### الفاصلة المنقوطة

```sad
# 🟢 أساسية — بدون فاصلة منقوطة (الأسطر الجديدة كافية)
متغير س = 10
متغير ص = 20

# 🟡 بديلة — فاصلة منقوطة عربية لفصل جمل بنفس السطر
متغير س = 10؛ متغير ص = 20
```

### التعليقات

```sad
# 🟢 أساسية — تعليق سطر
# هذا تعليق

# 🟢 أساسية — تعليق كتلة
#*
   هذا تعليق
   متعدد الأسطر
*#

# 🟢 أساسية — تعليق توثيقي
## يحسب مجموع عددين
## @معامل أ - العدد الأول
## @معامل ب - العدد الثاني
## @ترجع مجموع العددين
دالة رقم جمع(أ، ب)
    ارجع أ + ب
نهاية
```

## 11. القوالب وفضاء الأسماء

### القوالب

```sad
# 🟢 أساسية
قالب<ت: قابل_للمقارنة> دالة مصفوفة<ت> ترتيب(قائمة: مصفوفة<ت>)
    # ...
نهاية

# 🟢 أساسية — صنف قالب
قالب<ت> صنف صندوق
    خاصية ت المحتوى
    باني(هذا.المحتوى)
    نهاية
نهاية
```

### فضاء الأسماء

```sad
# 🟢 أساسية — بـ نهاية_فضاء (أوضح)
فضاء رياضيات
    دالة جمع(أ، ب)
        ارجع أ + ب
    نهاية
نهاية_فضاء

# 🔴 توافقية — بأقواس أو نهاية
فضاء رياضيات { ... }
```

### الاختبارات

```sad
# 🟢 أساسية — بدون أقواس
# 🟢 الصيغة الوحيدة — بأقواس إلزامية
اختبر("اختبار الجمع")
    أكد(جمع(2، 3) == 5)
نهاية

اختبر("اختبار الطرح")
    أكد(طرح(5، 3) == 2)
نهاية
```

> ❌ `اختبر "اسم"` بدون أقواس — أُزيلت

## 12. جدول ملخص الصيغ

| البنية | 🟢 أساسية | 🟡 بديلة | 🔴 توافقية |
|--------|-----------|----------|-----------|
| **متغير** | `متغير اسم: نوع = قيمة` | `نوع اسم = قيمة` | `متغير نوع_كاسم = قيمة` |
| **ثابت** | `ثابت اسم: نوع = قيمة` | — | — |
| **نوع إرجاع** | `دالة نوع اسم()` | — | ~~`ترجع نوع`~~، ~~`-> نوع`~~، ~~`(): نوع`~~ (مُزالة) |
| **كتلة** | `... نهاية` | — | `{ ... }` |
| **لامدا** | `لامدا(x) => expr` | `لامدا(x) body نهاية` | ~~`لامدا x: expr`~~، ~~`لامدا(){}`~~، ~~`x => expr`~~ (مُزالة) |
| **حلقة** | `لكل x في قائمة` | `لكل x من 1 الى 10` | ~~`لكل (x في قائمة)`~~ (مُزالة) |
| **وراثة** | `صنف أ يرث ب` | — | ~~`صنف أ : ب`~~ (مُزالة) |
| **سمة** | `سمة اسم` | — | ~~`واجهة اسم`~~ (مُزالة) |
| **تنفيذ** | `نفّذ سمة لـ صنف` | `نفّذ صنف` | — |
| **استيراد** | `من وحدة استورد عناصر` | `استورد وحدة` | — |
| **مطابقة** | `طابق` + `عندما` ... `نهاية` | — | ~~`طابق { ... }`~~، ~~`حالة نمط:` في فروع المطابقة~~ (مُزالة) |
| **تبديل** | `حالة تعبير` بدون أقواس | — | ~~`حالة (تعبير)`~~ (مُزالة) |
| **فاصلة** | `،` (عربية) | `,` (لاتينية) | — |
| **فضاء** | `فضاء ... نهاية_فضاء` | `فضاء ... نهاية` | ~~`فضاء { ... }`~~ (مُزالة) |
| **تعداد** | `تعداد ... نهاية` | — | ~~`تعداد { ... }`~~ (مُزالة) |
| **بنية** | `بنية ... نهاية` | — | ~~`بنية { ... }`~~ (مُزالة) |
| **اختبار** | `اختبر("اسم")` | — | ~~`اختبر "اسم"`~~ (مُزالة) |
| **غير متزامن** | `دالة غير_متزامن اسم()` | — | ~~`غير_متزامن دالة`~~ (مُزالة) |
| **مولّد** | `مولد دالة اسم()` | — | ~~`دالة مولد`~~ (مُزالة) |
| **إنتاج** | `أنتج قيمة` | — | ~~`اعطِ`~~ (مُزالة) |
| **باستخدام** | `باستخدام ... نهاية` | — | ~~`نهاية_استخدام`~~ (مُزالة) |
| **امسك** | `امسك خطأ` بدون أقواس | — | ~~`امسك (خطأ)`~~ (مُزالة) |
| **نوع عشري** | `عشري` | — | ~~`مضاعف`~~ (مُزالة) |

## ملاحظة للمنسق (Formatter)

ينبغي أن يقوم المنسق (`sad_formatter`) بالتحويلات التالية عند تفعيل وضع "التنسيق الصارم":

1. **الفواصل:** `,` → `،` (كلاهما مدعوم، لكن `،` أفضل في الكود العربي)
2. **المنقوطات:** `;` → `؛` (كلاهما مدعوم، لكن `؛` أفضل في الكود العربي)
3. **الوراثة:** `يرث` فقط (الوراثة بـ `:` مُزالة)
4. **لامدا:** الأقواس حول المعاملات إلزامية (لم تعد الصيغ القديمة مدعومة)

> **ملاحظة:** الصيغ التالية أُزيلت ولم تعد بحاجة لتحويل — ستُنتج خطأ مباشرة:
> - نوع الإرجاع بعد المعاملات (`ترجع`، `->`، `:`)
> - `واجهة` (استخدم `سمة`)
> - `{ }` في البنى والتعدادات والمطابقة وفضاء الأسماء (استخدم `نهاية`)
> - `لكل (...)` بأقواس — استخدم `لكل ... في ...` بدون أقواس
> - `حالة (تعبير)` بأقواس — استخدم `حالة تعبير` بدون أقواس
> - `اختبر "اسم"` بدون أقواس — استخدم `اختبر("اسم")`
> - `غير_متزامن دالة` — استخدم `دالة غير_متزامن`
> - `دالة مولد` — استخدم `مولد دالة`
> - `نهاية_استخدام` — استخدم `نهاية`
> - `اعطِ` — استخدم `أنتج`
> - `امسك (خطأ)` بأقواس — استخدم `امسك خطأ` بدون أقواس
> - `حالة نمط:` في فروع `طابق` — استخدم `عندما نمط:` فقط
> - `مضاعف` — استخدم `عشري`
