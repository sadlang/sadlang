# 🔀 التحكم في التدفق

## مقدمة

التحكم في التدفق يحدد مسار تنفيذ البرنامج. هل ينفذ هذا الكود أم ذاك؟ هل يكرر عملية معينة؟

ستتعلم في هذا الفصل:
- العبارات الشرطية (إذا/وإلا)
- مطابقة الأنماط (طابق/حالة)
- حلقات التكرار (بينما/لكل)
- أوامر التحكم (اكسر/استمر)

---

## 🔍 العبارات الشرطية

### إذا البسيطة

```س
دالة رئيسية()
    رقم العمر = 18
    
    إذا (العمر >= 18)
        اطبع("أنت بالغ ✅")
    نهاية
    
    ارجع 0
نهاية
```

**الشرح:**
- إذا كان العمر 18 أو أكثر، ينفذ الكود بالداخل
- إذا كان أقل من 18، يتجاوز الكتلة بالكامل

### إذا/وإلا

```س
دالة رئيسية()
    رقم الدرجة = 55
    
    إذا (الدرجة >= 60)
        اطبع("ناجح! 🎉")
    وإلا
        اطبع("راسب 😢")
    نهاية
    
    ارجع 0
نهاية
```

### إذا/وإلا_إذا/وإلا (سلسلة شروط)

```س
دالة رئيسية()
    رقم درجة = 85
    
    اطبع("التقدير: ")
    
    إذا (درجة >= 90)
        اطبع("ممتاز 🌟")
    وإلا_إذا (درجة >= 80)
        اطبع("جيد جداً 👍")
    وإلا_إذا (درجة >= 70)
        اطبع("جيد")
    وإلا_إذا (درجة >= 60)
        اطبع("مقبول")
    وإلا
        اطبع("راسب")
    نهاية
    
    ارجع 0
نهاية
```

**ملاحظات مهمة:**
- الشروط تُفحص بالترتيب من الأعلى للأسفل
- أول شرط صحيح يُنفَّذ، والباقي يُتجاوز
- `وإلا` اختيارية وتُنفَّذ إذا فشلت كل الشروط

### شروط مركبة

```س
دالة رئيسية()
    رقم العمر = 25
    منطقي لديه_رخصة = صحيح
    
    # شرط مركب باستخدام "و"
    إذا (العمر >= 18 و لديه_رخصة)
        اطبع("يمكنك القيادة 🚗")
    وإلا
        اطبع("لا يمكنك القيادة ❌")
    نهاية
    
    # شرط مركب باستخدام "أو"
    رقم اليوم = 6  # السبت
    إذا (اليوم == 6 أو اليوم == 7)
        اطبع("عطلة نهاية الأسبوع! 🎉")
    وإلا
        اطبع("يوم عمل 💼")
    نهاية
    
    ارجع 0
نهاية
```

### شروط متداخلة

```س
دالة رئيسية()
    رقم العمر = 25
    نص الجنسية = "سعودي"
    
    إذا (العمر >= 18)
        اطبع("بالغ\n")
        
        إذا (الجنسية == "سعودي")
            اطبع("يحق لك التصويت ✅")
        وإلا
            اطبع("التصويت للمواطنين فقط")
        نهاية
    وإلا
        اطبع("قاصر - لا يحق لك التصويت")
    نهاية
    
    ارجع 0
نهاية
```

## 🎯 مطابقة الأنماط (طابق)

`طابق` بديل أنيق لسلسلة طويلة من `إذا/وإلا_إذا`:

### مطابقة قيمة بسيطة

```س
دالة رئيسية()
    رقم يوم = 3
    
    طابق يوم
        حالة 1: اطبع("الأحد")
        حالة 2: اطبع("الاثنين")
        حالة 3: اطبع("الثلاثاء")
        حالة 4: اطبع("الأربعاء")
        حالة 5: اطبع("الخميس")
        حالة 6: اطبع("الجمعة")
        حالة 7: اطبع("السبت")
        حالة _: اطبع("يوم غير صالح!")
    نهاية
    
    ارجع 0
نهاية
```

**ملاحظة:** `حالة _` تطابق أي قيمة أخرى (مثل `default` في لغات أخرى)

### مطابقة نطاقات

```س
دالة رئيسية()
    رقم درجة = 85
    
    طابق درجة
        حالة 90..100: اطبع("ممتاز 🌟")
        حالة 80..89: اطبع("جيد جداً 👍")
        حالة 70..79: اطبع("جيد")
        حالة 60..69: اطبع("مقبول")
        حالة 0..59: اطبع("راسب")
        حالة _: اطبع("درجة غير صالحة!")
    نهاية
    
    ارجع 0
نهاية
```

### مطابقة نصوص

```س
دالة رئيسية()
    نص أمر = "مساعدة"
    
    طابق أمر
        حالة "ابدأ": اطبع("بدء التشغيل...")
        حالة "أوقف": اطبع("إيقاف...")
        حالة "مساعدة": اطبع("الأوامر المتاحة: ابدأ، أوقف، مساعدة، خروج")
        حالة "خروج": اطبع("وداعاً!")
        حالة _: اطبع("أمر غير معروف")
    نهاية
    
    ارجع 0
نهاية
```

### مقارنة: إذا vs طابق

```س
# ❌ باستخدام إذا (طويل ومكرر)
إذا (لون == "أحمر")
    اطبع("#FF0000")
وإلا_إذا (لون == "أخضر")
    اطبع("#00FF00")
وإلا_إذا (لون == "أزرق")
    اطبع("#0000FF")
وإلا
    اطبع("لون غير معروف")
نهاية

# ✅ باستخدام طابق (أنظف وأوضح)
طابق لون
    حالة "أحمر": اطبع("#FF0000")
    حالة "أخضر": اطبع("#00FF00")
    حالة "أزرق": اطبع("#0000FF")
    حالة _: اطبع("لون غير معروف")
نهاية
```

## 🔄 حلقات التكرار

### حلقة بينما (while)

تكرر الكود طالما الشرط صحيح:

```س
دالة رئيسية()
    رقم عداد = 1
    
    بينما (عداد <= 5)
        اطبع(عداد)
        اطبع(" ")
        عداد = عداد + 1
    نهاية
    
    # يطبع: 1 2 3 4 5
    ارجع 0
نهاية
```

**⚠️ تحذير:** تأكد من أن الشرط سيصبح خاطئاً في النهاية، وإلا ستدخل في حلقة لا نهائية!

```س
# ❌ حلقة لا نهائية - لا تفعل هذا!
رقم س = 1
بينما (س > 0)
    اطبع(س)  # س دائماً أكبر من 0، لن تتوقف أبداً!
نهاية
```

### مثال: جمع الأرقام

```س
دالة رئيسية()
    # جمع الأرقام من 1 إلى 100
    رقم مجموع = 0
    رقم ع = 1
    
    بينما (ع <= 100)
        مجموع = مجموع + ع
        ع = ع + 1
    نهاية
    
    اطبع("مجموع الأرقام من 1 إلى 100 = ")
    اطبع(مجموع)  # يطبع: 5050
    
    ارجع 0
نهاية
```

### حلقة لكل (foreach)

للتكرار على عناصر مصفوفة:

```س
دالة رئيسية()
    مصفوفة أسماء = ["أحمد"، "سارة"، "محمد"، "فاطمة"]
    
    لكل (اسم في أسماء)
        اطبع("مرحباً ")
        اطبع(اسم)
        اطبع("!\n")
    نهاية
    
    ارجع 0
نهاية
```

**النتيجة:**
```
مرحباً أحمد!
مرحباً سارة!
مرحباً محمد!
مرحباً فاطمة!
```

### مثال: حساب المتوسط

```س
دالة رئيسية()
    مصفوفة درجات = [85، 90، 78، 92، 88]
    رقم مجموع = 0
    رقم عدد = 0
    
    لكل (درجة في درجات)
        مجموع = مجموع + درجة
        عدد = عدد + 1
    نهاية
    
    عشري المتوسط = مجموع / عدد
    اطبع("المتوسط: ")
    اطبع(المتوسط)
    
    ارجع 0
نهاية
```

## ⏹️ أوامر التحكم في الحلقات

### اكسر (break)

يخرج من الحلقة فوراً:

```س
دالة رئيسية()
    # ابحث عن الرقم 5 في المصفوفة
    مصفوفة أرقام = [1، 3، 7، 5، 9، 2]
    
    لكل (رقم في أرقام)
        إذا (رقم == 5)
            اطبع("وجدت الرقم 5! 🎯")
            اكسر  # اخرج من الحلقة
        نهاية
        اطبع(رقم)
        اطبع(" ")
    نهاية
    
    ارجع 0
نهاية
```

**النتيجة:**
```
1 3 7 وجدت الرقم 5! 🎯
```

### استمر (continue)

يتخطى باقي الدورة الحالية وينتقل للدورة التالية:

```س
دالة رئيسية()
    # اطبع الأرقام الفردية فقط
    رقم ع = 0
    
    بينما (ع < 10)
        ع = ع + 1
        
        إذا (ع % 2 == 0)  # إذا كان زوجياً
            استمر  # تخطاه
        نهاية
        
        اطبع(ع)
        اطبع(" ")
    نهاية
    
    # يطبع: 1 3 5 7 9
    ارجع 0
نهاية
```

## 🎯 أمثلة متقدمة

### مثال 1: لعبة تخمين الرقم

```س
دالة رئيسية()
    رقم السر = 7  # الرقم السري
    رقم محاولة = 0
    رقم عدد_المحاولات = 0
    
    اطبع("=== لعبة تخمين الرقم ===\n")
    اطبع("خمّن رقماً بين 1 و 10\n")
    
    بينما (محاولة != السر)
        # في التطبيق الحقيقي، نقرأ من المستخدم
        # هنا نحاكي بقيم ثابتة
        مصفوفة تخمينات = [3، 5، 8، 7]
        
        إذا (عدد_المحاولات >= 4)
            اكسر
        نهاية
        
        محاولة = تخمينات[عدد_المحاولات]
        عدد_المحاولات = عدد_المحاولات + 1
        
        اطبع("المحاولة ")
        اطبع(عدد_المحاولات)
        اطبع(": ")
        اطبع(محاولة)
        
        إذا (محاولة < السر)
            اطبع(" - الرقم أكبر ⬆️\n")
        وإلا_إذا (محاولة > السر)
            اطبع(" - الرقم أصغر ⬇️\n")
        وإلا
            اطبع(" - أحسنت! 🎉\n")
        نهاية
    نهاية
    
    ارجع 0
نهاية
```

### مثال 2: جدول الضرب

```س
دالة رئيسية()
    رقم الرقم = 7
    
    اطبع("=== جدول ضرب ")
    اطبع(الرقم)
    اطبع(" ===\n")
    
    رقم ع = 1
    بينما (ع <= 10)
        اطبع(الرقم)
        اطبع(" × ")
        اطبع(ع)
        اطبع(" = ")
        اطبع(الرقم * ع)
        اطبع("\n")
        ع = ع + 1
    نهاية
    
    ارجع 0
نهاية
```

### مثال 3: فحص الأعداد الأولية

```س
دالة رئيسية()
    رقم ن = 17
    منطقي أولي = صحيح
    
    إذا (ن <= 1)
        أولي = خطأ
    وإلا
        رقم ع = 2
        بينما (ع * ع <= ن)
            إذا (ن % ع == 0)
                أولي = خطأ
                اكسر
            نهاية
            ع = ع + 1
        نهاية
    نهاية
    
    اطبع(ن)
    إذا (أولي)
        اطبع(" عدد أولي ✅")
    وإلا
        اطبع(" ليس عدداً أولياً ❌")
    نهاية
    
    ارجع 0
نهاية
```

### مثال 4: قائمة الطعام

```س
دالة رئيسية()
    نص الاختيار = "2"
    
    اطبع("=== قائمة المطعم ===\n")
    اطبع("1. برجر 🍔\n")
    اطبع("2. بيتزا 🍕\n")
    اطبع("3. سلطة 🥗\n")
    اطبع("4. مشروبات 🥤\n\n")
    
    طابق الاختيار
        حالة "1":
            اطبع("اخترت: برجر\n")
            اطبع("السعر: 25 ريال")
        حالة "2":
            اطبع("اخترت: بيتزا\n")
            اطبع("السعر: 35 ريال")
        حالة "3":
            اطبع("اخترت: سلطة\n")
            اطبع("السعر: 15 ريال")
        حالة "4":
            اطبع("اخترت: مشروبات\n")
            اطبع("السعر: 8 ريال")
        حالة _:
            اطبع("اختيار غير صالح!")
    نهاية
    
    ارجع 0
نهاية
```

## 💡 نصائح وأفضل الممارسات

### 1. تجنب الشروط المعقدة جداً
```س
# ❌ صعب القراءة
إذا (العمر >= 18 و (لديه_رخصة أو لديه_تصريح) و ليس محظور)
    # ...
نهاية

# ✅ أوضح
منطقي بالغ = العمر >= 18
منطقي مصرح = لديه_رخصة أو لديه_تصريح
منطقي مسموح = بالغ و مصرح و (ليس محظور)

إذا (مسموح)
    # ...
نهاية
```

### 2. استخدم طابق للقيم المحددة
```س
# استخدم طابق عندما تقارن متغيراً بقيم ثابتة متعددة
طابق الحالة
    حالة "نشط": # ...
    حالة "معلق": # ...
    حالة "ملغى": # ...
نهاية
```

### 3. تجنب الحلقات اللانهائية
```س
# ✅ تأكد دائماً من وجود شرط خروج
رقم عداد = 0
رقم الحد_الأقصى = 1000  # حماية إضافية

بينما (لم_ينتهِ و عداد < الحد_الأقصى)
    # ...
    عداد = عداد + 1
نهاية
```

## ✅ تمارين

### تمرين 1: الفصول الأربعة
اكتب برنامجاً يأخذ رقم الشهر (1-12) ويطبع الفصل المناسب.

### تمرين 2: الأعداد الأولية
اطبع جميع الأعداد الأولية بين 1 و 50.

### تمرين 3: المضاعفات
اطبع الأرقام من 1 إلى 30، لكن:
- إذا كان من مضاعفات 3، اطبع "فز"
- إذا كان من مضاعفات 5، اطبع "بز"
- إذا كان من مضاعفات كليهما، اطبع "فزبز"
