# استدلال الأنواع في لغة ص

## مقدمة

تُعد ميزة استدلال الأنواع (Type Inference) من أهم الميزات التي تجعل البرمجة بلغة ص تجربة سلسة وممتعة. فبدلاً من إجبار المبرمج على كتابة نوع كل متغير بشكل صريح، تقوم لغة ص تلقائياً بتحديد النوع المناسب بناءً على القيمة المُسندة إلى المتغير. هذه الميزة تجمع بين مرونة اللغات الديناميكية مثل Python وأمان اللغات ذات الأنواع الثابتة مثل C++، مما يمنحك أفضل ما في العالمين.

عندما تكتب برنامجاً بلغة ص، لا تحتاج للقلق بشأن تحديد الأنواع في كل مرة تُنشئ فيها متغيراً جديداً. المترجم ذكي بما يكفي ليفهم ما تقصده من خلال القيمة التي تُسندها. هذا يعني كوداً أقصر وأكثر قابلية للقراءة، مع الحفاظ على جميع مزايا فحص الأنواع أثناء التنفيذ.

## للمبتدئين: أساسيات استدلال الأنواع

### ما هو استدلال الأنواع؟

تخيل أنك تتحدث مع صديق وتقول له "أعطني الرقم خمسة". صديقك يفهم تلقائياً أنك تتحدث عن رقم وليس عن نص أو أي شيء آخر. هذا بالضبط ما يفعله مترجم لغة ص - إنه يفهم نوع البيانات من السياق دون أن تحتاج لإخباره صراحةً.

في اللغات التقليدية، كنت مضطراً لكتابة شيء مثل:
```
رقم س = 42
نص اسم = "أحمد"
عشري سعر = 19.99
```

لكن في لغة ص، يمكنك ببساطة كتابة:
```
س = 42
اسم = "أحمد"
سعر = 19.99
```

المترجم يفهم تلقائياً أن `س` هو رقم صحيح، و`اسم` هو نص، و`سعر` هو رقم عشري.

### أمثلة بسيطة للمبتدئين

#### المثال الأول: الأرقام
```
دالة رئيسية() {
    # المترجم يعرف أن هذا رقم صحيح
    عمري = 25
    
    # يمكنك إجراء عمليات حسابية عليه
    عمري_بعد_عام = عمري + 1
    
    اطبع(عمري_بعد_عام)  # يطبع: 26
}
```

#### المثال الثاني: النصوص
```
دالة رئيسية() {
    # المترجم يعرف أن هذا نص
    رسالة = "مرحباً بك في لغة ص!"
    
    # يمكنك معرفة طول النص
    عدد_الحروف = طول(رسالة)
    
    اطبع(رسالة)
    اطبع(عدد_الحروف)
}
```

#### المثال الثالث: العمليات الحسابية المركبة
```
دالة رئيسية() {
    سعر_المنتج = 100
    نسبة_الخصم = 20
    
    # المترجم يستنتج أن النتيجة رقم
    السعر_النهائي = سعر_المنتج - (سعر_المنتج * نسبة_الخصم / 100)
    
    اطبع(السعر_النهائي)  # يطبع: 80
}
```

## للمستوى المتوسط: فهم آلية الاستدلال

### كيف يعمل استدلال الأنواع؟

عندما تكتب تعبيراً في لغة ص، يقوم المترجم بتحليل القيمة المُسندة ويحدد نوعها بناءً على عدة قواعد واضحة. هذه العملية تحدث في مرحلة التحليل وتُنفذ أثناء وقت التشغيل، مما يعني أن البرنامج يحافظ على مرونته مع ضمان صحة العمليات.

### جدول أنواع البيانات المُستدلة

| القيمة | النوع المُستدل | مثال |
|--------|---------------|------|
| أرقام صحيحة | رقم (INTEGER) | `س = 42` |
| أرقام عشرية | عشري (FLOAT) | `س = 3.14` |
| نصوص بين علامات تنصيص | نص (STRING) | `س = "مرحبا"` |
| صحيح أو خطأ | منطقي (BOOLEAN) | `س = صحيح` |
| قائمة قيم | مصفوفة (ARRAY) | `س = [1, 2, 3]` |

### استدلال الأنواع في التعبيرات المركبة

عندما يكون لديك تعبير يجمع بين عدة قيم، يقوم المترجم بتحديد النوع النهائي بناءً على نوع العملية والمعاملات. على سبيل المثال، إذا جمعت رقمين صحيحين، فالنتيجة ستكون رقماً صحيحاً. وإذا جمعت نصين، فالنتيجة ستكون نصاً مدمجاً.

```
دالة رئيسية() {
    # جمع رقمين → رقم
    أ = 10
    ب = 20
    المجموع = أ + ب  # المجموع من نوع رقم
    
    # دمج نصين → نص
    الاسم_الأول = "محمد"
    الاسم_الأخير = "أحمد"
    الاسم_الكامل = الاسم_الأول + " " + الاسم_الأخير  # نص
    
    # تحويل الأنواع صريح
    رقم_نصي = "123"
    رقم_فعلي = لرقم(رقم_نصي)  # تحويل من نص إلى رقم
    
    اطبع(المجموع)       # 30
    اطبع(الاسم_الكامل)  # محمد أحمد
    اطبع(رقم_فعلي + 7)  # 130
}
```

### التعامل مع الدوال المدمجة

تدعم لغة ص مجموعة من الدوال المدمجة التي يمكنك استخدامها مباشرة. هذه الدوال متاحة بأسماء عربية وإنجليزية لتناسب تفضيلاتك:

```
دالة رئيسية() {
    نص_تجريبي = "Hello World"
    
    # دالة الطول - يمكن استخدامها بأي من هذه الأسماء:
    # طول، الطول، length، len
    الطول = طول(نص_تجريبي)
    اطبع(الطول)  # 11
    
    # تحويل من نص إلى رقم - الأسماء المتاحة:
    # لرقم، to_int، int
    قيمة_نصية = "42"
    قيمة_رقمية = لرقم(قيمة_نصية)
    اطبع(قيمة_رقمية * 2)  # 84
    
    # تحويل من رقم إلى نص - الأسماء المتاحة:
    # لنص، نص، to_string، str، string
    رقم = 2024
    سنة_نصية = لنص(رقم)
    اطبع("السنة الحالية: " + سنة_نصية)
}
```

## للمستوى المتقدم: أفضل الممارسات والحالات الخاصة

### متى تستخدم التصريح الصريح؟

على الرغم من قوة استدلال الأنواع، هناك حالات يُفضل فيها التصريح الصريح عن النوع لتحسين قابلية قراءة الكود أو لتوثيق نيتك البرمجية:

```
دالة رئيسية() {
    # استدلال تلقائي - مناسب للمتغيرات المحلية البسيطة
    عداد = 0
    رسالة = "جاري المعالجة..."
    
    # تصريح صريح - مفيد للوضوح في الحالات المعقدة
    رقم المجموع_الكلي = 0
    نص التقرير_النهائي = ""
    
    # كلا الأسلوبين صحيح ويعمل بنفس الكفاءة
}
```

### سلوك إعادة التعيين

في لغة ص، عندما تُعيد تعيين قيمة لمتغير موجود، يحتفظ المتغير بقيمته الجديدة. هذا السلوك مشابه للغات الديناميكية ويمنحك مرونة كبيرة:

```
دالة رئيسية() {
    # تعريف أولي
    قيمة = 100
    اطبع(قيمة)  # 100
    
    # إعادة تعيين بقيمة جديدة
    قيمة = قيمة + 50
    اطبع(قيمة)  # 150
    
    # يمكنك حتى إعادة تعيين بنوع مختلف
    # (مع الحذر في استخدام هذه الميزة)
    قيمة = "انتهى الحساب"
    اطبع(قيمة)  # انتهى الحساب
}
```

### نطاق المتغيرات

المتغيرات التي تُنشئها باستخدام استدلال الأنواع تتبع نفس قواعد النطاق (Scope) كأي متغير آخر في لغة ص:

```
دالة رئيسية() {
    # متغير في النطاق الرئيسي
    رسالة_عامة = "مرحبا"
    
    إذا صحيح {
        # متغير محلي داخل الشرط
        رسالة_محلية = "داخل الشرط"
        اطبع(رسالة_محلية)
        
        # يمكن الوصول للمتغير العام
        اطبع(رسالة_عامة)
    }
    
    # رسالة_عامة لا تزال متاحة هنا
    اطبع(رسالة_عامة)
}
```

## أمثلة عملية شاملة

### مثال 1: حاسبة بسيطة

```
دالة رئيسية() {
    # إدخال الأرقام
    الرقم_الأول = 50
    الرقم_الثاني = 30
    
    # العمليات الحسابية الأساسية
    الجمع = الرقم_الأول + الرقم_الثاني
    الطرح = الرقم_الأول - الرقم_الثاني
    الضرب = الرقم_الأول * الرقم_الثاني
    القسمة = الرقم_الأول / الرقم_الثاني
    
    # عرض النتائج
    اطبع(الجمع)    # 80
    اطبع(الطرح)    # 20
    اطبع(الضرب)    # 1500
    اطبع(القسمة)   # 1
}
```

### مثال 2: معالجة بيانات المستخدم

```
دالة رئيسية() {
    # بيانات المستخدم
    اسم_المستخدم = "علي"
    العمر = 28
    المدينة = "الرياض"
    
    # حساب سنة الميلاد
    السنة_الحالية = 2026
    سنة_الميلاد = السنة_الحالية - العمر
    
    # إنشاء رسالة ترحيب
    اطبع("مرحباً")
    اطبع(اسم_المستخدم)
    اطبع("من مدينة")
    اطبع(المدينة)
    اطبع("مواليد عام")
    اطبع(سنة_الميلاد)
}
```

### مثال 3: حساب المتوسط

```
دالة رئيسية() {
    # الدرجات
    درجة_الرياضيات = 85
    درجة_العلوم = 90
    درجة_اللغة = 88
    درجة_التاريخ = 92
    
    # حساب المجموع
    المجموع = درجة_الرياضيات + درجة_العلوم + درجة_اللغة + درجة_التاريخ
    
    # حساب المتوسط
    عدد_المواد = 4
    المتوسط = المجموع / عدد_المواد
    
    اطبع(المجموع)   # 355
    اطبع(المتوسط)   # 88
}
```

### مثال 4: معالجة النصوص

```
دالة رئيسية() {
    # نص للمعالجة
    جملة = "البرمجة بلغة ص ممتعة"
    
    # معرفة طول النص
    طول_الجملة = طول(جملة)
    اطبع(طول_الجملة)
    
    # تحويل رقم إلى نص للدمج
    عدد_الكلمات = 4
    تقرير = لنص(عدد_الكلمات)
    اطبع(تقرير)
}
```

## ملخص

استدلال الأنواع في لغة ص يجعل كتابة البرامج أسهل وأسرع دون التضحية بالوضوح أو الأمان. تذكر هذه النقاط الرئيسية:

- **البساطة**: اكتب `س = 42` بدلاً من `رقم س = 42`
- **المرونة**: المترجم يفهم نوع البيانات من القيمة المُسندة
- **التوافق**: يمكنك استخدام التصريح الصريح متى شئت
- **الدوال المدمجة**: استخدم `طول()` و`لرقم()` و`لنص()` بأسماء عربية أو إنجليزية

ابدأ بالأمثلة البسيطة وتدرج في التعقيد. ستجد أن استدلال الأنواع يجعل تجربة البرمجة بلغة ص أكثر متعة وإنتاجية.
