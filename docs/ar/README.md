# 📚 توثيق لغة ص الشامل

## مرحباً بك في عالم البرمجة بالعربية! 🌟

**لغة ص** هي لغة برمجة عربية حديثة صُممت لتكون سهلة التعلم وقوية في نفس الوقت. سواء كنت مبتدئاً لم تكتب سطر كود من قبل، أو مبرمجاً محترفاً يبحث عن تجربة جديدة، ستجد في لغة ص ما يناسبك.

---

## 🎯 لماذا لغة ص؟

### للمبتدئين
- **اكتب بلغتك الأم**: تخيل أن تتعلم البرمجة وأنت تقرأ وتكتب بالعربية!
- **بدون تعقيد**: صيغة بسيطة وواضحة، لا أقواس معقوفة `{}` مربكة
- **رسائل خطأ مفهومة**: عندما يحدث خطأ، ستفهم ما حدث بالعربية
- **أمثلة كثيرة**: عشرات الأمثلة الجاهزة للتعلم منها

### للمحترفين
- **نظام أنواع قوي**: استدلال أنواع ذكي مع فحص أنواع صارم
- **دعم الشبكات**: TCP، UDP، WebSocket، HTTP
- **البرمجة المتزامنة**: goroutines، channels، async/await
- **أنماط حديثة**: مطابقة الأنماط، المولدات، المزخرفات

## 🚀 ابدأ الآن!

```bash
# تحميل وتثبيت لغة ص
git clone https://github.com/sad-lang/sad
cd sad
cmake -B build
cmake --build build

# تشغيل أول برنامج
./build/bin/sad examples/test_hello.s
```

## 💡 نصيحة للمبتدئين

> **لا تخف من الأخطاء!** كل مبرمج محترف ارتكب آلاف الأخطاء قبل أن يصبح محترفاً.
> الأخطاء ليست فشلاً، بل هي الطريقة التي نتعلم بها.
> 
> ابدأ بالأمثلة البسيطة، جرب تعديلها، وشاهد ماذا يحدث. هذه هي أفضل طريقة للتعلم!
