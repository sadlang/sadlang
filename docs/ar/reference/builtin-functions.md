# 📚 الدوال المضمنة

## نظرة عامة

لغة ص تأتي مع مجموعة غنية من الدوال المضمنة التي تُسهل عليك البرمجة.

---

## 🖨️ الإدخال والإخراج

### `اطبع(قيمة)`
تطبع قيمة على الشاشة.

```س
اطبع("مرحباً!")       # يطبع: مرحباً!
اطبع(42)             # يطبع: 42
اطبع(3.14)           # يطبع: 3.14
اطبع(صحيح)           # يطبع: صحيح
```

### `اطبع_سطر(قيمة)`
تطبع قيمة مع سطر جديد في النهاية.

```س
اطبع_سطر("السطر الأول")
اطبع_سطر("السطر الثاني")
# النتيجة:
# السطر الأول
# السطر الثاني
```

### `اقرأ() -> نص`
تقرأ سطراً من المستخدم.

```س
اطبع("أدخل اسمك: ")
نص الاسم = اقرأ()
اطبع("مرحباً " + الاسم)
```

### `اقرأ_رقم() -> رقم`
تقرأ رقماً من المستخدم.

```س
اطبع("أدخل عمرك: ")
رقم العمر = اقرأ_رقم()
```

## 📏 دوال النصوص

### `طول(نص) -> رقم`
تُرجع طول النص.

```س
رقم ط = طول("مرحباً")  # 6
```

### `قص(نص) -> نص`
تزيل المسافات من البداية والنهاية.

```س
نص ن = قص("  مرحباً  ")  # "مرحباً"
```

### `كبّر(نص) -> نص`
تحوّل الحروف اللاتينية للأحرف الكبيرة.

```س
نص ن = كبّر("hello")  # "HELLO"
```

### `صغّر(نص) -> نص`
تحوّل الحروف اللاتينية للأحرف الصغيرة.

```س
نص ن = صغّر("HELLO")  # "hello"
```

### `قسّم(نص، فاصل) -> مصفوفة`
تقسم النص إلى مصفوفة.

```س
مصفوفة كلمات = قسّم("أحمد،سارة،محمد"، "،")
# ["أحمد"، "سارة"، "محمد"]
```

### `ادمج(مصفوفة، فاصل) -> نص`
تدمج مصفوفة إلى نص.

```س
نص ن = ادمج(["أ"، "ب"، "ج"]، "-")  # "أ-ب-ج"
```

### `استبدل(نص، قديم، جديد) -> نص`
تستبدل نصاً بنص آخر.

```س
نص ن = استبدل("مرحبا"، "ح"، "خ")  # "مرخبا"
```

### `يحتوي(نص، جزء) -> منطقي`
تتحقق من وجود نص فرعي.

```س
منطقي موجود = يحتوي("مرحباً بالعالم"، "بالعالم")  # صحيح
```

### `يبدأ_بـ(نص، بادئة) -> منطقي`
تتحقق إذا كان النص يبدأ ببادئة معينة.

```س
منطقي ن = يبدأ_بـ("مرحباً"، "مر")  # صحيح
```

### `ينتهي_بـ(نص، لاحقة) -> منطقي`
تتحقق إذا كان النص ينتهي بلاحقة معينة.

```س
منطقي ن = ينتهي_بـ("مرحباً"، "باً")  # صحيح
```

### `جد(نص، جزء) -> رقم`
تُرجع موقع أول ظهور للنص الفرعي، أو -1 إذا لم يُوجد.

```س
رقم موقع = جد("مرحباً بالعالم"، "بالعالم")  # 7
```

### `عدّ(نص، جزء) -> رقم`
تعدّ تكرارات النص الفرعي.

```س
رقم عدد = عدّ("أبابا"، "با")  # 2
```

### `نسّق(قالب، ...قيم) -> نص`
تنسّق نصاً مع قيم.

```س
نص ن = نسّق("الاسم: {}، العمر: {}"، "أحمد"، 25)
# "الاسم: أحمد، العمر: 25"
```

## 📊 دوال المصفوفات

### `طول(مصفوفة) -> رقم`
تُرجع عدد العناصر.

```س
رقم عدد = طول([1، 2، 3، 4، 5])  # 5
```

### `أضف(مصفوفة، قيمة)`
تضيف عنصراً في النهاية.

```س
مصفوفة م = [1، 2، 3]
أضف(م، 4)  # [1، 2، 3، 4]
```

### `أدرج(مصفوفة، فهرس، قيمة)`
تُدرج عنصراً في موقع محدد.

```س
مصفوفة م = [1، 3، 4]
أدرج(م، 1، 2)  # [1، 2، 3، 4]
```

### `احذف(مصفوفة، فهرس)`
تحذف عنصراً من موقع محدد.

```س
مصفوفة م = [1، 2، 3، 4]
احذف(م، 1)  # [1، 3، 4]
```

### `فارغة(مصفوفة) -> منطقي`
تتحقق إذا كانت المصفوفة فارغة.

```س
منطقي ن = فارغة([])  # صحيح
```

### `يحتوي(مصفوفة، قيمة) -> منطقي`
تتحقق من وجود قيمة.

```س
منطقي موجود = يحتوي([1، 2، 3]، 2)  # صحيح
```

### `موقع(مصفوفة، قيمة) -> رقم`
تُرجع فهرس أول ظهور للقيمة، أو -1.

```س
رقم فهرس = موقع([10، 20، 30]، 20)  # 1
```

### `رتّب(مصفوفة)`
ترتّب المصفوفة تصاعدياً.

```س
مصفوفة م = [3، 1، 4، 1، 5]
رتّب(م)  # [1، 1، 3، 4، 5]
```

### `اعكس(مصفوفة)`
تعكس ترتيب المصفوفة.

```س
مصفوفة م = [1، 2، 3]
اعكس(م)  # [3، 2، 1]
```

### `شريحة(مصفوفة، بداية، نهاية) -> مصفوفة`
تُرجع جزءاً من المصفوفة.

```س
مصفوفة جزء = شريحة([0، 1، 2، 3، 4]، 1، 4)  # [1، 2، 3]
```

## 🔢 دوال الأرقام

### `مطلق(رقم) -> رقم`
تُرجع القيمة المطلقة.

```س
رقم ن = مطلق(-5)  # 5
```

### `أقصى(أ، ب) -> رقم`
تُرجع الأكبر.

```س
رقم ن = أقصى(10، 20)  # 20
```

### `أدنى(أ، ب) -> رقم`
تُرجع الأصغر.

```س
رقم ن = أدنى(10، 20)  # 10
```

### `قوة(أساس، أس) -> رقم`
تحسب الأس.

```س
رقم ن = قوة(2، 10)  # 1024
```

### `جذر(رقم) -> عشري`
تحسب الجذر التربيعي.

```س
عشري ن = جذر(16)  # 4.0
```

### `تقريب(عشري) -> رقم`
تُقرّب لأقرب عدد صحيح.

```س
رقم ن = تقريب(3.7)  # 4
```

### `أرضية(عشري) -> رقم`
تُقرّب للأسفل.

```س
رقم ن = أرضية(3.9)  # 3
```

### `سقف(عشري) -> رقم`
تُقرّب للأعلى.

```س
رقم ن = سقف(3.1)  # 4
```

### `عشوائي() -> عشري`
تُرجع رقماً عشوائياً بين 0 و 1.

```س
عشري ن = عشوائي()  # مثلاً: 0.7234
```

### `عشوائي_نطاق(أدنى، أقصى) -> رقم`
تُرجع رقماً عشوائياً في نطاق.

```س
رقم ن = عشوائي_نطاق(1، 100)  # رقم بين 1 و 100
```

## 🔄 دوال التحويل

### `لرقم(قيمة) -> رقم`
تحوّل القيمة لرقم صحيح.

```س
رقم ن = لرقم("42")  # 42
رقم ن2 = لرقم(3.7)  # 3
```

### `لعشري(قيمة) -> عشري`
تحوّل القيمة لرقم عشري.

```س
عشري ن = لعشري("3.14")  # 3.14
عشري ن2 = لعشري(42)     # 42.0
```

### `لنص(قيمة) -> نص`
تحوّل القيمة لنص.

```س
نص ن = لنص(42)      # "42"
نص ن2 = لنص(صحيح)  # "صحيح"
```

### `لمنطقي(قيمة) -> منطقي`
تحوّل القيمة لمنطقي.

```س
منطقي ن = لمنطقي(1)   # صحيح
منطقي ن2 = لمنطقي(0)  # خطأ
منطقي ن3 = لمنطقي("صحيح")  # صحيح
```

## 📂 دوال الملفات

### `افتح(مسار، وضع) -> ملف`
تفتح ملفاً. الأوضاع: `"قراءة"`، `"كتابة"`، `"إضافة"`.

```س
متغير م = افتح("بيانات.txt"، "قراءة")
```

### `اقرأ_ملف(مسار) -> نص`
تقرأ محتوى ملف كاملاً.

```س
نص محتوى = اقرأ_ملف("بيانات.txt")
```

### `اكتب_ملف(مسار، محتوى)`
تكتب محتوى في ملف (يستبدل المحتوى القديم).

```س
اكتب_ملف("ناتج.txt"، "مرحباً بالعالم!")
```

### `أضف_لملف(مسار، محتوى)`
تضيف محتوى لنهاية ملف.

```س
أضف_لملف("سجل.txt"، "سطر جديد\n")
```

### `ملف_موجود(مسار) -> منطقي`
تتحقق من وجود ملف.

```س
إذا (ملف_موجود("بيانات.txt"))
    اطبع("الملف موجود")
نهاية
```

### `احذف_ملف(مسار)`
تحذف ملفاً.

```س
احذف_ملف("مؤقت.txt")
```

## ⏰ دوال الوقت

### `الآن() -> وقت`
تُرجع الوقت الحالي.

```س
متغير و = الآن()
اطبع(و.لنص())
```

### `انتظر(ميلي_ثانية)`
تنتظر مدة محددة.

```س
اطبع("انتظر 2 ثانية...")
انتظر(2000)
اطبع("تم!")
```

### `وقت_التنفيذ(دالة) -> رقم`
تقيس وقت تنفيذ دالة بالميلي ثانية.

```س
رقم الوقت = وقت_التنفيذ(دالة()
    # كود للقياس
نهاية)
اطبع("استغرق: " + لنص(الوقت) + " مللي ثانية")
```

## 🔍 دوال النوع

### `نوع(قيمة) -> نص`
تُرجع اسم نوع القيمة.

```س
اطبع(نوع(42))        # "رقم"
اطبع(نوع("مرحبا"))   # "نص"
اطبع(نوع([1، 2، 3])) # "مصفوفة"
```

### `هو_رقم(قيمة) -> منطقي`
تتحقق إذا كانت القيمة رقماً.

```س
منطقي ن = هو_رقم(42)      # صحيح
منطقي ن2 = هو_رقم("42")   # خطأ
```

### `هو_نص(قيمة) -> منطقي`
تتحقق إذا كانت القيمة نصاً.

```س
منطقي ن = هو_نص("مرحبا")  # صحيح
```

### `هو_مصفوفة(قيمة) -> منطقي`
تتحقق إذا كانت القيمة مصفوفة.

```س
منطقي ن = هو_مصفوفة([1، 2، 3])  # صحيح
```

### `هو_فارغ(قيمة) -> منطقي`
تتحقق إذا كانت القيمة فارغة (null).

```س
منطقي ن = هو_فارغ(فارغ)  # صحيح
```

## 🛠️ دوال متنوعة

### `نطاق(بداية، نهاية، خطوة؟) -> مصفوفة`
تُنشئ مصفوفة أرقام في نطاق.

```س
مصفوفة أ = نطاق(1، 5)      # [1، 2، 3، 4]
مصفوفة ب = نطاق(0، 10، 2) # [0، 2، 4، 6، 8]
```

### `خريطة(مصفوفة، دالة) -> مصفوفة`
تُطبّق دالة على كل عنصر.

```س
مصفوفة مربعات = خريطة([1، 2، 3]، دالة(س) 
    ارجع س * س 
نهاية)
# [1، 4، 9]
```

### `رشّح(مصفوفة، دالة) -> مصفوفة`
تُرشّح العناصر حسب شرط.

```س
مصفوفة زوجية = رشّح([1، 2، 3، 4، 5]، دالة(س) 
    ارجع س % 2 == 0 
نهاية)
# [2، 4]
```

### `اختزل(مصفوفة، دالة، قيمة_ابتدائية)`
تختزل المصفوفة لقيمة واحدة.

```س
رقم مجموع = اختزل([1، 2، 3، 4، 5]، دالة(تراكم، س)
    ارجع تراكم + س
نهاية، 0)
# 15
```

## 📋 جدول مرجعي سريع

### إدخال/إخراج
| الدالة | الوصف |
|--------|-------|
| `اطبع(قيمة)` | طباعة |
| `اطبع_سطر(قيمة)` | طباعة مع سطر جديد |
| `اقرأ()` | قراءة نص |
| `اقرأ_رقم()` | قراءة رقم |

### نصوص
| الدالة | الوصف |
|--------|-------|
| `طول(نص)` | طول النص |
| `قص(نص)` | إزالة المسافات |
| `كبّر(نص)` | أحرف كبيرة |
| `صغّر(نص)` | أحرف صغيرة |
| `قسّم(نص، فاصل)` | تقسيم |
| `ادمج(مصفوفة، فاصل)` | دمج |
| `استبدل(نص، قديم، جديد)` | استبدال |

### أرقام
| الدالة | الوصف |
|--------|-------|
| `مطلق(رقم)` | القيمة المطلقة |
| `أقصى(أ، ب)` | الأكبر |
| `أدنى(أ، ب)` | الأصغر |
| `قوة(أساس، أس)` | الأس |
| `جذر(رقم)` | الجذر التربيعي |
| `تقريب(عشري)` | تقريب |
| `عشوائي()` | رقم عشوائي |

### تحويل
| الدالة | الوصف |
|--------|-------|
| `لرقم(قيمة)` | تحويل لرقم |
| `لعشري(قيمة)` | تحويل لعشري |
| `لنص(قيمة)` | تحويل لنص |
| `لمنطقي(قيمة)` | تحويل لمنطقي |
