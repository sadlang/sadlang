## 3. العوامل (Operators)

### 3.1 العوامل الحسابية

### 3.2 عوامل المقارنة

## 4. بنيات التحكم في التدفق (Control Flow)

### 4.1 الشروط (if/else)

```sad
إذا (شرط)
    # كود
وإلا
    # كود بديل
نهاية

# مع else if
إذا (س < 13)
    ارجع "طفل"
والا_اذا (س < 18)
    ارجع "مراهق"
والا_اذا (س < 65)
    ارجع "بالغ"
وإلا
    ارجع "كبير"
نهاية
```

### 4.2 العامل الثلاثي (Ternary)

```sad
متغير وصف = س > 10 ? "كبير" : "صغير"
```

### 4.3 حلقة بينما (while)

```sad
متغير ع = 0
بينما (ع < 10)
    اطبع_سطر(ع)
    ع = ع + 1
نهاية
```

### 4.4 حلقة لكل (for-each)

```sad
# مع مصفوفة
لكل عنصر في [1, 2, 3, 4, 5]
    اطبع_سطر(عنصر)
نهاية

# مع نطاق
لكل ع في 1..10
    اطبع_سطر(ع)
نهاية
```

### 4.5 الخروج والمتابعة (break/continue)

```sad
بينما (صحيح)
    ع = ع + 1
    إذا (ع % 2 == 0)
        تابع    # انتقل للتكرار التالي
    نهاية
    إذا (ع >= 10)
        اخرج    # اخرج من الحلقة
    نهاية
نهاية
```

### 4.6 حالة/عندما (Switch/Case)

```sad
حالة (يوم)
    عندما 1:
        اطبع_سطر("الأحد")
    عندما 2:
        اطبع_سطر("الاثنين")
    عندما 3:
        اطبع_سطر("الثلاثاء")
    افتراضي:
        اطبع_سطر("يوم آخر")
نهاية
```

### 4.7 مطابقة الأنماط (Pattern Matching)

```sad
طابق (قيمة)
    عندما 1:
        اطبع("واحد")
    عندما 2:
        اطبع("اثنان")
    عندما "أحمر":
        اطبع("لون أحمر")
    افتراضي:
        اطبع("قيمة أخرى: " + قيمة)
نهاية
```

### 5.5 الدوال السهمية (Arrow Functions)

```sad

# تمرير كمعامل
```

### 5.6 الإغلاقات (Closures)

### 5.7 الدوال العليا (Higher-Order Functions)


### 5.8 الدوال المتداخلة

### 5.10 دوال المولد (Generator Functions)

## 6. البرمجة الكائنية (OOP)

### 6.1 تعريف الأصناف

```sad
صنف حيوان
    نص الاسم
    نص الصوت

    باني(اسم، صوت)
        هذا.الاسم = اسم
        هذا.الصوت = صوت
    نهاية

    دالة تكلم()
        ارجع هذا.الاسم + " يقول: " + هذا.الصوت
    نهاية
نهاية

متغير قطة = جديد حيوان("القطة"، "مياو")
اطبع_سطر(قطة.تكلم())
```

### 6.2 الوراثة (Inheritance)

```sad
صنف شكل
    باني(اللون)
        هذا.اللون = اللون
    نهاية

    دالة وصف()
        ارجع "شكل بلون " + هذا.اللون
    نهاية
نهاية

صنف مستطيل يرث شكل
    باني(اللون، العرض، الارتفاع)
        أصل(اللون)
        هذا.العرض = العرض
        هذا.الارتفاع = الارتفاع
    نهاية

    دالة المساحة()
        ارجع هذا.العرض * هذا.الارتفاع
    نهاية

    دالة وصف()   # تجاوز (override)
        ارجع "مستطيل " + هذا.العرض + "x" + هذا.الارتفاع
    نهاية
نهاية

# وراثة متعددة المستويات
صنف مربع يرث مستطيل
    باني(اللون، الضلع)
        أصل(اللون، الضلع، الضلع)
    نهاية
نهاية
```

### 6.3 الأعضاء الساكنة (Static Members)
