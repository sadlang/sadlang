## 1. المتغيرات والثوابت

**ملف المصدر الرئيسي:** `parser_declarations.cpp` (دالة `parseVarDecl`)

### الصيغ المدعومة

```sad
# الصيغة 1: متغير/ثابت
متغير اسم = قيمة
ثابت اسم = قيمة

# الصيغة 2: مع تحديد النوع
متغير اسم: نوع = قيمة

# الصيغة 3: النوع أولاً (type-first)
رقم عداد = 0
نص رسالة = "مرحباً"
عشري نسبة = 3.14

# الصيغة 4: كائنات الأصناف
متغير شخص1 = جديد شخص("أحمد")
شخص شخص2 = جديد شخص("سارة")
```

### ملاحظات
- **الفاصلة المنقوطة اختيارية** — يدعم `;` و `؛` وكلاهما اختياري.
- **أسماء الأنواع المدمجة** (`رقم`, `نص`, `عشري`, `منطقي`, `مصفوفة`, `خريطة`, `أي`) **ليست محجوزة** — يمكن استخدامها كأسماء متغيرات.
- **استنتاج النوع** — إذا لم يُحدد النوع والقيمة الأولية موجودة، يُستنتج من القيمة.
- يُدعم الإعلان بنوع صنف مسجل في `ClassManager`.


### أنواع الأنماط

```sad
طابق قيمة
   # نمط حرفي
   عندما 42: اطبع("الرقم")
   
   # نمط متغير
   عندما س: اطبع(س)
   
   # نمط عام (Wildcard)
   عندما _: اطبع("أي شيء")
   
   # نمط قائمة
   عندما [أ، ب، *باقي]: اطبع(أ)
   
   # نمط بديل (OR)
   عندما 1 | 2 | 3: اطبع("صغير")
نهاية
```

### شروط الحراسة (Guard Clauses)

```sad
طابق عدد
   عندما س إذا س > 0:
      اطبع("موجب")
   عندما س إذا س < 0:
      اطبع("سالب")
   عندما _:
      اطبع("صفر")
نهاية
```

- من `pattern_guard.cpp`: يتحقق أن الشرط يرجع قيمة منطقية، وأن المتغيرات المستخدمة مُربوطة في النمط.

### نمط القائمة المتقدم

```sad
عندما [أول، *وسط، آخر]:
   # أول = العنصر الأول
   # وسط = بقية العناصر (rest pattern)
   # آخر = العنصر الأخير
```

## 17. عامل الأنبوب (Pipeline)

**ملفات المصدر:** `parser_expressions.cpp` (دالة `parsePipeline`), `pipeline_parser.cpp`

```sad
# أساسي — يتحول إلى استدعاء دالة
قيمة |> دالة          # ≡ دالة(قيمة)

# مع معاملات إضافية
قيمة |> دالة(_, معامل2) # ≡ دالة(قيمة، معامل2)

# سلسلة أنابيب
أرقام
   |> تصفية(|ر| ر % 2 == 0)
   |> تحويل(|ر| ر * 2)
   |> أخذ(5)
   |> إلى_قائمة()
```

### آلية العمل
- `a |> f(b)` → يُحول إلى `f(a, b)` — يُضاف `a` كأول معامل.
- `a |> f` → يُحول إلى `f(a)` — استدعاء بدون أقواس.
- `_` يُستخدم كعنصر نائب (placeholder) لموضع القيمة.

## 32. استرداد الأخطاء (Error Recovery)

**ملفات المصدر:** `error_recovery.cpp`, `parser_core_helpers.cpp`

### الآلية
عند اكتشاف خطأ نحوي:
1. **يُسجّل الخطأ** مع الموقع والرمز المُتوقع والرمز الموجود.
2. **يبحث عن نقطة آمنة** (synchronization point) مثل كلمة مفتاحية جديدة أو `نهاية`.
3. **يستمر في التحليل** ليكتشف أخطاء إضافية.

### رسائل الخطأ
- ثنائية اللغة (عربية + إنجليزية).
- تتضمن اقتراحات إصلاح تلقائية (fix-it) — مثلاً: "أضف `)` هنا".
- تعرض السطر المحتوي على الخطأ مع سهم يشير للموقع.

### كشف الحلقات اللانهائية
في `parseProgram()` — يكتشف عدم تقدم المحلل ويُعيد التزامن.
