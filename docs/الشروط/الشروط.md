# الشروط في لغة ص (إذا / وإلا)

## نظرة عامة

تدعم لغة ص بنية شرطية كاملة تشمل `إذا`، `وإلا_إذا`، و`وإلا`. تُستخدم لتنفيذ كتل برمجية مختلفة حسب تحقق شروط معينة.

---

## الصيغة الأساسية

### شرط بسيط

```sad
إذا (شرط)
    # كود يُنفّذ إذا تحقق الشرط
نهاية
```

### شرط مع بديل

```sad
إذا (شرط)
    # كود إذا تحقق الشرط
وإلا
    # كود إذا لم يتحقق الشرط
نهاية
```

### شرط متعدد

```sad
إذا (شرط1)
    # ...
وإلا_إذا (شرط2)
    # ...
وإلا_إذا (شرط3)
    # ...
وإلا
    # ...
نهاية
```

---

## الكتابات البديلة المدعومة

لغة ص تدعم عدة كتابات لنفس الجمل الشرطية:

| الكلمة المفتاحية | البدائل المدعومة |
|------------------|------------------|
| `إذا` | `اذا` (بدون همزة) |
| `وإلا` | `والا` (بدون همزة) |
| `وإلا_إذا` | `والا_اذا` (بدون همزات) |

---

## العامل الثلاثي (Ternary)

بديل مختصر لعبارة إذا/وإلا:

```sad
متغير النتيجة = شرط ? قيمة_صحيح : قيمة_خطأ
```

---

## عامل العضوية `في`

```sad
إذا (عنصر في مصفوفة)
    # العنصر موجود
نهاية
```
