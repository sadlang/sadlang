# إطار عمل الويب الشامل - Sad Web Framework

## 📋 نظرة عامة / Overview

**النسخة / Version:** 1.0.0  
**الحالة / Status:** 🚧 قيد التخطيط / In Planning  
**الهدف / Goal:** إطار عمل ويب متكامل مثل Django أو Laravel للغة ص

---

## 🎯 الأهداف / Objectives

### بالعربية
إطار عمل ويب شامل يسمح للمطورين ببناء تطبيقات ويب ضخمة باستخدام لغة ص بسهولة ومرونة. يوفر الإطار جميع الأدوات اللازمة لبناء تطبيقات حديثة من الصفر.

### English
A comprehensive web framework that allows developers to build large-scale web applications using Sad Language with ease and flexibility. The framework provides all necessary tools to build modern applications from scratch.

### 1. نظام التوجيه (Router) / Routing System

**الميزات:**
- ✅ توجيه RESTful كامل
- ✅ دعم المعاملات الديناميكية
- ✅ مجموعات المسارات (Route Groups)
- ✅ الوسطاء (Middlewares)
- ✅ التوجيه المبني على النطاقات

**مثال الاستخدام:**
```sad
استخدم("ص_ويب")

متغير تطبيق = ص_ويب.إنشاء_تطبيق()

# توجيه بسيط
تطبيق.جلب("/"، دالة(طلب، استجابة)
    استجابة.أرسل("مرحباً بك!")
نهاية)

# مسار ديناميكي
تطبيق.جلب("/مستخدم/:المعرف"، دالة(طلب، استجابة)
    متغير معرف = طلب.معاملات.المعرف
    استجابة.جسون({ "معرف": معرف })
نهاية)

# مجموعة مسارات مع وسيط
تطبيق.مجموعة("/api"، { وسيط: "مصادقة" }، دالة()
    تطبيق.جلب("/بيانات"، جلب_البيانات)
    تطبيق.أرسل("/بيانات"، حفظ_البيانات)
نهاية)

تطبيق.استمع(3000)
```

### 2. نظام القوالب (Templates) / Template Engine

**الميزات:**
- ✅ محرك قوالب سريع وآمن
- ✅ دعم الوراثة والتضمين
- ✅ الفلاتر والدوال المساعدة
- ✅ التخزين المؤقت الذكي
- ✅ دعم كامل للعربية

**مثال القالب:**
```html
<!-- القالب الأساسي: layout.html -->
<!DOCTYPE html>
<html dir="rtl" lang="ar">
<head>
    <title>{{ عنوان }}</title>
</head>
<body>
    {% كتلة محتوى %}
    {% نهاية_كتلة %}
</body>
</html>

<!-- قالب فرعي: home.html -->
{% يمتد "layout.html" %}

{% كتلة محتوى %}
    <h1>مرحباً {{ اسم_المستخدم }}</h1>
    
    {% لكل عنصر في القائمة %}
        <div>{{ عنصر.عنوان }}</div>
    {% نهاية_لكل %}
    
    {% إذا عدد > 10 %}
        <p>العدد كبير</p>
    {% وإلا %}
        <p>العدد صغير</p>
    {% نهاية_إذا %}
{% نهاية_كتلة %}
```

```sad
استخدم("ص_ويب.قاعدة_بيانات")

# تعريف نموذج المستخدم
صنف مستخدم يمتد نموذج
    متغير الجدول = "المستخدمين"
    
    متغير الحقول = {
        "المعرف": { نوع: "عدد_صحيح"، رئيسي: صحيح، تلقائي: صحيح }،
        "الاسم": { نوع: "نص"، طول: 255، مطلوب: صحيح }،
        "البريد": { نوع: "نص"، فريد: صحيح }،
        "كلمة_السر": { نوع: "نص"، مشفر: صحيح }،
        "تاريخ_الإنشاء": { نوع: "تاريخ_ووقت"، افتراضي: "الآن" }
    }
    
    # علاقات
    دالة المقالات()
        إرجاع هذا.له_متعدد(مقالة، "معرف_المستخدم")
    نهاية
نهاية

// استخدام النموذج
متغير مستخدمين = مستخدم.كل()
متغير مستخدم_واحد = مستخدم.أين("البريد", "=", "user@example.com").أول()

// إنشاء مستخدم جديد
متغير مستخدم_جديد = مستخدم.أنشئ({
    "الاسم": "أحمد محمد",
    "البريد": "ahmed@example.com",
    "كلمة_السر": "password123"
})

// تحديث
مستخدم_واحد.الاسم = "محمد أحمد"
مستخدم_واحد.احفظ()

// حذف
مستخدم_واحد.احذف()
```

```sad
استخدم("ص_ويب.مصادقة")

# تسجيل دخول
تطبيق.أرسل("/دخول"، دالة(طلب، استجابة)
    متغير بيانات = طلب.جسم()

        بيانات.البريد،
        بيانات.كلمة_السر
    )
    
    إذا (مستخدم)
        متغير رمز = مصادقة.أنشئ_رمز(مستخدم)
        استجابة.جسون({ "رمز": رمز })
    وإلا
        استجابة.خطأ(401، "بيانات خاطئة")
    نهاية
نهاية)

# حماية مسار
تطبيق.جلب("/لوحة_التحكم"، 
    [وسيط.مصادقة، وسيط.صلاحية("admin")]،
    دالة(طلب، استجابة)
        متغير مستخدم = طلب.مستخدم()
        استجابة.عرض("dashboard"، { مستخدم: مستخدم })
    نهاية
)
```

### 7. WebSocket و Real-time / الاتصال الحي

**الميزات:**
- ✅ دعم WebSocket كامل
- ✅ البث المباشر (Broadcasting)
- ✅ الغرف والقنوات
- ✅ المصادقة والأمان
- ✅ Presence Channels

**مثال:**
```sad
استخدم("ص_ويب.ويب_سوكت")

# إنشاء خادم WebSocket
متغير سوكت = ويب_سوكت.أنشئ()

# الاستماع للاتصالات
سوكت.عند("اتصال", دالة(عميل)
    اطبع_سطر("عميل جديد متصل: " + عميل.معرف)
    
    # الاستماع للرسائل
    عميل.عند("رسالة", دالة(بيانات)
        # بث للجميع
        سوكت.بث("رسالة_جديدة", بيانات)
    نهاية)
    
    عميل.عند("انفصال", دالة()
        اطبع_سطر("عميل انفصل")
    نهاية)
نهاية)

# البث لغرفة محددة
سوكت.لـ("غرفة_الدردشة").بث("رسالة"، { نص: "مرحباً" })
```

متغير مستخدمين_api = api.مورد("مستخدمين", {
    نموذج: مستخدم،
    حقول: ["المعرف"، "الاسم"، "البريد"]،

// GET    /api/مستخدمين       - قائمة المستخدمين

// POST   /api/مستخدمين       - إنشاء مستخدم
// PUT    /api/مستخدمين/:id   - تحديث مستخدم
// DELETE /api/مستخدمين/:id   - حذف مستخدم

## 🚀 CLI Tools / أدوات سطر الأوامر

```bash
# إنشاء مشروع جديد
sad new project مشروعي --template=web

# إنشاء وحدة تحكم
sad make:controller UserController

# إنشاء نموذج
sad make:model User

# إنشاء هجرة قاعدة بيانات
sad make:migration create_users_table

# تشغيل الهجرات
sad migrate

# تشغيل الخادم
sad serve --port=3000

# بناء للإنتاج
sad build --production
```
