## 🌟 مقدمة عن لغة ص

**لغة ص (Sad Language)** هي أول لغة برمجة عربية حديثة ومكتملة. تهدف إلى:

### ✨ الرؤية
- 🇸🇦 **البرمجة بالعربية**: استخدام الكلمات العربية في الكود
- 🎓 **سهولة التعلم**: مناسبة للمبتدئين والمحترفين
- 🛠️ **الميزات الحديثة**: دعم البرمجة الكائنية ومعالجة الأخطاء
- 🌍 **المعايير العالمية**: تدعم UTF-8 والترميز العربي

### 🎯 لماذا لغة ص؟
```sad
# بدلاً من:
if (age >= 18) {
    print("Adult");
}

# اكتب بالعربية:
إذا ( العمر >= 18 )
    اطبع("بالغ") ;
نهاية
```

## 💻 التثبيت والإعداد

### متطلبات النظام
- **نظام التشغيل**: Windows 10/11، Linux، macOS
- **الذاكرة**: 512 MB RAM على الأقل
- **المساحة**: 100 MB مساحة فارغة
- **المعالج**: أي معالج حديث

### خطوات التثبيت

#### على Windows:
```bash
# 1. تنزيل أحدث إصدار
git clone https://github.com/sadlang/sad-language.git
cd sad-language

# 2. بناء المشروع
cmake --build build --config Debug

# 3. اختبار التثبيت
.\build\bin\Debug\sad.exe --version
```

#### على Linux/macOS:
```bash
# 1. تنزيل المشروع
git clone https://github.com/sadlang/sad-language.git
cd sad-language

# 2. بناء المشروع
mkdir build && cd build
cmake ..
make

# 3. اختبار التثبيت
./sad --version
```

# برنامج مرحبا بالعالم

sad مرحبا.s

## 🔢 المتغيرات والأنواع

### أنواع البيانات الأساسية

#### الأرقام الصحيحة (رقم)
```sad
رقم عمر = 25 ;
رقم السنة = 2025 ;
رقم درجات = 95 ;
```

#### الأرقام العشرية (عشري)
```sad
عشري الطول = 175.5 ;
عشري الوزن = 68.2 ;
عشري الدرجة = 98.7 ;
```

#### النصوص (نص)
```sad
نص الاسم = "أحمد محمد" ;
نص المدينة = "الرياض" ;
نص الرسالة = "مرحباً بك" ;
```

#### القيم المنطقية (منطق)
```sad
منطق مُسجل = صحيح ;
منطق مُكتمل = خطأ ;
منطق نشط = صحيح ;
```

### مثال شامل:
```sad
# بيانات شخصية
نص الاسم = "سارة أحمد" ;
رقم العمر = 22 ;
عشري المعدل = 3.85 ;
منطق طالبة = صحيح ;

# طباعة البيانات
اطبع("الاسم: ", الاسم) ;
اطبع("العمر: ", العمر, " سنة") ;
اطبع("المعدل: ", المعدل) ;
```

## ⚡ العمليات الحسابية

### العمليات الأساسية
```sad
رقم أ = 10 ;
رقم ب = 3 ;

رقم الجمع = أ + ب ;        # 13
رقم الطرح = أ - ب ;        # 7
رقم الضرب = أ * ب ;        # 30
رقم القسمة = أ / ب ;       # 3
رقم الباقي = أ % ب ;       # 1

اطبع("الجمع: ", الجمع) ;
اطبع("القسمة: ", القسمة) ;
```

### عمليات المقارنة
```sad
رقم درجة = 85 ;

منطق ممتاز = درجة >= 90 ;      # خطأ
منطق جيد = درجة >= 80 ;        # صحيح
منطق مقبول = درجة >= 60 ;      # صحيح

اطبع("الدرجة ممتازة: ", ممتاز) ;
اطبع("الدرجة جيدة: ", جيد) ;
```

### عمليات التزايد والتناقص
```sad
رقم عداد = 5 ;

عداد = عداد + 1 ;     # 6
عداد += 2 ;           # 8
عداد -= 3 ;           # 5
عداد *= 2 ;           # 10
```

## 🔀 الجمل الشرطية

### الجملة الشرطية البسيطة
```sad
رقم العمر = 18 ;

إذا ( العمر >= 18 )
    اطبع("أهلاً، يمكنك التصويت!") ;
نهاية
```

### الجملة الشرطية مع وإلا
```sad
رقم الدرجة = 85 ;

إذا ( الدرجة >= 90 )
    اطبع("ممتاز") ;
وإلا
    اطبع("جيد") ;
نهاية
```

### الجمل الشرطية المتداخلة
```sad
رقم الدرجة = 78 ;

إذا ( الدرجة >= 90 )
    اطبع("ممتاز") ;
وإلا
    إذا ( الدرجة >= 80 )
        اطبع("جيد جداً") ;
    وإلا
        إذا ( الدرجة >= 70 )
            اطبع("جيد") ;
        وإلا
            اطبع("مقبول") ;
        نهاية
    نهاية
نهاية
```

### الشروط المركبة
```sad
رقم العمر = 25 ;
منطق لديه_رخصة = صحيح ;

إذا ( العمر >= 18 && لديه_رخصة )
    اطبع("يمكنه القيادة") ;
وإلا
    اطبع("لا يمكنه القيادة") ;
نهاية
```

## 🔄 الحلقات

### حلقة بينما (While)
```sad
رقم عداد = 1 ;

بينما ( عداد <= 5 )
    اطبع("العدد: ", عداد) ;
    عداد = عداد + 1 ;
نهاية

# النتيجة:
# العدد: 1
# العدد: 2
# العدد: 3
# العدد: 4
# العدد: 5
```

### مثال عملي - حساب المجموع
```sad
رقم مجموع = 0 ;
رقم عداد = 1 ;

بينما ( عداد <= 10 )
    مجموع = مجموع + عداد ;
    عداد = عداد + 1 ;
نهاية

اطبع("مجموع الأرقام من 1 إلى 10: ", مجموع) ;
# النتيجة: 55
```

### حلقة لكل (For Each) - قادمة في الإصدارات المستقبلية
```sad
# سيتم دعمها قريباً
مصفوفة أرقام = [1, 2, 3, 4, 5] ;

لكل ( رقم في أرقام )
    اطبع("الرقم: ", رقم) ;
نهاية
```

## 📦 المصفوفات

### إنشاء المصفوفات
```sad
# مصفوفة أرقام
مصفوفة أرقام = [10, 20, 30, 40, 50] ;

# مصفوفة نصوص
مصفوفة أسماء = ["أحمد", "فاطمة", "علي", "زينب"] ;

# مصفوفة مختلطة
مصفوفة بيانات = [25, "سارة", صحيح, 3.14] ;
```

### الوصول للعناصر
```sad
مصفوفة درجات = [85, 92, 78, 95, 88] ;

اطبع("الدرجة الأولى: ", درجات[0]) ;      # 85
اطبع("الدرجة الثالثة: ", درجات[2]) ;     # 78
اطبع("الدرجة الأخيرة: ", درجات[4]) ;     # 88
```

### تعديل العناصر
```sad
مصفوفة نقاط = [100, 200, 300] ;

نقاط[1] = 250 ;    # تغيير القيمة الثانية
اطبع("النقاط المُحدثة: ", نقاط[1]) ;    # 250
```

### مثال عملي - حساب المتوسط
```sad
مصفوفة درجات = [85, 90, 78, 92, 88] ;
رقم مجموع = 0 ;
رقم عداد = 0 ;

بينما ( عداد < 5 )
    مجموع = مجموع + درجات[عداد] ;
    عداد = عداد + 1 ;
نهاية

عشري متوسط = مجموع / 5.0 ;
اطبع("متوسط الدرجات: ", متوسط) ;
```

## 🔧 الدوال

### تعريف الدالة البسيطة
```sad
دالة رحب()
    اطبع("مرحباً بك في لغة ص!") ;
نهاية

# استدعاء الدالة
رحب() ;
```

### دالة مع معاملات
```sad
دالة احسب_المساحة( رقم الطول ، رقم العرض )
    رقم المساحة = الطول * العرض ;
    اطبع("المساحة: ", المساحة) ;
نهاية

# استدعاء الدالة
احسب_المساحة(10, 5) ;    # المساحة: 50
```

### دالة مع إرجاع قيمة
```sad
دالة مربع( رقم العدد )
    أرجع العدد * العدد ;
نهاية

رقم النتيجة = مربع(7) ;
اطبع("مربع 7 هو: ", النتيجة) ;    # 49
```

### مثال أكثر تعقيداً
```sad
دالة احسب_المعدل( مصفوفة درجات )
    رقم مجموع = 0 ;
    رقم عداد = 0 ;
    
    بينما ( عداد < طول(درجات) )
        مجموع = مجموع + درجات[عداد] ;
        عداد = عداد + 1 ;
    نهاية
    
    أرجع مجموع / طول(درجات) ;
نهاية

مصفوفة درجات_الطالب = [85, 90, 78, 92] ;
عشري المعدل = احسب_المعدل(درجات_الطالب) ;
اطبع("معدل الطالب: ", المعدل) ;
```

## 🏗️ البرمجة الكائنية

### تعريف الصنف
```sad
صنف طالب
    # الخصائص
    نص الاسم ;
    رقم العمر ;
    عشري المعدل ;
    
    # الدالة البانية
    دالة طالب( نص اسم ، رقم عمر )
        الاسم = اسم ;
        العمر = عمر ;
        المعدل = 0.0 ;
    نهاية
    
    # دالة لعرض المعلومات
    دالة اعرض_المعلومات()
        اطبع("الاسم: ", الاسم) ;
        اطبع("العمر: ", العمر) ;
        اطبع("المعدل: ", المعدل) ;
    نهاية
    
    # دالة لتحديث المعدل
    دالة حدث_المعدل( عشري معدل_جديد )
        المعدل = معدل_جديد ;
    نهاية
نهاية
```

### استخدام الصنف
```sad
# إنشاء كائن جديد
طالب أحمد = جديد طالب("أحمد محمد", 20) ;

# استخدام الدوال
أحمد.حدث_المعدل(3.75) ;
أحمد.اعرض_المعلومات() ;
```

### الوراثة
```sad
صنف طالب_جامعي يرث طالب
    نص التخصص ;
    
    دالة طالب_جامعي( نص اسم ، رقم عمر ، نص تخصص )
        # استدعاء البانى الأساسي
        عام(اسم, عمر) ;
        التخصص = تخصص ;
    نهاية
    
    دالة اعرض_التخصص()
        اطبع("التخصص: ", التخصص) ;
    نهاية
نهاية
```

## 🏆 أمثلة متقدمة

### مثال 1: حاسبة بسيطة
```sad
دالة حاسبة( رقم أ ، نص العملية ، رقم ب )
    إذا ( العملية == "+" )
        أرجع أ + ب ;
    وإلا
        إذا ( العملية == "-" )
            أرجع أ - ب ;
        وإلا
            إذا ( العملية == "*" )
                أرجع أ * ب ;
            وإلا
                إذا ( العملية == "/" )
                    إذا ( ب != 0 )
                        أرجع أ / ب ;
                    وإلا
                        اطبع("خطأ: لا يمكن القسمة على صفر") ;
                        أرجع 0 ;
                    نهاية
                نهاية
            نهاية
        نهاية
    نهاية
نهاية

# استخدام الحاسبة
رقم نتيجة1 = حاسبة(15, "+", 5) ;    # 20
رقم نتيجة2 = حاسبة(10, "*", 3) ;    # 30
رقم نتيجة3 = حاسبة(20, "/", 4) ;    # 5

اطبع("15 + 5 = ", نتيجة1) ;
اطبع("10 * 3 = ", نتيجة2) ;
اطبع("20 / 4 = ", نتيجة3) ;
```

### مثال 2: إدارة درجات الطلاب
```sad
صنف إدارة_الدرجات
    مصفوفة الطلاب ;
    
    دالة إدارة_الدرجات()
        الطلاب = [] ;
    نهاية
    
    دالة أضف_طالب( نص الاسم ، مصفوفة الدرجات )
        مصفوفة بيانات_الطالب = [الاسم, الدرجات] ;
        # إضافة للمصفوفة (ستكون متاحة في الإصدارات القادمة)
    نهاية
    
    دالة احسب_متوسط_طالب( مصفوفة درجات )
        رقم مجموع = 0 ;
        رقم عداد = 0 ;
        
        بينما ( عداد < طول(درجات) )
            مجموع = مجموع + درجات[عداد] ;
            عداد = عداد + 1 ;
        نهاية
        
        أرجع مجموع / طول(درجات) ;
    نهاية
نهاية
```
