## 📐 القواعد الأساسية

### بنية الملف
```sad
# اسم الملف يجب أن ينتهي بـ .s
# مثال: برنامجي.s أو my_program.s

# بداية البرنامج
اطبع("بداية البرنامج") ;

# كود البرنامج هنا
رقم متغير = 10 ;

# نهاية البرنامج
اطبع("نهاية البرنامج") ;
```

### قواعد الكتابة
1. **حساسية الأحرف**: اللغة حساسة لحالة الأحرف
2. **الفواصل المنقوطة**: كل جملة يجب أن تنتهي بـ `;`
3. **الأقواس**: استخدم `( )` للمعاملات و `{ }` للكتل (اختياري)
4. **المسافات**: المسافات والفراغات غير مهمة إلا داخل النصوص

```sad
# ✅ صحيح
رقم عمر = 25 ;
اطبع("العمر:", عمر) ;

# ✅ صحيح أيضاً
رقم عمر=25;
اطبع( "العمر:" , عمر );

# ❌ خطأ - بدون فاصلة منقوطة
رقم عمر = 25
```

### تسمية المتغيرات
```sad
# ✅ أسماء صحيحة
رقم العمر ;
نص الاسم_الأول ;
عشري متوسط_الدرجات ;
منطق طالب_نشط ;

# ✅ يمكن استخدام الإنجليزية
رقم age ;
نص firstName ;
عشري average_grade ;

# ❌ أسماء خاطئة
رقم 123متغير ;     # لا تبدأ برقم
نص اسم-خاطئ ;      # لا تحتوي على شرطة
رقم اسم متغير ;    # لا مسافات في الاسم
```

## 🔤 الكلمات المحجوزة

### أنواع البيانات
| الكلمة العربية | المعنى | استخدام |
|---------------|-------|---------|
| `رقم` | Integer | `رقم العمر = 25 ;` |
| `عشري` | Float | `عشري الطول = 175.5 ;` |
| `نص` | String | `نص الاسم = "أحمد" ;` |
| `منطق` | Boolean | `منطق صحيح = true ;` |
| `مصفوفة` | Array | `مصفوفة أرقام = [1,2,3] ;` |

### القيم المنطقية
| الكلمة العربية | المعنى | استخدام |
|---------------|-------|---------|
| `صحيح` | true | `منطق نشط = صحيح ;` |
| `خطأ` | false | `منطق مُكتمل = خطأ ;` |

### التحكم في التدفق
| الكلمة العربية | المعنى | استخدام |
|---------------|-------|---------|
| `إذا` | if | `إذا ( الشرط )` |
| `وإلا` | else | `وإلا` |
| `بينما` | while | `بينما ( الشرط )` |
| `لكل` | for each | `لكل ( عنصر في مصفوفة )` |
| `نهاية` | end | `نهاية` |

### الدوال
| الكلمة العربية | المعنى | استخدام |
|---------------|-------|---------|
| `دالة` | function | `دالة الاسم()` |
| `أرجع` | return | `أرجع القيمة ;` |
| `اطبع` | print | `اطبع("النص") ;` |

### البرمجة الكائنية
| الكلمة العربية | المعنى | استخدام |
|---------------|-------|---------|
| `صنف` | class | `صنف الطالب` |
| `يرث` | inherits | `صنف أ يرث ب` |
| `جديد` | new | `جديد الطالب()` |
| `هذا` | this | `هذا.الخاصية` |
| `عام` | public | `عام دالة()` |
| `خاص` | private | `خاص رقم السن ;` |

### معالجة الأخطاء
| الكلمة العربية | المعنى | استخدام |
|---------------|-------|---------|
| `حاول` | try | `حاول` |
| `امسك` | catch | `امسك ( الاستثناء )` |
| `أخيراً` | finally | `أخيراً` |
| `ارمي` | throw | `ارمي الاستثناء ;` |

## ⚙️ العمليات

### العمليات الحسابية
```sad
رقم أ = 15 ;
رقم ب = 4 ;

# العمليات الأساسية
رقم جمع = أ + ب ;      # 19
رقم طرح = أ - ب ;      # 11
رقم ضرب = أ * ب ;      # 60
رقم قسمة = أ / ب ;     # 3 (قسمة صحيحة)
رقم باقي = أ % ب ;     # 3

# العمليات مع الأرقام العشرية
عشري قسمة_عشرية = 15.0 / 4.0 ;  # 3.75

# عمليات التعيين المركبة
أ += 5 ;    # أ = أ + 5 (20)
أ -= 3 ;    # أ = أ - 3 (17)
أ *= 2 ;    # أ = أ * 2 (34)
أ /= 2 ;    # أ = أ / 2 (17)
```

### عمليات المقارنة
```sad
رقم x = 10 ;
رقم y = 20 ;

# عمليات المقارنة الأساسية
منطق مساوي = x == y ;      # خطأ
منطق غير_مساوي = x != y ;  # صحيح
منطق أكبر = x > y ;        # خطأ
منطق أصغر = x < y ;        # صحيح
منطق أكبر_أو_مساوي = x >= y ;  # خطأ
منطق أصغر_أو_مساوي = x <= y ;  # صحيح

# مقارنة النصوص
نص اسم1 = "أحمد" ;
نص اسم2 = "أحمد" ;
منطق أسماء_متساوية = اسم1 == اسم2 ;  # صحيح
```

### العمليات المنطقية
```sad
منطق أ = صحيح ;
منطق ب = خطأ ;

# عمليات منطقية
منطق و = أ && ب ;        # خطأ (AND)
منطق أو = أ || ب ;       # صحيح (OR)
منطق ليس_أ = !أ ;        # خطأ (NOT)

# عمليات مركبة
منطق معقد = (أ && ب) || (!ب && أ) ;  # صحيح
```

### عمليات المصفوفات
```sad
مصفوفة قائمة = [10, 20, 30] ;

# الوصول للعناصر
رقم أول = قائمة[0] ;      # 10
رقم ثاني = قائمة[1] ;     # 20

# تغيير العناصر
قائمة[2] = 35 ;           # [10, 20, 35]

# طول المصفوفة (دالة مدمجة)
رقم الطول = طول(قائمة) ;  # 3
```

## 🔀 التحكم في التدفق

### الجمل الشرطية (إذا/وإلا)

#### بنية أساسية
```sad
إذا ( الشرط )
    # كود ينفذ عند تحقق الشرط
نهاية
```

#### أمثلة عملية
```sad
رقم العمر = 18 ;

# شرط بسيط
إذا ( العمر >= 18 )
    اطبع("بالغ") ;
نهاية

# شرط مع وإلا
إذا ( العمر >= 18 )
    اطبع("بالغ") ;
وإلا
    اطبع("قاصر") ;
نهاية

# شروط متداخلة
رقم الدرجة = 85 ;

إذا ( الدرجة >= 90 )
    اطبع("ممتاز") ;
وإلا
    إذا ( الدرجة >= 80 )
        اطبع("جيد جداً") ;
    وإلا
        إذا ( الدرجة >= 70 )
            اطبع("جيد") ;
        وإلا
            إذا ( الدرجة >= 60 )
                اطبع("مقبول") ;
            وإلا
                اطبع("راسب") ;
            نهاية
        نهاية
    نهاية
نهاية
```

#### شروط مركبة
```sad
رقم العمر = 25 ;
منطق لديه_رخصة = صحيح ;
منطق نظره_جيد = صحيح ;

# شرط AND
إذا ( العمر >= 18 && لديه_رخصة )
    اطبع("يمكنه القيادة") ;
نهاية

# شرط OR
إذا ( العمر < 18 || !لديه_رخصة )
    اطبع("لا يمكنه القيادة") ;
نهاية

# شروط معقدة
إذا ( (العمر >= 18 && لديه_رخصة) && نظره_جيد )
    اطبع("مؤهل للقيادة بالكامل") ;
نهاية
```

```sad
# حساب مضروب العدد
رقم عدد = 5 ;

بينما ( مؤشر <= عدد )

# البحث في مصفوفة
مصفوفة أرقام = [10, 25, 30, 45, 50] ;
رقم المطلوب = 30 ;
رقم فهرس = 0 ;
منطق وُجد = خطأ ;

بينما ( فهرس < طول(أرقام) && !وُجد )

        وُجد = صحيح ;
        اطبع("وُجد في الفهرس:", فهرس) ;

    فهرس = فهرس + 1 ;
نهاية

إذا ( !وُجد )
    اطبع("لم يوجد العدد") ;
نهاية
```

## 🔧 الدوال

### تعريف الدوال

#### دالة بسيطة بدون معاملات
```sad
دالة رحب()
    اطبع("مرحباً بك في لغة ص!") ;
    اطبع("أهلاً وسهلاً") ;
نهاية

# استدعاء الدالة
رحب() ;
```

#### دالة مع معاملات
```sad
دالة احسب_المساحة( رقم الطول ، رقم العرض )
    رقم المساحة = الطول * العرض ;
    اطبع("المساحة =", المساحة) ;
نهاية

# استدعاء الدالة
احسب_المساحة(10, 5) ;    # المساحة = 50
احسب_المساحة(7, 3) ;     # المساحة = 21
```

#### دالة مع إرجاع قيمة
```sad
دالة مربع( رقم العدد )
    رقم النتيجة = العدد * العدد ;
    أرجع النتيجة ;
نهاية

# استخدام القيمة المرجعة
رقم رقم7_مربع = مربع(7) ;
اطبع("مربع 7 =", رقم7_مربع) ;    # 49
```

#### دوال معقدة
```sad
دالة احسب_المعدل( مصفوفة درجات )
    رقم مجموع = 0 ;
    رقم عداد = 0 ;
    
    # التحقق من المصفوفة الفارغة
    إذا ( طول(درجات) == 0 )
        أرجع 0.0 ;
    نهاية
    
    # حساب المجموع
    بينما ( عداد < طول(درجات) )
        مجموع = مجموع + درجات[عداد] ;
        عداد = عداد + 1 ;
    نهاية
    
    # حساب المعدل
    عشري المعدل = مجموع / طول(درجات) ;
    أرجع المعدل ;
نهاية

# استخدام الدالة
مصفوفة درجات_الطالب = [85, 90, 78, 92, 88] ;
عشري معدل_الطالب = احسب_المعدل(درجات_الطالب) ;
اطبع("معدل الطالب:", معدل_الطالب) ;
```

### دوال متخصصة
```sad
# دالة للتحقق من الأرقام الأولية
دالة هل_عدد_أولي( رقم العدد )
    إذا ( العدد < 2 )
        أرجع خطأ ;
    نهاية
    
    رقم مقسوم = 2 ;
    بينما ( مقسوم * مقسوم <= العدد )
        إذا ( العدد % مقسوم == 0 )
            أرجع خطأ ;
        نهاية
        مقسوم = مقسوم + 1 ;
    نهاية
    
    أرجع صحيح ;
نهاية

# دالة لعكس نص
دالة اعكس_النص( نص الكلمة )
    # سيتم تطويرها في الإصدارات القادمة
    اطبع("عكس", الكلمة, "سيتوفر قريباً") ;
نهاية
```

## 🏗️ البرمجة الكائنية

### تعريف الصنف

#### صنف بسيط
```sad
صنف شخص
    # الخصائص (Private by default)
    نص الاسم ;
    رقم العمر ;
    
    # الدالة البانية (Constructor)
    دالة شخص( نص اسم ، رقم عمر )
        الاسم = اسم ;
        العمر = عمر ;
    نهاية
    
    # دوال الصنف (Methods)
    دالة اعرض_المعلومات()
        اطبع("الاسم:", الاسم) ;
        اطبع("العمر:", العمر, "سنة") ;
    نهاية
    
    دالة حدث_العمر( رقم عمر_جديد )
        العمر = عمر_جديد ;
    نهاية
    
    دالة احصل_على_الاسم()
        أرجع الاسم ;
    نهاية
نهاية
```

#### استخدام الصنف
```sad
# إنشاء كائن جديد
شخص أحمد = جديد شخص("أحمد محمد", 25) ;

# استدعاء دوال الكائن
أحمد.اعرض_المعلومات() ;
أحمد.حدث_العمر(26) ;

نص اسم_أحمد = أحمد.احصل_على_الاسم() ;
اطبع("اسم الشخص:", اسم_أحمد) ;
```

### الوراثة
```sad
# الصنف الأساسي
صنف مركبة
    نص النوع ;
    رقم السرعة_القصوى ;
    
    دالة مركبة( نص نوع ، رقم سرعة )
        النوع = نوع ;
        السرعة_القصوى = سرعة ;
    نهاية
    
    دالة احرك()
        اطبع("المركبة تتحرك") ;
    نهاية
نهاية

# الصنف المشتق
صنف سيارة يرث مركبة
    رقم عدد_الأبواب ;
    
    دالة سيارة( نص نوع ، رقم سرعة ، رقم أبواب )
        # استدعاء البانى الأساسي
        عام(نوع, سرعة) ;
        عدد_الأبواب = أبواب ;
    نهاية
    
    # إعادة تعريف دالة من الصنف الأساسي
    دالة احرك()
        اطبع("السيارة تقود على الطريق") ;
    نهاية
    
    # دالة جديدة خاصة بالسيارة
    دالة اطبع_المواصفات()
        اطبع("نوع المركبة:", النوع) ;
        اطبع("السرعة القصوى:", السرعة_القصوى, "كم/س") ;
        اطبع("عدد الأبواب:", عدد_الأبواب) ;
    نهاية
نهاية

# استخدام الوراثة
سيارة سيارتي = جديد سيارة("سيدان", 180, 4) ;
سيارتي.احرك() ;
سيارتي.اطبع_المواصفات() ;
```

### الكابسولة (Encapsulation)
```sad
صنف حساب_بنكي
    # خصائص خاصة
    خاص رقم الرصيد ;
    خاص نص رقم_الحساب ;
    
    # دالة بانية عامة
    عام دالة حساب_بنكي( نص رقم ، رقم رصيد_أولي )
        رقم_الحساب = رقم ;
        الرصيد = رصيد_أولي ;
    نهاية
    
    # دوال عامة للوصول للخصائص الخاصة
    عام دالة احصل_على_الرصيد()
        أرجع الرصيد ;
    نهاية
    
    عام دالة ايداع( رقم المبلغ )
        إذا ( المبلغ > 0 )
            الرصيد = الرصيد + المبلغ ;
            اطبع("تم إيداع", المبلغ, "ريال") ;
        وإلا
            اطبع("مبلغ الإيداع يجب أن يكون موجب") ;
        نهاية
    نهاية
    
    عام دالة سحب( رقم المبلغ )
        إذا ( المبلغ > 0 && المبلغ <= الرصيد )
            الرصيد = الرصيد - المبلغ ;
            اطبع("تم سحب", المبلغ, "ريال") ;
        وإلا
            اطبع("لا يمكن سحب هذا المبلغ") ;
        نهاية
    نهاية
نهاية
```

## 📋 ملخص سريع للقواعد

### أساسيات الكتابة
- ✅ كل جملة تنتهي بـ `;`
- ✅ استخدم `( )` للمعاملات و الشروط
- ✅ كلمة `نهاية` تغلق الكتل
- ✅ الكلمات العربية للأوامر الأساسية

### أنواع البيانات
- `رقم` للأعداد الصحيحة
- `عشري` للأعداد العشرية
- `نص` للنصوص
- `منطق` للقيم المنطقية (`صحيح`/`خطأ`)
- `مصفوفة` للمصفوفات

### التحكم في التدفق
- `إذا`...`وإلا`...`نهاية` للشروط
- `بينما`...`نهاية` للحلقات
- `حاول`...`امسك`...`أخيراً`...`نهاية` لمعالجة الأخطاء

### البرمجة الكائنية
- `صنف`...`نهاية` لتعريف الأصناف
- `دالة` لتعريف الدوال والطرق
- `يرث` للوراثة
- `جديد` لإنشاء كائنات
