## 🌟 أساسيات اللغة

### ❓ ما هي لغة ص؟
**الجواب**: لغة ص (Sad Language) هي أول لغة برمجة عربية حديثة ومكتملة. تم تصميمها لتمكين المطورين العرب من البرمجة بلغتهم الأم، مع دعم جميع الميزات الحديثة مثل البرمجة الكائنية ومعالجة الأخطاء.

### ❓ لماذا سميت بـ "لغة ص"؟
**الجواب**: اسم "ص" يأتي من كلمة "صاد" وهو الحرف الرابع عشر في الأبجدية العربية، ويرمز إلى "الصدق" في التعبير البرمجي باللغة العربية.

### ❓ هل لغة ص مناسبة للمبتدئين؟
**الجواب**: نعم، بالتأكيد! تم تصميم لغة ص لتكون سهلة التعلم للمبتدئين:
- **بناء الجملة البسيط**: قواعد واضحة ومفهومة
- **رسائل خطأ بالعربية**: لفهم أفضل للمشاكل
- **أمثلة تفاعلية**: موارد تعليمية شاملة
- **مجتمع داعم**: مساعدة من المطورين العرب

### ❓ ما الفرق بين لغة ص واللغات الأخرى؟
**الجواب**:

| الميزة | لغة ص | اللغات التقليدية |
|-------|-------|------------------|
| **اللغة** | العربية | الإنجليزية |
| **الكلمات المحجوزة** | `إذا`، `بينما`، `دالة` | `if`, `while`, `function` |
| **رسائل الخطأ** | بالعربية | بالإنجليزية |
| **التوثيق** | عربي/إنجليزي | إنجليزي فقط |
| **المجتمع** | عربي | عالمي |

### ❓ هل يمكنني استخدام أسماء إنجليزية للمتغيرات؟
**الجواب**: نعم، يمكنك استخدام:
```sad
# أسماء عربية (مفضل)
رقم العمر = 25 ;
نص الاسم = "أحمد" ;

# أسماء إنجليزية (مقبول)
رقم age = 25 ;
نص name = "Ahmed" ;

# خليط (مقبول)
رقم student_age = 25 ;
نص اسم_الطالب = "أحمد" ;
```

### ❓ هل تدعم لغة ص Unicode؟
**الجواب**: نعم، تدعم لغة ص بالكامل UTF-8 وUnicode، مما يعني:
- **النصوص العربية**: تعامل مثالي مع الأحرف العربية
- **الأرقام العربية**: دعم ١٢٣٤٥٦٧٨٩٠
- **علامات الترقيم**: جميع علامات الترقيم العربية
- **الاتجاه**: دعم RTL في المحررات المناسبة

## 💻 التثبيت والإعداد

### ❓ ما هي متطلبات النظام لتشغيل لغة ص؟
**الجواب**:

**الحد الأدنى**:
- Windows 10، Linux، أو macOS
- 512 MB ذاكرة وصول عشوائي
- 100 MB مساحة تخزين
- معالج 1 GHz أو أعلى

**المستحسن**:
- 2 GB ذاكرة وصول عشوائي أو أكثر
- 1 GB مساحة تخزين للمشاريع
- معالج متعدد النوى للمشاريع الكبيرة

### ❓ كيف أقوم بتثبيت لغة ص على Windows؟
**الجواب**:
```bash
# 1. تحميل الكود المصدري
git clone https://github.com/sadlang/sad-language.git
cd sad-language

# 2. إنشاء مجلد البناء
mkdir build
cd build

# 3. تكوين المشروع
cmake ..

# 4. بناء المشروع
cmake --build . --config Release

# 5. اختبار التثبيت
.\bin\Release\sad.exe --version
```

### ❓ لا يعمل أمر `sad` في Terminal، ما الحل؟
**الجواب**:

**على Windows**:
```bash
# إضافة المجلد إلى PATH
$env:PATH += ";C:\path\to\sad-language\build\bin\Release"

# أو استخدام المسار الكامل
C:\path\to\sad-language\build\bin\Release\sad.exe myfile.s
```

**على Linux/macOS**:
```bash
# إضافة إلى .bashrc أو .zshrc
export PATH=$PATH:/path/to/sad-language/build/bin

# إعادة تحميل Shell
source ~/.bashrc
```

### ❓ هل يمكنني استخدام لغة ص مع VS Code؟
**الجواب**: نعم! يمكنك إعداد VS Code للعمل مع لغة ص:

**إعداد التمييز النحوي**:
1. أنشئ ملف `.vscode/settings.json`
2. أضف الإعدادات التالية:
```json
{
    "files.associations": {
        "*.s": "sad"
    },
    "editor.unicodeHighlight.allowedCharacters": {
        "ا": true,
        "أ": true,
        "إ": true,
        "ؤ": true,
        "ئ": true,
        "ة": true
    }
}
```

**تشغيل الملفات**:
```json
{
    "version": "2.0.0",
    "tasks": [
        {
            "label": "Run Sad Program",
            "type": "shell",
            "command": "sad",
            "args": ["${file}"],
            "group": "build",
            "presentation": {
                "echo": true,
                "reveal": "always",
                "focus": false,
                "panel": "shared"
            }
        }
    ]
}
```

## 🚨 الأخطاء الشائعة

### ❓ أحصل على خطأ "Syntax Error"، ما السبب؟
**الجواب**: الأخطاء النحوية الشائعة:



**2. استخدام أقواس خاطئة**:
```sad
# ❌ خطأ
إذا العمر >= 18
    اطبع("بالغ") ;
نهاية

# ✅ صحيح
إذا ( العمر >= 18 )
    اطبع("بالغ") ;
نهاية
```

**3. عدم إغلاق النصوص**:
```sad
# ❌ خطأ
اطبع("مرحبا بك) ;

# ✅ صحيح
اطبع("مرحبا بك") ;
```

### ❓ أحصل على "Undefined Variable Error"، كيف أحلها؟
**الجواب**: هذا يحدث عندما تحاول استخدام متغير لم يتم تعريفه:

```sad
# ❌ خطأ - لم يتم تعريف المتغير
اطبع(الاسم) ;

# ✅ صحيح - تعريف ثم استخدام
نص الاسم = "أحمد" ;
اطبع(الاسم) ;
```

**نصائح للتجنب**:
- تأكد من تعريف جميع المتغيرات قبل الاستخدام
- تحقق من الهجاء (Case Sensitive)
- تأكد من النطاق (Scope) الصحيح

### ❓ "Type Mismatch Error" - ماذا يعني؟
**الجواب**: يحدث عند خلط الأنواع غير المتوافقة:

```sad
# ❌ خطأ - لا يمكن جمع نص مع رقم مباشرة
نص الرسالة = "العمر: " + 25 ;

# ✅ صحيح - تحويل الرقم إلى نص
نص الرسالة = "العمر: " + إلى_نص(25) ;

# أو
رقم العمر = 25 ;
اطبع("العمر:", العمر) ; # اطبع يتعامل مع الأنواع المختلفة
```

### ❓ "Array Index Out of Bounds" - كيف أتجنبها؟
**الجواب**: تحدث عند محاولة الوصول لعنصر غير موجود:

```sad
مصفوفة أرقام = [1, 2, 3] ;

# ❌ خطأ - الفهرس 5 غير موجود
اطبع(أرقام[5]) ;

# ✅ صحيح - تحقق من الطول أولاً
إذا ( 5 < طول(أرقام) )
    اطبع(أرقام[5]) ;
وإلا
    اطبع("الفهرس خارج النطاق") ;
نهاية

# أو استخدام دالة آمنة
دالة وصول_آمن( مصفوفة القائمة ، رقم الفهرس )
    إذا ( الفهرس >= 0 && الفهرس < طول(القائمة) )
        أرجع القائمة[الفهرس] ;
    وإلا
        أرجع فارغ ;
    نهاية
نهاية
```

### ❓ "Division by Zero Error" - كيف أتعامل معها؟
**الجواب**: استخدم التحقق أو معالجة الأخطاء:

```sad
# الطريقة الأولى: التحقق المسبق
دالة قسمة_آمنة( رقم أ ، رقم ب )
    إذا ( ب == 0 )
        اطبع("خطأ: لا يمكن القسمة على صفر") ;
        أرجع 0 ;
    نهاية
    أرجع أ / ب ;
نهاية

# الطريقة الثانية: معالجة الأخطاء
حاول
    رقم النتيجة = 10 / 0 ;
نهاية
امسك ( خطأ_قسمة )
    اطبع("تم التعامل مع خطأ القسمة على صفر") ;
نهاية
```

## ⚡ الأداء والتحسين

### ❓ برنامجي بطيء، كيف أحسن الأداء؟
**الجواب**: نصائح التحسين:

**1. تجنب الحلقات المتداخلة غير الضرورية**:
```sad
# ❌ بطيء
مصفوفة كبيرة = [1, 2, ..., 1000] ;
رقم عداد = 0 ;
بينما ( عداد < طول(كبيرة) )
    رقم عداد2 = 0 ;
    بينما ( عداد2 < طول(كبيرة) )
        # عملية معقدة
        عداد2 = عداد2 + 1 ;
    نهاية
    عداد = عداد + 1 ;
نهاية

# ✅ أسرع - تجنب التعقيد غير الضروري
```

**2. استخدم المتغيرات المحلية**:
```sad
# ❌ بطيء - حساب الطول في كل مرة
رقم عداد = 0 ;
بينما ( عداد < طول(المصفوفة_الكبيرة) )
    # معالجة
    عداد = عداد + 1 ;
نهاية

# ✅ أسرع - حفظ الطول
رقم الطول = طول(المصفوفة_الكبيرة) ;
رقم عداد = 0 ;
بينما ( عداد < الطول )
    # معالجة
    عداد = عداد + 1 ;
نهاية
```

**3. تجنب إنشاء مصفوفات كبيرة غير ضرورية**:
```sad
# ❌ يستهلك ذاكرة كثيرة
مصفوفة نتائج = [] ;
رقم عداد = 0 ;
بينما ( عداد < 1000000 )
    نتائج = أضف_عنصر(نتائج, عداد * 2) ;
    عداد = عداد + 1 ;
نهاية

# ✅ أفضل - معالجة مباشرة
رقم عداد = 0 ;
بينما ( عداد < 1000000 )
    رقم النتيجة = عداد * 2 ;
    # استخدم النتيجة مباشرة
    عداد = عداد + 1 ;
نهاية
```

### ❓ هل يؤثر استخدام النص العربي على الأداء؟
**الجواب**: لا، لا يؤثر بشكل ملحوظ:
- **التأثير**: أقل من 1% في معظم الحالات
- **السبب**: المترجم يحول الكلمات العربية إلى رموز داخلية
- **التوصية**: استخدم العربية بثقة للوضوح والفهم

## 🏗️ البرمجة الكائنية

### ❓ كيف أنشئ صنف (Class) بسيط؟
**الجواب**:
```sad
صنف شخص
    # الخصائص
    نص الاسم ;
    رقم العمر ;
    
    # الدالة البانية
    دالة شخص( نص اسم ، رقم عمر )
        الاسم = اسم ;
        العمر = عمر ;
    نهاية
    
    # دوال الصنف
    دالة اعرض_المعلومات()
        اطبع("الاسم:", الاسم, "العمر:", العمر) ;
    نهاية
نهاية

# الاستخدام
شخص أحمد = جديد شخص("أحمد محمد", 25) ;
أحمد.اعرض_المعلومات() ;
```

### ❓ كيف أطبق الوراثة؟
**الجواب**:
```sad
# الصنف الأساسي
صنف حيوان
    نص الاسم ;
    
    دالة حيوان( نص اسم )
        الاسم = اسم ;
    نهاية
    
    دالة أصدر_صوت()
        اطبع("الحيوان يصدر صوتاً") ;
    نهاية
نهاية

# الصنف المشتق
صنف قطة يرث حيوان
    دالة قطة( نص اسم )
        عام(اسم) ; # استدعاء البانى الأساسي
    نهاية
    
    # إعادة تعريف الدالة
    دالة أصدر_صوت()
        اطبع("مواء!") ;
    نهاية
نهاية

# الاستخدام
قطة قطتي = جديد قطة("مشمش") ;
قطتي.أصدر_صوت() ; # "مواء!"
```

### ❓ ما الفرق بين `عام` و `خاص`؟
**الجواب**:

```sad
صنف حساب_بنكي
    # خصائص خاصة - لا يمكن الوصول إليها من الخارج
    خاص رقم الرصيد ;
    خاص نص رقم_الحساب ;
    
    # دالة عامة - يمكن استدعاؤها من الخارج
    عام دالة ايداع( رقم المبلغ )
        الرصيد = الرصيد + المبلغ ;
    نهاية
    
    عام دالة احصل_على_الرصيد()
        أرجع الرصيد ;
    نهاية
نهاية

حساب_بنكي حسابي = جديد حساب_بنكي() ;
حسابي.ايداع(100) ; # ✅ يعمل - دالة عامة

# حسابي.الرصيد = 1000000 ; # ❌ خطأ - خاصية خاصة
```

## 📚 المكتبة القياسية

### ❓ ما هي الدوال المتاحة في المكتبة القياسية؟
**الجواب**: المكتبة تحتوي على:

**الدوال الأساسية**:
- `اطبع()` - طباعة القيم
- `طول()` - طول المصفوفات والنصوص
- `نوع()` - معرفة نوع القيمة

**الدوال الرياضية**:
- `مطلق()` - القيمة المطلقة
- `جذر_تربيعي()` - الجذر التربيعي
- `قوة()` - رفع لقوة
- `أصغر()` و `أكبر()` - أصغر وأكبر قيمة

**دوال النصوص**:
- `طول_النص()` - طول النص
- `جزء_من_النص()` - استخراج جزء
- `ابحث_في_النص()` - البحث
- `استبدل_في_النص()` - الاستبدال

### ❓ كيف أقرأ إدخال من المستخدم؟
**الجواب**:
```sad
# قراءة نص
نص الاسم = اقرأ_سطر("ما اسمك؟ ") ;
اطبع("مرحباً", الاسم) ;

# قراءة رقم
رقم العمر = اقرأ_رقم("كم عمرك؟ ") ;
اطبع("عمرك", العمر, "سنة") ;

# التعامل مع الأخطاء في الإدخال
حاول
    نص عمر_نص = اقرأ_سطر("أدخل عمرك: ") ;
    رقم العمر = إلى_رقم(عمر_نص) ;
    اطبع("العمر صحيح:", العمر) ;
نهاية
امسك ( خطأ_تحويل )
    اطبع("خطأ: يجب إدخال رقم صحيح") ;
نهاية
```

### ❓ كيف أولد أرقام عشوائية؟
**الجواب**:
```sad
# رقم عشوائي بين 0.0 و 1.0
عشري احتمال = عشوائي() ;

# رقم صحيح بين 0 و 9
رقم رقم_عشوائي = عشوائي(10) ;

# رقم صحيح بين 1 و 6 (نرد)
رقم النرد = عشوائي(1, 7) ;

# اختيار عنصر عشوائي من مصفوفة
مصفوفة الألوان = ["أحمر", "أخضر", "أزرق"] ;
رقم فهرس_عشوائي = عشوائي(طول(الألوان)) ;
نص لون_مختار = الألوان[فهرس_عشوائي] ;
```

### ❓ كيف أضيف دالة جديدة للمكتبة القياسية؟

**1. تعديل ملف `builtin_functions.cpp`**:
```cpp
// إضافة الدالة الجديدة
Value builtin_my_function(const std::vector<Value>& args) {
    // تطبيق الدالة
    return Value(/* النتيجة */);
}

// تسجيل الدالة في المترجم
interpreter.defineBuiltin("دالتي", builtin_my_function);
```

**2. تحديث التوثيق**:
- إضافة الدالة لدليل المكتبة القياسية
- كتابة أمثلة للاستخدام
- إضافة اختبارات

**3. اختبار الدالة**:
```sad
# اختبار الدالة الجديدة
رقم النتيجة = دالتي(10, 20) ;
اطبع("النتيجة:", النتيجة) ;
```

```json
{
    "name": "sad-language-support",
```

## 💡 نصائح متقدمة

### ❓ كيف أكتب كود نظيف وقابل للقراءة؟
**الجواب**:

**1. استخدم أسماء وصفية**:
```sad
# ❌ غير واضح
رقم x = 25 ;
رقم y = 30 ;

# ✅ واضح ووصفي
رقم عمر_الطالب = 25 ;
```

**2. اكتب تعليقات مفيدة**:
```sad
# حساب معدل الطالب على أساس درجاته
دالة احسب_المعدل( مصفوفة الدرجات )
    رقم مجموع_الدرجات = 0 ;
    
    # جمع جميع الدرجات
    رقم عداد = 0 ;
    بينما ( عداد < طول(الدرجات) )
        مجموع_الدرجات += الدرجات[عداد] ;
        عداد += 1 ;
    نهاية
    
    # حساب المتوسط
    أرجع مجموع_الدرجات / طول(الدرجات) ;
نهاية
```

**3. قسّم الكود إلى دوال صغيرة**:
```sad
# ✅ دوال متخصصة وواضحة
دالة تحقق_من_صحة_الدرجة( رقم الدرجة )
    أرجع الدرجة >= 0 && الدرجة <= 100 ;
نهاية

دالة احسب_مجموع_الدرجات( مصفوفة الدرجات )
    رقم المجموع = 0 ;
    # ... كود حساب المجموع
    أرجع المجموع ;
نهاية

دالة احسب_المعدل( مصفوفة الدرجات )
    رقم المجموع = احسب_مجموع_الدرجات(الدرجات) ;
    أرجع المجموع / طول(الدرجات) ;
نهاية
```
