# الأصناف في لغة ص
## البرمجة الكائنية - الجزء الأول

## 🎓 مقدمة: ما هي البرمجة الكائنية؟

**البرمجة الكائنية (Object-Oriented Programming - OOP)** هي نموذج برمجي يعتمد على فكرة **الكائنات** (Objects) - وحدات مستقلة تحتوي على:
- **البيانات** (Properties/Attributes): المتغيرات التي تمثل حالة الكائن
- **السلوكيات** (Methods): الدوال التي تعمل على هذه البيانات

الكائنات تُنشأ من **أصناف** (Classes) - وهي قوالب أو مخططات لإنشاء كائنات متشابهة.

## 🏗️ الصنف (Class)

الصنف هو **تعريف** لنوع جديد من البيانات. يشبه المخطط المعماري لبناء منزل - المخطط ليس منزلاً، بل تعليمات لبناء منازل متعددة.

### الصيغة الأساسية

```
صنف اسم_الصنف
    # الخصائص (Properties)
    نوع خاصية1
    نوع خاصية2
    
    # الدوال (Methods)
    دالة اسم_دالة(معاملات) نوع_الإرجاع
        # كود الدالة
    نهاية
نهاية
```

### مثال بسيط: صنف الشخص

```
صنف شخص
    # الخصائص
    نص الاسم
    رقم العمر
    نص المدينة
    
    # دالة لطباعة معلومات الشخص
    دالة اطبع_معلومات() فراغ
        اطبع_سطر("الاسم: " + هذا.الاسم)
        اطبع_سطر("العمر: " + هذا.العمر)
        اطبع_سطر("المدينة: " + هذا.المدينة)
    نهاية
نهاية
```

## 🎯 الكائن (Object)

الكائن هو **نسخة حقيقية** (instance) من الصنف. إذا كان الصنف هو المخطط، فالكائن هو البناء الفعلي.

### إنشاء كائن

```
# الصيغة
نوع_الصنف اسم_المتغير = جديد نوع_الصنف(معاملات_البناء)

# مثال
شخص أحمد = جديد شخص()
```

### الوصول للخصائص

```
# قراءة الخصائص
اسم_الكائن.اسم_الخاصية

# تعديل الخصائص
اسم_الكائن.اسم_الخاصية = قيمة_جديدة

# مثال
أحمد.الاسم = "أحمد محمد"
أحمد.العمر = 25
أحمد.المدينة = "الرياض"
```

### استدعاء الدوال

```
# الصيغة
اسم_الكائن.اسم_الدالة(معاملات)

# مثال
أحمد.اطبع_معلومات()
```

## 📝 مثال كامل: إدارة الطلاب

```
# تعريف الصنف
صنف طالب
    # الخصائص
    نص الاسم
    رقم الرقم_الجامعي
    عشري المعدل
    مصفوفة المواد
    
    # دالة لإضافة مادة
    دالة أضف_مادة(نص اسم_المادة) فراغ
        أضف(هذا.المواد، اسم_المادة)
        اطبع_سطر("تمت إضافة المادة: " + اسم_المادة)
    نهاية
    
    # دالة لعرض جميع المواد
    دالة اطبع_المواد() فراغ
        اطبع_سطر("=== مواد " + هذا.الاسم + " ===")
        لكل مادة في هذا.المواد
            اطبع_سطر("- " + مادة)
        نهاية
    نهاية
    
    # دالة لحساب التقدير
    دالة احصل_تقدير() ترجع نص
        اذا (هذا.المعدل >= 4.5)
            ارجع "ممتاز"
        نهاية_اذا
        اذا (هذا.المعدل >= 3.5)
            ارجع "جيد جداً"
        نهاية_اذا
        اذا (هذا.المعدل >= 2.5)
            ارجع "جيد"
        نهاية_اذا
        ارجع "مقبول"
    نهاية
    
    # دالة لطباعة جميع المعلومات
    دالة اطبع_معلومات() فراغ
        اطبع_سطر("╔════════════════════════════╗")
        اطبع_سطر("  الاسم: " + هذا.الاسم)
        اطبع_سطر("  الرقم: " + هذا.الرقم_الجامعي)
        اطبع_سطر("  المعدل: " + هذا.المعدل)
        اطبع_سطر("  التقدير: " + هذا.احصل_تقدير())
        اطبع_سطر("  عدد المواد: " + طول(هذا.المواد))
        اطبع_سطر("╚════════════════════════════╝")
    نهاية
نهاية

# ========== البرنامج الرئيسي ==========

دالة رئيسية() رقم
    اطبع_سطر("=== نظام إدارة الطلاب ===")
    اطبع_سطر("")
    
    # إنشاء طالب أول
    طالب علي = جديد طالب()
    علي.الاسم = "علي أحمد"
    علي.الرقم_الجامعي = 202301
    علي.المعدل = 4.75
    علي.المواد = []
    
    علي.أضف_مادة("البرمجة")
    علي.أضف_مادة("قواعد البيانات")
    علي.أضف_مادة("هندسة البرمجيات")
    
    اطبع_سطر("")
    علي.اطبع_معلومات()
    اطبع_سطر("")
    علي.اطبع_المواد()
    
    اطبع_سطر("")
    اطبع_سطر("────────────────────────────")
    اطبع_سطر("")
    
    # إنشاء طالب ثاني
    طالب فاطمة = جديد طالب()
    فاطمة.الاسم = "فاطمة محمد"
    فاطمة.الرقم_الجامعي = 202302
    فاطمة.المعدل = 3.85
    فاطمة.المواد = []
    
    فاطمة.أضف_مادة("الخوارزميات")
    فاطمة.أضف_مادة("الشبكات")
    
    فاطمة.اطبع_معلومات()
    اطبع_سطر("")
    فاطمة.اطبع_المواد()
    
    ارجع 0
نهاية
```

## 🔑 كلمة "هذا" (this)

`هذا` (this) هي كلمة مفتاحية تشير إلى **الكائن الحالي** - الكائن الذي تم استدعاء الدالة عليه.

### متى نستخدم "هذا"؟

```
صنف حساب
    رقم الرصيد
    
    دالة إيداع(رقم المبلغ) فراغ
        # ✅ واضح - نستخدم "هذا" للتمييز
        هذا.الرصيد = هذا.الرصيد + المبلغ
    نهاية
    
    دالة سحب(رقم الرصيد) فراغ
        # ⚠️ تعارض الأسماء! المعامل اسمه "الرصيد" أيضاً
        # بدون "هذا"، نقصد المعامل
        # مع "هذا"، نقصد خاصية الصنف
        
        اذا (هذا.الرصيد >= الرصيد)  # خاصية الصنف >= المعامل
            هذا.الرصيد = هذا.الرصيد - الرصيد
        نهاية
    نهاية
نهاية
```

### نصيحة مهمة

**استخدم "هذا" دائماً** للوصول لخصائص الصنف، حتى لو لم يكن هناك تعارض في الأسماء. هذا يجعل الكود أوضح وأسهل للقراءة.

## 🏭 المنشئ (Constructor)

المنشئ هو دالة خاصة تُستدعى تلقائياً عند إنشاء كائن جديد. يُستخدم لتهيئة الخصائص بقيم أولية.

### الصيغة

```
صنف اسم_الصنف
    # الخصائص
    نوع خاصية1
    
    # المنشئ
    دالة منشئ(معاملات) فراغ
        # تهيئة الخصائص
        هذا.خاصية1 = قيمة
    نهاية
نهاية
```

### مثال: صنف السيارة

```
صنف سيارة
    نص النوع
    نص اللون
    رقم السنة
    عشري السرعة
    
    # المنشئ
    دالة منشئ(نص نوع، نص لون، رقم سنة) فراغ
        هذا.النوع = نوع
        هذا.اللون = لون
        هذا.السنة = سنة
        هذا.السرعة = 0.0  # السيارة متوقفة عند الإنشاء
        
        اطبع_سطر("تم إنشاء سيارة " + نوع + " " + لون)
    نهاية
    
    دالة تسريع(عشري زيادة) فراغ
        هذا.السرعة = هذا.السرعة + زيادة
        اطبع_سطر("السرعة الآن: " + هذا.السرعة + " كم/س")
    نهاية
    
    دالة توقف() فراغ
        هذا.السرعة = 0.0
        اطبع_سطر("السيارة توقفت")
    نهاية
نهاية

# الاستخدام
دالة رئيسية() رقم
    # إنشاء سيارة - المنشئ يُستدعى تلقائياً
    سيارة سيارتي = جديد سيارة("تويوتا كامري"، "فضي"، 2024)
    
    سيارتي.تسريع(60.0)
    سيارتي.تسريع(20.0)
    سيارتي.توقف()
    
    ارجع 0
نهاية
```

## 🎨 مثال تطبيقي شامل: نظام مكتبة

```
# صنف الكتاب
صنف كتاب
    نص العنوان
    نص المؤلف
    رقم سنة_النشر
    منطقي معار
    
    دالة منشئ(نص عنوان، نص مؤلف، رقم سنة) فراغ
        هذا.العنوان = عنوان
        هذا.المؤلف = مؤلف
        هذا.سنة_النشر = سنة
        هذا.معار = خطأ
    نهاية
    
    دالة إعارة() ترجع منطقي
        اذا (هذا.معار)
            اطبع_سطر("❌ الكتاب معار بالفعل")
            ارجع خطأ
        نهاية
        
        هذا.معار = صحيح
        اطبع_سطر("✅ تمت إعارة: " + هذا.العنوان)
        ارجع صحيح
    نهاية
    
    دالة إرجاع() ترجع منطقي
        اذا (!هذا.معار)
            اطبع_سطر("❌ الكتاب غير معار")
            ارجع خطأ
        نهاية
        
        هذا.معار = خطأ
        اطبع_سطر("✅ تم إرجاع: " + هذا.العنوان)
        ارجع صحيح
    نهاية
    
    دالة معلومات() فراغ
        نص حالة = هذا.معار ? "معار ❌" : "متاح ✅"
        اطبع_سطر("📖 " + هذا.العنوان)
        اطبع_سطر("   المؤلف: " + هذا.المؤلف)
        اطبع_سطر("   السنة: " + هذا.سنة_النشر)
        اطبع_سطر("   الحالة: " + حالة)
    نهاية
نهاية

# صنف المكتبة
صنف مكتبة
    نص الاسم
    مصفوفة الكتب
    رقم عدد_الإعارات
    
    دالة منشئ(نص اسم) فراغ
        هذا.الاسم = اسم
        هذا.الكتب = []
        هذا.عدد_الإعارات = 0
        اطبع_سطر("🏛️ تم إنشاء مكتبة: " + اسم)
    نهاية
    
    دالة أضف_كتاب(كتاب ك) فراغ
        أضف(هذا.الكتب، ك)
        اطبع_سطر("➕ تمت إضافة كتاب جديد")
    نهاية
    
    دالة أعر_كتاب(رقم رقم_الكتاب) فراغ
        اذا (رقم_الكتاب < 0 أو رقم_الكتاب >= طول(هذا.الكتب))
            اطبع_سطر("❌ رقم كتاب غير صحيح")
            ارجع
        نهاية
        
        كتاب ك = هذا.الكتب[رقم_الكتاب]
        اذا (ك.إعارة())
            هذا.عدد_الإعارات = هذا.عدد_الإعارات + 1
        نهاية
    نهاية
    
    دالة ارجع_كتاب(رقم رقم_الكتاب) فراغ
        اذا (رقم_الكتاب < 0 أو رقم_الكتاب >= طول(هذا.الكتب))
            اطبع_سطر("❌ رقم كتاب غير صحيح")
            ارجع
        نهاية
        
        كتاب ك = هذا.الكتب[رقم_الكتاب]
        ك.إرجاع()
    نهاية
    
    دالة اطبع_جميع_الكتب() فراغ
        اطبع_سطر("═══════════════════════════════")
        اطبع_سطر("📚 كتب مكتبة " + هذا.الاسم)
        اطبع_سطر("═══════════════════════════════")
        
        رقم عداد = 0
        لكل كتاب في هذا.الكتب
            اطبع_سطر("")
            اطبع_سطر("[" + عداد + "]")
            كتاب.معلومات()
            عداد = عداد + 1
        نهاية
        
        اطبع_سطر("")
        اطبع_سطر("═══════════════════════════════")
        اطبع_سطر("📊 إحصائيات:")
        اطبع_سطر("   إجمالي الكتب: " + طول(هذا.الكتب))
        اطبع_سطر("   إجمالي الإعارات: " + هذا.عدد_الإعارات)
        اطبع_سطر("═══════════════════════════════")
    نهاية
نهاية

# ========== البرنامج الرئيسي ==========

دالة رئيسية() رقم
    # إنشاء المكتبة
    مكتبة مكتبتي = جديد مكتبة("مكتبة المعرفة")
    اطبع_سطر("")
    
    # إضافة كتب
    كتاب ك1 = جديد كتاب("تعلم البرمجة"، "أحمد محمد"، 2023)
    كتاب ك2 = جديد كتاب("الخوارزميات"، "فاطمة علي"، 2022)
    كتاب ك3 = جديد كتاب("قواعد البيانات"، "محمود سعيد"، 2024)
    
    مكتبتي.أضف_كتاب(ك1)
    مكتبتي.أضف_كتاب(ك2)
    مكتبتي.أضف_كتاب(ك3)
    
    اطبع_سطر("")
    مكتبتي.اطبع_جميع_الكتب()
    
    # إعارة كتاب
    اطبع_سطر("")
    اطبع_سطر("🔄 إعارة كتاب...")
    مكتبتي.أعر_كتاب(0)
    
    اطبع_سطر("")
    مكتبتي.اطبع_جميع_الكتب()
    
    # إرجاع كتاب
    اطبع_سطر("")
    اطبع_سطر("🔄 إرجاع كتاب...")
    مكتبتي.ارجع_كتاب(0)
    
    اطبع_سطر("")
    مكتبتي.اطبع_جميع_الكتب()
    
    ارجع 0
نهاية
```

## 📚 الخلاصة

الأصناف توفر:
- 🎯 **التنظيم** - تجميع البيانات والدوال ذات الصلة
- 🔒 **التغليف** - إخفاء التفاصيل الداخلية
- ♻️ **إعادة الاستخدام** - إنشاء كائنات متعددة من نفس الصنف
- 🧩 **النمذجة** - تمثيل الكيانات الحقيقية في الكود
