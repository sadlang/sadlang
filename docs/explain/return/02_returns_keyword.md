# كلمة "ترجع" الاختيارية
## دليل تفصيلي للمطورين

## 🎯 مقدمة

كلمة "ترجع" في لغة ص هي كلمة مفتاحية اختيارية تُستخدم لتوضيح نوع القيمة التي تُرجعها الدالة أو القالب. الهدف الأساسي من وجودها هو تحسين قراءة الكود ووضوحه، خاصة للمطورين الجدد أو عند مراجعة كود معقد.

## 📖 الفلسفة وراء كلمة "ترجع"

عند تصميم لغة ص، كان هناك اهتمام خاص بجعل اللغة **طبيعية وقريبة من اللغة العربية المحكية**. في اللغة العربية، عندما نريد أن نصف دالة رياضية نقول: "دالة الجمع **ترجع** رقماً" وليس "دالة الجمع رقماً". لذلك، وُجدت كلمة "ترجع" لجعل الكود يبدو أكثر طبيعية.

في نفس الوقت، نحن ندرك أن بعض المطورين يفضلون الإيجاز والبساطة، خاصة المطورين المخضرمين القادمين من لغات أخرى. لهذا السبب، **كلمة "ترجع" اختيارية تماماً** - يمكنك استخدامها أو حذفها حسب تفضيلك الشخصي.

## 🔍 متى تستخدم "ترجع"؟

### حالة الاستخدام 1: للمبتدئين والكود التعليمي

إذا كنت تكتب كوداً تعليمياً أو توثيقياً، أو إذا كان هدفك أن يقرأ الكود أشخاص غير متخصصين في البرمجة، فإن استخدام "ترجع" يجعل الكود أكثر وضوحاً:

```
# مثال: كود تعليمي لطلاب المدارس
دالة احسب_مساحة_مربع(رقم طول_الضلع) ترجع رقم
    # هذه الدالة ترجع رقماً يمثل المساحة
    ارجع طول_الضلع * طول_الضلع
نهاية
```

عندما يقرأ الطالب هذا الكود، يفهم فوراً: "هذه الدالة **ترجع** رقماً".

### حالة الاستخدام 2: الدوال المعقدة مع معاملات كثيرة

عندما تكون قائمة المعاملات طويلة، قد يكون من الصعب ملاحظة نوع الإرجاع بدون كلمة "ترجع":

```
# بدون "ترجع" - قد يكون غير واضح
دالة احسب_الخصم(رقم السعر، عشري نسبة_الخصم، منطقي عميل_مميز، رقم عدد_السنوات) عشري
    # ... كود معقد
نهاية

# مع "ترجع" - أكثر وضوحاً
دالة احسب_الخصم(رقم السعر، عشري نسبة_الخصم، منطقي عميل_مميز، رقم عدد_السنوات) ترجع عشري
    # ... كود معقد
نهاية
```

الآن من الواضح أن الدالة **ترجع** قيمة عشرية!

### حالة الاستخدام 3: عند استخدام أنواع مخصصة (أصناف)

عندما يكون نوع الإرجاع هو صنف مخصص أنت قمت بتعريفه، قد يساعد استخدام "ترجع" في التمييز بين اسم الصنف ونوع الإرجاع:

```
# تعريف صنف
صنف طالب
    نص الاسم
    رقم العمر
نهاية

# دالة تُرجع كائناً من نوع طالب
دالة احصل_على_طالب(رقم المعرف) ترجع طالب
    # ... كود للبحث عن الطالب
    ارجع طالب_جديد
نهاية
```

## 🚫 متى لا تحتاج "ترجع"؟

### حالة 1: الدوال البسيطة الواضحة

إذا كانت الدالة بسيطة جداً وقصيرة، فإن حذف "ترجع" لا يؤثر على الوضوح:

```
# واضح بدون "ترجع"
دالة ضِعف(رقم ع) رقم
    ارجع ع * 2
نهاية

# نفس الوضوح مع "ترجع"
دالة ضِعف(رقم ع) ترجع رقم
    ارجع ع * 2
نهاية
```

### حالة 2: عند اتباع أسلوب معين في المشروع

إذا كان فريقك أو مشروعك يتبع أسلوباً موحداً (مثلاً: عدم استخدام "ترجع" أبداً)، فالتزم بهذا الأسلوب للحفاظ على تناسق الكود:

```
# أسلوب موحد بدون "ترجع" في كل المشروع
دالة جمع(رقم أ، رقم ب) رقم
    ارجع أ + ب
نهاية

دالة طرح(رقم أ، رقم ب) رقم
    ارجع أ - ب
نهاية

دالة ضرب(رقم أ، رقم ب) رقم
    ارجع أ * ب
نهاية
```

### حالة 3: المطورون المخضرمون

إذا كنت مطور محترف وتفضل الإيجاز، فليس هناك أي مشكلة في حذف "ترجع":

```
# أسلوب مختصر للمحترفين
دالة معالج_البيانات(مصفوفة بيانات) خريطة
    # معالجة معقدة...
    ارجع النتيجة
نهاية
```

## 📊 مقارنة شاملة

### الأسلوب الأول: بدون "ترجع"

**المميزات:**
- ✅ أقصر وأكثر إيجازاً
- ✅ أسرع في الكتابة
- ✅ مألوف للمطورين القادمين من JavaScript أو Python

**العيوب:**
- ❌ قد يكون أقل وضوحاً للمبتدئين
- ❌ في الدوال المعقدة، قد يختلط نوع الإرجاع مع باقي الكود

**مثال:**
```
دالة حساب_المعدل(مصفوفة درجات) عشري
    عشري مجموع = 0
    لكل درجة في درجات
        مجموع = مجموع + درجة
    نهاية
    ارجع مجموع / طول(درجات)
نهاية
```

### الأسلوب الثاني: مع "ترجع"

**المميزات:**
- ✅ أكثر وضوحاً ووصفاً
- ✅ أقرب للغة العربية الطبيعية
- ✅ أفضل للكود التعليمي والتوثيقي
- ✅ يساعد في التمييز بين نوع الإرجاع وباقي الكود

**العيوب:**
- ❌ أطول قليلاً
- ❌ كلمة إضافية للكتابة

**مثال:**
```
دالة حساب_المعدل(مصفوفة درجات) ترجع عشري
    عشري مجموع = 0
    لكل درجة في درجات
        مجموع = مجموع + درجة
    نهاية
    ارجع مجموع / طول(درجات)
نهاية
```

```
نهاية

# دالة لحساب المعدل التراكمي
دالة احسب_معدل_تراكمي(مصفوفة درجات) ترجع عشري

        مجموع = مجموع + درجة
    نهاية

نهاية

# دالة للتحقق من نجاح الطالب
دالة هل_ناجح(عشري معدل) ترجع منطقي
    ارجع معدل >= 2.0
نهاية

# دالة للحصول على تقدير الطالب
دالة احصل_على_تقدير(عشري معدل) ترجع نص
    اذا (معدل >= 4.5)
        ارجع "ممتاز"
    والا_اذا (معدل >= 3.5)
        ارجع "جيد جداً"
    والا_اذا (معدل >= 2.5)
        ارجع "جيد"
    والا_اذا (معدل >= 2.0)
        ارجع "مقبول"
    والا
        ارجع "راسب"
    نهاية
نهاية
```

### مثال 2: مكتبة رياضيات - أسلوب بدون "ترجع"

```
# مكتبة دوال رياضية - أسلوب مختصر

دالة قوة(رقم الأساس، رقم الأس) رقم
    رقم نتيجة = 1
    لكل ع في نطاق(الأس)
        نتيجة = نتيجة * الأساس
    نهاية

    اذا (ن <= 1)

    نهاية

دالة مطلق(رقم ع) رقم
    اذا (ع < 0)
        ارجع -ع
    نهاية
    ارجع ع
نهاية
```

## 🔄 الخلاصة والتوصيات

### للمبتدئين:
استخدم كلمة "ترجع" دائماً في البداية. هذا سيساعدك على:
1. فهم تدفق البيانات في برنامجك
2. تجنب الأخطاء المتعلقة بأنواع البيانات
3. كتابة كود أكثر وضوحاً وسهولة في القراءة

### للمطورين المتوسطين:
- استخدم "ترجع" في الدوال المعقدة والعامة
- يمكنك حذفها في الدوال البسيطة والمساعدة
- الأهم هو **التناسق**: اختر أسلوباً والتزم به في نفس الملف

### للمطورين المحترفين:
- اتبع دليل أسلوب مشروعك (Style Guide)
- إذا لم يكن هناك دليل، اختر ما هو أوضح **للفريق** وليس لك فقط
- في المكتبات العامة والكود مفتوح المصدر، استخدم "ترجع" لزيادة الوضوح

## 💡 نصيحة ذهبية
