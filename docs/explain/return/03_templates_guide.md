# دليل القوالب الشامل (Generic Programming)
## البرمجة العامة في لغة ص

## 🎓 مقدمة: ما هي القوالب؟

القوالب (Templates) هي إحدى أقوى ميزات البرمجة الحديثة، وتُعرف أيضاً بـ **البرمجة العامة** (Generic Programming). القوالب تسمح لك بكتابة دالة أو صنف واحد يعمل مع **أنواع متعددة من البيانات** دون الحاجة لكتابة نفس الكود مرات متعددة.

### مثال توضيحي: المشكلة

تخيل أنك تريد كتابة دالة تُرجع القيمة الأكبر بين قيمتين. بدون القوالب، ستحتاج لكتابة دالة منفصلة لكل نوع:

```
# دالة للأرقام الصحيحة
دالة أكبر_رقم(رقم أ، رقم ب) رقم
    اذا (أ > ب)
        ارجع أ
    والا
        ارجع ب
    نهاية
نهاية

# دالة للأرقام العشرية
دالة أكبر_عشري(عشري أ، عشري ب) عشري
    اذا (أ > ب)
        ارجع أ
    والا
        ارجع ب
    نهاية
نهاية

# دالة للنصوص
دالة أكبر_نص(نص أ، نص ب) نص
    اذا (أ > ب)
        ارجع أ
    والا
        ارجع ب
    نهاية
نهاية
```

هذا الكود **مكرر** و**صعب الصيانة**! إذا أردت تعديل المنطق، ستحتاج لتعديل ثلاث دوال!

### الحل: القوالب!

مع القوالب، تكتب الدالة **مرة واحدة فقط** وتعمل مع جميع الأنواع:

```
# قالب واحد يعمل مع جميع الأنواع!
قالب<نوع ت> دالة أكبر(ت أ، ت ب) ترجع ت
    اذا (أ > ب)
        ارجع أ
    والا
        ارجع ب
    نهاية
نهاية

# الآن يمكنك استخدامها مع أي نوع:
رقم نتيجة1 = أكبر<رقم>(10، 20)          # يعمل مع الأرقام
عشري نتيجة2 = أكبر<عشري>(3.14، 2.71)   # يعمل مع الأعداد العشرية
نص نتيجة3 = أكبر<نص>("أحمد"، "محمد")    # يعمل مع النصوص
```

## 📖 صيغة القوالب في لغة ص

### الصيغة الأساسية

```
قالب<نوع اسم_معامل_النوع> دالة اسم_الدالة(معاملات) ترجع نوع_الإرجاع
    # كود الدالة
نهاية
```

- `قالب` - الكلمة المفتاحية لبدء تعريف قالب
- `<نوع اسم_معامل_النوع>` - تعريف معامل النوع (Type Parameter)
- `اسم_معامل_النوع` - اسم تختاره (مثل: ت، س، النوع، TypeT)
- بقية الدالة تُكتب بشكل طبيعي، لكن تستخدم معامل النوع بدلاً من نوع محدد

### مع كلمة "ترجع" (الطريقة الأولى - موصى بها للمبتدئين)

```
قالب<نوع ت> دالة مضاعفة(ت قيمة) ترجع ت
    ارجع قيمة + قيمة
نهاية
```

### بدون كلمة "ترجع" (الطريقة الثانية - أقصر)

```
قالب<نوع ت> دالة مضاعفة(ت قيمة) ت
    ارجع قيمة + قيمة
نهاية
```

**كلتا الطريقتين صحيحتان ومدعومتان!** اختر ما يناسبك.

## 🔍 شرح تفصيلي لأجزاء القالب

### 1. معامل النوع (Type Parameter)

معامل النوع هو "متغير" يمثل نوع بيانات. تختار له اسماً، وعادة ما نستخدم:
- **ت** أو **T** - للنوع العام (Type)
- **س** أو **U** - لنوع ثانٍ إذا احتجته
- **مفتاح** أو **K** - لنوع المفتاح في الخرائط (Key)
- **قيمة** أو **V** - لنوع القيمة (Value)

```
# مثال بمعامل نوع واحد
قالب<نوع ت> دالة ...

# مثال بمعاملي نوع
قالب<نوع مفتاح، نوع قيمة> دالة ...
```

### 2. استخدام معامل النوع في المعاملات

بعد تعريف معامل النوع، يمكنك استخدامه في أي مكان داخل الدالة:

```
قالب<نوع ت> دالة معالجة(ت عنصر1، ت عنصر2، رقم عدد) ترجع ت
    # ت يُستخدم كنوع للمعاملات
    # رقم هو نوع محدد (ليس جزءاً من القالب)
    # ت أيضاً يُستخدم كنوع إرجاع
نهاية
```

### 3. استدعاء دوال القوالب

عند استدعاء دالة قالب، يجب تحديد النوع المطلوب باستخدام `<النوع>`:

```
# الصيغة العامة
اسم_الدالة<النوع>(المعاملات)

# أمثلة
رقم نتيجة = أكبر<رقم>(5، 10)
عشري نتيجة2 = أكبر<عشري>(3.14، 2.71)
نص نتيجة3 = أكبر<نص>("أ"، "ب")
```

## 💡 أمثلة عملية شاملة

### مثال 1: دالة المبادلة (Swap)

دالة تبادل قيمتين - تعمل مع أي نوع:

```
قالب<نوع ت> دالة تبادل(ت أ، ت ب) ترجع مصفوفة
    # ترجع مصفوفة تحتوي القيمتين مبادلتين
    مصفوفة نتيجة = [ب، أ]
    ارجع نتيجة
نهاية

# الاستخدام
مصفوفة نتيجة1 = تبادل<رقم>(10، 20)
اطبع(نتيجة1)  # [20, 10]

مصفوفة نتيجة2 = تبادل<نص>("أحمد"، "فاطمة")
اطبع(نتيجة2)  # ["فاطمة", "أحمد"]
```

### مثال 2: دالة الأول من ثلاثة

دالة تُرجع أول عنصر من ثلاثة عناصر:

```
قالب<نوع ت> دالة الأول(ت أ، ت ب، ت ج) ترجع ت
    ارجع أ
نهاية

# الاستخدام
رقم أول_رقم = الأول<رقم>(1، 2، 3)
اطبع(أول_رقم)  # 1

نص أول_كلمة = الأول<نص>("مرحبا"، "أهلا"، "سلام")
اطبع(أول_كلمة)  # "مرحبا"
```

### مثال 3: دالة الجمع العام

```
قالب<نوع ت> دالة جمع(ت أ، ت ب) ترجع ت
    ارجع أ + ب
نهاية

# مع الأرقام - يجمع رياضياً
رقم مجموع_أرقام = جمع<رقم>(5، 10)
اطبع(مجموع_أرقام)  # 15

# مع النصوص - يدمج النصوص
نص نص_مدمج = جمع<نص>("مرحبا "، "بك")
اطبع(نص_مدمج)  # "مرحبا بك"

# مع الأرقام العشرية
عشري مجموع_عشري = جمع<عشري>(3.14، 2.71)
اطبع(مجموع_عشري)  # 5.85
```

### مثال 4: دالة بحث في مصفوفة

دالة تبحث عن عنصر في مصفوفة - تعمل مع أي نوع:

```
قالب<نوع ت> دالة يوجد_في(مصفوفة قائمة، ت عنصر_البحث) ترجع منطقي
    لكل عنصر في قائمة
        اذا (عنصر == عنصر_البحث)
            ارجع صحيح
        نهاية
    نهاية
    ارجع خطأ
نهاية

# الاستخدام مع الأرقام
مصفوفة أرقام = [1، 2، 3، 4، 5]
منطقي موجود1 = يوجد_في<رقم>(أرقام، 3)
اطبع(موجود1)  # صحيح

منطقي موجود2 = يوجد_في<رقم>(أرقام، 10)
اطبع(موجود2)  # خطأ

# الاستخدام مع النصوص
مصفوفة أسماء = ["أحمد"، "فاطمة"، "علي"]
منطقي موجود3 = يوجد_في<نص>(أسماء، "فاطمة")
اطبع(موجود3)  # صحيح
```

## 🔄 قوالب بمعاملي نوع

أحياناً تحتاج لأكثر من معامل نوع واحد. على سبيل المثال، دالة تحول من نوع إلى آخر:

```
قالب<نوع مصدر، نوع هدف> دالة حَوِّل(مصدر قيمة) ترجع هدف
    # منطق التحويل
    ارجع قيمة  # تحويل تلقائي
نهاية

# مثال: تحويل رقم إلى نص
نص نص_من_رقم = حَوِّل<رقم، نص>(42)
اطبع(نص_من_رقم)  # "42"
```

مثال آخر: دالة تُنشئ زوجاً (Pair):

```
قالب<نوع أول، نوع ثان> دالة انشئ_زوج(أول قيمة1، ثان قيمة2) ترجع خريطة
    خريطة زوج = {
        "الأول": قيمة1،
        "الثاني": قيمة2
    }
    ارجع زوج
نهاية

# استخدام
خريطة زوج1 = انشئ_زوج<نص، رقم>("العمر"، 25)
اطبع(زوج1["الأول"])   # "العمر"
اطبع(زوج1["الثاني"])  # 25
```

## 📊 مثال تطبيقي شامل: مكتبة مصفوفات

لنبني مكتبة صغيرة من دوال المصفوفات العامة:

```
# ========== مكتبة دوال المصفوفات العامة ==========

# 1. دالة للحصول على أول عنصر
قالب<نوع ت> دالة أول_عنصر(مصفوفة قائمة) ترجع ت
    اذا (طول(قائمة) > 0)
        ارجع قائمة[0]
    نهاية
    # إذا كانت المصفوفة فارغة، نُرجع قيمة افتراضية
    ارجع عدم
نهاية

# 2. دالة للحصول على آخر عنصر
قالب<نوع ت> دالة آخر_عنصر(مصفوفة قائمة) ترجع ت
    رقم الطول = طول(قائمة)
    اذا (الطول > 0)
        ارجع قائمة[الطول - 1]
    نهاية
    ارجع عدم
نهاية

# 3. دالة لحساب مجموع عناصر (تعمل فقط مع الأرقام)
قالب<نوع ت> دالة مجموع_عناصر(مصفوفة قائمة) ترجع ت
    ت مجموع = 0
    لكل عنصر في قائمة
        مجموع = مجموع + عنصر
    نهاية
    ارجع مجموع
نهاية

# 4. دالة لعكس ترتيب المصفوفة
قالب<نوع ت> دالة عكس(مصفوفة قائمة) ترجع مصفوفة
    مصفوفة معكوسة = []
    رقم ع = طول(قائمة) - 1
    بينما (ع >= 0)
        أضف(معكوسة، قائمة[ع])
        ع = ع - 1
    نهاية
    ارجع معكوسة
نهاية

# 5. دالة للحصول على أكبر عنصر
قالب<نوع ت> دالة أكبر_عنصر(مصفوفة قائمة) ترجع ت
    اذا (طول(قائمة) == 0)
        ارجع عدم
    نهاية
    
    ت الأكبر = قائمة[0]
    لكل عنصر في قائمة
        اذا (عنصر > الأكبر)
            الأكبر = عنصر
        نهاية
    نهاية
    ارجع الأكبر
نهاية

# ========== استخدام المكتبة ==========

دالة رئيسية() رقم
    اطبع("=== اختبار مكتبة المصفوفات ===")
    اطبع("")
    
    # اختبار مع الأرقام
    مصفوفة أرقام = [5، 2، 8، 1، 9]
    اطبع("المصفوفة: " + أرقام)
    
    رقم أول = أول_عنصر<رقم>(أرقام)
    اطبع("الأول: " + أول)
    
    رقم آخر = آخر_عنصر<رقم>(أرقام)
    اطبع("الآخر: " + آخر)
    
    رقم مجموع = مجموع_عناصر<رقم>(أرقام)
    اطبع("المجموع: " + مجموع)
    
    رقم أكبر = أكبر_عنصر<رقم>(أرقام)
    اطبع("الأكبر: " + أكبر)
    
    مصفوفة معكوسة = عكس<رقم>(أرقام)
    اطبع("معكوسة: " + معكوسة)
    
    اطبع("")
    
    # اختبار مع النصوص
    مصفوفة أسماء = ["أحمد"، "فاطمة"، "علي"، "مريم"]
    اطبع("الأسماء: " + أسماء)
    
    نص أول_اسم = أول_عنصر<نص>(أسماء)
    اطبع("الأول: " + أول_اسم)
    
    نص آخر_اسم = آخر_عنصر<نص>(أسماء)
    اطبع("الآخر: " + آخر_اسم)
    
    مصفوفة أسماء_معكوسة = عكس<نص>(أسماء)
    اطبع("معكوسة: " + أسماء_معكوسة)
    
    ارجع 0
نهاية
```

## ⚠️ نقاط مهمة يجب تذكرها

### 1. معامل النوع ليس نوعاً حقيقياً

معامل النوع (مثل `ت`) هو **بديل** (placeholder) للنوع الحقيقي. عند الاستدعاء، يتم **استبداله** بالنوع المحدد:

```
قالب<نوع ت> دالة مثال(ت قيمة) ترجع ت
    # هنا، "ت" ليس نوعاً موجوداً
    # بل بديل يُستبدل عند الاستدعاء
نهاية

# عند الاستدعاء:
رقم نتيجة = مثال<رقم>(5)
# الآن، كل "ت" في الدالة يُستبدل بـ "رقم"
```

### 2. العمليات يجب أن تكون مدعومة للنوع

إذا استخدمت عملية معينة (مثل `+` أو `>`) داخل القالب، يجب أن يدعم النوع المُستخدم هذه العملية:

```
قالب<نوع ت> دالة اجمع(ت أ، ت ب) ترجع ت
    ارجع أ + ب  # العملية + يجب أن تكون مدعومة
نهاية

# ✅ يعمل - الأرقام تدعم +
رقم نتيجة1 = اجمع<رقم>(5، 10)

# ✅ يعمل - النصوص تدعم + (للدمج)
نص نتيجة2 = اجمع<نص>("مرحبا "، "بك")

# ❌ قد لا يعمل - المنطقي لا يدعم +
منطقي نتيجة3 = اجمع<منطقي>(صحيح، خطأ)  # خطأ!
```

### 3. يجب تحديد النوع عند الاستدعاء

لا يمكن للمترجم تخمين النوع تلقائياً (حالياً):

```
# ❌ خطأ - لم نحدد النوع
رقم نتيجة = أكبر(5، 10)

# ✅ صحيح - حددنا النوع
رقم نتيجة = أكبر<رقم>(5، 10)
```

## 🎯 متى تستخدم القوالب؟

### استخدم القوالب عندما:
1. ✅ تريد نفس المنطق لأنواع مختلفة
2. ✅ تبني مكتبة أو أداة عامة
3. ✅ تريد تقليل تكرار الكود
4. ✅ المنطق لا يعتمد على نوع البيانات المحدد

### لا تستخدم القوالب عندما:
1. ❌ المنطق مختلف لكل نوع
2. ❌ تعمل مع نوع واحد فقط
3. ❌ القالب يجعل الكود أكثر تعقيداً بدلاً من تبسيطه
