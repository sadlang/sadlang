# الأنواع العامة (Generics)
## دليل شامل للمبرمجين

---

## 🎯 ما هي الأنواع العامة؟

**الأنواع العامة (Generics)** هي واحدة من أقوى الميزات في لغات البرمجة الحديثة، وهي تسمح لك بكتابة كود مرن وقابل لإعادة الاستخدام مع الحفاظ على أمان الأنواع (Type Safety). ببساطة، الأنواع العامة تسمح لك بكتابة دالة أو صنف واحد يعمل مع أنواع بيانات مختلفة دون الحاجة لإعادة كتابة نفس الكود لكل نوع.

تخيل أنك تريد إنشاء صندوق (Box) يمكنه تخزين أي شيء - أرقام، نصوص، قوائم، أو حتى كائنات معقدة. بدلاً من إنشاء `صندوق_أرقام`، `صندوق_نصوص`، `صندوق_قوائم`، وهكذا، يمكنك إنشاء `صندوق<T>` واحد حيث `T` هو متغير النوع (Type Parameter) الذي يتم تحديده عند الاستخدام.

الأنواع العامة تحل مشكلة أساسية في البرمجة: كيف نكتب كوداً عاماً (Generic) دون التضحية بأمان الأنواع؟ قبل Generics، كان المبرمجون يستخدمون أحد خيارين:
1. **التكرار**: كتابة نفس الكود لكل نوع (مما يؤدي لكود طويل ومملّ)
2. **استخدام Any/Object**: استخدام نوع عام يقبل أي شيء (مما يفقدنا أمان الأنواع)

الأنواع العامة تقدم الحل الأمثل: كود عام + أمان أنواع كامل.

---

## 📚 المفاهيم الأساسية

### 1. معاملات الأنواع (Type Parameters)

معاملات الأنواع هي متغيرات خاصة تُكتب بين القوسين الزاويين `< >` وتمثل أنواعاً سيتم تحديدها لاحقاً عند الاستخدام. التقليد الشائع هو استخدام أحرف كبيرة منفردة:
- `T` (Type): نوع عام
- `E` (Element): نوع العنصر
- `K` (Key): نوع المفتاح
- `V` (Value): نوع القيمة

لكن في لغة ص، يمكنك استخدام أسماء عربية واضحة مثل `النوع`، `العنصر`، `المفتاح`، `القيمة`.

### 2. القيود على الأنواع (Type Constraints)

أحياناً تحتاج لتقييد الأنواع التي يمكن استخدامها مع Generic. مثلاً، قد تريد دالة تقارن عنصرين، لكن المقارنة تتطلب أن يكون النوع قابلاً للمقارنة. هنا تأتي القيود:

```sad
دالة الأكبر<T: قابل_للمقارنة>(أ: T، ب: T) -> T {
    إذا (أ > ب) {
        ارجع أ
    }
    ارجع ب
}
```

القيد `T: قابل_للمقارنة` يضمن أن النوع `T` يدعم عمليات المقارنة.

### 3. التباين (Variance)

التباين يحدد كيف تتعلق الأنواع العامة ببعضها عند وجود علاقة وراثة:
- **Covariance (التباين المشترك)**: `قائمة<كلب>` يمكن استخدامها كـ `قائمة<حيوان>`
- **Contravariance (التباين العكسي)**: `مقارن<حيوان>` يمكن استخدامه كـ `مقارن<كلب>`
- **Invariance (عدم التباين)**: لا يوجد علاقة بين `صندوق<كلب>` و `صندوق<حيوان>`

### 4. Monomorphization

عند الترجمة، يتم إنشاء نسخة منفصلة من الكود لكل نوع مستخدم. مثلاً:
```sad
قائمة<رقم> أرقام
قائمة<نص> نصوص
```
يتم ترجمتهما إلى نوعين منفصلين تماماً في الكود الآلي، مما يحقق أفضل أداء.

## 🎓 لماذا نحتاج الأنواع العامة؟

### المشكلة: التكرار

تخيل أنك تريد إنشاء دالة للعثور على أكبر عنصر في مصفوفة. بدون Generics:

```sad
دالة أكبر_رقم(المصفوفة: رقم[]) -> رقم {
    متغير الأكبر = المصفوفة[0]
    لكل عنصر في المصفوفة {
        إذا (عنصر > الأكبر) {
            الأكبر = عنصر
        }
    }
    ارجع الأكبر
}

دالة أكبر_نص(المصفوفة: نص[]) -> نص {
    متغير الأكبر = المصفوفة[0]
    لكل عنصر في المصفوفة {
        إذا (عنصر > الأكبر) {
            الأكبر = عنصر
        }
    }
    ارجع الأكبر
}

دالة أكبر_عشري(المصفوفة: عشري[]) -> عشري {
    متغير الأكبر = المصفوفة[0]
    لكل عنصر في المصفوفة {
        إذا (عنصر > الأكبر) {
            الأكبر = عنصر
        }
    }
    ارجع الأكبر
}
```

هذا تكرار مروع! نفس المنطق يُكتب 3 مرات فقط لاختلاف النوع.

### الحل: Generics

```sad
دالة الأكبر<T: قابل_للمقارنة>(المصفوفة: T[]) -> T {
    متغير الأكبر = المصفوفة[0]
    لكل عنصر في المصفوفة {
        إذا (عنصر > الأكبر) {
            الأكبر = عنصر
        }
    }
    ارجع الأكبر
}

# الآن يمكن استخدامها مع أي نوع قابل للمقارنة:
متغير أكبر_رقم = الأكبر<رقم>([1، 5، 3، 9، 2])      # 9
متغير أكبر_نص = الأكبر<نص>(["أحمد"، "زينب"، "محمد"])  # "زينب"
متغير أكبر_عشري = الأكبر<عشري>([1.5، 3.7، 2.1])    # 3.7
```

دالة واحدة تعمل مع جميع الأنواع!

## 💡 أمثلة عملية

### المثال الأول: صندوق عام (Generic Box)

الصندوق هو أبسط مثال على Generics - حاوية يمكنها تخزين قيمة من أي نوع:

```sad
# تعريف صنف صندوق عام
صنف صندوق<T> {
    خاص متغير المحتوى: T
    
    # المُنشئ
    دالة جديد(محتوى: T) {
        هذا.المحتوى = محتوى
    }
    
    # وضع قيمة جديدة
    دالة ضع(قيمة: T) {
        هذا.المحتوى = قيمة
    }
    
    # استخراج القيمة
    دالة احصل() -> T {
        ارجع هذا.المحتوى
    }
    
    # هل الصندوق يحتوي على قيمة محددة؟
    دالة يحتوي(قيمة: T) -> منطقي {
        ارجع هذا.المحتوى == قيمة
    }
    
    # تحويل المحتوى باستخدام دالة
    دالة حوّل<U>(دالة_التحويل: (T) -> U) -> صندوق<U> {
        متغير قيمة_جديدة = دالة_التحويل(هذا.المحتوى)
        ارجع صندوق<U>.جديد(قيمة_جديدة)
    }
}

# الاستخدام:

# صندوق للأرقام
متغير صندوق_رقم = صندوق<رقم>.جديد(42)
اطبع(صندوق_رقم.احصل())  # 42
صندوق_رقم.ضع(100)
اطبع(صندوق_رقم.احصل())  # 100

# صندوق للنصوص
متغير صندوق_نص = صندوق<نص>.جديد("مرحباً")
اطبع(صندوق_نص.احصل())  # "مرحباً"

# التحويل بين الأنواع
متغير صندوق_طول = صندوق_نص.حوّل<رقم>(|نص| -> نص.طول())
اطبع(صندوق_طول.احصل())  # 5

# صندوق لقوائم
متغير صندوق_قائمة = صندوق<قائمة<رقم>>.جديد([1، 2، 3])
متغير القائمة = صندوق_قائمة.احصل()
اطبع(القائمة[0])  # 1
```

**الفوائد:**
- نفس الكود يعمل مع أي نوع
- أمان أنواع كامل: لا يمكن وضع نص في `صندوق<رقم>`
- المترجم يكتشف الأخطاء مبكراً
- لا حاجة للتحويل (casting)

### المثال الثاني: قائمة مرتبطة عامة (Generic Linked List)

مثال أكثر تعقيداً يوضح قوة Generics في هياكل البيانات:

```sad
# تعريف عقدة في القائمة المرتبطة
صنف عقدة<T> {
    عام متغير القيمة: T
    عام متغير التالي: عقدة<T>?
    
    دالة جديد(قيمة: T) {
        هذا.القيمة = قيمة
        هذا.التالي = لاشيء
    }
}

# تعريف القائمة المرتبطة
صنف قائمة_مرتبطة<T> {
    خاص متغير الرأس: عقدة<T>?
    خاص متغير الحجم: رقم
    
    # المُنشئ
    دالة جديد() {
        هذا.الرأس = لاشيء
        هذا.الحجم = 0
    }
    
    # إضافة عنصر في البداية
    دالة أضف_في_البداية(قيمة: T) {
        متغير عقدة_جديدة = عقدة<T>.جديد(قيمة)
        عقدة_جديدة.التالي = هذا.الرأس
        هذا.الرأس = عقدة_جديدة
        هذا.الحجم = هذا.الحجم + 1
    }
    
    # إضافة عنصر في النهاية
    دالة أضف_في_النهاية(قيمة: T) {
        متغير عقدة_جديدة = عقدة<T>.جديد(قيمة)
        
        إذا (هذا.الرأس == لاشيء) {
            هذا.الرأس = عقدة_جديدة
        } وإلا {
            متغير الحالي = هذا.الرأس
            بينما (الحالي.التالي != لاشيء) {
                الحالي = الحالي.التالي
            }
            الحالي.التالي = عقدة_جديدة
        }
        
        هذا.الحجم = هذا.الحجم + 1
    }
    
    # الحصول على عنصر بموقع محدد
    دالة احصل(الموقع: رقم) -> T? {
        إذا (الموقع < 0 أو الموقع >= هذا.الحجم) {
            ارجع لاشيء
        }
        
        متغير الحالي = هذا.الرأس
        متغير العداد = 0
        
        بينما (العداد < الموقع) {
            الحالي = الحالي.التالي
            العداد = العداد + 1
        }
        
        ارجع الحالي.القيمة
    }
    
    # طباعة جميع العناصر
    دالة اطبع_الكل() {
        متغير الحالي = هذا.الرأس
        بينما (الحالي != لاشيء) {
            اطبع(الحالي.القيمة)
            الحالي = الحالي.التالي
        }
    }
    
    # تحويل القائمة باستخدام دالة
    دالة حوّل<U>(دالة_التحويل: (T) -> U) -> قائمة_مرتبطة<U> {
        متغير قائمة_جديدة = قائمة_مرتبطة<U>.جديد()
        متغير الحالي = هذا.الرأس
        
        بينما (الحالي != لاشيء) {
            متغير قيمة_جديدة = دالة_التحويل(الحالي.القيمة)
            قائمة_جديدة.أضف_في_النهاية(قيمة_جديدة)
            الحالي = الحالي.التالي
        }
        
        ارجع قائمة_جديدة
    }
    
    # تصفية العناصر
    دالة صفّي(شرط: (T) -> منطقي) -> قائمة_مرتبطة<T> {
        متغير قائمة_جديدة = قائمة_مرتبطة<T>.جديد()
        متغير الحالي = هذا.الرأس
        
        بينما (الحالي != لاشيء) {
            إذا (شرط(الحالي.القيمة)) {
                قائمة_جديدة.أضف_في_النهاية(الحالي.القيمة)
            }
            الحالي = الحالي.التالي
        }
        
        ارجع قائمة_جديدة
    }
}

# الاستخدام:

# قائمة أرقام
متغير قائمة_أرقام = قائمة_مرتبطة<رقم>.جديد()
قائمة_أرقام.أضف_في_النهاية(10)
قائمة_أرقام.أضف_في_النهاية(20)
قائمة_أرقام.أضف_في_النهاية(30)
قائمة_أرقام.اطبع_الكل()  # 10، 20، 30

# قائمة نصوص
متغير قائمة_أسماء = قائمة_مرتبطة<نص>.جديد()
قائمة_أسماء.أضف_في_البداية("محمد")
قائمة_أسماء.أضف_في_البداية("فاطمة")
قائمة_أسماء.أضف_في_البداية("علي")
قائمة_أسماء.اطبع_الكل()  # علي، فاطمة، محمد

# تحويل قائمة أرقام إلى قائمة نصوص
متغير قائمة_نصوص = قائمة_أرقام.حوّل<نص>(|رقم| -> رقم.إلى_نص())
قائمة_نصوص.اطبع_الكل()  # "10"، "20"، "30"

# تصفية الأرقام الزوجية
متغير قائمة_زوجية = قائمة_أرقام.صفّي(|رقم| -> رقم % 2 == 0)
قائمة_زوجية.اطبع_الكل()  # 10، 20، 30
```

**الفوائد المتقدمة:**
- هيكل بيانات واحد يعمل مع أي نوع
- دوال التحويل والتصفية تحافظ على أمان الأنواع
- الكود قابل لإعادة الاستخدام 100%
- سهولة في الصيانة والتوسع

## 🔧 التنفيذ في لغة ص

في لغة ص، تم تنفيذ نظام Generics كامل في **Phase 1.3.4** يتضمن:

### 1. Generic Types
```cpp
class GenericType : public Type {
    TypeParameterList typeParameters_;
    TypePtr baseType_;
    // ...
};
```

### 2. Type Parameters
```cpp
class TypeParameter {
    std::string name_;
    TypeConstraintList constraints_;
    Variance variance_;
    // ...
};
```

### 3. Type Constraints
```cpp
class TypeConstraint {
    enum class Kind {
        SubtypeOf,      // T: Parent
        ImplementsInterface,  // T: Interface
        HasMethod,      // T: { method() }
        Equality        // T == U
    };
    // ...
};
```

### 4. Generic Instantiation (Monomorphization)
```cpp
class GenericInstantiation {
    GenericTypePtr genericType_;
    TypeList typeArguments_;
    TypePtr instantiate();  // Creates concrete type
    // ...
};
```

### الميزات المُنفذة:
✅ Generic functions  
✅ Generic classes  
✅ Type constraints  
✅ Variance (covariant, contravariant, invariant)  
✅ Nested generics  
✅ Generic inference  
✅ Monomorphization للأداء الأمثل

## 📖 مصطلحات ذات صلة

### Type Parameter (معامل النوع)
المتغير الذي يمثل نوعاً عاماً، مثل `T` في `قائمة<T>`.

### Type Argument (وسيط النوع)
النوع الفعلي المُستخدم عند Instantiation، مثل `رقم` في `قائمة<رقم>`.

### Generic Constraint (قيد عام)
شرط يجب أن يحققه النوع المُستخدم، مثل `T: قابل_للمقارنة`.

### Monomorphization
عملية إنشاء نسخ مخصصة من الكود العام لكل نوع مستخدم.

### Type Inference (استنتاج الأنواع)
قدرة المترجم على استنتاج وسائط الأنواع تلقائياً:
```sad
متغير قائمة = [1، 2، 3]  # المترجم يستنتج: قائمة<رقم>
```

## 🎯 الخلاصة

الأنواع العامة (Generics) هي أداة قوية تسمح لك بكتابة كود:
- ✅ **مرن**: يعمل مع أنواع متعددة
- ✅ **آمن**: المترجم يضمن صحة الأنواع
- ✅ **قابل لإعادة الاستخدام**: لا تكرار
- ✅ **سريع**: Monomorphization يحقق أداء ممتاز

في لغة ص، Generics مُنفذة بالكامل مع دعم:
- Generic functions & classes
- Type constraints
- Variance
- Type inference
- Monomorphization

الأنواع العامة هي أساس البرمجة الحديثة وتُستخدم في كل مكان: القوائم، القواميس، الأشجار، الخوارزميات، وأكثر بكثير!
