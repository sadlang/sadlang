# مطابقة الأنماط (مطابقة الانماط)
## دليل شامل للمبرمجين

---

## 🎯 ما هي مطابقة الأنماط؟

**مطابقة الأنماط (مطابقة الانماط)** هي أسلوب برمجي قوي يسمح لك بفحص بنية البيانات ومحتواها في نفس الوقت، ثم تنفيذ كود مختلف بناءً على النمط الذي يطابق البيانات. إنها أكثر من مجرد `switch` أو `if-else` - إنها طريقة معبّرة وآمنة لتفكيك وفحص البيانات المعقدة.

تخيل أنك تفتح صندوقاً وتريد معرفة ما بداخله. بدلاً من فتحه والتحقق يدوياً من كل احتمال، مطابقة الانماط يسمح لك بقول: "إذا كان الصندوق يحتوي على تفاحة حمراء، افعل X. إذا كان يحتوي على تفاحة خضراء، افعل Y. إذا كان يحتوي على برتقالة، افعل Z."

```sad
طابق الصندوق 
    تفاحة(اللون: "أحمر") => اطبع("تفاحة حمراء لذيذة!")
    تفاحة(اللون: "أخضر") => اطبع("تفاحة خضراء منعشة!")
    برتقالة(الحجم) إذا (الحجم > 5) => اطبع("برتقالة كبيرة!")
    _ => اطبع("شيء آخر")
نهاية
```

مطابقة الانماط تحل مشاكل عديدة:
1. **تفكيك هياكل البيانات**: استخراج قيم من هياكل معقدة
2. **التحقق من الشروط**: فحص قيم وأنواع متعددة دفعة واحدة
3. **Exhaustiveness**: التأكد من معالجة جميع الحالات الممكنة
4. **قراءة أفضل**: كود أكثر وضوحاً وتعبيراً

## 📚 المفاهيم الأساسية

### 1. الأنماط (Patterns)

النمط هو "قالب" يصف شكل البيانات التي تريد مطابقتها. أنواع الأنماط:

#### أ. Literal Pattern (نمط حرفي)
يطابق قيمة محددة:
```sad
طابق العدد 
    0 => اطبع("صفر")
    1 => اطبع("واحد")
    42 => اطبع("الجواب النهائي!")
نهاية
```

#### ب. Variable Pattern (نمط متغير)
يطابق أي قيمة ويربطها بمتغير:
```sad
طابق القيمة 
    س => اطبع("القيمة هي: " + س)
نهاية
```

#### ج. Wildcard Pattern (نمط البديل)
يطابق أي شيء دون ربطه:
```sad
طابق القيمة 
    0 => اطبع("صفر")
    _ => اطبع("قيمة أخرى")
نهاية
```

#### د. Constructor Pattern (نمط المُنشئ)
يطابق نوعاً محدداً ويفكك حقوله:
```sad
طابق النقطة 
    نقطة(س، ص) => اطبع("النقطة عند " + س + "، " + ص)
نهاية
```

#### هـ. Tuple Pattern (نمط المجموعة)
يطابق tuple ويفككه:
```sad
طابق الزوج 
    (أول، ثاني) => اطبع(أول + " و " + ثاني)
نهاية
```

#### و. Array/List Pattern (نمط المصفوفة)
يطابق مصفوفة أو قائمة ويفككها:
```sad
طابق القائمة 
    [] => اطبع("قائمة فارغة")
    [أول] => اطبع("عنصر واحد: " + أول)
    [أول، ثاني، ..الباقي] => اطبع("يبدأ بـ " + أول + " و " + ثاني)
نهاية
```

#### ز. Or Pattern (نمط أو)
يطابق أحد عدة أنماط:
```sad
طابق الرقم 
    0 | 1 => اطبع("صفر أو واحد")
    2 | 3 | 5 | 7 => اطبع("عدد أولي صغير")
نهاية
```

### 2. Guards (الحراس)

Guards هي شروط إضافية يتم فحصها بعد مطابقة النمط:

```sad
طابق العمر 
    س إذا (س < 13) => اطبع("طفل")
    س إذا (س < 20) => اطبع("مراهق")
    س إذا (س < 65) => اطبع("بالغ")
    _ => اطبع("كبير السن")
نهاية
```

### 3. Exhaustiveness Checking (التحقق من الشمولية)

المترجم يتحقق من أنك قد غطيت جميع الحالات الممكنة:

```sad
نوع اللون = أحمر | أخضر | أزرق

طابق اللون 
    أحمر => ...
    أخضر => ...
    # ❌ خطأ: لم تعالج أزرق
نهاية

# الحل:
طابق اللون 
    أحمر => ...
    أخضر => ...
    أزرق => ...  # ✅ جميع الحالات معالجة
نهاية
```

## 🎓 لماذا نحتاج مطابقة الأنماط؟

### المشكلة: if-else معقدة

تخيل أنك تعالج أشكالاً هندسية مختلفة. بدون مطابقة الانماط:

```sad
صنف دائرة 
    متغير نصف_القطر: عشري
نهاية

صنف مستطيل 
    متغير العرض: عشري
    متغير الطول: عشري
نهاية

صنف مثلث 
    متغير القاعدة: عشري
    متغير الارتفاع: عشري
نهاية

نوع شكل = دائرة | مستطيل | مثلث

# بدون مطابقة الانماط:
دالة المساحة(الشكل: شكل) -> عشري 
    إذا (الشكل نوع دائرة) 
        متغير د = (الشكل كـ دائرة)
        ارجع 3.14159 * د.نصف_القطر * د.نصف_القطر
    نهاية وإلا إذا (الشكل نوع مستطيل) 
        متغير م = (الشكل كـ مستطيل)
        ارجع م.العرض * م.الطول
    نهاية وإلا إذا (الشكل نوع مثلث) 
        متغير م = (الشكل كـ مثلث)
        ارجع 0.5 * م.القاعدة * م.الارتفاع
    نهاية وإلا 
        ارجع 0.0  # حالة لا يجب أن تحدث
    نهاية
نهاية
```

هذا الكود:
- ❌ مطوّل ومملّ
- ❌ يحتاج casting يدوي
- ❌ عرضة للأخطاء
- ❌ لا يتحقق من الشمولية

### الحل: مطابقة الانماط

```sad
# مع مطابقة الانماط:
دالة المساحة(الشكل: شكل) -> عشري 
    طابق الشكل 
        دائرة(ر) => ارجع 3.14159 * ر * ر
        مستطيل(ع، ط) => ارجع ع * ط
        مثلث(ق، ا) => ارجع 0.5 * ق * ا
    نهاية
نهاية
```

هذا الكود:
- ✅ موجز وواضح
- ✅ casting تلقائي
- ✅ آمن من الأخطاء
- ✅ المترجم يتحقق من الشمولية

## 💡 أمثلة عملية

### المثال الأول: معالج تعبيرات حسابية (Expression Evaluator)

لنبني معالج لتعبيرات حسابية بسيطة باستخدام مطابقة الانماط:

```sad
# تعريف أنواع التعبيرات
نوع تعبير =
    | رقم(قيمة: رقم)
    | جمع(يسار: تعبير، يمين: تعبير)
    | طرح(يسار: تعبير، يمين: تعبير)
    | ضرب(يسار: تعبير، يمين: تعبير)
    | قسمة(يسار: تعبير، يمين: تعبير)
    | قوة(أساس: تعبير، أس: تعبير)
    | سالب(قيمة: تعبير)

# دالة لتقييم التعبير
دالة قيّم(التعبير: تعبير) -> رقم 
    طابق التعبير 
        # رقم مباشر
        رقم(ق) => ارجع ق
        
        # عمليات ثنائية
        جمع(يسار، يمين) => ارجع قيّم(يسار) + قيّم(يمين)
        طرح(يسار، يمين) => ارجع قيّم(يسار) - قيّم(يمين)
        ضرب(يسار، يمين) => ارجع قيّم(يسار) * قيّم(يمين)
        قسمة(يسار، يمين) => 
            متغير البسط = قيّم(يسار)
            متغير المقام = قيّم(يمين)
            إذا (المقام == 0) 
                رمي خطأ("القسمة على صفر")
            نهاية
            ارجع البسط / المقام
        نهاية
        قوة(أساس، أس) => 
            متغير الأساس = قيّم(أساس)
            متغير الأس = قيّم(أس)
            ارجع الأساس ^ الأس
        نهاية
        
        # عملية أحادية
        سالب(قيمة) => ارجع -قيّم(قيمة)
    نهاية
نهاية

# الاستخدام:

# (5 + 3) * 2
متغير تعبير1 = ضرب(
    جمع(رقم(5)، رقم(3))،
    رقم(2)
)
اطبع(قيّم(تعبير1))  # 16

# (10 - 4) / 2
متغير تعبير2 = قسمة(
    طرح(رقم(10)، رقم(4))،
    رقم(2)
)
اطبع(قيّم(تعبير2))  # 3

# 2 ^ 3 + 1
متغير تعبير3 = جمع(
    قوة(رقم(2)، رقم(3))،
    رقم(1)
)
اطبع(قيّم(تعبير3))  # 9

# -(5 * 3)
متغير تعبير4 = سالب(ضرب(رقم(5)، رقم(3)))
اطبع(قيّم(تعبير4))  # -15

# دالة لتحويل التعبير إلى نص
دالة إلى_نص(التعبير: تعبير) -> نص 
    طابق التعبير 
        رقم(ق) => ارجع ق.إلى_نص()
        
        جمع(يسار، يمين) => 
            ارجع "(" + إلى_نص(يسار) + " + " + إلى_نص(يمين) + ")"
        نهاية
        
        طرح(يسار، يمين) => 
            ارجع "(" + إلى_نص(يسار) + " - " + إلى_نص(يمين) + ")"
        نهاية
        
        ضرب(يسار، يمين) => 
            ارجع إلى_نص(يسار) + " × " + إلى_نص(يمين)
        نهاية
        
        قسمة(يسار، يمين) => 
            ارجع إلى_نص(يسار) + " ÷ " + إلى_نص(يمين)
        نهاية
        
        قوة(أساس، أس) => 
            ارجع إلى_نص(أساس) + "^" + إلى_نص(أس)
        نهاية
        
        سالب(قيمة) => ارجع "-" + إلى_نص(قيمة)
    نهاية
نهاية

اطبع(إلى_نص(تعبير1))  # "(5 + 3) × 2"
اطبع(إلى_نص(تعبير2))  # "(10 - 4) ÷ 2"
اطبع(إلى_نص(تعبير3))  # "2^3 + 1"

# دالة لتبسيط التعبيرات
دالة بسّط(التعبير: تعبير) -> تعبير 
    طابق التعبير 
        # تبسيط جمع
        جمع(رقم(0)، يمين) => ارجع بسّط(يمين)  # 0 + x = x
        جمع(يسار، رقم(0)) => ارجع بسّط(يسار)  # x + 0 = x
        جمع(رقم(أ)، رقم(ب)) => ارجع رقم(أ + ب)  # ثابتان
        
        # تبسيط ضرب
        ضرب(رقم(0)، _) => ارجع رقم(0)  # 0 × x = 0
        ضرب(_, رقم(0)) => ارجع رقم(0)  # x × 0 = 0
        ضرب(رقم(1)، يمين) => ارجع بسّط(يمين)  # 1 × x = x
        ضرب(يسار، رقم(1)) => ارجع بسّط(يسار)  # x × 1 = x
        ضرب(رقم(أ)، رقم(ب)) => ارجع رقم(أ * ب)  # ثابتان
        
        # تبسيط قوة
        قوة(_, رقم(0)) => ارجع رقم(1)  # x^0 = 1
        قوة(أساس، رقم(1)) => ارجع بسّط(أساس)  # x^1 = x
        قوة(رقم(أ)، رقم(ب)) => ارجع رقم(أ ^ ب)  # ثابتان
        
        # باقي الحالات: تبسيط العناصر الفرعية
        جمع(يسار، يمين) => ارجع جمع(بسّط(يسار)، بسّط(يمين))
        طرح(يسار، يمين) => ارجع طرح(بسّط(يسار)، بسّط(يمين))
        ضرب(يسار، يمين) => ارجع ضرب(بسّط(يسار)، بسّط(يمين))
        قسمة(يسار، يمين) => ارجع قسمة(بسّط(يسار)، بسّط(يمين))
        قوة(أساس، أس) => ارجع قوة(بسّط(أساس)، بسّط(أس))
        سالب(قيمة) => ارجع سالب(بسّط(قيمة))
        
        # رقم مباشر: بالفعل مُبسط
        رقم(_) => ارجع التعبير
    نهاية
نهاية

# الاستخدام:
متغير معقد = جمع(ضرب(رقم(1)، رقم(5))، رقم(0))  # (1 × 5) + 0
متغير مُبسط = بسّط(معقد)
اطبع(إلى_نص(مُبسط))  # "5"
```

**الفوائد:**
- ✅ كود واضح ومعبّر
- ✅ سهولة إضافة عمليات جديدة
- ✅ Exhaustiveness checking تلقائي
- ✅ لا حاجة لـ instanceof/casting

### المثال الثاني: State Machine (آلة الحالات)

مطابقة الأنماط مثالية لتنفيذ State Machines:

```sad
# تعريف الحالات
نوع حالة_الاتصال =
    | منفصل
    | جاري_الاتصال
    | متصل(عنوان_IP: نص، المنفذ: رقم)
    | فشل_الاتصال(سبب: نص)
    | جاري_القطع

# تعريف الأحداث
نوع حدث =
    | طلب_اتصال(عنوان: نص، منفذ: رقم)
    | نجح_الاتصال
    | فشل_الاتصال(خطأ: نص)
    | طلب_قطع
    | اكتمل_القطع

# دالة انتقال الحالة
دالة انتقال(الحالة: حالة_الاتصال، الحدث: حدث) -> حالة_الاتصال 
    طابق (الحالة، الحدث) 
        # من منفصل
        (منفصل، طلب_اتصال(ع، م)) => 
            اطبع("بدء الاتصال بـ " + ع + ":" + م)
            ارجع جاري_الاتصال
        نهاية
        
        # من جاري_الاتصال
        (جاري_الاتصال، نجح_الاتصال) => 
            # نحتاج العنوان والمنفذ من الحدث السابق
            # في تطبيق حقيقي، نحفظها
            اطبع("الاتصال نجح!")
            ارجع متصل("192.168.1.1"، 8080)
        نهاية
        
        (جاري_الاتصال، فشل_الاتصال(خطأ)) => 
            اطبع("فشل الاتصال: " + خطأ)
            ارجع فشل_الاتصال(خطأ)
        نهاية
        
        # من متصل
        (متصل(ع، م)، طلب_قطع) => 
            اطبع("قطع الاتصال من " + ع + ":" + م)
            ارجع جاري_القطع
        نهاية
        
        # من جاري_القطع
        (جاري_القطع، اكتمل_القطع) => 
            اطبع("تم القطع بنجاح")
            ارجع منفصل
        نهاية
        
        # من فشل_الاتصال
        (فشل_الاتصال(_)، طلب_اتصال(ع، م)) => 
            اطبع("إعادة محاولة الاتصال")
            ارجع جاري_الاتصال
        نهاية
        
        # حالات غير صحيحة
        _ => 
            اطبع("حدث غير متوقع في هذه الحالة")
            ارجع الحالة  # لا تغيير
        نهاية
    نهاية
نهاية

# الاستخدام:
متغير الحالة = منفصل

# سيناريو نجاح الاتصال
الحالة = انتقال(الحالة، طلب_اتصال("server.com"، 80))
الحالة = انتقال(الحالة، نجح_الاتصال)
الحالة = انتقال(الحالة، طلب_قطع)
الحالة = انتقال(الحالة، اكتمل_القطع)

# سيناريو فشل الاتصال
الحالة = انتقال(الحالة، طلب_اتصال("server.com"، 80))
الحالة = انتقال(الحالة، فشل_الاتصال("Connection timeout"))
الحالة = انتقال(الحالة، طلب_اتصال("server.com"، 80))

# دالة للحصول على وصف الحالة
دالة وصف_الحالة(الحالة: حالة_الاتصال) -> نص 
    طابق الحالة 
        منفصل => ارجع "غير متصل"
        جاري_الاتصال => ارجع "جاري الاتصال..."
        متصل(ع، م) => ارجع "متصل بـ " + ع + ":" + م
        فشل_الاتصال(س) => ارجع "فشل: " + س
        جاري_القطع => ارجع "جاري القطع..."
    نهاية
نهاية

اطبع(وصف_الحالة(الحالة))
```

**الفوائد:**
- ✅ انتقالات الحالة واضحة ومعبّرة
- ✅ سهولة إضافة حالات وأحداث جديدة
- ✅ المترجم يتحقق من تغطية جميع الحالات
- ✅ استخراج بيانات من الحالات تلقائياً

## 📖 مصطلحات ذات صلة

### Destructuring (التفكيك)
استخراج قيم من هياكل معقدة:
```sad
متغير (س، ص) = النقطة  # تفكيك tuple
متغير [أول، ..الباقي] = القائمة  # تفكيك array
```

### Guard Clause (جملة الحارس)
شرط إضافي في Pattern:
```sad
طابق العمر 
    س إذا (س >= 18) => "بالغ"
    _ => "قاصر"
نهاية
```

### Exhaustiveness (الشمولية)
التأكد من معالجة جميع الحالات الممكنة.

### Refutability (القابلية للدحض)
Pattern قد يفشل في المطابقة (مثل `Some(x)`) vs irrefutable pattern يطابق دائماً (مثل `x`).

### Binding (الربط)
ربط قيمة بمتغير أثناء المطابقة:
```sad
طابق القيمة 
    Some(x) => x  # x مربوط بالقيمة الداخلية
نهاية
```

## 🎯 الخلاصة

مطابقة الأنماط (مطابقة الانماط) هي أداة قوية تسمح بـ:
- ✅ **تفكيك البيانات**: استخراج قيم من هياكل معقدة
- ✅ **فحص وشرط معاً**: مطابقة وتحقق في خطوة واحدة
- ✅ **أمان**: Exhaustiveness checking تلقائي
