# 📖 استيعاب القواميس (Dictionary Comprehension)

## مقدمة

استيعاب القواميس هو أسلوب قوي لإنشاء قواميس (dictionaries) جديدة بطريقة مختصرة وأنيقة. مثل استيعاب القوائم، يتيح لك إنشاء قواميس كاملة في سطر واحد، مما يجعل الكود أكثر قراءة وكفاءة.

## الفرق عن استيعاب القوائم

استيعاب القوائم ينتج قائمة، بينما استيعاب القواميس ينتج قاموساً من أزواج مفتاح-قيمة:

```s
دالة رئيسية()
    # استيعاب قائمة - ينتج قائمة
    قائمة مربعات = [ن * ن لكل ن في مدى(1، 6)]
    اطبع(مربعات)  # [1، 4، 9، 16، 25]
    
    # استيعاب قاموس - ينتج قاموساً
    قاموس مربعات_قاموس = {ن: ن * ن لكل ن في مدى(1، 6)}
    اطبع(مربعات_قاموس)  # {1: 1، 2: 4، 3: 9، 4: 16، 5: 25}
نهاية
```

## الصيغة الأساسية

```s
{مفتاح: قيمة لكل متغير في مصدر}
```

حيث:
- **مفتاح**: التعبير الذي يُنتج المفتاح
- **قيمة**: التعبير الذي يُنتج القيمة
- **متغير**: متغير التكرار
- **مصدر**: ما نتكرر عليه

## أمثلة أساسية

### من قائمة إلى قاموس

```s
دالة رئيسية()
    قائمة أسماء = ["أحمد"، "محمد"، "سارة"، "فاطمة"]
    
    # قاموس بأطوال الأسماء
    قاموس أطوال = {اسم: طول(اسم) لكل اسم في أسماء}
    اطبع(أطوال)  # {"أحمد": 4، "محمد": 4، "سارة": 4، "فاطمة": 5}
    
    # قاموس بالحرف الأول
    قاموس أوائل = {اسم: اسم[0] لكل اسم في أسماء}
    اطبع(أوائل)  # {"أحمد": "أ"، "محمد": "م"، ...}
نهاية
```

### من مدى إلى قاموس

```s
دالة رئيسية()
    # قاموس الأرقام ومربعاتها
    قاموس مربعات = {ن: ن ** 2 لكل ن في مدى(1، 11)}
    اطبع(مربعات)
    # {1: 1، 2: 4، 3: 9، 4: 16، 5: 25، 6: 36، 7: 49، 8: 64، 9: 81، 10: 100}
    
    # قاموس الأرقام وجذورها التربيعية
    قاموس جذور = {ن: جذر(ن) لكل ن في [1، 4، 9، 16، 25، 36]}
    اطبع(جذور)
    # {1: 1.0، 4: 2.0، 9: 3.0، 16: 4.0، 25: 5.0، 36: 6.0}
نهاية
```

### تبديل المفاتيح والقيم

```s
دالة رئيسية()
    قاموس أصلي = {"أ": 1، "ب": 2، "ج": 3، "د": 4}
    
    # تبديل المفاتيح مع القيم
    قاموس معكوس = {قيمة: مفتاح لكل مفتاح، قيمة في أصلي.عناصر()}
    اطبع(معكوس)  # {1: "أ"، 2: "ب"، 3: "ج"، 4: "د"}
نهاية
```

## الاستيعاب مع الشرط

### الصيغة مع شرط

```s
{مفتاح: قيمة لكل متغير في مصدر إذا شرط}
```

### أمثلة مع الشرط

```s
دالة رئيسية()
    # فقط الأرقام الزوجية ومربعاتها
    قاموس زوجية = {ن: ن ** 2 لكل ن في مدى(1، 11) إذا ن % 2 == 0}
    اطبع(زوجية)  # {2: 4، 4: 16، 6: 36، 8: 64، 10: 100}
    
    # فقط الأرقام القابلة للقسمة على 3
    قاموس قابلة = {ن: ن * 10 لكل ن في مدى(1، 21) إذا ن % 3 == 0}
    اطبع(قابلة)
نهاية
```

### تصفية قاموس موجود

```s
دالة رئيسية()
    قاموس درجات = {
        "أحمد": 85،
        "محمد": 72،
        "سارة": 95،
        "فاطمة": 68،
        "علي": 90،
        "خديجة": 78
    }
    
    # الطلاب الناجحون (70 فأكثر)
    قاموس ناجحون = {اسم: درجة لكل اسم، درجة في درجات.عناصر() إذا درجة >= 70}
    اطبع(ناجحون)
    # {"أحمد": 85، "محمد": 72، "سارة": 95، "علي": 90، "خديجة": 78}
    
    # الطلاب المتفوقون (90 فأكثر)
    قاموس متفوقون = {اسم: درجة لكل اسم، درجة في درجات.عناصر() إذا درجة >= 90}
    اطبع(متفوقون)  # {"سارة": 95، "علي": 90}
نهاية
```

## التعامل مع قائمتين

### باستخدام zip

```s
دالة رئيسية()
    قائمة مفاتيح = ["اسم"، "عمر"، "مدينة"، "مهنة"]
    قائمة قيم = ["أحمد"، 25، "الرياض"، "مبرمج"]
    
    # دمج القائمتين في قاموس
    قاموس شخص = {م: ق لكل م، ق في ضم(مفاتيح، قيم)}
    اطبع(شخص)
    # {"اسم": "أحمد"، "عمر": 25، "مدينة": "الرياض"، "مهنة": "مبرمج"}
نهاية
```

### باستخدام الفهرس

```s
دالة رئيسية()
    قائمة أيام = ["الأحد"، "الاثنين"، "الثلاثاء"، "الأربعاء"، "الخميس"، "الجمعة"، "السبت"]

    # {"الأحد": 0، "الاثنين": 1، "الثلاثاء": 2، ...}
    
    # العكس: من الرقم لليوم
```

## تحويلات القواميس

### تحويل القيم

```s
دالة رئيسية()
    قاموس أسعار = {
        "تفاح": 5.0،
        "برتقال": 3.5،
        "موز": 2.0،
        "عنب": 8.0
    }
    
    # زيادة الأسعار 10%
    قاموس أسعار_جديدة = {فاكهة: سعر * 1.1 لكل فاكهة، سعر في أسعار.عناصر()}
    اطبع(أسعار_جديدة)
    
    # تقريب الأسعار
    قاموس مقربة = {فاكهة: قرب(سعر، 2) لكل فاكهة، سعر في أسعار_جديدة.عناصر()}
    اطبع(مقربة)
نهاية
```

### تحويل المفاتيح

```s
دالة رئيسية()

    # تحويل المفاتيح للعربية

    قاموس بيانات_عربية = {ترجمة[م]: ق لكل م، ق في بيانات.عناصر()}
    اطبع(بيانات_عربية)
    # {"الاسم": "أحمد"، "العمر": 25، "المدينة": "الرياض"}
نهاية
```

## تجميع البيانات

### تجميع حسب خاصية

```s
دالة رئيسية()
    قائمة طلاب = [
        {"اسم": "أحمد"، "صف": "أول"، "درجة": 85}،
        {"اسم": "محمد"، "صف": "ثاني"، "درجة": 90}،
        {"اسم": "سارة"، "صف": "أول"، "درجة": 95}،
        {"اسم": "فاطمة"، "صف": "ثاني"، "درجة": 88}،
        {"اسم": "علي"، "صف": "أول"، "درجة": 78}
    ]
    
    # تجميع الدرجات حسب الصف
    قاموس حسب_الصف = {}
    لكل طالب في طلاب
        نص صف = طالب.صف
        إذا (صف ليس_في حسب_الصف)
            حسب_الصف[صف] = []
        نهاية
        حسب_الصف[صف].أضف(طالب.درجة)
    نهاية
    
    # حساب المتوسط لكل صف
    قاموس متوسطات = {صف: مجموع(درجات) / طول(درجات) لكل صف، درجات في حسب_الصف.عناصر()}
    اطبع(متوسطات)  # {"أول": 86.0، "ثاني": 89.0}
نهاية
```

### عد التكرارات

```s
دالة رئيسية()
```

## استيعاب متداخل

### قاموس من قواميس

```s
دالة رئيسية()
    قائمة طلاب = ["أحمد"، "محمد"، "سارة"]
    قائمة مواد = ["رياضيات"، "علوم"، "لغة"]
    
    # إنشاء هيكل لدرجات كل طالب في كل مادة
    قاموس درجات = {
        طالب: {مادة: 0 لكل مادة في مواد}
        لكل طالب في طلاب
    }
    اطبع(درجات)
    # {
    #     "أحمد": {"رياضيات": 0، "علوم": 0، "لغة": 0}،
    #     "محمد": {"رياضيات": 0، "علوم": 0، "لغة": 0}،
    #     "سارة": {"رياضيات": 0، "علوم": 0، "لغة": 0}
    # }
نهاية
```

### تسطيح قاموس متداخل

```s
دالة رئيسية()
    قاموس متداخل = {
        "قسم1": {"أحمد": 85، "محمد": 90}،
        "قسم2": {"سارة": 95، "فاطمة": 88}
    }
    
    # تسطيح إلى قاموس واحد
    قاموس مسطح = {
        اسم: درجة
        لكل قسم، طلاب في متداخل.عناصر()
        لكل اسم، درجة في طلاب.عناصر()
    }
    اطبع(مسطح)  # {"أحمد": 85، "محمد": 90، "سارة": 95، "فاطمة": 88}
نهاية
```

## تطبيقات عملية

```s
دالة رئيسية()

        {"id": 1، "name": "قميص"، "price": 50، "in_stock": صحيح}،
        {"id": 2، "name": "بنطال"، "price": 80، "in_stock": خطأ}،
```

```s
دالة رئيسية()
```

```s
    }
    اطبع(تصنيف)
```

## نصائح وأفضل الممارسات

### 1. تجنب المفاتيح المكررة

```s
دالة رئيسية()
    قائمة بيانات = [("أ"، 1)، ("ب"، 2)، ("أ"، 3)]
    
    # تحذير: المفتاح "أ" مكرر، القيمة الأخيرة ستُستخدم
    قاموس نتيجة = {م: ق لكل م، ق في بيانات}
    اطبع(نتيجة)  # {"أ": 3، "ب": 2}
نهاية
```

### 2. استخدم أسماء واضحة

```s
# غير واضح ❌
قاموس ن = {س: ص لكل س، ص في ب.عناصر() إذا ص > 0}

# واضح ✅
قاموس منتجات_متوفرة = {
    اسم: كمية
    لكل اسم، كمية في المخزون.عناصر()
    إذا كمية > 0
}
```

### 3. قسم التعبيرات المعقدة

```s
# معقد ❌
قاموس ن = {حول_المفتاح(م): حول_القيمة(ق) لكل م، ق في بيانات.عناصر() إذا تحقق(م) وَ تحقق2(ق)}

# أوضح ✅
دالة يجب_تضمينه(مفتاح، قيمة)
    إرجاع تحقق(مفتاح) وَ تحقق2(قيمة)
نهاية

قاموس نتيجة = {
    حول_المفتاح(م): حول_القيمة(ق)
    لكل م، ق في بيانات.عناصر()
    إذا يجب_تضمينه(م، ق)
}
```

## الخلاصة

استيعاب القواميس في لغة ص:
- صيغة مختصرة لإنشاء قواميس
- يدعم الشروط والتحويلات
- مفيد لتحويل البيانات وتصفيتها
- يمكن أن يكون متداخلاً
- احذر من المفاتيح المكررة
- حافظ على وضوح الكود
