# 🏠 مديرو السياق - مقدمة شاملة

## ما هو مدير السياق؟

مدير السياق (Context Manager) هو نمط برمجي قوي في لغة ص يُستخدم لإدارة الموارد بشكل آمن وموثوق. الفكرة الأساسية بسيطة: عندما تفتح مورداً (مثل ملف أو اتصال قاعدة بيانات)، تحتاج للتأكد من إغلاقه بشكل صحيح عند الانتهاء، حتى لو حدث خطأ أثناء الاستخدام.

تخيل أنك تستعير كتاباً من المكتبة - يجب أن تُعيده عند الانتهاء منه. مدير السياق يضمن "إعادة الكتاب" تلقائياً، بغض النظر عما يحدث أثناء قراءتك له.

## لماذا نحتاج مديري السياق؟

### المشكلة التقليدية

```s
# ❌ طريقة غير آمنة
دالة قراءة_ملف_غير_آمنة(نص المسار)
    متغير ملف = افتح(المسار، "قراءة")
    نص المحتوى = ملف.اقرأ()
    # ماذا لو حدث خطأ هنا؟ الملف لن يُغلق!
    اغلق(ملف)
    إرجاع المحتوى
نهاية
```

إذا حدث خطأ قبل استدعاء `اغلق(ملف)`، سيظل الملف مفتوحاً، مما قد يسبب:
- تسرب الموارد (Resource Leak)
- عدم حفظ البيانات
- منع عمليات أخرى من الوصول للملف
- استهلاك موارد النظام

### الحل باستخدام try/finally

```s
# أفضل، لكن الكود طويل ومتكرر
دالة قراءة_ملف_آمنة(نص المسار)
    متغير ملف = افتح(المسار، "قراءة")
    حاول
        نص المحتوى = ملف.اقرأ()
        إرجاع المحتوى
    أخيراً
        اغلق(ملف)
    نهاية
نهاية
```

### الحل الأمثل: مدير السياق

```s
# ✅ أنيق وآمن
دالة قراءة_ملف_مثالية(نص المسار)
    باستخدام افتح(المسار، "قراءة") كـ ملف
        إرجاع ملف.اقرأ()
    نهاية_استخدام
نهاية
```

## الصيغة الأساسية

```s
باستخدام تعبير_المورد كـ اسم_المتغير
    # الكود الذي يستخدم المورد
    # ...
نهاية_استخدام
```

### شرح الأجزاء:

| الجزء | الوصف |
|-------|-------|
| `باستخدام` | كلمة مفتاحية تبدأ كتلة مدير السياق |
| `تعبير_المورد` | التعبير الذي يُنتج المورد |
| `كـ` | كلمة مفتاحية للربط (اختيارية) |
| `اسم_المتغير` | اسم المتغير الذي سيحتوي على المورد |
| `نهاية_استخدام` | كلمة مفتاحية تُنهي الكتلة |

## أمثلة أساسية

### 1. التعامل مع الملفات

```s
دالة رئيسية()
    # قراءة ملف
    باستخدام افتح("بيانات.txt"، "قراءة") كـ ملف_قراءة
        نص محتوى = ملف_قراءة.اقرأ()
        اطبع("المحتوى: " + محتوى)
    نهاية_استخدام
    # الملف يُغلق تلقائياً هنا
    
    # كتابة ملف
    باستخدام افتح("نتائج.txt"، "كتابة") كـ ملف_كتابة
        ملف_كتابة.اكتب("مرحباً بالعالم!")
        ملف_كتابة.اكتب_سطر("سطر جديد")
    نهاية_استخدام
    # الملف يُغلق ويُحفظ تلقائياً
نهاية
```

### 2. بدون اسم مستعار

إذا لم تحتج لاستخدام المورد مباشرة، يمكنك حذف جزء `كـ`:

```s
دالة رئيسية()
    # مفيد للعمليات التي تُنفذ عند الدخول/الخروج فقط
    باستخدام قفل_المزامنة()
        # الكود المحمي هنا
        عملية_حساسة()
    نهاية_استخدام
    # القفل يُحرر تلقائياً
نهاية
```

### 3. مديرو سياق متداخلون

```s
دالة نسخ_ملف(نص المصدر، نص الهدف)
    باستخدام افتح(المصدر، "قراءة") كـ ملف_المصدر
        باستخدام افتح(الهدف، "كتابة") كـ ملف_الهدف
            نص المحتوى = ملف_المصدر.اقرأ()
            ملف_الهدف.اكتب(المحتوى)
        نهاية_استخدام
    نهاية_استخدام
    
    اطبع("تم نسخ الملف بنجاح")
نهاية
```

## فوائد استخدام مديري السياق

### 1. ضمان تنظيف الموارد

```s
دالة رئيسية()
    باستخدام اتصال_قاعدة_البيانات("localhost"، "قاعدتي") كـ قب
        # حتى لو حدث خطأ هنا
        متغير نتائج = قب.نفذ("SELECT * FROM جدول_غير_موجود")
        # الاتصال سيُغلق تلقائياً
    نهاية_استخدام
نهاية
```

### 2. كود أكثر نظافة وقراءة

```s
# ❌ بدون مدير سياق
دالة معالجة_v1()
    متغير مورد1 = احصل_على_مورد1()
    حاول
        متغير مورد2 = احصل_على_مورد2()
        حاول
            معالجة(مورد1، مورد2)
        أخيراً
            حرر(مورد2)
        نهاية
    أخيراً
        حرر(مورد1)
    نهاية
نهاية

# ✅ مع مدير السياق
دالة معالجة_v2()
    باستخدام احصل_على_مورد1() كـ مورد1
        باستخدام احصل_على_مورد2() كـ مورد2
            معالجة(مورد1، مورد2)
        نهاية_استخدام
    نهاية_استخدام
نهاية
```

### 3. تجنب الأخطاء الشائعة

```s
# الأخطاء التي تتجنبها مع مديري السياق:
# - نسيان إغلاق الملفات
# - نسيان تحرير الأقفال
# - نسيان إغلاق اتصالات الشبكة
# - نسيان إلغاء المعاملات
# - تسرب الذاكرة
```

## كيف يعمل مدير السياق؟

عندما تستخدم `باستخدام`، يحدث ما يلي:

1. **الدخول**: يُقيّم تعبير المورد ويُخزن في المتغير
2. **التنفيذ**: يُنفذ الكود داخل الكتلة
3. **الخروج**: يُنفذ كود التنظيف تلقائياً

```s
# ما يحدث خلف الكواليس:
# 
# باستخدام مورد كـ م
#     استخدم(م)
# نهاية_استخدام
#
# يُترجم تقريباً إلى:
#
# متغير م = مورد
# حاول
#     # إذا كان المورد يدعم __دخول__، استدعِه
#     استخدم(م)
# أخيراً
#     # إذا كان المورد يدعم __خروج__، استدعِه
# نهاية
```

## النطاق والحياة

المتغير المُعرّف في `كـ` متاح فقط داخل كتلة `باستخدام`:

```s
دالة رئيسية()
    باستخدام افتح("ملف.txt") كـ ملف
        # ملف متاح هنا
        اطبع(ملف.اقرأ())
    نهاية_استخدام
    
    # ملف غير متاح هنا (خارج النطاق)
    # اطبع(ملف)  # ❌ خطأ
نهاية
```

## حالات الاستخدام الشائعة

| الحالة | الوصف |
|--------|-------|
| الملفات | فتح، قراءة/كتابة، إغلاق |
| قواعد البيانات | اتصال، استعلام، إغلاق |
| الشبكات | اتصال، إرسال/استقبال، إغلاق |
| الأقفال | اكتساب، عمليات حرجة، تحرير |
| المعاملات | بدء، عمليات، التزام/تراجع |
| التوقيت | بدء القياس، كود، إنهاء القياس |

## الخلاصة

مدير السياق هو نمط أساسي في البرمجة الحديثة يضمن:
- إدارة الموارد بشكل آمن
- كود أنظف وأقصر
- تجنب الأخطاء الشائعة
- معالجة الاستثناءات بشكل صحيح

في الدروس القادمة، سنتعلم كيفية إنشاء مديري سياق مخصصين وأنماط استخدام متقدمة.
