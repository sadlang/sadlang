# النصوص الخام في لغة ص
# Raw Strings in S Language

**الموضوع:** حل مشكلة الشرطة المائلة العكسية  
**المستوى:** مبتدئ  
**الاستخدامات:** مسارات Windows، تعبيرات نمطية

---

## المشكلة: الشرطة المائلة العكسية المزعجة

عند كتابة مسارات الملفات في Windows أو كتابة تعبيرات نمطية (Regex) معقدة، تواجه مشكلة محرجة: الشرطة المائلة العكسية `\` لها معنى خاص في النصوص البرمجية. عندما تكتب `"\n"` فإن البرنامج يفهمها كسطر جديد وليس كحرف الشرطة متبوعاً بحرف n.

لكتابة مسار Windows مثل `C:\Users\Ahmad`، عليك مضاعفة كل شرطة:

```s
# طريقة خاطئة (لن تعمل!)
نص مسار_خاطئ = "C:\Users\Ahmad"  # ✗ \U و \A غير معروفة!

# الطريقة الصحيحة التقليدية (مزعجة!)
نص مسار_صحيح = "C:\\Users\\Ahmad"  # ✓ لكن طويل ومربك!
```

## الحل: النصوص الخام (Raw Strings)

النصوص الخام تحل هذه المشكلة تماماً. عندما تضع `r` قبل النص، كل شيء داخله يُعامل حرفياً بدون أي معالجة خاصة:

### الطريقة الإنجليزية: `r"..."`

```s
# مسارات Windows بدون مضاعفة
نص مسار1 = r"C:\Users\Ahmad\Documents"
نص مسار2 = r"D:\Projects\MyApp\src"
نص مسار3 = r"\\Server\Share\Folder"

# تعبيرات نمطية واضحة
نص regex_رقم = r"\d+"           # أي أرقام
نص regex_بريد = r"\w+@\w+\.\w+"  # بريد إلكتروني بسيط
نص regex_معقد = r"^\s*[\w.]+\s*$"

اطبع("المسار:", مسار1)
اطبع("Regex:", regex_رقم)
```

### الطريقة العربية: `ح"..."`

البادئة العربية `ح` (من "حرفي") تعمل بنفس الطريقة:

```s
# نفس الأمثلة بالبادئة العربية
نص مسار_عربي = ح"C:\Users\Ahmad\Documents"
نص regex_عربي = ح"\d+\s*\w+"

اطبع("مسار عربي:", مسار_عربي)
```

## أمثلة عملية

### استخدام 1: مسارات الملفات

```s
# تكوين التطبيق
نص مسار_قاعدة_البيانات = r"C:\ProgramData\MyApp\database.db"
نص مسار_السجلات = r"C:\ProgramData\MyApp\logs\"
نص مسار_التكوين = r"C:\Users\Public\config.ini"

# مشاركات الشبكة
نص مشاركة_الملفات = r"\\Server01\SharedDocs\Reports"
نص مشاركة_النسخ = r"\\Backup\DailyBackups\"

اطبع("قاعدة البيانات في:", مسار_قاعدة_البيانات)
```

### استخدام 2: تعبيرات نمطية

```s
# أنماط شائعة
نص نمط_رقم_هاتف = r"\+966\s?\d{9}"
نص نمط_رقم_وطني = r"\d{10}"
نص نمط_تاريخ = r"\d{4}-\d{2}-\d{2}"
نص نمط_وقت = r"\d{2}:\d{2}:\d{2}"

# نمط معقد لعنوان URL
نص نمط_URL = r"https?://[\w.-]+\.\w{2,}(/[\w.-]*)*"

اطبع("نمط التاريخ:", نمط_تاريخ)
```

### استخدام 3: SQL و JSON

```s
# استعلام SQL متعدد الأسطر (بدون مشاكل مع الشرطة)
نص استعلام = r"SELECT * FROM users WHERE name LIKE '%\%%'"

# مسار JSON مع شرطات
نص مسار_JSON = r"data\users\profiles\user123.json"
```

## متى تستخدم النصوص الخام؟

✅ **استخدمها عندما:**
- تكتب مسارات ملفات Windows
- تكتب تعبيرات نمطية (Regex)
- تحتاج شرطات مائلة عكسية كثيرة
- تريد أن يكون النص بالضبط كما تكتبه

❌ **لا تستخدمها عندما:**
- تحتاج تسلسلات هروب (`\n`, `\t`, إلخ)
- تريد سطوراً جديدة أو تابات
- النص عادي بدون شرطات
