## مقدمة: لماذا أنظمة أرقام متعددة؟

عندما نتحدث في حياتنا اليومية عن الأرقام، نستخدم النظام العشري (Decimal) دون أن نفكر فيه. هذا النظام يستخدم عشرة أرقام (0-9) وكل خانة تمثل قوة من قوى العشرة. الرقم 123 يعني `1×100 + 2×10 + 3×1`. هذا النظام طبيعي بالنسبة لنا لأننا نملك عشرة أصابع، لكن الحاسوب "يفكر" بطريقة مختلفة تماماً.

الحاسوب في جوهره لا يفهم إلا حالتين: تيار كهربائي موجود (1) أو غير موجود (0). لذلك، النظام الطبيعي للحاسوب هو النظام الثنائي الذي يستخدم فقط رقمين: 0 و 1. كل بت (Bit) في ذاكرة الحاسوب هو إما صفر أو واحد. لكن التعامل المباشر مع النظام الثنائي صعب على البشر لأن الأرقام تصبح طويلة جداً بسرعة. الرقم 255 بالنظام العشري يصبح 11111111 بالنظام الثنائي!

لحل هذه المشكلة، يستخدم المبرمجون أنظمة وسيطة أكثر إحكاماً: النظام الثماني (يستخدم 8 أرقام: 0-7) والنظام الست عشري (يستخدم 16 رمزاً: 0-9 و A-F). هذه الأنظمة تسمح بتمثيل الأرقام الثنائية الطويلة بطريقة أقصر وأسهل قراءة، مع الحفاظ على العلاقة المباشرة مع كيفية تخزين البيانات فعلياً في الذاكرة.

لغة ص تدعم جميع هذه الأنظمة بطريقة سهلة ومرنة، مع إضافة لمسة فريدة: بادئات عربية بجانب البادئات الإنجليزية التقليدية. هذا يعني أنك كمبرمج عربي يمكنك كتابة كود أكثر قرباً للغتك الأم، مما يسهل القراءة والفهم، خاصة عند مراجعة الكود بعد فترة طويلة.

## النظام الثنائي (Binary) - لغة الآلة

النظام الثنائي هو أبسط نظام عددي وأكثرها أساسية في الحوسبة. كل رقم يتكون من سلسلة من الأصفار والآحاد، وكل خانة تمثل قوة من قوى الاثنين. الرقم `1010` بالنظام الثنائي يعني `1×8 + 0×4 + 1×2 + 0×1 = 10` بالنظام العشري.

### متى تستخدم الأرقام الثنائية؟

الأرقام الثنائية ليست مجرد تمرين نظري، بل لها استخدامات عملية كثيرة في البرمجة الحقيقية:

**الأعلام والخيارات (Flags):** في كثير من الأحيان، تحتاج لتخزين عدة خيارات منطقية (نعم/لا) في متغير واحد. كل بت يمثل خياراً مختلفاً. مثلاً، في برنامج معالجة نصوص، قد تحتاج لتخزين صفات النص: هل هو غامق؟ مائل؟ تحته خط؟ بدلاً من استخدام ثلاثة متغيرات منفصلة، يمكنك استخدام رقم واحد بثلاثة بتات.

**عمليات البتات (Bitwise Operations):** عند التعامل مع الأجهزة مباشرة أو كتابة برامج نظم، تحتاج غالباً لقراءة أو تعديل بتات معينة في رقم. الأرقام الثنائية تجعل هذا واضحاً جداً. إذا أردت تفعيل البت الثالث، يمكنك كتابة `0b0100` بدلاً من محاولة حساب `4` بالنظام العشري.

**الأقنعة (Masks):** في البرمجة الشبكية والرسوميات، تستخدم الأقنعة بكثرة. قناع الشبكة `255.255.255.0` غالباً ما تُكتب بالثنائي لفهم البتات المفعلة: `11111111.11111111.11111111.00000000`.

### كيف تكتب الأرقام الثنائية في لغة ص؟

لغة ص توفر طريقتين لكتابة الأرقام الثنائية، حسب تفضيلك:

**الطريقة الإنجليزية:** تبدأ بالبادئة `0b` (من Binary) متبوعة بالأرقام الثنائية (0 و 1 فقط):

```s
# أمثلة بسيطة
رقم واحد = 0b1           # يساوي 1
رقم اثنان = 0b10          # يساوي 2
رقم عشرة = 0b1010         # يساوي 10
رقم مئة = 0b1100100        # يساوي 100
```

**الطريقة العربية:** تبدأ بالبادئة `0ثن` (من ثنائي) متبوعة بنفس الأرقام:

```s
# نفس الأمثلة بالعربي
رقم واحد_عربي = 0ثن1     # يساوي 1
رقم اثنان_عربي = 0ثن10    # يساوي 2
رقم عشرة_عربي = 0ثن1010   # يساوي 10
رقم مئة_عربي = 0ثن1100100  # يساوي 100
```

لاحظ أن القيمة الناتجة هي نفسها تماماً في الحالتين. الفرق فقط في البادئة التي تختار استخدامها. بعض المبرمجين يفضلون الالتزام ببادئة واحدة في كل المشروع لتوحيد الأسلوب، بينما يفضل آخرون استخدام البادئة العربية في الأجزاء التي تحتوي على تعليقات ومتغيرات عربية، والبادئة الإنجليزية في الأجزاء التقنية البحتة.

### أمثلة عملية على استخدام الأرقام الثنائية

لنرى كيف تُستخدم الأرقام الثنائية في برامج حقيقية:

```s
# مثال 1: إدارة صلاحيات المستخدم
# كل بت يمثل صلاحية معينة
رقم قراءة = 0b001        # الصلاحية للقراءة فقط
رقم كتابة = 0b010        # الصلاحية للكتابة فقط
رقم تنفيذ = 0b100        # الصلاحية للتنفيذ فقط

# مستخدم لديه صلاحية القراءة والكتابة
رقم صلاحيات_المستخدم = 0b011  # قراءة (001) + كتابة (010)

# التحقق من صلاحية معينة (سيتم شرح العمليات البتية لاحقاً)
اطبع("هل يستطيع القراءة؟")
اطبع(صلاحيات_المستخدم)

# مثال 2: حالة اللعبة
# استخدام البتات لتخزين حالات متعددة في رقم واحد
رقم اللاعب_حي = 0b00001       # البت الأول: هل اللاعب حي؟
رقم اللاعب_مسلح = 0b00010     # البت الثاني: هل اللاعب مسلح؟
رقم اللاعب_محمي = 0b00100     # البت الثالث: هل لديه درع؟
رقم اللاعب_مصاب = 0b01000     # البت الرابع: هل مصاب؟
رقم اللاعب_متخفي = 0b10000    # البت الخامس: هل متخفي؟

# لاعب حي، مسلح، ومحمي
رقم حالة_اللاعب = 0b00111  # الثلاثة بتات الأولى مفعلة
اطبع("حالة اللاعب:", حالة_اللاعب)

# مثال 3: أعلام التكوين
# في برنامج يقرأ ملف تكوين
رقم تفعيل_السجلات = 0ثن1           # البت الأول
رقم وضع_التطوير = 0ثن10             # البت الثاني
رقم الضغط_المفعل = 0ثن100           # البت الثالث
رقم التشفير_المفعل = 0ثن1000        # البت الرابع

# التكوين: السجلات مفعلة، وضع التطوير مفعل
رقم التكوين = 0ثن11  # أول بتين مفعلان
اطبع("التكوين الحالي:", التكوين)
```

هذه الأمثلة توضح القوة الحقيقية للأرقام الثنائية: القدرة على تخزين معلومات منطقية متعددة في رقم واحد صغير بطريقة فعالة جداً من حيث الذاكرة والأداء.

### قواعد مهمة عند استخدام الأرقام الثنائية

عند كتابة أرقام ثنائية، هناك بعض القواعد التي يجب أن تعرفها:

**الأرقام المسموحة:** يمكنك فقط استخدام `0` و `1` بعد البادئة. أي رقم آخر سيسبب خطأ:

```s
رقم صحيح = 0b1010      # ✓ صحيح
رقم خاطئ = 0b1012      # ✗ خطأ! 2 ليس رقماً ثنائياً
```

**البادئة إلزامية:** لا يمكنك كتابة الصفر والواحد مباشرة وتتوقع أن تُفسر كأرقام ثنائية:

```s
رقم عشري = 1010        # هذا 1010 بالنظام العشري، ليس 10 بالثنائي!
رقم ثنائي = 0b1010     # ✓ هذا 10 بالنظام العشري
```

**الأصفار البادئة مسموحة:** يمكنك إضافة أصفار في البداية لتحسين قابلية القراءة:

```s
رقم مع_أصفار = 0b00001010   # نفس 0b1010 تماماً
رقم بايت = 0b00000001        # واحد على شكل بايت كامل (8 بتات)
```

## النظام الثماني (Octal) - النظام التاريخي

النظام الثماني يستخدم ثمانية أرقام: 0، 1، 2، 3، 4، 5، 6، 7. كل خانة تمثل قوة من قوى الثمانية. الرقم `755` بالنظام الثماني يعني `7×64 + 5×8 + 5×1 = 493` بالنظام العشري.

### تاريخ النظام الثماني وأهميته

النظام الثماني كان شائعاً جداً في الأيام الأولى للحوسبة، خاصة في أنظمة Unix القديمة. السبب هو أن ثلاثة بتات ثنائية يمكن تمثيلها بخانة ثمانية واحدة بدقة: `000` إلى `111` بالثنائي تساوي `0` إلى `7` بالثماني. هذا جعل النظام الثماني طريقة مختصرة ومريحة لكتابة الأرقام الثنائية الطويلة قبل أن يصبح النظام الست عشري هو المعيار.

رغم أن النظام الثماني أصبح أقل شيوعاً اليوم، إلا أنه لا يزال مستخدماً في سياقات محددة، أهمها **صلاحيات الملفات في Unix/Linux**. عندما ترى أمراً مثل `chmod 755`، فإن `755` هو رقم ثماني يحدد صلاحيات القراءة والكتابة والتنفيذ للمالك والمجموعة والآخرين.

### كيف تكتب الأرقام الثمانية في لغة ص؟

مثل الأرقام الثنائية، لديك خياران:

**الطريقة الإنجليزية:** البادئة `0o` (من Octal) متبوعة بالأرقام من 0 إلى 7:

```s
# أمثلة أساسية
رقم سبعة = 0o7          # يساوي 7
رقم ثمانية = 0o10        # يساوي 8 (1×8 + 0×1)
رقم ستة_عشر = 0o20       # يساوي 16 (2×8 + 0×1)
رقم خمسمائة = 0o764      # يساوي 500
```

**الطريقة العربية:** البادئة `0ع` (من عشري/ثماني) متبوعة بنفس الأرقام:

```s
# نفس الأمثلة بالعربي
رقم سبعة_عربي = 0ع7      # يساوي 7
رقم ثمانية_عربي = 0ع10    # يساوي 8
رقم ستة_عشر_عربي = 0ع20   # يساوي 16
رقم خمسمائة_عربي = 0ع764  # يساوي 500
```

### الاستخدام الأكثر شيوعاً: صلاحيات Unix

المثال الأكثر شهرة وشيوعاً لاستخدام الأرقام الثمانية هو تحديد صلاحيات الملفات:

```s
# صلاحيات الملفات في نمط Unix
# كل رقم ثماني يمثل صلاحيات لمجموعة معينة

# 7 = قراءة (4) + كتابة (2) + تنفيذ (1)
# 5 = قراءة (4) + تنفيذ (1)
# 4 = قراءة (4) فقط

رقم صلاحية_كاملة = 0o777       # الكل يستطيع كل شيء
رقم صلاحية_قياسية = 0o755       # المالك كل شيء، الآخرون قراءة وتنفيذ
رقم صلاحية_خاصة = 0o700         # المالك فقط كل شيء
رقم صلاحية_قراءة = 0o444        # الكل قراءة فقط
رقم صلاحية_ملف_نصي = 0o644     # المالك قراءة وكتابة، الآخرون قراءة

اطبع("صلاحية قياسية (755):", صلاحية_قياسية)
اطبع("صلاحية خاصة (700):", صلاحية_خاصة)

# بالبادئة العربية
رقم صلاحية_عربية = 0ع755
اطبع("صلاحية بالعربي:", صلاحية_عربية)
```

هذا المثال يوضح لماذا النظام الثماني مفيد: الرقم `755` واضح ومختصر، وكل خانة لها معنى محدد. فك تشفير هذا الرقم بسيط: 7 للمالك (4+2+1 = قراءة+كتابة+تنفيذ)، 5 للمجموعة (4+1 = قراءة+تنفيذ)، 5 للآخرين (4+1 = قراءة+تنفيذ).

### قواعد الأرقام الثمانية

**الأرقام المسموحة:** من `0` إلى `7` فقط. الرقمان 8 و 9 غير موجودين في النظام الثماني:

```s
رقم صحيح = 0o754      # ✓ صحيح
رقم خاطئ = 0o758      # ✗ خطأ! 8 ليس رقماً ثمانياً
```

**التحويل السريع:** كل ثلاثة بتات ثنائية = خانة ثمانية واحدة:
- `000` = 0
- `001` = 1
- `010` = 2
- `011` = 3
- `100` = 4
- `101` = 5
- `110` = 6
- `111` = 7

## النظام الست عشري (Hexadecimal) - المعيار الحديث

النظام الست عشري هو الأكثر استخداماً في البرمجة الحديثة. يستخدم 16 رمزاً: الأرقام من 0 إلى 9، والأحرف من A إلى F (أو a إلى f، غير حساسة لحالة الأحرف). كل خانة تمثل قوة من قوى الستة عشر.

### لماذا الست عشري هو المعيار؟

السبب الرئيسي لشهرة النظام الست عشري هو علاقته المثالية مع البايت (Byte). البايت يتكون من 8 بتات، ويمكن تمثيله بخانتين ست عشريتين فقط. من `00` (0 بالعشري) إلى `FF` (255 بالعشري). هذا يجعل قراءة وكتابة البيانات الخام والعناوين والألوان سهلة جداً.

**استخدامات شائعة:**

**عناوين الذاكرة:** في البرمجة منخفضة المستوى، العناوين دائماً بالست عشري: `0x7FFE1234`

**الألوان:** في تطوير الويب والرسوميات، الألوان تُكتب بالست عشري: `#FF0000` للأحمر، `#00FF00` للأخضر

**البيانات الخام:** عند قراءة أو كتابة ملفات ثنائية، البيانات غالباً تُعرض بالست عشري

**المعرّفات الفريدة:** الـ UUIDs والهاشات تُعرض بالست عشري

### كيف تكتب الأرقام الست عشرية في لغة ص؟

**الطريقة الإنجليزية:** البادئة `0x` متبوعة بالأرقام 0-9 والأحرف A-F:

```s
# أمثلة أساسية
رقم عشرة = 0xA           # A = 10
رقم خمسة_عشر = 0xF       # F = 15
رقم ستة_عشر = 0x10       # 1×16 + 0 = 16
رقم مئتان_خمسة_خمسون = 0xFF  # F×16 + F = 15×16 + 15 = 255

# حالة الأحرف غير مهمة
رقم نفس_الشيء1 = 0xAB
رقم نفس_الشيء2 = 0xab
رقم نفس_الشيء3 = 0xAb
رقم نفس_الشيء4 = 0xaB
# الأربعة متساوون!
```

**الطريقة العربية:** البادئة `0س` (من ست عشري) متبوعة بنفس الرموز:

```s
# نفس الأمثلة بالعربي
رقم عشرة_عربي = 0سA
رقم مئتان_خمسة_خمسون_عربي = 0سFF
رقم ألف = 0س3E8         # 1000 بالعشري
```

### أمثلة عملية شاملة

دعنا نرى أمثلة واقعية لاستخدام الأرقام الست عشرية:

```s
# مثال 1: الألوان في الرسوميات
# تنسيق RGB: كل لون له بايتان (00-FF)

رقم أحمر_نقي = 0xFF0000      # أحمر كامل، لا أخضر، لا أزرق
رقم أخضر_نقي = 0x00FF00      # لا أحمر، أخضر كامل، لا أزرق  
رقم أزرق_نقي = 0x0000FF      # لا أحمر، لا أخضر، أزرق كامل
رقم أبيض = 0xFFFFFF           # كل الألوان بالكامل
رقم أسود = 0x000000           # لا ألوان
رقم رمادي = 0x808080          # نصف كل لون

# ألوان مخصصة
رقم لون_الذهب = 0xFFD700
رقم لون_السماء = 0x87CEEB
رقم لون_الزيتوني = 0x808000

اطبع("اللون الأحمر:", أحمر_نقي)
اطبع("لون الذهب:", لون_الذهب)

# مثال 2: عناوين الذاكرة (محاكاة)
رقم عنوان_البداية = 0x1000
رقم عنوان_النهاية = 0x2000
رقم حجم_الذاكرة = 0x1000    # 4096 بايت

اطبع("عنوان البداية:", عنوان_البداية)
اطبع("حجم الذاكرة:", حجم_الذاكرة)

# مثال 3: الأقنعة البتية
رقم قناع_البايت_الأول = 0xFF000000
رقم قناع_البايت_الثاني = 0x00FF0000
رقم قناع_البايت_الثالث = 0x0000FF00
رقم قناع_البايت_الرابع = 0x000000FF

# مثال 4: رموز خاصة وثوابت
رقم كود_النجاح = 0x00
رقم كود_خطأ_عام = 0xFF
رقم كود_خطأ_الذاكرة = 0xE1
رقم كود_خطأ_الملف = 0xE2

# مثال 5: بالبادئة العربية
رقم لون_أحمر_عربي = 0سFF0000
رقم عنوان_عربي = 0س1234ABCD

اطبع("لون أحمر بالعربي:", لون_أحمر_عربي)
```

## مقارنة شاملة بين الأنظمة

لنقارن كيف يُكتب نفس الرقم (255) بالأنظمة المختلفة:

```s
# الرقم 255 بجميع الأنظمة
رقم عشري = 255                # النظام العشري العادي
رقم ثنائي = 0b11111111        # النظام الثنائي (8 بتات كلها 1)
رقم ثماني = 0o377             # النظام الثماني
رقم ست_عشري = 0xFF            # النظام الست عشري

# بالبادئات العربية
رقم ثنائي_عربي = 0ثن11111111
رقم ثماني_عربي = 0ع377
رقم ست_عشري_عربي = 0سFF

# كلهم يساوون 255!
اطبع("عشري:", عشري)
اطبع("ثنائي:", ثنائي)
اطبع("ثماني:", ثماني)
اطبع("ست عشري:", ست_عشري)
```

## نصائح وأفضل الممارسات

عند اختيار أي نظام عددي تستخدم، ضع هذه المبادئ في الاعتبار:

**استخدم النظام الثنائي عندما:** تتعامل مع أعلام وبتات فردية، أو تريد توضيح عملية بتية معينة

**استخدم النظام الثماني عندما:** تتعامل مع صلاحيات ملفات Unix، أو تعمل على كود قديم يستخدمه

**استخدم النظام الست عشري عندما:** تتعامل مع ألوان، عناوين ذاكرة، بيانات خام، أو معرّفات

**استخدم النظام العشري عندما:** تتعامل مع قيم رياضية أو منطقية عادية، أو عند قراءة مدخلات المستخدم

**اختر البادئات بحكمة:** استخدم البادئات العربية في الكود ذو الطابع العربي الثقيل، والإنجليزية في الكود التقني البحت، أو اختر واحدة والتزم بها
