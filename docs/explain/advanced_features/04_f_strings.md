# النصوص المنسقة في لغة ص  
# F-Strings in S Language

**الموضوع:** دمج المتغيرات والتعبيرات في النصوص  
**المستوى:** متوسط  
**الفائدة:** كود أقصر وأوضح

---

## المشكلة: دمج النصوص التقليدي مربك

الطريقة التقليدية لدمج المتغيرات في النصوص طويلة ومربكة:

```s
# الطريقة القديمة (مزعجة!)
نص الاسم = "أحمد"
رقم العمر = 25
نص رسالة = "مرحباً " + الاسم + "، عمرك " + نص(العمر) + " سنة"
```

## الحل: النصوص المنسقة (F-Strings)

النصوص المنسقة تسمح لك بوضع المتغيرات والتعبيرات مباشرة داخل النص:

### الطريقة الإنجليزية: `f"...{expr}..."`

```s
نص الاسم = "أحمد"  
رقم العمر = 25

# بسيطة وواضحة!
نص رسالة = f"مرحباً {الاسم}، عمرك {العمر} سنة"

اطبع(رسالة)
# النتيجة: مرحباً أحمد، عمرك 25 سنة
```

### الطريقة العربية: `م"...{expr}..."`

البادئة `م` (من "منسق") تعمل بنفس الطريقة:

```s
نص رسالة_عربية = م"الاسم: {الاسم}، العمر: {العمر}"
```

## أمثلة عملية شاملة

### مثال 1: تقارير بسيطة

```s
نص اسم_الموظف = "خالد"
رقم الراتب = 8000
رقم المكافأة = 2000

نص التقرير = f"الموظف {اسم_الموظف} - الراتب: {الراتب} ريال - المكافأة: {المكافأة} ريال"

اطبع(التقرير)
```

### مثال 2: حسابات داخل النص

```s
رقم السعر = 100
رقم الكمية = 5

نص الفاتورة = f"السعر: {السعر} × الكمية: {الكمية} = {السعر * الكمية} ريال"

اطبع(الفاتورة)
# النتيجة: السعر: 100 × الكمية: 5 = 500 ريال
```

### مثال 3: تعبيرات معقدة

```s
رقم درجة1 = 90
رقم درجة2 = 85  
رقم درجة3 = 95

نص النتيجة = f"المعدل = {(درجة1 + درجة2 + درجة3) / 3}"

اطبع(النتيجة)
```

### مثال 4: نصوص متعددة المتغيرات

```s
نص المدينة = "الرياض"
عشري الحرارة = 42.5
نص الطقس = "مشمس"

نص تقرير_الطقس = f"الطقس في {المدينة}: {الطقس}، درجة الحرارة {الحرارة}°م"

اطبع(تقرير_الطقس)
```

## أقواس معقوفة حرفية

إذا أردت أن تكتب `{` أو `}` حرفياً في F-string، ضاعفها:

```s
نص العدد = 10
نص مع_أقواس = f"العدد: {العدد}، أقواس حرفية: {{هنا}}"

اطبع(مع_أقواس)
# النتيجة: العدد: 10، أقواس حرفية: {هنا}
```

## متى تستخدم F-Strings؟

✅ **استخدمها عندما:**
- تدمج متغيرات في نصوص
- تريد إجراء حسابات بسيطة داخل النص
- تحتاج لتنسيق واضح ومباشر
- الكود يحتوي على الكثير من دمج النصوص

❌ **لا تستخدمها عندما:**
- النص ثابت بدون متغيرات
- التعبيرات معقدة جداً (افصلها لمتغير منفصل أولاً)

## نصائح مهمة

**ملاحظة:** حالياً في لغة ص، المحلل المعجمي (Lexer) يدعم F-strings بالكامل، لكن المفسر (Interpreter) لا يزال قيد التطوير لتقييم التعبيرات داخل الأقواس. الدعم الكامل قادم في إصدار قريب!
