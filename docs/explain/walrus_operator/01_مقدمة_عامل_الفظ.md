# 🦭 عامل الفظ (Walrus Operator)

## مقدمة

عامل الفظ (`:=`) هو عامل تعيين خاص في لغة ص يتيح لك تعيين قيمة لمتغير واستخدامها في نفس التعبير. سُمي بهذا الاسم لأن الرمز `:=` يشبه وجه الفظ (الفقمة) مع أنيابه.

هذا العامل يُعرف أيضاً باسم "تعبير التعيين" (Assignment Expression) لأنه يجمع بين التعيين والتعبير في آن واحد.

## لماذا عامل الفظ؟

### المشكلة التقليدية

لنفترض أنك تريد التحقق من طول نص وإذا كان طويلاً، تطبعه مع طوله:

```s
# الطريقة التقليدية - تكرار حساب طول(نص)
دالة رئيسية()
    نص جملة = "مرحباً بكم في لغة ص للبرمجة"
    
    إذا (طول(جملة) > 10)
        اطبع("النص طويل، طوله: " + طول(جملة))  # حسبنا الطول مرتين!
    نهاية
نهاية
```

أو بمتغير منفصل:

```s
# بمتغير منفصل - سطر إضافي
دالة رئيسية()
    نص جملة = "مرحباً بكم في لغة ص للبرمجة"
    
    رقم الطول = طول(جملة)  # سطر إضافي
    إذا (الطول > 10)
        اطبع("النص طويل، طوله: " + الطول)
    نهاية
نهاية
```

### الحل بعامل الفظ

```s
دالة رئيسية()
    نص جملة = "مرحباً بكم في لغة ص للبرمجة"
    
    إذا ((الطول := طول(جملة)) > 10)
        اطبع("النص طويل، طوله: " + الطول)  # نستخدم المتغير المُعيَّن
    نهاية
نهاية
```

## الصيغة الأساسية

```s
(متغير := تعبير)
```

- **متغير**: اسم المتغير الذي سيُعيَّن
- **تعبير**: القيمة التي ستُعيَّن وتُستخدم

**ملاحظة مهمة**: غالباً تحتاج لوضع التعبير بين أقواس.

## أمثلة أساسية

### في جملة if

```s
دالة رئيسية()
    قائمة أرقام = [1، 2، 3، 4، 5]
    
    # التحقق من الطول واستخدامه
    إذا ((ن := طول(أرقام)) > 3)
        اطبع("القائمة تحتوي " + ن + " عناصر")
    نهاية
نهاية
```

### في جملة while

```s
دالة رئيسية()
    # قراءة مدخلات حتى يدخل المستخدم "خروج"
    بينما ((مدخل := اقرأ_سطر("أدخل أمراً: ")) != "خروج")
        اطبع("نفذت: " + مدخل)
    نهاية
    
    اطبع("وداعاً!")
نهاية
```

### في قراءة الملفات

```s
دالة رئيسية()
    باستخدام افتح("بيانات.txt"، "قراءة") كـ ملف
        بينما ((سطر := ملف.اقرأ_سطر()) != عدم)
            اطبع(سطر)
        نهاية
    نهاية_استخدام
```

## في استيعاب القوائم

### تجنب الحساب المتكرر

```s
دالة رئيسية()
    قائمة نصوص = ["مرحباً"، "أهلاً وسهلاً بكم"، "مع السلامة"]
    
    # بدون عامل الفظ - حساب الطول مرتين
    قائمة نتيجة1 = [(نص، طول(نص)) لكل نص في نصوص إذا طول(نص) > 5]
    
    # مع عامل الفظ - حساب الطول مرة واحدة
    قائمة نتيجة2 = [(نص، ط) لكل نص في نصوص إذا (ط := طول(نص)) > 5]
    
    اطبع(نتيجة2)  # [("أهلاً وسهلاً بكم"، 13)، ("مع السلامة"، 10)]
نهاية
```

### مع دالة معقدة

```s
دالة حساب_معقد(رقم ن)
    # تخيل أن هذه عملية مكلفة
    إرجاع ن ** 2 + ن * 3 + 7
نهاية

دالة رئيسية()
    قائمة أرقام = مدى(1، 20)
    
    # تصفية وتحويل مع حساب واحد فقط
    قائمة نتيجة = [
        (ن، نتيجة)
        لكل ن في أرقام
        إذا (نتيجة := حساب_معقد(ن)) > 50
    ]
    
    لكل عنصر في نتيجة[:5]
        اطبع(عنصر)
    نهاية
نهاية
```

## في التعبيرات الشرطية

```s
دالة رئيسية()
    قائمة بيانات = [5، 0، 15، 0، 25، 0، 35]
    
    # حساب واستخدام في التعبير الشرطي
    قائمة نتيجة = [
        نتيجة إذا (نتيجة := ن * 2) > 0 وإلا "صفر"
        لكل ن في بيانات
    ]
    
    اطبع(نتيجة)  # [10، "صفر"، 30، "صفر"، 50، "صفر"، 70]
نهاية
```

## مقارنة بدون وبعامل الفظ

### مثال 1: التحقق من القاموس

```s
# بدون عامل الفظ
دالة احصل_على_قيمة_1(قاموس بيانات، نص مفتاح)
    متغير قيمة = بيانات.احصل(مفتاح)
    إذا (قيمة != عدم)
        إرجاع معالجة(قيمة)
    نهاية
    إرجاع افتراضي()
نهاية

# مع عامل الفظ
دالة احصل_على_قيمة_2(قاموس بيانات، نص مفتاح)
    إذا ((قيمة := بيانات.احصل(مفتاح)) != عدم)
        إرجاع معالجة(قيمة)
    نهاية
    إرجاع افتراضي()
نهاية
```

### مثال 2: البحث في قائمة

```s
# بدون عامل الفظ
دالة ابحث_1(قائمة عناصر)
    رقم فهرس = 0
    منطقي وُجد = خطأ
    
    لكل ت في مدى(طول(عناصر))
        إذا (شرط(عناصر[ت]))
            فهرس = ت
            وُجد = صحيح
            اخرج
        نهاية
    نهاية
    
    إذا (وُجد)
        إرجاع عناصر[فهرس]
    نهاية
    إرجاع عدم
نهاية

# مع عامل الفظ (في حلقة)
دالة ابحث_2(قائمة عناصر)
    لكل عنصر في عناصر
        إذا ((نتيجة := تحقق_وأرجع(عنصر)) != عدم)
            إرجاع نتيجة
        نهاية
    نهاية
    إرجاع عدم
نهاية
```

### مثال 3: تصفية مع تحويل

```s
دالة رئيسية()
    قائمة نصوص = ["hello"، "مرحبا"، "WORLD"، "عالم"، "test"]
    
    # بدون عامل الفظ
    قائمة نتيجة1 = []
    لكل نص في نصوص
        متغير محول = تحويل_معقد(نص)
        إذا (محول != عدم وَ طول(محول) > 3)
            نتيجة1.أضف(محول)
        نهاية
    نهاية
    
    # مع عامل الفظ
    قائمة نتيجة2 = [
        م
        لكل نص في نصوص
        إذا (م := تحويل_معقد(نص)) != عدم وَ طول(م) > 3
    ]
نهاية
```

## قواعد وقيود

### 1. الأقواس ضرورية في معظم الحالات

```s
# خطأ ❌
إذا (ن := طول(قائمة) > 5)  # غامض

# صحيح ✅
إذا ((ن := طول(قائمة)) > 5)
```

### 2. لا يمكن استخدامه في التعيين المباشر

```s
# خطأ ❌
ن := 5  # لا يمكن استخدامه كجملة مستقلة

# صحيح ✅
ن = 5  # استخدم التعيين العادي
```

### 3. نطاق المتغير

```s
دالة رئيسية()
    قائمة أرقام = [1، 2، 3، 4، 5]
    
    # المتغير يبقى متاحاً بعد الاستيعاب
    قائمة نتيجة = [ق لكل ن في أرقام إذا (ق := ن * 2) > 5]
    
    اطبع(ق)  # آخر قيمة للمتغير (10)
نهاية
```

### 4. في التعبيرات الشرطية

```s
دالة رئيسية()
    نص قيمة = "اختبار"
    
    # استخدام في التعبير الشرطي
    نص نتيجة = ط إذا (ط := طول(قيمة)) > 5 وإلا "قصير"
    اطبع(نتيجة)
نهاية
```

## أخطاء شائعة

### 1. نسيان الأقواس

```s
# خطأ
إذا ن := حساب() > 0  # ❌

# صحيح
إذا (ن := حساب()) > 0  # ✅
```

### 2. استخدامه حيث = كافٍ

```s
# مبالغة
ن := 5  # ❌ لا معنى له

# الأفضل
ن = 5  # ✅
```

### 3. تعقيد الكود بدون داعٍ

```s
# معقد جداً
إذا ((أ := ف()) != عدم وَ (ب := ج(أ)) != عدم وَ (ج := هـ(ب)) > 10)

# أوضح
متغير أ = ف()
إذا (أ == عدم)
    إرجاع
نهاية
متغير ب = ج(أ)
إذا (ب == عدم)
    إرجاع
نهاية
متغير ج = هـ(ب)
إذا (ج > 10)
    # ...
نهاية
```

## متى تستخدم عامل الفظ؟

### استخدمه عندما:
- تحتاج حساب قيمة واستخدامها في شرط
- تريد تجنب تكرار حساب مكلف
- في استيعاب القوائم مع تصفية وتحويل
- في حلقات `بينما` لقراءة البيانات

### تجنبه عندما:
- التعيين البسيط كافٍ
- يجعل الكود أصعب للقراءة
- يمكن تقسيم التعبير لأسطر أوضح

## الخلاصة

عامل الفظ (`:=`) في لغة ص:
- يجمع بين التعيين والتعبير
- يتجنب تكرار الحسابات
- مفيد جداً في الشروط والحلقات والاستيعاب
- يحتاج أقواس في معظم الحالات
- استخدمه بحكمة للحفاظ على وضوح الكود
