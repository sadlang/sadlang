# أصناف القوالب في لغة ص

## ما هي أصناف القوالب؟

أصناف القوالب هي أصناف عامة يمكنها العمل مع أنواع بيانات مختلفة. تماماً كما تُتيح لنا دوال القوالب كتابة دالة واحدة تعمل مع أنواع متعددة، تُتيح لنا أصناف القوالب إنشاء هياكل بيانات عامة ومرنة.

تخيل أنك تريد إنشاء صندوق يحتوي على قيمة واحدة. هذا الصندوق يمكن أن يحتوي على رقم، أو نص، أو أي نوع آخر. بدون القوالب، ستحتاج لإنشاء صندوق مختلف لكل نوع. مع أصناف القوالب، تُنشئ صنفاً واحداً يعمل مع جميع الأنواع!

## الصيغة الأساسية

```س
قالب<نوع ت> صنف اسم_الصنف
    خاص:
        ت قيمة
    
    عام:
        دالة منشئ(ت ق)
            قيمة = ق
        نهاية
        
        دالة احصل() ت
            ارجع قيمة
        نهاية
        
        دالة عيّن(ت ق)
            قيمة = ق
        نهاية
نهاية
```

### شرح المكونات

- `قالب<نوع ت>`: تُعلن أن هذا صنف قالب بمعامل نوع `ت`
- `صنف اسم_الصنف`: تعريف الصنف كالمعتاد
- `ت قيمة`: خاصية من النوع المُعمم `ت`
- `دالة منشئ(ت ق)`: المُنشئ يستقبل قيمة من النوع `ت`
- `دالة احصل() ت`: تُرجع قيمة من النوع `ت`

## مثال شامل: صندوق القيمة

لنبدأ بمثال بسيط لفهم الأساسيات:

```س
قالب<نوع ت> صنف صندوق
    خاص:
        ت محتوى
        منطقي فارغ
    
    عام:
        # مُنشئ فارغ
        دالة منشئ()
            فارغ = صحيح
        نهاية
        
        # مُنشئ بقيمة ابتدائية
        دالة منشئ(ت قيمة)
            محتوى = قيمة
            فارغ = خطأ
        نهاية
        
        # وضع قيمة في الصندوق
        دالة ضع(ت قيمة)
            محتوى = قيمة
            فارغ = خطأ
        نهاية
        
        # الحصول على القيمة
        دالة احصل() ت
            ارجع محتوى
        نهاية
        
        # التحقق من الفراغ
        دالة هل_فارغ() منطقي
            ارجع فارغ
        نهاية
        
        # إفراغ الصندوق
        دالة افرغ()
            فارغ = صحيح
        نهاية
نهاية

دالة رئيسية() رقم
    # صندوق أرقام
    متغير صندوق_رقم = صندوق<رقم>(42)
    اطبع("محتوى صندوق الرقم: ")
    اطبع(صندوق_رقم.احصل())
    
    # صندوق نصوص
    متغير صندوق_نص = صندوق<نص>("مرحباً بالعالم")
    اطبع("محتوى صندوق النص: ")
    اطبع(صندوق_نص.احصل())
    
    # تغيير المحتوى
    صندوق_رقم.ضع(100)
    اطبع("المحتوى الجديد: ")
    اطبع(صندوق_رقم.احصل())
    
    ارجع 0
نهاية
```

هذا المثال يُظهر كيف يمكن لنفس الصنف `صندوق` أن يحتوي على أرقام أو نصوص حسب النوع المُحدد عند الإنشاء.

## هياكل البيانات الأساسية

### 1. القائمة المتصلة (Linked List)

القائمة المتصلة هي هيكل بيانات أساسي حيث كل عنصر يُشير للعنصر التالي:

```س
# عقدة في القائمة المتصلة
قالب<نوع ت> صنف عقدة
    عام:
        ت بيانات
        عقدة<ت> التالي
        
        دالة منشئ(ت قيمة)
            بيانات = قيمة
            التالي = فارغ
        نهاية
نهاية

# القائمة المتصلة
قالب<نوع ت> صنف قائمة_متصلة
    خاص:
        عقدة<ت> الرأس
        عقدة<ت> الذيل
        رقم العدد
    
    عام:
        دالة منشئ()
            الرأس = فارغ
            الذيل = فارغ
            العدد = 0
        نهاية
        
        # إضافة عنصر في النهاية
        دالة أضف(ت قيمة)
            متغير عقدة_جديدة = عقدة<ت>(قيمة)
            
            إذا(الرأس == فارغ)
                الرأس = عقدة_جديدة
                الذيل = عقدة_جديدة
            وإلا
                الذيل.التالي = عقدة_جديدة
                الذيل = عقدة_جديدة
            نهاية
            
            العدد = العدد + 1
        نهاية
        
        # إضافة عنصر في البداية
        دالة أضف_في_البداية(ت قيمة)
            متغير عقدة_جديدة = عقدة<ت>(قيمة)
            عقدة_جديدة.التالي = الرأس
            الرأس = عقدة_جديدة
            
            إذا(الذيل == فارغ)
                الذيل = عقدة_جديدة
            نهاية
            
            العدد = العدد + 1
        نهاية
        
        # الحصول على عنصر بالفهرس
        دالة احصل(رقم فهرس) ت
            متغير حالي = الرأس
            متغير ع = 0
            
            طالما(ع < فهرس و حالي != فارغ)
                حالي = حالي.التالي
                ع = ع + 1
            نهاية
            
            ارجع حالي.بيانات
        نهاية
        
        # الحصول على عدد العناصر
        دالة الحجم() رقم
            ارجع العدد
        نهاية
        
        # التحقق من الفراغ
        دالة فارغة() منطقي
            ارجع العدد == 0
        نهاية
        
        # طباعة القائمة
        دالة اطبع_الكل()
            متغير حالي = الرأس
            اطبع("[")
            طالما(حالي != فارغ)
                اطبع(حالي.بيانات)
                إذا(حالي.التالي != فارغ)
                    اطبع(" -> ")
                نهاية
                حالي = حالي.التالي
            نهاية
            اطبع("]")
        نهاية
نهاية

دالة رئيسية() رقم
    # قائمة أرقام
    متغير أرقام = قائمة_متصلة<رقم>()
    أرقام.أضف(10)
    أرقام.أضف(20)
    أرقام.أضف(30)
    
    اطبع("قائمة الأرقام: ")
    أرقام.اطبع_الكل()
    
    # قائمة نصوص
    متغير أسماء = قائمة_متصلة<نص>()
    أسماء.أضف("أحمد")
    أسماء.أضف("محمد")
    أسماء.أضف("علي")
    
    اطبع("قائمة الأسماء: ")
    أسماء.اطبع_الكل()
    
    ارجع 0
نهاية
```

### 2. المكدس (Stack)

المكدس هو هيكل بيانات يعمل بمبدأ "آخر من يدخل أول من يخرج" (LIFO):

```س
قالب<نوع ت> صنف مكدس
    خاص:
        ت[] عناصر
        رقم القمة
        رقم السعة
    
    عام:
        دالة منشئ(رقم سعة_ابتدائية)
            السعة = سعة_ابتدائية
            عناصر = ت[السعة]
            القمة = -1
        نهاية
        
        # إضافة عنصر (Push)
        دالة ادفع(ت قيمة) منطقي
            إذا(القمة >= السعة - 1)
                اطبع("خطأ: المكدس ممتلئ!")
                ارجع خطأ
            نهاية
            
            القمة = القمة + 1
            عناصر[القمة] = قيمة
            ارجع صحيح
        نهاية
        
        # إزالة عنصر (Pop)
        دالة اسحب() ت
            إذا(القمة < 0)
                اطبع("خطأ: المكدس فارغ!")
            نهاية
            
            متغير قيمة = عناصر[القمة]
            القمة = القمة - 1
            ارجع قيمة
        نهاية
        
        # رؤية العنصر الأعلى دون إزالته (Peek)
        دالة اقرأ_القمة() ت
            إذا(القمة < 0)
                اطبع("خطأ: المكدس فارغ!")
            نهاية
            ارجع عناصر[القمة]
        نهاية
        
        # التحقق من الفراغ
        دالة فارغ() منطقي
            ارجع القمة < 0
        نهاية
        
        # التحقق من الامتلاء
        دالة ممتلئ() منطقي
            ارجع القمة >= السعة - 1
        نهاية
        
        # الحجم الحالي
        دالة الحجم() رقم
            ارجع القمة + 1
        نهاية
نهاية

دالة رئيسية() رقم
    # مكدس أرقام
    متغير مكدس_أرقام = مكدس<رقم>(10)
    
    مكدس_أرقام.ادفع(1)
    مكدس_أرقام.ادفع(2)
    مكدس_أرقام.ادفع(3)
    
    اطبع("حجم المكدس: ")
    اطبع(مكدس_أرقام.الحجم())
    
    اطبع("قمة المكدس: ")
    اطبع(مكدس_أرقام.اقرأ_القمة())
    
    اطبع("سحب العناصر:")
    طالما(!مكدس_أرقام.فارغ())
        اطبع(مكدس_أرقام.اسحب())
    نهاية
    
    ارجع 0
نهاية
```

### 3. الطابور (Queue)

الطابور يعمل بمبدأ "أول من يدخل أول من يخرج" (FIFO):

```س
قالب<نوع ت> صنف طابور
    خاص:
        ت[] عناصر
        رقم الأمام
        رقم الخلف
        رقم السعة
        رقم العدد
    
    عام:
        دالة منشئ(رقم سعة_ابتدائية)
            السعة = سعة_ابتدائية
            عناصر = ت[السعة]
            الأمام = 0
            الخلف = -1
            العدد = 0
        نهاية
        
        # إضافة عنصر (Enqueue)
        دالة أدخل(ت قيمة) منطقي
            إذا(العدد >= السعة)
                اطبع("خطأ: الطابور ممتلئ!")
                ارجع خطأ
            نهاية
            
            الخلف = (الخلف + 1) % السعة
            عناصر[الخلف] = قيمة
            العدد = العدد + 1
            ارجع صحيح
        نهاية
        
        # إزالة عنصر (Dequeue)
        دالة أخرج() ت
            إذا(العدد <= 0)
                اطبع("خطأ: الطابور فارغ!")
            نهاية
            
            متغير قيمة = عناصر[الأمام]
            الأمام = (الأمام + 1) % السعة
            العدد = العدد - 1
            ارجع قيمة
        نهاية
        
        # رؤية العنصر الأمامي
        دالة الأول() ت
            إذا(العدد <= 0)
                اطبع("خطأ: الطابور فارغ!")
            نهاية
            ارجع عناصر[الأمام]
        نهاية
        
        # التحقق من الفراغ
        دالة فارغ() منطقي
            ارجع العدد == 0
        نهاية
        
        # الحجم
        دالة الحجم() رقم
            ارجع العدد
        نهاية
نهاية

دالة رئيسية() رقم
    # طابور للمهام
    متغير مهام = طابور<نص>(5)
    
    مهام.أدخل("مهمة 1")
    مهام.أدخل("مهمة 2")
    مهام.أدخل("مهمة 3")
    
    اطبع("معالجة المهام:")
    طالما(!مهام.فارغ())
        اطبع("معالجة: ")
        اطبع(مهام.أخرج())
    نهاية
    
    ارجع 0
نهاية
```

## أصناف القوالب مع معاملات متعددة

يمكن لأصناف القوالب أن تأخذ أكثر من معامل نوع:

### الزوج (Pair)

```س
قالب<نوع ت1، نوع ت2> صنف زوج
    عام:
        ت1 الأول
        ت2 الثاني
        
        دالة منشئ(ت1 أول، ت2 ثاني)
            الأول = أول
            الثاني = ثاني
        نهاية
        
        دالة عيّن_الأول(ت1 قيمة)
            الأول = قيمة
        نهاية
        
        دالة عيّن_الثاني(ت2 قيمة)
            الثاني = قيمة
        نهاية
        
        دالة اطبع()
            اطبع("(")
            اطبع(الأول)
            اطبع("، ")
            اطبع(الثاني)
            اطبع(")")
        نهاية
نهاية

دالة رئيسية() رقم
    # زوج من اسم وعمر
    متغير شخص = زوج<نص، رقم>("أحمد"، 25)
    شخص.اطبع()
    
    # زوج من إحداثيات
    متغير نقطة = زوج<عشري، عشري>(3.14، 2.71)
    نقطة.اطبع()
    
    ارجع 0
نهاية
```

### الخريطة البسيطة (Simple Map)

```س
قالب<نوع مفتاح، نوع قيمة> صنف خريطة
    خاص:
        مفتاح[] مفاتيح
        قيمة[] قيم
        رقم العدد
        رقم السعة
    
    عام:
        دالة منشئ(رقم سعة_ابتدائية)
            السعة = سعة_ابتدائية
            مفاتيح = مفتاح[السعة]
            قيم = قيمة[السعة]
            العدد = 0
        نهاية
        
        # إضافة أو تحديث عنصر
        دالة ضع(مفتاح م، قيمة ق) منطقي
            # البحث عن المفتاح
            متغير ع = 0
            طالما(ع < العدد)
                إذا(مفاتيح[ع] == م)
                    قيم[ع] = ق
                    ارجع صحيح
                نهاية
                ع = ع + 1
            نهاية
            
            # إضافة عنصر جديد
            إذا(العدد >= السعة)
                اطبع("خطأ: الخريطة ممتلئة!")
                ارجع خطأ
            نهاية
            
            مفاتيح[العدد] = م
            قيم[العدد] = ق
            العدد = العدد + 1
            ارجع صحيح
        نهاية
        
        # الحصول على قيمة بالمفتاح
        دالة احصل(مفتاح م) قيمة
            متغير ع = 0
            طالما(ع < العدد)
                إذا(مفاتيح[ع] == م)
                    ارجع قيم[ع]
                نهاية
                ع = ع + 1
            نهاية
            اطبع("خطأ: المفتاح غير موجود!")
        نهاية
        
        # التحقق من وجود مفتاح
        دالة يحتوي(مفتاح م) منطقي
            متغير ع = 0
            طالما(ع < العدد)
                إذا(مفاتيح[ع] == م)
                    ارجع صحيح
                نهاية
                ع = ع + 1
            نهاية
            ارجع خطأ
        نهاية
        
        # الحجم
        دالة الحجم() رقم
            ارجع العدد
        نهاية
نهاية

دالة رئيسية() رقم
    # خريطة من اسم إلى عمر
    متغير أعمار = خريطة<نص، رقم>(10)
    
    أعمار.ضع("أحمد"، 25)
    أعمار.ضع("محمد"، 30)
    أعمار.ضع("علي"، 28)
    
    اطبع("عمر أحمد: ")
    اطبع(أعمار.احصل("أحمد"))
    
    اطبع("هل يوجد محمد؟ ")
    اطبع(أعمار.يحتوي("محمد"))
    
    ارجع 0
نهاية
```

## نصائح متقدمة

### 1. استخدام أصناف القوالب مع الوراثة

```س
# صنف قالب أساسي
قالب<نوع ت> صنف حاوية
    خاص:
        ت قيمة
    
    عام:
        دالة احصل() ت
            ارجع قيمة
        نهاية
        
        دالة عيّن(ت ق)
            قيمة = ق
        نهاية
نهاية

# صنف قالب وارث
قالب<نوع ت> صنف حاوية_مسماة يرث حاوية<ت>
    خاص:
        نص الاسم
    
    عام:
        دالة منشئ(نص اسم، ت قيمة)
            الاسم = اسم
            عيّن(قيمة)
        نهاية
        
        دالة احصل_الاسم() نص
            ارجع الاسم
        نهاية
        
        دالة اطبع()
            اطبع(الاسم)
            اطبع(": ")
            اطبع(احصل())
        نهاية
نهاية
```

### 2. القوالب المتداخلة

```س
قالب<نوع ت> صنف قائمة
    # يمكن استخدام صنف قالب آخر داخل صنف القالب
    خاص:
        زوج<ت، رقم>[] عناصر  # كل عنصر مع فهرسه
        رقم العدد
    
    عام:
        # ...
نهاية
```

## الأخطاء الشائعة في أصناف القوالب

### 1. نسيان تحديد النوع عند الإنشاء

```س
# خطأ
متغير ص = صندوق()

# صحيح
متغير ص = صندوق<رقم>()
```

### 2. خلط الأنواع

```س
# خطأ - لا يمكن وضع نص في صندوق أرقام
متغير ص = صندوق<رقم>()
ص.ضع("نص")  # خطأ!

# صحيح
ص.ضع(42)
```

### 3. استخدام عمليات غير مدعومة

```س
# خطأ - ليس كل الأنواع تدعم المقارنة
قالب<نوع ت> صنف مجموعة_مرتبة
    دالة أضف(ت قيمة)
        # استخدام < للترتيب قد لا يعمل مع بعض الأنواع
    نهاية
نهاية
```

## ملخص

أصناف القوالب تُمكّنك من:

- إنشاء هياكل بيانات عامة تعمل مع أي نوع
- بناء مكتبات قوية ومرنة
- تقليل تكرار الكود بشكل كبير
- الحفاظ على أمان الأنواع

استخدم أصناف القوالب لبناء هياكل البيانات الأساسية مثل القوائم والمكدسات والطوابير، ثم توسع لبناء هياكل أكثر تعقيداً!
