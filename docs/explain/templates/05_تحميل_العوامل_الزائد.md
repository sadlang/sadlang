# تحميل العوامل الزائد في لغة ص

## ما هو تحميل العوامل الزائد؟

تحميل العوامل الزائد (Operator Overloading) هو ميزة تُتيح لك إعادة تعريف سلوك العوامل الحسابية والمنطقية (`+`، `-`، `*`، `/`، `==`، `<`، إلخ) لتعمل مع أصنافك الخاصة. بدلاً من كتابة `كسر1.أضف(كسر2)`، يمكنك كتابة `كسر1 + كسر2` وهو أكثر طبيعية وقراءة.

تخيل أنك أنشأت صنفاً يُمثل كسراً رياضياً. بالطبع تريد جمع كسرين معاً باستخدام علامة `+` كما تفعل مع الأرقام العادية. تحميل العوامل الزائد يُمكّنك من ذلك!

## الصيغة الأساسية

```س
صنف اسم_الصنف
    # الخصائص والدوال...
    
    عامل +(اسم_الصنف آخر) اسم_الصنف
        # تعريف عملية الجمع
    نهاية
    
    عامل ==(اسم_الصنف آخر) منطقي
        # تعريف عملية المقارنة
    نهاية
نهاية
```

## العوامل القابلة للتحميل الزائد

في لغة ص، يمكنك تحميل العوامل التالية:

### العوامل الحسابية
| العامل | الوصف | مثال |
|--------|-------|------|
| `+` | الجمع | `أ + ب` |
| `-` | الطرح | `أ - ب` |
| `*` | الضرب | `أ * ب` |
| `/` | القسمة | `أ / ب` |
| `%` | باقي القسمة | `أ % ب` |

### عوامل المقارنة
| العامل | الوصف | مثال |
|--------|-------|------|
| `==` | يساوي | `أ == ب` |
| `!=` | لا يساوي | `أ != ب` |
| `<` | أصغر من | `أ < ب` |
| `>` | أكبر من | `أ > ب` |
| `<=` | أصغر أو يساوي | `أ <= ب` |
| `>=` | أكبر أو يساوي | `أ >= ب` |

### عوامل أخرى
| العامل | الوصف | مثال |
|--------|-------|------|
| `[]` | الوصول بالفهرس | `أ[5]` |
| `()` | الاستدعاء | `أ()` |

## أمثلة عملية للمبتدئين

### مثال 1: صنف الكسر

```س
صنف كسر
    خاص:
        رقم البسط
        رقم المقام
    
    عام:
        دالة منشئ(رقم بسط، رقم مقام)
            البسط = بسط
            إذا(مقام == 0)
                اطبع("خطأ: المقام لا يمكن أن يكون صفراً!")
                المقام = 1
            وإلا
                المقام = مقام
            نهاية
        نهاية
        
        دالة احصل_البسط() رقم
            ارجع البسط
        نهاية
        
        دالة احصل_المقام() رقم
            ارجع المقام
        نهاية
        
        # تحميل عامل الجمع
        عامل +(كسر آخر) كسر
            # الجمع: (أ/ب) + (ج/د) = (أ×د + ج×ب) / (ب×د)
            متغير بسط_جديد = البسط * آخر.المقام + آخر.البسط * المقام
            متغير مقام_جديد = المقام * آخر.المقام
            ارجع كسر(بسط_جديد، مقام_جديد)
        نهاية
        
        # تحميل عامل الطرح
        عامل -(كسر آخر) كسر
            متغير بسط_جديد = البسط * آخر.المقام - آخر.البسط * المقام
            متغير مقام_جديد = المقام * آخر.المقام
            ارجع كسر(بسط_جديد، مقام_جديد)
        نهاية
        
        # تحميل عامل الضرب
        عامل *(كسر آخر) كسر
            # الضرب: (أ/ب) × (ج/د) = (أ×ج) / (ب×د)
            ارجع كسر(البسط * آخر.البسط، المقام * آخر.المقام)
        نهاية
        
        # تحميل عامل القسمة
        عامل /(كسر آخر) كسر
            # القسمة: (أ/ب) ÷ (ج/د) = (أ×د) / (ب×ج)
            ارجع كسر(البسط * آخر.المقام، المقام * آخر.البسط)
        نهاية
        
        # تحميل عامل المساواة
        عامل ==(كسر آخر) منطقي
            # كسران متساويان إذا: أ×د = ب×ج
            ارجع البسط * آخر.المقام == المقام * آخر.البسط
        نهاية
        
        # تحميل عامل أصغر من
        عامل <(كسر آخر) منطقي
            ارجع البسط * آخر.المقام < المقام * آخر.البسط
        نهاية
        
        # طباعة الكسر
        دالة اطبع()
            اطبع(البسط)
            اطبع("/")
            اطبع(المقام)
        نهاية
        
        # تحويل لعشري
        دالة كعشري() عشري
            ارجع البسط / المقام
        نهاية
نهاية

دالة رئيسية() رقم
    متغير ك1 = كسر(1، 2)  # نصف
    متغير ك2 = كسر(1، 3)  # ثلث
    
    اطبع("الكسر الأول: ")
    ك1.اطبع()
    
    اطبع("الكسر الثاني: ")
    ك2.اطبع()
    
    # استخدام العوامل المُحمّلة
    متغير مجموع = ك1 + ك2
    اطبع("المجموع: ")
    مجموع.اطبع()  # 5/6
    
    متغير حاصل_الضرب = ك1 * ك2
    اطبع("حاصل الضرب: ")
    حاصل_الضرب.اطبع()  # 1/6
    
    # المقارنة
    إذا(ك1 > ك2)
        اطبع("الكسر الأول أكبر")
    وإلا
        اطبع("الكسر الثاني أكبر أو متساويان")
    نهاية
    
    ارجع 0
نهاية
```

### مثال 2: صنف النقطة (إحداثيات)

```س
صنف نقطة
    عام:
        عشري س
        عشري ص
        
        دالة منشئ(عشري إكس، عشري واي)
            س = إكس
            ص = واي
        نهاية
        
        # جمع نقطتين (جمع المتجهات)
        عامل +(نقطة أخرى) نقطة
            ارجع نقطة(س + أخرى.س، ص + أخرى.ص)
        نهاية
        
        # طرح نقطتين
        عامل -(نقطة أخرى) نقطة
            ارجع نقطة(س - أخرى.س، ص - أخرى.ص)
        نهاية
        
        # ضرب بعدد (تكبير/تصغير)
        عامل *(عشري معامل) نقطة
            ارجع نقطة(س * معامل، ص * معامل)
        نهاية
        
        # المساواة
        عامل ==(نقطة أخرى) منطقي
            ارجع س == أخرى.س و ص == أخرى.ص
        نهاية
        
        # حساب المسافة من نقطة الأصل
        دالة المسافة() عشري
            ارجع جذر(س * س + ص * ص)
        نهاية
        
        # طباعة النقطة
        دالة اطبع()
            اطبع("(")
            اطبع(س)
            اطبع("، ")
            اطبع(ص)
            اطبع(")")
        نهاية
نهاية

دالة رئيسية() رقم
    متغير ن1 = نقطة(3.0، 4.0)
    متغير ن2 = نقطة(1.0، 2.0)
    
    اطبع("النقطة الأولى: ")
    ن1.اطبع()
    
    اطبع("النقطة الثانية: ")
    ن2.اطبع()
    
    # جمع النقطتين
    متغير مجموع = ن1 + ن2
    اطبع("مجموع النقطتين: ")
    مجموع.اطبع()  # (4، 6)
    
    # تكبير النقطة
    متغير مكبرة = ن1 * 2.0
    اطبع("النقطة مكبرة ×2: ")
    مكبرة.اطبع()  # (6، 8)
    
    # المسافة
    اطبع("مسافة النقطة الأولى من الأصل: ")
    اطبع(ن1.المسافة())  # 5.0
    
    ارجع 0
نهاية
```

## أمثلة متوسطة المستوى

### مثال 3: صنف العدد المركب

```س
صنف عدد_مركب
    خاص:
        عشري الحقيقي
        عشري التخيلي
    
    عام:
        دالة منشئ(عشري حقيقي، عشري تخيلي)
            الحقيقي = حقيقي
            التخيلي = تخيلي
        نهاية
        
        # الجمع: (أ + بi) + (ج + دi) = (أ+ج) + (ب+د)i
        عامل +(عدد_مركب آخر) عدد_مركب
            ارجع عدد_مركب(
                الحقيقي + آخر.الحقيقي،
                التخيلي + آخر.التخيلي
            )
        نهاية
        
        # الطرح
        عامل -(عدد_مركب آخر) عدد_مركب
            ارجع عدد_مركب(
                الحقيقي - آخر.الحقيقي،
                التخيلي - آخر.التخيلي
            )
        نهاية
        
        # الضرب: (أ + بi)(ج + دi) = (أج - بد) + (أد + بج)i
        عامل *(عدد_مركب آخر) عدد_مركب
            متغير حقيقي_جديد = الحقيقي * آخر.الحقيقي - التخيلي * آخر.التخيلي
            متغير تخيلي_جديد = الحقيقي * آخر.التخيلي + التخيلي * آخر.الحقيقي
            ارجع عدد_مركب(حقيقي_جديد، تخيلي_جديد)
        نهاية
        
        # المساواة
        عامل ==(عدد_مركب آخر) منطقي
            ارجع الحقيقي == آخر.الحقيقي و التخيلي == آخر.التخيلي
        نهاية
        
        # القيمة المطلقة (المعيار)
        دالة المعيار() عشري
            ارجع جذر(الحقيقي * الحقيقي + التخيلي * التخيلي)
        نهاية
        
        # المرافق
        دالة المرافق() عدد_مركب
            ارجع عدد_مركب(الحقيقي، -التخيلي)
        نهاية
        
        # الطباعة
        دالة اطبع()
            اطبع(الحقيقي)
            إذا(التخيلي >= 0)
                اطبع(" + ")
                اطبع(التخيلي)
            وإلا
                اطبع(" - ")
                اطبع(-التخيلي)
            نهاية
            اطبع("i")
        نهاية
نهاية

دالة رئيسية() رقم
    متغير ع1 = عدد_مركب(3.0، 4.0)   # 3 + 4i
    متغير ع2 = عدد_مركب(1.0، -2.0)  # 1 - 2i
    
    اطبع("العدد الأول: ")
    ع1.اطبع()
    
    اطبع("العدد الثاني: ")
    ع2.اطبع()
    
    متغير مجموع = ع1 + ع2
    اطبع("المجموع: ")
    مجموع.اطبع()  # 4 + 2i
    
    متغير حاصل_الضرب = ع1 * ع2
    اطبع("حاصل الضرب: ")
    حاصل_الضرب.اطبع()  # 11 - 2i
    
    اطبع("معيار العدد الأول: ")
    اطبع(ع1.المعيار())  # 5.0
    
    ارجع 0
نهاية
```

### مثال 4: صنف المصفوفة

```س
صنف مصفوفة
    خاص:
        رقم[][] البيانات
        رقم الصفوف
        رقم الأعمدة
    
    عام:
        دالة منشئ(رقم صفوف، رقم أعمدة)
            الصفوف = صفوف
            الأعمدة = أعمدة
            البيانات = رقم[صفوف][أعمدة]
            
            # تهيئة بأصفار
            متغير ص = 0
            طالما(ص < صفوف)
                متغير ع = 0
                طالما(ع < أعمدة)
                    البيانات[ص][ع] = 0
                    ع = ع + 1
                نهاية
                ص = ص + 1
            نهاية
        نهاية
        
        # تعيين قيمة
        دالة عيّن(رقم صف، رقم عمود، رقم قيمة)
            إذا(صف >= 0 و صف < الصفوف و عمود >= 0 و عمود < الأعمدة)
                البيانات[صف][عمود] = قيمة
            وإلا
                اطبع("خطأ: فهرس خارج الحدود!")
            نهاية
        نهاية
        
        # الحصول على قيمة
        دالة احصل(رقم صف، رقم عمود) رقم
            إذا(صف >= 0 و صف < الصفوف و عمود >= 0 و عمود < الأعمدة)
                ارجع البيانات[صف][عمود]
            نهاية
            اطبع("خطأ: فهرس خارج الحدود!")
            ارجع 0
        نهاية
        
        # جمع مصفوفتين
        عامل +(مصفوفة أخرى) مصفوفة
            إذا(الصفوف != أخرى.الصفوف أو الأعمدة != أخرى.الأعمدة)
                اطبع("خطأ: أبعاد المصفوفتين غير متطابقة!")
                ارجع مصفوفة(0، 0)
            نهاية
            
            متغير نتيجة = مصفوفة(الصفوف، الأعمدة)
            
            متغير ص = 0
            طالما(ص < الصفوف)
                متغير ع = 0
                طالما(ع < الأعمدة)
                    نتيجة.البيانات[ص][ع] = البيانات[ص][ع] + أخرى.البيانات[ص][ع]
                    ع = ع + 1
                نهاية
                ص = ص + 1
            نهاية
            
            ارجع نتيجة
        نهاية
        
        # ضرب مصفوفتين
        عامل *(مصفوفة أخرى) مصفوفة
            إذا(الأعمدة != أخرى.الصفوف)
                اطبع("خطأ: لا يمكن ضرب المصفوفتين!")
                ارجع مصفوفة(0، 0)
            نهاية
            
            متغير نتيجة = مصفوفة(الصفوف، أخرى.الأعمدة)
            
            متغير ص = 0
            طالما(ص < الصفوف)
                متغير ع = 0
                طالما(ع < أخرى.الأعمدة)
                    متغير مجموع = 0
                    متغير ك = 0
                    طالما(ك < الأعمدة)
                        مجموع = مجموع + البيانات[ص][ك] * أخرى.البيانات[ك][ع]
                        ك = ك + 1
                    نهاية
                    نتيجة.البيانات[ص][ع] = مجموع
                    ع = ع + 1
                نهاية
                ص = ص + 1
            نهاية
            
            ارجع نتيجة
        نهاية
        
        # المساواة
        عامل ==(مصفوفة أخرى) منطقي
            إذا(الصفوف != أخرى.الصفوف أو الأعمدة != أخرى.الأعمدة)
                ارجع خطأ
            نهاية
            
            متغير ص = 0
            طالما(ص < الصفوف)
                متغير ع = 0
                طالما(ع < الأعمدة)
                    إذا(البيانات[ص][ع] != أخرى.البيانات[ص][ع])
                        ارجع خطأ
                    نهاية
                    ع = ع + 1
                نهاية
                ص = ص + 1
            نهاية
            
            ارجع صحيح
        نهاية
        
        # الطباعة
        دالة اطبع()
            متغير ص = 0
            طالما(ص < الصفوف)
                اطبع("| ")
                متغير ع = 0
                طالما(ع < الأعمدة)
                    اطبع(البيانات[ص][ع])
                    اطبع(" ")
                    ع = ع + 1
                نهاية
                اطبع("|")
                ص = ص + 1
            نهاية
        نهاية
نهاية

دالة رئيسية() رقم
    # إنشاء مصفوفتين 2×2
    متغير م1 = مصفوفة(2، 2)
    م1.عيّن(0، 0، 1)
    م1.عيّن(0، 1، 2)
    م1.عيّن(1، 0، 3)
    م1.عيّن(1، 1، 4)
    
    متغير م2 = مصفوفة(2، 2)
    م2.عيّن(0، 0، 5)
    م2.عيّن(0، 1، 6)
    م2.عيّن(1، 0، 7)
    م2.عيّن(1، 1، 8)
    
    اطبع("المصفوفة الأولى:")
    م1.اطبع()
    
    اطبع("المصفوفة الثانية:")
    م2.اطبع()
    
    # الجمع
    متغير مجموع = م1 + م2
    اطبع("مجموع المصفوفتين:")
    مجموع.اطبع()
    
    # الضرب
    متغير حاصل_الضرب = م1 * م2
    اطبع("حاصل ضرب المصفوفتين:")
    حاصل_الضرب.اطبع()
    
    ارجع 0
نهاية
```

## نصائح وأفضل الممارسات

### 1. حافظ على التناسق الرياضي

عند تحميل العوامل، تأكد أن سلوكها يتوافق مع التوقعات الرياضية:

```س
# إذا حمّلت + و -، تأكد أن:
# (أ + ب) - ب == أ

# إذا حمّلت == تأكد أنها:
# - انعكاسية: أ == أ (دائماً صحيح)
# - تماثلية: أ == ب يعني ب == أ
# - متعدية: إذا أ == ب و ب == ج فإن أ == ج
```

### 2. لا تُبالغ في التحميل

```س
# غير جيد - معنى غير واضح
عامل +(مستخدم آخر) مستخدم  # ماذا يعني جمع مستخدمين؟!

# جيد - معنى واضح
عامل +(نقطة أخرى) نقطة  # جمع المتجهات
عامل +(كسر آخر) كسر       # جمع الكسور
```

### 3. أرجع نوعاً مناسباً

```س
# عامل حسابي يُرجع نفس النوع
عامل +(كسر آخر) كسر  # صحيح

# عامل مقارنة يُرجع منطقي
عامل ==(كسر آخر) منطقي  # صحيح
```

### 4. تعامل مع الحالات الخاصة

```س
عامل /(كسر آخر) كسر
    # تحقق من القسمة على صفر
    إذا(آخر.البسط == 0)
        اطبع("خطأ: القسمة على صفر!")
        ارجع كسر(0، 1)
    نهاية
    ارجع كسر(البسط * آخر.المقام، المقام * آخر.البسط)
نهاية
```

## الأخطاء الشائعة

### 1. تعديل الكائن الأصلي

```س
# خطأ - يُعدّل الكائن الأصلي
عامل +(كسر آخر) كسر
    البسط = البسط + آخر.البسط  # خطأ!
    ارجع هذا
نهاية

# صحيح - يُنشئ كائناً جديداً
عامل +(كسر آخر) كسر
    ارجع كسر(البسط + آخر.البسط، المقام)  # صحيح
نهاية
```

### 2. نسيان التحقق من الصلاحية

```س
# خطأ - بدون تحقق
عامل *(مصفوفة أخرى) مصفوفة
    # قد يفشل إذا الأبعاد غير متوافقة!
نهاية

# صحيح - مع تحقق
عامل *(مصفوفة أخرى) مصفوفة
    إذا(الأعمدة != أخرى.الصفوف)
        اطبع("خطأ!")
        ارجع مصفوفة(0، 0)
    نهاية
    # ...
نهاية
```

## ملخص

تحميل العوامل الزائد يُتيح لك:

- كتابة كود أكثر قراءة وطبيعية
- استخدام العوامل المألوفة مع أصنافك
- جعل الأصناف تتصرف كالأنواع الأساسية

استخدم هذه الميزة بحكمة - فقط عندما يكون المعنى واضحاً ومتوقعاً!
