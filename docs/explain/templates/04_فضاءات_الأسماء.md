# فضاءات الأسماء في لغة ص

## ما هي فضاءات الأسماء؟

فضاء الأسماء (Namespace) هو آلية لتنظيم الكود ومنع تعارض الأسماء. تخيل أنك تعمل في مشروع كبير مع فريق من المبرمجين، وكل واحد منكم أنشأ دالة اسمها `حساب`. بدون فضاءات الأسماء، سيحدث تعارض! لكن مع فضاءات الأسماء، يمكن لكل مبرمج وضع دالته في فضاء منفصل: `رياضيات::حساب`، `مالية::حساب`، `إحصاء::حساب`.

فكر في فضاءات الأسماء كالمجلدات على جهازك. يمكنك إنشاء ملفين بنفس الاسم طالما في مجلدات مختلفة. بنفس الطريقة، يمكنك إنشاء دالتين أو صنفين بنفس الاسم طالما في فضاءات أسماء مختلفة.

## الصيغة الأساسية

```س
فضاء اسم_الفضاء
    # الدوال والأصناف والمتغيرات هنا
نهاية_فضاء
```

### مثال بسيط

```س
فضاء رياضيات
    دالة جمع(رقم أ، رقم ب) رقم
        ارجع أ + ب
    نهاية
    
    دالة طرح(رقم أ، رقم ب) رقم
        ارجع أ - ب
    نهاية
    
    دالة ضرب(رقم أ، رقم ب) رقم
        ارجع أ * ب
    نهاية
    
    دالة قسمة(رقم أ، رقم ب) رقم
        إذا(ب == 0)
            اطبع("خطأ: القسمة على صفر!")
            ارجع 0
        نهاية
        ارجع أ / ب
    نهاية
نهاية_فضاء

دالة رئيسية() رقم
    # استخدام الدوال من فضاء الرياضيات
    متغير نتيجة = رياضيات::جمع(10، 20)
    اطبع("10 + 20 = ")
    اطبع(نتيجة)
    
    نتيجة = رياضيات::ضرب(5، 4)
    اطبع("5 × 4 = ")
    اطبع(نتيجة)
    
    ارجع 0
نهاية
```

لاحظ استخدام `::` للوصول للعناصر داخل فضاء الأسماء. هذا يُسمى "معامل دقة النطاق" (Scope Resolution Operator).

## لماذا نحتاج فضاءات الأسماء؟

### 1. منع تعارض الأسماء

بدون فضاءات الأسماء:

```س
# ملف 1: دوال الرياضيات
دالة حساب(رقم س) رقم
    ارجع س * س  # تربيع
نهاية

# ملف 2: دوال المالية
دالة حساب(رقم س) رقم  # خطأ! تعارض الأسماء
    ارجع س * 1.15  # إضافة ضريبة
نهاية
```

مع فضاءات الأسماء:

```س
فضاء رياضيات
    دالة حساب(رقم س) رقم
        ارجع س * س
    نهاية
نهاية_فضاء

فضاء مالية
    دالة حساب(رقم س) رقم
        ارجع س * 1.15
    نهاية
نهاية_فضاء

دالة رئيسية() رقم
    اطبع(رياضيات::حساب(5))   # النتيجة: 25
    اطبع(مالية::حساب(100))   # النتيجة: 115
    ارجع 0
نهاية
```

### 2. تنظيم الكود

فضاءات الأسماء تُساعد في تنظيم الكود حسب الوظيفة:

```س
فضاء واجهة_المستخدم
    دالة رسم_زر(نص نص_الزر)
        # كود رسم الزر
    نهاية
    
    دالة رسم_نافذة(نص عنوان)
        # كود رسم النافذة
    نهاية
نهاية_فضاء

فضاء قاعدة_البيانات
    دالة اتصل(نص عنوان)
        # كود الاتصال
    نهاية
    
    دالة استعلم(نص استعلام)
        # كود الاستعلام
    نهاية
نهاية_فضاء

فضاء منطق_الأعمال
    دالة سجّل_مستخدم(نص اسم، نص بريد)
        # كود التسجيل
    نهاية
    
    دالة تحقق_من_كلمة_المرور(نص كلمة_مرور)
        # كود التحقق
    نهاية
نهاية_فضاء
```

### 3. إعادة استخدام المكتبات

عندما تستورد مكتبات خارجية، فضاءات الأسماء تمنع تعارضها مع كودك:

```س
# مكتبة الرسوميات الخارجية
فضاء رسوميات
    دالة رسم(...)
    دالة امسح(...)
نهاية_فضاء

# مكتبة الملفات الخارجية
فضاء ملفات
    دالة اقرأ(...)
    دالة اكتب(...)
نهاية_فضاء

# كودك الخاص
دالة رسم(...)  # لا تعارض!
دالة اقرأ(...)  # لا تعارض!
```

## فضاءات الأسماء المتداخلة

يمكنك إنشاء فضاءات أسماء داخل فضاءات أخرى:

```س
فضاء تطبيق
    فضاء نماذج
        صنف مستخدم
            خاص:
                نص الاسم
                نص البريد
            
            عام:
                دالة منشئ(نص اسم، نص بريد)
                    الاسم = اسم
                    البريد = بريد
                نهاية
                
                دالة احصل_الاسم() نص
                    ارجع الاسم
                نهاية
        نهاية
        
        صنف منتج
            خاص:
                نص الاسم
                عشري السعر
            
            عام:
                دالة منشئ(نص اسم، عشري سعر)
                    الاسم = اسم
                    السعر = سعر
                نهاية
        نهاية
    نهاية_فضاء
    
    فضاء خدمات
        دالة سجّل_مستخدم(نماذج::مستخدم م)
            # كود التسجيل
        نهاية
        
        دالة اشتري_منتج(نماذج::منتج م)
            # كود الشراء
        نهاية
    نهاية_فضاء
نهاية_فضاء

دالة رئيسية() رقم
    # الوصول للعناصر المتداخلة
    متغير مستخدم = تطبيق::نماذج::مستخدم("أحمد"، "ahmed@email.com")
    تطبيق::خدمات::سجّل_مستخدم(مستخدم)
    
    ارجع 0
نهاية
```

## أمثلة عملية شاملة

### مثال 1: مكتبة رياضيات متكاملة

```س
فضاء رياضيات
    # الثوابت
    ثابت عشري باي = 3.14159265359
    ثابت عشري هـ = 2.71828182845
    
    # العمليات الأساسية
    فضاء أساسي
        دالة القيمة_المطلقة(رقم س) رقم
            إذا(س < 0)
                ارجع -س
            نهاية
            ارجع س
        نهاية
        
        دالة الأكبر(رقم أ، رقم ب) رقم
            إذا(أ > ب)
                ارجع أ
            نهاية
            ارجع ب
        نهاية
        
        دالة الأصغر(رقم أ، رقم ب) رقم
            إذا(أ < ب)
                ارجع أ
            نهاية
            ارجع ب
        نهاية
        
        دالة القوة(رقم قاعدة، رقم أس) رقم
            إذا(أس == 0)
                ارجع 1
            نهاية
            
            متغير نتيجة = 1
            متغير ع = 0
            طالما(ع < أس)
                نتيجة = نتيجة * قاعدة
                ع = ع + 1
            نهاية
            ارجع نتيجة
        نهاية
    نهاية_فضاء
    
    # الهندسة
    فضاء هندسة
        دالة مساحة_مربع(عشري ضلع) عشري
            ارجع ضلع * ضلع
        نهاية
        
        دالة مساحة_مستطيل(عشري طول، عشري عرض) عشري
            ارجع طول * عرض
        نهاية
        
        دالة مساحة_دائرة(عشري نصف_قطر) عشري
            ارجع باي * نصف_قطر * نصف_قطر
        نهاية
        
        دالة محيط_دائرة(عشري نصف_قطر) عشري
            ارجع 2 * باي * نصف_قطر
        نهاية
        
        دالة مساحة_مثلث(عشري قاعدة، عشري ارتفاع) عشري
            ارجع 0.5 * قاعدة * ارتفاع
        نهاية
    نهاية_فضاء
    
    # الإحصاء
    فضاء إحصاء
        دالة المتوسط(رقم[] أرقام، رقم حجم) عشري
            متغير مجموع = 0
            متغير ع = 0
            طالما(ع < حجم)
                مجموع = مجموع + أرقام[ع]
                ع = ع + 1
            نهاية
            ارجع مجموع / حجم
        نهاية
        
        دالة المجموع(رقم[] أرقام، رقم حجم) رقم
            متغير مجموع = 0
            متغير ع = 0
            طالما(ع < حجم)
                مجموع = مجموع + أرقام[ع]
                ع = ع + 1
            نهاية
            ارجع مجموع
        نهاية
        
        دالة الأكبر_في_مصفوفة(رقم[] أرقام، رقم حجم) رقم
            متغير أكبر = أرقام[0]
            متغير ع = 1
            طالما(ع < حجم)
                إذا(أرقام[ع] > أكبر)
                    أكبر = أرقام[ع]
                نهاية
                ع = ع + 1
            نهاية
            ارجع أكبر
        نهاية
    نهاية_فضاء
نهاية_فضاء

دالة رئيسية() رقم
    # استخدام الثوابت
    اطبع("قيمة باي: ")
    اطبع(رياضيات::باي)
    
    # استخدام العمليات الأساسية
    اطبع("2 مرفوع للقوة 10: ")
    اطبع(رياضيات::أساسي::القوة(2، 10))
    
    # استخدام الهندسة
    اطبع("مساحة دائرة نصف قطرها 5: ")
    اطبع(رياضيات::هندسة::مساحة_دائرة(5.0))
    
    # استخدام الإحصاء
    متغير درجات = [85، 90، 78، 92، 88]
    اطبع("متوسط الدرجات: ")
    اطبع(رياضيات::إحصاء::المتوسط(درجات، 5))
    
    ارجع 0
نهاية
```

### مثال 2: نظام إدارة متجر

```س
فضاء متجر
    # نماذج البيانات
    فضاء نماذج
        صنف منتج
            عام:
                رقم المعرف
                نص الاسم
                عشري السعر
                رقم الكمية
                
                دالة منشئ(رقم معرف، نص اسم، عشري سعر، رقم كمية)
                    المعرف = معرف
                    الاسم = اسم
                    السعر = سعر
                    الكمية = كمية
                نهاية
                
                دالة متوفر() منطقي
                    ارجع الكمية > 0
                نهاية
                
                دالة اطبع()
                    اطبع("المنتج: ")
                    اطبع(الاسم)
                    اطبع(" - السعر: ")
                    اطبع(السعر)
                    اطبع(" - الكمية: ")
                    اطبع(الكمية)
                نهاية
        نهاية
        
        صنف طلب
            عام:
                رقم رقم_الطلب
                نص اسم_العميل
                منتج[] المنتجات
                رقم عدد_المنتجات
                عشري الإجمالي
                
                دالة منشئ(رقم رقم، نص عميل)
                    رقم_الطلب = رقم
                    اسم_العميل = عميل
                    عدد_المنتجات = 0
                    الإجمالي = 0.0
                نهاية
                
                دالة أضف_منتج(منتج م، رقم كمية)
                    # إضافة المنتج للطلب
                    الإجمالي = الإجمالي + (م.السعر * كمية)
                    عدد_المنتجات = عدد_المنتجات + 1
                نهاية
        نهاية
    نهاية_فضاء
    
    # خدمات المخزون
    فضاء مخزون
        دالة أضف_كمية(نماذج::منتج م، رقم كمية)
            م.الكمية = م.الكمية + كمية
            اطبع("تمت إضافة الكمية بنجاح")
        نهاية
        
        دالة اطرح_كمية(نماذج::منتج م، رقم كمية) منطقي
            إذا(م.الكمية >= كمية)
                م.الكمية = م.الكمية - كمية
                ارجع صحيح
            نهاية
            اطبع("خطأ: الكمية غير كافية!")
            ارجع خطأ
        نهاية
        
        دالة تحقق_من_التوفر(نماذج::منتج م) منطقي
            ارجع م.متوفر()
        نهاية
    نهاية_فضاء
    
    # خدمات الطلبات
    فضاء طلبات
        دالة أنشئ_طلب(رقم رقم_طلب، نص عميل) نماذج::طلب
            ارجع نماذج::طلب(رقم_طلب، عميل)
        نهاية
        
        دالة احسب_الإجمالي(نماذج::طلب ط) عشري
            ارجع ط.الإجمالي
        نهاية
        
        دالة طبّق_خصم(نماذج::طلب ط، عشري نسبة_الخصم) عشري
            متغير خصم = ط.الإجمالي * نسبة_الخصم / 100
            ارجع ط.الإجمالي - خصم
        نهاية
    نهاية_فضاء
    
    # التقارير
    فضاء تقارير
        دالة تقرير_منتج(نماذج::منتج م)
            اطبع("=== تقرير المنتج ===")
            م.اطبع()
            إذا(م.متوفر())
                اطبع("الحالة: متوفر")
            وإلا
                اطبع("الحالة: نفذ من المخزون")
            نهاية
        نهاية
        
        دالة تقرير_طلب(نماذج::طلب ط)
            اطبع("=== تقرير الطلب ===")
            اطبع("رقم الطلب: ")
            اطبع(ط.رقم_الطلب)
            اطبع("العميل: ")
            اطبع(ط.اسم_العميل)
            اطبع("الإجمالي: ")
            اطبع(ط.الإجمالي)
        نهاية
    نهاية_فضاء
نهاية_فضاء

دالة رئيسية() رقم
    # إنشاء منتجات
    متغير هاتف = متجر::نماذج::منتج(1، "هاتف ذكي"، 2500.0، 10)
    متغير سماعة = متجر::نماذج::منتج(2، "سماعة لاسلكية"، 350.0، 25)
    
    # طباعة تقرير المنتج
    متجر::تقارير::تقرير_منتج(هاتف)
    
    # إنشاء طلب
    متغير طلب1 = متجر::طلبات::أنشئ_طلب(1001، "أحمد")
    طلب1.أضف_منتج(هاتف، 1)
    طلب1.أضف_منتج(سماعة، 2)
    
    # طباعة تقرير الطلب
    متجر::تقارير::تقرير_طلب(طلب1)
    
    # تطبيق خصم
    متغير الإجمالي_بعد_الخصم = متجر::طلبات::طبّق_خصم(طلب1، 10)
    اطبع("الإجمالي بعد خصم 10%: ")
    اطبع(الإجمالي_بعد_الخصم)
    
    ارجع 0
نهاية
```

## أفضل الممارسات

### 1. اختر أسماء واضحة ومعبرة

```س
# غير جيد
فضاء ف
    دالة د()
    نهاية
نهاية_فضاء

# جيد
فضاء معالجة_البيانات
    دالة فلتر_البيانات()
    نهاية
نهاية_فضاء
```

### 2. نظّم حسب الوظيفة

```س
فضاء تطبيق
    فضاء نماذج     # كل الكائنات والبيانات
    فضاء خدمات     # منطق الأعمال
    فضاء أدوات     # الدوال المساعدة
    فضاء واجهات    # واجهات المستخدم
نهاية_فضاء
```

### 3. تجنب التداخل العميق جداً

```س
# تجنب هذا
فضاء أ
    فضاء ب
        فضاء ج
            فضاء د
                # عميق جداً!
            نهاية_فضاء
        نهاية_فضاء
    نهاية_فضاء
نهاية_فضاء

# أفضل - تقسيم منطقي
فضاء الوحدة_أ
    # ...
نهاية_فضاء

فضاء الوحدة_ب
    # ...
نهاية_فضاء
```

## ملخص

فضاءات الأسماء في لغة ص تُقدم لك:

- تنظيم أفضل للكود
- منع تعارض الأسماء
- إمكانية إعادة استخدام المكتبات
- هيكلة واضحة للمشاريع الكبيرة

استخدم فضاءات الأسماء منذ البداية في مشاريعك، حتى لو كانت صغيرة. هذا سيُسهّل توسيعها لاحقاً!
