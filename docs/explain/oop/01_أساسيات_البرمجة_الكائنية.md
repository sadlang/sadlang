# 🔰 أساسيات البرمجة الكائنية في لغة ص

## مقدمة

البرمجة الكائنية (Object-Oriented Programming - OOP) هي نمط برمجي يعتمد على مفهوم "الكائنات" التي تجمع بين البيانات والسلوكيات. في لغة ص، تُعد البرمجة الكائنية أساساً قوياً لبناء برامج منظمة وقابلة للصيانة والتوسعة.

## المفاهيم الأساسية

### ما هو الصنف؟

الصنف (Class) هو قالب أو مخطط يُعرِّف خصائص وسلوكيات نوع معين من الكائنات. فكر فيه كـ"وصفة" لإنشاء كائنات.

```s
# تعريف صنف بسيط
صنف سيارة
    # الخصائص (البيانات)
    نص الماركة
    نص الموديل
    رقم السنة
    نص اللون
نهاية
```

### ما هو الكائن؟

الكائن (Object) هو نسخة فعلية من الصنف. عندما تُنشئ كائناً من صنف، تحصل على كيان له خصائصه الخاصة.

```s
دالة رئيسية()
    # إنشاء كائن من صنف سيارة
    متغير سيارتي = جديد سيارة()
    
    # تعيين قيم للخصائص
    سيارتي.الماركة = "تويوتا"
    سيارتي.الموديل = "كامري"
    سيارتي.السنة = 2023
    سيارتي.اللون = "أبيض"
    
    اطبع(سيارتي.الماركة + " " + سيارتي.الموديل)
نهاية
```

## المنشئ (Constructor)

المنشئ هو دالة خاصة تُستدعى تلقائياً عند إنشاء كائن جديد. يُستخدم لتهيئة الخصائص.

```s
صنف سيارة
    نص الماركة
    نص الموديل
    رقم السنة
    نص اللون
    
    # المنشئ
    منشئ(نص ماركة، نص موديل، رقم سنة، نص لون = "أبيض")
        هذا.الماركة = ماركة
        هذا.الموديل = موديل
        هذا.السنة = سنة
        هذا.اللون = لون
    نهاية
نهاية

دالة رئيسية()
    # الآن نمرر القيم مباشرة عند الإنشاء
    متغير سيارتي = جديد سيارة("تويوتا"، "كامري"، 2023)
    متغير سيارة_أخرى = جديد سيارة("هوندا"، "أكورد"، 2022، "أسود")
    
    اطبع(سيارتي.اللون)      # أبيض (القيمة الافتراضية)
    اطبع(سيارة_أخرى.اللون)  # أسود
نهاية
```

## الدوال (Methods)

الدوال داخل الصنف تُعرِّف السلوكيات التي يمكن للكائن القيام بها.

```s
صنف سيارة
    نص الماركة
    نص الموديل
    رقم السنة
    رقم السرعة_الحالية = 0
    منطقي المحرك_يعمل = خطأ
    
    منشئ(نص ماركة، نص موديل، رقم سنة)
        هذا.الماركة = ماركة
        هذا.الموديل = موديل
        هذا.السنة = سنة
    نهاية
    
    # دالة لتشغيل المحرك
    دالة شغل_المحرك()
        إذا (!هذا.المحرك_يعمل)
            هذا.المحرك_يعمل = صحيح
            اطبع("🚗 المحرك يعمل الآن")
        وإلا
            اطبع("⚠️ المحرك يعمل بالفعل")
        نهاية
    نهاية
    
    # دالة لإيقاف المحرك
    دالة أوقف_المحرك()
        إذا (هذا.المحرك_يعمل)
            هذا.السرعة_الحالية = 0
            هذا.المحرك_يعمل = خطأ
            اطبع("🛑 تم إيقاف المحرك")
        وإلا
            اطبع("⚠️ المحرك متوقف بالفعل")
        نهاية
    نهاية
    
    # دالة للتسارع
    دالة تسارع(رقم مقدار)
        إذا (!هذا.المحرك_يعمل)
            اطبع("❌ يجب تشغيل المحرك أولاً")
            إرجاع
        نهاية
        
        هذا.السرعة_الحالية = هذا.السرعة_الحالية + مقدار
        إذا (هذا.السرعة_الحالية > 200)
            هذا.السرعة_الحالية = 200
            اطبع("⚠️ وصلت للسرعة القصوى")
        نهاية
        اطبع("🏎️ السرعة الحالية: " + هذا.السرعة_الحالية + " كم/س")
    نهاية
    
    # دالة للتباطؤ
    دالة تباطؤ(رقم مقدار)
        هذا.السرعة_الحالية = هذا.السرعة_الحالية - مقدار
        إذا (هذا.السرعة_الحالية < 0)
            هذا.السرعة_الحالية = 0
        نهاية
        اطبع("🐢 السرعة الحالية: " + هذا.السرعة_الحالية + " كم/س")
    نهاية
    
    # دالة لعرض معلومات السيارة
    دالة معلومات()
        اطبع("═══════════════════════")
        اطبع("السيارة: " + هذا.الماركة + " " + هذا.الموديل)
        اطبع("السنة: " + هذا.السنة)
        اطبع("المحرك: " + (هذا.المحرك_يعمل ? "يعمل" : "متوقف"))
        اطبع("السرعة: " + هذا.السرعة_الحالية + " كم/س")
        اطبع("═══════════════════════")
    نهاية
نهاية

دالة رئيسية()
    متغير سيارتي = جديد سيارة("تويوتا"، "كامري"، 2023)
    
    سيارتي.معلومات()
    سيارتي.تسارع(50)     # لن يعمل - المحرك متوقف
    سيارتي.شغل_المحرك()
    سيارتي.تسارع(50)
    سيارتي.تسارع(30)
    سيارتي.تباطؤ(20)
    سيارتي.معلومات()
    سيارتي.أوقف_المحرك()
نهاية
```

## الكلمة المفتاحية `هذا`

`هذا` (this) تشير إلى الكائن الحالي. تُستخدم للوصول إلى خصائص ودوال الكائن من داخل الصنف.

```s
صنف شخص
    نص الاسم
    رقم العمر
    
    منشئ(نص الاسم، رقم العمر)
        # هذا.الاسم تشير لخاصية الكائن
        # الاسم بدون "هذا." تشير للمعامل
        هذا.الاسم = الاسم
        هذا.العمر = العمر
    نهاية
    
    دالة عرف_عن_نفسك()
        # استخدام هذا للوصول للخصائص
        اطبع("أنا " + هذا.الاسم + " وعمري " + هذا.العمر + " سنة")
    نهاية
    
    دالة احتفل_بعيد_ميلاد()
        هذا.العمر = هذا.العمر + 1
        اطبع("🎂 عيد ميلاد سعيد! أصبح عمري " + هذا.العمر)
    نهاية
نهاية
```

## خصائص بقيم افتراضية

```s
صنف حساب_بنكي
    نص رقم_الحساب
    نص اسم_المالك
    رقم الرصيد = 0  # قيمة افتراضية
    منطقي نشط = صحيح
    قائمة العمليات = []
    
    منشئ(نص رقم، نص اسم، رقم رصيد_ابتدائي = 0)
        هذا.رقم_الحساب = رقم
        هذا.اسم_المالك = اسم
        هذا.الرصيد = رصيد_ابتدائي
        
        إذا (رصيد_ابتدائي > 0)
            هذا.سجل_عملية("إيداع ابتدائي"، رصيد_ابتدائي)
        نهاية
    نهاية
    
    دالة سجل_عملية(نص نوع، رقم مبلغ)
        هذا.العمليات.أضف({
            "نوع": نوع،
            "مبلغ": مبلغ،
            "التاريخ": تاريخ_اليوم()،
            "الرصيد_بعدها": هذا.الرصيد
        })
    نهاية
    
    دالة إيداع(رقم مبلغ)
        إذا (مبلغ <= 0)
            اطبع("❌ المبلغ يجب أن يكون موجباً")
            إرجاع خطأ
        نهاية
        
        هذا.الرصيد = هذا.الرصيد + مبلغ
        هذا.سجل_عملية("إيداع"، مبلغ)
        اطبع("✅ تم إيداع " + مبلغ + " ريال")
        اطبع("💰 الرصيد الحالي: " + هذا.الرصيد + " ريال")
        إرجاع صحيح
    نهاية
    
    دالة سحب(رقم مبلغ)
        إذا (مبلغ <= 0)
            اطبع("❌ المبلغ يجب أن يكون موجباً")
            إرجاع خطأ
        نهاية
        
        إذا (مبلغ > هذا.الرصيد)
            اطبع("❌ الرصيد غير كافٍ")
            إرجاع خطأ
        نهاية
        
        هذا.الرصيد = هذا.الرصيد - مبلغ
        هذا.سجل_عملية("سحب"، مبلغ)
        اطبع("✅ تم سحب " + مبلغ + " ريال")
        اطبع("💰 الرصيد الحالي: " + هذا.الرصيد + " ريال")
        إرجاع صحيح
    نهاية
    
    دالة كشف_حساب()
        اطبع("═════════════════════════════════")
        اطبع("كشف حساب: " + هذا.رقم_الحساب)
        اطبع("المالك: " + هذا.اسم_المالك)
        اطبع("═════════════════════════════════")
        
        لكل عملية في هذا.العمليات
            اطبع(عملية.التاريخ + " | " + عملية.نوع + " | " + عملية.مبلغ + " ريال")
        نهاية
        
        اطبع("═════════════════════════════════")
        اطبع("الرصيد الحالي: " + هذا.الرصيد + " ريال")
        اطبع("═════════════════════════════════")
    نهاية
نهاية

دالة رئيسية()
    متغير حسابي = جديد حساب_بنكي("SA001"، "أحمد محمد"، 1000)
    
    حسابي.إيداع(500)
    حسابي.سحب(200)
    حسابي.سحب(2000)  # لن ينجح
    حسابي.إيداع(1000)
    حسابي.كشف_حساب()
نهاية
```

## الدوال التي تُرجع قيماً

```s
صنف مستطيل
    رقم الطول
    رقم العرض
    
    منشئ(رقم طول، رقم عرض)
        هذا.الطول = طول
        هذا.العرض = عرض
    نهاية
    
    دالة المساحة()
        إرجاع هذا.الطول * هذا.العرض
    نهاية
    
    دالة المحيط()
        إرجاع 2 * (هذا.الطول + هذا.العرض)
    نهاية
    
    دالة هل_مربع()
        إرجاع هذا.الطول == هذا.العرض
    نهاية
    
    دالة القطر()
        إرجاع جذر(هذا.الطول ** 2 + هذا.العرض ** 2)
    نهاية
نهاية

دالة رئيسية()
    متغير م = جديد مستطيل(5، 3)
    
    اطبع("المساحة: " + م.المساحة())   # 15
    اطبع("المحيط: " + م.المحيط())     # 16
    اطبع("هل مربع؟ " + م.هل_مربع())  # خطأ
    اطبع("القطر: " + م.القطر())       # 5.83
    
    متغير مربع = جديد مستطيل(4، 4)
    اطبع("هل مربع؟ " + مربع.هل_مربع())  # صحيح
نهاية
```

## إنشاء كائنات متعددة

```s
صنف طالب
    نص الاسم
    رقم الرقم_الجامعي
    قائمة الدرجات = []
    
    منشئ(نص اسم، رقم رقم)
        هذا.الاسم = اسم
        هذا.الرقم_الجامعي = رقم
    نهاية
    
    دالة أضف_درجة(رقم درجة)
        هذا.الدرجات.أضف(درجة)
    نهاية
    
    دالة المعدل()
        إذا (طول(هذا.الدرجات) == 0)
            إرجاع 0
        نهاية
        إرجاع مجموع(هذا.الدرجات) / طول(هذا.الدرجات)
    نهاية
نهاية

دالة رئيسية()
    # إنشاء عدة طلاب
    قائمة الطلاب = [
        جديد طالب("أحمد"، 1001)،
        جديد طالب("محمد"، 1002)،
        جديد طالب("سارة"، 1003)
    ]
    
    # إضافة درجات لكل طالب
    الطلاب[0].أضف_درجة(85)
    الطلاب[0].أضف_درجة(90)
    الطلاب[1].أضف_درجة(78)
    الطلاب[1].أضف_درجة(82)
    الطلاب[2].أضف_درجة(95)
    الطلاب[2].أضف_درجة(98)
    
    # عرض معدلات الطلاب
    لكل طالب في الطلاب
        اطبع(طالب.الاسم + ": " + طالب.المعدل())
    نهاية
نهاية
```

## الخصائص المحسوبة (Computed Properties)

```s
صنف شخص
    نص الاسم_الأول
    نص اسم_العائلة
    رقم سنة_الميلاد
    
    منشئ(نص أول، نص عائلة، رقم سنة)
        هذا.الاسم_الأول = أول
        هذا.اسم_العائلة = عائلة
        هذا.سنة_الميلاد = سنة
    نهاية
    
    # خاصية محسوبة - الاسم الكامل
    دالة الاسم_الكامل()
        إرجاع هذا.الاسم_الأول + " " + هذا.اسم_العائلة
    نهاية
    
    # خاصية محسوبة - العمر
    دالة العمر()
        إرجاع السنة_الحالية() - هذا.سنة_الميلاد
    نهاية
    
    # خاصية محسوبة - هل بالغ
    دالة هل_بالغ()
        إرجاع هذا.العمر() >= 18
    نهاية
نهاية

دالة رئيسية()
    متغير شخص = جديد شخص("أحمد"، "محمد"، 2000)
    
    اطبع(شخص.الاسم_الكامل())  # أحمد محمد
    اطبع(شخص.العمر())         # يعتمد على السنة الحالية
    اطبع(شخص.هل_بالغ())       # صحيح
نهاية
```

## الخلاصة

أساسيات البرمجة الكائنية في لغة ص:
- **الصنف**: قالب يعرف الخصائص والدوال
- **الكائن**: نسخة من الصنف بقيمها الخاصة
- **المنشئ**: يُهيئ الكائن عند إنشائه
- **هذا**: للوصول لخصائص ودوال الكائن الحالي
- **الدوال**: تُعرِّف سلوكيات الكائن
- **الخصائص**: تُخزِّن بيانات الكائن
