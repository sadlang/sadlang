# الكائنات في لغة ص - الدليل الشامل

## ما هو الكائن؟

الكائن (Object) هو نسخة حية من الصنف. إذا كان الصنف هو المخطط أو القالب، فإن الكائن هو الشيء الفعلي الذي يُنشأ من هذا المخطط. كل كائن يمتلك قيمه الخاصة للحقول المُعرّفة في الصنف، ويستطيع استدعاء الدوال المُعرّفة فيه.

لفهم الفرق بشكل أوضح، تخيّل أن لديك صنف `سيارة` يُعرّف خصائص السيارات بشكل عام (اللون، الموديل، السرعة). عندما تُنشئ كائناً من هذا الصنف، فأنت تُنشئ سيارة محددة بلون معين وموديل معين وسرعة معينة.

## إنشاء الكائنات في لغة ص

لإنشاء كائن في لغة ص، نستخدم الكلمة المفتاحية `جديد` متبوعة باسم الصنف والقوسين. الصيغة العامة:

```
اسم_الصنف اسم_الكائن = جديد اسم_الصنف()
```

أو إذا كان للصنف باني يأخذ معاملات:

```
اسم_الصنف اسم_الكائن = جديد اسم_الصنف(المعاملات)
```

### مثال بسيط

```
صنف نقطة
    رقم س
    رقم ص
نهاية

دالة رئيسية()
    # إنشاء كائن من الصنف نقطة
    نقطة ن = جديد نقطة()
    
    # تعيين قيم للحقول
    ن.س = 10
    ن.ص = 20
    
    # قراءة قيم الحقول
    اطبع_سطر("الإحداثي س: " + ن.س)
    اطبع_سطر("الإحداثي ص: " + ن.ص)
    
    ارجع 0
نهاية
```

## إنشاء كائنات متعددة

يمكنك إنشاء عدد غير محدود من الكائنات من نفس الصنف، وكل كائن يكون مستقلاً عن الآخرين:

```
صنف طالب
    نص الاسم
    رقم العمر
    عشري المعدل
    
    دالة عرض()
        اطبع_سطر("الاسم: " + الاسم + " | العمر: " + العمر + " | المعدل: " + المعدل)
    نهاية
نهاية

دالة رئيسية()
    # إنشاء ثلاثة كائنات مختلفة
    طالب ط1 = جديد طالب()
    طالب ط2 = جديد طالب()
    طالب ط3 = جديد طالب()
    
    # تعيين قيم مختلفة لكل كائن
    ط1.الاسم = "أحمد"
    ط1.العمر = 20
    ط1.المعدل = 3.8
    
    ط2.الاسم = "سارة"
    ط2.العمر = 21
    ط2.المعدل = 3.9
    
    ط3.الاسم = "محمد"
    ط3.العمر = 19
    ط3.المعدل = 3.5
    
    # كل كائن يحتفظ بقيمه الخاصة
    ط1.عرض()
    ط2.عرض()
    ط3.عرض()
    
    ارجع 0
نهاية
```

عند تشغيل هذا البرنامج، سيُطبع:
```
الاسم: أحمد | العمر: 20 | المعدل: 3.8
الاسم: سارة | العمر: 21 | المعدل: 3.9
الاسم: محمد | العمر: 19 | المعدل: 3.5
```

## استخدام الباني لتهيئة الكائنات

الطريقة المُثلى لإنشاء الكائنات هي استخدام الباني. الباني يُمكّنك من تعيين القيم الأولية للحقول في لحظة إنشاء الكائن:

```
صنف موظف
    نص الاسم
    نص القسم
    رقم الراتب
    
    باني(نص اسم، نص قسم، رقم راتب)
        الاسم = اسم
        القسم = قسم
        الراتب = راتب
    نهاية
    
    دالة عرض_البطاقة()
        اطبع_سطر("╔════════════════════════╗")
        اطبع_سطر("║   بطاقة موظف          ║")
        اطبع_سطر("╠════════════════════════╣")
        اطبع_سطر("║ الاسم: " + الاسم)
        اطبع_سطر("║ القسم: " + القسم)
        اطبع_سطر("║ الراتب: " + الراتب)
        اطبع_سطر("╚════════════════════════╝")
    نهاية
نهاية

دالة رئيسية()
    # إنشاء موظفين باستخدام الباني
    موظف م1 = جديد موظف("خالد العلي"، "تقنية المعلومات"، 15000)
    موظف م2 = جديد موظف("نورة السالم"، "الموارد البشرية"، 12000)
    
    م1.عرض_البطاقة()
    م2.عرض_البطاقة()
    
    ارجع 0
نهاية
```

## الوصول إلى أعضاء الكائن

للوصول إلى حقول أو دوال الكائن، نستخدم عامل النقطة (`.`):

```
# الوصول لحقل
اسم_الكائن.اسم_الحقل

# استدعاء دالة
اسم_الكائن.اسم_الدالة()
```

### مثال تفصيلي

```
صنف حساب_بنكي
    نص رقم_الحساب
    نص اسم_المالك
    عشري الرصيد
    
    باني(نص رقم، نص اسم)
        رقم_الحساب = رقم
        اسم_المالك = اسم
        الرصيد = 0.0
    نهاية
    
    دالة إيداع(عشري مبلغ)
        إذا مبلغ > 0
            الرصيد = الرصيد + مبلغ
            اطبع_سطر("تم إيداع " + مبلغ + " ريال")
            اطبع_سطر("الرصيد الحالي: " + الرصيد + " ريال")
        وإلا
            اطبع_سطر("خطأ: المبلغ يجب أن يكون موجباً")
        نهاية
    نهاية
    
    دالة سحب(عشري مبلغ)
        إذا مبلغ <= 0
            اطبع_سطر("خطأ: المبلغ يجب أن يكون موجباً")
        وإلا
            إذا مبلغ > الرصيد
                اطبع_سطر("خطأ: الرصيد غير كافٍ")
            وإلا
                الرصيد = الرصيد - مبلغ
                اطبع_سطر("تم سحب " + مبلغ + " ريال")
                اطبع_سطر("الرصيد الحالي: " + الرصيد + " ريال")
            نهاية
        نهاية
    نهاية
    
    دالة عشري استعلام_الرصيد()
        ارجع الرصيد
    نهاية
    
    دالة عرض_معلومات_الحساب()
        اطبع_سطر("═══════════════════════════")
        اطبع_سطر("رقم الحساب: " + رقم_الحساب)
        اطبع_سطر("اسم المالك: " + اسم_المالك)
        اطبع_سطر("الرصيد: " + الرصيد + " ريال")
        اطبع_سطر("═══════════════════════════")
    نهاية
نهاية

دالة رئيسية()
    # إنشاء حساب بنكي جديد
    حساب_بنكي حسابي = جديد حساب_بنكي("SA1234567890"، "محمد أحمد")
    
    # عرض معلومات الحساب
    حسابي.عرض_معلومات_الحساب()
    
    # إجراء عمليات على الحساب
    حسابي.إيداع(5000)
    حسابي.إيداع(3000)
    حسابي.سحب(2000)
    حسابي.سحب(10000)  # سيفشل - رصيد غير كاف
    
    # عرض المعلومات النهائية
    حسابي.عرض_معلومات_الحساب()
    
    ارجع 0
نهاية
```

## الكائنات كمعاملات للدوال

يمكن تمرير الكائنات كمعاملات للدوال، مما يُتيح إنشاء دوال تعمل مع أنواع البيانات المُخصصة:

```
صنف نقطة
    رقم س
    رقم ص
    
    باني(رقم إحداثي_س، رقم إحداثي_ص)
        س = إحداثي_س
        ص = إحداثي_ص
    نهاية
نهاية

# دالة تحسب المسافة بين نقطتين
دالة عشري حساب_المسافة(نقطة أ، نقطة ب)
    رقم فرق_س = ب.س - أ.س
    رقم فرق_ص = ب.ص - أ.ص
    ارجع جذر(فرق_س * فرق_س + فرق_ص * فرق_ص)
نهاية

# دالة تُنشئ نقطة في منتصف نقطتين
دالة نقطة نقطة_المنتصف(نقطة أ، نقطة ب)
    رقم س_جديد = (أ.س + ب.س) / 2
    رقم ص_جديد = (أ.ص + ب.ص) / 2
    ارجع جديد نقطة(س_جديد، ص_جديد)
نهاية

دالة رئيسية()
    نقطة ن1 = جديد نقطة(0، 0)
    نقطة ن2 = جديد نقطة(3، 4)
    
    عشري المسافة = حساب_المسافة(ن1، ن2)
    اطبع_سطر("المسافة بين النقطتين: " + المسافة)
    
    نقطة المنتصف = نقطة_المنتصف(ن1، ن2)
    اطبع_سطر("نقطة المنتصف: (" + المنتصف.س + "، " + المنتصف.ص + ")")
    
    ارجع 0
نهاية
```

## الكائنات داخل الكائنات (التركيب)

يمكن للكائن أن يحتوي على كائنات أخرى كحقول. هذا النمط يُسمى "التركيب" (Composition):

```
صنف عنوان
    نص الدولة
    نص المدينة
    نص الحي
    نص الشارع
    رقم رقم_المبنى
    
    باني(نص دولة، نص مدينة، نص حي، نص شارع، رقم رقم)
        الدولة = دولة
        المدينة = مدينة
        الحي = حي
        الشارع = شارع
        رقم_المبنى = رقم
    نهاية
    
    دالة نص صيغة_كاملة()
        ارجع رقم_المبنى + " " + الشارع + "، " + الحي + "، " + المدينة + "، " + الدولة
    نهاية
نهاية

صنف شخص
    نص الاسم
    رقم العمر
    نص البريد_الإلكتروني
    نص الهاتف
    عنوان عنوان_السكن
    
    باني(نص اسم، رقم عمر، عنوان عنوان)
        الاسم = اسم
        العمر = عمر
        عنوان_السكن = عنوان
        البريد_الإلكتروني = ""
        الهاتف = ""
    نهاية
    
    دالة تعيين_بريد(نص بريد)
        البريد_الإلكتروني = بريد
    نهاية
    
    دالة تعيين_هاتف(نص هاتف)
        الهاتف = هاتف
    نهاية
    
    دالة عرض_البطاقة()
        اطبع_سطر("╔══════════════════════════════════════╗")
        اطبع_سطر("║          البطاقة الشخصية             ║")
        اطبع_سطر("╠══════════════════════════════════════╣")
        اطبع_سطر("║ الاسم: " + الاسم)
        اطبع_سطر("║ العمر: " + العمر + " سنة")
        اطبع_سطر("║ البريد: " + البريد_الإلكتروني)
        اطبع_سطر("║ الهاتف: " + الهاتف)
        اطبع_سطر("║ العنوان: " + عنوان_السكن.صيغة_كاملة())
        اطبع_سطر("╚══════════════════════════════════════╝")
    نهاية
نهاية

دالة رئيسية()
    # إنشاء عنوان
    عنوان عنواني = جديد عنوان("السعودية"، "الرياض"، "النخيل"، "شارع الملك فهد"، 123)
    
    # إنشاء شخص مع العنوان
    شخص أنا = جديد شخص("عبدالله محمد"، 30، عنواني)
    أنا.تعيين_بريد("abdullah@example.com")
    أنا.تعيين_هاتف("0501234567")
    
    # عرض المعلومات
    أنا.عرض_البطاقة()
    
    ارجع 0
نهاية
```

## مثال متقدم: نظام إدارة المهام

```
صنف مهمة
    نص العنوان
    نص الوصف
    نص الحالة  # "قيد الانتظار"، "قيد التنفيذ"، "مكتملة"
    رقم الأولوية  # 1 = عالية، 2 = متوسطة، 3 = منخفضة
    
    باني(نص عنوان، نص وصف، رقم أولوية)
        العنوان = عنوان
        الوصف = وصف
        الأولوية = أولوية
        الحالة = "قيد الانتظار"
    نهاية
    
    دالة بدء()
        الحالة = "قيد التنفيذ"
        اطبع_سطر("بدأ العمل على: " + العنوان)
    نهاية
    
    دالة إكمال()
        الحالة = "مكتملة"
        اطبع_سطر("تم إكمال: " + العنوان)
    نهاية
    
    دالة منطقي مكتملة()
        ارجع الحالة == "مكتملة"
    نهاية
    
    دالة نص نص_الأولوية()
        إذا الأولوية == 1
            ارجع "عالية 🔴"
        نهاية
        إذا الأولوية == 2
            ارجع "متوسطة 🟡"
        نهاية
        ارجع "منخفضة 🟢"
    نهاية
    
    دالة عرض()
        اطبع_سطر("─────────────────────────")
        اطبع_سطر("المهمة: " + العنوان)
        اطبع_سطر("الوصف: " + الوصف)
        اطبع_سطر("الأولوية: " + نص_الأولوية())
        اطبع_سطر("الحالة: " + الحالة)
        اطبع_سطر("─────────────────────────")
    نهاية
نهاية

دالة رئيسية()
    # إنشاء قائمة مهام
    مهمة م1 = جديد مهمة("إنهاء التقرير"، "كتابة التقرير الشهري"، 1)
    مهمة م2 = جديد مهمة("اجتماع الفريق"، "حضور الاجتماع الأسبوعي"، 2)
    مهمة م3 = جديد مهمة("تنظيم الملفات"، "ترتيب المجلدات القديمة"، 3)
    
    # عرض جميع المهام
    اطبع_سطر("═══════════════════════════")
    اطبع_سطر("      قائمة المهام         ")
    اطبع_سطر("═══════════════════════════")
    
    م1.عرض()
    م2.عرض()
    م3.عرض()
    
    # العمل على المهام
    اطبع_سطر("\n=== بدء العمل ===\n")
    
    م1.بدء()
    م1.إكمال()
    
    م2.بدء()
    
    # عرض الحالة النهائية
    اطبع_سطر("\n=== الحالة النهائية ===\n")
    م1.عرض()
    م2.عرض()
    م3.عرض()
    
    ارجع 0
نهاية
```

## نصائح للعمل مع الكائنات

**تحقق من القيم قبل الاستخدام**: عند إنشاء كائنات أو تعديل حقولها، تحقق دائماً من صحة القيم.

**استخدم الباني لضمان التهيئة الصحيحة**: الباني يضمن أن الكائن يبدأ في حالة صالحة.

**لا تُفرط في إنشاء الكائنات**: إنشاء الكائنات يستهلك الذاكرة. أنشئ الكائنات التي تحتاجها فقط.

**استخدم أسماء ذات معنى**: `حسابي` أفضل من `ح`، و`قائمة_الطلاب` أفضل من `ق`.

## الخلاصة

الكائنات هي التجسيد الحي للأصناف. فهم كيفية إنشاء الكائنات واستخدامها هو المفتاح لكتابة برامج كائنية فعّالة. في الأقسام التالية، سنتعمق في الحقول والدوال والبناة بمزيد من التفصيل.
