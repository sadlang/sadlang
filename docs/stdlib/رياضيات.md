# وحدة رياضيات

دوال رياضية متقدمة وثوابت رياضية.

## الاستيراد
```sad
# استيراد كامل
استورد رياضيات

# استيراد بإسم مستعار
استورد رياضيات كـ ر

# استيراد انتقائي — الصيغة العربية
استورد جذر من رياضيات
استورد جذر، لوغاريتم من رياضيات

# استيراد انتقائي — الصيغة المعيارية
من رياضيات استورد جذر
من رياضيات استورد جذر، لوغاريتم

# استيراد شامل
استورد * من رياضيات
من رياضيات استورد *
```

## البدائل المقبولة للاسم
`math`, `mathematics`, `حساب`

---

## الدوال

### `لوغاريتم(س)`
اللوغاريتم الطبيعي (ln).
- **المعامل:** رقم موجب
- **تُرجع:** عشري

```sad
من رياضيات استورد لوغاريتم
اطبع_سطر(لوغاريتم(1))       # 0
اطبع_سطر(لوغاريتم(2.718))   # ~1.0
```

### `لوغاريتم10(س)`
اللوغاريتم العشري (log₁₀).

```sad
اطبع_سطر(رياضيات.لوغاريتم10(100))   # 2
اطبع_سطر(رياضيات.لوغاريتم10(1000))  # 3
```

### `لوغاريتم2(س)`
لوغاريتم للأساس 2 (مفيد للخوارزميات).

```sad
اطبع_سطر(رياضيات.لوغاريتم2(8))     # 3
اطبع_سطر(رياضيات.لوغاريتم2(1024))  # 10
```

### `أس(س)`
الدالة الأسية $e^x$.

```sad
اطبع_سطر(رياضيات.أس(0))    # 1
اطبع_سطر(رياضيات.أس(1))    # ~2.718
```

### `بتر(س)`
حذف الجزء العشري (truncate نحو الصفر).

```sad
اطبع_سطر(رياضيات.بتر(3.7))     # 3
اطبع_سطر(رياضيات.بتر(-3.7))    # -3
اطبع_سطر(رياضيات.بتر(0.99))    # 0
```

### `إشارة(س)`
إشارة الرقم.
- **تُرجع:** `-1` إذا سالب، `0` إذا صفر، `1` إذا موجب

```sad
اطبع_سطر(رياضيات.إشارة(-5))    # -1
اطبع_سطر(رياضيات.إشارة(0))     # 0
اطبع_سطر(رياضيات.إشارة(10))    # 1
```

### `حد_أقصى_أدنى(قيمة، أدنى، أقصى)`
تقييد القيمة بين حد أدنى وأقصى (clamp).

```sad
اطبع_سطر(رياضيات.حد_أقصى_أدنى(15، 0، 10))   # 10
اطبع_سطر(رياضيات.حد_أقصى_أدنى(-5، 0، 10))   # 0
اطبع_سطر(رياضيات.حد_أقصى_أدنى(5، 0، 10))    # 5
```

### `باقي(أ، ب)`
باقي القسمة (modulo).

```sad
اطبع_سطر(رياضيات.باقي(10، 3))   # 1
اطبع_سطر(رياضيات.باقي(7، 2))    # 1
```

## الثوابت

### `باي()`
النسبة الثابتة $\pi = 3.14159265358979...$

```sad
اطبع_سطر(رياضيات.باي())   # 3.14159265358979
```

### `ثابت_هـ()`
العدد $e = 2.71828182845905...$

```sad
اطبع_سطر(رياضيات.ثابت_هـ())   # 2.71828182845905
```

## الدوال الرياضية المضمنة (بدون استيراد)

هذه الدوال الأساسية متاحة تلقائياً بدون `استورد رياضيات`:

| الدالة | الوصف | مثال |
|---|---|---|
| `القيمة_المطلقة(س)` | القيمة المطلقة \|x\| | `القيمة_المطلقة(-5)` → `5` |
| `أكبر(أ، ب)` | أكبر قيمتين | `أكبر(3, 7)` → `7` |
| `أصغر(أ، ب)` | أصغر قيمتين | `أصغر(3, 7)` → `3` |
| `جمع(مصفوفة)` | مجموع عناصر مصفوفة | `جمع([1,2,3])` → `6` |
| `الجذر(س)` | الجذر التربيعي $\sqrt{x}$ | `الجذر(16)` → `4` |

## مثال عملي كامل

```sad
استورد رياضيات كـ ر

# حساب مساحة دائرة
دالة مساحة_دائرة(نصف_القطر)
    ارجع ر.باي() * نصف_القطر ** 2
نهاية

# حساب المسافة بين نقطتين
دالة مسافة(س1، ص1، س2، ص2)
    متغير فرق_س = (س2 - س1) ** 2
    متغير فرق_ص = (ص2 - ص1) ** 2
    ارجع الجذر(فرق_س + فرق_ص)
نهاية

اطبع_سطر("مساحة دائرة نصف قطرها 5: " + نص(مساحة_دائرة(5)))
اطبع_سطر("المسافة: " + نص(مسافة(0، 0، 3، 4)))
```
