# وحدة شبكة_عالية

طلبات HTTP واتصالات TCP عالية المستوى.

## الاستيراد
```sad
# استيراد كامل
استورد شبكة_عالية

# استيراد انتقائي — الصيغة العربية
استورد طلب_ويب من شبكة_عالية

# استيراد انتقائي — الصيغة المعيارية
من شبكة_عالية استورد طلب_ويب

# استيراد شامل
استورد * من شبكة_عالية
من شبكة_عالية استورد *
```

## البدائل المقبولة للاسم
`http`, `sockets_hl`, `اتصالات`

---

## دوال HTTP

### `طلب_ويب(رابط، طريقة؟)`
إرسال طلب HTTP. الطريقة الافتراضية GET.
- **المعاملات:** رابط (نص)، طريقة اختيارية ("GET", "POST", ...)
- **تُرجع:** نص الاستجابة

```sad
متغير استجابة = شبكة_عالية.طلب_ويب("https://api.example.com/data")
اطبع_سطر(استجابة)
```

---

## دوال TCP

### `اتصال_tcp(عنوان، منفذ)`
إنشاء اتصال TCP مع خادم.

```sad
متغير اتصال = شبكة_عالية.اتصال_tcp("127.0.0.1"، 8080)
```

---

## مثال عملي

```sad
من شبكة_عالية استورد *

# جلب بيانات من واجهة برمجية
متغير بيانات = طلب_ويب("https://api.example.com/users")
اطبع_سطر("البيانات: " + بيانات)
```
