# الدوال المضمنة — مرجع كامل

هذه الدوال والطرق متاحة تلقائياً بدون أي استيراد.

---

## 1. دوال الإخراج

### `اطبع(...)`
طباعة قيم بدون سطر جديد.
- **البدائل:** `print`, `إطبع`
- **المعاملات:** 1 أو أكثر

```sad
اطبع("مرحبا ")
اطبع("العالم!")    # مرحبا العالم!
```

### `اطبع_سطر(...)`
طباعة قيم مع سطر جديد في النهاية.
- **البدائل:** `println`, `طبع_سطر`
- **المعاملات:** 1 أو أكثر

```sad
اطبع_سطر("مرحبا بالعالم!")
اطبع_سطر(42)
اطبع_سطر("الاسم: " + اسم + " — العمر: " + عمر)
```

---

## 2. دوال الإدخال

### `اقرأ(رسالة؟)`
قراءة سطر من المستخدم. الرسالة اختيارية.
- **البدائل:** `input`, `أدخل`
- **تُرجع:** نص (string)

```sad
متغير الاسم = اقرأ("أدخل اسمك: ")
متغير العمر = رقم(اقرأ("أدخل عمرك: "))
```

---

## 3. دوال الطول والنوع

### `طول(قيمة)`
طول نص أو مصفوفة (يدعم Unicode).
- **البدائل:** `len`, `length`, `الطول`

```sad
اطبع_سطر(طول("مرحبا"))      # 5
اطبع_سطر(طول([1، 2، 3]))    # 3
```

### `نوع(قيمة)`
اسم نوع القيمة كنص.
- **البدائل:** `type`, `النوع`

```sad
اطبع_سطر(نوع(42))           # int
اطبع_سطر(نوع("نص"))         # string
اطبع_سطر(نوع([1, 2]))       # array
اطبع_سطر(نوع(صحيح))         # bool
```

---

## 4. دوال تحويل الأنواع

### `رقم(قيمة)`
تحويل نص أو عشري إلى رقم صحيح.
- **البدائل:** `int`, `لرقم`, `to_int`, `عدد`

```sad
متغير س = رقم("42")         # 42
متغير ع = رقم(3.7)          # 3
```

### `عشري(قيمة)`
تحويل نص أو رقم إلى عدد عشري.
- **البدائل:** `float`, `لعشري`, `to_float`

```sad
متغير ع = عشري("3.14")     # 3.14
```

### `نص(قيمة)`
تحويل أي قيمة إلى نص.
- **البدائل:** `str`, `لنص`, `to_string`

```sad
متغير ن = نص(100)           # "100"
```

### `منطقي(قيمة)`
تحويل قيمة إلى منطقي.
- **البدائل:** `bool`, `لمنطقي`, `to_bool`
- **قواعد التحويل:** `0`, `""`, `لاشيء` → `خطأ`، أي شيء آخر → `صحيح`

```sad
متغير م = منطقي(1)          # صحيح
متغير ف = منطقي(0)          # خطأ
متغير ج = منطقي("")         # خطأ
متغير ك = منطقي("نص")       # صحيح
```

> **ملاحظة مهمة:** القسمة `/` تعطي دائماً نتيجة عشرية:
> ```sad
> متغير ن = 47 / 2          # 23.5
> متغير ص = رقم(47 / 2)     # 23 (قسمة صحيحة)
> ```

## 5. دوال التزامن

### `قناة(حجم)`
إنشاء قناة اتصال مخزّنة.
- **البدائل:** `channel`, `chan`

```sad
متغير ق = قناة(10)
ق.أرسل(42)
متغير قيمة = ق.استقبل()
```

### `انتظر_الكل()`
انتظار انتهاء جميع الخيوط الخفيفة (goroutines).
- **البدائل:** `wait_all`, `waitAll`

```sad
أطلق دالة_ما()
أطلق دالة_أخرى()
انتظر_الكل()
```

### `عدد_المهام()`
عدد الخيوط النشطة حالياً.
- **البدائل:** `active_goroutines`

### `مجموعة_انتظار()`
إنشاء WaitGroup للتنسيق بين الخيوط.
- **البدائل:** `wait_group`, `waitGroup`

```sad
متغير مج = مجموعة_انتظار()
مج.أضف(3)
# ... إطلاق 3 خيوط تنادي مج.أنهي()
مج.انتظر()
```

### `قفل()`
إنشاء Mutex للحماية من التعارض.
- **البدائل:** `mutex`

```sad
متغير ق = قفل()
ق.اقفل()
# ... عملية حرجة
ق.افتح()
```

### `مستقبل()`
إنشاء Future لإرجاع قيمة من خيط.
- **البدائل:** `future`

```sad
متغير م = مستقبل()
أطلق
    م.عيّن(نتيجة_حساب)
نهاية
متغير ن = م.احصل()  # يحجب حتى تجهز النتيجة
```

## 6. طرق المصفوفات

جميع هذه الطرق تعمل مباشرة على أي مصفوفة:

| الطريقة | الوصف | مثال |
|---|---|---|
| `.اضف(عنصر)` | إضافة عنصر للنهاية | `م.اضف(4)` |
| `.أضف(عنصر)` | نفس اضف (بالهمزة) | `م.أضف(4)` |
| `.احذف_اخير()` | حذف وإرجاع آخر عنصر | `متغير آخر = م.احذف_اخير()` |
| `.الطول()` | عدد العناصر | `م.الطول()` |
| `.فارغة()` | هل المصفوفة فارغة؟ | `م.فارغة()` |
| `.يحتوي(قيمة)` | هل تحتوي على القيمة؟ | `م.يحتوي(3)` |
| `.فهرس(قيمة)` | موضع القيمة (-1 إذا غير موجودة) | `م.فهرس(2)` |
| `.اول()` | أول عنصر | `م.اول()` |
| `.آخر()` | آخر عنصر | `م.آخر()` |
| `.شريحة(بداية, نهاية)` | جزء من المصفوفة | `م.شريحة(1, 3)` |
| `.رتب()` | ترتيب تصاعدي | `م.رتب()` |
| `.عكس()` | عكس الترتيب | `م.عكس()` |
| `.مسطح()` | فك التعشيش | `[[1],[2,3]].مسطح()` → `[1,2,3]` |

### طرق البرمجة الوظيفية (تقبل لامدا):

```sad
متغير م = [1، 2، 3، 4، 5]

# خريطة — تحويل كل عنصر
متغير مضاعف = م.خريطة(لامدا (س) ارجع س * 2 نهاية)
# [2، 4، 6، 8، 10]

# رشح — تصفية حسب شرط
متغير زوجي = م.رشح(لامدا (س) ارجع س % 2 == 0 نهاية)
# [2، 4]

# اختزل — تجميع إلى قيمة واحدة
متغير مجموع = م.اختزل(لامدا (تراكم، س) ارجع تراكم + س نهاية، 0)
# 15

# لكل — تنفيذ عملية على كل عنصر
م.لكل(لامدا (س) اطبع_سطر(س) نهاية)
```

## 7. طرق النصوص

| الطريقة | الوصف | مثال |
|---|---|---|
| `.طول()` | طول النص | `"مرحبا".طول()` → `5` |
| `.يحتوي(فرعي)` | هل يحتوي على النص الفرعي؟ | `"مرحبا".يحتوي("رح")` |
| `.يبدأ_بـ(بادئة)` | هل يبدأ بالبادئة؟ | `"مرحبا".يبدأ_بـ("مرح")` |
| `.ينتهي_بـ(لاحقة)` | هل ينتهي باللاحقة؟ | `"مرحبا".ينتهي_بـ("حبا")` |
| `.تقسيم(فاصل)` | تقسيم إلى مصفوفة | `"أ-ب-ج".تقسيم("-")` |
| `.استبدل(قديم, جديد)` | استبدال نص فرعي | `"مرحبا".استبدل("مرحبا", "أهلا")` |
| `.استخراج(بداية, نهاية)` | جزء من النص | `"مرحبا".استخراج(0, 3)` |
| `.قص_أطراف()` | إزالة المسافات | `"  نص  ".قص_أطراف()` |
| `.تحويل_كبير()` | أحرف كبيرة (لاتينية) | `"hello".تحويل_كبير()` |
| `.تحويل_صغير()` | أحرف صغيرة (لاتينية) | `"HELLO".تحويل_صغير()` |

## 8. طرق الخرائط

```sad
متغير خ = {"اسم": "أحمد"، "عمر": 25}

خ.احصل("اسم")               # "أحمد"
خ.عيّن("مدينة"، "الرياض")    # إضافة مفتاح جديد
خ.احذف("عمر")                # حذف مفتاح
خ.يحتوي("اسم")              # صحيح
خ.مفاتيح()                  # ["اسم"، "مدينة"]
خ.قيم()                     # ["أحمد"، "الرياض"]
خ.حجم()                     # 2
خ.فارغة()                   # خطأ
```

## 9. طرق القنوات

```sad
متغير ق = قناة(10)

# إرسال واستقبال (مع حجب)
ق.أرسل(42)
متغير قيمة = ق.استقبل()

# بدون حجب
ق.حاول_ارسل(42)             # يرجع صحيح/خطأ
ق.حاول_استقبل()             # يرجع القيمة أو لاشيء

# بمهلة (مللي ثانية)
ق.أرسل_بمهلة(42، 1000)      # محاولة لمدة ثانية
ق.استقبل_بمهلة(500)          # محاولة لمدة نصف ثانية

# الحالة
ق.الحجم()                   # عدد العناصر الحالي
ق.السعة()                   # السعة القصوى
ق.فارغة()                   # هل فارغة؟
ق.أغلق()                    # إغلاق القناة
ق.مغلقة()                   # هل مغلقة؟

# التكرار عبر القناة
لكل عنصر في ق
    اطبع_سطر(عنصر)
نهاية
```

## 10. طرق مجموعة الانتظار والقفل والمستقبل

### مجموعة الانتظار
```sad
متغير مج = مجموعة_انتظار()
مج.أضف(عدد)       # إضافة مهام للعداد
مج.أنهي()          # إنقاص العداد بواحد
مج.انتظر()         # حجب حتى العداد = 0
مج.العداد()        # قراءة العداد الحالي
```

### القفل (Mutex)
```sad
متغير ق = قفل()
ق.اقفل()           # قفل (حجب حتى الحصول)
ق.افتح()           # فتح القفل
ق.حاول_قفل()       # محاولة بدون حجب (يرجع صحيح/خطأ)
ق.مقفل()           # هل مقفل؟
```

### المستقبل (Future)
```sad
متغير م = مستقبل()
م.عيّن(قيمة)       # تعيين النتيجة (مرة واحدة فقط)
م.احصل()           # الحصول على النتيجة (يحجب حتى تجهز)
م.جاهز()           # هل النتيجة جاهزة؟
```
