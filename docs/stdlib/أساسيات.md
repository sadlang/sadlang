# وحدة أساسيات

أدوات أساسية: عمليات الملفات، مدى الأرقام، التحقق من الشروط، الخروج من البرنامج.

## الاستيراد
```sad
# استيراد كامل
استورد أساسيات

# استيراد انتقائي — الصيغة العربية
استورد مدى، اخرج من أساسيات

# استيراد انتقائي — الصيغة المعيارية
من أساسيات استورد مدى، اخرج

# استيراد شامل
استورد * من أساسيات
من أساسيات استورد *
```

## البدائل المقبولة للاسم
`basics`, `basic`, `base`, `ملفات`

---

## دوال عامة

### `اخرج(كود)`
إنهاء البرنامج برمز خروج.
- `0` = خروج ناجح
- أي رقم آخر = خروج بخطأ

```sad
من أساسيات استورد اخرج

إذا (خطأ_حرج)
    اطبع_سطر("خطأ حرج!")
    اخرج(1)
نهاية
```

### `تأكد(شرط، رسالة)`
فحص شرط — يرمي خطأ إذا كان الشرط خاطئاً.

```sad
من أساسيات استورد تأكد

تأكد(العمر > 0، "العمر يجب أن يكون موجباً")
تأكد(الاسم != ""، "الاسم مطلوب")
```

### `مدى(بداية، نهاية)`
إنشاء مصفوفة أرقام من `بداية` إلى `نهاية - 1`.

```sad
من أساسيات استورد مدى

متغير أرقام = مدى(1، 6)   # [1، 2، 3، 4، 5]
لكل ر في مدى(0، 10)
    اطبع_سطر(ر)
نهاية
```

## عمليات الملفات

### `اقرأ_ملف(مسار)` — قراءة ملف كاملاً
```sad
متغير محتوى = أساسيات.اقرأ_ملف("بيانات.txt")
اطبع_سطر(محتوى)
```

### `اكتب_ملف(مسار، محتوى)` — كتابة ملف (يستبدل المحتوى)
```sad
أساسيات.اكتب_ملف("ناتج.txt"، "مرحبا بالعالم!")
```

### `اقرأ_أسطر(مسار)` — قراءة ملف كمصفوفة أسطر
```sad
متغير أسطر = أساسيات.اقرأ_أسطر("بيانات.txt")
لكل سطر في أسطر
    اطبع_سطر(سطر)
نهاية
```

### `أضف_إلى_ملف(مسار، نص)` — إضافة نص لنهاية ملف
```sad
أساسيات.أضف_إلى_ملف("سجل.txt"، "رسالة جديدة\n")
```

### `انسخ_ملف(من، إلى)` — نسخ ملف
```sad
أساسيات.انسخ_ملف("أصل.txt"، "نسخة.txt")
```

### `انقل_ملف(من، إلى)` — نقل/إعادة تسمية ملف
```sad
أساسيات.انقل_ملف("قديم.txt"، "جديد.txt")
```

### `احذف_ملف(مسار)` — حذف ملف
```sad
أساسيات.احذف_ملف("مؤقت.txt")
```

### `أنشئ_مجلد(مسار)` — إنشاء مجلد
```sad
أساسيات.أنشئ_مجلد("مجلد_جديد")
```

### `اسرد_مجلد(مسار)` — سرد محتويات مجلد
```sad
متغير ملفات = أساسيات.اسرد_مجلد(".")
لكل ملف في ملفات
    اطبع_سطر(ملف)
نهاية
```

### `هل_ملف(مسار)` / `هل_مجلد(مسار)` — فحص نوع المسار
```sad
إذا (أساسيات.هل_ملف("بيانات.txt"))
    اطبع_سطر("ملف موجود!")
نهاية

إذا (أساسيات.هل_مجلد("مجلد"))
    اطبع_سطر("مجلد موجود!")
نهاية
```

## مثال عملي: قراءة ومعالجة ملف

```sad
من أساسيات استورد *

# قراءة ملف وعدّ الأسطر
متغير أسطر = اقرأ_أسطر("بيانات.txt")
اطبع_سطر("عدد الأسطر: " + نص(طول(أسطر)))

# كتابة النتائج
اكتب_ملف("تقرير.txt"، "عدد الأسطر: " + نص(طول(أسطر)))
```
