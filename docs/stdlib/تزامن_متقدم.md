# وحدة تزامن_متقدم

عمليات ذرية (atomic) وأدوات تزامن متقدمة.

## الاستيراد
```sad
# استيراد كامل
استورد تزامن_متقدم

# استيراد انتقائي — الصيغة العربية
استورد ذري_أضف من تزامن_متقدم

# استيراد انتقائي — الصيغة المعيارية
من تزامن_متقدم استورد ذري_أضف

# استيراد شامل
استورد * من تزامن_متقدم
من تزامن_متقدم استورد *
```

## البدائل المقبولة للاسم
`async`, `concurrency`, `توازي`

---

## العمليات الذرية

العمليات الذرية تضمن أن القراءة والكتابة تحدث بشكل غير قابل للانقسام (atomic)، مما يمنع حالات السباق (race conditions).

### `ذري_تحميل(متغير)`
قراءة ذرية لقيمة متغير مشترك.

```sad
متغير قيمة = تزامن_متقدم.ذري_تحميل(عداد_مشترك)
```

### `ذري_تخزين(متغير، قيمة)`
كتابة ذرية لقيمة متغير مشترك.

```sad
تزامن_متقدم.ذري_تخزين(عداد_مشترك، 42)
```

### `ذري_أضف(متغير، قيمة)`
إضافة ذرية لقيمة عددية.

```sad
تزامن_متقدم.ذري_أضف(عداد، 1)
```

---

## ملاحظة مهمة
> دوال التزامن الأساسية التالية **لا تحتاج استيراد** — متاحة تلقائياً:
> - `قناة(حجم)` — إنشاء قناة اتصال
> - `قفل()` — إنشاء Mutex
> - `مستقبل()` — إنشاء Future
> - `مجموعة_انتظار()` — إنشاء WaitGroup
> - `أطلق` — إطلاق خيط خفيف
> - `انتظر_الكل()` — انتظار جميع الخيوط
>
> هذه الوحدة توفر **عمليات ذرية منخفضة المستوى** فقط.

---

## مثال: عداد ذري آمن

```sad
من تزامن_متقدم استورد *

متغير عداد = 0

# إطلاق عدة خيوط تزيد العداد
لكل _ في [1، 2، 3، 4، 5]
    أطلق
        ذري_أضف(عداد، 1)
    نهاية
نهاية

انتظر_الكل()
اطبع_سطر("العداد: " + نص(ذري_تحميل(عداد)))   # 5
```
