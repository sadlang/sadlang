## القسم الأول: دوال مضمنة (لا تحتاج استيراد)

هذه الدوال متاحة تلقائياً في أي برنامج بلغة ص:

| الفئة | الدوال |
|---|---|
| **إخراج** | `اطبع(...)`, `اطبع_سطر(...)` |
| **إدخال** | `اقرأ(رسالة؟)` |
| **طول/نوع** | `طول(قيمة)`, `نوع(قيمة)` |
| **تحويل أنواع** | `رقم()`, `عشري()`, `نص()`, `منطقي()` |
| **تزامن** | `قناة()`, `انتظر_الكل()`, `قفل()`, `مستقبل()`, `مجموعة_انتظار()` |

بالإضافة إلى طرق مضمنة على الأنواع:
- **مصفوفات:** `.اضف()`, `.رتب()`, `.خريطة()`, `.رشح()`, `.اختزل()`, `.عكس()`
- **نصوص:** `.طول()`, `.يحتوي()`, `.تقسيم()`, `.استبدل()`, `.قص_أطراف()`
- **خرائط:** `.احصل()`, `.عيّن()`, `.مفاتيح()`, `.قيم()`, `.حجم()`
- **قنوات:** `.أرسل()`, `.استقبل()`, `.أغلق()`, `.الحجم()`, `.السعة()`

> للتفاصيل الكاملة: [الدوال_المضمنة.md](الدوال_المضمنة.md)

## طرق الاستيراد

لغة ص تدعم **صيغتين** للاستيراد: الصيغة العربية (استورد ... من) والصيغة المعيارية (من ... استورد).

```sad
# ──────────── استيراد بسيط ────────────
# 1. استيراد كامل (فضاء أسماء)
استورد رياضيات
اطبع(رياضيات.جذر(16))

# 2. استيراد بإسم مستعار
استورد رياضيات كـ ر
اطبع(ر.جذر(16))

# ──────────── الصيغة العربية (استورد ... من) ────────────
# 3. استيراد دالة محددة
استورد جذر من رياضيات
اطبع(جذر(16))

# 4. استيراد عدة دوال
استورد جذر، لوغاريتم من رياضيات

# 5. استيراد مع اسم مستعار
استورد جذر كـ ج من رياضيات

# 6. استيراد شامل
استورد * من رياضيات

# ──────────── الصيغة المعيارية (من ... استورد) ────────────
# 7. استيراد دالة محددة
من رياضيات استورد جذر

# 8. استيراد عدة دوال
من رياضيات استورد جذر، لوغاريتم

# 9. استيراد مع اسم مستعار
من رياضيات استورد جذر كـ ج

# 10. استيراد شامل
من رياضيات استورد *
```

> **ملاحظة:** الصيغتان متكافئتان تماماً — اختر الأنسب لك.

## دليل سريع — ماذا تحتاج لكل مهمة؟

| المهمة | استيراد؟ | الوحدة |
|---|---|---|
| طباعة وإدخال | لا | مضمنة |
| طول/نوع/تحويل أنواع | لا | مضمنة |
| طرق المصفوفات والنصوص | لا | مضمنة |
| قنوات وخيوط خفيفة | لا | مضمنة |
| عمليات الملفات | نعم | `استورد أساسيات` |
| لوغاريتم / أس / π | نعم | `استورد رياضيات` |
| JSON / regex | نعم | `استورد خرائط` |
| تشفير / hash | نعم | `استورد تشفير` |
| HTTP | نعم | `استورد شبكة` |
| مقابس TCP / UDP | نعم | `استورد مقابس` |
