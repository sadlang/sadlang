# وحدة مقابس

مقابس TCP/UDP منخفضة المستوى للاتصالات الشبكية.

## الاستيراد
```sad
# استيراد كامل
استورد مقابس

# استيراد انتقائي — الصيغة العربية
استورد مقبس_tcp من مقابس

# استيراد انتقائي — الصيغة المعيارية
من مقابس استورد مقبس_tcp

# استيراد شامل
استورد * من مقابس
من مقابس استورد *
```

## البدائل المقبولة للاسم
`sockets`, `socket`, `tcp`, `udp`, `مقبس`

---

## الدوال

### `مقبس_tcp()`
إنشاء مقبس TCP جديد.

```sad
متغير م = مقابس.مقبس_tcp()
```

### `مقبس_udp()`
إنشاء مقبس UDP جديد.

```sad
متغير م = مقابس.مقبس_udp()
```

---

## مثال: خادم TCP

```sad
من مقابس استورد *

متغير خادم = مقبس_tcp()
# خادم.اربط("0.0.0.0"، 8080)
# خادم.استمع(5)
# متغير عميل = خادم.اقبل()
# ...
```

## مثال: عميل TCP

```sad
من مقابس استورد *

متغير عميل = مقبس_tcp()
# عميل.اتصل("127.0.0.1"، 8080)
# عميل.أرسل("مرحبا")
# متغير رد = عميل.استقبل()
```
