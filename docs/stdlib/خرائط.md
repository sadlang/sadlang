# وحدة خرائط

خرائط متقدمة (hash maps) ودوال مساعدة.

## الاستيراد
```sad
# استيراد كامل
استورد خرائط

# استيراد انتقائي — الصيغة العربية
استورد خريطة من خرائط

# استيراد انتقائي — الصيغة المعيارية
من خرائط استورد خريطة

# استيراد شامل
استورد * من خرائط
من خرائط استورد *
```

## البدائل المقبولة للاسم
`maps`, `functional`, `json`, `xml`, `محرك`

---

## الدوال

### `خريطة()`
إنشاء خريطة فارغة جديدة.

```sad
متغير خ = خرائط.خريطة()
```

### `خريطة_احصل(خريطة، مفتاح)`
الحصول على قيمة بمفتاح.

```sad
متغير قيمة = خرائط.خريطة_احصل(خ، "اسم")
```

### `خريطة_عيّن(خريطة، مفتاح، قيمة)`
تعيين أو تحديث قيمة لمفتاح.

```sad
خرائط.خريطة_عيّن(خ، "اسم"، "أحمد")
خرائط.خريطة_عيّن(خ، "عمر"، 25)
```

### `خريطة_مفاتيح(خريطة)`
مصفوفة بجميع المفاتيح.

```sad
متغير م = خرائط.خريطة_مفاتيح(خ)   # ["اسم"، "عمر"]
```

### `خريطة_قيم(خريطة)`
مصفوفة بجميع القيم.

```sad
متغير ق = خرائط.خريطة_قيم(خ)   # ["أحمد"، 25]
```

### `خريطة_تحتوي(خريطة، مفتاح)`
هل الخريطة تحتوي على المفتاح؟

```sad
إذا (خرائط.خريطة_تحتوي(خ، "اسم"))
    اطبع_سطر("موجود!")
نهاية
```

### `خريطة_احذف(خريطة، مفتاح)`
حذف مفتاح وقيمته.

```sad
خرائط.خريطة_احذف(خ، "عمر")
```

### `خريطة_حجم(خريطة)`
عدد العناصر في الخريطة.

```sad
اطبع_سطر(خرائط.خريطة_حجم(خ))
```

### `خريطة_عناصر(خريطة)`
مصفوفة من أزواج `[مفتاح، قيمة]`.

```sad
لكل زوج في خرائط.خريطة_عناصر(خ)
    اطبع_سطر(زوج[0] + ": " + نص(زوج[1]))
نهاية
```

## ملاحظة
> الطرق المضمنة على الخرائط (`.احصل()`, `.عيّن()`, `.مفاتيح()`, `.قيم()`, `.حجم()`, `.فارغة()`) تعمل مباشرة بدون استيراد.
> هذه الوحدة توفر دوال حرة (free functions) إضافية.
