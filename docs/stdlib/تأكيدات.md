# وحدة تأكيدات

دوال الاختبار والتحقق من صحة الشروط والقيم.

## الاستيراد
```sad
# استيراد كامل
استورد تأكيدات

# استيراد انتقائي — الصيغة العربية
استورد تأكد، تأكد_متساوي من تأكيدات

# استيراد انتقائي — الصيغة المعيارية
من تأكيدات استورد تأكد، تأكد_متساوي

# استيراد شامل
استورد * من تأكيدات
من تأكيدات استورد *
```

## البدائل المقبولة للاسم
`assertions`, `assert`, `testing`, `اختبار`

---

## الدوال

### `تأكد(شرط)`
فحص أن الشرط صحيح — يرمي خطأ إذا كان خاطئاً.

```sad
تأكيدات.تأكد(2 + 2 == 4)          # ✅ ينجح
تأكيدات.تأكد(طول("مرحبا") > 0)    # ✅ ينجح
```

### `تأكد_متساوي(أ، ب)`
فحص أن القيمتين متساويتان — يرمي خطأ مع تفاصيل القيمتين إذا اختلفتا.

```sad
تأكيدات.تأكد_متساوي(2 + 3، 5)            # ✅ ينجح
تأكيدات.تأكد_متساوي(طول("مرحبا")، 5)    # ✅ ينجح
```

---

## مثال: اختبار وحدة كامل

```sad
من تأكيدات استورد *

# الدالة المراد اختبارها
دالة جمع(أ، ب)
    ارجع أ + ب
نهاية

دالة ضرب(أ، ب)
    ارجع أ * ب
نهاية

# الاختبارات
تأكد_متساوي(جمع(2، 3)، 5)
تأكد_متساوي(جمع(-1، 1)، 0)
تأكد_متساوي(جمع(0، 0)، 0)

تأكد_متساوي(ضرب(3، 4)، 12)
تأكد_متساوي(ضرب(0، 100)، 0)
تأكد_متساوي(ضرب(-2، 3)، -6)

اطبع_سطر("جميع الاختبارات نجحت! ✅")
```

---

## مثال: اختبار مع كتلة حاول/امسك

```sad
من تأكيدات استورد *

حاول
    تأكد_متساوي(1 + 1، 3)   # سيفشل!
امسك خطأ
    اطبع_سطر("فشل الاختبار: " + خطأ)
نهاية
```
