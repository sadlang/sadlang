# وحدة تشفير

دوال التشفير والبصمات الرقمية (hashing).

## الاستيراد
```sad
# استيراد كامل
استورد تشفير

# استيراد انتقائي — الصيغة العربية
استورد هاش_256، شفّر من تشفير

# استيراد انتقائي — الصيغة المعيارية
من تشفير استورد هاش_256، شفّر

# استيراد شامل
استورد * من تشفير
من تشفير استورد *
```

## البدائل المقبولة للاسم
`crypto`, `encryption`, `أمان_بيانات`

---

## الدوال

### `هاش_256(نص)`
حساب بصمة SHA-256 لنص. تُرجع نصاً بتمثيل سداسي عشري (hex).

```sad
متغير بصمة = تشفير.هاش_256("مرحبا")
اطبع_سطر(بصمة)
# مثال: "2cf24dba5fb0a30e..."
```

### `شفّر(نص، مفتاح)`
تشفير نص بتقنية CTR (تشفير متماثل).

```sad
متغير مشفر = تشفير.شفّر("رسالة سرية"، "مفتاح_آمن_123")
اطبع_سطر(مشفر)
```

### `فك_تشفير(نص_مشفر، مفتاح)`
فك تشفير نص مشفّر بنفس المفتاح.

```sad
متغير أصلي = تشفير.فك_تشفير(مشفر، "مفتاح_آمن_123")
اطبع_سطر(أصلي)   # "رسالة سرية"
```

---

## مثال عملي: تشفير وفك تشفير

```sad
من تشفير استورد *

متغير الرسالة = "هذه رسالة سرية جداً"
متغير المفتاح = "مفتاح_سري_2024"

# التشفير
متغير مشفر = شفّر(الرسالة، المفتاح)
اطبع_سطر("النص المشفر: " + مشفر)

# فك التشفير
متغير أصلي = فك_تشفير(مشفر، المفتاح)
اطبع_سطر("النص الأصلي: " + أصلي)

# التحقق من البصمة
متغير بصمة1 = هاش_256("كلمة_سر")
متغير بصمة2 = هاش_256("كلمة_سر")
اطبع_سطر("البصمات متطابقة: " + نص(بصمة1 == بصمة2))   # صحيح
```
