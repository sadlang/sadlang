# وحدة منصة

كشف نظام التشغيل ومعمارية المعالج.

## الاستيراد
```sad
# استيراد كامل
استورد منصة

# استيراد انتقائي — الصيغة العربية
استورد النظام من منصة

# استيراد انتقائي — الصيغة المعيارية
من منصة استورد النظام

# استيراد شامل
استورد * من منصة
من منصة استورد *
```

## البدائل المقبولة للاسم
`platform`, `نظام_تشغيل`

---

## الدوال

### `النظام()`
اسم نظام التشغيل الحالي.
- **تُرجع:** نص — `"Windows"`, `"Linux"`, أو `"macOS"`

```sad
اطبع_سطر(منصة.النظام())   # "Windows"
```

### `المعمارية()`
معمارية المعالج.
- **تُرجع:** نص — `"x64"`, `"x86"`, `"arm64"`, ...

```sad
اطبع_سطر(منصة.المعمارية())   # "x64"
```

---

## مثال عملي: كود متعدد المنصات

```sad
من منصة استورد *

إذا (النظام() == "Windows")
    اطبع_سطر("نظام ويندوز")
وإلا
    إذا (النظام() == "Linux")
        اطبع_سطر("نظام لينكس")
    وإلا
        اطبع_سطر("نظام ماك")
    نهاية
نهاية

اطبع_سطر("المعمارية: " + المعمارية())
```
