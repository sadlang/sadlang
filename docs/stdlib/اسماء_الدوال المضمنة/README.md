# أسماء الدوال المضمنة لمكتبة الشبكة

هذا المرجع يوثق الأسماء **القانونية الحالية** للدوال المضمنة التي تعتمد على مكتبة [stdlib/network](../../../stdlib/network)، كما هي معرّفة فعلياً في الكود وتُستخدم بالاسم نفسه في المفسر والمترجم.

## ملاحظات مهمة

- الاسم القانوني لوحدة المقابس هو `مقابس`.
- الاسم القانوني الحالي لوحدة HTTP وأدوات الشبكة هو `شبكة`.
- الاسم `شبكة_عالية` يظهر في بعض ملفات التوثيق الأقدم، لكنه **ليس** الاسم القانوني الحالي في سجل الوحدات المركزي.
- أسماء الدوال أدناه ليست اجتهاداً توثيقياً، بل هي نفس السلاسل النصية المعرّفة في `builtin_registry.h`.

## نتيجة التحقق

- عدد دوال `مقابس` القانونية: `18`.
- عدد دوال `شبكة` القانونية: `49`.
- المجموع الكلي لدوال `stdlib/network`: `67` اسماً.
- المفسر يسجل الأسماء نفسها مباشرة من السجل المركزي.
- المترجم الأمامي يطابق الأسماء نفسها عند بناء تعليمات SIR.
- المترجم الخلفي يملك دعماً مقابلاً لها عبر تعليمات `BUILTIN_NET_*`.

## الاستيراد الصحيح

```sad
استورد مقابس
استورد شبكة

من مقابس استورد أنشئ_وصلة، اتصل_بـ
من شبكة استورد اجلب، أنشئ_خادم، جهّز_الشبكة
```

## لماذا هذه القائمة هي المرجع الصحيح؟

- جميع الأسماء السابقة معرفة أولاً في `shared/builtins/include/builtin_registry.h`.
- المفسر لا يعيد تسمية هذه الدوال، بل يسجلها كما هي عبر `registerBuiltinFunction(std::string(...))`.
- المترجم لا يستخدم أسماء بديلة، بل يطابق `funcName` على نفس الثوابت النصية نفسها.
- المترجم الخلفي لا يخترع واجهة مستقلة، بل يحوّل هذه الأسماء إلى `BUILTIN_NET_*` المقابلة لها.

بناءً على ذلك، فهذه القائمة تمثل **العقد الفعلي الحالي** بين كود لغة ص، والمفسر، والمترجم، ومكتبة `stdlib/network`.
