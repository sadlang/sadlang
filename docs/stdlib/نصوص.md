# وحدة نصوص

معالجة نصوص متقدمة ودوال فحص الأنواع.

## الاستيراد
```sad
# استيراد كامل
استورد نصوص

# استيراد انتقائي — الصيغة العربية
استورد أحرف_كبيرة من نصوص

# استيراد انتقائي — الصيغة المعيارية
من نصوص استورد أحرف_كبيرة

# استيراد شامل
استورد * من نصوص
من نصوص استورد *
```

## البدائل المقبولة للاسم
`strings`, `string`, `str`, `سلاسل`

---

## دوال معالجة النصوص

### `أحرف_كبيرة(نص)`
تحويل الأحرف اللاتينية إلى كبيرة (uppercase).

```sad
اطبع_سطر(نصوص.أحرف_كبيرة("hello"))   # "HELLO"
```

### `أحرف_صغيرة(نص)`
تحويل الأحرف اللاتينية إلى صغيرة (lowercase).

```sad
اطبع_سطر(نصوص.أحرف_صغيرة("HELLO"))   # "hello"
```

### `قسم(نص، فاصل)`
تقسيم النص إلى مصفوفة حسب الفاصل.

```sad
متغير أجزاء = نصوص.قسم("أحمد-محمد-علي"، "-")
# ["أحمد"، "محمد"، "علي"]
```

### `صل(مصفوفة، فاصل)`
دمج عناصر مصفوفة في نص واحد مع فاصل.

```sad
متغير ن = نصوص.صل(["أ"، "ب"، "ج"]، " - ")
# "أ - ب - ج"
```

### `بحث(نص، فرعي)`
البحث عن نص فرعي — يرجع الموضع (0-indexed) أو -1 إذا لم يُوجد.

```sad
اطبع_سطر(نصوص.بحث("مرحبا بالعالم"، "بال"))   # 6
اطبع_سطر(نصوص.بحث("مرحبا"، "وداعاً"))         # -1
```

### `استبدل(نص، قديم، جديد)`
استبدال جميع تكرارات نص فرعي.

```sad
اطبع_سطر(نصوص.استبدل("أهلاً وسهلاً"، "أهلاً"، "مرحبا"))
# "مرحبا وسهلاً"
```

### `استخراج(نص، بداية، نهاية)`
استخراج جزء من النص (من بداية إلى نهاية-1).

```sad
اطبع_سطر(نصوص.استخراج("مرحبا بالعالم"، 0، 5))   # "مرحبا"
```

### `قص_أطراف(نص)`
إزالة المسافات البيضاء من بداية ونهاية النص.

```sad
اطبع_سطر(نصوص.قص_أطراف("  مرحبا  "))   # "مرحبا"
```

### `يبدأ_ب(نص، بادئة)`
هل يبدأ النص بالبادئة المحددة؟

```sad
اطبع_سطر(نصوص.يبدأ_ب("مرحبا"، "مرح"))   # صحيح
```

### `ينتهي_ب(نص، لاحقة)`
هل ينتهي النص باللاحقة المحددة؟

```sad
اطبع_سطر(نصوص.ينتهي_ب("مرحبا"، "حبا"))   # صحيح
```

### `يحتوي_على(نص، فرعي)`
هل يحتوي النص على النص الفرعي؟

```sad
اطبع_سطر(نصوص.يحتوي_على("مرحبا بالعالم"، "عالم"))   # صحيح
```

## دوال فحص النوع

| الدالة | الوصف | مثال |
|---|---|---|
| `هو_رقم_صحيح(قيمة)` | هل القيمة رقم صحيح (int)؟ | `هو_رقم_صحيح(42)` → `صحيح` |
| `هو_رقم_عشري(قيمة)` | هل القيمة رقم عشري (float)؟ | `هو_رقم_عشري(3.14)` → `صحيح` |
| `هو_نص(قيمة)` | هل القيمة نص (string)؟ | `هو_نص("مرحبا")` → `صحيح` |
| `هو_مصفوفة(قيمة)` | هل القيمة مصفوفة (array)؟ | `هو_مصفوفة([1,2])` → `صحيح` |

```sad
من نصوص استورد *

اطبع_سطر(هو_رقم_صحيح(42))       # صحيح
اطبع_سطر(هو_رقم_صحيح(3.14))     # خطأ
اطبع_سطر(هو_نص("مرحبا"))        # صحيح
اطبع_سطر(هو_مصفوفة([1، 2]))     # صحيح
```

## دوال المصفوفات

### `أضف(مصفوفة، عنصر)`
إضافة عنصر لنهاية المصفوفة.

```sad
متغير م = [1، 2]
نصوص.أضف(م، 3)   # م = [1، 2، 3]
```

### `أزل(مصفوفة، فهرس)`
حذف عنصر بالفهرس.

```sad
نصوص.أزل(م، 0)   # م = [2، 3]
```
