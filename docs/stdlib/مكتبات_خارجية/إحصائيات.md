# مكتبة إحصائيات

حسابات إحصائية: متوسط، وسيط، منوال، انحراف معياري.

## الاستيراد
```sad
من مكتبات_خارجية.إحصائيات.src.مكتبة استورد *
```

## الدوال

| الدالة | الوصف | مثال | النتيجة |
|---|---|---|---|
| `المتوسط(مصفوفة)` | المتوسط الحسابي | `المتوسط([10, 20, 30])` | 20 |
| `الوسيط(مصفوفة)` | القيمة الوسطى | `الوسيط([1, 3, 5, 7])` | 4 |
| `الانحراف_المعياري(مصفوفة)` | الانحراف المعياري | `الانحراف_المعياري([10, 20, 30])` | ~8.16 |
| `التباين(مصفوفة)` | التباين | `التباين([10, 20, 30])` | ~66.67 |

## مثال عملي
```sad
من مكتبات_خارجية.إحصائيات.src.مكتبة استورد *

متغير درجات = [85، 90، 78، 92، 88]
اطبع_سطر("المتوسط: " + نص(المتوسط(درجات)))
اطبع_سطر("الوسيط: " + نص(الوسيط(درجات)))
اطبع_سطر("الانحراف: " + نص(الانحراف_المعياري(درجات)))
```
