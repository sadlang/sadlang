# مكتبة خيوط

أقفال ومراجع ذرية للتزامن الآمن.

## الاستيراد
```sad
من مكتبات_خارجية.خيوط.src.مكتبة استورد *
```

## الأصناف

### `قفل()`
| الطريقة | الوصف |
|---|---|
| `.احجز()` | قفل (حجب) |
| `.أطلق()` | فتح القفل |

### `مرجع_ذري(قيمة_أولية)`
| الطريقة | الوصف |
|---|---|
| `.احصل_على_قيمة()` | قراءة ذرية |
| `.اضبط(قيمة)` | كتابة ذرية |

## مثال عملي
```sad
من مكتبات_خارجية.خيوط.src.مكتبة استورد *

متغير ق = قفل()
متغير عداد = مرجع_ذري(0)

أطلق
    ق.احجز()
    عداد.اضبط(عداد.احصل_على_قيمة() + 1)
    ق.أطلق()
نهاية
```
