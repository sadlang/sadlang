# مكتبة اختبار

اختبار وحدات بسيط مع دوال تأكيد.

## الاستيراد
```sad
من مكتبات_خارجية.اختبار.src.مكتبة استورد *
```

## الدوال

| الدالة | الوصف |
|---|---|
| `تأكد_يساوي(فعلي، متوقع، وصف)` | فحص مساواة مع وصف |
| `تأكد(شرط، وصف)` | فحص شرط مع وصف |

## مثال عملي
```sad
من مكتبات_خارجية.اختبار.src.مكتبة استورد *

دالة جمع(أ، ب)
    ارجع أ + ب
نهاية

تأكد_يساوي(جمع(2, 3), 5, "جمع بسيط")
تأكد_يساوي(جمع(0, 0), 0, "جمع أصفار")
تأكد(جمع(1, 1) > 0, "الناتج موجب")
اطبع_سطر("كل الاختبارات نجحت ✅")
```
