لغة ص توفر **30 مكتبة خارجية** جاهزة للاستخدام تغطي مجالات متنوعة:

```sad
# الصيغة العربية — استيراد شامل
استورد * من مكتبات_خارجية.اسم_المكتبة.src.مكتبة

# الصيغة العربية — استيراد انتقائي

```

## قيود حرجة يجب معرفتها

### 1. المصفوفات تُمرر بالقيمة
الدوال التي تعدّل المصفوفات داخلياً لا تؤثر على المصفوفة الأصلية.
**الحل:** استخدم أصنافاً مع `هذا._البيانات`.

### 2. عامل المودولو (32-bit)
لا تستخدم قيماً أكبر من `2147483647` مع `%`.

### 3. تقطيع النصوص غير مدعوم
استخدم حلقة بدلاً من `نص[0..5]`.

### 4. صيغة اللامدا
```sad
# ✅ الصيغة الصحيحة
لامدا(س) => س * 2
لامدا(س)
    ارجع س * 2
نهاية
```
