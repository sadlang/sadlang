# مكتبة نظام

معلومات عن نظام التشغيل والمعالج والبيئة.

## الاستيراد
```sad
من مكتبات_خارجية.نظام.src.مكتبة استورد *
```

## الدوال

| الدالة | الوصف | مثال |
|---|---|---|
| `اسم_المنصة()` | اسم نظام التشغيل | `"Windows"` |
| `نوع_المعالج()` | نوع المعالج | `"x86_64"` |
| `متغير_بيئة(اسم)` | قراءة متغير بيئة | `متغير_بيئة("PATH")` |
