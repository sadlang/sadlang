# مكتبة ملفات_csv

قراءة وكتابة ملفات CSV.

## الاستيراد
```sad
من مكتبات_خارجية.ملفات_csv.src.مكتبة استورد *
```

## الدوال

| الدالة | الوصف |
|---|---|
| `تحليل_csv(نص)` | تحليل نص CSV إلى مصفوفة صفوف |
| `تحليل_csv_بترويسة(نص)` | تحليل CSV مع أسماء الأعمدة |

## مثال عملي
```sad
من مكتبات_خارجية.ملفات_csv.src.مكتبة استورد *

متغير بيانات = تحليل_csv("1,أحمد,25\n2,محمد,30")
لكل صف في بيانات
    اطبع_سطر(صف[1] + " — عمره " + صف[2])
نهاية

# مع ترويسة
متغير جدول = تحليل_csv_بترويسة("اسم,عمر\nأحمد,25\nمحمد,30")
```
