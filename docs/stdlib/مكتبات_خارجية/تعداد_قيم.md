# مكتبة تعداد_قيم

إنشاء أنواع تعداد مخصصة.

## الاستيراد
```sad
من مكتبات_خارجية.تعداد_قيم.src.مكتبة استورد *
```

## الدوال

### `إنشاء_تعداد(اسم، عناصر)`
إنشاء تعداد جديد.

### `عنصر_تعداد(اسم، قيمة)`
تعريف عنصر واحد في التعداد.

## مثال عملي
```sad
من مكتبات_خارجية.تعداد_قيم.src.مكتبة استورد *

متغير ألوان = إنشاء_تعداد("ألوان", [
    عنصر_تعداد("أحمر", 1),
    عنصر_تعداد("أخضر", 2),
    عنصر_تعداد("أزرق", 3)
])
```

> **ملاحظة:** كلمة `تعداد` محجوزة — لا تستخدمها كاسم صنف أو متغير.
