# مكتبة تاريخ_ووقت

التعامل مع التاريخ والوقت.

## الاستيراد
```sad
من مكتبات_خارجية.تاريخ_ووقت.src.مكتبة استورد *
```

## الدوال

| الدالة | الوصف |
|---|---|
| `الآن()` | الوقت والتاريخ الحاليان |
| `تنسيق(تاريخ، صيغة)` | تنسيق التاريخ حسب الصيغة |

## مثال عملي
```sad
من مكتبات_خارجية.تاريخ_ووقت.src.مكتبة استورد *

متغير اليوم = الآن()
اطبع_سطر(تنسيق(اليوم, "يوم/شهر/سنة"))
```
