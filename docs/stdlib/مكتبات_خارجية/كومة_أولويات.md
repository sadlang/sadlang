# مكتبة كومة_أولويات

طابور أولويات (min-heap) مع دوال ترتيب ودمج.

## الاستيراد
```sad
من مكتبات_خارجية.كومة_أولويات.src.مكتبة استورد *
```

## الأصناف

### `قائمة_أولويات()`
طابور أولويات — يُخرج الأصغر أولاً.

| الطريقة | الوصف |
|---|---|
| `.أدخل(قيمة)` | إدخال عنصر |
| `.استخرج_الأصغر()` | استخراج وإرجاع أصغر عنصر |
| `.الحجم()` | عدد العناصر |
| `.فارغة()` | هل فارغة؟ |

## الدوال المساعدة

| الدالة | الوصف | مثال |
|---|---|---|
| `دمج_مرتب(م1، م2)` | دمج مصفوفتين مرتبتين | `دمج_مرتب([1,3,5], [2,4,6])` → `[1,2,3,4,5,6]` |
| `ترتيب_تنازلي(مصفوفة)` | ترتيب من الأكبر للأصغر | `ترتيب_تنازلي([3,1,4])` → `[4,3,1]` |

## مثال عملي
```sad
من مكتبات_خارجية.كومة_أولويات.src.مكتبة استورد *

متغير ك = قائمة_أولويات()
ك.أدخل(5)
ك.أدخل(2)
ك.أدخل(8)
ك.أدخل(1)

بينما (ليس ك.فارغة())
    اطبع_سطر(ك.استخرج_الأصغر())   # 1، 2، 5، 8
نهاية
```
