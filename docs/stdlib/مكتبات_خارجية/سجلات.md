# مكتبة سجلات

تسجيل أحداث ورسائل بمستويات مختلفة (معلومة، تحذير، خطأ).

## الاستيراد
```sad
من مكتبات_خارجية.سجلات.src.مكتبة استورد *
```

## الدوال

| الدالة | المستوى | مثال |
|---|---|---|
| `معلومة(رسالة)` | INFO | `معلومة("بدء التطبيق")` |
| `تحذير(رسالة)` | WARNING | `تحذير("ذاكرة منخفضة")` |
| `خطأ(رسالة)` | ERROR | `خطأ("فشل الاتصال")` |

## مثال عملي
```sad
من مكتبات_خارجية.سجلات.src.مكتبة استورد *

معلومة("بدء التطبيق")
معلومة("جاري التحميل...")
تحذير("الذاكرة المتبقية أقل من 10%")
خطأ("فشل الاتصال بقاعدة البيانات")
```
