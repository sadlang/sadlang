# مكتبة برمجة_وظيفية

دوال البرمجة الوظيفية: map, filter, reduce (كدوال حرة).

## الاستيراد
```sad
من مكتبات_خارجية.برمجة_وظيفية.src.مكتبة استورد *
```

## الدوال

| الدالة | الوصف | مثال |
|---|---|---|
| `خريطة(دالة، مصفوفة)` | تحويل كل عنصر | `خريطة(لامدا(س) => س * 2, [1,2,3])` → `[2,4,6]` |
| `مرشح(دالة، مصفوفة)` | تصفية حسب شرط | `مرشح(لامدا(س) => س > 2, [1,2,3,4])` → `[3,4]` |
| `اختصار(دالة، مصفوفة، قيمة_أولية)` | تجميع إلى قيمة واحدة | `اختصار(لامدا(م,س) => م + س, [1,2,3], 0)` → `6` |

## مثال عملي
```sad
من مكتبات_خارجية.برمجة_وظيفية.src.مكتبة استورد *

متغير أرقام = [1، 2، 3، 4، 5]

# مضاعفة كل عنصر
متغير مضاعف = خريطة(لامدا(س) => س * 2, أرقام)
اطبع_سطر(مضاعف)   # [2, 4, 6, 8, 10]

# الأعداد الزوجية فقط
متغير زوجي = مرشح(لامدا(س) => س % 2 == 0, أرقام)
اطبع_سطر(زوجي)   # [2, 4]

# المجموع
متغير مجموع = اختصار(لامدا(م، س) => م + س, أرقام, 0)
اطبع_سطر(مجموع)   # 15
```

> **ملاحظة:** المصفوفات المضمنة لديها طرق مشابهة (`.خريطة()`, `.رشح()`, `.اختزل()`) تعمل بدون استيراد. هذه المكتبة توفرها كدوال حرة.
