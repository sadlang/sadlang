# مكتبة مقابس (خارجية)

التحقق من صحة عناوين IP وأرقام المنافذ.

## الاستيراد
```sad
من مكتبات_خارجية.مقابس.src.مكتبة استورد *
```

## الدوال

| الدالة | الوصف | مثال | النتيجة |
|---|---|---|---|
| `هل_منفذ_صحيح(رقم)` | هل المنفذ صحيح (0-65535)؟ | `هل_منفذ_صحيح(8080)` | صحيح |
| `هل_ip_صحيح(نص)` | هل عنوان IPv4 صحيح؟ | `هل_ip_صحيح("192.168.1.1")` | صحيح |
