# مكتبة معالجة_متوازية

تجمع عمليات (Thread Pool) للمعالجة المتوازية.

## الاستيراد
```sad
من مكتبات_خارجية.معالجة_متوازية.src.مكتبة استورد *
```

## الأصناف

### `تجمع_عمليات(عدد_الخيوط)`
| الطريقة | الوصف |
|---|---|
| `.خريطة(دالة، مصفوفة)` | تطبيق دالة على كل عنصر بالتوازي |

## مثال عملي
```sad
من مكتبات_خارجية.معالجة_متوازية.src.مكتبة استورد *

متغير ت = تجمع_عمليات(4)
متغير نتائج = ت.خريطة(لامدا(س) => س * 2, [1, 2, 3, 4, 5])
اطبع_سطر(نتائج)   # [2, 4, 6, 8, 10]
```
