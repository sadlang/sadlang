# مكتبة نماذج_بيانات

كائنات بيانات منظمة (مشابهة لـ dataclass).

## الاستيراد
```sad
من مكتبات_خارجية.نماذج_بيانات.src.مكتبة استورد *
```

## الدوال والأصناف

### `نموذج_بيانات(خريطة)`
إنشاء كائن بيانات من خريطة.

| الطريقة | الوصف |
|---|---|
| `.احصل(مفتاح)` | قراءة قيمة |
| `.إلى_خريطة()` | تحويل إلى خريطة |

## مثال عملي
```sad
من مكتبات_خارجية.نماذج_بيانات.src.مكتبة استورد *

متغير شخص = نموذج_بيانات({"اسم": "أحمد"، "عمر": 25، "مدينة": "الرياض"})
اطبع_سطر(شخص.احصل("اسم"))      # "أحمد"
اطبع_سطر(شخص.إلى_خريطة())       # {"اسم": "أحمد", ...}
```
