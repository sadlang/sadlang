# مكتبة محولات

تحويل الوحدات: حرارة، مسافة، وزن.

## الاستيراد
```sad
من مكتبات_خارجية.محولات.src.مكتبة استورد *
```

## الدوال

| الدالة | الوصف | مثال | النتيجة |
|---|---|---|---|
| `سيلسيوس_إلى_فهرنهايت(درجة)` | °C → °F | `سيلسيوس_إلى_فهرنهايت(100)` | 212 |
| `فهرنهايت_إلى_سيلسيوس(درجة)` | °F → °C | `فهرنهايت_إلى_سيلسيوس(212)` | 100 |
| `كيلو_إلى_ميل(مسافة)` | كم → ميل | `كيلو_إلى_ميل(10)` | ~6.21 |
| `ميل_إلى_كيلو(مسافة)` | ميل → كم | `ميل_إلى_كيلو(5)` | ~8.05 |

## مثال عملي
```sad
من مكتبات_خارجية.محولات.src.مكتبة استورد *

اطبع_سطر("100°C = " + نص(سيلسيوس_إلى_فهرنهايت(100)) + "°F")
اطبع_سطر("10 كم = " + نص(كيلو_إلى_ميل(10)) + " ميل")
```
