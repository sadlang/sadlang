# مكتبة مجموعات

هياكل بيانات أساسية: مكدس (Stack)، طابور (Queue)، مجموعة (Set).

## الاستيراد
```sad
من مكتبات_خارجية.مجموعات.src.مكتبة استورد *
```

## الأصناف

### `مكدس()` — Stack (LIFO)
| الطريقة | الوصف |
|---|---|
| `.ادفع(قيمة)` | إضافة عنصر للأعلى |
| `.انزع()` | إزالة وإرجاع العنصر الأعلى |
| `.القمة()` | عرض العنصر الأعلى بدون إزالة |
| `.فارغة()` | هل فارغ؟ |

### `طابور()` — Queue (FIFO)
| الطريقة | الوصف |
|---|---|
| `.أضف(قيمة)` | إضافة عنصر للنهاية |
| `.أزل()` | إزالة وإرجاع العنصر الأول |
| `.الأول()` | عرض العنصر الأول بدون إزالة |
| `.فارغة()` | هل فارغ؟ |

## مثال عملي
```sad
من مكتبات_خارجية.مجموعات.src.مكتبة استورد *

# مكدس — آخر من يدخل أول من يخرج
متغير م = مكدس()
م.ادفع("أ")
م.ادفع("ب")
م.ادفع("ج")
اطبع_سطر(م.انزع())   # "ج"
اطبع_سطر(م.انزع())   # "ب"
```
