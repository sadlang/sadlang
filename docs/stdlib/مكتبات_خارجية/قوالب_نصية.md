# مكتبة قوالب_نصية

قوالب نصوص مع متغيرات قابلة للاستبدال (مثل Mustache).

## الاستيراد
```sad
من مكتبات_خارجية.قوالب_نصية.src.مكتبة استورد *
```

## الأصناف

### `قالب(نص_القالب)`
| الطريقة | الوصف |
|---|---|
| `.نفّذ(خريطة_قيم)` | استبدال المتغيرات وإرجاع النتيجة |

## مثال عملي
```sad
من مكتبات_خارجية.قوالب_نصية.src.مكتبة استورد *

متغير ق = قالب("مرحبا {{اسم}}، عمرك {{عمر}} سنة!")
متغير نتيجة = ق.نفّذ({"اسم": "أحمد"، "عمر": "25"})
اطبع_سطر(نتيجة)   # "مرحبا أحمد، عمرك 25 سنة!"
```
