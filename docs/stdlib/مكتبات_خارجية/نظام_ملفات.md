# مكتبة نظام_ملفات

عمليات الملفات والمجلدات.

## الاستيراد
```sad
من مكتبات_خارجية.نظام_ملفات.src.مكتبة استورد *
```

## الدوال

| الدالة | الوصف |
|---|---|
| `اقرأ_ملف(مسار)` | قراءة محتوى ملف كنص |
| `اكتب_ملف(مسار، محتوى)` | كتابة نص إلى ملف |
| `هل_موجود(مسار)` | هل الملف/المجلد موجود؟ |
| `امتداد(مسار)` | استخراج امتداد الملف |
| `اسم_الملف(مسار)` | اسم الملف بدون المسار |
| `المجلد_الأب(مسار)` | المجلد الحاوي |

## مثال عملي
```sad
من مكتبات_خارجية.نظام_ملفات.src.مكتبة استورد *

إذا (هل_موجود("بيانات.txt"))
    متغير محتوى = اقرأ_ملف("بيانات.txt")
    اطبع_سطر("المحتوى: " + محتوى)
نهاية

اطبع_سطر(امتداد("صورة.png"))   # ".png"
```
