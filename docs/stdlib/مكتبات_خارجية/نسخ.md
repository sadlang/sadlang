# مكتبة نسخ

نسخ عميق وسطحي للكائنات والمصفوفات.

## الاستيراد
```sad
من مكتبات_خارجية.نسخ.src.مكتبة استورد *
```

## الدوال

| الدالة | الوصف |
|---|---|
| `نسخة_عميقة(كائن)` | نسخ عميق (deep copy) — الكائنات المتداخلة تُنسخ أيضاً |
| `هل_متساويان(أ، ب)` | مقارنة عميقة بين كائنين |

## مثال عملي
```sad
من مكتبات_خارجية.نسخ.src.مكتبة استورد *

متغير أصل = [1, [2, 3], [4, 5]]
متغير نسخة = نسخة_عميقة(أصل)

# تعديل النسخة لا يؤثر على الأصل
نسخة[1][0] = 99
اطبع_سطر(أصل[1][0])    # 2 (لم يتغير)
اطبع_سطر(نسخة[1][0])   # 99

# مقارنة
اطبع_سطر(هل_متساويان([1,2], [1,2]))   # صحيح
اطبع_سطر(هل_متساويان([1,2], [1,3]))   # خطأ
```
