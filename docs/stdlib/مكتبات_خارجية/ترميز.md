# مكتبة ترميز

تحويل بين تنسيقات مختلفة: hex، binary، base64، morse، URL.

## الاستيراد
```sad
من مكتبات_خارجية.ترميز.src.مكتبة استورد *
```

## الدوال

| الدالة | الوصف | مثال | النتيجة |
|---|---|---|---|
| `إلى_ست_عشري(رقم)` | رقم → hex | `إلى_ست_عشري(255)` | `"ff"` |
| `إلى_ثنائي(رقم)` | رقم → binary | `إلى_ثنائي(42)` | `"101010"` |
| `شفرة_قيصر(نص، إزاحة)` | شفرة قيصر | `شفرة_قيصر("ABC", 3)` | `"DEF"` |
| `ترميز_url(نص)` | ترميز URL | `ترميز_url("مرحبا بك")` | نص مُرمّز |
