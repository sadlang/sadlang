# مكتبة طلبات_ويب

إرسال طلبات HTTP وتحليل روابط URL.

## الاستيراد
```sad
من مكتبات_خارجية.طلبات_ويب.src.مكتبة استورد *
```

## الدوال

| الدالة | الوصف |
|---|---|
| `طلب(رابط)` | إرسال طلب HTTP GET |
| `تحليل_رابط(رابط)` | تحليل URL إلى مكوناته |

### خصائص كائن تحليل_رابط
| الخاصية | الوصف | مثال |
|---|---|---|
| `.البروتوكول` | http/https | `"https"` |
| `.المضيف` | اسم الخادم | `"example.com"` |
| `.المنفذ` | رقم المنفذ | `443` |
| `.المسار` | مسار الصفحة | `"/path"` |

## مثال عملي
```sad
من مكتبات_خارجية.طلبات_ويب.src.مكتبة استورد *

# تحليل رابط
متغير رابط = تحليل_رابط("https://example.com:443/api/users")
اطبع_سطر("البروتوكول: " + رابط.البروتوكول)
اطبع_سطر("المضيف: " + رابط.المضيف)
```
