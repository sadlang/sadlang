# مكتبة جيسون

تحليل وإنتاج بيانات JSON.

## الاستيراد
```sad
من مكتبات_خارجية.جيسون.src.مكتبة استورد *
```

## الدوال

| الدالة | الوصف |
|---|---|
| `حلل_json(نص)` | تحويل نص JSON إلى كائن (خريطة/مصفوفة) |
| `إلى_json(كائن)` | تحويل كائن إلى نص JSON |
| `هل_json_صحيح(نص)` | هل النص JSON صحيح؟ |

## مثال عملي
```sad
من مكتبات_خارجية.جيسون.src.مكتبة استورد *

# تحليل JSON
متغير بيانات = حلل_json("{\"اسم\": \"أحمد\", \"عمر\": 25}")
اطبع_سطر(بيانات["اسم"])   # "أحمد"

# إنتاج JSON
متغير خ = {"لغة": "ص", "إصدار": 1}
اطبع_سطر(إلى_json(خ))

# التحقق
اطبع_سطر(هل_json_صحيح("{\"x\": 1}"))   # صحيح
اطبع_سطر(هل_json_صحيح("{x: 1}"))        # خطأ
```
