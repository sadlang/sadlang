# مكتبة تعبيرات_منتظمة

بحث واستبدال باستخدام التعبيرات المنتظمة (Regular Expressions).

## الاستيراد
```sad
من مكتبات_خارجية.تعبيرات_منتظمة.src.مكتبة استورد *
```

## الدوال

| الدالة | الوصف | مثال |
|---|---|---|
| `بحث(نمط، نص)` | البحث عن أول تطابق | `بحث("[0-9]+", "عمري 25")` |
| `استبدل(نمط، نص، بديل)` | استبدال التطابقات | `استبدل("[0-9]+", "عمري 25", "XX")` |

## مثال عملي
```sad
من مكتبات_خارجية.تعبيرات_منتظمة.src.مكتبة استورد *

# البحث عن أرقام
متغير نتيجة = بحث("[0-9]+", "عمري 25 سنة")
اطبع_سطر(نتيجة)

# استبدال
متغير جديد = استبدل("[0-9]+", "سنة 2024", "XXXX")
اطبع_سطر(جديد)   # "سنة XXXX"
```
