# مكتبة ألوان

إنشاء ومعالجة الألوان (RGB/HSL/hex).

## الاستيراد
```sad
من مكتبات_خارجية.ألوان.src.مكتبة استورد *
```

## الدوال

| الدالة | الوصف |
|---|---|
| `لون_جديد(أحمر، أخضر، أزرق)` | إنشاء لون RGB (0-255) |
| `إلى_سداسي(لون)` | تحويل إلى hex (#RRGGBB) |
| `مزج(لون1، لون2، نسبة)` | مزج لونين (نسبة 0-1) |

## مثال عملي
```sad
من مكتبات_خارجية.ألوان.src.مكتبة استورد *

متغير أحمر = لون_جديد(255, 0, 0)
متغير أزرق = لون_جديد(0, 0, 255)
متغير بنفسجي = مزج(أحمر, أزرق, 0.5)
اطبع_سطر(إلى_سداسي(بنفسجي))
```
