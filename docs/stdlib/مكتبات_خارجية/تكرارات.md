# مكتبة تكرارات

أدوات للتعامل مع المصفوفات: سلسلة، ضغط، تعداد، تبديلات.

## الاستيراد
```sad
من مكتبات_خارجية.تكرارات.src.مكتبة استورد *
```

## الدوال

| الدالة | الوصف | مثال | النتيجة |
|---|---|---|---|
| `سلسل(مصفوفات)` | دمج عدة مصفوفات | `سلسل([[1,2],[3,4]])` | `[1,2,3,4]` |
| `اضغط(م1، م2)` | ربط عناصر مصفوفتين | `اضغط(["أ","ب"],[1,2])` | `[["أ",1],["ب",2]]` |
| `عدّد(مصفوفة، بداية)` | إضافة فهرس لكل عنصر | `عدّد(["أ","ب"], 0)` | `[[0,"أ"],[1,"ب"]]` |

## مثال عملي
```sad
من مكتبات_خارجية.تكرارات.src.مكتبة استورد *

# ترقيم العناصر
متغير أسماء = ["أحمد"، "محمد"، "علي"]
لكل زوج في عدّد(أسماء، 1)
    اطبع_سطر(نص(زوج[0]) + ". " + زوج[1])
نهاية
# 1. أحمد
# 2. محمد
# 3. علي
```
