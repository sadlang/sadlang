# مكتبة إدخال_إخراج

مجاري نصية وثنائية (Streams) للقراءة والكتابة.

## الاستيراد
```sad
من مكتبات_خارجية.إدخال_إخراج.src.مكتبة استورد *
```

## الأصناف

### `مجرى_نصي()`
مجرى نصي للقراءة والكتابة في الذاكرة.

| الطريقة | الوصف |
|---|---|
| `.اكتب(نص)` | إضافة نص للمجرى |
| `.اقرأ_الكل()` | قراءة كل المحتوى |

## مثال عملي
```sad
من مكتبات_خارجية.إدخال_إخراج.src.مكتبة استورد *

متغير م = مجرى_نصي()
م.اكتب("مرحبا ")
م.اكتب("بالعالم")
اطبع_سطر(م.اقرأ_الكل())   # "مرحبا بالعالم"
```
