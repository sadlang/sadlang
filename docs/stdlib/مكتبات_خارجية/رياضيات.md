# مكتبة رياضيات (خارجية)

دوال رياضية متقدمة: مثلثية، أعداد أولية، عاملي، قوة.

## الاستيراد
```sad
# استيراد شامل
من مكتبات_خارجية.رياضيات.src.مكتبة استورد *

# أو استيراد انتقائي
استورد جيب، جيب_تمام من مكتبات_خارجية.رياضيات.src.مكتبة
```

## الدوال

| الدالة | الوصف | مثال | النتيجة |
|---|---|---|---|
| `جيب(س)` | sin(x) بالراديان | `جيب(3.14)` | ~0 |
| `جيب_تمام(س)` | cos(x) بالراديان | `جيب_تمام(0)` | 1 |
| `ظل(س)` | tan(x) بالراديان | `ظل(0)` | 0 |
| `هل_أولي(ن)` | هل العدد أولي؟ | `هل_أولي(17)` | صحيح |
| `عاملي(ن)` | n! | `عاملي(5)` | 120 |
| `قوة(أساس، أس)` | أساس^أس | `قوة(2, 10)` | 1024 |
| `القيمة_المطلقة(س)` | |x| | `القيمة_المطلقة(-5)` | 5 |
| `أكبر(أ، ب)` | أكبر قيمتين | `أكبر(3, 7)` | 7 |
| `أصغر(أ، ب)` | أصغر قيمتين | `أصغر(3, 7)` | 3 |

## مثال عملي
```sad
من مكتبات_خارجية.رياضيات.src.مكتبة استورد *

اطبع_سطر("5! = " + نص(عاملي(5)))              # 120
اطبع_سطر("2^10 = " + نص(قوة(2, 10)))           # 1024
اطبع_سطر("هل 17 أولي؟ " + نص(هل_أولي(17)))    # صحيح
اطبع_سطر("sin(π/2) = " + نص(جيب(3.14159 / 2))) # ~1
```
