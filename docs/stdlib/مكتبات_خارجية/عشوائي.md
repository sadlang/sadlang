# مكتبة عشوائي

توليد أرقام عشوائية واختيار عناصر عشوائية.

## الاستيراد
```sad
من مكتبات_خارجية.عشوائي.src.مكتبة استورد *
```

## الدوال

| الدالة | الوصف | مثال |
|---|---|---|
| `بذرة(رقم)` | تعيين بذرة التوليد (للتكرارية) | `بذرة(42)` |
| `عشوائي()` | رقم عشري بين [0, 1) | `عشوائي()` |
| `عشوائي_نطاق(من، إلى)` | رقم صحيح عشوائي في نطاق | `عشوائي_نطاق(1, 100)` |
| `اختر(مصفوفة)` | عنصر عشوائي من مصفوفة | `اختر(["أ", "ب"])` |

## مثال عملي
```sad
من مكتبات_خارجية.عشوائي.src.مكتبة استورد *

بذرة(42)
اطبع_سطر("عشوائي: " + نص(عشوائي()))
اطبع_سطر("نطاق 1-100: " + نص(عشوائي_نطاق(1, 100)))
اطبع_سطر("اختيار: " + اختر(["تفاحة"، "موزة"، "برتقالة"]))
```

> **ملاحظة:** استخدم `بذرة()` بنفس الرقم لتحصل على نفس النتائج — مفيد للاختبارات.
