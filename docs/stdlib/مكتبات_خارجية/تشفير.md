# مكتبة تشفير (خارجية)

خوارزميات البصمات الرقمية والتشفير.

## الاستيراد
```sad
من مكتبات_خارجية.تشفير.src.مكتبة استورد *
```

## الدوال

| الدالة | الوصف |
|---|---|
| `sha256(نص)` | بصمة SHA-256 |
| `md5(نص)` | بصمة MD5 |
| `crc32(نص)` | بصمة CRC32 |
| `hmac_sha256(رسالة، مفتاح)` | HMAC-SHA256 |
| `ترميز_سداسي(نص)` | تحويل إلى hex |

## مثال عملي
```sad
من مكتبات_خارجية.تشفير.src.مكتبة استورد *

اطبع_سطر(sha256("مرحبا"))
اطبع_سطر(md5("test"))
اطبع_سطر(crc32("data"))
اطبع_سطر(hmac_sha256("message", "secret_key"))
```
