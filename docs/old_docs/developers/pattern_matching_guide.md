## مقدمة

**مطابقة الأنماط** (Pattern Matching) هي ميزة قوية في لغة ص تتيح لك مقارنة قيمة مع عدة أنماط واختيار الكود المناسب للتنفيذ بناءً على النمط المطابق.

### لماذا مطابقة الأنماط؟

| المشكلة مع if/else | الحل مع طابق |
|-------------------|--------------|
| كود طويل ومتكرر | كود مختصر ومقروء |
| سهولة نسيان حالة | فحص شمولية تلقائي |
| لا يدعم التفكيك | تفكيك مدمج |
| شروط معقدة | أنماط واضحة |

## الصيغ المدعومة

### الصيغة العربية الأصيلة (مُستحسنة) ✨

```س
طابق قيمة
    حالة نمط١: أوامر
    حالة نمط٢: أوامر
    حالة _: أوامر_افتراضية
نهاية
```

**مثال:**
```س
رقم س = 5

طابق س
    حالة 1: اطبع("واحد")
    حالة 2: اطبع("اثنان")
    حالة 3: اطبع("ثلاثة")
    حالة _: اطبع("رقم آخر")
نهاية
```

### صيغة الأقواس المعقوفة

```س
طابق قيمة {
    حالة نمط١: أوامر
    حالة نمط٢: أوامر
}
```

**مثال:**
```س
طابق س {
    حالة 1: اطبع("واحد")
    حالة _: اطبع("آخر")
}
```

### متى تستخدم كل صيغة؟

| الصيغة | الاستخدام الأمثل |
|--------|-----------------|
| `طابق...نهاية` | الكود العربي الصرف، القراءة السهلة |
| `طابق { }` | التوافق مع أنماط البرمجة الغربية |

## أنواع الأنماط

### 1. نمط القيمة الحرفية (Literal Pattern)

يطابق قيمة محددة بالضبط.

```س
طابق لون
    حالة "أحمر": اطبع("🔴")
    حالة "أخضر": اطبع("🟢")
    حالة "أزرق": اطبع("🔵")
نهاية

طابق رقم
    حالة 0: اطبع("صفر")
    حالة 1: اطبع("واحد")
    حالة 42: اطبع("الجواب!")
نهاية
```

### 2. نمط البدل (Wildcard Pattern) `_`

يطابق أي قيمة. يُستخدم كحالة افتراضية.

```س
طابق حالة
    حالة "نجاح": اطبع("✅")
    حالة "فشل": اطبع("❌")
    حالة _: اطبع("❓ حالة غير معروفة")
نهاية
```

> ⚠️ **تحذير**: ضع نمط `_` دائماً في النهاية لأنه يطابق كل شيء!

### 3. نمط المتغير (Variable Pattern)

يربط القيمة المُطابقة بمتغير جديد.

```س
طابق قيمة
    حالة س: اطبع("القيمة هي: ", س)
نهاية
```

### 4. نمط القائمة (List Pattern)

يطابق قوائم ويفكك عناصرها.

```س
طابق قائمة
    حالة []: اطبع("قائمة فارغة")
    حالة [أ]: اطبع("عنصر واحد: ", أ)
    حالة [أ، ب]: اطبع("عنصران: ", أ، " و "، ب)
    حالة [أ، ب، ج]: اطبع("ثلاثة: "، أ، ب، ج)
    حالة _: اطبع("أكثر من ثلاثة")
نهاية
```

### 5. نمط الاختيار (Or Pattern) `|`

يطابق أي نمط من عدة أنماط.

```س
طابق يوم
    حالة "السبت" | "الأحد": اطبع("عطلة نهاية الأسبوع 🎉")
    حالة _: اطبع("يوم عمل 💼")
نهاية

طابق رقم
    حالة 1 | 2 | 3: اطبع("صغير")
    حالة 4 | 5 | 6: اطبع("متوسط")
    حالة _: اطبع("كبير")
نهاية
```

### 6. نمط النطاق (Range Pattern)

يطابق قيمة ضمن نطاق.

```س
طابق درجة
    حالة 90..100: اطبع("ممتاز 🌟")
    حالة 80..89: اطبع("جيد جداً")
    حالة 70..79: اطبع("جيد")
    حالة 60..69: اطبع("مقبول")
    حالة _: اطبع("راسب")
نهاية
```

## الشروط الحارسة (Guards)

الشروط الحارسة تضيف شروطاً إضافية للنمط.

### الصيغة

```س
حالة نمط إذا شرط: أوامر
```

### أمثلة

```س
طابق رقم
    حالة س إذا س > 100: اطبع("كبير جداً: "، س)
    حالة س إذا س > 10: اطبع("كبير: "، س)
    حالة س إذا س > 0: اطبع("موجب: "، س)
    حالة س إذا س < 0: اطبع("سالب: "، س)
    حالة 0: اطبع("صفر")
نهاية
```

### شروط معقدة

```س
طابق نقطة
    حالة [س، ص] إذا س == 0 && ص == 0:
        اطبع("نقطة الأصل")
    حالة [س، ص] إذا س == 0:
        اطبع("على المحور الصادي")
    حالة [س، ص] إذا ص == 0:
        اطبع("على المحور السيني")
    حالة [س، ص]:
        اطبع("نقطة عامة")
نهاية
```

## التفكيك (Destructuring)

التفكيك يتيح استخراج أجزاء من بنى البيانات المركبة.

### تفكيك القوائم

```س
متغير أرقام = [1، 2، 3]

طابق أرقام
    حالة [أول، _، آخر]:
        اطبع("الأول: "، أول)
        اطبع("الأخير: "، آخر)
نهاية
```

### تفكيك السجلات

```س
صنف نقطة
    رقم س
    رقم ص
نهاية

متغير ن = نقطة(10، 20)

طابق ن
    حالة نقطة(0، 0): اطبع("الأصل")
    حالة نقطة(س، 0): اطبع("على السينات: "، س)
    حالة نقطة(0، ص): اطبع("على الصادات: "، ص)
    حالة نقطة(س، ص): اطبع("النقطة: ("، س، "، "، ص، ")")
نهاية
```

### تفكيك متداخل

```س
متغير بيانات = [[1، 2]، [3، 4]]

طابق بيانات
    حالة [[أ، ب]، [ج، د]]:
        اطبع("أ="، أ، " ب="، ب، " ج="، ج، " د="، د)
نهاية
```

## التحقق من الشمولية

لغة ص تفحص تلقائياً أن جملة `طابق` تغطي جميع الحالات الممكنة.

### أمثلة على الشمولية

**✅ شامل:**
```س
طابق منطقي
    حالة صحيح: اطبع("نعم")
    حالة خطأ: اطبع("لا")
نهاية
```

**❌ غير شامل (تحذير):**
```س
طابق رقم
    حالة 1: اطبع("واحد")
    حالة 2: اطبع("اثنان")
    # ⚠️ ماذا عن الأرقام الأخرى؟
نهاية
```

**✅ إصلاح:**
```س
طابق رقم
    حالة 1: اطبع("واحد")
    حالة 2: اطبع("اثنان")
    حالة _: اطبع("آخر")  # يغطي البقية
نهاية
```

### التحذيرات

| التحذير | السبب |
|---------|-------|
| حالات ناقصة | لم تُغطَّ جميع القيم الممكنة |
| حالة لا يمكن الوصول إليها | نمط سابق يطابق نفس القيم |
| نمط مكرر | نفس النمط مكتوب مرتين |

## التكامل مع نظام الملكية

### أوضاع الربط (Binding Modes)

| الوضع | الصيغة | الاستخدام |
|-------|--------|-----------|
| نقل | `حالة س:` | نقل الملكية للمتغير |
| مرجع | `حالة &س:` | مرجع قابل للتعديل |
| مرجع ثابت | `حالة &ثابت س:` | مرجع للقراءة فقط |
| نسخ | `حالة نسخة س:` | نسخ القيمة |

### أمثلة

```س
# نقل الملكية
طابق قيمة
    حالة س: استخدم(س)  # القيمة الأصلية لم تعد صالحة
نهاية

# مرجع (لا ينقل الملكية)
طابق قيمة
    حالة &س: عدّل(س)  # القيمة الأصلية لا تزال صالحة
نهاية
```

## أفضل الممارسات

### 1. ✅ ضع الحالات الأكثر تحديداً أولاً

```س
# ✅ صحيح
طابق س
    حالة 0: ...      # الأكثر تحديداً
    حالة ن إذا ن > 0: ...
    حالة _: ...      # الأعم
نهاية

# ❌ خطأ
طابق س
    حالة _: ...      # يطابق كل شيء!
    حالة 0: ...      # لن يصل إلى هنا أبداً
نهاية
```

### 2. ✅ استخدم `_` للقيم غير المهمة

```س
# ✅ واضح
طابق نقطة
    حالة [س، _]: اطبع("السيني: "، س)
نهاية

# ❌ مبهم
طابق نقطة
    حالة [س، متغير_غير_مستخدم]: اطبع("السيني: "، س)
نهاية
```

### 3. ✅ جمّع الحالات المتشابهة

```س
# ✅ مختصر
طابق يوم
    حالة "السبت" | "الأحد": اطبع("عطلة")
    حالة _: اطبع("عمل")
نهاية

# ❌ مطوّل
طابق يوم
    حالة "السبت": اطبع("عطلة")
    حالة "الأحد": اطبع("عطلة")
    حالة _: اطبع("عمل")
نهاية
```

### 4. ✅ استخدم الشروط الحارسة للمنطق المعقد

```س
# ✅ واضح مع guard
طابق عمر
    حالة ع إذا ع < 0: خطأ("عمر سالب!")
    حالة ع إذا ع < 18: اطبع("قاصر")
    حالة ع إذا ع < 65: اطبع("بالغ")
    حالة _: اطبع("مسن")
نهاية
```

## الأخطاء الشائعة

### ❌ الخطأ 1: نسيان `نهاية`

```س
# ❌ خطأ
طابق س
    حالة 1: اطبع("واحد")
# نسيان نهاية!

# ✅ صحيح
طابق س
    حالة 1: اطبع("واحد")
نهاية
```

### ❌ الخطأ 2: استخدام `=` بدلاً من نمط

```س
# ❌ خطأ - هذا ليس مقارنة
طابق س
    حالة س = 5: ...  # خطأ!

# ✅ صحيح
طابق س
    حالة 5: ...
نهاية
```

### ❌ الخطأ 3: حالة لا يمكن الوصول إليها

```س
# ❌ خطأ
طابق س
    حالة _: اطبع("أي شيء")
    حالة 5: اطبع("خمسة")  # لن يصل أبداً!
نهاية

# ✅ صحيح
طابق س
    حالة 5: اطبع("خمسة")
    حالة _: اطبع("أي شيء")
نهاية
```

### ❌ الخطأ 4: نسيان النقطتين

```س
# ❌ خطأ
طابق س
    حالة 1 اطبع("واحد")  # نسيان :

# ✅ صحيح
طابق س
    حالة 1: اطبع("واحد")
نهاية
```

## المرجع السريع

### الكلمات المفتاحية

| العربية | الإنجليزية | الوصف |
|---------|------------|-------|
| `طابق` | `match` | بداية جملة المطابقة |
| `حالة` | `case` | فرع من فروع المطابقة |
| `نهاية` | `end` | نهاية الكتلة |
| `إذا` | `if` | شرط حارس |
| `_` | `_` | نمط البدل (يطابق أي شيء) |

### قالب سريع

```س
طابق قيمة
    حالة نمط١: 
        # أوامر للنمط الأول
    حالة نمط٢ إذا شرط:
        # أوامر مع شرط
    حالة _:
        # الحالة الافتراضية
نهاية
```

### مقارنة مع لغات أخرى

| لغة ص | Rust | Python 3.10+ | C# |
|-------|------|--------------|-----|
| `طابق س` | `match x` | `match x:` | `switch (x)` |
| `حالة 1:` | `1 =>` | `case 1:` | `case 1:` |
| `حالة _:` | `_ =>` | `case _:` | `default:` |
| `نهاية` | `}` | (indentation) | `}` |

## الخلاصة

مطابقة الأنماط في لغة ص توفر:

1. ✅ **صيغة عربية أصيلة** - `طابق...نهاية`
2. ✅ **أنماط متنوعة** - حرفية، قوائم، نطاقات، اختيارات
3. ✅ **شروط حارسة** - منطق إضافي مع `إذا`
4. ✅ **تفكيك مدمج** - استخراج أجزاء البنى
5. ✅ **فحص شمولية** - اكتشاف الحالات الناقصة
6. ✅ **تكامل مع الملكية** - أوضاع ربط متعددة
