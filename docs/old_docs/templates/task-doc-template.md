# 📝 قالب التوثيق الموازي للمهام

## مقدمة للمبتدئين

### ما هو "التوثيق الموازي"؟

**التوثيق الموازي** يعني كتابة التوثيق **بالتزامن مع كتابة الكود**، وليس بعد الانتهاء منه.

```
┌─────────────────────────────────────────────────────────────────┐
│              التوثيق التقليدي vs التوثيق الموازي                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   التوثيق التقليدي (❌):                                       │
│   ───────────────────────                                       │
│   1. اكتب كل الكود                                             │
│   2. ...أسابيع تمر...                                          │
│   3. حاول تذكر ماذا فعلت                                       │
│   4. اكتب توثيق ناقص وغير دقيق                                 │
│                                                                 │
│   التوثيق الموازي (✅):                                        │
│   ────────────────────────                                      │
│   1. ابدأ بكتابة التوثيق أولاً (ماذا سأفعل؟)                  │
│   2. اكتب الكود                                                │
│   3. حدّث التوثيق بأي تغييرات                                  │
│   4. توثيق كامل ودقيق ومحدث!                                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### لماذا التوثيق الموازي؟

1. **الذاكرة طازجة**: تكتب التوثيق وأنت تتذكر كل التفاصيل
2. **يوجه التصميم**: كتابة التوثيق أولاً يجبرك على التفكير
3. **يكشف المشاكل**: إذا صعب شرح الكود، ربما التصميم سيء
4. **يوفر الوقت**: لا حاجة للعودة لاحقاً وتذكر كل شيء

## 📚 شرح المفهوم (للمبتدئين)

### ما هو "الحارس قبل التوليد"؟

تخيل أنك تطلب من شخص كتابة رسالة لك. قبل أن يبدأ الكتابة،
تسأله: "ما الذي ستكتبه؟" - هذا هو الحارس قبل التوليد.

يفحص **النية** (ماذا يريد المستخدم؟) قبل **التنفيذ** (كتابة الكود).

### لماذا نحتاجه؟

في عصر الذكاء الاصطناعي، أحياناً نطلب من الـ AI كتابة كود.
لكن ماذا لو طلبت شيئاً خطيراً بالخطأ؟

```
المستخدم: "اكتب كود يحذف كل الملفات"
الحارس: ⚠️ تحذير! هذا طلب خطير. هل أنت متأكد؟
```

### مثال من الحياة

مثل حارس الأمن في البنك:
- يسألك: "لماذا أنت هنا؟"
- قبل أن يسمح لك بالدخول
- لا ينتظر حتى تسرق ثم يوقفك!

## نصائح للكتابة الجيدة

### 1. ابدأ بالسؤال "لماذا؟"

قبل كتابة أي كود، اسأل:
- لماذا نحتاج هذه الميزة؟
- ما المشكلة التي تحلها؟
- من سيستخدمها؟

### 2. استخدم أمثلة واقعية

```
❌ سيء: "الدالة تعالج البيانات"
✅ جيد: "مثل فلتر القهوة - تأخذ الماء والبن،
        وتُرجع قهوة صافية بدون الحبوب"
```

### 3. اكتب للمستقبل

تخيل أنك ستقرأ هذا التوثيق بعد سنة.
هل ستفهمه؟

### 4. حدّث باستمرار
