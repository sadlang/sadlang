## 🌟 مرحباً بالعالم

في كل لغة برمجة، التقليد المتبع هو أن يكون أول برنامج هو طباعة "مرحباً بالعالم". هذا البرنامج البسيط يساعدك على التأكد من أن كل شيء يعمل بشكل صحيح ويعطيك نظرة أولى على كيفية كتابة الكود.

في لغة ص، أول برنامج لك بسيط جداً - سطر واحد فقط!

```s
اطبع("مرحباً بالعالم!")
```

نعم، هذا كل شيء! لا حاجة لاستيرادات معقدة، ولا دوال main إلزامية، ولا إعدادات طويلة. فقط اكتب ما تريد وشغله.

---

## ✏️ كتابة الكود

الآن دعنا نكتب هذا البرنامج خطوة بخطوة:

### الخطوة 1: افتح محرر النصوص

افتح محرر النصوص المفضل لديك. إذا كنت تستخدم **Visual Studio Code** (موصى به)، افتحه من قائمة Start أو بالضغط على أيقونته.

### الخطوة 2: أنشئ ملفاً جديداً

في VS Code:
1. اضغط `Ctrl + N` لإنشاء ملف جديد
2. أو اذهب إلى **File → New File**

### الخطوة 3: احفظ الملف

احفظ الملف باسم `مرحبا.s`:
1. اضغط `Ctrl + S`
2. اختر المجلد الذي تريد حفظ الملف فيه (مثلاً: `C:\SadProjects\HelloWorld`)
3. اكتب اسم الملف: `مرحبا.s`
4. اضغط **Save**

**مهم جداً:** تأكد من أن اسم الملف ينتهي بـ `.s` - هذا هو امتداد ملفات لغة ص.

### الخطوة 4: اكتب الكود

الآن اكتب هذا الكود بالضبط في الملف:

```s
اطبع("مرحباً بالعالم!")
```

تأكد من:
- ✅ كتابة `اطبع` بالعربية الصحيحة
- ✅ وضع الأقواس `()` بعد `اطبع`
- ✅ وضع النص داخل علامات التنصيص `""`
- ✅ إغلاق القوس والتنصيص بشكل صحيح

### الخطوة 5: احفظ الملف مرة أخرى

بعد كتابة الكود، احفظه مرة أخرى بالضغط على `Ctrl + S`.

## ▶️ تشغيل البرنامج

الآن حان وقت تشغيل برنامجك الأول!

### الطريقة 1: من Terminal المدمج في VS Code

إذا كنت تستخدم VS Code:

1. افتح Terminal المدمج:
   - اضغط ``Ctrl + ` `` (الزر الذي فيه علامة الـ backtick)
   - أو اذهب إلى **Terminal → New Terminal**

2. تأكد من أنك في المجلد الصحيح. إذا لم تكن، انتقل إليه:
   ```powershell
   cd C:\SadProjects\HelloWorld
   ```

3. شغل البرنامج:
   ```powershell
   sad مرحبا.s
   ```

### الطريقة 2: من PowerShell أو Command Prompt

إذا كنت تفضل استخدام PowerShell أو Command Prompt:

1. افتح PowerShell:
   - اضغط `Win + X`
   - اختر **Windows PowerShell**

2. انتقل إلى مجلد البرنامج:
   ```powershell
   cd C:\SadProjects\HelloWorld
   ```

3. شغل البرنامج:
   ```powershell
   sad مرحبا.s
   ```

### النتيجة المتوقعة

بعد تشغيل الأمر، يجب أن ترى:

```
مرحباً بالعالم!
```

**مبروك! 🎉** لقد شغلت أول برنامج لك بنجاح!

## 🔍 فهم الكود

الآن دعنا نفهم ماذا حدث بالضبط:

### تحليل السطر

```s
اطبع("مرحباً بالعالم!")
```

هذا السطر يتكون من عدة أجزاء:

#### 1. `اطبع`
هذه **دالة مدمجة** (Built-in Function) في لغة ص. وظيفتها طباعة النص أو القيم على الشاشة. تستطيع استخدام `اطبع` في أي مكان في برنامجك لعرض معلومات للمستخدم.

#### 2. `()`
الأقواس تحيط بـ **الوسائط** (Arguments) التي نريد تمريرها للدالة. في هذه الحالة، نمرر نصاً واحداً.

#### 3. `"مرحباً بالعالم!"`
هذا هو **النص** (String) الذي نريد طباعته. أي شيء بين علامات التنصيص `""` يعتبر نصاً.

### كيف يعمل البرنامج خطوة بخطوة

عندما تشغل البرنامج:

1. **المفسر يقرأ الملف**: يبدأ مفسر لغة ص بقراءة ملف `مرحبا.s` من البداية

2. **تحليل الكود**: المفسر يحلل الكود ويفهم أنك تريد استدعاء دالة `اطبع`

3. **تنفيذ الدالة**: المفسر ينفذ دالة `اطبع` ويمرر لها النص `"مرحباً بالعالم!"`

4. **عرض النتيجة**: الدالة `اطبع` تعرض النص على الشاشة

5. **انتهاء البرنامج**: بعد تنفيذ كل الأسطر، ينتهي البرنامج

### التحليل اللغوي (Token Analysis)

المفسر يحلل الكود إلى "رموز" (Tokens):

```
TOKEN_PRINT      اطبع
TOKEN_LPAREN     (
TOKEN_STRING     "مرحباً بالعالم!"
TOKEN_RPAREN     )
TOKEN_EOF        <نهاية الملف>
```

كل جزء من الكود له نوع خاص يفهمه المفسر.

### بنية الشجرة النحوية (AST)

المفسر يبني شجرة نحوية داخلية:

```
Program (البرنامج الكامل)
└── ExpressionStmt (جملة تعبير)
    └── CallExpr (استدعاء دالة)
        ├── callee: Identifier("اطبع")
        └── arguments:
            └── Literal("مرحباً بالعالم!")
```

هذه الشجرة تساعد المفسر على فهم بنية البرنامج وتنفيذه بشكل صحيح.

## 💡 أمثلة إضافية بسيطة

الآن بعد أن فهمت كيف يعمل أول برنامج، دعنا نجرب أمثلة أخرى بسيطة:

### مثال 1: طباعة أكثر من سطر

```s
اطبع("مرحباً بالعالم!")
اطبع("هذا برنامجي الأول")
اطبع("أنا أتعلم لغة ص")
```

**النتيجة:**
```
مرحباً بالعالم!
هذا برنامجي الأول
أنا أتعلم لغة ص
```

كل استدعاء لـ `اطبع` يطبع سطراً جديداً تلقائياً.

---

### مثال 2: طباعة أرقام

```s
اطبع(42)
اطبع(3.14)
اطبع(100 + 200)
```

**النتيجة:**
```
42
3.14
300
```

دالة `اطبع` لا تطبع النصوص فقط - يمكنها طباعة الأرقام والعمليات الحسابية أيضاً!

---

### مثال 3: طباعة عدة أشياء في سطر واحد

```s
اطبع("الناتج هو:", 42)
اطبع("الجمع:", 10, "+", 20, "=", 30)
```

**النتيجة:**
```
الناتج هو: 42
الجمع: 10 + 20 = 30
```

يمكنك تمرير عدة وسائط إلى `اطبع` مفصولة بفواصل، وستطبعها جميعاً في نفس السطر مع مسافات بينها.

---

### مثال 4: عمليات حسابية

```s
اطبع("الجمع:", 10 + 5)
اطبع("الطرح:", 20 - 7)
اطبع("الضرب:", 6 * 8)
اطبع("القسمة:", 100 / 4)
اطبع("الباقي:", 17 % 5)
اطبع("القوة:", 2 ** 10)
```

**النتيجة:**
```
الجمع: 15
الطرح: 13
الضرب: 48
القسمة: 25
الباقي: 2
القوة: 1024
```

لغة ص تدعم جميع العمليات الحسابية الأساسية والمتقدمة!

---

### مثال 5: دمج النصوص

```s
اطبع("مرحباً" + " " + "بالعالم")
اطبع("لغة " + "ص" + " رائعة!")
```

**النتيجة:**
```
مرحباً بالعالم
لغة ص رائعة!
```

يمكنك دمج النصوص باستخدام علامة `+`.

---

### مثال 6: تكرار النصوص

```s
اطبع("ص" * 5)
اطبع("=" * 20)
اطبع("مرحبا " * 3)
```

**النتيجة:**
```
صصصصص
====================
مرحبا مرحبا مرحبا 
```

يمكنك تكرار النصوص باستخدام علامة `*` مع رقم!

---

### مثال 7: برنامج أكثر اكتمالاً

دعنا ندمج كل ما تعلمناه في برنامج واحد:

```s
# برنامج الترحيب
# يعرض رسالة ترحيب جميلة

اطبع("=" * 40)
اطبع("        مرحباً بك في لغة ص!")
اطبع("=" * 40)
اطبع()
اطبع("لغة ص هي لغة برمجة عربية حديثة")
اطبع("سهلة التعلم وقوية في نفس الوقت")
اطبع()
اطبع("هل تعلم؟")
اطبع("- يمكنك كتابة كل شيء بالعربية")
اطبع("- لغة ص تدعم البرمجة الكائنية")
اطبع("- لغة ص لديها مكتبة رسوميات مدمجة")
اطبع()
اطبع("العمليات الحسابية:")
اطبع("10 + 5 =", 10 + 5)
اطبع("2 ** 8 =", 2 ** 8)
اطبع()
اطبع("=" * 40)
اطبع("     ابدأ رحلتك في البرمجة الآن!")
اطبع("=" * 40)
```

**النتيجة:**
```
========================================
        مرحباً بك في لغة ص!
========================================

لغة ص هي لغة برمجة عربية حديثة
سهلة التعلم وقوية في نفس الوقت

هل تعلم؟
- يمكنك كتابة كل شيء بالعربية
- لغة ص تدعم البرمجة الكائنية
- لغة ص لديها مكتبة رسوميات مدمجة

العمليات الحسابية:
10 + 5 = 15
2 ** 8 = 256

========================================
     ابدأ رحلتك في البرمجة الآن!
========================================
```

لاحظ في هذا المثال:
- **التعليقات:** نستخدم `#` لكتابة تعليقات توضيحية (لا تؤثر على البرنامج)
- **السطر الفارغ:** `اطبع()` بدون وسائط يطبع سطراً فارغاً
- **التنسيق:** نستخدم `"=" * 40` لإنشاء خطوط جميلة
- **الدمج:** ندمج النصوص والأرقام في نفس السطر

## 🎯 تمرين: اكتب برنامجك الخاص

الآن دورك! جرب كتابة برنامج بسيط عن نفسك:

```s
# برنامج التعريف بنفسي

اطبع("=" * 30)
اطبع("      معلومات عني")
اطبع("=" * 30)
اطبع()
اطبع("الاسم: [اسمك هنا]")

اطبع("المدينة: [مدينتك]")
اطبع()
```

## 🐛 الأخطاء الشائعة وكيفية إصلاحها

### خطأ 1: نسيان علامات التنصيص

❌ **خطأ:**
```s
اطبع(مرحبا)
```

**رسالة الخطأ:**
```
خطأ: اسم غير معرف 'مرحبا'
```

✅ **الصواب:**
```s
اطبع("مرحبا")
```

**الحل:** النصوص يجب أن تكون بين علامات التنصيص `""`.

---

### خطأ 2: نسيان إغلاق القوس

❌ **خطأ:**
```s
اطبع("مرحبا"
```

**رسالة الخطأ:**
```
خطأ نحوي: توقع ')' في السطر 1
```

✅ **الصواب:**
```s
اطبع("مرحبا")
```

**الحل:** تأكد من إغلاق جميع الأقواس.

---

### خطأ 3: خطأ إملائي في الدالة

❌ **خطأ:**
```s
اضبع("مرحبا")
```

**رسالة الخطأ:**
```
خطأ: دالة غير معرفة 'اضبع'
```

✅ **الصواب:**
```s
اطبع("مرحبا")
```

**الحل:** تأكد من كتابة أسماء الدوال بشكل صحيح.

---

### خطأ 4: استخدام الفاصلة الخاطئة

❌ **مربك (لكن يعمل):**
```s
اطبع("مرحبا", "عالم")
```

✅ **الأفضل (الفاصلة العربية):**
```s
اطبع("مرحبا"، "عالم")
```

**ملاحظة:** كلاهما يعمل، لكن استخدام الفاصلة العربية `،` أفضل للاتساق.
