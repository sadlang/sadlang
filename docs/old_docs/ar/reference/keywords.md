# 📖 قاموس الكلمات المفتاحية

## نظرة عامة

هذا الدليل يحتوي على جميع الكلمات المفتاحية في لغة ص مع شرح مفصل وأمثلة.

---

## 🔤 الكلمات المفتاحية الأساسية

### `دالة`
تُعرّف دالة جديدة.

```س
دالة مرحبا()
    اطبع("مرحباً!")
نهاية

دالة اجمع(رقم أ، رقم ب) -> رقم
    ارجع أ + ب
نهاية
```

### `نهاية`
تُنهي كتلة من الكود (دالة، شرط، حلقة، إلخ).

```س
دالة رئيسية()
    إذا (صحيح)
        اطبع("نعم")
    نهاية  # نهاية الشرط
    ارجع 0
نهاية  # نهاية الدالة
```

### `ارجع` / `إرجاع`
تُرجع قيمة من دالة وتُنهي تنفيذها.

```س
دالة مربع(رقم س) -> رقم
    ارجع س * س
نهاية
```

---

## 📊 أنواع البيانات

### `رقم`
عدد صحيح (integer).

```س
رقم عمر = 25
رقم درجة_حرارة = -5
رقم عدد_كبير = 1000000
```

### `عشري`
عدد عشري (floating-point).

```س
عشري سعر = 19.99
عشري نسبة = 0.75
عشري باي = 3.14159
```

### `نص`
سلسلة حروف (string).

```س
نص اسم = "أحمد"
نص رسالة = "مرحباً بالعالم!"
نص متعدد_الأسطر = "السطر الأول\nالسطر الثاني"
```

### `منطقي`
قيمة صحيح/خطأ (boolean).

```س
منطقي نشط = صحيح
منطقي متاح = خطأ
```

### `مصفوفة`
قائمة مرتبة من العناصر (array).

```س
مصفوفة أرقام = [1، 2، 3، 4، 5]
مصفوفة أسماء = ["أحمد"، "سارة"، "محمد"]
مصفوفة فارغة = []
```

### `قاموس`
أزواج مفتاح-قيمة (dictionary).

```س
قاموس شخص = {
    "الاسم": "أحمد"،
    "العمر": 25،
    "المدينة": "الرياض"
}
```

### `مجموعة`
قيم فريدة غير مكررة (set).

```س
مجموعة أرقام = {1، 2، 3، 4، 5}
```

### `متغير`
نوع ديناميكي يُستدل تلقائياً.

```س
متغير س = 10        # يصبح رقم
متغير اسم = "أحمد"  # يصبح نص
```

## 🔀 التحكم في التدفق

### `إذا` / `وإلا_إذا` / `وإلا`
عبارات شرطية.

```س
إذا (العمر >= 18)
    اطبع("بالغ")
وإلا_إذا (العمر >= 13)
    اطبع("مراهق")
وإلا
    اطبع("طفل")
نهاية
```

### `طابق` / `حالة`
مطابقة الأنماط.

```س
طابق اليوم
    حالة 1: اطبع("الأحد")
    حالة 2: اطبع("الاثنين")
    حالة _: اطبع("يوم آخر")  # الحالة الافتراضية
نهاية
```

### `بينما`
حلقة تكرار شرطية.

```س
رقم ع = 0
بينما (ع < 5)
    اطبع(ع)
    ع = ع + 1
نهاية
```

### `لكل`
حلقة تكرار على عناصر.

```س
مصفوفة أرقام = [1، 2، 3، 4، 5]
لكل (رقم في أرقام)
    اطبع(رقم)
نهاية
```

### `اكسر`
يخرج من الحلقة فوراً.

```س
بينما (صحيح)
    إذا (الشرط)
        اكسر
    نهاية
نهاية
```

### `استمر`
يتخطى باقي الدورة الحالية.

```س
لكل (رقم في أرقام)
    إذا (رقم % 2 == 0)
        استمر  # تخطي الأرقام الزوجية
    نهاية
    اطبع(رقم)
نهاية
```

## 🏗️ البرمجة الكائنية

### `فئة`
تُعرّف فئة (class).

```س
فئة سيارة
    نص اللون
    رقم السرعة
    
    دالة أنشئ(نص لون)
        هذا.اللون = لون
        هذا.السرعة = 0
    نهاية
    
    دالة سرّع(رقم مقدار)
        هذا.السرعة = هذا.السرعة + مقدار
    نهاية
نهاية
```

### `هذا`
يشير إلى الكائن الحالي.

```س
دالة عين_الاسم(نص اسم)
    هذا.الاسم = اسم
نهاية
```

### `يرث`
توريث من فئة أخرى.

```س
فئة قط يرث حيوان
    دالة أصدر_صوت()
        اطبع("مياو!")
    نهاية
نهاية
```

### `فوق`
يشير إلى الفئة الأب.

```س
فئة كلب يرث حيوان
    دالة أنشئ(نص اسم)
        فوق.أنشئ(اسم)  # استدعاء منشئ الأب
    نهاية
نهاية
```

### `واجهة`
تُعرّف واجهة (interface).

```س
واجهة قابل_للطباعة
    دالة اطبع_نفسك()
نهاية
```

### `يطبق`
تطبيق واجهة.

```س
فئة تقرير يطبق قابل_للطباعة
    دالة اطبع_نفسك()
        اطبع("محتوى التقرير")
    نهاية
نهاية
```

### `خاص`
خاصية أو دالة خاصة.

```س
فئة حساب
    خاص رقم _الرصيد
    
    دالة الرصيد() -> رقم
        ارجع هذا._الرصيد
    نهاية
نهاية
```

## ⚠️ معالجة الأخطاء

### `حاول`
يبدأ كتلة قد تُنتج خطأ.

```س
حاول
    رقم نتيجة = 10 / 0
اصطاد (خطأ)
    اطبع("حدث خطأ!")
نهاية
```

### `اصطاد`
يلتقط الخطأ ويعالجه.

```س
حاول
    # كود خطير
اصطاد (خطأ_قسمة خ)
    اطبع("قسمة على صفر!")
اصطاد (خطأ خ)
    اطبع("خطأ: " + خ.رسالة)
نهاية
```

### `أخيراً`
يُنفَّذ دائماً بعد حاول/اصطاد.

```س
حاول
    ملف = افتح("بيانات.txt")
    # ... العمليات
اصطاد (خطأ)
    اطبع("خطأ!")
أخيراً
    ملف.اغلق()  # يُنفَّذ دائماً
نهاية
```

### `ارمِ`
يرمي استثناء.

```س
دالة قسمة(رقم أ، رقم ب) -> رقم
    إذا (ب == 0)
        ارمِ خطأ.أنشئ("لا يمكن القسمة على صفر")
    نهاية
    ارجع أ / ب
نهاية
```

### `استثناء`
يُعرّف نوع استثناء مخصص.

```س
استثناء خطأ_تحقق يرث خطأ
    نص الحقل
    
    دالة أنشئ(نص رسالة، نص حقل)
        فوق.أنشئ(رسالة)
        هذا.الحقل = حقل
    نهاية
نهاية
```

## 📦 الاستيراد والتصدير

### `استورد`
يستورد وحدة أو مكتبة.

```س
استورد رياضيات من "stdlib/math"
استورد شبكة من "stdlib/network"
استورد {قائمة، مصفوفة} من "stdlib/collections"
```

### `صدّر`
يُصدّر دالة أو فئة للاستخدام الخارجي.

```س
صدّر دالة حساب_المساحة(رقم طول، رقم عرض) -> رقم
    ارجع طول * عرض
نهاية
```

## 🎭 القيم الخاصة

### `صحيح` / `خطأ`
القيم المنطقية.

```س
منطقي نشط = صحيح
منطقي متوقف = خطأ
```

### `فارغ`
قيمة فارغة (null).

```س
متغير س = فارغ
إذا (س == فارغ)
    اطبع("المتغير فارغ")
نهاية
```

## 🔧 أدوات إضافية

### `باستخدام` / `نهاية_استخدام`
مدير السياق لإدارة الموارد.

```س
باستخدام ملف = افتح("بيانات.txt") كـ م
    نص محتوى = م.اقرأ()
نهاية_استخدام  # يُغلق الملف تلقائياً
```

### `تأكد`
التأكيد (assertion) للتصحيح.

```س
دالة جذر_تربيعي(عشري س) -> عشري
    تأكد(س >= 0، "لا يمكن حساب الجذر لرقم سالب")
    ارجع جذر(س)
نهاية
```

### `@`
بادئة المزخرفات (decorators).

```س
@توقيت
دالة عملية_بطيئة()
    # ...
نهاية
```
