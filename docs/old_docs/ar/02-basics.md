# 📘 أساسيات لغة ص

## مقدمة

في هذا الفصل ستتعلم الأساسيات التي تحتاجها لكتابة برامج حقيقية. سنغطي:
- المتغيرات وأنواع البيانات
- العمليات الحسابية والمنطقية
- الثوابت والتعليقات
- أفضل الممارسات لكتابة كود نظيف

---

## 🗃️ المتغيرات

### ما هو المتغير؟

المتغير مثل **صندوق** نضع فيه قيمة ونعطيه اسماً. يمكننا:
- وضع قيمة في الصندوق
- قراءة ما بداخله
- تغيير محتواه

### كيف نعرّف متغيراً؟

```س
# الطريقة 1: مع تحديد النوع
رقم عمري = 25
نص اسمي = "أحمد"
عشري راتبي = 5000.50
منطقي متزوج = صحيح

# الطريقة 2: استدلال النوع تلقائياً
عمرك = 30           # المترجم يعرف أنه رقم
اسمك = "سارة"       # المترجم يعرف أنه نص
```

### قواعد تسمية المتغيرات

| ✅ صحيح | ❌ خاطئ | السبب |
|---------|---------|-------|
| `اسم_المستخدم` | `اسم المستخدم` | لا مسافات |
| `عمر١` | `1عمر` | لا يبدأ برقم |
| `_خاص` | `رقم` | الكلمات المفتاحية محجوزة |
| `totalCount` | `total-count` | لا شرطات |

**نصيحة:** اختر أسماء واضحة تصف محتوى المتغير!

```س
# ❌ سيء
رقم س = 25
نص ن = "أحمد"

# ✅ جيد
رقم عمر_الموظف = 25
نص اسم_الموظف = "أحمد"
```

## 📊 أنواع البيانات

### الأنواع الأساسية

| النوع | الوصف | مثال |
|-------|-------|------|
| `رقم` | عدد صحيح | `42`, `-7`, `0` |
| `عشري` | عدد عشري | `3.14`, `-0.5` |
| `نص` | سلسلة حروف | `"مرحباً"`, `"123"` |
| `منطقي` | صحيح أو خطأ | `صحيح`, `خطأ` |
| `مصفوفة` | قائمة قيم | `[1، 2، 3]` |

### أمثلة تفصيلية

#### الأرقام الصحيحة (`رقم`)
```س
رقم عمر = 25
رقم درجة_حرارة = -5
رقم عدد_الطلاب = 30

# العمليات الحسابية
رقم مجموع = 10 + 5      # = 15
رقم فرق = 10 - 3        # = 7
رقم حاصل_ضرب = 4 * 5    # = 20
رقم ناتج_قسمة = 20 / 4  # = 5
رقم الباقي = 17 % 5     # = 2 (باقي القسمة)
```

#### الأعداد العشرية (`عشري`)
```س
عشري سعر = 19.99
عشري درجة = 98.6
عشري نسبة = 0.75

# دقة عالية في الحسابات المالية
عشري ضريبة = سعر * 0.15      # = 2.9985
عشري الإجمالي = سعر + ضريبة  # = 22.9885
```

#### النصوص (`نص`)
```س
نص اسم = "أحمد محمد"
نص تحية = "مرحباً بك!"
نص فارغ = ""

# دمج النصوص
نص رسالة = "مرحباً " + اسم + "!"  # = "مرحباً أحمد محمد!"

# رموز خاصة
نص سطر_جديد = "السطر الأول\nالسطر الثاني"
نص تاب = "عمود1\tعمود2"
نص اقتباس = "قال: \"مرحباً\""
```

**رموز الهروب:**
| الرمز | المعنى |
|-------|--------|
| `\n` | سطر جديد |
| `\t` | مسافة Tab |
| `\"` | علامة اقتباس |
| `\\` | شرطة مائلة |

#### القيم المنطقية (`منطقي`)
```س
منطقي نشط = صحيح
منطقي متاح = خطأ

# ناتج المقارنات منطقي
منطقي أكبر = 10 > 5       # = صحيح
منطقي يساوي = 5 == 5      # = صحيح
منطقي مختلف = 3 != 3      # = خطأ
```

## ➕ العمليات

### العمليات الحسابية

```س
رقم أ = 10
رقم ب = 3

اطبع(أ + ب)   # الجمع: 13
اطبع(أ - ب)   # الطرح: 7
اطبع(أ * ب)   # الضرب: 30
اطبع(أ / ب)   # القسمة: 3
اطبع(أ % ب)   # الباقي: 1
اطبع(أ ** ب)  # الأس: 1000 (10³)
```

### العمليات المقارنة

```س
رقم س = 5
رقم ص = 10

اطبع(س == ص)  # يساوي: خطأ
اطبع(س != ص)  # لا يساوي: صحيح
اطبع(س > ص)   # أكبر من: خطأ
اطبع(س < ص)   # أصغر من: صحيح
اطبع(س >= ص)  # أكبر أو يساوي: خطأ
اطبع(س <= ص)  # أصغر أو يساوي: صحيح
```

### العمليات المنطقية

```س
منطقي أ = صحيح
منطقي ب = خطأ

اطبع(أ و ب)     # AND: خطأ (كلاهما يجب أن يكون صحيح)
اطبع(أ أو ب)    # OR: صحيح (أحدهما على الأقل صحيح)
اطبع(ليس أ)     # NOT: خطأ (عكس القيمة)
```

**جدول الحقيقة:**

| أ | ب | أ و ب | أ أو ب |
|---|---|-------|--------|
| صحيح | صحيح | صحيح | صحيح |
| صحيح | خطأ | خطأ | صحيح |
| خطأ | صحيح | خطأ | صحيح |
| خطأ | خطأ | خطأ | خطأ |

### عمليات الإسناد المختصرة

```س
رقم س = 10

س = س + 5   # طريقة عادية
س += 5      # طريقة مختصرة (نفس النتيجة)

س -= 3      # س = س - 3
س *= 2      # س = س * 2
س /= 4      # س = س / 4
```

## 📝 التعليقات

التعليقات نص يتجاهله الحاسوب، نكتبها لتوثيق الكود.

```س
# هذا تعليق سطر واحد

# يمكن كتابة عدة أسطر
# كل سطر يبدأ بـ #

دالة رئيسية()
    # حساب مجموع الأرقام من 1 إلى 10
    رقم مجموع = 0
    رقم ع = 1
    
    بينما (ع <= 10)  # كرر 10 مرات
        مجموع += ع   # أضف الرقم للمجموع
        ع += 1
    نهاية
    
    اطبع(مجموع)  # النتيجة: 55
    ارجع 0
نهاية
```

### متى نكتب تعليقات؟

| ✅ اكتب تعليقاً | ❌ لا تكتب تعليقاً |
|----------------|------------------|
| شرح خوارزمية معقدة | شرح كود واضح |
| توثيق سبب قرار | تكرار ما يقوله الكود |
| تحذير من حالة خاصة | كل سطر |

```س
# ❌ تعليق غير مفيد
رقم س = 5  # نضع 5 في س

# ✅ تعليق مفيد
# نستخدم 5 لأنه الحد الأقصى المسموح حسب سياسة الشركة
رقم الحد_الأقصى = 5
```

## 🎯 أمثلة عملية

### مثال 1: حاسبة العمر

```س
دالة رئيسية()
    # بيانات المستخدم
    رقم سنة_الميلاد = 1995
    رقم السنة_الحالية = 2024
    
    # حساب العمر
    رقم العمر = السنة_الحالية - سنة_الميلاد
    
    # طباعة النتيجة
    اطبع("عمرك هو: ")
    اطبع(العمر)
    اطبع(" سنة")
    
    ارجع 0
نهاية
```

### مثال 2: تحويل درجة الحرارة

```س
دالة رئيسية()
    # درجة الحرارة بالسيلسيوس
    عشري سيلسيوس = 25.0
    
    # التحويل إلى فهرنهايت
    # الصيغة: F = (C × 9/5) + 32
    عشري فهرنهايت = (سيلسيوس * 9 / 5) + 32
    
    اطبع(سيلسيوس)
    اطبع(" درجة سيلسيوس = ")
    اطبع(فهرنهايت)
    اطبع(" درجة فهرنهايت")
    
    ارجع 0
نهاية
```

### مثال 3: حاسبة المتوسط

```س
دالة رئيسية()
    # درجات الطالب
    رقم درجة١ = 85
    رقم درجة٢ = 90
    رقم درجة٣ = 78
    رقم درجة٤ = 92
    
    # حساب المتوسط
    رقم المجموع = درجة١ + درجة٢ + درجة٣ + درجة٤
    عشري المتوسط = المجموع / 4.0
    
    اطبع("مجموع الدرجات: ")
    اطبع(المجموع)
    اطبع("\nالمتوسط: ")
    اطبع(المتوسط)
    
    ارجع 0
نهاية
```

## 💡 نصائح مهمة

### 1. اختر أسماء واضحة
```س
# ❌ سيء
رقم س = 1000
رقم ص = 150

# ✅ جيد
رقم الراتب_الأساسي = 1000
رقم البدلات = 150
```

### 2. استخدم الثوابت للقيم الثابتة
```س
# ❌ أرقام سحرية
عشري ضريبة = سعر * 0.15

# ✅ ثابت واضح
عشري نسبة_الضريبة = 0.15
عشري ضريبة = سعر * نسبة_الضريبة
```

### 3. قسّم العمليات المعقدة
```س
# ❌ صعب الفهم
رقم نتيجة = ((أ + ب) * ج - د) / (هـ + و)

# ✅ سهل الفهم
رقم مجموع = أ + ب
رقم حاصل_ضرب = مجموع * ج
رقم بعد_الطرح = حاصل_ضرب - د
رقم المقام = هـ + و
رقم نتيجة = بعد_الطرح / المقام
```

## ✅ تمارين

### تمرين 1: بيانات شخصية
أنشئ متغيرات لتخزين:
- اسمك
- عمرك
- مدينتك
- هل أنت طالب (صحيح/خطأ)

ثم اطبعها.

### تمرين 2: حاسبة المساحة
اكتب برنامجاً يحسب مساحة مستطيل (الطول × العرض).
