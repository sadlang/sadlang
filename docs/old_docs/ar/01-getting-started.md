# 🚀 البداية السريعة

## مرحباً بك في رحلة البرمجة!

هل أنت مستعد لكتابة أول برنامج لك؟ لن يستغرق الأمر أكثر من 5 دقائق!

---

## 📦 الخطوة 1: التثبيت

### على Windows

```powershell
# افتح PowerShell وانسخ هذه الأوامر
git clone https://github.com/sad-lang/sad
cd sad
cmake -B build
cmake --build build --config Release
```

### على Linux/macOS

```bash
git clone https://github.com/sad-lang/sad
cd sad
cmake -B build
cmake --build build
```

### التحقق من التثبيت

```bash
./build/bin/sad --version
# يجب أن ترى: لغة ص - الإصدار X.X.X
```

---

## 👋 الخطوة 2: مرحباً بالعالم!

### إنشاء ملف البرنامج

1. افتح محرر النصوص المفضل لديك (VS Code، Notepad++، أو حتى المفكرة)
2. أنشئ ملفاً جديداً باسم `مرحبا.s`
3. اكتب الكود التالي:

```س
# بسم الله الرحمن الرحيم
# أول برنامج لي بلغة ص

دالة رئيسية()
    اطبع("مرحباً بالعالم! 🌍")
    اطبع("أنا أتعلم البرمجة بالعربية!")
    ارجع 0
نهاية
```

### شرح الكود سطراً بسطر

| السطر | الشرح |
|-------|-------|
| `# بسم الله...` | تعليق - يتجاهله الحاسوب، للتوثيق فقط |
| `دالة رئيسية()` | نقطة بداية البرنامج - كل برنامج يحتاج هذا |
| `اطبع("...")` | يطبع النص على الشاشة |
| `ارجع 0` | ينهي البرنامج بنجاح |
| `نهاية` | نهاية الدالة |

### تشغيل البرنامج

```bash
./build/bin/sad مرحبا.s
```

**النتيجة:**
```
مرحباً بالعالم! 🌍
أنا أتعلم البرمجة بالعربية!
```

🎉 **تهانينا!** لقد كتبت أول برنامج لك!

## 🔢 الخطوة 3: برنامج الآلة الحاسبة

لنكتب برنامجاً أكثر فائدة - آلة حاسبة بسيطة:

```س
# آلة حاسبة بسيطة
دالة رئيسية()
    اطبع("=== الآلة الحاسبة ===\n")
    
    # تعريف الأرقام
    رقم أ = 10
    رقم ب = 5
    
    # العمليات الحسابية
    اطبع("الجمع: ")
    اطبع(أ + ب)  # يطبع: 15
    
    اطبع("\nالطرح: ")
    اطبع(أ - ب)  # يطبع: 5
    
    اطبع("\nالضرب: ")
    اطبع(أ * ب)  # يطبع: 50
    
    اطبع("\nالقسمة: ")
    اطبع(أ / ب)  # يطبع: 2
    
    ارجع 0
نهاية
```

## 🤔 الخطوة 4: اتخاذ القرارات

البرامج تحتاج أن تتخذ قرارات. هكذا نفعل ذلك:

```س
# برنامج تقييم الدرجات
دالة رئيسية()
    رقم درجة = 85
    
    اطبع("درجتك: ")
    اطبع(درجة)
    اطبع("\nالتقدير: ")
    
    إذا (درجة >= 90)
        اطبع("ممتاز! 🌟")
    وإلا_إذا (درجة >= 80)
        اطبع("جيد جداً! 👍")
    وإلا_إذا (درجة >= 70)
        اطبع("جيد")
    وإلا_إذا (درجة >= 60)
        اطبع("مقبول")
    وإلا
        اطبع("راسب 😢")
    نهاية
    
    ارجع 0
نهاية
```

### شرح الشروط

```س
إذا (شرط)
    # ينفذ إذا الشرط صحيح
وإلا_إذا (شرط آخر)
    # ينفذ إذا الشرط الآخر صحيح
وإلا
    # ينفذ إذا كل الشروط خاطئة
نهاية
```

**ملاحظة مهمة:** 
- نستخدم `نهاية` لإغلاق الكتلة
- لا نستخدم الأقواس المعقوفة `{}` مثل لغات أخرى

## 🔄 الخطوة 5: التكرار

كثيراً ما نحتاج تكرار عملية ما. إليك الطرق:

### حلقة بينما (while)

```س
# عد من 1 إلى 5
دالة رئيسية()
    رقم عداد = 1
    
    بينما (عداد <= 5)
        اطبع(عداد)
        اطبع(" ")
        عداد = عداد + 1
    نهاية
    
    # يطبع: 1 2 3 4 5
    ارجع 0
نهاية
```

### حلقة لكل (foreach)

```س
# طباعة عناصر مصفوفة
دالة رئيسية()
    مصفوفة أسماء = ["أحمد"، "سارة"، "محمد"، "فاطمة"]
    
    لكل (اسم في أسماء)
        اطبع("مرحباً ")
        اطبع(اسم)
        اطبع("!\n")
    نهاية
    
    ارجع 0
نهاية
```

## ❓ أسئلة شائعة

### س: لماذا `نهاية` وليس `}`؟
**ج:** لغة ص صُممت لتكون سهلة القراءة بالعربية. كلمة `نهاية` أوضح من قوس غريب!

### س: هل يجب أن أكتب `دالة رئيسية()`؟
**ج:** نعم! هذه نقطة بداية كل برنامج. بدونها، الحاسوب لا يعرف من أين يبدأ.

### س: ما الفرق بين `ارجع` و`إرجاع`؟
**ج:** نفس الشيء! يمكنك استخدام أيهما تفضل.

### س: لماذا `ارجع 0`؟
**ج:** العدد `0` يعني "انتهى البرنامج بنجاح". رقم آخر يعني حدث خطأ.
