## مقدمة

لغة ص هي أول لغة برمجة عربية كاملة المواصفات، صُممت لتكون سهلة التعلم وقوية الأداء في آن واحد. توفر لغة ص مجموعة متكاملة من أدوات التطوير التي تمكّن المبرمج العربي من كتابة برامج احترافية بلغته الأم.

### لماذا لغة ص؟

- **🌍 عربية بالكامل**: كلمات مفتاحية وأسماء دوال ورسائل خطأ بالعربية
- **⚡ أداء عالي**: ترجمة إلى كود آلي أصلي عبر LLVM
- **🔒 آمنة**: نظام ملكية يمنع أخطاء الذاكرة
- **📱 متعددة المنصات**: ويندوز، لينكس، ماك، أندرويد، iOS، والويب
- **🧰 أدوات متكاملة**: CLI، LSP، مدير حزم، ومنسّق كود

### المتطلبات الأساسية

| المتطلب | الحد الأدنى | الموصى به |
|---------|-------------|-----------|
| نظام التشغيل | Windows 10 / Ubuntu 18.04 / macOS 10.14 | أحدث إصدار |
| ذاكرة RAM | 4 GB | 8 GB |
| مساحة القرص | 500 MB | 2 GB |
| المعالج | x86_64 أو ARM64 | - |

## التثبيت

### الطريقة السريعة (موصى بها)

#### على ويندوز (PowerShell):
```powershell
# تحميل وتثبيت لغة ص
irm https://sadlang.org/install.ps1 | iex
```

#### على لينكس / ماك:
```bash
# تحميل وتثبيت لغة ص
curl -fsSL https://sadlang.org/install.sh | sh
```

### التثبيت من المصدر

```bash
# استنساخ المستودع
git clone https://github.com/sad-lang/sad.git
cd sad

# البناء باستخدام CMake
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build . --config Release

# التثبيت (قد يتطلب صلاحيات المدير)
cmake --install .
```

### التحقق من التثبيت

```bash
# عرض إصدار لغة ص
ص نسخة

# أو بالإنجليزية
sad version
```


## أوامر سطر الأوامر

### نظرة عامة

أداة `ص` (أو `sad` بالإنجليزية) هي الواجهة الرئيسية للتعامل مع لغة ص. تتبع الصيغة التالية:

```
ص <أمر> [خيارات] [ملفات]
sad <command> [options] [files]
```

### قائمة الأوامر المتاحة

| الأمر العربي | الأمر الإنجليزي | الوصف |
|-------------|----------------|-------|
| `ص بناء` | `sad build` | ترجمة الكود إلى ملف تنفيذي |
| `ص شغّل` | `sad run` | ترجمة وتشغيل برنامج |
| `ص اختبر` | `sad test` | تشغيل اختبارات المشروع |
| `ص جديد` | `sad new` | إنشاء مشروع جديد |
| `ص أضف` | `sad add` | إضافة اعتمادية |
| `ص نشر` | `sad publish` | نشر حزمة |
| `ص وثّق` | `sad doc` | توليد التوثيق |
| `ص نسّق` | `sad fmt` | تنسيق الكود |
| `ص تحقق` | `sad check` | التحقق من الكود |
| `ص نسخة` | `sad version` | عرض الإصدار |
| `ص مساعدة` | `sad help` | عرض المساعدة |

## ص بناء

أمر البناء يترجم الكود المصدري إلى ملفات تنفيذية أو مكتبات.

### الصيغة الأساسية

```bash
ص بناء [ملف.ص] [خيارات]
sad build [file.s] [options]
```

### الخيارات

| الخيار العربي | الخيار الإنجليزي | الوصف | مثال |
|--------------|-----------------|-------|------|
| `--إخراج` | `-o, --output` | مسار ملف الإخراج | `--إخراج برنامجي` |
| `--إصدار` | `--release` | بناء محسّن للإنتاج | `ص بناء --إصدار` |
| `--تطوير` | `--debug` | بناء مع معلومات التصحيح | `ص بناء --تطوير` |
| `--تحسين` | `-O` | مستوى التحسين (0-3, s, z) | `-O3` |
| `--هدف` | `--target` | المنصة المستهدفة | `--هدف wasm32` |
| `--مكتبة` | `--lib` | بناء كمكتبة ثابتة | `ص بناء --مكتبة` |
| `--مشتركة` | `--shared` | بناء كمكتبة مشتركة | `ص بناء --مشتركة` |
| `--واسم` | `--wasm` | بناء لـ WebAssembly | `ص بناء --واسم` |
| `--مفصل` | `-v, --verbose` | إخراج مفصل | `ص بناء -v` |

### مستويات التحسين

| المستوى | الوصف | حالة الاستخدام |
|---------|-------|----------------|
| `O0` | بدون تحسين | التطوير والتصحيح |
| `O1` | تحسينات أساسية | توازن معقول |
| `O2` | تحسينات قياسية (افتراضي) | الاستخدام العام |
| `O3` | تحسينات قصوى | أقصى أداء |
| `Os` | تحسين الحجم | تطبيقات الويب |
| `Oz` | أدنى حجم ممكن | الأنظمة المدمجة |

### أمثلة

```bash
# بناء برنامج بسيط
ص بناء برنامج.ص

# بناء مع تحديد اسم الإخراج
ص بناء برنامج.ص --إخراج تطبيقي

# بناء للإنتاج (محسّن)
ص بناء برنامج.ص --إصدار

# بناء لـ WebAssembly
ص بناء تطبيق_ويب.ص --واسم

# بناء كمكتبة ثابتة
ص بناء مكتبتي.ص --مكتبة

# بناء مع معلومات التصحيح
ص بناء برنامج.ص --تطوير
```

### الأهداف المدعومة

| الهدف | الوصف |
|-------|-------|
| `x86_64-pc-windows-msvc` | ويندوز 64-بت |
| `x86_64-pc-linux-gnu` | لينكس 64-بت |
| `aarch64-apple-macos` | ماك على معالجات Apple Silicon |
| `x86_64-apple-macos` | ماك على معالجات Intel |
| `aarch64-linux-android` | أندرويد ARM |
| `wasm32-unknown-unknown` | WebAssembly |

## ص شغّل

أمر التشغيل يجمع بين الترجمة والتنفيذ في خطوة واحدة.

### الصيغة الأساسية

```bash
ص شغّل [ملف.ص] [-- وسائط_البرنامج]
sad run [file.s] [-- program_arguments]
```

### الخيارات

| الخيار العربي | الخيار الإنجليزي | الوصف |
|--------------|-----------------|-------|
| `--إصدار` | `--release` | تشغيل بوضع الإصدار (محسّن) |
| `--تطوير` | `--debug` | تشغيل بوضع التطوير |
| `--وقت` | `--time` | عرض وقت التنفيذ |
| `--راقب` | `--watch` | مراقبة التغييرات وإعادة التشغيل |
| `--احتفظ` | `--keep` | الاحتفاظ بالملف التنفيذي المؤقت |

### أمثلة

```bash
# تشغيل برنامج بسيط
ص شغّل برنامج.ص

# تشغيل مع وسائط
ص شغّل برنامج.ص -- ملف.txt --كلمة

# تشغيل بوضع الإصدار (أسرع)
ص شغّل برنامج.ص --إصدار

# تشغيل مع عرض الوقت
ص شغّل برنامج.ص --وقت

# تشغيل مع مراقبة التغييرات
ص شغّل برنامج.ص --راقب

# تشغيل من مجلد المشروع (بدون تحديد ملف)
cd مشروعي
ص شغّل
```

### تمرير الوسائط للبرنامج

استخدم `--` للفصل بين خيارات أداة `ص` ووسائط البرنامج:

```bash
ص شغّل خادم.ص --إصدار -- --منفذ 8080 --مسار /api
```

في هذا المثال:
- `--إصدار` خيار لأداة `ص`
- `--منفذ 8080 --مسار /api` وسائط للبرنامج

## ص اختبر

أمر الاختبار يكتشف ويشغل جميع اختبارات المشروع.

### الصيغة الأساسية

```bash
ص اختبر [نمط] [خيارات]
sad test [pattern] [options]
```

### الخيارات

| الخيار العربي | الخيار الإنجليزي | الوصف |
|--------------|-----------------|-------|
| `--متوازي` | `--parallel` | تشغيل الاختبارات بالتوازي |
| `--خيوط` | `-j, --jobs` | عدد خيوط الاختبار |
| `--مفصل` | `-v, --verbose` | إخراج مفصل |
| `--صامت` | `-q, --quiet` | إخراج هادئ |
| `--صفّي` | `-f, --filter` | تصفية بنمط |
| `--تغطية` | `--coverage` | توليد تقرير تغطية |
| `--توقف-عند-فشل` | `--fail-fast` | التوقف عند أول فشل |
| `--تقرير` | `--report` | حفظ التقرير في ملف |
| `--صيغة` | `--format` | صيغة التقرير (text, json, junit) |

### أنواع الاختبارات

#### اختبار وحدة (Unit Test)

```sad
# tests/test_حاسبة.ص

استورد "../src/حاسبة.ص"

#[اختبار]
دالة اختبار_الجمع()
    متغير نتيجة = اجمع(2، 3)
    تأكد_يساوي(نتيجة، 5)
نهاية

#[اختبار]
دالة اختبار_الطرح()
    متغير نتيجة = اطرح(10، 4)
    تأكد_يساوي(نتيجة، 6)
نهاية
```

#### اختبار يتوقع فشلاً

```sad
#[اختبار_يفشل]
دالة اختبار_قسمة_على_صفر()
    اقسم(10، 0)  # يجب أن يُلقي هلع
نهاية
```

#### اختبار خاصية (Property Test)

```sad
#[اختبار_خاصية]
دالة اختبار_الجمع_تبادلي(أ: عدد، ب: عدد)
    تأكد_يساوي(اجمع(أ، ب)، اجمع(ب، أ))
نهاية
```

### أمثلة

```bash
# تشغيل جميع الاختبارات
ص اختبر

# تشغيل اختبارات محددة
ص اختبر اختبار_المحلل*

# تشغيل بالتوازي مع 8 خيوط
ص اختبر --متوازي --خيوط 8

# تشغيل مع تقرير تغطية
ص اختبر --تغطية

# حفظ تقرير JSON
ص اختبر --تقرير نتائج.json --صيغة json
```

## ملف المشروع ص.toml

ملف `ص.toml` هو ملف إعدادات المشروع بصيغة TOML.

### مثال كامل

```toml
# معلومات الحزمة
[حزمة]
اسم = "مشروعي"
نسخة = "1.0.0"
مؤلفون = ["أحمد محمد <ahmed@example.com>"]
وصف = "مشروع تجريبي للغة ص"
ترخيص = "MIT"
مستودع = "https://github.com/ahmed/مشروعي"

# الاعتماديات
[اعتماديات]
json = "1.0"
http = "2.1"

# اعتماديات التطوير
[اعتماديات-تطوير]
اختبار = "1.0"

# إعدادات البناء
[بناء]
هدف = "x86_64-pc-linux-gnu"
تحسين = "2"

# إعدادات الإصدار
[ملف-تعريف.إصدار]
تحسين = "3"
تصحيح = false

# إعدادات التطوير
[ملف-تعريف.تطوير]
تحسين = "0"
تصحيح = true
```

### الأقسام الرئيسية

| القسم | الوصف |
|-------|-------|
| `[حزمة]` | معلومات أساسية عن المشروع |
| `[اعتماديات]` | المكتبات المطلوبة |
| `[اعتماديات-تطوير]` | اعتماديات للتطوير فقط |
| `[بناء]` | إعدادات البناء |
| `[ملف-تعريف.*]` | إعدادات خاصة بالوضع |

## أمثلة عملية

### برنامج "مرحباً بالعالم"

```sad
# مرحبا.ص
دالة رئيسية()
    اطبع("مرحباً بالعالم! 🌍")
    ارجع 0
نهاية
```

التشغيل:
```bash
ص شغّل مرحبا.ص
```

### قراءة ملف

```sad
# قراءة_ملف.ص
استورد "ملفات" من المكتبة_القياسية

دالة رئيسية()
    # محاولة قراءة ملف
    نتيجة محتوى = ملفات.اقرأ("بيانات.txt")
    
    طابق محتوى
        حالة نجاح(نص):
            اطبع("محتوى الملف:")
            اطبع(نص)
        حالة فشل(خطأ):
            اطبع("خطأ في قراءة الملف: " + خطأ)
    نهاية
    
    ارجع 0
نهاية
```

### خادم HTTP بسيط

```sad
# خادم.ص
استورد "شبكة" من المكتبة_القياسية

غير_متزامن دالة رئيسية()
    متغير خادم = شبكة.خادم_http()
    
    خادم.عند_طلب("/") { طلب، استجابة ->
        استجابة.ارسل("مرحباً من خادم لغة ص! 🎉")
    }
    
    خادم.عند_طلب("/api/مستخدمين") { طلب، استجابة ->
        استجابة.نوع_المحتوى("application/json")
        استجابة.ارسل(`{"المستخدمون": ["أحمد", "محمد", "فاطمة"]}`)
    }
    
    اطبع("الخادم يعمل على http://localhost:8080")
    انتظر خادم.ابدأ(8080)
نهاية
```

التشغيل:
```bash
ص شغّل خادم.ص
```
