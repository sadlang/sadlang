## مقدمة

نظام الأنواع في لغة ص هو نظام **ثابت قوي** (statically typed, strongly typed) مستوحى من أفضل ممارسات لغات مثل Rust و Haskell، مع واجهة **عربية أصيلة**.

### الفلسفة الأساسية

```
"الأمان أولاً، الأداء ثانياً، سهولة الاستخدام ثالثاً"
```

نظام الأنواع يضمن:
- ✅ اكتشاف الأخطاء في وقت الترجمة
- ✅ تحويلات آمنة بين الأنواع
- ✅ دعم كامل للبرمجة المعممة
- ✅ واجهة برمجة عربية طبيعية

## الأنواع البدائية

### الأعداد الصحيحة الموجبة (Unsigned Integers)

| النوع العربي | النوع الإنجليزي | الحجم | النطاق |
|-------------|-----------------|-------|--------|
| `ح8` | `u8` | 1 بايت | 0 إلى 255 |
| `ح16` | `u16` | 2 بايت | 0 إلى 65,535 |
| `ح32` | `u32` | 4 بايت | 0 إلى 4,294,967,295 |
| `ح64` | `u64` | 8 بايت | 0 إلى 18,446,744,073,709,551,615 |

### الأعداد الصحيحة المؤشرة (Signed Integers)

| النوع العربي | النوع الإنجليزي | الحجم | النطاق |
|-------------|-----------------|-------|--------|
| `ع8` | `i8` | 1 بايت | -128 إلى 127 |
| `ع16` | `i16` | 2 بايت | -32,768 إلى 32,767 |
| `ع32` | `i32` | 4 بايت | -2.1 مليار إلى 2.1 مليار |
| `ع64` | `i64` | 8 بايت | نطاق ضخم جداً |
| `رقم` | `int` | 8 بايت | الاسم المختصر لـ `ع64` |

### الأعداد العشرية (Floating Point)

| النوع العربي | النوع الإنجليزي | الحجم | الدقة |
|-------------|-----------------|-------|-------|
| `عش32` | `f32` | 4 بايت | ~7 أرقام معنوية |
| `عش64` | `f64` | 8 بايت | ~15 رقماً معنوياً |
| `عشري` | `float` | 8 بايت | الاسم المختصر لـ `عش64` |

### أنواع أخرى

| النوع العربي | النوع الإنجليزي | الوصف |
|-------------|-----------------|-------|
| `منطقي` | `bool` | صحيح أو خطأ |
| `حرف` | `char` | حرف يونيكود واحد (32 بت) |
| `بايت` | `byte` | بايت واحد (8 بت) |
| `فراغ` | `void` | لا قيمة |
| `أبداً` | `never` | للدوال التي لا ترجع |

### مثال على الاستخدام

```sad
// تعريف متغيرات بأنواع مختلفة
دع عمر: ح8 = 25                    // عدد موجب صغير
دع درجة_الحرارة: ع16 = -10         // عدد سالب
دع المسافة: عش64 = 3.14159         // عدد عشري
دع نشط: منطقي = صحيح              // قيمة منطقية
دع الحرف_الأول: حرف = 'ص'         // حرف يونيكود

// استخدام الاسم المختصر
دع العدد: رقم = 1000000            // رقم = ع64
دع النسبة: عشري = 0.75             // عشري = عش64
```

### التحويل الآمن بين الأنواع

```sad
// التحويل الضمني الآمن (من الأصغر للأكبر)
دع صغير: ع8 = 100
دع كبير: ع64 = صغير               // ✅ آمن تلقائياً

// التحويل الصريح (قد يفقد بيانات)
دع ضخم: ع64 = 1000000
دع مختصر: ع16 = ضخم كـ ع16        // ⚠️ تحذير: قد يفقد بيانات
```

### قواعد التحويل الضمني

```
ع8  → ع16 → ع32 → ع64  ✅ آمن
ح8  → ح16 → ح32 → ح64  ✅ آمن
عش32 → عش64            ✅ آمن
ع32 → عش64             ✅ آمن (مع احتمال فقدان الدقة)
```

## البنيات

البنية (بنية/هيكل) هي نوع مركب يجمع عدة قيم معاً.

### التعريف الأساسي

```sad
// تعريف بنية بسيطة
بنية نقطة {
    س: عشري،
    ص: عشري
}

// أو باستخدام الكلمة البديلة
هيكل مستطيل {
    عرض: عشري،
    ارتفاع: عشري
}
```

### إنشاء مثيلات

```sad
// إنشاء مثيل جديد
دع النقطة = نقطة {
    س: 10.0،
    ص: 20.0
}

// الوصول للحقول
اطبع(النقطة.س)      // 10.0
اطبع(النقطة.ص)      // 20.0
```

### البنيات المعممة

```sad
// بنية معممة مع معامل نوع واحد
بنية<ت> صندوق {
    محتوى: ت
}

// بنية معممة مع قيد سمة
بنية<ت: قابل_للنسخ> مخزن {
    القيمة: ت،
    العدد: رقم
}

// الاستخدام
دع صندوق_أرقام = صندوق<رقم> { محتوى: 42 }
دع صندوق_نصوص = صندوق<نص> { محتوى: "مرحبا" }
```

### تخطيط الذاكرة

```sad
// تخطيط تلقائي (الافتراضي)
بنية تلقائي {
    أ: ح8،
    ب: ح64
}  // الحجم: 16 بايت (مع محاذاة)

// تخطيط مضغوط
#[تخطيط(مضغوط)]
بنية مضغوط {
    أ: ح8،
    ب: ح64
}  // الحجم: 9 بايت (بدون محاذاة)

// تخطيط متوافق مع C
#[تخطيط(سي)]
بنية متوافق_سي {
    أ: ح32،
    ب: ح32
}
```

### الدوال المرتبطة

```sad
بنية دائرة {
    نصف_القطر: عشري
}

// دوال مرتبطة بالبنية
تنفيذ دائرة {
    // دالة منشئة (ثابتة)
    دالة جديدة(نق: عشري) -> دائرة {
        أرجع دائرة { نصف_القطر: نق }
    }
    
    // دالة على المثيل
    دالة المساحة(ذات) -> عشري {
        أرجع 3.14159 * ذات.نصف_القطر * ذات.نصف_القطر
    }
    
    // دالة تعدل المثيل
    دالة تكبير(ذات&، مضاعف: عشري) {
        ذات.نصف_القطر *= مضاعف
    }
}

// الاستخدام
دع د = دائرة::جديدة(5.0)
اطبع(د.المساحة())        // 78.54
د.تكبير(2.0)
اطبع(د.المساحة())        // 314.16
```

## التعدادات

التعداد (تعداد) يمثل نوعاً يمكن أن يكون واحداً من عدة متغيرات محتملة.

### التعداد البسيط (بنمط C)

```sad
// تعداد بسيط بدون بيانات
تعداد اللون {
    أحمر،
    أخضر،
    أزرق
}

// الاستخدام
دع لوني = اللون::أحمر

// المطابقة
طابق لوني {
    اللون::أحمر => اطبع("أحمر!"),
    اللون::أخضر => اطبع("أخضر!"),
    اللون::أزرق => اطبع("أزرق!")
}
```

### التعداد مع بيانات

```sad
// تعداد مع بيانات tuple
تعداد رسالة {
    خروج،                          // بدون بيانات
    تحريك(رقم، رقم)،              // tuple مع قيمتين
    كتابة(نص)                      // tuple مع قيمة واحدة
}

// تعداد مع بيانات struct
تعداد حدث {
    نقر { س: رقم، ص: رقم }،
    ضغط_مفتاح { الرمز: حرف }،
    إغلاق
}

// الاستخدام
دع ر = رسالة::تحريك(10، 20)

طابق ر {
    رسالة::خروج => إنهاء()،
    رسالة::تحريك(س، ص) => تحريك_إلى(س، ص)،
    رسالة::كتابة(نص) => اطبع(نص)
}
```

### النوع اختياري (Option)

نوع مدمج للقيم التي قد تكون موجودة أو لا.

```sad
// التعريف المدمج (مُعرَّف مسبقاً)
تعداد<ت> اختياري {
    لا_شيء،            // None
    بعض(ت)             // Some(T)
}

// الاستخدام
دالة أوجد_مستخدم(معرف: رقم) -> اختياري<مستخدم> {
    إذا معرف_موجود(معرف) {
        أرجع بعض(جلب_مستخدم(معرف))
    }
    أرجع لا_شيء
}

// التعامل مع النتيجة
دع نتيجة = أوجد_مستخدم(42)

طابق نتيجة {
    بعض(م) => اطبع("وجدنا: " + م.الاسم)،
    لا_شيء => اطبع("المستخدم غير موجود")
}

// أو باستخدام الاختصارات
إذا دع بعض(م) = نتيجة {
    اطبع("وجدنا: " + م.الاسم)
}

// أو باستخدام unwrap (خطير!)
دع المستخدم = نتيجة.افتح()           // ⚠️ يتوقف إذا كان لا_شيء
دع المستخدم = نتيجة.افتح_أو(افتراضي)  // ✅ آمن
```

### النوع نتيجة (Result)

نوع مدمج لمعالجة الأخطاء.

```sad
// التعريف المدمج (مُعرَّف مسبقاً)
تعداد<ن، خ> نتيجة {
    نجاح(ن)،           // Ok(T)
    خطأ(خ)             // Err(E)
}

// الاستخدام
دالة اقرأ_ملف(المسار: نص) -> نتيجة<نص، خطأ_قراءة> {
    إذا !ملف_موجود(المسار) {
        أرجع خطأ(خطأ_قراءة::ملف_غير_موجود)
    }
    أرجع نجاح(محتوى_الملف(المسار))
}

// التعامل مع النتيجة
دع محتوى = اقرأ_ملف("بيانات.txt")

طابق محتوى {
    نجاح(نص) => معالجة(نص)،
    خطأ(خ) => اطبع("خطأ: " + خ.رسالة())
}

// استخدام عامل ?
دالة معالجة_ملف(المسار: نص) -> نتيجة<()، خطأ_قراءة> {
    دع محتوى = اقرأ_ملف(المسار)?   // ينشر الخطأ تلقائياً
    اطبع(محتوى)
    أرجع نجاح(())
}
```

## الاتحادات

الاتحاد (اتحاد) هو نوع يحتل نفس المساحة في الذاكرة لعدة أنواع مختلفة. **استخدامه يتطلب كتلة غير_آمن**.

### التعريف

```sad
// اتحاد بسيط
اتحاد قيمة_خام {
    صحيح: ع64،
    عشري: عش64،
    بايتات: [ح8؛ 8]
}
```

### الاستخدام (غير آمن)

```sad
دع ق = قيمة_خام { صحيح: 42 }

غير_آمن {
    // الوصول للقيمة كعدد صحيح
    اطبع(ق.صحيح)      // 42
    
    // ⚠️ خطير: تفسير نفس البتات كعشري
    اطبع(ق.عشري)      // قيمة غير متوقعة!
}
```

### متى نستخدم الاتحادات؟

الاتحادات مفيدة في:
- التفاعل مع كود C (FFI)
- تحويلات البتات المنخفضة المستوى
- تحسين حجم الذاكرة

```sad
// مثال: تمثيل عنوان IP
اتحاد عنوان_خام {
    v4: [ح8؛ 4]،
    v6: [ح16؛ 8]
}

// الأفضل: استخدام تعداد بدلاً من اتحاد
تعداد عنوان_آي_بي {
    الرابع([ح8؛ 4])،
    السادس([ح16؛ 8])
}
```

## المعممات

المعممات (Generics) تسمح بكتابة كود يعمل مع أنواع متعددة.

### الدوال المعممة

```sad
// دالة معممة بسيطة
دالة<ت> هوية(قيمة: ت) -> ت {
    أرجع قيمة
}

// الاستخدام
دع أ = هوية(42)           // ت = رقم
دع ب = هوية("مرحبا")      // ت = نص
دع ج = هوية(3.14)         // ت = عشري
```

### المعممات مع قيود

```sad
// دالة تتطلب سمة معينة
دالة<ت: قابل_للعرض> اطبع_قيمة(قيمة: ت) {
    اطبع(قيمة.إلى_نص())
}

// عدة قيود
دالة<ت: قابل_للنسخ + قابل_للمقارنة> الأصغر(أ: ت، ب: ت) -> ت {
    إذا أ < ب {
        أرجع أ
    }
    أرجع ب
}

// قيود معقدة باستخدام "حيث"
دالة<ت، ك> دمج(قائمة: قائمة<ت>، محول: دالة(ت) -> ك) -> قائمة<ك>
حيث
    ت: قابل_للنسخ،
    ك: افتراضي
{
    // ...
}
```

### البنيات المعممة

```sad
// بنية معممة
بنية<ت> قائمة_مرتبطة {
    الرأس: اختياري<عقدة<ت>>
}

بنية<ت> عقدة {
    القيمة: ت،
    التالي: اختياري<صندوق<عقدة<ت>>>
}

// بنية معممة مع عدة معاملات
بنية<م، ق> خريطة {
    العناصر: متجه<(م، ق)>
}
```

### التخصيص (Monomorphization)

المترجم ينشئ نسخة متخصصة لكل نوع مستخدم:

```sad
// الكود الأصلي
دالة<ت> مضاعفة(س: ت) -> (ت، ت) {
    أرجع (س، س)
}

دع أ = مضاعفة(5)        // ينشئ: مضاعفة_رقم
دع ب = مضاعفة("نص")     // ينشئ: مضاعفة_نص

// ما ينتجه المترجم (داخلياً)
دالة مضاعفة_رقم(س: رقم) -> (رقم، رقم) { ... }
دالة مضاعفة_نص(س: نص) -> (نص، نص) { ... }
```

## السمات

السمات (Traits) تُعرِّف سلوكاً مشتركاً يمكن للأنواع تنفيذه.

### تعريف سمة

```sad
// سمة بسيطة
سمة قابل_للعرض {
    دالة إلى_نص(ذات) -> نص
}

// سمة مع دالة افتراضية
سمة قابل_للمقارنة {
    دالة يساوي(ذات، آخر: ذات&) -> منطقي
    
    // دالة افتراضية (لها تنفيذ)
    دالة لا_يساوي(ذات، آخر: ذات&) -> منطقي {
        أرجع !ذات.يساوي(آخر)
    }
}
```

### تنفيذ سمة

```sad
بنية نقطة {
    س: عشري،
    ص: عشري
}

// تنفيذ سمة لبنية
تنفيذ قابل_للعرض لـ نقطة {
    دالة إلى_نص(ذات) -> نص {
        أرجع "(" + ذات.س.إلى_نص() + "، " + ذات.ص.إلى_نص() + ")"
    }
}

تنفيذ قابل_للمقارنة لـ نقطة {
    دالة يساوي(ذات، آخر: نقطة&) -> منطقي {
        أرجع ذات.س == آخر.س && ذات.ص == آخر.ص
    }
}

// الاستخدام
دع ن1 = نقطة { س: 1.0، ص: 2.0 }
دع ن2 = نقطة { س: 1.0، ص: 2.0 }

اطبع(ن1.إلى_نص())      // "(1.0، 2.0)"
اطبع(ن1.يساوي(ن2&))    // صحيح
```

### السمات الأساسية المدمجة

| السمة العربية | السمة الإنجليزية | الوصف |
|--------------|-----------------|-------|
| `قابل_للنسخ` | `Copy` | النوع يُنسخ بدلاً من النقل |
| `قابل_للاستنساخ` | `Clone` | يمكن إنشاء نسخة عميقة |
| `قابل_للمقارنة` | `Eq` | يمكن مقارنة المساواة |
| `قابل_للترتيب` | `Ord` | يمكن الترتيب (أكبر/أصغر) |
| `قابل_للتجزئة` | `Hash` | يمكن حساب قيمة التجزئة |
| `قابل_للعرض` | `Display` | يمكن تحويله لنص للعرض |
| `قابل_للتنقيح` | `Debug` | يمكن تحويله لنص للتنقيح |

### سمات العلامة (Marker Traits)

```sad
// سمة قابل_للنسخ هي سمة علامة (بدون دوال)
// الأنواع البدائية تنفذها تلقائياً

سمة قابل_للنسخ { }  // سمة فارغة

// الأنواع التي تنفذ قابل_للنسخ:
// - جميع الأعداد (ع8، ع16، ... عش64)
// - منطقي، حرف، بايت
// - البنيات التي كل حقولها قابلة للنسخ
```

### وراثة السمات

```sad
// سمة ترث من سمة أخرى
سمة قابل_للاستنساخ: قابل_للنسخ {
    دالة استنسخ(ذات) -> ذات
}

// أي نوع ينفذ قابل_للاستنساخ يجب أن ينفذ قابل_للنسخ أيضاً
```

## استنتاج الأنواع

نظام استنتاج الأنواع في لغة ص يستخدم خوارزمية **Hindley-Milner** لاستنتاج الأنواع تلقائياً.

### الاستنتاج الأساسي

```sad
// المترجم يستنتج النوع من القيمة
دع عدد = 42              // يُستنتج: رقم
دع نص = "مرحبا"         // يُستنتج: نص
دع قائمة = [1، 2، 3]    // يُستنتج: [رقم]
```

### استنتاج أنواع الدوال

```sad
// المترجم يستنتج نوع الإرجاع
دالة مضاعفة(س: رقم) {    // يُستنتج: -> رقم
    أرجع س * 2
}

// استنتاج من السياق
دع النتيجة = مضاعفة(5)   // يُستنتج: رقم
```

### استنتاج المعممات

```sad
// المترجم يستنتج معامل النوع
دالة<ت> أول(قائمة: [ت]) -> اختياري<ت> {
    إذا قائمة.طول() > 0 {
        أرجع بعض(قائمة[0])
    }
    أرجع لا_شيء
}

دع أ = أول([1، 2، 3])      // ت يُستنتج كـ رقم
دع ب = أول(["أ"، "ب"])     // ت يُستنتج كـ نص
```

### حدود الاستنتاج

في بعض الحالات، يجب تحديد النوع صراحةً:

```sad
// ❌ غامض - المترجم لا يعرف النوع
دع فارغ = []

// ✅ واضح - النوع محدد
دع فارغ: [رقم] = []

// أو
دع فارغ = متجه::جديد<رقم>()
```

## أمثلة عملية

### مثال 1: نظام مستخدمين

```sad
// تعريف الأنواع
تعداد دور_المستخدم {
    مدير،
    محرر،
    قارئ
}

بنية مستخدم {
    المعرف: ح64،
    الاسم: نص،
    البريد: نص،
    الدور: دور_المستخدم،
    نشط: منطقي
}

// تنفيذ السمات
تنفيذ قابل_للعرض لـ مستخدم {
    دالة إلى_نص(ذات) -> نص {
        أرجع "مستخدم[" + ذات.الاسم + "]"
    }
}

// دوال مرتبطة
تنفيذ مستخدم {
    دالة جديد(الاسم: نص، البريد: نص) -> مستخدم {
        أرجع مستخدم {
            المعرف: توليد_معرف()،
            الاسم: الاسم،
            البريد: البريد،
            الدور: دور_المستخدم::قارئ،
            نشط: صحيح
        }
    }
    
    دالة هل_مدير(ذات) -> منطقي {
        طابق ذات.الدور {
            دور_المستخدم::مدير => أرجع صحيح،
            _ => أرجع خطأ
        }
    }
}
```

### مثال 2: قائمة معممة

```sad
// تعريف قائمة مرتبطة معممة
بنية<ت> قائمة_مرتبطة {
    الرأس: اختياري<صندوق<عقدة<ت>>>،
    الطول: حجم
}

بنية<ت> عقدة {
    القيمة: ت،
    التالي: اختياري<صندوق<عقدة<ت>>>
}

تنفيذ<ت> قائمة_مرتبطة<ت> {
    دالة جديدة() -> قائمة_مرتبطة<ت> {
        أرجع قائمة_مرتبطة {
            الرأس: لا_شيء،
            الطول: 0
        }
    }
    
    دالة أضف(ذات&، قيمة: ت) {
        دع عقدة_جديدة = صندوق::جديد(عقدة {
            القيمة: قيمة،
            التالي: ذات.الرأس.خذ()
        })
        ذات.الرأس = بعض(عقدة_جديدة)
        ذات.الطول += 1
    }
    
    دالة طول(ذات) -> حجم {
        أرجع ذات.الطول
    }
}
```

### مثال 3: معالجة الأخطاء

```sad
// تعريف أنواع الأخطاء
تعداد خطأ_ملف {
    غير_موجود(نص)،
    رفض_الوصول،
    تالف
}

تنفيذ قابل_للعرض لـ خطأ_ملف {
    دالة إلى_نص(ذات) -> نص {
        طابق ذات {
            خطأ_ملف::غير_موجود(مسار) => 
                أرجع "الملف غير موجود: " + مسار،
            خطأ_ملف::رفض_الوصول => 
                أرجع "تم رفض الوصول للملف"،
            خطأ_ملف::تالف => 
                أرجع "الملف تالف"
        }
    }
}

// دالة تستخدم Result
دالة اقرأ_إعدادات(المسار: نص) -> نتيجة<إعدادات، خطأ_ملف> {
    دع محتوى = اقرأ_ملف(المسار)?
    دع إعدادات = حلل_جيسون(محتوى)?
    أرجع نجاح(إعدادات)
}

// الاستخدام
دالة رئيسية() {
    طابق اقرأ_إعدادات("config.json") {
        نجاح(إ) => {
            اطبع("تم تحميل الإعدادات!")
            طبق_إعدادات(إ)
        }،
        خطأ(خ) => {
            اطبع("خطأ: " + خ.إلى_نص())
            استخدم_إعدادات_افتراضية()
        }
    }
}
```

## الأخطاء الشائعة

### خطأ 1: عدم تطابق الأنواع

```sad
// ❌ خطأ
دع عدد: ع32 = "مرحبا"

// رسالة الخطأ:
// خطأ[ص0001]: عدم تطابق الأنواع
//   متوقع: ع32
//   وُجد: نص
```

### خطأ 2: قيد سمة غير محقق

```sad
// ❌ خطأ
دالة<ت: قابل_للمقارنة> ترتيب(قائمة: [ت]) { ... }

بنية غير_قابل_للمقارنة { }

دع ق = [غير_قابل_للمقارنة {}]
ترتيب(ق)  // خطأ!

// رسالة الخطأ:
// خطأ[ص0015]: قيد السمة غير محقق
//   النوع `غير_قابل_للمقارنة` لا ينفذ `قابل_للمقارنة`
```

### خطأ 3: استخدام اختياري بدون فحص

```sad
// ❌ خطأ
دع ربما: اختياري<رقم> = لا_شيء
دع قيمة = ربما.افتح()  // توقف في وقت التشغيل!

// ✅ صحيح
إذا دع بعض(ق) = ربما {
    اطبع(ق)
} وإلا {
    اطبع("لا قيمة")
}
```

### خطأ 4: تحويل ضمني غير آمن

```sad
// ❌ تحذير/خطأ
دع كبير: ع64 = 1000000000000
دع صغير: ع16 = كبير  // قد يفقد بيانات!

// ✅ صحيح
دع صغير: ع16 = كبير كـ ع16  // تحويل صريح
```
