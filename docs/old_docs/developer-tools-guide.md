## 🎯 مقدمة

تُقدم لغة ص مجموعة متكاملة من أدوات التطوير المصممة خصيصاً للمبرمج العربي. تتضمن هذه الأدوات:

| الأداة | الوصف | الحالة |
|--------|-------|--------|
| **ص-حزم** | مدير حزم متكامل | ✅ جاهز |
| **ص-خادم** | خادم بروتوكول اللغة (LSP) | ✅ جاهز |
| **ص-نسق** | منسق كود تلقائي | ✅ جاهز |
| **إضافة VS Code** | دعم كامل في VS Code | ✅ جاهز |

### المتطلبات الأساسية

```
- نظام التشغيل: Windows 10/11، Linux، macOS
- ذاكرة: 4 جيجابايت كحد أدنى
- مساحة القرص: 500 ميجابايت
- VS Code: الإصدار 1.70 أو أحدث (اختياري)
```

## 📦 مدير الحزم (ص-حزم)

مدير الحزم هو أداة لإدارة التبعيات والمكتبات الخارجية في مشاريع لغة ص.

### 🚀 البدء السريع

#### تهيئة مشروع جديد

```bash
ص-حزم هيئ
```

سينشئ هذا الأمر ملف `ص.toml` في المجلد الحالي:

```toml
[حزمة]
اسم = "مشروعي"
إصدار = "1.0.0"
وصف = "وصف المشروع"
مؤلف = "اسمك <بريدك@مثال.com>"
رخصة = "MIT"

[تبعيات]
# أضف تبعياتك هنا

[تبعيات_تطوير]
# تبعيات التطوير والاختبار
```

### 📥 تثبيت الحزم

#### تثبيت حزمة محددة

```bash
# تثبيت أحدث إصدار
ص-حزم ثبت رياضيات

# تثبيت إصدار محدد
ص-حزم ثبت رياضيات@1.2.0

# تثبيت مع تحديد نطاق الإصدار
ص-حزم ثبت رياضيات@"^1.0"
```

#### تثبيت جميع التبعيات

```bash
ص-حزم ثبت
```

### 🗑️ إزالة الحزم

```bash
ص-حزم أزل رياضيات
```

### 🔄 تحديث الحزم

```bash
# تحديث جميع الحزم
ص-حزم حدث

# تحديث حزمة محددة
ص-حزم حدث رياضيات
```

### 🔍 البحث عن الحزم

```bash
ص-حزم ابحث "معالجة نصوص"
```

### 📋 عرض الحزم المثبتة

```bash
ص-حزم قائمة
```

### 🌳 عرض شجرة التبعيات

```bash
ص-حزم شجرة
```

مثال على المخرجات:

```
مشروعي@1.0.0
├── رياضيات@2.1.0
│   └── أساسيات@1.0.0
├── نصوص@1.5.0
│   ├── أساسيات@1.0.0
│   └── ترميز@1.2.0
└── شبكات@3.0.0
    └── غير_متزامن@2.0.0
```

### 📤 نشر حزمة

```bash
# التحقق قبل النشر
ص-حزم تحقق

# النشر للسجل
ص-حزم انشر
```

### 📁 هيكل ملفات المشروع

```
مشروعي/
├── ص.toml              # ملف تكوين المشروع
├── ص.قفل               # ملف قفل الإصدارات (يُولد تلقائياً)
├── مصدر/                # الكود المصدري
│   └── رئيسي.ص
├── اختبارات/            # ملفات الاختبار
│   └── اختبار_رئيسي.ص
└── حزم/                 # الحزم المُثبتة (يُولد تلقائياً)
```

### ⚙️ خيارات ملف ص.toml

```toml
[حزمة]
اسم = "اسم_الحزمة"           # مطلوب: اسم الحزمة
إصدار = "1.0.0"              # مطلوب: إصدار SemVer
وصف = "وصف مختصر"            # اختياري: وصف الحزمة
مؤلف = "الاسم <بريد>"        # اختياري: معلومات المؤلف
رخصة = "MIT"                 # اختياري: نوع الرخصة
مستودع = "https://..."       # اختياري: رابط المستودع
صفحة = "https://..."         # اختياري: الصفحة الرئيسية
كلمات_مفتاحية = ["أ", "ب"]    # اختياري: كلمات للبحث

[تبعيات]
رياضيات = "^1.0"             # متوافق مع 1.x.x
نصوص = "~2.3"                # متوافق مع 2.3.x
شبكات = ">=1.0, <2.0"       # نطاق محدد
محلية = { مسار = "../حزمة" } # حزمة محلية
git = { مستودع = "https://github.com/..." }  # من Git

[تبعيات_تطوير]
اختبار = "^1.0"

[بناء]
هدف = "مكتبة"                # أو "تنفيذي"
تحسين = 2                    # مستوى التحسين (0-3)
```

### 🔢 قواعد الإصدارات (SemVer)

| الرمز | المعنى | مثال |
|-------|--------|------|
| `^1.2.3` | متوافق مع 1.x.x | 1.2.3 ≤ v < 2.0.0 |
| `~1.2.3` | متوافق مع 1.2.x | 1.2.3 ≤ v < 1.3.0 |
| `1.2.3` | إصدار محدد بالضبط | v = 1.2.3 |
| `>=1.0` | أكبر من أو يساوي | v ≥ 1.0.0 |
| `<2.0` | أصغر من | v < 2.0.0 |
| `*` | أي إصدار | أي v |

## 🖥️ خادم اللغة (LSP)

خادم اللغة يوفر ميزات الذكاء البرمجي للمحررات المختلفة.

### ✨ الميزات المدعومة

| الميزة | الوصف | اختصار |
|--------|-------|--------|
| **الإكمال التلقائي** | اقتراحات ذكية أثناء الكتابة | `Ctrl+Space` |
| **التشخيصات** | أخطاء وتحذيرات فورية | تلقائي |
| **معلومات التمرير** | توثيق عند وضع المؤشر | تمرير الفأرة |
| **الانتقال للتعريف** | الذهاب لمكان التعريف | `F12` |
| **إيجاد المراجع** | جميع استخدامات الرمز | `Shift+F12` |
| **إعادة التسمية** | تغيير الاسم في كل الأماكن | `F2` |
| **التنسيق** | تنسيق الكود تلقائياً | `Shift+Alt+F` |

### 🚀 تشغيل الخادم

```bash
# التشغيل العادي (يتصل عبر stdin/stdout)
ص-خادم

# التشغيل مع تسجيل مفصل
ص-خادم --تسجيل=مفصل

# التشغيل على منفذ TCP
ص-خادم --منفذ=6008
```

### 📝 الإكمال التلقائي

يقدم الخادم اقتراحات ذكية تشمل:

#### الكلمات المفتاحية

```
دالة، نهاية، إذا، وإلا، وإلا_إذا، طالما، لكل، إرجاع،
متغير، ثابت، صنف، سمة، تعداد، بنية، استورد، من
```

#### الأنواع الأساسية

```
رقم، نص، منطقي، قائمة، خريطة، مجموعة،
ع32، ع64، عش32، عش64، ح8، ح16، ح32، ح64
```

#### الدوال المدمجة

```
اطبع، أدخل، طول، نوع، نطاق، عشوائي،
افتح، اقرأ، اكتب، أغلق، موجود
```

#### القصاصات الذكية

| الاختصار | التوسعة |
|----------|---------|
| `دالة` | قالب دالة كامل |
| `إذا` | جملة شرطية |
| `طالما` | حلقة while |
| `لكل` | حلقة for |
| `صنف` | تعريف صنف |
| `اختبار` | دالة اختبار |

### 🔴 رموز الأخطاء

| الرمز | المعنى | مثال |
|-------|--------|------|
| `ص-001` | أقواس غير متطابقة | `دالة(س` |
| `ص-002` | كلمة مفتاحية ناقصة | `دالة` بدون `نهاية` |
| `ص-003` | متغير غير معرف | استخدام `س` بدون تعريف |
| `ص-004` | استيراد فاشل | `استورد "غير_موجود"` |
| `ص-005` | نوع غير متطابق | `رقم س = "نص"` |
| `ص-006` | دالة غير معرفة | استدعاء دالة غير موجودة |
| `ص-007` | معاملات خاطئة | عدد معاملات غير صحيح |
| `ص-008` | كود غير قابل للوصول | كود بعد `إرجاع` |
| `ص-009` | تحذير عام | تلميحات وملاحظات |
| `ص-010` | خطأ صياغة | خطأ في بنية الكود |

### 📖 معلومات التمرير (Hover)

عند وضع المؤشر فوق عنصر، يظهر توثيق تفصيلي:

**مثال - الكلمة المفتاحية `دالة`:**

```markdown
**دالة** - تعريف دالة جديدة

═══════════════════════════════════════

الصياغة:
    دالة اسم_الدالة(معامل1: نوع1, معامل2: نوع2) -> نوع_الإرجاع
        // جسم الدالة
    نهاية

مثال:
    دالة جمع(أ: رقم, ب: رقم) -> رقم
        إرجاع أ + ب
    نهاية

ملاحظات:
• يمكن حذف نوع الإرجاع إذا كانت الدالة لا ترجع قيمة
• المعاملات تُمرر بالقيمة افتراضياً
• استخدم & للتمرير بالمرجع
```

## ✨ منسق الكود

منسق الكود يُنظم شكل الكود تلقائياً وفق قواعد موحدة.

### 🚀 الاستخدام

```bash
# تنسيق ملف واحد
ص-نسق ملف.ص

# تنسيق مع الكتابة على الملف
ص-نسق -w ملف.ص

# تنسيق جميع ملفات المشروع
ص-نسق -w مصدر/

# التحقق فقط بدون تعديل
ص-نسق --تحقق ملف.ص
```

### ⚙️ خيارات التنسيق

يمكن تخصيص التنسيق عبر ملف `ص.تنسيق.toml`:

```toml
[تنسيق]
# حجم المسافة البادئة
حجم_مسافة = 4

# استخدام مسافات بدلاً من Tab
استخدم_مسافات = true

# الحد الأقصى لطول السطر
طول_سطر = 80

# مسافة بعد الفاصلة
مسافة_بعد_فاصلة = true

# مسافة حول العوامل
مسافة_حول_عوامل = true

# سطر فارغ بين الدوال
سطر_فارغ_بين_دوال = true

# الأقواس على نفس السطر
أقواس_نفس_سطر = true
```

### 📋 قواعد التنسيق

#### المسافات البادئة

```
// قبل التنسيق
دالة مثال()
رقم س = 5
إذا (س > 0)
اطبع(س)
نهاية
نهاية

// بعد التنسيق
دالة مثال()
    رقم س = 5
    إذا (س > 0)
        اطبع(س)
    نهاية
نهاية
```

#### المسافات حول العوامل

```
// قبل التنسيق
رقم نتيجة=أ+ب*ج

// بعد التنسيق
رقم نتيجة = أ + ب * ج
```

#### الأسطر الفارغة

```
// قبل التنسيق
دالة أ()
    // ...
نهاية
دالة ب()
    // ...
نهاية

// بعد التنسيق
دالة أ()
    // ...
نهاية

دالة ب()
    // ...
نهاية
```

## 💻 إضافة VS Code

إضافة VS Code توفر تجربة تطوير متكاملة للغة ص.

### 📥 التثبيت

1. افتح VS Code
2. اضغط `Ctrl+Shift+X` لفتح متجر الإضافات
3. ابحث عن "Sad Language" أو "لغة ص"
4. اضغط "Install"

أو من سطر الأوامر:

```bash
code --install-extension sad-language.sad-language
```

### ✨ الميزات

#### تمييز الصياغة

- تلوين الكلمات المفتاحية (أزرق)
- تلوين النصوص (أخضر)
- تلوين الأرقام (برتقالي)
- تلوين التعليقات (رمادي)
- تلوين الدوال (أصفر)

#### اختصارات لوحة المفاتيح

| الاختصار | الوظيفة |
|----------|---------|
| `F5` | تشغيل البرنامج |
| `Ctrl+F5` | تصريف البرنامج |
| `Shift+Alt+F` | تنسيق الكود |
| `F12` | الانتقال للتعريف |
| `Shift+F12` | إيجاد جميع المراجع |
| `F2` | إعادة التسمية |
| `Ctrl+Space` | الإكمال التلقائي |
| `Ctrl+Shift+O` | الانتقال للرمز |

#### أوامر الإضافة

افتح لوحة الأوامر (`Ctrl+Shift+P`) واكتب "Sad" لرؤية جميع الأوامر:

| الأمر | الوصف |
|-------|-------|
| `Sad: Run Program` | تشغيل البرنامج الحالي |
| `Sad: Compile Program` | تصريف البرنامج |
| `Sad: Format Code` | تنسيق الكود |
| `Sad: Initialize Project` | تهيئة مشروع جديد |
| `Sad: Install Package` | تثبيت حزمة |
| `Sad: Remove Package` | إزالة حزمة |
| `Sad: Update Packages` | تحديث الحزم |
| `Sad: Search Packages` | البحث عن حزم |
| `Sad: Restart Server` | إعادة تشغيل خادم اللغة |
| `Sad: Show Output` | عرض سجل الخادم |

#### إعدادات الإضافة

افتح الإعدادات (`Ctrl+,`) وابحث عن "sad":

```json
{
    // مسار خادم اللغة (اتركه فارغاً للاكتشاف التلقائي)
    "sad.server.path": "",
    
    // تفعيل خادم اللغة
    "sad.server.enabled": true,
    
    // مستوى تسجيل الخادم
    "sad.trace.server": "off",  // off, messages, verbose
    
    // تفعيل التنسيق التلقائي
    "sad.formatting.enabled": true,
    
    // حجم المسافة البادئة
    "sad.formatting.tabSize": 4,
    
    // استخدام مسافات بدلاً من Tab
    "sad.formatting.insertSpaces": true
}
```

#### شريط الحالة

يظهر في أسفل يمين الشاشة رمز `ص` عند فتح ملف لغة ص:
- 🟢 الخادم متصل وجاهز
- 🟡 الخادم قيد التحميل
- 🔴 الخادم غير متصل

اضغط على الرمز لعرض سجل الخادم.

## 📚 أمثلة عملية

### مثال 1: مشروع بسيط

**الخطوة 1: إنشاء المشروع**

```bash
mkdir مشروعي
cd مشروعي
ص-حزم هيئ
```

**الخطوة 2: كتابة الكود**

أنشئ ملف `مصدر/رئيسي.ص`:

```
// بسم الله الرحمن الرحيم
// مشروعي الأول بلغة ص

دالة رئيسية()
    اطبع("مرحباً بالعالم!")
    
    رقم س = 10
    رقم ص = 20
    رقم مجموع = جمع(س، ص)
    
    اطبع("المجموع: " + مجموع)
    
    إرجاع 0
نهاية

دالة جمع(أ: رقم، ب: رقم) -> رقم
    إرجاع أ + ب
نهاية
```

**الخطوة 3: التشغيل**

```bash
ص شغل مصدر/رئيسي.ص
```

### مثال 2: استخدام الحزم

**الخطوة 1: إضافة تبعية**

```bash
ص-حزم ثبت رياضيات
```

**الخطوة 2: استخدام الحزمة**

```
استورد رياضيات من "رياضيات"

دالة رئيسية()
    رقم س = 16
    رقم جذر = رياضيات.جذر_تربيعي(س)
    اطبع("الجذر التربيعي لـ " + س + " هو " + جذر)
نهاية
```

### مثال 3: التعامل مع الأخطاء

عند كتابة كود به أخطاء، سيظهر LSP التشخيصات:

```
دالة رئيسية()
    رقم س = 10
    اطبع(ص)        // خطأ ص-003: المتغير 'ص' غير معرف
    إرجاع 0
    اطبع("مرحبا")  // تحذير ص-008: كود غير قابل للوصول
نهاية
```

### مثال 4: تنسيق الكود

**قبل التنسيق:**

```
دالة حساب(س:رقم,ص:رقم)->رقم
رقم نتيجة=س+ص*2
إذا(نتيجة>100)
اطبع("كبير")
وإلا
اطبع("صغير")
نهاية
إرجاع نتيجة
نهاية
```

**بعد التنسيق (`ص-نسق -w`):**

```
دالة حساب(س: رقم, ص: رقم) -> رقم
    رقم نتيجة = س + ص * 2
    
    إذا (نتيجة > 100)
        اطبع("كبير")
    وإلا
        اطبع("صغير")
    نهاية
    
    إرجاع نتيجة
نهاية
```

## 📋 المرجع السريع

```bash
ص-حزم هيئ                    # تهيئة مشروع جديد

ص-حزم أزل <حزمة>            # إزالة حزمة
ص-حزم حدث                   # تحديث الحزم
ص-حزم قائمة                 # عرض الحزم المثبتة
ص-حزم شجرة                  # عرض شجرة التبعيات
ص-حزم ابحث <كلمة>           # البحث عن حزم
ص-حزم تحقق                  # التحقق من الحزمة
ص-حزم انشر                  # نشر الحزمة
```

```bash
ص-خادم                       # تشغيل الخادم

ص-خادم --منفذ=6008          # تشغيل على منفذ TCP
```

```bash
ص-نسق <ملف>                 # عرض الكود المنسق
ص-نسق -w <ملف>              # تنسيق وكتابة
ص-نسق --تحقق <ملف>          # التحقق فقط
```

### أوامر ص (المترجم)

```bash
ص بناء <ملف>                # بناء الملف
ص شغل <ملف>                 # تشغيل الملف
ص اختبر                     # تشغيل الاختبارات
```
