## 📖 مقدمة

إذا كان TCP هو البريد المسجل الموثوق، فـ UDP (User Datagram Protocol) هو البطاقة البريدية السريعة. UDP بروتوكول بسيط وسريع جداً، لكنه لا يضمن وصول البيانات أو ترتيبها. في هذا الدليل الشامل، سنتعلم كل شيء عن UDP من الأساسيات إلى التقنيات المتقدمة مثل البث الجماعي (Multicast) والبث العام (Broadcast).

UDP مثالي لتطبيقات تحتاج للسرعة أكثر من الموثوقية - البث المباشر، الألعاب الأونلاين، خدمات DNS، وأنظمة المراقبة. سنستكشف كل هذه الاستخدامات مع أمثلة عملية في لغة ص.

## 🎯 لماذا UDP؟ متى نستخدمه؟

### مزايا UDP

**السرعة الفائقة:** UDP ليس لديه عملية مصافحة، لا أرقام تسلسل، لا إعادة إرسال، لا تحكم في التدفق. هذا يجعله أسرع بكثير من TCP. ترسل الحزمة مباشرة إلى وجهتها دون أي تأخير إضافي.

**استهلاك موارد أقل:** بدون كل آليات TCP المعقدة، UDP يستهلك ذاكرة ومعالج أقل بكثير. هذا مهم للأجهزة المحدودة الموارد مثل أجهزة IoT.

**مرونة في التصميم:** بما أن UDP لا يفرض أي بنية على البيانات، لديك حرية كاملة في تصميم بروتوكولك الخاص. يمكنك إضافة الموثوقية فقط حيث تحتاجها.

**دعم البث (Broadcast/Multicast):** UDP يدعم إرسال نفس الحزمة لعدة مستقبلين في وقت واحد. هذا مستحيل مع TCP الذي يتطلب اتصال منفصل لكل مستقبل.

### متى تستخدم UDP؟

**البث المباشر (Streaming):**
عند بث فيديو أو صوت حي، السرعة أهم من الكمال. إذا فقدت إطار واحد من الفيديو، المشاهد قد لا يلاحظ. لكن إذا توقف الفيديو لإعادة إرسال البيانات المفقودة (كما يفعل TCP)، ستكون التجربة سيئة جداً. UDP يسمح بالتدفق المستمر مع فقدان بسيط مقبول.

```sad
// مثال: بث فيديو
استخدم شبكة

دالة بث_فيديو() {
    مقبس = شبكة.انشئ_مقبس_udp()
    
    بينما صحيح {
        إطار = اقرأ_إطار_فيديو_تالي()
        
        // إرسال الإطار لكل المشاهدين
        لكل مشاهد في قائمة_المشاهدين {
            مقبس.ارسل_الى(إطار، مشاهد)
        }
        
        // لا ننتظر تأكيد - نرسل الإطار التالي مباشرة!
    }
}
```

**الألعاب الأونلاين:**
في لعبة إطلاق نار سريعة، موقع اللاعب يتغير 60 مرة في الثانية. إذا فُقد تحديث واحد، التحديث التالي سيصل بعد 16 ميلي ثانية. إعادة إرسال التحديث القديم لا فائدة منه - البيانات أصبحت قديمة. UDP مثالي هنا:

```sad
استخدم شبكة

دالة حلقة_اللعبة_الرئيسية() {
    مقبس = شبكة.انشئ_مقبس_udp()
    
    بينما اللعبة_تعمل {
        // إرسال موقع اللاعب الحالي
        موقع = احصل_على_موقع_اللاعب()
        مقبس.ارسل_الى(موقع، عنوان_الخادم)
        
        // استقبال مواقع اللاعبين الآخرين
        (تحديث، مرسل) = مقبس.استقبل_من()
        حدث_موقع_اللاعب(تحديث)
        
        // كل هذا يحدث 60 مرة في الثانية!
    }
}
```

**DNS (Domain Name System):**
عند كتابة عنوان موقع، جهازك يرسل طلب UDP صغير (عادة أقل من 512 بايت) لخادم DNS. الطلب بسيط: "ما عنوان IP لـ google.com؟". الرد أيضاً بسيط. إذا لم يصل الرد خلال ثانية، الجهاز يعيد الطلب. UDP مثالي لهذا:

```sad
استخدم شبكة

دالة استعلام_dns(اسم_النطاق) {
    مقبس = شبكة.انشئ_مقبس_udp()
    مقبس.عين_مهلة_الاستقبال(1000)  // ثانية واحدة
    
    طلب = بناء_طلب_dns(اسم_النطاق)
    
    لـ محاولة من 1 إلى 3 {  // 3 محاولات كحد أقصى
        مقبس.ارسل_الى(طلب، "8.8.8.8:53")  // Google DNS
        
        محاولة {
            (رد، _) = مقبس.استقبل_من()
            ارجع حلل_رد_dns(رد)
        } اصطياد (مهلة) {
            اطبع("المحاولة " + محاولة + " فشلت، أعيد المحاولة...")
        }
    }
    
    ارجع باطل  // فشل بعد 3 محاولات
}
```

**أنظمة المراقبة والقياس:**
عند جمع ملايين القياسات من آلاف الأجهزة، فقدان قياس واحد هنا وهناك ليس كارثة. لكن إعادة إرسال كل قياس مفقود سيغرق الشبكة. UDP يسمح بجمع البيانات بكفاءة عالية:

```sad
استخدم شبكة

دالة ارسل_قياس(اسم_القياس، قيمة) {
    مقبس = شبكة.انشئ_مقبس_udp()
    
    // بناء رسالة بسيطة
    رسالة = اسم_القياس + ":" + قيمة + ":" + الوقت_الحالي()
    
    // إرسال لخادم جمع البيانات
    مقبس.ارسل_الى(رسالة، "monitoring-server:8125")
    
    // لا ننتظر رد - نرسل القياس التالي!
}
```

## 💻 أساسيات UDP في لغة ص

### إنشاء مقبس UDP

بخلاف TCP، UDP لا يحتاج لاتصال. تنشئ مقبساً واحداً وترسل/تستقبل مباشرة:

```sad
استخدم شبكة

دالة رئيسية() {
    // إنشاء مقبس UDP
    مقبس = شبكة.انشئ_مقبس_udp()
    
    إذا مقبس == باطل {
        اطبع("❌ فشل إنشاء المقبس")
        ارجع 1
    }
    
    اطبع("✅ تم إنشاء مقبس UDP")
    
    // مقبس UDP جاهز للاستخدام مباشرة!
    // لا حاجة لـ connect() أو listen()
}
```

### خادم UDP بسيط

خادم UDP يربط المقبس بمنفذ ثم يستقبل الحزم:

```sad
استخدم شبكة
استخدم نص

دالة رئيسية() {
    // إنشاء مقبس وربطه بالمنفذ 9090
    مقبس = شبكة.انشئ_مقبس_udp()
    مقبس.اربط(9090)
    
    اطبع("📡 خادم UDP يستمع على المنفذ 9090")
    اطبع("في انتظار حزم...")
    اطبع("")
    
    عدد_الحزم = 0
    
    // حلقة لا نهائية لاستقبال الحزم
    بينما صحيح {
        // استقبال حزمة (حتى 4096 بايت)
        (بيانات، مرسل) = مقبس.استقبل_من(4096)
        
        عدد_الحزم = عدد_الحزم + 1
        
        // عرض معلومات الحزمة
        رسالة = نص.من_بايتات(بيانات)
        اطبع("📨 حزمة #" + عدد_الحزم)
        اطبع("   من: " + مرسل.عنوان() + ":" + مرسل.منفذ())
        اطبع("   الحجم: " + بيانات.طول() + " بايت")
        اطبع("   المحتوى: " + رسالة)
        اطبع("")
        
        // إرسال رد
        رد = "استلمت الحزمة #" + عدد_الحزم
        مقبس.ارسل_الى(نص.الى_بايتات(رد), مرسل)
    }
}
```

### عميل UDP بسيط

عميل UDP يرسل حزم مباشرة دون اتصال مسبق:

```sad
استخدم شبكة
استخدم نص

دالة رئيسية() {
    // إنشاء مقبس
    مقبس = شبكة.انشئ_مقبس_udp()
    
    اطبع("📤 عميل UDP")
    اطبع("إرسال رسائل للخادم...")
    اطبع("")
    
    // إنشاء عنوان الخادم
    خادم = شبكة.انشئ_عنوان("127.0.0.1", 9090)
    
    // إرسال 5 رسائل
    لـ ع من 1 إلى 5 {
        رسالة = "رسالة رقم " + ع + " من العميل"
        
        اطبع("📤 إرسال: " + رسالة)
        مقبس.ارسل_الى(نص.الى_بايتات(رسالة), خادم)
        
        // محاولة استقبال رد (مع مهلة)
        مقبس.عين_مهلة_الاستقبال(2000)  // ثانيتان
        
        محاولة {
            (رد_بايتات، _) = مقبس.استقبل_من(1024)
            رد = نص.من_بايتات(رد_بايتات)
            اطبع("📨 الخادم رد: " + رد)
        } اصطياد (مهلة) {
            اطبع("⏰ لم يصل رد (ربما الحزمة ضاعت)")
        }
        
        اطبع("")
        
        // انتظار ثانية قبل الرسالة التالية
        نم(1000)
    }
    
    مقبس.اغلق()
    اطبع("✅ تم")
}
```

## 🔗 UDP المتصل (Connected UDP)

بالرغم من أن UDP بروتوكول عديم الاتصال، يمكنك "ربطه" بعنوان محدد. هذا لا ينشئ اتصالاً حقيقياً (لا مصافحة)، لكنه يسمح لك باستخدام `ارسل()` و `استقبل()` البسيطة بدلاً من `ارسل_الى()` و `استقبل_من()`:

```sad
استخدم شبكة

دالة رئيسية() {
    مقبس = شبكة.انشئ_مقبس_udp()
    
    // "ربط" المقبس بعنوان الخادم
    مقبس.اتصل("127.0.0.1", 9090)
    
    اطبع("✅ المقبس مربوط بالخادم")
    
    // الآن يمكن استخدام الدوال البسيطة
    مقبس.ارسل("رسالة 1")  // بدلاً من ارسل_الى()
    رد = مقبس.استقبل(1024)  // بدلاً من استقبل_من()
    
    // يمكن فك الربط والربط بعنوان آخر
    مقبس.افصل()
    
    مقبس.اتصل("192.168.1.100", 8080)
    مقبس.ارسل("رسالة لخادم آخر")
}
```

**فوائد UDP المتصل:**
- كود أبسط وأقصر
- أداء أفضل قليلاً (النظام يتحقق من العنوان مرة واحدة)
- حماية من حزم من عناوين أخرى (نظام التشغيل يرفضها تلقائياً)

**متى تستخدمه:**
- عندما تتواصل مع خادم واحد فقط
- في العميل (ليس الخادم الذي يستقبل من عدة مصادر)
- عندما تريد كوداً أنظف

## 📢 البث العام (Broadcast)

البث العام يسمح بإرسال حزمة واحدة لكل الأجهزة على الشبكة المحلية. تخيل مكبر صوت يذيع إعلاناً للجميع!

### تفعيل البث العام

```sad
استخدم شبكة

دالة رئيسية() {
    مقبس = شبكة.انشئ_مقبس_udp()
    
    // تفعيل البث العام
    مقبس.فعل_البث()
    
    اطبع("📢 البث العام مفعّل")
    
    // إرسال لعنوان البث 255.255.255.255
    عنوان_بث = شبكة.انشئ_عنوان("255.255.255.255", 9999)
    
    رسالة = "رسالة للجميع على الشبكة!"
    مقبس.ارسل_الى(رسالة، عنوان_بث)
    
    اطبع("✅ تم إرسال البث")
}
```

### خادم يستقبل البث

```sad
استخدم شبكة

دالة رئيسية() {
    مقبس = شبكة.انشئ_مقبس_udp()
    مقبس.اربط(9999)  // الربط بنفس المنفذ المستخدم في البث
    
    اطبع("👂 أستمع لرسائل البث...")
    
    بينما صحيح {
        (بيانات، مرسل) = مقبس.استقبل_من(1024)
        اطبع("📢 رسالة بث من " + مرسل.عنوان() + ": " + بيانات)
    }
}
```

### مثال عملي: اكتشاف الأجهزة على الشبكة

تطبيق يكتشف جميع الأجهزة التي تشغل خدمة معينة على الشبكة المحلية:

```sad
استخدم شبكة
استخدم وقت

دالة اكتشف_الأجهزة() {
    مقبس = شبكة.انشئ_مقبس_udp()
    مقبس.فعل_البث()
    مقبس.عين_مهلة_الاستقبال(3000)  // 3 ثوانٍ
    
    // إرسال رسالة اكتشاف
    اطبع("🔍 جاري البحث عن أجهزة...")
    عنوان_بث = شبكة.انشئ_عنوان("255.255.255.255", 8888)
    مقبس.ارسل_الى("DISCOVER", عنوان_بث)
    
    أجهزة = []
    وقت_انتهاء = وقت.الآن() + 3000
    
    // جمع الردود لمدة 3 ثوانٍ
    بينما وقت.الآن() < وقت_انتهاء {
        محاولة {
            (رد، مرسل) = مقبس.استقبل_من(1024)
            اطبع("✅ وجدت جهاز: " + مرسل.عنوان())
            اطبع("   المعلومات: " + رد)
            أجهزة.أضف(مرسل)
        } اصطياد (مهلة) {
            اكسر  // انتهى الوقت
        }
    }
    
    اطبع("\n📊 النتيجة: وجدت " + أجهزة.طول() + " جهاز")
    ارجع أجهزة
}

// الخادم على كل جهاز (يرد على رسائل الاكتشاف)
دالة خادم_اكتشاف() {
    مقبس = شبكة.انشئ_مقبس_udp()
    مقبس.اربط(8888)
    
    بينما صحيح {
        (بيانات، مرسل) = مقبس.استقبل_من(1024)
        
        إذا بيانات == "DISCOVER" {
            معلومات = "جهاز ص - " + احصل_على_اسم_الجهاز()
            مقبس.ارسل_الى(معلومات، مرسل)
        }
    }
}
```

## 🌐 البث الجماعي (Multicast)

البث الجماعي أقوى من البث العام - يسمح بإرسال حزمة لمجموعة محددة من الأجهزة المهتمة، حتى عبر شبكات مختلفة!

### كيف يعمل Multicast؟

Multicast يستخدم عناوين IP خاصة من نطاق `224.0.0.0` إلى `239.255.255.255`. الأجهزة "تنضم" لمجموعة multicast معينة، وأي حزمة مرسلة لعنوان تلك المجموعة ستصل لجميع الأعضاء.

### الانضمام لمجموعة Multicast

```sad
استخدم شبكة

دالة رئيسية() {
    مقبس = شبكة.انشئ_مقبس_udp()
    
    // الربط بالمنفذ
    مقبس.اربط(5000)
    
    // الانضمام لمجموعة multicast
    عنوان_مجموعة = "239.0.0.1"
    مقبس.انضم_لمجموعة_multicast(عنوان_مجموعة)
    
    اطبع("✅ انضممت لمجموعة " + عنوان_مجموعة)
    اطبع("👂 أستمع للرسائل...")
    
    بينما صحيح {
        (بيانات، مرسل) = مقبس.استقبل_من(4096)
        اطبع("📨 رسالة من " + مرسل.عنوان() + ": " + بيانات)
    }
}
```

### إرسال لمجموعة Multicast

```sad
استخدم شبكة

دالة رئيسية() {
    مقبس = شبكة.انشئ_مقبس_udp()
    
    // عنوان المجموعة
    مجموعة = شبكة.انشئ_عنوان("239.0.0.1", 5000)
    
    عداد = 1
    بينما صحيح {
        رسالة = "رسالة رقم " + عداد + " للمجموعة"
        
        مقبس.ارسل_الى(رسالة، مجموعة)
        اطبع("📤 أرسلت: " + رسالة)
        
        عداد = عداد + 1
        نم(2000)  // إرسال كل ثانيتين
    }
}
```

### مثال عملي: غرفة دردشة Multicast

غرفة دردشة حيث كل المشاركين يرسلون ويستقبلون في نفس الوقت:

```sad
استخدم شبكة
استخدم نص
استخدم خيط

عنوان_مجموعة = "239.255.0.1"
منفذ_مجموعة = 9999

// خيط للاستقبال
دالة خيط_استقبال() {
    مقبس = شبكة.انشئ_مقبس_udp()
    مقبس.اربط(منفذ_مجموعة)
    مقبس.انضم_لمجموعة_multicast(عنوان_مجموعة)
    
    بينما صحيح {
        (بيانات، مرسل) = مقبس.استقبل_من(4096)
        رسالة = نص.من_بايتات(بيانات)
        
        // عرض الرسالة (لكن ليس رسائلنا الخاصة)
        إذا مرسل.عنوان() != احصل_على_عنواني_المحلي() {
            اطبع("\n" + رسالة)
            اطبع("> ", نهاية="")  // إعادة عرض المؤشر
        }
    }
}

// خيط للإرسال
دالة خيط_إرسال(اسمي) {
    مقبس = شبكة.انشئ_مقبس_udp()
    مجموعة = شبكة.انشئ_عنوان(عنوان_مجموعة، منفذ_مجموعة)
    
    بينما صحيح {
        اطبع("> ", نهاية="")
        رسالة = إدخال_إخراج.اقرأ_سطر()
        
        إذا رسالة.طول() > 0 {
            رسالة_كاملة = "[" + اسمي + "] " + رسالة
            مقبس.ارسل_الى(نص.الى_بايتات(رسالة_كاملة), مجموعة)
        }
    }
}

دالة رئيسية() {
    اطبع("💬 غرفة دردشة Multicast")
    اطبع("═════════════════════════════")
    
    اطبع("ما اسمك؟ ", نهاية="")
    اسم = إدخال_إخراج.اقرأ_سطر()
    
    اطبع("\n✅ مرحباً " + اسم + "!")
    اطبع("يمكنك الآن الكتابة. رسائلك ستصل لكل من في المجموعة.")
    اطبع("")
    
    // بدء خيطي الإرسال والاستقبال
    خيط.ابدأ(خيط_استقبال)
    خيط.ابدأ(خيط_إرسال، [اسم])
    
    // الانتظار للأبد
    بينما صحيح {
        نم(1000)
    }
}
```

### خيارات Multicast المتقدمة

**ضبط TTL (Time To Live):**
TTL يحدد كم "قفزة" (router) يمكن للحزمة أن تعبر:

```sad
مقبس = شبكة.انشئ_مقبس_udp()

// TTL = 1: الشبكة المحلية فقط (default)
مقبس.عين_multicast_ttl(1)

// TTL = 32: عدة شبكات (إنترانت شركة)
مقبس.عين_multicast_ttl(32)

// TTL = 255: الإنترنت كله (نادر الاستخدام)
مقبس.عين_multicast_ttl(255)
```

**Loopback (استقبال رسائلك الخاصة):**

```sad
مقبس = شبكة.انشئ_مقبس_udp()

// تعطيل loopback (لن تستقبل رسائلك)
مقبس.عين_multicast_loopback(خطأ)

// تفعيل loopback (ستستقبل رسائلك)
مقبس.عين_multicast_loopback(صحيح)
```

## 🎮 مثال متقدم: محرك لعبة شبكية

دعنا نبني محرك بسيط للعبة أونلاين باستخدام UDP:

```sad
استخدم شبكة
استخدم وقت
استخدم خيط

// بنية بيانات اللاعب
نوع لاعب = {
    معرف: رقم،
    موقع_x: رقم،
    موقع_y: رقم،
    عنوان: عنوان_مقبس،
    آخر_تحديث: رقم
}

// خادم اللعبة
صنف خادم_اللعبة {
    مقبس: مقبس_udp
    لاعبون: قائمة<لاعب>
    معرف_تالي: رقم
    
    دالة __init__() {
        هذا.مقبس = شبكة.انشئ_مقبس_udp()
        هذا.مقبس.اربط(8000)
        هذا.لاعبون = []
        هذا.معرف_تالي = 1
        
        اطبع("🎮 خادم اللعبة يعمل على المنفذ 8000")
    }
    
    دالة شغل() {
        // خيط لاستقبال التحديثات
        خيط.ابدأ(هذا.خيط_استقبال)
        
        // خيط لإرسال حالة اللعبة
        خيط.ابدأ(هذا.خيط_بث_الحالة)
        
        // خيط لتنظيف اللاعبين غير النشطين
        خيط.ابدأ(هذا.خيط_تنظيف)
    }
    
    دالة خيط_استقبال() {
        بينما صحيح {
            (بيانات، مرسل) = هذا.مقبس.استقبل_من(1024)
            هذا.عالج_رسالة(بيانات، مرسل)
        }
    }
    
    دالة عالج_رسالة(بيانات، مرسل) {
        نوع = بيانات[0]  // أول بايت: نوع الرسالة
        
        إذا نوع == 0x01 {  // JOIN
            // لاعب جديد
            لاعب_جديد = {
                معرف: هذا.معرف_تالي،
                موقع_x: 0،
                موقع_y: 0،
                عنوان: مرسل،
                آخر_تحديث: وقت.الآن()
            }
            
            هذا.لاعبون.أضف(لاعب_جديد)
            اطبع("✅ لاعب جديد #" + هذا.معرف_تالي + " انضم")
            
            // إرسال المعرف للاعب
            رد = [0x02، هذا.معرف_تالي]
            هذا.مقبس.ارسل_الى(رد، مرسل)
            
            هذا.معرف_تالي = هذا.معرف_تالي + 1
            
        } وإلا إذا نوع == 0x03 {  // UPDATE_POSITION
            // تحديث موقع لاعب
            معرف_لاعب = بيانات[1]
            موقع_x = فك_رقم(بيانات، 2)
            موقع_y = فك_رقم(بيانات، 6)
            
            لاعب = هذا.أوجد_لاعب(معرف_لاعب)
            إذا لاعب != باطل {
                لاعب.موقع_x = موقع_x
                لاعب.موقع_y = موقع_y
                لاعب.آخر_تحديث = وقت.الآن()
            }
        }
    }
    
    دالة خيط_بث_الحالة() {
        بينما صحيح {
            // بناء حزمة حالة اللعبة
            حزمة = بناء_حزمة_حالة(هذا.لاعبون)
            
            // إرسال لكل اللاعبين
            لكل لاعب في هذا.لاعبون {
                هذا.مقبس.ارسل_الى(حزمة، لاعب.عنوان)
            }
            
            // 60 تحديث في الثانية
            نم(16)  // ~16ms = 60 FPS
        }
    }
    
    دالة خيط_تنظيف() {
        بينما صحيح {
            الآن = وقت.الآن()
            
            // حذف اللاعبين الذين لم يرسلوا تحديث منذ 5 ثوانٍ
            لكل لاعب في هذا.لاعبون {
                إذا (الآن - لاعب.آخر_تحديث) > 5000 {
                    اطبع("❌ لاعب #" + لاعب.معرف + " انقطع")
                    هذا.لاعبون.احذف(لاعب)
                }
            }
            
            نم(1000)  // فحص كل ثانية
        }
    }
}

// عميل اللعبة
صنف عميل_اللعبة {
    مقبس: مقبس_udp
    معرفي: رقم
    موقعي_x: رقم
    موقعي_y: رقم
    
    دالة اتصل(عنوان_خادم، منفذ) {
        هذا.مقبس = شبكة.انشئ_مقبس_udp()
        هذا.مقبس.اتصل(عنوان_خادم، منفذ)
        
        // إرسال طلب انضمام
        هذا.مقبس.ارسل([0x01])  // JOIN
        
        // استقبال المعرف
        (رد، _) = هذا.مقبس.استقبل(1024)
        هذا.معرفي = رد[1]
        
        اطبع("✅ انضممت للعبة! معرفك: " + هذا.معرفي)
        
        // بدء خيط الاستقبال
        خيط.ابدأ(هذا.خيط_استقبال)
    }
    
    دالة حرك(x، y) {
        هذا.موقعي_x = x
        هذا.موقعي_y = y
        
        // إرسال تحديث موقع
        حزمة = [0x03، هذا.معرفي] + رمز_رقم(x) + رمز_رقم(y)
        هذا.مقبس.ارسل(حزمة)
    }
    
    دالة خيط_استقبال() {
        بينما صحيح {
            (حالة، _) = هذا.مقبس.استقبل(4096)
            هذا.حدث_عالم_اللعبة(حالة)
        }
    }
}
```

هذا المثال يوضح كيف تستخدم الألعاب الحديثة UDP لمزامنة سريعة مع تحمل فقدان بسيط للبيانات!

## ⚠️ التحديات والحلول

### 1. فقدان الحزم

**المشكلة:** UDP لا يضمن وصول الحزم.

**الحل:** أضف إعادة إرسال على مستوى التطبيق للبيانات الحرجة:

```sad
دالة ارسل_موثوق(مقبس، بيانات، عنوان، محاولات_قصوى=3) {
    لـ محاولة من 1 إلى محاولات_قصوى {
        مقبس.ارسل_الى(بيانات، عنوان)
        مقبس.عين_مهلة_الاستقبال(1000)
        
        محاولة {
            (رد، _) = مقبس.استقبل_من(1024)
            إذا رد == "ACK" {
                ارجع صحيح  // نجح!
            }
        } اصطياد (مهلة) {
            اطبع("المحاولة " + محاولة + " فشلت، أعيد...")
        }
    }
    
    ارجع خطأ  // فشل بعد كل المحاولات
}
```

### 2. الحزم خارج الترتيب

**المشكلة:** الحزم قد تصل بترتيب مختلف.

**الحل:** أضف رقم تسلسل:

```sad
رقم_تسلسل = 0

دالة ارسل_مرتب(مقبس، بيانات، عنوان) {
    حزمة = [رقم_تسلسل] + بيانات
    مقبس.ارسل_الى(حزمة، عنوان)
    رقم_تسلسل = رقم_تسلسل + 1
}

// في المستقبِل:
مخزن_مؤقت = {}
رقم_متوقع = 0

دالة استقبل_مرتب(مقبس) {
    (حزمة، مرسل) = مقبس.استقبل_من(4096)
    رقم = حزمة[0]
    بيانات = حزمة[1:]
    
    إذا رقم == رقم_متوقع {
        // الحزمة المتوقعة
        رقم_متوقع = رقم_متوقع + 1
        ارجع بيانات
    } وإلا {
        // حزمة متقدمة - حفظها للاحقاً
        مخزن_مؤقت[رقم] = بيانات
        ارجع باطل
    }
}
```

### 3. الحزم المكررة

**المشكلة:** نفس الحزمة قد تصل مرتين.

**الحل:** احتفظ بسجل الأرقام المستلمة:

```sad
أرقام_مستلمة = مجموعة()

دالة استقبل_بدون_تكرار(مقبس) {
    (حزمة، مرسل) = مقبس.استقبل_من(4096)
    رقم = حزمة[0]
    
    إذا رقم في أرقام_مستلمة {
        ارجع باطل  // مكرر - تجاهله
    }
    
    أرقام_مستلمة.أضف(رقم)
    ارجع حزمة[1:]
}
```
