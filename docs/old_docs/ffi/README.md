## 🎯 مقدمة

**جسر ص** هو نظام التكامل مع لغة C/C++ في لغة ص. يتيح لك استخدام مكتبات C الموجودة
مع الحفاظ على أمان الذاكرة وسلامة الأنواع التي تميز لغة ص.

### الميزات الرئيسية

| الميزة | الوصف |
|--------|-------|
| 🔒 **أمان الذاكرة** | تتبع الملكية والتحرير التلقائي |
| 🏷️ **تعليقات الملكية** | توثيق سلوك الدوال الخارجية |
| ⚠️ **تحذيرات ذكية** | كشف التسريبات وقت الترجمة |
| 🔧 **توليد تلقائي** | أداة لتحويل ملفات .h لـ ص |
| 🌍 **واجهة عربية** | أسماء عربية لجميع دوال libc |

## 📦 الكتل الخارجية (خارجي "C")

### البنية الأساسية

```س
خارجي "C" {
    // إعلان دالة C
    دالة اسم_الدالة(معامل١: نوع١, معامل٢: نوع٢) -> نوع_الإرجاع;
}
```

### مثال كامل

```س
// ═══════════════════════════════════════════════════════════════
// إعلان دوال C القياسية
// ═══════════════════════════════════════════════════════════════

خارجي "C" {
    // ─────────────────────────────────────────────────────────────
    // دوال الذاكرة
    // ─────────────────────────────────────────────────────────────
    
    #[ملك_النتيجة]
    #[يُحرر_بـ: free]
    دالة malloc(حجم: حجم) -> *متغير فراغ;
    
    دالة free(مؤشر: *متغير فراغ);
    
    #[ملك_النتيجة]
    #[يُحرر_بـ: free]
    دالة calloc(عدد: حجم, حجم_العنصر: حجم) -> *متغير فراغ;
    
    // ─────────────────────────────────────────────────────────────
    // دوال النصوص
    // ─────────────────────────────────────────────────────────────
    
    دالة strlen(نص: *ثابت حرف) -> حجم;
    
    #[يستعير: المصدر]
    دالة strcpy(الهدف: *متغير حرف, المصدر: *ثابت حرف) -> *متغير حرف;
    
    #[ملك_النتيجة]
    #[يُحرر_بـ: free]
    دالة strdup(نص: *ثابت حرف) -> *متغير حرف;
    
    // ─────────────────────────────────────────────────────────────
    // دوال الإدخال/الإخراج
    // ─────────────────────────────────────────────────────────────
    
    دالة printf(تنسيق: *ثابت حرف, ...) -> ص32;
    دالة puts(نص: *ثابت حرف) -> ص32;
    
    #[ملك_النتيجة]
    #[يُحرر_بـ: fclose]
    دالة fopen(مسار: *ثابت حرف, وضع: *ثابت حرف) -> *متغير ملف;
    
    دالة fclose(ملف: *متغير ملف) -> ص32;
}
```

### اصطلاحات الاستدعاء

| الاصطلاح | الوصف | الاستخدام |
|----------|-------|-----------|
| `"C"` | اصطلاح C القياسي (cdecl) | الافتراضي |
| `"C-stdcall"` | stdcall (Windows API) | Win32 API |
| `"C-fastcall"` | fastcall | دوال سريعة |
| `"C-vectorcall"` | vectorcall | SIMD |

```س
// مثال Windows API
خارجي "C-stdcall" {
    دالة MessageBoxW(
        نافذة: *متغير فراغ,
        نص: *ثابت ص16,
        عنوان: *ثابت ص16,
        نوع: ص32
    ) -> ص32;
}
```

| `char` | `حرف` | 1 | حرف/بايت |

| `unsigned int` | `ص_غ32` | 4 | عدد طبيعي 32-بت |

| `unsigned long long` | `ص_غ64` | 8 | عدد طبيعي 64-بت |

## 🏷️ تعليقات الملكية

تعليقات الملكية هي نظام فريد في لغة ص يوثق سلوك الدوال الخارجية
ويساعد المترجم في كشف أخطاء الذاكرة.

### التعليقات المتاحة

| التعليق | المعنى | مثال |
|---------|--------|-------|
| `#[ملك_النتيجة]` | الدالة تُرجع ذاكرة يجب تحريرها | `malloc` |
| `#[يُحرر_بـ: دالة]` | الذاكرة تُحرر بهذه الدالة | `free`, `fclose` |
| `#[يستعير]` | الدالة تستعير المعامل دون نقل ملكيته | `strlen` |
| `#[ينقل]` | الدالة تأخذ ملكية المعامل | - |
| `#[اختياري]` | المعامل يمكن أن يكون null | - |
| `#[غير_فارغ]` | المعامل يجب ألا يكون null | - |

### أمثلة تفصيلية

```س
خارجي "C" {
    // ─────────────────────────────────────────────────────────────
    // malloc: تُرجع ذاكرة مملوكة، تُحرر بـ free
    // ─────────────────────────────────────────────────────────────
    #[ملك_النتيجة]
    #[يُحرر_بـ: free]
    دالة malloc(حجم: حجم) -> *متغير فراغ;
    
    // ─────────────────────────────────────────────────────────────
    // fopen: تُرجع مقبض ملف، يُحرر بـ fclose
    // ─────────────────────────────────────────────────────────────
    #[ملك_النتيجة]
    #[يُحرر_بـ: fclose]
    دالة fopen(
        #[غير_فارغ] مسار: *ثابت حرف,
        #[غير_فارغ] وضع: *ثابت حرف
    ) -> *متغير ملف;  // قد تُرجع null
    
    // ─────────────────────────────────────────────────────────────
    // strlen: تستعير النص للقراءة فقط
    // ─────────────────────────────────────────────────────────────
    #[يستعير: نص]
    دالة strlen(
        #[غير_فارغ] نص: *ثابت حرف
    ) -> حجم;
    
    // ─────────────────────────────────────────────────────────────
    // strcpy: تستعير المصدر، تكتب في الهدف
    // ─────────────────────────────────────────────────────────────
    #[يستعير: المصدر]
    دالة strcpy(
        #[غير_فارغ] الهدف: *متغير حرف,
        #[غير_فارغ] المصدر: *ثابت حرف
    ) -> *متغير حرف;
    
    // ─────────────────────────────────────────────────────────────
    // realloc: تنقل ملكية المؤشر القديم
    // ─────────────────────────────────────────────────────────────
    #[ملك_النتيجة]
    #[يُحرر_بـ: free]
    #[ينقل: مؤشر]
    دالة realloc(
        #[اختياري] مؤشر: *متغير فراغ,
        حجم_جديد: حجم
    ) -> *متغير فراغ;
}
```

## 🛡️ الأغلفة الآمنة

الأغلفة الآمنة تحوّل دوال C الخطرة إلى دوال ص آمنة.

### البنية العامة

```س
// ═══════════════════════════════════════════════════════════════
// غلاف آمن لـ malloc
// ═══════════════════════════════════════════════════════════════

/// يحجز ذاكرة بشكل آمن ويُرجع نتيجة
دالة احجز_ذاكرة_آمن<ن>(عدد: حجم) -> نتيجة<*متغير ن, خطأ_ذاكرة> {
    إذا عدد == ٠ {
        إرجاع فشل(خطأ_ذاكرة::حجم_صفري);
    }
    
    متغير حجم_كلي = عدد * حجم_نوع<ن>();
    
    غير_آمن {
        متغير مؤشر = malloc(حجم_كلي) كـ *متغير ن;
        
        إذا مؤشر == فارغ {
            إرجاع فشل(خطأ_ذاكرة::فشل_حجز);
        }
        
        إرجاع نجاح(مؤشر);
    }
}
```

### أغلفة الملفات

```س
// ═══════════════════════════════════════════════════════════════
// غلاف آمن لعمليات الملفات
// ═══════════════════════════════════════════════════════════════

/// ملف مُدار تلقائياً
بنية ملف_آمن {
    مقبض: *متغير ملف,
}

تطبيق ملف_آمن {
    /// فتح ملف
    دالة افتح(مسار: نص, وضع: نص) -> نتيجة<ملف_آمن, خطأ_ملف> {
        غير_آمن {
            متغير مقبض = fopen(مسار.كـ_c_نص(), وضع.كـ_c_نص());
            
            إذا مقبض == فارغ {
                إرجاع فشل(خطأ_ملف::فشل_فتح);
            }
            
            إرجاع نجاح(ملف_آمن { مقبض });
        }
    }
    
    /// قراءة محتوى الملف
    دالة اقرأ(&ذات, مخزن: &متغير [ص_غ8]) -> نتيجة<حجم, خطأ_ملف> {
        غير_آمن {
            متغير تم_قراءته = fread(
                مخزن.كـ_مؤشر_متغير(),
                ١,
                مخزن.الطول(),
                ذات.مقبض
            );
            
            إذا ferror(ذات.مقبض) != ٠ {
                إرجاع فشل(خطأ_ملف::خطأ_قراءة);
            }
            
            إرجاع نجاح(تم_قراءته);
        }
    }
    
    /// كتابة في الملف
    دالة اكتب(&ذات, بيانات: &[ص_غ8]) -> نتيجة<حجم, خطأ_ملف> {
        غير_آمن {
            متغير تم_كتابته = fwrite(
                بيانات.كـ_مؤشر(),
                ١,
                بيانات.الطول(),
                ذات.مقبض
            );
            
            إذا تم_كتابته < بيانات.الطول() {
                إرجاع فشل(خطأ_ملف::خطأ_كتابة);
            }
            
            إرجاع نجاح(تم_كتابته);
        }
    }
}

// التحرير التلقائي عند خروج النطاق
تطبيق إسقاط لـ ملف_آمن {
    دالة أسقط(&متغير ذات) {
        إذا ذات.مقبض != فارغ {
            غير_آمن {
                fclose(ذات.مقبض);
            }
        }
    }
}
```

| `ص-FFI-012` | استخدام | تحرير مزدوج |
| `ص-FFI-013` | استخدام | تحرير غير صالح |
| `ص-FFI-014` | استخدام | عدم تطابق التخصيص/التحرير |
| `ص-FFI-021` | مؤشر | تمرير null لمعامل إلزامي |
| `ص-FFI-022` | مؤشر | نتيجة null غير مفحوصة |
| `ص-FFI-023` | مؤشر | مؤشر معلق |
| `ص-FFI-031` | ملكية | نقل قيمة مستعارة |
| `ص-FFI-032` | ملكية | ملكية غير واضحة |

### مثال على التحذيرات

```
تحذير[ص-FFI-001]: تسريب محتمل للذاكرة
   --> src/main.s:15:12
    |

    |            ^^^^^ المتغير 'ذاكرة' لم يُحرر
    |
   = ملاحظة: تم الحجز بواسطة malloc
   = اقتراح: استخدم free(ذاكرة) قبل نهاية النطاق

خطأ[ص-FFI-011]: استخدام بعد التحرير
   --> src/main.s:20:5
    |
 18 |     free(مؤشر);
    |     ----------- التحرير هنا
 ...
 20 |     *مؤشر = 42;
    |     ^^^^^^^^^^ استخدام بعد التحرير!
    |
   = ملاحظة: هذا سلوك غير محدد وقد يسبب انهيار البرنامج
```

## 🔧 أداة ص_ولّد_ربط

أداة سطر أوامر لتحويل ملفات C الرأسية (.h) إلى ربطات لغة ص.

### التثبيت

```bash
# الأداة مضمنة مع مترجم ص
ص --نسخة  # تأكد من الإصدار 1.0+
```

### الاستخدام الأساسي

```bash
# توليد ربطات بسيطة
ص_ولّد_ربط mylib.h -o ربط_mylib.sad

# مع ترجمة الأسماء للعربية
ص_ولّد_ربط mylib.h --ترجم-أسماء -o ربط_مكتبتي.sad

# مع أغلفة آمنة
ص_ولّد_ربط mylib.h --آمن -o ربط_آمن.sad

# الكل معاً
ص_ولّد_ربط mylib.h --آمن --ترجم-أسماء -o ربط_كامل.sad
```

### الخيارات الكاملة

| الخيار | الوصف |
|--------|-------|
| `-o, --output <ملف>` | ملف الخرج |
| `--آمن, --safe` | توليد أغلفة RAII آمنة |
| `--ترجم-أسماء, --translate` | ترجمة الأسماء للعربية |
| `--بادئة, --prefix <نص>` | بادئة للأسماء المولّدة |
| `-I, --include <مسار>` | مسار البحث عن ملفات الرأس |
| `--مكتبة, --library <اسم>` | اسم المكتبة |
| `--json` | إخراج JSON |
| `--مفصّل, --verbose` | وضع مفصّل |

### مثال عملي

**ملف الإدخال (mymath.h):**
```c
#ifndef MYMATH_H
#define MYMATH_H

typedef struct {
    double x;
    double y;
} Point;

typedef struct {
    Point center;
    double radius;
} Circle;

// Create a new circle
Circle* circle_create(double x, double y, double radius);

// Free a circle
void circle_free(Circle* c);

// Calculate area
double circle_area(const Circle* c);

// Calculate circumference
double circle_circumference(const Circle* c);

// Check if point is inside circle
int circle_contains(const Circle* c, const Point* p);

#endif
```

**الأمر:**
```bash
ص_ولّد_ربط mymath.h --آمن --ترجم-أسماء --مكتبة رياضيات -o ربط_رياضيات.sad
```

**ملف الخرج (ربط_رياضيات.sad):**
```س

 * @brief ربطات لغة ص لمكتبة رياضيات

    س: عش64,
    ص: عش64,
}

    نصف_قطر: عش64,

// الدوال الخارجية
// ═══════════════════════════════════════════════════════════════

    غير_آمن { circle_contains(&د كـ *ثابت دائرة, &ن كـ *ثابت نقطة) != ٠ }
```

### مثال 1: التعامل مع مكتبة SQLite

```س
// ═══════════════════════════════════════════════════════════════
// ربطات SQLite
// ═══════════════════════════════════════════════════════════════

خارجي "C" {
    نوع sqlite3;
    نوع sqlite3_stmt;
    
    ثابت SQLITE_OK: ص32 = ٠;
    ثابت SQLITE_ROW: ص32 = ١٠٠;
    ثابت SQLITE_DONE: ص32 = ١٠١;
    
    #[ملك_النتيجة]
    #[يُحرر_بـ: sqlite3_close]
    دالة sqlite3_open(اسم: *ثابت حرف, قاعدة: *متغير *متغير sqlite3) -> ص32;
    
    دالة sqlite3_close(قاعدة: *متغير sqlite3) -> ص32;
    
    دالة sqlite3_exec(
        قاعدة: *متغير sqlite3,
        استعلام: *ثابت حرف,
        استدعاء: *متغير فراغ,
        سياق: *متغير فراغ,
        خطأ: *متغير *متغير حرف
    ) -> ص32;
}

// غلاف آمن
بنية قاعدة_بيانات {
    مقبض: *متغير sqlite3,
}

تطبيق قاعدة_بيانات {
    دالة افتح(مسار: نص) -> نتيجة<قاعدة_بيانات, خطأ_قاعدة> {
        متغير مقبض: *متغير sqlite3 = فارغ;
        
        غير_آمن {
            متغير نتيجة = sqlite3_open(مسار.كـ_c_نص(), &متغير مقبض);
            
            إذا نتيجة != SQLITE_OK {
                إرجاع فشل(خطأ_قاعدة::فشل_فتح);
            }
        }
        
        إرجاع نجاح(قاعدة_بيانات { مقبض });
    }
    
    دالة نفّذ(&ذات, استعلام: نص) -> نتيجة<(), خطأ_قاعدة> {
        غير_آمن {
            متغير خطأ: *متغير حرف = فارغ;
            متغير نتيجة = sqlite3_exec(
                ذات.مقبض,
                استعلام.كـ_c_نص(),
                فارغ,
                فارغ,
                &متغير خطأ
            );
            
            إذا نتيجة != SQLITE_OK {
                إرجاع فشل(خطأ_قاعدة::فشل_تنفيذ);
            }
        }
        
        إرجاع نجاح(());
    }
}

تطبيق إسقاط لـ قاعدة_بيانات {
    دالة أسقط(&متغير ذات) {
        إذا ذات.مقبض != فارغ {
            غير_آمن { sqlite3_close(ذات.مقبض); }
        }
    }
}

// الاستخدام
دالة رئيسية() {
    متغير قب = قاعدة_بيانات::افتح("تطبيقي.db");
    
    طابق قب {
        نجاح(ق) => {
            ق.نفّذ("CREATE TABLE users (id INTEGER, name TEXT)");
            ق.نفّذ("INSERT INTO users VALUES (1, 'أحمد')");
            // القاعدة تُغلق تلقائياً
        }
        فشل(خ) => اطبع_سطر("فشل الاتصال");
    }
}
```

### مثال 3: استدعاء راجع (Callback)

```س
// ═══════════════════════════════════════════════════════════════
// التعامل مع callbacks من C
// ═══════════════════════════════════════════════════════════════

// تعريف نوع الاستدعاء الراجع
نوع دالة_مقارنة = دالة(*ثابت فراغ, *ثابت فراغ) -> ص32;

خارجي "C" {
    // qsort من libc
    دالة qsort(
        قاعدة: *متغير فراغ,
        عدد: حجم,
        حجم_عنصر: حجم,
        مقارنة: دالة_مقارنة
    );
}

// دالة مقارنة أعداد
خارجي "C" دالة قارن_أعداد(أ: *ثابت فراغ, ب: *ثابت فراغ) -> ص32 {
    متغير أ_عدد = *(أ كـ *ثابت ص32);
    متغير ب_عدد = *(ب كـ *ثابت ص32);
    
    إذا أ_عدد < ب_عدد {
        إرجاع -١;
    } وإلا إذا أ_عدد > ب_عدد {
        إرجاع ١;
    } وإلا {
        إرجاع ٠;
    }
}

// غلاف آمن للترتيب
دالة رتّب_أعداد(مصفوفة: &متغير [ص32]) {
    إذا مصفوفة.الطول() == ٠ {
        إرجاع;
    }
    
    غير_آمن {
        qsort(
            مصفوفة.كـ_مؤشر_متغير() كـ *متغير فراغ,
            مصفوفة.الطول(),
            حجم_نوع<ص32>(),
            قارن_أعداد
        );
    }
}

دالة رئيسية() {
    متغير أعداد: [ص32; ٥] = [٥, ٢, ٨, ١, ٩];
    
    اطبع_سطر("قبل الترتيب:");
    لكل عدد في &أعداد {
        اطبع_عدد(*عدد);
        اطبع(" ");
    }
    
    رتّب_أعداد(&متغير أعداد);
    
    اطبع_سطر("\nبعد الترتيب:");
    لكل عدد في &أعداد {
        اطبع_عدد(*عدد);
        اطبع(" ");
    }
}
```

## ✅ أفضل الممارسات

### 1. استخدم الأغلفة الآمنة دائماً

```س
// ❌ سيء - استخدام مباشر
غير_آمن {
    متغير م = malloc(١٠٠);
    // ... قد تنسى free
}

// ✅ جيد - غلاف آمن
متغير م = احجز_ذاكرة_آمن<ص32>(٢٥);
طابق م {
    نجاح(مؤشر) => {
        // استخدم بأمان
        // تحرير تلقائي
    }
    فشل(خ) => // معالجة الخطأ
}
```

### 2. تحقق دائماً من null

```س
// ❌ سيء
غير_آمن {
    متغير ملف = fopen("x.txt", "r");
    fread(..., ملف);  // قد يكون null!
}

// ✅ جيد
غير_آمن {
    متغير ملف = fopen("x.txt", "r");
    إذا ملف == فارغ {
        إرجاع فشل(خطأ::ملف_غير_موجود);
    }
    fread(..., ملف);
    fclose(ملف);
}
```

### 3. استخدم تعليقات الملكية

```س
// ❌ سيء - بدون توثيق
خارجي "C" {
    دالة my_alloc(حجم: حجم) -> *متغير فراغ;
}

// ✅ جيد - ملكية واضحة
خارجي "C" {
    #[ملك_النتيجة]
    #[يُحرر_بـ: my_free]
    دالة my_alloc(حجم: حجم) -> *متغير فراغ;
    
    دالة my_free(م: *متغير فراغ);
}
```

### 4. قلل نطاق `غير_آمن`

```س
// ❌ سيء - نطاق واسع
غير_آمن {
    متغير م = malloc(١٠٠);
    // ١٠٠ سطر من الكود...
    free(م);
}

// ✅ جيد - نطاق ضيق
متغير م = غير_آمن { malloc(١٠٠) };
إذا م == فارغ {
    إرجاع;
}

// كود آمن هنا...

غير_آمن { free(م); }
```

### 5. استخدم RAII مع البنى

```س
// ✅ ممتاز - RAII تلقائي
بنية مورد_c {
    مقبض: *متغير فراغ,
}

تطبيق إسقاط لـ مورد_c {
    دالة أسقط(&متغير ذات) {
        إذا ذات.مقبض != فارغ {
            غير_آمن { c_free_resource(ذات.مقبض); }
        }
    }
}
```

## 🔍 استكشاف الأخطاء

### مشكلة: "دالة غير معرّفة"

```
خطأ: الدالة 'malloc' غير معرّفة
```

**الحل**: تأكد من وجود `خارجي "C"`:

```س
خارجي "C" {
    دالة malloc(حجم: حجم) -> *متغير فراغ;
}
```

### مشكلة: "نوع غير متوافق"

```
خطأ: النوع 'int' غير متوافق مع 'ص32'
```

**الحل**: استخدم التحويل الصريح:

```س
متغير عدد: ص32 = c_function() كـ ص32;
```

### مشكلة: "تسريب ذاكرة"

```
تحذير[ص-FFI-001]: تسريب محتمل للذاكرة
```

**الحل**: استخدم غلاف آمن أو أضف `free`:

```س
// خيار 1: تحرير يدوي
غير_آمن {
    متغير م = malloc(١٠٠);
    // ...
    free(م);  // لا تنسَ!
}

// خيار 2: غلاف آمن (أفضل)
متغير م = احجز_ذاكرة_آمن<ص_غ8>(١٠٠);
```

### مشكلة: "انهيار عند التشغيل"

**الأسباب المحتملة**:
1. تمرير null لمعامل غير اختياري
2. استخدام بعد التحرير
3. تجاوز حدود المصفوفة

**الحل**: استخدم التحذيرات وفعّلها:

```س
#![تحذير(ص_FFI_الكل)]
```

## 📖 المرجع الكامل

### الكلمات المفتاحية

| الكلمة | الاستخدام |
|--------|-----------|
| `خارجي "C"` | كتلة إعلانات C |
| `غير_آمن` | كتلة كود غير آمن |
