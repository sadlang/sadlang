# أستاذ ص - نظام التعليم المدمج 🎓
# Sad Teacher System - Integrated Education

> **لغة ص هي أول لغة برمجة في العالم تُعلِّم مبرمجيها أثناء البرمجة!**
> 
> Sad is the world's first programming language that teaches its programmers while coding!

---

## 📖 نظرة عامة | Overview

نظام **أستاذ ص** هو نظام تعليمي ثوري مدمج في لغة ص يقدم:

- **دروس تفاعلية** عند مواجهة أخطاء
- **تمارين عملية** لتثبيت المفاهيم
- **فيديوهات تعليمية** مرتبطة بكل درس
- **تتبع التقدم** والإنجازات
- **مسارات تعليمية** مخصصة

### لماذا أستاذ ص؟ | Why Sad Teacher?

1. **التعلم السياقي**: تتعلم المفهوم عندما تحتاجه فعلاً
2. **لا حاجة للبحث الخارجي**: كل ما تحتاجه مدمج في اللغة
3. **تعلم بالممارسة**: تمارين تفاعلية بعد كل درس
4. **تحفيز مستمر**: نقاط وإنجازات ومستويات

## 🎯 ربط الأخطاء بالدروس | Error-to-Lesson Mapping

عندما تواجه خطأ، يقترح أستاذ ص درساً مناسباً:

| رمز الخطأ | الوصف | الدرس المقترح |
|-----------|-------|---------------|
| `ص0001` | نقل ملكية غير صالح | `ownership_basics` |
| `ص0002` | استخدام بعد النقل | `ownership_basics` |
| `ص0003` | استعارة متعددة قابلة للتعديل | `borrowing_rules` |
| `ص1001` | مطابقة نمط غير شاملة | `pattern_matching_intro` |
| `ص3001` | دالة غير معرّفة | `functions_basics` |

### مثال عملي

```sad
دالة رئيسية() {
    متغير نص = "مرحباً"
    متغير نص2 = نص
    اطبع(نص)  // ❌ خطأ ص0002: استخدام بعد النقل
}
```

## 📝 نظام التمارين | Exercise System

### أنواع التمارين

1. **اختيار من متعدد** - لفهم المفاهيم
2. **إكمال الكود** - لتطبيق ما تعلمته
3. **إصلاح الأخطاء** - لتعزيز مهارات التصحيح
4. **كتابة كود** - للتطبيق الكامل

## 📋 واجهة البرمجة | API Reference

### LessonContentManager

```cpp
// الحصول على المثيل
auto& manager = LessonContentManager::getInstance();

// تحميل الدروس
manager.loadEmbeddedLessons();

// الحصول على درس
auto* lesson = manager.getLesson("ownership_basics");

// البحث في الدروس
auto results = manager.searchLessons("ملكية");

// مسار المبتدئين
auto path = manager.getBeginnerPath();
```

### ExerciseEngine

```cpp
// الحصول على المحرك
auto& engine = getExerciseEngine();

// الحصول على تمرين
auto* exercise = engine.getExercise("ownership_basic_1");

// تقييم إجابة
auto result = engine.evaluateAnswer("ownership_basic_1", "ب");

// الحصول على تلميح
auto hint = engine.getHint("ownership_basic_1", 1);
```

### ProgressTracker

```cpp
// الحصول على المتتبع
auto& tracker = ProgressTracker::getInstance();

// بدء درس
tracker.startLesson("ownership_basics");

// إكمال تمرين
tracker.completeExercise("ownership_basics", true, 10);

// الحصول على التقدم
auto progress = tracker.getLessonProgress("ownership_basics");

// طباعة التقرير
tracker.printProgressReport();
```
