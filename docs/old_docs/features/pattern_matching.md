# 🎯 مطابقة الأنماط في لغة ص (Pattern Matching)

## Phase 12 - User Story 10

---

## 📋 نظرة عامة | Overview

مطابقة الأنماط (Pattern Matching) هي ميزة قوية في لغة ص تسمح بمقارنة القيم مع أنماط متعددة وتنفيذ كود مختلف حسب النمط المطابق.

Pattern Matching is a powerful feature in Sad language that allows comparing values against multiple patterns and executing different code based on the matching pattern.

---

## 🚀 الصيغة الأساسية | Basic Syntax

### جملة match | Match Statement

```sad
طابق قيمة {
    حالة 0:
        اطبع("صفر")
    حالة 1:
        اطبع("واحد")
    حالة _:
        اطبع("عدد آخر")
}
```

أو بالإنجليزية (Or in English):

```sad
match value {
    case 0:
        print("zero")
    case 1:
        print("one")
    case _:
        print("other number")
}
```

## 📝 أنواع الأنماط | Pattern Types

### 1. النمط الشامل (Wildcard Pattern) `_`

يطابق أي قيمة بدون ربطها بمتغير.

```sad
طابق x {
    حالة 1: اطبع("واحد")
    حالة _: اطبع("أي شيء آخر")  # النمط الشامل
}
```

### 2. نمط القيمة الحرفية (Literal Pattern)

يطابق قيمة محددة بالضبط.

```sad
طابق اللون {
    حالة "أحمر": اطبع("🔴")
    حالة "أخضر": اطبع("🟢")
    حالة "أزرق": اطبع("🔵")
}
```

**القيم المدعومة:**
- أرقام: `0`, `42`, `3.14`
- نصوص: `"مرحبا"`, `"hello"`
- منطقية: `صحيح`, `خطأ` (أو `true`, `false`)
- فارغ: `فارغ` (أو `null`)

### 3. نمط المتغير (Variable Pattern)

يطابق أي قيمة ويربطها بمتغير للاستخدام في الجسم.

```sad
طابق x {
    حالة 0: اطبع("صفر")
    حالة n: اطبع("القيمة هي: ", n)  # n يحتوي على قيمة x
}
```

### 4. نمط القائمة (List Pattern)

يطابق قوائم بهيكل معين.

```sad
طابق القائمة {
    حالة []: 
        اطبع("قائمة فارغة")
    حالة [x]: 
        اطبع("عنصر واحد: ", x)
    حالة [أول، ثاني]: 
        اطبع("عنصران: ", أول, " و ", ثاني)
    حالة [أول، *باقي]: 
        اطبع("أول عنصر: ", أول, " والباقي: ", باقي)
}
```

### 5. نمط OR (Or Pattern)

يطابق أي من عدة بدائل.

```sad
طابق اليوم {
    حالة "السبت" || "الأحد":
        اطبع("عطلة نهاية الأسبوع! 🎉")
    حالة _:
        اطبع("يوم عمل 💼")
}
```

## 🛡️ شروط الحراسة (Guard Clauses)

أضف شروطاً إضافية باستخدام `إذا` (أو `if`):

```sad
طابق العمر {
    حالة n إذا n < 0:
        اطبع("خطأ: عمر سالب!")
    حالة n إذا n < 18:
        اطبع("قاصر")
    حالة n إذا n < 65:
        اطبع("بالغ")
    حالة n:
        اطبع("متقاعد")
}
```

```sad
طابق الدرجة {
    حالة d إذا d >= 90: اطبع("ممتاز 🌟")
    حالة d إذا d >= 80: اطبع("جيد جداً")
    حالة d إذا d >= 70: اطبع("جيد")
    حالة d إذا d >= 60: اطبع("مقبول")
    حالة _: اطبع("راسب")
}
```

## 🔐 تكامل نظام الملكية | Ownership Integration

### النقل (Move) vs الاستعارة (Borrow)

```sad
# نقل الملكية (افتراضي)
طابق قيمة {
    حالة x:
        # x يملك القيمة الآن
        استخدم(x)
}
# قيمة لم تعد صالحة هنا

# الاستعارة (بالمرجع)
طابق &قيمة {
    حالة &x:
        # x مرجع للقيمة
        اقرأ(x)
}
# قيمة لا تزال صالحة
```

### الأنواع Copy

الأنواع البدائية تُنسخ تلقائياً:

```sad
رقم x = 42
طابق x {
    حالة n:
        اطبع(n)  # نسخة من x
}
اطبع(x)  # x لا يزال صالحاً (نوع Copy)
```

## ✅ فحص الشمولية (Exhaustiveness Checking)

المترجم يتحقق من تغطية جميع الحالات:

```sad
# ❌ خطأ: غير شامل
طابق منطقي {
    حالة صحيح: اطبع("صحيح")
    # مفقود: حالة خطأ
}

# ✅ صحيح: شامل
طابق منطقي {
    حالة صحيح: اطبع("صحيح")
    حالة خطأ: اطبع("خطأ")
}

# ✅ صحيح: باستخدام النمط الشامل
طابق منطقي {
    حالة صحيح: اطبع("صحيح")
    حالة _: اطبع("ليس صحيحاً")
}
```

## 🔄 فك التركيب (Destructuring)

### قوائم | Lists

```sad
متغير نقطة = [10، 20]
طابق نقطة {
    حالة [0، 0]:
        اطبع("نقطة الأصل")
    حالة [x، 0]:
        اطبع("على المحور السيني: x =", x)
    حالة [0، y]:
        اطبع("على المحور الصادي: y =", y)
    حالة [x، y]:
        اطبع("نقطة عند (", x, "، ", y, ")")
}
```

### مع Rest | With Rest

```sad
متغير أرقام = [1، 2، 3، 4، 5]
طابق أرقام {
    حالة []:
        اطبع("فارغ")
    حالة [أول]:
        اطبع("عنصر واحد: ", أول)
    حالة [أول، *باقي]:
        اطبع("أول: ", أول)
        اطبع("باقي: ", باقي)  # [2، 3، 4، 5]
}
```

## 🧪 أمثلة متقدمة | Advanced Examples

### مثال 1: معالجة نتائج API

```sad
نوع نتيجة<ت> = نجاح(ت) | فشل(نص)

دالة معالجة_استجابة(نتيجة: نتيجة<بيانات>) {
    طابق نتيجة {
        حالة نجاح(بيانات):
            اطبع("البيانات: ", بيانات)
        حالة فشل(رسالة) إذا رسالة.يحتوي("شبكة"):
            اطبع("خطأ شبكة: ", رسالة)
            أعد_المحاولة()
        حالة فشل(رسالة):
            اطبع("خطأ: ", رسالة)
    }
}
```

### مثال 2: آلة حالات

```sad
نوع حالة_اللعبة = قائمة | لعب | إيقاف | انتهاء

دالة حدث(الحالة: حالة_اللعبة، مدخل: نص) -> حالة_اللعبة {
    طابق [الحالة، مدخل] {
        حالة [قائمة، "ابدأ"]: إرجاع لعب
        حالة [لعب، "إيقاف"]: إرجاع إيقاف
        حالة [إيقاف، "استمر"]: إرجاع لعب
        حالة [لعب، "انتهى"]: إرجاع انتهاء
        حالة _: إرجاع الحالة
    }
}
```

### مثال 3: تحليل JSON

```sad
دالة تحليل_قيمة(json: قيمة_JSON) {
    طابق json {
        حالة رقم(n):
            اطبع("رقم: ", n)
        حالة نص(s):
            اطبع("نص: ", s)
        حالة قائمة(عناصر):
            لكل عنصر في عناصر {
                تحليل_قيمة(عنصر)
            }
        حالة كائن(حقول):
            لكل [مفتاح، قيمة] في حقول {
                اطبع(مفتاح, ": ")
                تحليل_قيمة(قيمة)
            }
        حالة فارغ:
            اطبع("null")
    }
}
```

## 📊 مقارنة مع if-else

### قبل (if-else)

```sad
إذا x == 0 {
    اطبع("صفر")
} وإلا_إذا x == 1 {
    اطبع("واحد")
} وإلا_إذا x == 2 || x == 3 {
    اطبع("اثنان أو ثلاثة")
} وإلا {
    اطبع("آخر")
}
```

### بعد (match)

```sad
طابق x {
    حالة 0: اطبع("صفر")
    حالة 1: اطبع("واحد")
    حالة 2 || 3: اطبع("اثنان أو ثلاثة")
    حالة _: اطبع("آخر")
}
```

**مميزات match:**
- ✅ أكثر وضوحاً وقراءة
- ✅ فحص شمولية تلقائي
- ✅ دعم فك التركيب
- ✅ أداء أفضل (jump table)

## ⚠️ أخطاء شائعة | Common Mistakes

### 1. نسيان النمط الشامل

```sad
# ❌ خطأ
طابق رقم {
    حالة 1: ...
    حالة 2: ...
}  # ماذا لو كان رقم = 3؟

# ✅ صحيح
طابق رقم {
    حالة 1: ...
    حالة 2: ...
    حالة _: ...  # معالجة الباقي
}
```

### 2. أنماط لا يمكن الوصول إليها

```sad
# ❌ تحذير: النمط الثاني لن يُطابق أبداً
طابق x {
    حالة _: اطبع("أي شيء")
    حالة 1: اطبع("واحد")  # لن يصل هنا أبداً!
}

# ✅ الترتيب الصحيح
طابق x {
    حالة 1: اطبع("واحد")
    حالة _: اطبع("أي شيء آخر")
}
```

### 3. متغيرات مختلفة في OR

```sad
# ❌ خطأ
حالة [x، _] || [_، y]:  # x و y مختلفان!

# ✅ صحيح
حالة [x، _] || [x، _]:  # نفس المتغير
```
