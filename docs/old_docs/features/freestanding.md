# دليل Freestanding الشامل للغة ص

## ما هو وضع Freestanding؟

وضع **Freestanding** (المستقل / بدون مكتبة) هو طريقة تشغيل لغة ص التي تُنتج كوداً يعمل **مباشرة على الحديدة** دون الحاجة إلى نظام تشغيل أو مكتبة C القياسية (libc). هذا يعني أن الكود الناتج يمكن تشغيله على:

- **المتحكمات الدقيقة** (Arduino، STM32، ESP32، Raspberry Pi Pico)
- **أنظمة RTOS** (FreeRTOS، Zephyr، RT-Thread)
- **أنظمة تشغيل مُخصَّصة** (أنوية OS من الصفر)
- **Bootloaders** وبرمجيات الإقلاع
- **نظم مدمجة صناعية** (PLC، وحدات تحكم صناعية)

---

## الفرق بين المترجمَين

تأتي لغة ص بأداتَين مختلفتَين لأغراض مختلفة:

| الميزة | `sad.exe` (المترجم التفاعلي) | `sadc.exe` (المترجم الفردي) |
|--------|------------------------------|------------------------------|
| **الغرض** | تطوير سريع، اختبار، تعليم | إنتاج كود bare-metal |
| **الكتابة** | ديناميكية (بدون أنواع) | ثابتة (مع أنواع صريحة) |
| **المكتبة القياسية** | متوفرة تلقائياً | يجب تعطيلها يدوياً |
| **التعليقات** | `#` | `#` |
| **المتغيرات** | `متغير اسم = قيمة` | `متغير اسم: نوع = قيمة` |
| **الدوال** | `دالة رئيسية()` | `#[نقطة_دخول] لن_ترجع دالة _start()` |
| **الأصناف/الهياكل** | `صنف` مع `باني` | `هيكل` فقط |

## أولاً: sad.exe — المترجم التفاعلي

### النحو الصحيح

```sad
# تعليق بالرمز #

# المتغيرات — بدون أنواع
متغير أ = 10
متغير ب = "نص"
متغير ج = صحيح

# الشروط
إذا (أ > 5)
    اطبع_سطر("أكبر من 5")
وإلا
    اطبع_سطر("أصغر من 5")
نهاية

# الحلقات
بينما (أ < 20)
    أ = أ + 1
نهاية

# الدوال
دالة اجمع(رقم أ، رقم ب)
    أرجع أ + ب
نهاية

# فصل المعاملات بـ ، (فاصلة عربية)
دالة رئيسية()
    متغير ناتج = اجمع(3، 7)
    اطبع_سطر(ناتج)
نهاية
```

### الأصناف (OOP) في sad.exe

```sad
صنف شخص
    نص الاسم          # حقل نصي
    رقم العمر         # حقل رقمي
    منطق نشط          # حقل منطقي

    باني(نص اسم_م، رقم عمر_م)
        هذا.الاسم = اسم_م
        هذا.العمر = عمر_م
        هذا.نشط = صحيح
    نهاية

    دالة قدِّم_نفسك()
        اطبع("اسمي ")
        اطبع(هذا.الاسم)
        اطبع(" وعمري ")
        اطبع_سطر(هذا.العمر)
    نهاية
نهاية

دالة رئيسية()
    متغير علي = جديد شخص("علي"، 25)
    علي.قدِّم_نفسك()
    اطبع_سطر(علي.الاسم)
نهاية
```

### قواعد مهمة لـ sad.exe

1. **فاصل المعاملات**: `،` (فاصلة عربية) وليس `,`
2. **حقول الصنف**: `نوع اسم_الحقل` (مثل `رقم العمر`) وليس `العمر = 0`
3. **إنشاء الكائن**: `جديد اسم_الصنف(معامل1، معامل2)`
4. **الوصول للحقول**: `هذا.الحقل` داخل الصنف، `كائن.الحقل` خارجه
5. **العمليات المدعومة**: `+` `-` `*` `/` `%` `==` `!=` `<` `>` `<=` `>=`
6. **غير مدعوم**: `^` (XOR) ، `>>` `<<` (إزاحة البت) ، `&` `|` (بت AND/OR)

## ثانياً: sadc.exe — مترجم Freestanding

### هيكل برنامج Freestanding الأساسي

```sad
# ==============================================================
# بدون مكتبة قياسية — الكود يعمل مباشرة على الحديدة
# ==============================================================

#![بلا_مكتبة_قياسية]
#![بلا_رئيسية]

# ثوابت عناوين الذاكرة المُوجَّهة للـ MMIO
ثابت عنوان_UART: عنوان = 0x40011000 ك عنوان
ثابت UART_DR: عنوان = عنوان_UART + 0x04

# متغيرات عالمية (في قسم .bss أو .data)
متغير_عام عدد_المقاطعات: ع32 = 0
متغير_عام مُهيَّأ: منطق = خطأ

# معالج الذعر — إلزامي في Freestanding
#[معالج_ذعر]
لن_ترجع دالة عند_الذعر(معلومات: *معلومات_ذعر)
    حلقة لا_نهائية
نهاية

# نقطة الدخول — تُستدعى من Bootloader أو BIOS
#[نقطة_دخول]
لن_ترجع دالة _start()
    هيئ_النظام()
    حلقة لا_نهائية
نهاية

دالة هيئ_النظام()
    مُهيَّأ = صحيح
نهاية
```

### أنواع البيانات في sadc.exe

| النوع | المعنى | الحجم |
|-------|--------|-------|
| `ع8` | عدد صحيح بدون إشارة 8-بت | 1 بايت |
| `ع16` | عدد صحيح بدون إشارة 16-بت | 2 بايت |
| `ع32` | عدد صحيح بدون إشارة 32-بت | 4 بايت |
| `ع64` | عدد صحيح بدون إشارة 64-بت | 8 بايت |
| `ح8` | عدد صحيح بإشارة 8-بت | 1 بايت |
| `ح16` | عدد صحيح بإشارة 16-بت | 2 بايت |
| `ح32` | عدد صحيح بإشارة 32-بت | 4 بايت |
| `ح64` | عدد صحيح بإشارة 64-بت | 8 بايت |
| `منطق` | قيمة منطقية (صحيح/خطأ) | 1 بايت |
| `عنوان` | عنوان ذاكرة (pointer-sized) | 4/8 بايت |
| `*نوع` | مؤشر لنوع معين | 4/8 بايت |
| `[نوع; N]` | مصفوفة ثابتة الحجم | N × حجم_النوع |

### إعلان المتغيرات في sadc.exe

```sad
# متغير محلي مع نوع
متغير عداد: ع32 = 0
متغير بايت_البيانات: ع8 = 0xFF
متغير مؤشر_حزمة: *ع8 = 0 ك *ع8

# متغير عالمي — يُخصَّص في .bss أو .data
متغير_عام عداد_الإطارات: ع64 = 0
متغير_عام مصفوفة: [ع8; 256] = [0; 256]

# ثابت — يُوضَع في .rodata
ثابت MAX_TASKS: ع32 = 32
ثابت عنوان_GPIO: عنوان = 0x40020000 ك عنوان
```

### الهياكل (structs)

```sad
# تعريف هيكل
هيكل سياق_معالج
    r0: ع32,
    r1: ع32,
    r2: ع32,
    r3: ع32,
    sp: عنوان,
    lr: عنوان,
    pc: عنوان,
نهاية

# استخدام الهيكل
متغير_عام سياق_حالي: سياق_معالج = سياق_معالج {
    r0: 0,
    r1: 0,
    sp: 0x20010000 ك عنوان,
    pc: 0 ك عنوان,
}
```

### المؤشرات وعمليات الذاكرة

```sad
# قراءة من عنوان ذاكرة مُوجَّه (MMIO)
دالة اقرأ_سجل(عنوان_سجل: عنوان) -> ع32
    أرجع *(عنوان_سجل ك *ع32)
نهاية

# كتابة إلى عنوان ذاكرة مُوجَّه
دالة اكتب_سجل(عنوان_سجل: عنوان، قيمة: ع32)
    *(عنوان_سجل ك *ع32) = قيمة
نهاية

# مثال: تفعيل ساعة GPIO على STM32
دالة هيئ_GPIO()
    ثابت RCC_AHB1ENR: عنوان = 0x40023830 ك عنوان
    متغير قيمة_حالية: ع32 = اقرأ_سجل(RCC_AHB1ENR)
    اكتب_سجل(RCC_AHB1ENR، قيمة_حالية | 0x01)  # تفعيل GPIOA
نهاية
```

## الإعدادات والسمات (Attributes)

### سمات الوحدة (أعلى الملف)

| السمة | المعنى |
|-------|--------|
| `#![بلا_مكتبة_قياسية]` | تعطيل مكتبة ص القياسية (إلزامي في Freestanding) |

| السمة | المعنى |
|-------|--------|
| `#[نقطة_دخول]` | دالة أول ما يُنفَّذ بعد الإقلاع |
| `#[معالج_ذعر]` | تُستدعى عند الأخطاء الحرجة |
| `#[مُنسَّق_C]` | دالة متوافقة مع C ABI |
| `#[مُضمَّن]` | قرار inlining إلزامي للمترجم |

## خط سير Freestanding الكامل

### 1. هيكل المشروع المُوصَى به

```
مشروع_متحكم/
├── src/
│   ├── main.ص          # نقطة الدخول والحلقة الرئيسية
│   ├── drivers/
│   │   ├── gpio.ص      # تشغيل GPIO
│   │   ├── uart.ص      # تشغيل UART
│   │   └── spi.ص       # تشغيل SPI
│   ├── kernel/
│   │   ├── scheduler.ص  # جدولة المهام
│   │   └── memory.ص    # إدارة الذاكرة
│   └── hal/
│       └── stm32f4.ص   # طبقة تجريد الحديدة
├── linker.ld            # نص الرابط
└── CMakeLists.txt       # ملف البناء
```

### 2. نص الرابط (linker script)

```ld
/* linker.ld — STM32F407 */
MEMORY
{
    FLASH (rx)  : ORIGIN = 0x08000000, LENGTH = 1M
    RAM   (rw)  : ORIGIN = 0x20000000, LENGTH = 192K
    CCM   (rw)  : ORIGIN = 0x10000000, LENGTH = 64K
}

SECTIONS
{
    .text : {
        KEEP(*(.isr_vector))    /* جدول متجهات المقاطعات */
        *(.text*)               /* كل الكود */
        *(.rodata*)             /* الثوابت */
    } > FLASH

    .data : {
        *(.data*)               /* المتغيرات العالمية المُهيَّأة */
    } > RAM AT > FLASH

    .bss : {
        *(.bss*)                /* المتغيرات العالمية الصفرية */
        *(COMMON)
    } > RAM
}
```

### 3. التجميع والربط

```bash
# تجميع مع sadc.exe
sadc.exe src/main.ص --target thumbv7em-none-eabihf -o main.o

# ربط
arm-none-eabi-ld -T linker.ld main.o -o firmware.elf

# تحويل إلى ثنائي قابل للتحميل
arm-none-eabi-objcopy -O binary firmware.elf firmware.bin

# تنزيل على الجهاز
openocd -f interface/stlink.cfg -f target/stm32f4x.cfg \
    -c "program firmware.bin 0x08000000 verify reset exit"
```

## أمثلة تفصيلية

### مثال 1: إضاءة LED على STM32

```sad
#![بلا_مكتبة_قياسية]
#![بلا_رئيسية]

# عناوين STM32F407 الحقيقية
ثابت RCC_BASE: عنوان = 0x40023800 ك عنوان
ثابت GPIOA_BASE: عنوان = 0x40020000 ك عنوان
ثابت RCC_AHB1ENR: عنوان = RCC_BASE + 0x30
ثابت GPIOA_MODER: عنوان = GPIOA_BASE + 0x00
ثابت GPIOA_ODR: عنوان = GPIOA_BASE + 0x14

دالة هيئ_LED()
    # تفعيل ساعة GPIOA
    متغير ahb1enr: *ع32 = RCC_AHB1ENR ك *ع32
    *ahb1enr = *ahb1enr | 0x01

    # ضبط PA5 كمخرج
    متغير moder: *ع32 = GPIOA_MODER ك *ع32
    *moder = (*moder & 0xFFFFF3FF) | 0x00000400
نهاية

دالة ضبط_LED(حالة: منطق)
    متغير odr: *ع32 = GPIOA_ODR ك *ع32
    إذا (حالة)
        *odr = *odr | 0x0020      # PA5 = 1
    وإلا
        *odr = *odr & 0xFFDF      # PA5 = 0
    نهاية
نهاية

دالة تأخير(مدة: ع32)
    متغير عداد: ع32 = 0
    بينما (عداد < مدة)
        عداد = عداد + 1
    نهاية
نهاية

#[معالج_ذعر]
لن_ترجع دالة عند_الذعر(معلومات: *معلومات_ذعر)
    حلقة لا_نهائية
نهاية

#[نقطة_دخول]
لن_ترجع دالة _start()
    هيئ_LED()
    حلقة لا_نهائية
        ضبط_LED(صحيح)
        تأخير(1000000)
        ضبط_LED(خطأ)
        تأخير(1000000)
    نهاية
نهاية
```

### مثال 2: UART بسيط على ARM

```sad
#![بلا_مكتبة_قياسية]
#![بلا_رئيسية]

# عناوين USART2 على STM32F4
ثابت USART2_BASE: عنوان = 0x40004400 ك عنوان
ثابت USART2_SR: عنوان = USART2_BASE + 0x00    # سجل الحالة
ثابت USART2_DR: عنوان = USART2_BASE + 0x04    # سجل البيانات
ثابت USART2_BRR: عنوان = USART2_BASE + 0x08   # سجل معدل الباود
ثابت USART2_CR1: عنوان = USART2_BASE + 0x0C   # سجل التحكم 1

ثابت SR_TXE: ع32 = (1 << 7)   # بت "إرسال فارغ"

دالة هيئ_UART(باود: ع32)
    متغير cr1: *ع32 = USART2_CR1 ك *ع32
    متغير brr: *ع32 = USART2_BRR ك *ع32
    # ضبط الباود: PCLK=16MHz
    *brr = 16000000 / باود
    # تفعيل TX + USART
    *cr1 = 0x200C
نهاية

دالة أرسل_بايت(بيانات: ع8)
    # انتظر حتى يكون TX خالياً
    متغير sr: *ع32 = USART2_SR ك *ع32
    بينما ((*sr & SR_TXE) == 0)
    نهاية
    متغير dr: *ع32 = USART2_DR ك *ع32
    *dr = بيانات ك ع32
نهاية

دالة أرسل_نص(نص: *ع8، طول: ع32)
    متغير ف: ع32 = 0
    بينما (ف < طول)
        أرسل_بايت(*(نص + ف))
        ف = ف + 1
    نهاية
نهاية

#[معالج_ذعر]
لن_ترجع دالة عند_الذعر(معلومات: *معلومات_ذعر)
    حلقة لا_نهائية
نهاية

#[نقطة_دخول]
لن_ترجع دالة _start()
    هيئ_UART(115200)
    حلقة لا_نهائية
نهاية
```

### مثال 3: مُخصِّص ذاكرة Bump Allocator

```sad
#![بلا_مكتبة_قياسية]
#![بلا_رئيسية]

# منطقة الكومة — 64 كيلوبايت
ثابت عنوان_الكومة: عنوان = 0x20010000 ك عنوان
ثابت حجم_الكومة: ع32 = 65536

متغير_عام رأس_الكومة: عنوان = عنوان_الكومة

# دالة التخصيص — O(1)
دالة خصِّص(حجم: ع32، محاذاة: ع32) -> عنوان
    # محاذاة العنوان الحالي
    متغير عنوان_خام: ع32 = رأس_الكومة ك ع32
    متغير مُحاذى: ع32 = (عنوان_خام + محاذاة - 1) / محاذاة * محاذاة

    # التحقق من توفر المساحة
    متغير نهاية الكومة: ع32 = (عنوان_الكومة ك ع32) + حجم_الكومة
    إذا (مُحاذى + حجم > نهاية الكومة)
        أرجع 0 ك عنوان  # فشل التخصيص
    نهاية

    # تحريك الرأس وإرجاع العنوان
    رأس_الكومة = (مُحاذى + حجم) ك عنوان
    أرجع مُحاذى ك عنوان
نهاية

# إعادة تعيين الكومة كاملة — O(1)
دالة صفِّر_الكومة()
    رأس_الكومة = عنوان_الكومة
نهاية
```


## ملفات Runtime Freestanding

تتضمن اللغة ملفات رأسية متخصصة لوضع Freestanding:

### `runtime_new/freestanding/sad_types.h`
يُعرِّف جميع أنواع البيانات الأساسية:
- `ع8`, `ع16`, `ع32`, `ع64` — أعداد بدون إشارة
- `ح8`, `ح16`, `ح32`, `ح64` — أعداد بإشارة
- `عنوان` — عنوان الذاكرة (مُتوافق مع المعمارية)
- `منطق` — القيم المنطقية

### `runtime_new/freestanding/sad_mmio.h`
ماكرو وعمليات MMIO:
- `اقرأ_سجل8(عنوان)` — قراءة 8-بت
- `اقرأ_سجل16(عنوان)` — قراءة 16-بت
- `اقرأ_سجل32(عنوان)` — قراءة 32-بت
- `اكتب_سجل32(عنوان، قيمة)` — كتابة 32-بت
- `عدِّل_سجل32(عنوان، قناع، قيمة)` — تعديل بتات محددة

### `runtime_new/freestanding/sad_interrupt.h`
التحكم بالمقاطعات:
- `علِّق_المقاطعات()` — تعليق جميع المقاطعات
- `شغِّل_المقاطعات()` — تفعيل جميع المقاطعات
- `حفظ_حالة_وعلِّق()` — للأقسام الحرجة

### `runtime_new/freestanding/sad_core.h`
عمليات المعالج الأساسية:
- `انتظر_أحداث()` — WFE (Wait For Event)
- `انتظر_مقاطعة()` — WFI (Wait For Interrupt)
- `تزامن_الذاكرة()` — Memory Barrier
- `إشارة_سطح()` — SEV (Send Event)

## الأخطاء الشائعة وحلولها

### خطأ: "Expected valid datatype"
```
خطأ: "Expected valid datatype. Current token: 'ع32'"
```
**السبب**: استخدام أنواع `sadc.exe` في `sad.exe`
**الحل**: احذف التعليمات بالنوع — `متغير أ = 10` بدلاً من `متغير أ: ع32 = 10`

---

### خطأ: "Unknown operator: ^"
```
خطأ: "Unknown operator: ^"
```
**السبب**: `^` (XOR) غير مدعوم في `sad.exe`
**الحل**: استخدم تشفير سيزر `(قيمة + مفتاح) % 256` بدلاً من XOR

---

### خطأ: "عضو صنف غير معروف"
```
خطأ: "Unknown class member"
```
**السبب**: تعريف حقول الصنف بالقيم مثل `الاسم = ""`
**الحل**: استخدم `نص الاسم` (نوع ثم اسم)، وفي الباني للمعاملات `باني(نص اسم_م)`

---

### خطأ: "unexpected token ')'"
**السبب**: العامل `×` داخل الأقواس `(أ × ب × ج)` يسبب مشكلة في بعض الحالات
**الحل**: اكسر العملية لخطوات:
```sad
# بدلاً من:   (حجم_FAT × عدد_FATs × حجم_قطاع)
# استخدم:
متغير temp = حجم_FAT * عدد_FATs
متغير نتيجة = temp * حجم_قطاع
```
ملاحظة: استخدم `*` بدلاً من `×` في حال التداخل.

---

### خطأ: "Unexpected token '>>" أو "<<"
**السبب**: عمليات إزاحة البت غير مدعومة في `sad.exe`
**الحل**: استبدل بالضرب/القسمة:
```sad
# بدلاً من:  قيمة >> 8
متغير نتيجة = قيمة / 256

# بدلاً من: قيمة << 4
متغير نتيجة = قيمة * 16
```

## نصائح الأداء في Freestanding

1. **تجنب malloc** — استخدم مُخصِّصات ثابتة (Slab, Bump) لمنع تشتت الذاكرة
2. **تجنب الاستدعاء العودي** في الأنظمة محدودة المكدس
3. **المُتقلِّبة (volatile)** — استخدم `متغير_عام` للمتغيرات المأثِّرة بالـ MMIO
4. **المحاذاة** — تأكد من محاذاة الهياكل على حدود الكلمة (word boundary)
5. **حجم الكود** — استخدم `-O2` في الإنتاج لتقليل البصمة (footprint)
6. **الاختبار أولاً** — اختبر الخوارزميات في `sad.exe` قبل نقلها لـ `sadc.exe`
