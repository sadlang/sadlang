## مقدمة

### ما هو نظام تطوير الهاتف في لغة ص؟

نظام تطوير تطبيقات الهاتف في لغة ص يُمكّنك من كتابة تطبيقات لأندرويد و iOS من كود واحد مكتوب بالعربية. يوفر النظام:

- **كتابة الكود بالعربية الكاملة**: جميع الكلمات المفتاحية والمعرفات عربية
- **منصة موحدة**: كود واحد يعمل على الأندرويد و iOS
- **أداء أصلي**: يُترجم إلى كود آلة (Native) وليس تفسيري
- **تكامل سلس**: يتكامل مع Jetpack Compose و SwiftUI

### المنصات المدعومة

| المنصة | المعمارية | الإصدار الأدنى |
|--------|-----------|---------------|
| Android | ARM64-v8a, armeabi-v7a, x86_64 | API 21 (Android 5.0) |
| iOS | ARM64 | iOS 14.0 |

## إنشاء مشروع جديد

### الطريقة الأولى: سطر الأوامر

```bash
# مشروع لكلا المنصتين
ص هاتف جديد --الكل تطبيقي

# مشروع أندرويد فقط
ص هاتف جديد --اندرويد تطبيقي

# مشروع iOS فقط
ص هاتف جديد --آيفون تطبيقي
```

### خيارات الإنشاء

```bash
ص هاتف جديد --الكل تطبيقي \
    --معرف com.example.myapp \
    --قالب تنقل \
    --كاميرا \
    --موقع
```

| الخيار | الوصف |
|--------|-------|
| `--الكل` | كلا المنصتين (Android + iOS) |
| `--اندرويد` | أندرويد فقط |
| `--آيفون` | iOS فقط |
| `--معرف` | معرف الحزمة (Bundle ID) |
| `--قالب` | قالب المشروع (فارغ، تنقل، قائمة، إلخ) |
| `--كاميرا` | إضافة دعم الكاميرا |
| `--موقع` | إضافة دعم الموقع |

### القوالب المتاحة

| القالب | الوصف |
|--------|-------|
| `فارغ` | مشروع بالحد الأدنى |
| `مرحبا` | تطبيق مرحباً بالعالم |
| `تنقل` | متعدد الشاشات |
| `قائمة` | قائمة مع تفاصيل |
| `أقسام` | تطبيق بأقسام (tabs) |
| `دخول` | شاشة تسجيل دخول |
| `خرائط` | تطبيق خرائط |
| `كاميرا` | تطبيق كاميرا |

### الطريقة الثانية: من الكود


```
                              │
```

1. افتح Android Studio
2. اختر "Open" وحدد مجلد `android/`

4. اضغط Run (▶️)

### تخصيص كود Android

```kotlin
// android/app/src/main/java/com/example/myapp/MainActivity.kt

class MainActivity : ComponentActivity() 
    // تحميل المكتبة الأصلية
    init 
        System.loadLibrary("sad_app")
    }
    
    // استدعاء دوال لغة ص
    external fun sadInit()
    external fun sadGetGreeting(): String
    
    override fun onCreate(savedInstanceState: Bundle?) 
        super.onCreate(savedInstanceState)
        
        sadInit() // تهيئة runtime لغة ص
        
        setContent 
            MyAppTheme 
                // استخدام القيم من لغة ص
                Text(text = sadGetGreeting())
            }
        }
    }
}
```

```swift
// ios/App/SadBridge.swift

import Foundation

// استيراد الدوال من لغة ص
@_silgen_name("sad_init")
func sadInit()

@_silgen_name("sad_get_greeting")
func sadGetGreeting() -> UnsafePointer<CChar>

class SadBridge 
    static func initialize() 
        sadInit()
    }
    
    static func getGreeting() -> String 
        return String(cString: sadGetGreeting())
    }
}
```

```swift
// ios/App/ContentView.swift

import SwiftUI

struct ContentView: View 
    var body: some View 
        VStack 
            Text(SadBridge.getGreeting())
                .font(.largeTitle)
        }
        .onAppear 
            SadBridge.initialize()
        }
    }
}
```

## الكود المشترك

### مبادئ الكود المشترك

1. **منطق الأعمال**: كل منطق التطبيق يكون في `shared/`
2. **نماذج البيانات**: تعريفات البيانات مشتركة
3. **الواجهة التصريحية**: نظام واجهة موحد
4. **Platform-specific**: فقط للميزات الخاصة بكل منصة

### مثال: نموذج بيانات مشترك

```sad
// shared/src/نماذج/مستخدم.ص

/// نموذج بيانات المستخدم
بنية مستخدم 
    معرف: نص
    اسم: نص
    بريد: نص
    صورة: نص?
    تاريخ_إنشاء: وقت
}

/// إدارة حالة المستخدم
صنف مدير_مستخدم 
    خاص مستخدم_حالي: مستخدم?
    
    /// تسجيل الدخول
    دالة سجّل_دخول(بريد: نص، كلمة_سر: نص) -> نتيجة<مستخدم، خطأ> 
        // منطق تسجيل الدخول
    }
    
    /// تسجيل الخروج
    دالة سجّل_خروج() 
        مستخدم_حالي = لاشيء
    }
    
    /// الحصول على المستخدم الحالي
    دالة المستخدم_الحالي() -> مستخدم? 
        ارجع مستخدم_حالي
    }
}
```

### مثال: خدمة شبكة مشتركة

```sad
// shared/src/خدمات/شبكة.ص

استورد http

/// خدمة الشبكة المشتركة
صنف خدمة_api 
    خاص عنوان_أساسي: نص
    
    منشئ(عنوان: نص) 
        عنوان_أساسي = عنوان
    }
    
    /// طلب GET
    دالة احصل<ن: قابل_للفك>(مسار: نص) -> نتيجة<ن، خطأ_شبكة> async 
        دع رابط = عنوان_أساسي + مسار
        دع استجابة = انتظر http.احصل(رابط)
        
        إذا استجابة.ناجح 
            ارجع .نجاح(استجابة.فك<ن>())
        } وإلا 
            ارجع .فشل(.خطأ_اتصال(استجابة.رمز))
        }
    }
    
    /// طلب POST
    دالة أرسل<ط: قابل_للترميز، ن: قابل_للفك>(
        مسار: نص، 
        بيانات: ط
    ) -> نتيجة<ن، خطأ_شبكة> async 
        دع رابط = عنوان_أساسي + مسار
        دع استجابة = انتظر http.أرسل(رابط، json: بيانات)
        
        إذا استجابة.ناجح 
            ارجع .نجاح(استجابة.فك<ن>())
        } وإلا 
            ارجع .فشل(.خطأ_اتصال(استجابة.رمز))
        }
    }
}
```

## واجهة المستخدم بالعربية

### نظام واجهة ص الموحد (SadUI)

```sad
// shared/src/واجهات/شاشة_رئيسية.ص

استورد واجهة

/// الشاشة الرئيسية
واجهة شاشة_رئيسية 
    // حالة الشاشة
    @حالة عناصر: [عنصر] = []
    @حالة محمّل: منطقي = خطأ
    
    عرض() 
        قائمة_تنقل 
            إذا محمّل 
                مؤشر_تحميل()
            } وإلا 
                قائمة(عناصر)  عنصر في
                    صف_عنصر(عنصر)
                }
            }
        }
        .عنوان("قائمتي")
        .زر_إضافة 
            أضف_عنصر()
        }
    }
    
    /// صف عنصر واحد
    @منشئ_واجهة
    دالة صف_عنصر(_ عنصر: عنصر) -> واجهة 
        صف 
            صورة(عنصر.أيقونة)
                .حجم(٤٠)
            
            عمود 
                نص(عنصر.عنوان)
                    .خط(.عنوان)
                نص(عنصر.وصف)
                    .خط(.فرعي)
                    .لون(.رمادي)
            }
        }
        .عند_النقر 
            اذهب_إلى(شاشة_تفاصيل(عنصر))
        }
    }
}
```

```
خطأ: لم يتم العثور على هوية توقيع صالحة
```

2. تأكد من وجود شهادة تطوير صالحة

**الحل**:
