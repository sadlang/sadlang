# Error Handling

This chapter covers exception handling, custom errors, and error recovery patterns in Sad language.

## Try-Catch Blocks

### Basic Try-Catch

```
دالة رئيسية()
    حاول
        رقم نتيجة = 10 / 0
        اطبع(نتيجة)
    امسك (خطأ)
        اطبع("حدث خطأ: ")
        اطبع(خطأ.رسالة)
        اطبع("\n")
    نهاية
    
    ارجع 0
نهاية
```

### Multiple Catch Blocks

```
حاول
    # Code that might throw different errors
    متغير ملف = افتح_ملف("data.txt")
    رقم رقم = لرقم(اقرأ_سطر(ملف))
    رقم نتيجة = 100 / رقم
    
امسك خطأ_ملف (خ)
    اطبع("خطأ في الملف: ")
    اطبع(خ.رسالة)
    اطبع("\n")
    
امسك خطأ_تحويل (خ)
    اطبع("خطأ في تحويل النص لرقم: ")
    اطبع(خ.رسالة)
    اطبع("\n")
    
امسك خطأ_قسمة (خ)
    اطبع("خطأ في القسمة: ")
    اطبع(خ.رسالة)
    اطبع("\n")
    
امسك (خ)
    # Catch all other errors
    اطبع("خطأ غير متوقع: ")
    اطبع(خ.رسالة)
    اطبع("\n")
نهاية
```

### Finally Block

```
متغير ملف = فارغ

حاول
    ملف = افتح_ملف("data.txt")
    # Process file...
    
امسك (خطأ)
    اطبع("خطأ: ")
    اطبع(خطأ.رسالة)
    اطبع("\n")
    
أخيراً
    # Always executed, even if error occurs
    إذا (ملف != فارغ)
        أغلق_ملف(ملف)
        اطبع("تم إغلاق الملف\n")
    نهاية
نهاية
```

## Throwing Errors

### Basic Throw

```
دالة قسمة(رقم أ، رقم ب) -> رقم
    إذا (ب == 0)
        ألقِ خطأ("لا يمكن القسمة على صفر")
    نهاية
    ارجع أ / ب
نهاية

دالة رئيسية()
    حاول
        رقم نتيجة = قسمة(10، 0)
    امسك (خ)
        اطبع("خطأ: ")
        اطبع(خ.رسالة)
    نهاية
    
    ارجع 0
نهاية
```

### Custom Error Types

```
خطأ خطأ_رصيد غير_كافي
    نص رسالة
    عشري المطلوب
    عشري المتاح
    
    دالة بناء(عشري مطلوب، عشري متاح)
        هذا.المطلوب = مطلوب
        هذا.المتاح = متاح
        هذا.رسالة = "رصيد غير كافي. المطلوب: " + لنص(مطلوب) + "، المتاح: " + لنص(متاح)
    نهاية
نهاية

فئة حساب
    خاص عشري الرصيد = 0
    
    دالة اسحب(عشري مبلغ)
        إذا (مبلغ > هذا.الرصيد)
            ألقِ خطأ_رصيد غير_كافي(مبلغ، هذا.الرصيد)
        نهاية
        هذا.الرصيد = هذا.الرصيد - مبلغ
    نهاية
نهاية

دالة رئيسية()
    متغير حسابي = حساب()
    
    حاول
        حسابي.اسحب(100)
    امسك خطأ_رصيد غير_كافي (خ)
        اطبع("❌ ")
        اطبع(خ.رسالة)
        اطبع("\n")
        اطبع("المطلوب: ")
        اطبع(خ.المطلوب)
        اطبع("\n")
        اطبع("المتاح: ")
        اطبع(خ.المتاح)
        اطبع("\n")
    نهاية
    
    ارجع 0
نهاية
```

## Result Type (نتيجة)

For operations that can fail, use the Result type instead of exceptions:

### Basic Result

```
دالة قسمة_آمنة(رقم أ، رقم ب) -> نتيجة<رقم، نص>
    إذا (ب == 0)
        ارجع فشل("لا يمكن القسمة على صفر")
    نهاية
    ارجع نجاح(أ / ب)
نهاية

دالة رئيسية()
    متغير نتيجة1 = قسمة_آمنة(10، 2)
    متغير نتيجة2 = قسمة_آمنة(10، 0)
    
    إذا (نتيجة1.ناجحة())
        اطبع("النتيجة: ")
        اطبع(نتيجة1.قيمة())  # 5
    نهاية
    
    إذا (نتيجة2.فاشلة())
        اطبع("خطأ: ")
        اطبع(نتيجة2.خطأ())  # "لا يمكن القسمة على صفر"
    نهاية
    
    ارجع 0
نهاية
```

### Chaining Results

```
دالة اقرأ_رقم_من_ملف(نص مسار) -> نتيجة<رقم، نص>
    متغير نتيجة_ملف = افتح_ملف_آمن(مسار)
    
    إذا (نتيجة_ملف.فاشلة())
        ارجع فشل(نتيجة_ملف.خطأ())
    نهاية
    
    متغير محتوى = اقرأ_ملف(نتيجة_ملف.قيمة())
    متغير نتيجة_تحويل = حوّل_لرقم_آمن(محتوى)
    
    إذا (نتيجة_تحويل.فاشلة())
        ارجع فشل("محتوى الملف ليس رقماً: " + نتيجة_تحويل.خطأ())
    نهاية
    
    ارجع نجاح(نتيجة_تحويل.قيمة())
نهاية
```

### Using Match with Results

```
دالة رئيسية()
    متغير نتيجة = قسمة_آمنة(10، 2)
    
    طابق نتيجة
        حالة نجاح(قيمة):
            اطبع("الناتج: ")
            اطبع(قيمة)
            اطبع("\n")
            
        حالة فشل(خطأ):
            اطبع("خطأ: ")
            اطبع(خطأ)
            اطبع("\n")
    نهاية
    
    ارجع 0
نهاية
```

## Optional Type (اختياري)

For values that might not exist:

```
دالة ابحث_عن_مستخدم(رقم معرف) -> اختياري<مستخدم>
    لكل م في المستخدمين
        إذا (م.المعرف == معرف)
            ارجع بعض(م)
        نهاية
    نهاية
    ارجع لا_شيء
نهاية

دالة رئيسية()
    متغير نتيجة = ابحث_عن_مستخدم(123)
    
    إذا (نتيجة.موجود())
        متغير المستخدم = نتيجة.قيمة()
        اطبع("وُجد: ")
        اطبع(المستخدم.الاسم)
    وإلا
        اطبع("المستخدم غير موجود")
    نهاية
    
    # Or use default
    متغير اسم = نتيجة.أو_افتراضي(مستخدم_افتراضي).الاسم
    
    ارجع 0
نهاية
```

## Validation Patterns

### Input Validation

```
دالة تحقق_من_البريد(نص بريد) -> نتيجة<نص، نص>
    إذا (بريد == "")
        ارجع فشل("البريد الإلكتروني مطلوب")
    نهاية
    
    إذا (! يحتوي(بريد، "@"))
        ارجع فشل("البريد يجب أن يحتوي على @")
    نهاية
    
    إذا (! يحتوي(بريد، "."))
        ارجع فشل("البريد يجب أن يحتوي على نطاق")
    نهاية
    
    ارجع نجاح(بريد)
نهاية

دالة تحقق_من_كلمة_المرور(نص كلمة_مرور) -> نتيجة<نص، مصفوفة>
    مصفوفة أخطاء = []
    
    إذا (طول(كلمة_مرور) < 8)
        أخطاء.أضف("يجب أن تكون 8 أحرف على الأقل")
    نهاية
    
    إذا (! يحتوي_على_رقم(كلمة_مرور))
        أخطاء.أضف("يجب أن تحتوي على رقم واحد على الأقل")
    نهاية
    
    إذا (! يحتوي_على_حرف_كبير(كلمة_مرور))
        أخطاء.أضف("يجب أن تحتوي على حرف كبير واحد على الأقل")
    نهاية
    
    إذا (طول(أخطاء) > 0)
        ارجع فشل(أخطاء)
    نهاية
    
    ارجع نجاح(كلمة_مرور)
نهاية
```

### Form Validation

```
فئة نموذج_تسجيل
    نص الاسم
    نص البريد
    نص كلمة_المرور
    رقم العمر
    
    دالة تحقق() -> نتيجة<منطقي، قاموس>
        قاموس أخطاء = {}
        
        # Validate name
        إذا (طول(هذا.الاسم) < 2)
            أخطاء["الاسم"] = "الاسم قصير جداً"
        نهاية
        
        # Validate email
        متغير نتيجة_البريد = تحقق_من_البريد(هذا.البريد)
        إذا (نتيجة_البريد.فاشلة())
            أخطاء["البريد"] = نتيجة_البريد.خطأ()
        نهاية
        
        # Validate password
        متغير نتيجة_كلمة_المرور = تحقق_من_كلمة_المرور(هذا.كلمة_المرور)
        إذا (نتيجة_كلمة_المرور.فاشلة())
            أخطاء["كلمة_المرور"] = نتيجة_كلمة_المرور.خطأ()
        نهاية
        
        # Validate age
        إذا (هذا.العمر < 13)
            أخطاء["العمر"] = "يجب أن يكون العمر 13 سنة على الأقل"
        نهاية
        
        إذا (طول(أخطاء) > 0)
            ارجع فشل(أخطاء)
        نهاية
        
        ارجع نجاح(صحيح)
    نهاية
نهاية
```

### Example 3: Transaction with Rollback

```
فئة معاملة_بنكية
    مصفوفة العمليات = []
    منطقي نشطة = خطأ
    
    دالة ابدأ()
        هذا.نشطة = صحيح
        هذا.العمليات = []
    نهاية
    
    دالة أضف_عملية(دالة عملية، دالة تراجع)
        إذا (هذا.نشطة)
            هذا.العمليات.أضف({
                "نفذ": عملية،
                "تراجع": تراجع
            })
        نهاية
    نهاية
    
    دالة نفذ() -> نتيجة<منطقي، نص>
        إذا (! هذا.نشطة)
            ارجع فشل("المعاملة غير نشطة")
        نهاية
        
        رقم ي = 0
        
        حاول
            بينما (ي < طول(هذا.العمليات))
                هذا.العمليات[ي]["نفذ"]()
                ي = ي + 1
            نهاية
            
            هذا.نشطة = خطأ
            ارجع نجاح(صحيح)
            
        امسك (خطأ)
            # Rollback all completed operations
            بينما (ي > 0)
                ي = ي - 1
                حاول
                    هذا.العمليات[ي]["تراجع"]()
                امسك (_)
                    # Log rollback failure but continue
                نهاية
            نهاية
            
            هذا.نشطة = خطأ
            ارجع فشل("فشلت المعاملة: " + خطأ.رسالة)
        نهاية
    نهاية
نهاية
```

## Best Practices

1. **Be Specific**: Catch specific errors, not general exceptions
2. **Fail Fast**: Validate inputs early and return errors immediately
3. **Use Result for Expected Failures**: Use exceptions for unexpected errors
4. **Provide Context**: Include helpful information in error messages
5. **Clean Up Resources**: Always use finally blocks for cleanup
6. **Don't Swallow Errors**: Log or handle errors, don't ignore them

## Exercises

1. **Safe Calculator**: Create a calculator that handles division by zero, overflow, etc.
2. **File Parser**: Parse a config file with detailed error messages for invalid syntax
3. **User Registration**: Implement complete validation with helpful error messages
4. **Retry Logic**: Implement a function that retries failed operations
5. **Error Aggregator**: Collect multiple errors and report them all at once
