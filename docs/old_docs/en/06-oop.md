# Object-Oriented Programming

This chapter covers classes, objects, encapsulation, inheritance, and polymorphism in Sad language.

## Classes and Objects

### Defining a Class

Use the `فئة` keyword to define a class:

```
فئة شخص
    نص الاسم
    رقم العمر
نهاية
```

### Creating Objects

```
دالة رئيسية()
    متغير أحمد = شخص()
    أحمد.الاسم = "أحمد محمد"
    أحمد.العمر = 25
    
    اطبع(أحمد.الاسم)  # أحمد محمد
    اطبع(أحمد.العمر)  # 25
    
    ارجع 0
نهاية
```

## Encapsulation

### Public and Private Members

By default, all members are public. Use `خاص` for private:

```
فئة حساب_بنكي
    # Public
    نص رقم_الحساب
    نص اسم_المالك
    
    # Private
    خاص عشري الرصيد = 0
    
    دالة بناء(نص رقم، نص اسم)
        هذا.رقم_الحساب = رقم
        هذا.اسم_المالك = اسم
    نهاية
    
    # Public method to access private balance
    دالة أودع(عشري مبلغ)
        إذا (مبلغ > 0)
            هذا.الرصيد = هذا.الرصيد + مبلغ
            اطبع("تم إيداع ")
            اطبع(مبلغ)
            اطبع("\n")
        نهاية
    نهاية
    
    دالة اسحب(عشري مبلغ) -> منطقي
        إذا (مبلغ > 0 && مبلغ <= هذا.الرصيد)
            هذا.الرصيد = هذا.الرصيد - مبلغ
            اطبع("تم سحب ")
            اطبع(مبلغ)
            اطبع("\n")
            ارجع صحيح
        نهاية
        اطبع("عملية السحب مرفوضة\n")
        ارجع خطأ
    نهاية
    
    دالة الرصيد_الحالي() -> عشري
        ارجع هذا.الرصيد
    نهاية
نهاية

دالة رئيسية()
    متغير حسابي = حساب_بنكي("SA1234567890"، "أحمد")
    
    حسابي.أودع(1000)
    حسابي.أودع(500)
    حسابي.اسحب(200)
    
    اطبع("الرصيد: ")
    اطبع(حسابي.الرصيد_الحالي())
    # Output: 1300
    
    # This would not work:
    # حسابي.الرصيد = 1000000  # Error: private member
    
    ارجع 0
نهاية
```

### Getters and Setters

```
فئة موظف
    خاص نص _الاسم

    دالة بناء(نص اسم، عشري راتب)
        هذا._الاسم = اسم

            هذا._الراتب = راتب_جديد
        وإلا
            اطبع("خطأ: الراتب يجب أن يكون موجباً\n")
        نهاية
    نهاية
    
    دالة الراتب() -> عشري
        ارجع هذا._الراتب
    نهاية
نهاية
```

## Inheritance

### Basic Inheritance

Use `يرث` to inherit from another class:

```
فئة حيوان
    نص الاسم
    
    دالة بناء(نص اسم)
        هذا.الاسم = اسم
    نهاية
    
    دالة تحدث()
        اطبع(هذا.الاسم)
        اطبع(" يصدر صوتاً\n")
    نهاية
نهاية

فئة قطة يرث حيوان
    دالة بناء(نص اسم)
        أساس.بناء(اسم)
    نهاية
    
    دالة تحدث()
        اطبع(هذا.الاسم)
        اطبع(" يقول: مياو!\n")
    نهاية
نهاية

فئة كلب يرث حيوان
    دالة بناء(نص اسم)
        أساس.بناء(اسم)
    نهاية
    
    دالة تحدث()
        اطبع(هذا.الاسم)
        اطبع(" يقول: هاو هاو!\n")
    نهاية
نهاية

دالة رئيسية()
    متغير قطتي = قطة("مشمش")
    متغير كلبي = كلب("بوبي")
    
    قطتي.تحدث()  # مشمش يقول: مياو!
    كلبي.تحدث()  # بوبي يقول: هاو هاو!
    
    ارجع 0
نهاية
```

### Calling Parent Methods

Use `أساس` to call parent class methods:

```
فئة مركبة
    نص النوع
    رقم السرعة_القصوى
    
    دالة بناء(نص نوع، رقم سرعة)
        هذا.النوع = نوع
        هذا.السرعة_القصوى = سرعة
    نهاية
    
    دالة وصف() -> نص
        ارجع هذا.النوع + " - سرعة قصوى: " + لنص(هذا.السرعة_القصوى)
    نهاية
نهاية

فئة سيارة يرث مركبة
    رقم عدد_الأبواب
    
    دالة بناء(نص نوع، رقم سرعة، رقم أبواب)
        أساس.بناء(نوع، سرعة)
        هذا.عدد_الأبواب = أبواب
    نهاية
    
    دالة وصف() -> نص
        نص وصف_أساسي = أساس.وصف()
        ارجع وصف_أساسي + " - أبواب: " + لنص(هذا.عدد_الأبواب)
    نهاية
نهاية
```

## Polymorphism

### Method Overriding

```
فئة شكل
    دالة المساحة() -> عشري
        ارجع 0
    نهاية
    
    دالة المحيط() -> عشري
        ارجع 0
    نهاية
نهاية

فئة مستطيل يرث شكل
    عشري الطول
    عشري العرض
    
    دالة بناء(عشري طول، عشري عرض)
        هذا.الطول = طول
        هذا.العرض = عرض
    نهاية
    
    دالة المساحة() -> عشري
        ارجع هذا.الطول * هذا.العرض
    نهاية
    
    دالة المحيط() -> عشري
        ارجع 2 * (هذا.الطول + هذا.العرض)
    نهاية
نهاية

فئة دائرة يرث شكل
    عشري نصف_القطر
    ثابت عشري باي = 3.14159
    
    دالة بناء(عشري نصف_قطر)
        هذا.نصف_القطر = نصف_قطر
    نهاية
    
    دالة المساحة() -> عشري
        ارجع باي * هذا.نصف_القطر * هذا.نصف_القطر
    نهاية
    
    دالة المحيط() -> عشري
        ارجع 2 * باي * هذا.نصف_القطر
    نهاية
نهاية

دالة اطبع_معلومات(شكل ش)
    اطبع("المساحة: ")
    اطبع(ش.المساحة())
    اطبع("\n")
    اطبع("المحيط: ")
    اطبع(ش.المحيط())
    اطبع("\n")
نهاية

دالة رئيسية()
    متغير مستطيل1 = مستطيل(10، 5)
    متغير دائرة1 = دائرة(7)
    
    اطبع("المستطيل:\n")
    اطبع_معلومات(مستطيل1)
    
    اطبع("\nالدائرة:\n")
    اطبع_معلومات(دائرة1)
    
    ارجع 0
نهاية
```

## Interfaces (سمة)

### Defining Interfaces

```
سمة قابل_للرسم
    دالة ارسم()
    دالة اللون() -> نص
نهاية

سمة قابل_للتحريك
    دالة حرّك(رقم س، رقم ص)
نهاية

فئة زر ينفذ قابل_للرسم، قابل_للتحريك
    رقم س
    رقم ص
    نص _اللون
    نص النص
    
    دالة بناء(رقم س، رقم ص، نص نص، نص لون)
        هذا.س = س
        هذا.ص = ص
        هذا.النص = نص
        هذا._اللون = لون
    نهاية
    
    دالة ارسم()
        اطبع("رسم زر [")
        اطبع(هذا.النص)
        اطبع("] في (")
        اطبع(هذا.س)
        اطبع("، ")
        اطبع(هذا.ص)
        اطبع(")\n")
    نهاية
    
    دالة اللون() -> نص
        ارجع هذا._اللون
    نهاية
    
    دالة حرّك(رقم س_جديد، رقم ص_جديد)
        هذا.س = س_جديد
        هذا.ص = ص_جديد
    نهاية
نهاية
```

## Practical Example: Library System

```
# ════════════════════════════════════════════
# نظام المكتبة الشامل
# ════════════════════════════════════════════

فئة كتاب
    نص الرقم
    نص العنوان
    نص المؤلف
    منطقي متاح = صحيح
    
    دالة بناء(نص رقم، نص عنوان، نص مؤلف)
        هذا.الرقم = رقم
        هذا.العنوان = عنوان
        هذا.المؤلف = مؤلف
    نهاية
    
    دالة استعر() -> منطقي
        إذا (هذا.متاح)
            هذا.متاح = خطأ
            ارجع صحيح
        نهاية
        ارجع خطأ
    نهاية
    
    دالة أعد()
        هذا.متاح = صحيح
    نهاية
    
    دالة اعرض()
        اطبع("[")
        اطبع(هذا.الرقم)
        اطبع("] ")
        اطبع(هذا.العنوان)
        اطبع(" - ")
        اطبع(هذا.المؤلف)
        إذا (هذا.متاح)
            اطبع(" ✅")
        وإلا
            اطبع(" ❌")
        نهاية
        اطبع("\n")
    نهاية
نهاية

فئة عضو
    نص المعرف
    نص الاسم
    مصفوفة الكتب_المستعارة = []
    
    دالة بناء(نص معرف، نص اسم)
        هذا.المعرف = معرف
        هذا.الاسم = اسم
    نهاية
    
    دالة استعر_كتاب(كتاب ك) -> منطقي
        إذا (طول(هذا.الكتب_المستعارة) >= 5)
            اطبع("تجاوزت الحد الأقصى للاستعارة\n")
            ارجع خطأ
        نهاية
        
        إذا (ك.استعر())
            هذا.الكتب_المستعارة.أضف(ك)
            اطبع("تم استعارة: ")
            اطبع(ك.العنوان)
            اطبع("\n")
            ارجع صحيح
        نهاية
        
        اطبع("الكتاب غير متاح\n")
        ارجع خطأ
    نهاية
    
    دالة أعد_كتاب(كتاب ك)
        لكل ي في مدى(0، طول(هذا.الكتب_المستعارة))
            إذا (هذا.الكتب_المستعارة[ي].الرقم == ك.الرقم)
                ك.أعد()
                هذا.الكتب_المستعارة.احذف(ي)
                اطبع("تم إرجاع: ")
                اطبع(ك.العنوان)
                اطبع("\n")
                ارجع
            نهاية
        نهاية
    نهاية
نهاية

فئة مكتبة
    نص الاسم
    مصفوفة الكتب = []
    مصفوفة الأعضاء = []
    
    دالة بناء(نص اسم)
        هذا.الاسم = اسم
    نهاية
    
    دالة أضف_كتاب(كتاب ك)
        هذا.الكتب.أضف(ك)
    نهاية
    
    دالة سجّل_عضو(عضو ع)
        هذا.الأعضاء.أضف(ع)
    نهاية
    
    دالة ابحث_بالعنوان(نص بحث) -> مصفوفة
        مصفوفة نتائج = []
        لكل ك في هذا.الكتب
            إذا (يحتوي(ك.العنوان، بحث))
                نتائج.أضف(ك)
            نهاية
        نهاية
        ارجع نتائج
    نهاية
    
    دالة الكتب_المتاحة() -> مصفوفة
        مصفوفة متاحة = []
        لكل ك في هذا.الكتب
            إذا (ك.متاح)
                متاحة.أضف(ك)
            نهاية
        نهاية
        ارجع متاحة
    نهاية
    
    دالة اعرض_الكتب()
        اطبع("📚 مكتبة ")
        اطبع(هذا.الاسم)
        اطبع("\n")
        اطبع("────────────────────────────\n")
        لكل ك في هذا.الكتب
            ك.اعرض()
        نهاية
    نهاية
نهاية

دالة رئيسية()
    # إنشاء المكتبة
    متغير مكتبتي = مكتبة("المعرفة")
    
    # إضافة الكتب
    مكتبتي.أضف_كتاب(كتاب("001"، "البرمجة للمبتدئين"، "أحمد محمد"))
    مكتبتي.أضف_كتاب(كتاب("002"، "الخوارزميات"، "خالد علي"))
    مكتبتي.أضف_كتاب(كتاب("003"، "قواعد البيانات"، "سارة أحمد"))
    
    # تسجيل عضو
    متغير عضو1 = عضو("M001"، "محمد سعيد")
    مكتبتي.سجّل_عضو(عضو1)
    
    # عرض الكتب
    مكتبتي.اعرض_الكتب()
    
    # استعارة كتاب
    اطبع("\n")
    عضو1.استعر_كتاب(مكتبتي.الكتب[0])
    
    # عرض الكتب بعد الاستعارة
    اطبع("\n")
    مكتبتي.اعرض_الكتب()
    
    ارجع 0
نهاية
```

## Best Practices

1. **Single Responsibility**: Each class should have one job
2. **Favor Composition**: Use composition over inheritance when possible
3. **Program to Interfaces**: Depend on abstractions, not implementations
4. **Keep Inheritance Shallow**: Avoid deep inheritance hierarchies
5. **Encapsulate Changes**: Hide implementation details that might change
