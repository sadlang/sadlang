# التغليف والتحكم في الوصول
## البرمجة الكائنية - الجزء الثالث

## 🎓 مقدمة: ما هو التغليف؟

**التغليف (Encapsulation)** هو مبدأ أساسي في البرمجة الكائنية يعني:
- **إخفاء التفاصيل الداخلية** للصنف عن العالم الخارجي
- **التحكم في الوصول** إلى البيانات والدوال
- **توفير واجهة عامة** واضحة للتعامل مع الكائن

### لماذا التغليف؟

تخيل صندوق أمان في البنك:
- لا يمكنك الوصول مباشرة إلى المحتويات (البيانات محمية)
- تستخدم **الواجهة** (القفل والمفتاح) للتفاعل معه
- التفاصيل الداخلية (آلية القفل) **مخفية** عنك

في البرمجة، التغليف يحقق نفس الهدف:
```
صنف حساب_بنكي
    # ❌ خاص - لا يمكن الوصول مباشرة
    خاصة عشري الرصيد
    
    # ✅ عام - واجهة عامة للتفاعل
    عامة دالة إيداع(عشري مبلغ) فراغ
        # التحقق من صحة المبلغ
        اذا (مبلغ > 0)
            هذا.الرصيد = هذا.الرصيد + مبلغ
        نهاية
    نهاية
    
    عامة دالة احصل_الرصيد() ترجع عشري
        ارجع هذا.الرصيد
    نهاية
نهاية
```

## 🔐 مستويات الوصول

لغة ص تدعم ثلاثة مستويات للوصول:

| المستوى | الكلمة المفتاحية | الوصول من الصنف نفسه | الوصول من صنف فرعي | الوصول من خارج الصنف |
|---------|------------------|----------------------|-------------------|---------------------|
| **عام** | `عامة` (public) | ✅ | ✅ | ✅ |
| **محمي** | `محمي` (protected) | ✅ | ✅ | ❌ |
| **خاص** | `خاصة` (private) | ✅ | ❌ | ❌ |

### الصيغة الأساسية

```
صنف اسم_الصنف
    # أعضاء عامة - يمكن الوصول إليها من أي مكان
    عامة نوع خاصية_عامة
    
    عامة دالة دالة_عامة() نوع_الإرجاع
        # ...
    نهاية
    
    # أعضاء محمية - للصنف والأصناف الفرعية فقط
    محمي نوع خاصية_محمية
    
    محمي دالة دالة_محمية() نوع_الإرجاع
        # ...
    نهاية
    
    # أعضاء خاصة - للصنف نفسه فقط
    خاصة نوع خاصية_خاصة
    
    خاصة دالة دالة_خاصة() نوع_الإرجاع
        # ...
    نهاية
نهاية
```

## 📖 مثال: حساب بنكي آمن

```
صنف حساب_بنكي
    # ═══ أعضاء خاصة - لا يمكن الوصول إليها من الخارج ═══
    خاصة رقم رقم_الحساب
    خاصة نص اسم_العميل
    خاصة عشري الرصيد
    خاصة نص رقم_السري  # حساس جداً!
    خاصة مصفوفة سجل_العمليات
    
    # ═══ منشئ عام ═══
    عامة دالة منشئ(رقم رقم، نص اسم، نص رقم_سري، عشري رصيد_أولي) فراغ
        هذا.رقم_الحساب = رقم
        هذا.اسم_العميل = اسم
        هذا.رقم_السري = رقم_سري
        هذا.الرصيد = رصيد_أولي
        هذا.سجل_العمليات = []
        
        هذا.سجل_عملية("فتح حساب برصيد: " + رصيد_أولي)
    نهاية
    
    # ═══ دوال خاصة - مساعدة داخلية ═══
    خاصة دالة سجل_عملية(نص وصف) فراغ
        أضف(هذا.سجل_العمليات، وصف)
    نهاية
    
    خاصة دالة تحقق_رقم_سري(نص رقم_مدخل) ترجع منطقي
        ارجع رقم_مدخل == هذا.رقم_السري
    نهاية
    
    # ═══ دوال عامة - الواجهة العامة ═══
    عامة دالة إيداع(عشري مبلغ) ترجع منطقي
        اذا (مبلغ <= 0)
            اطبع_سطر("❌ المبلغ يجب أن يكون موجباً")
            ارجع خطأ
        نهاية
        
        هذا.الرصيد = هذا.الرصيد + مبلغ
        هذا.سجل_عملية("إيداع: " + مبلغ)
        اطبع_سطر("✅ تم إيداع " + مبلغ + " ريال")
        ارجع صحيح
    نهاية
    
    عامة دالة سحب(عشري مبلغ، نص رقم_سري) ترجع منطقي
        # التحقق من الرقم السري
        اذا (!هذا.تحقق_رقم_سري(رقم_سري))
            اطبع_سطر("❌ رقم سري خاطئ!")
            ارجع خطأ
        نهاية
        
        اذا (مبلغ <= 0)
            اطبع_سطر("❌ المبلغ يجب أن يكون موجباً")
            ارجع خطأ
        نهاية
        
        اذا (مبلغ > هذا.الرصيد)
            اطبع_سطر("❌ رصيد غير كافٍ")
            ارجع خطأ
        نهاية
        
        هذا.الرصيد = هذا.الرصيد - مبلغ
        هذا.سجل_عملية("سحب: " + مبلغ)
        اطبع_سطر("✅ تم سحب " + مبلغ + " ريال")
        ارجع صحيح
    نهاية
    
    # Getter - قراءة الرصيد فقط (لا تعديل)
    عامة دالة احصل_الرصيد() ترجع عشري
        ارجع هذا.الرصيد
    نهاية
    
    عامة دالة احصل_رقم_الحساب() ترجع رقم
        ارجع هذا.رقم_الحساب
    نهاية
    
    عامة دالة اطبع_كشف_حساب(نص رقم_سري) فراغ
        اذا (!هذا.تحقق_رقم_سري(رقم_سري))
            اطبع_سطر("❌ رقم سري خاطئ!")
            ارجع
        نهاية
        
        اطبع_سطر("╔════════════════════════════════╗")
        اطبع_سطر("       كشف حساب               ")
        اطبع_سطر("╠════════════════════════════════╣")
        اطبع_سطر("  رقم الحساب: " + هذا.رقم_الحساب)
        اطبع_سطر("  العميل: " + هذا.اسم_العميل)
        اطبع_سطر("  الرصيد: " + هذا.الرصيد + " ريال")
        اطبع_سطر("╠════════════════════════════════╣")
        اطبع_سطر("  سجل العمليات:")
        
        لكل عملية في هذا.سجل_العمليات
            اطبع_سطر("  • " + عملية)
        نهاية
        
        اطبع_سطر("╚════════════════════════════════╝")
    نهاية
نهاية

# ========== الاستخدام ==========

دالة رئيسية() رقم
    حساب_بنكي حساب = جديد حساب_بنكي(12345، "أحمد محمد"، "1234"، 1000.0)
    
    اطبع_سطر("")
    اطبع_سطر("الرصيد الحالي: " + حساب.احصل_الرصيد())
    
    اطبع_سطر("")
    حساب.إيداع(500.0)
    
    اطبع_سطر("")
    حساب.سحب(200.0، "1234")  # رقم سري صحيح
    
    اطبع_سطر("")
    حساب.سحب(100.0، "9999")  # رقم سري خاطئ!
    
    # ❌ لا يمكن الوصول مباشرة للرصيد - محمي!
    # حساب.الرصيد = 9999999  # خطأ في الترجمة!
    
    اطبع_سطر("")
    حساب.اطبع_كشف_حساب("1234")
    
    ارجع 0
نهاية
```

## 🔒 الخصائص (Properties) - Getters & Setters

الخصائص هي طريقة للتحكم في الوصول للبيانات الخاصة:

```
صنف شخص
    # بيانات خاصة
    خاصة نص الاسم_الكامل
    خاصة رقم العمر
    
    # ═══ Getter & Setter للاسم ═══
    عامة دالة احصل_اسم() ترجع نص
        ارجع هذا.الاسم_الكامل
    نهاية
    
    عامة دالة عدل_اسم(نص اسم_جديد) فراغ
        # التحقق من صحة الاسم
        اذا (طول(اسم_جديد) < 2)
            اطبع_سطر("❌ الاسم قصير جداً")
            ارجع
        نهاية
        
        اذا (طول(اسم_جديد) > 100)
            اطبع_سطر("❌ الاسم طويل جداً")
            ارجع
        نهاية
        
        هذا.الاسم_الكامل = اسم_جديد
        اطبع_سطر("✅ تم تعديل الاسم")
    نهاية
    
    # ═══ Getter & Setter للعمر ═══
    عامة دالة احصل_عمر() ترجع رقم
        ارجع هذا.العمر
    نهاية
    
    عامة دالة عدل_عمر(رقم عمر_جديد) فراغ
        # التحقق من صحة العمر
        اذا (عمر_جديد < 0)
            اطبع_سطر("❌ العمر لا يمكن أن يكون سالباً")
            ارجع
        نهاية
        
        اذا (عمر_جديد > 150)
            اطبع_سطر("❌ العمر غير معقول")
            ارجع
        نهاية
        
        هذا.العمر = عمر_جديد
        اطبع_سطر("✅ تم تعديل العمر")
    نهاية
نهاية

# الاستخدام
شخص ش = جديد شخص()

ش.عدل_اسم("أحمد")        # ✅
ش.عدل_اسم("أ")            # ❌ قصير جداً
ش.عدل_عمر(25)            # ✅
ش.عدل_عمر(-5)             # ❌ سالب
```

## 🛡️ الأعضاء المحمية (Protected)

الأعضاء المحمية يمكن للأصناف الفرعية الوصول إليها، لكن ليس من الخارج:

```
# الصنف الأساسي
صنف موظف
    خاصة نص الاسم
    محمي عشري الراتب_الأساسي  # يمكن للأصناف الفرعية الوصول
    
    عامة دالة منشئ(نص اسم، عشري راتب) فراغ
        هذا.الاسم = اسم
        هذا.الراتب_الأساسي = راتب
    نهاية
    
    # دالة محمية - يمكن للفروع استخدامها
    محمي دالة احسب_ضريبة() ترجع عشري
        ارجع هذا.الراتب_الأساسي * 0.1
    نهاية
    
    عامة دالة احصل_اسم() ترجع نص
        ارجع هذا.الاسم
    نهاية
نهاية

# صنف فرعي
صنف مدير يرث موظف
    خاصة عشري مكافأة_إدارية
    
    عامة دالة منشئ(نص اسم، عشري راتب، عشري مكافأة) فراغ
        أساسي.منشئ(اسم، راتب)
        هذا.مكافأة_إدارية = مكافأة
    نهاية
    
    عامة دالة احسب_راتب_صافي() ترجع عشري
        # ✅ يمكن الوصول للراتب_الأساسي - محمي
        # ✅ يمكن استدعاء احسب_ضريبة - محمية
        
        عشري الإجمالي = هذا.الراتب_الأساسي + هذا.مكافأة_إدارية
        عشري الضريبة = هذا.احسب_ضريبة()
        ارجع الإجمالي - الضريبة
    نهاية
نهاية

# الاستخدام
دالة رئيسية() رقم
    مدير م = جديد مدير("أحمد"، 10000.0، 2000.0)
    
    اطبع_سطر("الاسم: " + م.احصل_اسم())
    اطبع_سطر("الراتب الصافي: " + م.احسب_راتب_صافي())
    
    # ❌ لا يمكن الوصول للراتب_الأساسي من الخارج - محمي!
    # اطبع_سطر(م.الراتب_الأساسي)  # خطأ!
    
    ارجع 0
نهاية
```

## 📊 مثال تطبيقي شامل: نظام مكتبة محمي

```
# صنف الكتاب مع تغليف كامل
صنف كتاب
    # ═══ بيانات خاصة ═══
    خاصة نص العنوان
    خاصة نص المؤلف
    خاصة نص ISBN
    خاصة منطقي معار
    خاصة نص المستعير_الحالي
    
    # ═══ المنشئ ═══
    عامة دالة منشئ(نص عنوان، نص مؤلف، نص isbn) فراغ
        هذا.العنوان = عنوان
        هذا.المؤلف = مؤلف
        هذا.ISBN = isbn
        هذا.معار = خطأ
        هذا.المستعير_الحالي = ""
    نهاية
    
    # ═══ Getters العامة ═══
    عامة دالة احصل_عنوان() ترجع نص
        ارجع هذا.العنوان
    نهاية
    
    عامة دالة احصل_مؤلف() ترجع نص
        ارجع هذا.المؤلف
    نهاية
    
    عامة دالة هل_معار() ترجع منطقي
        ارجع هذا.معار
    نهاية
    
    عامة دالة احصل_مستعير() ترجع نص
        اذا (هذا.معار)
            ارجع هذا.المستعير_الحالي
        نهاية
        ارجع "غير معار"
    نهاية
    
    # ═══ دوال الإعارة ═══
    عامة دالة أعر_لـ(نص اسم_المستعير) ترجع منطقي
        اذا (هذا.معار)
            اطبع_سطر("❌ الكتاب معار بالفعل لـ: " + هذا.المستعير_الحالي)
            ارجع خطأ
        نهاية
        
        اذا (طول(اسم_المستعير) == 0)
            اطبع_سطر("❌ اسم المستعير مطلوب")
            ارجع خطأ
        نهاية
        
        هذا.معار = صحيح
        هذا.المستعير_الحالي = اسم_المستعير
        اطبع_سطر("✅ تمت إعارة '" + هذا.العنوان + "' لـ " + اسم_المستعير)
        ارجع صحيح
    نهاية
    
    عامة دالة ارجع_الكتاب() ترجع منطقي
        اذا (!هذا.معار)
            اطبع_سطر("❌ الكتاب غير معار")
            ارجع خطأ
        نهاية
        
        اطبع_سطر("✅ تم إرجاع '" + هذا.العنوان + "' من " + هذا.المستعير_الحالي)
        هذا.معار = خطأ
        هذا.المستعير_الحالي = ""
        ارجع صحيح
    نهاية
    
    # ═══ طباعة المعلومات ═══
    عامة دالة اطبع_معلومات() فراغ
        نص حالة = هذا.معار ? "معار ❌" : "متاح ✅"
        
        اطبع_سطر("┌─────────────────────────────┐")
        اطبع_سطر("│ 📖 " + هذا.العنوان)
        اطبع_سطر("│ ✍️  المؤلف: " + هذا.المؤلف)
        اطبع_سطر("│ 🔖 ISBN: " + هذا.ISBN)
        اطبع_سطر("│ 📊 الحالة: " + حالة)
        
        اذا (هذا.معار)
            اطبع_سطر("│ 👤 المستعير: " + هذا.المستعير_الحالي)
        نهاية
        
        اطبع_سطر("└─────────────────────────────┘")
    نهاية
نهاية

# صنف المكتبة مع تغليف
صنف مكتبة
    خاصة نص الاسم
    خاصة مصفوفة الكتب
    خاصة رقم حد_الإعارة_للشخص
    
    عامة دالة منشئ(نص اسم) فراغ
        هذا.الاسم = اسم
        هذا.الكتب = []
        هذا.حد_الإعارة_للشخص = 3
        اطبع_سطر("🏛️ تم إنشاء مكتبة: " + اسم)
    نهاية
    
    # دالة خاصة للبحث
    خاصة دالة ابحث_عن_كتاب_بالعنوان(نص عنوان) ترجع كتاب
        لكل كتاب في هذا.الكتب
            اذا (كتاب.احصل_عنوان() == عنوان)
                ارجع كتاب
            نهاية
        نهاية
        ارجع عدم
    نهاية
    
    # دالة خاصة لعد الكتب المعارة لشخص
    خاصة دالة عدد_الإعارات(نص اسم) ترجع رقم
        رقم عدد = 0
        لكل كتاب في هذا.الكتب
            اذا (كتاب.هل_معار() و كتاب.احصل_مستعير() == اسم)
                عدد = عدد + 1
            نهاية
        نهاية
        ارجع عدد
    نهاية
    
    عامة دالة أضف_كتاب(كتاب ك) فراغ
        أضف(هذا.الكتب، ك)
        اطبع_سطر("➕ تمت إضافة: " + ك.احصل_عنوان())
    نهاية
    
    عامة دالة أعر_كتاب(نص عنوان_الكتاب، نص اسم_المستعير) ترجع منطقي
        # التحقق من عدد الإعارات
        رقم عدد_الحالي = هذا.عدد_الإعارات(اسم_المستعير)
        اذا (عدد_الحالي >= هذا.حد_الإعارة_للشخص)
            اطبع_سطر("❌ " + اسم_المستعير + " وصل للحد الأقصى من الإعارات")
            ارجع خطأ
        نهاية
        
        كتاب ك = هذا.ابحث_عن_كتاب_بالعنوان(عنوان_الكتاب)
        
        اذا (ك == عدم)
            اطبع_سطر("❌ الكتاب غير موجود: " + عنوان_الكتاب)
            ارجع خطأ
        نهاية
        
        ارجع ك.أعر_لـ(اسم_المستعير)
    نهاية
    
    عامة دالة ارجع_كتاب(نص عنوان_الكتاب) ترجع منطقي
        كتاب ك = هذا.ابحث_عن_كتاب_بالعنوان(عنوان_الكتاب)
        
        اذا (ك == عدم)
            اطبع_سطر("❌ الكتاب غير موجود")
            ارجع خطأ
        نهاية
        
        ارجع ك.ارجع_الكتاب()
    نهاية
    
    عامة دالة اطبع_جميع_الكتب() فراغ
        اطبع_سطر("╔═══════════════════════════════╗")
        اطبع_سطر("  📚 كتب " + هذا.الاسم)
        اطبع_سطر("╚═══════════════════════════════╝")
        اطبع_سطر("")
        
        لكل كتاب في هذا.الكتب
            كتاب.اطبع_معلومات()
            اطبع_سطر("")
        نهاية
    نهاية
نهاية

# ========== البرنامج الرئيسي ==========

    مكتبة مكتبة_الجامعة = جديد مكتبة("مكتبة جامعة الملك سعود")
```
