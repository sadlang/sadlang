# دليل الدوال العادية في لغة ص
## للمبتدئين والمطورين الجدد

## 🎓 مقدمة

الدالة (Function) هي كتلة من الأوامر البرمجية التي تقوم بمهمة محددة، وتستطيع إرجاع قيمة إلى المكان الذي تم استدعاؤها منه. في لغة ص، تعريف الدوال مرن جداً ويدعم عدة أساليب مختلفة لتحديد نوع القيمة المُرجعة.

## 📖 الصيغة الأساسية

### الطريقة الأولى: نوع الإرجاع بعد قائمة المعاملات مباشرة

هذه هي الطريقة الأبسط والأكثر وضوحاً للمبتدئين، حيث تكتب نوع القيمة التي ستُرجعها الدالة مباشرة بعد إغلاق قوس المعاملات:

```
دالة جمع(رقم أ، رقم ب) رقم
    ارجع أ + ب
نهاية
```

في هذا المثال:
- `دالة` هي الكلمة المفتاحية لبدء تعريف الدالة
- `جمع` هو اسم الدالة الذي نختاره
- `(رقم أ، رقم ب)` هي قائمة المعاملات - هنا نستقبل رقمين
- `رقم` بعد القوس المغلق هو **نوع القيمة المُرجعة** - الدالة سترجع رقماً
- `ارجع أ + ب` هو الأمر الذي ينفذ الجمع ويُرجع النتيجة
- `نهاية` تغلق تعريف الدالة

### الطريقة الثانية: باستخدام كلمة "ترجع" الاختيارية

لغة ص توفر كلمة "ترجع" لجعل الكود أكثر وضوحاً وقراءة، خاصة للمطورين الجدد:

```
دالة جمع(رقم أ، رقم ب) ترجع رقم
    ارجع أ + ب
نهاية
```

هذه الطريقة **مطابقة تماماً** للطريقة الأولى! الفرق الوحيد هو إضافة كلمة "ترجع" التي تجعل النية واضحة: "هذه الدالة **ترجع** قيمة من نوع رقم".

### الطريقة الثالثة: نوع الإرجاع قبل اسم الدالة

في هذه الطريقة، نضع نوع الإرجاع مباشرة بعد كلمة "دالة" وقبل اسم الدالة:

```
دالة رقم جمع(رقم أ، رقم ب)
    ارجع أ + ب
نهاية
```

هذه الطريقة شائعة في لغات البرمجة الأخرى مثل C وJava، وهي مدعومة في لغة ص لراحة المطورين القادمين من تلك اللغات.

## 🔍 أمثلة تفصيلية

### مثال 1: دالة بسيطة بدون معاملات

```
# دالة ترجع عدد ثابت
دالة رقم_الحظ() رقم
    ارجع 7
نهاية

# استخدام الدالة
رقم حظي = رقم_الحظ()
اطبع("رقم حظي اليوم: " + حظي)
# النتيجة: رقم حظي اليوم: 7
```

### مثال 2: دالة تُرجع نصاً

```
دالة احصل_على_تحية(نص اسم) ترجع نص
    ارجع "مرحباً " + اسم + "!"
نهاية

# استخدام الدالة
نص رسالة = احصل_على_تحية("أحمد")
اطبع(رسالة)
# النتيجة: مرحباً أحمد!
```

### مثال 3: دالة تُرجع قيمة منطقية

القيم المنطقية (Boolean) تُستخدم للتعبير عن صحيح أو خطأ:

```
دالة هل_رقم_موجب(رقم عدد) منطقي
    اذا (عدد > 0)
        ارجع صحيح
    والا
        ارجع خطأ
    نهاية
نهاية

# استخدام الدالة
منطقي نتيجة = هل_رقم_موجب(10)
اذا (نتيجة)
    اطبع("الرقم موجب")
نهاية
# النتيجة: الرقم موجب
```

### مثال 4: دالة تُرجع عدداً عشرياً

```
دالة احسب_المتوسط(رقم أ، رقم ب) ترجع عشري
    عشري مجموع = أ + ب
    ارجع مجموع / 2.0
نهاية

# استخدام الدالة
عشري متوسط = احسب_المتوسط(10، 20)
اطبع("المتوسط هو: " + متوسط)
# النتيجة: المتوسط هو: 15.0
```

## 📋 أنواع البيانات المدعومة

لغة ص تدعم الأنواع التالية كنوع إرجاع:

1. **رقم** (integer) - أرقام صحيحة: 1, 2, 100, -5
2. **عشري** (double/float) - أرقام عشرية: 3.14, -0.5, 2.71828
3. **نص** (string) - نصوص: "مرحباً", "لغة ص"
4. **منطقي** (boolean) - قيم منطقية: صحيح، خطأ
5. **مصفوفة** (array) - قوائم من القيم: [1, 2, 3]
6. **خريطة** (map) - أزواج مفتاح-قيمة: {"الاسم": "أحمد"}
7. **فراغ** (void) - عدم إرجاع قيمة (للدوال الإجرائية)

## 🎯 الدوال التي لا تُرجع قيمة

بعض الدوال تقوم بعمل معين دون إرجاع قيمة، مثل طباعة رسالة أو تعديل متغير عام. في هذه الحالة، نستخدم نوع "فراغ" أو نحذف نوع الإرجاع تماماً:

```
# دالة لا تُرجع قيمة - الطريقة الأولى
دالة اطبع_رسالة_ترحيب(نص اسم) فراغ
    اطبع("أهلاً وسهلاً " + اسم)
نهاية

# دالة لا تُرجع قيمة - الطريقة الثانية (بحذف النوع)
دالة اطبع_رسالة_وداع(نص اسم)
    اطبع("إلى اللقاء " + اسم)
نهاية

# استخدام الدوال
اطبع_رسالة_ترحيب("فاطمة")
اطبع_رسالة_وداع("علي")
```

## 💡 نصائح للمبتدئين

### نصيحة 1: اختر أسلوباً والتزم به
ليس هناك طريقة "صحيحة" أو "خاطئة" - كل الطرق مدعومة. اختر الأسلوب الأوضح لك:
- إذا كنت مبتدئاً تماماً، استخدم كلمة "ترجع" لأنها أكثر وضوحاً
- إذا كنت معتاداً على لغات مثل JavaScript، قد تفضل الطريقة الأولى
- إذا كنت قادماً من C++ أو Java، قد تفضل الطريقة الثالثة

### نصيحة 2: اسم الدالة يجب أن يعبر عن وظيفتها
```
# ❌ سيء - اسم غير واضح
دالة د1(رقم س) رقم
    ارجع س * 2
نهاية

# ✅ جيد - اسم واضح
دالة ضاعف_الرقم(رقم عدد) رقم
    ارجع عدد * 2
نهاية
```

### نصيحة 3: تأكد من إرجاع القيمة دائماً
إذا حددت نوع إرجاع للدالة، يجب أن تُرجع قيمة من هذا النوع في **جميع** الحالات الممكنة:

```
# ❌ خطأ - لا تُرجع قيمة في حالة العدد السالب
دالة جذر_تربيعي(رقم عدد) عشري
    اذا (عدد >= 0)
        ارجع جذر(عدد)
    نهاية
    # هنا مشكلة - ماذا لو كان العدد سالباً؟
نهاية

# ✅ صحيح - نُرجع قيمة في جميع الحالات
دالة جذر_تربيعي(رقم عدد) عشري
    اذا (عدد >= 0)
        ارجع جذر(عدد)
    والا
        اطبع("خطأ: لا يمكن حساب جذر عدد سالب")
        ارجع 0.0
    نهاية
نهاية
```

## 🔄 مثال تطبيقي شامل

لنبني برنامجاً صغيراً يستخدم عدة دوال بأنواع إرجاع مختلفة:

```
# برنامج حاسبة بسيطة

# دالة للجمع
دالة جمع(رقم أ، رقم ب) ترجع رقم
    ارجع أ + ب
نهاية

# دالة للطرح
دالة طرح(رقم أ، رقم ب) ترجع رقم
    ارجع أ - ب
نهاية

# دالة للضرب
دالة ضرب(رقم أ، رقم ب) رقم
    ارجع أ * ب
نهاية

# دالة للقسمة (تُرجع عدداً عشرياً)
دالة قسمة(رقم أ، رقم ب) ترجع عشري
    اذا (ب == 0)
        اطبع("خطأ: لا يمكن القسمة على صفر!")
        ارجع 0.0
    نهاية
    ارجع أ / ب
نهاية

# دالة لطباعة النتيجة (لا تُرجع قيمة)
دالة اطبع_نتيجة(نص عملية، عشري نتيجة)
    اطبع("نتيجة " + عملية + " = " + نتيجة)
نهاية

# البرنامج الرئيسي
دالة رئيسية() رقم
    رقم س = 10
    رقم ص = 5
    
    اطبع("=== حاسبة بسيطة ===")
    اطبع("الرقم الأول: " + س)
    اطبع("الرقم الثاني: " + ص)
    اطبع("")
    
    # استخدام الدوال
    رقم مجموع = جمع(س، ص)
    اطبع_نتيجة("الجمع", مجموع)
    
    رقم فرق = طرح(س، ص)
    اطبع_نتيجة("الطرح", فرق)
    
    رقم ضرب_نتيجة = ضرب(س، ص)
    اطبع_نتيجة("الضرب", ضرب_نتيجة)
    
    عشري قسمة_نتيجة = قسمة(س، ص)
    اطبع_نتيجة("القسمة", قسمة_نتيجة)
    
    ارجع 0
نهاية
```

**النتيجة المتوقعة:**
```
=== حاسبة بسيطة ===
الرقم الأول: 10
الرقم الثاني: 5

نتيجة الجمع = 15
نتيجة الطرح = 5
نتيجة الضرب = 50
نتيجة القسمة = 2.0
```
