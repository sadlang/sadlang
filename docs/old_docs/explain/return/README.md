## 🎯 نظرة سريعة

لغة ص تدعم مرونة كبيرة في تحديد نوع الإرجاع للدوال والقوالب:

### الطريقة الأولى: نوع الإرجاع مباشرة
```
دالة جمع(رقم أ، رقم ب) رقم
    ارجع أ + ب
نهاية
```

### الطريقة الثانية: باستخدام كلمة "ترجع"
```
دالة جمع(رقم أ، رقم ب) ترجع رقم
    ارجع أ + ب
نهاية
```

### الطريقة الثالثة: نوع الإرجاع قبل اسم الدالة
```
دالة رقم جمع(رقم أ، رقم ب)
    ارجع أ + ب
نهاية
```

كل هذه الطرق صحيحة ومدعومة! اختر الأسلوب الذي يناسبك.
