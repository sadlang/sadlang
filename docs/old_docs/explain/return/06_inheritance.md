# الوراثة في لغة ص
## البرمجة الكائنية - الجزء الثاني

## 🎓 مقدمة: ما هي الوراثة؟

**الوراثة (Inheritance)** هي آلية تسمح لصنف جديد (**الصنف الفرعي** أو **الوريث**) بأن **يرث** خصائص ودوال من صنف موجود (**الصنف الأساسي** أو **الأب**).

### لماذا الوراثة؟

تخيل أنك تبني نظاماً لإدارة الموظفين. لديك موظفون عاديون، ومدراء، ومهندسون. جميعهم **موظفون** ولديهم خصائص مشتركة (الاسم، الراتب)، لكن كل نوع له خصائص ودوال إضافية.

**بدون الوراثة:**
```
صنف موظف_عادي
    نص الاسم
    رقم الراتب
    # ... دوال مشتركة
نهاية

صنف مدير
    نص الاسم        # تكرار!
    رقم الراتب      # تكرار!
    رقم عدد_المرؤوسين
    # ... نفس الدوال المشتركة مكررة!
نهاية

صنف مهندس
    نص الاسم        # تكرار!
    رقم الراتب      # تكرار!
    نص التخصص
    # ... نفس الدوال المشتركة مكررة!
نهاية
```

**مع الوراثة:**
```
# الصنف الأساسي
صنف موظف
    نص الاسم
    رقم الراتب
    # ... دوال مشتركة مرة واحدة فقط
نهاية

# الأصناف الفرعية ترث من الأساسي
صنف مدير يرث موظف
    رقم عدد_المرؤوسين  # خاصية إضافية فقط
نهاية

صنف مهندس يرث موظف
    نص التخصص  # خاصية إضافية فقط
نهاية
```

## 📖 مثال بسيط: الحيوانات

```
# الصنف الأساسي - حيوان
صنف حيوان
    نص الاسم
    رقم العمر
    
    دالة منشئ(نص اسم، رقم عمر) فراغ
        هذا.الاسم = اسم
        هذا.العمر = عمر
    نهاية
    
    دالة يأكل() فراغ
        اطبع_سطر(هذا.الاسم + " يأكل")
    نهاية
    
    دالة ينام() فراغ
        اطبع_سطر(هذا.الاسم + " ينام")
    نهاية
    
    دالة معلومات() فراغ
        اطبع_سطر("الاسم: " + هذا.الاسم)
        اطبع_سطر("العمر: " + هذا.العمر)
    نهاية
نهاية

# الصنف الفرعي - كلب
صنف كلب يرث حيوان
    نص السلالة
    
    دالة منشئ(نص اسم، رقم عمر، نص سلالة) فراغ
        # استدعاء منشئ الأب
        أساسي.منشئ(اسم، عمر)
        هذا.السلالة = سلالة
    نهاية
    
    # دالة جديدة خاصة بالكلب
    دالة ينبح() فراغ
        اطبع_سطر(هذا.الاسم + " ينبح: هاو هاو!")
    نهاية
    
    # تجاوز دالة من الأب (Override)
    دالة معلومات() فراغ
        اطبع_سطر("🐕 كلب")
        أساسي.معلومات()  # استدعاء دالة الأب
        اطبع_سطر("السلالة: " + هذا.السلالة)
    نهاية
نهاية

# الصنف الفرعي - قطة
صنف قطة يرث حيوان
    نص اللون
    
    دالة منشئ(نص اسم، رقم عمر، نص لون) فراغ
        أساسي.منشئ(اسم، عمر)
        هذا.اللون = لون
    نهاية
    
    دالة تموء() فراغ
        اطبع_سطر(هذا.الاسم + " تموء: مياو مياو!")
    نهاية
    
    دالة معلومات() فراغ
        اطبع_سطر("🐱 قطة")
        أساسي.معلومات()
        اطبع_سطر("اللون: " + هذا.اللون)
    نهاية
نهاية

# ========== الاستخدام ==========

دالة رئيسية() رقم
    # إنشاء كلب
    كلب ريكس = جديد كلب("ريكس"، 3، "جيرمن شيبرد")
    ريكس.معلومات()
    ريكس.يأكل()      # موروثة من حيوان
    ريكس.ينبح()      # خاصة بالكلب
    
    اطبع_سطر("")
    اطبع_سطر("─────────────────")
    اطبع_سطر("")
    
    # إنشاء قطة
    قطة مشمش = جديد قطة("مشمش"، 2، "برتقالي")
    مشمش.معلومات()
    مشمش.ينام()      # موروثة من حيوان
    مشمش.تموء()      # خاصة بالقطة
    
    ارجع 0
نهاية
```

## 🔑 كلمة "أساسي" (super/base)

`أساسي` هي كلمة مفتاحية تشير إلى **الصنف الأساسي** (الأب). تُستخدم لـ:

### 1. استدعاء منشئ الأب

```
صنف فرعي يرث أساسي
    دالة منشئ(معاملات) فراغ
        أساسي.منشئ(معاملات_الأب)
        # تهيئة خصائص الفرع
    نهاية
نهاية
```

### 2. استدعاء دالة من الأب

```
صنف فرعي يرث أساسي
    دالة دالة_ما() فراغ
        أساسي.دالة_ما()  # استدعاء نسخة الأب
        # كود إضافي
    نهاية
نهاية
```

## 🔄 تجاوز الدوال (Method Overriding)

**تجاوز الدوال** يعني إعادة تعريف دالة موجودة في الأب، لتعطي سلوكاً مختلفاً في الفرع.

### مثال: أشكال هندسية

```
# الصنف الأساسي
صنف شكل
    نص الاسم
    
    دالة منشئ(نص اسم) فراغ
        هذا.الاسم = اسم
    نهاية
    
    # دالة المساحة - ستُجاوَز في الفروع
    دالة مساحة() ترجع عشري
        اطبع_سطر("⚠️ لا يمكن حساب مساحة شكل عام")
        ارجع 0.0
    نهاية
    
    دالة محيط() ترجع عشري
        اطبع_سطر("⚠️ لا يمكن حساب محيط شكل عام")
        ارجع 0.0
    نهاية
نهاية

# مربع
صنف مربع يرث شكل
    عشري الطول
    
    دالة منشئ(عشري طول) فراغ
        أساسي.منشئ("مربع")
        هذا.الطول = طول
    نهاية
    
    # تجاوز دالة المساحة
    دالة مساحة() ترجع عشري
        ارجع هذا.الطول * هذا.الطول
    نهاية
    
    دالة محيط() ترجع عشري
        ارجع 4.0 * هذا.الطول
    نهاية
نهاية

# مستطيل
صنف مستطيل يرث شكل
    عشري الطول
    عشري العرض
    
    دالة منشئ(عشري طول، عشري عرض) فراغ
        أساسي.منشئ("مستطيل")
        هذا.الطول = طول
        هذا.العرض = عرض
    نهاية
    
    دالة مساحة() ترجع عشري
        ارجع هذا.الطول * هذا.العرض
    نهاية
    
    دالة محيط() ترجع عشري
        ارجع 2.0 * (هذا.الطول + هذا.العرض)
    نهاية
نهاية

# دائرة
صنف دائرة يرث شكل
    عشري نصف_القطر
    ثابت عشري باي = 3.14159
    
    دالة منشئ(عشري نصف_قطر) فراغ
        أساسي.منشئ("دائرة")
        هذا.نصف_القطر = نصف_قطر
    نهاية
    
    دالة مساحة() ترجع عشري
        ارجع باي * هذا.نصف_القطر * هذا.نصف_القطر
    نهاية
    
    دالة محيط() ترجع عشري
        ارجع 2.0 * باي * هذا.نصف_القطر
    نهاية
نهاية

# ========== دالة عامة تعمل مع أي شكل ==========

دالة اطبع_معلومات_شكل(شكل ش) فراغ
    اطبع_سطر("╔════════════════════════╗")
    اطبع_سطر("  الشكل: " + ش.الاسم)
    اطبع_سطر("  المساحة: " + ش.مساحة())
    اطبع_سطر("  المحيط: " + ش.محيط())
    اطبع_سطر("╚════════════════════════╝")
نهاية

# ========== البرنامج الرئيسي ==========

دالة رئيسية() رقم
    مربع م = جديد مربع(5.0)
    مستطيل مس = جديد مستطيل(4.0، 6.0)
    دائرة د = جديد دائرة(3.0)
    
    اطبع_معلومات_شكل(م)
    اطبع_سطر("")
    اطبع_معلومات_شكل(مس)
    اطبع_سطر("")
    اطبع_معلومات_شكل(د)
    
    ارجع 0
نهاية
```

## 🎯 تعدد الأشكال (Polymorphism)

**تعدد الأشكال** يعني أن متغيراً من نوع الصنف الأساسي يمكن أن **يشير** إلى كائن من الصنف الفرعي، وعند استدعاء دالة، تُستدعى النسخة الصحيحة حسب **النوع الفعلي** للكائن.

```
# مصفوفة من الأشكال المختلفة
مصفوفة أشكال = [
    جديد مربع(4.0),
    جديد دائرة(5.0),
    جديد مستطيل(3.0، 7.0)
]

# حلقة تطبع معلومات كل شكل
لكل شكل في أشكال
    اطبع_معلومات_شكل(شكل)  # تُستدعى الدالة الصحيحة لكل نوع!
    اطبع_سطر("")
نهاية
```

## 📊 مثال تطبيقي شامل: نظام البنك

```
# الصنف الأساسي - حساب بنكي
صنف حساب
    رقم رقم_الحساب
    نص اسم_العميل
    عشري الرصيد
    
    دالة منشئ(رقم رقم، نص اسم، عشري رصيد_أولي) فراغ
        هذا.رقم_الحساب = رقم
        هذا.اسم_العميل = اسم
        هذا.الرصيد = رصيد_أولي
        اطبع_سطر("✅ تم فتح حساب برقم " + رقم)
    نهاية
    
    دالة إيداع(عشري مبلغ) فراغ
        اذا (مبلغ <= 0)
            اطبع_سطر("❌ المبلغ يجب أن يكون موجباً")
            ارجع
        نهاية
        
        هذا.الرصيد = هذا.الرصيد + مبلغ
        اطبع_سطر("💰 تم إيداع " + مبلغ + " ريال")
        اطبع_سطر("   الرصيد الحالي: " + هذا.الرصيد)
    نهاية
    
    دالة سحب(عشري مبلغ) ترجع منطقي
        اذا (مبلغ <= 0)
            اطبع_سطر("❌ المبلغ يجب أن يكون موجباً")
            ارجع خطأ
        نهاية
        
        اذا (مبلغ > هذا.الرصيد)
            اطبع_سطر("❌ رصيد غير كافٍ")
            ارجع خطأ
        نهاية
        
        هذا.الرصيد = هذا.الرصيد - مبلغ
        اطبع_سطر("💸 تم سحب " + مبلغ + " ريال")
        اطبع_سطر("   الرصيد الحالي: " + هذا.الرصيد)
        ارجع صحيح
    نهاية
    
    دالة معلومات() فراغ
        اطبع_سطر("┌─────────────────────────┐")
        اطبع_سطر("│ حساب بنكي              │")
        اطبع_سطر("├─────────────────────────┤")
        اطبع_سطر("│ الرقم: " + هذا.رقم_الحساب)
        اطبع_سطر("│ العميل: " + هذا.اسم_العميل)
        اطبع_سطر("│ الرصيد: " + هذا.الرصيد + " ريال")
        اطبع_سطر("└─────────────────────────┘")
    نهاية
نهاية

# حساب توفير - لا يمكن السحب منه إلا بشروط
صنف حساب_توفير يرث حساب
    رقم مدة_الإيداع_بالأشهر
    عشري معدل_الفائدة
    
    دالة منشئ(رقم رقم، نص اسم، عشري رصيد، رقم مدة) فراغ
        أساسي.منشئ(رقم، اسم، رصيد)
        هذا.مدة_الإيداع_بالأشهر = مدة
        هذا.معدل_الفائدة = 0.05  # 5% سنوياً
    نهاية
    
    # تجاوز دالة السحب - قيود أكثر صرامة
    دالة سحب(عشري مبلغ) ترجع منطقي
        اطبع_سطر("⚠️ حساب توفير: يجب الانتظار " + هذا.مدة_الإيداع_بالأشهر + " أشهر")
        # في التطبيق الحقيقي، نتحقق من التاريخ
        ارجع خطأ
    نهاية
    
    # دالة جديدة لحساب الفائدة
    دالة احسب_فائدة() ترجع عشري
        عشري سنوات = هذا.مدة_الإيداع_بالأشهر / 12.0
        عشري فائدة = هذا.الرصيد * هذا.معدل_الفائدة * سنوات
        ارجع فائدة
    نهاية
    
    دالة معلومات() فراغ
        اطبع_سطر("┌─────────────────────────┐")
        اطبع_سطر("│ حساب توفير 💎          │")
        اطبع_سطر("├─────────────────────────┤")
        اطبع_سطر("│ الرقم: " + هذا.رقم_الحساب)
        اطبع_سطر("│ العميل: " + هذا.اسم_العميل)
        اطبع_سطر("│ الرصيد: " + هذا.الرصيد + " ريال")
        اطبع_سطر("│ المدة: " + هذا.مدة_الإيداع_بالأشهر + " أشهر")
        اطبع_سطر("│ الفائدة المتوقعة: " + هذا.احسب_فائدة())
        اطبع_سطر("└─────────────────────────┘")
    نهاية
نهاية

# حساب جاري - يسمح بسحب على المكشوف
صنف حساب_جاري يرث حساب
    عشري حد_السحب_على_المكشوف
    
    دالة منشئ(رقم رقم، نص اسم، عشري رصيد، عشري حد) فراغ
        أساسي.منشئ(رقم، اسم، رصيد)
        هذا.حد_السحب_على_المكشوف = حد
    نهاية
    
    # تجاوز دالة السحب - يسمح بالسحب على المكشوف
    دالة سحب(عشري مبلغ) ترجع منطقي
        اذا (مبلغ <= 0)
            اطبع_سطر("❌ المبلغ يجب أن يكون موجباً")
            ارجع خطأ
        نهاية
        
        عشري الرصيد_بعد_السحب = هذا.الرصيد - مبلغ
        
        اذا (الرصيد_بعد_السحب < -هذا.حد_السحب_على_المكشوف)
            اطبع_سطر("❌ تجاوز حد السحب على المكشوف")
            اطبع_سطر("   الحد المتاح: " + هذا.حد_السحب_على_المكشوف)
            ارجع خطأ
        نهاية
        
        هذا.الرصيد = الرصيد_بعد_السحب
        اطبع_سطر("💸 تم سحب " + مبلغ + " ريال")
        
        اذا (هذا.الرصيد < 0)
            اطبع_سطر("⚠️ الرصيد سالب! " + هذا.الرصيد)
        نهاية_اذا_والا
            اطبع_سطر("   الرصيد الحالي: " + هذا.الرصيد)
        نهاية
        
        ارجع صحيح
    نهاية
    
    دالة معلومات() فراغ
        اطبع_سطر("┌─────────────────────────┐")
        اطبع_سطر("│ حساب جاري 💳           │")
        اطبع_سطر("├─────────────────────────┤")
        اطبع_سطر("│ الرقم: " + هذا.رقم_الحساب)
        اطبع_سطر("│ العميل: " + هذا.اسم_العميل)
        اطبع_سطر("│ الرصيد: " + هذا.الرصيد + " ريال")
        اطبع_سطر("│ حد السحب: " + هذا.حد_السحب_على_المكشوف)
        اطبع_سطر("└─────────────────────────┘")
    نهاية
نهاية

# ========== البرنامج الرئيسي ==========

دالة رئيسية() رقم
    اطبع_سطر("═══════════════════════════════")
    اطبع_سطر("     🏦 نظام البنك         ")
    اطبع_سطر("═══════════════════════════════")
    اطبع_سطر("")
    
    # حساب عادي
    حساب ح1 = جديد حساب(1001، "أحمد محمد"، 5000.0)
    اطبع_سطر("")
    ح1.معلومات()
    اطبع_سطر("")
    ح1.إيداع(1000.0)
    ح1.سحب(2000.0)
    
    اطبع_سطر("")
    اطبع_سطر("═══════════════════════════════")
    اطبع_سطر("")
    
    # حساب توفير
    حساب_توفير ح2 = جديد حساب_توفير(1002، "فاطمة علي"، 10000.0، 12)
    اطبع_سطر("")
    ح2.معلومات()
    اطبع_سطر("")
    ح2.سحب(1000.0)  # سيفشل
    
    اطبع_سطر("")
    اطبع_سطر("═══════════════════════════════")
    اطبع_سطر("")
    
    # حساب جاري
    حساب_جاري ح3 = جديد حساب_جاري(1003، "محمود سعيد"، 3000.0، 2000.0)
    اطبع_سطر("")
    ح3.معلومات()
    اطبع_سطر("")
    ح3.سحب(4000.0)  # سحب على المكشوف
    ح3.معلومات()
    
    ارجع 0
نهاية
```

## 📚 الخلاصة

الوراثة توفر:
- ♻️ **إعادة استخدام الكود** - لا تكرار
- 🎯 **التخصيص** - كل فرع له ميزاته الخاصة
- 🔄 **تعدد الأشكال** - دالة واحدة، سلوكيات متعددة
- 🏗️ **التسلسل الهرمي** - تنظيم الأصناف منطقياً
