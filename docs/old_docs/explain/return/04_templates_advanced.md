# أمثلة متقدمة للقوالب
## للمطورين المتوسطين والمحترفين

## 🎯 مقدمة

بعد أن تعلمت أساسيات القوالب، حان الوقت لاستكشاف حالات استخدام أكثر تقدماً وواقعية. في هذا الدليل، سنبني أمثلة عملية تُستخدم في المشاريع الحقيقية.

## 📊 مثال 1: نظام ذاكرة التخزين المؤقت (Cache)

نظام Cache عام يمكن استخدامه لتخزين أي نوع من البيانات:

```
# نظام Cache بسيط يخزن أزواج مفتاح-قيمة

قالب<نوع مفتاح، نوع قيمة> صنف ذاكرة_مؤقتة
    خاصة خريطة التخزين
    خاصة رقم الحد_الأقصى
    
    # المنشئ
    دالة منشئ(رقم حد_أقصى) فراغ
        هذا.التخزين = {}
        هذا.الحد_الأقصى = حد_أقصى
    نهاية
    
    # دالة للإضافة
    دالة أضف(مفتاح م، قيمة ق) فراغ
        اذا (طول(هذا.التخزين) >= هذا.الحد_الأقصى)
            # احذف أقدم عنصر
            هذا.احذف_الأقدم()
        نهاية
        هذا.التخزين[م] = ق
    نهاية
    
    # دالة للحصول على قيمة
    دالة احصل(مفتاح م) ترجع قيمة
        اذا (م في هذا.التخزين)
            ارجع هذا.التخزين[م]
        نهاية
        ارجع عدم
    نهاية
    
    # دالة للتحقق من وجود مفتاح
    دالة يوجد(مفتاح م) ترجع منطقي
        ارجع م في هذا.التخزين
    نهاية
    
    # دالة خاصة لحذف أقدم عنصر
    خاصة دالة احذف_الأقدم() فراغ
        # حذف أول مفتاح
        مصفوفة مفاتيح = مفاتيح(هذا.التخزين)
        اذا (طول(مفاتيح) > 0)
            احذف هذا.التخزين[مفاتيح[0]]
        نهاية
    نهاية
نهاية

# ========== الاستخدام ==========

دالة رئيسية() رقم
    # Cache لتخزين أسماء بأرقام الهويات
    ذاكرة_مؤقتة<رقم، نص> أسماء_الموظفين = ذاكرة_مؤقتة<رقم، نص>(100)
    
    أسماء_الموظفين.أضف(1001، "أحمد محمد")
    أسماء_الموظفين.أضف(1002، "فاطمة علي")
    
    نص اسم = أسماء_الموظفين.احصل(1001)
    اطبع("الموظف 1001: " + اسم)
    
    # Cache لتخزين نتائج العمليات الحسابية
    ذاكرة_مؤقتة<نص، رقم> نتائج_حسابية = ذاكرة_مؤقتة<نص، رقم>(50)
    
    نتائج_حسابية.أضف("2+3"، 5)
    نتائج_حسابية.أضف("10*5"، 50)
    
    رقم نتيجة = نتائج_حسابية.احصل("2+3")
    اطبع("نتيجة 2+3: " + نتيجة)
    
    ارجع 0
نهاية
```

## 🔍 مثال 2: نظام التصفية والتحويل (Filter & Map)

دوال عالية المستوى (Higher-Order Functions) للعمل مع المصفوفات:

```
# ========== دوال التصفية والتحويل ==========

# دالة قالب لتصفية المصفوفة
قالب<نوع ت> دالة صفِّي(مصفوفة قائمة، دالة شرط) ترجع مصفوفة
    مصفوفة نتيجة = []
    لكل عنصر في قائمة
        اذا (شرط(عنصر))
            أضف(نتيجة، عنصر)
        نهاية
    نهاية
    ارجع نتيجة
نهاية

# دالة قالب لتحويل عناصر المصفوفة
قالب<نوع مصدر، نوع هدف> دالة حَوِّل(مصفوفة قائمة، دالة محوِّل) ترجع مصفوفة
    مصفوفة نتيجة = []
    لكل عنصر في قائمة
        أضف(نتيجة، محوِّل(عنصر))
    نهاية
    ارجع نتيجة
نهاية

# دالة قالب للتجميع (Reduce)
قالب<نوع ت> دالة اجمع(مصفوفة قائمة، دالة مجمِّع، ت قيمة_أولية) ترجع ت
    ت نتيجة = قيمة_أولية
    لكل عنصر في قائمة
        نتيجة = مجمِّع(نتيجة، عنصر)
    نهاية
    ارجع نتيجة
نهاية

# ========== دوال مساعدة للاختبار ==========

دالة هل_زوجي(رقم ع) ترجع منطقي
    ارجع ع % 2 == 0
نهاية

دالة هل_موجب(رقم ع) ترجع منطقي
    ارجع ع > 0
نهاية

دالة مربع(رقم ع) ترجع رقم
    ارجع ع * ع
نهاية

دالة جمع_عددين(رقم أ، رقم ب) ترجع رقم
    ارجع أ + ب
نهاية

# ========== الاستخدام ==========

دالة رئيسية() رقم
    مصفوفة أرقام = [1، 2، 3، 4، 5، -1، -2، 6، 7، 8]
    
    اطبع("المصفوفة الأصلية: " + أرقام)
    اطبع("")
    
    # تصفية: احصل على الأرقام الزوجية فقط
    مصفوفة أرقام_زوجية = صفِّي<رقم>(أرقام، هل_زوجي)
    اطبع("الأرقام الزوجية: " + أرقام_زوجية)
    
    # تصفية: احصل على الأرقام الموجبة فقط
    مصفوفة أرقام_موجبة = صفِّي<رقم>(أرقام، هل_موجب)
    اطبع("الأرقام الموجبة: " + أرقام_موجبة)
    
    # تحويل: احصل على مربعات الأرقام
    مصفوفة مربعات = حَوِّل<رقم، رقم>(أرقام_موجبة، مربع)
    اطبع("مربعات الأرقام الموجبة: " + مربعات)
    
    # تجميع: احصل على مجموع جميع الأرقام
    رقم المجموع = اجمع<رقم>(أرقام_موجبة، جمع_عددين، 0)
    اطبع("مجموع الأرقام الموجبة: " + المجموع)
    
    ارجع 0
نهاية
```

## 📦 مثال 3: حاوية ذكية (Smart Container)

حاوية تحتفظ بقيمة واحدة مع معلومات إضافية:

```
# حاوية ذكية تخزن قيمة مع وقت الإنشاء والتعديل

قالب<نوع ت> صنف حاوية_ذكية
    خاصة ت القيمة
    خاصة رقم وقت_الإنشاء
    خاصة رقم وقت_آخر_تعديل
    خاصة رقم عدد_التعديلات
    
    # المنشئ
    دالة منشئ(ت قيمة_أولية) فراغ
        هذا.القيمة = قيمة_أولية
        هذا.وقت_الإنشاء = الوقت_الحالي()
        هذا.وقت_آخر_تعديل = هذا.وقت_الإنشاء
        هذا.عدد_التعديلات = 0
    نهاية
    
    # احصل على القيمة
    دالة احصل() ترجع ت
        ارجع هذا.القيمة
    نهاية
    
    # عدّل القيمة
    دالة عدّل(ت قيمة_جديدة) فراغ
        هذا.القيمة = قيمة_جديدة
        هذا.وقت_آخر_تعديل = الوقت_الحالي()
        هذا.عدد_التعديلات = هذا.عدد_التعديلات + 1
    نهاية
    
    # احصل على معلومات
    دالة معلومات() ترجع خريطة
        خريطة بيانات = {
            "القيمة": هذا.القيمة،
            "وقت_الإنشاء": هذا.وقت_الإنشاء،
            "وقت_آخر_تعديل": هذا.وقت_آخر_تعديل،
            "عدد_التعديلات": هذا.عدد_التعديلات
        }
        ارجع بيانات
    نهاية
    
    # هل تم التعديل؟
    دالة هل_عُدِّل() ترجع منطقي
        ارجع هذا.عدد_التعديلات > 0
    نهاية
نهاية

# ========== الاستخدام ==========

دالة رئيسية() رقم
    # حاوية لاسم
    حاوية_ذكية<نص> اسم = حاوية_ذكية<نص>("أحمد")
    
    اطبع("الاسم الأولي: " + اسم.احصل())
    اطبع("هل عُدّل؟ " + اسم.هل_عُدِّل())
    
    # تعديل الاسم
    اسم.عدّل("محمد")
    اطبع("الاسم بعد التعديل: " + اسم.احصل())
    اطبع("هل عُدّل؟ " + اسم.هل_عُدِّل())
    
    # طباعة المعلومات
    خريطة معلومات = اسم.معلومات()
    اطبع("المعلومات: " + معلومات)
    
    # حاوية لرقم
    حاوية_ذكية<رقم> عمر = حاوية_ذكية<رقم>(25)
    
    عمر.عدّل(26)
    عمر.عدّل(27)
    
    اطبع("العمر: " + عمر.احصل())
    خريطة معلومات_عمر = عمر.معلومات()
    اطبع("عدد التعديلات: " + معلومات_عمر["عدد_التعديلات"])
    
    ارجع 0
نهاية
```

## 🎲 مثال 4: مولد أرقام عشوائية بنطاق محدد

قالب يولد أرقاماً عشوائية ضمن نطاق معين:

```
# مولد أرقام عشوائية عام

قالب<نوع ت> صنف مولد_عشوائي
    خاصة ت القيمة_الدنيا
    خاصة ت القيمة_العليا
    
    # المنشئ
    دالة منشئ(ت دنيا، ت عليا) فراغ
        هذا.القيمة_الدنيا = دنيا
        هذا.القيمة_العليا = عليا
    نهاية
    
    # ولّد قيمة عشوائية
    دالة ولّد() ترجع ت
        # منطق التوليد (مبسط)
        عشري نسبة = عشوائي()  # رقم بين 0 و 1
        ت نطاق = هذا.القيمة_العليا - هذا.القيمة_الدنيا
        ت نتيجة = هذا.القيمة_الدنيا + (نطاق * نسبة)
        ارجع نتيجة
    نهاية
    
    # ولّد مصفوفة من القيم
    دالة ولّد_مصفوفة(رقم العدد) ترجع مصفوفة
        مصفوفة نتيجة = []
        لكل ع في نطاق(العدد)
            أضف(نتيجة، هذا.ولّد())
        نهاية
        ارجع نتيجة
    نهاية
نهاية

# ========== الاستخدام ==========

دالة رئيسية() رقم
    # مولد أرقام صحيحة بين 1 و 100
    مولد_عشوائي<رقم> مولد_أرقام = مولد_عشوائي<رقم>(1، 100)
    
    رقم رقم_عشوائي = مولد_أرقام.ولّد()
    اطبع("رقم عشوائي: " + رقم_عشوائي)
    
    مصفوفة أرقام = مولد_أرقام.ولّد_مصفوفة(10)
    اطبع("10 أرقام عشوائية: " + أرقام)
    
    # مولد أرقام عشرية بين 0 و 1
    مولد_عشوائي<عشري> مولد_نسب = مولد_عشوائي<عشري>(0.0، 1.0)
    
    عشري نسبة = مولد_نسب.ولّد()
    اطبع("نسبة عشوائية: " + نسبة)
    
    ارجع 0
نهاية
```

## 🔗 مثال 5: سلسلة معالجات (Processing Chain)

نظام لتطبيق سلسلة من المعالجات على بيانات:

```
# نظام سلسلة المعالجات

قالب<نوع ت> صنف سلسلة_معالجات
    خاصة مصفوفة المعالجات
    
    # المنشئ
    دالة منشئ() فراغ
        هذا.المعالجات = []
    نهاية
    
    # أضف معالج
    دالة أضف_معالج(دالة معالج) ترجع سلسلة_معالجات<ت>
        أضف(هذا.المعالجات، معالج)
        ارجع هذا  # للسماح بالتسلسل
    نهاية
    
    # طبّق جميع المعالجات
    دالة طبّق(ت بيانات) ترجع ت
        ت نتيجة = بيانات
        لكل معالج في هذا.المعالجات
            نتيجة = معالج(نتيجة)
        نهاية
        ارجع نتيجة
    نهاية
    
    # طبّق على مصفوفة
    دالة طبّق_على_مصفوفة(مصفوفة بيانات) ترجع مصفوفة
        مصفوفة نتيجة = []
        لكل عنصر في بيانات
            أضف(نتيجة، هذا.طبّق(عنصر))
        نهاية
        ارجع نتيجة
    نهاية
نهاية

# ========== معالجات للأرقام ==========

دالة ضاعف(رقم ع) ترجع رقم
    ارجع ع * 2
نهاية

دالة أضف_عشرة(رقم ع) ترجع رقم
    ارجع ع + 10
نهاية

دالة مطلق(رقم ع) ترجع رقم
    اذا (ع < 0)
        ارجع -ع
    نهاية
    ارجع ع
نهاية

# ========== معالجات للنصوص ==========

دالة حروف_كبيرة(نص س) ترجع نص
    ارجع كبّر(س)
نهاية

دالة أضف_تعجب(نص س) ترجع نص
    ارجع س + "!"
نهاية

# ========== الاستخدام ==========

دالة رئيسية() رقم
    # سلسلة معالجات للأرقام
    سلسلة_معالجات<رقم> معالجات_أرقام = سلسلة_معالجات<رقم>()
    معالجات_أرقام.أضف_معالج(مطلق)
                   .أضف_معالج(ضاعف)
                   .أضف_معالج(أضف_عشرة)
    
    رقم نتيجة = معالجات_أرقام.طبّق(-5)
    اطبع("معالجة -5: " + نتيجة)  # النتيجة: 20
    # (-5 → 5 → 10 → 20)
    
    مصفوفة أرقام = [-3، 7، -2، 4]
    مصفوفة نتائج = معالجات_أرقام.طبّق_على_مصفوفة(أرقام)
    اطبع("معالجة المصفوفة: " + نتائج)
    
    # سلسلة معالجات للنصوص
    سلسلة_معالجات<نص> معالجات_نصوص = سلسلة_معالجات<نص>()
    معالجات_نصوص.أضف_معالج(حروف_كبيرة)
                  .أضف_معالج(أضف_تعجب)
    
    نص رسالة = معالجات_نصوص.طبّق("مرحبا")
    اطبع("معالجة النص: " + رسالة)  # مرحبا!
    
    ارجع 0
نهاية
```

## 🎯 نصائح متقدمة

### 1. استخدم أسماء واضحة لمعاملات النوع

```
# ❌ غير واضح
قالب<نوع ت، نوع س> دالة ...

# ✅ واضح
قالب<نوع مفتاح، نوع قيمة> دالة ...
قالب<نوع مدخل، نوع مخرج> دالة ...
```

### 2. وثّق القيود على الأنواع

```
# دالة تتطلب أن يدعم النوع عملية الجمع
# القيد: ت يجب أن يدعم العملية +
قالب<نوع ت> دالة مجموع(مصفوفة قائمة) ترجع ت
    ت نتيجة = 0
    لكل عنصر في قائمة
        نتيجة = نتيجة + عنصر
    نهاية
    ارجع نتيجة
نهاية
```

### 3. تجنب التعقيد الزائد

القوالب أداة قوية، لكن **لا تبالغ في استخدامها**. إذا كان القالب يجعل الكود أكثر تعقيداً، فكر في بدائل:

```
# ❌ معقد جداً
قالب<نوع ت1، نوع ت2، نوع ت3، نوع ت4> دالة معالج_معقد(...)

# ✅ أبسط - استخدم أصنافاً مخصصة بدلاً من ذلك
صنف بيانات_معالجة
    # ...
نهاية

دالة معالج_بسيط(بيانات_معالجة بيانات) ...
```

## 📚 الخلاصة

القوالب المتقدمة تفتح أبواباً واسعة لكتابة كود:
- 🔄 **قابل لإعادة الاستخدام** - اكتب مرة واستخدم في أي مكان
- 🎯 **نوع-آمن** (Type-Safe) - المترجم يتحقق من الأنواع
- ⚡ **فعّال** - لا حاجة لتكرار الكود
- 🧩 **مرن** - يعمل مع أي نوع يدعم العمليات المطلوبة
