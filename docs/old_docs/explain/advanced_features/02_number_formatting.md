## مقدمة: مشكلة قراءة الأرقام الكبيرة

عندما ترى رقماً مثل `1000000` في كود برمجي، كم يستغرقك الأمر لتحدد أنه مليون؟ غالباً ستحتاج لعد الأصفار واحداً تلو الآخر، وهذا مضيعة للوقت وعرضة للخطأ. المشكلة تصبح أسوأ مع الأرقام الأكبر: هل `100000000` مئة مليون أم عشرة ملايين؟ من السهل أن تخطئ في العد.

في الحياة اليومية، نحل هذه المشكلة باستخدام الفواصل: نكتب 1,000,000 بدلاً من 1000000، والفاصلة تساعدنا على تجميع الأرقام وقراءتها بسرعة. لغة ص تقدم حلاً أفضل: استخدام الشرطة السفلية `_` كفاصل بصري داخل الأرقام، دون أن تؤثر على القيمة الفعلية للرقم.

بالإضافة لذلك، لغة ص تدعم ميزة فريدة ونادرة في لغات البرمجة: القدرة على كتابة الأرقام بالأحرف العربية (٠-٩) مباشرة في الكود! هذا يجعل الكود أكثر طبيعية وقرباً للمبرمجين العرب، خاصة في التطبيقات التي تستهدف الجمهور العربي.

## الفواصل البصرية: الشرطة السفلية `_`

### ما هي الفواصل البصرية؟

الفواصل البصرية هي أحرف تُضاف داخل الرقم لتحسين قابلية القراءة، دون أن تغير قيمة الرقم. عندما تكتب `1_000_000`، اللغة تتجاهل الشرطة السفلية تماماً وتقرأ الرقم كـ `1000000`. لكن بالنسبة لك كمبرمج، الفرق في القراءة هائل.

هذه الميزة مستوحاة من لغات حديثة مثل Python و Rust و Java الحديثة، وقد أثبتت أنها تقلل الأخطاء البرمجية بشكل ملحوظ، خاصة عند التعامل مع الأرقام المالية الكبيرة أو الثوابت الرياضية الطويلة.

### كيف تستخدم الشرطة السفلية؟

القاعدة بسيطة: يمكنك وضع `_` في أي مكان داخل الرقم لتحسين القراءة. الأماكن الأكثر شيوعاً هي كل ثلاثة أرقام (كما في النظام العشري) أو كل أربعة (كما في بعض الأنظمة الآسيوية):

```s
# تنسيق كل ثلاثة أرقام (الأكثر شيوعاً)
رقم ألف = 1_000
رقم مليون = 1_000_000
رقم مليار = 1_000_000_000
رقم تريليون = 1_000_000_000_000

# تنسيق كل أربعة أرقام (نظام شرق آسيوي)
رقم عشرة_آلاف = 1_0000
رقم مئة_مليون = 1_0000_0000

# يمكنك استخدام أي تنسيق يناسبك
رقم مخصص = 12_34_56_78

اطبع("مليون:", مليون)
اطبع("مليار:", مليار)
```

### الأرقام العشرية مع الفواصل

الفواصل لا تقتصر على الأرقام الصحيحة، بل يمكن استخدامها أيضاً مع الأرقام العشرية لتحسين قراءة الثوابت الرياضية والعلمية:

```s
# ثابت باي بدقة عالية
عشري باي = 3.141_592_653_589_793

# ثابت أويلر
عشري اويلر = 2.718_281_828_459_045

# السرعة الضوئية (متر/ثانية)
عشري سرعة_الضوء = 299_792_458.0

# ثابت بلانك (جول·ثانية)
عشري ثابت_بلانك = 0.000_000_000_000_000_000_000_000_000_000_000_662_607

اطبع("باي:", باي)
اطبع("سرعة الضوء:", سرعة_الضوء)
```

لاحظ كيف أن الفواصل تجعل قراءة هذه الأرقام الطويلة أسهل بكثير. بدون فواصل، من السهل أن تخطئ في عدد الأصفار أو الأرقام.

### الفواصل في الأنظمة غير العشرية

الميزة الرائعة حقاً هي أن الفواصل تعمل مع جميع أنظمة الأرقام: الثنائي، الثماني، والست عشري!

```s
# فواصل في الأرقام الثنائية (كل 4 بتات = nibble)
رقم ثنائي_مقروء = 0b1111_0000_1010_0101
رقم ثنائي_بايت = 0b0000_1111           # بايت واحد مع فواصل

# فواصل في الأرقام الثمانية
رقم ثماني_مقروء = 0o7_777_777         # واضح جداً

# فواصل في الأرقام الست عشرية (كل بايتين)
رقم لون_مقروء = 0xFF_00_FF            # أحمر وأزرق (فوشيا)
رقم عنوان_ذاكرة = 0x7FFF_FFFF_FFFF_FFFF

# مع البادئات العربية أيضاً!
رقم ثنائي_عربي = 0ثن1111_0000_1010
رقم ست_عشري_عربي = 0سFF_00_FF

اطبع("ثنائي مقروء:", ثنائي_مقروء)
اطبع("لون مقروء:", لون_مقروء)
```

هذا مفيد جداً عند التعامل مع البيانات الخام أو عناوين الذاكرة. فاصل كل أربعة بتات في الأرقام الثنائية يساعد على رؤية كل نصف بايت (nibble) بوضوح، وفاصل كل بايتين في الست عشري يساعد على تمييز أجزاء العنوان أو اللون.

### قواعد استخدام الفواصل

هناك بعض القواعد المهمة التي يجب اتباعها عند استخدام الفواصل:

**لا يمكن البدء أو الانتهاء بفاصل:**

```s
رقم صحيح = 1_000_000      # ✓ صحيح
رقم خاطئ1 = _1000000       # ✗ خطأ! لا تبدأ بفاصل
رقم خاطئ2 = 1000000_       # ✗ خطأ! لا تنتهي بفاصل
```

**الفواصل للقراءة فقط:**

الفواصل لا تؤثر على القيمة الفعلية للرقم بأي شكل. هذه الأرقام كلها متساوية تماماً:

```s
رقم أ = 1000000
رقم ب = 1_000_000
رقم ج = 10_00_000
رقم د = 1_0_0_0_0_0_0

# الأربعة يساوون 1000000
اطبع(أ == ب)  # صحيح
اطبع(ب == ج)  # صحيح
اطبع(ج == د)  # صحيح
```

**استخدم تنسيقاً متسقاً:**

رغم أن اللغة لا تفرض نمطاً معيناً، من الأفضل أن تلتزم بنمط واحد في كل المشروع لتحسين القراءة:

```s
# جيد: نمط متسق (كل 3 أرقام)
رقم ميزانية_2024 = 5_000_000
رقم ميزانية_2025 = 6_500_000
رقم مجموع = 11_500_000

# ليس جيداً: أنماط مختلفة
رقم ميزانية_أخرى1 = 5_000_000
رقم ميزانية_أخرى2 = 65_00_000  # نمط مختلف!
```

## الأرقام العربية: كتابة طبيعية

### ميزة فريدة في عالم البرمجة

واحدة من أكثر الميزات إثارة وتفرداً في لغة ص هي القدرة على كتابة الأرقام بالأحرف العربية (٠-٩) مباشرة في الكود. هذه ميزة نادرة جداً في لغات البرمجة، ولكنها منطقية تماماً للغة عربية. لماذا يجب على المبرمج العربي أن يكتب الكود بالعربية ثم يضطر لاستخدام الأرقام الإنجليزية؟

مع لغة ص، يمكنك كتابة `رقم العمر = ٢٥` بشكل طبيعي كامل، والبرنامج سيفهم تماماً أن العمر يساوي 25. هذا يجعل الكود أكثر اتساقاً وطبيعية، خاصة في التطبيقات التي تستهدف المستخدمين العرب.

### كيف تستخدم الأرقام العربية؟

استخدام الأرقام العربية بسيط جداً: اكتبها كما تكتبها في أي نص عربي عادي:

```s
# أرقام عربية بسيطة
رقم واحد = ١
رقم اثنان = ٢
رقم عشرة = ١٠
رقم مئة = ١٠٠

# أرقام أكبر
رقم ألف = ١٠٠٠
رقم عشرة_آلاف = ١٠٠٠٠
رقم مليون = ١٠٠٠٠٠٠

# أرقام عشرية
عشري نصف = ٠.٥
عشري ثلاثة_أرباع = ٠.٧٥
عشري باي = ٣.١٤١٥٩

اطبع("العدد واحد:", واحد)
اطبع("العدد مئة:", مئة)
اطبع("باي:", باي)
```

### خلط الأرقام العربية والإنجليزية

اللغة ذكية بما يكفي لفهم الأرقام حتى لو خلطت بين العربية والإنجليزية في نفس الرقم:

```s
# خليط عربي-إنجليزي (يعمل لكن غير منصوح به)
رقم مخلوط1 = ١٢٣45      # الرقم 12345
رقم مخلوط2 = 12٣٤٥      # نفس الشيء

اطبع("مخلوط:", مخلوط1)
```

رغم أن هذا يعمل، لكن من الأفضل الالتزام بنوع واحد من الأرقام في كل المشروع لتجنب الإرباك. إما تستخدم الأرقام العربية في كل مكان، أو الإنجليزية في كل مكان.

### متى تستخدم الأرقام العربية؟

اختيار نوع الأرقام يعتمد على سياق المشروع:

**استخدم الأرقام العربية عندما:**
- المشروع كله بالعربية (أسماء متغيرات، تعليقات، رسائل)
- التطبيق موجه للمستخدمين العرب بشكل حصري
- تريد أن يكون الكود "عربياً" بنسبة 100%
- تتعامل مع أرقام ستُعرض للمستخدمين العرب

**استخدم الأرقام الإنجليزية عندما:**
- المشروع مختلط أو تقني بحت
- تعمل مع فريق متعدد اللغات
- الكود يحتوي على كثير من الرياضيات والحسابات
- تستخدم مكتبات أو APIs خارجية

### أمثلة عملية مع الأرقام العربية

دعنا نرى أمثلة واقعية لاستخدام الأرقام العربية:

```s
# مثال 1: برنامج حساب العمر
رقم سنة_الميلاد = ١٩٩٥
رقم السنة_الحالية = ٢٠٢٦
رقم العمر = السنة_الحالية - سنة_الميلاد

اطبع("العمر:", العمر, "سنة")

# مثال 2: حساب معدل الطالب
عشري درجة_الرياضيات = ٩٥.٥
عشري درجة_العلوم = ٨٨.٠
عشري درجة_اللغة = ٩٢.٥
عشري المعدل = (درجة_الرياضيات + درجة_العلوم + درجة_اللغة) / ٣.٠

اطبع("المعدل:", المعدل)

# مثال 3: حساب فاتورة
عشري سعر_المنتج = ٢٥٠.٠
رقم الكمية = ٥
عشري الضريبة = ٠.١٥  # 15%

عشري المجموع_قبل_الضريبة = سعر_المنتج * الكمية
عشري قيمة_الضريبة = المجموع_قبل_الضريبة * الضريبة
عشري المجموع_النهائي = المجموع_قبل_الضريبة + قيمة_الضريبة

اطبع("المجموع قبل الضريبة:", المجموع_قبل_الضريبة)
اطبع("الضريبة:", قيمة_الضريبة)
اطبع("المجموع النهائي:", المجموع_النهائي)

# مثال 4: الأيام والساعات
رقم عدد_أيام_السنة = ٣٦٥
رقم عدد_ساعات_اليوم = ٢٤
رقم عدد_دقائق_الساعة = ٦٠

رقم عدد_ساعات_السنة = عدد_أيام_السنة * عدد_ساعات_اليوم
رقم عدد_دقائق_السنة = عدد_ساعات_السنة * عدد_دقائق_الساعة

اطبع("عدد ساعات السنة:", عدد_ساعات_السنة)
اطبع("عدد دقائق السنة:", عدد_دقائق_السنة)
```

## الجمع بين الفواصل والأرقام العربية

الآن السؤال المثير: هل يمكن استخدام الفواصل مع الأرقام العربية؟ للأسف، حالياً الفواصل تعمل فقط مع الأرقام الإنجليزية. لكن هذا ليس مشكلة كبيرة لأن الأرقام العربية عادة تُستخدم في سياقات لا تحتاج أرقاماً كبيرة جداً.

إذا احتجت لكتابة أرقام كبيرة مع فواصل، يمكنك استخدام الأرقام الإنجليزية مع الفواصل:

```s
# للأرقام الكبيرة: استخدم الإنجليزية مع فواصل
رقم ميزانية_كبيرة = 5_000_000_000

# للأرقام الصغيرة: استخدم العربية
رقم عدد_الموظفين = ٢٥
رقم عدد_الأقسام = ٧
```

## أمثلة متقدمة: المزج بين كل الميزات

الآن بعد أن تعلمنا عن الفواصل والأرقام العربية، لنرى كيف يمكن استخدامها مع أنظمة الأرقام المختلفة:

```s
# مثال شامل: برنامج إدارة ألوان

# تعريف الألوان بالست عشري مع فواصل (للوضوح)
رقم لون_أحمر = 0xFF_00_00
رقم لون_أخضر = 0x00_FF_00
رقم لون_أزرق = 0x00_00_FF

# كميات الألوان (بالأرقام العربية)
رقم عدد_علب_الأحمر = ٥
رقم عدد_علب_الأخضر = ٣
رقم عدد_علب_الأزرق = ٨

# السعر (بالإنجليزية مع فواصل)
عشري سعر_العلبة = 25_000.00

# الحسابات
عشري تكلفة_الأحمر = عدد_علب_الأحمر * سعر_العلبة
عشري تكلفة_الأخضر = عدد_علب_الأخضر * سعر_العلبة
عشري تكلفة_الأزرق = عدد_علب_الأزرق * سعر_العلبة
عشري التكلفة_الإجمالية = تكلفة_الأحمر + تكلفة_الأخضر + تكلفة_الأزرق

اطبع("=== تقرير المخزون ===")
اطبع("اللون الأحمر (كود:", لون_أحمر, ") - العدد:", عدد_علب_الأحمر)
اطبع("اللون الأخضر (كود:", لون_أخضر, ") - العدد:", عدد_علب_الأخضر)
اطبع("اللون الأزرق (كود:", لون_أزرق, ") - العدد:", عدد_علب_الأزرق)
اطبع("التكلفة الإجمالية:", التكلفة_الإجمالية, "ريال")
```

## نصائح عملية وأفضل الممارسات

عند التعامل مع تنسيق الأرقام، ضع هذه النصائح في اعتبارك:

**للفواصل:**
1. استخدم فواصل في الأرقام الكبيرة (أكثر من 4-5 أرقام)
2. التزم بنمط واحد في كل المشروع (كل 3 أو كل 4 أرقام)
3. استخدم الفواصل بحرية في الثوابت الرياضية الطويلة
4. لا تفرط في استخدام الفواصل في الأرقام الصغيرة

**للأرقام العربية:**
1. قرر في بداية المشروع: عربية أم إنجليزية، والتزم بالقرار
2. استخدم العربية إذا كان المشروع كله عربياً
3. لا تخلط بين العربية والإنجليزية في نفس الرقم
4. في حالة الشك، استخدم الإنجليزية (أكثر شيوعاً)

**العامل:**
- الوضوح أهم من الاختصار
- اكتب الكود لمن سيقرأه بعد ستة أشهر (قد تكون أنت!)
- استخدم الأدوات التي تجعل الكود أسهل فهماً، لا أصعب
