# نظرة عامة على لغة ص (Sad Language)

## مقدمة شاملة

لغة ص (Sad Language) هي لغة برمجة حديثة ومبتكرة تم تصميمها لتكون أول لغة برمجة عربية متكاملة تدعم البرمجة بالعربية الكاملة مع الحفاظ على القدرات المتقدمة للغات البرمجة الحديثة. تجمع هذه اللغة بين سهولة التعلم والقوة في الأداء، حيث يمكن للمبرمج كتابة الكود بالعربية أو الإنجليزية أو كليهما معاً. الهدف الأساسي من هذه اللغة هو كسر حاجز اللغة أمام المبرمجين العرب وتمكينهم من فهم مفاهيم البرمجة بلغتهم الأم قبل الانتقال للغات الأخرى.

تتميز لغة ص ببنية معمارية متطورة تشمل عدة مكونات أساسية تعمل معاً بتناغم لإنتاج برامج فعالة وسريعة. هذه المكونات تتضمن المحلل المعجمي (Lexer) الذي يحول النص المصدري إلى رموز، والمحلل النحوي (Parser) الذي يبني شجرة الصيغة المجردة (AST)، والمفسر (Interpreter) للتنفيذ المباشر، والمترجم (Compiler) لإنتاج كود آلة عالي الأداء، والآلة الافتراضية (VM) لتنفيذ البايت كود، ومحرك التجميع الفوري (JIT) لتحسين الأداء أثناء التشغيل.

## البنية العامة للمشروع

يتكون مشروع لغة ص من عدة مجلدات رئيسية، كل منها مسؤول عن جزء محدد من النظام:

```
s_language/
├── shared/              # المكونات المشتركة (Lexer, Parser, AST)
├── interpreter_new/     # المفسر الجديد
├── compiler_new/        # المترجم الجديد (Frontend, Backend, JIT)
├── runtime_new/         # بيئة التشغيل (VM, Memory, GC)
├── tools/               # الأدوات (REPL, LSP, PKG)
├── stdlib/              # المكتبة القياسية
├── docs/                # التوثيق
└── examples/            # أمثلة برمجية
```

## مراحل إنتاج الكود

### المرحلة الأولى: التحليل المعجمي (Lexical Analysis)

يبدأ كل شيء عندما يقرأ المحلل المعجمي (Lexer) الكود المصدري حرفاً بحرف. يقوم المحلل المعجمي بتحويل النص إلى سلسلة من الرموز (Tokens) التي تمثل الوحدات الأساسية للغة مثل الأرقام والنصوص والمعرفات والكلمات المفتاحية والعوامل. على سبيل المثال، عندما يقرأ الكود `رقم س = 42`، ينتج الرموز التالية: `رقم` (كلمة مفتاحية)، `س` (معرف)، `=` (عامل إسناد)، `42` (رقم).

### المرحلة الثانية: التحليل النحوي (Parsing)

بعد التحليل المعجمي، يأخذ المحلل النحوي (Parser) سلسلة الرموز ويبني منها شجرة الصيغة المجردة (Abstract Syntax Tree - AST). هذه الشجرة تمثل البنية المنطقية للبرنامج بشكل هرمي، حيث كل عقدة تمثل بنية برمجية معينة (تعبير، تصريح، عبارة). الشجرة تحافظ على العلاقات بين العناصر مثل ترتيب العمليات وتداخل النطاقات.

### المرحلة الثالثة: التحليل الدلالي (Semantic Analysis)

في هذه المرحلة، يتم فحص الشجرة للتأكد من صحتها الدلالية. يشمل ذلك التحقق من الأنواع (Type Checking)، والتأكد من أن المتغيرات معرفة قبل استخدامها، والتحقق من توافق أنواع البيانات في العمليات، وفحص قواعد النطاق (Scope Rules).

### المرحلة الرابعة: التنفيذ أو التجميع

بعد التحقق من صحة الكود، يمكن للبرنامج أن يسلك أحد مسارين:

**المسار الأول - التفسير:** المفسر يمشي على شجرة AST مباشرة وينفذ كل عقدة فوراً. هذا المسار مناسب للتطوير السريع والتجربة.

**المسار الثاني - التجميع:** المترجم يحول شجرة AST إلى تمثيل وسيط (SIR)، ثم يحوله إلى LLVM IR، وأخيراً إلى كود آلة أصلي. هذا المسار ينتج برامج أسرع بكثير.

## الكلمات المفتاحية المدعومة

تدعم لغة ص الكلمات المفتاحية بالعربية والإنجليزية:

| العربية | الإنجليزية | الوظيفة |
|---------|-----------|---------|
| دالة | func | تعريف دالة |
| إذا | if | شرط |
| وإلا | else | بديل الشرط |
| طالما | while | حلقة |
| لكل | for | حلقة تكرارية |
| أرجع | return | إرجاع قيمة |
| متغير | var | تعريف متغير |
| ثابت | const | تعريف ثابت |
| صنف | class | تعريف صنف |
| اطبع | print | طباعة |

## مثال برنامج بسيط

```sad
# برنامج مرحباً بالعالم
دالة رئيسية() {
    اطبع("مرحباً بالعالم!");
    
    متغير س = 10;
    متغير ص = 20;
    متغير المجموع = س + ص;
    
    اطبع("المجموع: " + المجموع);
    
    أرجع 0;
}
```

## الميزات المتقدمة

لغة ص ليست مجرد لغة تعليمية بسيطة، بل تدعم العديد من الميزات المتقدمة:

- **البرمجة كائنية التوجه (OOP):** تدعم الأصناف والوراثة وتعدد الأشكال
- **نظام أنواع متقدم:** يشمل Union Types و Optional Types و Generic Types
- **البرمجة غير المتزامنة:** دعم async/await للعمليات غير المتزامنة
- **إدارة الذاكرة التلقائية:** جامع قمامة (Garbage Collector) متطور
- **نظام وحدات:** استيراد وتصدير الوحدات
- **المكتبة القياسية:** مكتبة شاملة للملفات والشبكات والواجهات الرسومية
