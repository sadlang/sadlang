## البدء السريع

### تثبيت اللغة
```bash
# تحميل من الموقع الرسمي
# أو البناء من المصدر
cmake -B build
cmake --build build --config Release
```

### أول برنامج
```sad
# مرحباً بالعالم
دالة رئيسية() {
    اطبع("مرحباً بالعالم!");
    أرجع 0;
}
```

### التشغيل
```bash
# التفسير المباشر
sad run برنامج.s

# الترجمة
sad compile -o برنامج برنامج.s

# REPL
sad repl
```

## المساهمة

التوثيق مفتوح المصدر. للمساهمة:
1. راجع الملفات المصدرية في `compiler_new/`، `interpreter_new/`، `runtime_new/`
2. أضف أو حسّن التوثيق
3. أرسل طلب دمج (Pull Request)
