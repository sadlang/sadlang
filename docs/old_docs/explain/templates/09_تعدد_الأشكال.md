# تعدد الأشكال في لغة ص

## ما هو تعدد الأشكال؟

تعدد الأشكال (Polymorphism) هو قدرة الكائنات المختلفة على الاستجابة لنفس الرسالة بطرق مختلفة. الكلمة تأتي من اليونانية وتعني "أشكال متعددة".

تخيل أنك تقول "تحدث!" لمجموعة من الحيوانات. القطة ستقول "مياو"، الكلب سيقول "هاو"، والطائر سيُغرد. كلهم استجابوا لنفس الأمر لكن بطرق مختلفة - هذا هو تعدد الأشكال!

## أنواع تعدد الأشكال

### 1. تعدد الأشكال في وقت الترجمة (Compile-time Polymorphism)

يُعرف أيضاً بالتحميل الزائد (Overloading). يحدث عندما يكون لديك دوال متعددة بنفس الاسم لكن بمعاملات مختلفة.

```س
صنف آلة_حاسبة
    عام:
        # جمع رقمين
        دالة جمع(رقم أ، رقم ب) رقم
            ارجع أ + ب
        نهاية
        
        # جمع ثلاثة أرقام
        دالة جمع(رقم أ، رقم ب، رقم ج) رقم
            ارجع أ + ب + ج
        نهاية
        
        # جمع أرقام عشرية
        دالة جمع(عشري أ، عشري ب) عشري
            ارجع أ + ب
        نهاية
        
        # جمع نصوص (دمج)
        دالة جمع(نص أ، نص ب) نص
            ارجع أ + ب
        نهاية
نهاية

دالة رئيسية() رقم
    متغير حاسبة = آلة_حاسبة()
    
    اطبع(حاسبة.جمع(5، 10))           # 15
    اطبع(حاسبة.جمع(5، 10، 15))       # 30
    اطبع(حاسبة.جمع(3.14، 2.71))      # 5.85
    اطبع(حاسبة.جمع("مرحباً "، "عالم"))  # "مرحباً عالم"
    
    ارجع 0
نهاية
```

### 2. تعدد الأشكال في وقت التشغيل (Runtime Polymorphism)

يحدث عندما يتم تحديد الدالة المُستدعاة في وقت التشغيل بناءً على نوع الكائن الفعلي. يعتمد على الوراثة والدوال الافتراضية.

```س
صنف صوت
    عام:
        دالة افتراضية اصدر_صوت()
            اطبع("...")
        نهاية
نهاية

صنف قطة يرث صوت
    عام:
        دالة اصدر_صوت()
            اطبع("مياو مياو!")
        نهاية
نهاية

صنف كلب يرث صوت
    عام:
        دالة اصدر_صوت()
            اطبع("هاو هاو!")
        نهاية
نهاية

صنف عصفور يرث صوت
    عام:
        دالة اصدر_صوت()
            اطبع("زقزقة زقزقة!")
        نهاية
نهاية

# دالة تقبل أي صوت وتُشغّله
دالة شغّل_الصوت(صوت ص)
    ص.اصدر_صوت()  # الدالة الصحيحة تُستدعى تلقائياً!
نهاية

دالة رئيسية() رقم
    متغير ق = قطة()
    متغير ك = كلب()
    متغير ع = عصفور()
    
    شغّل_الصوت(ق)  # مياو مياو!
    شغّل_الصوت(ك)  # هاو هاو!
    شغّل_الصوت(ع)  # زقزقة زقزقة!
    
    ارجع 0
نهاية
```

```س
# دالة تعمل مع أي شكل - تعدد الأشكال في أبهى صوره

    ش.اطبع_المعلومات()
    اطبع("الرسم:")
    ش.ارسم()
    اطبع("")
نهاية

# دالة لحساب مجموع المساحات
دالة مجموع_المساحات(شكل[] أشكال، رقم عدد) عشري
    متغير مجموع = 0.0
    متغير ع = 0
    طالما(ع < عدد)
        مجموع = مجموع + أشكال[ع].احسب_المساحة()
        ع = ع + 1
    نهاية
    ارجع مجموع
نهاية

دالة رئيسية() رقم
    # إنشاء أشكال مختلفة
    متغير م = مربع("أحمر"، 5.0)
    متغير مس = مستطيل("أزرق"، 10.0، 4.0)
    متغير د = دائرة("أخضر"، 3.0)
    متغير ث = مثلث("أصفر"، 6.0، 4.0، 5.0، 5.0، 6.0)
    
    # عرض كل شكل
    اعرض_شكل(م)
    اعرض_شكل(مس)
    اعرض_شكل(د)
    اعرض_شكل(ث)
    
    # مصفوفة من الأشكال
    متغير أشكال = شكل[4]
    أشكال[0] = م
    أشكال[1] = مس
    أشكال[2] = د
    أشكال[3] = ث
    
    اطبع("مجموع مساحات جميع الأشكال: ")
    اطبع(مجموع_المساحات(أشكال، 4))
    
    ارجع 0
نهاية
```

## فوائد تعدد الأشكال

### 1. المرونة
كود واحد يعمل مع أنواع متعددة:

```س
# دالة واحدة تعمل مع جميع الأشكال
دالة اطبع_مساحة(شكل ش)
    اطبع(ش.احسب_المساحة())
نهاية
```

### 2. قابلية التوسع
إضافة أنواع جديدة بدون تغيير الكود الموجود:

```س
# إضافة شكل جديد
صنف شبه_منحرف يرث شكل
    # ... التنفيذ
نهاية

# الدالة القديمة تعمل تلقائياً مع الشكل الجديد!
اطبع_مساحة(شبه_منحرف_جديد)
```

### 3. تقليل التكرار
لا حاجة لكتابة دوال منفصلة لكل نوع:

```س
# بدلاً من:
دالة احسب_مساحة_مربع(...)
دالة احسب_مساحة_دائرة(...)
دالة احسب_مساحة_مثلث(...)

# دالة واحدة:
دالة احسب_مساحة(شكل ش)
```

## ملخص

تعدد الأشكال في لغة ص يُقدم لك:

- **التحميل الزائد**: دوال بنفس الاسم ومعاملات مختلفة
- **الدوال الافتراضية**: تحديد السلوك في وقت التشغيل
- **كود مرن**: يعمل مع أنواع متعددة
- **قابلية التوسع**: إضافة أنواع جديدة بسهولة

استخدم تعدد الأشكال لكتابة كود نظيف ومرن وقابل للصيانة!
