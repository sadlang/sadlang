# دوال القوالب في لغة ص

## تعريف دالة القالب

دالة القالب هي دالة عامة يمكنها العمل مع أنواع بيانات متعددة. لتعريف دالة قالب، نستخدم الكلمة المفتاحية `قالب` متبوعة بمعاملات النوع بين أقواس زاوية.

### الصيغة الأساسية

```س
قالب<نوع ت> دالة اسم_الدالة(ت معامل) ت
    # جسم الدالة
    ارجع معامل
نهاية
```

### شرح الأجزاء

- `قالب<نوع ت>`: تُعلن عن قالب بمعامل نوع واحد يُسمى `ت`
- `دالة اسم_الدالة`: تعريف الدالة كالمعتاد
- `(ت معامل)`: المعامل من النوع `ت` (النوع المُعمم)
- `ت` بعد القوسين: نوع الإرجاع هو أيضاً `ت`

## أمثلة عملية للمبتدئين

### دالة الهوية (Identity Function)

أبسط دالة قالب هي دالة الهوية التي تُرجع ما تستقبله كما هو:

```س
قالب<نوع ت> دالة هوية(ت قيمة) ت
    ارجع قيمة
نهاية

دالة رئيسية() رقم
    متغير أ = هوية<رقم>(42)      # النتيجة: 42
    متغير ب = هوية<نص>("مرحباً") # النتيجة: "مرحباً"
    متغير ج = هوية<عشري>(3.14)  # النتيجة: 3.14
    
    اطبع(أ)
    اطبع(ب)
    اطبع(ج)
    
    ارجع 0
نهاية
```

هذا المثال يُظهر كيف يمكن لدالة واحدة أن تتعامل مع أنواع مختلفة تماماً. نفس الدالة `هوية` تعمل مع الأرقام والنصوص والأرقام العشرية!

### دالة المقارنة

دالة تُقارن قيمتين وتُرجع الأكبر:

```س
قالب<نوع ت> دالة أكبر(ت أ، ت ب) ت
    إذا(أ > ب)
        ارجع أ
    نهاية
    ارجع ب
نهاية

دالة رئيسية() رقم
    # مع الأرقام الصحيحة
    اطبع(أكبر<رقم>(10، 20))  # النتيجة: 20
    
    # مع الأرقام العشرية
    اطبع(أكبر<عشري>(3.14، 2.71))  # النتيجة: 3.14
    
    # مع النصوص (مقارنة أبجدية)
    اطبع(أكبر<نص>("زيد"، "أحمد"))  # النتيجة: "زيد"
    
    ارجع 0
نهاية
```

لاحظ أن الدالة تعمل مع أي نوع يدعم عملية المقارنة `>`. هذا يُسمى "البرمجة العامة" - تكتب كوداً يعمل مع أنواع متعددة طالما تدعم العمليات المطلوبة.

### دالة التبديل

دالة تُبدّل قيمتين (مفيدة جداً في خوارزميات الترتيب):

```س
قالب<نوع ت> دالة بدّل(ت أ، ت ب)
    متغير مؤقت = أ
    أ = ب
    ب = مؤقت
    
    اطبع("بعد التبديل: ")
    اطبع(أ)
    اطبع(ب)
نهاية

دالة رئيسية() رقم
    متغير س = 5
    متغير ص = 10
    
    اطبع("قبل التبديل: ")
    اطبع(س)
    اطبع(ص)
    
    بدّل<رقم>(س، ص)
    
    ارجع 0
نهاية
```

## أمثلة متوسطة المستوى

### دالة مع معاملات متعددة

يمكنك تعريف دالة قالب بأكثر من معامل نوع:

```س
قالب<نوع ت1، نوع ت2> دالة زوج(ت1 أول، ت2 ثاني)
    اطبع("العنصر الأول: ")
    اطبع(أول)
    اطبع("العنصر الثاني: ")
    اطبع(ثاني)
نهاية

دالة رئيسية() رقم
    # زوج من رقم ونص
    زوج<رقم، نص>(42، "الجواب")
    
    # زوج من نصين
    زوج<نص، نص>("اسم"، "أحمد")
    
    # زوج من عشري ورقم
    زوج<عشري، رقم>(3.14، 314)
    
    ارجع 0
نهاية
```

هذا مفيد عندما تحتاج دالة تتعامل مع نوعين مختلفين. مثلاً، دالة تُحوّل من نوع لآخر، أو دالة تُقارن عنصرين من أنواع مختلفة.

### دالة البحث في مصفوفة

```س
قالب<نوع ت> دالة ابحث(ت[] مصفوفة، ت قيمة، رقم حجم) رقم
    متغير ع = 0
    طالما(ع < حجم)
        إذا(مصفوفة[ع] == قيمة)
            ارجع ع
        نهاية
        ع = ع + 1
    نهاية
    ارجع -1  # لم يُوجد
نهاية

دالة رئيسية() رقم
    # البحث في مصفوفة أرقام
    متغير أرقام = [10، 20، 30، 40، 50]
    متغير موقع = ابحث<رقم>(أرقام، 30، 5)
    اطبع("موقع 30: ")
    اطبع(موقع)  # النتيجة: 2
    
    # البحث في مصفوفة نصوص
    متغير أسماء = ["أحمد"، "محمد"، "علي"]
    متغير موقع2 = ابحث<نص>(أسماء، "محمد"، 3)
    اطبع("موقع محمد: ")
    اطبع(موقع2)  # النتيجة: 1
    
    ارجع 0
نهاية
```

### دالة الحد الأدنى والأقصى

```س
قالب<نوع ت> دالة أصغر(ت أ، ت ب) ت
    إذا(أ < ب)
        ارجع أ
    نهاية
    ارجع ب
نهاية

قالب<نوع ت> دالة محصور(ت قيمة، ت حد_أدنى، ت حد_أقصى) ت
    # تأكد أن القيمة ضمن الحدود
    إذا(قيمة < حد_أدنى)
        ارجع حد_أدنى
    نهاية
    إذا(قيمة > حد_أقصى)
        ارجع حد_أقصى
    نهاية
    ارجع قيمة
نهاية

دالة رئيسية() رقم
    # حصر قيمة بين 0 و 100
    اطبع(محصور<رقم>(150، 0، 100))  # النتيجة: 100
    اطبع(محصور<رقم>(-50، 0، 100))  # النتيجة: 0
    اطبع(محصور<رقم>(75، 0، 100))   # النتيجة: 75
    
    # يعمل مع الأرقام العشرية أيضاً
    اطبع(محصور<عشري>(1.5، 0.0، 1.0))  # النتيجة: 1.0
    
    ارجع 0
نهاية
```

## أمثلة متقدمة

### دالة خريطة (Map)

تُطبّق دالة على كل عنصر في مصفوفة:

```س
قالب<نوع ت> دالة خريطة(ت[] مصفوفة، رقم حجم)
    # طباعة كل عنصر بعد معالجته
    متغير ع = 0
    طالما(ع < حجم)
        اطبع("العنصر ")
        اطبع(ع)
        اطبع(": ")
        اطبع(مصفوفة[ع])
        ع = ع + 1
    نهاية
نهاية

دالة رئيسية() رقم
    متغير أرقام = [1، 2، 3، 4، 5]
    خريطة<رقم>(أرقام، 5)
    
    ارجع 0
نهاية
```

### دالة التصفية (Filter)

تُرجع عدد العناصر التي تُحقق شرطاً معيناً:

```س
قالب<نوع ت> دالة عدّ_الأكبر_من(ت[] مصفوفة، رقم حجم، ت حد) رقم
    متغير عداد = 0
    متغير ع = 0
    طالما(ع < حجم)
        إذا(مصفوفة[ع] > حد)
            عداد = عداد + 1
        نهاية
        ع = ع + 1
    نهاية
    ارجع عداد
نهاية

دالة رئيسية() رقم
    متغير درجات = [85، 92، 78، 95، 88، 70، 99]
    متغير فوق_90 = عدّ_الأكبر_من<رقم>(درجات، 7، 90)
    
    اطبع("عدد الدرجات فوق 90: ")
    اطبع(فوق_90)  # النتيجة: 3
    
    ارجع 0
نهاية
```

### دالة الترتيب (Bubble Sort)

```س
قالب<نوع ت> دالة رتّب_فقاعي(ت[] مصفوفة، رقم حجم)
    متغير ع = 0
    طالما(ع < حجم - 1)
        متغير ج = 0
        طالما(ج < حجم - ع - 1)
            إذا(مصفوفة[ج] > مصفوفة[ج + 1])
                # تبديل العنصرين
                متغير مؤقت = مصفوفة[ج]
                مصفوفة[ج] = مصفوفة[ج + 1]
                مصفوفة[ج + 1] = مؤقت
            نهاية
            ج = ج + 1
        نهاية
        ع = ع + 1
    نهاية
نهاية

قالب<نوع ت> دالة اطبع_مصفوفة(ت[] مصفوفة، رقم حجم)
    اطبع("[")
    متغير ع = 0
    طالما(ع < حجم)
        اطبع(مصفوفة[ع])
        إذا(ع < حجم - 1)
            اطبع("، ")
        نهاية
        ع = ع + 1
    نهاية
    اطبع("]")
نهاية

دالة رئيسية() رقم
    متغير أرقام = [64، 34، 25، 12، 22، 11، 90]
    
    اطبع("قبل الترتيب: ")
    اطبع_مصفوفة<رقم>(أرقام، 7)
    
    رتّب_فقاعي<رقم>(أرقام، 7)
    
    اطبع("بعد الترتيب: ")
    اطبع_مصفوفة<رقم>(أرقام، 7)
    
    ارجع 0
نهاية
```

## نصائح وأفضل الممارسات

### 1. اختر أسماء واضحة لمعاملات النوع

بدلاً من استخدام حروف مفردة مبهمة، استخدم أسماء تُوضح الغرض:

```س
# غير واضح
قالب<نوع ت> دالة معالجة(ت س) ت

# أوضح
قالب<نوع عنصر> دالة معالجة_عنصر(عنصر قيمة) عنصر

# للمفتاح والقيمة في خريطة
قالب<نوع مفتاح، نوع قيمة> دالة أضف(مفتاح م، قيمة ق)
```

### 2. وثّق القيود على أنواع القالب

اكتب تعليقات توضح ما الذي يجب أن يدعمه النوع:

```س
# هذا القالب يتطلب نوعاً يدعم عملية المقارنة >
قالب<نوع ت> دالة أكبر(ت أ، ت ب) ت
    إذا(أ > ب)
        ارجع أ
    نهاية
    ارجع ب
نهاية
```

### 3. اختبر مع أنواع متعددة

دائماً اختبر دوال القوالب مع أنواع مختلفة للتأكد من صحتها:

```س
دالة اختبر_أكبر()
    # اختبار مع أرقام
    متغير ن1 = أكبر<رقم>(10، 20)
    تحقق(ن1 == 20)
    
    # اختبار مع أرقام عشرية
    متغير ن2 = أكبر<عشري>(3.14، 2.71)
    تحقق(ن2 == 3.14)
    
    # اختبار مع نصوص
    متغير ن3 = أكبر<نص>("ب"، "أ")
    تحقق(ن3 == "ب")
نهاية
```

### 4. تجنب التعقيد الزائد

لا تُبالغ في استخدام القوالب. إذا كان الكود سيُستخدم مع نوع واحد فقط، اكتب دالة عادية.

## الأخطاء الشائعة

### 1. نسيان تحديد النوع عند الاستدعاء

```س
# خطأ - النوع غير محدد
أكبر(10، 20)

# صحيح
أكبر<رقم>(10، 20)
```

### 2. استخدام عمليات غير مدعومة

```س
# خطأ - ليس كل الأنواع تدعم الجمع
قالب<نوع ت> دالة مجموع(ت أ، ت ب) ت
    ارجع أ + ب  # قد يفشل مع بعض الأنواع
نهاية

# استدعاء مع نوع لا يدعم الجمع سيُسبب خطأ
```

### 3. عدم تطابق الأنواع

```س
# خطأ - الأنواع يجب أن تتطابق
أكبر<رقم>(10، 3.14)  # 3.14 ليس رقماً صحيحاً

# صحيح
أكبر<عشري>(10.0، 3.14)
```

## ملخص

دوال القوالب في لغة ص تُمكّنك من:

- كتابة كود عام يعمل مع أنواع متعددة
- تقليل التكرار وتسهيل الصيانة
- بناء مكتبات قوية ومرنة
- الحفاظ على أمان الأنواع والأداء

تدرّب على الأمثلة المذكورة وحاول تطبيقها في مشاريعك. مع الممارسة، ستجد القوالب أداة لا غنى عنها في برمجتك!
