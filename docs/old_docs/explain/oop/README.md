```

يوم 3-4: الكائنات + البناة
```

## 📖 دليل سريع

### الكلمات المفتاحية الأساسية

| الكلمة | الاستخدام | مثال |
|--------|----------|------|
| `صنف` | تعريف صنف جديد | `صنف سيارة` |
| `نهاية` | إنهاء كتلة الكود | `نهاية` |
| `جديد` | إنشاء كائن | `جديد سيارة()` |
| `باني` | تعريف الباني | `باني(...)` |
| `يرث` | الوراثة من صنف | `صنف سيارة يرث مركبة` |
| `دالة` | تعريف دالة | `دالة تشغيل()` |
| `ارجع` | إرجاع قيمة | `ارجع القيمة` |

### أنواع البيانات

| النوع | الوصف | مثال |
|-------|-------|------|
| `رقم` | عدد صحيح | `رقم العمر` |
| `عشري` | عدد عشري | `عشري السعر` |
| `نص` | سلسلة نصية | `نص الاسم` |
| `منطقي` | قيمة منطقية | `منطقي نشط` |

### بنية الصنف الأساسية

```
صنف اسم_الصنف
    # الحقول
    نوع اسم_الحقل
    
    # الباني
    باني(المعاملات)
        # تهيئة الحقول
    نهاية
    
    # الدوال
    دالة نوع_الإرجاع اسم_الدالة(المعاملات)
        # الكود
    نهاية
نهاية
```
