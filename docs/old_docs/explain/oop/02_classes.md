# الأصناف في لغة ص - الدليل الشامل

## ما هو الصنف؟

الصنف هو الوحدة الأساسية في البرمجة الكائنية، وهو بمثابة القالب أو المخطط الذي نستخدمه لإنشاء الكائنات. يمكنك تشبيه الصنف بالقالب الذي يُستخدم في صناعة الحلوى: القالب نفسه ليس حلوى، لكنه يُحدد شكل الحلوى التي ستُصنع منه. وبنفس الطريقة، الصنف يُحدد خصائص وسلوكيات الكائنات التي ستُنشأ منه، لكنه ليس كائناً بحد ذاته.

عندما تُنشئ صنفاً، فأنت تُعرّف نوعاً جديداً من البيانات خاصاً ببرنامجك. هذا النوع يُجمّع البيانات المرتبطة (الحقول) مع العمليات التي تُنفّذ عليها (الدوال) في وحدة واحدة متماسكة. هذا التجميع يُسمّى "التغليف" وهو أحد أهم مبادئ البرمجة الكائنية.

## تعريف الصنف في لغة ص

لتعريف صنف في لغة ص، نستخدم الكلمة المفتاحية `صنف` متبوعة باسم الصنف، ثم نكتب محتوياته، وننهيه بالكلمة المفتاحية `نهاية`. الصيغة العامة هي:

```
صنف اسم_الصنف
    # الحقول (البيانات)
    # الدوال (السلوكيات)
نهاية
```

### مثال بسيط: صنف النقطة

لنبدأ بمثال بسيط جداً - صنف يُمثّل نقطة في المستوى الديكارتي:

```
صنف نقطة
    رقم س
    رقم ص
نهاية
```

هذا الصنف البسيط يُعرّف نوعاً جديداً اسمه `نقطة`، ولكل نقطة إحداثيان: `س` (المحور الأفقي) و`ص` (المحور العمودي).

### مثال أكثر اكتمالاً: صنف الطالب

```
صنف طالب
    نص الاسم
    رقم الرقم_الجامعي
    عشري المعدل
    نص التخصص
    
    دالة طباعة_المعلومات()
        اطبع_سطر("الاسم: " + الاسم)
        اطبع_سطر("الرقم الجامعي: " + الرقم_الجامعي)
        اطبع_سطر("المعدل: " + المعدل)
        اطبع_سطر("التخصص: " + التخصص)
    نهاية
    
    دالة منطقي متفوق()
        إذا المعدل >= 3.5
            ارجع صحيح
        نهاية
        ارجع خطأ
    نهاية
نهاية
```

## قواعد تسمية الأصناف

اختيار أسماء جيدة للأصناف يُحسّن قابلية قراءة الكود بشكل كبير. إليك بعض القواعد والإرشادات:

**القاعدة الأولى: الوضوح والدلالة**
اسم الصنف يجب أن يصف بوضوح ما يُمثّله. استخدم أسماء ذات معنى مثل `سيارة`، `موظف`، `حساب_بنكي` بدلاً من أسماء غامضة مثل `ص1` أو `بيانات`.

**القاعدة الثانية: استخدام الأسماء (وليس الأفعال)**
الأصناف تُمثّل أشياء أو مفاهيم، لذا يجب أن تكون أسماؤها أسماء وليس أفعال. استخدم `حاسبة` بدلاً من `احسب`، و`مستخدم` بدلاً من `استخدم`.

**القاعدة الثالثة: المفرد**
عادةً ما نُسمّي الصنف بصيغة المفرد لأن كل كائن يُمثّل نسخة واحدة. استخدم `كتاب` بدلاً من `كتب`، و`طالب` بدلاً من `طلاب`.

## أنواع أعضاء الصنف

يتكون الصنف من عدة أنواع من الأعضاء:

### 1. الحقول (Fields)

الحقول هي المتغيرات التي تُخزّن حالة الكائن. كل كائن يُنشأ من الصنف يمتلك نسخته الخاصة من هذه الحقول.

```
صنف مستطيل
    رقم العرض
    رقم الارتفاع
نهاية
```

### 2. الدوال (Methods)

الدوال تُحدد السلوكيات التي يستطيع الكائن تنفيذها. يمكن للدوال الوصول إلى حقول الكائن وتعديلها.

```
صنف مستطيل
    رقم العرض
    رقم الارتفاع
    
    دالة رقم المساحة()
        ارجع العرض * الارتفاع
    نهاية
    
    دالة رقم المحيط()
        ارجع 2 * (العرض + الارتفاع)
    نهاية
نهاية
```

### 3. البناة (Constructors)

الباني هو دالة خاصة تُستدعى تلقائياً عند إنشاء كائن جديد. يُستخدم لتهيئة حقول الكائن.

```
صنف مستطيل
    رقم العرض
    رقم الارتفاع
    
    باني(رقم ع، رقم ا)
        العرض = ع
        الارتفاع = ا
    نهاية
نهاية
```

## مثال شامل: نظام إدارة المكتبة

لنُنشئ مثالاً عملياً يوضح استخدام الأصناف في سيناريو واقعي:

```
صنف كتاب
    نص العنوان
    نص المؤلف
    نص الرقم_الدولي
    رقم سنة_النشر
    رقم عدد_الصفحات
    منطقي متاح
    
    باني(نص عنوان، نص مؤلف، نص رقم_دولي، رقم سنة، رقم صفحات)
        العنوان = عنوان
        المؤلف = مؤلف
        الرقم_الدولي = رقم_دولي
        سنة_النشر = سنة
        عدد_الصفحات = صفحات
        متاح = صحيح
    نهاية
    
    دالة استعارة()
        إذا متاح
            متاح = خطأ
            اطبع_سطر("تمت استعارة الكتاب: " + العنوان)
        وإلا
            اطبع_سطر("الكتاب غير متاح حالياً")
        نهاية
    نهاية
    
    دالة إرجاع()
        متاح = صحيح
        اطبع_سطر("تم إرجاع الكتاب: " + العنوان)
    نهاية
    
    دالة عرض_المعلومات()
        اطبع_سطر("═══════════════════════════════")
        اطبع_سطر("العنوان: " + العنوان)
        اطبع_سطر("المؤلف: " + المؤلف)
        اطبع_سطر("ISBN: " + الرقم_الدولي)
        اطبع_سطر("سنة النشر: " + سنة_النشر)
        اطبع_سطر("عدد الصفحات: " + عدد_الصفحات)
        إذا متاح
            اطبع_سطر("الحالة: متاح للاستعارة")
        وإلا
            اطبع_سطر("الحالة: مُستعار")
        نهاية
        اطبع_سطر("═══════════════════════════════")
    نهاية
نهاية

دالة رئيسية()
    # إنشاء كتب جديدة
    كتاب كتاب1 = جديد كتاب("البرمجة بلغة ص"، "أحمد محمد"، "978-1234567890"، 2024، 350)
    كتاب كتاب2 = جديد كتاب("الذكاء الاصطناعي"، "سارة علي"، "978-0987654321"، 2023، 500)
    
    # عرض معلومات الكتب
    كتاب1.عرض_المعلومات()
    كتاب2.عرض_المعلومات()
    
    # استعارة كتاب
    كتاب1.استعارة()
    كتاب1.استعارة()  # محاولة استعارة كتاب مُستعار
    
    # إرجاع الكتاب
    كتاب1.إرجاع()
    كتاب1.استعارة()  # الآن يمكن استعارته
    
    ارجع 0
نهاية
```

## الأصناف المتعددة في ملف واحد

يمكنك تعريف عدة أصناف في ملف واحد، وهذا مفيد عندما تكون الأصناف مرتبطة ببعضها:

```
صنف عنوان
    نص المدينة
    نص الشارع
    نص رقم_المبنى
    
    باني(نص مدينة، نص شارع، نص رقم)
        المدينة = مدينة
        الشارع = شارع
        رقم_المبنى = رقم
    نهاية
    
    دالة نص النص_الكامل()
        ارجع رقم_المبنى + "، " + الشارع + "، " + المدينة
    نهاية
نهاية

صنف شركة
    نص الاسم
    عنوان المقر
    رقم عدد_الموظفين
    
    باني(نص اسم، عنوان مقر)
        الاسم = اسم
        المقر = مقر
        عدد_الموظفين = 0
    نهاية
    
    دالة عرض_المعلومات()
        اطبع_سطر("اسم الشركة: " + الاسم)
        اطبع_سطر("العنوان: " + المقر.النص_الكامل())
        اطبع_سطر("عدد الموظفين: " + عدد_الموظفين)
    نهاية
نهاية
```

## نصائح للمبتدئين

**ابدأ بسيطاً**: لا تحاول إنشاء أصناف معقدة في البداية. ابدأ بأصناف بسيطة تحتوي على عدد قليل من الحقول والدوال.

**فكّر في الواقع**: عندما تُصمم صنفاً، فكّر في الشيء الذي يُمثّله في العالم الحقيقي. ما هي خصائصه؟ ما هي الأفعال التي يستطيع القيام بها؟

**اجعل كل صنف مسؤولاً عن شيء واحد**: تجنب إنشاء أصناف ضخمة تفعل كل شيء. بدلاً من ذلك، قسّم المسؤوليات على عدة أصناف صغيرة.

**استخدم أسماء واضحة**: الأسماء الجيدة تجعل الكود يشرح نفسه بنفسه.

## الخلاصة

الأصناف هي اللبنة الأساسية للبرمجة الكائنية. إتقان كتابة الأصناف يُمكّنك من بناء برامج منظمة وقابلة للصيانة. في الأقسام التالية، سنتعمق في كيفية إنشاء الكائنات من الأصناف، وكيفية استخدام الوراثة لبناء تسلسلات هرمية من الأصناف.
