# الوراثة في لغة ص - الدليل الشامل

## ما هي الوراثة؟

الوراثة (Inheritance) هي أحد الأركان الأساسية للبرمجة الكائنية، وهي آلية تُمكّن صنفاً جديداً من أن يرث خصائص وسلوكيات صنف موجود. الصنف الذي يرث يُسمّى "الصنف الابن" أو "الصنف المشتق"، والصنف الذي يُورَث منه يُسمّى "الصنف الأب" أو "الصنف الأساسي".

الوراثة تُشبه العلاقة بين الآباء والأبناء في الحياة الواقعية: الأبناء يرثون صفات آبائهم (لون العيون، الطول) لكنهم قد يكتسبون صفات إضافية خاصة بهم. بنفس الطريقة، الصنف الابن يرث حقول ودوال الصنف الأب، ويمكنه إضافة حقول ودوال جديدة أو تعديل السلوك الموروث.

## فوائد الوراثة

**إعادة استخدام الكود**: بدلاً من كتابة نفس الكود مراراً، نكتبه مرة في الصنف الأب ونرثه.

**التنظيم الهرمي**: الوراثة تُنشئ هياكل منطقية تعكس العلاقات الحقيقية بين المفاهيم.

**سهولة الصيانة**: التغيير في الصنف الأب ينعكس تلقائياً على جميع الأصناف الأبناء.

**التوسعة**: يمكن إضافة وظائف جديدة للأصناف الأبناء دون تعديل الصنف الأب.

## تعريف الوراثة في لغة ص

لتعريف صنف يرث من صنف آخر، نستخدم الكلمة المفتاحية `يرث`:

```
صنف الصنف_الابن يرث الصنف_الأب
    # حقول ودوال إضافية
نهاية
```

### مثال بسيط

```
صنف حيوان
    نص الاسم
    رقم العمر
    
    باني(نص اسم، رقم عمر)
        الاسم = اسم
        العمر = عمر
    نهاية
    
    دالة صوت()
        اطبع_سطر("يُصدر صوتاً")
    نهاية
    
    دالة معلومات()
        اطبع_سطر("الاسم: " + الاسم)
        اطبع_سطر("العمر: " + العمر + " سنة")
    نهاية
نهاية

صنف قطة يرث حيوان
    نص اللون
    
    باني(نص اسم، رقم عمر، نص لون)
        الاسم = اسم
        العمر = عمر
        اللون = لون
    نهاية
    
    دالة صوت()
        اطبع_سطر("مياو! 🐱")
    نهاية
نهاية

صنف كلب يرث حيوان
    نص السلالة
    
    باني(نص اسم، رقم عمر، نص سلالة)
        الاسم = اسم
        العمر = عمر
        السلالة = سلالة
    نهاية
    
    دالة صوت()
        اطبع_سطر("هاو هاو! 🐕")
    نهاية
نهاية

دالة رئيسية()
    قطة ق = جديد قطة("ميمي"، 3، "أبيض")
    كلب ك = جديد كلب("بوبي"، 5، "جيرمن شيبرد")
    
    اطبع_سطر("=== القطة ===")
    ق.معلومات()  # موروثة من حيوان
    ق.صوت()      # مُعاد تعريفها
    
    اطبع_سطر("\n=== الكلب ===")
    ك.معلومات()  # موروثة من حيوان
    ك.صوت()      # مُعاد تعريفها
    
    ارجع 0
نهاية
```

## ما الذي يُورَث؟

عندما يرث صنف من صنف آخر، يرث:

### 1. الحقول

```
صنف مركبة
    نص الماركة
    نص الموديل
    رقم سنة_الصنع
نهاية

صنف سيارة يرث مركبة
    رقم عدد_الأبواب
    # السيارة ترث: الماركة، الموديل، سنة_الصنع
    # وتُضيف: عدد_الأبواب
نهاية

صنف دراجة_نارية يرث مركبة
    نص نوع_المحرك
    # الدراجة ترث: الماركة، الموديل، سنة_الصنع
    # وتُضيف: نوع_المحرك
نهاية
```

### 2. الدوال

```
صنف شكل
    دالة عرض()
        اطبع_سطر("هذا شكل هندسي")
    نهاية
    
    دالة تحية()
        اطبع_سطر("مرحباً!")
    نهاية
نهاية

صنف مربع يرث شكل
    رقم الضلع
    
    باني(رقم ض)
        الضلع = ض
    نهاية
    
    # المربع يرث دالة تحية()
    # ويُعيد تعريف دالة عرض()
    دالة عرض()
        اطبع_سطر("هذا مربع بضلع " + الضلع)
    نهاية
    
    # ويُضيف دوالاً جديدة
    دالة رقم المساحة()
        ارجع الضلع * الضلع
    نهاية
نهاية

دالة رئيسية()
    مربع م = جديد مربع(5)
    م.تحية()  # موروثة كما هي
    م.عرض()   # مُعاد تعريفها
    اطبع_سطر("المساحة: " + م.المساحة())  # جديدة
    ارجع 0
نهاية
```

## إعادة تعريف الدوال (Overriding)

الصنف الابن يمكنه إعادة تعريف دوال الصنف الأب لتغيير سلوكها:

```
صنف موظف
    نص الاسم
    عشري الراتب_الأساسي
    
    باني(نص اسم، عشري راتب)
        الاسم = اسم
        الراتب_الأساسي = راتب
    نهاية
    
    دالة عشري حساب_الراتب()
        ارجع الراتب_الأساسي
    نهاية
    
    دالة عرض_الراتب()
        اطبع_سطر(الاسم + " - الراتب: " + حساب_الراتب() + " ريال")
    نهاية
نهاية

صنف مدير يرث موظف
    عشري بدل_الإدارة
    
    باني(نص اسم، عشري راتب، عشري بدل)
        الاسم = اسم
        الراتب_الأساسي = راتب
        بدل_الإدارة = بدل
    نهاية
    
    # إعادة تعريف حساب الراتب لإضافة بدل الإدارة
    دالة عشري حساب_الراتب()
        ارجع الراتب_الأساسي + بدل_الإدارة
    نهاية
نهاية

صنف مبرمج يرث موظف
    عشري بدل_فني
    رقم ساعات_إضافية
    
    باني(نص اسم، عشري راتب، عشري بدل، رقم ساعات)
        الاسم = اسم
        الراتب_الأساسي = راتب
        بدل_فني = بدل
        ساعات_إضافية = ساعات
    نهاية
    
    # إعادة تعريف حساب الراتب لإضافة البدل والساعات الإضافية
    دالة عشري حساب_الراتب()
        عشري أجر_الساعة = 50.0
        ارجع الراتب_الأساسي + بدل_فني + (ساعات_إضافية * أجر_الساعة)
    نهاية
نهاية

دالة رئيسية()
    موظف م1 = جديد موظف("أحمد"، 5000)
    مدير م2 = جديد مدير("خالد"، 8000، 3000)
    مبرمج م3 = جديد مبرمج("سارة"، 7000، 2000، 20)
    
    اطبع_سطر("═══════════════════════════════════")
    اطبع_سطر("         كشف الرواتب              ")
    اطبع_سطر("═══════════════════════════════════")
    
    م1.عرض_الراتب()
    م2.عرض_الراتب()
    م3.عرض_الراتب()
    
    ارجع 0
نهاية
```

## نصائح لاستخدام الوراثة

**استخدم الوراثة لعلاقات "هو نوع من"**: السيارة "هي نوع من" المركبات. لكن المحرك ليس نوعاً من السيارة، بل جزء منها.

**لا تُفرط في استخدام الوراثة**: سلاسل الوراثة العميقة تُعقّد الكود. حاول ألا تتجاوز 3-4 مستويات.

**صمّم للتوسعة**: عند تصميم الصنف الأب، فكّر في ما قد تحتاجه الأصناف الأبناء.

## الخلاصة

الوراثة أداة قوية لإعادة استخدام الكود وتنظيمه. فهم متى وكيف تستخدمها يُحسّن جودة برامجك بشكل كبير. في القسم التالي، سنتعرف على تعدد الأشكال وكيف يُكمّل الوراثة.
