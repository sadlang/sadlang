# البناة في لغة ص - الدليل الشامل

## ما هو الباني؟

الباني (Constructor) هو دالة خاصة جداً في الصنف، تُستدعى تلقائياً عند إنشاء كائن جديد. وظيفته الأساسية هي تهيئة الكائن وضبط قيمه الأولية لضمان أن الكائن يبدأ في حالة صالحة ومتسقة.

تخيّل أنك تشتري هاتفاً جديداً من المصنع. عند تشغيله لأول مرة، يمر بعملية إعداد أولية: ضبط اللغة، تعيين المنطقة الزمنية، إنشاء حساب المستخدم، وغيرها. هذه العملية تُشبه ما يفعله الباني - يُجهّز الكائن للاستخدام.

## تعريف الباني في لغة ص

في لغة ص، نستخدم الكلمة المفتاحية `باني` لتعريف باني الصنف. الصيغة العامة:

```
صنف اسم_الصنف
    # الحقول
    
    باني(المعاملات)
        # كود التهيئة
    نهاية
نهاية
```

### مثال بسيط

```
صنف مستطيل
    رقم العرض
    رقم الارتفاع
    
    باني(رقم ع، رقم ا)
        العرض = ع
        الارتفاع = ا
    نهاية
    
    دالة رقم المساحة()
        ارجع العرض * الارتفاع
    نهاية
نهاية

دالة رئيسية()
    مستطيل م = جديد مستطيل(10، 5)
    اطبع_سطر("المساحة: " + م.المساحة())  # سيطبع: 50
    ارجع 0
نهاية
```

## فوائد استخدام الباني

### 1. ضمان التهيئة الصحيحة

بدون الباني، قد يُنشئ المستخدم كائناً دون تعيين قيم لحقوله، مما يؤدي لسلوك غير متوقع:

```
# بدون باني - خطير!
صنف شخص_بدون_باني
    نص الاسم
    رقم العمر
نهاية

# مع باني - آمن!
صنف شخص_مع_باني
    نص الاسم
    رقم العمر
    
    باني(نص اسم، رقم عمر)
        الاسم = اسم
        العمر = عمر
    نهاية
نهاية
```

### 2. التحقق من صحة البيانات

يمكن للباني التحقق من صحة البيانات قبل تعيينها:

```
صنف حساب_مصرفي
    نص رقم_الحساب
    عشري الرصيد
    
    باني(نص رقم، عشري رصيد_أولي)
        # التحقق من صحة رقم الحساب
        إذا طول(رقم) < 10
            اطبع_سطر("خطأ: رقم الحساب يجب أن يكون 10 أرقام على الأقل")
            رقم_الحساب = "غير صالح"
        وإلا
            رقم_الحساب = رقم
        نهاية
        
        # التحقق من الرصيد الأولي
        إذا رصيد_أولي < 0
            اطبع_سطر("تحذير: الرصيد الأولي لا يمكن أن يكون سالباً")
            الرصيد = 0
        وإلا
            الرصيد = رصيد_أولي
        نهاية
    نهاية
نهاية
```

### 3. تبسيط إنشاء الكائنات

بدلاً من عدة أسطر لتعيين كل حقل، سطر واحد يكفي:

```
# بدون باني - مطول
شخص س = جديد شخص()
س.الاسم = "أحمد"
س.العمر = 25
س.المدينة = "الرياض"
س.البريد = "ahmed@example.com"

# مع باني - مختصر
شخص س = جديد شخص("أحمد"، 25، "الرياض"، "ahmed@example.com")
```

## أنماط شائعة للبناة

### النمط الأول: باني بسيط

يأخذ قيماً ويُعيّنها مباشرة للحقول:

```
صنف نقطة
    رقم س
    رقم ص
    
    باني(رقم إحداثي_س، رقم إحداثي_ص)
        س = إحداثي_س
        ص = إحداثي_ص
    نهاية
نهاية
```

### النمط الثاني: باني مع قيم افتراضية

يُعيّن قيماً افتراضية لبعض الحقول:

```
صنف اتصال_قاعدة_بيانات
    نص المضيف
    رقم المنفذ
    نص اسم_المستخدم
    نص كلمة_المرور
    منطقي متصل
    
    باني(نص مضيف، نص مستخدم، نص كلمة_سر)
        المضيف = مضيف
        المنفذ = 3306  # المنفذ الافتراضي
        اسم_المستخدم = مستخدم
        كلمة_المرور = كلمة_سر
        متصل = خطأ  # غير متصل افتراضياً
    نهاية
نهاية
```

### النمط الثالث: باني مع حسابات

يُجري حسابات لتعيين قيم الحقول:

```
صنف دائرة
    عشري نصف_القطر
    عشري القطر
    عشري المحيط
    عشري المساحة
    
    باني(عشري نق)
        نصف_القطر = نق
        القطر = نق * 2
        المحيط = 2 * 3.14159 * نق
        المساحة = 3.14159 * نق * نق
    نهاية
    
    دالة عرض_المعلومات()
        اطبع_سطر("نصف القطر: " + نصف_القطر)
        اطبع_سطر("القطر: " + القطر)
        اطبع_سطر("المحيط: " + المحيط)
        اطبع_سطر("المساحة: " + المساحة)
    نهاية
نهاية

دالة رئيسية()
    دائرة د = جديد دائرة(5)
    د.عرض_المعلومات()
    ارجع 0
نهاية
```

### النمط الرابع: باني مع إنشاء كائنات داخلية

يُنشئ كائنات أخرى كجزء من التهيئة:

```
صنف تاريخ
    رقم اليوم
    رقم الشهر
    رقم السنة
    
    باني(رقم ي، رقم ش، رقم س)
        اليوم = ي
        الشهر = ش
        السنة = س
    نهاية
    
    دالة نص صيغة_نصية()
        ارجع اليوم + "/" + الشهر + "/" + السنة
    نهاية
نهاية

صنف فاتورة
    رقم رقم_الفاتورة
    تاريخ تاريخ_الإصدار
    عشري المبلغ
    نص العميل
    
    باني(رقم رقم، نص عميل، عشري مبلغ)
        رقم_الفاتورة = رقم
        العميل = عميل
        المبلغ = مبلغ
        # إنشاء تاريخ اليوم تلقائياً
        تاريخ_الإصدار = جديد تاريخ(15، 6، 2024)
    نهاية
    
    دالة طباعة()
        اطبع_سطر("══════════════════════════════")
        اطبع_سطر("         فاتورة              ")
        اطبع_سطر("══════════════════════════════")
        اطبع_سطر("رقم الفاتورة: " + رقم_الفاتورة)
        اطبع_سطر("التاريخ: " + تاريخ_الإصدار.صيغة_نصية())
        اطبع_سطر("العميل: " + العميل)
        اطبع_سطر("المبلغ: " + المبلغ + " ريال")
        اطبع_سطر("══════════════════════════════")
    نهاية
نهاية

دالة رئيسية()
    فاتورة ف = جديد فاتورة(1001، "شركة التقنية المتقدمة"، 15000.50)
    ف.طباعة()
    ارجع 0
نهاية
```

## مثال شامل: نظام إدارة الموظفين

```
صنف قسم
    نص الاسم
    رقم الميزانية
    رقم عدد_الموظفين
    
    باني(نص اسم، رقم ميزانية)
        الاسم = اسم
        الميزانية = ميزانية
        عدد_الموظفين = 0
    نهاية
    
    دالة إضافة_موظف()
        عدد_الموظفين = عدد_الموظفين + 1
    نهاية
نهاية

صنف موظف
    رقم الرقم_الوظيفي
    نص الاسم_الكامل
    نص المسمى_الوظيفي
    عشري الراتب
    قسم القسم
    تاريخ تاريخ_التعيين
    
    باني(رقم رقم، نص اسم، نص مسمى، عشري راتب، قسم قسم_العمل)
        الرقم_الوظيفي = رقم
        الاسم_الكامل = اسم
        المسمى_الوظيفي = مسمى
        
        # التحقق من الراتب
        إذا راتب < 3000
            اطبع_سطر("تحذير: الراتب أقل من الحد الأدنى، تم تعيينه للحد الأدنى")
            الراتب = 3000
        وإلا
            الراتب = راتب
        نهاية
        
        القسم = قسم_العمل
        قسم_العمل.إضافة_موظف()
        
        # تاريخ التعيين هو تاريخ اليوم
        تاريخ_التعيين = جديد تاريخ(1، 1، 2024)
    نهاية
    
    دالة عرض_البطاقة_الوظيفية()
        اطبع_سطر("╔═════════════════════════════════════════╗")
        اطبع_سطر("║        البطاقة الوظيفية               ║")
        اطبع_سطر("╠═════════════════════════════════════════╣")
        اطبع_سطر("║ الرقم الوظيفي: " + الرقم_الوظيفي)
        اطبع_سطر("║ الاسم: " + الاسم_الكامل)
        اطبع_سطر("║ المسمى: " + المسمى_الوظيفي)
        اطبع_سطر("║ القسم: " + القسم.الاسم)
        اطبع_سطر("║ الراتب: " + الراتب + " ريال")
        اطبع_سطر("║ تاريخ التعيين: " + تاريخ_التعيين.صيغة_نصية())
        اطبع_سطر("╚═════════════════════════════════════════╝")
    نهاية
    
    دالة ترقية(نص مسمى_جديد، عشري زيادة)
        المسمى_الوظيفي = مسمى_جديد
        الراتب = الراتب + زيادة
        اطبع_سطر("تمت ترقية " + الاسم_الكامل + " إلى " + مسمى_جديد)
        اطبع_سطر("الراتب الجديد: " + الراتب + " ريال")
    نهاية
نهاية

دالة رئيسية()
    # إنشاء الأقسام
    قسم قسم_تقنية = جديد قسم("تقنية المعلومات"، 500000)
    قسم قسم_مالية = جديد قسم("الشؤون المالية"، 300000)
    
    # إنشاء الموظفين
    موظف م1 = جديد موظف(1001، "محمد العلي"، "مبرمج"، 12000، قسم_تقنية)
    موظف م2 = جديد موظف(1002، "سارة الأحمد"، "محلل بيانات"، 10000، قسم_تقنية)
    موظف م3 = جديد موظف(1003، "خالد السالم"، "محاسب"، 9000، قسم_مالية)
    
    # عرض بطاقات الموظفين
    م1.عرض_البطاقة_الوظيفية()
    م2.عرض_البطاقة_الوظيفية()
    م3.عرض_البطاقة_الوظيفية()
    
    # عرض معلومات الأقسام
    اطبع_سطر("\n=== معلومات الأقسام ===")
    اطبع_سطر(قسم_تقنية.الاسم + ": " + قسم_تقنية.عدد_الموظفين + " موظفين")
    اطبع_سطر(قسم_مالية.الاسم + ": " + قسم_مالية.عدد_الموظفين + " موظفين")
    
    # ترقية موظف
    اطبع_سطر("\n=== الترقيات ===")
    م1.ترقية("مبرمج أول"، 3000)
    م1.عرض_البطاقة_الوظيفية()
    
    ارجع 0
نهاية
```

## أخطاء شائعة مع البناة

### الخطأ الأول: نسيان تهيئة بعض الحقول

```
# خاطئ - نسيان تهيئة الرصيد
صنف حساب_خاطئ
    نص الاسم
    عشري الرصيد
    
    باني(نص اسم)
        الاسم = اسم
        # نسينا تهيئة الرصيد!
    نهاية
نهاية

# صحيح - تهيئة جميع الحقول
صنف حساب_صحيح
    نص الاسم
    عشري الرصيد
    
    باني(نص اسم)
        الاسم = اسم
        الرصيد = 0  # تهيئة صريحة
    نهاية
نهاية
```

### الخطأ الثاني: عدم التحقق من المدخلات

```
# خاطئ - قبول أي قيمة
صنف مستخدم_خاطئ
    نص الاسم
    رقم العمر
    
    باني(نص اسم، رقم عمر)
        الاسم = اسم
        العمر = عمر  # ماذا لو كان سالباً؟
    نهاية
نهاية

# صحيح - التحقق من القيم
صنف مستخدم_صحيح
    نص الاسم
    رقم العمر
    
    باني(نص اسم، رقم عمر)
        إذا طول(اسم) == 0
            اطبع_سطر("خطأ: الاسم لا يمكن أن يكون فارغاً")
            الاسم = "غير معروف"
        وإلا
            الاسم = اسم
        نهاية
        
        إذا عمر < 0 أو عمر > 150
            اطبع_سطر("خطأ: العمر غير صالح")
            العمر = 0
        وإلا
            العمر = عمر
        نهاية
    نهاية
نهاية
```

## متى تستخدم الباني؟

**استخدم الباني عندما:**
- تحتاج لضمان أن الكائن يبدأ في حالة صالحة
- هناك حقول إلزامية يجب تعيينها عند الإنشاء
- تحتاج للتحقق من صحة البيانات الأولية
- تحتاج لإجراء حسابات أو إعدادات أولية

## الخلاصة

الباني هو أداة قوية لضمان أن الكائنات تُنشأ بشكل صحيح. استخدام البناة بشكل فعّال يقلل من الأخطاء ويجعل الكود أكثر أماناً وقابلية للصيانة. في القسم التالي، سنتعرف على الحقول بمزيد من التفصيل.
