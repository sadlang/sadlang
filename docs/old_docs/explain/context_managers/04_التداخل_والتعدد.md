# 🔗 مديرو السياق المتداخلون والمتعددون

## مقدمة

في البرمجة الواقعية، غالباً ما نحتاج للتعامل مع عدة موارد في نفس الوقت. لغة ص توفر طرقاً أنيقة للتعامل مع مديري سياق متعددين ومتداخلين.

## مديرو السياق المتداخلون

### التداخل البسيط

عندما تحتاج لفتح ملفين معاً، يمكنك تداخل كتل `باستخدام`:

```s
دالة نسخ_ملف(نص المصدر، نص الوجهة)
    باستخدام افتح(المصدر، "قراءة") كـ ملف_المصدر
        باستخدام افتح(الوجهة، "كتابة") كـ ملف_الوجهة
            نص المحتوى = ملف_المصدر.اقرأ()
            ملف_الوجهة.اكتب(المحتوى)
        نهاية_استخدام
    نهاية_استخدام
نهاية
```

### ترتيب الفتح والإغلاق

في التداخل، الترتيب مهم جداً:
- الموارد تُفتح من الخارج إلى الداخل
- الموارد تُغلق من الداخل إلى الخارج (عكس الفتح)

```s
دالة توضيح_الترتيب()
    اطبع("1: قبل الأول")
    باستخدام جديد مسجل("الأول") كـ أ
        اطبع("2: داخل الأول، قبل الثاني")
        باستخدام جديد مسجل("الثاني") كـ ب
            اطبع("3: داخل الثاني، قبل الثالث")
            باستخدام جديد مسجل("الثالث") كـ ج
                اطبع("4: داخل الثالث")
            نهاية_استخدام
            اطبع("5: بعد الثالث")
        نهاية_استخدام
        اطبع("6: بعد الثاني")
    نهاية_استخدام
    اطبع("7: بعد الأول")
نهاية

# المخرجات:
# 1: قبل الأول
# 🔵 دخول: الأول
# 2: داخل الأول، قبل الثاني
# 🔵 دخول: الثاني
# 3: داخل الثاني، قبل الثالث
# 🔵 دخول: الثالث
# 4: داخل الثالث
# 🟢 خروج: الثالث
# 5: بعد الثالث
# 🟢 خروج: الثاني
# 6: بعد الثاني
# 🟢 خروج: الأول
# 7: بعد الأول
```

## التعامل مع الأخطاء في التداخل

### الخطأ في المورد الداخلي

```s
دالة مثال_خطأ_داخلي()
    باستخدام جديد مورد("الخارجي") كـ خارجي
        اطبع("الخارجي مفتوح")
        
        حاول
            باستخدام جديد مورد("الداخلي") كـ داخلي
                اطبع("الداخلي مفتوح")
                ارفع خطأ("خطأ متعمد!")
            نهاية_استخدام
        التقط خطأ كـ خ
            اطبع("التقطنا الخطأ: " + خ.الرسالة)
            # الداخلي أُغلق تلقائياً قبل الوصول هنا
        نهاية
        
        اطبع("الخارجي لا يزال مفتوحاً")
    نهاية_استخدام
    # الخارجي أُغلق الآن
نهاية
```

### ضمان إغلاق جميع الموارد

```s
دالة عملية_آمنة()

                معالجة_معقدة(ف1، ف2)

    التقط خطأ كـ خ
        # الملفان أُغلقا تلقائياً حتى مع الخطأ

    نهاية
نهاية
```

## أنماط متقدمة

### مدير سياق يدير مديرين آخرين

```s
صنف مدير_موارد_متعددة
    قائمة الموارد = []
    قائمة المديرون = []
    
    دالة أضف(متغير مدير)
        هذا.المديرون.أضف(مدير)
        إرجاع هذا  # للسلسلة
    نهاية
    
    دالة __دخول__()
        # فتح جميع المديرين بالترتيب
        لكل مدير في هذا.المديرون
            متغير مورد = مدير.__دخول__()
            هذا.الموارد.أضف(مورد)
        نهاية
        إرجاع هذا.الموارد
    نهاية
    
    دالة __خروج__()
        # إغلاق بالترتيب العكسي
        متغير مديرون_معكوسة = اعكس(هذا.المديرون)
        لكل مدير في مديرون_معكوسة
            حاول
                مدير.__خروج__()
            التقط خطأ
                # استمر في الإغلاق حتى مع الأخطاء
            نهاية
        نهاية
    نهاية
نهاية

# الاستخدام
دالة رئيسية()
    متغير مدير = جديد مدير_موارد_متعددة()
    مدير.أضف(جديد ملف_مدار("ملف1.txt"))
          .أضف(جديد ملف_مدار("ملف2.txt"))
          .أضف(جديد اتصال_شبكة("خادم"))
    
    باستخدام مدير كـ موارد
        متغير [ملف1، ملف2، اتصال] = موارد
        # استخدم الموارد الثلاثة
    نهاية_استخدام
    # جميعها أُغلقت بالترتيب الصحيح
نهاية
```

### مدير السياق المشروط

```s
صنف مدير_مشروط
```

### كومة مديري السياق

```s
صنف كومة_سياق
```

## نصائح للتداخل

### 1. لا تتداخل أكثر من اللازم

```s
# أفضل: فصل المسؤوليات
دالة معالجة_بيانات()
    متغير بيانات = قراءة_البيانات()
    متغير نتائج = تحليل_البيانات(بيانات)
    حفظ_النتائج(نتائج)
نهاية

# بدلاً من تداخل عميق واحد
```

### 2. رتب حسب الأهمية

```s
# المورد الأهم (الذي يجب أن يُغلق أخيراً) يكون الخارجي
باستخدام اتصال_قاعدة_البيانات()  # يُغلق أخيراً
    باستخدام معاملة()
        باستخدام قفل()  # يُغلق أولاً
            # العمل
        نهاية_استخدام
    نهاية_استخدام
نهاية_استخدام
```

### 3. استخدم التعليقات للتوضيح

```s
باستخدام افتح(المصدر) كـ قارئ  # مصدر البيانات
    باستخدام افتح(الوجهة) كـ كاتب  # وجهة البيانات
        # نسخ البيانات من المصدر إلى الوجهة
    نهاية_استخدام
نهاية_استخدام
```

## الخلاصة

التداخل في مديري السياق:
- يتيح إدارة موارد متعددة بأمان
- الترتيب: فتح من الخارج، إغلاق من الداخل
- الأخطاء لا تمنع الإغلاق
- يمكن إنشاء مديرين يديرون مديرين آخرين
- التداخل العميق جداً قد يشير لحاجة إعادة التصميم
