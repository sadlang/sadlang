# فهرس التوثيق - مفاهيم نظام الأنواع
## دليل شامل لمفاهيم البرمجة المتقدمة في لغة ص

---

## 📖 نظرة عامة

هذا الدليل يشرح المفاهيم الأساسية المُنفذة في نظام الأنواع للغة ص (Sad Language). كل ملف يغطي مفهوماً رئيسياً مع أمثلة عملية وتفسيرات مفصلة باللغة العربية.

---

## 📚 الملفات المتاحة

### 1. [الأنواع العامة (Generics)](01_generics.md)
**Phase 1.3.4 - مُنفذ بالكامل ✅**

تعلم كيفية كتابة كود مرن وقابل لإعادة الاستخدام مع الحفاظ على أمان الأنواع.

**المواضيع المُغطاة:**
- ما هي Generics ولماذا نحتاجها؟
- معاملات الأنواع (Type Parameters)
- القيود على الأنواع (Type Constraints)
- التباين (Variance)
- Monomorphization
- أمثلة عملية: صندوق عام، قائمة مرتبطة

**الاستخدامات:**
```sad
# صنف عام
صنف صندوق<T> {
    متغير المحتوى: T
}

# دالة عامة
دالة الأكبر<T: قابل_للمقارنة>(أ: T، ب: T) -> T
```

---

### 2. [الأنواع الاتحادية (Union Types)](02_union_types.md)
**Phase 1.3.5.0 - مُنفذ بالكامل ✅**

تعلم كيفية التعبير عن قيم يمكن أن تكون من أنواع متعددة بطريقة آمنة.

**المواضيع المُغطاة:**
- ما هي Union Types؟
- البدائل (Alternatives)
- Type Narrowing (تضييق النوع)
- Optional Types (الأنواع الاختيارية)
- عمليات Set (∪، ∩، −)
- أمثلة عملية: Result Type، JSON Value

**الاستخدامات:**
```sad
# Union type بسيط
متغير القيمة: رقم | نص

# Optional type
متغير الاسم: نص?  # نص | لاشيء

# Result type
نوع النتيجة<T، E> = نجاح<T> | فشل<E>
```

---

### 3. [مطابقة الأنماط (Pattern Matching)](03_pattern_matching.md)
**Phase 1.3.5.3 - قيد التنفيذ 🔄**

تعلم كيفية فحص وتفكيك البيانات المعقدة بطريقة معبّرة وآمنة.

**المواضيع المُغطاة:**
- ما هي Pattern Matching؟
- أنواع الأنماط (Literal، Variable، Constructor، ...)
- Guards (الحراس)
- Exhaustiveness Checking
- أمثلة عملية: Expression Evaluator، State Machine

**الاستخدامات:**
```sad
# مطابقة بسيطة
طابق القيمة {
    0 => "صفر"
    1 => "واحد"
    _ => "أخرى"
}

# مطابقة مع تفكيك
طابق الشكل {
    دائرة(ر) => 3.14 * ر * ر
    مستطيل(ع، ط) => ع * ط
}
```

---

### 4. [استنتاج الأنواع (Type Inference)](04_type_inference.md)
**Phase 1.3.2 - مُنفذ بالكامل ✅**

فهم كيف يستنتج المترجم الأنواع تلقائياً.

**المواضيع المُغطاة:**
- ما هو Type Inference؟
- خوارزمية Hindley-Milner
- متغيرات الأنواع (Type Variables)
- التوحيد (Unification)
- حلال القيود (Constraint Solver)
- أمثلة عملية

**الاستخدامات:**
```sad
# المترجم يستنتج الأنواع تلقائياً
متغير س = 5              # رقم
متغير ي = "مرحباً"        # نص
متغير قائمة = [1، 2، 3]   # قائمة<رقم>
```

---

### 5. [Type Guards والأنواع الحارسة](05_type_guards.md)
**Phase 1.3.5.1 - قيد التنفيذ 🔄**

تعلم كيفية تضييق الأنواع في runtime بطريقة آمنة.

**المواضيع المُغطاة:**
- ما هي Type Guards؟
- Built-in type guards
- User-defined type guards
- Type narrowing في control flow
- أمثلة عملية

**الاستخدامات:**
```sad
# type guard مدمج
إذا (القيمة نوع رقم) {
    # هنا القيمة من النوع رقم
}

# user-defined type guard
دالة هو_نص(القيمة: أي) -> القيمة نوع نص {
    ارجع نوع_من(القيمة) == "نص"
}
```

---

### 6. [Type Narrowing وتضييق الأنواع](06_type_narrowing.md)
**Phase 1.3.5.2 - قيد التنفيذ 🔄**

فهم كيف يتتبع المترجم الأنواع في control flow.

**المواضيع المُغطاة:**
- ما هو Type Narrowing؟
- Control Flow Analysis
- Type refinement
- Exhaustiveness checking
- أمثلة عملية

**الاستخدامات:**
```sad
متغير س: رقم | نص = ...

إذا (س نوع رقم) {
    # س: رقم (narrowed)
    اطبع(س * 2)
} وإلا {
    # س: نص (narrowed)
    اطبع(س.طول())
}
```
