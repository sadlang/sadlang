# الفصل الخامس والعشرون: الشبكات (Networking)

## مقدمة نظرية

**بروتوكولات الشبكة** تُحدد كيف تتواصل البرامج عبر الإنترنت:

| البروتوكول | النوع | الاستخدام |
|-----------|-------|-----------|
| **TCP** | موثوق، مرتب | ويب، بريد، قواعد بيانات |
| **UDP** | سريع، غير موثوق | ألعاب، بث فيديو، DNS |
| **HTTP** | طلب/استجابة فوق TCP | واجهات REST، مواقع |
| **WebSocket** | ثنائي الاتجاه | دردشة، بيانات حية |

---

## 1. طلبات HTTP

```sad
من "شبكة" استورد http

# طلب GET
متغير استجابة = http.احصل("https://api.example.com/users")
اطبع_سطر("الحالة: " + استجابة.رمز_الحالة)
اطبع_سطر("البيانات: " + استجابة.الجسم)

# طلب POST
متغير بيانات = {
   "اسم": "أحمد"،
   "بريد": "ahmed@example.com"
}
متغير نتيجة = http.أرسل("https://api.example.com/users"، بيانات)
اطبع_سطر("تم الإنشاء: " + نتيجة.رمز_الحالة)
```

## 2. خادم TCP بسيط

```sad
من "شبكة" استورد tcp

# خادم بسيط يستقبل رسائل
دالة شغّل_خادم(منفذ)
   متغير خادم = tcp.أنشئ_خادم(منفذ)
   اطبع_سطر("الخادم يستمع على المنفذ " + منفذ)

   بينما (صحيح)
      متغير عميل = خادم.اقبل()
      اطبع_سطر("عميل جديد: " + عميل.العنوان)

      متغير رسالة = عميل.اقرأ()
      اطبع_سطر("الرسالة: " + رسالة)

      عميل.اكتب("مرحباً من الخادم!")
      عميل.أغلق()
   نهاية
نهاية

# شغّل_خادم(8080)
```

## 3. عميل TCP

```sad
من "شبكة" استورد tcp

دالة أرسل_رسالة(مضيف، منفذ، رسالة)
   متغير اتصال = tcp.اتصل(مضيف، منفذ)
   اتصال.اكتب(رسالة)
   متغير رد = اتصال.اقرأ()
   اطبع_سطر("الرد: " + رد)
   اتصال.أغلق()
نهاية

# أرسل_رسالة("localhost"، 8080، "مرحباً!")
```

## 4. خادم HTTP مبسط

```sad
من "شبكة" استورد http_خادم

متغير خادم = جديد http_خادم(3000)

خادم.عالج("/"، دالة(طلب، استجابة)

خادم.عالج("/api/معلومات"، دالة(طلب، استجابة)

نهاية)
```

## 5. WebSocket — اتصال حي

```sad
من "شبكة" استورد websocket

# خادم WebSocket
متغير خادم_ws = جديد websocket.خادم(8081)

خادم_ws.عند_اتصال(دالة(عميل)
   اطبع_سطر("عميل اتصل!")

   عميل.عند_رسالة(دالة(رسالة)
      اطبع_سطر("استُقبل: " + رسالة)
      # بث لكل المتصلين
      خادم_ws.بث("مستخدم يقول: " + رسالة)
   نهاية)
نهاية)

اطبع_سطر("WebSocket على المنفذ 8081")
# خادم_ws.ابدأ()
```

## 6. تطبيق عملي: فاحص مواقع

```sad
من "شبكة" استورد http

دالة افحص_موقع(رابط)
   حاول
      متغير بداية = الآن()
      متغير استجابة = http.احصل(رابط)
      متغير مدة = الآن() - بداية

      إذا (استجابة.رمز_الحالة == 200)
         اطبع_سطر("✓ " + رابط + " — يعمل (" + مدة + " ثانية)")
      وإلا
         اطبع_سطر("⚠ " + رابط + " — خطأ " + استجابة.رمز_الحالة)
      نهاية
   امسك (خطأ)
      اطبع_سطر("✗ " + رابط + " — غير متاح: " + خطأ)
   نهاية
نهاية

متغير مواقع = [
   "https://example.com"،
   "https://sad-lang.org"،
   "https://github.com"
]

لكل موقع في مواقع
   افحص_موقع(موقع)
نهاية
```

## خلاصة

| الوحدة | الدوال الرئيسية | الاستخدام |
|--------|----------------|-----------|
| `http` | `احصل`، `أرسل` | طلبات REST |
| `tcp` | `أنشئ_خادم`، `اتصل` | اتصالات مباشرة |
| `websocket` | `خادم`، `بث` | اتصال حي ثنائي |
| `http_خادم` | `عالج`، `ابدأ` | خادم ويب |

## تمارين

1. ابنِ عميل REST يتعامل مع واجهة REST — إنشاء/قراءة/تحديث/حذف.
2. ابنِ دردشة بسيطة باستخدام WebSocket.
3. اكتب فاحص DNS يحوّل أسماء نطاقات إلى عناوين IP.
4. ابنِ خادم يخدم ملفات ثابتة (HTML, CSS, JS) من مجلد.
