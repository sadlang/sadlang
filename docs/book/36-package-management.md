# الفصل السادس والثلاثون: إدارة الحزم (Package Management)

## مقدمة نظرية

**مدير الحزم** أداة تُدير المكتبات الخارجية التي يعتمد عليها مشروعك. بدلاً من نسخ الكود يدوياً، تصف اعتماداتك في ملف واحد والمدير يُنزّلها ويُحدّثها.

| المفهوم | الوصف |
|---------|-------|
| **حزمة** | مكتبة أو أداة مغلّفة قابلة لإعادة الاستخدام |
| **اعتماد** | حزمة يحتاجها مشروعك |
| **سجل** | خادم يخزن الحزم المتاحة |
| **القفل** | ملف يثبّت إصدارات محددة |
| **النطاق** | اسم المؤلف أو المنظمة |

لغة ص تأتي مع مدير حزم مدمج: `sad-pkg`.

---

## 1. ملف الحزمة (حزمة.ص)

```sad
# ملف: حزمة.ص — يصف المشروع واعتماداته
{
   "الاسم": "تطبيقي",
   "الإصدار": "1.0.0",
   "الوصف": "تطبيق ويب بلغة ص",
   "المؤلف": "أحمد محمد",
   "الرخصة": "MIT",

   "اعتمادات": {
      "خادم-ويب": "^2.0.0",
      "قاعدة-بيانات": "~1.5.0",
      "تشفير": ">=3.0.0"
   },

   "اعتمادات-تطوير": {
      "اختبارات": "^1.0.0",
      "تنسيق": "^1.2.0"
   },

   "أوامر": {
      "بدء": "sad رئيسي.ص",
      "اختبار": "sad اختبارات/",
      "بناء": "sadc رئيسي.ص -o تطبيقي"
   }
}
```

## 2. أوامر مدير الحزم

```bash
# تهيئة مشروع جديد
sad-pkg تهيئة

# تثبيت كل الاعتمادات
sad-pkg تثبيت

# إضافة حزمة جديدة
sad-pkg أضف خادم-ويب

# إضافة حزمة تطوير
sad-pkg أضف --تطوير اختبارات

# تحديث حزمة
sad-pkg حدّث قاعدة-بيانات

# إزالة حزمة
sad-pkg أزل تشفير

# عرض الاعتمادات
sad-pkg قائمة

# البحث عن حزمة
sad-pkg بحث "json"
```

## 3. إصدارات الحزم (Semantic Versioning)

```
الإصدار: رئيسي.فرعي.تصحيح
مثال:   2.5.3
```

| الجزء | متى يتغير | مثال |
|-------|-----------|------|
| **رئيسي** | تغييرات كاسرة (breaking) | 1.0→2.0 |
| **فرعي** | ميزات جديدة متوافقة | 2.0→2.1 |
| **تصحيح** | إصلاح أخطاء | 2.1.0→2.1.1 |

| الرمز | المعنى | مثال |
|-------|--------|------|
| `^2.0.0` | أي 2.x.x | 2.0.0, 2.5.3, لكن ليس 3.0 |
| `~1.5.0` | أي 1.5.x | 1.5.0, 1.5.9, لكن ليس 1.6 |
| `>=3.0.0` | 3.0.0 فأعلى | 3.0, 4.0, 100.0 |
| `1.2.3` | هذا الإصدار بالضبط | 1.2.3 فقط |

## 4. إنشاء حزمة خاصة بك

```sad
# ملف: حزمة.ص
{
   "الاسم": "رياضيات-عربية",
   "الإصدار": "1.0.0",
   "الوصف": "مكتبة رياضيات بأسماء عربية",
   "الرئيسي": "فهرس.ص"
}

# ملف: فهرس.ص — نقطة الدخول للحزمة
صدّر دالة الجذر_التربيعي(ن)
   إذا (ن < 0)
      ارمي "لا يمكن حساب الجذر التربيعي لعدد سالب"
   نهاية
   متغير تخمين = ن / 2
   لكل _ في نطاق(0، 50)
      تخمين = (تخمين + ن / تخمين) / 2
   نهاية
   ارجع تخمين
نهاية

صدّر دالة القوة(أساس، أس)
   إذا (أس == 0)
      ارجع 1
   نهاية
   متغير نتيجة = 1
   لكل _ في نطاق(0، أس)
      نتيجة = نتيجة * أساس
   نهاية
   ارجع نتيجة
نهاية

صدّر دالة المضروب(ن)
   إذا (ن <= 1)
      ارجع 1
   نهاية
   ارجع ن * المضروب(ن - 1)
نهاية

صدّر ثابت باي = 3.14159265358979
```

## 5. استخدام الحزم في مشروعك

```sad
# تثبيت: sad-pkg أضف رياضيات-عربية
استورد الجذر_التربيعي، القوة، المضروب من "رياضيات-عربية"
استورد باي من "رياضيات-عربية"

اطبع_سطر("√16 = " + الجذر_التربيعي(16))    # 4
اطبع_سطر("2⁸ = " + القوة(2، 8))             # 256
اطبع_سطر("5! = " + المضروب(5))               # 120
اطبع_سطر("π = " + باي)                       # 3.14159...

# مساحة دائرة
متغير نصف_قطر = 7
متغير المساحة = باي * القوة(نصف_قطر، 2)
اطبع_سطر("مساحة الدائرة: " + المساحة)
```

## 6. نشر حزمتك

```bash
# ① تأكد من الملفات
sad-pkg تحقق

# ② سجّل حساباً (مرة واحدة)
sad-pkg تسجيل

# ③ سجّل الدخول
sad-pkg دخول

# ④ انشر!
sad-pkg نشر

# ⑤ إصدار جديد
# عدّل "الإصدار" في حزمة.ص ثم:
sad-pkg نشر
```

---

## خلاصة

| الأمر | الوظيفة |
|-------|---------|
| `sad-pkg تهيئة` | مشروع جديد |
| `sad-pkg أضف` | إضافة حزمة |
| `sad-pkg تثبيت` | تثبيت الاعتمادات |
| `sad-pkg حدّث` | تحديث حزمة |
| `sad-pkg نشر` | نشر حزمتك |

## تمارين

1. أنشئ حزمة `تحويلات` تحتوي دوال تحويل (درجات↔فهرنهايت، كم↔ميل).
2. أنشئ مشروعاً يعتمد على حزمتين واكتب ملف `حزمة.ص` له.
3. ارسم شجرة اعتمادات لمشروع يعتمد على 3 حزم، كل واحدة تعتمد على حزمتين.
4. اكتب سكريبت يتحقق من إصدارات الحزم ويُخبرك بالتحديثات المتاحة.
