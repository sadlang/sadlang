# الفصل الثالث والأربعون: بناء مكتبة خاصة (Building Your Own Library)

## مقدمة نظرية

**المكتبة** مجموعة من الدوال والأصناف المغلّفة للاستخدام في مشاريع متعددة. بناء مكتبة جيدة يتطلب: واجهة واضحة، توثيق كامل، اختبارات شاملة، وتصميم قابل للتوسع.

### دورة حياة المكتبة

```
فكرة → تصميم API → تنفيذ → اختبار → توثيق → نشر → صيانة
```

## 1. تصميم الواجهة (API Design)

```sad
# ✗ واجهة سيئة — معاملات كثيرة بترتيب غير واضح
دالة أنشئ(ن، م، ع، و، ت، ر)
   # ماذا يعني كل معامل؟!
نهاية

# ✓ واجهة جيدة — أسماء واضحة، معاملات منطقية
دالة أنشئ_مستخدم(الاسم، البريد)
   # واضح فوراً
نهاية

# ✓ أفضل — صنف مع Builder Pattern
صنف بانِ_مستخدم
   خاص متغير _الاسم = ""
   خاص متغير _البريد = ""
   خاص متغير _العمر = 0

   دالة الاسم(اسم)
      _الاسم = اسم
      ارجع هذا
   نهاية

   دالة البريد(بريد)
      _البريد = بريد
      ارجع هذا
   نهاية

   دالة العمر(عمر)
      _العمر = عمر
      ارجع هذا
   نهاية

   دالة ابنِ()
      إذا (_الاسم == "")
         ارمي "الاسم مطلوب"
      نهاية
      ارجع جديد مستخدم(_الاسم، _البريد، _العمر)
   نهاية
نهاية

# الاستخدام
متغير م = جديد بانِ_مستخدم()
   .الاسم("أحمد")
   .البريد("ahmed@example.com")
   .العمر(25)
   .ابنِ()
```

## 3. مثال كامل: مكتبة التحقق

```sad
# ملف: فهرس.ص — ما يراه المستخدم
صدّر تحقق_بريد من "مصدر/تحقق"
صدّر تحقق_هاتف من "مصدر/تحقق"
صدّر تحقق_رقم_وطني من "مصدر/تحقق"
صدّر أداة_تحقق من "مصدر/تحقق"

# ملف: مصدر/تحقق.ص — التنفيذ

#**
   دوال التحقق من صحة البيانات
   تدعم: البريد الإلكتروني، الهاتف، الرقم الوطني
**#

## يتحقق من صحة عنوان بريد إلكتروني
## الإرجاع: صحيح إذا كان البريد صالحاً
## مثال: تحقق_بريد("ahmed@mail.com") → صحيح
صدّر دالة تحقق_بريد(بريد)
   إذا (بريد == لاشيء أو طول(بريد) == 0)
      ارجع خطأ
   نهاية

   # يجب أن يحتوي @ واحدة بالضبط
   متغير عدد_آت = 0
   متغير موقع_آت = -1
   لكل ي في نطاق(0، طول(بريد))
      إذا (بريد[ي] == "@")
         عدد_آت = عدد_آت + 1
         موقع_آت = ي
      نهاية
   نهاية

   إذا (عدد_آت != 1)
      ارجع خطأ
   نهاية
   إذا (موقع_آت == 0 أو موقع_آت == طول(بريد) - 1)
      ارجع خطأ
   نهاية

   # يجب أن يحتوي الجزء بعد @ على نقطة
   متغير النطاق = قطع(بريد، موقع_آت + 1، طول(بريد))
   إذا (ليس يحتوي(النطاق، "."))
      ارجع خطأ
   نهاية

   ارجع صحيح
نهاية

## يتحقق من صحة رقم هاتف (10-15 رقماً)
صدّر دالة تحقق_هاتف(هاتف)
   إذا (هاتف == لاشيء)
      ارجع خطأ
   نهاية
   # إزالة الفراغات والشرطات
   متغير نظيف = استبدل(استبدل(هاتف، " "، "")، "-"، "")
   # إزالة + من البداية
   إذا (طول(نظيف) > 0 و نظيف[0] == "+")
      نظيف = قطع(نظيف، 1، طول(نظيف))
   نهاية
   # التحقق: 10-15 رقماً فقط
   إذا (طول(نظيف) < 10 أو طول(نظيف) > 15)
      ارجع خطأ
   نهاية
   لكل حرف في نظيف
      إذا (ليس رقم(حرف))
         ارجع خطأ
      نهاية
   نهاية
   ارجع صحيح
نهاية

## أداة تحقق قابلة للتخصيص
صدّر صنف أداة_تحقق
   خاص متغير _قواعد = []
   خاص متغير _أخطاء = []

   ## يضيف قاعدة تحقق جديدة
   ## المعاملات:
   ##   الاسم — اسم الحقل
   ##   القيمة — القيمة المُراد التحقق منها
   ##   شرط — دالة تُرجع صحيح/خطأ
   ##   رسالة — رسالة الخطأ إذا فشل الشرط
   دالة أضف_قاعدة(الاسم، القيمة، شرط، رسالة)
      متغير قاعدة = خريطة()
      قاعدة["الاسم"] = الاسم
      قاعدة["القيمة"] = القيمة
      قاعدة["شرط"] = شرط
      قاعدة["رسالة"] = رسالة
      _قواعد[طول(_قواعد)] = قاعدة
      ارجع هذا
   نهاية

   ## يُنفذ كل القواعد ويُرجع النتيجة
   دالة تحقق()
      _أخطاء = []
      لكل قاعدة في _قواعد
         إذا (ليس قاعدة["شرط"](قاعدة["القيمة"]))
            _أخطاء[طول(_أخطاء)] = قاعدة["الاسم"] + ": " + قاعدة["رسالة"]
         نهاية
      نهاية
      ارجع طول(_أخطاء) == 0
   نهاية

   دالة الأخطاء()
      ارجع _أخطاء
   نهاية
نهاية
```

## 5. نشر المكتبة

```sad
# ملف: حزمة.ص
{
   "الاسم": "تحقق-عربي",
   "الإصدار": "1.0.0",
   "الوصف": "مكتبة تحقق من صحة البيانات بالعربية",
   "الرئيسي": "فهرس.ص",
   "المؤلف": "اسمك",
   "الرخصة": "MIT",
   "كلمات_مفتاحية": ["تحقق"، "بريد"، "هاتف"، "عربي"]
}
```

```bash
# تحقق من جاهزية الحزمة
sad-pkg تحقق

# نشر
sad-pkg نشر
```

## خلاصة

| المرحلة | النصيحة |
|---------|---------|
| التصميم | واجهة بسيطة، أسماء واضحة |
| التنفيذ | كود نظيف، تعامل مع الحالات الحدية |
| الاختبار | تغطية شاملة، حالات عادية وحدية |
| التوثيق | `##` لكل دالة + README + أمثلة |
| النشر | `sad-pkg نشر` مع CHANGELOG |

## تمارين

1. ابنِ مكتبة `تنسيق-عربي` تنسق الأرقام والتواريخ بالعربية.
2. ابنِ مكتبة `تحويلات` للتحويل بين الوحدات (طول، وزن، حرارة).
3. اكتب 10 اختبارات على الأقل لمكتبة أنشأتها.
4. انشر مكتبتك واستخدمها في مشروع آخر عبر `sad-pkg`.
