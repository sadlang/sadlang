# الفصل الثلاثون: اختبار البرمجيات (Software Testing)

## مقدمة نظرية

**الاختبار** يضمن أن البرنامج يعمل بشكل صحيح. أنواع الاختبارات:

| النوع | الوصف | مثال |
|-------|-------|------|
| **وحدة** (Unit) | اختبار دالة واحدة | هل `جمع(2,3)` تُرجع `5`؟ |
| **تكامل** (Integration) | اختبار عدة مكونات معاً | هل القاعدة + الخادم يعملان؟ |
| **شامل** (E2E) | اختبار النظام بالكامل | سيناريو مستخدم كامل |
| **انحدار** (Regression) | هل التعديل كسر شيئاً؟ | إعادة الاختبارات السابقة |

## 1. إطار اختبار بسيط

```sad
# إطار اختبار مدمج في لغة ص
متغير _نجح = 0
متغير _فشل = 0
متغير _أخطاء = []

دالة تأكد_يساوي(فعلي، متوقع، وصف)
   إذا (فعلي == متوقع)
      _نجح = _نجح + 1
      اطبع_سطر("  ✓ " + وصف)
   وإلا
      _فشل = _فشل + 1
      _أخطاء.أضف(وصف + " — توقع: " + متوقع + "، حصل: " + فعلي)
      اطبع_سطر("  ✗ " + وصف)
   نهاية
نهاية

دالة تأكد_صحيح(شرط، وصف)
   تأكد_يساوي(شرط، صحيح، وصف)
نهاية

دالة تأكد_خطأ(شرط، وصف)
   تأكد_يساوي(شرط، خطأ، وصف)
نهاية

دالة تأكد_يرمي(دالة_اختبار، وصف)
   حاول
      دالة_اختبار()
      _فشل = _فشل + 1
      اطبع_سطر("  ✗ " + وصف + " — لم يُرم خطأ")
   امسك (خطأ)
      _نجح = _نجح + 1
      اطبع_سطر("  ✓ " + وصف)
   نهاية
نهاية

دالة ملخص_الاختبارات()
   اطبع_سطر("\n═══════════════════════════════")
   اطبع_سطر("  النتائج: " + _نجح + " نجح، " + _فشل + " فشل")
   اطبع_سطر("═══════════════════════════════")
   إذا (_فشل > 0)
      اطبع_سطر("\nالأخطاء:")
      لكل خطأ في _أخطاء
         اطبع_سطر("  • " + خطأ)
      نهاية
   نهاية
نهاية
```

## 2. اختبارات وحدة

```sad
# الكود المُختبر
دالة جمع(أ، ب)
   ارجع أ + ب
نهاية

دالة مضروب(ن)
   إذا (ن < 0)
      ارمي "لا يوجد مضروب لعدد سالب"
   نهاية
   إذا (ن <= 1)
      ارجع 1
   نهاية
   ارجع ن * مضروب(ن - 1)
نهاية

# الاختبارات
اطبع_سطر("━━ اختبارات دالة الجمع ━━")
تأكد_يساوي(جمع(2، 3)، 5، "جمع موجبين")
تأكد_يساوي(جمع(-1، 1)، 0، "جمع سالب وموجب")
تأكد_يساوي(جمع(0، 0)، 0، "جمع أصفار")

اطبع_سطر("\n━━ اختبارات المضروب ━━")
تأكد_يساوي(مضروب(0)، 1، "مضروب 0")
تأكد_يساوي(مضروب(1)، 1، "مضروب 1")
تأكد_يساوي(مضروب(5)، 120، "مضروب 5")
تأكد_يرمي(لامدا() مضروب(-1) نهاية، "مضروب سالب يرمي خطأ")

ملخص_الاختبارات()
```

## 3. اختبار الأصناف

```sad
صنف حساب_بنكي
   عام باني(اسم، رصيد)
      هذا.اسم = اسم
      هذا.رصيد = رصيد
   نهاية

   عام دالة إيداع(مبلغ)
      إذا (مبلغ <= 0)
         ارمي "المبلغ يجب أن يكون موجباً"
      نهاية
      هذا.رصيد = هذا.رصيد + مبلغ
   نهاية

   عام دالة سحب(مبلغ)
      إذا (مبلغ > هذا.رصيد)
         ارمي "رصيد غير كافٍ"
      نهاية
      هذا.رصيد = هذا.رصيد - مبلغ
   نهاية
نهاية

# الاختبارات
اطبع_سطر("━━ اختبارات الحساب البنكي ━━")

متغير ح = جديد حساب_بنكي("أحمد"، 1000)
تأكد_يساوي(ح.رصيد، 1000، "الرصيد الأولي")

ح.إيداع(500)
تأكد_يساوي(ح.رصيد، 1500، "بعد الإيداع")

ح.سحب(200)
تأكد_يساوي(ح.رصيد، 1300، "بعد السحب")

تأكد_يرمي(لامدا() ح.سحب(5000) نهاية، "سحب يتجاوز الرصيد")
تأكد_يرمي(لامدا() ح.إيداع(-100) نهاية، "إيداع مبلغ سالب")

ملخص_الاختبارات()
```

## 4. اختبارات التكامل

```sad
# اختبار النظام الكامل: قاعدة بيانات + خدمة
اطبع_سطر("━━ اختبارات التكامل ━━")

متغير قب = جديد قاعدة_بيانات("اختبار.json")

# إضافة + قراءة
قب.أضف("منتجات"، {"اسم": "كتاب"، "سعر": 50})
قب.أضف("منتجات"، {"اسم": "قلم"، "سعر": 5})
متغير الكل = قب.الكل("منتجات")
تأكد_يساوي(طول(الكل)، 2، "إضافة منتجين")

# بحث
متغير غالي = قب.ابحث("منتجات"، لامدا(م) م["سعر"] > 10 نهاية)
تأكد_يساوي(طول(غالي)، 1، "بحث بالسعر")
تأكد_يساوي(غالي[0]["اسم"]، "كتاب"، "المنتج الغالي هو الكتاب")

ملخص_الاختبارات()
```

## أفضل الممارسات

| الممارسة | الوصف |
|----------|-------|
| اسم وصفي | `"جمع_موجبين"` أفضل من `"اختبار_1"` |
| اختبار واحد = فحص واحد | لا تخلط عدة تأكيدات غير مرتبطة |
| اختبر الحالات الحدية | صفر، فارغ، سالب، أقصى قيمة |
| اختبر الأخطاء | تأكد من رمي الأخطاء المتوقعة |
| عزل الاختبارات | كل اختبار مستقل عن الآخرين |

## تمارين

1. اكتب اختبارات للمكدس (ادفع، اسحب، فارغ، القمة).
2. اكتب اختبارات لخوارزمية الترتيب (مرتبة، عكسية، عنصر واحد، فارغة).
3. ابنِ دالة `تأكد_قريب(فعلي، متوقع، هامش)` للأرقام العشرية.
4. اكتب اختبار تكامل كامل لنظام المكتبة (الفصل 15).
