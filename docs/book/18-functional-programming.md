# الفصل الثامن عشر: البرمجة الوظيفية (Functional Programming)

## مقدمة نظرية

**البرمجة الوظيفية** نموذج برمجي يعامل الحوسبة كتقييم دوال رياضية. المبادئ الأساسية:

| المبدأ | الوصف |
|--------|-------|
| **الدوال النقية** | نفس المُدخل → نفس المُخرج دائماً، بلا آثار جانبية |
| **عدم التغيير** | البيانات لا تُعدّل بعد إنشائها — تُنشأ نسخ جديدة |
| **الدوال العليا** | الدوال تُمرّر كمعاملات وتُرجع كقيم |
| **التركيب** | بناء عمليات معقدة من دوال بسيطة |

لغة ص تدعم البرمجة الوظيفية رغم كونها متعددة الأنماط.

---

## 1. الدوال النقية مقابل غير النقية

```sad
# ✗ دالة غير نقية — تعتمد على حالة خارجية
متغير عداد = 0
دالة زد()
   عداد = عداد + 1    # تغيّر حالة خارجية
   ارجع عداد
نهاية

# ✓ دالة نقية — لا آثار جانبية
دالة اجمع(أ، ب)
   ارجع أ + ب           # نفس المدخل = نفس المخرج دائماً
نهاية
```

**لماذا النقاء مهم؟**
- سهلة الاختبار: لا تحتاج إعداد حالة
- قابلة للتوازي: لا تعارضات على بيانات مشتركة
- قابلة للتخزين المؤقت: النتيجة ثابتة

## 2. الدوال العليا (Higher-Order Functions)

دالة تأخذ دالة أخرى كمعامل أو تُرجع دالة:

```sad
# دالة تأخذ دالة أخرى كمعامل
دالة طبّق(قائمة، عملية)
   متغير نتيجة = []
   لكل عنصر في قائمة
      نتيجة.أضف(عملية(عنصر))
   نهاية
   ارجع نتيجة
نهاية

# دوال بسيطة
دالة ضعف(ن)
   ارجع ن * 2
نهاية

دالة تربيع(ن)
   ارجع ن * ن
نهاية

متغير أرقام = [1، 2، 3، 4، 5]
اطبع_سطر(طبّق(أرقام، ضعف))    # [2, 4, 6, 8, 10]
اطبع_سطر(طبّق(أرقام، تربيع))   # [1, 4, 9, 16, 25]
```

---

## 3. لامدا (الدوال المجهولة)

```sad
متغير أرقام = [1، 2، 3، 4، 5، 6، 7، 8]

# فلترة الأرقام الزوجية
متغير زوجية = طبّق(أرقام، لامدا(ن) ن % 2 == 0 نهاية)

# جمع تراكمي
دالة اختصر(قائمة، دالة_جمع، قيمة_أولية)
   متغير تراكم = قيمة_أولية
   لكل عنصر في قائمة
      تراكم = دالة_جمع(تراكم، عنصر)
   نهاية
   ارجع تراكم
نهاية

متغير المجموع = اختصر(أرقام، لامدا(تراكم، ن) تراكم + ن نهاية، 0)
اطبع_سطر("المجموع: " + المجموع)   # 36
```

## 4. التركيب (Composition)

بناء دوال معقدة من تركيب دوال بسيطة:

```sad
دالة أضف_واحد(ن)
   ارجع ن + 1
نهاية

دالة اضرب_ثلاثة(ن)
   ارجع ن * 3
نهاية

# تركيب يدوي
دالة ركّب(د1، د2)
   ارجع لامدا(س) د1(د2(س)) نهاية
نهاية

متغير عملية = ركّب(اضرب_ثلاثة، أضف_واحد)
اطبع_سطر(عملية(4))   # (4+1)*3 = 15
```

## 5. أنابيب البيانات (Pipeline)

```sad
# بناء أنبوب معالجة بيانات
دالة أنبوب(بيانات، عمليات)
   متغير نتيجة = بيانات
   لكل عملية في عمليات
      نتيجة = عملية(نتيجة)
   نهاية
   ارجع نتيجة
نهاية

# معالجة قائمة طلاب
متغير درجات = [85، 42، 93، 67، 55، 98، 71]

دالة فقط_الناجحون(قائمة)
   متغير نتيجة = []
   لكل د في قائمة
      إذا (د >= 60)
         نتيجة.أضف(د)
      نهاية
   نهاية
   ارجع نتيجة
نهاية

دالة أضف_مكافأة(قائمة)
   متغير نتيجة = []
   لكل د في قائمة
      نتيجة.أضف(د + 5)
   نهاية
   ارجع نتيجة
نهاية

متغير النهائي = أنبوب(درجات، [فقط_الناجحون، أضف_مكافأة])
اطبع_سطر(النهائي)   # [90, 98, 72, 103, 76]
```

## 6. الإغلاقات (Closures)

الدالة تحتفظ بمرجع لبيئتها عند إنشائها:

```sad
دالة أنشئ_عداد(بداية)
   متغير ن = بداية
   ارجع لامدا()
      ن = ن + 1
      ارجع ن
   نهاية
نهاية

متغير عد = أنشئ_عداد(0)
اطبع_سطر(عد())   # 1
اطبع_سطر(عد())   # 2
اطبع_سطر(عد())   # 3

# كل عداد مستقل
متغير عد2 = أنشئ_عداد(100)
اطبع_سطر(عد2())  # 101
اطبع_سطر(عد())   # 4 — العداد الأول ما زال يعمل
```

## خلاصة

| المفهوم | الوصف | مثال في لغة ص |
|---------|-------|---------------|
| دالة نقية | لا آثار جانبية | `دالة اجمع(أ، ب)` |
| دالة عليا | تأخذ/تُرجع دوال | `دالة طبّق(قائمة، عملية)` |
| لامدا | دالة مجهولة | `لامدا(ن) ن * 2 نهاية` |
| تركيب | دمج دوال | `ركّب(د1، د2)` |
| إغلاق | حفظ البيئة | `أنشئ_عداد(0)` |

## تمارين

1. اكتب دالة `صفّي(قائمة، شرط)` تُرجع عناصر تحقق الشرط فقط.
2. اكتب دالة `حوّل_ثم_صفّي(قائمة، تحويل، شرط)` تجمع العمليتين.
3. ابنِ نظام أحداث وظيفي بدون أصناف (دوال فقط).
4. اكتب دالة تخزين مؤقت (memoize) تحفظ نتائج الاستدعاءات السابقة.
