# الفصل الخامس والثلاثون: بنية المشاريع (Project Architecture)

## مقدمة نظرية

مع نمو المشروع، يصبح التنظيم ضرورياً. **بنية المشروع** الجيدة تسهّل:
- **الصيانة**: العثور على الكود وتعديله بسهولة
- **التعاون**: كل مطور يعمل في منطقة مستقلة
- **التوسع**: إضافة ميزات جديدة بدون كسر القديم
- **الاختبار**: اختبار كل جزء على حدة

## 1. تنظيم الملفات

### بنية مشروع صغير
```
مشروعي/
  ├── رئيسي.ص          # نقطة الدخول
  ├── إعدادات.ص        # ثوابت وتهيئة
  └── مساعدات.ص        # دوال مشتركة
```

### بنية مشروع متوسط
```
مشروعي/
  ├── رئيسي.ص
  ├── نماذج/
  │   ├── مستخدم.ص
  │   ├── مقال.ص
  │   └── تعليق.ص
  ├── خدمات/

  │   └── قاعدة_بيانات.ص
  ├── مسارات/

  │   └── اختبار_مقال.ص
  └── إعدادات.ص
```

## 2. نمط MVC (نموذج-عرض-تحكم)

```sad
# ===== النموذج (Model) — البيانات =====
# ملف: نماذج/مهمة.ص
صنف مهمة
   عام متغير المعرف
   عام متغير العنوان
   عام متغير مكتملة = خطأ

   باني(معرف، عنوان)
      هذا.المعرف = معرف
      هذا.العنوان = عنوان
   نهاية
نهاية

# ===== العرض (View) — ما يراه المستخدم =====
# ملف: عروض/مهام.ص
صنف عرض_مهام
   دالة اعرض_قائمة(مهام)
      اطبع_سطر("═══════════════════════")
      اطبع_سطر("   قائمة المهام")
      اطبع_سطر("═══════════════════════")
      لكل م في مهام
         متغير حالة = "○"
         إذا (م.مكتملة)
            حالة = "●"
         نهاية
         اطبع_سطر(حالة + " [" + م.المعرف + "] " + م.العنوان)
      نهاية
   نهاية

   دالة اعرض_رسالة(نص)
      اطبع_سطر("→ " + نص)
   نهاية
نهاية

# ===== التحكم (Controller) — المنطق =====
# ملف: تحكم/تحكم_مهام.ص
صنف تحكم_مهام
   خاص متغير _مهام = []
   خاص متغير _عرض = جديد عرض_مهام()
   خاص متغير _عداد = 0

   دالة أضف(عنوان)
      _عداد = _عداد + 1
      متغير م = جديد مهمة(_عداد، عنوان)
      _مهام[طول(_مهام)] = م
      _عرض.اعرض_رسالة("تمت إضافة: " + عنوان)
   نهاية

   دالة أنجز(معرف)
      لكل م في _مهام
         إذا (م.المعرف == معرف)
            م.مكتملة = صحيح
            _عرض.اعرض_رسالة("تم إنجاز: " + م.العنوان)
            ارجع
         نهاية
      نهاية
      _عرض.اعرض_رسالة("مهمة غير موجودة!")
   نهاية

   دالة اعرض()
      _عرض.اعرض_قائمة(_مهام)
   نهاية
نهاية
```

## 3. نمط الطبقات (Layered Architecture)

```
┌──────────────────────┐
│   واجهة المستخدم     │  عرض / طرفية / API
├──────────────────────┤
│   طبقة الأعمال       │  قواعد ومنطق التطبيق
├──────────────────────┤
│   طبقة البيانات      │  قاعدة بيانات / ملفات
└──────────────────────┘
```

```sad
# طبقة البيانات — تتحدث مع التخزين فقط
صنف مستودع_منتجات
   خاص متغير _مخزن = خريطة()

   دالة احفظ(منتج)
      _مخزن[منتج.المعرف] = منتج
   نهاية

   دالة جد(معرف)
      ارجع _مخزن[معرف]
   نهاية

   دالة الكل()
      متغير قائمة = []
      لكل مفتاح في مفاتيح(_مخزن)
         قائمة[طول(قائمة)] = _مخزن[مفتاح]
      نهاية
      ارجع قائمة
   نهاية
نهاية

# طبقة الأعمال — القواعد والمنطق
صنف خدمة_منتجات
   خاص متغير _مستودع = جديد مستودع_منتجات()

   دالة أضف_منتج(اسم، سعر)
      إذا (سعر <= 0)
         ارمي "السعر يجب أن يكون موجباً"
      نهاية
      إذا (طول(اسم) < 2)
         ارمي "اسم المنتج قصير جداً"
      نهاية
      متغير م = خريطة()
      م["المعرف"] = اسم
      م["الاسم"] = اسم
      م["السعر"] = سعر
      _مستودع.احفظ(م)
   نهاية

   دالة منتجات_أقل_من(حد)
      متغير نتائج = []
      لكل م في _مستودع.الكل()
         إذا (م["السعر"] < حد)
            نتائج[طول(نتائج)] = م
         نهاية
      نهاية
      ارجع نتائج
   نهاية
نهاية
```

## 4. نمط الوحدات (Module Pattern)

```sad
# ملف: رياضيات/هندسة.ص
صدّر دالة مساحة_دائرة(نصف_قطر)
   ارجع 3.14159 * نصف_قطر ** 2
نهاية

صدّر دالة محيط_دائرة(نصف_قطر)
   ارجع 2 * 3.14159 * نصف_قطر
نهاية

صدّر دالة مساحة_مستطيل(طول، عرض)
   ارجع طول * عرض

# ملف: رئيسي.ص
استورد مساحة_دائرة، محيط_دائرة من "رياضيات/هندسة"

اطبع_سطر("مساحة الدائرة: " + مساحة_دائرة(5))
```

## 5. مبادئ التصميم (SOLID)

| المبدأ | الاختصار | المعنى |
|--------|----------|--------|
| **S** | مسؤولية واحدة | كل صنف يفعل شيئاً واحداً |
| **O** | مفتوح/مغلق | مفتوح للتوسع، مغلق للتعديل |
| **L** | ليسكوف | الصنف الابن يحل محل الأب |
| **I** | إفراز الواجهات | واجهات صغيرة متخصصة |
| **D** | عكس التبعية | اعتمد على التجريد لا التنفيذ |

```sad
# ✗ ينتهك مبدأ المسؤولية الواحدة
صنف تقرير_سيء
   دالة احسب_المجموع(بيانات)
      # حساب ...
   نهاية
   دالة نسّق_html(بيانات)
      # تنسيق ...
   نهاية
   دالة أرسل_بريد(تقرير)
      # إرسال ...
   نهاية
نهاية

# ✓ كل صنف مسؤول عن شيء واحد
صنف حاسبة_تقارير
   دالة احسب_المجموع(بيانات)
      متغير مجموع = 0
      لكل عنصر في بيانات
         مجموع = مجموع + عنصر
      نهاية
      ارجع مجموع
   نهاية
نهاية

صنف منسق_html
   دالة نسّق(بيانات)
      ارجع "<table>" + بيانات + "</table>"
   نهاية
نهاية

صنف مرسل_بريد
   دالة أرسل(محتوى، إلى)
      # إرسال البريد
   نهاية
نهاية
```

## خلاصة

| النمط | متى تستخدمه |
|-------|-------------|
| ملف واحد | سكريبتات صغيرة (<100 سطر) |
| مجلدات وملفات | مشاريع متوسطة |
| MVC | تطبيقات تفاعلية |
| طبقات | تطبيقات مؤسسية |
| وحدات | مكتبات قابلة لإعادة الاستخدام |

## تمارين

1. حوّل مشروعاً من ملف واحد إلى بنية MVC بـ 3 ملفات على الأقل.
2. ابنِ نظام مكتبة باستخدام نمط الطبقات (بيانات + أعمال + واجهة).
3. طبّق مبدأ المسؤولية الواحدة على صنف `مدير_متجر` يفعل كل شيء.
4. صمم بنية مشروع لتطبيق دردشة (chat) مع رسم توضيحي للمجلدات.
