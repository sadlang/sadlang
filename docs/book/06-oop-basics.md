# الفصل السادس: البرمجة الكائنية — الأساسيات

## مقدمة

البرمجة الكائنية في لغة ص وسيلة لبناء نماذج مجال واضحة، وليست هدفاً بحد ذاته. يتعلم القارئ كيف يصمم صنفاً يمثل مفهوماً حقيقياً في التطبيق، وكيف يستخدم الباني والخصائص والدوال العضوية لتنظيم المنطق بشكل قابل للتوسع.

---

## 1. تعريف الأصناف

الصنف في لغة ص يُعرَّف بالكلمة المفتاحية `صنف` وينتهي بـ `نهاية`:

```sad
صنف شخص
    نص الاسم
    رقم العمر

    باني(نص اسم، رقم عمر)
        الاسم = اسم
        العمر = عمر
    نهاية

    دالة تعريف()
        ارجع "أنا " + الاسم + " وعمري " + العمر
    نهاية
نهاية
```

يتكون الصنف من:
- **الحقول** (الخصائص): متغيرات تحدد حالة الكائن.
- **الباني** (`باني`): دالة خاصة تُنفَّذ عند إنشاء كائن جديد.
- **الدوال العضوية**: دوال تعمل على بيانات الكائن.

## 2. إنشاء الكائنات

لإنشاء كائن من صنف، نستخدم الكلمة `جديد`:

```sad
متغير أحمد = جديد شخص("أحمد"، 30)
اطبع_سطر(أحمد.تعريف())
# المخرج: أنا أحمد وعمري 30
```

يمكن إنشاء عدة كائنات من نفس الصنف، كل منها يحتفظ ببياناته المستقلة:

```sad
متغير سارة = جديد شخص("سارة"، 25)
متغير خالد = جديد شخص("خالد"، 35)
اطبع_سطر(سارة.تعريف())
اطبع_سطر(خالد.تعريف())
```

## 3. الكلمة المفتاحية `هذا`

`هذا` تُستخدم للتفريق بين الحقول والمعاملات عندما يتشابه الاسم:

```sad
صنف منتج
    نص الاسم
    عشري السعر

    باني(نص الاسم، عشري السعر)
        هذا.الاسم = الاسم
        هذا.السعر = السعر
    نهاية

    دالة اعرض()
        اطبع_سطر(هذا.الاسم + ": " + هذا.السعر + " ريال")
    نهاية
نهاية
```

## 4. الوراثة

الوراثة تسمح ببناء صنف جديد يعتمد على صنف موجود باستخدام `يرث`:

```sad
صنف حيوان
    نص الاسم

    باني(نص اسم)
        الاسم = اسم
    نهاية

    دالة صوت()
        ارجع "..."
    نهاية
نهاية

صنف قط يرث حيوان
    باني(نص اسم)
        الأساس(اسم)
    نهاية

    دالة صوت()
        ارجع "مياو!"
    نهاية
نهاية

صنف كلب يرث حيوان
    باني(نص اسم)
        الأساس(اسم)
    نهاية

    دالة صوت()
        ارجع "هاو هاو!"
    نهاية
نهاية

متغير ق = جديد قط("ميشو")
متغير ك = جديد كلب("ريكس")
اطبع_سطر(ق.الاسم + " يقول: " + ق.صوت())
اطبع_سطر(ك.الاسم + " يقول: " + ك.صوت())
```

**ملاحظة:** `الأساس(...)` تستدعي باني الصنف الأب لتمرير المعاملات اللازمة.

## 5. محددات الوصول

لغة ص تدعم ثلاث مستويات وصول:

| المحدد | الوصف |
|--------|-------|
| `عام` | متاح من أي مكان (الافتراضي) |
| `خاص` | متاح فقط داخل الصنف نفسه |
| `محمي` | متاح داخل الصنف والأصناف الوارثة |

```sad
صنف حساب_بنكي
    خاص عشري الرصيد

    باني(عشري رصيد_أولي)
        الرصيد = رصيد_أولي
    نهاية

    عام دالة إيداع(عشري مبلغ)
        إذا (مبلغ > 0)
            الرصيد += مبلغ
        نهاية
    نهاية

    عام دالة الرصيد_الحالي()
        ارجع الرصيد
    نهاية
نهاية

متغير حسابي = جديد حساب_بنكي(1000.0)
حسابي.إيداع(500.0)
اطبع_سطر("الرصيد: " + حسابي.الرصيد_الحالي())
# المخرج: الرصيد: 1500
```

## 6. الأعضاء الساكنة

الأعضاء الساكنة مشتركة بين جميع كائنات الصنف:

```sad
صنف عداد
    ساكن رقم العدد = 0

    باني()
        عداد.العدد += 1
    نهاية

    ساكن دالة الإجمالي()
        ارجع عداد.العدد
    نهاية
نهاية

متغير أ = جديد عداد()
متغير ب = جديد عداد()
اطبع_سطر("عدد الكائنات: " + عداد.الإجمالي())
# المخرج: عدد الكائنات: 2
```

## 7. مثال تطبيقي: نظام مكتبة

```sad
صنف كتاب
    نص العنوان
    نص المؤلف
    رقم السنة
    منطقي متاح

    باني(نص عنوان، نص مؤلف، رقم سنة)
        العنوان = عنوان
        المؤلف = مؤلف
        السنة = سنة
        متاح = صحيح
    نهاية

    دالة استعر()
        إذا (متاح)
            متاح = خطأ
            اطبع_سطر("تمت الاستعارة: " + العنوان)
        وإلا
            اطبع_سطر("الكتاب غير متاح: " + العنوان)
        نهاية
    نهاية

    دالة أرجع()
        متاح = صحيح
        اطبع_سطر("تم الإرجاع: " + العنوان)
    نهاية

    دالة اعرض()
        متغير حالة = "متاح"
        إذا (ليس متاح)
            حالة = "مستعار"
        نهاية
        اطبع_سطر(العنوان + " — " + المؤلف + " (" + السنة + ") [" + حالة + "]")
    نهاية
نهاية

متغير ك1 = جديد كتاب("الرحيق المختوم"، "المباركفوري"، 1976)
متغير ك2 = جديد كتاب("مقدمة ابن خلدون"، "ابن خلدون"، 1377)

ك1.اعرض()
ك1.استعر()
ك1.اعرض()
ك1.أرجع()
ك1.اعرض()
```

## تمارين

1. أنشئ صنف `طالب` يحتوي على الاسم والعمر والدرجة، مع دالة `نجح()` تتحقق إن كانت الدرجة >= 50.
2. أنشئ صنف `سيارة` يرث من `مركبة`، وأضف خاصية `عدد_الأبواب`.
3. صمم صنف `قائمة_مهام` يسمح بإضافة وحذف وعرض المهام.
4. أضف عداداً ساكناً لصنف `طالب` يحسب عدد الطلاب المسجلين.
