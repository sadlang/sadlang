# الفصل السابع والعشرون: واجهات المستخدم الرسومية (GUI)

## مقدمة نظرية

**واجهة المستخدم الرسومية** (GUI) تتيح التفاعل مع البرنامج بصرياً عبر نوافذ، أزرار، وحقول نص. لغة ص تدعم بناء واجهات عبر مكتبة الرسوميات المدمجة.

| المفهوم | الوصف |
|---------|-------|
| **عنصر** (Widget) | وحدة بناء الواجهة (زر، نص، حقل) |
| **تخطيط** (Layout) | ترتيب العناصر (عمودي، أفقي، شبكي) |
| **حدث** (Event) | فعل المستخدم (نقر، كتابة، تمرير) |
| **حالة** (State) | بيانات تتغير وتُحدّث الواجهة |

## 1. نافذة بسيطة

```sad
من "واجهات" استورد نافذة، نص، زر

متغير تطبيق = جديد نافذة("تطبيقي الأول"، 400، 300)

تطبيق.أضف(جديد نص("مرحباً بالعالم! 🌍"))
تطبيق.أضف(جديد زر("اضغط هنا"، دالة()
   اطبع_سطر("تم الضغط!")
نهاية))

تطبيق.اعرض()
```

## 2. التخطيطات

```sad
من "واجهات" استورد نافذة، عمود، صف، نص، زر، حقل_نص

         نهاية)،
         جديد زر("إلغاء"، دالة()
            اطبع_سطر("تم الإلغاء")
         نهاية)
      ])
   ])
)

تطبيق.اعرض()
```

## 3. إدارة الحالة

```sad
من "واجهات" استورد نافذة، عمود، نص، زر

متغير عداد = 0

دالة بناء_واجهة()
   ارجع جديد عمود([
      جديد نص("العداد: " + عداد)،
      جديد زر("زيادة +"، دالة()
         عداد = عداد + 1
         تطبيق.حدّث()
      نهاية)،
      جديد زر("إنقاص −"، دالة()
         عداد = عداد - 1
         تطبيق.حدّث()
      نهاية)،
      جديد زر("صفر"، دالة()
         عداد = 0
         تطبيق.حدّث()
      نهاية)
   ])
نهاية

متغير تطبيق = جديد نافذة("عداد"، 300، 200)
تطبيق.المحتوى = بناء_واجهة
تطبيق.اعرض()
```

## 4. قوائم ديناميكية

```sad
من "واجهات" استورد نافذة، عمود، صف، نص، زر، حقل_نص، قائمة

متغير المهام = []
متغير حقل_إدخال = ""

دالة بناء_مهام()
   متغير عناصر = []
   متغير ي = 0
   لكل مهمة في المهام
      عناصر.أضف(
         جديد صف([
            جديد نص("• " + مهمة)،
            جديد زر("حذف"، لامدا()
               المهام.احذف(ي)
               تطبيق.حدّث()
            نهاية)
         ])
      )
      ي = ي + 1
   نهاية

   ارجع جديد عمود([
      جديد نص("قائمة المهام (" + طول(المهام) + ")")،
      جديد حقل_نص("مهمة جديدة..."، دالة(نص)
         حقل_إدخال = نص
      نهاية)،
      جديد زر("أضف"، دالة()
         إذا (حقل_إدخال != "")
            المهام.أضف(حقل_إدخال)
            تطبيق.حدّث()
         نهاية
      نهاية)،
      جديد قائمة(عناصر)
   ])
نهاية

متغير تطبيق = جديد نافذة("مهامي"، 400، 500)
تطبيق.المحتوى = بناء_مهام
تطبيق.اعرض()
```

## خلاصة

| العنصر | الاستخدام |
|--------|-----------|
| `نافذة` | الحاوية الرئيسية |
| `نص` | عرض نص |
| `زر` | تفاعل بالنقر |
| `حقل_نص` | إدخال المستخدم |
| `عمود` / `صف` | تخطيط عمودي/أفقي |
| `قائمة` | عناصر ديناميكية |

## تمارين

1. ابنِ آلة حاسبة رسومية مع أزرار الأرقام والعمليات.
2. ابنِ محرر نصوص بسيط مع أزرار (فتح/حفظ/جديد).
3. ابنِ لعبة تيك تاك تو (X-O) رسومية.
4. ابنِ تطبيق ساعة رقمية تُحدّث كل ثانية.
