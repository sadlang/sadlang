# الفصل السادس والعشرون: قواعد البيانات (Database)

## مقدمة نظرية

**قاعدة البيانات** نظام لتخزين البيانات واسترجاعها بكفاءة. أنواعها:

| النوع | مثال | الاستخدام |
|-------|------|-----------|
| علائقية (SQL) | SQLite, PostgreSQL | بيانات منظمة، علاقات |
| مستندات (NoSQL) | MongoDB | بيانات مرنة، JSON |
| مفتاح/قيمة | Redis | تخزين مؤقت، جلسات |
| ملفية | قاعدة ص | بيانات بسيطة، محلية |

## 1. قاعدة بيانات ملفية (بلغة ص)

   نهاية

      نهاية

      هذا.البيانات[جدول].أضف(سجل)
      هذا._احفظ()
      ارجع سجل["_id"]
   نهاية

   عام دالة ابحث(جدول، شرط)
      إذا (هذا.البيانات[جدول] == لاشيء)
         ارجع []
      نهاية
      متغير نتائج = []
      لكل سجل في هذا.البيانات[جدول]

      ارجع نتائج
   نهاية

   عام دالة الكل(جدول)
      إذا (هذا.البيانات[جدول] == لاشيء)
         ارجع []
      نهاية
      ارجع هذا.البيانات[جدول]
   نهاية

   عام دالة حدّث(جدول، معرف، تعديلات)
      لكل سجل في هذا.البيانات[جدول]

            لكل مفتاح في تعديلات
               سجل[مفتاح] = تعديلات[مفتاح]
            نهاية
            هذا._احفظ()

      نهاية
      ارجع خطأ
   نهاية

   عام دالة احذف(جدول، معرف)
      متغير الجديدة = []
      لكل سجل في هذا.البيانات[جدول]

      اكتب_ملف(هذا.المسار، نص_json(هذا.البيانات))

## 2. SQLite (عبر المكتبة القياسية)

```sad
من "قاعدة" استورد sqlite

متغير قب = sqlite.افتح("مدرسة.db")

# إنشاء جدول
قب.نفّذ("CREATE TABLE IF NOT EXISTS طلاب (id INTEGER PRIMARY KEY, اسم TEXT, درجة INTEGER)")

# إدراج بيانات (مع معاملات آمنة لمنع حقن SQL)
قب.نفّذ("INSERT INTO طلاب (اسم, درجة) VALUES (?, ?)"، ["أحمد"، 95])
قب.نفّذ("INSERT INTO طلاب (اسم, درجة) VALUES (?, ?)"، ["سارة"، 88])

# استعلام
متغير نتائج = قب.استعلم("SELECT * FROM طلاب WHERE درجة > ?"، [80])
لكل صف في نتائج
   اطبع_سطر(صف["اسم"] + ": " + صف["درجة"])
نهاية

قب.أغلق()
```

## 3. نمط المستودع (Repository Pattern)

فصل منطق البيانات عن المنطق التجاري:

```sad
صنف مستودع_طلاب
   عام باني(قب)
      هذا.قب = قب
   نهاية

   عام دالة أضف(اسم، درجة)
      ارجع هذا.قب.أضف("طلاب"، {"اسم": اسم، "درجة": درجة})
   نهاية

   عام دالة الناجحون()
      ارجع هذا.قب.ابحث("طلاب"، لامدا(ط) ط["درجة"] >= 60 نهاية)
   نهاية

   عام دالة المتفوقون()
      ارجع هذا.قب.ابحث("طلاب"، لامدا(ط) ط["درجة"] >= 90 نهاية)
   نهاية

   عام دالة المعدل_العام()
      متغير الكل = هذا.قب.الكل("طلاب")
      إذا (طول(الكل) == 0)
         ارجع 0
      نهاية
      متغير مجموع = 0
      لكل ط في الكل
         مجموع = مجموع + ط["درجة"]
      نهاية
      ارجع مجموع / طول(الكل)
   نهاية
نهاية

# الاستخدام
متغير قب = جديد قاعدة_بيانات("بيانات.json")
متغير طلاب = جديد مستودع_طلاب(قب)

طلاب.أضف("فاطمة"، 95)
طلاب.أضف("عمر"، 72)
طلاب.أضف("نورة"، 58)

اطبع_سطر("المعدل: " + طلاب.المعدل_العام())
اطبع_سطر("عدد المتفوقين: " + طول(طلاب.المتفوقون()))
```

## خلاصة

| العملية | القاعدة الملفية | SQLite |
|---------|----------------|--------|
| إنشاء | `أضف(جدول, سجل)` | `INSERT INTO` |
| قراءة | `ابحث(جدول, شرط)` | `SELECT ... WHERE` |
| تحديث | `حدّث(جدول, id, ...)` | `UPDATE ... SET` |
| حذف | `احذف(جدول, id)` | `DELETE FROM` |

## تمارين

1. أضف لقاعدة البيانات الملفية: فهرس (index) على حقل لتسريع البحث.
2. ابنِ نظام تسجيل مستخدمين مع تشفير كلمة السر.
3. ابنِ نظام حجز مع التحقق من التعارضات الزمنية.
4. أضف خاصية "هجرة" (migration) — تحديث هيكل القاعدة تلقائياً.
