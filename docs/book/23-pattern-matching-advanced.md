# الفصل الثالث والعشرون: مطابقة الأنماط المتقدمة (Advanced Pattern Matching)

## مقدمة نظرية

تعرفنا في فصول سابقة على `طابق`/`عندما` للمطابقة البسيطة. هذا الفصل يتعمق في الأنماط المتقدمة: نطاقات، تفكيك البنى، ربط المتغيرات، والأنماط المتداخلة.

---

## 1. مطابقة النطاقات

```sad
دالة فئة_العمر(عمر)
   طابق (عمر)
      عندما 0..2:
         ارجع "رضيع 👶"
      عندما 3..5:
         ارجع "طفل صغير"
      عندما 6..12:
         ارجع "طفل"
      عندما 13..17:
         ارجع "مراهق"
      عندما 18..64:
         ارجع "بالغ"
      عندما 65..120:
         ارجع "مسن"
      افتراضي:
         ارجع "عمر غير صالح"
   نهاية
نهاية

اطبع_سطر(فئة_العمر(7))    # طفل
اطبع_سطر(فئة_العمر(25))   # بالغ
```

---

## 2. مطابقة OR (بدائل)

```sad
دالة نوع_اليوم(يوم)
   طابق (يوم)
      عندما "السبت" || "الأحد":
         ارجع "عطلة 🎉"
      عندما "الجمعة":
         ارجع "شبه عطلة"
      عندما "الاثنين" || "الثلاثاء" || "الأربعاء" || "الخميس":
         ارجع "يوم عمل 💼"
      افتراضي:
         ارجع "يوم غير معروف"
   نهاية
نهاية

اطبع_سطر(نوع_اليوم("الجمعة"))    # شبه عطلة
اطبع_سطر(نوع_اليوم("السبت"))     # عطلة 🎉
```

---

## 3. تفكيك القوائم

```sad
دالة وصف_قائمة(ق)
   طابق (ق)
      عندما []:
         اطبع_سطر("قائمة فارغة")
      عندما [عنصر]:
         اطبع_سطر("عنصر واحد: " + عنصر)
      عندما [أول، ثاني]:
         اطبع_سطر("عنصران: " + أول + " و " + ثاني)
      عندما [أول، ثاني، باقي]:
         اطبع_سطر("أول عنصرين: " + أول + " و " + ثاني + " + المزيد")
      افتراضي:
         اطبع_سطر("قائمة كبيرة")
   نهاية
نهاية

وصف_قائمة([])            # قائمة فارغة
وصف_قائمة([42])          # عنصر واحد: 42
وصف_قائمة([1، 2])       # عنصران: 1 و 2
وصف_قائمة([1، 2، 3])   # أول عنصرين: 1 و 2 + المزيد
```

---

## 4. مطابقة البنى (Struct Patterns)

```sad
دالة وصف_نقطة(نقطة)
   طابق (نقطة)
      عندما {س: 0، ص: 0}:
         اطبع_سطر("نقطة الأصل")
      عندما {س: 0، ص: ص}:
         اطبع_سطر("على المحور الصادي: " + ص)
      عندما {س: س، ص: 0}:
         اطبع_سطر("على المحور السيني: " + س)
      عندما {س: س، ص: ص}:
         اطبع_سطر("نقطة عامة: (" + س + "، " + ص + ")")
   نهاية
نهاية

وصف_نقطة({"س": 0، "ص": 0})     # نقطة الأصل
وصف_نقطة({"س": 0، "ص": 5})     # على المحور الصادي: 5
وصف_نقطة({"س": 3، "ص": 4})     # نقطة عامة: (3، 4)
```

## 5. الربط مع نمط (Binding)

ربط القيمة المطابقة بمتغير مع شرط إضافي:

```sad
دالة تقييم_درجة(درجة)
   طابق (درجة)
      عندما ن @ 90..100:
         اطبع_سطر("ممتاز! الدرجة " + ن)
      عندما ن @ 80..89:
         اطبع_سطر("جيد جداً: " + ن)
      عندما ن @ 70..79:
         اطبع_سطر("جيد: " + ن)
      عندما ن @ 0..69:
         اطبع_سطر("يحتاج تحسين: " + ن)
      افتراضي:
         اطبع_سطر("درجة خارج النطاق")
   نهاية
نهاية

تقييم_درجة(95)   # ممتاز! الدرجة 95
تقييم_درجة(73)   # جيد: 73
```

## 6. النمط الشامل والتجاهل

```sad
دالة أول_عنصر(قائمة)
   طابق (قائمة)
      عندما [أول، _]:
         ارجع أول     # لا يهم العنصر الثاني
      عندما [أول]:
         ارجع أول
      عندما _:
         ارجع لاشيء    # أي حالة أخرى
   نهاية
نهاية
```

## 7. تطبيق شامل: محلل تعبيرات

```sad
# نظام تقييم تعبيرات حسابية بسيطة
دالة قيّم(تعبير)
   طابق (تعبير)
      عندما {"نوع": "رقم"، "قيمة": ق}:
         ارجع ق
      عندما {"نوع": "جمع"، "يسار": ي، "يمين": م}:
         ارجع قيّم(ي) + قيّم(م)
      عندما {"نوع": "ضرب"، "يسار": ي، "يمين": م}:
         ارجع قيّم(ي) * قيّم(م)
      افتراضي:
         ارمي "تعبير غير معروف"
   نهاية
نهاية

# تمثيل: (3 + 4) × 2
متغير تعبير = {
   "نوع": "ضرب"،
   "يسار": {
      "نوع": "جمع"،
      "يسار": {"نوع": "رقم"، "قيمة": 3}،
      "يمين": {"نوع": "رقم"، "قيمة": 4}
   }،
   "يمين": {"نوع": "رقم"، "قيمة": 2}
}

اطبع_سطر(قيّم(تعبير))   # 14
```

## خلاصة

| نوع النمط | الصيغة | مثال |
|-----------|--------|------|
| حرفي | `عندما 42:` | مطابقة قيمة ثابتة |
| نطاق | `عندما 1..10:` | مجال أرقام |
| OR | `عندما أ \|\| ب:` | بدائل |
| قائمة | `عندما [أ، ب]:` | تفكيك مصفوفة |
| بنية | `عندما {س: س}:` | تفكيك كائن |
| ربط | `عندما ن @ 1..10:` | متغير + شرط |
| شامل | `عندما _:` أو `افتراضي:` | أي شيء |

## تمارين

1. اكتب دالة `شكل_هندسي(شكل)` تستخدم مطابقة بنى لحساب مساحة (دائرة، مربع، مثلث).
2. استخدم النطاقات لتحويل درجة مئوية إلى وصف (مُجمد، بارد، معتدل، حار، ساخن جداً).
3. ابنِ محلل JSON بسيط يستخدم مطابقة الأنماط لتحويل نص إلى بنية بيانات.
4. اكتب دالة تستخدم تفكيك القوائم لتنفيذ `zip` (دمج قائمتين في أزواج).
