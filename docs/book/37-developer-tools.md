# الفصل السابع والثلاثون: أدوات التطوير (Developer Tools)

## مقدمة نظرية

لغة ص تأتي مع مجموعة أدوات متكاملة تسهّل الكتابة والتصحيح والتنسيق:

| الأداة | الأمر | الوظيفة |
|--------|-------|---------|
| **المفسر** | `sad` | تنفيذ ملفات .ص مباشرة |
| **المترجم** | `sadc` | ترجمة إلى ملف تنفيذي أصلي |
| **LSP** | `sad-lsp-server` | دعم المحررات (إكمال، أخطاء، ...) |
| **المنسق** | `sad-fmt` | تنسيق الكود تلقائياً |
| **مدير الحزم** | `sad-pkg` | إدارة المكتبات الخارجية |
| **REPL** | `sad --repl` | تفاعل فوري مع اللغة |

---

## 1. المفسر (sad)

```bash
# تشغيل ملف
sad مشروعي.ص

# تشغيل مع معاملات
sad خادم.ص --منفذ 8080

# وضع التصحيح — يطبع معلومات إضافية
sad --debug مشروعي.ص

# عرض الشجرة النحوية (AST)
sad --ast مشروعي.ص
```

```sad
# ملف: مرحبا.ص
دالة رئيسية()
   اطبع_سطر("مرحباً بالعالم!")
   اطبع_سطر("لغة ص تعمل بنجاح 🎉")
نهاية
```

---

## 2. المترجم (sadc)

المترجم يحوّل كود ص إلى ملف تنفيذي أصلي عبر LLVM:

```
كود .ص → AST → SIR → LLVM IR → ملف تنفيذي
```

```bash
# ترجمة إلى ملف تنفيذي
sadc رئيسي.ص -o تطبيقي

# ترجمة مع تحسينات
sadc رئيسي.ص -o تطبيقي -O2

# عرض SIR (التمثيل الوسيط)
sadc رئيسي.ص --emit-sir

# عرض LLVM IR
sadc رئيسي.ص --emit-llvm
```

| وضع التحسين | الوصف |
|-------------|-------|
| `-O0` | بدون تحسين (افتراضي، للتصحيح) |
| `-O1` | تحسينات بسيطة |
| `-O2` | تحسينات متوسطة (مُوصى به) |
| `-O3` | تحسينات عدوانية (أسرع، حجم أكبر) |

## 3. خادم LSP (sad-lsp-server)

LSP (Language Server Protocol) يُضيف ذكاءً للمحرر:

### الميزات المدعومة

| الميزة | الوصف |
|--------|-------|
| **إكمال تلقائي** | اقتراح دوال ومتغيرات أثناء الكتابة |
| **تشخيص فوري** | أخطاء حمراء وتحذيرات صفراء |
| **اذهب للتعريف** | Ctrl+Click للانتقال لموقع التعريف |
| **معلومات عند التحويم** | عرض نوع المتغير ووثائق الدالة |
| **تلميحات توقيع** | معاملات الدالة أثناء الكتابة |
| **إعادة تسمية** | تغيير اسم متغير في كل الأماكن |
| **تنسيق** | ترتيب الكود تلقائياً |

### إعداد VS Code

```json
{
   "sad.lsp.path": "sad-lsp-server",
   "sad.lsp.trace": "messages",
   "sad.format.onSave": true
}
```

### رموز التشخيص

| الرمز | النوع | المعنى |
|-------|-------|--------|
| ص-ن٢٠١ | خطأ | متغير غير معرف |
| ص-ن٢٠٢ | خطأ | دالة غير معرفة |
| ص-ت١٠٣ | تحذير | صنف غير موجود في ملف مستورد |

## 4. المنسق (sad-fmt)

```bash
# تنسيق ملف واحد
sad-fmt ملف.ص

# تنسيق كل ملفات المشروع
sad-fmt --مسار .

# التحقق فقط (بدون تعديل)
sad-fmt --تحقق ملف.ص

# عرض الفروقات
sad-fmt --فرق ملف.ص
```

### قبل التنسيق:
```sad
دالة   حاسبة( أ،ب )
متغير     نتيجة=أ+ب
       ارجع نتيجة
   نهاية
```

### بعد التنسيق:
```sad
دالة حاسبة(أ، ب)
   متغير نتيجة = أ + ب
   ارجع نتيجة
نهاية
```

## 5. البيئة التفاعلية (REPL)

```bash
$ sad --repl
ص> 2 + 3
5
ص> متغير اسم = "أحمد"
ص> اطبع_سطر("مرحباً " + اسم)
مرحباً أحمد
ص> دالة مربع(ن)
...    ارجع ن * ن
... نهاية
ص> مربع(7)
49
ص> .خروج
```

| أمر REPL | الوظيفة |
|----------|---------|
| `.مساعدة` | عرض الأوامر المتاحة |
| `.مسح` | مسح المتغيرات والدوال |
| `.حفظ ملف.ص` | حفظ الجلسة في ملف |
| `.تحميل ملف.ص` | تحميل ملف في الجلسة |
| `.خروج` | إنهاء REPL |

## 6. سير العمل المتكامل

```bash
# ① إنشاء مشروع
sad-pkg تهيئة مشروعي
cd مشروعي

# ② كتابة الكود (مع LSP في المحرر)
# ... كتابة في VS Code مع إضافة ص ...

# ③ تنسيق
sad-fmt --مسار .

# ④ اختبار سريع بالمفسر
sad رئيسي.ص

# ⑤ ترجمة للإنتاج
sadc رئيسي.ص -o تطبيقي -O2

# ⑥ اختبار
sad اختبارات/

# ⑦ نشر
sad-pkg نشر
```

---

## خلاصة

| الأداة | أمر سريع | الحالة |
|--------|----------|--------|
| مفسر | `sad ملف.ص` | شجري (treewalk) |
| مترجم | `sadc ملف.ص -o app` | LLVM native |
| LSP | تلقائي مع المحرر | 28 مزوداً |
| منسق | `sad-fmt ملف.ص` | تنسيق عربي |
| حزم | `sad-pkg تثبيت` | اعتمادات |
| REPL | `sad --repl` | تجربة فورية |

## تمارين

1. شغّل المفسر مع `--ast` على ملف بسيط واشرح الشجرة الناتجة.
2. قارن أداء المفسر مع المترجم على برنامج فيبوناتشي(35).
3. أعد تنسيق ملف فوضوي باستخدام `sad-fmt` ولاحظ التغييرات.
4. استخدم REPL لاستكشاف الأنواع المدمجة (رقم، نص، مصفوفة، خريطة).
