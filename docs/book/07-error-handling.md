# الفصل السابع: معالجة الأخطاء

## مقدمة

البرامج الجيدة لا تتجنب الأخطاء فقط، بل تتعامل معها بوضوح ومسؤولية. يقدم هذا الفصل نظام معالجة الأخطاء في لغة ص باستخدام `حاول`/`امسك`/`أخيراً` وآلية `ارمي`.

---

## 1. كتلة حاول / امسك

الطريقة الأساسية لالتقاط الأخطاء:

```sad
حاول
    متغير نتيجة = 10 / 0
امسك (خطأ)
    اطبع_سطر("حدث خطأ: " + خطأ)
نهاية
```

`حاول` تحيط بالكود الذي قد يُنتج خطأً، و`امسك` تلتقط الخطأ وتتيح لك التعامل معه.

## 2. رمي الأخطاء

يمكنك رمي أخطاء مخصصة باستخدام `ارمي`:

```sad
دالة قسمة(رقم أ، رقم ب)
    إذا (ب == 0)
        ارمي "لا يمكن القسمة على صفر"
    نهاية
    ارجع أ / ب
نهاية

حاول
    متغير ن = قسمة(10، 0)
امسك (خطأ)
    اطبع_سطر("خطأ: " + خطأ)
نهاية
# المخرج: خطأ: لا يمكن القسمة على صفر
```

## 3. كتلة أخيراً

`أخيراً` تُنفَّذ دائماً سواء حدث خطأ أم لا — مفيدة لتنظيف الموارد:

```sad
حاول
    اطبع_سطر("فتح الملف...")
    ارمي "الملف تالف"
امسك (خ)
    اطبع_سطر("خطأ: " + خ)
أخيراً
    اطبع_سطر("إغلاق الملف...")
نهاية
```

**المخرج:**
```
فتح الملف...
خطأ: الملف تالف
إغلاق الملف...
```

## 4. الأخطاء المتداخلة

يمكن تداخل كتل `حاول` للتعامل مع مستويات مختلفة من الأخطاء:

```sad
حاول
    اطبع_سطر("المستوى الخارجي")
    حاول
        ارمي "خطأ داخلي"
    امسك (خ)
        اطبع_سطر("التقاط داخلي: " + خ)
        ارمي "خطأ مُعاد رميه"
    نهاية
امسك (خ)
    اطبع_سطر("التقاط خارجي: " + خ)
نهاية
```

## 5. أنماط معالجة الأخطاء

### النمط الدفاعي: التحقق المسبق

```sad
دالة ابحث_في_مصفوفة(مصفوفة م، رقم فهرس)
    إذا (فهرس < 0 أو فهرس >= طول(م))
        ارمي "فهرس خارج النطاق: " + فهرس
    نهاية
    ارجع م[فهرس]
نهاية
```

### النمط التراكمي: جمع الأخطاء

```sad
دالة تحقق_بيانات(نص الاسم، رقم العمر، نص البريد)
    متغير أخطاء = []
    
    إذا (الاسم == "")
        أخطاء.أضف("الاسم مطلوب")
    نهاية
    
    إذا (العمر < 0 أو العمر > 150)
        أخطاء.أضف("العمر غير صالح")
    نهاية
    
    إذا (طول(أخطاء) > 0)
        ارمي "أخطاء التحقق: " + أخطاء
    نهاية
    
    ارجع صحيح
نهاية
```

## 6. مثال تطبيقي: قارئ ملفات آمن

```sad
دالة اقرأ_إعدادات(نص المسار)
    متغير محتوى = ""
    
    حاول
        إذا (المسار == "")
            ارمي "مسار الملف فارغ"
        نهاية
        
        # محاكاة قراءة ملف
        محتوى = "إعداد1=قيمة1"
        اطبع_سطر("تم قراءة الملف بنجاح")
        
    امسك (خ)
        اطبع_سطر("تحذير: " + خ)
        اطبع_سطر("استخدام القيم الافتراضية")
        محتوى = "إعداد1=افتراضي"
        
    أخيراً
        اطبع_سطر("انتهت عملية القراءة")
    نهاية
    
    ارجع محتوى
نهاية

متغير إعدادات = اقرأ_إعدادات("config.sad")
اطبع_سطر("الإعدادات: " + إعدادات)
```

## إرشادات عملية

1. **لا تلتقط كل شيء** — التقط فقط الأخطاء التي تستطيع التعامل معها بشكل مفيد.
2. **رسائل واضحة** — اجعل رسالة الخطأ تصف المشكلة والسياق بدقة.
3. **أخيراً للموارد** — استخدم `أخيراً` لضمان تنظيف الموارد (ملفات، اتصالات).
4. **التحقق المسبق** — تحقق من المدخلات قبل المعالجة بدلاً من الاعتماد على الالتقاط.

## تمارين

1. اكتب دالة `حوّل_لرقم(نص ن)` ترمي خطأً إذا لم يكن النص رقماً صالحاً.
2. صمم نظام تسجيل دخول يرمي أخطاء مختلفة حسب نوع المشكلة (كلمة سر خاطئة، مستخدم غير موجود).
3. أنشئ دالة تقرأ قائمة ملفات وتجمع كل الأخطاء ثم تعرضها مرة واحدة.
4. اكتب كتلة `حاول/امسك/أخيراً` تحاكي فتح اتصال بقاعدة بيانات مع ضمان الإغلاق.
