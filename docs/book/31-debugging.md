# الفصل الحادي والثلاثون: تصحيح الأخطاء (Debugging)

## مقدمة نظرية

**تصحيح الأخطاء** عملية البحث عن الأخطاء وإصلاحها. المبرمج يقضي ~50% من وقته في التصحيح.

| نوع الخطأ | الوصف | مثال |
|-----------|-------|------|
| **نحوي** (Syntax) | خطأ في بناء الجملة | `إذا` بدون `نهاية` |
| **منطقي** (Logic) | تنفيذ خاطئ للمنطق | `>` بدلاً من `<` |
| **تنفيذي** (Runtime) | ينهار أثناء التشغيل | القسمة على صفر |
| **دلالي** (Semantic) | يعمل لكن النتيجة خاطئة | خوارزمية خاطئة |

---

## 1. الطباعة التشخيصية

أبسط وأقدم أداة تصحيح:

```sad
دالة بحث_ثنائي(قائمة، هدف)
   متغير يسار = 0
   متغير يمين = طول(قائمة) - 1
   متغير خطوة = 0

   بينما (يسار <= يمين)
      خطوة = خطوة + 1
      متغير وسط = (يسار + يمين) / 2

      # ← طباعة تشخيصية
      اطبع_سطر("[خطوة " + خطوة + "] يسار=" + يسار +
                " يمين=" + يمين + " وسط=" + وسط +
                " قيمة=" + قائمة[وسط])

      إذا (قائمة[وسط] == هدف)
         اطبع_سطر("وُجد في الخطوة " + خطوة)
         ارجع وسط
      وإلا
         إذا (قائمة[وسط] < هدف)
            يسار = وسط + 1
         وإلا
            يمين = وسط - 1
         نهاية
      نهاية
   نهاية
   ارجع -1
نهاية

بحث_ثنائي([2، 5، 8، 12، 16، 23، 38، 56، 72، 91]، 23)
```

## 2. أنماط أخطاء شائعة

```sad
# ① خطأ الفهرس — Off-by-One
دالة عناصر_سيء(قائمة)
   متغير ي = 0
   بينما (ي <= طول(قائمة))  # ✗ <= بدلاً من <
      اطبع(قائمة[ي])
      ي = ي + 1
   نهاية
نهاية

دالة عناصر_صحيح(قائمة)
   متغير ي = 0
   بينما (ي < طول(قائمة))   # ✓
      اطبع(قائمة[ي])
      ي = ي + 1
   نهاية
نهاية

# ② حلقة لا نهائية
# ✗ نسيان زيادة العداد:
# بينما (ي < 10)
#    اطبع(ي)     # ي لا يتغير أبداً!
# نهاية

# ③ مقارنة بدلاً من إسناد
# ✗ إذا (س == 5)     # مقارنة — صحيح
# ✗ إذا (س = 5)      # ← خطأ نحوي في بعض السياقات

# ④ لاشيء غير المتوقع
دالة طول_آمن(نص)
   إذا (نص == لاشيء)
      ارجع 0
   نهاية
   ارجع طول(نص)
نهاية
```

## 3. تتبع المكدس (Stack Trace)

```sad
دالة أ()
   ب()
نهاية

دالة ب()
   ج()
نهاية

دالة ج()
   ارمي "خطأ في الدالة ج!"
نهاية

حاول
   أ()
امسك (خطأ)
   اطبع_سطر("الخطأ: " + خطأ)
   # المفسر يعرض تتبع المكدس:
   # ج() → ب() → أ() → الرئيسي
نهاية
```

## 4. سجل تصحيح متدرج

```sad
ثابت مستوى_تصحيح = 2   # 0=بدون، 1=أخطاء، 2=تحذيرات، 3=كل شيء

دالة سجل(مستوى، رسالة)
   إذا (مستوى <= مستوى_تصحيح)
      متغير بادئة = ""
      طابق (مستوى)
         عندما 1: بادئة = "[خطأ] "
         عندما 2: بادئة = "[تحذير] "
         عندما 3: بادئة = "[معلومات] "
      نهاية
      اطبع_سطر(بادئة + رسالة)
   نهاية
نهاية

سجل(1، "فشل الاتصال بالقاعدة")      # يظهر
سجل(2، "الذاكرة المتاحة منخفضة")    # يظهر
سجل(3، "بدء معالجة الطلب #42")       # لا يظهر (مستوى 3 > 2)
```

---

## 5. منهجية التصحيح

1. **أعد إنتاج الخطأ** — حدد الخطوات الدقيقة
2. **اعزل المشكلة** — صغّر الكود حتى تجد السبب
3. **اقرأ رسالة الخطأ** — غالباً تُخبرك بالسطر والسبب
4. **استخدم الطباعة** — اطبع القيم قبل وبعد كل خطوة
5. **راجع الافتراضات** — هل المُدخلات كما تتوقع؟
6. **استرح ثم عُد** — عيون جديدة ترى أخطاء جديدة

---

## خلاصة

| الأداة | الاستخدام |
|--------|-----------|
| `اطبع_سطر()` | أبسط أداة تشخيص |
| `حاول/امسك` | التقاط الأخطاء التنفيذية |
| سجل متدرج | تحكم في مستوى التفاصيل |
| اختبارات وحدة | كشف الأخطاء مبكراً |
| LSP | تحذيرات فورية أثناء الكتابة |

## تمارين

1. اكتب دالة فيها 3 أخطاء مخفية، ثم صححها واشرح كيف وجدتها.
2. ابنِ صنف `مصحح` يسجل كل استدعاء دالة مع المعاملات والنتيجة.
3. اكتب دالة تكتشف الحلقات اللانهائية (تتوقف بعد حد معين من التكرارات).
4. استخدم LSP لاكتشاف 5 أخطاء في ملف .ص وصححها.
