# الفصل الأربعون: تطوير تطبيقات الهاتف (Mobile Development)

## مقدمة نظرية

لغة ص تدعم تطوير تطبيقات الهاتف لـ **Android** و **iOS** عبر أدوات مدمجة تحوّل كود ص إلى كود أصلي لكل منصة.

| المنصة | الأداة | التقنية | المخرج |
|--------|--------|---------|--------|
| Android | `sad-android` | Kotlin + Jetpack Compose | APK/AAB |
| iOS | `sad-ios` | Swift + SwiftUI | IPA/Xcode Project |

### المعمارية

```
كود ص (.ص)
    ↓
┌───────────────────┐
│   محلل الواجهات    │  يفهم عرض()، زر()، نص()
├───────────────────┤
│   مولد الكود       │  يولد Kotlin أو Swift
├───────────────────┤
│   بناء المشروع     │  Gradle أو Xcode
└───────────────────┘
    ↓
تطبيق أصلي (APK / IPA)
```

## 1. تطبيقك الأول (Hello World)

```sad
# ملف: تطبيقي.ص
استورد تطبيق، نص، عمود من "واجهة"

دالة الرئيسية()
   تطبيق("تطبيقي الأول")
      عمود()
         نص("مرحباً بالعالم! 🌍")
         نص("مصنوع بلغة ص")
      نهاية
   نهاية
نهاية
```

```bash
# لـ Android
sad-android create تطبيقي
sad-android build

# لـ iOS
sad-ios create تطبيقي
sad-ios build
```

## 2. الواجهات التفاعلية

### الأزرار والنقر

```sad
استورد تطبيق، عمود، زر، نص، حالة من "واجهة"

دالة الرئيسية()
   متغير عدد = حالة(0)

   تطبيق("عداد")
      عمود(محاذاة: "وسط")
         نص("العدد: " + عدد.القيمة)
            .حجم_خط(32)
            .لون("أزرق")

         صف()
            زر("➕ زيادة")
               .عند_النقر(لامدا()
                  عدد.عيّن(عدد.القيمة + 1)
               نهاية)

            زر("➖ نقصان")
               .عند_النقر(لامدا()
                  عدد.عيّن(عدد.القيمة - 1)
               نهاية)
         نهاية
      نهاية
   نهاية
نهاية
```

## 3. القوائم والتمرير

```sad
استورد تطبيق، عمود، قائمة، عنصر_قائمة، حقل_نص، زر من "واجهة"

صنف تطبيق_مهام
   متغير مهام = حالة([])
   متغير إدخال = حالة("")

   دالة عرض()
      عمود(هامش: 16)
         نص("📝 قائمة المهام")
            .حجم_خط(24)
            .سُمك("عريض")

         صف()
            حقل_نص("أضف مهمة...")
               .قيمة(إدخال.القيمة)
               .عند_التغيير(لامدا(نص_جديد)
                  إدخال.عيّن(نص_جديد)
               نهاية)

            زر("أضف")
               .عند_النقر(لامدا()
                  إذا (طول(إدخال.القيمة) > 0)
                     متغير جديدة = مهام.القيمة
                     جديدة[طول(جديدة)] = إدخال.القيمة
                     مهام.عيّن(جديدة)
                     إدخال.عيّن("")
                  نهاية
               نهاية)
         نهاية

         قائمة(مهام.القيمة)
            لكل مهمة في مهام.القيمة
               عنصر_قائمة()
                  نص(مهمة)
               نهاية
            نهاية
         نهاية
      نهاية
   نهاية
نهاية
```

## 4. التنقل بين الشاشات

```sad
استورد تطبيق، متنقل، شاشة، زر، نص من "واجهة"

دالة الرئيسية()
   تطبيق("متعدد الشاشات")
      متنقل()
         شاشة("الرئيسية"، هي_الافتراضية: صحيح)
            عمود()
               نص("الشاشة الرئيسية")
                  .حجم_خط(28)

               زر("اذهب للإعدادات")
                  .عند_النقر(لامدا()
                     انتقل_إلى("الإعدادات")
                  نهاية)

               زر("اذهب للملف الشخصي")
                  .عند_النقر(لامدا()
                     انتقل_إلى("الملف_الشخصي")
                  نهاية)
            نهاية
         نهاية

         شاشة("الإعدادات")
            عمود()
               نص("الإعدادات ⚙")
               زر("رجوع")
                  .عند_النقر(لامدا()
                     ارجع_للخلف()
                  نهاية)
            نهاية
         نهاية

         شاشة("الملف_الشخصي")
            عمود()
               نص("الملف الشخصي 👤")
               زر("رجوع")
                  .عند_النقر(لامدا()
                     ارجع_للخلف()
                  نهاية)
            نهاية
         نهاية
      نهاية
   نهاية
نهاية
```

## 5. التخطيطات (Layouts)

### عمود (Column) — عناصر تحت بعض

```sad
عمود(محاذاة: "وسط"، فراغ: 8)
   نص("العنوان")
   نص("الوصف")
   زر("اضغط")
نهاية
```

### صف (Row) — عناصر بجانب بعض

```sad
صف(فراغ: 16)
   زر("حفظ")
   زر("إلغاء")
   زر("حذف")
نهاية
```

### شبكة (Grid) — جدول

```sad
شبكة(أعمدة: 3، فراغ: 4)
   لكل ي في نطاق(1، 10)
      زر(نص(ي))
         .عند_النقر(لامدا()
            اطبع(ي)
         نهاية)
   نهاية
نهاية
```

## 6. دعم RTL (العربية)

لغة ص تدعم الاتجاه من اليمين لليسار تلقائياً:

```sad
تطبيق("تطبيق عربي")
   عمود(اتجاه: "يمين_لليسار")
      نص("مرحباً بكم في التطبيق")
         .محاذاة("يمين")
         .خط("Cairo")
         .حجم_خط(20)

      حقل_نص("اكتب اسمك...")
         .محاذاة("يمين")
         .لغة("ar")

      زر("إرسال")
   نهاية
نهاية
```

## أوامر البناء

| الأمر | الوظيفة |
|-------|---------|
| `sad-android create اسم` | إنشاء مشروع Android |
| `sad-android build` | بناء APK |
| `sad-android run` | تشغيل على جهاز/محاكي |
| `sad-ios create اسم` | إنشاء مشروع iOS |
| `sad-ios build` | بناء IPA |
| `sad-ios run` | تشغيل على محاكي |

---

## خلاصة

| المكون | الوظيفة |
|--------|---------|
| `تطبيق()` | نقطة الدخول |
| `عمود()/صف()` | تخطيط العناصر |
| `حالة()` | إدارة الحالة التفاعلية |
| `متنقل()/شاشة()` | التنقل بين الشاشات |
| `عند_النقر()` | معالجة الأحداث |
| RTL | دعم العربية تلقائي |

## تمارين

1. ابنِ تطبيق آلة حاسبة بواجهة شبكة (0-9 + عمليات).
2. ابنِ تطبيق قائمة مشتريات مع إمكانية الإضافة والحذف.
3. ابنِ تطبيق متعدد الشاشات: رئيسية + تفاصيل + إعدادات.
4. ابنِ تطبيق ملاحظات عربي مع دعم RTL الكامل.
