# الفصل الثالث والثلاثون: البرمجة المتزامنة (Concurrency)

## مقدمة نظرية

**التزامن** (Concurrency) يعني تنفيذ عدة مهام في آنٍ واحد أو بالتناوب. يختلف عن **التوازي** (Parallelism):

| المفهوم | الوصف | مثال |
|---------|-------|------|
| **التزامن** | إدارة عدة مهام (قد تتناوب) | طباخ يُعد 3 أطباق بالتبديل |
| **التوازي** | تنفيذ مهام فعلياً بنفس اللحظة | 3 طباخين كل واحد يُعد طبقاً |
| **غير متزامن** | لا تنتظر — تابع عملك | أرسل طلباً وتابع حتى يأتي الرد |

### لماذا التزامن مهم؟
- الشبكة: لا تنتظر استجابة الخادم
- واجهة المستخدم: لا تتجمد أثناء العمليات الطويلة
- أداء: استغلال أنوية المعالج المتعددة

## 1. الدوال غير المتزامنة (Async/Await)

```sad
# تعريف دالة غير متزامنة
غير_متزامن دالة جلب_بيانات(رابط)
   اطبع_سطر("بدء جلب: " + رابط)
   متغير استجابة = انتظر طلب_شبكة(رابط)
   اطبع_سطر("اكتمل: " + رابط)
   ارجع استجابة
نهاية

# الاستدعاء — `انتظر` يوقف الدالة حتى النتيجة
غير_متزامن دالة رئيسية()
   متغير بيانات = انتظر جلب_بيانات("https://api.example.com/users")
   اطبع_سطر("عدد المستخدمين: " + طول(بيانات))
نهاية
```

## 2. تشغيل مهام متعددة بالتوازي

```sad
غير_متزامن دالة جلب_كل_البيانات()
   # ✗ بالتسلسل — بطيء
   # متغير مستخدمون = انتظر جلب("/users")
   # متغير مقالات = انتظر جلب("/posts")
   # متغير تعليقات = انتظر جلب("/comments")
   # الوقت: t1 + t2 + t3

   # ✓ بالتوازي — سريع
   متغير وعود = [
      جلب_بيانات("/users")،
      جلب_بيانات("/posts")،
      جلب_بيانات("/comments")
   ]
   متغير نتائج = انتظر كل(وعود)
   # الوقت: max(t1, t2, t3)

   اطبع_سطر("مستخدمون: " + طول(نتائج[0]))
   اطبع_سطر("مقالات: " + طول(نتائج[1]))
   اطبع_سطر("تعليقات: " + طول(نتائج[2]))
نهاية
```

## 3. معالجة الأخطاء في الكود المتزامن

```sad
غير_متزامن دالة جلب_آمن(رابط)
   حاول
      متغير نتيجة = انتظر طلب_شبكة(رابط)
      ارجع نتيجة
   امسك (خطأ)
      اطبع_سطر("فشل جلب " + رابط + ": " + خطأ)
      ارجع لاشيء
   نهاية
نهاية

غير_متزامن دالة رئيسية()
   # انتظر أول وعد ينجح
   متغير خوادم = [
      "https://server1.example.com"،
      "https://server2.example.com"،
      "https://server3.example.com"
   ]

   لكل خادم في خوادم
      متغير نتيجة = انتظر جلب_آمن(خادم)
      إذا (نتيجة != لاشيء)
         اطبع_سطر("نجح من: " + خادم)
         ارجع نتيجة
      نهاية
   نهاية

   اطبع_سطر("فشلت كل الخوادم!")
نهاية
```

## 4. المولدات غير المتزامنة

```sad

غير_متزامن مولد دالة اقرأ_صفحات(رابط_أساسي)
   متغير صفحة = 1
   بينما (صحيح)
      متغير نتيجة = انتظر جلب_بيانات(رابط_أساسي + "?page=" + صفحة)
      إذا (طول(نتيجة) == 0)
         توقف
      نهاية
      أنتج نتيجة
      صفحة = صفحة + 1
   نهاية
نهاية

# الاستخدام
غير_متزامن دالة اعرض_كل_المستخدمين()
   لكل صفحة في اقرأ_صفحات("/api/users")
      لكل مستخدم في صفحة
         اطبع_سطر(مستخدم)
      نهاية
   نهاية
نهاية
```

```sad
      _مهام[طول(_مهام)] = مهمة
   نهاية

   غير_متزامن دالة نفّذ_التالي()
      إذا (طول(_مهام) == 0)
         ارجع لاشيء
      نهاية
      متغير مهمة = _مهام[0]
      # إزالة أول عنصر
      متغير جديدة = []
      لكل ي في نطاق(1، طول(_مهام))

      نهاية
      _مهام = جديدة

```

## خلاصة

| المفهوم | الكلمة | الاستخدام |
|---------|--------|-----------|
| دالة غير متزامنة | `غير_متزامن دالة` | عمليات I/O |
| انتظار | `انتظر` | انتظار نتيجة |
| تشغيل متوازي | `كل(وعود)` | عدة مهام معاً |
| مولد غير متزامن | `غير_متزامن مولد` | بيانات تدريجية |
| معالجة أخطاء | `حاول/امسك` | أخطاء الشبكة |

## تمارين

1. اكتب دالة غير متزامنة تجلب بيانات من 5 روابط بالتوازي وتطبع أوقات كل منها.
2. ابنِ صنف `مجمّع_طلبات` يجمع عدة طلبات صغيرة ويرسلها كطلب واحد.
3. اكتب نظام `إعادة_محاولة` يعيد استدعاء دالة فاشلة 3 مرات مع تأخير متزايد.
4. ابنِ مولداً غير متزامن يقرأ ملفاً سطراً بسطر مع تأخير محاكاة.
