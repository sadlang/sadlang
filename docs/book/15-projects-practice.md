# الفصل الخامس عشر: مشاريع عملية تطبيقية

## مقدمة

حان وقت التطبيق! في هذا الفصل نبني ثلاثة مشاريع متكاملة تجمع كل ما تعلمناه: متغيرات، دوال، أصناف، وراثة، معالجة أخطاء، وحدات، ومطابقة أنماط.

كل مشروع يمر بدورة كاملة: **تصميم → تنفيذ → اختبار → تحسين**.

---

## المشروع الأول: نظام إدارة مكتبة

### التصميم

نحتاج: كتب، أعضاء، عمليات استعارة وإرجاع.

```sad
صنف كتاب
   عام باني(عنوان، مؤلف، رقم_isbn)
      هذا.عنوان = عنوان
      هذا.مؤلف = مؤلف
      هذا.رقم = رقم_isbn
      هذا.متاح = صحيح
   نهاية

   عام دالة استعر()
      إذا (هذا.متاح)
         هذا.متاح = خطأ
         ارجع صحيح
      نهاية
      ارجع خطأ
   نهاية

   عام دالة أرجع()
      هذا.متاح = صحيح
   نهاية

   عام دالة وصف()
      متغير حالة = "متاح"
      إذا (ليس هذا.متاح)
         حالة = "مُستعار"
      نهاية
      ارجع هذا.عنوان + " — " + هذا.مؤلف + " [" + حالة + "]"
   نهاية
نهاية

صنف عضو
   عام باني(اسم، رقم_عضوية)
      هذا.اسم = اسم
      هذا.رقم = رقم_عضوية
      هذا.كتبي = []
   نهاية

   عام دالة استعر_كتاب(كتاب)
      إذا (كتاب.استعر())
         هذا.كتبي.أضف(كتاب)
         اطبع_سطر(هذا.اسم + " استعار: " + كتاب.عنوان)
      وإلا
         اطبع_سطر("الكتاب غير متاح!")
      نهاية
   نهاية
نهاية
```

### التنفيذ والاختبار

```sad
# إنشاء الكتب
متغير ك1 = جديد كتاب("مقدمة في البرمجة"، "أحمد"، "001")
متغير ك2 = جديد كتاب("هياكل البيانات"، "سارة"، "002")

# إنشاء عضو
متغير طالب = جديد عضو("خالد"، "م100")

# عمليات
طالب.استعر_كتاب(ك1)      # ← خالد استعار: مقدمة في البرمجة
طالب.استعر_كتاب(ك1)      # ← الكتاب غير متاح!
اطبع_سطر(ك1.وصف())       # ← مقدمة في البرمجة — أحمد [مُستعار]
```

## المشروع الثاني: آلة حاسبة ذكية

آلة حاسبة تدعم العمليات الأساسية مع محفوظات ودوال مخصصة:

```sad
صنف حاسبة
   عام باني()
      هذا.النتيجة = 0
      هذا.المحفوظات = []
   نهاية

   عام دالة احسب(عملية، أ، ب)
      متغير ناتج = 0
      طابق (عملية)
         عندما "+":
            ناتج = أ + ب
         عندما "-":
            ناتج = أ - ب
         عندما "*":
            ناتج = أ * ب
         عندما "/":
            إذا (ب == 0)
               اطبع_سطر("خطأ: القسمة على صفر!")
               ارجع لاشيء
            نهاية
            ناتج = أ / ب
         عندما "%":
            ناتج = أ % ب
         افتراضي:
            اطبع_سطر("عملية غير معروفة: " + عملية)
            ارجع لاشيء
      نهاية

      هذا.النتيجة = ناتج
      هذا.المحفوظات.أضف(أ + " " + عملية + " " + ب + " = " + ناتج)
      ارجع ناتج
   نهاية

   عام دالة اعرض_المحفوظات()
      لكل سجل في هذا.المحفوظات
         اطبع_سطر("  " + سجل)
      نهاية
   نهاية
نهاية

متغير ح = جديد حاسبة()
ح.احسب("+"، 10، 5)      # 15
ح.احسب("*"، 3، 7)       # 21
ح.احسب("/"، 10، 0)      # خطأ: القسمة على صفر!
ح.اعرض_المحفوظات()
```

## المشروع الثالث: دفتر ملاحظات

نظام ملاحظات مع بحث وتصنيف:

```sad
صنف ملاحظة
   عام باني(محتوى، تصنيف)
      هذا.محتوى = محتوى
      هذا.تصنيف = تصنيف
      هذا.التاريخ = "2026-03-07"
   نهاية
نهاية

صنف دفتر
   عام باني()
      هذا.الملاحظات = []
   نهاية

   عام دالة أضف(محتوى، تصنيف)
      هذا.الملاحظات.أضف(جديد ملاحظة(محتوى، تصنيف))
      اطبع_سطر("✓ تمت الإضافة")
   نهاية

   عام دالة ابحث(كلمة)
      متغير نتائج = 0
      لكل م في هذا.الملاحظات
         إذا (م.محتوى.يحتوي(كلمة))
            اطبع_سطر("[" + م.تصنيف + "] " + م.محتوى)
            نتائج = نتائج + 1
         نهاية
      نهاية
      إذا (نتائج == 0)
         اطبع_سطر("لا توجد نتائج.")
      نهاية
   نهاية

   عام دالة لكل_تصنيف(تصنيف)
      لكل م في هذا.الملاحظات
         إذا (م.تصنيف == تصنيف)
            اطبع_سطر("• " + م.محتوى)
         نهاية
      نهاية
   نهاية
نهاية

متغير د = جديد دفتر()
د.أضف("تعلم الحلقات في لغة ص"، "برمجة")
د.أضف("قراءة كتاب الخوارزميات"، "قراءة")
د.أضف("مراجعة مفاهيم OOP"، "برمجة")
د.ابحث("برمجة")
د.لكل_تصنيف("برمجة")
```

## خلاصة

| المشروع | المفاهيم المُستخدمة |
|---------|---------------------|
| نظام مكتبة | أصناف، كائنات، حالة داخلية، تعديل مرجعي |
| آلة حاسبة | `طابق`، معالجة الأخطاء، مصفوفات كمحفوظات |
| دفتر ملاحظات | أصناف متداخلة، بحث نصي، تصفية بالشرط |

## تمارين

1. أضف للمكتبة: حد أقصى لعدد الكتب المستعارة لكل عضو (3 كتب).
2. أضف للحاسبة: دعم الأس (`**`) والجذر التربيعي.
3. أضف للدفتر: دالة حذف ملاحظة بالفهرس.
4. ابنِ مشروعاً رابعاً: قائمة مهام (Todo List) مع أولويات.

## إرشادات تطبيقية

1. ابدأ بحالة بسيطة ثم أضف التعقيد تدريجياً.
2. اكتب مثالاً قابلاً للتنفيذ لكل مفهوم.
3. أضف اختبارات للحالات الطبيعية وحالات الحافة.
4. راجع الكود من زاوية القارئ الجديد، لا من زاوية الكاتب فقط.

## تمارين

1. عدّل المثال ليعالج حالة إضافية واقعية.
2. اكتب دالة ثانية تعتمد على نتيجة الدالة الأولى.
3. أنشئ نسخة موثقة بالكامل من المثال مع تعليق يشرح قراراً تصميمياً واحداً.
