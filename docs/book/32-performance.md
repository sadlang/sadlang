# الفصل الثاني والثلاثون: الأداء والتحسين (Performance & Optimization)

## مقدمة نظرية

**تحسين الأداء** يعني جعل البرنامج أسرع أو يستهلك ذاكرة أقل. القاعدة الذهبية: **لا تحسّن مبكراً** — اكتب كوداً واضحاً أولاً، ثم قِس، ثم حسّن الأجزاء البطيئة.

| مفهوم | الوصف |
|-------|-------|
| **Big-O** | تعقيد الخوارزمية (O(1), O(n), O(n²), ...) |
| **Profiling** | قياس وقت كل جزء من البرنامج |
| **Bottleneck** | الجزء الأبطأ الذي يحد الأداء |
| **Caching** | حفظ النتائج لتجنب إعادة الحساب |
| **Lazy Evaluation** | لا تحسب شيئاً حتى تحتاجه |

## 1. قياس الزمن

```sad
دالة قِس_الوقت(دالة_الهدف)
   متغير بداية = الوقت_الحالي()
   دالة_الهدف()
   متغير نهاية_وقت = الوقت_الحالي()
   متغير مضى = نهاية_وقت - بداية
   اطبع_سطر("الوقت: " + مضى + " مللي ثانية")
   ارجع مضى
نهاية

# مقارنة طريقتين للبحث
متغير بيانات = مصفوفة(10000)
لكل ي في نطاق(0، 10000)
   بيانات[ي] = ي
نهاية

قِس_الوقت(لامدا()
   # بحث خطي O(n)
   لكل عنصر في بيانات
      إذا (عنصر == 9999)
         توقف
      نهاية
   نهاية
نهاية)

قِس_الوقت(لامدا()
   # بحث ثنائي O(log n)
   متغير يسار = 0
   متغير يمين = 9999
   بينما (يسار <= يمين)
      متغير وسط = (يسار + يمين) / 2
      إذا (بيانات[وسط] == 9999)
         توقف
      وإلا
         إذا (بيانات[وسط] < 9999)
            يسار = وسط + 1
         وإلا
            يمين = وسط - 1
         نهاية
      نهاية
   نهاية
نهاية)
```

## 2. التخزين المؤقت (Memoization)

```sad
# فيبوناتشي بدون تخزين — O(2ⁿ) !
دالة فيب_بطيء(ن)
   إذا (ن <= 1)
      ارجع ن
   نهاية
   ارجع فيب_بطيء(ن - 1) + فيب_بطيء(ن - 2)
نهاية

# فيبوناتشي مع تخزين مؤقت — O(n)
متغير ذاكرة_فيب = خريطة()

دالة فيب_سريع(ن)
   إذا (ن <= 1)
      ارجع ن
   نهاية
   إذا (ذاكرة_فيب[ن] != لاشيء)
      ارجع ذاكرة_فيب[ن]
   نهاية
   متغير نتيجة = فيب_سريع(ن - 1) + فيب_سريع(ن - 2)
   ذاكرة_فيب[ن] = نتيجة
   ارجع نتيجة
نهاية

اطبع_سطر(فيب_سريع(40))  # فوري!
```

## 3. اختيار هيكل البيانات المناسب

```sad
# ✗ بحث في مصفوفة — O(n)
متغير أسماء = ["أحمد"، "سارة"، "خالد"، "منى"]
لكل اسم في أسماء
   إذا (اسم == "خالد")
      اطبع_سطر("موجود!")
      توقف
   نهاية
نهاية

# ✓ بحث في خريطة — O(1)
متغير فهرس = خريطة()
فهرس["أحمد"] = صحيح
فهرس["سارة"] = صحيح
فهرس["خالد"] = صحيح
فهرس["منى"] = صحيح

إذا (فهرس["خالد"] != لاشيء)
   اطبع_سطر("موجود!")
نهاية
```

| العملية | مصفوفة | خريطة |
|---------|--------|-------|
| بحث | O(n) | O(1) |
| إضافة (نهاية) | O(1) | O(1) |
| حذف | O(n) | O(1) |
| ترتيب | O(n log n) | غير مدعوم |

## 4. تجنب العمليات المكررة

```sad
# ✗ حساب الطول في كل تكرار
بينما (ي < طول(قائمة_كبيرة))
   # طول() يُستدعى كل مرة
   ي = ي + 1
نهاية

# ✓ حساب مرة واحدة
متغير الحجم = طول(قائمة_كبيرة)
بينما (ي < الحجم)
   ي = ي + 1
نهاية

# ✗ بناء نص بالتكرار — O(n²)
متغير نتيجة = ""
لكل ي في نطاق(0، 1000)
   نتيجة = نتيجة + "سطر " + ي + "\n"  # نسخ كل مرة
نهاية

# ✓ استخدم مصفوفة ثم اجمع — O(n)
متغير أسطر = []
لكل ي في نطاق(0، 1000)
   أسطر[ي] = "سطر " + ي
نهاية
متغير نتيجة = اربط(أسطر، "\n")
```

## 5. المعالجة الكسولة (Lazy Evaluation)

```sad
# ✗ تحميل كل شيء مقدماً
دالة ابحث_في_كل_الملفات()
   متغير كل_المحتوى = []
   لكل ملف في اقرأ_مجلد(".")
      كل_المحتوى[طول(كل_المحتوى)] = اقرأ_ملف(ملف)
   نهاية
   # ثم ابحث في كل المحتوى
   ارجع كل_المحتوى
نهاية

# ✓ توقف عند أول نتيجة
دالة ابحث_عن_سطر(مجلد، نمط)
   لكل ملف في اقرأ_مجلد(مجلد)
      متغير محتوى = اقرأ_ملف(ملف)
      إذا (يحتوي(محتوى، نمط))
         ارجع ملف   # وجدنا! لا حاجة لإكمال
      نهاية
   نهاية
   ارجع لاشيء
نهاية
```

## خلاصة

| التقنية | المكسب |
|---------|--------|
| قياس الوقت | معرفة الأجزاء البطيئة |
| التخزين المؤقت | تجنب حساب مكرر |
| هيكل بيانات مناسب | عمليات أسرع |
| تقليل العمليات | أقل عمل = أسرع |
| معالجة كسولة | لا تعمل أكثر مما تحتاج |

## تمارين

1. قارن أداء فيبوناتشي العادي مع المخزن مؤقتاً لأعداد 10 و20 و30 و40.
2. اكتب صنف `ذاكرة_مؤقتة` يمكنه تخزين نتائج أي دالة تلقائياً.
3. حسّن كود يبحث عن عناصر مكررة في مصفوفة من O(n²) إلى O(n).
4. اكتب أداة قياس أداء تقارن بين خوارزميتين وتطبع تقريراً.
