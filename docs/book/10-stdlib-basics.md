# الفصل العاشر: أساسيات المكتبة القياسية

## مقدمة

المكتبة القياسية في لغة ص توفر دوالاً ووحدات جاهزة للاستخدام اليومي. هذا الفصل يشرح الوحدات الأساسية: النواة (core)، الإدخال والإخراج (io)، الرياضيات (math)، والنصوص (string).

---

## 1. وحدة النواة (core)

الدوال المدمجة متوفرة تلقائياً بدون استيراد:

### الطباعة

```sad
اطبع("مرحبا ")           # طباعة بدون سطر جديد
اطبع_سطر("مرحبا بالعالم")   # طباعة مع سطر جديد
```

### الإدخال

```sad
متغير الاسم = أدخل("ما اسمك؟ ")
اطبع_سطر("أهلاً يا " + الاسم)
```

### فحص وتحويل الأنواع

```sad
متغير ن = "42"

# فحص النوع
اطبع_سطر(نوع(ن))         # نص
اطبع_سطر(نوع(42))        # رقم
اطبع_سطر(نوع(صحيح))      # منطقي

# تحويل الأنواع
متغير رقم = إلى_رقم(ن)
اطبع_سطر(رقم + 8)         # 50

متغير نص_رقم = إلى_نص(100)
اطبع_سطر("القيمة: " + نص_رقم)
```

### دوال المصفوفات

```sad
متغير م = [5, 3, 8, 1, 9]

اطبع_سطر("الطول: " + طول(م))       # 5
م.أضف(7)                              # إضافة عنصر
اطبع_سطر("بعد الإضافة: " + طول(م))  # 6

# الوصول والتعديل
اطبع_سطر("الأول: " + م[0])          # 5
اطبع_سطر("الأخير: " + م[طول(م) - 1]) # 7
```

### دوال مساعدة

```sad
# رقم عشوائي
متغير ع = عشوائي(1, 100)
اطبع_سطر("عدد عشوائي: " + ع)

# الانتظار (بالمللي ثانية)
اطبع("جارٍ التحميل")
انتظر(1000)
اطبع_سطر("... تم!")

# التأكيد (للاختبار)
تأكد(1 + 1 == 2)
```

## 2. وحدة الرياضيات (math)

```sad
من "رياضيات" استورد جذر، قوة، مطلق، أكبر، أصغر

# الجذر التربيعي
اطبع_سطر("جذر(144) = " + جذر(144))    # 12

# القوة
اطبع_سطر("2^10 = " + قوة(2, 10))       # 1024

# القيمة المطلقة
اطبع_سطر("|-5| = " + مطلق(-5))          # 5

# الأكبر والأصغر
اطبع_سطر("أكبر(3,7) = " + أكبر(3, 7))   # 7
اطبع_سطر("أصغر(3,7) = " + أصغر(3, 7))   # 3
```

### ثوابت رياضية

```sad
من "رياضيات" استورد باي، هاء

اطبع_سطر("π = " + باي)        # 3.14159...
اطبع_سطر("e = " + هاء)        # 2.71828...

# حساب محيط دائرة
دالة محيط_دائرة(عشري نصف_قطر)
    ارجع 2 * باي * نصف_قطر
نهاية

اطبع_سطر("المحيط: " + محيط_دائرة(5.0))
```

## 3. وحدة الإدخال والإخراج (io)

```sad
من "io" استورد اقرأ_ملف، اكتب_ملف

# كتابة ملف
اكتب_ملف("بيانات.txt", "محتوى الملف هنا")

# قراءة ملف
متغير محتوى = اقرأ_ملف("بيانات.txt")
اطبع_سطر(محتوى)
```

### التعامل مع الملفات بأمان

```sad
من "io" استورد اقرأ_ملف، اكتب_ملف، ملف_موجود

دالة اقرأ_بأمان(نص مسار)
    حاول
        إذا (ليس ملف_موجود(مسار))
            ارمي "الملف غير موجود: " + مسار
        نهاية
        ارجع اقرأ_ملف(مسار)
    امسك (خ)
        اطبع_سطر("خطأ في القراءة: " + خ)
        ارجع ""
    نهاية
نهاية
```

## 4. وحدة النصوص (string)

```sad
من "نصوص" استورد قسّم، ضم، استبدل، يحتوي، يبدأ_بـ، ينتهي_بـ

متغير جملة = "البرمجة بلغة ص سهلة ومرنة"

# التحقق
اطبع_سطر(يحتوي(جملة, "ص"))     # صحيح
اطبع_سطر(يبدأ_بـ(جملة, "البرمجة"))  # صحيح

# التقسيم والدمج
متغير كلمات = قسّم(جملة, " ")
اطبع_سطر("عدد الكلمات: " + طول(كلمات))

متغير مدمج = ضم(كلمات, " - ")
اطبع_سطر(مدمج)
# المخرج: البرمجة - بلغة - ص - سهلة - ومرنة
```

## 5. مثال تطبيقي: أداة إحصاء نصية

```sad
دالة حلل_نص(نص المحتوى)
    متغير الكلمات = قسّم(المحتوى, " ")
    متغير الأسطر = قسّم(المحتوى, "\n")
    متغير الحروف = طول(المحتوى)
    
    اطبع_سطر("══════════════════════")
    اطبع_سطر("  إحصائيات النص")
    اطبع_سطر("══════════════════════")
    اطبع_سطر("  الحروف: " + الحروف)
    اطبع_سطر("  الكلمات: " + طول(الكلمات))
    اطبع_سطر("  الأسطر: " + طول(الأسطر))
    اطبع_سطر("══════════════════════")
نهاية

متغير نص_تجريبي = "لغة ص هي لغة برمجة عربية
تدعم البرمجة الكائنية والوظيفية
وتعمل على جميع المنصات"

حلل_نص(نص_تجريبي)
```

## 6. مثال تطبيقي: آلة حاسبة تفاعلية

```sad
من "رياضيات" استورد جذر، قوة

دالة حاسبة()
    اطبع_سطر("╔═══════════════════════╗")
    اطبع_سطر("║  آلة حاسبة لغة ص     ║")
    اطبع_سطر("╚═══════════════════════╝")
    
    بينما (صحيح)
        متغير أمر = أدخل("\nالعملية (+,-,*,/,جذر,خروج): ")
        
        إذا (أمر == "خروج")
            اطبع_سطر("وداعاً!")
            توقف
        نهاية
        
        إذا (أمر == "جذر")
            متغير ن = إلى_رقم(أدخل("الرقم: "))
            اطبع_سطر("النتيجة: " + جذر(ن))
        وإلا
            متغير أ = إلى_رقم(أدخل("الرقم الأول: "))
            متغير ب = إلى_رقم(أدخل("الرقم الثاني: "))
            
            طابق (أمر)
                عندما "+":
                    اطبع_سطر("النتيجة: " + (أ + ب))
                عندما "-":
                    اطبع_سطر("النتيجة: " + (أ - ب))
                عندما "*":
                    اطبع_سطر("النتيجة: " + (أ * ب))
                عندما "/":
                    إذا (ب == 0)
                        اطبع_سطر("خطأ: لا يمكن القسمة على صفر")
                    وإلا
                        اطبع_سطر("النتيجة: " + (أ / ب))
                    نهاية
                افتراضي:
                    اطبع_سطر("عملية غير معروفة")
            نهاية
        نهاية
    نهاية
نهاية

حاسبة()
```

## إرشادات عملية

1. **ابحث أولاً في المكتبة القياسية** — لا تكتب ما هو موجود جاهزاً.
2. **استورد ما تحتاجه فقط** — لا تستورد وحدة كاملة إذا كنت تحتاج دالة واحدة.
3. **اقرأ الوثائق** — كل وحدة لها توثيق مفصل في `docs/api/`.
4. **عالج الأخطاء** — دوال الملفات والشبكة قد تفشل، ضعها في `حاول/امسك`.

## تمارين

1. اكتب برنامج يقرأ ملفاً ويحسب تكرار كل كلمة فيه.
2. أنشئ آلة حاسبة علمية تدعم الجذر والقوة والدوال المثلثية.
3. اكتب دالة تحوّل درجة الحرارة بين مئوية وفهرنهايت وكلفن.
4. صمم نظام ملاحظات بسيط يحفظ ويقرأ من ملف نصي.
