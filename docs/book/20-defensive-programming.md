# الفصل العشرون: البرمجة الدفاعية (Defensive Programming)

## مقدمة نظرية

**البرمجة الدفاعية** منهج يفترض أن كل مُدخل قد يكون خاطئاً وكل عملية قد تفشل. الهدف: بناء برامج تتعامل بلطف مع الأخطاء بدلاً من الانهيار.

| المبدأ | الوصف |
|--------|-------|
| **تحقق أولاً** | افحص المُدخلات قبل المعالجة |
| **افشل بسرعة** | اكتشف الخطأ مبكراً قبل تفاقمه |
| **افشل بوضوح** | رسالة خطأ دقيقة أفضل من انهيار صامت |
| **لا تثق بالمستخدم** | كل مُدخل خارجي مشبوه |

---

## 1. التحقق من المُدخلات

```sad
دالة أنشئ_حساب(اسم، عمر، بريد)
   # التحقق من الاسم
   إذا (اسم == "" أو اسم == لاشيء)
      ارمي "الاسم مطلوب ولا يمكن أن يكون فارغاً"
   نهاية

   إذا (طول(اسم) < 2)
      ارمي "الاسم قصير جداً (الحد الأدنى حرفان)"
   نهاية

   # التحقق من العمر
   إذا (عمر < 0 أو عمر > 150)
      ارمي "العمر غير منطقي: " + عمر
   نهاية

   # التحقق من البريد
   إذا (ليس بريد.يحتوي("@"))
      ارمي "صيغة البريد غير صحيحة: " + بريد
   نهاية

   ارجع {"اسم": اسم، "عمر": عمر، "بريد": بريد}
نهاية

# استخدام مع معالجة الأخطاء
حاول
   متغير حساب = أنشئ_حساب("أحمد"، 25، "ahmed@email.com")
   اطبع_سطر("✓ تم إنشاء الحساب: " + حساب["اسم"])
امسك (خطأ)
   اطبع_سطر("✗ فشل: " + خطأ)
نهاية
```

## 2. نمط حراسة الحدود (Guard Clauses)

بدلاً من `إذا` متداخلة، تحقق وارجع مبكراً:

```sad
# ✗ سيء — تداخل عميق
دالة عالج_طلب_سيء(طلب)
   إذا (طلب != لاشيء)
      إذا (طلب.صالح)
         إذا (طلب.مصرّح)
            # المنطق الفعلي هنا — بعد 3 مستويات!
            ارجع "تم"
         نهاية
      نهاية
   نهاية
   ارجع "فشل"
نهاية

# ✓ جيد — حراسة الحدود
دالة عالج_طلب(طلب)
   إذا (طلب == لاشيء)
      ارجع "خطأ: الطلب فارغ"
   نهاية
   إذا (ليس طلب.صالح)
      ارجع "خطأ: الطلب غير صالح"
   نهاية
   إذا (ليس طلب.مصرّح)
      ارجع "خطأ: غير مصرّح"
   نهاية

   # المنطق الفعلي — واضح ومسطّح
   ارجع "تم التنفيذ بنجاح"
نهاية
```

## 3. القيم الافتراضية الآمنة

```sad
دالة إعدادات_الصفحة(خيارات)
   # قيم افتراضية آمنة
   متغير عنوان = "بدون عنوان"
   متغير لون = "#000000"
   متغير حجم_خط = 16

   إذا (خيارات != لاشيء)
      إذا (خيارات["عنوان"] != لاشيء)
         عنوان = خيارات["عنوان"]
      نهاية
      إذا (خيارات["لون"] != لاشيء)
         لون = خيارات["لون"]
      نهاية
      إذا (خيارات["حجم"] != لاشيء)
         حجم_خط = خيارات["حجم"]
      نهاية
   نهاية

   اطبع_سطر("العنوان: " + عنوان)
   اطبع_سطر("اللون: " + لون)
   اطبع_سطر("الحجم: " + حجم_خط)
نهاية

# يعمل حتى بدون خيارات
إعدادات_الصفحة(لاشيء)
إعدادات_الصفحة({"عنوان": "الرئيسية"، "لون": "#0070f3"})
```

## 4. التعامل مع الحدود (Edge Cases)

```sad
دالة المعدل(درجات)
   # الحالة الحدية: قائمة فارغة
   إذا (درجات == لاشيء أو طول(درجات) == 0)
      اطبع_سطر("تحذير: لا توجد درجات")
      ارجع 0
   نهاية

   متغير مجموع = 0
   لكل د في درجات
      مجموع = مجموع + د
   نهاية
   ارجع مجموع / طول(درجات)
نهاية

# حالات طبيعية وحدية
اطبع_سطر(المعدل([90، 80، 95]))  # 88.33
اطبع_سطر(المعدل([]))             # 0 — مع تحذير
اطبع_سطر(المعدل(لاشيء))          # 0 — مع تحذير
```

## 5. التوكيدات (Assertions)

```sad
دالة تأكد(شرط، رسالة)
   إذا (ليس شرط)
      ارمي "تأكيد فاشل: " + رسالة
   نهاية
نهاية

دالة قسمة_آمنة(أ، ب)
   تأكد(ب != 0، "القسمة على صفر غير مسموحة")
   ارجع أ / ب
نهاية

دالة سحب(رصيد، مبلغ)
   تأكد(مبلغ > 0، "المبلغ يجب أن يكون موجباً")
   تأكد(مبلغ <= رصيد، "الرصيد غير كافٍ")
   ارجع رصيد - مبلغ
نهاية

اطبع_سطر(قسمة_آمنة(10، 3))    # 3.33
# قسمة_آمنة(10، 0)             # ← تأكيد فاشل!
```

## قائمة مراجعة دفاعية

- [ ] هل تحققت من كل مُدخل خارجي؟
- [ ] هل عالجت القوائم الفارغة وقيم `لاشيء`؟
- [ ] هل الرسائل الخطأ واضحة ومفيدة؟
- [ ] هل استخدمت حراسة الحدود بدل التداخل العميق؟
- [ ] هل حددت قيماً افتراضية آمنة؟

## تمارين

1. اكتب دالة `تحقق_كلمة_سر(كلمة)` تفحص: الطول ≥ 8، تحتوي رقماً، تحتوي حرفاً.
2. ابنِ صنف `مصفوفة_آمنة` يمنع الوصول خارج الحدود.
3. اكتب دالة `اقرأ_إعداد(اسم، افتراضي)` تُرجع القيمة الافتراضية إذا لم يُعثر على الإعداد.
4. طبّق نمط "محاولة إعادة" (retry) — أعد تنفيذ العملية 3 مرات قبل الاستسلام.
