# الفصل السادس عشر: مشروع التخرج وخارطة التعلم

## مقدمة

وصلت إلى نهاية القسم الأول من الكتاب! هذا الفصل يقدم لك مشروعاً شاملاً يجمع كل المفاهيم، ثم يرسم خارطة طريق لما بعد الكتاب.

---

## مشروع التخرج: نظام إدارة مدرسة

### المتطلبات

- أصناف: `طالب`، `مادة`، `درجة`، `مدرسة`
- وراثة: `طالب_متميز` يرث `طالب`
- وحدات: فصل كل صنف في ملف منفصل
- معالجة أخطاء: التحقق من صحة البيانات
- مطابقة أنماط: تصنيف الدرجات

### هيكل المشروع

```
مدرسة/
├── نماذج/
│   ├── طالب.ص
│   ├── مادة.ص
│   └── درجة.ص
├── خدمات/
│   ├── إدارة_طلاب.ص
│   └── تقارير.ص
└── رئيسي.ص
```

### التنفيذ

```sad
# ─── نماذج/طالب.ص ───
صدّر صنف طالب
   عام باني(اسم، رقم)
      هذا.اسم = اسم
      هذا.رقم = رقم
      هذا.الدرجات = []
   نهاية

   عام دالة أضف_درجة(مادة، علامة)
      إذا (علامة < 0 أو علامة > 100)
         ارمي "درجة غير صالحة: " + علامة
      نهاية
      هذا.الدرجات.أضف({"مادة": مادة، "علامة": علامة})
   نهاية

   عام دالة المعدل()
      إذا (طول(هذا.الدرجات) == 0)
         ارجع 0
      نهاية
      متغير مجموع = 0
      لكل د في هذا.الدرجات
         مجموع = مجموع + د["علامة"]
      نهاية
      ارجع مجموع / طول(هذا.الدرجات)
   نهاية

   عام دالة التقدير()
      متغير م = هذا.المعدل()
      طابق (م)
         عندما 90..100:
            ارجع "ممتاز ⭐"
         عندما 80..90:
            ارجع "جيد جداً"
         عندما 70..80:
            ارجع "جيد"
         عندما 60..70:
            ارجع "مقبول"
         افتراضي:
            ارجع "راسب ✗"
      نهاية
   نهاية
نهاية
```

## تمارين نهائية

1. أضف صنف `مادة` مع وزن (معامل) لحساب المعدل المرجّح.
2. أضف خاصية `الحضور` للطالب (عدد أيام الحضور من أصل 30).
3. ابنِ نظام طباعة شهادات يصدّر تقريراً لكل طالب.
4. حوّل المشروع لاستخدام الوحدات: كل صنف في ملف مستقل.

## إرشادات تطبيقية

1. ابدأ بحالة بسيطة ثم أضف التعقيد تدريجياً.
2. اكتب مثالاً قابلاً للتنفيذ لكل مفهوم.
3. أضف اختبارات للحالات الطبيعية وحالات الحافة.
4. راجع الكود من زاوية القارئ الجديد، لا من زاوية الكاتب فقط.

## تمارين

1. عدّل المثال ليعالج حالة إضافية واقعية.
2. اكتب دالة ثانية تعتمد على نتيجة الدالة الأولى.
3. أنشئ نسخة موثقة بالكامل من المثال مع تعليق يشرح قراراً تصميمياً واحداً.
