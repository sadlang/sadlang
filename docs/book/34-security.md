# الفصل الرابع والثلاثون: أمان البرمجيات (Software Security)

## مقدمة نظرية

**أمان البرمجيات** يعني حماية البرنامج من الاستغلال. الأخطاء الأمنية يمكن أن تؤدي إلى سرقة بيانات، تعطيل خدمات، أو تنفيذ أكواد خبيثة.

### أهم التهديدات (OWASP Top 5)

| الترتيب | التهديد | الوصف |
|---------|---------|-------|
| 1 | **الحقن** (Injection) | إدخال أوامر خبيثة عبر المُدخلات |
| 2 | **كسر المصادقة** | تجاوز نظام تسجيل الدخول |
| 3 | **كشف البيانات** | عرض بيانات حساسة بدون تشفير |
| 4 | **التحكم المكسور** | وصول لموارد غير مصرح بها |
| 5 | **خطأ التهيئة** | إعدادات أمنية خاطئة |

## 1. التحقق من المُدخلات

```sad
# ✗ خطير — ثقة عمياء بالمُدخل
دالة سجل_خطير(اسم_المستخدم)
   # لا تحقق!
   احفظ("مستخدمون"، اسم_المستخدم)
نهاية

# ✓ آمن — تحقق شامل
دالة تحقق_اسم(اسم)
   إذا (اسم == لاشيء أو طول(اسم) == 0)
      ارمي "الاسم مطلوب"
   نهاية
   إذا (طول(اسم) < 3)
      ارمي "الاسم قصير جداً (3 أحرف على الأقل)"
   نهاية
   إذا (طول(اسم) > 50)
      ارمي "الاسم طويل جداً (50 حرف كحد أقصى)"
   نهاية
   # تحقق من الأحرف المسموحة
   لكل حرف في اسم
      إذا (ليس (حرف_عربي(حرف) أو حرف_لاتيني(حرف) أو حرف == "_"))
         ارمي "حرف غير مسموح: " + حرف
      نهاية
   نهاية
   ارجع صحيح
نهاية

دالة سجل_آمن(اسم_المستخدم)
   تحقق_اسم(اسم_المستخدم)
   احفظ("مستخدمون"، اسم_المستخدم)
نهاية
```

## 2. تعقيم المُدخلات (Sanitization)

```sad
# منع حقن HTML/XSS
دالة عقّم_نص(نص)
   متغير نتيجة = نص
   نتيجة = استبدل(نتيجة، "&"، "&amp;")
   نتيجة = استبدل(نتيجة، "<"، "&lt;")
   نتيجة = استبدل(نتيجة، ">"، "&gt;")
   نتيجة = استبدل(نتيجة، "\""، "&quot;")
   نتيجة = استبدل(نتيجة، "'"، "&#39;")
   ارجع نتيجة
نهاية

# ✗ خطير
# متغير html = "<p>" + تعليق_المستخدم + "</p>"

# ✓ آمن
# متغير html = "<p>" + عقّم_نص(تعليق_المستخدم) + "</p>"
```

## 3. إدارة كلمات المرور

```sad
صنف مدير_كلمات_المرور
   ثابت الحد_الأدنى = 8

   ساكن دالة تحقق_قوة(كلمة_مرور)
      إذا (طول(كلمة_مرور) < هذا.الحد_الأدنى)
         ارجع "ضعيفة: أقل من " + هذا.الحد_الأدنى + " أحرف"
      نهاية

      متغير فيها_رقم = خطأ
      متغير فيها_حرف_كبير = خطأ
      متغير فيها_رمز = خطأ

      لكل حرف في كلمة_مرور
         إذا (رقم(حرف))
            فيها_رقم = صحيح
         نهاية
         إذا (حرف_كبير(حرف))
            فيها_حرف_كبير = صحيح
         نهاية
         إذا (رمز_خاص(حرف))
            فيها_رمز = صحيح
         نهاية
      نهاية

      إذا (ليس فيها_رقم)
         ارجع "متوسطة: تحتاج رقماً"
      نهاية
      إذا (ليس فيها_رمز)
         ارجع "متوسطة: تحتاج رمزاً خاصاً"
      نهاية
      ارجع "قوية"
   نهاية

   ساكن دالة هاش(كلمة_مرور، ملح)
      # لا تخزن كلمة المرور الأصلية أبداً!
      ارجع تشفير_sha256(ملح + كلمة_مرور)
   نهاية
نهاية

# الاستخدام
متغير كلمة = "MyP@ss123"
اطبع_سطر(مدير_كلمات_المرور.تحقق_قوة(كلمة))
```

## 4. مبدأ الحد الأدنى من الصلاحيات

```sad
صنف مستخدم
   خاص متغير _الاسم
   خاص متغير _الدور     # "مشرف" أو "محرر" أو "قارئ"

   باني(اسم، دور)
      _الاسم = اسم
      _الدور = دور
   نهاية

   دالة يملك_صلاحية(إجراء)
      متغير صلاحيات = خريطة()
      صلاحيات["قارئ"] = ["قراءة"]
      صلاحيات["محرر"] = ["قراءة"، "كتابة"]
      صلاحيات["مشرف"] = ["قراءة"، "كتابة"، "حذف"، "إدارة"]

      متغير قائمة = صلاحيات[_الدور]
      إذا (قائمة == لاشيء)
         ارجع خطأ
      نهاية
      لكل ص في قائمة
         إذا (ص == إجراء)
            ارجع صحيح
         نهاية
      نهاية
      ارجع خطأ
   نهاية
نهاية

# تحقق قبل كل عملية
دالة حذف_مقال(مستخدم، معرف_مقال)
   إذا (ليس مستخدم.يملك_صلاحية("حذف"))
      ارمي "غير مصرح لك بالحذف!"
   نهاية
   # تنفيذ الحذف...
   اطبع_سطر("تم حذف المقال " + معرف_مقال)
نهاية
```

## 5. تسجيل الأحداث الأمنية

```sad
صنف سجل_أمني
   خاص متغير _أحداث = []

   دالة سجّل(نوع، تفاصيل)
      متغير حدث = خريطة()
      حدث["الوقت"] = الوقت_الحالي()
      حدث["النوع"] = نوع
      حدث["التفاصيل"] = تفاصيل
      _أحداث[طول(_أحداث)] = حدث

      إذا (نوع == "تحذير" أو نوع == "خطر")
         اطبع_سطر("⚠ [" + نوع + "] " + تفاصيل)
      نهاية
   نهاية

   دالة محاولات_فاشلة(اسم_مستخدم)
      متغير عدد = 0
      لكل حدث في _أحداث
         إذا (حدث["النوع"] == "فشل_دخول" و
              حدث["التفاصيل"] == اسم_مستخدم)
            عدد = عدد + 1
         نهاية
      نهاية
      ارجع عدد
   نهاية
نهاية

متغير السجل = جديد سجل_أمني()

دالة تسجيل_دخول(اسم، كلمة_مرور)
   # حماية من القوة العمياء (brute force)
   إذا (السجل.محاولات_فاشلة(اسم) >= 5)
      السجل.سجّل("خطر"، "حساب مقفل: " + اسم)
      ارمي "الحساب مقفل مؤقتاً"
   نهاية

   إذا (تحقق_كلمة_المرور(اسم، كلمة_مرور))
      السجل.سجّل("نجاح"، "دخول: " + اسم)
   وإلا
      السجل.سجّل("فشل_دخول"، اسم)
      ارمي "اسم مستخدم أو كلمة مرور خاطئة"
   نهاية
نهاية
```

## خلاصة

| المبدأ | التطبيق |
|--------|---------|
| تحقق من كل مُدخل | `تحقق_اسم()` قبل الحفظ |
| عقّم المخرجات | `عقّم_نص()` قبل العرض |
| لا تخزن أسراراً | استخدم `تشفير_sha256()` |
| الحد الأدنى | صلاحيات حسب الدور |
| سجّل كل شيء | `سجل_أمني` لكل حدث مهم |

## تمارين

1. اكتب دالة تعقّم مُدخلات SQL لمنع حقن قواعد البيانات.
2. ابنِ نظام CAPTCHA بسيط يطرح سؤال حساب عشوائي.
3. اكتب مُحلل سجل أمني يكتشف أنماط الهجوم (5 محاولات فاشلة خلال دقيقة).
4. ابنِ نظام توثيق ثنائي (2FA) يولّد رمزاً مؤقتاً من 6 أرقام.
