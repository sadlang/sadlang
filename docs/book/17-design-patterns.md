# الفصل السابع عشر: أنماط التصميم (Design Patterns)

## مقدمة نظرية

**أنماط التصميم** هي حلول متكررة لمشاكل شائعة في تصميم البرمجيات. صاغها أربعة مؤلفين عام 1994 (عُرفوا بـ Gang of Four) وتصنف إلى ثلاث فئات:

| الفئة | الوصف | أمثلة |
|-------|-------|-------|
| **إنشائية** (Creational) | كيف تُنشئ الكائنات | مصنع، وحيد، بانٍ |
| **هيكلية** (Structural) | كيف تُركّب الكائنات | محوّل، واجهة، مُزخرِف |
| **سلوكية** (Behavioral) | كيف تتفاعل الكائنات | مراقب، استراتيجية، أمر |

---

## 1. نمط المصنع (Factory)

بدلاً من استخدام `جديد` مباشرة، نُفوّض الإنشاء لدالة مصنع تختار النوع المناسب:

```sad
صنف شكل
   عام دالة ارسم()
      اطبع_سطر("شكل عام")
   نهاية
نهاية

صنف دائرة يرث شكل
   عام دالة ارسم()
      اطبع_سطر("○ رسم دائرة")
   نهاية
نهاية

صنف مربع يرث شكل
   عام دالة ارسم()
      اطبع_سطر("□ رسم مربع")
   نهاية
نهاية

صنف مثلث يرث شكل
   عام دالة ارسم()
      اطبع_سطر("△ رسم مثلث")
   نهاية
نهاية

# المصنع
دالة أنشئ_شكل(نوع)
   طابق (نوع)
      عندما "دائرة":
         ارجع جديد دائرة()
      عندما "مربع":
         ارجع جديد مربع()
      عندما "مثلث":
         ارجع جديد مثلث()
      افتراضي:
         اطبع_سطر("نوع غير معروف: " + نوع)
         ارجع جديد شكل()
   نهاية
نهاية

# الاستخدام — المستدعي لا يعرف الصنف الفعلي
متغير أشكال = ["دائرة"، "مربع"، "مثلث"]
لكل ش في أشكال
   متغير شكل = أنشئ_شكل(ش)
   شكل.ارسم()
نهاية
```

**متى تستخدمه؟** عندما يعتمد نوع الكائن على مُدخل ديناميكي (إعداد ملف، اختيار المستخدم).

## 2. نمط الوحيد (Singleton)

كائن واحد فقط في البرنامج بأكمله — مناسب لإدارة الإعدادات أو الاتصال بقاعدة البيانات:

```sad
صنف إعدادات
   ساكن متغير _النسخة = لاشيء

   ساكن دالة النسخة()
      إذا (إعدادات._النسخة == لاشيء)
         إعدادات._النسخة = جديد إعدادات()
      نهاية
      ارجع إعدادات._النسخة
   نهاية

   عام باني()
      هذا.اللغة = "ar"
      هذا.السمة = "داكن"
   نهاية

   عام دالة عيّن(مفتاح، قيمة)
      إذا (مفتاح == "لغة")
         هذا.اللغة = قيمة
      وإلا
         إذا (مفتاح == "سمة")
            هذا.السمة = قيمة
         نهاية
      نهاية
   نهاية
نهاية

# نفس النسخة دائماً
متغير ض1 = إعدادات.النسخة()
ض1.عيّن("لغة"، "en")
متغير ض2 = إعدادات.النسخة()
اطبع_سطر(ض2.اللغة)  # "en" — نفس الكائن!
```

## 3. نمط المراقب (Observer)

كائن يُخطر مراقبيه تلقائياً عند تغيّر حالته:

```sad
صنف ناشر
   عام باني(اسم)
      هذا.اسم = اسم
      هذا.المشتركون = []
   نهاية

   عام دالة اشترك(مراقب)
      هذا.المشتركون.أضف(مراقب)
   نهاية

   عام دالة أخبر(رسالة)
      لكل م في هذا.المشتركون
         م.استقبل(هذا.اسم، رسالة)
      نهاية
   نهاية
نهاية

صنف مشترك
   عام باني(اسم)
      هذا.اسم = اسم
   نهاية

   عام دالة استقبل(من، رسالة)
      اطبع_سطر(هذا.اسم + " ← إشعار من " + من + ": " + رسالة)
   نهاية
نهاية

متغير أخبار = جديد ناشر("وكالة الأنباء")
متغير قارئ1 = جديد مشترك("أحمد")
متغير قارئ2 = جديد مشترك("سارة")

أخبار.اشترك(قارئ1)
أخبار.اشترك(قارئ2)
أخبار.أخبر("خبر عاجل!")
# أحمد ← إشعار من وكالة الأنباء: خبر عاجل!
# سارة ← إشعار من وكالة الأنباء: خبر عاجل!
```

## 4. نمط الاستراتيجية (Strategy)

تبديل الخوارزمية في وقت التشغيل:

```sad
# استراتيجيات الترتيب
دالة ترتيب_تصاعدي(أ، ب)
   ارجع أ > ب
نهاية

دالة ترتيب_تنازلي(أ، ب)
   ارجع أ < ب
نهاية

صنف مُرتّب
   عام باني(استراتيجية)
      هذا.قارن = استراتيجية
   نهاية

   عام دالة رتّب(قائمة)
      # ترتيب فقاعي باستخدام الاستراتيجية
      متغير ن = طول(قائمة)
      متغير ي = 0
      بينما (ي < ن)
         متغير ج = 0
         بينما (ج < ن - 1)
            إذا (هذا.قارن(قائمة[ج]، قائمة[ج + 1]))
               متغير مبادلة = قائمة[ج]
               قائمة[ج] = قائمة[ج + 1]
               قائمة[ج + 1] = مبادلة
            نهاية
            ج = ج + 1
         نهاية
         ي = ي + 1
      نهاية
      ارجع قائمة
   نهاية
نهاية

متغير أرقام = [5، 2، 8، 1، 9]
متغير م1 = جديد مُرتّب(ترتيب_تصاعدي)
اطبع_سطر(م1.رتّب(أرقام))  # [1, 2, 5, 8, 9]
```

## خلاصة

| النمط | المشكلة | الحل |
|-------|---------|------|
| مصنع | إنشاء كائنات متنوعة | دالة مصنع مركزية |
| وحيد | نسخة واحدة فقط | متغير ساكن + دالة ساكنة |
| مراقب | إخطار عند التغيير | قائمة مشتركين + دالة إخطار |
| استراتيجية | تبديل الخوارزمية | تمرير دالة كمعامل |

## تمارين

1. ابنِ نمط **المُزخرِف** (Decorator): صنف `قهوة` مع مزخرفات (حليب، سكر) تضيف للسعر.
2. طبّق نمط **الأمر** (Command): صنف `محرر_نص` مع أوامر (كتابة، تراجع، إعادة).
3. استخدم نمط المصنع لإنشاء أنواع مختلفة من الإشعارات (بريد، رسالة، تنبيه).
4. ابنِ نظام أحداث (Event System) يوسّع نمط المراقب.
