# الفصل الرابع والعشرون: إدارة الملفات (File I/O)

## مقدمة نظرية

التعامل مع الملفات مهارة أساسية: القراءة من ملفات، الكتابة إليها، ومعالجة المسارات. لغة ص تقدم دوال مدمجة للتعامل مع نظام الملفات.

| العملية | الدالة | الوصف |
|---------|--------|-------|
| قراءة | `اقرأ_ملف(مسار)` | يُرجع محتوى الملف كنص |
| كتابة | `اكتب_ملف(مسار، محتوى)` | يكتب نصاً في ملف |
| إلحاق | `ألحق_ملف(مسار، محتوى)` | يُضيف إلى نهاية الملف |
| وجود | `ملف_موجود(مسار)` | يتحقق من وجود الملف |
| حذف | `احذف_ملف(مسار)` | يحذف ملفاً |
| مجلدات | `اقرأ_مجلد(مسار)` | يُرجع محتويات المجلد |

## 1. قراءة وكتابة ملفات نصية

```sad
# كتابة ملف
متغير محتوى = "بسم الله الرحمن الرحيم\n"
محتوى = محتوى + "هذا ملف تجريبي\n"
محتوى = محتوى + "مكتوب بلغة ص\n"
اكتب_ملف("تجربة.txt"، محتوى)
اطبع_سطر("✓ تم كتابة الملف")

# قراءة ملف
متغير نص = اقرأ_ملف("تجربة.txt")
اطبع_سطر(نص)

# إلحاق سطر جديد
ألحق_ملف("تجربة.txt"، "سطر جديد!\n")
```

## 2. معالجة ملفات البيانات

```sad
# قراءة ملف CSV وتحليله
دالة اقرأ_csv(مسار)
   متغير محتوى = اقرأ_ملف(مسار)
   متغير أسطر = محتوى.قسّم("\n")
   متغير نتيجة = []

   متغير ي = 0
   لكل سطر في أسطر
      إذا (سطر != "" و ي > 0)   # تخطي العنوان
         متغير حقول = سطر.قسّم(",")
         نتيجة.أضف({
            "اسم": حقول[0]،
            "درجة": حقول[1]
         })
      نهاية
      ي = ي + 1
   نهاية
   ارجع نتيجة
نهاية

# إنشاء ملف CSV تجريبي
اكتب_ملف("طلاب.csv"، "الاسم,الدرجة\nأحمد,95\nسارة,88\nخالد,72\n")

# معالجة البيانات
متغير طلاب = اقرأ_csv("طلاب.csv")
لكل ط في طلاب
   اطبع_سطر(ط["اسم"] + ": " + ط["درجة"])
نهاية
```

## 3. تطبيق: نظام سجل (Logger)

```sad
صنف سجل
   عام باني(مسار_ملف)
      هذا.المسار = مسار_ملف
      # إنشاء الملف إذا لم يكن موجوداً
      إذا (ليس ملف_موجود(مسار_ملف))
         اكتب_ملف(مسار_ملف، "")
      نهاية
   نهاية

   عام دالة معلومات(رسالة)
      هذا._اكتب("معلومات"، رسالة)
   نهاية

   عام دالة تحذير(رسالة)
      هذا._اكتب("تحذير"، رسالة)
   نهاية

   عام دالة خطأ(رسالة)
      هذا._اكتب("خطأ"، رسالة)
   نهاية

   خاص دالة _اكتب(مستوى، رسالة)
      متغير سطر = "[" + مستوى + "] " + رسالة + "\n"
      ألحق_ملف(هذا.المسار، سطر)
      اطبع_سطر(سطر)
   نهاية
نهاية

متغير س = جديد سجل("تطبيق.log")
س.معلومات("بدأ التطبيق")
س.تحذير("الذاكرة منخفضة")
س.خطأ("فشل الاتصال بالقاعدة")
```

## 4. تطبيق: مدير إعدادات

```sad
صنف مدير_إعدادات
   عام باني(مسار)
      هذا.المسار = مسار
      هذا.الإعدادات = {}
      إذا (ملف_موجود(مسار))
         هذا._حمّل()
      نهاية
   نهاية

   خاص دالة _حمّل()
      متغير محتوى = اقرأ_ملف(هذا.المسار)
      متغير أسطر = محتوى.قسّم("\n")
      لكل سطر في أسطر
         إذا (سطر != "" و سطر.يحتوي("="))
            متغير أجزاء = سطر.قسّم("=")
            هذا.الإعدادات[أجزاء[0]] = أجزاء[1]
         نهاية
      نهاية
   نهاية

   عام دالة احصل(مفتاح، افتراضي)
      إذا (هذا.الإعدادات[مفتاح] != لاشيء)
         ارجع هذا.الإعدادات[مفتاح]
      نهاية
      ارجع افتراضي
   نهاية

   عام دالة عيّن(مفتاح، قيمة)
      هذا.الإعدادات[مفتاح] = قيمة
      هذا._احفظ()
   نهاية

   خاص دالة _احفظ()
      متغير محتوى = ""
      لكل مفتاح في هذا.الإعدادات
         محتوى = محتوى + مفتاح + "=" + هذا.الإعدادات[مفتاح] + "\n"
      نهاية
      اكتب_ملف(هذا.المسار، محتوى)
   نهاية
نهاية

متغير إعدادات = جديد مدير_إعدادات("إعدادات.ini")
إعدادات.عيّن("اللغة"، "ar")
إعدادات.عيّن("السمة"، "داكن")
اطبع_سطر(إعدادات.احصل("اللغة"، "en"))  # ar
```

## ممارسات جيدة

- **أغلق الملفات**: استخدم `باستخدام` لضمان الإغلاق
- **تحقق من الوجود**: `ملف_موجود()` قبل القراءة
- **عالج الأخطاء**: `حاول/امسك` حول عمليات الملفات
- **مسارات نسبية**: تجنب المسارات المطلقة إلا عند الضرورة
- **ترميز UTF-8**: لغة ص تدعم UTF-8 تلقائياً للعربية

## تمارين

1. اكتب برنامج يحسب عدد الكلمات في ملف نصي.
2. ابنِ نظام "قاعدة بيانات ملفية" بسيط: اقرأ/اكتب سجلات في ملف JSON.
3. اكتب أداة بحث تبحث عن كلمة في جميع ملفات `.ص` في مجلد.
4. ابنِ دالة `نسخ_ملف(مصدر، هدف)` تنسخ ملفاً مع معالجة الأخطاء.
