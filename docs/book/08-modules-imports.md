# الفصل الثامن: الوحدات والاستيراد

## مقدمة

كلما كبر المشروع زادت الحاجة إلى حدود واضحة بين الأجزاء. هذا الفصل يشرح نظام الوحدات في لغة ص: كيف تقسم مشروعك إلى ملفات منفصلة، وكيف تستورد ما تحتاجه فقط.

---

## 1. الاستيراد الكامل

أبسط طريقة لاستيراد وحدة:

```sad
استورد "رياضيات"

متغير ن = رياضيات.جذر(144)
اطبع_سطر("الجذر التربيعي: " + ن)
```

عند الاستيراد الكامل، تصل لمحتويات الوحدة عبر اسمها كبادئة.

## 2. الاستيراد الانتقائي

لاستيراد دوال أو أصناف محددة فقط:

```sad
من "رياضيات" استورد جذر، قوة

متغير ن = جذر(25)
متغير ق = قوة(2، 10)
اطبع_سطر(ن)    # 5
اطبع_سطر(ق)    # 1024
```

هذا أوضح ويمنع تلويث فضاء الأسماء.

## 3. إعادة التسمية عند الاستيراد

استخدم `كـ` لتسمية بديلة:

```sad
استورد "شبكة/http" كـ خادم
من "نصوص" استورد قسّم كـ فصل

متغير أجزاء = فصل("أحمد،سارة،خالد"، "،")
```

مفيد عند التعارض أو لتقصير الأسماء الطويلة.

## 4. التصدير

لتحديد ما يمكن للوحدات الأخرى رؤيته، استخدم `صدّر`:

```sad
# ملف: أدوات.ص

صدّر دالة تنسيق_تاريخ(نص تاريخ)
    # تحويل التاريخ للصيغة العربية
    ارجع تاريخ
نهاية

صدّر دالة تنسيق_رقم(رقم ن)
    ارجع ن
نهاية

# هذه الدالة خاصة — لا يمكن استيرادها
دالة مساعد_داخلي()
    ارجع "داخلي"
نهاية
```

```sad
# ملف: رئيسي.ص
من "أدوات" استورد تنسيق_تاريخ، تنسيق_رقم

اطبع_سطر(تنسيق_تاريخ("2026-05-15"))
```

## 5. الوحدات المتداخلة

يمكن تنظيم الوحدات في مجلدات فرعية:

```sad
# استيراد من مسار متداخل
استورد "مكتبتي.أدوات.مساعدة"
من "شبكة.http" استورد طلب
```

النقطة `.` تفصل بين مستويات المسار.

## 6. فضاءات الأسماء

لتنظيم الكود داخل فضاء اسم:

```sad
فضاء أدوات_النصوص
    دالة حذف_مسافات(نص ن)
        # حذف المسافات الزائدة
        ارجع ن
    نهاية

    دالة إلى_أحرف_كبيرة(نص ن)
        ارجع ن
    نهاية
نهاية_فضاء

# الاستخدام
متغير نتيجة = أدوات_النصوص.حذف_مسافات("  مرحبا  ")
```

## 7. مثال تطبيقي: مشروع متعدد الملفات

### ملف `نماذج.ص`:
```sad
صدّر صنف مستخدم
    نص الاسم
    نص البريد

    باني(نص اسم، نص بريد)
        الاسم = اسم
        البريد = بريد
    نهاية

    دالة اعرض()
        اطبع_سطر(الاسم + " <" + البريد + ">")
    نهاية
نهاية
```

### ملف `خدمات.ص`:
```sad
من "نماذج" استورد مستخدم

صدّر دالة أنشئ_مستخدم(نص اسم، نص بريد)
    إذا (اسم == "" أو بريد == "")
        ارمي "البيانات ناقصة"
    نهاية
    ارجع جديد مستخدم(اسم، بريد)
نهاية
```

### ملف `رئيسي.ص`:
```sad
من "خدمات" استورد أنشئ_مستخدم

حاول
    متغير م = أنشئ_مستخدم("أحمد"، "ahmad@example.com")
    م.اعرض()
امسك (خ)
    اطبع_سطر("خطأ: " + خ)
نهاية
```

## إرشادات عملية

1. **ملف واحد = مسؤولية واحدة** — لا تضع أصنافاً غير مرتبطة في نفس الملف.
2. **صدّر الحد الأدنى** — صدّر فقط ما يحتاجه المستخدم الخارجي.
3. **تجنب الاستيراد الدائري** — إذا استورد ملف أ من ملف ب، لا تجعل ب يستورد من أ.
4. **أسماء ملفات واضحة** — اسم الملف يعكس محتواه: `نماذج.ص`، `خدمات.ص`، `أدوات_نصوص.ص`.

## تمارين

1. أنشئ وحدة `حاسبة.ص` تصدّر دوال الحساب الأربع، واستوردها في ملف رئيسي.
2. نظّم مشروع بسيط من 3 ملفات: نماذج، خدمات، ورئيسي.
3. استخدم `كـ` لاستيراد وحدتين بنفس اسم الدالة دون تعارض.
4. أنشئ فضاء أسماء لأدوات رياضية واستخدمه في ملف آخر.
