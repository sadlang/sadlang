# الفصل الحادي والعشرون: هياكل البيانات (Data Structures)

## مقدمة نظرية

**هيكل البيانات** هو طريقة لتنظيم البيانات في الذاكرة لتسهيل الوصول والتعديل. اختيار الهيكل الصحيح يؤثر جذرياً على أداء البرنامج.

| الهيكل | الوصول | الإدراج | الحذف | الاستخدام |
|--------|--------|---------|-------|-----------|
| مصفوفة | O(1) | O(n) | O(n) | بيانات مرقمة |
| مكدس | O(n) | O(1) | O(1) | تراجع، تعبيرات |
| طابور | O(n) | O(1) | O(1) | معالجة بالترتيب |
| قائمة مترابطة | O(n) | O(1) | O(1) | إدراج متكرر |
| خريطة | O(1)* | O(1)* | O(1)* | بحث بالمفتاح |

## 1. المكدس (Stack) — LIFO

آخر عنصر يدخل هو أول من يخرج:

```sad
صنف مكدس
   عام باني()
      هذا.العناصر = []
   نهاية

   عام دالة ادفع(قيمة)
      هذا.العناصر.أضف(قيمة)
   نهاية

   عام دالة اسحب()
      إذا (هذا.فارغ())
         ارمي "المكدس فارغ!"
      نهاية
      ارجع هذا.العناصر.احذف(طول(هذا.العناصر) - 1)
   نهاية

   عام دالة القمة()
      إذا (هذا.فارغ())
         ارجع لاشيء
      نهاية
      ارجع هذا.العناصر[طول(هذا.العناصر) - 1]
   نهاية

   عام دالة فارغ()
      ارجع طول(هذا.العناصر) == 0
   نهاية

   عام دالة الحجم()
      ارجع طول(هذا.العناصر)
   نهاية
نهاية

# تطبيق: فحص الأقواس المتوازنة
دالة أقواس_متوازنة(نص)
   متغير م = جديد مكدس()
   متغير ي = 0
   بينما (ي < طول(نص))
      متغير حرف = نص[ي]
      إذا (حرف == "(" أو حرف == "[" أو حرف == "{")
         م.ادفع(حرف)
      وإلا
         إذا (حرف == ")" أو حرف == "]" أو حرف == "}")
            إذا (م.فارغ())
               ارجع خطأ
            نهاية
            م.اسحب()
         نهاية
      نهاية
      ي = ي + 1
   نهاية
   ارجع م.فارغ()
نهاية

اطبع_سطر(أقواس_متوازنة("(([]))"))   # صحيح
اطبع_سطر(أقواس_متوازنة("([)"))       # خطأ
```

## 2. الطابور (Queue) — FIFO

أول عنصر يدخل هو أول من يخرج:

```sad
صنف طابور
   عام باني()
      هذا.العناصر = []
   نهاية

   عام دالة أضف(قيمة)
      هذا.العناصر.أضف(قيمة)
   نهاية

   عام دالة أخرج()
      إذا (هذا.فارغ())
         ارمي "الطابور فارغ!"
      نهاية
      ارجع هذا.العناصر.احذف(0)
   نهاية

   عام دالة الأول()
      إذا (هذا.فارغ())
         ارجع لاشيء
      نهاية
      ارجع هذا.العناصر[0]
   نهاية

   عام دالة فارغ()
      ارجع طول(هذا.العناصر) == 0
   نهاية
نهاية

# تطبيق: نظام انتظار عملاء
متغير انتظار = جديد طابور()
انتظار.أضف("أحمد")
انتظار.أضف("سارة")
انتظار.أضف("خالد")

بينما (ليس انتظار.فارغ())
   اطبع_سطر("خدمة: " + انتظار.أخرج())
نهاية
# خدمة: أحمد → خدمة: سارة → خدمة: خالد
```

## 3. القائمة المترابطة (Linked List)

```sad
صنف عقدة
   عام باني(قيمة)
      هذا.القيمة = قيمة
      هذا.التالي = لاشيء
   نهاية
نهاية

صنف قائمة_مترابطة
   عام باني()
      هذا.الرأس = لاشيء
      هذا.الحجم = 0
   نهاية

   عام دالة أضف_بداية(قيمة)
      متغير ع = جديد عقدة(قيمة)
      ع.التالي = هذا.الرأس
      هذا.الرأس = ع
      هذا.الحجم = هذا.الحجم + 1
   نهاية

   عام دالة أضف_نهاية(قيمة)
      متغير ع = جديد عقدة(قيمة)
      إذا (هذا.الرأس == لاشيء)
         هذا.الرأس = ع
      وإلا
         متغير حالي = هذا.الرأس
         بينما (حالي.التالي != لاشيء)
            حالي = حالي.التالي
         نهاية
         حالي.التالي = ع
      نهاية
      هذا.الحجم = هذا.الحجم + 1
   نهاية

   عام دالة اعرض()
      متغير حالي = هذا.الرأس
      متغير نتيجة = ""
      بينما (حالي != لاشيء)
         نتيجة = نتيجة + حالي.القيمة + " → "
         حالي = حالي.التالي
      نهاية
      اطبع_سطر(نتيجة + "∅")
   نهاية
نهاية

متغير ق = جديد قائمة_مترابطة()
ق.أضف_نهاية(10)
ق.أضف_نهاية(20)
ق.أضف_بداية(5)
ق.اعرض()   # 5 → 10 → 20 → ∅
```

## 4. الشجرة الثنائية (Binary Tree)

```sad
صنف عقدة_شجرة
   عام باني(قيمة)
      هذا.القيمة = قيمة
      هذا.يسار = لاشيء
      هذا.يمين = لاشيء
   نهاية
نهاية

صنف شجرة_بحث
   عام باني()
      هذا.الجذر = لاشيء
   نهاية

   عام دالة أدرج(قيمة)
      هذا.الجذر = هذا._أدرج(هذا.الجذر، قيمة)
   نهاية

   خاص دالة _أدرج(عقدة، قيمة)
      إذا (عقدة == لاشيء)
         ارجع جديد عقدة_شجرة(قيمة)
      نهاية
      إذا (قيمة < عقدة.القيمة)
         عقدة.يسار = هذا._أدرج(عقدة.يسار، قيمة)
      وإلا
         عقدة.يمين = هذا._أدرج(عقدة.يمين، قيمة)
      نهاية
      ارجع عقدة
   نهاية

   عام دالة ابحث(قيمة)
      ارجع هذا._ابحث(هذا.الجذر، قيمة)
   نهاية

   خاص دالة _ابحث(عقدة، قيمة)
      إذا (عقدة == لاشيء)
         ارجع خطأ
      نهاية
      إذا (قيمة == عقدة.القيمة)
         ارجع صحيح
      وإلا
         إذا (قيمة < عقدة.القيمة)
            ارجع هذا._ابحث(عقدة.يسار، قيمة)
         وإلا
            ارجع هذا._ابحث(عقدة.يمين، قيمة)
         نهاية
      نهاية
   نهاية

   عام دالة بالترتيب()
      هذا._بالترتيب(هذا.الجذر)
      اطبع_سطر("")
   نهاية

   خاص دالة _بالترتيب(عقدة)
      إذا (عقدة != لاشيء)
         هذا._بالترتيب(عقدة.يسار)
         اطبع(عقدة.القيمة + " ")
         هذا._بالترتيب(عقدة.يمين)
      نهاية
   نهاية
نهاية

متغير شجرة = جديد شجرة_بحث()
شجرة.أدرج(50)
شجرة.أدرج(30)
شجرة.أدرج(70)
شجرة.أدرج(20)
شجرة.أدرج(40)
شجرة.بالترتيب()        # 20 30 40 50 70
اطبع_سطر(شجرة.ابحث(40))  # صحيح
اطبع_سطر(شجرة.ابحث(99))  # خطأ
```

## خلاصة

| الهيكل | العمليات الرئيسية | أفضل استخدام |
|--------|-------------------|-------------|
| مكدس | `ادفع`، `اسحب` | تراجع/إعادة، تعبيرات |
| طابور | `أضف`، `أخرج` | معالجة بالترتيب |
| قائمة مترابطة | `أضف_بداية`، `أضف_نهاية` | إدراج/حذف متكرر |
| شجرة بحث | `أدرج`، `ابحث` | بحث سريع O(log n) |

## تمارين

1. أضف للمكدس: دالة `أقل()` تُرجع أصغر عنصر بكفاءة O(1).
2. ابنِ طابور أولويات (Priority Queue): العناصر ذات الأولوية العالية تخرج أولاً.
3. أضف لشجرة البحث: دالة `احذف(قيمة)`.
4. ابنِ جدول هاش (Hash Table) باستخدام مصفوفة من قوائم مترابطة.
