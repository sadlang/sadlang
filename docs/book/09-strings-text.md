# الفصل التاسع: النصوص ومعالجة UTF-8

## مقدمة

النص العربي جزء أصيل من لغة ص. هذا الفصل يشرح كيفية التعامل مع النصوص بشكل صحيح، بما في ذلك الترميز UTF-8 وعمليات البحث والاستبدال والتقسيم.

---

## 1. إنشاء النصوص

النصوص تُحاط بعلامات اقتباس مزدوجة أو مفردة:

```sad
متغير تحية = "مرحباً بالعالم"
متغير اسم = 'أحمد'
متغير فارغ = ""

اطبع_سطر(تحية)
اطبع_سطر("الاسم: " + اسم)
```

## 2. دمج النصوص

العامل `+` يدمج النصوص:

```sad
متغير الأول = "لغة"
متغير الثاني = "ص"
متغير المدمج = الأول + " " + الثاني
اطبع_سطر(المدمج)    # لغة ص
```

يمكن دمج أنواع أخرى مع النصوص:

```sad
متغير عمر = 25
اطبع_سطر("العمر: " + عمر)    # العمر: 25

متغير سعر = 99.5
اطبع_سطر("السعر: " + سعر + " ريال")
```

## 3. طول النص

```sad
متغير نص = "مرحبا"
اطبع_سطر("الطول: " + طول(نص))

# النصوص العربية — كل حرف عربي يُعد حرفاً واحداً
متغير عربي = "أهلاً"
اطبع_سطر("الطول: " + طول(عربي))
```

## 4. الوصول للحروف

```sad
متغير كلمة = "سلام"
اطبع_سطر(كلمة[0])    # س
اطبع_سطر(كلمة[1])    # ل
اطبع_سطر(كلمة[3])    # م
```

## 5. دوال النصوص الشائعة

### البحث

```sad
متغير جملة = "البرمجة بلغة ص ممتعة"

# البحث عن نص فرعي
إذا ("ص" في جملة)
    اطبع_سطر("وُجدت!")
نهاية
```

### التقسيم

```sad
متغير بيانات = "أحمد,سارة,خالد,ريم"
متغير أسماء = قسّم(بيانات, ",")

لكل اسم في أسماء
    اطبع_سطر("- " + اسم)
نهاية
```

### الاستبدال

```sad
متغير نص = "مرحبا يا عالم"
متغير جديد = استبدل(نص, "عالم", "ص")
اطبع_سطر(جديد)    # مرحبا يا ص
```

### التحويل

```sad
متغير ن = "  مرحبا  "
اطبع_سطر(اقتطع(ن))    # "مرحبا" — حذف المسافات

# تحويل الحالة (للنصوص اللاتينية)
متغير إنج = "hello"
اطبع_سطر(أحرف_كبيرة(إنج))    # HELLO
```

## 6. نصوص متعددة الأسطر

```sad
متغير قصيدة = "بسم الله الرحمن الرحيم
الحمد لله رب العالمين
الرحمن الرحيم"

اطبع_سطر(قصيدة)
```

## 7. محارف الهروب

| المحرف | المعنى |
|--------|--------|
| `\n` | سطر جديد |
| `\t` | مسافة جدولة |
| `\\` | شرطة مائلة |
| `\"` | علامة اقتباس |

```sad
اطبع_سطر("السطر الأول\nالسطر الثاني")
اطبع_سطر("العمود1\tالعمود2")
اطبع_سطر("قال: \"مرحبا\"")
```

## 8. مثال تطبيقي: محلل بيانات CSV

```sad
دالة حلل_سطر(نص سطر)
    متغير حقول = قسّم(سطر, ",")
    ارجع حقول
نهاية

دالة حلل_csv(نص بيانات)
    متغير أسطر = قسّم(بيانات, "\n")
    متغير نتائج = []
    
    لكل سطر في أسطر
        إذا (سطر != "")
            متغير حقول = حلل_سطر(سطر)
            نتائج.أضف(حقول)
        نهاية
    نهاية
    
    ارجع نتائج
نهاية

متغير csv = "أحمد,30,القاهرة\nسارة,25,الرياض\nخالد,35,دبي"
متغير جدول = حلل_csv(csv)

لكل صف في جدول
    اطبع_سطر("الاسم: " + صف[0] + " | العمر: " + صف[1] + " | المدينة: " + صف[2])
نهاية
```

## 9. UTF-8 والعربية

لغة ص تدعم UTF-8 بالكامل. النصوص العربية تعمل بسلاسة:

```sad
# أسماء متغيرات عربية مع نصوص عربية
متغير رسالة = "أهلاً وسهلاً"
متغير عدد_الحروف = طول(رسالة)

# المقارنة تعمل مع العربية
إذا (رسالة == "أهلاً وسهلاً")
    اطبع_سطر("متطابق!")
نهاية

# البحث في النصوص العربية
إذا ("سهلاً" في رسالة)
    اطبع_سطر("وُجدت الكلمة")
نهاية
```

## إرشادات عملية

1. **استخدم UTF-8 دائماً** — لغة ص تفترض ترميز UTF-8 لجميع الملفات.
2. **انتبه للطول** — `طول()` تعد الحروف (code points) وليس البايتات.
3. **تقسيم قبل المعالجة** — عند معالجة بيانات مهيكلة، قسّم أولاً ثم عالج كل جزء.
4. **الدمج بالترتيب** — عند دمج نصوص كثيرة، رتبها بشكل منطقي للقراءة.

## تمارين

1. اكتب دالة `عكس_نص(نص ن)` تعكس ترتيب حروف النص.
2. اكتب دالة `عدّ_كلمات(نص ن)` تحسب عدد الكلمات في جملة.
3. صمم دالة `هل_جملة_متناظرة(نص ن)` تتحقق إن كان النص يُقرأ من الاتجاهين.
4. أنشئ محللاً بسيطاً لملفات JSON (مفاتيح وقيم نصية فقط).
