# الفصل الثالث عشر: الوحدات والحزم المتقدمة

هذا الفصل يغطي نظام الوحدات المتقدم في لغة ص: الاستيراد الانتقائي، إعادة التصدير، فضاءات الأسماء، تنظيم المشاريع الكبيرة، وإدارة التبعيات باستخدام مدير الحزم.

---

## 13.1 مراجعة: الاستيراد الأساسي

في الفصل الثامن تعلمنا الاستيراد البسيط. لنُراجع الأساسيات سريعاً:

```sad
# استيراد وحدة كاملة
استورد "رياضيات"

# استيراد جزئي باستخدام من
من "رياضيات" استورد جذر_تربيعي، قوة

# استيراد مع تسمية بديلة
استورد "رياضيات" كـ ر

متغير النتيجة = ر.جذر_تربيعي(144)    # 12
```

## 13.2 التصدير

لجعل دوال وأصناف ملفك متاحة للاستخدام من ملفات أخرى، استخدم `صدّر`:

```sad
# ملف: أدوات_نص.ص

صدّر دالة أحرف_كبيرة(نص)
    # تحويل النص للأحرف الكبيرة
    ارجع نص.كبير()
نهاية

صدّر دالة عكس(نص)
    متغير النتيجة = ""
    متغير ف = طول(نص) - 1
    بينما (ف >= 0)
        النتيجة += نص[ف]
        ف -= 1
    نهاية
    ارجع النتيجة
نهاية

# دالة داخلية — غير مُصدَّرة
دالة مساعد_داخلي(نص)
    ارجع نص + "!"
نهاية
```

```sad
# ملف: التطبيق.ص
من "أدوات_نص" استورد أحرف_كبيرة، عكس

اطبع_سطر(أحرف_كبيرة("مرحبا"))   # مرحبا
اطبع_سطر(عكس("لغة ص"))          # ص ةغل
```

## 13.3 تنظيم المشروع في مجلدات

المشاريع الكبيرة تُنظَّم عادة في مجلدات:

```
مشروعي/
├── رئيسي.ص              # نقطة الدخول
├── نماذج/
│   ├── مستخدم.ص
│   ├── منتج.ص
│   └── طلب.ص
├── خدمات/
│   ├── مصادقة.ص
│   └── دفع.ص
├── أدوات/
│   ├── تحقق.ص
│   └── تنسيق.ص
└── اختبارات/
    ├── اختبار_مستخدم.ص
    └── اختبار_دفع.ص
```

### الاستيراد من مجلدات

```sad
# من ملف رئيسي.ص
```

## 13.4 فضاءات الأسماء

فضاء الأسماء يُنظم الرموز (الدوال والأصناف والمتغيرات) تحت اسم مشترك لتجنب التعارضات:

```sad
فضاء رياضيات
    ثابت باي = 3.14159265
    ثابت هـ = 2.71828182

    دالة مساحة_دائرة(نصف_القطر)
        ارجع باي * نصف_القطر ** 2
    نهاية

    دالة محيط_دائرة(نصف_القطر)
        ارجع 2 * باي * نصف_القطر
    نهاية
نهاية_فضاء

# الاستخدام
اطبع_سطر(رياضيات.مساحة_دائرة(5))    # 78.5398...
اطبع_سطر(رياضيات.باي)                 # 3.14159265
```

### فضاءات متداخلة

```sad
فضاء تطبيقي
    فضاء نماذج
        صنف مستخدم
            متغير الاسم = ""
            باني(اسم)
                هذا.الاسم = اسم
            نهاية
        نهاية
    نهاية_فضاء

    فضاء خدمات
        دالة أهلاً(مستخدم)
            اطبع_سطر("أهلاً " + مستخدم.الاسم)
        نهاية
    نهاية_فضاء
نهاية_فضاء

متغير م = جديد تطبيقي.نماذج.مستخدم("سارة")
تطبيقي.خدمات.أهلاً(م)    # أهلاً سارة
```

## 13.5 الاستيراد المتقدم

### استيراد انتقائي مع إعادة تسمية

```sad
من "رياضيات" استورد جذر_تربيعي كـ جذر، قوة كـ أس

اطبع_سطر(جذر(144))          # 12
اطبع_سطر(أس(2، 10))         # 1024
```

### إعادة التصدير

يمكنك إنشاء ملف "واجهة" يجمع تصديرات من عدة وحدات:

```sad
# ملف: نماذج/الكل.ص — نقطة دخول واحدة لكل النماذج
من "نماذج/مستخدم" استورد مستخدم
من "نماذج/منتج" استورد منتج
من "نماذج/طلب" استورد طلب

صدّر مستخدم
صدّر منتج
صدّر طلب
```

```sad
# الآن يمكن استيراد كل النماذج من مكان واحد
من "نماذج/الكل" استورد مستخدم، منتج، طلب
```

## 13.6 المكتبة القياسية

لغة ص توفر مكتبة قياسية غنية بوحدات جاهزة:

| الوحدة | الوصف | مثال |
|--------|-------|------|
| `رياضيات` | دوال رياضية | `جذر_تربيعي`، `جيب`، `جتا` |
| `نص` | معالجة النصوص | `قص`، `استبدال`، `قسّم` |
| `ملفات` | قراءة وكتابة الملفات | `اقرأ`، `اكتب`، `موجود` |
| `شبكة` | طلبات HTTP | `طلب_GET`، `طلب_POST` |
| `json` | تحليل وإنشاء JSON | `حلل`، `صيّغ` |
| `وقت` | التعامل مع الوقت | `الآن`، `تأخير` |
| `تشفير` | تجزئة وتشفير | `sha256`، `شفّر` |
| `مقابس` | اتصالات TCP/UDP | `tcp_جديد`، `اتصال` |

```sad
استورد "رياضيات"
استورد "json"

متغير بيانات = {"اسم": "أحمد"، "عمر": 25}
متغير نص_json = json.صيّغ(بيانات)
اطبع_سطر(نص_json)    # {"اسم":"أحمد","عمر":25}

اطبع_سطر(رياضيات.جذر_تربيعي(2))    # 1.4142...
```

## 13.7 مدير الحزم (sad-pkg)

مدير الحزم `sad-pkg` يتيح تثبيت واستخدام مكتبات خارجية:

```bash
# تثبيت حزمة
sad-pkg install اسم_الحزمة

# إنشاء مشروع جديد
sad-pkg init مشروعي

# بناء المشروع
sad-pkg build

# تشغيل الاختبارات
sad-pkg test
```

### ملف الحزمة (حزمة.ص أو package.sad)

```sad
# ملف: حزمة.ص
الاسم = "تطبيقي"
النسخة = "1.0.0"
المؤلف = "أحمد"

[تبعيات]
"خادم_ويب" = ">=2.0"
"قاعدة_بيانات" = "1.5.*"
```

### الاستيراد الدائري

```sad
# ❌ ملف أ.ص يستورد ب.ص، وب.ص يستورد أ.ص
# هذا يسبب حلقة لانهائية!

# ✅ الحل: أنشئ ملف مشترك يستورده كلاهما
# مشترك.ص — يحتوي الأنواع المشتركة
# أ.ص — يستورد مشترك.ص
# ب.ص — يستورد مشترك.ص
```

### تلوث فضاء الأسماء

```sad
# ❌ استيراد كل شيء
استورد "مكتبة_ضخمة"    # كل الرموز متاحة

# ✅ استيراد ما تحتاجه فقط
من "مكتبة_ضخمة" استورد الدالة_التي_أحتاجها
```

## ملخص الفصل

| المفهوم | الكلمة المفتاحية | الغرض |
|---------|------------------|-------|
| استيراد | `استورد` | جلب وحدة |
| استيراد جزئي | `من ... استورد` | جلب رموز محددة |
| تسمية بديلة | `كـ` | إعادة تسمية عند الاستيراد |
| تصدير | `صدّر` | إتاحة رمز للخارج |
| فضاء أسماء | `فضاء` / `نهاية_فضاء` | تنظيم الرموز |

---

## تمارين الفصل

1. **مكتبة أدوات:** أنشئ مجلد `أدوات/` يحوي 3 ملفات (رياضيات، نصوص، تحقق) وملف `الكل.ص` يعيد تصدير كل شيء.
2. **فضاء أسماء متداخل:** أنشئ فضاء `متجر` يحوي فضاء `منتجات` وفضاء `عملاء` لكل منهما صنف وأدوات.
3. **مقارنة الأنماط:** اكتب نفس البرنامج بثلاث طرق: استيراد كامل، استيراد جزئي، واستيراد مع تسمية. قارن الوضوح.
4. **ملف حزمة:** اكتب ملف `حزمة.ص` لمشروع خيالي يعتمد على 3 مكتبات خارجية.
