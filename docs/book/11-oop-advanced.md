# الفصل الحادي عشر: البرمجة الكائنية المتقدمة

في هذا الفصل، نتعمق في المفاهيم المتقدمة للبرمجة الكائنية في لغة ص: الوراثة المتعددة المستويات، الأصناف المجردة، السمات (الواجهات)، الخصائص، تحميل العوامل الزائد، الأعضاء الساكنة، والهدّامات.

---

## 11.1 الوراثة المتعددة المستويات

لغة ص تدعم الوراثة الأحادية باستخدام الكلمة المفتاحية `يرث`. يمكن بناء سلاسل وراثة متعددة المستويات حيث يرث الصنف الابن كل خصائص ودوال الصنف الأب وأجداده:

```sad
صنف كائن_حي
    دالة تنفس()
        اطبع_سطر("يتنفس...")
    نهاية
نهاية

صنف حيوان يرث كائن_حي
    متغير اسم = ""

    باني(الاسم)
        هذا.اسم = الاسم
    نهاية

    دالة تحرك()
        اطبع_سطر(هذا.اسم + " يتحرك")
    نهاية
نهاية

صنف قط يرث حيوان
    باني(الاسم)
        الأساس(الاسم)
    نهاية

    دالة مواء()
        اطبع_سطر(هذا.اسم + ": مياو!")
    نهاية
نهاية

متغير ق = جديد قط("ميشو")
ق.تنفس()     # يتنفس... (موروثة من كائن_حي)
ق.تحرك()     # ميشو يتحرك (موروثة من حيوان)
ق.مواء()      # ميشو: مياو! (خاصة بالقط)
```

عند استدعاء `الأساس(...)` في الباني، يتم تمرير القيم لباني الصنف الأب. هذا ضروري عندما يحتاج الأب لتهيئة خصائصه.

### إعادة تعريف الدوال (Override)

يمكن للصنف الابن إعادة تعريف دالة موروثة لتغيير سلوكها:

```sad
صنف حيوان
    دالة صوت()
        اطبع_سطر("...")
    نهاية
نهاية

صنف كلب يرث حيوان
    دالة صوت()
        اطبع_سطر("هاو هاو!")
    نهاية
نهاية

صنف قط يرث حيوان
    دالة صوت()
        اطبع_سطر("مياو!")
    نهاية
نهاية

# تعدد الأشكال: كل حيوان يصدر صوته الخاص
متغير حيوانات = [جديد كلب()، جديد قط()]
لكل ح في حيوانات
    ح.صوت()
نهاية
# هاو هاو!
# مياو!
```

## 11.2 محددات الوصول

لغة ص توفر ثلاثة مستويات للتحكم في رؤية الأعضاء:

| المحدد | المعنى | من يستطيع الوصول |
|--------|--------|------------------|
| `عام` | public | أي كود في أي مكان |
| `خاص` | private | من داخل نفس الصنف فقط |
| `محمي` | protected | من الصنف ومن الأصناف التي ترث منه |

```sad
صنف حساب_بنكي
    خاص متغير الرصيد = 0
    محمي متغير رقم_الحساب = ""
    عام متغير اسم_المالك = ""

    باني(الاسم، الرقم، رصيد_أولي)
        هذا.اسم_المالك = الاسم
        هذا.رقم_الحساب = الرقم
        هذا.الرصيد = رصيد_أولي
    نهاية

    عام دالة إيداع(مبلغ)
        إذا (مبلغ > 0)
            هذا.الرصيد += مبلغ
            اطبع_سطر("تم إيداع " + مبلغ)
        نهاية
    نهاية

    عام دالة الرصيد_الحالي()
        ارجع هذا.الرصيد
    نهاية
نهاية

صنف حساب_توفير يرث حساب_بنكي
    عام دالة عرض_الرقم()
        # يمكن الوصول لـ رقم_الحساب لأنه محمي
        اطبع_سطر("رقم الحساب: " + هذا.رقم_الحساب)
    نهاية
نهاية
```

> **قاعدة:** إذا لم تحدد مستوى الوصول، فالافتراضي هو `عام`.

## 11.3 الأصناف المجردة

الصنف المجرد يُعرَّف بالكلمة `مجرد` ولا يمكن إنشاء نسخ منه مباشرة. يُستخدم كقالب أساسي يُلزم الأصناف الابنة بتنفيذ دوال معينة:

```sad
مجرد صنف شكل
    مجرد دالة المساحة()
    مجرد دالة المحيط()

    دالة وصف()
        اطبع_سطر("شكل هندسي — المساحة: " + هذا.المساحة())
    نهاية
نهاية

صنف مستطيل يرث شكل
    متغير العرض = 0
    متغير الطول = 0

    باني(ع، ط)
        هذا.العرض = ع
        هذا.الطول = ط
    نهاية

    دالة المساحة()
        ارجع هذا.العرض * هذا.الطول
    نهاية

    دالة المحيط()
        ارجع 2 * (هذا.العرض + هذا.الطول)
    نهاية
نهاية

صنف دائرة يرث شكل
    متغير نصف_القطر = 0

    باني(نق)
        هذا.نصف_القطر = نق
    نهاية

    دالة المساحة()
        ارجع 3.14159 * هذا.نصف_القطر ** 2
    نهاية

    دالة المحيط()
        ارجع 2 * 3.14159 * هذا.نصف_القطر
    نهاية
نهاية

متغير م = جديد مستطيل(5، 3)
م.وصف()       # شكل هندسي — المساحة: 15

متغير د = جديد دائرة(7)
د.وصف()       # شكل هندسي — المساحة: 153.93...
```

الدوال المجردة ليس لها جسم — يجب تنفيذها في كل صنف ابن.

## 11.4 السمات (الواجهات)

السمة مشابهة للصنف المجرد لكنها أكثر مرونة: يمكن للصنف تنفيذ عدة سمات في آن واحد. تُعرَّف السمة بكلمة `سمة` وتُنفَّذ بكلمة `نفّذ`:

```sad
سمة قابل_للطباعة
    دالة إلى_نص()
نهاية

سمة قابل_للمقارنة
    دالة قارن(آخر)
نهاية

صنف طالب
    متغير الاسم = ""
    متغير الدرجة = 0

    باني(اسم، درجة)
        هذا.الاسم = اسم
        هذا.الدرجة = درجة
    نهاية
نهاية

نفّذ قابل_للطباعة ل طالب
    دالة إلى_نص()
        ارجع "طالب(" + هذا.الاسم + "، " + هذا.الدرجة + ")"
    نهاية
نهاية

نفّذ قابل_للمقارنة ل طالب
    دالة قارن(آخر)
        إذا (هذا.الدرجة > آخر.الدرجة)
            ارجع 1
        وإلا
            إذا (هذا.الدرجة < آخر.الدرجة)
                ارجع -1
            وإلا
                ارجع 0
            نهاية
        نهاية
    نهاية
نهاية

متغير أحمد = جديد طالب("أحمد"، 95)
اطبع_سطر(أحمد.إلى_نص())     # طالب(أحمد، 95)
```

### الفرق بين السمة والصنف المجرد

| الخاصية | صنف مجرد | سمة |
|---------|----------|------|
| إنشاء نسخ | لا | لا |
| وراثة متعددة | لا (أحادية فقط) | نعم (عدة سمات) |
| خصائص ومتغيرات | نعم | لا (دوال فقط) |
| دوال بجسم | نعم | عادة لا |

## 11.5 الخصائص (Getter/Setter)

الخصائص توفر واجهة أنيقة للوصول المتحكم به للبيانات. تبدو كمتغيرات عادية لكن خلف الكواليس تنفّذ دوال:

```sad
صنف درجة_حرارة
    خاص متغير _سلسيوس = 0

    باني(س)
        هذا._سلسيوس = س
    نهاية

    خاصية سلسيوس
        احصل
            ارجع هذا._سلسيوس
        نهاية
        عيّن(قيمة)
            إذا (قيمة < -273.15)
                ارمي "درجة حرارة غير ممكنة!"
            نهاية
            هذا._سلسيوس = قيمة
        نهاية
    نهاية

    خاصية فهرنهايت
        احصل
            ارجع هذا._سلسيوس * 9 / 5 + 32
        نهاية
        عيّن(قيمة)
            هذا._سلسيوس = (قيمة - 32) * 5 / 9
        نهاية
    نهاية
نهاية

متغير ح = جديد درجة_حرارة(100)
اطبع_سطر(ح.سلسيوس)       # 100
اطبع_سطر(ح.فهرنهايت)     # 212
ح.فهرنهايت = 32
اطبع_سطر(ح.سلسيوس)       # 0
```

الخصائص تسمح بالتحقق من القيم (validation) والحساب الكسول (lazy computation) دون تغيير واجهة الاستخدام.

## 11.6 تحميل العوامل الزائد

يمكنك تعريف سلوك العوامل الحسابية والمقارنة لأصنافك باستخدام كلمة `عامل`:

```sad
صنف متجه
    متغير س = 0
    متغير ص = 0

    باني(س، ص)
        هذا.س = س
        هذا.ص = ص
    نهاية

    عامل +(آخر)
        ارجع جديد متجه(هذا.س + آخر.س، هذا.ص + آخر.ص)
    نهاية

    عامل -(آخر)
        ارجع جديد متجه(هذا.س - آخر.س، هذا.ص - آخر.ص)
    نهاية

    عامل *(عدد)
        ارجع جديد متجه(هذا.س * عدد، هذا.ص * عدد)
    نهاية

    عامل ==(آخر)
        ارجع هذا.س == آخر.س و هذا.ص == آخر.ص
    نهاية

    دالة إلى_نص()
        ارجع "(" + هذا.س + "، " + هذا.ص + ")"
    نهاية
نهاية

متغير أ = جديد متجه(3، 4)
متغير ب = جديد متجه(1، 2)
متغير ج = أ + ب
اطبع_سطر(ج.إلى_نص())     # (4، 6)
اطبع_سطر(أ == ب)          # خطأ

متغير د = أ * 3
اطبع_سطر(د.إلى_نص())     # (9، 12)
```

العوامل المدعومة للتحميل: `+`، `-`، `*`، `/`، `%`، `**`، `==`، `!=`، `<`، `>`، `<=`، `>=`.

## 11.7 الأعضاء الساكنة

الأعضاء الساكنة تنتمي للصنف نفسه وليس لنسخة محددة. تُعرَّف بكلمة `ساكن`:

```sad
صنف عدّاد
    ساكن متغير العدد = 0

    باني()
        عدّاد.العدد += 1
    نهاية

    ساكن دالة كم_نسخة()
        ارجع عدّاد.العدد
    نهاية

    ساكن دالة صفّر()
        عدّاد.العدد = 0
    نهاية
نهاية

متغير أ = جديد عدّاد()
متغير ب = جديد عدّاد()
متغير ج = جديد عدّاد()
اطبع_سطر(عدّاد.كم_نسخة())   # 3
عدّاد.صفّر()
اطبع_سطر(عدّاد.كم_نسخة())   # 0
```

> **استخدام عملي:** الأعضاء الساكنة مفيدة لعدّ النسخ، مشاركة إعدادات عامة، أو نمط Singleton.

## 11.8 الهدّامات

الهدّام يُنفَّذ تلقائياً عند تدمير الكائن. يُستخدم لتنظيف الموارد (إغلاق ملفات، تحرير اتصالات):

```sad
صنف اتصال_قاعدة_بيانات
    متغير المضيف = ""

    باني(مضيف)
        هذا.المضيف = مضيف
        اطبع_سطر("اتصال بـ " + مضيف)
    نهاية

    دالة استعلام(جملة)
        اطبع_سطر("تنفيذ: " + جملة)
        ارجع "نتيجة"
    نهاية

    هدم()
        اطبع_سطر("إغلاق الاتصال بـ " + هذا.المضيف)
    نهاية
نهاية
```

## 11.9 نمط تصميم: البناء المتسلسل (Method Chaining)

يمكن بناء واجهة سلسة بإرجاع `هذا` من كل دالة:

```sad
صنف بانٍ_استعلام
    خاص متغير _جدول = ""
    خاص متغير _شرط = ""
    خاص متغير _حد = 0

    دالة من(جدول)
        هذا._جدول = جدول
        ارجع هذا
    نهاية

    دالة حيث(شرط)
        هذا._شرط = شرط
        ارجع هذا
    نهاية

    دالة حد_أقصى(ن)
        هذا._حد = ن
        ارجع هذا
    نهاية

    دالة بناء()
        متغير ق = "SELECT * FROM " + هذا._جدول
        إذا (هذا._شرط != "")
            ق += " WHERE " + هذا._شرط
        نهاية
        إذا (هذا._حد > 0)
            ق += " LIMIT " + هذا._حد
        نهاية
        ارجع ق
    نهاية
نهاية

متغير استعلام = جديد بانٍ_استعلام()
متغير نتيجة = استعلام.من("طلاب").حيث("الدرجة > 90").حد_أقصى(10).بناء()
اطبع_سطر(نتيجة)
# SELECT * FROM طلاب WHERE الدرجة > 90 LIMIT 10
```

## ملخص الفصل

| المفهوم | الكلمة المفتاحية | الغرض |
|---------|------------------|-------|
| الوراثة | `يرث` | إعادة استخدام كود الأب |
| باني الأب | `الأساس(...)` | تهيئة الصنف الأب |
| مجرد | `مجرد` | فرض تنفيذ دوال في الأبناء |
| سمة | `سمة` / `نفّذ` | عقد يطبقه عدة أصناف |
| خاصية | `خاصية` / `احصل` / `عيّن` | وصول متحكم للبيانات |
| عامل | `عامل` | تحميل العوامل (+، -، ==، ...) |
| ساكن | `ساكن` | عضو ينتمي للصنف لا للنسخة |
| هدّام | `هدم` | تنظيف الموارد عند التدمير |
| وصول | `عام` / `خاص` / `محمي` | التحكم في الرؤية |

## تمارين الفصل

1. **أشكال هندسية:** أنشئ صنف `مثلث` يرث من `شكل` المجرد وينفّذ `المساحة()` و`المحيط()` باستخدام صيغة هيرون.
2. **نظام بنكي:** أوسّع صنف `حساب_بنكي` ليدعم `حساب_توفير` (بفائدة) و`حساب_جاري` (بسقف سحب).
3. **السمات المركبة:** عرّف سمة `قابل_للتسلسل` مع دالة `إلى_json()`، وسمة `قابل_للنسخ` مع دالة `نسخ()`، ونفّذهما لصنف `مستند`.
4. **متجه ثلاثي الأبعاد:** وسّع صنف `متجه` ليدعم البعد الثالث `ز` مع حساب الطول (الجذر التربيعي) وكل العوامل.
