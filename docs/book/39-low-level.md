# الفصل التاسع والثلاثون: البرمجة منخفضة المستوى (Low-Level Programming)

## مقدمة نظرية

**البرمجة منخفضة المستوى** تعني التحكم المباشر بالعتاد: الذاكرة، المعالج، العمليات الذرية. لغة ص تدعم ذلك عبر **التوجيهات** (`@`) — تعليمات خاصة للتحكم المنخفض.

| المستوى | اللغة | التحكم |
|---------|-------|--------|
| عالي | Python, JavaScript | تلقائي بالكامل |
| **متوسط-عالي** | **لغة ص** | **تلقائي + توجيهات للتحكم** |
| منخفض | C, Rust | يدوي بالكامل |
| أدنى | Assembly | تعليمات معالج مباشرة |

---

## 1. التوجيهات (@)

### حجم النوع

```sad
# @حجم — حجم النوع بالبايتات
متغير حجم_رقم = @حجم(رقم)       # 8 بايت (64-bit)
متغير حجم_عشري = @حجم(عشري)     # 8 بايت (64-bit)
متغير حجم_منطقي = @حجم(منطقي)   # 1 بايت
متغير حجم_نص = @حجم(نص)         # حجم المؤشر (8 بايت)

اطبع_سطر("حجم رقم: " + حجم_رقم + " بايت")
اطبع_سطر("حجم عشري: " + حجم_عشري + " بايت")
```

### المتغيرات المتطايرة

```sad
# @متطاير — لا يُحسّن المترجم هذا المتغير
# مهم للعتاد والتزامن
@متطاير متغير حالة_الجهاز = 0

# بدون @متطاير، المترجم قد يزيل القراءات المتكررة
بينما (حالة_الجهاز == 0)
   # المترجم يقرأ من الذاكرة كل مرة بسبب @متطاير
نهاية
```

## 2. العمليات الذرية

```sad
# العمليات الذرية آمنة في البيئات المتزامنة
متغير عداد = 0

# ✗ غير آمن في التزامن
# عداد = عداد + 1   # قراءة + حساب + كتابة = 3 خطوات

# ✓ آمن — عملية واحدة غير قابلة للمقاطعة
@ذري(أضف، عداد، 1)

# عمليات ذرية متاحة:
@ذري(تحميل، عداد)           # قراءة ذرية
@ذري(تخزين، عداد، 42)       # كتابة ذرية
@ذري(أضف، عداد، 1)          # جمع ذري
@ذري(اطرح، عداد، 1)         # طرح ذري
@ذري(تبادل، عداد، 100)      # استبدال ذري
@ذري(قارن_وتبادل، عداد، 0، 1)  # CAS — أساس الأقفال
```

## 3. الكتلة غير الآمنة

```sad
# @غير_آمن — يعطل فحوصات الأمان
# استخدم فقط عندما تعرف ماذا تفعل!

@غير_آمن
   # وصول مباشر للذاكرة
   متغير مؤشر = عنوان_ذاكرة(0x1000)
   متغير قيمة = اقرأ_ذاكرة(مؤشر)

   # تحويل أنواع بدون فحص
   متغير بايتات = حوّل_خام(عدد_كبير، مصفوفة)
نهاية

# خارج @غير_آمن، كل الفحوصات تعود
```

## 4. التنفيذ وقت الترجمة

```sad
# @وقت_الترجمة — يُنفذ أثناء الترجمة، لا أثناء التشغيل
@وقت_الترجمة
   ثابت جدول_مربعات = مصفوفة(100)
   لكل ي في نطاق(0، 100)
      جدول_مربعات[ي] = ي * ي
   نهاية
نهاية

# عند التشغيل، الجدول جاهز مباشرة — لا حساب!
اطبع_سطر(جدول_مربعات[7])   # 49 — محسوب مسبقاً

# مثال: حساب ثوابت رياضية مسبقاً
@وقت_الترجمة
   ثابت مضروبات = مصفوفة(20)
   مضروبات[0] = 1
   لكل ي في نطاق(1، 20)
      مضروبات[ي] = مضروبات[ي - 1] * ي
   نهاية
نهاية

اطبع_سطر("10! = " + مضروبات[10])  # 3628800
```

## 5. التجميع المضمن (sadc فقط)

```sad
# @تجميع — تعليمات معالج مباشرة (للمترجم sadc فقط)
دالة توقف_المعالج()
   @تجميع("nop")        # لا تفعل شيئاً (تأخير)
   @تجميع("nop")
   @تجميع("nop")
نهاية

# استخدام عملي: قراءة عداد الأداء
دالة اقرأ_عداد_الدورات()
   متغير منخفض = 0
   متغير مرتفع = 0
   @تجميع("rdtsc")      # قراءة Time Stamp Counter
   # النتيجة في سجلات المعالج
   ارجع مرتفع * 4294967296 + منخفض
نهاية
```

## 6. البنى (Struct) للتحكم بتخطيط الذاكرة

```sad
# البنية تخزن البيانات بترتيب ثابت في الذاكرة
بنية نقطة
   عام متغير س: عشري    # 8 بايت، إزاحة 0
   عام متغير ص: عشري    # 8 بايت، إزاحة 8
نهاية
# الحجم الإجمالي: 16 بايت

بنية لون
   عام متغير أحمر: رقم    # 8 بايت
   عام متغير أخضر: رقم    # 8 بايت
   عام متغير أزرق: رقم    # 8 بايت
نهاية

بنية بكسل
   عام متغير الموقع: نقطة
   عام متغير اللون: لون
نهاية

# الاستخدام
متغير ب = جديد بكسل()
ب.الموقع.س = 100.0
ب.الموقع.ص = 200.0
ب.اللون.أحمر = 255
ب.اللون.أخضر = 128
ب.اللون.أزرق = 0
```

## متى تستخدم البرمجة المنخفضة؟

| السيناريو | التوجيه |
|-----------|---------|
| قياس حجم الأنواع | `@حجم` |
| برمجة متزامنة آمنة | `@ذري` |
| أداء حرج، جداول مُحسّبة | `@وقت_الترجمة` |
| تعامل مع عتاد | `@غير_آمن` + `@متطاير` |
| أنظمة تشغيل / drivers | `@تجميع` |

> **تحذير:** معظم البرامج لا تحتاج هذه التوجيهات. استخدمها فقط عند الضرورة.

---

## خلاصة

| التوجيه | الوظيفة |
|---------|---------|
| `@حجم(نوع)` | حجم بالبايتات |
| `@متطاير` | منع تحسين المتغير |
| `@ذري(عملية)` | عملية ذرية |
| `@غير_آمن` | كتلة بدون فحوصات |
| `@وقت_الترجمة` | حساب مسبق |
| `@تجميع("code")` | تعليمات معالج |

## تمارين

1. استخدم `@حجم` لحساب الحجم الكلي لبنية `سيارة` (اسم + لون + سنة + سعر).
2. اكتب عداداً ذرياً آمناً للاستخدام في عدة مسارات تنفيذ.
3. استخدم `@وقت_الترجمة` لبناء جدول الأعداد الأولية حتى 1000.
4. اشرح لماذا `@غير_آمن` خطير ومتى يكون ضرورياً.
