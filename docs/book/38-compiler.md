# الفصل الثامن والثلاثون: المترجم sadc (The Compiler)

## مقدمة نظرية

**المترجم** (Compiler) يحوّل الكود المصدري إلى ملف تنفيذي أصلي يعمل مباشرة على المعالج بدون مفسر. مترجم ص (`sadc`) يستخدم LLVM كبنية خلفية.

### مراحل الترجمة

```
 ① التحليل المعجمي    ② التحليل النحوي    ③ البناء الوسيط
    Source .ص      →     Tokens         →      AST

 ④ تحويل SIR        ⑤ تحسين SIR        ⑥ توليد LLVM IR
    AST           →     SIR Opcodes    →      LLVM IR

 ⑦ تحسين LLVM       ⑧ توليد الكود       ⑨ الربط
    LLVM IR       →     Object Code    →      Executable
```

---

## 1. المحلل المعجمي (Lexer)

المحلل المعجمي يحوّل النص إلى رموز (Tokens):

```sad
متغير س = 42 + 8
```

ينتج الرموز:
```
KEYWORD_VAR    "متغير"      سطر 1، عمود 1
IDENTIFIER     "س"          سطر 1، عمود 6
ASSIGN         "="          سطر 1، عمود 8
NUMBER         "42"         سطر 1، عمود 10
PLUS           "+"          سطر 1، عمود 13
NUMBER         "8"          سطر 1، عمود 15
```

### أنواع الرموز

| الفئة | أمثلة |
|-------|-------|
| كلمات محجوزة | `KEYWORD_FUNCTION`، `KEYWORD_IF`، `KEYWORD_END` |
| معرفات | `IDENTIFIER` |
| أعداد | `NUMBER`، `FLOAT` |
| نصوص | `STRING` |
| عوامل | `PLUS`، `MINUS`، `ASSIGN`، `EQUAL` |
| فواصل | `COMMA`، `SEMICOLON`، `NEWLINE` |

---

## 2. المحلل النحوي (Parser)

المحلل النحوي يبني **شجرة البناء المجرد** (AST):

```sad
إذا (س > 0)
   اطبع_سطر("موجب")
نهاية
```

الشجرة الناتجة:
```
IfStatement
├── condition: BinaryExpr
│   ├── left: Identifier("س")
│   ├── op: ">"
│   └── right: NumberLiteral(0)
├── thenBlock:
│   └── CallExpr
│       ├── callee: Identifier("اطبع_سطر")
│       └── args: [StringLiteral("موجب")]
└── elseBlock: null
```

## 3. التمثيل الوسيط SIR

SIR (Sad Intermediate Representation) هو تمثيل وسيط ملكي بـ 12 تعليمة:

| التعليمة | الوصف | مثال |
|----------|-------|------|
| `LOAD` | تحميل قيمة | `LOAD r0, 42` |
| `STORE` | تخزين في متغير | `STORE "س", r0` |
| `ADD` | جمع | `ADD r2, r0, r1` |
| `SUB` | طرح | `SUB r2, r0, r1` |
| `MUL` | ضرب | `MUL r2, r0, r1` |
| `DIV` | قسمة | `DIV r2, r0, r1` |
| `CMP` | مقارنة | `CMP r0, r1` |
| `JMP` | قفز | `JMP label` |
| `JMPIF` | قفز شرطي | `JMPIF cond, label` |
| `CALL` | استدعاء دالة | `CALL "اطبع", r0` |
| `RET` | إرجاع | `RET r0` |
| `ALLOC` | حجز ذاكرة | `ALLOC r0, 64` |

### مثال SIR

```sad
دالة جمع(أ، ب)
   ارجع أ + ب
نهاية
```

```
FUNCTION "جمع":
   PARAM r0, "أ"
   PARAM r1, "ب"
   ADD r2, r0, r1
   RET r2
END
```

## 4. توليد LLVM IR

SIR يتحول إلى LLVM IR:

```llvm
define double @"جمع"(double %0, double %1) {
entry:
  %2 = fadd double %0, %1
  ret double %2
}
```

LLVM يتولى:
- **التحسينات**: إزالة الكود الميت، طي الثوابت، فتح الحلقات
- **توليد الكود**: تحويل إلى كود آلة لمعالج محدد (x86, ARM, ...)
- **الربط**: ربط مع المكتبات النظامية

## 5. استخدام المترجم عملياً

```bash
# ترجمة أساسية
sadc حاسبة.ص -o حاسبة

# ترجمة مع تحسين
sadc حاسبة.ص -o حاسبة -O2

# عرض المراحل الوسيطة
sadc حاسبة.ص --emit-tokens    # الرموز
sadc حاسبة.ص --emit-ast       # الشجرة
sadc حاسبة.ص --emit-sir       # التمثيل الوسيط
sadc حاسبة.ص --emit-llvm      # LLVM IR

# ترجمة متعددة الملفات
sadc رئيسي.ص مساعدات.ص نماذج.ص -o تطبيقي
```

### مقارنة: المفسر vs المترجم

```sad
دالة فيب(ن)
   إذا (ن <= 1)
      ارجع ن
   نهاية
   ارجع فيب(ن - 1) + فيب(ن - 2)
نهاية

اطبع_سطر(فيب(35))
```

| الوضع | الأمر | السرعة النموذجية |
|-------|-------|-----------------|
| مفسر | `sad فيب.ص` | ~5-10 ثوانٍ |
| مترجم O0 | `sadc فيب.ص -o f; ./f` | ~0.5 ثانية |
| مترجم O2 | `sadc فيب.ص -o f -O2; ./f` | ~0.1 ثانية |

## 6. الأنواع في المترجم

المترجم يستنتج الأنواع تلقائياً (Type Inference):

```sad
متغير س = 42        # → رقم (i64)
متغير ع = 3.14      # → عشري (f64)
متغير ن = "مرحبا"   # → نص (string)
متغير م = صحيح      # → منطقي (i1)

# المترجم يختار التعليمات المناسبة:
# رقم + رقم → ADD (integer)
# عشري + عشري → FADD (float)
# نص + نص → CONCAT (string)
```

## خلاصة

| المرحلة | المدخل | المخرج |
|---------|--------|--------|
| المعجمي | كود .ص | رموز (Tokens) |
| النحوي | رموز | شجرة AST |
| SIR | AST | تعليمات SIR |
| LLVM | SIR | LLVM IR |
| الكود | LLVM IR | ملف تنفيذي |

## تمارين

1. اكتب برنامجاً بسيطاً وشغّله بالمفسر ثم المترجم وقارن الأداء.
2. استخدم `--emit-ast` لعرض شجرة بناء دالة تكرارية.
3. استخدم `--emit-sir` واشرح كل تعليمة SIR في دالة `حاسبة(أ، ب)`.
4. اكتب ملاحظاتك عن الفرق بين LLVM IR وتعليمات SIR.
