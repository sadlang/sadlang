# الفصل الثامن والعشرون: الرسوميات ثنائية البعد (2D Graphics)

## مقدمة نظرية

الرسوميات ثنائية البعد تسمح برسم أشكال وصور وتحريكها. لغة ص تستخدم SDL2 لتقديم واجهة رسومية عربية.

| المفهوم | الوصف |
|---------|-------|
| **اللوحة** (Canvas) | سطح الرسم |
| **الأشكال** | نقطة، خط، مستطيل، دائرة |
| **الألوان** | قيم RGB أو RGBA |
| **التحريك** | تحديث الإطارات (frames) |

---

## 1. نافذة رسومية

```sad
من "رسوميات" استورد لوحة

متغير شاشة = جديد لوحة("رسومياتي"، 800، 600)

# تعيين لون الخلفية
شاشة.لون_الخلفية(30، 30، 50)
شاشة.امسح()

# رسم مستطيل
شاشة.لون(255، 100، 50)
شاشة.مستطيل(100، 100، 200، 150)

# رسم دائرة
شاشة.لون(50، 200، 100)
شاشة.دائرة(400، 300، 80)

# رسم خط
شاشة.لون(255، 255، 255)
شاشة.خط(0، 0، 800، 600)

# عرض النص
شاشة.لون(255، 255، 0)
شاشة.نص("مرحباً بالرسوميات!"، 250، 50، 24)

شاشة.حدّث()
شاشة.انتظر()
```

## 2. التحريك (Animation)

```sad
من "رسوميات" استورد لوحة

متغير شاشة = جديد لوحة("تحريك"، 800، 600)
متغير س = 50
متغير ص = 300
متغير سرعة = 3

بينما (شاشة.نشط())
   شاشة.لون_الخلفية(20، 20، 40)
   شاشة.امسح()

   # رسم الكرة المتحركة
   شاشة.لون(255، 50، 50)
   شاشة.دائرة(س، ص، 25)

   # تحريك
   س = س + سرعة
   إذا (س > 775 أو س < 25)
      سرعة = -سرعة
   نهاية

   شاشة.حدّث()
   شاشة.تأخير(16)   # ~60 إطار/ثانية
نهاية
```

## 3. التفاعل مع المستخدم

```sad
من "رسوميات" استورد لوحة

متغير شاشة = جديد لوحة("تفاعل"، 800، 600)
متغير نقاط = []

بينما (شاشة.نشط())
   # قراءة الأحداث
   متغير حدث = شاشة.حدث()

   إذا (حدث != لاشيء)
      إذا (حدث.نوع == "نقر")
         نقاط.أضف({"س": حدث.س، "ص": حدث.ص})
      نهاية
   نهاية

   # رسم
   شاشة.لون_الخلفية(0، 0، 0)
   شاشة.امسح()

   شاشة.لون(0، 255، 0)
   لكل نقطة في نقاط
      شاشة.دائرة(نقطة["س"]، نقطة["ص"]، 10)
   نهاية

   شاشة.لون(255، 255، 255)
   شاشة.نص("انقر لرسم نقاط (" + طول(نقاط) + ")"، 10، 10، 18)

   شاشة.حدّث()
   شاشة.تأخير(16)
نهاية
```

## 4. رسم الأشكال الهندسية

```sad
من "رسوميات" استورد لوحة

متغير شاشة = جديد لوحة("أشكال"، 800، 600)

شاشة.لون_الخلفية(245، 245، 250)
شاشة.امسح()

# مستطيل
شاشة.لون(65، 105، 225)
شاشة.مستطيل_ممتلئ(50، 50، 150، 100)

# مستطيل مفرّغ
شاشة.لون(220، 50، 50)
شاشة.مستطيل(250، 50، 150، 100)

# دوائر متداخلة
متغير ي = 0
بينما (ي < 5)
   شاشة.لون(50 + ي * 40، 100، 200 - ي * 30)
   شاشة.دائرة(550، 100، 50 - ي * 10)
   ي = ي + 1
نهاية

# شبكة
شاشة.لون(200، 200، 200)
متغير خ = 0
بينما (خ < 800)
   شاشة.خط(خ، 300، خ، 600)
   خ = خ + 40
نهاية
متغير ع = 300
بينما (ع < 600)
   شاشة.خط(0، ع، 800، ع)
   ع = ع + 40
نهاية

شاشة.حدّث()
شاشة.انتظر()
```

## 5. لعبة بسيطة: بونغ (Pong)

```sad
من "رسوميات" استورد لوحة

متغير شاشة = جديد لوحة("بونج"، 800، 600)

# الكرة
متغير كرة_س = 400
متغير كرة_ص = 300
متغير كرة_سرعة_س = 4
متغير كرة_سرعة_ص = 3

# المضرب
متغير مضرب_ص = 250
متغير مضرب_ع = 100
متغير نقاط = 0

بينما (شاشة.نشط())
   # إدخال
   إذا (شاشة.مفتاح("أعلى") و مضرب_ص > 0)
      مضرب_ص = مضرب_ص - 5
   نهاية
   إذا (شاشة.مفتاح("أسفل") و مضرب_ص < 500)
      مضرب_ص = مضرب_ص + 5
   نهاية

   # تحريك الكرة
   كرة_س = كرة_س + كرة_سرعة_س
   كرة_ص = كرة_ص + كرة_سرعة_ص

   # ارتداد من الحدود
   إذا (كرة_ص <= 0 أو كرة_ص >= 590)
      كرة_سرعة_ص = -كرة_سرعة_ص
   نهاية
   إذا (كرة_س >= 790)
      كرة_سرعة_س = -كرة_سرعة_س
   نهاية

   # اصطدام بالمضرب
   إذا (كرة_س <= 30 و كرة_ص >= مضرب_ص و كرة_ص <= مضرب_ص + مضرب_ع)
      كرة_سرعة_س = -كرة_سرعة_س
      نقاط = نقاط + 1
   نهاية

   # خروج من اليسار
   إذا (كرة_س < 0)
      كرة_س = 400
      كرة_ص = 300
   نهاية

   # رسم
   شاشة.لون_الخلفية(0، 0، 0)
   شاشة.امسح()

   شاشة.لون(255، 255، 255)
   شاشة.مستطيل_ممتلئ(20، مضرب_ص، 10، مضرب_ع)   # المضرب

   شاشة.لون(255، 255، 0)
   شاشة.دائرة(كرة_س، كرة_ص، 10)                  # الكرة

   شاشة.لون(255، 255، 255)
   شاشة.نص("النقاط: " + نقاط، 350، 10، 20)

   شاشة.حدّث()
   شاشة.تأخير(16)
نهاية
```

## خلاصة

| الدالة | الوصف |
|--------|-------|
| `لوحة(عنوان, عرض, ارتفاع)` | إنشاء نافذة |
| `لون(ر, خ, ز)` | تعيين لون الرسم |
| `مستطيل/دائرة/خط` | رسم أشكال |
| `نص(محتوى, س, ص, حجم)` | رسم نص |
| `حدث()` | قراءة أحداث المستخدم |
| `مفتاح(اسم)` | فحص ضغط المفتاح |

## تمارين

1. ابنِ لعبة ثعبان (Snake) كاملة.
2. ارسم ساعة تناظرية (analog clock) متحركة.
3. ابنِ برنامج رسم حر (paint) مع ألوان وأحجام فراشي.
4. ابنِ لعبة asteroid بسيطة مع سفينة فضاء تدور.
