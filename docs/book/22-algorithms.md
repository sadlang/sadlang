# الفصل الثاني والعشرون: الخوارزميات الأساسية (Algorithms)

## مقدمة نظرية

**الخوارزمية** هي مجموعة خطوات محددة لحل مشكلة. تُقاس كفاءتها بـ **التعقيد الزمني** (Big-O):

| التعقيد | المعنى | مثال |
|---------|--------|------|
| O(1) | ثابت | الوصول لعنصر بالفهرس |
| O(log n) | لوغاريتمي | البحث الثنائي |
| O(n) | خطي | البحث التسلسلي |
| O(n log n) | خطي لوغاريتمي | الترتيب بالدمج |
| O(n²) | تربيعي | الترتيب الفقاعي |

## 1. البحث التسلسلي (Linear Search)

```sad
دالة بحث_تسلسلي(قائمة، هدف)
   متغير ي = 0
   بينما (ي < طول(قائمة))
      إذا (قائمة[ي] == هدف)
         ارجع ي
      نهاية
      ي = ي + 1
   نهاية
   ارجع -1    # غير موجود
نهاية

متغير بيانات = [4، 7، 2، 9، 1، 5]
اطبع_سطر(بحث_تسلسلي(بيانات، 9))   # 3
اطبع_سطر(بحث_تسلسلي(بيانات، 8))   # -1
```

## 2. البحث الثنائي (Binary Search)

يعمل فقط على قوائم **مرتبة** — يقسم المنطقة إلى نصفين في كل خطوة:

```sad
دالة بحث_ثنائي(قائمة، هدف)
   متغير يسار = 0
   متغير يمين = طول(قائمة) - 1

   بينما (يسار <= يمين)
      متغير وسط = (يسار + يمين) / 2
      إذا (قائمة[وسط] == هدف)
         ارجع وسط
      وإلا
         إذا (قائمة[وسط] < هدف)
            يسار = وسط + 1
         وإلا
            يمين = وسط - 1
         نهاية
      نهاية
   نهاية
   ارجع -1
نهاية

متغير مرتبة = [1، 3، 5، 7، 9، 11، 13، 15]
اطبع_سطر(بحث_ثنائي(مرتبة، 7))    # 3
اطبع_سطر(بحث_ثنائي(مرتبة، 10))   # -1
```

## 3. الترتيب الفقاعي (Bubble Sort)

```sad
دالة ترتيب_فقاعي(قائمة)
   متغير ن = طول(قائمة)
   متغير ي = 0
   بينما (ي < ن)
      متغير ج = 0
      متغير تم_تبديل = خطأ
      بينما (ج < ن - ي - 1)
         إذا (قائمة[ج] > قائمة[ج + 1])
            متغير مبادلة = قائمة[ج]
            قائمة[ج] = قائمة[ج + 1]
            قائمة[ج + 1] = مبادلة
            تم_تبديل = صحيح
         نهاية
         ج = ج + 1
      نهاية
      إذا (ليس تم_تبديل)
         توقف    # القائمة مرتبة بالفعل
      نهاية
      ي = ي + 1
   نهاية
   ارجع قائمة
نهاية

اطبع_سطر(ترتيب_فقاعي([64، 34، 25، 12، 22، 11، 90]))
# [11, 12, 22, 25, 34, 64, 90]
```

## 4. ترتيب الاختيار (Selection Sort)

```sad
دالة ترتيب_اختيار(قائمة)
   متغير ن = طول(قائمة)
   متغير ي = 0
   بينما (ي < ن)
      متغير أصغر = ي
      متغير ج = ي + 1
      بينما (ج < ن)
         إذا (قائمة[ج] < قائمة[أصغر])
            أصغر = ج
         نهاية
         ج = ج + 1
      نهاية
      # تبديل
      متغير مبادلة = قائمة[ي]
      قائمة[ي] = قائمة[أصغر]
      قائمة[أصغر] = مبادلة
      ي = ي + 1
   نهاية
   ارجع قائمة
نهاية

اطبع_سطر(ترتيب_اختيار([29، 10، 14، 37، 13]))
# [10, 13, 14, 29, 37]
```

## 5. الترتيب بالدمج (Merge Sort)

خوارزمية "فرّق تسُد" — تقسم ثم تدمج:

```sad
دالة ترتيب_دمج(قائمة)
   إذا (طول(قائمة) <= 1)
      ارجع قائمة
   نهاية

   متغير وسط = طول(قائمة) / 2
   متغير يسار = []
   متغير يمين = []

   متغير ي = 0
   بينما (ي < وسط)
      يسار.أضف(قائمة[ي])
      ي = ي + 1
   نهاية
   بينما (ي < طول(قائمة))
      يمين.أضف(قائمة[ي])
      ي = ي + 1
   نهاية

   ارجع ادمج(ترتيب_دمج(يسار)، ترتيب_دمج(يمين))
نهاية

دالة ادمج(يسار، يمين)
   متغير نتيجة = []
   متغير ي = 0
   متغير ج = 0
   بينما (ي < طول(يسار) و ج < طول(يمين))
      إذا (يسار[ي] <= يمين[ج])
         نتيجة.أضف(يسار[ي])
         ي = ي + 1
      وإلا
         نتيجة.أضف(يمين[ج])
         ج = ج + 1
      نهاية
   نهاية
   بينما (ي < طول(يسار))
      نتيجة.أضف(يسار[ي])
      ي = ي + 1
   نهاية
   بينما (ج < طول(يمين))
      نتيجة.أضف(يمين[ج])
      ج = ج + 1
   نهاية
   ارجع نتيجة
نهاية

اطبع_سطر(ترتيب_دمج([38، 27، 43، 3، 9، 82، 10]))
# [3, 9, 10, 27, 38, 43, 82]
```

## 6. العودية (Recursion)

```sad
# مضروب العدد n!
دالة مضروب(ن)
   إذا (ن <= 1)
      ارجع 1
   نهاية
   ارجع ن * مضروب(ن - 1)
نهاية

اطبع_سطر(مضروب(5))   # 120 = 5×4×3×2×1

# أبراج هانوي
دالة هانوي(ن، من، إلى، وسيط)
   إذا (ن == 1)
      اطبع_سطر("نقل قرص من " + من + " إلى " + إلى)
      ارجع لاشيء
   نهاية
   هانوي(ن - 1، من، وسيط، إلى)
   اطبع_سطر("نقل قرص من " + من + " إلى " + إلى)
   هانوي(ن - 1، وسيط، إلى، من)
نهاية

هانوي(3، "أ"، "ج"، "ب")
```

## مقارنة الخوارزميات

| الخوارزمية | أفضل حالة | أسوأ حالة | مستقر؟ |
|-----------|----------|----------|--------|
| فقاعي | O(n) | O(n²) | نعم |
| اختيار | O(n²) | O(n²) | لا |
| دمج | O(n log n) | O(n log n) | نعم |
| بحث تسلسلي | O(1) | O(n) | — |
| بحث ثنائي | O(1) | O(log n) | — |
