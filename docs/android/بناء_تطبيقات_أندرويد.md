# 📱 بناء تطبيقات أندرويد بلغة ص

## نظرة عامة

يمكنك بناء تطبيقات أندرويد باستخدام **لغة ص فقط** - بدون الحاجة لكتابة أي كود بلغات أخرى مثل Java أو Kotlin.

## كيف تعمل؟

```
مشروعك/
├── التطبيق.ص          # الكود الرئيسي بلغة ص
├── مشروع.صد           # إعدادات المشروع
└── (ملفات .ص أخرى)
        ↓
    sad build-apk مشروعك/
        ↓
    مشروعك.apk         # تطبيق أندرويد جاهز!
```

## هيكل المشروع

```
مشروعي/
├── التطبيق.ص          # نقطة الدخول الرئيسية (مطلوب)
├── مشروع.صد           # إعدادات المشروع (اختياري)
├── الأيقونة.png       # أيقونة التطبيق (اختياري)
└── *.ص                # ملفات مصدر إضافية
```

## ملف الإعدادات (مشروع.صد)

```
# معلومات التطبيق
الاسم = "تطبيقي"
الحزمة = "com.example.myapp"
الإصدار = "1.0.0"

# متطلبات أندرويد
الحد_الأدنى = 24
الهدف = 34

# الملف الرئيسي
الملف_الرئيسي = "التطبيق.ص"
```

## مثال: آلة حاسبة

```sad
# التطبيق.ص
استورد واجهة

متغير العنوان = جديد نص("🧮 الآلة الحاسبة")
متغير حقل١ = جديد حقل_إدخال("الرقم الأول")
متغير حقل٢ = جديد حقل_إدخال("الرقم الثاني")
متغير النتيجة = جديد نص("النتيجة: --")

متغير زر_جمع = جديد زر("➕ جمع")
زر_جمع.عند_الضغط(دالة()
    متغير أ = رقم(حقل١.احصل())
    متغير ب = رقم(حقل٢.احصل())
    النتيجة.غير("النتيجة: " + (أ + ب))
نهاية)
```

## عناصر الواجهة المتاحة

### العناصر الأساسية

| الصنف | الوصف | مثال |
|-------|-------|------|
| `نص` | عرض نص | `جديد نص("مرحباً")` |
| `زر` | زر قابل للضغط | `جديد زر("اضغط هنا")` |
| `حقل_إدخال` | حقل إدخال نص | `جديد حقل_إدخال("أدخل اسمك")` |
| `قائمة` | قائمة عناصر | `جديد قائمة()` |

### التخطيط

| الصنف | الوصف |
|-------|-------|
| `عمود` | ترتيب عمودي |
| `صف` | ترتيب أفقي |

### الرسائل

| الدالة | الوصف |
|--------|-------|
| `أظهر_رسالة(نص)` | رسالة منبثقة قصيرة |
| `أظهر_حوار(عنوان, رسالة, callback)` | مربع حوار |
| `أظهر_تأكيد(عنوان, رسالة, نعم, لا)` | حوار تأكيد |

### التخزين

```sad
متغير التخزين = جديد تخزين()
التخزين.احفظ("المفتاح", "القيمة")
متغير قيمة = التخزين.اقرأ("المفتاح")
التخزين.احذف("المفتاح")
```

## بناء التطبيق

```bash
# بناء APK
sad build-apk مشروعي/

# مع خيارات
sad build-apk مشروعي/ -o تطبيقي.apk -n "تطبيقي الأول"

# عرض المساعدة
sad build-apk --help
```

## الخيارات المتاحة

| الخيار | الوصف |
|--------|-------|
| `-o, --output` | مسار ملف APK الناتج |
| `-n, --name` | اسم التطبيق |
| `-p, --package` | اسم الحزمة |
| `-r, --release` | بناء نسخة Release |
| `-s, --sign` | توقيع APK |
| `-v, --verbose` | عرض تفاصيل البناء |

## المتطلبات

- **لغة ص** (sad) مثبتة
- **Android SDK** (لبناء APK النهائي)
- **Java JDK 17+**

## الأمثلة الجاهزة

```
examples/android/
├── حاسبة/          # آلة حاسبة بسيطة
├── مهام/           # قائمة مهام
└── ...
```

شغّل أي مثال:
```bash
sad build-apk examples/android/حاسبة/
```

## ملاحظات

- جميع الملفات يجب أن تكون بترميز UTF-8
- الواجهة تدعم RTL (من اليمين لليسار) تلقائياً
- يمكن استخدام الأرقام العربية (٠-٩) أو اللاتينية (0-9)

## 🏗️ المعمارية الداخلية — للمطورين

هذا القسم يشرح كيف تعمل سلسلة التحويل من كود لغة ص إلى تطبيق Android أصلي.
الهدف هو تمكين المطورين الراغبين في المساهمة من فهم البنية بشكل كامل.

### مسار التحويل الكامل

```
ملف .ص (واجهة)
    ↓  [المحلل النحوي — shared/parser/]
شجرة AST (عقد UINode)
    ↓  [المحلل الدلالي — تحقق الأمان، التحقق من الأنواع]
AST+Types محقق
    ↓  [android_compose.cpp — تحويل مكونات]
خريطة مكونات Compose (ComponentMapping)
    ↓  [android_compose_codegen.cpp — توليد مشروع كامل]
مشروع Gradle كامل:
├── app/build.gradle.kts
├── app/src/main/AndroidManifest.xml
├── app/src/main/kotlin/*/Screen.kt (لكل شاشة)
├── app/src/main/kotlin/*/MainActivity.kt
├── app/src/main/kotlin/*/Theme.kt
├── app/src/main/kotlin/*/Navigation.kt
└── settings.gradle.kts
    ↓  [./gradlew assembleDebug]
ملف APK جاهز للتثبيت
```

### الملفات المصدرية الأساسية

| الملف | المسار | المسؤولية |
|-------|--------|-----------|
| تحويل المكونات | `compiler_new/src/backend/android_compose.cpp` | تحويل عقد AST إلى Jetpack Compose |
| توليد المشروع | `compiler_new/src/ui/android_compose_codegen.cpp` | إنتاج مشروع Gradle كامل |
| أداة البناء | `tools/apk_builder/src/apk_builder.cpp` | كشف SDK، بناء، توقيع |
| toolchain | `compiler_new/src/backend/llvm_codegen_android.cpp` | كود JNI الأصلي (ARM64/x86_64) |

### خريطة تحويل المكونات

```
عنصر لغة ص          →    مكون Jetpack Compose
───────────────────        ──────────────────────
نص("مرحباً")         →    Text(text = "مرحباً")
زر("اضغط")          →    Button(onClick = {}) { Text("اضغط") }
حقل_إدخال("اسمك")   →    TextField(value = ..., label = { Text("اسمك") })
عمود { ... }         →    Column { ... }
صف { ... }           →    Row { ... }
صورة("مسار")         →    Image(painter = painterResource(...))
```

### إعدادات البناء الافتراضية

```kotlin
// القيم الافتراضية في android_compose_codegen.cpp
minSdk = 24           // Android 7.0 (Nougat)
targetSdk = 34        // Android 14
compileSdk = 34
kotlinVersion = "1.9.22"
composeVersion = "1.5.10"
```

### الأمان

جميع النصوص المولدة تمر عبر `escapeKotlinString()` لمنع حقن الكود.
المتغيرات المستخدمة في Compose تُغلف تلقائياً بـ `remember { mutableStateOf(...) }`
لضمان إدارة الحالة الصحيحة.
