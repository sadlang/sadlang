## نظرة عامة / Overview

وحدة الرياضيات توفر مجموعة شاملة من الدوال الرياضية تشمل: العمليات الأساسية، الدوال المثلثية، الدوال اللوغاريتمية والأسية، الثوابت الرياضية، والأرقام العشوائية. جميع الدوال تدعم الأعداد الصحيحة والعشرية.

The math module provides a comprehensive set of mathematical functions including: basic operations, trigonometric functions, logarithmic and exponential functions, mathematical constants, and random number generation.

### الملفات المصدرية

| الملف | الوصف |
|-------|-------|
| `math_functions.h` | تعريفات 22 دالة رياضية |
| `math_functions.cpp` | التنفيذ |
| `advanced_math.h` | دوال رياضية متقدمة |
| `advanced_math.cpp` | التنفيذ المتقدم |

### فضاء الأسماء

```cpp
Sad::StdLib::Math::MathFunctions
```

## 1. دوال رياضية أساسية (7 دوال)

### `جذر(عدد)` / `sqrt(number)`

حساب الجذر التربيعي.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `جذر` |
| **الاسم الإنجليزي** | `sqrt` |
| **المعاملات** | `عدد` — رقم صحيح أو عشري (≥ 0) |
| **القيمة المُرجعة** | `عشري` (float) |
| **خطأ** | إذا كان العدد سالباً |

```sad
متغير نتيجة = جذر(16)      # 4.0
متغير نتيجة2 = جذر(2)      # 1.41421356...
متغير نتيجة3 = جذر(0)      # 0.0
```

---

### `أس(أساس، قوة)` / `power(base, exponent)`

رفع عدد لأس (قوة) معين.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `أس` |
| **الاسم الإنجليزي** | `power` |
| **المعاملات** | `أساس` + `قوة` (كلاهما رقم) |
| **القيمة المُرجعة** | `رقم` أو `عشري` |

```sad
اطبع_سطر(أس(2، 3))      # 8
اطبع_سطر(أس(2، 10))     # 1024
اطبع_سطر(أس(2.5، 2))    # 6.25
اطبع_سطر(أس(9، 0.5))    # 3.0 (جذر تربيعي)
```

---

### `مطلق(عدد)` / `abs(number)`

القيمة المطلقة — إزالة الإشارة السالبة.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `مطلق` |
| **الاسم الإنجليزي** | `abs` |
| **المعاملات** | `عدد` — رقم صحيح أو عشري |
| **القيمة المُرجعة** | نفس نوع المدخل |

```sad
اطبع_سطر(مطلق(-5))       # 5
اطبع_سطر(مطلق(5))        # 5
اطبع_سطر(مطلق(-3.14))    # 3.14
```

---

### `أكبر(...)` / `max(...)`

إيجاد أكبر قيمة بين مجموعة أرقام.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `أكبر` |
| **الاسم الإنجليزي** | `max` |
| **المعاملات** | `...أرقام` — رقمان أو أكثر |
| **القيمة المُرجعة** | أكبر رقم |

```sad
اطبع_سطر(أكبر(5، 10))           # 10
اطبع_سطر(أكبر(5، 10، 3، 8))    # 10
اطبع_سطر(أكبر(1.5، 2.7، 1.9))  # 2.7
```

---

### `أصغر(...)` / `min(...)`

إيجاد أصغر قيمة.

```sad
اطبع_سطر(أصغر(5، 10))           # 5
اطبع_سطر(أصغر(5، 10، 3، 8))    # 3
اطبع_سطر(أصغر(1.5، 2.7، 1.9))  # 1.5
```

---

### `مربع(عدد)` / `square(number)`

حساب مربع العدد (العدد × العدد).

```sad
اطبع_سطر(مربع(5))      # 25
اطبع_سطر(مربع(2.5))    # 6.25
اطبع_سطر(مربع(-3))     # 9
```

## 2. دوال التقريب (3 دوال)

### `تقريب(عدد)` / `round(number)`

التقريب لأقرب عدد صحيح.

| القاعدة | المثال |
|---------|--------|
| `.5` فأكثر → للأعلى | `تقريب(3.5)` → `4` |
| أقل من `.5` → للأسفل | `تقريب(3.2)` → `3` |
| سالب `.5` → بعيداً عن الصفر | `تقريب(-2.5)` → `-3` |

```sad
اطبع_سطر(تقريب(3.2))    # 3
اطبع_سطر(تقريب(3.7))    # 4
اطبع_سطر(تقريب(3.5))    # 4
اطبع_سطر(تقريب(-2.3))   # -2
اطبع_سطر(تقريب(-2.7))   # -3
```

---

### `أرضية(عدد)` / `floor(number)`

التقريب للأسفل دائماً (نحو سالب اللانهاية).

```sad
اطبع_سطر(أرضية(3.2))    # 3
اطبع_سطر(أرضية(3.9))    # 3
اطبع_سطر(أرضية(-2.1))   # -3
اطبع_سطر(أرضية(-2.9))   # -3
```

---

### `سقف(عدد)` / `ceil(number)`

التقريب للأعلى دائماً (نحو موجب اللانهاية).

```sad
اطبع_سطر(سقف(3.1))     # 4
اطبع_سطر(سقف(3.9))     # 4
اطبع_سطر(سقف(-2.1))    # -2
اطبع_سطر(سقف(-2.9))    # -2
```

## 3. دوال مثلثية (3 + 4 دوال)

### الدوال المثلثية الأساسية

جميع الزوايا بالراديان (radians). لتحويل من درجات: `الزاوية_بالراديان = الزاوية_بالدرجات * ثابت_باي() / 180`

#### `جيب(زاوية)` / `sin(angle)`

حساب جيب الزاوية.

```sad
اطبع_سطر(جيب(0))                    # 0
اطبع_سطر(جيب(ثابت_باي() / 2))      # 1
اطبع_سطر(جيب(ثابت_باي()))          # 0 (تقريباً)
```

---

#### `جيب_تمام(زاوية)` / `cos(angle)`

حساب جيب تمام الزاوية.

```sad
اطبع_سطر(جيب_تمام(0))              # 1
اطبع_سطر(جيب_تمام(ثابت_باي()))    # -1
```

---

#### `ظل(زاوية)` / `tan(angle)`

حساب ظل الزاوية.

```sad
اطبع_سطر(ظل(0))                    # 0
اطبع_سطر(ظل(ثابت_باي() / 4))      # 1 (تقريباً)
```

---

### الدوال المثلثية العكسية

| الدالة العربية | الدالة الإنجليزية | الوصف | المجال | المدى |
|---------------|-----------------|-------|--------|-------|
| — | `asin(x)` | جيب عكسي | [-1, 1] | [-π/2, π/2] |
| — | `acos(x)` | جيب تمام عكسي | [-1, 1] | [0, π] |
| — | `atan(x)` | ظل عكسي | ℝ | (-π/2, π/2) |
| — | `atan2(y, x)` | ظل عكسي ثنائي | ℝ × ℝ | (-π, π] |

```sad
اطبع_سطر(asin(1))       # 1.5708 (π/2)
اطبع_سطر(acos(0))       # 1.5708 (π/2)
اطبع_سطر(atan(1))       # 0.7854 (π/4)
اطبع_سطر(atan2(1، 1))   # 0.7854 (π/4)
```

## 4. دوال لوغاريتمية وأسية (4 دوال)

### `log(عدد)` — اللوغاريتم الطبيعي (ln)

```sad
اطبع_سطر(log(هـ()))          # 1.0
اطبع_سطر(log(1))            # 0.0
اطبع_سطر(log(2.71828))     # 1.0 (تقريباً)
```

---

### `log2(عدد)` — اللوغاريتم الثنائي (أساس 2)

```sad
اطبع_سطر(log2(8))      # 3.0
اطبع_سطر(log2(1024))   # 10.0
اطبع_سطر(log2(1))      # 0.0
```

---

### `log10(عدد)` — اللوغاريتم العشري (أساس 10)

```sad
اطبع_سطر(log10(100))     # 2.0
اطبع_سطر(log10(1000))    # 3.0
اطبع_سطر(log10(1))       # 0.0
```

---

### `exp(عدد)` — الدالة الأسية (e^x)

```sad
اطبع_سطر(exp(0))     # 1.0
اطبع_سطر(exp(1))     # 2.71828 (تقريباً)
اطبع_سطر(exp(2))     # 7.38906 (تقريباً)
```

## 5. ثوابت رياضية (2 ثابت)

### `ثابت_باي()` / `pi()`

ثابت π (باي) = 3.14159265358979323846...

```sad
متغير محيط = 2 * ثابت_باي() * 5    # محيط دائرة نصف قطرها 5
اطبع_سطر("المحيط: " + لنص(محيط))   # ≈ 31.4159
```

---

### `هـ()` / `e()`

عدد أويلر (e) = 2.71828182845904523536...

```sad
اطبع_سطر(هـ())     # 2.71828...
```

## 6. دوال عشوائية (2 دالة)

### `عشوائي()` / `random()`

توليد رقم عشري عشوائي بين 0 و 1.

```sad
متغير ع = عشوائي()   # مثل: 0.738291
اطبع_سطر(ع)
```

---

### `عشوائي_صحيح(أدنى، أقصى)` / `randomInt(min, max)`

توليد رقم صحيح عشوائي ضمن نطاق.

```sad
متغير ع = عشوائي_صحيح(1، 6)   # نرد: 1-6
اطبع_سطر("نتيجة النرد: " + لنص(ع))
```

## 8. مثال شامل — حاسبة هندسية

```sad
# حاسبة هندسية — أشكال هندسية

اطبع_سطر("╔════════════════════════════════╗")
اطبع_سطر("║   الحاسبة الهندسية            ║")
اطبع_سطر("╚════════════════════════════════╝")

# === 1. الدائرة ===
متغير نصف_قطر = 5.0
متغير المحيط = 2 * ثابت_باي() * نصف_قطر
متغير المساحة = ثابت_باي() * مربع(نصف_قطر)
اطبع_سطر("الدائرة (نصف القطر = " + لنص(نصف_قطر) + "):")
اطبع_سطر("  المحيط  = " + لنص(تقريب(المحيط * 100) / 100))
اطبع_سطر("  المساحة = " + لنص(تقريب(المساحة * 100) / 100))

# === 2. المثلث ===
متغير أ = 3.0
متغير ب = 4.0
متغير وتر = جذر(مربع(أ) + مربع(ب))
اطبع_سطر("المثلث القائم (" + لنص(أ) + "، " + لنص(ب) + "):")
اطبع_سطر("  الوتر = " + لنص(وتر))

# === 3. الزوايا ===
متغير زاوية_درجات = 45.0
متغير زاوية_راديان = زاوية_درجات * ثابت_باي() / 180
اطبع_سطر("الزاوية " + لنص(زاوية_درجات) + " درجة:")
اطبع_سطر("  جيب = " + لنص(جيب(زاوية_راديان)))
اطبع_سطر("  جيب تمام = " + لنص(جيب_تمام(زاوية_راديان)))
اطبع_سطر("  ظل = " + لنص(ظل(زاوية_راديان)))

# === 4. النمو الأسي ===
اطبع_سطر("النمو الأسي e^2 = " + لنص(exp(2)))
اطبع_سطر("log₂(1024) = " + لنص(log2(1024)))
```
