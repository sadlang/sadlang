# وثائق API — وحدة الصوت ثلاثي الأبعاد (`audio3d`)
# API Reference — 3D Audio Module

> **الوحدة:** `stdlib/audio3d/`
> **الإصدار:** 1.0.0
> **آخر تحديث:** مارس 2026
> **المسؤولة:** ريم — مهندسة المكتبات والأدوات

---

## نظرة عامة / Overview

وحدة الصوت ثلاثي الأبعاد توفر حسابات الصوت المكاني: التوهين (attenuation)، تأثير دوبلر، HRTF (Head-Related Transfer Function)، والصدى. مفيدة للألعاب والتطبيقات التفاعلية.

### الملفات المصدرية

| الملف | الوصف |
|-------|-------|
| `spatial.ص` | جميع الدوال والبنى لحسابات الصوت المكاني |

## الدوال

### `متجه_صوت_جديد(س, ص, ع)` → `متجه_صوت`
إنشاء متجه صوت جديد.

### `طول_متجه(م)` → `عشري`
حساب طول المتجه: $\sqrt{x^2 + y^2 + z^2}$

### `طبيعي_متجه(م)` → `متجه_صوت`
تطبيع المتجه (طول = 1).

### `فرق_متجه(أ, ب)` → `متجه_صوت`
الفرق بين متجهين.

### `مستمع_افتراضي()` → `مستمع`
إنشاء مستمع في الأصل يواجه المحور Z السالب.

### `مصدر_صوت_جديد(موضع)` → `مصدر_صوت`
إنشاء مصدر صوت جديد في الموضع المحدد.

### `حساب_توهين(مصدر, مسافة)` → `عشري`
حساب مستوى التوهين (0.0 = صامت، 1.0 = أقصى حجم).

### `حساب_اتجاهية(مصدر, اتجاه)` → `عشري`
حساب عامل الاتجاهية لمصدر صوت اتجاهي.

### `حساب_دوبلر(مصدر, مستمع)` → `عشري`
حساب تحول نبرة دوبلر: $f' = f \cdot \frac{v + v_l}{v + v_s}$

### `حساب_HRTF(مستمع, موضع_مصدر)` → `معاملات_HRTF`
حساب معاملات HRTF للصوت المكاني (تأخير + مكسب لكل أذن).

---

### مثال استخدام

```sad
# إنشاء مستمع ومصدر صوت
متغير مستمع = مستمع_افتراضي()
متغير مصدر = مصدر_صوت_جديد(متجه_صوت_جديد(10.0, 0.0, 0.0))

# حساب التوهين
متغير مسافة = طول_متجه(فرق_متجه(مصدر.الموضع, مستمع.الموضع))
متغير توهين = حساب_توهين(مصدر, مسافة)
اطبع("مستوى الصوت: " + توهين)

# حساب دوبلر
متغير نبرة = حساب_دوبلر(مصدر, مستمع)
اطبع("تحول النبرة: " + نبرة)
```

---

> **ملاحظة:** هذه الوحدة تحتاج مكتبة صوت (مثل OpenAL أو SDL_Mixer) للتشغيل الفعلي. الدوال الحسابية مستقلة ويمكن اختبارها بدون عتاد.
