# وثائق API — وحدة نظام الملفات (`filesystem`)
# API Reference — Filesystem Module

> **الوحدة:** `stdlib/filesystem/`
> **الإصدار:** 1.0.0
> **آخر تحديث:** مايو 2026
> **المسؤولة:** ريم — مهندسة المكتبات والأدوات

---

## نظرة عامة / Overview

وحدة نظام الملفات توفر دوال التعامل مع الملفات والمجلدات والمسارات. تدعم القراءة والكتابة ونسخ ونقل وحذف الملفات، وإنشاء وتصفح المجلدات.

The filesystem module provides functions for file and directory operations including read, write, copy, move, delete, and directory traversal.

### الاستيراد

```sad
استورد "filesystem"
# أو
من "filesystem" استورد اقرأ_ملف، اكتب_ملف، ملف_موجود
```

## 1. فحص الوجود

### `ملف_موجود(مسار)` / `file_exists(path)`

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `ملف_موجود` |
| **المعاملات** | `مسار` — نص |
| **القيمة المُرجعة** | `منطقي` — `صحيح` إذا كان الملف موجوداً |

```sad
إذا (ملف_موجود("بيانات.txt"))
    اطبع_سطر("الملف موجود")
وإلا
    اطبع_سطر("الملف غير موجود")
نهاية
```

### `مجلد_موجود(مسار)` / `dir_exists(path)`

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `مجلد_موجود` |
| **المعاملات** | `مسار` — نص |
| **القيمة المُرجعة** | `منطقي` |

```sad
إذا (مجلد_موجود("مخرجات"))
    اطبع_سطر("المجلد موجود")
نهاية
```

## 2. قراءة الملفات

### `اقرأ_ملف(مسار)` / `read_file(path)`

قراءة محتوى ملف نصي بالكامل.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `اقرأ_ملف` |
| **المعاملات** | `مسار` — مسار الملف |
| **القيمة المُرجعة** | `نص` — محتوى الملف |
| **خطأ** | إذا كان الملف غير موجود أو لا يمكن قراءته |

```sad
حاول
    متغير محتوى = اقرأ_ملف("ملاحظات.txt")
    اطبع_سطر(محتوى)
امسك (خ)
    اطبع_سطر("خطأ في القراءة: " + خ)
نهاية
```

### `اقرأ_أسطر(مسار)` / `read_lines(path)`

قراءة ملف وإرجاع الأسطر كمصفوفة.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `اقرأ_أسطر` |
| **المعاملات** | `مسار` — مسار الملف |
| **القيمة المُرجعة** | `مصفوفة[نص]` — أسطر الملف |

```sad
متغير أسطر = اقرأ_أسطر("قائمة.txt")
لكل سطر في أسطر
    اطبع_سطر("→ " + سطر)
نهاية
```

---

## 3. كتابة الملفات

### `اكتب_ملف(مسار، محتوى)` / `write_file(path, content)`

كتابة نص إلى ملف (يُنشئ الملف أو يستبدل المحتوى).

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `اكتب_ملف` |
| **المعاملات** | `مسار` + `محتوى` |
| **القيمة المُرجعة** | `فراغ` |
| **خطأ** | إذا فشلت الكتابة |

```sad
اكتب_ملف("مخرج.txt", "محتوى الملف")
اطبع_سطر("تم الحفظ")
```

### `ألحق_بملف(مسار، محتوى)` / `append_file(path, content)`

إلحاق نص بنهاية ملف موجود.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `ألحق_بملف` |
| **المعاملات** | `مسار` + `محتوى` |

```sad
ألحق_بملف("سجل.txt", "إدخال جديد\n")
```

---

## 4. عمليات الملفات

### `احذف_ملف(مسار)` / `delete_file(path)`

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `احذف_ملف` |
| **المعاملات** | `مسار` — مسار الملف |
| **القيمة المُرجعة** | `منطقي` — `صحيح` إذا نجح الحذف |

```sad
إذا (ملف_موجود("مؤقت.txt"))
    احذف_ملف("مؤقت.txt")
    اطبع_سطر("تم الحذف")
نهاية
```

### `انسخ_ملف(مصدر، هدف)` / `copy_file(source, dest)`

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `انسخ_ملف` |
| **المعاملات** | `مصدر` + `هدف` |
| **القيمة المُرجعة** | `منطقي` |

```sad
انسخ_ملف("أصل.txt", "نسخة.txt")
```

### `انقل_ملف(مصدر، هدف)` / `move_file(source, dest)`

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `انقل_ملف` |
| **المعاملات** | `مصدر` + `هدف` |

```sad
انقل_ملف("مسودة.txt", "نهائي.txt")
```

## 5. عمليات المجلدات

### `أنشئ_مجلد(مسار)` / `create_dir(path)`

| الخاصية | القيمة |
|---------|--------|
| **المعاملات** | `مسار` — اسم المجلد |
| **القيمة المُرجعة** | `منطقي` |

```sad
أنشئ_مجلد("مخرجات/تقارير")
```

### `محتويات_مجلد(مسار)` / `list_dir(path)`

| الخاصية | القيمة |
|---------|--------|
| **المعاملات** | `مسار` — مسار المجلد |
| **القيمة المُرجعة** | `مصفوفة[نص]` — أسماء الملفات والمجلدات |

```sad
متغير ملفات = محتويات_مجلد("مشروعي")
لكل ملف في ملفات
    اطبع_سطر("  " + ملف)
نهاية
```

---

## 6. معلومات المسار

### `اسم_الملف(مسار)` / `file_name(path)`

استخراج اسم الملف من المسار الكامل.

```sad
متغير اسم = اسم_الملف("/مجلد/ملف.txt")
اطبع_سطر(اسم)    # ملف.txt
```

### `امتداد_الملف(مسار)` / `file_extension(path)`

```sad
متغير امتداد = امتداد_الملف("برنامج.ص")
اطبع_سطر(امتداد)    # .ص
```

### `حجم_الملف(مسار)` / `file_size(path)`

```sad
متغير حجم = حجم_الملف("بيانات.csv")
اطبع_سطر("الحجم: " + حجم + " بايت")
```

## 7. مثال تطبيقي: نسخ احتياطي

```sad
من "filesystem" استورد اقرأ_ملف، اكتب_ملف، محتويات_مجلد
من "filesystem" استورد ملف_موجود، أنشئ_مجلد، انسخ_ملف

دالة نسخ_احتياطي(نص مصدر، نص هدف)
    إذا (ليس مجلد_موجود(هدف))
        أنشئ_مجلد(هدف)
    نهاية
    
    متغير ملفات = محتويات_مجلد(مصدر)
    متغير عداد = 0
    
    لكل ملف في ملفات
        حاول
            انسخ_ملف(مصدر + "/" + ملف, هدف + "/" + ملف)
            عداد += 1
        امسك (خ)
            اطبع_سطر("تخطي: " + ملف + " — " + خ)
        نهاية
    نهاية
    
    اطبع_سطر("تم نسخ " + عداد + " ملف من " + طول(ملفات))
نهاية

نسخ_احتياطي("مشروعي", "نسخة_احتياطية")
```
