# وثائق API — وحدة سطح المكتب (`desktop`)
# API Reference — Desktop Module

> **الوحدة:** `stdlib/desktop/`
> **الإصدار:** 1.0.0
> **آخر تحديث:** مايو 2026
> **المسؤولة:** ريم — مهندسة المكتبات والأدوات

---

## نظرة عامة / Overview

وحدة سطح المكتب توفر واجهات برمجة للتعامل مع ميزات نظام التشغيل المكتبي: شريط النظام (System Tray)، الإشعارات (Notifications)، الحافظة (Clipboard)، ومعلومات الشاشة (Display).

The desktop module provides APIs for OS-level desktop features: system tray, notifications, clipboard, and display information.

### الاستيراد

```sad
استورد "desktop"
# أو
من "desktop" استورد الحافظة، الإشعارات
```

---

## 1. شريط النظام (System Tray)

### `شريط_أنشئ(عنوان)` / `tray_create(title)`

إنشاء أيقونة في شريط النظام.

| الخاصية | القيمة |
|---------|--------|
| **المعاملات** | `عنوان` — نص يُعرض كتلميح |
| **القيمة المُرجعة** | `منطقي` — `صحيح` إذا نجح الإنشاء |

```sad
شريط_أنشئ("تطبيقي")
```

### `شريط_أزل()` / `tray_remove()`

إزالة أيقونة شريط النظام.

```sad
شريط_أزل()
```

### `شريط_تلميح(نص)` / `tray_tooltip(text)`

تعيين نص التلميح عند التحويم.

```sad
شريط_تلميح("تطبيقي — يعمل")
```

### `شريط_أشعر(عنوان، رسالة)` / `tray_notify(title, message)`

عرض إشعار بالون من شريط النظام.

```sad
شريط_أشعر("تحديث", "تم تحميل التحديث الجديد")
```

---

## 2. الإشعارات (Notifications)

### `أشعر(عنوان، رسالة)` / `notify_send(title, message)`

إرسال إشعار نظام.

| الخاصية | القيمة |
|---------|--------|
| **المعاملات** | `عنوان` + `رسالة` |
| **القيمة المُرجعة** | `منطقي` |

```sad
أشعر("مهمة مكتملة", "تم تنفيذ جميع الاختبارات بنجاح")
```

---

## 3. الحافظة (Clipboard)

### `حافظة_انسخ(نص)` / `clipboard_copy(text)`

نسخ نص إلى الحافظة.

| الخاصية | القيمة |
|---------|--------|
| **المعاملات** | `نص` — النص المراد نسخه |
| **القيمة المُرجعة** | `منطقي` |

```sad
حافظة_انسخ("مرحبا بالعالم")
اطبع_سطر("تم النسخ")
```

### `حافظة_ألصق()` / `clipboard_paste()`

لصق محتوى الحافظة.

| الخاصية | القيمة |
|---------|--------|
| **القيمة المُرجعة** | `نص` — محتوى الحافظة |

```sad
متغير محتوى = حافظة_ألصق()
اطبع_سطر("المحتوى: " + محتوى)
```

### `حافظة_نص_موجود()` / `clipboard_has_text()`

التحقق من وجود نص في الحافظة.

```sad
إذا (حافظة_نص_موجود())
    اطبع_سطر("الحافظة تحتوي نصاً")
نهاية
```

### `حافظة_امسح()` / `clipboard_clear()`

مسح محتوى الحافظة.

```sad
حافظة_امسح()
```

---

## 4. معلومات الشاشة (Display)

### `شاشة_معلومات()` / `display_info()`

معلومات الشاشة الرئيسية.

| الخاصية | القيمة |
|---------|--------|
| **القيمة المُرجعة** | خريطة: `{عرض، ارتفاع، dpi}` |

```sad
متغير شاشة = شاشة_معلومات()
اطبع_سطر("الدقة: " + شاشة["عرض"] + "×" + شاشة["ارتفاع"])
اطبع_سطر("DPI: " + شاشة["dpi"])
```

### `عدد_الشاشات()` / `display_count()`

عدد الشاشات المتصلة.

```sad
اطبع_سطر("عدد الشاشات: " + عدد_الشاشات())
```

## 5. مثال تطبيقي: أداة إنتاجية

```sad
من "desktop" استورد شريط_أنشئ، شريط_أشعر، حافظة_انسخ

# إنشاء تطبيق في شريط النظام
شريط_أنشئ("أداة الإنتاجية")

# نسخ نتيجة للحافظة وإشعار المستخدم
دالة انسخ_وأشعر(نص محتوى)
    حافظة_انسخ(محتوى)
    شريط_أشعر("تم النسخ", "تم نسخ النتيجة للحافظة")
نهاية

انسخ_وأشعر("نتيجة الحساب: 42")
```
