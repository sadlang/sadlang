## 1. core - النواة

الوحدة الأساسية المُحمّلة تلقائياً.

### الدوال

#### `اطبع(قيمة)` / `print(value)`
طباعة قيمة بدون سطر جديد.

```sad
اطبع("مرحباً ")
اطبع("عالم")
# الناتج: مرحباً عالم
```

#### `اطبع_سطر(قيمة)` / `println(value)`
طباعة قيمة مع سطر جديد.

```sad
اطبع_سطر("السلام عليكم")
```

#### `اقرأ()` / `input()`
قراءة سطر من المدخلات.

```sad
متغير الاسم = اقرأ()
```

#### `اقرأ_رقم()` / `input_number()`
قراءة رقم من المدخلات.

```sad
متغير العمر = اقرأ_رقم()
```

#### `نوع(قيمة)` / `type(value)`
إرجاع نوع القيمة كنص.

```sad
نوع(42)        # "رقم"
نوع("نص")      # "نص"
نوع([1,2,3])   # "مصفوفة"
```

#### `طول(قيمة)` / `len(value)`
إرجاع طول النص أو المصفوفة.

```sad
طول("مرحبا")   # 5
طول([1,2,3])   # 3
```

## 2. io - الإدخال والإخراج

```sad
استورد "io"
```

### الدوال

#### `io.اقرأ_ملف(مسار)` / `io.read_file(path)`
قراءة محتوى ملف كاملاً.

```sad
متغير محتوى = io.اقرأ_ملف("بيانات.txt")
```

#### `io.اكتب_ملف(مسار، محتوى)` / `io.write_file(path, content)`
كتابة محتوى إلى ملف.

```sad
io.اكتب_ملف("ناتج.txt"، "مرحباً")
```

#### `io.أضف_لملف(مسار، محتوى)` / `io.append_file(path, content)`
إضافة محتوى لنهاية ملف.

#### `io.موجود(مسار)` / `io.exists(path)`
التحقق من وجود ملف أو مجلد.

#### `io.احذف(مسار)` / `io.delete(path)`
حذف ملف أو مجلد.

#### `io.أنشئ_مجلد(مسار)` / `io.mkdir(path)`
إنشاء مجلد.

#### `io.قائمة_الملفات(مسار)` / `io.list_files(path)`
قائمة محتويات مجلد.

## 3. math - الرياضيات

```sad
استورد "math"
```

| الثابت | القيمة | الوصف |

#### `math.ظا(زاوية)` / `math.tan(angle)`
ظل الزاوية.

#### `math.مطلق(س)` / `math.abs(x)`
القيمة المطلقة.

#### `math.أدنى(أ، ب)` / `math.min(a, b)`
الحد الأدنى.

#### `math.أقصى(أ، ب)` / `math.max(a, b)`
الحد الأقصى.

#### `math.تقريب(س)` / `math.round(x)`
تقريب لأقرب عدد صحيح.

#### `math.أرضية(س)` / `math.floor(x)`
تقريب للأسفل.

#### `math.سقف(س)` / `math.ceil(x)`
تقريب للأعلى.

#### `math.لو(س)` / `math.log(x)`
اللوغاريتم الطبيعي.

#### `math.لو10(س)` / `math.log10(x)`
لوغاريتم أساس 10.

تحويل لأحرف كبيرة.

#### `string.سفلي(نص)` / `string.lower(text)`
تحويل لأحرف صغيرة.

#### `string.يحتوي(نص، جزء)` / `string.contains(text, part)`
التحقق من احتواء نص.

#### `string.يبدأ_ب(نص، بداية)` / `string.starts_with(text, prefix)`
التحقق من البداية.

#### `string.ينتهي_ب(نص، نهاية)` / `string.ends_with(text, suffix)`
التحقق من النهاية.

#### `string.استبدل(نص، قديم، جديد)` / `string.replace(text, old, new)`

#### `string.اربط(مصفوفة، فاصل)` / `string.join(array, separator)`
ربط مصفوفة إلى نص.

#### `string.موضع(نص، جزء)` / `string.index_of(text, part)`
موضع أول ظهور.

#### `string.قطع(نص، من، إلى)` / `string.substring(text, from, to)`
