# وثائق API — وحدة النصوص (`string`)
# API Reference — String Module

> **الوحدة:** `stdlib/string/`
> **الإصدار:** 1.0.0
> **آخر تحديث:** مارس 2026
> **المسؤولة:** ريم — مهندسة المكتبات والأدوات

---

## نظرة عامة / Overview

وحدة النصوص توفر 12 دالة شاملة لمعالجة النصوص مع دعم كامل لـ Unicode والعربية. تدعم البحث والاستبدال والتقسيم والدمج وفحص البداية/النهاية والاحتواء، وغيرها.

The string module provides 12 comprehensive text processing functions with full Unicode and Arabic support. Includes search, replace, split, join, prefix/suffix checking, containment, and more.

### الملفات المصدرية

| الملف | الوصف |
|-------|-------|
| `string_functions.h` | تعريفات 12 دالة نصية |
| `string_functions.cpp` | التنفيذ مع دعم UTF-8 |

### فضاء الأسماء

```cpp
Sad::StdLib::String::StringFunctions
```

### خصائص الوحدة

- **Unicode-aware**: جميع الدوال تتعامل مع UTF-8 بشكل صحيح
- **RTL Support**: النصوص العربية وثنائية الاتجاه مدعومة
- **الأطوال بالأحرف**: `طول("مرحبا")` = 5 (أحرف)، وليس 10 (بايتات)
- **Edge-case safe**: فحص حدود وحالات خاصة

## الدوال (12 دالة)

### 1. `طول(نص)` / `length(text)`

الحصول على طول النص **بالأحرف** (وليس بالبايتات).

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `طول` |
| **الاسم الإنجليزي** | `length` |
| **المعاملات** | `نص` (string) |
| **القيمة المُرجعة** | `رقم` (integer) — عدد الأحرف |
| **ملاحظة** | يحسب الأحرف Unicode وليس البايتات |

```sad
اطبع_سطر(طول("مرحبا"))        # 5 (5 أحرف عربية)
اطبع_سطر(طول("Hello"))       # 5
اطبع_سطر(طول(""))            # 0
اطبع_سطر(طول("مرحبا Hello")) # 11
```

> **هام:** الحرف العربي "م" يُخزّن كـ 2 بايتات في UTF-8، لكن `طول` يحسب أحرفاً وليس بايتات.

---

### 2. `بحث(نص، نص_فرعي، بداية؟)` / `find(text, substring, start?)`

البحث عن موقع نص فرعي داخل النص.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `بحث` |
| **الاسم الإنجليزي** | `find` |
| **المعاملات** | `نص` + `نص_فرعي` + `بداية` (اختياري، افتراضي 0) |
| **القيمة المُرجعة** | `رقم` — موقع أول ظهور، أو `-1` إذا لم يُعثر عليه |

```sad
اطبع_سطر(بحث("مرحبا بالعالم"، "العالم"))    # 7
اطبع_سطر(بحث("مرحبا"، "وداعا"))             # -1
اطبع_سطر(بحث("AABAA"، "A"، 2))             # 3

# البحث عن كل المواقع
متغير نص = "أحمد وسعيد وريم"
متغير موقع = بحث(نص، "و")
اطبع_سطر("أول ظهور لـ 'و': " + لنص(موقع))
```

---

### 3. `استبدل(نص، قديم، جديد، عدد؟)` / `replace(text, old, new, count?)`

استبدال كل ظهورات (أو عدد محدد) من نص فرعي بآخر.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `استبدل` |
| **الاسم الإنجليزي** | `replace` |
| **المعاملات** | `نص` + `قديم` + `جديد` + `عدد` (اختياري، -1 = الكل) |
| **القيمة المُرجعة** | `نص` — النص بعد الاستبدال |

```sad
# استبدال الكل
اطبع_سطر(استبدل("مرحبا مرحبا"، "مرحبا"، "أهلا"))
# الناتج: أهلا أهلا

# استبدال أول ظهور فقط
اطبع_سطر(استبدل("مرحبا مرحبا"، "مرحبا"، "أهلا"، 1))
# الناتج: أهلا مرحبا

# استبدال حروف
اطبع_سطر(استبدل("Hello World"، "o"، "0"))
# الناتج: Hell0 W0rld
```

---

### 4. `استخراج(نص، بداية، طول؟)` / `substring(text, start, length?)`

استخراج جزء من النص.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `استخراج` |
| **الاسم الإنجليزي** | `substring` |
| **المعاملات** | `نص` + `بداية` (من 0) + `طول` (اختياري، حتى النهاية) |
| **القيمة المُرجعة** | `نص` — الجزء المُستخرج |
| **ملاحظة** | يدعم UTF-8 بشكل صحيح |

```sad
اطبع_سطر(استخراج("مرحبا بالعالم"، 0، 5))    # "مرحبا"
اطبع_سطر(استخراج("مرحبا بالعالم"، 7))        # "بالعالم" (حتى النهاية)
اطبع_سطر(استخراج("Hello World"، 0، 5))      # "Hello"
اطبع_سطر(استخراج("مرحبا"، 1، 3))            # "رحب"
```

---

### 5. `تحويل_صغير(نص)` / `toLower(text)`

تحويل الأحرف الإنجليزية إلى أحرف صغيرة. النص العربي لا يتغير.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `تحويل_صغير` |
| **الاسم الإنجليزي** | `toLower` |
| **المعاملات** | `نص` |
| **القيمة المُرجعة** | `نص` بأحرف صغيرة |

```sad
اطبع_سطر(تحويل_صغير("HELLO World"))    # "hello world"
اطبع_سطر(تحويل_صغير("مرحبا"))          # "مرحبا" (لا تغيير)
اطبع_سطر(تحويل_صغير("API"))            # "api"
```

---

### 6. `تحويل_كبير(نص)` / `toUpper(text)`

تحويل الأحرف الإنجليزية إلى أحرف كبيرة. النص العربي لا يتغير.

```sad
اطبع_سطر(تحويل_كبير("hello World"))    # "HELLO WORLD"
اطبع_سطر(تحويل_كبير("مرحبا"))          # "مرحبا" (لا تغيير)
اطبع_سطر(تحويل_كبير("api"))            # "API"
```

---

### 7. `قص_أطراف(نص)` / `trim(text)`

إزالة المسافات والأحرف البيضاء من بداية ونهاية النص.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `قص_أطراف` |
| **الاسم الإنجليزي** | `trim` |
| **يزيل** | مسافات، tabs (`\t`)، أسطر جديدة (`\n`, `\r`) |

```sad
اطبع_سطر(قص_أطراف("  مرحبا  "))          # "مرحبا"
اطبع_سطر(قص_أطراف("\n\tمرحبا\t\n"))      # "مرحبا"
اطبع_سطر(قص_أطراف("   Hello World   "))  # "Hello World"
اطبع_سطر(قص_أطراف("مرحبا"))              # "مرحبا" (لا تغيير)
```

---

### 8. `تقسيم(نص، فاصل، حد؟)` / `split(text, delimiter, limit?)`

تقسيم النص إلى مصفوفة نصوص باستخدام فاصل.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `تقسيم` |
| **الاسم الإنجليزي** | `split` |
| **المعاملات** | `نص` + `فاصل` + `حد` (اختياري، -1 = لا حد) |
| **القيمة المُرجعة** | `مصفوفة` من النصوص |

```sad
# تقسيم بفاصلة
متغير أسماء = تقسيم("أحمد،سعيد،ريم"، "،")
اطبع_سطر(أسماء)    # ["أحمد", "سعيد", "ريم"]

# تقسيم بمسافة
متغير كلمات = تقسيم("مرحبا بالعالم العربي"، " ")
اطبع_سطر(كلمات)    # ["مرحبا", "بالعالم", "العربي"]

# تقسيم مع حد
متغير أجزاء = تقسيم("أ-ب-ج-د"، "-"، 2)
اطبع_سطر(أجزاء)    # ["أ", "ب", "ج-د"]

# تقسيم CSV
متغير بيانات = تقسيم("أحمد,25,مبرمج"، ",")
اطبع_سطر(بيانات[0])   # "أحمد"
اطبع_سطر(بيانات[1])   # "25"
اطبع_سطر(بيانات[2])   # "مبرمج"
```

---

### 9. `دمج(مصفوفة، فاصل؟)` / `join(array, separator?)`

دمج عناصر مصفوفة في نص واحد مع فاصل بينها.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `دمج` |
| **الاسم الإنجليزي** | `join` |
| **المعاملات** | `مصفوفة` + `فاصل` (اختياري، افتراضي `""`) |
| **القيمة المُرجعة** | `نص` |

```sad
# دمج بفاصلة
اطبع_سطر(دمج(["أحمد"، "سعيد"، "ريم"]، "، "))
# الناتج: أحمد، سعيد، ريم

# دمج بدون فاصل
اطبع_سطر(دمج(["أ"، "ب"، "ج"]))
# الناتج: أبج

# دمج مع شرطة
اطبع_سطر(دمج(["2026"، "03"، "06"]، "-"))
# الناتج: 2026-03-06

# تقسيم ثم دمج (تنظيف)
متغير جملة = "  كلمة1  كلمة2  كلمة3  "
متغير نظيف = دمج(تقسيم(قص_أطراف(جملة)، "  ")، " ")
اطبع_سطر(نظيف)   # "كلمة1 كلمة2 كلمة3"
```

### 10. `يبدأ_ب(نص، بادئة)` / `startsWith(text, prefix)`

التحقق هل النص يبدأ ببادئة معينة.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `يبدأ_ب` |
| **الاسم الإنجليزي** | `startsWith` |
| **المعاملات** | `نص` + `بادئة` |
| **القيمة المُرجعة** | `منطقي` (`صحيح` أو `خطأ`) |

```sad
اطبع_سطر(يبدأ_ب("مرحبا بالعالم"، "مرحبا"))    # صحيح
اطبع_سطر(يبدأ_ب("مرحبا"، "أهلا"))              # خطأ
اطبع_سطر(يبدأ_ب("Hello"، "He"))               # صحيح
اطبع_سطر(يبدأ_ب(""، ""))                       # صحيح (نص فارغ يبدأ بنص فارغ)

# استخدام عملي
متغير ملف = "صورة.png"
إذا (يبدأ_ب(ملف، "صورة"))
    اطبع_سطر("هذا ملف صورة")
نهاية
```

### 11. `ينتهي_ب(نص، لاحقة)` / `endsWith(text, suffix)`

التحقق هل النص ينتهي بلاحقة معينة.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `ينتهي_ب` |
| **الاسم الإنجليزي** | `endsWith` |
| **المعاملات** | `نص` + `لاحقة` |
| **القيمة المُرجعة** | `منطقي` |

```sad
اطبع_سطر(ينتهي_ب("تقرير.pdf"، ".pdf"))       # صحيح
اطبع_سطر(ينتهي_ب("مرحبا"، "ا"))              # صحيح
اطبع_سطر(ينتهي_ب("Hello World"، "World"))   # صحيح
اطبع_سطر(ينتهي_ب("Hello"، "World"))         # خطأ

# استخدام عملي — فحص امتداد الملف
متغير اسم_الملف = "مستند.ص"
إذا (ينتهي_ب(اسم_الملف، ".ص"))
    اطبع_سطر("ملف لغة ص!")
نهاية
```

### 12. `يحتوي_على(نص، نص_فرعي)` / `contains(text, substring)`

التحقق هل النص يحتوي على نص فرعي.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `يحتوي_على` |
| **الاسم الإنجليزي** | `contains` |
| **المعاملات** | `نص` + `نص_فرعي` |
| **القيمة المُرجعة** | `منطقي` |

```sad
اطبع_سطر(يحتوي_على("مرحبا بالعالم"، "العالم"))    # صحيح
اطبع_سطر(يحتوي_على("مرحبا"، "أهلا"))              # خطأ
اطبع_سطر(يحتوي_على("Hello World"، "lo W"))       # صحيح

# استخدام عملي — فلترة
متغير كلمات = ["لغة ص"، "لغة Python"، "لغة Rust"، "ص البرمجية"]
لكل كلمة في كلمات
    إذا (يحتوي_على(كلمة، "ص"))
        اطبع_سطر("وجدت: " + كلمة)
    نهاية
نهاية
# الناتج:
# وجدت: لغة ص
# وجدت: ص البرمجية
```

## جدول مرجعي سريع

| الدالة العربية | الإنجليزية | المعاملات | المخرج | مثال |
|---------------|-----------|----------|--------|------|
| `طول(ن)` | `length(s)` | نص | رقم | `طول("مرحبا")` → `5` |
| `بحث(ن، ف)` | `find(s, sub)` | نص + فرعي | رقم/‒1 | `بحث("أبجد"، "ب")` → `1` |
| `استبدل(ن، ق، ج)` | `replace(s, o, n)` | نص + قديم + جديد | نص | `استبدل("أأ"، "أ"، "ب")` → `"بب"` |
| `استخراج(ن، ب، ط)` | `substring(s, i, l)` | نص + بداية + طول | نص | `استخراج("مرحبا"، 0، 2)` → `"مر"` |
| `تحويل_صغير(ن)` | `toLower(s)` | نص | نص | `تحويل_صغير("ABC")` → `"abc"` |
| `تحويل_كبير(ن)` | `toUpper(s)` | نص | نص | `تحويل_كبير("abc")` → `"ABC"` |
| `قص_أطراف(ن)` | `trim(s)` | نص | نص | `قص_أطراف("  أ  ")` → `"أ"` |
| `تقسيم(ن، ف)` | `split(s, d)` | نص + فاصل | مصفوفة | `تقسيم("أ,ب"، ",")` → `["أ","ب"]` |
| `دمج(م، ف)` | `join(a, s)` | مصفوفة + فاصل | نص | `دمج(["أ","ب"]، "-")` → `"أ-ب"` |
| `يبدأ_ب(ن، ب)` | `startsWith(s, p)` | نص + بادئة | منطقي | `يبدأ_ب("مرحبا"، "م")` → `صحيح` |
| `ينتهي_ب(ن، ل)` | `endsWith(s, x)` | نص + لاحقة | منطقي | `ينتهي_ب("مرحبا"، "ا")` → `صحيح` |
| `يحتوي_على(ن، ف)` | `contains(s, sub)` | نص + فرعي | منطقي | `يحتوي_على("أبج"، "ب")` → `صحيح` |

## مثال شامل — معالج نصوص

```sad
# معالج نصوص بسيط بلغة ص

اطبع_سطر("═══════════════════════════════")
اطبع_سطر("   معالج النصوص — لغة ص       ")
اطبع_سطر("═══════════════════════════════")

متغير جملة = "  بسم الله الرحمن الرحيم  "

# 1. تنظيف
متغير نظيف = قص_أطراف(جملة)
اطبع_سطر("بعد التنظيف: '" + نظيف + "'")

# 2. معلومات
اطبع_سطر("الطول: " + لنص(طول(نظيف)) + " حرف")

# 3. تقسيم لكلمات
متغير كلمات = تقسيم(نظيف، " ")
اطبع_سطر("عدد الكلمات: " + لنص(الطول(كلمات)))

# 4. البحث
متغير موقع = بحث(نظيف، "الرحمن")
إذا (موقع != -1)
    اطبع_سطر("كلمة 'الرحمن' في الموقع: " + لنص(موقع))
نهاية

# 5. الاستبدال
متغير معدّل = استبدل(نظيف، "الرحمن"، "الرحمٰن")
اطبع_سطر("بعد الاستبدال: " + معدّل)

# 6. فحص البداية والنهاية
اطبع_سطر("يبدأ بـ 'بسم': " + لنص(يبدأ_ب(نظيف، "بسم")))
اطبع_سطر("ينتهي بـ 'الرحيم': " + لنص(ينتهي_ب(نظيف، "الرحيم")))

# 7. إعادة الدمج
متغير مُدمج = دمج(كلمات، " - ")
اطبع_سطر("مدموج بشرطات: " + مُدمج)

# 8. استخراج
اطبع_سطر("أول 3 أحرف: " + استخراج(نظيف، 0، 3))
```

## ملاحظات مهمة

### دعم Unicode

جميع الدوال تتعامل بشكل صحيح مع:
- **النصوص العربية** — الأحرف متعددة البايتات
- **النصوص المختلطة** — عربي + إنجليزي + أرقام
- **الأحرف الخاصة** — التشكيل، الهمزات، الأحرف الممدودة

### حالات حدية (Edge Cases)

| الحالة | السلوك |
|--------|--------|
| نص فارغ `""` | `طول("")` = 0, `تقسيم("")` = `[""]` |
| فاصل غير موجود | `تقسيم("أبج"، ",")` = `["أبج"]` |
| موقع خارج النطاق | `استخراج("أب"، 5)` = `""` |
| بحث عن نص فارغ | `بحث("أبج"، "")` = `0` |
| استبدال بنص فارغ | `استبدل("أبأ"، "أ"، "")` = `"ب"` |
