## نظرة عامة / Overview

وحدة JSON توفر عمليات التحليل (`parse`) والتحويل إلى نص (`stringify`) والطباعة المنسقة. تدعم JSON القياسي (RFC 8259) مع إضافات اختيارية كالتعليقات والفواصل الزائدة.

The JSON module provides parse, stringify, and pretty-print operations. It supports standard JSON (RFC 8259) with optional extensions like comments and trailing commas.

### الملفات المصدرية

| الملف | الوصف |
|-------|-------|
| `json_parser.h/.cpp` | محلل JSON |
| `json_stringify.h/.cpp` | تحويل القيم إلى نصوص JSON |

### الاستيراد

```sad
استورد "json"
# أو
من "json" استورد حلل_json، حول_لـjson
```

## 1. الدوال الأساسية

### `حلل_json(نص)` / `json_parse(text)`

تحليل نص JSON وتحويله إلى قيمة في لغة ص.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `حلل_json` |
| **الاسم الإنجليزي** | `json_parse` |
| **المعاملات** | `نص` — نص JSON صالح |
| **القيمة المُرجعة** | `أي` — القيمة المُحللة (خريطة، مصفوفة، نص، رقم، منطقي، لاشيء) |
| **خطأ** | إذا كان النص JSON غير صالح |

```sad
# تحليل كائن JSON
متغير بيانات = حلل_json('{"الاسم": "أحمد", "العمر": 30}')
اطبع_سطر(بيانات["الاسم"])    # أحمد
اطبع_سطر(بيانات["العمر"])    # 30

# تحليل مصفوفة JSON
متغير أرقام = حلل_json('[1, 2, 3, 4, 5]')
اطبع_سطر(أرقام[0])           # 1
```

---

### `حول_لـjson(قيمة)` / `json_stringify(value)`

تحويل قيمة في لغة ص إلى نص JSON.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `حول_لـjson` |
| **الاسم الإنجليزي** | `json_stringify` |
| **المعاملات** | `قيمة` — أي قيمة قابلة للتحويل |
| **القيمة المُرجعة** | `نص` — نص JSON |

```sad
متغير خريطة = {"اسم": "سارة", "عمر": 25}
متغير json = حول_لـjson(خريطة)
اطبع_سطر(json)
# {"اسم":"سارة","عمر":25}

متغير قائمة = [1, "نص", صحيح, لاشيء]
اطبع_سطر(حول_لـjson(قائمة))
# [1,"نص",true,null]
```

---

### `json_منسق(قيمة، مسافة)` / `json_pretty(value, indent)`

تحويل قيمة إلى نص JSON منسق مع مسافات بادئة.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `json_منسق` |
| **الاسم الإنجليزي** | `json_pretty` |
| **المعاملات** | `قيمة` + `مسافة` (اختياري، الافتراضي 2) |
| **القيمة المُرجعة** | `نص` — JSON منسق |

```sad
متغير بيانات = {"اسم": "خالد", "هوايات": ["قراءة", "برمجة"]}
اطبع_سطر(json_منسق(بيانات, 4))
```

**المخرج:**
```json
{
    "اسم": "خالد",
    "هوايات": [
        "قراءة",
        "برمجة"
    ]
}
```

---

### `json_مصغر(قيمة)` / `json_minify(value)`

تحويل إلى JSON مضغوط بدون مسافات زائدة.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `json_مصغر` |
| **المعاملات** | `قيمة` — أي قيمة |
| **القيمة المُرجعة** | `نص` — JSON مضغوط |

```sad
متغير ب = {"أ": 1, "ب": [2, 3]}
اطبع_سطر(json_مصغر(ب))
# {"أ":1,"ب":[2,3]}
```

## 2. خيارات التحليل

يمكن تمرير خيارات إضافية عند التحليل:

| الخيار | النوع | الافتراضي | الوصف |
|--------|-------|-----------|-------|
| `allow_comments` | منطقي | خطأ | السماح بتعليقات `//` و `/* */` |
| `allow_trailing_commas` | منطقي | خطأ | السماح بفاصلة بعد آخر عنصر |
| `strict_mode` | منطقي | صحيح | رفض JSON غير قياسي |

```sad
# تحليل JSON مع تعليقات
متغير نص = '{
    // تعليق
    "اسم": "أحمد",
    "عمر": 30,  /* ملاحظة */
}'
متغير بيانات = حلل_json(نص, {"allow_comments": صحيح})
```
