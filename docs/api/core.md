# وثائق API — وحدة النواة (`core`)
# API Reference — Core Module

> **الوحدة:** `stdlib/core/`
> **الإصدار:** 1.0.0
> **آخر تحديث:** مارس 2026
> **المسؤولة:** ريم — مهندسة المكتبات والأدوات

---

## نظرة عامة / Overview

وحدة النواة هي الأساس الذي تُبنى عليه لغة ص. تحتوي على الدوال المدمجة (builtins) التي تتوفر تلقائياً في كل برنامج بدون استيراد، بالإضافة إلى دوال المصفوفات ودوال الأنواع/التحويلات والدوال المساعدة.

The core module is the foundation of the Sad Language. It contains built-in functions automatically available in every program without importing, plus array functions, type/conversion functions, and utility functions.

### الملفات المصدرية / Source Files

| الملف | الوصف |
|-------|-------|
| `builtins.h/.cpp` | الدوال المدمجة الأساسية — I/O + مصفوفات + نصوص + رياضيات + أنواع |
| `array_functions.h/.cpp` | 10 دوال لمعالجة المصفوفات |
| `type_functions.h/.cpp` | 10 دوال لفحص وتحويل الأنواع |
| `other_functions.h/.cpp` | 5 دوال مساعدة — إدخال، عشوائي، انتظار، خروج، تأكد |
| `stdlib_manager.h/.cpp` | مدير تسجيل الدوال في المفسر |

### فضاءات الأسماء / Namespaces

```cpp
Sad::StdLib::BuiltinFunctions   // الدوال المدمجة
Sad::StdLib::Core::ArrayFunctions   // دوال المصفوفات
Sad::StdLib::Core::TypeFunctions    // دوال الأنواع
Sad::StdLib::Core::OtherFunctions   // دوال مساعدة (input, random, sleep, exit, assert)
```

## 1. الدوال المدمجة (Builtins)

هذه الدوال متوفرة مباشرة في أي برنامج بلغة ص بدون الحاجة لاستيراد.

### 1.1 دوال الإدخال والإخراج

#### `اطبع(...)` / `print(...)`

طباعة قيمة أو أكثر بدون سطر جديد في النهاية.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `اطبع` |
| **الاسم الإنجليزي** | `print` |
| **المعاملات** | `...قيم` — قيمة واحدة أو أكثر من أي نوع |
| **القيمة المُرجعة** | `فراغ` (void) |
| **المعاملات الاختيارية** | لا |

```sad
اطبع("مرحبا")           # الناتج: مرحبا
اطبع(42)               # الناتج: 42
اطبع("العدد: "، 100)   # الناتج: العدد:  100
```

---

#### `اطبع_سطر(...)` / `println(...)`

طباعة قيمة أو أكثر مع إضافة سطر جديد تلقائياً.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `اطبع_سطر` |
| **الاسم الإنجليزي** | `println` |
| **المعاملات** | `...قيم` — قيمة واحدة أو أكثر |
| **القيمة المُرجعة** | `فراغ` (void) |

```sad
اطبع_سطر("السطر الأول")
اطبع_سطر("السطر الثاني")
# الناتج:
# السطر الأول
# السطر الثاني
```

---

#### `أدخل(رسالة؟)` / `input(prompt?)`

قراءة سطر نصي من المستخدم عبر stdin.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `أدخل` |
| **الاسم الإنجليزي** | `input` |
| **المعاملات** | `رسالة` (اختياري) — رسالة تُعرض قبل القراءة |
| **القيمة المُرجعة** | `نص` (string) — النص المُدخل |

```sad
متغير الاسم = أدخل("ما اسمك؟ ")
اطبع_سطر("مرحباً " + الاسم)
```

---

#### `قراءة_سطر(رسالة؟)` / `readLine(prompt?)`

قراءة سطر كامل من الإدخال — شبيهة بـ `أدخل` مع تصميم مخصص لقراءة الأسطر.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `قراءة_سطر` |
| **الاسم الإنجليزي** | `readLine` |
| **المعاملات** | `رسالة` (اختياري) |
| **القيمة المُرجعة** | `نص` (string) |

```sad
متغير السطر = قراءة_سطر("أدخل جملة: ")
اطبع_سطر("قلت: " + السطر)
```

---

#### `مسح_الشاشة()` / `clear()`

مسح شاشة الطرفية ووضع المؤشر في الزاوية العلوية اليسرى.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `مسح_الشاشة` |
| **الاسم الإنجليزي** | `clear` |
| **المعاملات** | لا شيء |
| **القيمة المُرجعة** | `فراغ` (void) |

```sad
مسح_الشاشة()
اطبع_سطر("شاشة نظيفة!")
```

### 1.2 دوال المصفوفات والنصوص المدمجة

#### `الطول(قيمة)` / `length(value)`

الحصول على طول مصفوفة أو نص.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `الطول` |
| **الاسم الإنجليزي** | `length` |
| **المعاملات** | `قيمة` — مصفوفة أو نص |
| **القيمة المُرجعة** | `رقم` (integer) — عدد العناصر أو الأحرف |

```sad
متغير م = [1، 2، 3، 4، 5]
اطبع_سطر(الطول(م))       # الناتج: 5

متغير ن = "مرحبا"
اطبع_سطر(الطول(ن))       # الناتج: 5
```

---

#### `أضف(مصفوفة، عنصر)` / `append(array, element)`

إضافة عنصر إلى نهاية المصفوفة.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `أضف` |
| **الاسم الإنجليزي** | `append` |
| **المعاملات** | `مصفوفة` + `عنصر` من أي نوع |
| **القيمة المُرجعة** | `مصفوفة` — المصفوفة الجديدة بعد الإضافة |

```sad
متغير م = [1، 2، 3]
م = أضف(م، 4)
اطبع_سطر(م)   # الناتج: [1, 2, 3, 4]
```

---

#### `أزل(مصفوفة)` / `remove(array)`

إزالة عنصر من المصفوفة.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `أزل` |
| **الاسم الإنجليزي** | `remove` |
| **المعاملات** | `مصفوفة` |
| **القيمة المُرجعة** | المصفوفة بعد الإزالة |

```sad
متغير م = [1، 2، 3]
أزل(م)
اطبع_سطر(م)   # الناتج: [1, 2]
```

### 1.3 دوال النصوص المدمجة

#### `طول_النص(نص)` / `str_len(text)`

الحصول على طول نص مع دعم Unicode.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `طول_النص` |
| **الاسم الإنجليزي** | `str_len` |
| **المعاملات** | `نص` (string) |
| **القيمة المُرجعة** | `رقم` — عدد الأحرف (ليس البايتات) |

```sad
اطبع_سطر(طول_النص("مرحبا"))    # الناتج: 5
اطبع_سطر(طول_النص("Hello"))    # الناتج: 5
```

---

#### `كبير(نص)` / `upper(text)`

تحويل النص إلى أحرف كبيرة (للأحرف الإنجليزية).

```sad
اطبع_سطر(كبير("hello"))    # الناتج: HELLO
```

---

#### `صغير(نص)` / `lower(text)`

تحويل النص إلى أحرف صغيرة.

```sad
اطبع_سطر(صغير("HELLO"))    # الناتج: hello
```

---

#### `قسّم(نص، فاصل)` / `split(text, delimiter)`

تقسيم النص إلى مصفوفة باستخدام فاصل.

```sad
متغير أجزاء = قسّم("أحمد،سعيد،ريم"، "،")
اطبع_سطر(أجزاء)   # الناتج: ["أحمد", "سعيد", "ريم"]
```

---

#### `ادمج(مصفوفة، فاصل)` / `join(array, separator)`

دمج عناصر مصفوفة في نص واحد.

```sad
متغير أسماء = ["أحمد"، "سعيد"، "ريم"]
اطبع_سطر(ادمج(أسماء، " و "))   # الناتج: أحمد و سعيد و ريم
```

### 1.5 دوال النوع والتحويل المدمجة

#### `نوع_القيمة(قيمة)` / `type_of(value)`


تحويل أي قيمة لعدد صحيح.

```sad
اطبع_سطر(لرقم_صحيح("42"))     # الناتج: 42
```

---

#### `لرقم_عشري(قيمة)` / `to_float(value)`


### 1.6 دالة المدى

#### `مدى(نهاية)` / `مدى(بداية، نهاية)` / `مدى(بداية، نهاية، خطوة)` / `range(...)`

إنشاء مصفوفة أرقام متسلسلة.

| الخاصية | القيمة |
|---------|--------|
| **الصيغة 1** | `مدى(نهاية)` — من 0 إلى نهاية-1 |
| **الصيغة 2** | `مدى(بداية، نهاية)` — من بداية إلى نهاية-1 |
| **الصيغة 3** | `مدى(بداية، نهاية، خطوة)` — مع خطوة محددة |
| **القيمة المُرجعة** | `مصفوفة` من الأرقام |

```sad
اطبع_سطر(مدى(5))         # الناتج: [0, 1, 2, 3, 4]
اطبع_سطر(مدى(2، 6))      # الناتج: [2, 3, 4, 5]
اطبع_سطر(مدى(0، 10، 2))  # الناتج: [0, 2, 4, 6, 8]
```

## 2. دوال المصفوفات المتقدمة (`ArrayFunctions`)

هذه الدوال في فضاء `Sad::StdLib::Core::ArrayFunctions` وتوفر عمليات متقدمة على المصفوفات.

### `إضافة(مصفوفة، عنصر)` / `append(array, element)`

إضافة عنصر لنهاية المصفوفة وإرجاع مصفوفة جديدة.

| الخاصية | القيمة |
|---------|--------|
| **المعاملات** | `مصفوفة` + `عنصر` |
| **القيمة المُرجعة** | مصفوفة جديدة |
| **ملاحظة** | لا تُعدّل المصفوفة الأصلية |

```sad
متغير م = [1، 2، 3]
متغير م2 = إضافة(م، 4)   # م2 = [1, 2, 3, 4]، م لم تتغير
```

---

### `إزالة(مصفوفة)` / `pop(array)`

إزالة وإرجاع آخر عنصر.

| الخاصية | القيمة |
|---------|--------|
| **المعاملات** | `مصفوفة` |
| **القيمة المُرجعة** | العنصر الأخير |
| **خطأ** | ترمي خطأ إذا كانت المصفوفة فارغة |

```sad
متغير م = [10، 20، 30]
متغير آخر_عنصر = إزالة(م)   # آخر_عنصر = 30
```

---

### `حجم(مصفوفة)` / `size(array)`

عدد العناصر في المصفوفة.

```sad
متغير م = [1، 2، 3، 4، 5]
اطبع_سطر(حجم(م))   # الناتج: 5
```

---

### `فهرس(مصفوفة، عنصر، بداية؟)` / `indexOf(array, element, start?)`

إيجاد موقع عنصر في المصفوفة.

| الخاصية | القيمة |
|---------|--------|
| **المعاملات** | `مصفوفة` + `عنصر` + `بداية` (اختياري، افتراضي 0) |
| **القيمة المُرجعة** | `رقم` — الموقع، أو `-1` إذا لم يُعثر عليه |

```sad
متغير م = [10، 20، 30، 40]
اطبع_سطر(فهرس(م، 30))     # الناتج: 2
اطبع_سطر(فهرس(م، 99))     # الناتج: -1
```

---

### `يحتوي(مصفوفة، عنصر)` / `contains(array, element)`

التحقق من وجود عنصر.

```sad
متغير م = [1، 2، 3، 4]
اطبع_سطر(يحتوي(م، 3))   # الناتج: صحيح
اطبع_سطر(يحتوي(م، 9))   # الناتج: خطأ
```

---

### `قلب(مصفوفة)` / `reverse(array)`

قلب ترتيب العناصر.

```sad
متغير م = [1، 2، 3، 4]
اطبع_سطر(قلب(م))   # الناتج: [4, 3, 2, 1]
```

---

### `فرز(مصفوفة)` / `sort(array)`

فرز العناصر تصاعدياً.

```sad
متغير م = [3، 1، 4، 1، 5، 9]
اطبع_سطر(فرز(م))   # الناتج: [1, 1, 3, 4, 5, 9]
```

---

### `أول(مصفوفة)` / `first(array)`

الحصول على أول عنصر.

```sad
متغير م = [10، 20، 30]
اطبع_سطر(أول(م))   # الناتج: 10
```

---

### `آخر(مصفوفة)` / `last(array)`

الحصول على آخر عنصر.

```sad
متغير م = [10، 20، 30]
اطبع_سطر(آخر(م))   # الناتج: 30
```

---

### `شريحة(مصفوفة، بداية، نهاية)` / `slice(array, start, end)`

استخراج جزء من المصفوفة.

```sad
متغير م = [10، 20، 30، 40، 50]
اطبع_سطر(شريحة(م، 1، 4))   # الناتج: [20, 30, 40]
```

## 3. دوال الأنواع والتحويلات (`TypeFunctions`)

فضاء: `Sad::StdLib::Core::TypeFunctions`

### دوال التحويل (5 دوال)

| الدالة العربية | الدالة الإنجليزية | الوصف | مثال |
|---------------|-----------------|-------|------|
| `لنص(قيمة)` | `toString(value)` | تحويل لنص | `لنص(42)` → `"42"` |
| `لرقم_صحيح(قيمة)` | `toInt(value)` | تحويل لعدد صحيح | `لرقم_صحيح("123")` → `123` |
| `لرقم_عشري(قيمة)` | `toFloat(value)` | تحويل لعدد عشري | `لرقم_عشري("3.14")` → `3.14` |
| `لمصفوفة(قيمة)` | `toArray(value)` | تحويل لمصفوفة | `لمصفوفة("abc")` → `["a","b","c"]` |
| `لمنطقي(قيمة)` | `toBool(value)` | تحويل لمنطقي | `لمنطقي(1)` → `صحيح` |

### قواعد التحويل

#### `لنص` / `toString`
- `42` → `"42"`
- `3.14` → `"3.14"`
- `صحيح` → `"true"` / `"صحيح"`
- `[1,2,3]` → `"[1, 2, 3]"`
- `لاشيء` → `"null"` / `"لاشيء"`

#### `لرقم_صحيح` / `toInt`
- `"123"` → `123`
- `3.14` → `3` (قطع الكسور)
- `صحيح` → `1`، `خطأ` → `0`
- `"hello"` → `0`

#### `لرقم_عشري` / `toFloat`
- `"3.14"` → `3.14`
- `42` → `42.0`
- `خطأ` → `0.0`
- `"hello"` → `0.0`

#### `لمنطقي` / `toBool`
- `0` → `خطأ`
- أي رقم آخر → `صحيح`
- `""` → `خطأ`
- أي نص غير فارغ → `صحيح`
- `لاشيء` → `خطأ`

### دوال الفحص (4 دوال)

| الدالة العربية | الدالة الإنجليزية | الوصف | مثال |
|---------------|-----------------|-------|------|
| `هل_صحيح(قيمة)` | `isInt(value)` | هل القيمة عدد صحيح | `هل_صحيح(42)` → `صحيح` |
| `هل_عشري(قيمة)` | `isFloat(value)` | هل القيمة عدد عشري | `هل_عشري(3.14)` → `صحيح` |
| `هل_نص(قيمة)` | `isString(value)` | هل القيمة نص | `هل_نص("مرحبا")` → `صحيح` |
| `هل_مصفوفة(قيمة)` | `isArray(value)` | هل القيمة مصفوفة | `هل_مصفوفة([1])` → `صحيح` |

### دالة معلومات النوع

#### `النوع(قيمة)` / `type(value)`

الحصول على اسم النوع كنص.

```sad
اطبع_سطر(النوع(42))          # "رقم" أو "integer"
اطبع_سطر(النوع(3.14))       # "عشري" أو "float"
اطبع_سطر(النوع("مرحبا"))    # "نص" أو "string"
اطبع_سطر(النوع(صحيح))      # "منطقي" أو "boolean"
اطبع_سطر(النوع([1، 2]))     # "مصفوفة" أو "array"
```

### `عشوائي(...)` / `random(...)`

توليد رقم عشوائي. يدعم 3 صيغ:

| الصيغة | الوصف | مثال |
|-------|-------|------|
| `عشوائي()` | رقم بين 0 و RAND_MAX | `عشوائي()` |
| `عشوائي(حد)` | رقم بين 0 و حد-1 | `عشوائي(10)` → 0-9 |
| `عشوائي(أدنى، أقصى)` | رقم بين أدنى و أقصى-1 | `عشوائي(5، 15)` → 5-14 |

```sad
متغير رقم = عشوائي(1، 100)
اطبع_سطر("الرقم العشوائي: " + لنص(رقم))
```

---

### `انتظر(مللي_ثانية)` / `sleep(milliseconds)`

إيقاف التنفيذ مؤقتاً.

```sad
اطبع("جاري التحميل...")
انتظر(2000)   # انتظار ثانيتين
اطبع_سطر("تم!")
```

---

### `اخرج(كود؟)` / `exit(code?)`

إنهاء البرنامج فوراً.

| الخاصية | القيمة |
|---------|--------|
| **المعاملات** | `كود` (اختياري) — كود الخروج، افتراضي 0 |
| **القيمة المُرجعة** | لا شيء — البرنامج ينتهي |

```sad
إذا (خطأ_حرج)
    اطبع_سطر("خطأ حرج!")
    اخرج(1)
نهاية
```

---

### `تأكد(شرط، رسالة؟)` / `assert(condition, message?)`

التحقق من شرط — ترمي خطأ إذا كان الشرط خاطئاً.

```sad
متغير العمر = 25
تأكد(العمر > 0، "العمر يجب أن يكون موجباً")
تأكد(العمر < 200، "العمر غير واقعي")
```

## 6. ملاحظات مهمة

### تناقضات API معروفة

| التناقض | التفاصيل |
|---------|----------|
| تكرار أسماء | `اطبع`(builtins) vs `طبع`(io) — نفس الوظيفة باسمين مختلفين |
| `أدخل` مكرر | موجود في builtins وفي other_functions |
| `الطول` vs `حجم` | `الطول` في builtins، `حجم` في ArrayFunctions — يمكن استخدام أي منهما |

> هذه التناقضات مُراد إصلاحها في الإصدارات القادمة.

### حدود معروفة

1. `فرز` يعمل على أنواع متجانسة فقط — فرز مصفوفة أنواع مختلطة قد يرمي خطأ
2. `شريحة` بحدود خارج المصفوفة قد يعطي نتائج غير متوقعة
3. `قسّم` بفاصل فارغ `""` قد لا يعمل كما هو متوقع مع UTF-8
