# وثائق API — وحدة نص

> المسار: `stdlib/نص/`
> مساحة الأسماء: `sad::نص`

## نظرة عامة
وحدة نص تقدم قدرات معالجة عربية متقدمة: التطبيع، التخزين المضغوط، تجميع النصوص، واستخراج الجذور.

## الملفات الأساسية
- `نص/arabic_normalization.hpp`
- `نص/arabic_string_pool.hpp`
- `نص/arabic_storage.hpp`
- `نص/root_search.hpp`

## API رئيسية
- `struct خيارات_تطبيع`
  - `للبحث()`, `للعرض()`, `للتخزين()`
- `class مُطبِّع`
  - `طبّع(text)`
  - `متساويان(a, b)`
  - `يحتوي(text, query)`
- `class string_pool`
  - `العام()` (singleton)
  - `أضف(text)`, `ابحث(text)`, `احصل(id)`
  - `الحجم()`, `حجم_الذاكرة()`, `الإحصائيات()`, `امسح()`
- `struct حرف_مُرمَّز`
- `class مُحوِّل_حروف`
- `class مُستخرج_جذور`
  - `استخرج(word)`

## مثال سريع
```cpp
using namespace sad::نص;
مُطبِّع n(خيارات_تطبيع::للبحث());
std::string x = n.طبّع("مُحَمَّد"); // -> محمد
```

## ملاحظات
- الوحدة مصممة لدعم UTF-8 والعربية مباشرة.
- `string_pool` يجب التعامل معه غالباً عبر `string_pool::العام()`.
