# وثائق API — وحدة الأنظمة المدمجة (`embedded`)
# API Reference — Embedded Module

> **الوحدة:** `stdlib/embedded/`
> **الإصدار:** 1.0.0
> **آخر تحديث:** مارس 2026
> **المسؤولة:** ريم — مهندسة المكتبات والأدوات
> **ملاحظة:** جميع الملفات تستخدم `#![بلا_مكتبة_قياسية]` — لا يمكن تشغيلها بالمفسر

---

## نظرة عامة / Overview

وحدة الأنظمة المدمجة توفر واجهات برمجة منخفضة المستوى للتعامل مع العتاد مباشرة. تدعم Arduino، MMIO، RTOS (FreeRTOS)، الاتصال التسلسلي (Serial)، ومخرج VGA.

### الملفات المصدرية

| الملف | الوصف |
|-------|-------|
| `arduino.ص` | واجهة Arduino (منافذ، قراءة/كتابة رقمية وتمثيلية) |
| `mmio.ص` | Memory-Mapped I/O (سجلات متطايرة) |
| `rtos.ص` | نظام تشغيل في الوقت الحقيقي (مهام، أولويات) |
| `serial.ص` | اتصال تسلسلي (UART/USART) |
| `vga.ص` | مخرج شاشة VGA نصي |

## 1. Arduino (`arduino.ص`)

### الثوابت

| الثابت | القيمة | الوصف |
|--------|--------|-------|
| `د0` - `د13` | 0-13 | منافذ رقمية |
| `ت0` - `ت5` | 0-5 | منافذ تمثيلية |
| `منفذ_ليد` | 13 | LED المدمج |
| `منخفض` | 0 | قيمة منخفضة |
| `عالٍ` | 1 | قيمة عالية |

### تعداد `وضع_منفذ`

| القيمة | الرقم | الوصف |
|--------|-------|-------|
| `دخل` | 0 | وضع الإدخال |
| `خرج` | 1 | وضع الإخراج |
| `دخل_رفع` | 2 | إدخال مع مقاومة رفع داخلية |

### الدوال

| الدالة | المعاملات | الوصف |
|--------|-----------|-------|
| `حدد_وضع(منفذ, وضع)` | رقم, وضع_منفذ | تحديد وضع المنفذ |
| `اكتب_رقمي(منفذ, قيمة)` | رقم, رقم | كتابة قيمة رقمية |
| `اقرأ_رقمي(منفذ)` | رقم | → `ص8` قراءة قيمة رقمية |
| `اقرأ_تماثلي(منفذ)` | رقم | → `ص16` قراءة قيمة تمثيلية |

## 2. MMIO (`mmio.ص`)

### تعداد `نوع_وصول`

| القيمة | الرمز | الوصف |
|--------|-------|-------|
| `قراءة` | 0x01 | قراءة فقط |
| `كتابة` | 0x02 | كتابة فقط |
| `قراءة_كتابة` | 0x03 | قراءة وكتابة |

### بنية `سجل_متطاير<ن>`

| الدالة | الوصف |
|--------|-------|
| `جديد(عنوان)` | إنشاء سجل في عنوان ذاكرة |
| `اقرأ()` | → `ن` قراءة القيمة |
| `اكتب(قيمة)` | كتابة قيمة |
| `عدّل(قناع, قيمة)` | تعديل جزئي |
| `عيّن_بتات(بتات)` | تفعيل بتات |
| `امسح_بتات(بتات)` | إلغاء بتات |

## 3. RTOS (`rtos.ص`)

### الثوابت

| الثابت | القيمة | الوصف |
|--------|--------|-------|
| `انتظار_للأبد` | 0xFFFFFFFF | مهلة لانهائية |
| `بدون_انتظار` | 0 | بدون انتظار |

### تعداد `أولوية`

`خاملة(0)` → `منخفضة(1)` → `أقل_من_عادية(2)` → `عادية(3)` → `أعلى_من_عادية(4)` → `عالية(5)` → `فورية(6)`

### تعداد `حالة_مهمة`

`جاهزة` | `قيد_التنفيذ` | `محجوبة` | `معلّقة` | `محذوفة`

### بنية `مقبض_مهمة`

| الدالة | الوصف |
|--------|-------|
| `فارغ()` | → `منطقي` هل المقبض فارغ |
| `صالح()` | → `منطقي` هل المقبض صالح |

### وحدة `مهمة`

| الدالة | الوصف |
|--------|-------|
| `أنشئ(اسم, دالة, حجم_مكدس, ...)` | إنشاء مهمة جديدة (FreeRTOS wrapper) |

## 4. Serial (`serial.ص`)

### تعداد `معدل_باود`

`1200` | `2400` | `4800` | `9600` | `19200` | `38400` | `57600` | `115200` | `230400` | `460800` | `921600`

### تعداد `بتات_بيانات`

`خمسة(5)` | `ستة(6)` | `سبعة(7)` | `ثمانية(8)`

### تعداد `تكافؤ`

`لا_شيء` | `زوجي` | `فردي` | `علامة` | `فراغ`

### بنية `إعدادات_تسلسلي`

| الإعداد المسبق | المعدل | البيانات | التكافؤ | التوقف |
|---------------|--------|----------|---------|--------|
| `افتراضي()` | 115200 | 8 | لا شيء | 1 |
| `بطيء()` | 9600 | 8 | لا شيء | 1 |

## 5. VGA (`vga.ص`)

### الثوابت

| الثابت | القيمة |
|--------|--------|
| `عنوان_VGA` | 0xB8000 |
| `عرض_شاشة` | 80 |
| `ارتفاع_شاشة` | 25 |

### تعداد `لون_VGA` (16 لون)

`أسود(0x0)` | `أزرق(0x1)` | `أخضر(0x2)` | `سماوي(0x3)` | `أحمر(0x4)` | `بنفسجي(0x5)` | `بني(0x6)` | `رمادي_فاتح(0x7)` | `رمادي_غامق(0x8)` | `أزرق_فاتح(0x9)` | `أخضر_فاتح(0xA)` | `سماوي_فاتح(0xB)` | `أحمر_فاتح(0xC)` | `وردي(0xD)` | `أصفر(0xE)` | `أبيض(0xF)`

### بنية `كود_لون`

| الإعداد | المقدمة | الخلفية |
|---------|---------|---------|
| `افتراضي()` | رمادي فاتح | أسود |
| `تحذير()` | أصفر | أسود |
| `خطأ()` | أحمر فاتح | أسود |
| `نجاح()` | أخضر فاتح | أسود |
| `معلومات()` | سماوي فاتح | أسود |

---

> **ملاحظة:** هذه الوحدة مخصصة للأنظمة المدمجة (bare-metal) ولا يمكن اختبارها بالمفسر. الاختبار يتطلب أجهزة فعلية أو محاكيات (QEMU, Wokwi).
