## نظرة عامة / Overview

وحدة الإدخال والإخراج توفر الدوال الأساسية للتعامل مع الشاشة (stdout) والمدخلات (stdin). هي المرحلة الأولى (Phase 1) من تنفيذ المكتبة القياسية.

The I/O module provides fundamental functions for console output (stdout) and user input (stdin). This is Phase 1 of the standard library implementation.

### الملفات المصدرية

| الملف | الوصف |
|-------|-------|
| `io_functions.h` | تعريفات دوال I/O |
| `io_functions.cpp` | تنفيذ دوال I/O |

### فضاء الأسماء


## الدوال

### 1. `طبع(...)` / `print(...)`

طباعة قيمة أو أكثر إلى الشاشة **بدون** سطر جديد في النهاية.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `طبع` |
| **الاسم الإنجليزي** | `print` |
| **المعاملات** | `...قيم` — عدد غير محدد من القيم |
| **القيمة المُرجعة** | `فراغ` (VOID) |
| **آمنة للمعالجة المتزامنة** | نعم |
| **تعالج تسلسلات الهروب** | نعم (`\n`, `\t`, `\r`, `\\`) |

#### الأنواع المدعومة للطباعة

| النوع | المخرج |
|-------|--------|
| `رقم` (INT) | `42` |
| `عشري` (FLOAT) | `3.14` |
| `نص` (STRING) | `مرحبا` |
| `منطقي` (BOOL) | `صحيح` أو `خطأ` |
| `مصفوفة` (ARRAY) | `[1, 2, 3]` |
| `خريطة` (MAP) | `{مفتاح: قيمة}` |
| `فراغ` (VOID/NULL) | `لاشيء` |

#### أمثلة

```sad
# طباعة قيمة واحدة
طبع("مرحبا")              # الناتج: مرحبا

# طباعة رقم
طبع(42)                   # الناتج: 42

# طباعة عدة قيم (مفصولة بمسافة)
طبع("العدد:"، 100)        # الناتج: العدد: 100

# استخدام تسلسلات الهروب
طبع("سطر1\nسطر2")        # الناتج:
                           # سطر1
                           # سطر2

# طباعة مع tab
طبع("الاسم\tالعمر")       # الناتج: الاسم    العمر
```

### 2. `طبع_سطر(...)` / `println(...)`

طباعة قيمة أو أكثر مع إضافة سطر جديد (`\n`) تلقائياً في النهاية.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `طبع_سطر` |
| **الاسم الإنجليزي** | `println` |
| **المعاملات** | `...قيم` — عدد غير محدد من القيم |
| **القيمة المُرجعة** | `فراغ` (VOID) |
| **الفرق عن `طبع`** | يضيف `\n` في النهاية تلقائياً |

#### أمثلة

```sad
طبع_سطر("السلام عليكم")
طبع_سطر("كيف الحال؟")
# الناتج:
# السلام عليكم
# كيف الحال؟

# طباعة عدة أنواع
طبع_سطر("الاسم: أحمد، العمر: "، 25)
# الناتج: الاسم: أحمد، العمر:  25

# بدون معاملات — سطر فارغ
طبع_سطر()
# الناتج: (سطر فارغ)
```

---

### 3. `أدخل(رسالة؟)` / `input(prompt?)`

قراءة مدخل نصي من المستخدم عبر stdin.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `أدخل` |
| **الاسم الإنجليزي** | `input` |
| **المعاملات** | `رسالة` (اختياري) — نص يُعرض كمحث قبل القراءة |
| **القيمة المُرجعة** | `نص` (STRING) — السطر المُدخل |
| **يقرأ حتى** | نهاية السطر (`\n`) |

#### أمثلة

```sad
# بدون رسالة محث
متغير نص = أدخل()

# مع رسالة محث
متغير الاسم = أدخل("ما اسمك؟ ")
طبع_سطر("مرحباً يا " + الاسم)

# قراءة عدد (تحتاج تحويل)
متغير عدد_نص = أدخل("أدخل رقماً: ")
متغير عدد = لرقم_صحيح(عدد_نص)
طبع_سطر("الضعف: " + لنص(عدد * 2))
```

---

### 4. `قراءة_سطر(رسالة؟)` / `readLine(prompt?)`

قراءة سطر كامل من الإدخال — مشابهة لـ `أدخل` لكن مصممة خصيصاً لقراءة الأسطر.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `قراءة_سطر` |
| **الاسم الإنجليزي** | `readLine` |
| **المعاملات** | `رسالة` (اختياري) |
| **القيمة المُرجعة** | `نص` (STRING) |
| **الفرق عن `أدخل`** | تصميم أوضح لقراءة أسطر كاملة |

#### أمثلة

```sad
متغير السطر = قراءة_سطر("أدخل جملة كاملة: ")
طبع_سطر("قلت: " + السطر)

# قراءة عدة أسطر
متغير سطر1 = قراءة_سطر("السطر الأول: ")
متغير سطر2 = قراءة_سطر("السطر الثاني: ")
طبع_سطر(سطر1 + "\n" + سطر2)
```

---

### 5. `مسح_الشاشة()` / `clear()`

مسح شاشة الطرفية (الكونسول) بالكامل ووضع المؤشر في الزاوية العلوية اليسرى.

| الخاصية | القيمة |
|---------|--------|
| **الاسم العربي** | `مسح_الشاشة` |
| **الاسم الإنجليزي** | `clear` |
| **المعاملات** | لا شيء |
| **القيمة المُرجعة** | `فراغ` (VOID) |
| **تعمل على** | Windows (cls) + Linux/macOS (ANSI escape) |

#### أمثلة

```sad
# مسح الشاشة قبل عرض قائمة
مسح_الشاشة()
طبع_سطر("═══════════════════════")
طبع_سطر("   القائمة الرئيسية   ")
طبع_سطر("═══════════════════════")
طبع_سطر("1. بدء لعبة جديدة")
طبع_سطر("2. تحميل لعبة")
طبع_سطر("3. خروج")
```

## الدوال الداخلية (Private)

هذه الدوال لا تتوفر للمستخدم مباشرة — تُستخدم داخلياً فقط:

| الدالة | الوصف |
|--------|-------|
| `validateArguments(args, min, max)` | التحقق من عدد المعاملات |
| `processEscapeSequences(input)` | معالجة `\n`, `\t`, `\r`, `\\` |
| `valueToString(value, depth)` | تحويل قيمة لنص للطباعة (يدعم العمق للمصفوفات المتداخلة) |

## ملاحظات

### الفرق بين `اطبع`/`اطبع_سطر` (builtins) و `طبع`/`طبع_سطر` (io)

| الوحدة | الدالة | الموقع |
|--------|--------|--------|
| builtins | `اطبع` / `اطبع_سطر` | `stdlib/core/builtins.h` |
| io | `طبع` / `طبع_سطر` | `stdlib/io/io_functions.h` |

كلاهما يؤديان نفس الوظيفة. `اطبع` / `اطبع_سطر` هما الأسماء **الرسمية** المدمجة التي تتوفر تلقائياً. `طبع` / `طبع_سطر` موجودان في وحدة io كبديل.

> **التوصية:** استخدم `اطبع_سطر` (الاسم المدمج الرسمي) في البرامج الجديدة.

### دعم Unicode

جميع دوال I/O تدعم UTF-8 بالكامل:
- النصوص العربية تُطبع وتُقرأ بشكل صحيح
- النصوص ثنائية الاتجاه (عربي + إنجليزي) مدعومة
- تسلسلات الهروب تعمل مع أي نص Unicode

### مشكلة معروفة — Windows Terminal

على بعض إصدارات Windows، قد لا يظهر النص العربي بشكل صحيح في cmd.exe القديم. الحل:
- استخدم Windows Terminal الحديث
- أو أضف `chcp 65001` قبل تشغيل البرنامج
