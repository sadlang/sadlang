# 15. ميزات متقدمة

## النطاقات (Ranges)

لغة ص تدعم النطاقات باستخدام `..`:

```sad
لكل ع في 1..5
    اطبع_سطر(ع)
نهاية
# يطبع: 1 2 3 4 5
```

يمكن استخدام النطاقات في:
- حلقات `لكل`
- إنشاء مصفوفات
- التحقق من عضوية قيمة

## النصوص المنسّقة (F-strings)

تبدأ بحرف `م` قبل علامة الاقتباس، وتحتوي تعبيرات بين `{}`:

```sad
متغير اسم = "أحمد"
متغير عمر = 25
اطبع_سطر(م"مرحباً {اسم}، عمرك {عمر} سنة")
# مرحباً أحمد، عمرك 25 سنة
```

يمكن وضع أي تعبير داخل `{}`:

```sad
اطبع_سطر(م"2 + 3 = {2 + 3}")
اطبع_سطر(م"جذر 16 = {جذر(16)}")
```

## المُطابقة المتقدمة (Pattern Matching)

```sad
طابق قيمة
    عندما 1 => اطبع_سطر("واحد")
    عندما 2 => اطبع_سطر("اثنان")
    عندما _ => اطبع_سطر("آخر")
نهاية
```

## المراجع (References)

عامل المرجع `&` يسمح بتمرير قيمة بالمرجع:

```sad
متغير س = 10
دالة غيّر(&م)
    م = 20
نهاية
غيّر(&س)
اطبع_سطر(س) # 20
```

## المزخرفات (Decorators)

```sad
# تعريف مزخرف
دالة سجّل(دالة_أصلية)
    ارجع لامدا: (
        اطبع_سطر("بداية التنفيذ")
        دالة_أصلية()
        اطبع_سطر("نهاية التنفيذ")
    )
نهاية
```

### مثال 6 — متوسط: التمرير بالمرجع
```sad
دالة زيادة(&عدد، مقدار)
    عدد = عدد + مقدار
نهاية

دالة مبادلة(&أ، &ب)
    متغير مؤقت = أ
    أ = ب
    ب = مؤقت
نهاية

متغير س = 10
متغير ص = 20

اطبع_سطر(م"قبل الزيادة: س = {س}")

اطبع_سطر(م"بعد الزيادة: س = {س}")

اطبع_سطر(م"قبل المبادلة: س = {س}، ص = {ص}")

اطبع_سطر(م"بعد المبادلة: س = {س}، ص = {ص}")
```
**المخرجات:**

### مثال 7 — متقدم: برنامج إحصائي بميزات متقدمة
```sad
دالة تحليل_بيانات(بيانات)
    متغير المجموع = 0
    متغير الأصغر = بيانات[0]
    متغير الأكبر = بيانات[0]
    متغير العدد = طول(بيانات)
    
    لكل قيمة في بيانات
        المجموع = المجموع + قيمة
        إذا (قيمة < الأصغر)
            الأصغر = قيمة
        نهاية
        إذا (قيمة > الأكبر)
            الأكبر = قيمة
        نهاية
    نهاية
    
    متغير المتوسط = المجموع / العدد
    
    # حساب الانحراف المعياري
    متغير مجموع_الفروق = 0
    لكل قيمة في بيانات
        متغير فرق = قيمة - المتوسط
        مجموع_الفروق = مجموع_الفروق + (فرق * فرق)
    نهاية
    متغير الانحراف = جذر(مجموع_الفروق / العدد)
    
    اطبع_سطر("╔══════════════════════════╗")
    اطبع_سطر("║    التحليل الإحصائي     ║")
    اطبع_سطر("╠══════════════════════════╣")
    اطبع_سطر(م"║ العدد:    {العدد}")
    اطبع_سطر(م"║ المجموع: {المجموع}")
    اطبع_سطر(م"║ المتوسط: {تقريب(المتوسط)}")
    اطبع_سطر(م"║ الأصغر:  {الأصغر}")
    اطبع_سطر(م"║ الأكبر:  {الأكبر}")
    اطبع_سطر(م"║ المدى:   {الأكبر - الأصغر}")
    اطبع_سطر(م"║ الانحراف: {تقريب(الانحراف)}")
    اطبع_سطر("╚══════════════════════════╝")
نهاية

تحليل_بيانات([85، 92، 78، 95، 88، 76، 91، 83، 87، 94])
```
**المخرجات:**
```
╔══════════════════════════╗
║    التحليل الإحصائي     ║
╠══════════════════════════╣
║ العدد:    10
║ المجموع: 869
║ المتوسط: 87
║ الأصغر:  76
║ الأكبر:  95
║ المدى:   19
║ الانحراف: 6
╚══════════════════════════╝
```

### مثال 8 — متقدم جداً: نظام قائمة مهام تفاعلي
```sad
صنف مهمة
    باني(عنوان، أولوية)
        هذا.عنوان = عنوان
        هذا.أولوية = أولوية
        هذا.مكتملة = خطأ
    نهاية
    
    دالة إكمال()
        هذا.مكتملة = صحيح
    نهاية
    
    دالة نص()
        متغير حالة = هذا.مكتملة ? "✓" : "○"
        ارجع م"[{حالة}] ({هذا.أولوية}) {هذا.عنوان}"
    نهاية
نهاية

صنف قائمة_مهام
    باني(اسم)
        هذا.اسم = اسم
        هذا.مهام = []
    نهاية
    
    دالة أضف(عنوان، أولوية)
        متغير م = جديد مهمة(عنوان، أولوية)
        أضف(هذا.مهام، م)
        اطبع_سطر(م"+ تمت إضافة: {عنوان}")
    نهاية
    
    دالة أكمل(فهرس)
        هذا.مهام[فهرس].إكمال()
        اطبع_سطر(م"✓ تم إكمال: {هذا.مهام[فهرس].عنوان}")
    نهاية
    
    دالة عرض()
        اطبع_سطر("")
        اطبع_سطر(م"══════ {هذا.اسم} ══════")
        لكل ع في 0..طول(هذا.مهام) - 1
            اطبع_سطر(م"  {ع + 1}. {هذا.مهام[ع].نص()}")
        نهاية
        
        # إحصائيات
        متغير مكتملة = 0
        لكل م في هذا.مهام
            إذا (م.مكتملة)
                مكتملة = مكتملة + 1
            نهاية
        نهاية
        متغير الكل = طول(هذا.مهام)
        اطبع_سطر(م"  ──────────────────")
        اطبع_سطر(م"  الإجمالي: {الكل} | مكتمل: {مكتملة} | متبقي: {الكل - مكتملة}")
    نهاية
نهاية

# الاستخدام
متغير قائمتي = جديد قائمة_مهام("مهام اليوم")

قائمتي.أضف("تعلم لغة ص"، "عالية")
قائمتي.أضف("كتابة التوثيق"، "عالية")
قائمتي.أضف("اختبار الأمثلة"، "متوسطة")
قائمتي.أضف("مراجعة الكود"، "منخفضة")

قائمتي.أكمل(0)
قائمتي.أكمل(1)

قائمتي.عرض()
```
**المخرجات:**
```
+ تمت إضافة: تعلم لغة ص
+ تمت إضافة: كتابة التوثيق
+ تمت إضافة: اختبار الأمثلة
+ تمت إضافة: مراجعة الكود
✓ تم إكمال: تعلم لغة ص
✓ تم إكمال: كتابة التوثيق

══════ مهام اليوم ══════
  1. [✓] (عالية) تعلم لغة ص
  2. [✓] (عالية) كتابة التوثيق
  3. [○] (متوسطة) اختبار الأمثلة
  4. [○] (منخفضة) مراجعة الكود
  ──────────────────
  الإجمالي: 4 | مكتمل: 2 | متبقي: 2
```
