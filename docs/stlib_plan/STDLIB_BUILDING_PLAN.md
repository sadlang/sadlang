## 📊 المراحل التفصيلية

### المرحلة 1: I/O Functions (الإدخال/الإخراج) ⏳
**الأهمية:** حيوية 🔴  
**المدة المتوقعة:** 2-3 أيام

#### الدوال المطلوبة (5):
```
1. طبع() / print()
   - الهدف: طباعة متغير واحد أو أكثر
   - المعاملات: variable arguments
   - الإرجاع: void
   - الأمثلة:
     طبع("مرحبا")
     طبع(10, 20, "نص")

2. أدخل() / input()
   - الهدف: قراءة مدخل من المستخدم
   - المعاملات: رسالة اختيارية (prompt)
   - الإرجاع: string
   - الأمثلة:
     الاسم = أدخل("أدخل الاسم: ")

3. طبع_سطر() / println()
   - الهدف: طباعة مع سطر جديد
   - المعاملات: variable arguments
   - الإرجاع: void
   - الأمثلة:
     طبع_سطر("سطر 1")
     طبع_سطر("سطر 2")

4. قراءة_سطر() / readLine()
   - الهدف: قراءة سطر كامل
   - المعاملات: بدون
   - الإرجاع: string
   - الأمثلة:
     السطر = قراءة_سطر()

5. مسح_الشاشة() / clear()
   - الهدف: تنظيف الشاشة
   - المعاملات: بدون
   - الإرجاع: void
   - الأمثلة:
     مسح_الشاشة()
```

#### معايير القبول:
- [ ] جميع الدوال تعمل مع العربية
- [ ] معالجة صحيحة للأخطاء
- [ ] رسائل خطأ ثنائية اللغة
- [ ] توثيق كامل

### المرحلة 2: String Functions (دوال النصوص) ⏳
**الأهمية:** عالية 🟠  
**المدة المتوقعة:** 4-5 أيام

#### الدوال المطلوبة (12):
```
1. طول() / length()
   - الهدف: حساب طول النص
   - المعاملات: string
   - الإرجاع: int
   - الأمثلة:
     ط = طول("السلام عليكم")  // 11

2. بحث() / find()
   - الهدف: البحث عن نصوص جزئية
   - المعاملات: (text, substring)
   - الإرجاع: int (index or -1)
   - الأمثلة:
     فهرس = بحث("مرحبا بك", "بك")  // 6

3. استبدل() / replace()
   - الهدف: استبدال نصوص جزئية
   - المعاملات: (text, old, new)
   - الإرجاع: string
   - الأمثلة:
     نتيجة = استبدل("السلام", "ا", "ي")  // "سليم"

4. استخراج() / substring()
   - الهدف: استخراج جزء من النص
   - المعاملات: (text, start, length)
   - الإرجاع: string
   - الأمثلة:
     جزء = استخراج("مرحبا", 0, 3)  // "مرح"

5. تحويل_صغير() / toLower()
   - الهدف: تحويل للأحرف الصغيرة
   - المعاملات: string
   - الإرجاع: string
   - الأمثلة:
     صغير = تحويل_صغير("HELLO")  // "hello"

6. تحويل_كبير() / toUpper()
   - الهدف: تحويل للأحرف الكبيرة
   - المعاملات: string
   - الإرجاع: string
   - الأمثلة:
     كبير = تحويل_كبير("hello")  // "HELLO"

7. قص_أطراف() / trim()
   - الهدف: حذف المسافات من الأطراف
   - المعاملات: string
   - الإرجاع: string
   - الأمثلة:
     نتيجة = قص_أطراف("  مرحبا  ")  // "مرحبا"

8. تقسيم() / split()
   - الهدف: تقسيم النص إلى صفيف
   - المعاملات: (text, delimiter)
   - الإرجاع: array
   - الأمثلة:
     أجزاء = تقسيم("أ,ب,ج", ",")  // ["أ", "ب", "ج"]

9. دمج() / join()
   - الهدف: دمج عناصر الصفيف بفاصل
   - المعاملات: (array, separator)
   - الإرجاع: string
   - الأمثلة:
     نص = دمج(["أ", "ب", "ج"], "-")  // "أ-ب-ج"

10. يبدأ_ب() / startsWith()
    - الهدف: التحقق من بداية النص
    - المعاملات: (text, prefix)
    - الإرجاع: boolean
    - الأمثلة:
      نتيجة = يبدأ_ب("مرحبا", "مر")  // true

11. ينتهي_ب() / endsWith()
    - الهدف: التحقق من نهاية النص
    - المعاملات: (text, suffix)
    - الإرجاع: boolean
    - الأمثلة:
      نتيجة = ينتهي_ب("مرحبا", "با")  // true

12. يحتوي_على() / contains()
    - الهدف: التحقق من وجود نص
    - المعاملات: (text, substring)
    - الإرجاع: boolean
    - الأمثلة:
      نتيجة = يحتوي_على("مرحبا", "حب")  // true
```

### المرحلة 3: Array Functions (دوال الصفائف) ⏳
**الأهمية:** عالية 🟠  
**المدة المتوقعة:** 4-5 أيام

#### الدوال المطلوبة (10):
```
1. إضافة() / append()
   - الهدف: إضافة عنصر آخر الصفيف
   - المعاملات: (array, value)
   - الإرجاع: void
   - الأمثلة:
     قائمة = [1, 2]
     إضافة(قائمة, 3)  // [1, 2, 3]

2. إزالة() / pop()
   - الهدف: إزالة آخر عنصر
   - المعاملات: array
   - الإرجاع: value (آخر عنصر)
   - الأمثلة:
     قائمة = [1, 2, 3]
     آخر = إزالة(قائمة)  // 3

3. حجم() / size()
   - الهدف: الحصول على عدد العناصر
   - المعاملات: array
   - الإرجاع: int
   - الأمثلة:
     حجم([1, 2, 3])  // 3

4. فهرس() / indexOf()
   - الهدف: البحث عن موضع عنصر
   - المعاملات: (array, value)
   - الإرجاع: int (-1 if not found)
   - الأمثلة:
      موضع = فهرس([1, 2, 3], 2)  // 1

5. يحتوي() / contains()
   - الهدف: التحقق من وجود عنصر
   - المعاملات: (array, value)
   - الإرجاع: boolean
   - الأمثلة:
     موجود = يحتوي([1, 2, 3], 2)  // true

6. قلب() / reverse()
   - الهدف: عكس ترتيب العناصر
   - المعاملات: array
   - الإرجاع: array (جديد)
   - الأمثلة:
     معكوس = قلب([1, 2, 3])  // [3, 2, 1]

7. فرز() / sort()
   - الهدف: ترتيب العناصر
   - المعاملات: (array, ascending?)
   - الإرجاع: array (جديد)
   - الأمثلة:
     مرتب = فرز([3, 1, 2])  // [1, 2, 3]

8. أول() / first()
   - الهدف: الحصول على أول عنصر
   - المعاملات: array
   - الإرجاع: value
   - الأمثلة:
     أول([1, 2, 3])  // 1

9. آخر() / last()
   - الهدف: الحصول على آخر عنصر
   - المعاملات: array
   - الإرجاع: value
   - الأمثلة:
     آخر([1, 2, 3])  // 3

10. شريحة() / slice()
    - الهدف: استخراج جزء من الصفيف
    - المعاملات: (array, start, end)
    - الإرجاع: array
    - الأمثلة:
      جزء = شريحة([1, 2, 3, 4], 1, 3)  // [2, 3]
```

### المرحلة 4: Math Functions (دوال الرياضيات) ⏳

```

   - الأمثلة:

   - الهدف: رفع للأس
   - المعاملات: (base, exponent)
   - الإرجاع: number
   - الأمثلة:
     قوة(2, 3)  // 8

3. قيمة_مطلقة() / abs()
   - الهدف: القيمة المطلقة
   - المعاملات: number
   - الإرجاع: number
   - الأمثلة:
     قيمة_مطلقة(-5)  // 5

4. أقصى() / max()
   - الهدف: الحد الأقصى
   - المعاملات: variable numbers
   - الإرجاع: number
   - الأمثلة:
     أقصى(1, 5, 3)  // 5

5. أدنى() / min()
   - الهدف: الحد الأدنى
   - المعاملات: variable numbers
   - الإرجاع: number
   - الأمثلة:
     أدنى(1, 5, 3)  // 1

6. دور() / round()
   - الهدف: تقريب لأقرب صحيح
   - المعاملات: number
   - الإرجاع: int
   - الأمثلة:
     دور(3.7)  // 4

7. أرضية() / floor()
   - الهدف: تقريب لأسفل
   - المعاملات: number
   - الإرجاع: int
   - الأمثلة:
     أرضية(3.7)  // 3

8. سقف() / ceil()
   - الهدف: تقريب لأعلى
   - المعاملات: number
   - الإرجاع: int
   - الأمثلة:
     سقف(3.2)  // 4

9. تربيع() / square()
   - الهدف: تربيع الرقم
   - المعاملات: number
   - الإرجاع: number
   - الأمثلة:
     تربيع(5)  // 25

10. جيب() / sin()
    - الهدف: جيب الزاوية
    - المعاملات: angle (radians)
    - الإرجاع: number
    - الأمثلة:
      جيب(0)  // 0

11. جتا() / cos()
    - الهدف: جتا الزاوية
    - المعاملات: angle (radians)
    - الإرجاع: number
    - الأمثلة:
      جتا(0)  // 1

12. ظا() / tan()
    - الهدف: ظا الزاوية
    - المعاملات: angle (radians)
    - الإرجاع: number
    - الأمثلة:
      ظا(0)  // 0
```

### المرحلة 5: Type Functions (دوال النوع) ⏳
**الأهمية:** عالية 🟠  
**المدة المتوقعة:** 3 أيام

#### الدوال المطلوبة (10):
```
1. نوع() / type()
   - الهدف: الحصول على نوع المتغير
   - المعاملات: value
   - الإرجاع: string
   - الأمثلة:
     نوع(10)  // "integer"
     نوع("مرحبا")  // "string"

2. هو_رقم() / isNumber()
   - الهدف: التحقق من أنه رقم
   - المعاملات: value
   - الإرجاع: boolean
   - الأمثلة:
     هو_رقم(10)  // true

3. هو_نص() / isString()
   - الهدف: التحقق من أنه نص
   - المعاملات: value
   - الإرجاع: boolean
   - الأمثلة:
     هو_نص("مرحبا")  // true

4. هو_صفيف() / isArray()
   - الهدف: التحقق من أنه صفيف
   - المعاملات: value
   - الإرجاع: boolean
   - الأمثلة:
     هو_صفيف([1, 2, 3])  // true

5. هو_خريطة() / isMap()
   - الهدف: التحقق من أنها خريطة
   - المعاملات: value
   - الإرجاع: boolean
   - الأمثلة:
     هو_خريطة({أ: 1})  // true

6. هو_منطقي() / isBoolean()
   - الهدف: التحقق من قيمة منطقية
   - المعاملات: value
   - الإرجاع: boolean
   - الأمثلة:
     هو_منطقي(صحيح)  // true

7. هو_فارغ() / isVoid()
   - الهدف: التحقق من قيمة فارغة
   - المعاملات: value
   - الإرجاع: boolean
   - الأمثلة:
     هو_فارغ(لا_شيء)  // true

8. حول() / convert()
   - الهدف: تحويل بين الأنواع
   - المعاملات: (value, targetType)
   - الإرجاع: converted value
   - الأمثلة:
     حول(10, "string")  // "10"

9. ل_عدد() / toNumber()
   - الهدف: تحويل لعدد
   - المعاملات: value
   - الإرجاع: number
   - الأمثلة:
     ل_عدد("42")  // 42

10. ل_نص() / toString()
    - الهدف: تحويل لنص
    - المعاملات: value
    - الإرجاع: string
    - الأمثلة:
      ل_نص(42)  // "42"
```
