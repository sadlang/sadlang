```

فرز() أول() آخر() شريحة()
```

### المرحلة 4️⃣: Math Functions (دوال الرياضيات)
**12 دالة** • **3-4 أيام**
```

أرضية() سقف() تربيع() جيب() جتا() ظا()

### المرحلة 5️⃣: Type Functions (دوال النوع)

```
