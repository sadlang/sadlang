## 📚 معايير التوثيق

### لكل دالة:
```cpp
/**
 * @brief (AR) الوصف بالعربية
 * @brief (EN) Description in English
 * 
 * @param arg1 (AR) وصف المعامل الأول
 * @param arg1 (EN) First parameter description
 * 
 * @return (AR) وصف القيمة المرجعة
 * @return (EN) Return value description
 * 
 * @example
 * نتيجة = دالة(معامل1, معامل2);
 * result = function(param1, param2);
 * 
 * @throws std::runtime_error إذا كان المعامل غير صحيح
 */
```
