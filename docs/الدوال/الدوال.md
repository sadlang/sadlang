# الدوال في لغة ص

## نظرة عامة

الدوال هي أحد أهم عناصر البرمجة في لغة ص. تدعم اللغة عدة طرق لتعريف الدوال، مع دعم القيم الافتراضية للمعاملات، والدوال المتداخلة، والدوال العودية (التكرارية)، والمولدات.

---

## طرق تعريف الدوال

### الطريقة الأولى: الدالة الأساسية (بدون تحديد نوع الإرجاع)

```sad
دالة اسم_الدالة(معامل1، معامل2)
    # جسم الدالة
    ارجع نتيجة
نهاية
```

### الطريقة الثانية: مع تحديد نوع الإرجاع

```sad
دالة رقم مضاعف(عدد)
    ارجع عدد * 2
نهاية

دالة نص تحية(اسم)
    ارجع "مرحباً " + اسم
نهاية
```

### الطريقة الثالثة: الدوال السهمية (Arrow Functions)

```sad
متغير ضعف = x => x * 2
متغير جمع = (أ, ب) => أ + ب
متغير تحية = () => "مرحبا!"
```

### الطريقة الرابعة: تعبيرات لامدا

```sad
متغير مربع = لامدا س: س * س
```

### الطريقة الخامسة: دالة مع نوع الإرجاع بعد `ترجع`

```sad
دالة حساب(أ، ب) ترجع رقم
    ارجع أ + ب
نهاية
```

## المعاملات

### معاملات عادية

```sad
دالة جمع(أ، ب)
    ارجع أ + ب
نهاية
```

### معاملات بقيم افتراضية

```sad
دالة تحية(اسم، لقب = "المحترم")
    ارجع "مرحباً " + لقب + " " + اسم
نهاية

تحية("أحمد")              # "مرحباً المحترم أحمد"
تحية("أحمد"، "الدكتور")    # "مرحباً الدكتور أحمد"
```

### معاملات مع تحديد النوع

```sad
دالة جمع(رقم أ، رقم ب)
    ارجع أ + ب
نهاية
```

## أنواع الدوال الخاصة

### الدالة الرئيسية

```sad
دالة رئيسية()
    # نقطة دخول البرنامج
    اطبع_سطر("مرحباً بالعالم")
نهاية
```

### الدوال العودية (التكرارية)

```sad
دالة عاملي(ن)
    إذا (ن <= 1)
        ارجع 1
    نهاية
    ارجع ن * عاملي(ن - 1)
نهاية
```

### الدوال المتداخلة

```sad
دالة خارجية(س)
    دالة داخلية(ص)
        ارجع س + ص
    نهاية
    ارجع داخلية(10)
نهاية
```

### دوال المولدات

```sad
دالة مولد عداد()
    أنتج 1
    أنتج 2
    أنتج 3
نهاية

متغير النتائج = عداد()    # [1, 2, 3]
```

### الدوال المُصدّرة

```sad
صدّر دالة مضاعف(عدد)
    ارجع عدد * 2
نهاية
```

## جملة الإرجاع

- `ارجع` أو `إرجاع` — كلاهما مدعوم
- يمكن إرجاع أي نوع من البيانات
- يمكن الإرجاع بدون قيمة (الدالة ترجع `لاشيء`)

```sad
دالة بحث(قائمة، قيمة)
    لكل عنصر في قائمة
        إذا (عنصر == قيمة)
            ارجع صحيح
        نهاية
    نهاية
    ارجع خطأ
نهاية
```
