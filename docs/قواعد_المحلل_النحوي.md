## 2. التصريحات

```bnf
declaration    → directive
               | decorator* function_decl
               | decorator* async_function_decl
               | decorator* generator_function_decl
               | class_decl
               | abstract_class_decl
               | trait_decl
               | impl_decl
               | template_decl
               | namespace_decl
               | enum_decl
               | struct_decl
               | var_decl
               | const_decl
               | extern_function_decl
               | import_stmt
               | from_import_stmt
               | export_decl
               | extension_decl
               | macro_decl
               | test_decl
               | expression_stmt
```

**المصدر:** `parser_core_main.cpp` → `parseDeclaration()`

### 2.1 تصريح الدوال

```bnf
function_decl  → 'دالة' [return_type] ['غير_متزامن'] IDENTIFIER '(' param_list ')' block

param_list     → ε
               | parameter ((',' | '،') parameter)*

parameter      → [type] IDENTIFIER ['=' expression]
               | IDENTIFIER ':' type ['=' expression]
               | type IDENTIFIER ['=' expression]

return_type    → type_token
```

**ملاحظات:**
- نوع الإرجاع يُوضع **قبل** اسم الدالة فقط، وليس بعد المعاملات
- كلمة `غير_متزامن` **سياقية** — تُعامل كمُعرّف عادي خارج سياقها
- أسماء الأنواع المدمجة (`نص`، `رقم`، ...) يمكن استخدامها كأسماء دوال
- كلمات سياقية مثل `خطأ`، `صحيح`، `لاشيء` مسموحة كأسماء دوال

**المصدر:** `parser_declarations.cpp` → `parseFunctionDecl()`

### 2.2 الدالة الرئيسية

```bnf
main_function  → 'دالة' ['صحيح'] 'رئيسية' '(' [param_list] ')' block
```

- كلمة `رئيسية` **سياقية** (ليست محجوزة)
- نوع الإرجاع الافتراضي: `صحيح` (INTEGER)
- المعاملات: `()` أو `(نص[] الوسائط)` فقط

### 2.3 الدوال الخارجية (FFI)

```bnf
extern_func    → 'خارجي' ['(' STRING ')'] 'دالة' [return_type] IDENTIFIER '(' param_list ')'
```

- بدون جسم (تصريح فقط)
- النص بين الأقواس هو اسم الربط الخارجي (FFI link name)

**المصدر:** `parser_declarations.cpp` → `parseExternFunctionDecl()`

### 2.4 تصريح المتغيرات

```bnf
var_decl       → ('متغير' | 'ثابت') IDENTIFIER [':' type] ['=' expression] [';']
               | type IDENTIFIER ['=' expression] [';']
               | class_name IDENTIFIER ['=' expression] [';']

multi_var_decl → var_decl (',' IDENTIFIER [':' type] ['=' expression])*
```

**الصيغ المدعومة:**

| الصيغة | المثال |
|--------|--------|
| كلمة مفتاحية مع قيمة | `متغير س = 10` |
| كلمة مفتاحية مع نوع | `متغير س: رقم = 10` |
| نوع أولاً | `رقم س = 10` |
| نوع صنف | `شخص ش = شخص()` أو `شخص ش = شخص() جديد` |
| متعدد بفاصلة | `متغير س = 1 ، ص = 2 ، ع = 3` |
| ثوابت | `ثابت باي = 3.14` |
| نوع كاسم متغير | `متغير نص = "مرحبا"` |

**المصدر:** `parser_declarations.cpp` → `parseVarDecl()`

### 2.5 تصريح التعداد (Enum)

```bnf
enum_decl      → 'تعداد' IDENTIFIER
                   enum_member*
                 'نهاية'

enum_member    → IDENTIFIER ['=' expression] [',']
```

- الفواصل اختيارية بين الأعضاء
- الأسطر الجديدة تفصل تلقائياً
- الكلمات المحجوزة مسموحة كأعضاء: `خارجي`، `عام`، `خاص`، `خطأ`، `صحيح`، `نص`، ...
- صيغة `{}` **مُزالة** — استخدم `نهاية` فقط

**المصدر:** `parser_declarations.cpp` → `parseEnumDecl()`

### 2.6 تصريح البنية (Struct)

```bnf
struct_decl    → 'بنية' IDENTIFIER
                   (struct_field | method_decl)*
                 'نهاية'

struct_field   → [type] IDENTIFIER ['=' expression] [';']
```

**المصدر:** `parser_declarations.cpp` → `parseStructDecl()`

### 2.7 تصريح الاختبار

```bnf
test_decl      → 'اختبر' '(' STRING ')' block
```

- الأقواس إلزامية
- اسم الاختبار يجب أن يكون نصاً
- `اختبر` كلمة **سياقية** (ليست محجوزة)
- يُميَّز عن استدعاء الدالة `اختبر()` بعدد الوسائط والسياق

**المصدر:** `parser_declarations.cpp` → `parseTestDecl()`

## 3. الجمل

### 3.1 جملة الشرط (إذا)

```bnf
if_stmt        → 'إذا' '(' expression ')' block
                 ('وإلا_إذا' '(' expression ')' block)*
                 ['وإلا' block]
                 'نهاية'
```

- الأقواس `()` حول الشرط **إلزامية**
- كلمة `اذا` (بدون همزة) مدعومة أيضاً
- الكتل تنتهي بـ `نهاية` أو `وإلا`/`وإلا_إذا`

**المصدر:** `parser_statements.cpp` → `parseIfStmt()`

### 3.2 حلقة بينما

```bnf
while_stmt     → 'بينما' '(' expression ')' block 'نهاية'
```

**المصدر:** `parser_statements.cpp` → `parseWhileStmt()`

### 3.3 حلقة لكل

```bnf
for_stmt       → 'لكل' IDENTIFIER [',' IDENTIFIER] 'في' expression block 'نهاية'
               | 'لكل' IDENTIFIER 'من' expression 'الى' expression block 'نهاية'
```

| الصيغة | المثال |
|--------|--------|
| تكرار على مجموعة | `لكل عنصر في القائمة` |
| تفكيك ثنائي | `لكل مفتاح ، قيمة في الخريطة` |
| نطاق رقمي | `لكل ع من 1 الى 10` |

**المصدر:** `parser_statements.cpp` → `parseForStmt()`

### 3.4 جملة حالة (Switch)

```bnf
switch_stmt    → 'حالة' expression
                   ('عندما' expression ':' body)*
                   ['افتراضي' ':' body]
                 'نهاية'
```

- الأقواس `()` **مُزالة** — استخدم `حالة تعبير` مباشرة
- النقطتان `:` اختيارية بعد القيمة
- كلمة `حالة` **سياقية** (ليست محجوزة)

**المصدر:** `parser_statements.cpp` → `parseSwitchStmt()`

### 3.5 جملة الإرجاع

```bnf
return_stmt    → 'ارجع' [expression] [';']
```

**المصدر:** `parser_statements.cpp` → `parseReturnStmt()`

### 3.6 جملة الإنتاج (Yield)

```bnf
yield_stmt     → 'أنتج' ['من'] [expression] [';']
```

- `أنتج من` = yield from (تفويض المولد)
- كلمة `أنتج` **سياقية**

**المصدر:** `parser_statements.cpp` → `parseYieldStmt()`

### 3.7 جملة باستخدام (Context Manager)

```bnf
with_stmt      → 'باستخدام' expression ['كـ' IDENTIFIER] block 'نهاية'
```

- كلمة `باستخدام` **سياقية**

**المصدر:** `parser_statements.cpp` → `parseWithStmt()`

### 3.8 جملة الإيقاف والاستمرار

```bnf
break_stmt     → 'توقف' [';']
continue_stmt  → 'استمر' [';']
```

### 3.9 جملة الرمي

```bnf
throw_stmt     → 'ارمي' expression [';']
```

### 3.10 الكتلة

```bnf
block          → statement* 'نهاية'
```

- الكتلة تنتهي بـ `نهاية` أو بكلمات مفتاحية تُنهي السياق (`وإلا`، `امسك`، `أخيراً`)
- صيغة `{}` **مُزالة** من اللغة بالكامل

## 4. التعبيرات

### 4.1 تسلسل الأسبقية (من الأدنى إلى الأعلى)

```bnf
expression     → pipeline

pipeline       → assignment ('|>' assignment)*

assignment     → ternary (('=' | ':=' | '+=' | '-=' | '*=' | '/=' | '%=' | '//=') ternary)*

ternary        → null_coalesce ('?' expression ':' ternary)?

null_coalesce  → logical_or ('??' logical_or)*

logical_or     → logical_and (('||' | 'أو') logical_and)*

logical_and    → bitwise_or (('&&' | 'و') bitwise_or)*

bitwise_or     → bitwise_xor ('|' bitwise_xor)*

bitwise_xor    → bitwise_and ('^' bitwise_and)*

bitwise_and    → equality ('&' equality)*

equality       → comparison (('==' | '!=') comparison)*

comparison     → range (('<' | '<=' | '>' | '>=' | 'في') range)*

range          → term ('..' term)?

term           → factor (('+' | '-' | '<<' | '>>') factor)*

factor         → unary (('*' | '/' | '//' | '%') unary)*

unary          → ('!' | 'ليس' | '-' | '++' | '--' | '~' | '&')? power

power          → postfix ('**' power)?

postfix        → primary (call | member_access | index | slice | increment)*
```

**المصدر:** `parser_expressions.cpp`

### 4.2 العوامل اللاحقة (Postfix)

```bnf
call           → '(' argument_list ')'
member_access  → '.' IDENTIFIER ['(' argument_list ')']
safe_access    → '?.' IDENTIFIER
index          → '[' expression ']'
slice          → '[' [start] ':' [end] [':' step] ']'
               | '[' start '..' end ']'
increment      → '++' | '--'
typed_map      → '{' key ':' value (',' key ':' value)* '}'
```

### 4.3 الاستدعاء والوسائط

```bnf
argument_list  → ε
               | argument ((',' | '،') argument)*

argument       → expression
               | IDENTIFIER ':' expression       # وسيطة مسماة (Named Argument)
```

- الوسائط المسماة: `دالة(اسم: "أحمد"، عمر: 25)`
- الفاصلة العربية `،` مدعومة

### 4.4 التعبيرات الأساسية (Primary)

```bnf
primary        → NUMBER_INTEGER | NUMBER_DOUBLE
               | STRING_LITERAL | STRING_RAW
               | LITERAL_TRUE | LITERAL_FALSE | LITERAL_NULL
               | IDENTIFIER
               | '(' expression ')'
               | if_expression
               | await_expression
               | new_expression
               | this_expression
               | super_expression
               | lambda_expression
               | fstring_expression
               | array_literal
               | map_literal
               | directive_expression
               | abs_expression
```

### 4.5 تعبير الشرط المضمن

```bnf
if_expression  → 'إذا' '(' expression ')' expression 'وإلا' expression
```

### 4.6 تعبير الانتظار

```bnf
await_expr     → 'انتظر' expression
```

- كلمة `انتظر` **سياقية**

### 4.7 تعبير جديد (New)

```bnf
new_expr       → 'جديد' IDENTIFIER ['<' type_args '>'] '(' argument_list ')'

type_args      → type (',' type)*
```

### 4.8 تعبير هذا والأساس

```bnf
this_expr      → 'هذا'
super_expr     → 'الأساس'
```

### 4.9 تعبير لامدا

```bnf
lambda_expr    → 'لامدا' '(' param_list ')' '=>' expression
               | 'لامدا' '(' param_list ')' '=>' block 'نهاية'
               | 'لامدا' '(' param_list ')' block 'نهاية'
```

- كلمة `لامدا` **سياقية**
- الأقواس حول المعاملات إلزامية دائماً

### 4.10 نص مُنسق (F-String)

```bnf
fstring        → f"text {expression} text"
```

- يُحوّل إلى: `"text " + نص(expression) + " text"`
- أقواس مُفلتة: `f"{{x}}"` → `"{x}"`

### 4.11 المصفوفات

```bnf
array_literal  → '[' ']'                                    # فارغة
               | '[' expression (',' expression)* ']'        # عادية
               | '[' expression 'for' IDENTIFIER 'in' expression ['if' expression] ']'  # comprehension
```

- الفاصلة الزائدة مسموحة: `[1, 2, 3,]`

### 4.12 الخرائط والمجموعات

```bnf
map_literal    → '{' '}'                                    # خريطة فارغة
               | '{' key ':' value (',' key ':' value)* '}' # خريطة عادية
               | '{' '...' expression (',' ...)* '}'         # spread

set_comp       → '{' expression 'for' IDENTIFIER 'in' expression ['if' expression] '}'

dict_comp      → '{' key ':' value 'for' IDENTIFIER 'in' expression ['if' expression] '}'
```

- دعم Spread Syntax: `{...كائن1, ...كائن2, مفتاح: قيمة}`

### 4.13 القيمة المطلقة

```bnf
abs_expr       → '|' expression '|'
```

- تُحوّل إلى: `abs(expression)`

### 4.14 عامل الأنابيب (Pipeline)

```bnf
pipeline       → expression '|>' expression
```

- يُحوّل إلى استدعاء دالة: `أ |> ب` → `ب(أ)`

### 4.15 عامل الإسناد (Walrus)

```bnf
walrus         → IDENTIFIER ':=' expression
```

- إسناد داخل تعبير (مثل Python)

## 5. البرمجة الكائنية (OOP)

### 5.1 تصريح الصنف

```bnf
class_decl     → 'صنف' IDENTIFIER ['يرث' base_class_list] ['نفّذ' trait_list]
                   class_member*
                 'نهاية'

base_class_list → IDENTIFIER (',' IDENTIFIER)*
trait_list      → IDENTIFIER (',' IDENTIFIER)*

class_member   → field_decl
               | method_decl
               | constructor_decl
               | destructor_decl
               | operator_decl
               | property_decl
               | const_field_decl
```

**المصدر:** `parser_declarations.cpp` → `parseClassDecl()`

### 5.2 الحقول

```bnf
field_decl     → [access_modifier] ['ساكن'] type IDENTIFIER ['=' expression] [';']
               | [access_modifier] 'متغير' IDENTIFIER [':' type] ['=' expression] [';']
               | [access_modifier] 'ثابت' IDENTIFIER ['=' expression] [';']

multi_field    → field_decl (',' IDENTIFIER [':' type] ['=' expression])*

access_modifier → 'عام' | 'خاص' | 'محمي'
```

**المصدر:** `parser_core_oop.cpp` → `parseFieldDeclaration()`

### 5.3 الطُرق

```bnf
method_decl    → [access_modifier] ['ساكن'] ['مجرد']
                 'دالة' ['ساكن'] ['غير_متزامن'] [return_type] IDENTIFIER '(' param_list ')'
                 (block | ';')
```

- الطرق المجردة ليس لها جسم
- `غير_متزامن` يأتي بعد `دالة` (الصفة بعد الموصوف)

**المصدر:** `parser_core_oop.cpp` → `parseMethodDeclaration()`

### 5.4 الباني (Constructor)

```bnf
constructor_decl → 'باني' '(' constructor_params ')' [':' super_call] block

constructor_params → parameter
                   | 'هذا' '.' IDENTIFIER ['=' expression]   # تعيين تلقائي
                   | parameter (',' parameter)*

super_call     → 'الأساس' '(' argument_list ')'
```

- صيغة `هذا.خاصية`: `باني(هذا.اسم, هذا.عمر)` — تُولّد تلقائياً `هذا.اسم = اسم`
- استدعاء الأساس: `باني(س) : الأساس(س)` أو `الأساس(س)` في بداية الجسم
- صيغة `الأساس.باني()` مدعومة أيضاً

**المصدر:** `parser_core_oop.cpp` → `parseConstructorDeclaration()`

### 5.5 الهدام (Destructor)

```bnf
destructor_decl → 'هدم' '(' ')' block
```

- بدون معاملات

**المصدر:** `parser_core_oop.cpp` → `parseDestructorDeclaration()`

### 5.6 الخصائص (Properties)

```bnf
property_decl  → 'خاصية' [type] IDENTIFIER
                   'احصل' getter_body 'نهاية'
                   ['عيّن' '(' IDENTIFIER ')' setter_body 'نهاية']
                 'نهاية'
```

- كلمات `خاصية` و`احصل` و`عيّن` **سياقية**

**المصدر:** `parser_core_oop.cpp` → `parsePropertyDeclaration()`

### 5.7 الصنف المجرد

```bnf
abstract_class → 'مجرد' 'صنف' IDENTIFIER ['يرث' base_class_list]
                   class_member*
                 'نهاية'
```

## 6. مطابقة الأنماط

### 6.1 جملة طابق (Match)

```bnf
match_stmt     → 'طابق' expression
                   case_clause+
                   ['افتراضي' ':' body]
                 'نهاية'

case_clause    → 'عندما' pattern ['إذا' expression] ':' body
```

- فقط `عندما` مقبولة (وليس `حالة`)
- دعم حارس الشرط (Guard): `عندما نمط إذا شرط:`
- `افتراضي` يُعامل كـ WildcardPattern

**المصدر:** `parser_advanced.cpp` → `parseMatchStmt()`

### 6.2 الأنماط

```bnf
pattern        → primary_pattern ('@' pattern)?          # نمط ربط
               | primary_pattern ('||' primary_pattern)*  # نمط OR
               | struct_pattern
               | list_pattern
               | primary_pattern

primary_pattern → NUMBER ['..' ['='] NUMBER]             # حرفي أو نطاق
               | STRING                                   # نصي
               | LITERAL_TRUE | LITERAL_FALSE             # منطقي
               | LITERAL_NULL                             # فارغ
               | IDENTIFIER ['.' IDENTIFIER]*             # متغير أو عضو تعداد
               | '_'                                      # شامل (Wildcard)
```

| نوع النمط | المثال | الوصف |
|-----------|--------|-------|
| حرفي | `عندما 42:` | مطابقة قيمة |
| نطاق | `عندما 1..10:` | مطابقة مجال |
| نطاق شامل | `عندما 1..=10:` | شامل النهاية |
| متغير | `عندما س:` | ربط قيمة |
| شامل | `عندما _:` | أي قيمة |
| OR | `عندما 1 \|\| 2:` | بدائل |
| ربط | `عندما ن @ 1..10:` | ربط + نمط |
| قائمة | `عندما [أ, ب]:` | تفكيك مصفوفة |
| قائمة مع باقي | `عندما [أ, *باقي]:` | مع rest |
| بنية | `عندما {اسم: س}:` | تفكيك كائن |
| عضو تعداد | `عندما لون.أحمر:` | تعداد مؤهل |
| افتراضي | `افتراضي:` | الحالة الافتراضية |

**المصدر:** `parser_advanced.cpp` → `parsePattern()`, `parsePrimaryPattern()`, `parseListPattern()`, `parseStructPattern()`

### 6.3 نمط القائمة

```bnf
list_pattern   → '[' ']'                                # فارغة
               | '[' pattern (',' pattern)* [',' '*' IDENTIFIER] ']'
```

- `*rest` لالتقاط العناصر الباقية

### 6.4 نمط البنية

```bnf
struct_pattern → '{' '}'
               | '{' field_pattern (',' field_pattern)* '}'

field_pattern  → IDENTIFIER ':' pattern
               | IDENTIFIER                             # اختصار: الاسم = المتغير
```

## 7. القوالب (Generics)

### 7.1 تصريح القالب

```bnf
template_decl  → 'قالب' '<' template_params '>' (template_function | template_class)

template_params → 'نوع' IDENTIFIER [':' constraints] (',' 'نوع' IDENTIFIER [':' constraints])*

constraints    → IDENTIFIER ('+' IDENTIFIER)*
```

- كلمة `قالب` **سياقية**
- كلمة `نوع` (typename) **سياقية**

**المصدر:** `parser_advanced.cpp` → `parseTemplateDecl()`, `parseTemplateParameters()`

### 7.2 دالة قالب

```bnf
template_function → 'دالة' IDENTIFIER '(' param_list ')' [return_type] [where_clause] block
```

### 7.3 صنف قالب

```bnf
template_class → 'صنف' IDENTIFIER ['يرث' base_list] [where_clause]
                   class_member*
                 'نهاية'
```

### 7.4 جملة حيث (Where Clause)

```bnf
where_clause   → 'حيث' constraint_item (',' constraint_item)*

constraint_item → IDENTIFIER ['.' IDENTIFIER] ':' constraints
```

- كلمة `حيث` **سياقية**

### 10.6 الماكروز (Macros)

```bnf
macro_decl     → 'ماكرو' IDENTIFIER '(' macro_params ')' macro_body 'نهاية'

macro_params   → ε
               | macro_param ((',' | '،') macro_param)*

macro_param    → IDENTIFIER
               | '...' IDENTIFIER    # معامل متغير (يجب أن يكون الأخير)

macro_body     → declaration*

macro_call     → IDENTIFIER '!' '(' argument_list ')'
```

**ملاحظات:**
- كلمة `ماكرو` **سياقية** — تعمل كمُعرّف عادي خارج سياقها
- الاستدعاء يتطلب علامة `!` بعد الاسم: `سجّل!("رسالة")`
- المعامل المتغير `...اسم` يجمع الوسائط الزائدة في مصفوفة ويجب أن يكون الأخير
- جملة `ارجع` داخل الماكرو تُرجع قيمة (ماكرو تعبيري): `متغير ن = أكبر!(5، 3)`
- **أمان النطاق (Hygiene):** المتغيرات المُعرّفة داخل الماكرو لا تُلوّث النطاق الخارجي (نطاق `FUNCTION`)
- **النسخ للخلف:** إذا كان الوسيط متغيراً، تُنسخ التعديلات تلقائياً بعد التنفيذ
- **التقييم المسبق:** جميع الوسائط تُقيَّم في نطاق المُستدعي **قبل** الدخول لنطاق الماكرو — يضمن صحة التداخل
- **التداخل:** يمكن استدعاء ماكرو من داخل ماكرو آخر بأمان كامل
- الماكرو يجب تعريفه **قبل** استخدامه (لا يوجد رفع/hoisting)

**المصدر:** `parser_declarations.cpp` → `parseMacroDecl()`
**استدعاء:** `parser_expressions.cpp` → `parsePostfix()` (كشف `!()` بعد الاسم)

### 10.8 تعليقات العمر (Lifetime Annotations)

```bnf
lifetime_params → '<' LIFETIME (',' LIFETIME)* '>'
LIFETIME        → "'" IDENTIFIER

# الأعمار في الدوال: دالة اسم<'أ، 'ب>(معاملات) ... نهاية
function_decl   → 'دالة' NAME lifetime_params? '(' param_list ')' block 'نهاية'

# الأعمار في البنى: بنية اسم<'أ> ... نهاية
struct_decl     → 'بنية' NAME lifetime_params? field_list 'نهاية'

# استعارة مع عمر: &'أ متغير
borrow_expr     → '&' LIFETIME? expression
```

**أمثلة:**
```sad
# دالة بمعامل عمر واحد
دالة أطول<'أ>(س، ص)
    إذا (طول(س) > طول(ص))
        ارجع س
    وإلا
        ارجع ص
    نهاية
نهاية

# دالة بعدة معاملات عمر
دالة دمج<'أ، 'ب>(أول، ثاني)
    ارجع أول + " و " + ثاني
نهاية

# بنية مع عمر
بنية مرجع<'أ>
    رقم معرف = 0
نهاية

# استعارة مع تعليق عمر
متغير س = 42
متغير م = &'أ س
```

**ملاحظات:**
- الأعمار تبدأ بفاصلة عليا `'` متبوعة باسم عربي أو لاتيني (مثل: `'أ`، `'ثابت`، `'_`)
- المفسر يقبل الصيغة ويخزنها في AST لكن لا يفرض قيودها — الفرض يتم في المترجم `sadc`
- `'_` عمر مجهول (wildcard)، `'ثابت` عمر ثابت (static lifetime)
- الأعمار تُعرَّف بين `<` و `>` بعد اسم الدالة أو البنية مباشرة
- الفاصلة العربية `،` أو اللاتينية `,` تُستخدم للفصل بين عدة أعمار

**المصدر:** `parser_declarations.cpp` → `parseLifetimeParams()`, `parseFunctionDecl()`, `parseStructDecl()`

### 10.9 العقود البرمجية (Design by Contract)

```bnf
# الشرط المسبق (precondition) — يُفحص قبل تنفيذ الدالة
precondition    → 'يتطلب' expression

# الشرط اللاحق (postcondition) — يُفحص بعد تنفيذ الدالة
postcondition   → 'يضمن' expression

# الدالة مع عقود:
function_decl   → 'دالة' NAME lifetime_params? '(' param_list ')'
                  precondition*
                  postcondition*
                  where_constraint*
                  block
                  'نهاية'
```

**أمثلة:**
```sad
# شرط مسبق: يتطلب
دالة قسمة(أ، ب)
    يتطلب ب != 0
    ارجع أ / ب
نهاية

# شرط لاحق: يضمن (النتيجة = القيمة المُرجعة)
دالة قيمة_مطلقة(ن)
    يضمن النتيجة >= 0
    إذا (ن < 0)
        ارجع ن * -1
    نهاية
    ارجع ن
نهاية

# يتطلب + يضمن معاً
دالة مستطيل(عرض، ارتفاع)
    يتطلب عرض > 0
    يتطلب ارتفاع > 0
    يضمن النتيجة > 0
    ارجع عرض * ارتفاع
نهاية
```

**ملاحظات:**
- `يتطلب` و `يضمن` كلمات **سياقية** — يمكن استخدامها كأسماء متغيرات خارج سياق الدالة
- الشرط المسبق يُقيَّم قبل تنفيذ جسم الدالة — إذا فشل يُرمى `RuntimeError`
- الشرط اللاحق يُقيَّم بعد تنفيذ جسم الدالة — المتغير `النتيجة` يحمل القيمة المُرجعة
- يمكن وضع عدة شروط `يتطلب` وعدة شروط `يضمن` في نفس الدالة
- يمكن الجمع مع الأعمار والقيود: `دالة اسم<'أ>(معاملات) يتطلب ... يضمن ... حيث ...`

**المصدر:** `parser_declarations.cpp` → `parseFunctionDecl()`, `expression_evaluator_calls.cpp`

# قيود مع عقود برمجية

### 10.11 العقود الذكية (Smart Contracts)

```bnf
contract_decl   → 'عقد' IDENTIFIER inheritance? class_body 'نهاية'
inheritance     → 'يرث' IDENTIFIER
```

**أمثلة:**
```sad
# عقد ذكي بسيط
عقد محفظة
    متغير عام رصيد
    متغير عام مالك

    باني(مالك_جديد، رصيد_ابتدائي)
        هذا.مالك = مالك_جديد
        هذا.رصيد = رصيد_ابتدائي
    نهاية

    دالة عام إيداع(مبلغ)
        إذا (مبلغ > 0)
            هذا.رصيد = هذا.رصيد + مبلغ
        نهاية
    نهاية

    دالة عام سحب(مبلغ)
        إذا (مبلغ > 0 و مبلغ <= هذا.رصيد)
            هذا.رصيد = هذا.رصيد - مبلغ
            ارجع صحيح
        نهاية
        ارجع خطأ
    نهاية
نهاية

# عقد يرث من عقد آخر
عقد عقد_أساسي
    متغير عام اسم
    باني(اسم_عقد)
        هذا.اسم = اسم_عقد
    نهاية
نهاية

عقد عقد_تصويت يرث عقد_أساسي
    متغير عام أصوات
    باني(اسم)
        الأساس(اسم)
        هذا.أصوات = 0
    نهاية
    
    دالة عام صوّت()
        هذا.أصوات = هذا.أصوات + 1
    نهاية
نهاية
```

**ملاحظات:**
- `عقد` كلمة **سياقية** — يمكن استخدامها كاسم متغير خارج سياقها
- `عقد` يعمل تماماً مثل `صنف` لكن مع علامة `isContract = true` في AST
- يدعم كل ميزات الأصناف: الباني، الوراثة، المتغيرات، الدوال، مستويات الوصول
- الهدف: التمييز الدلالي بين الأصناف العادية والعقود الذكية — لدعم قواعد خاصة لاحقاً
- يمكن إنشاء كائنات منه بـ `جديد` كأي صنف عادي

**المصدر:** `parser_core_main.cpp` → dispatch `عقد`, `declarations.h` → `ClassDecl.isContract`

### 10.12 اختبار الخصائص (Property Testing)

```bnf
# اختبار عادي
test_decl       → 'اختبر' '(' STRING ')' block 'نهاية'

# اختبار خصائص — يتكرر N مرة
property_test   → 'اختبر' '(' STRING ')' property_config* block 'نهاية'
property_config → 'تكرارات' NUMBER
                | 'بذرة' NUMBER
                | 'حد_أقصى' NUMBER
```

**أمثلة:**
```sad
# اختبار عادي
اختبر("جمع بسيط")
    إذا (3 + 5 != 8)
        ارمي "خطأ!"
    نهاية
نهاية

# اختبار خصائص — يتكرر 100 مرة
اختبر("خاصية الجمع التبادلي") تكرارات 100
    متغير أ = _تكرار + 1
    متغير ب = _تكرار * 2
    إذا (أ + ب != ب + أ)
        ارمي "ليس تبادلياً!"
    نهاية
نهاية

# اختبار مع بذرة لنتائج قابلة للإعادة
اختبر("خاصية مع بذرة") تكرارات 50 بذرة 42
    # _تكرار: الفهرس (0..N-1)
    # _التكرار_الحالي: الرقم (1..N)
    # _إجمالي_التكرارات: المجموع
    # _بذرة: البذرة العشوائية
نهاية
```

**ملاحظات:**
- `تكرارات`، `بذرة`، `حد_أقصى` كلمات **سياقية** — تأتي بعد `)` وقبل جسم الاختبار
- المفسر يكرر الجسم N مرة مع متغيرات خاصة: `_تكرار`، `_التكرار_الحالي`، `_إجمالي_التكرارات`، `_بذرة`
- إذا `تكرارات = 0` أو غير محددة → اختبار عادي (تشغيل مرة واحدة)
- النتيجة تُعرض: `✓ اسم (N/N تكرار نجح)` أو `✗ اسم (M/N تكرار فشل)`

**المصدر:** `parser_declarations.cpp` → `parseTestDecl()`, `statement_executor_oop.cpp` → `visitTestDecl()`

### 10.14 تنفيذ قيود الأنواع في وقت التشغيل (Runtime Where Constraints)

عند استدعاء دالة بقيود `حيث`، يتحقق المفسر من أن الوسائط تحقق السمات المطلوبة:

| السمة | الفحص | ترفض |
|-------|-------|------|
| `رقمي` / `Numeric` | `isInteger()` أو `isDouble()` | نص، مصفوفة، كائن |
| `نصي` / `Textual` | `isString()` | رقم، مصفوفة، كائن |
| `قابل_للمقارنة` / `Comparable` | `isNumeric()` أو `isString()` | مصفوفة، كائن |
| سمة مجهولة | لا فحص (معلوماتية) | لا شيء |

**مثال:**
```sad
دالة مضاعفة(أ)
    حيث ت: رقمي
    ارجع أ * 2
نهاية

مضاعفة(5)      # ✓ نجح
مضاعفة("نص")   # ✗ RuntimeError: فشل قيد النوع
```

**المصدر:** `expression_evaluator_calls.cpp` → فحص where constraints قبل تنفيذ جسم الدالة

### 10.15 قواعد وراثة العقود الذكية (Contract Inheritance Rules)

العقد الذكي (`عقد`) لا يمكنه الوراثة من صنف عادي (`صنف`). يجب أن يرث فقط من عقد آخر:

```sad

    متغير عام رصيد
نهاية

عقد متقدم يرث أساسي    # ✓ مسموح — عقد يرث عقد
نهاية

صنف عادي
نهاية

عقد خاطئ يرث عادي       # ✗ RuntimeError — عقد لا يرث من صنف عادي
نهاية
```

**المصدر:** `statement_executor_oop.cpp` → `visitClassDecl()` → فحص `isContract` على الأصناف الأساسية

### 10.16 متغيرات اختبار الخصائص المحسّنة (Enhanced Property Test Variables)

| المتغير | القيمة | الوصف |
|---------|--------|-------|
| `_تكرار` | 0..N-1 | فهرس التكرار |
| `_التكرار_الحالي` | 1..N | رقم التكرار (1-based) |
| `_إجمالي_التكرارات` | N | عدد التكرارات الكلي |
| `_بذرة` | seed+i | بذرة التكرار |
| `_عشوائي` | 0.0..~1.0 | قيمة عشوائية عشرية (LCG) |
| `_عشوائي_صحيح` | 0..999 | عدد صحيح عشوائي |
| `_عشوائي_سالب` | -1000..1000 | عدد صحيح عشوائي (سالب أو موجب) |

## 11. تحميل العوامل الزائد

```bnf
operator_decl  → 'عامل' operator_symbol '(' param_list ')' [return_type] block

operator_symbol → '+' | '-' | '*' | '/' | '//' | '%' | '**'
                | '==' | '!=' | '<' | '>' | '<=' | '>='
                | '^' | '&' | '|' | '<<' | '>>'
                | '[]' | '[]=' | '()'
                | 'نص' | 'رقم' | 'منطقي'
```

| العامل | النوع | المثال |
|--------|-------|--------|
| `+` `-` `*` `/` | حسابي ثنائي | `عامل +(آخر) ... نهاية` |
| `u-` `u+` | حسابي أحادي | `عامل -() ... نهاية` (بدون معاملات) |
| `//` `%` `**` | حسابي إضافي | `عامل //(آخر) ... نهاية` |
| `==` `!=` | مساواة | `عامل ==(آخر) ... نهاية` |
| `<` `>` `<=` `>=` | مقارنة | `عامل <(آخر) ... نهاية` |
| `^` `&` `\|` | بتي | `عامل ^(آخر) ... نهاية` |
| `<<` `>>` | إزاحة | `عامل <<(آخر) ... نهاية` |
| `[]` | فهرسة | `عامل [](دليل) ... نهاية` |
| `[]=` | إسناد فهرسة | `عامل []=(دليل، قيمة) ... نهاية` |
| `()` | استدعاء | `عامل ()(وسائط) ... نهاية` |
| `نص` | تحويل نصي | `عامل نص() ... نهاية` |
| `رقم` | تحويل رقمي | `عامل رقم() ... نهاية` |
| `منطقي` | تحويل منطقي | `عامل منطقي() ... نهاية` |

- `عامل` كلمة **سياقية**
- العوامل الأحادية تُتعرف تلقائياً عند عدم وجود معاملات
- نوع الإرجاع يأتي مباشرة بعد `)` (بدون سهم `->`)

**المصدر:** `parser_advanced.cpp` → `parseOperatorDecl()`

## 12. التوجيهات والمُزخرِفات

### 12.1 التوجيهات (@)

```bnf
directive      → '@' 'حجم' '(' type ')'
               | '@' 'ذري' '(' op_name (',' expression)* ')'
               | '@' 'تجميع' '(' STRING ')'
               | '@' 'غير_آمن' block 'نهاية'
               | '@' 'وقت_الترجمة' block 'نهاية'
               | '@' 'متطاير' var_decl
```

### 12.2 المُزخرِفات (Decorators)

```bnf
decorator      → '@' IDENTIFIER ['(' argument_list ')']
```

- مثال: `@خاصية` أو `@مُؤقت(30)`
- تُرفق بالتصريح التالي (دالة، صنف، إلخ)

**المصدر:** `parser_advanced.cpp` → `parseDecorator()`

## ملاحظات عامة

### الفواصل والمنقوطات
- الفاصلة العربية `،` والإنجليزية `,` **متكافئتان** تماماً
- المنقوطة العربية `؛` والإنجليزية `;` **متكافئتان** تماماً
- المنقوطة **اختيارية** في جميع المواضع (لغة تعتمد على الأسطر)

### الكتل
- جميع الكتل تنتهي بكلمة `نهاية` فقط
- صيغة `{}` **مُزالة** بالكامل
- تُوفر رسائل خطأ واضحة عند استخدام `{}`

### الكلمات المحجوزة مقابل السياقية

| النوع | الأمثلة | السلوك |
|-------|---------|--------|
| **محجوزة** (40 كلمة) | `دالة`، `صنف`، `إذا`، `بينما`، `نهاية`، ... | لا يمكن استخدامها كأسماء متغيرات |
| **سياقية** | `غير_متزامن`، `لامدا`، `سمة`، `نفّذ`، `عامل`، `خاصية`، `امتداد`، `ماكرو`، `يتطلب`، `يضمن`، `حيث`، `عقد`، ... | تعمل كمُعرّفات عادية خارج سياقها |
| **أنواع مدمجة** | `رقم`، `نص`، `منطقي`، `مصفوفة`، `خريطة`، ... | يمكن استخدامها كأسماء متغيرات |

### نظام الأخطاء
- رسائل خطأ **ثنائية اللغة** (عربية + إنجليزية)
- اقتراحات **ذكية** مع أمثلة تصحيحية
- نظام **تعافي** من الأخطاء لمتابعة التحليل بعد الخطأ
- كشف أخطاء المسافات في الأسماء: `متغير عدد طلاب` → `متغير عدد_طلاب`

### ترميز UTF-8
- جميع الأسماء والمُعرّفات تدعم العربية والإنجليزية
- ملفات المصدر بامتداد `.ص`
