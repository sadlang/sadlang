# المتغيرات وأنواع البيانات في لغة ص

## نظرة عامة

لغة ص تدعم نظام أنواع مرن يجمع بين التصريح الصريح والاستنتاج التلقائي للأنواع. يمكنك تعريف المتغيرات بعدة طرق مختلفة حسب احتياجك.

---

## طرق تعريف المتغيرات

### الطريقة الأولى: باستخدام `متغير`

الطريقة الأكثر شيوعاً. يتم استنتاج النوع تلقائياً من القيمة المُسندة.

```sad
متغير الاسم = "أحمد"
متغير العمر = 25
متغير المعدل = 3.85
متغير نشط = صحيح
```

### الطريقة الثانية: التصريح بالنوع مباشرة

يمكنك تحديد النوع صراحةً عند التعريف:

```sad
رقم العدد = 42
نص الاسم = "سارة"
عشري المعدل = 3.14
منطقي فعال = صحيح
```

### الطريقة الثالثة: باستخدام `ثابت`

لتعريف قيم لا يمكن تغييرها بعد الإسناد الأول:

```sad
ثابت باي = 3.14159
ثابت الاسم = "لغة ص"
ثابت الحد_الأقصى = 100
```

### الطريقة الرابعة: باستخدام `دع`

بديل مختصر لـ `متغير`:

```sad
دع س = 10
دع اسم = "محمد"
```

## أنواع البيانات الأساسية

| النوع | الكلمة المفتاحية | الوصف | مثال |
|-------|-----------------|-------|------|
| عدد صحيح | `رقم` | أعداد صحيحة بدون فاصلة عشرية | `42`، `-7`، `0` |
| عدد عشري | `عشري` | أعداد بفاصلة عشرية | `3.14`، `-0.5` |
| نص | `نص` | سلسلة أحرف | `"مرحباً"` |
| منطقي | `منطقي` | قيمة صحيح/خطأ | `صحيح`، `خطأ` |
| مصفوفة | `مصفوفة` | قائمة مرتبة من القيم | `[1، 2، 3]` |
| خريطة | `خريطة` | أزواج مفتاح-قيمة | `{"اسم": "أحمد"}` |
| عدم/لاشيء | `لاشيء` | قيمة فارغة | `لاشيء` |

## القيم المنطقية

| القيمة | الوصف |
|--------|-------|
| `صحيح` | القيمة المنطقية الإيجابية (true) |
| `خطأ` | القيمة المنطقية السلبية (false) |

## القيمة الفارغة

```sad
متغير بيانات = لاشيء
```

---

## التحويل بين الأنواع

| الدالة | الوصف | مثال |
|--------|-------|------|
| `لرقم(قيمة)` أو `إلى_رقم(قيمة)` | تحويل إلى عدد صحيح | `لرقم("42")` → `42` |
| `لعشري(قيمة)` أو `إلى_عشري(قيمة)` | تحويل إلى عدد عشري | `لعشري("3.14")` → `3.14` |
| `لنص(قيمة)` أو `إلى_نص(قيمة)` | تحويل إلى نص | `لنص(42)` → `"42"` |

---

## الثوابت مقابل المتغيرات

- **`متغير`**: يمكن تغيير قيمته في أي وقت.
- **`ثابت`**: لا يمكن تغيير قيمته بعد الإسناد الأول. محاولة تغييره تُنتج خطأ.

```sad
متغير عداد = 0
عداد = عداد + 1    # ✅ مسموح

ثابت الحد = 100
الحد = 200          # ❌ خطأ: لا يمكن تعديل ثابت
```

---

## ملاحظات مهمة

1. أسماء المتغيرات يمكن أن تكون **عربية أو إنجليزية** أو مزيج منهما.
2. الفاصلة العربية `،` والإنجليزية `,` كلاهما مدعوم.
3. لا يُشترط وضع فاصلة منقوطة في نهاية السطر.
4. يتم استنتاج النوع تلقائياً عند استخدام `متغير` أو `دع`.
