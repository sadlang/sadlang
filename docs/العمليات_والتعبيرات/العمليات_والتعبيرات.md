# العمليات والتعبيرات في لغة ص

## نظرة عامة

لغة ص توفر مجموعة شاملة من العمليات (Operators) تشمل العمليات الحسابية، المقارنات، العمليات المنطقية، عمليات البت، وعمليات خاصة. تدعم اللغة كلاً من الرموز العالمية والكلمات المفتاحية العربية للعمليات المنطقية.

---

## العمليات الحسابية

| العامل | الوصف | مثال | النتيجة |
|--------|-------|------|---------|
| `+` | جمع | `5 + 3` | `8` |
| `-` | طرح | `10 - 4` | `6` |
| `*` | ضرب | `6 * 7` | `42` |
| `/` | قسمة | `15 / 4` | `3.75` |
| `%` | باقي القسمة | `17 % 5` | `2` |
| `**` | الأُس (الرفع إلى قوة) | `2 ** 10` | `1024` |

---

## عمليات المقارنة

| العامل | الوصف | مثال |
|--------|-------|------|
| `==` | يساوي | `5 == 5` → `صحيح` |
| `!=` | لا يساوي | `5 != 3` → `صحيح` |
| `>` | أكبر من | `10 > 5` → `صحيح` |
| `<` | أصغر من | `3 < 7` → `صحيح` |
| `>=` | أكبر من أو يساوي | `5 >= 5` → `صحيح` |
| `<=` | أصغر من أو يساوي | `3 <= 7` → `صحيح` |

---

## العمليات المنطقية

تدعم لغة ص **طريقتين** للعمليات المنطقية:

### الطريقة الأولى: الرموز

| العامل | الوصف | مثال |
|--------|-------|------|
| `&&` | و (AND) | `صحيح && خطأ` → `خطأ` |
| `\|\|` | أو (OR) | `صحيح \|\| خطأ` → `صحيح` |
| `!` | نفي (NOT) | `!صحيح` → `خطأ` |

### الطريقة الثانية: الكلمات العربية

| الكلمة | الوصف | مثال |
|--------|-------|------|
| `و` | و (AND) | `صحيح و خطأ` → `خطأ` |
| `أو` | أو (OR) | `صحيح أو خطأ` → `صحيح` |
| `ليس` | نفي (NOT) | `ليس صحيح` → `خطأ` |

---

## عمليات الإسناد

| العامل | الوصف | مثال | المكافئ |
|--------|-------|------|---------|
| `=` | إسناد | `س = 10` | — |
| `+=` | جمع وإسناد | `س += 5` | `س = س + 5` |
| `-=` | طرح وإسناد | `س -= 3` | `س = س - 3` |
| `*=` | ضرب وإسناد | `س *= 2` | `س = س * 2` |
| `/=` | قسمة وإسناد | `س /= 4` | `س = س / 4` |

---

## عمليات الزيادة والنقصان

| العامل | الوصف | مثال |
|--------|-------|------|
| `++` | زيادة بمقدار 1 | `س++` |
| `--` | نقصان بمقدار 1 | `س--` |

---

## عمليات البت (Bitwise)

| العامل | الوصف | مثال |
|--------|-------|------|
| `&` | AND ثنائي | `5 & 3` → `1` |
| `\|` | OR ثنائي | `5 \| 3` → `7` |
| `^` | XOR ثنائي | `5 ^ 3` → `6` |
| `~` | NOT ثنائي (قلب البتات) | `~5` |
| `<<` | إزاحة لليسار | `1 << 3` → `8` |
| `>>` | إزاحة لليمين | `8 >> 2` → `2` |

---

## العامل الثلاثي (Ternary)

```sad
متغير النتيجة = شرط ? قيمة_إذا_صحيح : قيمة_إذا_خطأ
```

مثال:
```sad
متغير العمر = 20
متغير الحالة = العمر >= 18 ? "بالغ" : "قاصر"
```

---

## عامل النطاق (Range)

```sad
متغير نطاق = 1..10    # ينشئ مصفوفة [1, 2, 3, ..., 10]
```

---

## عامل العضوية (in)

```sad
إذا ("أحمد" في الأسماء)
    اطبع_سطر("موجود")
نهاية
```
