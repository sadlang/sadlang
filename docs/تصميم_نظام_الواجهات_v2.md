## 1. الرؤية والأهداف

### الرؤية
نظام واجهات **تصريحي عربي** مدمج في لغة ص، يُكتب بصيغة طبيعية تتسق تماماً مع
قواعد اللغة (كتل بـ `نهاية`، بدون `{}`). مستوحى من Flutter + SwiftUI، لكن بهوية عربية.

### الأهداف
- **نمط واحد فقط** — التصريحي مع Modifier Chain — لا OOP بأصناف، لا قواميس خام
- **تصفير الفجوة** مع Flutter — كل widget رئيسي في Flutter له مقابل عربي
- **دعم RTL أصلي** — اتجاه يمين→يسار افتراضي
- **متعدد المنصات** — Desktop (SDL2), Web (HTML/CSS), Android (Compose), iOS (SwiftUI)
- **أداء عالي** — Reconciler ذكي + تخطيط Flexbox + رسم تزايدي

### المبادئ التصميمية
1. **كل شيء عنصر** — النص عنصر، الحشوة عنصر، المحاذاة عنصر
2. **التكوين فوق الوراثة** — عناصر صغيرة تتكوّن لبناء واجهات معقدة
3. **متسق مع لغة ص** — كلمات عربية، كتل بـ `نهاية`، لا أقواس `{}`
4. **تفاعلي بالتصميم** — `@حالة` + إعادة بناء تلقائية عند التغيير

## 3. الصيغة النحوية الجديدة

### 3.1 قاعدة تعريف الواجهة

```bnf
# ═══════════════════════════════════════════════════════════
# واجهة = صنف خاص بنمط Flutter Widget
# ═══════════════════════════════════════════════════════════

واجهة_decl     → 'واجهة' IDENTIFIER ['يرث' IDENTIFIER]
                  واجهة_body
                  'نهاية'

واجهة_body     → (state_decl | method_decl)*

# ═══════════════════════════════════════════════════════════
# تصريح الحالة — @مزخرف + متغير
# ═══════════════════════════════════════════════════════════

state_decl     → '@حالة' [type] IDENTIFIER ['=' expression]
               | '@ربط' [type] IDENTIFIER
               | '@بيئة' [type] IDENTIFIER
               | '@محسوب' IDENTIFIER '=' expression

# ═══════════════════════════════════════════════════════════
# دوال الواجهة
# ═══════════════════════════════════════════════════════════

method_decl    → 'دالة' IDENTIFIER '(' [params] ')' block
               # أهمها: دالة بناء() — تُرجع شجرة عناصر
```

**ملاحظة:** `واجهة` كلمة **سياقية** — تعمل كمُعرّف عادي خارج سياقها.

### 3.2 تعبيرات العناصر (UI Expressions)

داخل `دالة بناء()`, يُسمح باستخدام **تعبيرات عناصر** — شجرة عناصر تُرجع قيمة:

```bnf
# ═══════════════════════════════════════════════════════════
# تعبير عنصر — يُستخدم داخل دالة بناء()
# ═══════════════════════════════════════════════════════════

widget_expr    → widget_call modifier_chain? children_block?

# استدعاء عنصر (دالة تُنشئ عنصر UI)
widget_call    → WIDGET_NAME '(' [arg_list] ')'    # مع وسائط
               | WIDGET_NAME                         # بدون وسائط (للحاويات)

# سلسلة معدّلات — method chaining
modifier_chain → ('.' IDENTIFIER '(' arg_list ')')*          # معدّل بقيمة
               | ('.' IDENTIFIER '=>' expression)*             # حدث سطر واحد
               | ('.' IDENTIFIER block)*                       # حدث متعدد الأسطر

# كتلة أبناء — بين اسم الحاوية و نهاية
children_block → NEWLINE widget_expr* 'نهاية'

# قائمة الوسائط — تدعم المعاملات المسماة
arg_list       → arg (',' arg)*
arg            → expression                          # موضعي
               | IDENTIFIER ':' expression            # مسمّى
```

### 3.3 قواعد `نهاية` في سياق الواجهات

| السياق | يحتاج `نهاية`؟ | مثال |
|--------|----------------|------|
| واجهة | نعم | `واجهة عداد ... نهاية` |
| دالة بناء | نعم | `دالة بناء() ... نهاية` |
| حاوية بأبناء | نعم | `عمود ... نهاية` |
| حدث متعدد الأسطر | نعم | `.عند_النقر ... نهاية` |
| عنصر ورقي | لا | `نص("مرحبا")` |
| معدّل بقيمة | لا | `.حجم(32)` |
| حدث سطر واحد | لا | `.عند_النقر => عدد += 1` |

### 3.4 مثال كامل على الصيغة

```sad
استورد رسومات

واجهة قائمة_مهام
    @حالة مهام: مصفوفة = []
    @حالة نص_جديد: نص = ""

    دالة بناء()
        ارجع هيكل
            .شريط(شريط_تطبيق(عنوان: "مهامي"))
            .جسم(
                عمود
                    .حشوة(16)
                    .تباعد(8)

                    # حقل إدخال + زر إضافة
                    صف
                        .تباعد(8)

                        حقل_نص(تلميح: "مهمة جديدة...")
                            .قيمة(نص_جديد)
                            .عند_التغيير => نص_جديد = القيمة
                            .موسع(صحيح)

                        زر("أضف")
                            .لون_خلفية(.أزرق)
                            .عند_النقر
                                إذا (نص_جديد != "")
                                    مهام.أضف(نص_جديد)
                                    نص_جديد = ""
                                نهاية
                            نهاية
                    نهاية

                    فاصل_خط()

                    # قائمة المهام
                    عمود_كسول(عناصر: مهام)
                        .بنّاء(لامدا(مهمة, فهرس)
                            ارجع بطاقة
                                .حشوة(12)
                                .هامش(4)

                                صف
                                    نص(مهمة)
                                        .حجم(16)
                                        .موسع(صحيح)

                                    زر_أيقونة("حذف")
                                        .لون(.أحمر)
                                        .عند_النقر => مهام.احذف(فهرس)
                                نهاية
                            نهاية
                        نهاية)
                نهاية
            )
        نهاية
    نهاية
نهاية

دالة رئيسية()
    تشغيل_تطبيق(قائمة_مهام())
نهاية
```

## 6. نظام المعدّلات (Modifier Chain)

### 6.1 المبدأ

كل عنصر يُرجع **نفسه** بعد تطبيق كل معدّل — يتيح التسلسل:

```sad
نص("مرحبا")
    .حجم(32)           # → يُرجع نفس العنصر بعد تعيين الحجم
    .لون(.أزرق)        # → يُرجع نفس العنصر بعد تعيين اللون
    .وزن(.عريض)        # → يُرجع نفس العنصر بعد تعيين الوزن
    .حشوة(16)          # → يُرجع نفس العنصر بعد إضافة حشوة
```

### 6.2 معدّلات الألوان

| العربي | الوصف | المثال |
|--------|-------|--------|
| `.لون(لون)` | لون المحتوى (نص/أيقونة) | `.لون(.أزرق)` |
| `.لون_خلفية(لون)` | لون الخلفية | `.لون_خلفية(.أبيض)` |
| `.لون_صبغة(لون)` | لون الصبغة | `.لون_صبغة(.أخضر)` |
| `.تدرج(...)` | تدرج لوني | `.تدرج(.خطي، [.أزرق, .أخضر])` |

### 6.3 معدّلات النص

| العربي | الوصف | المثال |
|--------|-------|--------|
| `.حجم(رقم)` | حجم الخط | `.حجم(24)` |

## 7. نظام الحالة التفاعلي

### 7.1 `@حالة` — حالة محلية

```sad
واجهة عداد
    @حالة عدد: رقم = 0        # حالة محلية — يملكها هذا المكون

    دالة بناء()
        ارجع نص("العدد: " + عدد)
            .حجم(48)
    نهاية
نهاية
```

عند تعيين قيمة جديدة لـ `عدد`, يُعاد استدعاء `بناء()` تلقائياً.

### 7.2 `@ربط` — مرجع لحالة في الأب

```sad
واجهة مكون_ابن
    @ربط قيمة: رقم             # مرجع — يعدّله الابن، يتأثر الأب

    دالة بناء()
        ارجع زر("زيادة")
            .عند_النقر => قيمة += 1
    نهاية
نهاية

واجهة مكون_أب
    @حالة عدد: رقم = 0

    دالة بناء()
        ارجع عمود
            نص("العدد: " + عدد)
            مكون_ابن(قيمة: عدد)    # يُمرر كربط
        نهاية
    نهاية
نهاية
```

### 7.3 `@بيئة` — حالة عالمية مشتركة

```sad
واجهة شريط_العنوان
    @بيئة سمة: نص               # يقرأ السمة العالمية (فاتح/داكن)

    دالة بناء()
        ارجع شريط_تطبيق(عنوان: "تطبيقي")
            .لون_خلفية(إذا (سمة == "داكن") .رمادي_غامق وإلا .أزرق)
    نهاية
نهاية
```

### 7.4 `@محسوب` — قيمة مشتقة

```sad
واجهة سلة_تسوق
    @حالة عناصر: مصفوفة = []
    @محسوب المجموع = عناصر.اختزل(0, لامدا(مج, ع) => مج + ع.سعر نهاية)

    دالة بناء()
        ارجع نص("المجموع: " + المجموع + " ₪")
    نهاية
نهاية
```

### 7.5 آلية عمل الحالة (تحت الغطاء)

```
1. @حالة عدد: رقم = 0
   → ينشئ StateEntry { name: "عدد", value: 0, observers: [] }

2. دالة بناء() → نص("العدد: " + عدد)
   → يقرأ عدد → يسجّل هذا المكون كمُراقب لـ "عدد"

3. .عند_النقر => عدد += 1
   → يُعدّل StateEntry.value = 1
   → يُخطر جميع المراقبين
   → يُعيد استدعاء بناء() لهذا المكون فقط

4. Reconciler يُقارن:
   الشجرة القديمة: نص("العدد: 0") .حجم(48)
   الشجرة الجديدة: نص("العدد: 1") .حجم(48)
   → يُحدّث فقط محتوى النص — لا يُعيد رسم الصفحة كاملة
```

## 14. آلية التعرف على العناصر — مكتبة تُستورد

### القرار: العناصر تأتي عبر `استورد رسومات`

```sad
استورد رسومات            # ← يُسجّل جميع عناصر الواجهة في النطاق

نص("مرحبا")              # ← الآن نص = دالة بنّاء عنصر
عمود                     # ← الآن عمود = دالة بنّاء حاوية
```

### لماذا مكتبة؟

| السبب | التفسير |
|-------|---------|
| لا تلويث | العناصر تظهر فقط في الملفات التي تستورد `رسومات` |
| لا تصادم | `نص` بدون استيراد = نوع مدمج. بعد الاستيراد = دالة بنّاء |
| توسّع لانهائي | إضافة عنصر = إضافة إلى المكتبة — بدون تعديل Lexer/Parser |
| LSP ذكي | autocomplete يعرض العناصر فقط عند وجود الاستيراد |

### آلية التسجيل (C++)

```cpp
// عند استيراد "رسومات", تُسجَّل الدوال في FunctionManager:
void registerGraphicsModule(FunctionManager& fm) {
    fm.registerFunction("نص", text_widget_fn);
    fm.registerFunction("زر", button_widget_fn);
    fm.registerFunction("عمود", column_widget_fn);
    fm.registerFunction("هيكل", scaffold_widget_fn);
    // ... 50+ عنصر
}
```

### التمييز بين `نص` النوع و `نص()` دالة البناء

- `نص اسم = "أحمد"` → Parser يرى `نص IDENTIFIER` → تصريح متغير
- `نص("مرحبا")` → Parser يرى `نص(EXPRESSION)` → استدعاء دالة بنّاء

القاعدة: `isTypeToken()` مع lookahead — إذا بعده `(` فهو استدعاء، إذا بعده IDENTIFIER فهو تصريح.

### `تشغيل_تطبيق()` تبقى مدمجة

`تشغيل_تطبيق()` نقطة دخول — مدمجة بدون استيراد. لكن بدون `استورد رسومات` لا يمكن بناء widgets لتمريرها.

### التعامل مع العناصر غير المتوفرة أصلياً

#### آلية RenderingHint (موجودة في types.h)

```cpp
enum class RenderingHint { Auto, Native, Canvas, Hybrid };
```

- **Auto** (الافتراضي): النظام يختار الأفضل تلقائياً
- **Native**: يجبر استخدام المكون الأصلي — خطأ إذا غير متوفر
- **Canvas**: يرسم مخصصاً دائماً — يعمل على كل منصة
- **Hybrid**: أصلي إذا متوفر، canvas كبديل

## 18. وضع Freestanding (بدون نظام تشغيل)

### التحدي

في Freestanding لا يوجد نظام تشغيل — فقط عنوان ذاكرة framebuffer وأبعاد الشاشة.
لا مكتبة C، لا نظام ملفات، لا نظام نوافذ، لا خطوط TTF.

### ما المتاح

| العنصر | الآلية | الحالة |
|--------|--------|--------|
| `نص` | خط bitmap مدمج (16×16 عربي/لاتيني) | ✅ |
| `زر` | مستطيل ملون + نص + أحداث ماوس | ✅ |
| `عمود`/`صف` | محرك Flexbox (حسابات فقط) | ✅ |
| `حاوية`/`بطاقة` | fill_rect + إطار | ✅ |
| `صورة` | بيانات BMP مُضمّنة في الملف | ✅ |

### الدورة الداخلية (Render Loop)

```

```

## 19. آلية الربط: من كود ص إلى الشاشة

### المسار الكامل

```
نص("مرحبا").حجم(24)
    ↓ Parser
FunctionCallNode("نص") + MethodCallNode("حجم")
    ↓ Interpreter
C++ builtin نص() → IRNode{TEXT} → .حجم() → Modifier{FONT_SIZE:24}
    ↓ UIBridge::run()
Backend المناسب (SDL2 / HTML / Compose / SwiftUI / Framebuffer)
```

### المكونات الأساسية

| الطبقة | الملف | الدور |
|--------|-------|-------|
| Parser | `shared/parser/` | يفهم `عمود ... نهاية` و `.حجم()` كاستدعاءات |
| Widget Builtins | `interpreter_new/src/ui/widget_builtins.cpp` 🆕 | دوال C++ للمكونات (نص, زر, عمود...) |
| WidgetBuilder | `interpreter_new/src/ui/widget_builder.h` 🆕 | يلف IRNode ويدعم Modifier Chain |
| UIBridge | `interpreter_new/src/ui/ui_bridge.cpp` | يأخذ IRNode مباشرة → Backend |
| IR Layer | `sad_ui/core/` | UINodeType, IRNode, Modifiers |
| Backends | `sad_ui/backends/` | SDL2, HTML, Compose, SwiftUI, Framebuffer |

### كيف يعمل `استورد رسومات`

```cpp
// عندما المفسر يرى "استورد رسومات":
void loadGraphicsModule(FunctionManager& fm) {
    // تسجيل دوال المكونات الأساسية كـ builtins

```

### كيف يعمل WidgetBuilder (Modifier Chain)

```cpp
class WidgetBuilder : public ObjectInstance {
    std::shared_ptr<IRNode> node_;
public:
    // .حجم(24) → يضيف modifier ويُرجع نفسه (chaining)
    Value حجم(int size) { node_->addModifier(FONT_SIZE, size); return this; }
    // .لون(.أزرق) → يضيف modifier ويُرجع نفسه
    Value لون(Color c) { node_->addModifier(TEXT_COLOR, c); return this; }
    // .عند_النقر => ... → يسجل handler
    Value عند_النقر(Value handler) {
        auto id = UIBridge::active()->registerHandler(handler);
        node_->setEvent("عند_النقر", id);
        return this;
    }
};
```
