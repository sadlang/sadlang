## 💻 المتطلبات

قبل تثبيت لغة ص، تأكد من توفر المتطلبات التالية على جهازك:

### المتطلبات الأساسية

| المتطلب | الحد الأدنى | الموصى به | الوصف |
|---------|------------|-----------|---------|
| **نظام التشغيل** | Windows 10 | Windows 11 | نظام التشغيل الأساسي |
| **المعالج** | x64 (64-bit) | x64 متعدد الأنوية | معالج حديث |
| **الذاكرة** | 2 GB RAM | 4 GB RAM أو أكثر | ذاكرة عشوائية |
| **المساحة** | 500 MB | 1 GB | مساحة قرص صلب |

### البرامج المطلوبة

1. **Windows 10 أو أحدث**
   - يجب أن يكون Windows محدثاً بآخر التحديثات

2. **Visual C++ Redistributables**
   - يتم تثبيتها تلقائياً مع معظم أنظمة Windows
   - إذا كانت غير موجودة، سيتم تنزيلها تلقائياً

3. **مساحة كافية على القرص**
   - على الأقل 500 ميجابايت للتثبيت الأساسي
   - مساحة إضافية للمشاريع والمكتبات

### متطلبات اختيارية (للتطوير المتقدم)

- **LLVM 18.1.8+**: لميزات JIT compilation المتقدمة
- **CMake 3.20+**: لبناء المشروع من المصدر
- **Git**: لإدارة الإصدارات والمساهمة في المشروع

## 🪟 التثبيت على Windows

### الطريقة 1: التثبيت السريع (موصى بها)

هذه هي أسهل وأسرع طريقة لتثبيت لغة ص على Windows:

#### الخطوة 1: تنزيل المثبت

1. اذهب إلى صفحة الإصدارات الرسمية:
   ```
   https://github.com/sad-lang/sad/releases
   ```

2. قم بتنزيل آخر إصدار من ملف المثبت:
   ```
   sad-installer-x64-v1.0.0.exe
   ```

#### الخطوة 2: تشغيل المثبت

1. انقر نقراً مزدوجاً على الملف المحمل
2. قد تظهر رسالة تحذير من Windows - اضغط **"More info"** ثم **"Run anyway"**
3. اتبع خطوات المثبت:
   - اختر مسار التثبيت (الافتراضي: `C:\Program Files\Sad`)
   - حدد خيار **"Add to PATH"** (مهم جداً!)
   - اضغط **"Install"**

#### الخطوة 3: إكمال التثبيت

بعد انتهاء التثبيت، سيتم إضافة لغة ص إلى متغير البيئة PATH تلقائياً. هذا يعني أنه يمكنك تشغيل أوامر لغة ص من أي مكان في Command Prompt أو PowerShell.

### الطريقة 2: التثبيت اليدوي

إذا كنت تفضل التحكم الكامل في عملية التثبيت:

#### الخطوة 1: تنزيل الملفات

قم بتنزيل ملف ZIP من صفحة الإصدارات:
```
sad-portable-x64-v1.0.0.zip
```

#### الخطوة 2: فك الضغط

1. فك ضغط الملف إلى المسار الذي تريده، مثلاً:
   ```
   C:\sad
   ```

2. يجب أن يحتوي المجلد على الملفات التالية:
   ```
   C:\sad\
   ├── bin\
   │   ├── sad.exe          # المفسر الرئيسي
   │   ├── sadc.exe         # المترجم
   │   └── *.dll            # المكتبات المطلوبة
   ├── lib\                 # المكتبة القياسية
   ├── include\             # ملفات الرأس
   └── docs\                # التوثيق
   ```

#### الخطوة 3: إضافة PATH يدوياً

لتتمكن من تشغيل أوامر لغة ص من أي مكان:

1. افتح **إعدادات Windows**
2. ابحث عن **"Environment Variables"** أو **"متغيرات البيئة"**
3. في قسم **"User variables"**، اختر **"Path"** واضغط **"Edit"**
4. اضغط **"New"** وأضف المسار:
   ```
   C:\sad\bin
   ```
5. اضغط **"OK"** لحفظ التغييرات
6. أعد تشغيل Command Prompt أو PowerShell

### الطريقة 3: البناء من المصدر (للمطورين)

إذا كنت مطوراً وتريد بناء لغة ص من المصدر:

#### المتطلبات الإضافية

- **CMake 3.20+**
- **LLVM 18.1.8+**
- **Visual Studio 2022** مع C++ workload
- **Git**

#### خطوات البناء

```powershell
# 1. استنساخ المستودع
git clone https://github.com/sad-lang/sad.git
cd sad

# 2. إنشاء مجلد البناء
mkdir build
cd build

# 3. تهيئة CMake
cmake .. -G "Visual Studio 17 2022" -A x64

# 4. البناء
cmake --build . --config Release

# 5. تشغيل الاختبارات (اختياري)
ctest -C Release

# 6. التثبيت
cmake --install . --prefix "C:\sad"
```

بعد البناء، أضف `C:\sad\bin` إلى PATH كما هو موضح في الطريقة اليدوية.

## ✅ التحقق من التثبيت

بعد إكمال التثبيت، تحقق من أن كل شيء يعمل بشكل صحيح:

### الخطوة 1: فتح Terminal

افتح **PowerShell** أو **Command Prompt**. يمكنك فعل ذلك بالضغط على:
- `Win + X` ثم اختيار **"Windows PowerShell"**
- أو البحث عن **"PowerShell"** في قائمة Start

### الخطوة 2: التحقق من الإصدار

اكتب الأمر التالي:

```powershell
sad --version
```

يجب أن ترى نتيجة مشابهة لهذه:

```
Sad Programming Language
Version: 1.0.0
Build: Release x64
Compiler: MSVC 19.37
LLVM: 18.1.8
```

إذا رأيت هذه الرسالة، فهذا يعني أن التثبيت نجح! 🎉

### الخطوة 3: اختبار المفسر

جرب تشغيل أول كود بسيط:

```powershell
sad -c "اطبع('مرحباً بالعالم!')"
```

يجب أن ترى:
```
مرحباً بالعالم!
```

### الخطوة 4: الدخول للوضع التفاعلي

شغل المفسر بدون أي ملف:

```powershell
sad
```

يجب أن ترى prompt مثل هذا:

```
Sad Programming Language v1.0.0
اكتب "خروج()" أو Ctrl+C للخروج
>>>
```

جرب كتابة بعض الأوامر البسيطة:

```s
>>> اطبع("مرحباً")
مرحباً
>>> 2 + 3
5
>>> خروج()
```

إذا عملت كل هذه الخطوات، فأنت جاهز للبدء! 🚀

## 🛠️ إعداد بيئة التطوير

### محررات النصوص الموصى بها

#### 1. Visual Studio Code (موصى به بشدة)

**VS Code** هو المحرر الأكثر شعبية وقوة للبرمجة بشكل عام:

**التثبيت:**
1. قم بتنزيل VS Code من: https://code.visualstudio.com
2. ثبته بالطريقة العادية
3. افتح VS Code

**الإضافات الموصى بها:**

بعد تثبيت VS Code، ثبت هذه الإضافات لدعم أفضل للغة ص:

1. **Sad Language Support** (إذا كانت متوفرة)
   - تلوين الكود (Syntax Highlighting)
   - إكمال الكود التلقائي
   - اكتشاف الأخطاء

2. **Arabic Language Pack**
   - لجعل واجهة VS Code بالعربية

3. **Code Runner**
   - لتشغيل الأكواد مباشرة من المحرر

**إعداد VS Code للغة ص:**

أنشئ ملف إعدادات خاص:
```json
// في settings.json
{
    "files.associations": {
        "*.s": "sad"
    },
    "editor.fontSize": 14,
    "editor.fontFamily": "Cascadia Code, Consolas",
    "editor.tabSize": 4,
    "terminal.integrated.defaultProfile.windows": "PowerShell"
}
```

#### 2. Notepad++

محرر نصوص خفيف وسريع:

1. قم بالتنزيل من: https://notepad-plus-plus.org
2. ثبته واستخدمه مباشرة
3. يمكنك إنشاء ملف تعريف لغة مخصص للتلوين

#### 3. Sublime Text

محرر سريع وقوي:

1. قم بالتنزيل من: https://www.sublimetext.com
2. ثبت Package Control
3. ابحث عن إضافة Sad Language (إذا كانت متوفرة)

### إنشاء مجلد للمشاريع

من الجيد إنشاء مجلد مخصص لمشاريع لغة ص:

```powershell
# إنشاء مجلد المشاريع
mkdir C:\SadProjects
cd C:\SadProjects

# إنشاء أول مشروع
mkdir HelloWorld
cd HelloWorld
```

الآن أنت جاهز لكتابة أول برنامج!

## 🔧 المشاكل الشائعة وحلولها

### المشكلة 1: "sad is not recognized"

**الأعراض:**
```
'sad' is not recognized as an internal or external command,
operable program or batch file.
```

**السبب:**
لم يتم إضافة مسار لغة ص إلى متغير البيئة PATH.

**الحل:**
1. افتح إعدادات Windows
2. ابحث عن "Environment Variables"
3. تأكد من إضافة مسار `bin` (مثل `C:\Program Files\Sad\bin`) إلى PATH
4. أعد تشغيل Terminal

### المشكلة 2: رسالة خطأ DLL

**الأعراض:**
```
The program can't start because VCRUNTIME140.dll is missing
```

**السبب:**
مكتبات Visual C++ Redistributables غير مثبتة.

**الحل:**
قم بتثبيت Visual C++ Redistributables:
1. قم بالتنزيل من موقع Microsoft الرسمي
2. ثبت النسخة x64
3. أعد تشغيل الجهاز

### المشكلة 3: خطأ في الترميز (Encoding)

**الأعراض:**
النصوص العربية تظهر بشكل غريب أو رموز غير مفهومة.

**السبب:**
Terminal لا يستخدم ترميز UTF-8.

**الحل:**
في PowerShell، شغل هذا الأمر قبل تشغيل البرنامج:
```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
```

أو أضفه إلى ملف PowerShell Profile ليعمل دائماً:
```powershell
notepad $PROFILE
```

وأضف هذا السطر في الملف:
```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
```

### المشكلة 4: الأداء البطيء

**الأعراض:**
البرامج تعمل ببطء شديد.

**السبب المحتمل:**
- برامج الحماية تفحص كل عملية
- الذاكرة غير كافية
- البرنامج يحتوي على حلقات أو عمليات ثقيلة

**الحل:**
1. أضف مجلد لغة ص إلى استثناءات برنامج الحماية
2. تأكد من وجود ذاكرة كافية
3. راجع كود البرنامج للتحقق من الأداء

### المشكلة 5: خطأ في الأذونات (Permissions)

**الأعراض:**
```
Access Denied
```

**السبب:**
لا توجد أذونات كافية للكتابة في مجلد التثبيت.

**الحل:**
1. شغل PowerShell كمسؤول (Run as Administrator)
2. أو ثبت لغة ص في مجلد المستخدم بدلاً من `Program Files`
