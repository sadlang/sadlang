## 🎨 الميزات الرئيسية / Key Features

### المرحلة 0: التحضير (2 يوم)
- تحليل المعمارية الحالية
- تصميم البنية التفصيلية
- إعداد الملفات الأساسية
- إعداد بيئة الاختبار

### المرحلة 1: الأصناف الأساسية (5 أيام)
- ✅ تعريف الأصناف
- ✅ الخصائص (Fields)
- ✅ الطرق (Methods)
- ✅ البواني (Constructors)
- ✅ الهدامات (Destructors)

### المرحلة 2: الكائنات (4 أيام)
- إنشاء الكائنات بالكلمة المفتاحية `جديد`
- الوصول للخصائص
- استدعاء الطرق
- استخدام `هذا` (this)

### المرحلة 3: الوراثة (5 أيام)
- الوراثة الأحادية باستخدام `:` أو `يرث`
- تجاوز الطرق (Method Overriding)
- استدعاء الصنف الأساس (`الأساس`)
- التعددية الشكلية (Polymorphism)

### المرحلة 4: التغليف (3 أيام)
- `عام` (public)
- `خاص` (private)
- `محمي` (protected)
- فحص الوصول وإظهار أخطاء واضحة

### المرحلة 5: الأعضاء الثابتة (2 يوم)
- الخصائص الثابتة
- الطرق الثابتة
- الوصول بدون إنشاء كائن

### المرحلة 6: إدارة الذاكرة (4 أيام)
- عد المراجع (Reference Counting)
- جمع القمامة (Garbage Collection)
- استدعاء تلقائي للهدامات
- كشف التسربات

### المرحلة 7: التحسينات (5 أيام)
- الوراثة المتعددة
- الواجهات (Interfaces)
- الطرق المجردة (Abstract Methods)
- التحميل الزائد (Method Overloading)

## 📚 الأمثلة العملية / Practical Examples

### مثال 1: صنف بسيط

```s
صنف شخص
    عام نص الاسم
    عام رقم العمر
    
    باني(نص اسم، رقم عمر)
        هذا.الاسم = اسم
        هذا.العمر = عمر
    نهاية
    
    عام دالة اطبع_معلومات()
        اطبع("الاسم: ", هذا.الاسم)
        اطبع("العمر: ", هذا.العمر)
    نهاية
نهاية

# الاستخدام
شخص أحمد = جديد شخص("أحمد"، 25)
أحمد.اطبع_معلومات()
```

### مثال 2: الوراثة

```s
صنف حيوان
    عام نص اسم
    
    باني(نص اسم)
        هذا.اسم = اسم
    نهاية
    
    عام دالة صوت()
        اطبع("صوت عام")
    نهاية
نهاية

صنف كلب يرث حيوان
    باني(نص اسم)
        الأساس(اسم)
    نهاية
    
    عام دالة صوت()
        اطبع("نباح نباح!")
    نهاية
نهاية

# الاستخدام
كلب ريكس = جديد كلب("ريكس")
ريكس.صوت()  # نباح نباح!
```

### مثال 3: التغليف

```s
صنف حساب_بنكي
    خاص عشري رصيد
    عام نص اسم_صاحب_الحساب
    
    باني(نص اسم، عشري رصيد_أولي)
        هذا.اسم_صاحب_الحساب = اسم
        هذا.رصيد = رصيد_أولي
    نهاية
    
    عام دالة عشري احصل_على_رصيد()
        إرجاع هذا.رصيد
    نهاية
    
    عام دالة أودع(عشري مبلغ)
        إذا مبلغ > 0
            هذا.رصيد = هذا.رصيد + مبلغ
        نهاية
    نهاية
نهاية

# الاستخدام
حساب_بنكي حساب = جديد حساب_بنكي("علي"، 1000.0)
حساب.أودع(500.0)
اطبع(حساب.احصل_على_رصيد())  # 1500.0
# اطبع(حساب.رصيد)  # خطأ! الخاصية خاصة
```
