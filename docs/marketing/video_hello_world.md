- **مرئيات:** مقارنة جانبية بين كود Python وكود لغة ص
- **نص على الشاشة:**

```
Python:                    لغة ص:
def add(a, b):             دالة جمع(أ، ب)
    return a + b               ارجع أ + ب
                           نهاية

print(add(3, 5))           اطبع(جمع(3، 5))
```

> "لغة ص مصممة للمبرمج العربي. لاحظ كيف أن الكلمات المفتاحية مثل 
> 'دالة' و'ارجع' و'نهاية' كلها بالعربي. والمتغيرات أيضاً عربية."

### المشهد 6: كتابة Hello World

- **كتابة حية (typing):**

```sad
# أول برنامج بلغة ص

```

> "كما ترون — سطر واحد فقط. 'اطبع_سطر' هي الدالة المدمجة للطباعة."

### المشهد 7: التشغيل
```
> sad مرحبا.ص

```

> "رائع! أول برنامج يعمل!"

### المشهد 8: برنامج أكثر تعقيداً
- **كتابة حية:**

```sad
# برنامج حساب المعدل
دالة حساب_معدل(درجات)
    متغير مجموع = 0
    متغير عدد = 0
    لكل درجة في درجات
        مجموع = مجموع + درجة
        عدد = عدد + 1
    نهاية
    ارجع مجموع / عدد
نهاية

متغير الدرجات = [95، 87، 92، 78، 88]
متغير المعدل = حساب_معدل(الدرجات)
اطبع_سطر("المعدل: " + نص(المعدل))
```

> "هنا أنشأنا دالة 'حساب_معدل' التي تأخذ مصفوفة درجات وتحسب المعدل.
> لاحظ 'لكل' للتكرار و'ارجع' لإرجاع القيمة. كل شيء بالعربي!"

### المشهد 9: التشغيل
```
> sad معدل.ص
المعدل: 88
```

## القسم 4: صنف (Class) بالعربي (3:00 - 3:45)

### المشهد 10: برمجة كائنية
```sad
صنف طالب
    باني(الاسم، العمر)
        هذا.الاسم = الاسم
        هذا.العمر = العمر
        هذا.الدرجات = []
    نهاية

    دالة اضف_درجة(درجة)
        هذا.الدرجات = هذا.الدرجات + [درجة]
    نهاية
نهاية

متغير أحمد = جديد طالب("أحمد"، 20)
أحمد.اضف_درجة(95)
اطبع_سطر(أحمد.الاسم + " — عمره: " + نص(أحمد.العمر))
```

> "البرمجة الكائنية بالعربي! 'صنف' لتعريف الفئة، 'باني' للمُنشئ،
> 'هذا' للإشارة للكائن الحالي، و'جديد' لإنشاء كائن."
