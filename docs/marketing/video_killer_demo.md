## الجزء 1: تطبيق سطح المكتب (0:45 - 3:00)

### المشهد 3: بناء آلة حاسبة (كتابة حية)

> "لنبدأ بتطبيق سطح مكتب — آلة حاسبة بواجهة رسومية."

```sad
# آلة حاسبة — سطح المكتب

صنف آلة_حاسبة
    باني()
        هذا.الشاشة = "0"
        هذا.القيمة_الحالية = 0
        هذا.العملية = ""
    نهاية

    دالة ادخل_رقم(رقم_مدخل)
        إذا (هذا.الشاشة == "0")
            هذا.الشاشة = نص(رقم_مدخل)
        وإلا
            هذا.الشاشة = هذا.الشاشة + نص(رقم_مدخل)
        نهاية
    نهاية

    دالة عيّن_عملية(عملية_حسابية)
        هذا.القيمة_الحالية = رقم(هذا.الشاشة)
        هذا.العملية = عملية_حسابية
        هذا.الشاشة = "0"
    نهاية

    دالة احسب()
        متغير ثاني = رقم(هذا.الشاشة)
        إذا (هذا.العملية == "+")
            هذا.الشاشة = نص(هذا.القيمة_الحالية + ثاني)
        نهاية
        إذا (هذا.العملية == "-")
            هذا.الشاشة = نص(هذا.القيمة_الحالية - ثاني)
        نهاية
        إذا (هذا.العملية == "*")
            هذا.الشاشة = نص(هذا.القيمة_الحالية * ثاني)
        نهاية
    نهاية
نهاية
```

### المشهد 4: التشغيل
- **مرئيات:** نافذة التطبيق تظهر على الشاشة
- **عرض حي:** نقر على الأزرار 5 + 3 = 8

> "آلة حاسبة كاملة تعمل على ويندوز ولينكس وماك — بكود عربي 100%!"

### المشهد 5: الترجمة لملف تنفيذي
```
> sadc حاسبة.ص -o حاسبة.exe
✅ تم ترجمة حاسبة.exe (2.1 MB)

> .\حاسبة.exe
```

## الجزء 2: تطبيق Android (3:00 - 5:00)

### المشهد 6: نفس المنطق — واجهة Android

> "الآن لنأخذ نفس المنطق ونبني تطبيق Android كامل."

```sad
# تطبيق المهام — Android

صنف مدير_المهام
    باني()
        هذا.المهام = []
    نهاية

    دالة اضف(عنوان، أولوية)
        هذا.المهام = هذا.المهام + [{"عنوان": عنوان, "أولوية": أولوية}]
    نهاية
نهاية

# الواجهة
عمود {
    نص("قائمة المهام") .حجم(24) .لون(.أبيض)
    
    لكل مهمة في مدير.المهام
        بطاقة {
            صف {
                نص(مهمة.عنوان) .لون(.أسود)
                فراغ()
                شارة(مهمة.أولوية)
            }
        }
    نهاية
    
    زر("إضافة مهمة") .عند_الضغط(اضف_مهمة)
}
```

## الجزء 4: تطبيق ويب WASM (6:30 - 7:45)

### المشهد 10: الترجمة لـ WebAssembly

> "والآن الجزء الأكثر إثارة — نفس الكود يعمل في المتصفح!"

```
> sadc حاسبة.ص --target wasm -o حاسبة.wasm
✅ تم الترجمة: حاسبة.wasm (89 KB)
```

- **مرئيات:** فتح المتصفح → الآلة الحاسبة تعمل في المتصفح

> "WASM — WebAssembly. كود لغة ص يُترجم إلى ملف يعمل في أي متصفح.
> لا حاجة لخادم. لا حاجة لـ JavaScript. كود عربي يعمل في المتصفح مباشرة."

### المشهد 11: مقارنة WASM
- **جدول مرئي:**

| | قبل (JavaScript) | بعد (لغة ص + WASM) |
|---|---|---|
| اللغة | إنجليزية | عربية |
| الأداء | جيد | ممتاز (2x-10x) |
| الحجم | ~200KB | ~89KB |
| الحماية | مكشوف | مُترجم |
