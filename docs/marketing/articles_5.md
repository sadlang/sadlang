## لماذا نحتاج لغة برمجة عربية في 2026؟

### المشكلة الحقيقية

كل يوم، يبدأ آلاف الشباب العرب رحلتهم في تعلم البرمجة. يفتحون محرر الكود، يكتبون `print("Hello World")` — ويواجهون أول حاجز: **اللغة**.

ليست المشكلة في صعوبة البرمجة. المشكلة أن المبرمج العربي مُجبر على:
- حفظ كلمات مفتاحية بلغة أجنبية (`function`, `return`, `while`)
- التفكير بالعربية ثم الترجمة للإنجليزية
- قراءة توثيق ورسائل خطأ بالإنجليزية

هذا الحاجز اللغوي يُبطئ التعلم ويُحبط المبتدئين.

### الحل: لغة ص

لغة ص ليست مجرد ترجمة للكلمات المفتاحية. هي لغة برمجة **كاملة** صُممت من الصفر للمبرمج العربي:

```sad
دالة ترحيب(اسم)
    ارجع "مرحباً يا " + اسم + "!"
نهاية

اطبع_سطر(ترحيب("أحمد"))
# مرحباً يا أحمد!
```

### لماذا الآن؟

1. **500 مليون عربي** — أكبر مجتمع لغوي بدون لغة برمجة خاصة به
2. **نمو قطاع التقنية** — السعودية والإمارات تستثمران مليارات في التحول الرقمي
3. **تعليم البرمجة** — مناهج البرمجة أصبحت إلزامية في معظم الدول العربية
4. **الذكاء الاصطناعي** — نحتاج أدوات تدعم اللغة العربية بشكل أصلي

### مقارنة: قبل وبعد

| بدون لغة ص | مع لغة ص |
|---|---|
| `function calculate(grades)` | `دالة حساب(درجات)` |
| `for (let g of grades)` | `لكل درجة في درجات` |
| `return sum / count` | `ارجع مجموع / عدد` |
| `class Student extends Person` | `صنف طالب يرث شخص` |

### ما يميز لغة ص

- **40 كلمة مفتاحية عربية** — كل شيء بلغتك الأم
- **مترجم LLVM** — أداء مماثل لـ C++
- **متعددة المنصات** — Desktop, Android, iOS, WASM
- **مكتبة قياسية** — رياضيات، نصوص، تواريخ، شبكات
- **500+ اختبار** — مستقرة ومُختبرة

### تجربة حقيقية: حساب المعدل

```sad
صنف طالب
    باني(الاسم)
        هذا.الاسم = الاسم
        هذا.الدرجات = []
    نهاية

    دالة اضف_درجة(درجة)
        هذا.الدرجات = هذا.الدرجات + [درجة]
    نهاية

    دالة المعدل()
        متغير مجموع = 0
        متغير عدد = 0
        لكل د في هذا.الدرجات
            مجموع = مجموع + د
            عدد = عدد + 1
        نهاية
        إذا (عدد == 0)
            ارجع 0
        نهاية
        ارجع مجموع / عدد
    نهاية
نهاية

متغير سارة = جديد طالب("سارة")
سارة.اضف_درجة(95)
سارة.اضف_درجة(88)
سارة.اضف_درجة(92)
اطبع_سطر(سارة.الاسم + " — المعدل: " + نص(سارة.المعدل()))
# سارة — المعدل: 91
```

### الخلاصة

لغة ص ليست بديلاً عن تعلم الإنجليزية. لكنها **جسر** يُسهّل دخول عالم البرمجة للملايين. البرمجة بلغتك الأم تُزيل الحاجز اللغوي وتُركز التعلم على المفاهيم — وهذا ما نحتاجه.

## بناء تطبيق إدارة المهام بلغة ص

في هذا الدليل العملي، سنبني تطبيق إدارة مهام كامل بلغة ص. ستتعلم:

- إدارة المصفوفات

- الدوال والقيم المُرجعة

### الخطوة 1: نموذج المهمة

```sad

        هذا.المعرف = 0
        هذا.العنوان = عنوان
        هذا.الوصف = وصف
        هذا.مكتملة = خطأ
    نهاية

    دالة اكمل()
        هذا.مكتملة = صحيح
    نهاية

    دالة نص_العرض()
        متغير رمز = "○"
        إذا (هذا.مكتملة)
            رمز = "●"
        نهاية
        ارجع رمز + " " + هذا.العنوان
    نهاية
نهاية
```

### الخطوة 2: مدير المهام

```sad
صنف مدير_المهام
    باني()
        هذا.المهام = []
        هذا.العداد = 0
    نهاية

    دالة اضف(عنوان، وصف)
        هذا.العداد = هذا.العداد + 1
        متغير م = جديد مهمة(عنوان، وصف)
        م.المعرف = هذا.العداد
        هذا.المهام = هذا.المهام + [م]

    دالة اكمل_مهمة(معرف)
        لكل م في هذا.المهام
            إذا (م.المعرف == معرف)
                م.اكمل()
            نهاية
        نهاية
    نهاية

    دالة اعرض_الكل()
        لكل م في هذا.المهام
            اطبع_سطر(م.نص_العرض())
        نهاية
    نهاية
نهاية
```

### الخطوة 3: الاستخدام

## كيف تعمل لغة ص؟ نظرة داخلية على البنية التحتية

### مسار الكود من المصدر إلى التنفيذ

```
ملف .ص → محلل معجمي → محلل نحوي → AST → [مفسر | مترجم LLVM]
```

### 1. المحلل المعجمي (Lexer)

يحوّل النص العربي إلى رموز (Tokens):

```
"دالة جمع(أ، ب)" → [KEYWORD_FUNCTION, IDENTIFIER("جمع"), LPAREN, IDENTIFIER("أ"), COMMA, IDENTIFIER("ب"), RPAREN]
```

**التحدي:** دعم UTF-8 والعربية يتطلب معالجة خاصة:
- الأحرف العربية تتراوح بين 2-4 bytes
- اتجاه الكتابة RTL
- دعم الحركات والتشكيل

### 2. المحلل النحوي (Parser)

يحوّل الرموز إلى شجرة بناء نحوي (AST):

```
FunctionDecl
├── name: "جمع"
├── params: ["أ", "ب"]
└── body:
    └── ReturnStmt
        └── BinaryExpr(+)
            ├── Identifier("أ")
            └── Identifier("ب")
```

### 3. المفسر (Interpreter)

للتطوير السريع — ينفذ AST مباشرة بدون ترجمة.

### 4. المترجم (sadc)

للإنتاج — يمر بمراحل:

```
AST → SIR (Sad IR) → LLVM IR → كود أصلي
```

**SIR** — التمثيل الوسيط الخاص بلغة ص. 12 تعليمة:
- `LOAD`, `STORE`, `CALL`, `RETURN`
- `BRANCH`, `JUMP`
- `ADD`, `SUB`, `MUL`, `DIV`
- `CMP`, `ALLOC`

### الأرقام

- **40** كلمة محجوزة
- **12** تعليمة SIR
- **500+** اختبار
- **4** منصات (Desktop, Android, iOS, WASM)

## مستقبل البرمجة العربية: لماذا 2026 هو نقطة التحول

### الوضع الحالي

في 2026، العالم العربي يشهد تحولاً رقمياً غير مسبوق:
- **السعودية:** رؤية 2030 تستثمر مليارات في التقنية
- **الإمارات:** استراتيجية الذكاء الاصطناعي
- **مصر:** مبادرات رقمية لتأهيل 100,000 مبرمج
- **الأردن:** قطاع التقنية يمثل 14% من الناتج المحلي

### الفجوة

لكن هناك فجوة: **أدوات التطوير لا تتحدث العربية.**

- لغات البرمجة: Python, JavaScript, C++ — كلها إنجليزية
- التوثيق: 95% بالإنجليزية
- رسائل الخطأ: إنجليزية
- مجتمعات الدعم: Stack Overflow بالإنجليزية

### الحل: أدوات عربية حقيقية

لغة ص ليست مجرد لغة — هي **منظومة** كاملة:

| المكون | الوصف |
|---|---|
| المفسر `sad` | تنفيذ فوري للكود |
| المترجم `sadc` | ترجمة لملف تنفيذي أصلي |
| مدير الحزم `sad-pkg` | تثبيت المكتبات |
| خادم LSP | تلوين وإكمال في المحرر |
| المكتبة القياسية | رياضيات، نصوص، شبكات |

### التأثير المتوقع

1. **تعليم أسرع** — المبتدئ يركز على المفاهيم لا على الترجمة
2. **وصول أوسع** — ملايين العرب الذين لا يتقنون الإنجليزية
3. **هوية رقمية** — البرمجة جزء من الثقافة العربية
4. **فرص عمل** — صناعة تطبيقات عربية بأدوات عربية

### كيف تشارك؟

- **جرّب:** حمّل لغة ص واكتب أول برنامج
- **ساهم:** المشروع مفتوح المصدر على GitHub
- **علّم:** استخدم لغة ص في ورش عمل ودورات
- **انشر:** شارك تجربتك مع المجتمع
