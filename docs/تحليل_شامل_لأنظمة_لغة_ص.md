## 2. المحلل المعجمي (Lexer)

### الملفات الأساسية
| الملف | الدور |
|-------|-------|
| `shared/lexer/include/token.h` | تعداد TokenType + بنية Token + Position |
| `shared/lexer/src/lexer_keywords.cpp` | تسجيل الكلمات المحجوزة (40 كلمة) |
| `shared/lexer/src/lexer_core.cpp` | المحلل المعجمي الرئيسي |

### الكلمات المحجوزة (40 كلمة)
هذه الكلمات مسجلة في `KeywordTable::initialize()` ولا يمكن استخدامها كأسماء متغيرات:

```
دالة، ارجع، صنف، بنية، تعداد، يرث، نهاية، جديد، هذا، باني، الأساس،
إذا، وإلا، بينما، لكل، في، توقف، استمر،
طابق، عندما، افتراضي،
حاول، امسك، ارمي، أخيراً،
عام، خاص، محمي، مجرد،
استورد، من، كـ، صدّر،
متغير، ثابت، ساكن، خارجي،
صحيح، خطأ، لاشيء
```

إضافة 3 عوامل منطقية: `و`، `أو`، `ليس`

كل كلمة مسجلة بأسمائها البديلة (بدون تشكيل): `إذا` + `اذا`، `وإلا` + `والا`، `أخيراً` + `اخيرا`، إلخ.

### الكلمات السياقية (لا تُسجّل في Lexer)
هذه الكلمات تُعرَف فقط في سياقها النحوي عبر Parser بنمط "التحقق المزدوج":

```cpp
// نمط التحقق المزدوج في Parser:
if (match(TT::KEYWORD_UI_DECL) ||
    (check(TT::IDENTIFIER) && current_.getValue() == "واجهة" &&
     peekNext().getType() == TT::IDENTIFIER && (advance(), true)))
```

الكلمات السياقية تشمل: `واجهة`، `سمة`، `نفّذ`/`نفذ`، `غير_متزامن`، `انتظر`، `لامدا`، `خاصية`، `احصل`، `عيّن`، `هدم`، `عامل`، `رئيسية`، `حالة`، `امتداد`، `ماكرو`، `أجّل`، `أطلق`/`اطلق`، `اختر`

### أسماء الأنواع المدمجة (IDENTIFIER عادي)
`رقم`، `عشري`، `نص`، `منطقي`، `فراغ`، `عدم`، `مصفوفة`، `خريطة`، `أي`

Lexer يخرجها كـ `IDENTIFIER` ثم Parser يميزها عبر `isTypeToken()` مع lookahead — إذا تلا الاسم IDENTIFIER آخر فهو تصريح نوع.

### مسار اكتشاف `واجهة` في Parser

```
parseDeclaration() [parser_core_main.cpp:~670]
    ↓ يكتشف كلمة "واجهة" السياقية
    ↓ (check(TT::IDENTIFIER) && current_.getValue() == "واجهة" && peekNext() == IDENTIFIER)
    ↓
parseUIDeclaration() [parser_ui_declarations.cpp:146]
    ↓ يحلل: واجهة اسم [يرث أب] ... نهاية
    ↓ يكتشف @حالة/@ربط/@بيئة/@محسوب → parseUIStateDecl()
    ↓ يكتشف دالة → parseFunctionDecl()
    ↓
    ↓ داخل دالة بناء():
    ↓ يكتشف أسماء عناصر واجهة مسجلة → parseWidgetExpression()
    ↓
UIDeclarationNode ← النتيجة
```

### تحليل الواجهات التصريحية — parser_ui_declarations.cpp

#### الوظائف الست:

1. **`parseUIDeclaration()`** — تحليل `واجهة اسم [يرث أب] ... نهاية`
   - تدعم الوراثة (`يرث`)
   - تحلل تصريحات `@حالة`/`@ربط`/`@بيئة`/`@محسوب`
   - تحلل الدوال (بما فيها `بناء()`)
   - تنتج `UIDeclarationNode`

2. **`parseUIStateDecl(stateKind)`** — تحليل `@حالة اسم: نوع = قيمة`
   - يدعم 4 أنواع: STATE, BINDING, ENVIRONMENT, COMPUTED
   - نوع اختياري (بعد `:`)
   - قيمة ابتدائية اختيارية (بعد `=`)
   - `@محسوب` يتطلب تعبير ابتدائي إلزامياً
   - ينتج `UIStateDecl`

3. **`parseWidgetExpression()`** — تحليل `عمود(...).معدّل(...)` + أبناء
   - يحلل الوسائط الموضعية والمسماة (`اسم: قيمة`)
   - يدعم الفاصلة العربية `،` والإنجليزية `,`
   - يستدعي `parseModifierChain()` لسلسلة المعدّلات
   - يكتشف الحاويات عبر `containerWidgets` ويحلل أبناءها
   - ينتج `UIWidgetExprNode`

4. **`parseModifierChain()`** — تحليل `.حجم(32).لون(.أزرق).عند_النقر => ...`
   - يكتشف معالجات الأحداث عبر `knownEvents`
   - يدعم 3 أنواع معدّلات: بوسائط، بدون وسائط، حدث
   - ينتج `vector<UIModifierNode>`

5. **`parseUIEventHandler(eventName)`** — تحليل معالجات الأحداث
   - 3 صيغ:
     - **سهم:** `.عند_النقر => تعبير` → `UIEventHandlerNode::createArrow()`
     - **كتلة:** `.عند_النقر ... نهاية` → `UIEventHandlerNode::createBlock()`
     - **لامدا:** `.عند_التغيير(لامدا(ق) ...)` → `UIEventHandlerNode::createLambda()`
   - ينتج `UIEventHandlerNode`

6. **`parseWidgetChildren()`** — تحليل أبناء الحاوية
   - يحلل عناصر واجهة مسجلة عبر `isKnownWidget()`
   - ⚠ **لا يدعم حالياً** الجمل الشرطية (`إذا`/`لكل`) داخل الحاويات
   - يتوقف عند أي رمز غير عنصر واجهة معروف

#### مجموعة العناصر المعروفة (~60 عنصر)

### التعدادات
```cpp
enum class UIStateKind { STATE, BINDING, ENVIRONMENT, COMPUTED };

```

### العقد الخمس

#### 1. UIStateDecl (Statement)
```cpp
class UIStateDecl : public Statement {
    UIStateKind kind;           // @حالة/@ربط/@بيئة/@محسوب
    std::string name;           // اسم المتغير
    std::string typeName;       // نوع (اختياري)
    ExprPtr initializer;        // قيمة ابتدائية (اختيارية)
};
```

#### 2. UIEventHandlerNode (Expression)
```cpp
class UIEventHandlerNode : public Expression {
    std::string eventName;      // عند_النقر، عند_التغيير...
    UIEventKind kind;           // ARROW, BLOCK, LAMBDA
    ExprPtr arrowExpr;          // تعبير السهم
    StmtPtr blockBody;          // كتلة الأوامر
    ExprPtr lambdaExpr;         // لامدا صريحة
    // مصانع ثابتة:
    static createArrow(eventName, expr, pos);
    static createBlock(eventName, block, pos);
    static createLambda(eventName, lambda, pos);
};
```

#### 3. UIModifierNode (Expression)
```cpp
class UIModifierNode : public Expression {
    std::string name;                                   // اسم المعدّل
    ExprList arguments;                                 // وسائط القيمة
    bool isEvent;                                       // هل هو حدث؟
    std::unique_ptr<UIEventHandlerNode> eventHandler;   // معالج الحدث
};
```

#### 4. UIWidgetExprNode (Expression)
```cpp
class UIWidgetExprNode : public Expression {
    std::string widgetName;                             // اسم العنصر (نص، زر...)
    ExprList arguments;                                 // وسائط موضعية
    NamedArgs namedArgs;                                // وسائط مسماة
    std::vector<std::unique_ptr<UIModifierNode>> modifiers;  // سلسلة المعدّلات
    std::vector<std::unique_ptr<UIWidgetExprNode>> children; // الأبناء
    bool hasChildrenBlock;                              // هل يوجد كتلة أبناء

    // مساعدات:
    bool isLeaf();       // هل ورقي (بدون أبناء)
    bool hasModifiers(); // هل له معدّلات
    size_t childCount(); // عدد الأبناء
};
```

#### 5. UIDeclarationNode (Statement)
```cpp
class UIDeclarationNode : public Statement {
    std::string name;                                   // اسم المكون
    std::string parentName;                             // المكون الأب (وراثة)
    std::vector<std::unique_ptr<UIStateDecl>> stateDecls;  // تصريحات الحالة
    StmtList methods;                                   // الدوال (بناء، ...)
    bool isExported;                                    // مُصدّر؟

    // مساعدات:
    bool isStateful();    // هل يحتوي حالة
    bool hasBindings();   // هل يحتوي ربط
    bool hasParent();     // هل يرث
};
```

### visitUIDeclaration — تنفيذ تصريح واجهة

```
واجهة عداد
    @حالة عدد = 0
    دالة بناء()
        عمود
            نص(هذا.عدد)
            زر("زيادة").عند_النقر => هذا.عدد += 1
        نهاية
    نهاية
نهاية
```

المفسر يفعل التالي:
1. **ينشئ `ClassType`** بعلامة `isUIComponent = true`
2. **يسجل حقول `@حالة`** كحقول عضوية عامة مع قيم ابتدائية
3. **يسجل الحقل كحالة تفاعلية** في `uiStateFields`
4. **يسجل الدوال** (بما فيها `بناء()`) كطرق عادية
5. **يسجل المكون** في `ClassManager` للاستخدام لاحقاً

### visitUIWidgetExpr — تقييم تعبير عنصر واجهة

المسار الكامل لتعبير مثل `نص("مرحبا").حجم(24).لون(.أزرق)`:

```
1. تحويل اسم العنصر → UINodeType عبر arabicNameToNodeType()
2. إنشاء WidgetBuilder(nodeType)
3. معالجة الوسائط الموضعية:
   - الوسيط الأول → خاصية حسب نوع العنصر:
     * نص → محتوى
     * زر → عنوان
     * صورة → مصدر
     * حقل_نص → تلميح
     * غيره → _وسيط_0
   - باقي الوسائط → _وسيط_1, _وسيط_2, ...
4. معالجة الوسائط المسماة → خصائص على IRNode
5. معالجة سلسلة المعدّلات:
   أ. معدّل حدث (isEvent=true):
      - تسجيل الدالة المعالجة في FunctionManager (مع captures/closure)
      - إنشاء FunctionRef وتسجيلها في UIBridge.registerHandler()
      - إضافة الحدث على IRNode عبر addIREvent()
   ب. معدّل خاصية:
      - وسيط واحد → setIRPropertyFromValue()
      - عدة وسائط → قيمة مفصولة بفواصل
      - بدون وسائط → true
6. معالجة الأبناء (تكراري):
   - WidgetBuilder → إضافة IRNode كابن
   - كائن عادي (مكون واجهة) → CustomWidget IRNode
   - قيمة بسيطة → Text IRNode
7. إرجاع WidgetBuilder كـ Value::OBJECT
```

### WidgetBuilder — مُغلّف IRNode

```
WidgetBuilder يرث من ObjectInstance (للتوافق مع Value system)

الميزات:
├── setIRProperty(key, value)        — تعيين خصائص نصية/رقمية/منطقية
├── setIRPropertyFromValue(key, val) — تعيين من Value (تحديد نوع تلقائي)
├── addIREvent(name, handlerId)      — تسجيل حدث
├── addChild(IRNode)                 — إضافة ابن
├── addChildBuilder(WidgetBuilder)   — إضافة WidgetBuilder كابن
├── startAnimationChain(typeName)    — بدء تسلسل تحريك
├── currentAnimation()               — الحصول على التحريك الحالي
├── applyToActiveAnimations(fn)      — تطبيق تعديل على تحريكات نشطة
├── setRenderingHint(hint)           — تلميح العرض (أصلي/مرسوم/هجين)
└── getIRNode()                      — استخراج IRNode النهائي
```

### وحدة `رسومات` — ما يُسجّل عند الاستيراد

## 7. UIBridge — جسر الربط

### الوظيفة الرئيسية: `run(rootWidget, interpreter)`
```
UIBridge::run()
    ↓ يحوّل rootWidget إلى شجرة IRNode
    ↓ (إذا WidgetBuilder → يستخرج IRNode مباشرة)
    ↓ (إذا ObjectInstance → يبحث عن بناء() وينفذها)
    ↓
    ↓ ينشئ نافذة SDL2 (Desktop)
    ↓ يشغل حلقة الأحداث:
    │   ├── معالجة أحداث المستخدم (لمس/ماوس/لوحة مفاتيح)
    │   ├── تنفيذ التحريكات
    │   ├── إعادة حساب التخطيط إذا تغيرت الحالة
    │   └── عرض الواجهة عبر PlatformRenderer
    ↓
    ↓ عند حدث (مثل عند_النقر):
    │   ├── invokeHandler(handlerId, args) → ينفذ الدالة في المفسر
    │   └── rebuildUI() → يعيد بناء شجرة IR
    ↓
    ↓ حتى إغلاق النافذة
```

### نظام التنقل (Navigation Stack)
```
UIBridge يدير كومة تنقل:
├── navigateTo(page)                    — إضافة صفحة
├── navigateWithTransition(page, type)  — إضافة مع تحريك
├── navigateBack()                      — العودة
├── navigateBackWithTransition(type)    — العودة مع تحريك
├── navigateToRoot()                    — العودة للجذر
├── replacePage(page)                   — استبدال
└── getNavigationDepth()                — عمق الكومة
```

### نظام الأحداث
```
1. Parser يحلل   .عند_النقر => تعبير
2. ExpressionEvaluator يسجل دالة مجهولة في FunctionManager مع captures
3. يسجل FunctionRef في UIBridge.registerHandler() → يحصل على handlerId
4. يضيف الحدث على IRNode.addEvent(eventType, handlerId)
5. عند الحدث من المنصة → IRNode.getEvent() → UIBridge.invokeHandler(handlerId)
6. المفسر ينفذ الدالة → الحالة تتغير → rebuildUI()
```

## 8. محرك التخطيط (LayoutEngine)

### الملف: `sad_ui/core/include/sad_ui/layout.h`

### المراحل
1. **القياس (Measure)** — من الأسفل للأعلى
   - `measureColumn()` — أبناء عمودية
   - `measureRow()` — أبناء أفقية
   - `measureGrid()` — شبكة
   - `measureStack()` — مكدس (أكبر ابن)
   - `measureWrap()` — التفاف
   - `measureLeaf()` — ورقي (نص، صورة...)
   - `measureScrollView()` — قابل للتمرير

2. **التوزيع (Arrange)** — من الأعلى للأسفل
   - يحدد الموقع والحجم النهائي لكل عنصر
   - يدعم RTL (من اليمين لليسار) للعربية
   - ينتج `LayoutResult` مع `rect` و`children`

### الخصائص المدعومة
- `LayoutDirection::RTL` / `LTR`
- كثافة الشاشة (dp → px)
- حجم viewport

## 12. الفجوات والنواقص

### ⚠ فجوة حرجة: الجمل الشرطية داخل الحاويات
```sad
# هذا لا يعمل حالياً:
عمود
    إذا (مسجل_دخول)
        نص("مرحبا!")
    وإلا
        زر("تسجيل دخول")
    نهاية
نهاية
```
في `parseWidgetChildren()` يتوقف عند أي رمز غير عنصر واجهة معروف.
**الحل:** إضافة دعم `إذا`/`وإلا` و`لكل` داخل `parseWidgetChildren()`.

### ⚠ فجوة: لا يوجد Reconciler
حالياً `rebuildUI()` يعيد بناء شجرة IR بالكامل عند أي تغيير.
لا يوجد نظام diff/patch للتحديث الذكي (مثل React Virtual DOM).

### ⚠ فجوة: المترجم (sadc) لا يدعم الرسومات
لا يوجد أي كود لتحويل عقد UI إلى SIR/LLVM IR.

### ⚠ فجوة: لا يوجد LSP للواجهات التصريحية
أدوات LSP لا تدعم إكمال أسماء العناصر أو المعدّلات أو الحالة.

### ⚠ ملاحظة: ازدواجية بناء العناصر
يوجد مساران لبناء العناصر:
1. **دوال مدمجة** (`widget_builtins.cpp`): `نص()`, `زر()`, `عمود()` — تنشئ WidgetBuilder مباشرة
2. **بنية تصريحية** (`parser_ui_declarations.cpp`): `واجهة` + `بناء()` — تنشئ UIDeclarationNode → ClassType

المساران متوافقان: المسار التصريحي يسجل المكون كصنف، وعند استدعاء `بناء()` تُنفّذ العقد التصريحية عبر `visitUIWidgetExpr()` الذي يستخدم نفس WidgetBuilder.

## 13. المسار الكامل من الكود إلى العرض — مثال تفصيلي

```sad
استورد رسومات

واجهة عداد
    @حالة عدد = 0

    دالة بناء()
        ارجع عمود
            نص(هذا.عدد).حجم(32)
            زر("زيادة").عند_النقر => هذا.عدد += 1
        نهاية
    نهاية
نهاية

تشغيل_تطبيق(عداد())
```

### المسار خطوة بخطوة:

```
1. Lexer → رموز
   [KEYWORD_IMPORT][IDENTIFIER:"رسومات"]
   [IDENTIFIER:"واجهة"][IDENTIFIER:"عداد"]
   [AT_SIGN][IDENTIFIER:"حالة"][IDENTIFIER:"عدد"][OP_ASSIGN][NUMBER:0]
   [KEYWORD_FUNCTION][IDENTIFIER:"بناء"][PAREN_LEFT][PAREN_RIGHT]
   ...

2. Parser → AST
   ├── ImportStmt("رسومات")
   ├── UIDeclarationNode("عداد")
   │   ├── stateDecls: [UIStateDecl(STATE, "عدد", init=0)]
   │   └── methods: [FunctionDecl("بناء", body=[
   │       ReturnStmt(
   │           UIWidgetExprNode("عمود", children=[
   │               UIWidgetExprNode("نص", args=[MemberAccess(هذا.عدد)],
   │                   modifiers=[UIModifierNode("حجم", [32])]),
   │               UIWidgetExprNode("زر", args=["زيادة"],
   │                   modifiers=[UIModifierNode("عند_النقر", event=Arrow(هذا.عدد += 1))])
   │           ])
   │       )])]
   └── ExpressionStmt(CallExpr("تشغيل_تطبيق", [NewExpr("عداد")]))

3. Interpreter يُنفذ:
   أ. visitImportStmt("رسومات") →
      BuiltinModuleRegistry يُحمّل registerWidgetBuiltins + registerUIBuiltins

   ب. visitUIDeclaration("عداد") →
      ClassManager.registerClass(ClassType{
          name="عداد", isUIComponent=true,
          fields={عدد: PUBLIC, default=0},
          uiStateFields={"عدد"},
          methods={بناء: FunctionDecl...}
      })

   ج. "عداد()" → ObjectInstance{className="عداد", fields={عدد:0}}

   د. "تشغيل_تطبيق(obj)" →
      UIBridge::run(obj, interpreter)

4. UIBridge::run():
   أ. يكتشف أن obj هو ObjectInstance لمكون واجهة
   ب. يستدعي obj.بناء() → visitUIWidgetExpr():
      - عمود → WidgetBuilder(Column)
        - نص(هذا.عدد) → WidgetBuilder(Text, محتوى="0")
          - .حجم(32) → setIRProperty("حجم", 32)
        - زر("زيادة") → WidgetBuilder(Button, عنوان="زيادة")
          - .عند_النقر => ... → registerHandler(arrow_fn) → handlerId
          - addIREvent("عند_النقر", handlerId)
   ج. يستخرج شجرة IRNode النهائية

5. LayoutEngine::layout(irRoot, constraints):
   - measureColumn() → يحسب حجم العمود من أحجام الأبناء
   - arrange() → يحدد مواقع: نص في الأعلى، زر تحته
   - ينتج LayoutResult

6. PlatformRenderer::renderNode(irRoot, layout):
   - Column → لا شيء (حاوية)
     - Text → يرسم "0" بحجم 32
     - Button → يرسم خلفية + "زيادة"

7. عند النقر على الزر:
   - SDL يُبلغ عن حدث نقر
   - MouseEventProcessor يحدد العنصر المستهدف
   - UIBridge::invokeHandler(handlerId) → ينفذ هذا.عدد += 1
   - UIBridge::rebuildUI() → يعيد بناء الشجرة
   - الآن نص يعرض "1"
```
