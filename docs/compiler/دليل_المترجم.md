# المترجم sadc — دليل البنية الداخلية

## نظرة عامة

المترجم `sadc` يحوّل كود لغة ص إلى ملفات تنفيذية أصلية عبر LLVM 18.
يدعم منصات متعددة: Windows، Linux، macOS، Android، iOS.

## خط أنابيب الترجمة

```
                    ┌──────────────┐
    كود ص (.ص) ───→│ المحلل       │──→ AST
                    │ المعجمي+النحوي│
                    └──────────────┘
                           │
                    ┌──────▼───────┐
                    │   SIR        │──→ تمثيل وسيط ملكي
                    │  Builder     │    (12 تعليمة فريدة)
                    └──────────────┘
                           │
                    ┌──────▼───────┐
                    │   SIR        │──→ تحسينات:
                    │  Optimizer   │    - حذف الكود الميت
                    └──────────────┘    - طي الثوابت
                           │            - تحسين الحلقات
                    ┌──────▼───────┐
                    │   LLVM       │──→ LLVM IR
                    │  CodeGen     │
                    └──────────────┘
                           │
                    ┌──────▼───────┐
                    │   LLVM       │──→ كود أصلي
                    │  Backend     │    (x86-64, ARM64, WASM)
                    └──────────────┘
```

## الملفات الرئيسية

### SIR (Sad Intermediate Representation)
| الملف | الوصف |
|-------|-------|
| `compiler_new/src/sir/sir_opcodes.h` | تعليمات SIR (12 ملكية + 40+) |
| `compiler_new/src/sir/sir_builder.h` | بناء SIR من AST |
| `compiler_new/src/sir/sir_optimizer.h` | تحسينات SIR |

### LLVM CodeGen
| الملف | الوصف |
|-------|-------|
| `compiler_new/src/backend/llvm/llvm_codegen.cpp` | المولّد الرئيسي |

| `compiler_new/src/backend/llvm/llvm_codegen_wasm.cpp` | هدف WASM |

| الملف | الوصف |
|-------|-------|
| `compiler_new/src/backend/android_compose.cpp` | مولّد Jetpack Compose |

| الملف | الوصف |
|-------|-------|

## تعليمات SIR الملكية (12 تعليمة)

| التعليمة | الوصف |
|----------|-------|
| `SIR_ALLOC` | حجز ذاكرة |
| `SIR_FREE` | تحرير ذاكرة |
| `SIR_MOVE` | نقل ملكية |
| `SIR_BORROW` | استعارة مرجع |
| `SIR_BORROW_MUT` | استعارة متغيرة |
| `SIR_DROP` | إسقاط (تدمير) |
| `SIR_SCOPE_BEGIN` | بداية نطاق |
| `SIR_SCOPE_END` | نهاية نطاق |
| `SIR_LIFETIME_BEGIN` | بداية عمر |
| `SIR_LIFETIME_END` | نهاية عمر |
| `SIR_RC_INC` | زيادة عداد المراجع |
| `SIR_RC_DEC` | نقصان عداد المراجع |

## الاستخدام

```powershell
# ترجمة ملف بسيط
sadc ملف.ص -o ملف.exe

# ترجمة لهدف Android
sadc --target android ملف.ص -o ملف.apk

# ترجمة لهدف iOS (SwiftUI)
sadc --target ios-swiftui ملف.ص -o مشروع/

# ترجمة لهدف WASM
sadc --target wasm ملف.ص -o ملف.wasm

# عرض SIR (للتصحيح)
sadc --emit-sir ملف.ص

# عرض LLVM IR
sadc --emit-llvm ملف.ص
```

## البناء

```powershell
# يتطلب LLVM 18
cmake -S . -B build -DENABLE_LLVM_BACKEND=ON
cmake --build build --config Debug --target sadc
```
