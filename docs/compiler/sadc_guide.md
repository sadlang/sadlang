# توثيق المترجم sadc

> دليل استخدام المترجم الأصلي للغة ص

## نظرة عامة

`sadc` (Sad Compiler) هو المترجم الأصلي للغة ص، يحول كود `.ص` إلى ملفات تنفيذية أصلية باستخدام LLVM.

## التثبيت

```powershell
# Windows
winget install sad-lang.sadc

# أو من المصدر
cmake --build build --config Release --target sadc
```

## الاستخدام الأساسي

```powershell
# ترجمة ملف إلى ملف تنفيذي
sadc برنامج.ص -o برنامج.exe

# ترجمة مع تحسينات
sadc برنامج.ص -O2 -o برنامج.exe

# ترجمة إلى WASM
sadc برنامج.ص --target=wasm32 -o برنامج.wasm

# عرض IR الوسيط
sadc برنامج.ص --emit-sir

# عرض LLVM IR
sadc برنامج.ص --emit-llvm
```

## خيارات سطر الأوامر

### الإخراج

| الخيار | الوصف |
|--------|-------|
| `-o ملف` | اسم ملف الإخراج |
| `--emit-sir` | طباعة SIR (التمثيل الوسيط) |
| `--emit-llvm` | طباعة LLVM IR |
| `--emit-asm` | طباعة كود التجميع |
| `--emit-obj` | إنتاج ملف كائن (.o) |

### التحسينات

| الخيار | الوصف |
|--------|-------|
| `-O0` | بدون تحسين (افتراضي) |
| `-O1` | تحسين أساسي |
| `-O2` | تحسين متوسط (موصى به للإنتاج) |
| `-O3` | تحسين أقصى |
| `-Os` | تحسين للحجم |
| `-Oz` | تحسين أقصى للحجم |

### التصحيح

| الخيار | الوصف |
|--------|-------|
| `-g` | تضمين معلومات التصحيح (DWARF) |
| `--debug-info=dwarf` | تفعيل DWARF صريحاً |
| `--source-map` | إنتاج source map (لـ WASM) |

### المنصات المستهدفة

| الخيار | الوصف |
|--------|-------|
| `--target=x86_64-windows` | Windows 64-bit |
| `--target=x86_64-linux` | Linux 64-bit |
| `--target=x86_64-darwin` | macOS Intel |
| `--target=arm64-darwin` | macOS Apple Silicon |
| `--target=arm64-linux` | Linux ARM64 |
| `--target=wasm32` | WebAssembly |

### الربط

| الخيار | الوصف |
|--------|-------|
| `-L مسار` | إضافة مسار مكتبات |
| `-l مكتبة` | ربط مكتبة |
| `--static` | ربط ثابت |
| `--shared` | إنتاج مكتبة مشتركة |
| `--no-stdlib` | بدون المكتبة القياسية |

### متقدم

| الخيار | الوصف |
|--------|-------|
| `--verbose` | إخراج تفصيلي |
| `--time` | عرض وقت كل مرحلة |
| `--stats` | عرض إحصائيات |
| `--dump-ast` | طباعة AST |
| `--dump-types` | طباعة معلومات الأنواع |

## أمثلة عملية

### 1. برنامج بسيط

```sad
# مرحبا.ص
دالة رئيسية()
    اطبع_سطر("مرحبا بالعالم!")
    ارجع 0
نهاية
```

```powershell
sadc مرحبا.ص -o مرحبا.exe
./مرحبا.exe
# الناتج: مرحبا بالعالم!
```

### 2. برنامج مع مكتبات

```sad
# حاسبة.ص
استورد "رياضيات"

دالة رئيسية()
    متغير س = جذر_تربيعي(16.0)
    اطبع_سطر("الجذر التربيعي لـ 16 = " + نص(س))
    ارجع 0
نهاية
```

```powershell
sadc حاسبة.ص -o حاسبة.exe
```

### 3. ترجمة متعددة الملفات

```powershell
# ترجمة وحدات منفصلة
sadc utils.ص --emit-obj -o utils.o
sadc main.ص --emit-obj -o main.o

# الربط
sadc utils.o main.o -o برنامج.exe
```

### 4. ترجمة لـ WASM

```powershell
sadc ويب.ص --target=wasm32 -Os -o ويب.wasm

# مع source map
sadc ويب.ص --target=wasm32 --source-map -o ويب.wasm
```

### 5. ترجمة متقاطعة (Cross-compilation)

```powershell
# من Windows إلى Linux
sadc برنامج.ص --target=x86_64-linux -o برنامج

# من Windows إلى macOS ARM
sadc برنامج.ص --target=arm64-darwin -o برنامج
```

## SIR (Sad Intermediate Representation)

SIR هو التمثيل الوسيط الملكي للغة ص، يتكون من 12 تعليمة:

| التعليمة | الوصف |
|----------|-------|
| `SIR_CONST` | تحميل ثابت |
| `SIR_LOAD` | تحميل متغير |
| `SIR_STORE` | تخزين قيمة |
| `SIR_ADD`, `SUB`, `MUL`, `DIV` | عمليات حسابية |
| `SIR_CMP` | مقارنة |
| `SIR_JUMP` | قفز غير شرطي |
| `SIR_BRANCH` | قفز شرطي |
| `SIR_CALL` | استدعاء دالة |
| `SIR_RETURN` | إرجاع |
| `SIR_ALLOC` | تخصيص ذاكرة |
| `SIR_FIELD` | وصول لحقل |

## تحسينات SIR

| المرور | الوصف |
|--------|-------|
| DCE | إزالة الكود الميت |
| CSE | حذف التعابير المشتركة |
| Const Fold | طيّ الثوابت |
| Inline | تضمين الدوال الصغيرة |
| Loop | تحسين الحلقات |

## رسائل الأخطاء

المترجم يدعم رسائل خطأ محسّنة بالعربية:

```
خطأ[E0301]: متغير غير معرّف: `س`
   --> برنامج.ص:5:10
    |
  5 |     اطبع(س)
    |          ^
    |
    = تلميح: هل تقصد `ص`؟
    = ملاحظة: عرّف المتغير باستخدام `متغير س = قيمة`
```

## استكشاف الأخطاء

### خطأ: LLVM غير موجود

```
تأكد من:
1. تثبيت LLVM 18
2. إضافة LLVM_DIR إلى PATH
3. بناء sadc مع ENABLE_LLVM_BACKEND=ON
```

### خطأ: Debug/Release mismatch

```
sadc يجب أن يُبنى بنفس تكوين LLVM:
- LLVM Release → sadc Release
- LLVM Debug → sadc Debug
```

### الأداء بطيء

```
جرب:
1. استخدم -O2 أو -O3
2. تأكد من بناء Release
3. فعّل LTO: --lto
```
