## تحليل الفجوات بين النواة والمكونات المستقلة

| المجال | ما تدعمه النواة ✅ | ما يضيفه المكون المستقل ⭐ | حجم الفجوة |
|---|---|---|---|
| **OOP أساسي** | `صنف`, `باني`, `هدم`, حقول, طرق, `يرث`, `عام/خاص/محمي`, `ساكن`, `مجرد` | `class_parser`: تحويل صنف→هيكل+نفّذ (sugar desugar) | ⬜ لا فجوة |
| **البواني** | `باني(...)`, قائمة تهيئة, `هذا.حقل = قيمة`, `الأساس(...)` | `constructor_parser`: بواني نسخ/نقل/تحويل, delegation متقدم | 🟡 صغيرة |
| **الامتداد** | `امتداد نوع ... نهاية` مع دوال فقط | `extension_parser`: معاملات نوع `[T]`, قيود `حيث`, `&هذا`/`&متغير هذا` | 🟠 متوسطة |
| **Async/Await** | `دالة غير_متزامن اسم()` (flag), `انتظر تعبير` | `async_parser`: فئة async محددة النوع. `await_parser`: parallel join, race, timeout, select | 🔴 كبيرة |
| **المولدات** | `مولد دالة اسم()`, `parseYieldStmt()` بسيط | `yield_parser`: delegation `أنتج*`, yield في تدفقات async | 🟡 صغيرة |
| **العقود البرمجية** | `يتطلب`/`يضمن` بسيط (تعبير واحد) | `contract_parser`: تعبيرات كمية (`لكل`/`يوجد`), ثوابت invariant, `يفترض`, `يؤكد` | 🟠 متوسطة |
| **الماكروز** | `ماكرو اسم(معاملات) ... نهاية`, `...rest` variadic | `macro_pattern_parser`: أنماط `$اسم:نوع`, تكرار `$(...)*/+/?`, ماكروز إجرائية | 🔴 كبيرة |
| **القوالب** | `قالب<نوع ت>`, `حيث ت: سمة1 + سمة2` | `generics_parser`: قيود متعددة, وسائط نوع `<...>` | 🟡 صغيرة |
| **الأعمار** | `<'أ, 'ب>` بسيط | `lifetime_parser`: أنواع أعمار (مسمى/ثابت/مجهول/استنتاجي), حدود, علاقات | 🟠 متوسطة |
| **FFI** | `خارجي("link_name") دالة ...` بسيط | `extern_parser`: كتل `خارجي("C") { ... }`, أنواع C, اتفاقيات استدعاء, تعليقات ملكية | 🔴 كبيرة |
| **التجميع المُدمج** | `@تجميع("code")` توجيه بسيط | `asm_parser`: `تجميع!("instr" : outputs : inputs : clobbers : options)`, قيود x86/ARM/RISC-V | 🔴 كبيرة |
| **تعليقات التوثيق** | التقاط `DOC_COMMENT` كـ string | `doc_comment_parser`: تحليل هيكلي: `@معطى`, `@أرجع`, `@مثال`, `DocBlock` | 🟠 متوسطة |
| **Pipeline** | `a \|> f` → `f(a)` (desugaring بسيط) | `pipeline_parser`: تطبيق جزئي `a \|> f(_, b)`, method chaining | 🟡 صغيرة |
| **Comprehension** | `[x لكل x في قائمة]`, dict comprehension بسيط | `comprehension_parser`: مجموعات, مولدات, فهم async. `dict_comprehension`: دمج, مفاتيح محسوبة | 🟡 صغيرة |
| **اختبار الخصائص** | `اختبر("نص") تكرارات N بذرة S` بسيط | `property_test_attr`: سمات `#[اختبار_خاصية(...)]`, `PropertyTestFunction` | 🟡 صغيرة |
| **حراسة الأنماط** | شروط `إذا` في `طابق` | `pattern_guard`: `GuardChecker` يتحقق من صحة الشرط وربط المتغيرات | 🟡 صغيرة |
| **العقود الذكية** | `عقد اسم ... نهاية` → `parseClassDecl()` مع `isContract=true` | `contract_syntax`: سمات Solidity, أحداث, storage, حماية | 🔴 كبيرة (مستقبلي) |
| **UI** | `واجهة اسم ... نهاية`, widgets, modifiers | `ui_parser`: خرائط ترجمة عربي↔إنجليزي | ⬜ متكامل |
| **استعادة الأخطاء** | `synchronize()` في helpers | `error_recovery`: محرك كامل متعدد الاستراتيجيات | 🟡 صغيرة |
