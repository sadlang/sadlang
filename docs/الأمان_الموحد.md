# الأمان الموحَّد في لغة ص (Sad Unified Security)

> **الإصدار**: 1.0 — توثيق نظام `shared/security` بعد المراحل 4-8 من توحيد طبقة الأمان
> **النطاق**: المفسر، المترجم، الآلة الافتراضية، المكتبة القياسية، runtime
> **الهدف**: واجهة موحدة لكل عمليات تحويل الأنواع، فحص الحدود، وتعقيم المدخلات

## ١. لمحة عامة

`shared/security/` يحوي **خمسة مكونات أمان أساسية** يستخدمها كل مسارات التنفيذ في لغة ص بدون تكرار:

| المكون | الملف | الغرض |
|---|---|---|
| `SafeArithmetic` | `safe_arithmetic.h` | تحويل آمن بين الأنواع العددية مع كشف الفيض (overflow) |
| `BoundsChecker` | `bounds_checker.h` | فحص فهارس المصفوفات، صحة المؤشرات، حماية التخصيص، التحقق من الشرائح |
| `InputSanitizer` | `input_sanitizer.h` + `.cpp` | تعقيم الأوامر، المسارات، SQL، HTML + تحليل أرقام آمن |
| `OwnershipManager` | `shared/ownership/` | تتبع ملكية القيم وحدود استعارتها |
| `ProfilerHooks` | `shared/profiler/` | نقاط ربط لمراقبة العمليات الحساسة وقت التشغيل |

كل المكونات في الفضاء `Sad::Security`. مكتبة CMake: `sad_security_core`.

## ٢. SafeArithmetic — التحويل الآمن للأنواع

### ٢.١ المشكلة (قبل التوحيد)

كان `static_cast<int>(container.size())` منتشراً عبر ٢٢٢+ موقع في الكود. على المنصات 64-bit حيث `size_t = uint64_t`، أي حاوية تتجاوز `INT_MAX` (~٢ مليار عنصر) كانت تُسبب **اقتطاع صامت** بدون أي تحذير.

### ٢.٢ الواجهة العامة

```cpp
namespace Sad::Security::SafeArithmetic {
    // (AR) تحويل آمن مع رمي std::overflow_error عند الفيض
    // (EN) Safe cast that throws std::overflow_error on overflow
    template<typename To, typename From>
    To assertSafeCast(From value, const char* contextName);

    // (AR) فحص الإمكانية بدون رمي — يُرجع bool
    // (EN) Boolean check without throwing — returns bool
    template<typename To, typename From>
    bool checkSafeCast(From value);
}
```

### ٢.٣ مثال (C++)

```cpp
#include "safe_arithmetic.h"

void sendBuffer(const std::vector<char>& data) {
    // (AR) قبل التوحيد — اقتطاع صامت إذا data.size() > INT_MAX
    // int len = static_cast<int>(data.size());

    // (AR) بعد التوحيد — يرمي std::overflow_error مع context name
    int len = Sad::Security::SafeArithmetic::assertSafeCast<int>(
        data.size(), "sendBuffer_data_size"
    );

    ::send(socket, data.data(), len, 0);
}
```

## ٣. BoundsChecker — فحص الحدود الموحَّد

### ٣.١ الواجهة العامة

```cpp
namespace Sad::Security {
class BoundsChecker {
public:
    // فهرسة المصفوفات
    static bool checkArrayIndex(std::size_t index, std::size_t size) noexcept;
    static void assertArrayIndex(std::size_t index, std::size_t size, const char* arrayName);
    static bool checkArrayRange(std::size_t start, std::size_t end, std::size_t size) noexcept;
    static void assertArrayRange(std::size_t start, std::size_t end, std::size_t size, const char* arrayName);

    // المؤشرات والمحاذاة
    static bool checkNotNull(const void* ptr) noexcept;
    static void assertNotNull(const void* ptr, const char* name);
    static bool checkAlignment(const void* ptr, std::size_t alignment) noexcept;
    static void assertAlignment(const void* ptr, std::size_t alignment, const char* name);

    // التخصيص (سقف 1 GB افتراضي)
    static bool checkAllocationSize(std::size_t size) noexcept;
    static void assertAllocationSize(std::size_t size); // throws std::bad_alloc
    static bool checkSizeMultiply(std::size_t a, std::size_t b, std::size_t& result) noexcept;

    // النسخ الآمن (memcpy / memmove تلقائياً)
    static bool checkNoOverlap(const void* src, std::size_t srcSize,
                               const void* dst, std::size_t dstSize) noexcept;
    static bool safeCopy(void* dst, std::size_t dstSize,
                         const void* src, std::size_t srcSize) noexcept;

    // الشرائح
    static bool checkSlice(const void* basePtr, std::size_t baseSize,
                           std::size_t offset, std::size_t length) noexcept;
    static void assertSlice(const void* basePtr, std::size_t baseSize,
                            std::size_t offset, std::size_t length, const char* name);
};
}
```

### ٣.٢ النمطان الأساسيان

**النمط أ — فحص دفاعي قبل subscript** (يستخدم `checkArrayIndex` للحفاظ على الدلالة):

```cpp
// قبل
if (idx < params.size()) {
    arg.setName(params[idx].name);
}

// بعد
if (Sad::Security::BoundsChecker::checkArrayIndex(idx, params.size())) {
    arg.setName(params[idx].name);
}
```

**النمط ب — فهرسة مع فشل سريع** (يستخدم `assertArrayIndex` لرمي استثناء):

```cpp
Sad::Security::BoundsChecker::assertArrayIndex(idx, params.size(), "params");
arg.setName(params[idx].name); // مضمون السلامة
```

### ٣.٣ التغطية بعد المرحلة 8

١٨ موقع تم توحيدها (نمط أ) عبر ١٢ ملف في المترجم والمفسر. ١٣ موقع متبقٍ تُركت بحسب قاعدة BF-04 لأنها early-exit آمنة لا تؤدي إلى subscript خاطئ.

## ٤. InputSanitizer — تعقيم المدخلات

### ٤.١ الواجهة المختارة

```cpp
namespace Sad::Security {
class InputSanitizer {
public:
    // الأوامر
    static std::string sanitizeCommand(const std::string& input);
    static bool isCommandSafe(const std::string& cmd);
    static int safeSystem(const std::string& cmd); // throws على الخطر

    // المسارات
    static std::string sanitizePath(const std::string& path);
    static bool isPathWithinDirectory(const std::string& path, const std::string& allowedDir);
    static bool isValidFileName(const std::string& filename);

    // SQL و HTML
    static std::string sanitizeSQL(const std::string& input);
    static bool isSQLSafe(const std::string& query);
    static std::string sanitizeHTML(const std::string& input);
    static std::string stripTags(const std::string& input);

    // تحليل أرقام آمن (يُغني عن scanf)
    static bool safeParseInt(const std::string& str, std::int64_t& result);
    static bool safeParseDouble(const std::string& str, double& result);
};
}
```

### ٤.٢ استبدال scanf

في `compiler/src/backend/llvm/llvm_runtime_io_gc.cpp`:

```cpp
// قبل (سيئ التهيئة)
int64_t value;
scanf("%lld", (long long*)&value);

// بعد (آمن، حد واضح للمخزن)
char buffer[64];
if (fgets(buffer, sizeof(buffer), stdin) != nullptr) {
    std::int64_t parsed = 0;
    if (Sad::Security::InputSanitizer::safeParseInt(std::string(buffer), parsed)) {
        value = parsed;
    }
}
```

### ٤.٣ استبدال strcpy

النمط الموثوق داخلياً (الوجهة `new char[result.size()+1]`):

```cpp
// قبل
char* output = new char[result.size() + 1];
std::strcpy(output, result.c_str());

// بعد — أسرع وأكثر صراحة
const std::size_t bufSize = result.size() + 1;
char* output = new char[bufSize];
std::memcpy(output, result.c_str(), bufSize);
```

(لا حاجة لـ `InputSanitizer` هنا لأن المصدر داخلي موثوق — قاعدة BF-04.)

## ٦. حلول مشاكل MSVC الشائعة

### ٦.١ خطأ "dependent name" داخل lambdas المتشعبة

عند استخدام `Sad::Security::SafeArithmetic::assertSafeCast<int>(...)` داخل lambda متشعبة في `namespace Sad`، MSVC يعتبر الاسم dependent ويفشل:

```
error C7510: 'SafeArithmetic': use of dependent type name must be prefixed with 'typename'
```

**الحل المعتمد**: ألياس على مستوى الملف (خارج كل lambdas):

```cpp
namespace Sad {
namespace Interpreter {

namespace SecurityNS = ::Sad::Security; // ← الحل

void someFunction() {
    auto lambda = [&]() {
        auto inner = [&]() {
            int n = SecurityNS::SafeArithmetic::assertSafeCast<int>(v.size(), "ctx");
        };
    };
}

}}
```

### ٦.٢ خطأ "cannot find file" بعد إضافة include في كتلة `#ifdef`

أداة patch_safe_cast_v3.py تتعقَّب depth الـ preprocessor. **يجب** أن يُدرَج `#include "safe_arithmetic.h"` في `depth=0` فقط (خارج أي `#ifdef _WIN32 / #else`)، وإلا سيُتاح للمنصة الأخرى فقط.

## ٩. خطوات إضافة موقع جديد (دليل المطور)

1. اقرأ هذا المستند للتعرف على الـAPI الصحيح
2. اختر المكون المناسب:
   - تحويل `size_t → int`؟ → `SafeArithmetic::assertSafeCast`
   - فهرسة مصفوفة بفحص؟ → `BoundsChecker::checkArrayIndex`
   - مدخل من المستخدم؟ → `InputSanitizer::*`
3. أضف `#include` المناسب في `depth=0`
4. تأكد أن المكتبة المستهدفة مرتبطة بـ `sad_security_core` (انظر §٥)
5. اختبر: `cmake --build build --target <lib>` ثم `ctest -L hub`
