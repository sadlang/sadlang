# تعريف المتغيرات في لغة ص

هذا الملف يشرح بشكل موجز وواضح طرق تعريف المتغيرات في لغة ص وأنواع القيم المدعومة. كل الشرح والأمثلة مكتوبة باللغة العربية فقط، دون استخدام أي أحرف إنجليزية.

## أنواع القيم المتاحة
- الأنواع البدائية: رقم، عشري، منطقي، نص، عدم
- الأنواع المرجعية: مصفوفة، قاموس، كائنات/أصناف
- أنواع الدوال: دالة، إغلاق
- أنواع منخفضة المستوى: مؤشر (إن وُجد دعم)

## طرق تعريف المتغير
فيما يلي الصيغ المختلفة لتعريف المتغيرات في لغة ص مع مثال عربي لكل صيغة.

### ١. تعريف ثابت
**القاعدة:** يعرّف علاقة ثابتة لا يمكن إعادة ربطها بعد التهيئة.

**مثال:**
```
ثابت π : عشري = 3.14159
```

### ٢. تعريف متغير نطاق كتلة
**القاعدة:** متغير قابل للتغيير داخل النطاق (كتلة أو دالة).

**مثال:**
```
متغير عدد : رقم = 0
عدد = عدد + 1
```

### ٣. تعريف متغير تقليدي
**القاعدة:** متغير قابل للتغيير؛ نطاقه قد يختلف حسب قواعد اللغة.

**مثال:**
```
متغير اسم = "علي"
اسم = "أمينة"
```

### ٤. صيغة النوع أولاً
**القاعدة:** كتابة النوع ثم اسم المتغير ثم المهيئ الاختياري.

**مثال:**
```
رقم س = 42
نص عنوان = "وثيقة"
```

### ٥. متغير من نوع صنف
**القاعدة:** استخدام اسم الصنف كنوع لتعريف مرجع إلى كائن.

**مثال:**
```
نقطة p = انشاء نقطة(1, 2)
p.x = 10
```

### ٦. متغير صادر/عام
**القاعدة:** وضع كلمة التصدير قبل التصريح يجعل المتغير مرئياً كوحدة مُصدّرة أو عام.

**مثال:**
```
صدّر ثابت النسخة : نص = "1.0"
```

### ٧. استنتاج النوع
**القاعدة:** إذا لم يذكر النوع، يستنتج النظام نوع المتغير من المهيئ.

**مثال:**
```
متغير بيانات = [1,2,3]   # يستنتج كمصفوفة<رقم>
```

### ٨. أنواع عامة / معاملات نوعية
**القاعدة:** دعم تعريف مصفوفة أو قاموس بمعامل نوع، مثال توضيحي.

**مثال:**
```
مصفوفة<رقم> أرقام = [1,2,3]
قاموس<نص, رقم> جدول = {"س": 10}
```

## ملاحظات عملية
- استخدم التعريف الثابت للقيم التي لا تتغير لتقليل الأخطاء.
- تأكد من فحص النوع وقت التشغيل قبل إجراء عمليات حساسة مثل الوصول لخاصية على قيمة غير كائن.
- المتغيرات المصنفة كأصناف هي مراجع تُدار عبر مدير الكائنات وقد تتشارك الحالة بين المراجع.

هذا كل ما يلزم كتوضيح موجز ومبني على تمثيلات اللغة في المشروع. إذا رغبت، أستطيع تحويل أمثلة محددة إلى ملفات اختبار قابلة للتشغيل داخل بيئة التنفيذ المحلية.
