# مقتطفات المحرّرات (VS Code) — مولَّدة من مصدر الحقيقة

ملفّ [`sad.code-snippets`](sad.code-snippets) هو **ناتج مولَّد** لقوالب بُنى لغة ص
(دالة/رئيسية/إذا/لكل/بينما/طابق/بنية/تعداد/صنف/حاول-امسك/اختبر/متغيّر/ثابت/استورد)،
تستهلكه المحرّرات (محراب، إضافات VS Code) لتسريع الكتابة وتقليل أخطاء الإملاء في
الكلمات العربيّة. **لا تُحرِّره يدويًّا.**

## التوليد

```bash
python3 scripts/codegen/gen_snippets.py
```

يقرأ المولِّد الكلمات المفتاحيّة الرسميّة من [`language-truth/keywords.yaml`](../../language-truth/keywords.yaml)
فتتبع المقتطفات اللغة آليًّا: **كلّ كلمة عربيّة في القالب مأخوذة من مصدر الحقيقة** (لا تُكتب
حرفيًّا)، وما عداها سقالة عرض (أقواس، مواضع إدراج `${1:…}`). لا يوسّع المولِّد مصدر الحقيقة.

## حارس الانجراف

```bash
python3 scripts/codegen/gen_snippets.py --check
```

يفشل إن انجرف الملفّ المُلتزَم عن المولَّد (مقارنة نصّيّة دقيقة، LF حصرًا). يشغّله CI في
[`snippets-check.yml`](../../.github/workflows/snippets-check.yml) عند تغيّر `keywords.yaml`
أو المولِّد أو المقتطفات.

## التسليم إلى محراب

المقتطفات ليست جزءًا من هذا المستودع للمحرّر مباشرةً؛ تُنسَخ إلى إضافة `sad-lang` في محراب
عبر `build/sync-grammar.sh` هناك (كنحو TextMate). النسختان متطابقتان بايتيًّا.
