# مكتبة التحقق ✅

مكتبة للتحقق من صحة البيانات — تدعم النصوص والأرقام والبريد وكلمات المرور.

## التثبيت

```sad
من مكتبات_خارجية.التحقق.src.مكتبة استورد بريد_صالح, في_نطاق, أرقام_فقط
```

## الاستخدام

### تحقق بسيط

```sad
اطبع_سطر(بريد_صالح("user@example.com"))  # صحيح
اطبع_سطر(في_نطاق(25, 0, 100))            # صحيح
اطبع_سطر(أرقام_فقط("12345"))              # صحيح
```

### قوة كلمة المرور

```sad
من مكتبات_خارجية.التحقق.src.مكتبة استورد قوة_كلمة_مرور
متغير نتيجة = قوة_كلمة_مرور("MyP@ss123")
اطبع_سطر("القوة: " + نتيجة[0])
```

### محقق متسلسل

```sad
من مكتبات_خارجية.التحقق.src.مكتبة استورد محقق
متغير م = جديد محقق("بيانات المستخدم")
م.تحقق_ليس_فارغاً("أحمد")
م.تحقق_بريد("user@mail.com")
متغير ن = م.النتيجة()
```

## واجهة برمجة التطبيقات

### دوال التحقق

| الدالة | الوصف |
|--------|-------|
| `ليس_فارغاً(نص)` | ليس فارغاً |
| `هو_رقم(القيمة)` | هل هو رقم؟ |
| `في_نطاق(القيمة, أدنى, أقصى)` | ضمن نطاق |
| `موجب(القيمة)` | موجب |
| `سالب(القيمة)` | سالب |
| `زوجي(القيمة)` | زوجي |
| `فردي(القيمة)` | فردي |
| `طول_بين(نص, أدنى, أقصى)` | طول النص ضمن نطاق |
| `أرقام_فقط(نص)` | أرقام فقط |
| `حروف_فقط(نص)` | حروف فقط |
| `بريد_صالح(بريد)` | بريد إلكتروني صالح |
| `مصفوفة_ليست_فارغة(م)` | مصفوفة غير فارغة |
| `يبدأ_بـ(نص, بادئة)` | يبدأ بنص معين |
| `ينتهي_بـ(نص, لاحقة)` | ينتهي بنص معين |
| `قوة_كلمة_مرور(كلمة)` | تقييم القوة [قوة, أخطاء] |
| `لون_صالح(الرقم)` | فحص Luhn (بطاقات الائتمان) |
| `url_صالح(الرابط)` | رابط URL صالح |
| `عدد_صحيح(القيمة)` | عدد صحيح بلا كسور |

### صنف `محقق`

| الدالة | الوصف |
|--------|-------|
| `باني(الاسم)` | إنشاء محقق |
| `تحقق_ليس_فارغاً(القيمة)` | تسلسل: ليس فارغاً |
| `تحقق_طول(القيمة, أدنى, أقصى)` | تسلسل: طول |
| `تحقق_أرقام(القيمة)` | تسلسل: أرقام فقط |
| `تحقق_بريد(القيمة)` | تسلسل: بريد صالح |
| `تحقق_نطاق(القيمة, أدنى, أقصى)` | تسلسل: ضمن نطاق |
| `النتيجة()` | الحصول على نتيجة التحقق |

### صنف `نتيجة`

| الدالة | الوصف |
|--------|-------|
| `باني()` | إنشاء نتيجة |
| `أضف_خطأ(رسالة)` | إضافة خطأ |
| `اطبع_الأخطاء()` | عرض الأخطاء |
