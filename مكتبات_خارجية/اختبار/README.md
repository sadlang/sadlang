# مكتبة اختبار 🧪

إطار اختبار وحدات شامل بلغة ص — يدعم التأكيدات والمجموعات وطاقم الاختبار.

## التثبيت

```sad
من مكتبات_خارجية.اختبار.src.مكتبة استورد مجموعة, تأكد_يساوي, تأكد_صحيح, تقرير
```

## الاستخدام

### اختبار بسيط

```sad
مجموعة("الحساب")
تأكد_يساوي(2 + 2, 4, "جمع صحيح")
تأكد_صحيح(10 > 5, "مقارنة صحيحة")
تقرير()
```

### طاقم اختبار

```sad
من مكتبات_خارجية.اختبار.src.مكتبة استورد طاقم_اختبار

متغير ط = جديد طاقم_اختبار("الرياضيات")
# أضف اختبارات كدوال
ط.شغّل()
```

## واجهة برمجة التطبيقات

### دوال التأكيد

| الدالة | الوصف |
|--------|-------|
| `تأكد_يساوي(الفعلي, المتوقع, الوصف)` | التحقق من المساواة |
| `تأكد_لا_يساوي(الفعلي, القيمة, الوصف)` | التحقق من عدم المساواة |
| `تأكد_صحيح(شرط, الوصف)` | الشرط صحيح |
| `تأكد_خطأ(شرط, الوصف)` | الشرط خاطئ |
| `تأكد_أكبر(الفعلي, الحد, الوصف)` | أكبر من |
| `تأكد_أصغر(الفعلي, الحد, الوصف)` | أصغر من |
| `تأكد_أكبر_أو_يساوي(الفعلي, الحد, الوصف)` | أكبر أو يساوي |
| `تأكد_أصغر_أو_يساوي(الفعلي, الحد, الوصف)` | أصغر أو يساوي |
| `تأكد_ليس_لاشيء(القيمة, الوصف)` | ليس null |
| `تأكد_لاشيء(القيمة, الوصف)` | يساوي null |
| `تأكد_قريب(الفعلي, المتوقع, الهامش, الوصف)` | تقريبياً متساوي |
| `تأكد_في_نطاق(القيمة, أدنى, أقصى, الوصف)` | ضمن نطاق |
| `تأكد_يرمي(دالة, الوصف)` | يرمي استثناء |
| `تأكد_لا_يرمي(دالة, الوصف)` | لا يرمي استثناء |

### دوال التنظيم

| الدالة | الوصف |
|--------|-------|
| `مجموعة(اسم)` | بدء مجموعة اختبار |
| `فاصل(الوصف)` | فاصل بصري |
| `تقرير()` | طباعة التقرير النهائي |
| `صفّر()` | إعادة تعيين العدادات |
| `عدد_الاختبارات()` | العدد الكلي |
| `عدد_النجاح()` | عدد الناجحة |
| `عدد_الفشل()` | عدد الفاشلة |
| `كل_الاختبارات_ناجحة()` | هل جميعها ناجحة؟ |

### صنف `طاقم_اختبار`

| الدالة | الوصف |
|--------|-------|
| `باني(الاسم)` | إنشاء طاقم |
| `أضف(اسم, دالة)` | إضافة اختبار |
| `شغّل()` | تشغيل جميع الاختبارات |
| `كل_الاختبارات_ناجحة()` | هل جميعها ناجحة؟ |
