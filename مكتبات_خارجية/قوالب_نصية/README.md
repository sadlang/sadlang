# مكتبة قوالب_نصية 📝

مكتبة لبناء وتنسيق النصوص — تدعم القوالب و HTML و Markdown و JSON و XML.

## التثبيت

```sad
من مكتبات_خارجية.قوالب_نصية.src.مكتبة استورد استبدل, نسّق, اضم
```

## الاستخدام

### قوالب بسيطة

```sad
متغير قالب = "مرحباً {{الاسم}}، عمرك {{العمر}}"
متغير نتيجة = استبدل(قالب, "الاسم", "أحمد")
نتيجة = استبدل(نتيجة, "العمر", "25")
اطبع_سطر(نتيجة)  # مرحباً أحمد، عمرك 25
```

### تنسيق متعدد

```sad
متغير بدائل = [["الاسم", "سارة"], ["المدينة", "الرياض"]]
متغير ن = نسّق("{{الاسم}} من {{المدينة}}", بدائل)
```

### ضم القوائم

```sad
متغير فواكه = ["تفاح", "برتقال", "موز"]
اطبع_سطر(اضم(فواكه, " و "))  # تفاح و برتقال و موز
```

## واجهة برمجة التطبيقات

### دوال القوالب

| الدالة | الوصف |
|--------|-------|
| `استبدل(قالب, المفتاح, القيمة)` | استبدال `{{مفتاح}}` بقيمة |
| `نسّق(قالب, الاستبدالات)` | تنسيق مع مصفوفة أزواج |
| `كرر(قالب, المفتاح, القائمة)` | تكرار لكل عنصر |
| `اضم(القائمة, الفاصل)` | ضم مصفوفة بفاصل |
| `سطر_جدول(الأعمدة, الفاصل)` | بناء سطر جدول |

### دوال HTML

| الدالة | الوصف |
|--------|-------|
| `عنصر_html(الوسم, المحتوى)` | عنصر HTML |
| `عنصر_html_مع_صنف(الوسم, الصنف, المحتوى)` | عنصر مع class |
| `قائمة_html(العناصر)` | قائمة `<ul>` |
| `جدول_html(الرؤوس, الصفوف)` | جدول `<table>` |
| `رابط_html(العنوان, النص)` | رابط `<a>` |
| `صورة_html(المصدر, النص)` | صورة `<img>` |
| `هروب_html(نص)` | تهريب رموز HTML |

### دوال Markdown

| الدالة | الوصف |
|--------|-------|
| `عنوان_md(المستوى, النص)` | عنوان # |
| `قائمة_md(العناصر)` | قائمة نقطية |
| `قائمة_مرقمة_md(العناصر)` | قائمة مرقمة |
| `عريض_md(النص)` | **عريض** |
| `مائل_md(النص)` | *مائل* |
| `رابط_md(النص, العنوان)` | رابط |

### دوال JSON/XML

| الدالة | الوصف |
|--------|-------|
| `json_كائن(الأزواج)` | بناء كائن JSON |
| `json_مصفوفة(العناصر)` | بناء مصفوفة JSON |
| `عنصر_xml(الوسم, المحتوى)` | عنصر XML |

### أدوات

| الدالة | الوصف |
|--------|-------|
| `كرر_نص(النص, العدد)` | تكرار نص |
| `محاذاة_يمين(النص, العرض, الحرف)` | محاذاة يمين |
| `محاذاة_يسار(النص, العرض, الحرف)` | محاذاة يسار |
