# مكتبة سجلات 📋

نظام تسجيل (logging) متكامل — يدعم المستويات والتصنيف والفلترة.

## التثبيت

```sad
من مكتبات_خارجية.سجلات.src.مكتبة استورد مسجل, تتبع, معلومة, خطأ_مستوى
```

## الاستخدام

### مسجل بسيط

```sad
متغير م = جديد مسجل("تطبيقي")
م.معلومة("التطبيق بدأ")
م.تحذير("ذاكرة منخفضة")
م.خطأ("فشل الاتصال")
```

### تصفية المستوى

```sad
م.عيّن_المستوى(3)  # تحذير فما فوق فقط
م.تصحيح("لن تظهر")
م.تحذير("ستظهر")
```

### عرض السجل

```sad
اطبع_سطر("عدد الرسائل: " + م.عدد_الرسائل())
اطبع_سطر("عدد الأخطاء: " + م.عدد_الأخطاء())
م.اطبع_الكل()
```

### حد أقصى

```sad
متغير م2 = جديد مسجل("محدود")
م2.عيّن_الحد(100)  # أقصى 100 رسالة
```

## واجهة برمجة التطبيقات

### ثوابت المستويات

| الثابت | القيمة | الرمز |
|--------|--------|-------|
| `تتبع` | 0 | 🔍 |
| `تصحيح` | 1 | 🐛 |
| `معلومة` | 2 | ℹ️ |
| `تحذير` | 3 | ⚠️ |
| `خطأ_مستوى` | 4 | ❌ |
| `حرج` | 5 | 🔥 |

### دوال الأسماء والرموز

| الدالة | الوصف |
|--------|-------|
| `_اسم_المستوى(المستوى)` | اسم المستوى ("تتبع"...) |
| `_رمز_المستوى(المستوى)` | رمز المستوى (🔍...) |

### صنف `مسجل`

| الدالة | الوصف |
|--------|-------|
| `باني(الاسم)` | إنشاء مسجل |
| `تتبع(الرسالة)` | تسجيل مستوى تتبع |
| `تصحيح(الرسالة)` | تسجيل مستوى تصحيح |
| `معلومة(الرسالة)` | تسجيل مستوى معلومة |
| `تحذير(الرسالة)` | تسجيل مستوى تحذير |
| `خطأ(الرسالة)` | تسجيل مستوى خطأ |
| `حرج(الرسالة)` | تسجيل مستوى حرج |
| `عيّن_المستوى(المستوى)` | تعيين مستوى التصفية |
| `عيّن_الحد(الحد)` | تعيين الحد الأقصى للرسائل |
| `فعّل()` | تفعيل المسجل |
| `عطّل()` | تعطيل المسجل |
| `عدد_الرسائل()` | عدد الرسائل المسجلة |
| `عدد_الأخطاء()` | عدد الأخطاء (خطأ + حرج) |
| `يوجد_أخطاء()` | هل يوجد أخطاء؟ |
| `السجل()` | الحصول على السجل كمصفوفة |
| `رسائل_بمستوى(المستوى)` | تصفية بمستوى |
| `امسح()` | مسح السجل |
| `اطبع_الكل()` | طباعة جميع الرسائل |

> **ملاحظة:** الدوال العامة (`سجل_تتبع`, `عيّن_المستوى`, إلخ) تعتمد على حالة
> مستوى الوحدة وقد لا تعمل عبر حدود الاستيراد. يُنصح باستخدام صنف `مسجل` بدلاً منها.
