# مكتبة ترميز 🔤

مكتبة للترميز والتشفير — تدعم الأنظمة العددية والشفرات والترميزات.

## التثبيت

```sad
من مكتبات_خارجية.ترميز.src.مكتبة استورد رقم_إلى_ثنائي, ترميز_url, قيصر_تشفير
```

## الاستخدام

### تحويل الأنظمة العددية

```sad
اطبع_سطر(رقم_إلى_ثنائي(42))        # 101010
اطبع_سطر(رقم_إلى_ست_عشري(255))     # ff
اطبع_سطر(ثنائي_إلى_رقم("101010"))   # 42
```

### شفرة قيصر

```sad
متغير مشفر = قيصر_تشفير("hello", 3)  # khoor
متغير أصلي = قيصر_فك(مشفر, 3)         # hello
```

### ترميز URL

```sad
اطبع_سطر(ترميز_url("hello world"))     # hello%20world
اطبع_سطر(فك_ترميز_url("hello%20world")) # hello world
```

## واجهة برمجة التطبيقات

### تحويل الأنظمة العددية

| الدالة | الوصف |
|--------|-------|
| `رقم_إلى_ست_عشري(الرقم)` | عدد إلى ست عشري |
| `ست_عشري_إلى_رقم(نص)` | ست عشري إلى عدد |
| `رقم_إلى_ثنائي(الرقم)` | عدد إلى ثنائي |
| `ثنائي_إلى_رقم(نص)` | ثنائي إلى عدد |
| `رقم_إلى_ثماني(الرقم)` | عدد إلى ثماني |

### الترميزات

| الدالة | الوصف |
|--------|-------|
| `ترميز_url(نص)` | ترميز URL |
| `فك_ترميز_url(نص)` | فك ترميز URL |
| `rot13(نص)` | تشفير ROT13 |
| `إلى_مورس(نص)` | تحويل إلى مورس |
| `rle_ترميز(نص)` | ترميز RLE |

### الشفرات

| الدالة | الوصف |
|--------|-------|
| `قيصر_تشفير(نص, إزاحة)` | تشفير قيصر |
| `قيصر_فك(نص, إزاحة)` | فك شفرة قيصر |

### أدوات النصوص

| الدالة | الوصف |
|--------|-------|
| `اعكس(نص)` | عكس النص |
| `متناظر(نص)` | هل النص متناظر؟ |
