# مكتبة مجموعات 📦

هياكل بيانات متقدمة — مكدس، طابور، مجموعة فريدة، قائمة مرتبطة، خريطة مرتبة.

## التثبيت

```sad
من مكتبات_خارجية.مجموعات.src.مكتبة استورد مكدس, طابور, مجموعة_فريدة
```

## الاستخدام

### مكدس (LIFO)

```sad
متغير م = جديد مكدس()
م.ادفع(1)
م.ادفع(2)
م.ادفع(3)
اطبع_سطر(م.اسحب())  # 3
اطبع_سطر(م.القمة()) # 2
```

### طابور (FIFO)

```sad
متغير ط = جديد طابور()
ط.أضف("أول")
ط.أضف("ثاني")
اطبع_سطر(ط.أزل())   # أول
```

### مجموعة فريدة

```sad
متغير مف = جديد مجموعة_فريدة()
مف.أضف(1)
مف.أضف(2)
مف.أضف(1)  # لن يُضاف (مكرر)
اطبع_سطر(مف.الحجم())  # 2
```

### قائمة مرتبطة

```sad
من مكتبات_خارجية.مجموعات.src.مكتبة استورد قائمة_مرتبطة
متغير ق = جديد قائمة_مرتبطة()
ق.أضف(10)
ق.أضف(20)
ق.أضف_أولاً(5)
اطبع_سطر(ق.الأول())  # 5
```

## واجهة برمجة التطبيقات

### صنف `مكدس` (Stack)

| الدالة | الوصف |
|--------|-------|
| `ادفع(القيمة)` | إضافة عنصر |
| `اسحب()` | سحب آخر عنصر |
| `القمة()` | قراءة آخر عنصر |
| `الحجم()` | عدد العناصر |
| `فارغ()` | فارغ؟ |
| `امسح()` | مسح الكل |

### صنف `طابور` (Queue)

| الدالة | الوصف |
|--------|-------|
| `أضف(القيمة)` | إضافة عنصر |
| `أزل()` | إزالة أول عنصر |
| `الأمام()` | قراءة أول عنصر |
| `الحجم()` | عدد العناصر |
| `فارغ()` | فارغ؟ |
| `امسح()` | مسح الكل |

### صنف `طابور_أولويات` (Priority Queue)

| الدالة | الوصف |
|--------|-------|
| `أضف(القيمة, الأولوية)` | إضافة مع أولوية |
| `أزل()` | إزالة الأعلى أولوية |
| `الحجم()` | عدد العناصر |
| `فارغ()` | فارغ؟ |

### صنف `مجموعة_فريدة` (Set)

| الدالة | الوصف |
|--------|-------|
| `أضف(القيمة)` | إضافة عنصر فريد |
| `أزل(القيمة)` | إزالة عنصر |
| `يحتوي(القيمة)` | يحتوي على؟ |
| `الحجم()` | عدد العناصر |
| `إلى_مصفوفة()` | تحويل لمصفوفة |
| `اتحاد(أخرى)` | اتحاد مجموعتين |
| `تقاطع(أخرى)` | تقاطع مجموعتين |

### صنف `قائمة_مرتبطة` (Linked List)

| الدالة | الوصف |
|--------|-------|
| `أضف(القيمة)` | إضافة في النهاية |
| `أضف_أولاً(القيمة)` | إضافة في البداية |
| `أزل_أولاً()` | إزالة الأول |
| `أزل_أخيراً()` | إزالة الأخير |
| `الأول()` | أول عنصر |
| `الأخير()` | آخر عنصر |
| `يحتوي(القيمة)` | يحتوي؟ |
| `الحجم()` | الحجم |
| `إلى_مصفوفة()` | تحويل لمصفوفة |

### صنف `خريطة_مرتبة` (Ordered Map)

| الدالة | الوصف |
|--------|-------|
| `عيّن(المفتاح, القيمة)` | تعيين قيمة |
| `احصل(المفتاح)` | الحصول على قيمة |
| `يحتوي(المفتاح)` | يحتوي على مفتاح؟ |
| `أزل(المفتاح)` | إزالة مفتاح |
| `المفاتيح()` | جميع المفاتيح |
| `القيم()` | جميع القيم |
| `الحجم()` | الحجم |

### صنف `عداد` (Counter)

| الدالة | الوصف |
|--------|-------|
| `أضف(العنصر)` | زيادة عداد عنصر |
| `عدّ(العنصر)` | تكرار عنصر |
