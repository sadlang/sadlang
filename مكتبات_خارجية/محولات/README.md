# مكتبة محولات 🔄

مكتبة شاملة لتحويل الوحدات — حرارة، مسافات، أوزان، بيانات، طاقة، وأكثر.

## التثبيت

```sad
من مكتبات_خارجية.محولات.src.مكتبة استورد سيليزي_إلى_فهرنهايت, كيلومتر_إلى_ميل
```

## الاستخدام

### تحويلات الحرارة

```sad
اطبع_سطر(سيليزي_إلى_فهرنهايت(100))  # 212
اطبع_سطر(سيليزي_إلى_كلفن(0))        # 273.15
```

### تحويلات المسافة

```sad
اطبع_سطر(كيلومتر_إلى_ميل(10))  # 6.21
اطبع_سطر(متر_إلى_قدم(1))       # 3.28
```

### الأرقام الرومانية

```sad
من مكتبات_خارجية.محولات.src.مكتبة استورد إلى_روماني
اطبع_سطر(إلى_روماني(2025))  # MMXXV
```

### محول مخصص

```sad
من مكتبات_خارجية.محولات.src.مكتبة استورد محول
متغير م = جديد محول()
م.أضف_تحويل("متر", "سم", 100)
اطبع_سطر(م.حوّل(5, "متر", "سم"))  # 500
```

## واجهة برمجة التطبيقات

### الحرارة

| الدالة | التحويل |
|--------|---------|
| `سيليزي_إلى_فهرنهايت(درجة)` | °C → °F |
| `فهرنهايت_إلى_سيليزي(درجة)` | °F → °C |
| `سيليزي_إلى_كلفن(درجة)` | °C → K |
| `كلفن_إلى_سيليزي(درجة)` | K → °C |

### المسافات

| الدالة | التحويل |
|--------|---------|
| `كيلومتر_إلى_ميل(كم)` | كم → ميل |

| `متر_إلى_قدم(متر)` | م → قدم |
| `قدم_إلى_متر(قدم)` | قدم → م |
| `سنتيمتر_إلى_بوصة(سم)` | سم → بوصة |
