# مكتبة إحصائيات 📊

مكتبة شاملة للإحصاء والتحليل الرقمي بلغة ص.

## التثبيت

```sad
من مكتبات_خارجية.إحصائيات.src.مكتبة استورد المتوسط, الوسيط, الانحراف_المعياري
```

## الاستخدام

### الإحصاءات الأساسية

```sad
متغير بيانات = [10, 20, 30, 40, 50]
اطبع_سطر("المتوسط: " + المتوسط(بيانات))          # 30
اطبع_سطر("الوسيط: " + الوسيط(بيانات))            # 30
اطبع_سطر("الانحراف: " + الانحراف_المعياري(بيانات))
```

### ملخص إحصائي

```sad
من مكتبات_خارجية.إحصائيات.src.مكتبة استورد ملخص
متغير م = جديد ملخص(بيانات)
اطبع_سطر("المتوسط: " + م.المتوسط)
اطبع_سطر("التباين: " + م.التباين)
```

### الارتباط والانحدار

```sad
من مكتبات_خارجية.إحصائيات.src.مكتبة استورد الارتباط, الانحدار_الخطي
متغير س = [1, 2, 3, 4, 5]
متغير ص = [2, 4, 5, 4, 5]
اطبع_سطر("الارتباط: " + الارتباط(س, ص))
```

## واجهة برمجة التطبيقات

### دوال أساسية

| الدالة | الوصف |
|--------|-------|
| `العدد(البيانات)` | عدد العناصر |
| `المجموع(البيانات)` | مجموع العناصر |
| `المتوسط(البيانات)` | المتوسط الحسابي |
| `الأصغر(البيانات)` | أصغر قيمة |
| `الأكبر(البيانات)` | أكبر قيمة |
| `المدى(البيانات)` | المدى |
| `رتّب(البيانات)` | ترتيب تصاعدي |
| `الوسيط(البيانات)` | الوسيط |
| `التباين(البيانات)` | التباين |
| `الانحراف_المعياري(البيانات)` | الانحراف المعياري |
| `المنوال(البيانات)` | المنوال |
| `التكرارات(البيانات)` | أزواج [قيمة, تكرار] |

### دوال متقدمة

| الدالة | الوصف |
|--------|-------|
| `المتوسط_الهندسي(البيانات)` | المتوسط الهندسي |
| `المتوسط_التوافقي(البيانات)` | المتوسط التوافقي |
| `المئين(البيانات, النسبة)` | المئين بنسبة |
| `الربيع_الأول(البيانات)` | الربع الأول Q1 |
| `الربيع_الثالث(البيانات)` | الربع الثالث Q3 |
| `المدى_الربيعي(البيانات)` | المدى الربيعي IQR |
| `التباين_المشترك(س, ص)` | التباين المشترك |
| `الارتباط(س, ص)` | معامل الارتباط |
| `الانحدار_الخطي(س, ص)` | الانحدار الخطي [ميل, تقاطع] |
| `المتوسط_المتحرك(البيانات, حجم)` | المتوسط المتحرك |
| `النتيجة_المعيارية(القيمة, البيانات)` | Z-score |
| `التطبيع(البيانات)` | التطبيع [0-1] |
| `المتوسط_المرجح(القيم, الأوزان)` | المتوسط المرجح |

### صنف `ملخص`

يوفر ملخصاً إحصائياً كاملاً مع الخصائص: `العدد`, `المجموع`, `المتوسط`, `الوسيط`, `المنوال`, `الأصغر`, `الأكبر`, `المدى`, `التباين`, `الانحراف`, `ر1`, `ر3`.
