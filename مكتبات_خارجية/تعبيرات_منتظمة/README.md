# مكتبة تعبيرات_منتظمة 🔍

مكتبة للتعبيرات النمطية — بحث ومطابقة واستبدال النصوص.

## التثبيت

```sad
من مكتبات_خارجية.تعبيرات_منتظمة.src.مكتبة استورد تعبير, بحث, استبدل
```

## الاستخدام

### بحث بسيط

```sad
من مكتبات_خارجية.تعبيرات_منتظمة.src.مكتبة استورد يحتوي, بحث_الكل
اطبع_سطر(يحتوي("[0-9]+", "عمري 25 سنة"))  # صحيح
```

### تعبير مترجم

```sad
متغير ت = جديد تعبير("[a-z]+@[a-z]+\\.[a-z]+")
اطبع_سطر(ت.يحتوي("email@test.com"))   # صحيح
اطبع_سطر(ت.بحث("email@test.com").نص)  # email@test.com
```

### استبدال

```sad
متغير نتيجة = استبدل_الكل("[0-9]+", "abc123def456", "X")
اطبع_سطر(نتيجة)  # abcXdefX
```

## واجهة برمجة التطبيقات

### صنف `تعبير`

| الدالة | الوصف |
|--------|-------|
| `باني(نمط, أعلام)` | إنشاء تعبير مترجم |
| `تطابق(نص)` | مطابقة كاملة (1/0) |
| `بحث(نص)` | أول مطابقة |
| `يحتوي(نص)` | يحتوي على مطابقة؟ |
| `بحث_الكل(نص)` | جميع المطابقات |
| `استبدل(نص, البديل)` | استبدال أول مطابقة |
| `استبدل_الكل(نص, البديل)` | استبدال جميع المطابقات |
| `تقسيم(نص, الحد)` | تقسيم بالنمط |
| `استخرج_الكل(نص)` | استخراج جميع المطابقات |

### دوال مختصرة

| الدالة | الوصف |
|--------|-------|
| `تطابق(نمط, النص, أعلام)` | مطابقة كاملة |
| `بحث(نمط, النص, أعلام)` | بحث عن نمط |
| `بحث_الكل(نمط, النص, أعلام)` | بحث عن الكل |
| `استبدل(نمط, النص, البديل, أعلام)` | استبدال |
| `استبدل_الكل(نمط, النص, البديل, أعلام)` | استبدال الكل |
| `تقسيم(نمط, النص, الحد, أعلام)` | تقسيم |
| `يحتوي(نمط, النص, أعلام)` | يحتوي؟ |
| `استخرج_الكل(نمط, النص, أعلام)` | استخراج الكل |

### صنف `أعلام`

خصائص: `تجاهل_حالة`, `متعدد_أسطر`, `نقطة_شاملة`, `يونيكود_حدود`, `بلا_علم`

### صنف `نتيجة_مطابقة`

خصائص: `نص`, `بداية`, `نهاية`, `مجموعات`
دوال: `مجموعة(رقم)`, `مجموعة_مسماة(الاسم)`, `اعرض()`
