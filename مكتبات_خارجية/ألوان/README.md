# مكتبة ألوان 🎨

مكتبة للتعامل مع الألوان بلغة ص — تدعم RGB و HSL والتحويل بينهما.

## التثبيت

```sad
من مكتبات_خارجية.ألوان.src.مكتبة استورد لون, لوحة
```

## الاستخدام

### إنشاء لون

```sad
متغير أحمر = جديد لون(255, 0, 0)
اطبع_سطر(أحمر.نص())     # rgb(255, 0, 0)
اطبع_سطر(أحمر.سداسي())   # #ff0000
```

### مزج الألوان

```sad
متغير أزرق = جديد لون(0, 0, 255)
متغير بنفسجي = أحمر.مزج(أزرق, 0.5)
اطبع_سطر(بنفسجي.نص())   # rgb(127, 0, 127)
```

### تعديل الإضاءة

```sad
متغير فاتح = أحمر.أفتح(0.3)
متغير غامق = أحمر.أغمق(0.3)
```

### لوحة ألوان

```sad
متغير ل = جديد لوحة("ألوان أساسية")
ل.أضف("أحمر", جديد لون(255, 0, 0))
ل.أضف("أخضر", جديد لون(0, 255, 0))
ل.اعرض()
```

## واجهة برمجة التطبيقات

### صنف `لون`

| الدالة | الوصف |
|--------|-------|
| `باني(أحمر, أخضر, أزرق)` | إنشاء لون RGB (0-255) |
| `نص()` | تمثيل نصي `rgb(r, g, b)` |
| `سداسي()` | تمثيل ست عشري `#rrggbb` |
| `مزج(لون_آخر, نسبة)` | مزج لونين بنسبة 0-1 |
| `أفتح(نسبة)` | تفتيح اللون |
| `أغمق(نسبة)` | تغميق اللون |
| `إضاءة()` | حساب الإضاءة (0-255) |
| `هل_فاتح()` | هل اللون فاتح؟ |
| `هل_غامق()` | هل اللون غامق؟ |
| `عكس()` | اللون المعكوس (المكمل) |
| `رمادي()` | تحويل إلى رمادي |
| `يساوي(لون_آخر)` | هل اللونان متساويان؟ |
| `المسافة(لون_آخر)` | المسافة الإقليدية |
| `التباين(لون_آخر)` | نسبة التباين |
| `إلى_hsl()` | تحويل إلى HSL |
| `مع_شفافية(ألفا)` | إضافة شفافية |
| `تشبع(نسبة)` | تعديل التشبع |
| `نسخة()` | نسخة من اللون |

### صنف `لوحة`

| الدالة | الوصف |
|--------|-------|
| `باني(الاسم)` | إنشاء لوحة جديدة |
| `أضف(الاسم, اللون)` | إضافة لون |
| `العدد()` | عدد الألوان |
| `لون_بالترتيب(ن)` | لون حسب الترتيب |
| `اسم_بالترتيب(ن)` | اسم لون حسب الترتيب |
| `اعرض()` | عرض اللوحة |
