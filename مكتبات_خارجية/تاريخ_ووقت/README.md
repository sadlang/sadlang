# مكتبة تاريخ_ووقت 📅

مكتبة للتعامل مع التواريخ والأوقات — تدعم التقويم الميلادي والهجري.

## التثبيت

```sad
من مكتبات_خارجية.تاريخ_ووقت.src.مكتبة استورد تاريخ, وقت, تاريخ_ووقت
```

## الاستخدام

### التاريخ

```sad
متغير ت = جديد تاريخ(2025, 1, 15)
اطبع_سطر(ت.نص())           # 2025-1-15
اطبع_سطر(ت.يوم_الأسبوع()) # الأربعاء
اطبع_سطر(ت.هل_كبيسة())    # خطأ
```

### الوقت

```sad
متغير و = جديد وقت(14, 30, 0)
اطبع_سطر(و.نص())           # 14:30:0
اطبع_سطر(و.إلى_ثوانٍ())   # 52200
```

### التاريخ والوقت معاً

```sad
متغير تو = جديد تاريخ_ووقت(ت, و)
اطبع_سطر(تو.نص_كامل())
```

### التنسيق

```sad
من مكتبات_خارجية.تاريخ_ووقت.src.مكتبة استورد تاريخ_كامل, تاريخ_iso
اطبع_سطر(تاريخ_كامل(ت))    # الأربعاء 15 يناير 2025
اطبع_سطر(تاريخ_iso(ت))     # 2025-01-15
```

## واجهة برمجة التطبيقات

### صنف `تاريخ`

| الدالة | الوصف |
|--------|-------|
| `باني(السنة, الشهر, اليوم)` | إنشاء تاريخ |
| `نص()` | تمثيل نصي |
| `هل_كبيسة()` | سنة كبيسة؟ |
| `أيام_الشهر()` | عدد أيام الشهر |
| `يوم_الأسبوع()` | اسم يوم الأسبوع |
| `أضف_أيام(عدد)` | إضافة أيام |

### صنف `وقت`

| الدالة | الوصف |
|--------|-------|
| `باني(الساعة, الدقيقة, الثانية)` | إنشاء وقت |
| `نص()` | تمثيل نصي |
| `إلى_ثوانٍ()` | تحويل إلى ثوانٍ |
| `أضف_دقائق(عدد)` | إضافة دقائق |

### صنف `موقت`

| الدالة | الوصف |
|--------|-------|
| `باني()` | إنشاء موقت |
| `ابدأ(الوقت)` | بدء التوقيت |
| `سجل(الاسم, الوقت)` | تسجيل حدث |
| `اطبع_الأحداث()` | طباعة الأحداث |

### دوال التنسيق

| الدالة | الوصف |
|--------|-------|
| `تاريخ_كامل(ت)` | "الأربعاء 15 يناير 2025" |
| `تاريخ_مختصر(ت)` | "15/01/2025" |
| `تاريخ_iso(ت)` | "2025-01-15" |
| `وقت_12_ساعة(و)` | تنسيق 12 ساعة |
| `اسم_الشهر(رقم)` | اسم الشهر الميلادي |
| `اسم_الشهر_هجري(رقم)` | اسم الشهر الهجري |
| `اسم_اليوم(رقم)` | اسم اليوم (0=السبت) |

### دوال الحساب

| الدالة | الوصف |
|--------|-------|
| `الفرق_بالأيام(ت1, ت2)` | الفرق بالأيام |
| `يوم_السنة(ت)` | رقم اليوم في السنة |
| `رقم_الأسبوع(ت)` | رقم الأسبوع |
| `أضف_أشهر(ت, عدد)` | إضافة أشهر |
| `أضف_سنوات(ت, عدد)` | إضافة سنوات |
| `قبل(ت1, ت2)` | هل ت1 قبل ت2؟ |
| `تاريخ_متساوي(ت1, ت2)` | هل التاريخان متساويان؟ |
