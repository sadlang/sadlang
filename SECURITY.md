# Security Policy

## Supported Versions
The project currently supports security updates for:
- `main` (latest)
- latest stable release tag (when published)

## Reporting a Vulnerability
Please do not open public issues for security vulnerabilities.

Report privately via:
- security@sad-lang.org

Include:
- A clear description of the issue
- Steps to reproduce
- Potential impact
- Suggested mitigation (if available)

## Response Process
- Initial acknowledgement: within 72 hours
- Triage and severity assessment: within 7 days
- Fix timeline: based on severity and release cycle

## Disclosure
We follow coordinated disclosure. Public disclosure is made after a fix is prepared,
tested, and released (or mitigation guidance is available).
